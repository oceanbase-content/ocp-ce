# Manage SSL encryption

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

OceanBase Database supports Secure Sockets Layer (SSL) encryption to enhance the security of communication between nodes. When SSL encryption is enabled, network connections are encrypted at the transport layer, preventing communication traffic from being intercepted or modified. This ensures the security of communication data. SSL encryption applies to Remote Procedure Call (RPC) communication between OceanBase databases, communication between OceanBase Database Proxy (OBProxy) and OceanBase databases, and communication between business applications and OBProxy. After SSL encryption is enabled, clients can establish connections using SSL authentication or general authentication.

This topic describes the procedure for managing SSL encryption.

## Enable SSL encryption for cluster communication<a id="parameter"></a>

After you enable SSL encryption for cluster communication, the cluster performance will slightly degrade (transmitting and decrypting data consumes a certain amount of computing resources). We recommend that you enable SSL encryption for cluster communication only when you need to connect to the Internet or when you need to encrypt data transmission.

### Prerequisites

* The login user of the OCP console is the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is of V4.x or later.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab automatically appears.

5. Click **<UI-TERM key="ocp-v2.TrendAndOutline.SQLLimit.Enable">Enable</UI-TERM>**. In the dialog box that appears, select an SSL server certificate and click **<UI-TERM key="ocp-v2.TrendAndOutline.SQLLimit.Enable">Enable</UI-TERM>**.

   If the required certificate is not available in the drop-down list, click [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to add it.

## Disable SSL encryption

This topic describes how to disable SSL encryption. This operation takes a few minutes. Please wait.

### Prerequisites

* You are logged in to the OCP console as a user with the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is of V4.x or later.

* SSL encryption is enabled. For more information, see [Enable SSL encryption](#parameter).

* The SSL server certificate has not expired.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab automatically appears.

5. In the upper-right corner of the page, click **<UI-TERM key="ocp-v2.component.SecurityCard.TurnOffEncryption">Disable Encryption</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.CgroupEditModal.Close">Disable</UI-TERM>**.

## Update an SSL server certificate

When an SSL server certificate is about to expire or has expired, you can update the SSL server certificate online. After you reissue the encryption certificate, the previously created SSL connections continue to be valid, but new connections fail. You must pay attention to these changes.

### Prerequisites

* The login user of the OCP console is the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster version is V4.x or later.

* SSL encryption is enabled. For more information, see [Enable SSL encryption](#parameter).

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list on the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page, find the target cluster and click its name.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab is displayed by default.

5. In the upper-right corner of the page, click **Update SSL Server Certificate**. In the dialog box that appears, select the name of the SSL server certificate and click **<UI-TERM key="ocp-v2.src.constant.iam.Update">Update</UI-TERM>**.

   If the required certificate is not in the drop-down list, click [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to add it.

## Download the CA certificate

You can download the CA certificate as a compressed package to your local device and save it. The package contains the following three files:

* `p7b` file: used to import the CA certificate in Windows.

* `pem` file: used to import the CA certificate in other systems or applications.

* `jks` file: the truststore certificate file in Java. The password is OceanBase. It is used to import the CA certificate chain in a Java program.

### Prerequisites

* You are logged in to OCP as a user of the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is of V4.x or later.

* [SSL encryption is enabled](#parameter).

* The SSL server certificate has not expired.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Monitor.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab automatically appears.

5. Click **<UI-TERM key="ocp-v2.SecurityCard.SSL.DownloadCaCertificate">Download CA Certificate</UI-TERM>**.
