# Manage SSL link encryption

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature.</p>
</main>

To enhance link security, OceanBase Database supports SSL (Secure Sockets Layer) link encryption. By encrypting network connections at the transport layer, SSL ensures that communication traffic between nodes is not intercepted or tampered with, thereby improving the security of communication data. SSL link encryption can be applied to RPC communication between OceanBase Database nodes, communication between OBProxy and OceanBase Database, and communication between business applications and OBProxy. After enabling SSL link encryption, clients can establish connections using either SSL authentication or general authentication.

This topic describes how to manage SSL link encryption.

## Enable SSL link encryption<a id="parameter"></a>

After SSL link encryption is enabled, the cluster performance will slightly decrease (data transmission encryption and decryption consume some computing resources). We recommend that you enable SSL link encryption only when the cluster needs to connect to the Internet or requires data transmission encryption.

### Prerequisites

* You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is of V4.x or later.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** list, find the target cluster, click its name, and go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears by default.

5. Click **<UI-TERM key="ocp-v2.component.TraceTimelineDrawer.Open">Enable</UI-TERM>**. In the dialog box that appears, select the name of the SSL server certificate and click **<UI-TERM key="ocp-v2.Statistics.components.AutoCollectionDrawer.Enable">Enable</UI-TERM>**.

   If the required certificate is not in the drop-down list, you can click [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to upload it.

## Disable SSL link encryption

This topic describes how to disable SSL link encryption. Disabling SSL link encryption is a minute-level operation. Please wait patiently.

### Prerequisites

* You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is of V4.x or later.

* SSL link encryption has been enabled. For more information, see [Enable SSL link encryption](#parameter).

* The SSL server certificate has not expired.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.Arbitration.Cluster.1">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list, find the target cluster, click its name, and go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears by default.

5. Click **<UI-TERM key="ocp-v2.component.SecurityCard.TurnOffEncryption">Disable Encryption</UI-TERM>** in the upper-right corner. In the dialog box that appears, click **<UI-TERM key="ocp-v2.External.Component.DataSourceTable.Close">Close</UI-TERM>**.

## Update the SSL server certificate

When the SSL server certificate is about to expire or has expired, you can update it online. After the new certificate is generated, the existing SSL links will continue to work, but new links will fail. Please be aware of these changes.

### Prerequisites

* You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is of V4.x or later.

* SSL link encryption has been enabled. For more information, see [Enable SSL link encryption](#parameter).

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.component.TenantLabel.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** list, find the target cluster, click its name, and go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears by default.

5. Click **Update SSL Server Certificate** in the upper-right corner. In the dialog box that appears, select the name of the SSL server certificate and click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLLimit.Update">Update</UI-TERM>**.

   If the required certificate is not in the drop-down list, you can click [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to upload it.

## Download the CA certificate

You can download the CA certificate in a compressed package to your local device. The compressed package contains the following three files:

* `.p7b` file: used to import the CA certificate on Windows.

* `.pem` file: used to import the CA certificate on other systems or applications.

* `.jks` file: the truststore certificate storage file in Java. The password is OceanBase, and it is used to import the CA certificate chain in Java programs.

### Prerequisites

* The user logged in to the OCP console must be of the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster must be of V4.x or later.

* SSL link encryption is enabled. For more information, see [Enable SSL link encryption](#parameter).

* The SSL server certificate has not expired.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.inspection.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** list, find the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears.

5. Click **<UI-TERM key="ocp-v2.SecurityCard.SSL.DownloadCaCertificate">Download CA Certificate</UI-TERM>**.
