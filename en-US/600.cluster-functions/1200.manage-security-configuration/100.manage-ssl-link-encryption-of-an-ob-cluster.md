# Manage SSL link encryption

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature.</p>
</main>

To enhance link security, OceanBase Database supports SSL (Secure Sockets Layer) link encryption. By encrypting network connections at the transport layer, it ensures that communication traffic between nodes remains unmonitored and unaltered, thereby improving the security of transmitted data. SSL link encryption can be applied to RPC communications between OceanBase databases, between OBProxy and OceanBase, and between business applications and OBProxy. After enabling SSL link encryption, clients can establish connections using either SSL authentication or general authentication.

This topic describes how to manage SSL link encryption.

## Enable SSL encryption for links

After SSL connection encryption is enabled, the performance of the cluster is slightly affected. Therefore, we recommend that you enable SSL connection encryption only when an external network connection or data encryption is required.

### Prerequisites

* Make sure the user logged in to OCP is of **ADMIN** or **ORG_ADMIN** role.

* OceanBase Database cluster is of V4.x or later.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.component.alarm.Search.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** list, click the name of the target cluster to go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the cluster.

4. On the left navigation pane of the displayed page, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab is displayed by default.

5. Click **<UI-TERM key="ocp-v2.TrendAndOutline.SQLLimit.Enable">Enable</UI-TERM>**, select the SSL server certificate name in the dialog box, and click **<UI-TERM key="ocp-v2.Information.Detail.InformationCollectDrawer.Enable">Enable</UI-TERM>**.

   If the desired certificate is not listed, click [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to add it.

## Disable SSL Link Encryption

This topic describes how to disable link encryption. Disabling link encryption takes a few minutes. Please be patient.

### Prerequisites

* Make sure the user logged in to OCP has the **ADMIN** or **ORG_ADMIN** role.

* An OceanBase cluster of V4.x or a later version.

* [SSL link encryption is enabled](#enable-ssl-link-encryption).

* The SSL server certificate has not expired.

### Procedure

1. Log in to the OCP console.

2. In the left navigation pane, click **<UI-TERM key="ocp-v2.page.Cluster.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** section, choose the target cluster and click its name to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster.

4. On the left navigation pane of the displayed page, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**, which displays the **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab by default.

5. In the upper-right corner, click **<UI-TERM key="ocp-v2.component.SecurityCard.TurnOffEncryption">Disable Encryption</UI-TERM>**, and then click **<UI-TERM key="ocp-v2.Backup.Component.RestoreTenantCard.Close">Close</UI-TERM>** in the dialog box.

## Update SSL Server certificate

When the SSL server certificate is about to expire or has already expired, you can update the SSL server certificate online. After the encryption certificate is regenerated, existing SSL links will still be effective, but new links will fail. Please be aware of these changes.

### Prerequisites

* Make sure that the current login user is **ADMIN** role or **ORG_ADMIN** role on the OCP console.

* The cluster version of OceanBase is V4.x or later.

* SSL encryption is [enabled for the link](#enable-ssl-link-encryption).

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Alarm.LogFilter.Cluster">Cluster</UI-TERM>**. The system displays the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, click the name of the target cluster to go to its **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page.

4. On the left navigation pane of the displayed page, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab is displayed by default.

5. Click **Update SSL Server Certificate** in the upper-right corner. In the dialog box, select the name of the SSL server certificate and click **<UI-TERM key="ocp-v2.src.constant.iam.Update">Update</UI-TERM>**.

   If the required certificate is missing from the drop-down list, you can add the certificate by choosing [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md).

## Download the CA certificate

Supports downloading CA certificates as a compressed package to your local storage. The compressed package includes the following three files:

* `p7b` file: For importing CA certificate on Windows.

* `pem` file: to import the CA certificate into another system or application.

* `jks` files: truststore files that store certificates in Java. The password is OceanBase, which is used to import a CA certificate chain in a Java program.

### Prerequisites

* Make sure that the current logged-in user is in the **ADMIN** or **ORG_ADMIN** role.

* OceanBase Database cluster is of V4.x or later.

* [SSL encryption for link](#enable-ssl-encryption) is enabled.

* The SSL server certificate has not expired.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">Cluster</UI-TERM>**. The system displays the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page by default.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, click the name of the cluster you want to operate. The **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page of the cluster is displayed.

4. In the left-side navigation pane of the displayed page, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. By default, the **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears.

5. Click **<UI-TERM key="ocp-v2.SecurityCard.SSL.DownloadCaCertificate">Download CA Certificate</UI-TERM>**.
