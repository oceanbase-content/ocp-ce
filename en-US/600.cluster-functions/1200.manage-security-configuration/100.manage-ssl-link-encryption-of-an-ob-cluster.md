# Manage SSL Link Encryption

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not provide this feature.</p>
</main>

To enhance link security, OceanBase Database connections support enabling Secure Sockets Layer (SSL) link encryption. By encrypting network connections at the transport layer, it ensures that communication traffic between nodes is not monitored or tampered with, thereby improving the security of communication data. SSL link encryption can be applied to RPC communications between OceanBases, communications between OBProxy and OceanBase, and communications between business applications and OBProxy. After enabling SSL link encryption, clients can establish connections using either SSL authentication or general authentication.

This page describes the procedure for managing SSL link encryption.

## Enable SSL Link Encryption<a id="parameter"></a>

Enabling SSL link encryption may slightly impact cluster performance, as data encryption and decryption consume computational resources. It is recommended to enable SSL link encryption only when external network connections are required or when transmission encryption is needed.

### Prerequisites

* Ensure the current user logged in to OCP has the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is version V4.x or later.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.constant.report.Cluster">Cluster</UI-TERM>**. The system enters the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page by default.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, select the target cluster and click its name to go to the cluster **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page.

4. In the left navigation bar of the displayed page, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab is displayed by default.

5. Click **<UI-TERM key="ocp-v2.component.OperationConfig.List.Enable">Enable</UI-TERM>**, select an SSL server certificate name in the dialog box, and click **<UI-TERM key="ocp-v2.Detail.Overview.Enable">Enable</UI-TERM>**.

   If the required certificate is missing from the drop-down list, you can click [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to add it.

## Disable SSL Link Encryption

This section describes how to disable SSL link encryption. Disabling SSL link encryption is a minute-level operation; please be patient.

### Prerequisites

* Ensure the current user logged in to OCP has the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is version V4.x or later.

* SSL link encryption has been [enabled](#parameter).

* The SSL server certificate has not expired.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.inspection.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page appears by default.

3. On the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name. The cluster **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page appears.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears by default.

5. Click **<UI-TERM key="ocp-v2.component.SecurityCard.TurnOffEncryption">Disable Encryption</UI-TERM>** in the upper-right corner, then click **<UI-TERM key="ocp-v2.Component.CgroupEditModal.Close">Disable</UI-TERM>** in the dialog box.

## Update SSL Server certificate

You can update the SSL server certificate online when it is about to expire or has expired. After the encryption certificate is regenerated, the previously created SSL links will continue to be valid, but new links will fail. You need to be aware of this change.

### Prerequisites

* Ensure that the current user logged in to OCP has the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is version V4.x or later.

* [SSL link encryption](#parameter) is enabled.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.plan.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page appears by default.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, find the target cluster and click its name. The cluster **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page appears.

4. In the left-side navigation pane of the page that appears, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears by default.

5. Click **Update SSL Server Certificate** in the upper-right corner. In the dialog box, select the SSL server certificate name and click **<UI-TERM key="ocp-v2.SecurityCard.SSL.EnableSSL.Update">Update</UI-TERM>**.

   If the required certificate is missing from the drop-down list, you can click [Upload Certificate](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to add it.

## Download the CA certificate

You can download the CA certificate to your local device as a compressed package. The package contains the following three files:

* `p7b` file: used to import the CA certificate on Windows systems.

* `pem` file: used to import the CA certificate on other systems or in applications.

* `jks` file: a Java TrustStore certificate storage file with the password set to OceanBase. It is used to import the CA certificate chain in Java programs.

### Prerequisites

* Ensure the current OCP user is in the **ADMIN** or **ORG_ADMIN** role.

* The OceanBase cluster is V4.x or later.

* SSL link encryption is [enabled](#parameter).

* The SSL server certificate has not expired.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Cluster">Cluster</UI-TERM>**. The system enters the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page by default.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, select the target cluster and click its name to go to the cluster **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page.

4. In the left navigation bar of the displayed page, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab is displayed by default.

5. Click **<UI-TERM key="ocp-v2.src.constant.security.DownloadCaCertificate">Download CA Certificate</UI-TERM>**.
