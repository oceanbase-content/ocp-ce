# Delete a zone

This topic describes how to delete a zone from a cluster. This operation removes all OBServer nodes and data on the current zone from the OceanBase cluster and releases the host. Proceed with caution.


## Background information

* If the number of zones in a cluster is even, it cannot meet high availability requirements for data, posing a data security risk. We recommend that you adjust the configuration to maintain an odd number of zones or enable the arbitration service for the cluster or tenant.
* When a cluster is changed to single-zone multi-host mode, it only expands the computing capability of the OceanBase service and does not provide high availability through multiple replicas. It is suitable for development and test environments.
* When a cluster is changed to single-zone single-host mode, there is only one data replica, which does not support multiple replicas or scaling. Data loss may occur in case of storage or hardware failure. We recommend that you perform regular backups for important business systems or configure high availability solutions, such as primary/standby tenants or multi-replica disaster recovery, to avoid single points of failure.

## Prerequisites

* Ensure the current OCP user has the following permissions:

  * **Cluster Maintenance** resource permissions.
  * Permission to access the cluster **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu.

* Your OceanBase cluster is managed by the current OCP.

  If it is not, you can refer to [Take over a cluster](../300.manage-a-cluster/400.take-over-a-cluster.md) to take over your OceanBase cluster to the current OCP.
  
* Deleting a zone is not supported for a single-node cluster.

* Ensure the zone to be deleted does not host the primary replica of any tenant. If it does, ensure the tenant has another full-featured replica available. Otherwise, deleting this zone will cause business interruption that cannot be recovered.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.Cluster">Cluster</UI-TERM>**. The system goes to the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** tab by default.

3. On the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page, select the target cluster and click its name.

4. On the cluster **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page, in the **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">Zones</UI-TERM>** section, click **More > Delete** in the **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Operation">Actions</UI-TERM>** column.

   <!-- ![11181759](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%88%A0%E9%99%A4zone.png) -->

   A confirmation dialog box appears.

5. In the dialog box, click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Delete">Delete</UI-TERM>**.

   You can view the deletion progress via the **<UI-TERM key="ocp-v2.src.constant.ViewTasks">View Tasks</UI-TERM>** button in the dialog box, or check the progress of this task in **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**.

   The deletion is successful when the task status is **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">Complete</UI-TERM>** and the zone no longer appears in the **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">Zones</UI-TERM>** on the cluster **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page.
