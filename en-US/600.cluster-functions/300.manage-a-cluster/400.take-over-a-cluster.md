# Takeover a cluster

You can take over a cluster that is created through obscure screen operation or other OCPs by using OCP, and then continue to operate and manage the cluster by using OCP.

## Prerequisites

* You have logged in to the OCP console with an account that has the **ADMIN** or **ORG_ADMIN** role.

* All OBServer nodes in the OceanBase cluster are running.

* Observe the following rules to take over an OceanBase cluster:

  * In a single OCP scenario, take over the primary OceanBase cluster first, and then take over the standby OceanBase cluster.

  * In an OCP multi-cluster scenario, take over the primary OceanBase cluster in one OCP, and then take over the standby OceanBase cluster from any OCP.

* Service names of tenants in the OceanBase cluster to be taken over must be unique from those of existing services in the system. Otherwise, the service names of tenants with name conflicts in the OceanBase cluster will be marked as **Invalid** after the takeover. For more information about service names, see [Manage service names](../../700.tenant-functions/600.manage-a-tenant/800.manage-service-name.md).

* If the cluster to be taken over is deployed by obd, before the takeover, check whether the cluster meets the takeover requirements. For more information, see [Take over an obd-deployed cluster](https://www.oceanbase.com/docs/community-obd-cn-1000000001477802).

## Considerations

* After the OceanBase cluster is taken over, it cannot be properly operated and monitored within the original OCP cluster. Therefore, proceed with caution before you take over an OceanBase cluster.
* If the cluster to be taken over has been configured with a load type, you must configure a load type for the cluster on the **Overview** page after the cluster is taken over.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.src.constant.alarm.Cluster">Cluster</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, click **<UI-TERM key="ocp-v2.page.Cluster.TakeOverTheCluster">Take over Cluster</UI-TERM>** in the upper-right corner.

4. Select the **<UI-TERM key="ocp-v2.Cluster.Import.DirectlyConnected">Direct Connection</UI-TERM>** or **OBProxy** option to connect to the cluster.

   * **Direct Connect**: Enter the cluster's access **<UI-TERM key="ocp-v2.MultiCluster.Detail.Endpoint">Access URL</UI-TERM>**, port, and **<UI-TERM key="ocp-v2.Cluster.Import.RootSysPassword">Root@sys Password</UI-TERM>**. You can also enter the password for the **proxyro** account. Then, click **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step1.NextStep">Next</UI-TERM>**.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>The password for the proxyro account is used for OBProxy to access the OceanBase cluster. You can enter the password here to ensure consistency of the proxyro password. For more information about the proxyro account, see <a href="../../800.obproxy-functions/300.manage-a-obproxy-cluster/900.proxyro-user-management.md">Manage the proxyro account</a>. </p>
      </main>

   * **<UI-TERM key="ocp-v2.Detail.Component.RestartObproxyModal.Obproxy">ODP:</UI-TERM>**, port, **<UI-TERM key="ocp-v2.Detail.Component.FailoverDrawer.ClusterName">Cluster Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Cluster.Import.ClusterIdOptional">Cluster ID (Optional)</UI-TERM>**, and **<UI-TERM key="ocp-v2.Cluster.New.RootSysPassword">Root@sys Password</UI-TERM>**. You can also enter the password for the **proxyro** account. Then, click **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.NextStep">Next</UI-TERM>**.

5. After the cluster is connected, the take-over check starts.

   * If the check passes, if the hosts corresponding to some OBServer nodes are not managed by OCP, you must select credentials for these hosts so that OCP can manage them uniformly.

   * If the check fails, modify the OBServer node configurations as prompted and then click **<UI-TERM key="ocp-v2.Cluster.Import.ReCheck">Recheck</UI-TERM>**.

   ![09010928](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%8E%A5%E7%AE%A1%E9%9B%86%E7%BE%A41.png)

6. Click **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.Submitted">Submit</UI-TERM>**.

   After the task is submitted, you can view the task progress on the task result page or return to the cluster overview page.
