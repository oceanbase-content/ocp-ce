# View tenant-level information

This topic describes how to view the primary-standby relationship, major compaction details, and data backup progress at the tenant level in a cluster.

## Prerequisites

* Ensure that the current OCP user has at least the following permissions:

  * **Cluster Read-Only** resource permission.
  * Permission to access the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** menu.

* The current cluster version is V4.0.0.0 or later.

## Procedure

1. Log in to OCP.

2. In the left navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">Cluster</UI-TERM>**. The system goes to the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** tab by default.

3. In the cluster list, select the target cluster and click its name.

4. On the cluster **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page, click the **...** icon in the upper-right corner and select **<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.ViewTenantLevelInformation">View Tenant-level Information</UI-TERM>**.

5. In the panel that appears, view the tenant-level information of the cluster on different tabs.

   * **<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.PrimaryAndSecondaryTenants">Primary and Standby Tenants</UI-TERM>**: Details about the primary and standby tenants in the cluster, including the primary tenant (`cluster name/primary tenant name`), standby tenant (`cluster name/standby tenant name`), status, synchronization method, primary-standby protection mode, protection level, and log delay duration. You can also perform **View Delay** and **Pause Synchronization/Resume Synchronization** operations.

     <main id="notice" type='explain'>
     <h4>Note</h4>
     <p>Some information in the <b>Primary and Standby Tenants</b> section is displayed only when specific conditions are met. For details, refer to the description of <b>View Primary-Secondary Relationship</b> in <a href='../../700.tenant-functions/600.manage-a-tenant/100.overview-of-the-tenant-details-page.md'>Tenant Details Page Overview</a>.</p>
     </main>

   * **<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.TenantConsolidation">Tenant Major Compaction</UI-TERM>**: Details about tenant major compactions in the cluster, including tenant name, start time of the last major compaction, end time of the last major compaction, duration, status, and reason for triggering the major compaction.
   * **<UI-TERM key="ocp-v2.Component.BackupStrategyCard.DataBackup">Data Backup</UI-TERM>**: Data backup details for tenants in the cluster, including tenant name, backup method, start time of the last backup, end time of the last backup, duration, status, and progress.
