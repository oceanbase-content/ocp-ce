# Manage SQL Audit

The SQL Audit management feature supports seamless transmission of database audit logs to external storage systems (such as ElasticSearch or SLS), significantly enhancing database operation visibility and security. Through efficient log management and in-depth analysis capabilities, it helps enterprises achieve refined operations and risk control, effectively ensuring data security, business continuity, and compliance requirements.

This topic describes the procedure for managing SQL Audit.

### Prerequisites

* Please modify the cluster parameter: enable_sql_audit to true to enable the global SQL audit feature.
* Please ensure that the external storage data sources ElasticSearch or SLS are configured. For details, see [Connect SQL Audit to ElasticSearch](../1600.system-management-features/450.manage-external-integration/300.manage-sql-audit/300.manage-es.md) or [Connect SQL Audit to SLS](../1600.system-management-features/450.manage-external-integration/300.manage-sql-audit/200.manage-sls.md).

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Cluster">Cluster</UI-TERM>**. The system enters the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page by default.

3. On the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, select the target cluster and click its name to go to the cluster **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page.

4. In the left navigation bar of the displayed page, click **SQL Audit Management**.

5. In the **<UI-TERM key="ocp-v2.page.External.CreateDrawer.BasicInformation">Basic Information</UI-TERM>** section, click **Configure** and select a tenant in the dialog box.

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <ul><li>The SQL audit data of the selected tenant will be transmitted to the following external storage. When a new tenant is added or an existing tenant is deleted, to avoid unsynchronized SQL audit data or duplicate tenant names, the system will automatically update the OCP Agent parameters.</li><li>If you select <strong>All</strong>, the SQL audit data of all current tenants and future newly created tenants will be transmitted to the subsequently configured external storage. You can filter by using <strong>Exclude Objects</strong>.</li></ul>
</main>

6. Select an external storage.

7. Configure the **Log Database**, which is the name of the SLS service logstore.

8. Click **<UI-TERM key="ocp-v2.page.External.CreateDrawer.Save">Save</UI-TERM>**.

9. In the confirmation dialog box, click **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.Ok">OK</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/sql-audit-manage.png)

## Related operations

* **Edit SQL Audit**: In the upper-right corner of the **<UI-TERM key="ocp-v2.Host.Detail.BasicInformation">Basic Information</UI-TERM>** section, click **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.Edit">Edit</UI-TERM>**. Modify the relevant information in the pop-up dialog box, then click **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.Save">Save</UI-TERM>**.

* **Delete SQL Audit**: In the **<UI-TERM key="ocp-v2.Report.Scan.ReportContent.BasicInformation">Basic Information</UI-TERM>** section, turn off the **<UI-TERM>Enabled</UI-TERM>** switch. In the pop-up dialog box, click **<UI-TERM key="ocp-v2.Alarm.Template.Disable">Disable</UI-TERM>**. Then, in the upper-right corner of the **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.BasicInformation">Basic Information</UI-TERM>** section, click **<UI-TERM key="ocp-v2.User.MySQL.Delete">Delete</UI-TERM>**. Finally, in the confirmation dialog box, click **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.Ok">OK</UI-TERM>**.

* **View SQL Audit**: Below the **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.BasicInformation">Basic Information</UI-TERM>** section, you can view the **<UI-TERM>Number of Objects Written to Object Storage</UI-TERM>**. You can customize the time in the time filter box in the upper-right corner.
