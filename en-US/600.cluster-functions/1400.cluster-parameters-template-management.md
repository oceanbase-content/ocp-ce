# Manage cluster parameter templates

Cluster parameter templates preconfigure cluster parameters. In scenarios where you need to create a series of clusters with similar configurations, you can directly apply a parameter template when creating each cluster, eliminating the need to repeatedly configure parameters.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>For AI clusters (with shared storage), the semantics of some parameters change (for example, <code>datafile_size</code> now indicates cache space size), and parameters such as <code>datafile_next</code> and <code>datafile_maxsize</code> are no longer supported. When creating or editing a parameter template for a shared storage cluster, pay attention to the applicability of related parameters. For details, see [Parameter types](1300.manage-cluster-parameters/100.cluster-parameters-type.md).</p>
</main>

## Prerequisites

* To view cluster parameter template information, ensure the current OCP user has the following permissions:

  * **Cluster Read-Only** resource permission.
  * Permission to access the cluster **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** menu.

* To create, edit, copy, or delete a parameter template, ensure the current OCP user has the following permissions:

  * **Cluster Maintenance** resource permission.
  * Permission to access the cluster **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** menu.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.constant.inspection.Cluster">Cluster</UI-TERM>**. The system goes to the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** tab by default.

3. Click the **<UI-TERM key="ocp-v2.page.Cluster.ParameterTemplate">Parameter Templates</UI-TERM>** tab to go to the **Cluster Parameter Template List** page.

4. On the **Cluster Parameter Template List** page, you can perform management operations on cluster parameter templates, such as querying, creating, editing, copying, deleting, importing, and exporting.

   <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>System-built cluster parameter templates cannot be edited or deleted.</p>
   </main>

### Create a parameter template

You can configure common parameters into a parameter template to avoid repeated configuration later.

1. On the **Cluster Parameter Template List** page, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">Create Parameter Template</UI-TERM>**.
   Or, in the **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">Parameter Management</UI-TERM>** section of the **Create Cluster** page, select **Create Cluster Parameter Template**.

2. In the **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">Create Parameter Template</UI-TERM>** panel, define the template name and set related parameters.

   You can click **+ <UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.AddParameters">Add Parameter</UI-TERM>** to add multiple parameter items and configure their values.

3. Click **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">Submit</UI-TERM>**.

### Edit a parameter template

You can update the information of a parameter template as needed.

1. On the **Cluster Parameter Template List** page, find the parameter template you want to edit and select **... > <UI-TERM key="ocp-v2.component.FormEditTable.Editing">Edit</UI-TERM>** in the Actions column.

2. In the **Edit Cluster Parameter Template** panel, modify the **<UI-TERM key="ocp-v2.Alarm.Template.New.TemplateName">Template Name</UI-TERM>**, **<UI-TERM key="ocp-v2.pages.Certificate.Remarks">Remarks</UI-TERM>**, and **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.TemplateParameterSettings">Template Parameter Settings</UI-TERM>** fields.

3. Click **<UI-TERM key="ocp-v2.component.Compaction.DumpPolicyDrawer.Submit">Submit</UI-TERM>**.

### Copy a parameter template

This operation allows you to copy an existing complex template A and rename it to B. The content of template B only requires simple modifications based on A, eliminating the need to reconfigure a large number of parameters.

1. On the **Cluster Parameter Template List** page, find the parameter template you want to copy and select **... > <UI-TERM key="ocp-v2.component.ParameterTemplate.Copy">Copy</UI-TERM>** in the Actions column.

2. On the **Copy Cluster Parameter Template** page, rename the **<UI-TERM key="ocp-v2.component.ParameterTemplate.TemplateName">Template Name</UI-TERM>**, **<UI-TERM key="ocp-v2.Alarm.Event.Remarks">Remarks</UI-TERM>**, and **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.TemplateParameterSettings">Template Parameter Settings</UI-TERM>** fields.

3. Click **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Submitted">Submit</UI-TERM>**.

### Delete a parameter template

If a cluster parameter template is no longer applicable, you can delete it.

1. On the **Cluster Parameter Template List** page, find the parameter template you want to delete and select **... > <UI-TERM key="ocp-v2.Restore.SamplingStrategy.Delete">Delete</UI-TERM>** in the Actions column.

2. In the pop-up window, click **<UI-TERM key="ocp-v2.component.FormEditTable.Determine">OK</UI-TERM>**.

### Export a parameter template

If you want to use the same parameter template across different OCP instances, you can export the template file locally and then import it for use in another OCP instance.

1. On the **Cluster Parameter Template List** page, find the parameter template you want to export and select **... > Export** in the Actions column.

2. In your browser, choose a location to save the file, and the parameter template is exported to your local device.

### Import a parameter template

Import a locally saved tenant parameter template to avoid reconfiguring the same parameter information.

1. On the **Cluster Parameter Template List** page, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">Create Parameter Template</UI-TERM>**.
   Or, in the **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">Parameter Management</UI-TERM>** section of the **Create Cluster** page, select **Create Cluster Parameter Template**.

2. In the **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">Create Parameter Template</UI-TERM>** panel, click **<UI-TERM key="ocp-v2.Component.License.LicenseAlert.Import">Import</UI-TERM>**, select the YAML template file you want to import. Each parameter value in the template file must comply with the product specifications of OceanBase/OBProxy/Binlog and be unique.

3. Click **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">Submit</UI-TERM>**.
