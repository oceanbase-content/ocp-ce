# Manage Regions

A region indicates the geographical area where a host is located. A physical region can contain one or more data centers. Regions and data centers are reference items for OceanBase load balancing and SQL statement routing policies. Please fill them in according to the actual situation.

## Add a Region

This section describes how to add a region.

### Prerequisites

* The current user logged in to OCP has the **ADMIN** or **ORG_ADMIN** role.
* The region name must be globally unique.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Area">Region</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.pages.Host.NewArea">Add Region</UI-TERM>** in the upper-right corner.

4. In the dialog box, enter the region name and description, then click **<UI-TERM key="ocp-v2.Host.Component.AddHostTypeModal.New">Add</UI-TERM>**.

## Modify Region Description

This section describes how to modify the description of a region.

### Prerequisites

Ensure the current user logged in to OCP has at least the following permissions:

* **Host Maintenance** resource permission.
* **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu permission for hosts.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.Component.ZoneList.AddOBServerDrawer.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.RegionList.Area">Region</UI-TERM>** tab, select the region you want to modify and click the edit button in the Description column.

4. In the dialog box, modify the description information and click **<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.Ok">OK</UI-TERM>**.

## Delete a Region

This section describes how to delete a region.

### Prerequisites

* Ensure the current OCP user has at least the following permissions:

  * **Host Maintenance** resource permission.
  * **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu permission for hosts.

* Deletion is not supported if the region has associated IDCs.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.component.ArchitectureAndVpcAlert.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.Area">Region</UI-TERM>** tab, select the region you want to delete and click **<UI-TERM key="ocp-v2.pages.Host.HostType.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box, confirm the information. If correct, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.Delete">Delete</UI-TERM>**.
