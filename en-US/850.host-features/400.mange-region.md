# Manage regions

A region indicates the geographic location of a host. A physical region can contain one or more IDCs. Regions and IDCs are referenced in OceanBase Database load balancing and SQL statement routing strategies. Please fill in the information based on your actual situation.

## Add a region

This topic describes how to add a region.

### Prerequisites

* The current user logged in to OCP is the **ADMIN** or **ORG_ADMIN** role.
* The region name is globally unique.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.RegionList.Area">Region</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.pages.Host.NewArea">Add Region</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, enter the region name and description, and click **<UI-TERM key="ocp-v2.component.FormEditTable.Add">Add</UI-TERM>**.

## Modify the description of a region

This topic describes how to modify the description of a region.

### Prerequisites

The current user logged in to OCP must have the following permissions:

* **Host Maintenance** resource permission.
* **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** permission on the host.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.report.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.RegionList.Area">Region</UI-TERM>** tab, find the region whose description you want to modify and click the edit button in the Description column.

4. In the dialog box that appears, modify the description, and click **<UI-TERM key="ocp-v2.component.FormEditTable.Determine">OK</UI-TERM>**.

## Delete a region

This topic describes how to delete a region.

### Prerequisites

* The current user logged in to OCP must have the following permissions:

  * **Host Maintenance** resource permission.
  * **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** permission on the host.

* You cannot delete a region that has associated IDCs.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.ViewTable.OBProxyItem.HostTable.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.RegionList.Area">Region</UI-TERM>** tab, find the region that you want to delete and click **<UI-TERM key="ocp-v2.component.ParameterTemplate.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box that appears, confirm the information, and click **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.Delete">Delete</UI-TERM>**.
