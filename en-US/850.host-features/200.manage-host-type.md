# Manage Host Types

A host type is a label assigned by users to hosts with identical configurations. It is recommended to assign meaningful names for easier host management.

## Add a host type

This section describes how to add a host type.

### Prerequisites

* The current OCP user is in the **ADMIN** or **ORG_ADMIN** role.
* The host type name must be globally unique.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.inspection.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Models">Host Type</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.pages.Host.NewModel">Add Host Type</UI-TERM>** in the upper-right corner.

4. In the dialog box, enter the host type name and description, then click **<UI-TERM key="ocp-v2.Binlog.Component.AddInstanceModal.New">Add</UI-TERM>**.

## Modify the description of a host type

This section describes how to modify the description of a host type.

### Prerequisites

Ensure that the current OCP user has at least the following permissions:

* **Host Maintenance** resource permission.
* **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu permission for hosts.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Component.OBServerList.Models">Host Type</UI-TERM>** tab, find the target host type and click the edit button in its Description column.

4. In the dialog box, modify the description and click **<UI-TERM key="ocp-v2.component.Compaction.DumpPolicyDrawer.Ok">OK</UI-TERM>**.

## Delete a host type

This section describes how to delete a host type.

### Prerequisites

* Ensure the current OCP user has at least the following permissions:

  * **Host Maintenance** resource permission.
  * **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu permission for hosts.

* A host cannot be deleted if it is associated with a model.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.constant.inspection.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.OBProxy.New.ModelOptional">Host Type</UI-TERM>** tab, select the model you want to delete and click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupConfig.SelectGroupName.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box, confirm the host information. If correct, click **<UI-TERM key="ocp-v2.src.constant.oceanbase.Delete">Delete</UI-TERM>**.
