# Manage host types

A host type is a label that you specify for hosts with the same configuration. We recommend that you specify a meaningful name for a host type to facilitate host management.

## Create a host type

This topic describes how to create a host type.

### Prerequisites

* You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** user.
* The name of the host type is globally unique.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.OBProxy.New.DeployMode.Models">Host Type</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.Host.Component.AddHostTypeModal.NewModel">Add Host Type</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, enter the name and description of the host type, and click **<UI-TERM key="ocp-v2.Host.Component.AddHostRegionModal.New">Add</UI-TERM>**.

## Modify the description of a host type

This topic describes how to modify the description of a host type.

### Prerequisites

You have logged in to the OCP console as a user who has the following permissions:

* **Host Maintenance** resource permission.
* **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** permission on the host page.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.HostType.Model">Host Type</UI-TERM>** tab, find the host type whose description you want to modify and click the edit button in the Description column.

4. In the dialog box that appears, modify the description and click **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.Ok">OK</UI-TERM>**.

## Delete a host type

This topic describes how to delete a host type.

### Prerequisites

* You have logged in to the OCP console as a user who has the following permissions:

  * **Host Maintenance** resource permission.
  * **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** permission on the host page.

* You cannot delete a host type that is associated with a host.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.component.TakeOverArbitrationDrawer.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Detail.TakeOver.Models">Host Type</UI-TERM>** tab, find the host type that you want to delete and click **<UI-TERM key="ocp-v2.Detail.Overview.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box that appears, confirm the information about the host type and click **<UI-TERM key="ocp-v2.page.Credential.Binlog.Delete">Delete</UI-TERM>**.
