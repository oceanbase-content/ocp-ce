# Manage IDCs

You can refer to the following content to manage IDCs.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Starting from OCP V3.1.1, multi-zone mode is supported. When adding a new IDC, it will be created in the same zone where the current OCP is located.</p>
</main>

## Add an IDC

This section describes how to add an IDC.

### Prerequisites

* The current user logged in to OCP has the **ADMIN** or **ORG_ADMIN** role.
* The IDC name must be globally unique.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.component.ArchitectureAndVpcAlert.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ComputerRoom">IDC</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.Host.Component.AddHostIdcModal.NewMachineRoom">Add IDC</UI-TERM>** in the upper-right corner.

4. In the dialog box, enter the IDC name, region, and description, then click **<UI-TERM key="ocp-v2.Host.Component.AddHostIdcModal.New">Add</UI-TERM>**.

## Modify IDC description

This section describes how to modify the description of an IDC.

### Prerequisites

Ensure the current user logged in to OCP has at least the following permissions:

* **Host Maintenance** resource permission.
* **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu permission for hosts.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Host.Detail.Basic.ComputerRoom">IDC</UI-TERM>** tab, find the IDC you want to modify and click the edit button in the Description column.

4. In the dialog box, modify the description information and click **<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.Ok">OK</UI-TERM>**.

## Delete a data center

This topic describes how to delete a data center.

### Prerequisites

* Ensure the current OCP user has at least the following permissions:

  * **Host Maintenance** resource permission.
  * **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** host menu permission.

* A data center cannot be deleted if it contains associated hosts.

### Procedure

1. Log in to OCP.

2. In the left navigation pane, click **<UI-TERM key="ocp-v2.src.constant.log.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.component.ZoneFormCardList.DataCenter">IDC</UI-TERM>** tab, select the data center you want to delete and click **<UI-TERM key="ocp-v2.Backup.Service.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box, confirm the information. If correct, click **<UI-TERM key="ocp-v2.Auth.Role.Detail.Delete">Delete</UI-TERM>**.
