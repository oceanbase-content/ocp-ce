# Manage IDCs

This topic describes how to manage IDCs.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>Multi-zone mode is supported in OCP V3.1.1 and later. When you create an IDC, it will be created in the zone where OCP is located. </p>
</main>

## Create an IDC

This topic describes how to create an IDC.

### Prerequisites

* You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** role.
* The IDC name is globally unique.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Settings.Credential.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Cluster.Import.OBServerTable.ComputerRoom">IDC</UI-TERM>** tab, click **<UI-TERM key="ocp-v2.pages.Host.NewMachineRoom">Add IDC</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, specify the IDC name, region, and description, and click **<UI-TERM key="ocp-v2.Host.Component.AddHostIdcModal.New">Add</UI-TERM>**.

## Modify the description of an IDC

This topic describes how to modify the description of an IDC.

### Prerequisites

You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** role and have the following permissions:

* **Host Maintenance** resource permission.
* **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu permission for Hosts.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.OBProxy.New.DeployMode.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Cluster.New.ComputerRoom">IDC</UI-TERM>** tab, find the IDC whose description you want to modify and click the edit button in the Description column.

4. In the dialog box that appears, modify the description and click **<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.Ok">OK</UI-TERM>**.

## Delete an IDC

This topic describes how to delete an IDC.

### Prerequisites

* You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** role and have the following permissions:

  * **Host Maintenance** resource permission.
  * **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** menu permission for Hosts.

* The IDC has no associated hosts.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.alarm.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.component.ZoneFormCardList.DataCenter">IDC</UI-TERM>** tab, find the IDC that you want to delete and click **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box that appears, confirm the information and click **<UI-TERM key="ocp-v2.User.Component.AccessKeyCardTable.Delete">Delete</UI-TERM>**.
