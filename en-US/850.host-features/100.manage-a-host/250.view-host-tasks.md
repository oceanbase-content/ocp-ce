# View host task details

This topic describes how to view the details of an O&M task of a host.

## Prerequisites

* You have logged in to the OCP console as a user with the following permissions:

  * **Cluster Read-Only**, **Tenant Read-Only**, or **Host Read-Only** permission.
  * **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.OBServerWithExclude.All">All</UI-TERM>** permission on the host.

* The host is in the **<UI-TERM key="ocp-v2.src.constant.binlog.OM">In Operation Maintenance</UI-TERM>** state, which indicates that the host is being restarted, reinstalled, or deleted.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.util.cluster.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.Host">Host</UI-TERM>** tab, find the host and click **... > <UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">View Tasks</UI-TERM>** in the Actions column.

4. In the dialog box that appears, view the details of the O&M task. You can click the task ID to go to the task details page. On the task details page, you can view the task logs, roll back, or retry the task. For more information, see [Manage tasks](../../1600.system-management-features/600.manage-tasks.md).
