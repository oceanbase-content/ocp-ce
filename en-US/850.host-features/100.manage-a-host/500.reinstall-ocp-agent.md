# Reinstall OCP Agent

This topic describes how to reinstall the OCP Agent.

<main id="notice" type='notice'>
<h4>Notice</h4>
<p>Reinstalling the OCP Agent may interrupt ongoing cluster maintenance operations and result in a period of missing host monitoring. Proceed with caution.</p>
</main>

## Prerequisites

Ensure that the logged-in user has the following permissions in OCP:

* Permission to maintain **<UI-TERM key="ocp-v2.component.common.ClusterSelect.All">All</UI-TERM>** hosts.
* Permission to access the **<UI-TERM key="ocp-v2.Cluster.New.Host">Host</UI-TERM>** page.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Cluster.New.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.Host">Host</UI-TERM>** page, find the host for which you want to reinstall the OCP Agent and click **... > <UI-TERM key="ocp-v2.Host.Component.ReinstallModal.ReloadOcpAgent">Reinstall OCP Agent</UI-TERM>** in the Actions column.

4. In the dialog box that appears, select the software package that matches the hardware architecture of the current host and click **<UI-TERM key="ocp-v2.MultiCluster.Detail.FailoverModal.Determine">OK</UI-TERM>**.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>If you need to customize the port number of the agent, contact OCP technical support for assistance.</p>
</main>
