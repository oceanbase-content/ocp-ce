# Delete a host

This topic describes how to delete a host.

## Prerequisites

* The logged-in user has the following permissions in OCP:

  * **Host Management** resource permission.
  * **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.TenantWithExclude.All">All</UI-TERM>** permission for hosts.

* The host is in the **<UI-TERM key="ocp-v2.src.constant.compute.Idle">Idle</UI-TERM>** or **<UI-TERM key="ocp-v2.Component.RecoverableTimeRange.Offline">Offline</UI-TERM>** state.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.constant.inspection.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.src.constant.alarm.Host">Host</UI-TERM>** tab, find the target host and click **... > <UI-TERM key="ocp-v2.page.Package.Delete">Delete</UI-TERM>** in the Actions column to delete the host. You can also select the host and click **<UI-TERM key="ocp-v2.Alarm.Rule.BatchDeletion">Batch Delete</UI-TERM>** to delete multiple hosts.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p><ul><li>Deleting a host permanently removes all information and configurations of the host from OCP. </li><li>For a host in the <b>Offline</b> state, you can only perform <b>Force Delete</b>. Force delete permanently removes all information and configurations of the host from OCP, but you need to log in to the host to manually delete its internal services and configurations. </li></ul></p>
    </main>

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Detail.Component.DeleteUnitModal.Delete">Delete</UI-TERM>**.
