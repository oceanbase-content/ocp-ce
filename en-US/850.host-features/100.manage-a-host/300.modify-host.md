# Modify a host

This topic describes how to modify a host.

## Prerequisites

The user has the following permissions:

* **Host Maintenance** resource permission.
* **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">All</UI-TERM>** permission for hosts.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **Hosts**.

3. On the **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Host">Host</UI-TERM>** tab, find the host that you want to modify and click **... > <UI-TERM key="ocp-v2.Alarm.Rule.Editing">Edit</UI-TERM>** in the Actions column.

4. In the dialog box that appears, modify the IP address, SSH port, host type, IDC, host category, credentials, host alias, and description of the host.

5. Click **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.Ok">OK</UI-TERM>**.
