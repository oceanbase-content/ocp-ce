# OCP-Agent O&M scripts

To facilitate the installation, start, stop, and uninstallation of OCP-Agent, the OCP-Agent package includes the O&M tool ocp_agentctl. After installing the OCP-Agent package, you can use simple commands to perform O&M operations on OCP-Agent.

## Environment requirements

After installing the OCP-Agent package, the `ocp_agentctl` tool is located in the OCP-Agent directory: `/home/admin/ocp_agent/bin`.

  `ocp_agentctl` is an executable file that allows you to perform O&M and management operations on OCP-Agent through the command line. You can directly execute `ocp_agentctl` in the `/home/admin/ocp_agent/bin` directory.

  <main id="notice" type='explain'>
    <h4>Note</h4>
    <ul>
    <li>The execution logs of <code>ocp_agentctl</code> are output to the <code>agentctl.log</code> file in the <code>/home/admin/ocp_agent/log</code> directory.</li>
    <li>This file is only applicable for O&M of the local OCP-Agent and does not support remote O&M.</li>

## Command syntax

```javascript
ocp_agentctl [COMMAND] [OPTIONS]
```

* COMMAND specifies the operation command to be executed, such as start or stop.

* OPTIONS specifies the additional options for the operation. For example:

  * --help: You can also use "-h" to query the help information.

## Examples

### Query help information

* View help information

  ```python
  ./ocp_agentctl -h
  ```

  The system returns the usage method and supported operation commands of the tool.

* View the help information of a specific command

  ```python
  ./ocp_agentctl config -h
  ```

  The system returns the usage method, supported objects, and commands of the config command.

### Start OCP-Agent

```python
./ocp_agentctl start
```

After the command is executed successfully, ocp_agentd, ocp_monagent, and ocp_mgragent are started.

### Stop OCP-Agent

```python
./ocp_agentctl stop 
```

After the command is executed successfully, ocp_agentd, ocp_monagent, and ocp_mgragent are stopped. At the same time, the host status is set to offline, which will result in the missing of OCP monitoring metrics and SQL diagnostic data, as well as the unavailability of OceanBase log alerts.

### Restart OCP-Agent

```python
./ocp_agentctl restart
```

### View OCP-Agent installation information

```python
./ocp_agentctl info
```

The system returns the name, version, architecture, and description of OCP-Agent.
