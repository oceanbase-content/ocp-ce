# Restart OCP Agent

This topic describes how to restart the OCP Agent.

## Prerequisites

The user logged in to OCP has the following permissions:

* Permission to maintain hosts.
* Permission to access the **<UI-TERM key="ocp-v2.Auth.Role.Detail.All">All</UI-TERM>** menu.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Component.ZoneList.AddOBServerDrawer.Host">Host</UI-TERM>**.

3. On the **<UI-TERM key="ocp-v2.pages.Host.Host">Host</UI-TERM>** page, find the target host and click **... > <UI-TERM key="ocp-v2.Host.Detail.OCPAgent.RestartOcpAgent">Restart OCP Agent</UI-TERM>** in the Actions column.

   A prompt appears.

4. In the prompt, click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Determine">OK</UI-TERM>**.

5. After the restart task is submitted, you can click **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewTasks">View Tasks</UI-TERM>** in the Actions column of the target host to view the task details.
