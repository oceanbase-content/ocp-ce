# OCP-Agent process

This topic describes the OCP agent process.

## OCP agent process

|      Process name      |                Function                |               Start and stop method                |
|---------------|----------------------------------|-----------------------------------|
| ocp_agentd    | Monitors the OCP agent process.                 | Starts automatically when the OCP agent process starts and cannot be stopped. |
| ocp_mgragent  | Executes O&M commands issued by OCP and performs various O&M operations on the host. | Starts automatically when the OCP agent process starts and cannot be stopped.   |
| ocp_monagent  | Collects monitoring data required by OCP. | Starts automatically when the OCP agent process starts and cannot be stopped.      |

## Enable the OCP agent process to start automatically when the system boots

In this version, the OCP agent process can start automatically when the system boots. After the system restarts, the OCP agent process is automatically started. When you install the OCP agent rpm package, the rpm script configures the systemd service to start automatically. The `ocp_agent.service` file is written to the systemd configuration.

```Json
[Unit]
Description=start ocp_agent
[Service]
Type=forking
ExecStart=${ocp.agent.home.path}/bin/ocp_agentctl start
ExecStop=${ocp.agent.home.path}/bin/ocp_agentctl stop
ExecReload=${ocp.agent.home.path}/bin/ocp_agentctl restart
[Install]
WantedBy=multi-user.target
```

The `ocp.agent.home.path` parameter is replaced with the actual path during installation.

## Manually start the OCP agent process

If you need to start the OCP agent process in a headless mode, you can use the `start` command in the help script.

## Related services

In addition to the OCP agent process, the following services are automatically started when the OCP agent process starts after the system restarts.

|      Process name      |                Function                |               Start and stop method                |
|---------------|----------------------------------|-----------------------------------|
| obproxy    | Handles access proxying for OceanBase Database.       | Starts automatically when the OCP agent process starts and cannot be stopped. |
| observer  | Handles core functionalities of OceanBase Database. | Starts automatically when the OCP agent process starts and cannot be stopped.   |
