# Manage SSL encryption

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not support this feature. </p>
</main>

OceanBase Database supports Secure Sockets Layer (SSL) encryption to enhance the security of connections. SSL encryption encrypts network connections at the transport layer, preventing communication traffic from being intercepted or altered between nodes. This ensures the security of communication data. OceanBase Database supports SSL encryption for Remote Procedure Call (RPC) communication between OceanBase databases, communication between OceanBase Proxy (OBProxy) and OceanBase databases, and communication between business applications and OBProxy. After enabling SSL encryption, clients can establish connections using SSL authentication or general authentication.

This topic describes how to manage SSL encryption.

## Enable SSL encryption

After you enable SSL encryption, the cluster performance will slightly degrade (data transmission encryption and decryption consume some computing resources). We recommend that you enable SSL encryption only when you need to connect to the Internet or transmit encrypted data.

### Prerequisites

* The user who logs in to the OCP console is the **ADMIN** or **ORG_ADMIN** user.

* The OBProxy cluster is V2.0 or later.

* SSL encryption does not take effect for direct connection endpoints.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, find the OBProxy cluster that you want to manage and click its name to go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the cluster.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab automatically appears.

5. Click **<UI-TERM key="ocp-v2.Statistics.components.AutoCollectionDrawer.Enable">Enable</UI-TERM>**. In the dialog box that appears, select the name of the SSL server certificate and click **<UI-TERM key="ocp-v2.Component.SQLTable.Enable">Enable</UI-TERM>**.

   If the required certificate is not available in the drop-down list, click [Upload Certificate](../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to add it.

## Disable SSL encryption

This topic describes how to disable SSL encryption. This operation takes about a minute.

### Prerequisites

* The user who logs in to the OCP console is the **ADMIN** or **ORG_ADMIN** user.

* SSL encryption is enabled. For more information, see [Enable SSL encryption](#parameter).

* The SSL server certificate has not expired.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, find the OBProxy cluster that you want to manage and click its name to go to the **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab automatically appears.

5. In the upper-right corner, click **<UI-TERM key="ocp-v2.component.SecurityCard.TurnOffEncryption">Disable Encryption</UI-TERM>**. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Statistics.components.AutoCollectionDrawer.Close">Disable</UI-TERM>**.

## Update the SSL server certificate

When an SSL server certificate is about to expire or has expired, you can update the certificate online. After the certificate is regenerated, the existing SSL links will continue to work, but new links will fail. You need to be aware of these changes.

### Prerequisites

* Make sure that the login user in the OCP console has the **ADMIN** or **ORG_ADMIN** role.

* [SSL encryption](#parameter) is enabled.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, find the OBProxy cluster that you want to manage and click the name of the cluster to go to the **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page of the cluster.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears.

5. In the upper-right corner of the page, click **Update SSL Server Certificate**. In the dialog box that appears, select the name of the SSL server certificate and click **<UI-TERM key="ocp-v2.src.constant.iam.Update">Update</UI-TERM>**.

   If the required certificate is not in the drop-down list, you can click [Upload Certificate](../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) to add it.

## Download the CA certificate

You can download the CA certificate as a compressed package to your local device. The package contains three files:

* The `.p7b` file: used to import the CA certificate in Windows.

* The `.pem` file: used to import the CA certificate in other systems or applications.

* The `.jks` file: a Java TrustStore certificate file. The password is OceanBase, and it is used to import the CA certificate chain in Java programs.

### Prerequisites

* Make sure that the login user in the OCP console has the **ADMIN** or **ORG_ADMIN** role.

* [SSL encryption](#parameter) is enabled.

* The SSL server certificate has not expired.

### Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **OBProxy**.

3. In the cluster list, find the OBProxy cluster that you want to manage and click the name of the cluster to go to the **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page of the cluster.

4. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Security.SecurityConfiguration">Security Configuration</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSL Encryption</UI-TERM>** tab appears.

5. Click **<UI-TERM key="ocp-v2.src.constant.security.DownloadCaCertificate">Download CA Certificate</UI-TERM>**.
