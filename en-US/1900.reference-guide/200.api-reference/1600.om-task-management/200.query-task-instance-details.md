# View Task Details

## Feature description

This API is used to query the execution details of a task.

## Call instructions

### Interface constraints

The caller must be at least the TASK_VIEWER role.

### Request path

`GET /api/v2/tasks/instances/{taskInstanceId}`

### Request parameters

**path:**

|       Parameter       |  Type  | Required | Example Value  |      Description       |
|----------------|------|----|------|---------------|
| taskInstanceId | Long | Yes  | 1000 | The ID of the target task instance. |

### Returned result

|     Parameter     |    Type    |              Description              |
|------------|----------|------------------------------|
| data       | Object   | The data requested by the WrappedTaskInstance object. For more information, see **Data structure of WrappedTaskInstance**. |
| successful | Boolean  | Indicates whether the request was successful.                      |
| timestamp  | Datetime | The timestamp indicating the time when the server completed the request.                 |
| duration   | Integer  | The time taken by the server to process the request, in milliseconds.              |
| status     | Integer  | The HTTP status code that conforms to the HTTP status code specification.        |
| traceId    | String   | The Trace ID of the request, which is used for troubleshooting.         |
| server     | String   | The address of the application service that responded to the request.                |

**Data structure of WrappedTaskInstance**

|        Parameter        |     Type      |      Description    |
|------------------|-------------|-----------|
| id               | Long        | The ID of the software package. |
| name             | String      | The name of the software package. |
| taskDefinitionId | Long        | The ID of the task definition. |
| ├─ cluster       | Object      | The cluster information. For more information, see **Cluster parameters**.    |
| ├─ tenant        | Object      | The tenant information. For more information, see **Tenant parameters**.   |
| ├─ creator       | Object      | The information about the task creator. For more information, see **Creator parameters**.    |
| status           | StringArray | The execution status of the task. Valid values: <li>RUNNING: the task is running</li><li>FAILED: the task failed</li><li>SUCCESSFUL: the task succeeded</li>    |
| type             | String      | The type of the task. Valid values: <li>MANUAL: an O&M task manually initiated</li><li>SYS_ONECE: a one-time task executed by the system</li><li>SCHEDULED: a non-built-in scheduled task</li><li>SYS_SCHEDULED: a built-in scheduled task</li>    |
| operation        | String      | The operation performed on the task. Valid values: <li>EXECUTE: the task is normally executed</li><li>RETRY: the task is retried</li><li>ROLLBACK: the task is rolled back</li><li>SKIP: the task is skipped</li><li>CANCEL: the task is canceled</li>    |
| executor         | String      | The information about the host that executes the task.      |
| prohibitRollback | Boolean     | Indicates whether the task can be rolled back.   |
| subtasks         | ObjectArray | For more information, see **Data structure of SubtaskInstance**.     |
| createTime       | String      | The time when the task was created.   |
| startTime        | String      | The start time of the task.    |
| finishTime       | String      | The end time of the task.   |

**Cluster parameters**

|     Parameter      |   Type   |     Description        |
|-------------|--------|---------|
| id          | Long   | The ID of the cluster in the OCP console.  |
| name        | String | The name of the cluster.  |
| obClusterId | Long   | The ID of the cluster in the OceanBase console.   |
| type        | String | The type of the cluster. Valid values: <li>PRIMARY: a primary cluster</li><li>STANDBY: a standby cluster</li>    |

**Tenant parameters**

|     Parameter      |   Type   |    Description     |
|-------------|--------|------|
| id          | Long   | The ID of the tenant in the OCP console.  |
| name        | String | The name of the tenant.   |
| obClusterId | Long   | The ID of the tenant in the OceanBase console.     |
| mode        | String | The mode of the tenant. Valid values: <li>ORACLE: the Oracle compatible mode</li><li>MYSQL: the MySQL compatible mode</li>    |

**Creator parameters**

|  Parameter  |   Type   |    Description    |
|------|--------|----------|
| id   | Long   | The ID of the creator. |
| name | String | The username of the creator.   |

**Data structure of SubtaskInstance**

|        Parameter        |    Type     |     Description      |
|------------------|-----------|---------|
| id               | Long      | The ID of the subtask instance.  |
| name             | String    | The name of the subtask.    |
| seriesId         | Long      | The ID of the subtask series.    |
| description      | String    | The description of the subtask.    |
| timeout          | Integer   | The timeout period of the subtask, in seconds.    |
| status      | String | The status of the subtask. Valid values: <li>PENDING: the initial state, waiting for the upstream node to complete</li><li>READY: preparing, the dependency nodes have completed execution and are waiting to be executed</li><li>RUNNING: the subtask is being executed</li><li>CANCELING: the subtask is being canceled</li><li>FAILED: the final state, the subtask failed</li><li> SUCCESSFUL: the final state: the subtask succeeded</li>   |
| operation   | String | The operation performed on the subtask. Valid values: <li>EXECUTE: the subtask is normally executed</li><li>RETRY: the subtask is retried</li><li>ROLLBACK: the subtask is rolled back</li><li>SKIP: the subtask is skipped</li><li>CANCEL: the subtask is canceled</li>       |
| executor         | String    | The information about the node that executes the subtask.    |
| runTime          | Integer   | The number of times the subtask is executed.     |
| nodeType         | String    | The node type, for example, JAVA_TASK.    |
| paralleIdx       | Integer   | The parallel subtask index value. -1 indicates that the subtask is not parallel.      |
| upstreams        | LongArray | The list of upstream subtask IDs.     |
| downstream       | LongArray | The list of downstream subtask IDs.      |
| prohibitRollback | Boolean   | Indicates whether the subtask supports rollback.       |
| createTime       | String    | The time when the subtask was created.    |
| startTime        | String    | The start time of the subtask.     |
| finishTime       | String    | The end time of the subtask.    |
