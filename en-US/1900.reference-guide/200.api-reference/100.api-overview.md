# Overview

To facilitate the management of your OceanBase cluster resources and the development of your own applications through APIs, OCP exposes HTTP APIs that comply with the REST specification. This topic describes the APIs exposed by OCP, including their syntax and examples. It is intended for developers. Before calling the APIs, ensure you have a thorough understanding of the relevant concepts of the OCP platform.
