# Performance statistics of SQL queries

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">Function Description</UI-TERM>**

SQL Performance statistics can be queried for a tenant, with performance statistics for SQLs in a specified time interval. The performance data includes: cluster name, tenant name, server name, database name, username, SQL_ID, response time, CPU time, execution count, and error count. Check the **Whether**

You can query the performance metrics of a specific SQL by using SQL statements, keywords of the SQL statements, or advanced search conditions such as performance metrics, internal SQL statements, or SQL texts.
**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Description">Description</UI-TERM>**

Queries on this interface are time-consuming. If the response is slow, you can reduce the query frequency, time range, or number of concurrent requests. You can also check the resource usage of OCP Server and Monitor DB, and adjust the configurations as needed.

## **Call instructions**

**Interface constraints**

The caller must have read permissions on the specified tenant.

**Request path**

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/topSql`

**Request parameters**

|     Parameter     |    Type    | Required |            Example Value            |      Description     |
|------------|----------|-------|---------------------------|-------|
| id         | Integer  | Yes  | 1                         | The ID of the cluster.    |
| tenantId   | Integer  | Yes  | 1001                      | The ID of the tenant.     |
| startTime  | Datetime | Yes  | 2020-02-16T05:32:16+08:00 | The start time.    |
| endTime    | Datetime | Yes  | 2020-02-16T07:32:16+08:00 | The end time.           |
| serverId   | Integer  | No   | 300                       | The ID of the OceanBase server. If this parameter is not specified, SQL is executed on all OceanBase servers.   |
| inner      | Boolean  | No   | false                     | Specifies whether to include internal SQL. Internal SQL is initiated by OceanBase. The default value is false, indicating that internal SQL is not included.     |
| sqlText    | String   | No   | hello                     | Keywords in the SQL statement. The keywords are case-insensitive.     |
| searchAttr | String   | No   | executions                | The name of the metric for advanced search. This parameter will take effect only when both searchOp and searchVal are specified.  |
| searchOp   | String   | No   | GT                        | The operator for advanced search. This parameter will take effect only when both searchAttr and searchVal are specified. Valid values: <li>EQ: equal to</li><li>NE: not equal to</li><li>GT: greater than</li><li>GE: greater than or equal to</li><li>LT: less than</li><li>LE: less than or equal to</li>    |
| searchVal  | String   | No   | 1543                      | The value for advanced search. This parameter will take effect only when both searchAttr and searchOp are specified. |

**Return results**

* Basic data structure

  |     Parameter      |    Type    |          Description          |
  |-------------|----------|----------------------|
  | data        | Object   | The requested business data              |
  | ├─ contents | Array    | The list of SQL performance metrics data, see the table below.  |
  | successful  | Boolean  | Indicates whether the request is successful               |
  | timestamp   | Datetime | The server time when the request is completed.          |
  | duration    | Integer  | The time taken by the server to process the request in milliseconds.       |
  | status      | Integer  | The HTTP status code that conforms to the HTTP Status specification |
  | traceId     | String   | The trace ID of the request, which is used to troubleshoot issues. |
  | server      | String   | The IP address of the server that responds to the request.          |

## **Example**

**Request example**

Query the SQL performance of the cluster with Id 1 and tenant with Id 1001. The time range is from 2020-11-03T19:00:00+08:00 to 2020-11-03T20:00. Specify the advanced search condition: the number of executions is greater than or equal to 500.

```code
GET /api/v2/ob/clusters/1/tenants/1001/topSql?searchAttr=executions&searchOp=GE&searchVal=500&startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00
```
