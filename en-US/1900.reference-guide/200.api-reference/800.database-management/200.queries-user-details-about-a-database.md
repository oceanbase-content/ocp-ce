# Query the details of a database user

## Function

Obtain the details of a database user.

## How to call

### Interface constraints

The caller must authenticate with OCP Application Service.

The caller must have the read permission on the specified tenant.

### Request URL

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/users/{username}`

### Request parameters

**path parameter**

|    Parameter    |   Type    | Required | Example value  | Description   |
|----------|---------|-------|------|-------|
| id       | Integer | Yes | 1    | The ID of the cluster. |
| tenantId | Integer | Yes | 5    | Tenant ID |
| username | String  | Yes  | root | Username |
| hostName | String  | No   | 33.47.251.%        | Host name |

### Response

| Parameter | Type | Description |
|---------|------|-------------|
| data    | Object   | The database user. The data structure of a database user is described below.   |
| successful | Boolean  | Specifies whether the request was successful. |
| timestamp  | Datetime | The timestamp when the request was received. |
| duration   | Integer  | The time taken to process the request, in ms. |
| status     | Integer  | The HTTP status code. |
| traceId    | String   | The trace ID of the request, which is used for troubleshooting. |
| server     | String   | The address of the application service that responded to the request. |

**Data structure of a database user**

| Parameter | Type | Description |
|---------|------|-------------|
| username                | String      | The username.     |
| globalPrivileges        | StringArray | The list of global privileges. <li>For a MySQL tenant, this parameter indicates the list of global privileges. </li><li>For an Oracle tenant, this parameter indicates the list of system privileges. </li>    |
| dbPrivileges            | Array       | The list of database privileges. </br>**Note**: This parameter exists only for a MySQL tenant and does not exist for an Oracle tenant.     |
| ├─ dbName               | String      | The database name.     |
| ├─ privileges           | StringArray | The list of privileges on the database.    |
| objectPrivileges        | Array       | The list of object privileges. </br>**Note**: This parameter exists only for an Oracle tenant and does not exist for a MySQL tenant.     |
| ├─ dbObject             | Object      | The database object.      |
| ├─ privileges           | StringArray | The list of privileges on the object.    |
| grantedRoles            | String      | The roles granted to the user. </br>**Note**: This parameter exists only for an Oracle tenant and does not exist for a MySQL tenant.  |
| isLocked                | Bool        | Specifies whether the user is locked.      |
| createTime              | Datetime    | The time when the user was created.    |
| connectionStrings       | Array       | The list of connection strings and OBProxy addresses.     |
| ├─ connectionStringType | String      | The type of the connection string. Valid values: <li>OBPROXY</li><li>DIRECT, which indicates direct connection. </li>      |
| ├─ obProxyAddress       | String      | The address of the OBProxy. </br>**Note**: This parameter is valid only when the value of connectionStringType is OBPROXY.     |
| ├─ obProxyPort          | Integer     | The port of the OBProxy. </br>**Note**: This parameter is valid only when the value of connectionStringType is OBPROXY.        |
| ├─ connectionString     | String      | The connection string.     |
| accessibleDatabases     | StringArray | The list of accessible databases. </br>**Note**: This parameter exists only for an Oracle tenant and does not exist for a MySQL tenant.    |

**dbObject parameter**

| Parameter | Type | Description |
|---------|------|-------------|
| objectType | String | The type of the database object. Valid values: <li>TABLE, indicating a table. </li><li>VIEW, indicating a view. </li><li>STORED_PROCEDURE, indicating a stored procedure. </li>    |
| objectName | String | The name of the database object, which is the name of the table, view, or stored procedure.      |
| schemaName | String | The schema name, which is generally the same as the username.     |

## Examples

### Request example

Obtain the details of the root user in cluster 1 and tenant 1000001.

`GET /api/v2/ob/clusters/1/tenants/1000001/users/root?id=1&tenantId=1000001&username=root`
