Grant global privileges to users

## Function Description
--------------------------------

You can call this operation to grant global privileges to a user.
## Call Description
Call description 
### Interface Constraints

### Prerequisites 

You have passed the authentication for the OCP application service. 

### Request Path

### Request path 

### Request Parameters

**Path parameter**
path parameters

|----------|---------|-------|------|-------|
| Parameter |  Type   | Required | Example value |      Description       |
|-----------|---------|----------|---------------|------------------------|
| id        | Integer | Yes      | 1             | The ID of the cluster. |
| hostName | String  | No  | 33.47.251.%        | Hostname |
| tenantId  | Integer | Yes      | 5             | The ID of the tenant.  |
**Body parameter**
| username  | String  | Yes      | root          | The username.          |
|      Parameter     |     Type      | Required |      Example Value    |      Description     |
|------------------|-------------|-------|--------------------|-----------|
| globalPrivileges | ArrayString | Yes  | \[SELECT, CREATE\] | List of global privileges to be granted: <li>For MySQL tenants, it represents the list of global privileges.</li><li>For Oracle tenants, it represents the list of system privileges.</li>   |
