# Query the list of OceanBase clusters

## Description

This API is used to query information about OceanBase clusters managed by OCP.

You can specify keywords of the cluster name and the cluster status to narrow down the search scope. In a primary/standby deployment mode, the returned results include both the primary and standby clusters. You can identify the roles of the clusters based on their attributes.

## How to call

### API constraints

* The caller must have the CLUSTER_VIEWER role.

* The caller must authenticate with OCP.

### Request path

`GET /api/v2/ob/clusters`

### Request parameters

| Parameter | Type | Required | Example value | Description |
|-----------|------|----------|---------------|-------------|
| page      | Integer | No     | 1              | The page number of the requested data. Value range: 1 and above.  Default value: 1.    |
| size      | Integer | No     | 10             | The page size of the requested data. Default value: 10. Maximum value: 2000.     |
| sort      | String | No     | name,asc       | The sorting order of the requested data.    |
| name      | String | No     | foo            | The keyword for filtering clusters by name. The match is case-insensitive.    |
| status    | StringArray | No     | CREATING,RUNNING | The status of clusters.  Valid values: <li>RUNNING: Running.</li><li>CREATING: Creating.  </li><li>DELETING: Deleting.</li><li> STARTING: Starting.  </li><li>RESTARTING: Restarting.</li><li> STOPPING: Stopping.  </li><li>STOPPED: Stopped.</li><li> TAKINGOVER: Taking over.   </li><li>MOVINGOUT: Moving out. </li><li> SWITCHOVER: Switchover in progress.   </li><li>FAILOVER: Failover in progress. </li><li> OPERATING: Under O&M. </li>    |
| withStandby | -     | -  | -             | A deprecated parameter. It will be removed in later versions.    |

### Return result

| Parameter | Type | Description |
|----------|------|-------------|
| data     | Object   | The data of the ObCluster. For more information, see the following table. |
| ├─ contents      | Array    | An array of clusters (including the primary and standby clusters). For more information, see the following table. |
| ├─ page          | Object   | The pagination information.                    |
| ├─ totalElements | Integer  | The total number of records.                    |
| ├─ totalPage     | Integer  | The total number of pages.                     |
| ├─ number        | Integer  | The current page number.                    |
| ├─ size          | Integer  | The number of clusters on the current page.                   |
| successful       | Boolean  | Specifies whether the request is successful.                  |
| timestamp        | Datetime | The timestamp when the server received the request.             |
| duration         | Integer  | The time taken by the server to process the request (in ms).          |
| status           | Integer  | The HTTP status code.    |
| traceId          | String   | The trace ID of the request, which is used for troubleshooting.     |
| server           | String   | The address of the application service that responded to the request.            |

**The data structure of ObCluster**

| Parameter | Type | Description |
|----------|------|-------------|
| primaryCluster          | Object   | The primary cluster.     |
| standbyClusters         | Array    | The array of standby clusters.       |
| id                      | Integer  | The ID of the cluster.        |
| name                    | String   | The name of the cluster.       |
| obClusterId             | Integer  | The ID of the cluster in OceanBase.         |
| obVersion               | String   | The version of the cluster.      |
| status                  | String   | The status of the cluster. Valid values: <li> RUNNING: Running. </li><li> CREATING: Creating.   </li><li>DELETING: Deleting.</li><li>STARTING: Starting.   </li><li>RESTARTING: Restarting.</li><li> STOPPING: Stopping.   </li><li>STOPPED: Stopped.</li><li> TAKINGOVER: Taking over.   </li><li>MOVINGOUT: Moving out.</li><li> SWITCHOVER: Switchover in progress.   </li><li>FAILOVER: Failover in progress.</li><li> OPERATING: O&M in progress.</li>   |
| regionCount             | Integer  | The number of regions.     |
| rootServers             | Array    | The RootServer information.    |
| ├─ address              | String   | The address of the RootServer, in the format of IP:Port.       |
| ├─ role                 | String   | The role of the RootServer. Valid values: <li> LEADER: Leader. </li><li> FOLLOWER: Follower.</li>    |
| ├─ sql_port             | Integer  | The SQL port.    |
| type                    | String   | The type of the cluster. Valid values: <li>PRIMARY: Primary cluster. </li><li>STANDBY: Standby cluster. </li>      |
| regionCount             | Integer  | The number of regions.          |
| tenantCount             | Integer  | The number of tenants.    |
| partitionCount          | Integer  | The number of partitions.      |
| serverCount             | Integer  | The number of OBServer nodes.      |
| delayTime               | Float    | The latency to the standby database, in seconds.    |
| syncStatus              | String   | The status of synchronization between the primary and standby clusters. Valid values: <li>VALID: Valid. </li><li> DISABLED: Synchronization disabled.   </li><li> SYNCHRONIZING: Synchronization in progress.  </li>    |
| zones                   | Array    | The list of zones.        |
| createTime              | DateTime | The creation time.      |
| updateTime              | DateTime | The update time.       |
| creator                 | String   | The creator.        |
| deadLockDetectionEnabled | Boolean | Specifies whether automatic dead lock detection is enabled. |
| failToQueryFromObReason |-   | This parameter has been deprecated. It will be removed in later versions.      |
| loadType                | Enum     | The load type. Valid values: <li>EXPRESS_OLTP</li><li>COMPLEX_OLTP</li><li>HTAP</li><li>OLAP</li><li>KV</li> |

**Zone data structure**

| Parameter | Type | Description |
|-------------|---------|---------------|
| name        | String  | The name of the zone.       |
| idcName     | String  | The name of the IDC.        |
| regionName  | String  | The name of the region.         |
| servers     | Array   | The list of servers.    |
| clusterId   | Long    | The ID of the server.        |
| obClusterId | Long    | The ID of the cluster in OceanBase. |
| serverCount | Integer | The number of servers.     |
| hostCount   | Integer | The number of hosts.          |
