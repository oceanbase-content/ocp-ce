# Modify tenant parameters

## Description

This API is used to modify the parameters of a tenant.

## Call instructions

### API constraints

* The caller must have the permission to update the target tenant.

  For more information about the permissions of the caller, see [Overview of users and permissions](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md).

* The caller must be authenticated by using OCP.

### Request path

`PUT /api/v2/ob/clusters/{id}/tenants/{tenantId}/parameters`

### Request parameters

**path:**

|    Parameter    |  Type  | Required | Example value |      Description       |
|----------|------|----|-----|---------------|
| id       | Long | Yes  | 1   | The ID of the cluster to which the target tenant belongs. |
| tenantId | Long | Yes  | 10  | The ID of the target tenant.     |

**body:**

|          Parameter          |  Type   | Required | Example value |            Description            |
|----------------------|-------|----|-----|--------------------------|
| TenantParameterParam | Array | Yes  | NA  | A list of TenantParameterParam objects. For more information, see **TenantParameterParam data structure**. |

**TenantParameterParam data structure**

|  Parameter   |   Type   | Required |          Example value           |       Description        |
|-------|--------|----|------------------------|-----------------|
| name  | String | Yes  | ob_default_replica_num | The parameter name. The value of this parameter indicates the number of OceanBase Database replicas. |
| value | String | Yes  | 2                      | The value of the parameter.            |
| parameterType | String | Yes  | OB_SYSTEM_VARIABLE  | The type of the parameter. Valid values: OB_SYSTEM_VARIABLE (variable) and OB_TENANT_PARAMETER (parameter).  |

### Response

**Basic data structure**

|     Parameter     |    Type    |          Description           |
|------------|----------|-----------------------|
| successful | Boolean  | Indicates whether the request is successful.               |
| timestamp  | Datetime | The timestamp when the server completes the request.          |
| duration   | Integer  | The time taken by the server to process the request, in milliseconds. |
| status     | Integer  | The HTTP status code that conforms to the HTTP status code standard. |
| traceId    | String   | The trace ID of the request, which is used to troubleshoot issues.  |
| server     | String   | The address of the application service that responds to the request.         |

## Examples

### Request example

`PUT /api/v2/ob/clusters/1/tenants/12/parameters`

```json
[
  {
    "name": "ob_default_replica_num",
    "value": 2
  }
]
```
