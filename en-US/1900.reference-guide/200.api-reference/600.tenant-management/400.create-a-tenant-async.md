# Create a tenant

## Description

The interface used to create a single tenant under the specified cluster.

## Call instructions

### Interface constraints

The caller needs to be authenticated through the OCP application service.

### Request path

`POST /api/v2/ob/clusters/{id}/tenants/createTenant`

### Request parameters

**path:**

| Parameter |   Type    | Required | Example value |  Description   |
|----|---------|----|-----|-------|
| id | Integer | Yes  | 1   | The ID of the cluster to which the target tenant belongs. |

**body:**

|    Parameter   |   Type    | Required |   Example value    |     Description     |
|------------------|---------|---------|--------------------|-------------|
| name             | String  | Yes  | foo                | The name of the tenant, which must be unique in the cluster.    |
| mode             | String  | No  | MYSQL              | The tenant compatibility mode. Valid values: <li>ORACLE</li><li>MYSQL</li>    |
| primaryZone      | String  | No  | zone1,zone2;zone3  | The zone priority.  |
| charset          | String  | No  | utf8mb4            | The character set. Valid values: <ul><li>ORACLE mode: <ul><li>utf8mb4</li><li>gbk</li><li>gb18030 </li></ul></li><li>MYSQL mode: <ul><li>binary</li><li>utf8mb4</li><li>gbk</li><li>gb18030</li></ul></li></ul>Default value: utf8mb4     |
| collation        | String  | No  | utf8mb4_general_ci | The collation. Valid values: <ul><li>binary</li><li>utf8mb4</li><li>gbk</li><li>gb18030</li></ul>Default value: utf8mb4_general_ci.<blockquote>**<UI-TERM key="ocp-v2.Alarm.Template.Detail.Description">Description</UI-TERM>**</br>ORACLE tenants do not support this parameter.</blockquote>   |
| description      | String  | No  | bar                | The description of the tenant.   |
| whitelist        | String  | No  | %                  | Valid formats: <li>IP address, for example, xxx.xxx.xxx.1,xxx.xxx.xxx.2</li><li>Subnet mask, for example, xxx.xxx.xxx.3/24 </li><li>Wildcard match, for example, xxx.xxx.xxx.% or xxx.xxx.xxx.\_</li><li>A combination of multiple formats, for example, xxx.xxx.xxx.1,xxx.xxx.xxx.2,xxx.xxx.xxx.%,xxx.xxx.xxx._,xxx.xxx.xxx.3/24 </li><blockquote>**<UI-TERM key="ocp-v2.component.OperationConfig.List.Description">Description</UI-TERM>**</br>% indicates that all clients can connect. Default value: %.</blockquote>|
| rootPassword     | String  | Yes  |                    | The password of the administrator user. <li>For an ORACLE tenant: SYS user </li><li>For a MYSQL tenant: root user </li><li>Password strength requirements: Length must be 8 to 32 characters, and must contain at least three of the following four types: digits (0-9), uppercase letters (A-Z), lowercase letters (a-z), and special characters. Supported special characters: <code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>. </li>  |
| loadType         | Enum    | If OceanBase Database is V4.2.5.0 or later, this parameter is required. Otherwise, it is not required.  | EXPRESS_OLTP       | The load type. Valid values: <li>EXPRESS_OLTP</li><li>COMPLEX_OLTP</li><li>HTAP</li><li>OLAP</li><li>KV</li> |
| zones            | Array   | Yes  | --                 | --  |
| ├─name           | String  | Yes  | zone1              | The name of the zone in the cluster.   |
| ├─replicaType    | String  | Yes  | FULL               | Valid values: <li>FULL</li><li>LOGONLY</li><li>READONLY</li>  |
| ├─resourcePool   | Object  | Yes  |                    | The resource pool.  |
| ├─unitSpecName   | String  | Yes  | S1                 | View the specification list on the “Unit Specification Management” page.   |
| ├─unitCount      | Integer | Yes  | 1                  | The number of units.  |

### Return result

**Basic data structure**

|     Parameter     |    Type    |          Description           |
|------------|----------|-----------------------|
| data       | Object   | Asynchronous task information. For more information, see [Task information](../400.task-return-structure.md).            |
| successful | Boolean  | Indicates whether the request is successful.               |
| timestamp  | Datetime | The timestamp indicating when the server finishes the request.          |
| duration   | Integer  | The time taken by the server to process the request, in milliseconds.       |
| status     | Integer  | An HTTP status code that conforms to the HTTP status code specification. |
| traceId    | String   | The Trace ID of the request, which is used to troubleshoot issues.  |
| server     | String   | The address of the application service that responds to the request.         |
