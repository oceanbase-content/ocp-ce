# Create a standby tenant

## Description

This API is used to create a standby tenant for a specified OceanBase cluster.

## API description

### API constraints

* The caller must have the permission to modify clusters.

  For more information about the caller's permissions, see [Overview of users and permissions](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md).

* The caller must pass the OCP application service authentication.

### Request path

`POST /api/v2/ob/clusters/{id}/tenants/createStandbyTenant`

### Request parameters

**Path parameters**

| Parameter | Type    | Required | Example value | Description           |
|-----------|---------|---------|--------------|-----------------------|
| id        | Integer | Yes     | 1            | The unique identifier of the cluster. |

**Body parameters**

| Parameter              | Type | Required | Example value | Description |
|------------------------|------|----------|--------------|------------|
| name                   | String               | Yes | standbyA | The tenant name. |
| primaryZone            | String               | No  | zone1;zone2;zone3 | The primary zone. |
| primaryTenantId         | Integer              | Yes | 1 | The primary tenant ID. |
| logTransportMode        | String               | Yes | NETWORK | Specifies the log transmission mode. Valid values include NETWORK and LOG_BACKUP. |
| restoreTenant           | Boolean              | No  | false | Specifies whether to restore the standby tenant using a backup set. This parameter is effective only when `logTransportMode` is set to `NETWORK`. It indicates whether to create a network standby database based on a backup set. |
| enableArbitration        | Boolean              | No  | false | Specifies whether to enable arbitration. |
| backupConfig            | BackupConfigParam    | No   | - | The backup set information. This parameter is required when you directly create a network standby database or create a standby database based on an existing OCP backup strategy.  For more information, see **BackupConfigParam data structure**. |
| zones                   | ZoneParam            | Yes  | - | The replica zone configurations. |
| parameters              | TenantParameterParam | No   | - | The tenant parameters. |
| description             | String               | No   | this is standby tenant | The description. |
| loadType                | Enum                 | No   | EXPRESS_OLTP       | The load type. <li>EXPRESS_OLTP</li><li>COMPLEX_OLTP</li><li>HTAP</li><li>OLAP</li><li>KV</li> |

**BackupConfigParam data structure**

| Parameter              | Type    | Required   | Example value   | Description  |
|------------------------|---------|-----------|----------------|-------------|
| backupStorageType      | Enum    | Yes       | BACKUP_STORAGE_FILE | <li>BACKUP_STORAGE_FILE: NFS storage.<li>BACKUP_STORAGE_OSS: OSS storage.<li>BACKUP_STORAGE_COS: COS storage.<li>BACKUP_STORAGE_S3: S3 storage. </li> |
| dataBackupUrl          | String  | Yes       | `/obbackup/clusterA/tenantA/data` | The data backup directory. |
| logBackupUrl           | String  | Yes       | `/obbackup/clusterA/tenantA/clog` | The log backup directory. |
| ossSecretModel         | ObjectStorageSecretParam       | No       | - | The object storage secret information. This parameter is required when the backup storage type is set to OSS, COS, or S3. For more information, see **ObjectStorageSecretParam data structure**. |

**ObjectStorageSecretParam data structure**

| Parameter | Type | Required | Example value | Description |
|-----------|------|---------|--------------|------------|
| endpoint        | String | Yes | `oss.endpoint.sahnghai.com` | The object storage domain name. |
| accessKeyId     | String | Yes | - | The object storage access key ID. |
| accessKeySecret | String | Yes | - | The object storage access key secret. |
| region          | String | No  | - | The region. This parameter can be left empty. It is required only for the native AWS S3 storage medium.  |
| appId           | String | No  | - | The app ID. This parameter is required only for COS storage. |

### Return result

**Basic data structure**

| Parameter | Type | Description |
|---------|---------|---------|
| data | Object | Asynchronous task information. For more information, see [Task information](../400.task-return-structure.md). |
| successful | Boolean | Specifies whether the request is successful. |
| timestamp | Datetime | The timestamp when the server received the request. |
| duration | Integer | The time taken by the server to process the request (in ms). |
| status | Integer | The status code that complies with the HTTP Status standard. |
| traceId | String | The Trace ID of the request, which is used for troubleshooting. |
| server | String | The address of the application service that responded to the request. |
