# Data Disk

This topic describes the **<UI-TERM key="ocp-v2.Component.OBServerList.Disk">Data Disk</UI-TERM>** monitoring metric for OceanBase tenants. You can specify a statistical scope to query the **<UI-TERM key="ocp-v2.Detail.Capacity.Disk">Data Disk</UI-TERM>** data of a tenant in a single zone or OBServer node.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>When the cluster to which a tenant belongs is an AI cluster (shared storage), the data disk-related metrics are displayed as cache disk metrics, reflecting the usage of the local cache disk rather than the data volume on object storage.</p>
</main>

## data_disk_size

### Metric description

The data volume of the tenant's data disk within the statistical scope.

### Metric parameter description

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">Metric Item</UI-TERM>** | **Metric name** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">Unit</UI-TERM>** |
| ------------- | ----------------------- | -------- |
| data_disk_size | ob_tenant_data_size | Byte |

### Calculation expression

sum(ob_tenant_server_data_size{@LABELS}) by (@GBLABELS)

### Collection SQL

* For OceanBase versions earlier than V4.0.0.0:

  ```sql
  SELECT /*+ READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(50000000) */ tenant_id, svr_ip, svr_port, sum(data_size) as data_size, sum(required_size) as required_size, sum(row_count) row_count from (SELECT tenant_id, svr_ip, svr_port, table_id, partition_id, data_size, required_size, row_count FROM __all_virtual_meta_table union SELECT tenant_id, svr_ip, svr_port, table_id, partition_id, data_size, required_size, row_count FROM __all_root_table) group by tenant_id, svr_ip, svr_port
  ```

* For OceanBase V4.0.0.0 and later, but earlier than V4.2.1.9:
  
  ```sql
  SELECT /*+ READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(50000000) */ tenant_id,svr_ip,svr_port,sum(data_size) as data_size, sum(required_size) as required_size FROM CDB_OB_TABLET_REPLICAS  group by tenant_id, svr_ip, svr_port
  ```

* For OceanBase V4.2.1.9 and later, but earlier than V4.2.2.0:

  ```sql
  select tenant_id, svr_ip, svr_port, sum(occupy_size) as data_size, sum(required_size) as required_size from __all_virtual_tablet_pointer_status group by tenant_id, svr_ip, svr_port
  ```

* For OceanBase V4.2.2.0 and later, but earlier than V4.2.3.0:
  
  ```sql
  SELECT /*+ READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(50000000) */ tenant_id,svr_ip,svr_port,sum(data_size) as data_size, sum(required_size) as required_size FROM CDB_OB_TABLET_REPLICAS  group by tenant_id, svr_ip, svr_port
  ```

* For OceanBase V4.2.3.0 and later, but earlier than V4.3.0.0:
  
  ```sql
  select tenant_id, svr_ip, svr_port, sum(occupy_size) as data_size, sum(required_size) as required_size from __all_virtual_tablet_pointer_status group by tenant_id, svr_ip, svr_port
  ```

* For OceanBase V4.3.0.0 and later, but earlier than V4.3.2.0:
  

## data_index_size

### Metric description

The size of the data disk index for a tenant within the statistical scope.

### Metric parameters

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">Metric Item</UI-TERM>** | **Metric name** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">Unit</UI-TERM>** |
| ------------- | ----------------------- | -------- |
| data_index_size | ob_tenant_data_index_size | Byte |

### Calculation expression

sum(ob_tenant_server_data_index_data_size{@LABELS}) by (@GBLABELS)

### Collection SQL

* For OceanBase versions earlier than V4.0.0.0:

  ```sql
  select /*+ READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(50000000) */ a.tenant_id, b.svr_ip, b.svr_port, sum(size) as data_size from __all_virtual_table_mgr b left join __all_virtual_table a on a.tenant_id = b.tenant_id and a.table_id = b.index_id where a.table_type = 5 group by 1, 2, 3
  ```

* For OceanBase V4.0.0.0 and later:

  ```sql
  select  /*+ READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(50000000) */ a.tenant_id,a.svr_ip,a.svr_port,sum(a.data_size) as data_size FROM CDB_OB_TABLET_REPLICAS as a join (select b.tenant_id, b.tablet_id from  __all_virtual_tablet_to_ls as b right join (select tenant_id, table_id from __all_virtual_table where table_type = 5 and table_id > 500000) as c on b.tenant_id = c.tenant_id and b.table_id = c.table_id union all select tenant_id, table_id as tablet_id from __all_virtual_table where table_type = 5 and table_id < 500000 ) as d on a.tenant_id = d.tenant_id and a.tablet_id = d.tablet_id group by a.tenant_id,a.svr_ip,a.svr_port
  ```

## data_disk_used_percentage

### Metric description

The percentage of data disk usage for a tenant within the statistical scope.

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">Metric Item</UI-TERM>** | **Metric name** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">Unit</UI-TERM>** |
| ------------- | ----------------------- | -------- |
| data_disk_used_percentage | ob_tenant_disk_used_percentage | % |

### Calculation expression
