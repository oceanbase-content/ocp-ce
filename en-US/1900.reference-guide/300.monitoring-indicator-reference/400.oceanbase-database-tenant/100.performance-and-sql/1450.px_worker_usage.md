# Parallel Execution Worker Thread Usage

This topic describes the **Parallel Execution Worker Thread Usage** monitoring metric for an OceanBase tenant. You can specify the statistical scope to query the **Parallel Execution Worker Thread Usage** data of a tenant in a single zone or on a single OBServer node.

## Metric description

The number of active sessions that are executing database commands and occupy CPU resources within the statistical scope.

## Metric parameters

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">Metric Item</UI-TERM>** | **Metric name** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">Unit</UI-TERM>** |
| --------- | ------------------- | -------- |
| px_worker_usage | px_worker_usage | % |

## Calculation expression

max(px_target_usage{@LABELS}) by (@GBLABELS)

## Collection SQL

For OceanBase Database V4.0.0.0 and later:

```sql
select max(t2.tenant_name) as tenant_name, avg(100 * t1.PEER_TARGET_USED / t1.PEER_TARGET) as usage_percentage from GV$OB_PX_TARGET_MONITOR t1 left join DBA_OB_TENANTS t2 on t1.TENANT_ID = t2.TENANT_ID where t2.TENANT_TYPE <> 'META' group by t1.TENANT_ID;
```
