# RPC Requests

This topic describes the monitoring metrics related to LogService RPC requests.

## logservice_rpc_request_success_count

### Metric description

The average number of successful RPC requests per second, categorized by `service` and `method`.

### Metric parameters

| Metrics | Metric Name | unit |
| ------- | --------- | ------ |
| rpc_request_total{status="ok"} | logservice_rpc_request_success_count | times/s |

### Calculation expression

```
sum(rate(rpc_request_total{status="ok",@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus collection

Collect the `rpc_request_total` metric from `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics`` using `prometheusInput`.

## logservice_rpc_requestP95_duration_ms

### Metric description

The P95 percentile of RPC processing duration, categorized by `service` and `method`.

### Metric parameters

| Metrics | Metric Name | unit |
| ------- | --------- | ------ |
| rpc_request_duration_seconds_bucket | logservice_rpc_requestP95_duration_ms | ms |

### Calculation expression

```
1000 * histogram_quantile(0.95, sum(rate(rpc_request_duration_seconds_bucket{@LABELS}[@INTERVAL])) by (@GBLABELS,le))
```

### Prometheus collection

Collect the `rpc_request_duration_seconds_bucket` histogram metric from `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics`` using `prometheusInput`.

---

## logservice_rpc_requestP99_duration_ms

### Metric description

The P99 percentile of RPC processing duration, categorized by `service` and `method`. This metric is used for the `logservice_rpc_request_timeout` alert (threshold ≥ 1000 ms).

### Metric parameters

| Metrics | Metric Name | unit |
| ------- | --------- | ------ |
| rpc_request_duration_seconds_bucket | logservice_rpc_requestP99_duration_ms | ms |

### Calculation expression

```
1000 * histogram_quantile(0.99, sum(rate(rpc_request_duration_seconds_bucket{@LABELS}[@INTERVAL])) by (@GBLABELS,le))
```

### Prometheus collection

Collect the `rpc_request_duration_seconds_bucket` histogram metric from `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics`` using `prometheusInput`.
