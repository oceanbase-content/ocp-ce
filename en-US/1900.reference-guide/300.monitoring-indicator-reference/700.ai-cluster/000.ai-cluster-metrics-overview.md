# Overview of AI Cluster Monitoring Metrics

This topic describes the new AI cluster monitoring metrics added in OCP 4.5.0, including Logservice monitoring metrics and OceanBase Shared Storage (SS) mode monitoring metrics.

## Metric Types

AI cluster monitoring metrics are divided into the following two categories:

### Logservice Monitoring Metrics

Logservice monitoring focuses on the independently deployed **oblogservice** process, with the monitoring dimension being `LOG_SERVICE`.

Logservice monitoring metrics include the following categories:

* [Log Reception and Writing](100.logservice/100.log-receiving-and-writing.md)
* [Log Latency](100.logservice/200.log-latency.md)
* [Log Reading](100.logservice/300.log-reading.md)
* [FetchLog Operations](100.logservice/400.fetchlog.md)
* [RPC Requests](100.logservice/500.rpc.md)
* [HTTP Requests](100.logservice/600.http.md)
* [GC Collection](100.logservice/700.gc.md)
* [Object Storage Upload](100.logservice/800.object-storage-upload.md)
* [Thread Pool](100.logservice/900.thread-pool.md)
* [Process Resources](100.logservice/1000.process-resources.md)
* [Latency and Status](100.logservice/1100.delay-and-status.md)

### OceanBase Shared Storage (SS) Mode Monitoring Metrics

The following monitoring groups apply to **OceanBase Shared Storage (SS) mode**, requiring an OB cluster version of **≥ 4.6.2.0**.

Shared storage monitoring metrics include the following categories:

* [SS Macroblock Hit Rate](200.shared-storage/100.ss-macro-hit.md)
* [SS Macroblock Cache Size](200.shared-storage/200.ss-macro-cache-size.md)
* [Shared Data](200.shared-storage/300.shared-data.md)
* [Local Cache Warm-up](200.shared-storage/400.ss-local-cache-prewarm.md)
