# Delete a Binlog instance

This topic describes how to delete a Binlog instance.

In OCP, you can delete a Binlog instance in the following ways:

* **Method 1**: Go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the target Binlog instance and click **... > Delete Binlog Instance** in the Actions column.
* **Method 2**: Go to the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page of the target Binlog instance. Click **... > Delete Binlog Instance** in the upper-right corner.

## Prerequisites

* You have logged in to OCP as a user who has the following permissions:

  * The **Binlog Service Maintenance** permission.
  * The **Binlog Cluster Overview** permission for the Binlog service.

* The Binlog instance to be deleted is a standby instance, and the corresponding Binlog Server and Binlog cluster are in the **Running** state.

## Procedure

The following example describes **Method 2**.

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** section, find the target Binlog cluster and click its name. The **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page automatically appears.

4. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the target Binlog standby instance and click its name.

5. On the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, click **... > Delete Binlog Instance** in the upper-right corner.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Auth.Role.Detail.Delete">Delete</UI-TERM>**.
