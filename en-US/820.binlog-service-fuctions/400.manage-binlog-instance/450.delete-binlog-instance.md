# Delete a Binlog instance

This topic describes how to delete a standby Binlog instance.

In OCP, you can delete a standby instance by using one of the following two methods:

* **Method 1**: Go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** list, select the standby instance that you want to delete and click **... > Delete Binlog Instance** in the Actions column.
* **Method 2**: Go to the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page of the standby instance and click **... > Delete Binlog Instance** in the upper-right corner.

## Prerequisites

* Ensure that the current user logged in to OCP has the following permissions:

  * The **Binlog Service Maintenance** resource permission.
  * The **Binlog Cluster Overview** menu permission for the Binlog service.

* The Binlog instance to be deleted is a standby instance, and the Binlog Server and Binlog cluster corresponding to the instance are in the **RUNNING** state.

## Procedure

The following procedure uses **Method 2** as an example.

1. Log in to OCP.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlog Service</UI-TERM>**. The system goes to the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** page by default.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** list, find the target Binlog cluster and click its name. The **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page appears.

4. In the **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlog Instance List</UI-TERM>** section, find the standby Binlog instance you want to delete and click its name.

5. On the **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog Instance Overview</UI-TERM>** page, click **... > Delete Binlog Instance** in the upper-right corner.

6. In the dialog box, click **<UI-TERM key="ocp-v2.pages.Host.RegionList.Delete">Delete</UI-TERM>**.
