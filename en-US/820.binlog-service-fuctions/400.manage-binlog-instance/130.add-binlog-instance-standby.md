# Add an instance replica

This topic describes how to add an instance replica for a business tenant. You can use the "one primary and multiple standby" mode to ensure data synchronization between the primary and standby instances, thereby further enhancing the high availability of the Binlog service. It is recommended that a single Binlog Server host only carry one Binlog instance replica for a business tenant, with a maximum of five replicas per tenant.

## Prerequisites

* The Binlog service has been enabled for the business tenant. For details, see [Manage tenant Binlog service](../../700.tenant-functions/600.manage-a-tenant/700.manage-binlog-service-of-a-tenant.md).

* Ensure the current OCP user has the following permissions:

  * **Binlog Service Maintenance** resource permission.
  * **Binlog Cluster Overview** menu permission for the Binlog service.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlog Service</UI-TERM>**. The system enters the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page by default.

3. On the **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">Clusters</UI-TERM>** page, select the target Binlog cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Binlog.Component.AddInstanceModal.AddACopyOfAn">Add Instance Replica</UI-TERM>** in the upper-right corner.

5. In the **<UI-TERM key="ocp-v2.Binlog.Component.AddInstanceModal.AddACopyOfAn">Add Instance Replica</UI-TERM>** dialog box, specify the business tenant and configure the number of replicas and host information.

   You can deploy all instance replicas on the same host, or click **<UI-TERM key="ocp-v2.Binlog.Component.AddInstanceModal.AddInstanceReplica">Add Instance Replica</UI-TERM>** to deploy them on different hosts.

6. Click **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.Add">Add</UI-TERM>** to submit the task.

   You can view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**. When the task status is **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">Completed</UI-TERM>**, the addition is successful.
