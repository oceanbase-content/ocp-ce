# Add an instance replica

This topic describes how to add an instance replica for a business tenant. You can use the "one primary and multiple standby" mode to ensure data synchronization between the primary and standby instances, thereby enhancing the high availability of the Binlog service. We recommend that you configure only one Binlog instance replica for a single Binlog server. A business tenant can have up to five instance replicas.

## Prerequisites

* The Binlog service is enabled for the business tenant. For more information, see [Manage the Binlog service of a tenant](../../700.tenant-functions/600.manage-a-tenant/700.manage-binlog-service-of-a-tenant.md).

* The user logged in to the OCP console has the following permissions:

  * **Binlog service maintenance** resource permission.
  * **Binlog cluster overview** menu permission for the Binlog service.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, click **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlog Service</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">Clusters</UI-TERM>** page, find the target Binlog cluster and click its name.

4. On the **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlog Cluster Overview</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Binlog.Component.AddInstanceModal.AddACopyOfAn">Add Instance Replica</UI-TERM>** in the upper-right corner.

5. In the **<UI-TERM key="ocp-v2.Binlog.Component.AddInstanceModal.AddACopyOfAn">Add Instance Replica</UI-TERM>** dialog box, specify the business tenant and configure the number of replicas and host information.

   You can deploy all instance replicas on the same host or click **<UI-TERM key="ocp-v2.Binlog.Component.AddInstanceModal.AddInstanceReplica">Add Instance Replica</UI-TERM>** to deploy the instance replicas on different hosts.

6. Click **<UI-TERM key="ocp-v2.Host.Component.AddHostIdcModal.New">Add</UI-TERM>** to submit the task.

   You can view the task progress in **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>**. When the task status is **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">Completed</UI-TERM>**, the instance replica is added.
