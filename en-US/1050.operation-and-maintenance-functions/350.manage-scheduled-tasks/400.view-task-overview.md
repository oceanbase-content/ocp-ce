# View scheduled task details

You can refer to this section to view the configuration information and operation records of scheduled tasks.

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **Scheduled Tasks**.

3. The **Operation Records** tab displays a list of all executed scheduled tasks. You can view the operation details of each task, including **<UI-TERM key="ocp-v2.page.Task.TaskName">Task Name</UI-TERM>**, **Execution Object**, **Task Type**, **Estimated Execution Time**, **Actual Execution Time**, **<UI-TERM key="ocp-v2.pages.ReportCenter.SuccessModal.TaskStatus">Task Status</UI-TERM>**, and related operations.

   * You can filter operation records by execution status in the upper-right corner.
   * Enter a task name in the search box to perform a fuzzy search on operation records.
   * Click a task name to view its configuration information during execution.
   * You can filter operation records by **Task Type**.
   * You can sort task records by **Plan Execution Time** and **Actual Execution Time**.
   * Click **View Execution Progress** in the Actions column to go to the task execution page and view the task execution details.

4. The **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** tab displays a list of all created scheduled tasks. You can view the configuration details of each task, including **<UI-TERM key="ocp-v2.page.Task.TaskName">Task Name</UI-TERM>**, **Execution Object**, **Task Type**, **Scheduling Plan**, **Next Execution Time**, **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.TotalExecutionTimes">Total Executions</UI-TERM>**, **<UI-TERM key="ocp-v2.Alarm.Channel.Founder">Created By</UI-TERM>**, **<UI-TERM key="ocp-v2.Task.Detail.TaskStatus">Task Status</UI-TERM>**, and related operations.

   * You can filter scheduled tasks by task status in the upper-right corner.
   * Enter a task name in the search box to perform a fuzzy search on scheduled tasks.
   * Click a task name to view its current configuration details.
   * You can filter scheduled tasks by **Task Type**.
   * You can sort scheduled tasks by **Next Execution Time**.
   * You can perform daily management operations on scheduled tasks, including forced execution, disabling/enabling, editing, copying, and deleting. For more information, see [Manage scheduled tasks](300.manage-a-scheduled-task.md).

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   When viewing configuration details, if the task's execution object has just been deleted or migrated out, or if you currently do not have access permissions, the system may need some time to synchronize the status update. It is recommended that you wait for about 3 minutes to ensure you obtain the latest status information.
   </main>
