# Manage scheduled tasks

This topic describes how to perform routine management on scheduled tasks.

## Force the execution of a scheduled task

You can refer to this section to forcibly execute a created scheduled task. Forced execution will run the task immediately without affecting its scheduling plan; the task will still be executed again at its next scheduled time.

### Prerequisites

Ensure the scheduled task to be executed is in the **Normal** state.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, select **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **Scheduled Tasks**.

3. Go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** tab.

4. Select the scheduled task you want to force execute, and choose **...** > **Force Execution** in the Actions column.

## Disable a scheduled task

You can refer to this section to disable a created scheduled task. After disabling, the task will no longer be executed according to the scheduling plan.

### Prerequisites

Ensure the scheduled task to be executed is in the **Normal** state.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, select **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **Scheduled Tasks**.

3. Go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** tab.

4. Select the scheduled task you want to disable, and choose **...** > **<UI-TERM key="ocp-v2.src.constant.inspection.Disable">Disable</UI-TERM>** in the Actions column.

## Enable a scheduled task

You can refer to this section to re-enable a disabled scheduled task. After re-enabling, the task will resume execution at its next scheduled time according to the scheduling plan.

### Prerequisites

Ensure the scheduled task to be executed is in the **Disabled** state.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **Scheduled Tasks**.

3. Go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** tab.

4. Select the scheduled task you want to enable and choose **...** > **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Enable">Enable</UI-TERM>** in the Actions column.

## Edit a scheduled task

You can modify the scheduling plan of a scheduled task by referring to this section.

### Prerequisites

Ensure that the scheduled task to be executed is in the **Normal** or **Disabled** state.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **Scheduled Tasks**.

3. Go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** tab.

4. Select the scheduled task you want to enable and choose **...** > **<UI-TERM key="ocp-v2.src.constant.credential.Edit">Edit</UI-TERM>** in the Actions column.

5. Modify the task configuration in the **Edit Scheduled Task** panel and click **<UI-TERM key="ocp-v2.Compaction.Settings.EditCard.Save">Save</UI-TERM>**.

## Copy a scheduled task

You can refer to this section to copy an existing scheduled task, which helps you quickly create a similar scheduled task and reduces your time cost.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **Scheduled Tasks**.

3. Go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** tab.

4. Select the scheduled task you want to enable and choose **...** > **<UI-TERM key="ocp-v2.Auth.Role.Copy">Copy</UI-TERM>** in the Actions column.

5. Modify the task configuration as needed and click **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.Copy">Copy</UI-TERM>**.

## Delete a scheduled task

You can refer to this section to delete an existing scheduled task. After deletion, the task configuration cannot be restored. Proceed with caution.

### Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">O&M Management</UI-TERM>** > **Scheduled Tasks**.

3. Go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** tab.

4. Select the scheduled task you want to enable, and choose **...** > **<UI-TERM key="ocp-v2.Alarm.Shield.Delete">Delete</UI-TERM>** in the Actions column.

5. In the confirmation dialog box, click **<UI-TERM key="ocp-v2.src.constant.compute.Delete">Delete</UI-TERM>**.
