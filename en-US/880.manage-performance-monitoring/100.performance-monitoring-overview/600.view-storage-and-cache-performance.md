# View storage and cache

This topic describes how to view the storage and cache monitoring data of a tenant in OCP. You can view the data through the following two methods:

* **Method 1**: Log in to OCP, go to the Tenant Overview page, and click **<UI-TERM key="ocp-v2.Detail.Realtime.PerformanceMonitoring">Performance Monitoring</UI-TERM>** in the left-side navigation pane.

* **Method 2**: Log in to OCP, click **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>** in the left-side navigation pane to go to the **<UI-TERM key="ocp-v2.Task.TaskObjectAndType.OceanbaseTenants">OceanBase Tenant</UI-TERM>** tab.

## Prerequisites

* When viewing tenant storage and cache monitoring data by using **Method 1**, ensure that the current OCP user has the following permissions:

  * **Cluster Read Only** or **Tenant Read Only** resource permission.
  * Tenant **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">Performance Monitoring</UI-TERM>** menu permission.

* When viewing tenant storage and cache monitoring data by using **Method 2**, ensure that the current OCP user has the following permissions:

  * **Cluster Read Only**, **Tenant Read Only**, or **Host Read Only** resource permission.
  * Performance Monitoring **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ArbitrationServiceWithExclude.All">All</UI-TERM>** menu permission.

## Version limitations

* The <b>Frozen MEMStore</b> monitoring metric is applicable to OceanBase versions from [-∞, V4.0.0.0).

* The <b>Vector Index Data Size</b> and <b>Vector Index Data Usage Percentage</b> monitoring metrics are applicable to OceanBase versions from [V4.3.5.3, +∞).

* The <b>Log Disk</b> monitoring metric is applicable to OceanBase versions from [V4.0.0.0, +∞).

* For the <b>Physical IO Count</b>, <b>Physical IO Time</b>, and <b>Physical IO Throughput</b> monitoring metrics, the sub-items <code>clog_read</code> and <code>clog_write</code> are applicable to OceanBase versions from [V4.1.0.3, +∞).

* The <b>Dump Partitions</b> monitoring metric is applicable to OceanBase versions from [V4.2.0.0, +∞).

<main id="notice" type='explain'>
<h4>Note</h4>
<p>When the tenant belongs to an AI cluster (shared storage), the data disk-related metrics in the storage and cache monitoring are displayed as cache disk metrics. Additionally, the <b>Object Storage IOPS</b> and <b>Object Storage Bandwidth</b> monitoring metrics are added to monitor the read and write performance of object storage.</p>
</main>

## Procedure

The following steps use **Method 2** as an example.

1. Log in to OCP.

2. In the left-side navigation pane, select **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

3. Select the **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.OceanbaseTenants">OceanBase Tenant</UI-TERM>** tab.

4. In the **<UI-TERM key="ocp-v2.component.MonitorSearch.DataFiltering">Data Filtering</UI-TERM>** section, configure the monitoring data filtering conditions.

   The filter conditions are described in the following table:

   | Filter Condition | Description |
   |---------------|---------|
   | Refresh | Refreshes monitoring data. Automatic refresh is supported and is disabled by default. When automatic refresh is enabled, you can configure the refresh frequency.|
   | Time Range (also known as Monitoring Window) | Not displayed in automatic refresh mode. Select a time range to retrieve data within that period.  |
   | Tenant | Select a tenant to monitor.  |
   | Zone | By default, all zones are monitored.|
   | OBServer | By default, all OBServer nodes are monitored.|
  
5. Click the **Storage and Cache** tab to view related monitoring data on this tab.

   * OCP supports viewing monitoring data from two dimensions: tenant and unit. Data is displayed by default in the tenant dimension. The monitoring metrics supported for viewing vary by dimension.
   * The system displays all monitoring items under the current dimension by default. If you do not need to pay attention to a certain monitoring item, you can uncheck it in the **<UI-TERM key="ocp-v2.Detail.Monitor.IndicatorSelection">Selected Chart</UI-TERM>** panel on the right side of the area.
   * All monitoring items support displaying the maximum value (max), average value (avg), and current value (current) of each sub-metric.
   * For the specific meaning and value source of all monitoring items, you can refer to [Overview of monitoring metrics](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md). If the statistical range involves multiple OBServer nodes, an aggregated value is displayed.

   The following features help you better view and analyze detailed performance monitoring data in trend charts. You can understand them in combination with the following text and images.

   <!-- ![Image 114](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1426.png) -->

   * View and hide data for other sub-metrics: Hover the cursor over the metric area and scroll the mouse wheel up or down to view data for all sub-metrics displayed in the trend chart. Click the identifier of another sub-metric to gray it out, and that metric's information will not be displayed in the trend chart.

   * Hover the cursor over a point in time in the trend chart to view detailed data at that moment. Drag the cursor to select an area, and the system will zoom in to display the trend information for that area. You can view the detailed trend of the metric during this time period. Double-click the trend chart to restore it.

   * Zoom in on a trend chart: Click the zoom icon in the upper-right corner of the trend chart. The functions of ① and ② in the figure above also apply to the zoomed-in trend chart.

   * Edit a monitoring metric: Click the edit icon in the upper-right corner of the trend chart to choose which sub-metrics to display.

   * Drill down to view monitoring data from different dimensions: On the **<UI-TERM key="ocp-performance-report.pages.AWR.ReportContent.Tenant">Tenants</UI-TERM>** tab, if you find abnormal monitoring data for a tenant, such as excessively high physical I/O latency, you can perform drill-down analysis to locate the server causing the abnormal response time. Click the **<UI-TERM key="ocp-v2.component.MetricChart.Item.DrillDownAnalysis">Drill-down Analysis</UI-TERM>** icon in the upper-right corner of the trend chart to view the drill-down analysis details. The drill-down dimensions supported by **Storage and Cache** are: **Tenant \> OBServer**.

       The functions of ① and ② in the figure above also apply to the trend chart on the drill-down page. Additionally, you can:

       * Reset filter conditions on the drill-down page. If you have not set conditions, the settings from the parent level will be automatically inherited.

       * If the metric has sub-metrics, you can select them to view.

       * The trend chart provides a **Go to Host Performance Monitoring** feature. Hover the cursor over the **Go to Host Performance Monitoring** link, select the host you want to view, and it will redirect you to the **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">Performance</UI-TERM>** page of the relevant host to view the host monitoring details.
