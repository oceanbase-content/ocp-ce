# Overview of OceanBase Cloud Platform

The overview page of OceanBase Cloud Platform provides you with an overall view of various resources managed in OCP, such as OceanBase clusters, OceanBase tenants, OBProxy clusters, and hosts. You can view the alerts, diagnostics, and resource usage of each resource, which helps you quickly locate and resolve issues.


## Prerequisites

The current user logged in to OCP has the ADMIN or ADMIN_VIEWER role.

## Basic Resource Information

You can view the running status of OceanBase clusters, OceanBase tenants, OBProxy clusters, and hosts, and perform O&M management on resource objects with abnormal status in a timely manner.

Hover the cursor over the **?** icon next to **<UI-TERM key="ocp-v2.Auth.Org.SharedResourceDrawer.OceanbaseCluster">OceanBase Cluster</UI-TERM>** to view statistics on the number of core deployment units for the cluster.

## Task and Diagnostic Information

You can view task information and diagnostic information.

* Task Information: You can view the alert status, alert level, backup tasks, O&M tasks, and the top 5 major compactions within the last 7 days.
* Diagnostic Information:
  * SQL Diagnostics: Displays the number of clusters with suspicious SQL, slow SQL, and new SQL within the last 6 hours.
  * Transaction Diagnostics: Displays the number of clusters with long transactions and suspended transactions in real time.
  * Session Diagnostics: Displays the number of clusters with deadlocks within the last 7 days.
  * Security Diagnostics: Displays the number of clusters with high-risk SQL within the last 7 days.
  * Optimization History: Displays the number of clusters with optimization history within the last 7 days.
