# Lock an Oracle tenant user

This topic describes how to lock an Oracle tenant user. A locked user will not be allowed to log in. Proceed with caution.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This content applies only to OCP Enterprise Edition. OCP Community Edition provides only MySQL-compatible tenants.</p>
</main>

## Prerequisites

* Ensure the current OCP user has the following permissions:

  * The **Cluster Maintenance** or **Tenant Maintenance** resource permission.
  * The **User Management** menu permission for the tenant.

* The `sys` user cannot be locked.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, select **<UI-TERM key="ocp-v2.src.constant.plan.Tenant">Tenant</UI-TERM>**. The system enters the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** tab by default.

3. On the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">Tenants</UI-TERM>** page, find the target Oracle tenant and click its name to go to the tenant's **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page.

4. Click **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.UserManagement">User Management</UI-TERM>** in the left navigation bar.

5. On the **<UI-TERM key="ocp-v2.User.MySQL.UserList">Users</UI-TERM>** page, select the user you want to lock, and click **<UI-TERM key="ocp-v2.component.TenantList.Locking">Lock</UI-TERM>** in the **...** actions column; or select multiple users and click **<UI-TERM key="ocp-v2.User.Oracle.UserList.Lock">Lock</UI-TERM>** at the bottom of the list.

6. In the dialog box, click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Determine">OK</UI-TERM>**.
