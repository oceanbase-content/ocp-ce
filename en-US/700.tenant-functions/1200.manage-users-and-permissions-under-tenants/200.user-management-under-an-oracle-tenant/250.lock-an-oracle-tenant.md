# Lock an Oracle tenant user

This topic describes how to lock an Oracle tenant user. After a user is locked, the user cannot log in to the database. Proceed with caution.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition provides only MySQL tenants. </p>
</main>

## Prerequisites

* You have logged in to the OCP console as the root user or an OCP user with the following permissions:

  * The **Cluster Maintenance** or **Tenant Maintenance** resource permission.
  * The **User Management** permission on the **<UI-TERM key="ocp-v2.page.Auth.UserManagement">User Management</UI-TERM>** page of the tenant.

* You cannot lock the `sys` user.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.component.TenantLabel.Tenant">Tenant</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Tenant.TenantList">Tenants</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.Tenant.TenantList">Tenants</UI-TERM>** page, find the target Oracle tenant and click its name to go to the **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page of the tenant.

4. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.page.Auth.UserManagement">User Management</UI-TERM>**.

5. On the **<UI-TERM key="ocp-v2.User.Oracle.UserList">Users</UI-TERM>** page, find the user that you want to lock and click **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Lock">Lock</UI-TERM>** in the **Actions** column. You can also select multiple users and click **<UI-TERM key="ocp-v2.Tenant.Detail.Locking">Lock</UI-TERM>** in the lower part of the list.

6. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Component.ZoneList.EditZoneModal.Ok">OK</UI-TERM>**.
