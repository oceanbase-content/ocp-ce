# Modify parameters

You can modify the values of tenant parameters as needed. All modified tenant parameter values take effect in real time.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>When the cluster to which a tenant belongs is an AI cluster (shared storage), the following tenant-level parameters are added:<ul><li><b>shared_log_retention</b>: The retention period for shared logs. Default value: 1 day. Value range: [0d, 14d].</li><li><b>read_cache_disk_percentage</b>: The percentage of disk space used for the read cache. Default value: 40. Value range: [0, 90].</li><li><b>cache_disk_memory_limit</b>: The memory limit for the cache disk. Default value: 10. Value range: [5, 50].</li></ul></p>
</main>

## Prerequisites

Ensure that the current OCP user has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** resource permissions.
* Permission to access the **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">Parameter Management</UI-TERM>** menu for the tenant.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, select **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Tenant">Tenant</UI-TERM>**. The system goes to the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">Tenants</UI-TERM>** tab by default.

3. On the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the tenant **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page.

4. In the left navigation bar of the displayed page, click **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">Parameter Management</UI-TERM>**.

5. (Optional) In the search box at the top of the **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">Parameters</UI-TERM>** page, enter a parameter name to perform a fuzzy search.

6. Find the parameter to be modified and click the **<UI-TERM key="ocp-v2.Detail.Parameter.ModifyValue">Modify Value</UI-TERM>** button.

7. In the dialog box that appears, modify the parameter value.
