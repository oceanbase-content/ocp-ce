# Delete a unit

This topic describes how to delete a unit in a specified zone or delete multiple units across multiple zones in OCP. Deleted units cannot be recovered. Proceed with caution.

## Prerequisites

Ensure the current OCP user has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** resource permissions.
* Permission to access the **Overview** menu of the tenant.
  
## Considerations

Before deleting a unit, consider the following:

* **Deleting a specific unit**

  * For clusters of version V3.x, ensure there are at least two OBServer nodes in the zone.
  * For clusters of the following versions, ensure asymmetric zones are enabled for the tenant.
    * [V4.2.5.5, V4.3.0.0)
    * [V4.4.2.0, V4.5.0.0)

* **Batch deleting units**

  * Ensure the cluster version is V4.x or later.
  * Ensure there are at least two OBServer nodes in the zone.
  * Currently, only deleting unit groups reduces the number of units. Proceed based on your actual situation.
  * Deleting units triggers data migration among OBServer nodes within the zone. During the operation, closely monitor the CPU utilization and network bandwidth consumption of each host to prevent excessive resource usage from impacting business loads.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, select **<UI-TERM key="ocp-v2.Alarm.Event.Tenant">Tenant</UI-TERM>**. The system goes to the **<UI-TERM key="ocp-v2.page.Tenant.TenantList">Tenants</UI-TERM>** tab by default.

3. On the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the tenant's **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.CopyDetails">Replica Details</UI-TERM>** section, you can perform the following operations:

   * Select a specific zone, choose **...** > **Delete Unit** in the Actions column, select the belonging OBServer in the dialog box that appears, and click **<UI-TERM key="ocp-v2.Auth.User.Detail.Delete">Delete</UI-TERM>** to delete the specified unit in that zone.
   * In the upper-right corner, select **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.BatchDelete">Batch Delete</UI-TERM>** > **Unit**, select the zone name and belonging OBServer in the dialog box that appears, add multiple unit objects via **Add Delete Objects**, and click **<UI-TERM key="ocp-v2.src.constant.binlog.Delete">Delete</UI-TERM>** to delete multiple units simultaneously.
