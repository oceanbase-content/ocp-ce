# Modify units

This topic describes how to modify the specifications and number of units for all replicas of a tenant in batches.

## Prerequisites

* You have logged in to the OCP console as a user who has the following permissions:

  * **Cluster Maintenance** or **Tenant Maintenance** permission.
  * **Overview** permission on the tenant menu.

* In V4.0.0 and later, the unit specifications are limited by default. If you want to select a unit specification smaller than the default, you can use the <code>__min_full_resource_pool_memory</code> parameter to adjust the minimum unit specification. For example, in V4.1.0, you can modify the parameter as described in <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-10000000001697240">Modify cluster item configurations</a>.

* If the cluster to which a common tenant belongs is V4.2.0 or later, and the <code>enable_rebalance</code> parameter of the tenant is set to <code>false</code>, you cannot modify the number of units in a zone.

* During unit scaling down, additional space may be occupied. Make sure that sufficient space is available to avoid unit scaling down failure due to insufficient storage space.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.RealtimeMonitor.View3D.OverviewStat.Tenant">Tenant</UI-TERM>**. The **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** page automatically appears.

3. In the **<UI-TERM key="ocp-v2.page.Tenant.TenantList">Tenants</UI-TERM>** list, find the target tenant and click its name to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page.

4. In the **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.CopyDetails">Replica Details</UI-TERM>** section, click **<UI-TERM key="ocp-v2.Detail.Overview.ModifyUnit">Modify Unit</UI-TERM>** in the upper-right corner.

    <main id="notice" type='notice'>
    <h4>Notice</h4>
    <p>Reducing the number of units triggers partition replica migration, which increases the storage I/O of OBServer nodes and the network traffic between OBServer nodes. To control the traffic surge, we recommend that you change the values of the <code>ha_high_thread_score</code> and <code>ha_mid_thread_score</code> parameters, or isolate resources for the background tasks <code>HA_HIGH</code> and <code>HA_MID</code>. </p>
    </main>

5. Click **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Save">Save</UI-TERM>** to complete the modification.
