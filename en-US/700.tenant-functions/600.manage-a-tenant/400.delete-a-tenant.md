# Delete a tenant

This topic describes how to delete a tenant. When you delete a tenant, OCP also deletes its resource pools and tenant data. Deleted tenants cannot be moved to the recycle bin, and the tenant data cannot be recovered. Proceed with caution.

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>If the tenant belongs to an AI cluster (shared storage), the data on its object storage will not be immediately cleared after the tenant is deleted but will be gradually reclaimed.</li>
<li>After a tenant is deleted, you may find that the space occupied by object storage does not decrease immediately. If storage space is tight and you create a new tenant or import large amounts of data immediately, shared storage space may be insufficient. Plan your storage space in advance.</li>
</ul>
</main>

## Prerequisites

* Ensure the current OCP user has the following permissions:

  * **Cluster Management** or **<UI-TERM key="ocp-v2.src.util.menu.TenantManagement">Tenants</UI-TERM>** resource permissions.
  * **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** menu permission.

* Currently, only the primary cluster supports deleting tenants; standby clusters do not.
* If the current tenant is used to host the MetaDB information for Binlog Service, the tenant cannot be deleted.
* The tenant to be deleted is in the **Locked** state.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, select **<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.Tenant">Tenant</UI-TERM>**. The system goes to the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** tab by default.

3. On the **<UI-TERM key="ocp-v2.component.TenantList.TenantList">Tenants</UI-TERM>** page, select the target tenant and click its name to go to the tenant's **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">Overview</UI-TERM>** page.

4. On the tenant **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">Overview</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.DeleteATenant">Delete Tenant</UI-TERM>** in the upper-right corner.

   <!-- ![10141011](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%88%A0%E9%99%A4%E7%A7%9F%E6%88%B71.png) -->

5. In the dialog box that appears, enter **delete**.

   <!-- ![10141012](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/01241426.png) -->

6. Click **<UI-TERM key="ocp-v2.component.DatabasePrivilegeTransfer.PrivilegesCheckbox.Delete">Delete</UI-TERM>**.
