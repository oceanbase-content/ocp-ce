# Manage tenant parameters

You can refer to this section to set differentiated suspicious SQL diagnostic rules for different tenants to meet diverse business needs.

## Prerequisites

Ensure the current OCP user has the following permissions:

* **Cluster Maintenance** or **Tenant Maintenance** resource permission.
* Permission to access the **Overview** menu for the tenant.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, select **<UI-TERM key="ocp-v2.src.constant.report.Tenant">Tenant</UI-TERM>**. The system enters the **<UI-TERM key="ocp-v2.page.Tenant.TenantList">Tenants</UI-TERM>** tab by default.

3. On the **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">Tenants</UI-TERM>** page, find the target tenant and click its name to go to the tenant's **<UI-TERM key="ocp-v2.page.Overview.Overview">Overview</UI-TERM>** page.

4. Click the **...** icon in the upper-right corner and select **Tenant Parameters**.

5. In the panel that appears, select the parameter you want to modify and click the edit button next to its value. Some parameter changes take effect only after restarting the OCP server. This is indicated in the **<UI-TERM key="ocp-v2.Detail.Parameter.List.WhetherTheRestartTakesEffect">Restart to Apply Changes</UI-TERM>** column.
