# Parameter template

A parameter template is used to manage and apply parameter configurations to LogService clusters in batches. You can create a parameter template, define a set of parameter values, and then select to apply this template when creating a new cluster.

<main id="notice" type='notice'>
<h4>Note</h4>
<p>Parameter templates can only be applied when creating a <b>new cluster</b>. After a cluster is created, you cannot modify its parameters via a template; you must use the <b>Parameter Management</b> feature to modify cluster parameters individually.</p>
</main>

## Prerequisites

Ensure the current OCP user has the following permissions:

* The **Logservice Management** resource permission.
* The **Parameter Template** menu permission for Logservice.

## View the parameter template list

1. Log in to OCP.

2. In the left navigation bar, select **Logservice Instance**.

3. Click the **Parameter Template** tab to go to the parameter template list page.

   On this page, you can view the following information:

   | Item | Description |
   |-------|------|
   | Template Name | The name of the parameter template. |
   | Number of Parameters | The number of parameters in the template. |
   | Remarks | The description of the template. |
   | Created By | The user who created the template. |
   | Last Modified At | The time when the template was last modified. |
   | Last Modified By | The user who last modified the template. |

## Create a parameter template

1. On the parameter template list page, click **Create Template**.

2. In the Create Template dialog box, enter the following information:

   | Item | Description |
   |-------|------|
   | Template Name | Enter the name of the template. |
   | Remarks (Optional) | Enter a description for the template. |

3. Click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLLimit.Determine">OK</UI-TERM>** to go to the template details page.

4. On the template details page, add the parameters and their values you need to manage:

   | Information Item | Description |
   |-------|------|
   | Parameter Name | Select the parameter you want to configure. |
   | Parameter Value | Enter the value for this parameter. |
   | Value Type | Displays the value type of the parameter. |
   | Value Range | Displays the allowed value range of the parameter. |

5. Click **+ Add Parameter** to add more parameters.

6. After configuring the parameters, click **<UI-TERM key="ocp-v2.External.Component.DataSourceTable.New">Create</UI-TERM>**.

<main id="notice" type='explain'>
<h4>Note</h4>
<p>To delete an added parameter, click the <b>Delete</b> button in the corresponding parameter row.</p>
</main>


After creating a parameter template, you can select it when creating a new LogService cluster. For specific operations, see [Create a LogService cluster](../300.manage-a-logservice-cluster/200.create-a-logservice-cluster.md).



## Related operations

### Edit a parameter template

1. In the parameter template list, find the template you want to edit.

2. Click the template name to go to the template details page.

3. You can perform the following operations:

   * **<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterModal.ModifyParameterValues">Modify Value</UI-TERM>**: Directly modify the value of an existing parameter.
   * **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.AddParameters">Add Parameter</UI-TERM>**: Click **+ Add Parameter**, select new parameters, and set their values.
   * **Delete Parameter**: Click the **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Delete">Delete</UI-TERM>** button in the parameter row to remove unnecessary parameters.
   * **<UI-TERM key="ocp-v2.Detail.Overview.ModifyRemarks">Modify Remarks</UI-TERM>**: Modify the template's remarks in the template information area.

4. After completing the modifications, click **<UI-TERM key="ocp-v2.External.Component.CreateSlsDataSource.Save">Save</UI-TERM>**.

### Copy a parameter template

1. In the parameter template list, find the template you want to copy.
2. Click the **<UI-TERM key="ocp-v2.AIModel.Component.SetSystemModel.More">More</UI-TERM>** icon in the row where the template is located, or right-click the template.
3. In the action menu, select **<UI-TERM key="ocp-v2.Alarm.Template.Copy">Copy</UI-TERM>**.
4. In the copy dialog box that appears, enter the following information:

   | Information Item | Description |
   |-------|------|
   | Template Name | Enter the name of the copied template. |
   | Remarks (Optional) | Enter a description for the template. |

5. Click **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Determine">OK</UI-TERM>** to complete the template copy.

### Delete a parameter template

1. In the parameter template list, find the template you want to delete.

2. Click the **More** icon in the row where the template is located, or right-click the template.

3. In the action menu, select **Delete**.

4. In the confirmation dialog box, confirm the deletion.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>After a parameter template is deleted, it cannot be restored. Ensure that the template is no longer used by any cluster.</p>
   </main>
