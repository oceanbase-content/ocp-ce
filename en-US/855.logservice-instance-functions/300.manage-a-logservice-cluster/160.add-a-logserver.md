# Add a LogServer

This topic describes how to add a LogServer node to a LogService cluster.

<p class="relate-doc">
    <a href="../100.logservice-cluster-list.md">Logservice cluster list</a>
    <a href="../300.logservice-cluster-overview.md">Logservice cluster overview</a>
    <a href="../500.logservice-parameter-management.md">Parameter management</a>
</p>

## Prerequisites

* Ensure the current OCP user has the following permissions:
  * **Logservice Management** resource permission.
  * Permission to access the **Overview** or **Cluster List** menu for Logservice.
* Available host resources.

## Procedure

You can add a LogServer node through either of the following methods:

* **Method 1**: In the **Logservice Cluster** list, find the target cluster and click **Add LogServer** in the corresponding Actions column.
* **Method 2**: On the **Logservice Cluster** page, click the name of the target cluster to go to its overview page. Then, click **Add LogServer** in the **LogServer** list area.

The following steps use **Method 2** as an example:

1. Log in to OCP.

2. In the left navigation pane, select **Logservice Instance**.

3. In the cluster list, select the target Logservice cluster to go to its details page.

4. In the **LogServer** list area, click **Add LogServer**.

5. In the pop-up Add LogServer dialog box, configure the following information:

### Basic Information

| Parameter | Description |
| ------- | ------ |
| Affiliated Cluster | Displays the name of the log service cluster for the current operation (read-only). |

### Software Package Type

| Parameter | Description |
| ------- | ------ |
| Software package type | Select the operating system software package type, such as el7. |

### Deployment Mode

| Parameter | Description |
| ------- | ------ |
| Zone Name | Displays the zone name, such as zone1, zone2, or zone3 (read-only). |
| Region | Displays the region to which the zone belongs (read-only). |
| Instance Type (Optional) | Select the server type. |
| Host | Select the host for deploying LogServer. The drop-down list displays the available host resources. |

<main id="notice" type='notice'>
<h4>Notice</h4>
<ul>
<li>You can add multiple LogServer nodes to each zone.</li>
<li>When adding a LogServer, the system automatically configures the RPC port and HTTP port, which are 7890 and 7891 by default, respectively.</li>
</ul>
</main>

### Custom configuration

Select **Support executing cluster-level user configurations (such as the operating system owner user) and path settings (such as software installation paths and local storage paths)** as needed.

If you select this option, you can customize the following configurations:

| Parameter | Description |
| ------- | ------ |
| OS Owner User | The user to which the LogServer belongs, which is admin by default. |
| Software Installation Path | The installation directory of the LogServer software. |
| Local Storage Path | The local log storage directory of LogServer. |

6. After completing the configuration, click **<UI-TERM key="ocp-v2.Alarm.Template.New.Ok">OK</UI-TERM>**.

   The system creates an asynchronous task to perform the LogServer addition operation. You can view the task progress in **System Management > Task Management**.
