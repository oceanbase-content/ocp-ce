# Parameter Management

On the LogService cluster's parameter management page, you can view and modify various cluster parameter configurations.

## Prerequisites

Ensure the current OCP user has the following permissions:

* **Logservice Management** resource permission.
* Logservice **Parameter Management** menu permission.

## View the Parameter List

1. Log in to OCP.

2. In the left navigation bar, select **Logservice Instance**.

3. In the cluster list, click the target cluster name to go to the cluster details page.

4. In the left navigation bar, select **Parameter Management**. The system displays the parameter list page.


## Modify a Parameter Value

1. In the parameter list, find the parameter you want to modify.

2. Click the **Modify Value** button.

3. In the dialog box that appears, enter the new parameter value.

4. Click **OK** to save the modification.

<main id="notice" type='explain'>
<h4>Note</h4>
<ul>
<li>Modifying parameters may affect the cluster's runtime behavior. Proceed with caution.</li>
<li>Some parameter modifications require a service restart to take effect. The system will prompt you to perform the restart.</li>
<li>We recommend that you perform parameter changes during off-peak hours and assess the impact on your business in advance.</li>
</ul>
</main>

## Search for Parameters

You can enter a parameter name in the search box to quickly locate the target parameter.
