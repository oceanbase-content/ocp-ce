# Performance Monitoring

On the performance monitoring page of a LogService cluster, you can view various performance metrics of the cluster, including log reception, storage, GC, thread pool, and resource monitoring information, which helps you understand the cluster's running status and performance bottlenecks.

The performance monitoring page contains the following tabs:


## Prerequisites

Ensure that the current OCP user has the following permissions:

* **Logservice Read-Only** resource permission.
* Logservice **Performance Monitoring** menu permission.

## View Performance Monitoring

1. Log in to OCP.

2. In the left navigation bar, select **Logservice Instance**.

3. In the cluster list, click the target cluster name to enter the cluster details page.

4. In the left navigation bar, select **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">Performance Monitoring</UI-TERM>**.

   The system displays the performance monitoring page.

5. You can use the filter at the top of the page to select the viewing scope:

   * **Zone**: Select the zone to view. You can select all zones.
   * **LogServer**: Select the LogServer node to view. You can select all nodes.
   * **<UI-TERM key="ocp-v2.SQLDetail.DiagnosisDetail.DiagnosisCard.TimeRange">Time Range</UI-TERM>**: Select the time range to view, such as 1h, 3h, 12h, etc.

6. Click different tabs to view corresponding performance metrics, including log monitoring, performance monitoring, storage and GC, thread pool, and resource monitoring. For detailed metrics, see [AI Cluster Monitoring Metrics](../../../1900.reference-guide/300.monitoring-indicator-reference/700.ai-cluster/000.ai-cluster-metrics-overview.md).


## Time Range

The performance monitoring page displays data from the most recent period by default. You can adjust the display time range using the time selector below the refresh button at the top of the page, supporting options such as 1h, 3h, 12h, etc.

<main id="notice" type='notice'>
<h4>Note</h4>
<p>There may be some collection latency for performance metric data. If you notice abnormal data, please wait for a while and then refresh the page.</p>
</main>
