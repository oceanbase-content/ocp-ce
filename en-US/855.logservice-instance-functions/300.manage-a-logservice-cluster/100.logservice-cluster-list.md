# List of LogService clusters

On the LogService cluster list page, you can view the basic information of all LogService clusters, including the name, version number, associated OB cluster, creation time, and status.

## Prerequisites

Ensure the current OCP user has the following permissions:

* **Logservice Read-Only** resource permission.
* Logservice **Cluster List** menu permission.

## View the cluster list

1. Log in to OCP.

2. In the left navigation bar, select **Component** > **Logservice Instance**.

   The system defaults to the cluster list tab on the **Logservice Cluster** page.

3. In the cluster list, you can view the following information:

   | Information Item | Description |
   |-------|------|
   | Logservice Cluster Name | The name of the Logservice cluster. |
   | Version Number | The software version of the Logservice cluster. |
   | Associated OB Cluster | The associated OceanBase cluster. Displays "-" if not associated. |
   | Creation Time | The creation time of the Logservice cluster. |
   | Status | The running status of the Logservice cluster, including: Creating, Running, Starting, Stopping, Stopped, Restarting, Deleting, O&M, Key Rotation, Unavailable, and Deprecated. |

4. You can filter clusters by using the following methods:

   * Enter a cluster name in the search box to search.
   * Filter clusters by specific status using the drop-down list.

5. Click a cluster name to go to its details page. For more information, see [Logservice cluster overview](../300.logservice-cluster-overview.md).

## Common operations

On the cluster list page, you can perform the following operations:

* **Create a Logservice cluster**: Create a new Logservice cluster. For more information, see [Create a Logservice cluster](../200.create-a-logservice-cluster.md).
* **Add LogServer**: Add a LogServer node to a Logservice cluster. For more information, see [Add LogServer](../160.add-a-logserver.md).
* Restart or stop a cluster.
