# Logservice Cluster Overview

On the Logservice cluster overview page, you can view the basic information, zone information, and LogServer node information of the cluster.

## Prerequisites

Ensure that the current OCP user has the following permissions:

* **Logservice Read-Only** resource permission.
* Logservice **Overview** menu permission.

## View Basic Information

In the **Basic Information** section, you can view the following information:

| Information Item | Description |
| ------- | ------ |
| Name | The name of the LogService cluster. |
| Version | Software version number of the LogService cluster |
| Creation Time | Creation Time of LogService Cluster |
| Software Installation Path | Logservice software installation directory |
| Local Storage Path | Log Service Local Log Storage Directory |
| Object Storage | Configured object storage path |

## View Zone Information

In the **Zone** section, you can view the information of each zone in the Logservice cluster:

| Information Item | Description |
| ------- | ------ |
| Zone Name | The name of the zone, for example, zone1, zone2, or zone3. |
| Region | Region of the zone |
| Number of Machines | Number of Machines in This Zone |
| Software package type | Operating system software package type, such as el7. |
| CPU Architecture | CPU architecture, such as x86_64. |
| Status | Running Status of Zone |

## View LogServer Information

In the **LogServer** section, you can view the information of each LogServer node in the cluster:

| Information Item | Description |
| ------- | ------ |
| IP | IP Address of LogServer Node |
| RPC Port | RPC Communication Port |
| HTTP Port | HTTP Service Port |
| Zone | Zone of LogServer |
| Instance Type | CPU Architecture Type of the Server |
| Status | Running Status of LogServer |


## Related Operations

* Add LogServer: Add a LogServer node to the cluster. For more information, see [Add LogServer](../160.add-a-logserver.md).
* View Performance Monitoring: Go to the performance monitoring page to view cluster performance metrics. For more information, see [Logservice Performance Monitoring](../400.logservice-performance-monitoring.md).
* Manage Parameters: Go to the parameter management page to modify cluster parameter configurations. For more information, see [Logservice Parameter Management](../500.logservice-parameter-management.md).
* Download Logs: Download log files for the Logservice cluster. For more information, see [Download Logs](../../../../1300.log-service/200.download-log.md).
