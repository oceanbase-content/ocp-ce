# Create a Slack channel and obtain its webhook URL

Before sending alert messages through a Slack channel, you must obtain the webhook URL of your custom chatbot in Slack. This topic describes how to obtain the webhook URL in Slack and associate it with a Slack channel.

## Procedure

### Step 1: Create a Slack channel

1. Go to the [official Slack website](https://slack.com) or install the desktop version of Slack.

2. Click **Channel** > **Create Channel** on the left to create a Slack channel for receiving alert notifications (similar to a group chat).

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01271050.png) -->

   <!-- The page that appears after the channel is created is as follows. -->

   <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261659.png) -->

### Step 2: Add the Incoming Webhook app

1. In Slack, click **<UI-TERM key="ocp-v2.Alarm.Template.Detail.Application">Applications</UI-TERM>**, search for **Incoming Webhooks**, and go to the app.

   <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261700.png) -->

2. On the channel settings page, select the Slack channel created in **Step 1** and click **Add Incoming WebHook Integration** to associate it.

   <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261701.png) -->

### Step 3: Obtain the WebHook URL

1. After the association is successful, Incoming Webhook automatically generates a **WebHook URL**, for example: `https://hooks.slack.com/services/xxx/xxx`. As described in the "Sending Messages" section, you can choose to use any one of the alert message formats.

   <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261702.png) -->

2. Run the following script to test whether alert messages can be sent to the Slack channel.

    ```bash
    # https://hooks.slack.com/services/XXXX is the WebHook URL generated in Step 3.
    curl -X POST -H 'Content-type: application/json' \
    --data '{"text":"Hello, World!"}' \
    https://hooks.slack.com/services/XXXX
    ```

    If the test result shows `ok` and the message **Hello, World!** appears in the channel, it means the WebHook connection is normal and the Slack channel is properly associated with the WebHook.

    <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261415.png) -->
