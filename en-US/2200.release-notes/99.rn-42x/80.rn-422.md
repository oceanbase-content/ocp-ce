# OCP V4.2.2

<!--#RNDate#2024-2-21-->

## V4.2.2

OCP V4.2.2 officially supports OceanBase Database V4.2.2. It also fully implements the closed-loop management capabilities of the end-to-end tracing module of OceanBase Database, including cluster migration out of OceanBase Database and OBProxy, and takeover and migration out of arbitration services. The completeness of basic O&M capabilities has reached 95%. This version also introduces a major new feature: the monitoring dashboard, which allows users to monitor real-time performance and customize performance monitoring in large-scale promotion scenarios. In terms of backup and restore, it supports Huawei Cloud OBS, further enhancing support for storage media of major domestic cloud service providers. In addition, this version optimizes and enhances 30+ features in areas such as monitoring and alerting, task management, backup and restore, password management, and tag management. It provides 900+ product error codes, significantly improving the ease of use and stability of the product. This version aims to create a more user-friendly and efficient full-lifecycle database management platform, helping users better manage OceanBase Database.

### New features

#### OceanBase V4.x compatibility

* Added monitoring metric: Maximum tenant-level log synchronization delay. For more information, see [clog synchronization delay
](https://www.oceanbase.com/docs/common-ocp-1000000000585563).
* Added support for OceanBase read-only parameter configurations (EDIT_LEVEL='READONLY').
* Added support for network primary-standby replication roles in Oracle tenant mode of OceanBase Database.
* Added support for GIS data types in Oracle tenant mode of OceanBase Database.
* Added support for granting PL privileges to users with global privileges in MySQL mode of OceanBase Database.

#### Dashboard

The dashboard provides a comprehensive view of database performance and operational status, supporting scenarios such as monitoring during major events like Double 11. It allows users to compare monitoring data across multiple instances and metrics, link charts, and display data in seven types of charts, including pie charts, tables, and bar charts. For more information, see [Dashboard](https://www.oceanbase.com/docs/common-ocp-1000000000584639).

#### Tag management

OCP tags support organization, categorization, quick search and filtering, task and project management, team collaboration, and sharing. This provides a flexible and efficient way to organize, search, and manage various database objects, enhancing team collaboration. For more information, see [Manage tags](https://www.oceanbase.com/docs/common-ocp-1000000000585054).

### Key features

#### Monitoring Dashboard

The monitoring dashboard meets the needs of users in scenarios such as "monitoring" during Double 11 and allows users to create custom monitoring views. On the monitoring dashboard tab, you can create multiple monitoring dashboard pages. On each monitoring dashboard page, you can add multiple charts to display different metrics and data, such as multi-instance and multi-metric monitoring views, and monitoring metrics for single or multiple clusters. The monitoring dashboard also provides four monitoring comparison modes: year-on-year, day-on-day, week-on-week, and month-on-month, helping you easily detect data anomalies. You can also choose from seven different chart types, such as line charts, pie charts, and tables, based on the characteristics and requirements of your data to better understand and analyze the data. Additionally, the monitoring dashboard provides grouping functionality, allowing you to organize related metrics into the same group for unified management, making it easier to monitor and analyze database status. The monitoring dashboard supports features such as chart dragging, chart zooming, drilling down (in single-metric scenarios), and chart linkage, helping you achieve the goal of monitoring the overall performance and operation status of the database system.

#### Tag Management

OCP supports tagging operations for five object types: OceanBase clusters, arbitration services, tenants, OBProxy clusters, and hosts. It also supports management features such as creating, editing, deleting, and modifying associated objects. You can choose from two different styles to display tags based on your business needs. On various object type pages, such as the OceanBase cluster page, you can tag clusters to assign business meanings to objects, such as system type and manager. You can also use the tag filtering feature to organize, search, and manage cluster objects, improving your work efficiency.

### Fixed issues

OCP V4.2.2 fixes the following issues:

* Fixed the issue where OceanBase Database V4.2 failed to upgrade due to the `EnableRebalance` parameter setting.
* Fixed the issue where the `obproxyd.sh` script failed to start after the server was restarted.
* Fixed the issue where the startup items did not take effect on Kylin V10 systems.
* Fixed the issue where the resource display ratio of the log disk was abnormal.
* Optimized the monitoring query logic to reduce the probability of garbage collection.
* Optimized the access performance of multiple frontend pages, making the access speed faster under the same management scale.

### Limitations

#### Hardware requirements

OCP-Server can be installed on physical servers or in Docker containers. OCP-Server supports multi-node high-availability deployment.

The minimum hardware requirements for OCP-Server nodes are as follows:

| Hardware | Requirements                 |
|-------|------------------------------------|
| CPU  | <li>X86_64, 8-core</li><li>ARM aarch 64 architecture, 8-core</li> |
| Memory | 16 GB available memory             |
| NIC | 10 GbE NIC                |

OCP-Agent consumes very few resources and has no special hardware requirements for the installation node.

#### Operating system requirements

The operating system requirements for installing OCP-Server (including OCP-Agent) are as follows:

| Server type    | Operating system    | Supported versions   |
|-------------|------------|-----------|
| x86_64   | RHEL    | 7.2 and later |
| x86_64   | CentOS   | 7.2 and later |
| x86_64   | AliOS   | 7.2 and later |
| x86_64   | openSUSE  | 12SP3 and later |
| ARM aarch64 | AliOS   | 7.2 and later |
| ARM aarch64 | NeoKylin    | 7.6    |
| ARM aarch64 | Huawei EulerOS | 2.0 SP8  |
| x86_64 | Debian    | Debian GNU/Linux 11 (bullseye)  |
| x86_64 | Ubuntu | Ubuntu 18.04.6 LTS |

#### Client requirements

General users access OCP services through web browsers, so the client requirements are as follows:

| Browser   | Minimum version |
|---------|------|
| Chrome | 88  |
| Firefox | 78  |
| Safari | 14  |
| Edge  | 88  |

If you need to access OCP services on iOS devices, the minimum operating system version is as follows:

| Operating system | Minimum version |
|------|------|
| iOS | 10  |

For the best user experience, we recommend using a display with a resolution greater than 1440 x 810.
