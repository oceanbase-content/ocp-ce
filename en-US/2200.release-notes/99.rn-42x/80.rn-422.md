# OCP V4.2.2

<!--#RNDate#2024-2-21-->

## V4.2.2

OCP V4.2.2 officially supports OceanBase Database V4.2.2 and fully implements the closed-loop management capabilities of the OceanBase full-link tracing module. This includes features such as cluster migration out of OceanBase and OBProxy, as well as takeover and migration out of arbitration services. The completeness of basic O&M features has reached 95%. This version also introduces a powerful feature: the monitoring dashboard, which allows users to monitor in real-time during peak business scenarios and customize performance monitoring. In terms of backup and restore, support for Huawei Cloud OBS has been added, further enhancing support for mainstream cloud storage media in China. Additionally, this version includes over 30 optimizations and enhancements across areas such as monitoring and alerts, task management, backup and restore, password management, and tag management. It provides over 900 product error codes, significantly improving product usability and stability. This version aims to build a more user-friendly and easy-to-use full lifecycle database management platform, helping users better manage OceanBase Database.

### New features

#### OceanBase V4.x compatibility

* Added monitoring metric: maximum log synchronization delay at the tenant level. For more information, see [Log synchronization delay
](https://www.oceanbase.com/docs/common-ocp-1000000000585563).
* Added compatibility with OceanBase read-only parameter configurations (EDIT_LEVEL='READONLY').
* Added compatibility with the network primary-standby replication role for Oracle tenants in OceanBase Database.
* Added compatibility with GIS data types in Oracle tenants in OceanBase Database.
* Added compatibility with the PL permission for global users in MySQL tenants in OceanBase Database.

#### Dashboard

The dashboard meets the needs of users in scenarios such as monitoring during major events like Double 11 and allows users to create custom monitoring views. It provides features such as multi-instance and multi-metric monitoring view comparisons, chart interactivity, and support for seven chart types, including pie charts, tables, and bar charts. This helps users monitor the overall performance and operation status of the database system. For more information, see [Dashboard](https://www.oceanbase.com/docs/common-ocp-1000000000584639).

#### Tag management

OCP tags offer organization, classification, quick search and filtering, task and project management, team collaboration, and sharing features. They provide a flexible and efficient way for users to organize, search, and manage various database objects, enhancing team collaboration. For more information, see [Manage tags](https://www.oceanbase.com/docs/common-ocp-1000000000585054).

### Key feature explanations

#### Monitoring Dashboard

The monitoring dashboard is designed to meet the needs of users who need to monitor their systems during peak times, such as during major events like Double 11, and those who want to customize their monitoring views. On the monitoring dashboard tab, you can create multiple monitoring dashboard pages. Each dashboard page can include multiple charts to display different metrics and data, such as monitoring multiple instances and metrics, or different metrics across single or multiple clusters. The dashboard also provides four comparison modes: year-over-year, month-over-month, week-over-week, and day-over-day, to help you easily identify data anomalies. You can also choose from seven different chart types, such as line charts, pie charts, and tables, based on your data's characteristics and requirements, to better understand and analyze your data. Additionally, the dashboard supports grouping related metrics for unified management, making it easier to monitor and analyze database performance. The dashboard also offers features like chart dragging, zooming, drilling down (in single-metric scenarios), and chart linking to help you achieve your goals of monitoring the overall performance and operational status of your database system.

#### Tag Management

OCP allows you to apply tags to five types of objects: OceanBase clusters, arbitration services, tenants, OBProxy clusters, and hosts. You can also create, edit, delete, and modify associated objects. With two different tag styles, you can choose the most suitable display format based on your business needs. On various object management pages, such as the OceanBase cluster management page, you can apply tags to assign business meanings to objects, such as system type or manager. The tag filtering feature helps you organize, search, and manage cluster objects, improving your work efficiency.

### Fixed issues

OCP V4.2.2 fixes the following issues:

* Fixed the issue where OceanBase Database V4.2 failed to upgrade due to the `EnableRebalance` parameter setting.
* Fixed the issue where `obproxyd.sh` failed to start after a server restart.
* Fixed the issue where startup items did not take effect on Kylin V10.
* Fixed the issue where the resource display ratio on the log disk was abnormal.
* Optimized the monitoring query logic to reduce the occurrence of garbage collection.
* Optimized the access performance of multiple frontend pages, making the access speed faster under the same management scale.

### Limitations

#### Hardware requirements

OCP-Server can be installed on a physical server or in a Docker container. OCP-Server supports multi-node high availability deployment.

The following table lists the minimum hardware requirements for OCP-Server nodes.

| Hardware | Requirement                 |
|-------|------------------------------------|
| CPU  | <li>X86_64, 8 cores</li><li>ARM aarch 64 architecture, 8 cores</li> |
| Memory | 16 GB available memory             |
| NIC | 10 GbE NIC                |

OCP-Agent consumes very few resources and has no special hardware requirements for the installation node.
