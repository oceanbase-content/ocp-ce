# Version number rules

This topic describes the version number rules of OCP and their meanings.

As OCP is continuously iterated and optimized, new versions of OCP are released at irregular intervals. Different versions of OCP may have significant differences in features and capabilities. Therefore, it is essential to identify the OCP version number to obtain accurate documentation information.

The version number format of OCP is V.x.y.z-t, where:

* x represents the major version. This version typically involves architectural upgrades or the release of significant new features.

* y represents the planned iteration version. This version follows a regular iteration plan and includes updates and enhancements to important features and capabilities.

* z represents the release update version. This version includes minor feature or capability updates and fixes for known issues.

* t is usually displayed as a date and time string, such as 4.3.2-20241011163611 or 4.3.5-20250610150154. This is used for scenarios where a higher version number is required due to feature updates or bug fixes.

## View the version number

After you deploy OCP, you can view the current OCP version number by performing the following steps:

1. Log in to the OCP console.

2. Hover the pointer over **Help** in the upper-right corner and click **About OCP**.

3. In the dialog box that appears, view the current OCP version number. For example, the version number is 4.3.2-20241011163611.
