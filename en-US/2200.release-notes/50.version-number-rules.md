# Version number rules

This topic describes the version number rules of OCP and their meanings.

OCP is iterated and optimized continuously and new versions are released irregularly. The features and functions of different OCP versions may vary significantly. Therefore, you must identify the OCP version number to obtain accurate documentation.

The version number of OCP is in the V.x.y.z-t format, where:

* x indicates the major version. This version usually involves architecture upgrades or the release of major new features.

* y indicates the planned iteration version. This version is part of the normal iteration plan and includes updates and enhancements to important features or functions.

* z indicates the release update version. This version includes minor feature or function updates and fixes to known issues.

* t is usually a date and time string when the version is released. For example, 4.3.2-20241011163611 or 4.3.5-20250610150154. This version is released for scenarios that require feature updates or fixes to known issues.

## View the version number

After you deploy OCP, you can view the version number of OCP by performing the following steps:

1. Log in to the OCP console.

2. Hover the pointer over **Help** in the upper-right corner and click **About OCP**.

3. In the dialog box that appears, view the version number of OCP. For example, the version number is 4.3.2-20241011163611.
