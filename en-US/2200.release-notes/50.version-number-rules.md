# Version number guidelines

This topic describes the version number guidelines and their meanings for OCP.

As OCP continues to evolve and improve, new versions are released periodically. These versions can differ significantly in features and capabilities, so it's essential to identify the OCP version to obtain the correct documentation.

The OCP version format is represented as V.x.y.z-t, where:

* x indicates the major version. This version typically involves architectural upgrades or significant new features.

* y indicates a planned iteration version. This version follows the regular iteration plan and includes important feature or capability updates and enhancements.

* z indicates an update release version. This version contains minor feature or capability updates and fixes for known issues.

* t is usually a string representing the release date and time, such as 4.3.2-20241011163611 or 4.3.5-20250610150154, used when a higher version number is required for feature updates or bug fixes.

## View the version number

After deploying OCP, you can view the current OCP version number by following these steps:

1. Log in to OCP.

2. Hover the cursor over **Help** in the upper-right corner and click **About OCP**.

3. In the dialog box that appears, view the current OCP version number. For example, the version number might be 4.3.2-20241011163611.
