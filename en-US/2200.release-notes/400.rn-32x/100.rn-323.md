# OCP V3.2.3

#RNDate#2021-12-27

OceanBase Cloud Platform V3.2.3 introduces a new feature for visual log querying and parameter template management. Additionally, the platform undergoes significant updates in monitoring and alerting capabilities. The new performance monitoring feature includes drill-down analysis and detailed metrics for comprehensive business analysis. SQL diagnostics now support SQL throttling settings, plan binding, and query binding history tracking. Performance reports now include statistical information on PRC, memory, and parameter configuration changes. The alerting feature in this version supports multiple thresholds and includes 10 new built-in alerts to enhance OCP's operational capabilities for OceanBase clusters.

## Version information

* **Version number:** V3.2.3

* **Previous version:** V3.1.5

* **Date of release:** 2021 December 27

* **Supported upgrade path:** You can directly upgrade OCP V2.3.x or later versions to this version. If the source version is earlier than V2.3.0, you must first upgrade to V2.3.x and then upgrade to this version.

## Supported OceanBase Database versions

OceanBase Cloud V3.2.3 supports the following OceanBase Database versions:

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

## New Features

* The **<UI-TERM key="ocp-v2.Monitor.AddMonitor.PerformanceMonitoring">Performance Monitoring</UI-TERM>** feature supports drill-down analysis for metrics.

  You can drill down the metric in the tenant node or observer node dimensions to view metric data without switching to the **<UI-TERM key="ocp-v2.page.Monitor.Monitoring">Performance Monitoring</UI-TERM>** tab on the tenant details page or to the **<UI-TERM key="ocp-v2.Host.Detail.Surveillance">Monitoring</UI-TERM>** tab on the host details page.

* New log query feature: You can set query conditions on the OCP console to query logs of various types, including those of the OBServer nodes, OBProxy, and host. You do not need to download the logs.

* The SQL diagnosis feature supports binding indices, plan binding, SQL throttling, and querying binding history for SQL statements on their detail pages.

* New built-in alert items are added, providing comprehensive monitoring and early warning capabilities for metrics such as the number of active sessions, CLog synchronization delay, and cross-cloud management in OceanBase Cloud. Alerts support multiple threshold settings, enhancing the performance and stability of OceanBase clusters.

* The parameter template feature is now available. If you need to create multiple tenants or clusters with the same configurations, you can first create a parameter template and then apply it when you choose **<UI-TERM key="ocp-v2.Detail.Tenant.NewTenant">Create Tenant</UI-TERM>** or **<UI-TERM key="ocp-v2.page.Cluster.CreateANewCluster">Create Cluster</UI-TERM>**. This will avoid the need to reconfigure the parameters of the clusters or tenants each time you choose **<UI-TERM key="ocp-v2.Tenant.New.CreateACluster">Create Cluster</UI-TERM>** or **<UI-TERM key="ocp-v2.Cluster.Detail.NewTenant">Create Tenant</UI-TERM>**.

  * For information about how to create a template, see [Cluster parameter templates](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377800).

  * To create a cluster or tenant, see [Create a cluster](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000378283) or [Create a tenant](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377507).

## Feature enhancements

* Enhanced the performance monitoring feature. It further refines metrics to help you view more detailed performance information about the clusters and tenants. The following metrics are available:

  * Cluster: **QPS** , **Query response time** , **TPS** , **Transaction response time** .

  * Tenant: **request wait queue** , **TPS** , **transaction response time** .

* Optimized the logic for upgrading and restarting an OBServer node to support scheduled maintenance upgrades and restarts. This change allows you to upgrade and restart OBServer nodes without service continuity requirements.

* Enhanced the **<UI-TERM key="ocp-v2.Detail.Report.PerformanceReport">Performance Report</UI-TERM>** feature of the cluster, supporting the display of statistics including **<UI-TERM key="ocp-v2.src.component.DeleteUnitSpecModal.Memory">Memory</UI-TERM>**, **RPC**, and **<UI-TERM key="ocp-performance-report.pages.AWR.ParameterConfigurationChanges">Parameter Changes</UI-TERM>**.

## Fixed Issues

The following issues were fixed in OceanBase Cloud V3.2.3:

* Incomplete SQL diagnostics collection and slow frontend loading.

* Some data was missing from performance reports.

* Retry and abandon tasks that fail.

## Limitations

### Hardware requirements

OCP-Server can be installed on a physical server or in a Docker container. OCP-Server supports multi-node high availability deployment.

The following table lists the minimum hardware requirements for OCP-Server nodes.

| Hardware  |                 Requirements                 |
|-----|------------------------------------|
| CPU | <li>X86_64, 8 cores</li><li>ARM aarch 64 architecture, 8 cores</li> |
| Memory  | 16 GB available memory                         |
| NIC  | 10 GbE NIC                               |

OCP-Agent consumes very few resources and does not have special requirements for the hardware resources of the installation node.

### Operating system requirements

The following table lists the operating system requirements for installing OCP-Server (including OCP-Agent).
