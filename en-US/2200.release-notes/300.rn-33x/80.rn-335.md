# OCP V3.3.5

#RNDate#2023-07-25

## V3.3.5 BP2

### Version information

* **Version:** V3.3.5 BP2

* **Previous version:** V3.3.5 BP1

* **Version release date:** November 29, 2023

### Bug fixes

* Reduced the switchover time.

* Fixed the issue where an unexpected number of threads were generated when managing a large number of tenants.

* Fixed the issue where only the data of the last hour could be viewed in the monitoring data.

* Fixed the issue where the downgrade of SQL collection memory limit was not effective.

## V3.3.5 BP1

### Version information

* **Version:** V3.3.5 BP1

* **Previous version:** V3.3.5

* **Version release date:** August 3, 2023

### Bug fixes

* Fixed the issue where the CPU usage of a tenant was calculated incorrectly.

* Fixed the issue where the email information of OCP users may conflict.

## V3.3.5

OceanBase Cloud Platform (OCP) V3.3.5 introduces new audit events and optimizes other features.

### Version information

* **Version:** V3.3.5

* **Previous version:** V3.3.4

* **Version release date:** July 25, 2023

* **Supported upgrade path:** OCP V2.3.x and later can be directly upgraded to this version. OCP V2.3.0 and earlier must be upgraded to V2.3.x before being upgraded to this version.

### Supported OceanBase Database versions

OCP V3.3.5 supports the following versions of OceanBase Database:

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

### New features

* Added the **<UI-TERM key="ocp-v2.page.Overview.Content.ThreadUsage">Thread Usage</UI-TERM>** metric at the tenant level for easier issue diagnosis.

* Optimized the calculation logic of the **CPU Consumption** metric at the tenant level to provide a more accurate resource consumption ratio.

### Fixed issues

OCP V3.3.5 fixes the following issues:

1. Fixed the issue where an error occurred on the diagnostic page when upgrading from V3.3.4-BP1 to a higher V3.x version.

2. Fixed other issues during the upgrade of the V3.3.x-BP series.

3. Optimized the package download logic to better support concurrent upgrades across multiple hosts.

4. Optimized the data management logic to automatically clean up historical task data older than 30 days, reducing storage space usage.

### Known issues

None.

### Version limitations

#### Hardware requirements

OCP-Server can be installed on a physical server or in a Docker container. OCP-Server supports multi-node high-availability deployment.

The minimum hardware requirements for OCP-Server nodes are as follows:

| Hardware | Requirements |
|-------|------------------------------------|
| CPU   | <li>X86 X64 architecture with 8 cores</li><li>ARM aarch 64 architecture with 8 cores</li> |
| Memory  | 16 GB of available memory |
| Network card | 10 GbE network card |

OCP-Agent consumes minimal resources and has no special hardware requirements.

#### Operating system requirements

The operating system requirements for installing OCP Server (including OCP-Agent) are as follows:

|    Server type    |    Operating system    |   Supported versions    |
|-------------|------------|-----------|
| x86_64      | RHEL       | 7.2 and later |
| x86_64      | CentOS     | 7.2 and later |
| x86_64      | AliOS      | 7.2 and later |
| x86_64      | openSUSE   | 12SP3 and later |
| ARM aarch64 | AliOS      | 7.2 and later |
| ARM aarch64 | NeoKylin       | 7.6       |
| ARM aarch64 | Huawei EulerOS | 2.0 SP8   |

#### Client requirements

General users access OCP through a web browser, so the client requirements are as follows:

| Browser     | Minimum version |
|---------|------|
| Chrome  | 81   |
| Firefox | 64   |
| Safari  | 10   |
| Edge    | 13   |

If you need to access OCP from an iOS device, the minimum operating system version is as follows:

| Operating system | Minimum version |
|------|------|
| iOS  | 10   |

For the best user experience, we recommend using a display with a resolution greater than 1440 x 810.
