# OCP V3.3.4

#RNDate#2022-10-21

OceanBase Cloud Platform (OCP) introduces new audit events and enhances existing features in this release.

## Version information

* **Version number**: V3.3.4

* **Previous version**: V3.3.3

* **Version release date**: October 21, 2022

* **Supported upgrade path**: OCP V2.3.x and later can be directly upgraded to this version. For versions earlier than OCP V2.3.0, you must first upgrade to OCP V2.3.x and then upgrade to this version.

## Supported OceanBase Database versions

OCP V3.3.4 supports the following versions of OceanBase Database:

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

## Feature enhancements

* In operation audit: Added audit events, including stopping a zone, starting a zone, restarting a zone, modifying the dead lock detection switch, deleting a software package, modifying the OceanBase cluster's TopSQL switch, triggering OceanBase cluster compaction, clearing the failed state of OceanBase cluster compaction, and tenant unit maintenance (scale-in/scale-out).

* In diagnostics, **<UI-TERM key="ocp-v2.page.Overview.SuspiciousSql">Suspicious SQL</UI-TERM>** increases a new judgment mode, which lists **<UI-TERM key="ocp-v2.page.Diagnosis.SuspiciousSql">Suspicious SQL</UI-TERM>** when the PARTITION_CNT is greater than AffectRows.

* Optimized the secondary backup creation process, changing the success flag from **"add standby command success"** to **"snapshot access complete"**.

* Optimized the test alert feature, adding default values to environment variables to improve test alert success rates.

* Optimized the secondary backup path pre-check logic, prohibiting the backup path from containing directories with the same cluster name.

## Fixed issues

OCP V3.3.4 fixes the following issues:

1. Fixed the error in the unit of the system variable `connect_timeout` **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.Seconds">Seconds</UI-TERM>** mistakenly written as **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.Microseconds">Microseconds</UI-TERM>**.

2. Fixed the issue where OCP fails to start when the traffic control is disabled.

3. Fixed the errors in the host IP description and tenant list description for a specific alert message.

4. Fixed the issue where some parameters that cannot be modified are displayed as modifiable in the frontend.

5. Optimized the performance of AWR report generation to reduce the frequency of report generation timeouts when the number of tenants exceeds 100.

6. Optimized the internal table query statements to avoid abnormal cluster status display caused by business pressure.

7. Optimized the fault tolerance of host maintenance operations.

8. Optimized the Grafana monitoring push logic to avoid situations with no data.

9. Optimized the NTP delay collection method for hosts to improve accuracy under high load.

## Version limitations

### Hardware requirements

OCP-Server can be installed on a physical host or in a Docker container. OCP-Server supports multi-node high availability deployments.

The minimum hardware requirements for OCP-Server nodes are as follows:

| Hardware  | Requirements                                 |
|-----|------------------------------------|
| CPU | <li>X86_64 with 8 cores</li><li>ARM aarch 64 architecture with 8 cores</li> |
| Memory  | 16 GB of available memory                         |
| Network card  | 10 GbE network card                               |

OCP-Agent consumes minimal resources and does not have specific hardware requirements.

### Operating system requirements

The operating system requirements for installing the OCP server (including OCP-Agent) are as follows:

|    Server type    |    Operating system    |   Supported versions    |
|-------------|------------|-----------|
| x86_64      | RHEL       | 7.2 or later |
| x86_64      | CentOS     | 7.2 or later |
| x86_64      | AliOS      | 7.2 or later |
| x86_64      | openSUSE   | 12 SP3 or later |
| ARM aarch64 | AliOS      | 7.2 or later |
| ARM aarch64 | NeoKylin       | 7.6       |
| ARM aarch64 | Huawei EulerOS | 2.0 SP8   |
