# Prepare installation media

This topic describes the installation media list for OCP. OCP-Server can be installed using Docker images or RPM packages. We recommend that you install it using Docker images.

Before you install OCP, contact technical engineers of OceanBase to obtain the following installation packages.

| Used to deploy OCP components | Description |
| ----------------------- | --------- |
| OAT RPM Package | OceanBase Admin Toolkit (OAT) is a tool for automating the deployment of OceanBase ecosystem products.  <blockquote>**<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.Description">Note</UI-TERM>**</br>The OAT version must be V4.0.0 or later.</blockquote> |
| OCP docker image | Before installation, obtain the OCP Docker image. |
| OBServer docker image | Used to deploy OCP MetaDB and MonitorDB. |
