# Host resources

This topic describes the resource requirements for deploying OCP. It is intended for quick start. To deploy OCP in test and production environments, refer to [Deploy a database](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004475420).

In Enterprise Edition OCP deployment, Docker containerization is typically used; Community Edition OCP is deployed as RPM packages. Both versions can deploy OCP-Server, MetaDB, and MonitorDB on the same physical host. MetaDB and MonitorDB can be configured as different tenants within the same OceanBase cluster.

The total host resource requirement is calculated as follows:

**Total host resources** = **OCP-Server resources** + **MetaDB tenant resources** + **MonitorDB tenant resources** + **SYS tenant resources** + **System_Memory resources** + **Operating system kernel reserve** (20% of total resources, recommended to be configured based on the actual host resources).

## Hardware requirements

The minimum hardware requirements for an OCP-Server node are shown in the following table.

| **Hardware** | **Minimum requirements** |
| -------- | -------- |
| CPU | <ul><li>Single-node OCP:<ul><li>x86_64, 8-core</li><li>ARM AArch64 architecture, 8-core</li></ul></li><li>High-availability OCP:<ul><li>x86_64, 24-core</li><li>ARM AArch64 architecture, 24-core</li></ul></li></li></ul> |
| Memory | Available Memory: 64 GiB |
| NIC | 10 Gbit/s NIC |

## Example

Using the resources required to manage 10 business OBServer nodes as an example, the required resources are as follows:

| Container Classification | Deployment Content | CPU (Cores) | Memory (GiB) |
| ------------ | ------------------ | -------- | -------- |
| OCP Container | OCP-Server | 8 | 16 |
| OceanBase Container | MetaDB Tenant | 4 | 8 |
| OceanBase Container | MonitorDB Tenant | 4 | 16 |
| OceanBase Container | SYS Tenant | 5 | 28 |
| OceanBase Container | System_Memory | 0 | 0 |

<main id="notice" type='explain'>
<h4>Note</h4>
<p><li>The default memory capacity for System_Memory is 0, indicating the system will automatically adjust the memory usage strategy based on the memory situation. For details, refer to <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002015843">system_memory</a>.</li>
<li>The resources required by the host are the cumulative value of all resources in the <strong>Deployment content</strong> column. If the above content is deployed on a 32C 192GiB physical machine, this physical machine needs to be isolated into two containers to run OCP-Server and the OceanBase cluster that depends on OCP (MetaDB tenant, MonitorDB tenant, and SYS tenant).</li></p>
</main>
