# MetaDB Resources

This topic describes the MetaDB resources required for deploying OCP.

## CPU and Memory

MetaDB is used to store system metadata, uploaded RPM package files, and more. We recommend that you create a dedicated tenant in OceanBase Database for MetaDB.

| **Number of managed hosts** | **CPU (Cores)** | **Memory (GiB)** |
|---------------|--------------|-------------|
| ≤ 10          | 2            | 4           |
| ≤ 50          | 4            | 8           |
| ≤ 200         | 4            | 8           |
| ≤ 500         | 8            | 16          |
| ≤ 1000        | 8            | 16          |

## Disk Capacity

Disk capacity is affected by factors such as the cluster scale managed by OCP, the file resources stored, and the data retention period. Generally, we recommend that you have more than 100 GiB of disk space. If disk resources are insufficient, contact technical support.
