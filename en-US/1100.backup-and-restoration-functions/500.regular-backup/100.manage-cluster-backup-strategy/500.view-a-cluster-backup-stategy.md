# View the cluster-level backup strategy

This topic describes how to view the detailed configuration of the cluster-level backup strategy.

## Prerequisites

Ensure that the current OCP user has the following permissions:

* The **Cluster Read-Only** resource permission.
* The cluster **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">Backup & Restore</UI-TERM>** menu permission.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.Cluster">Cluster</UI-TERM>** to go to the clusters page.

3. In the **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">Clusters</UI-TERM>** list, click the target cluster. The cluster **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page appears by default.

4. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">Backup & Restore</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">Backup & Restore</UI-TERM>** page for that cluster.

5. Click the **<UI-TERM key="ocp-v2.Detail.Backup.BackupStrategy">Backup Strategy</UI-TERM>** tab to view the cluster-level backup strategy information and tenant-level backup strategy information for that cluster.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>In the storage configuration of the cluster-level backup strategy, the data backup storage path and log backup storage path are displayed (separate configuration of the log backup storage path is supported only in OceanBase Database V4.0 and later). If no tenant-level backup strategy is configured for a tenant, the <strong>Tenant-Level Backup Strategy</strong> section is not displayed.</p>
    </main>
