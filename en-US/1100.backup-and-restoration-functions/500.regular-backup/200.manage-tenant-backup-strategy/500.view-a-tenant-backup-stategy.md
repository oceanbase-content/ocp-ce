# View tenant-level backup strategies

This topic describes how to view the detailed configuration of a tenant-level backup strategy.

## Prerequisites

* Ensure the current OCP user has the following permissions:

  * **Cluster Read-Only** or **Tenant Read-Only** resource permission.
  * Permission to access the **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">Backup</UI-TERM>** menu for the tenant.

* A backup strategy has been created for the tenant.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Tenant">Tenant</UI-TERM>** to go to the Tenants page.

3. On the **<UI-TERM key="ocp-v2.page.Tenant.TenantList">Tenants</UI-TERM>** page, click the target tenant. The **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page for that tenant appears by default.

4. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">Backup & Restore</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">Backup & Restore</UI-TERM>** page for that tenant.

3. Click the **<UI-TERM key="ocp-v2.Detail.Backup.BackupStrategy">Backup Strategy</UI-TERM>** tab to view the backup strategy details.

    <main id="notice" type='explain'>
    <h4>Note</h4>
    <p>The backup strategy details page displays the data backup storage path and log backup storage path (separate configuration of the log backup storage path is supported only in OceanBase Database V4.0 and later).</p>
    </main>
