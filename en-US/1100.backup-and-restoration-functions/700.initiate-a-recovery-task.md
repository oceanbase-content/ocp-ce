# Initiate recovery

You can refer to this page to initiate recovery for a backed-up cluster.

You can initiate recovery through the following three entry points:

* **Entry point 1**: Log in to OCP, go to **Backup and Recovery > Restore**, and click **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.InitiateRecovery">Initiate Restore</UI-TERM>**.

* **Entry point 2**: Log in to OCP, go to the cluster **<UI-TERM key="ocp-v2.Detail.Overview.Overview">Overview</UI-TERM>** page, select **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">Backup & Restore</UI-TERM>** from the left navigation pane, and on the cluster's **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">Backup & Restore</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Backup.Restore.RestoreNow.InitiateRecovery">Initiate Restore</UI-TERM>**.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>Recovery for the cluster cannot be initiated via Entry Point 2 if any of the following conditions apply:<ul><li>The cluster status is not "Running".</li><li>The cluster has no backup strategy.</li></ul></p>
   </main>

* **Entry point 3**: Log in to OCP, go to the tenant **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">Overview</UI-TERM>** page, select **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">Backup & Restore</UI-TERM>** from the left navigation pane, and on the tenant's **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">Backup & Restore</UI-TERM>** page, click **<UI-TERM key="ocp-v2.Backup.Restore.RestoreNow.InitiateRecovery">Initiate Restore</UI-TERM>**.

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>Recovery for the tenant cannot be initiated via Entry Point 3 if any of the following conditions apply:<ul><li>The tenant status is not "Running".</li><li>The tenant has no backup strategy.</li></ul></p>
   </main>

## Prerequisites

* When initiating restore via **Entry 1**, ensure the current OCP user has the following permissions:

  * **Cluster Maintenance** or **Tenant Maintenance** resource permissions.
  * **Backup and Restore** > **Restore** menu permission.

* When initiating restore via **Entry 2**, ensure the current OCP user has the following permissions:

  * **Cluster Maintenance** resource permissions.
  * **Cluster** > **Backup and Restore** menu permission.

* When initiating restore via **Entry 3**, ensure the current OCP user has the following permissions:

  * **Cluster Maintenance** or **Tenant Maintenance** resource permissions.
  * Tenant **Backup and Restore** menu permission.

* The content to be restored has undergone [Immediate Backup](400.backup-now/100.back-up-cluster-now.md).

* For an OceanBase cluster that has undergone physical backup, restoring from a higher version to a lower version is not supported when initiating backup and restore.

## Procedure

The following steps use **Entry 1** as an example.

1. Log in to OCP.

2. In the left navigation bar, click **Backup and Recovery > Restore**.

3. On the **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.Recovery">Restore</UI-TERM>** page, click **<UI-TERM key="ocp-v2.src.constant.backup.InitiateRecovery">Initiate Restore</UI-TERM>** in the upper-right corner.

4. (Optional) When initiating a restore on the global page, you need to specify storage configurations. You can customize one or select an existing configuration. When customizing, refer to the parameters below; when selecting an existing configuration, click **<UI-TERM key="ocp-v2.Backup.Component.StorageConfigDropdown.SelectAnExistingConfiguration">Select Existing Configuration</UI-TERM>** and the parameters will be automatically populated.

   <p>When a native OSS storage type is available, it is recommended to prefer the OSS method for configuration.</p>
   </main>

5. (Optional) Specify the log backup path. When OceanBase Database is V4.0 or later, you can specify an independent storage path for log backups, allowing data backups and log backups to use different storage directories. If not specified, the default data backup storage path is used.

6. Enter the information in the **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.RestoreSourceInformation">Restore Source Information</UI-TERM>** section.

   <main id="notice" type='explain'>
   <h4>Note</h4>

      </main>
