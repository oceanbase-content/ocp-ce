# Delete object storage configuration

This topic describes how to delete an unused object storage configuration.

## Prerequisites

* You have created an object storage configuration.
* The object storage configuration to be deleted is not referenced by any AI cluster or log service cluster.

## Procedure

1. After logging in to OCP, select the icon **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">Administration</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>** from the left navigation bar to go to the External Integration page.

2. On the External Integration page, click the **Object Storage** tab.

3. Find the object storage configuration you want to delete and confirm that it is not referenced by any cluster.

   <main id="notice" type='notice'>
   <h4>Notice</h4>
   <p>If the object storage configuration is being used by an AI cluster, the deletion operation will be prohibited. Please modify the cluster's configuration to remove the reference before deleting it.</p>
   </main>

4. Click the **<UI-TERM key="ocp-v2.Settings.Credential.Host.Delete">Delete</UI-TERM>** button in the Actions column. A confirmation dialog box appears.

5. In the confirmation dialog box, verify the name of the object storage configuration to be deleted. If correct, click the **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchoverModal.Determine">OK</UI-TERM>** button.

   The object storage configuration has been successfully deleted.

## Situations where deletion fails

If an object storage configuration is being referenced by an AI cluster, the deletion operation will be blocked and the system will display an error message.

### Procedure

1. **Find the referencing cluster**: On the object storage configuration details page, view the list of associated clusters.

2. **Modify the cluster configuration**: Go to the details page of the referenced AI cluster and change its data storage path to another configuration.

3. **Retry the deletion**: After confirming no cluster is referencing it, re-execute the deletion operation.

<main id="notice" type='notice'>
<h4>Note</h4>
<p>Deleteing an object storage configuration only removes the configuration record in OCP; it does not delete the actual data on the object storage service. Deleted AccessKeys and SecretKeys may still be used by the kernel for a period of time. Therefore, even after deletion on this page, it is recommended to retain the AccessKeys and SecretKeys in the object storage management platform for at least 1 hour.</p>
</main>
