# Manage Prometheus data sources

This topic describes how to manage Prometheus data sources.

## Enable/Disable a Prometheus data source

After a Prometheus data source is created, it must be manually enabled before it can be used. You can refer to this section to enable or disable a Prometheus data source. After a Prometheus data source is disabled, monitoring data will be written only to MonitorDB.

### Prerequisites

* Ensure the current user logged in to OCP has the **ADMIN** role.
* Before enabling a Prometheus data source, make sure you have modified the `prometheus.yaml` configuration file and restarted the Prometheus service as described in [Create a Prometheus data source](200.create-prometheus-data-source.md).

### Procedure

1. Log in to OCP.

2. Click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>** in the left navigation pane.

3. Click the **Prometheus** tab.

4. On the **Prometheus Data Sources** page, click **Enable/Disable** in the Actions column to enable or disable a Prometheus data source.

## Verify a Prometheus data source

You can refer to this section to verify whether a Prometheus data source is available.

### Prerequisites

* Ensure the current user logged in to OCP has the **ADMIN** role.
* A Prometheus data source has been created as described in [Create a Prometheus data source](200.create-prometheus-data-source.md).

### Procedure

1. Log in to OCP.

2. Click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>** in the left navigation pane.

3. Click the **Prometheus** tab.

4. On the **Prometheus Data Sources** page, click **<UI-TERM key="ocp-v2.page.Credential.Cluster.Verification">Verify</UI-TERM>** in the Actions column.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.page.Credential.Cluster.Verification">Verify</UI-TERM>**.

6. View the verification result in the notification bubble.

## Edit a Prometheus data source

You can refer to this section to update or modify the configuration of a Prometheus data source.

### Prerequisites

* Ensure the current OCP user is in the **ADMIN** role.
* You have [created a Prometheus data source](200.create-prometheus-data-source.md).

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>**.

3. Click the **Prometheus** tab.

4. On the **Prometheus Data Sources** page, click **...** in the Actions column > **<UI-TERM key="ocp-v2.page.Settings.Profile.Edit">Edit</UI-TERM>**.

5. In the dialog box that appears, modify the configuration of the Prometheus data source.

   For configuration details, refer to [Create a Prometheus data source](200.create-prometheus-data-source.md).

6. After verification, click **<UI-TERM key="ocp-v2.component.MetricChart.EditMetrics.Save">Save</UI-TERM>**.

## Delete a Prometheus data source

You can refer to this section to delete a Prometheus data source. After deletion, monitoring historical data for all clusters will be unavailable, and the monitoring system will be inaccessible. Deleted data sources cannot be recovered; proceed with caution.

### Prerequisites

* Ensure the current OCP user is in the **ADMIN** role.
* You have [created a Prometheus data source](200.create-prometheus-data-source.md), and the Prometheus data source is in the **Pending Enablement** or **Disabled** state.

### Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**.

3. Click the **Prometheus** tab.

4. On the **Prometheus Data Sources** page, click **...** in the Actions column > **<UI-TERM key="ocp-v2.component.ZoneFormCardList.Delete">Delete</UI-TERM>**.

5. In the dialog box that appears, click **<UI-TERM key="ocp-v2.src.util.component.Delete">Delete</UI-TERM>**.
