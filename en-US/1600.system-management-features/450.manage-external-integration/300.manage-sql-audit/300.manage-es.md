# Connect SQL Audit to ElasticSearch

This topic describes how to connect SQL Audit to an ElasticSearch data source.

## Prerequisites

* Ensure the current OCP user is an admin, organization administrator, or cluster administrator.
* Ensure network connectivity between the OCP Agent and ES.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>**.

3. On the top **ElasticSearch** tab, click **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.New">Create</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, configure the following parameters.

   | Parameter | Description |
   |-----|-------|
   | **<UI-TERM>Data Source Name</UI-TERM>** | 2 to 32 characters, can contain Chinese, English, numbers, and underscores.  |
    | **<UI-TERM key="ocp-v2.Cluster.Import.Address">Access Address</UI-TERM>** | opensearch connection string.<ul><li>For single-node, enter in the format ip:port, for example: 127.0.0.1:9200</li><li>For multi-node, separate with commas. For example: ip1:port,ip2:port,ip3:port</li></ul>  |
    | **<UI-TERM key="ocp-v2.Channel.FormComponent.EMailForm.Username">Username</UI-TERM>** | opensearch cluster username.  |
    | **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.Password">Password</UI-TERM>** | opensearch cluster user password.  |
    | **<UI-TERM key="ocp-v2.Alarm.Event.Remarks">Remarks</UI-TERM>** | Optional.  |

5. Click **<UI-TERM key="ocp-v2.page.Credential.Cluster.Verification">Verify</UI-TERM>** in the lower-right corner of the dialog box.

6. After verification passes, click **<UI-TERM key="ocp-v2.src.constant.alarm.Create">Create</UI-TERM>**.

## Related operations

* **Verify ElasticSearch data source**: In the Data Source Actions column, click **<UI-TERM key="ocp-v2.page.Credential.Host.Verification">Verify</UI-TERM>**. If verification passes, **<UI-TERM key="ocp-v2.page.Credential.OBProxy.VerifiedSuccessfully">Verified.</UI-TERM>** will be displayed after the data source name.

* **Edit ElasticSearch data source**: In the Data Source Actions column, select **<UI-TERM>... > Edit</UI-TERM>**, modify the relevant information in the dialog box that appears, then click **<UI-TERM key="ocp-v2.Compaction.Settings.EditCard.Save">Save</UI-TERM>**.

* **Delete ElasticSearch data source**: In the Data Source Actions column, select **<UI-TERM>... > Delete</UI-TERM>**, then click **<UI-TERM key="ocp-v2.Binlog.Component.FlowBinlogModal.Ok">OK</UI-TERM>** in the dialog box that appears.
