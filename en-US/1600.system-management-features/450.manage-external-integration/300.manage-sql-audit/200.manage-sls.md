# Connect SQL Audit to SLS

This topic describes how to connect SQL Audit to an SLS data source.

## Prerequisites

* Ensure the current OCP user is an admin, organization administrator, or cluster administrator.
* Ensure network connectivity between the OCP Agent and SLS.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">External Integration</UI-TERM>**.

3. On the top page, under the **SLS** tab, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.New">Create</UI-TERM>** in the upper-right corner.

4. In the dialog box that appears, configure the following parameters.

   | Parameter | Description |
   |-----|-------|
   | **<UI-TERM>Data Source Name</UI-TERM>** | 2 to 32 characters, can contain Chinese, English, numbers, and underscores. |
    | **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.AccessDomainName">Domain</UI-TERM>** | The access domain name for the SLS service. |
    | **<UI-TERM>AccessKey ID</UI-TERM>** | The access ID for the SLS service, used to identify the user. |
    | **<UI-TERM>AccessKey Secret</UI-TERM>** | The key used to encrypt signature strings and for SLS to verify signature strings; must be kept confidential. |
    | **<UI-TERM key="ocp-v2.Component.BinlogServerList.Region">Region</UI-TERM>** | The current private cloud region. |
    | **<UI-TERM>Project</UI-TERM>** | The project name for the SLS service. |
    | **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.Remarks">Remarks</UI-TERM>** | Optional. |

5. Click **<UI-TERM key="ocp-v2.page.Credential.Host.Verification">Verify</UI-TERM>** in the lower-right corner of the dialog box.

6. After verification passes, click **<UI-TERM key="ocp-v2.src.constant.alarm.Create">Create</UI-TERM>**.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/sls.png)

## Related operations

* **Verify SLS Data Source**: In the Data Source Actions column, click **<UI-TERM key="ocp-v2.page.Credential.Cluster.Verification">Verify</UI-TERM>**. If verification passes, **<UI-TERM key="ocp-v2.page.Credential.Cluster.VerifiedSuccessfully">Verified.</UI-TERM>** will be displayed after the data source name.

* **Edit SLS Data Source**: In the Data Source Actions column, select **<UI-TERM>... > Edit</UI-TERM>**, modify the relevant information in the dialog box that appears, then click **<UI-TERM key="ocp-v2.page.External.CreateDrawer.Save">Save</UI-TERM>**.

* **Delete SLS Data Source**: In the Data Source Actions column, select **<UI-TERM>... > Delete</UI-TERM>**, then click **<UI-TERM key="ocp-v2.component.Compaction.DumpPolicyDrawer.Ok">OK</UI-TERM>** in the dialog box that appears.
