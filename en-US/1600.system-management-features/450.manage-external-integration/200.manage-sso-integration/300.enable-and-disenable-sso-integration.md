# Enable/Disable SSO integration configuration

OCP supports enabling only one SSO integration. When multiple SSO integrations are created, you can switch between third-party login methods by enabling or disabling them.

## Prerequisites

Ensure the current user logged in to OCP has the **ADMIN** role.

## Procedure

1. Log in to OCP.

2. Click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>** in the left navigation bar to go to the **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO Integration List</UI-TERM>** page.

3. Select the SSO integration you want to enable/disable and click the switch in the **<UI-TERM key="ocp-v2.src.component.TraceConfigModal.WhetherToEnable">Enable</UI-TERM>** column.

4. In the pop-up window, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">OK</UI-TERM>**.
