# Enable or disable SSO integration

OCP supports only one SSO integration. When you create multiple SSO integrations, you can switch between third-party login methods by enabling or disabling them.

## Prerequisites

The current user logged in to OCP must be of the **ADMIN** role.

## Procedure

1. Log in to OCP.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO Integration List</UI-TERM>** page automatically appears.

3. Select the SSO integration that you want to enable or disable and click the switch in the **<UI-TERM key="ocp-v2.src.component.TraceConfigModal.WhetherToEnable">Enable</UI-TERM>** column.

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">OK</UI-TERM>**.
