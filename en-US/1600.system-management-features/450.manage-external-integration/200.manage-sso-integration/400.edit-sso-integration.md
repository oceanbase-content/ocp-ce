# Edit an SSO integration

This topic describes how to modify an SSO integration.

## Prerequisites

The current user has the ADMIN role in the OCP console.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO Integration List</UI-TERM>** page automatically appears.

3. Find the SSO integration that you want to modify and click **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Operation">Actions</UI-TERM>** column.
4. In the dialog box that appears, modify the parameters and click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Ok">OK</UI-TERM>**.
