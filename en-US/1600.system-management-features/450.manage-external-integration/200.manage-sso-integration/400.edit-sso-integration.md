# Edit an SSO integration

If you need to update the configuration of an existing SSO integration, you can refer to this section to modify it.

## Prerequisites

Ensure that the user currently logged in to OCP has the ADMIN role.

## Procedure

1. Log in to OCP.

2. Click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>** in the left navigation pane to go to the **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO Integration List</UI-TERM>** page.

3. Select the SSO integration configuration you want to enable or disable, and click **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">Edit</UI-TERM>** in the **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Operation">Actions</UI-TERM>** column.
4. Update the configuration information in the dialog box and click **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Ok">OK</UI-TERM>**.
