# Delete an SSO integration

If an existing SSO integration configuration no longer meets your business needs, you can delete it by following the steps in this topic.

## Prerequisites

The user logged in to OCP has the ADMIN role.

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO Integration List</UI-TERM>** page automatically appears.

3. Find the SSO integration configuration that you want to delete and click **<UI-TERM key="ocp-v2.component.ZoneFormList.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Operation">Actions</UI-TERM>** column.

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">OK</UI-TERM>**.
