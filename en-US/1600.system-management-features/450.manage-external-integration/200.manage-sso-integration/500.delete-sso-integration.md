# Delete an SSO integration

When the created SSO integration configuration is no longer applicable to your business scenario, you can delete it by referring to this section.

## Prerequisites

Ensure that the user currently logged in to OCP has the ADMIN role.

## Procedure

1. Log in to OCP.

2. Click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">External Integration</UI-TERM>** in the left navigation bar to go to the **<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO Integration List</UI-TERM>** page.

3. Select the SSO integration configuration you want to delete and click **<UI-TERM key="ocp-v2.component.ZoneFormList.Delete">Delete</UI-TERM>** in the **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Operation">Actions</UI-TERM>** column.

4. In the pop-up window, click **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">OK</UI-TERM>**.
