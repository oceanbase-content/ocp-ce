# Delete a certificate

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not provide this feature.</p>
</main>

You can refer to this topic to delete an uploaded certificate. After a certificate is deleted, the corresponding files will be removed from the certificate. You can re-upload the files to a new certificate if they are still valid.

## Prerequisites

* You have logged in to the OCP console as the **ADMIN** or **ORG_ADMIN** role.

* If the certificate is being used, you cannot delete it. To delete a certificate being used, you must first disable SSL encryption for the corresponding cluster. For more information, see [Manage SSL encryption for an OceanBase cluster](../../600.cluster-functions/1200.manage-security-configuration/100.manage-ssl-link-encryption-of-an-ob-cluster.md) and [Manage SSL encryption for an OBProxy cluster](../../800.obproxy-functions/550.manage-ssl-link-encryption-of-an-obproxy-cluster.md).

## Procedure

1. Log in to the OCP console.

2. In the left-side navigation pane, choose **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** \> **<UI-TERM key="ocp-v2.pages.Certificate.CertificateManagement">Certificate Management</UI-TERM>**. The **<UI-TERM key="ocp-v2.src.hook.useMenu.CertificateManagement">Certificate Management</UI-TERM>** page automatically appears.

3. Select the certificate that you want to delete and click **<UI-TERM key="ocp-v2.User.Oracle.UserList.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box that appears, click **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Delete">Delete</UI-TERM>**.
