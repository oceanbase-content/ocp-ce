# Delete a certificate

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This topic applies only to OCP Enterprise Edition. OCP Community Edition does not provide this feature.</p>
</main>

You can delete an uploaded certificate by following the steps on this page. After a certificate is deleted, the corresponding file will be removed from the certificate. Files that are still valid can be re-uploaded in a new certificate.

## Prerequisites

* Ensure that the current user logged in to OCP has the **ADMIN** or **ORG_ADMIN** role.

* Certificates with active users cannot be deleted. If you need to delete one, first disable SSL encryption for the corresponding cluster. For details, see [Manage SSL encryption for an OceanBase cluster](../../600.cluster-functions/1200.manage-security-configuration/100.manage-ssl-link-encryption-of-an-ob-cluster.md) and [Manage SSL encryption for an OBProxy cluster](../../800.obproxy-functions/550.manage-ssl-link-encryption-of-an-obproxy-cluster.md).

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">System Management</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.hook.useMenu.CertificateManagement">Certificate Management</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.src.hook.useMenu.CertificateManagement">Certificate Management</UI-TERM>** page.

3. Select the certificate you want to delete and click **<UI-TERM key="ocp-v2.src.constant.binlog.Delete">Delete</UI-TERM>** in the Actions column.

4. In the dialog box, click **<UI-TERM key="ocp-v2.Detail.Component.DeleteUnitModal.Delete">Delete</UI-TERM>**.
