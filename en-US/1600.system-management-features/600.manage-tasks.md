# Manage tasks

OCP provides the management and viewing of tasks initiated through the OCP console, including O&M and management tasks for OceanBase clusters, tenants, and hosts, as well as O&M tasks for the OCP system.

This topic describes how to view the details of a task and how to handle a failed task.

## Prerequisites

* To view task details, locate the current progress, and download logs, the user logged in to OCP must have the following permissions:

  * **Cluster Read-Only**, **Tenant Read-Only**, **OBProxy Read-Only**, **Arbitration Service Read-Only**, **Binlog Service Read-Only**, or **Host Read-Only** resource permission.
  * **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.All">All</UI-TERM>** menu permission in the Task Center.

* To skip a task, retry a failed task, or roll back a failed task, the user logged in to OCP must have the following permissions:

  * **Cluster Maintenance**, **Tenant Maintenance**, **OBProxy Maintenance**, **Arbitration Service Maintenance**, **Binlog Service Maintenance**, or **Host Maintenance** resource permission.
  * **<UI-TERM key="ocp-v2.component.common.BinlogClusterSelect.All">All</UI-TERM>** menu permission in the Task Center.

## View task details

If there are **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.Running">Executing</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">Failed</UI-TERM>** tasks in OCP, the number of specific tasks will be displayed on the **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>** in the upper right corner of the OCP system page. You can view the details of a task in the following two ways:

* Method 1: Hover the cursor over **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>** and click the number of the task in the bubble. The **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** page will be displayed and will filter the tasks based on the status of the selected task, displaying only tasks with the same status.

* Method 2: Click **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>**. The **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** page will be displayed and will display all tasks.

The following steps are based on **Method 2**:

1. Log in to the OCP console.

2. Click **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>** in the upper part of the page to go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** page.

3. On the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** page, you can filter tasks based on their execution status and initiator, or search for tasks based on the operation object and task name.

   All tasks that meet the specified conditions will be returned in the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>**. You can click the links in the **<UI-TERM key="ocp-v2.Detail.Component.BatchModifyUnitModal.OperationObject">Object</UI-TERM>** column to go to the overview page of the corresponding object.

   ![07021600](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%BB%BB%E5%8A%A1%E5%88%97%E8%A1%A8.png)

   <main id="notice" type='explain'>
   <h4>Note</h4>
   <p>If the operation object of a task has been deleted, you can only view the object name and object type but cannot go to the <b>Object</b> overview page. </p>
   </main>

4. Click the name of the task you want to view to go to the task details page. By default, the task details page displays the logs of the task. You can click the view button to switch to the flow view.

   * In the log view, multiple task logs are displayed. You can click the subtask in the left area to switch to the subtask. The right area displays the execution information and all logs of the subtask. You can click the corresponding button in the following figure ① or ② to perform an operation on the subtask.

      ![07021544](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%A4%B1%E8%B4%A5%E4%BB%BB%E5%8A%A1%E6%97%A5%E5%BF%97%E8%A7%86%E5%9B%BE.png)

   * In the flow view, the page displays the upstream and downstream relationships of subtasks in a topology diagram. After you expand the collapse menu, a collapsed window displays the log information at the bottom of the screen. You can drag the window to zoom in on the window. You can click the operation item in the **...** column on the right side of the specified subtask to perform an operation on the subtask.

      <main id="notice" type='explain'>
      <h4>Note</h4>
      <p>You can drag the mouse to move the topology diagram, use the mouse wheel to zoom in or out, or use the zoom control in the upper right corner to adjust the canvas size. The zooming is centered on the mouse pointer. For a long task process, you can first zoom in to quickly locate the step you are interested in and then zoom out to achieve the purpose of quick location. </p>
      </main>

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%BB%BB%E5%8A%A1%E6%B5%81%E8%BD%AC%E8%A7%86%E5%9B%BE.png)

   The supported operations vary based on the status of the subtask. The supported operations are displayed in the **...** column.

    * For a subtask with the status **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">Completed</UI-TERM>**, you can view the details of the subtask.

    * For a subtask with the status **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">Failed</UI-TERM>**, you can perform the following operations.

       * Download the log information.

       * Retry: Run the subtask again. The subtask is rolled back first and then executed. If the subtask is executed successfully, the downstream subtasks are executed.

       * Skip: Set the status of the subtask to succeeded and then execute the downstream subtasks. Skipping a subtask may cause exceptions in the subsequent steps. Therefore, you must be cautious when you skip a subtask.

         ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%9C%80%E4%BD%B3%E5%AE%9E%E8%B7%B5/%E8%B7%B3%E8%BF%87%E4%BB%BB%E5%8A%A1.png)

    * For a subtask with the status **<UI-TERM key="ocp-v2.Layout.BasicLayout.Running">Executing</UI-TERM>**, you can download the log information or terminate the subtask. After the subtask is terminated, its status changes to **<UI-TERM key="ocp-v2.src.constant.task.Terminated">Aborted</UI-TERM>**, and the status of the main task changes to **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">Failed</UI-TERM>**. You can download the log information, skip, or retry a terminated subtask.

    * For a subtask with the status **<UI-TERM key="ocp-v2.src.constant.alarm.Warning">Warning</UI-TERM>**, you can perform the following operations.

      * Download the log information.

      * Retry: Run the subtask again. The subtask is rolled back first and then executed.

    * For a subtask with the status **<UI-TERM key="ocp-v2.src.constant.backup.Paused">Suspending</UI-TERM>**, you can perform the following operations.

      * Download the log information.

      * Continue: Continue to execute the subtask.

## Retry a failed task

You can retry a task that has been **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">Failed</UI-TERM>** or **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.RollbackFailed">Rollback Failed</UI-TERM>**. When you retry a failed task, all failed nodes in the current step are rolled back and then re-executed. If the retry is successful, the subsequent steps are executed.

You can retry a failed task in the following two ways:

* Method 1: On the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** page, select a failed task and click **<UI-TERM key="ocp-v2.page.Task.Retry">Retry</UI-TERM>**.
* Method 2: On the task details page, click **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.ReRun">Retry</UI-TERM>** in the upper-right corner.

The following example describes how to retry a failed task by using **Method 1**:

1. Log in to the OCP console.

2. In the upper-left corner of the page, click **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">Task Center</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** page.

3. Select a failed task and click **<UI-TERM key="ocp-v2.page.Task.Retry">Retry</UI-TERM>** in the ① column.

   You can also select multiple failed tasks and click ② to retry them in batches.

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E9%87%8D%E8%AF%95%E4%BB%BB%E5%8A%A1.png)

## Roll back a failed task

You can roll back a failed task to recycle resources and modify the task status.

1. Log in to the OCP console.

2. In the upper-left corner of the page, click **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">Task Center</UI-TERM>** to go to the **<UI-TERM key="ocp-v2.page.Task.TaskList">Tasks</UI-TERM>** page.

3. Click the name of the task to go to its details page.

4. In the upper-right corner of the task details page, click **<UI-TERM key="ocp-v2.src.constant.task.Rollback">Roll Back</UI-TERM>**.

   ![05101010](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E5%9B%9E%E6%BB%9A%E4%BB%BB%E5%8A%A1.png)

## Locate the current progress

During task execution, you can click **<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">Locate Current Progress</UI-TERM>** to quickly jump to the subtask that is being executed. This helps you monitor the task execution status and related logs. For a task that has been **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">Failed</UI-TERM>**, you can click **<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">Locate Current Progress</UI-TERM>** to quickly locate the subtask that failed and the task execution exception.

## Download logs

On the task details page, click **<UI-TERM key="ocp-v2.src.constant.obproxy.DownloadLogs">Download Logs</UI-TERM>** in the upper-right corner to download the execution logs of all subtasks under the task to your local device.
