# Export a credential

This topic describes how to export a credential.

## Prerequisites

Ensure the current OCP user has the following permissions:

* Any of the following resource permissions: **Cluster Read-Only**, **Tenant Read-Only**, **OBProxy Read-Only**, **Binlog Service Read-Only**, or **Host Read-Only**.
* Permission to access the **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.CredentialManagement">Credential Management</UI-TERM>** menu under Security Management.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">Security Management</UI-TERM>** \> **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">Credential Management</UI-TERM>** to go to the credential list page.

3. On the **OceanBase**, **OBProxy**, or **<UI-TERM key="ocp-v2.src.constant.alarm.Host">Host</UI-TERM>** tab, find the credential you want to export.

4. Hover the cursor over **<UI-TERM key="ocp-v2.Component.SQLDetail.ParallelSQLTraceTable.Actions">Actions</UI-TERM>** in that object's **<UI-TERM key="ocp-v2.src.util.component.More">More</UI-TERM>** column, and select **<UI-TERM key="ocp-v2.Monitor.Dashboard.Export">Export</UI-TERM>** from the drop-down list.

5. In the dialog box, enter an encryption password. The password must meet the following requirements:

    * Be 8 to 32 characters long.
    * Contain at least three of the four character types: digits (0–9), uppercase letters (A–Z), lowercase letters (a–z), and special characters.
    * Support the following special characters: <code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>.

6. Click **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ExportSqlButton.Export">Export</UI-TERM>**.
