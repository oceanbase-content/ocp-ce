# How can I locate distributed SQL statements in a tenant?

OceanBase Database is a distributed database that allows you to distribute data read and write services to all servers in a cluster. Distributed execution is less efficient than local execution. Therefore, OceanBase Database provides the table group syntax to bind business tables to a [table group](https://en.oceanbase.com/docs/common-oceanbase-database-10000000000872354). This converts distributed execution into local execution and improves query efficiency.

On the **TopSQL** tab, click **<UI-TERM key="ocp-v2.Component.filter.ColumnManagement">Column Management</UI-TERM>** and select **Proportion of Distributed Plans (%)**. Then sort the SQL statements on the tab by the **Proportion of Distributed Plans (%)** column.
