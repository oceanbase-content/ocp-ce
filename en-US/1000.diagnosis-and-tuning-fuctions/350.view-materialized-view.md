# View materialized views

This topic describes how to view details of materialized views for a tenant.

<main id="notice" type='notice'>
<h4>Applicability</h4>
<p>This content applies only to OCP Enterprise Edition. OCP Community Edition does not provide this feature.</p>
</main>

## Prerequisites

Ensure the current OCP user has the following permissions:

* **Cluster Read-Only** or **Tenant Read-Only** resource permission.
* Diagnostic Service **Real-Time Diagnostics** menu permission.

## Procedure

1. Log in to OCP.

2. In the left navigation bar, click **Diagnostic Service**.

3. In the **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">Cluster Details</UI-TERM>** section, click the name of the cluster you want to view.

4. Go to the **Materialized Views** tab under **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">Real-time Diagnostics</UI-TERM>** to filter tenants.

5. On the **List** tab, you can view all auto-refresh materialized views under the selected tenant. The view information includes **ID**, **<UI-TERM key="ocp-v2.ComparisonSqlDrawer.DetailedTable.Database">Database</UI-TERM>**, **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.Name">Name</UI-TERM>**, **View Definition**, **Construction Mode**, **Refresh Mode**, **Refresh Method**, **Refresh Interval**, **Current Latency (seconds)**, **Next Refresh**, **Last Refresh Time**, and **Last Refresh Duration (seconds)**.

   * You can filter views by **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.Database">Database</UI-TERM>**.
   * Click **<UI-TERM key="ocp-v2.src.constant.report.See">View</UI-TERM>** in the **View Definition** column to view the view definition details.

6. On the **Refresh Records** tab, you can view the refresh records for materialized views under the selected tenant. The record information includes **ID**, **<UI-TERM key="ocp-v2.Detail.Session.Statistics.Database">Database</UI-TERM>**, **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.Plan.Name">Name</UI-TERM>**, **Refresh Method**, **Refresh Duration (seconds)**, **<UI-TERM key="ocp-v2.Transaction.Detail.StartTime">Start Time</UI-TERM>**, **<UI-TERM key="ocp-v2.TraceContent.PlanOperation.EndTime">End Time</UI-TERM>**, and **Result**.

   * You can filter by time range. By default, the system displays data from the last 3 hours. You can select a time range in the upper-right corner to return data within that period.
   * You can filter refresh records using the **View Only Timeout Records** and **View Base Table Content** checkboxes. Selecting one of these checkboxes will display only refresh records that meet that condition in the list. When **View Base Table Content** is selected, the list below will additionally display information columns for **Number of Rows Inserted into Base Table**, **Number of Rows Updated in Base Table**, and **Number of Rows Deleted from Base Table**.
   * You can filter refresh records by **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Database">Database</UI-TERM>**.
