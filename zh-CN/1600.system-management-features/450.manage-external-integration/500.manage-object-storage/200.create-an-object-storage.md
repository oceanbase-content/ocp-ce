# 创建对象存储配置

本文将介绍如何在 OCP 中创建对象存储配置，为 AI 集群提供存储支持。

## 前提条件

* 已准备好对象存储服务（如阿里云 OSS、AWS S3、腾讯云 COS、华为云 OBS 等）。
* 已获取对象存储的以下信息：
  * Bucket 名称和路径
  * Endpoint 地址
  * AccessKey ID
  * AccessKey Secret

## 操作步骤

1. 登录 OCP 后，在左侧导航栏选择 **系统管理** > **外部集成**，进入外部集成页面。

2. 在外部集成页面，单击 **对象存储** 页签。

3. 单击 **新建对象存储** 按钮，弹出创建对象存储对话框。

4. 填写对象存储配置信息：

   | 参数 | 说明 | 是否必填 |
   |------|------|---------|
   | **名称** | 对象存储配置的名称，用于标识和区分不同的配置。 | 是 |
   | **存储类型** | 对象存储服务的类型，支持：<ul><li>阿里云 OSS</li><li>AWS S3</li><li>腾讯云 COS</li><li>华为云 OBS</li></ul> | 是 |
   | **Bucket URI** | 对象存储的桶路径，格式为 `s3://{bucket-name}/` 或 `oss://{bucket-name}/`。 | 是 |
   | **Endpoint（host）** | 对象存储服务的访问端点地址，例如 `s3.cn-northwest-1.amazonaws.com.cn`。 | 是 |
   | **AccessKey ID** | 访问对象存储的 AccessKey ID。 | 是 |
   | **AccessKey Secret** | 访问对象存储的 AccessKey Secret。 | 是 |
   | **说明** | 对此对象存储配置的备注说明。 | 否 |

5. 填写完成后，单击 **确定** 按钮。

   系统将验证所填信息是否有效。验证通过后，对象存储配置创建成功。

<main id="notice" type='explain'>
<h4>说明</h4>
<ul>
<li>创建对象存储配置时，系统会验证 Endpoint 是否可达、AccessKey 凭证是否有效。</li>
<li>建议为不同业务或不同环境的对象存储配置设置有区分度的名称，便于后续管理。</li>
</ul>
</main>

## 后续操作

对象存储配置创建完成后，您可以在以下场景中使用：

* **创建 AI 集群**：在创建 AI 集群时，选择已创建的对象存储配置作为数据存储。
* **查看详情**：单击对象存储配置名称，查看详细信息和关联的集群。
* **更新配置**：如需更新 AccessKey 或其他信息，可编辑对象存储配置。
* **删除配置**：如需删除未使用的对象存储配置，可在确认无集群引用后进行删除。
