# 创建对象存储配置

本文将介绍如何在 OCP 中创建对象存储配置，为 AI 集群提供存储支持。

## 前提条件

* 已准备好对象存储服务（支持 S3 协议的对象存储服务，如阿里云 OSS、AWS S3、腾讯云 COS、华为云 OBS 等）。
* 已获取对象存储的以下信息：
  * Endpoint 地址
  * 地域
  * AccessKey ID
  * AccessKey Secret


## 操作步骤

1. 登录 OCP 后，在左侧导航栏选择最下面的图标 **系统管理** > **外部集成**，进入外部集成页面。

2. 在外部集成页面，单击 **对象存储** 页签。

3. 单击 **新建** 按钮，弹出创建对象存储对话框。

4. 填写对象存储配置信息：

  <main id="notice" type='explain'>
  <h4>说明</h4>
  <ul>
  <li>创建对象存储配置时，系统会验证 Endpoint 是否可达、AccessKey 凭证是否有效。</li>
  <li>建议为不同业务或不同环境的对象存储配置设置有区分度的名称，便于后续管理。</li>
  <li>当前仅支持通过 AccessKey ID、AccessKey Secret 方式访问对象存储，不支持通过 RAM URL 方式授权。</li>
  </ul>
  </main>

   | 参数 | 说明 | 是否必填 |
   |------|------|---------|
   | **名称** | 对象存储配置的名称，用于标识和区分不同的配置。名称长度 2~32 字符，可包含中文、英文字母、数字、下划线。 | 是 |
   | **协议类别** | 对象存储服务的协议类型，支持 **S3**、**OSS**、**OBS** 协议。 | 是 |
   | **Endpoint** | 对象存储访问域名，例如 `oss-cn-hangzhou.aliyuncs.com`。 | 是 |
   | **AccessKey ID** | 对象存储访问 ID 用于标识用户。 | 是 |
   | **AccessKey Secret** | 用于加密签名字符串和签名服务用来验证签名字符串的密钥，请保管好您的 AccessKey Secret。 | 是 |
   | **地域** | 当前专有云 region，例如 `cn-hangzhou`。 | 是 |
   | **备注** | 对此对象存储配置的备注说明，可不填。 | 否 |

5. 填写完成后，单击 **验证** 按钮验证配置信息是否有效。

6. 验证通过后，单击 **确定** 按钮，对象存储配置创建成功。

## 编辑对象存储配置

已创建的对象存储配置支持编辑备注信息。单击对象存储列表中对应配置的 **编辑** 按钮，在弹出的对话框中修改备注后保存即可。
