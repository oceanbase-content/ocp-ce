# 删除对象存储配置

本文将介绍如何删除未使用的对象存储配置。

## 前提条件

* 已创建对象存储配置。
* 待删除的对象存储配置未被任何 AI 集群、日志服务集群引用。

## 操作步骤

1. 登录 OCP 后，在左侧导航栏选择最下面的图标 **系统管理** > **外部集成**，进入外部集成页面。

2. 在外部集成页面，单击 **对象存储** 页签。

3. 找到需要删除的对象存储配置，确认该配置未被任何集群引用。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>如果对象存储配置正在被 AI 集群使用，删除操作将被禁止。请先修改集群的配置，解除引用关系后再进行删除。</p>
   </main>

4. 单击操作列的 **删除** 按钮，弹出确认对话框。

5. 在确认对话框中，核对要删除的对象存储配置名称，确认无误后单击 **确定** 按钮。

   对象存储配置删除成功。

## 无法删除的情况

如果对象存储配置正在被 AI 集群引用，删除操作会被阻止，系统会提示相关错误信息。

### 处理步骤

1. **查找引用的集群**：在对象存储配置详情页面，查看关联的集群列表。

2. **修改集群配置**：进入被引用的 AI 集群详情页，将数据存储路径更换为其他配置。

3. **重新尝试删除**：确认无集群引用后，重新执行删除操作。

<main id="notice" type='notice'>
<h4>说明</h4>
<p>删除对象存储配置只会删除 OCP 中的配置记录，不会删除对象存储服务上的实际数据。</p>
</main>
