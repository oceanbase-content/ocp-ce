# 编辑对象存储配置

本文将介绍如何编辑对象存储配置信息，包括更新 AccessKey 凭证。

## 前提条件

* 已创建对象存储配置。

## 操作步骤

1. 登录 OCP 后，在左侧导航栏选择 **系统管理** > **外部集成**，进入外部集成页面。

2. 在外部集成页面，单击 **对象存储** 页签。

3. 找到需要编辑的对象存储配置，单击操作列的 **编辑** 按钮，弹出编辑对话框。

4. 根据需要修改配置信息：

   | 参数 | 说明 | 是否可编辑 |
   |------|------|---------|
   | **名称** | 对象存储配置的名称。 | 是 |
   | **协议类别** | 对象存储服务的类型（如 OSS）。 | 否 |
   | **Endpoint** | 对象存储服务的访问端点地址。 | 是 |
   | **AccessKey ID** | 访问对象存储的 AccessKey ID。 | 是 |
   | **AccessKey Secret** | 访问对象存储的 AccessKey Secret。 | 是 |
   | **地域** | 对象存储服务所属的地域（Region）。 | 是 |
   | **备注** | 对此对象存储配置的备注说明。 | 是 |

5. 填写完成后，单击 **保存** 按钮。

<main id="notice" type='explain'>
   <h4>说明</h4>
   <p>编辑修改只是更新 OCP 本地的配置记录，并不会立即生效到集群。如需让集群使用新的 AccessKey，请参考下方的 AccessKey 轮换流程进行操作。</p>
</main>

## AccessKey 轮换

为了保障安全性，建议定期更新 AccessKey 凭证。AccessKey 轮换的操作流程如下：

### 推荐方案：新建 → 修改引用 → 删除旧配置

1. **新建对象存储配置**：按照 [创建对象存储配置](200.create-an-object-storage.md) 的步骤，创建新的对象存储配置，使用新的 AccessKey。

2. **修改 AI 集群引用**：在 AI 集群的详情页或配置页面，将集群关联的对象存储切换为新创建的配置。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>修改集群的对象存储引用后，集群会使用新的 AccessKey 访问对象存储。</p>
   </main>

3. **等待旧凭证失效**：集群替换新的 AccessKey 后，旧 AccessKey 不会立即从集群中失效。**请确保等待至少一小时后再删除旧配置**，以确保所有节点都已完成凭证更新。

4. **删除旧配置**：确认集群正常运行后，删除旧的对象存储配置。

<main id="notice" type='explain'>
<h4>说明</h4>
<ul>
<li>集群替换为新 AccessKey 后，旧 AccessKey 不一定马上从集群中失效。删除旧 AccessKey 前，请确保已等待至少一小时，避免因凭证失效导致集群异常。</li>
<li>也支持直接在编辑页面更新 AccessKey，但建议优先使用"新建 → 修改引用 → 删除旧配置"的方案进行轮换，以确保安全性和可回退性。</li>
</ul>
</main>
