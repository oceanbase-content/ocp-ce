# 编辑对象存储配置

本文将介绍如何编辑对象存储配置信息，包括更新 AccessKey 凭证。

## 前提条件

* 已创建对象存储配置。

## 操作步骤

1. 登录 OCP 后，在左侧导航栏选择 **系统管理** > **外部集成**，进入外部集成页面。

2. 在外部集成页面，单击 **对象存储** 页签。

3. 找到需要编辑的对象存储配置，单击操作列的 **编辑** 按钮，弹出编辑对话框。

4. 根据需要修改配置信息：

   | 参数 | 说明 | 是否可编辑 |
   |------|------|---------|
   | **名称** | 对象存储配置的名称。 | 是 |
   | **存储类型** | 对象存储服务的类型。 | 否 |
   | **Bucket URI** | 对象存储的桶路径。 | 否 |
   | **Endpoint（host）** | 对象存储服务的访问端点地址。 | 是 |
   | **AccessKey ID** | 访问对象存储的 AccessKey ID。 | 是 |
   | **AccessKey Secret** | 访问对象存储的 AccessKey Secret。 | 是 |
   | **说明** | 对此对象存储配置的备注说明。 | 是 |

5. 填写完成后，单击 **确定** 按钮。

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li>修改 Endpoint、AccessKey 等信息后，使用该配置的 AI 集群可能会受到影响，请确保集群正常运行。</li>
<li>如果对象存储配置正在被 AI 集群使用，编辑后需要关注集群状态是否正常。</li>
</ul>
</main>

## AccessKey 轮换

为了保障安全性，建议定期更新 AccessKey 凭证。AccessKey 轮换的操作流程如下：

### 推荐方案：新建 → 修改引用 → 删除旧配置

1. **新建对象存储配置**：按照 [创建对象存储配置](200.create-an-object-storage.md) 的步骤，创建新的对象存储配置，使用新的 AccessKey。

2. **修改 AI 集群引用**：在 AI 集群的详情页或配置页面，将集群关联的对象存储切换为新创建的配置。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>修改集群的对象存储引用后，集群会使用新的 AccessKey 访问对象存储。</p>
   </main>

3. **等待旧凭证失效**：集群替换新的 AccessKey 后，旧 AccessKey 不会立即从集群中失效。**请确保等待至少一小时后再删除旧配置**，以确保所有节点都已完成凭证更新。

4. **删除旧配置**：确认集群正常运行后，删除旧的对象存储配置。

<main id="notice" type='notice'>
<h4>重要提示</h4>
<ul>
<li>集群替换为新 AccessKey 后，旧 AccessKey 不一定马上从集群中失效。</li>
<li>删除旧 AccessKey 前，请务必确认已等待足够时间（至少一小时），避免因凭证失效导致集群异常。</li>
<li>如果在删除旧 AccessKey 后集群出现异常，可能需要重新配置凭证。</li>
</ul>
</main>

### 不推荐方案：原地更新

您也可以直接在编辑页面更新 AccessKey ID 和 AccessKey Secret，但这种方案存在以下风险：

* 更新过程中如果出现错误，可能导致集群无法访问对象存储。
* 没有回退路径，一旦更新失败难以恢复。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>建议优先使用"新建 → 修改引用 → 删除旧配置"的方案进行 AccessKey 轮换，以确保安全性和可回退性。</p>
</main>
