# 对象存储最佳实践

本文档介绍 AI 集群、Logservice 集群与对象存储的配合使用方式，帮助您快速上手共享存储架构的部署和管理。

## 架构概述

OceanBase AI 集群采用存算分离（Shared Storage）架构，数据面由对象存储和日志服务（Logservice）共同支撑，实现更极致的弹性能力。

### 核心组件

| 组件 | 角色 | 关系 | 说明 |
|------|------|------|------|
| **对象存储** | 数据持久化层 | 1:N | 存储所有业务数据（基线数据 + 增量数据），作为数据的最终归宿。一个对象存储配置可被多个 AI 集群使用，但每个集群的数据通过不同的目录路径隔离 |
| **Logservice 集群** | 日志服务层 | 1:1 | 提供日志持久化能力，解耦计算节点与高可用需求，支持跨 AZ 容灾。一个 Logservice 集群只能绑定一个 AI 集群 |
| **AI 集群** | 计算服务层 | - | 仅保留本地缓存盘，提供读写服务，数据从对象存储按需拉取 |

```
┌─────────────────────────────────────────────────────────┐
│                      OCP 管理平台                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│    对象存储配置                                          │
│         │                                               │
│         ▼                                               │
│    Logservice 集群 ◄─── 日志持久化 / 跨 AZ 容灾          │
│         │                                               │
│         ▼                                               │
│    AI 集群（计算节点） ◄─── 本地缓存盘                    │
│         │                                               │
│         └───────────┬───────────────┘                   │
│                     │                                    │
│                     ▼                                    │

└─────────────────────────────────────────────────────────┘
```

<h4>说明</h4>
<p>虽然多个 AI 集群可以共用一个对象存储配置，但每个集群的数据通过不同的目录路径隔离，互不影响。建议在创建 AI 集群时，为每个集群指定独立的目录路径。</p>

## 使用流程

### 步骤一：创建对象存储配置

在创建 AI 集群前，需要先在外部集成模块中配置对象存储：

1. 登录 OCP，进入 **系统管理** > **外部集成** > **对象存储**。
2. 单击 **新建对象存储配置**。
3. 填写配置信息：
   * **名称**：自定义配置名称，建议为不同业务或环境设置有区分度的名称。
   * **协议类别**：选择 S3/OSS/OBS。
   * **Endpoint**：对象存储访问地址。
   * **地域**：对象存储所在地域，若无地域信息可任意填写。
   * **AccessKey ID/Secret**：访问凭证。

详细操作请参见 [创建对象存储配置](200.create-an-object-storage.md)。



### 步骤二：创建 Logservice 集群

Logservice 集群为 AI 集群提供日志服务能力，与 AI 集群为一对一关系。



1. 登录 OCP，进入 **日志服务** > **实例**。
2. 单击 **创建集群**。
3. 填写集群信息，可选择应用参数模板。
4. 单击完成创建。

详细操作请参见 [创建 Logservice 集群](../../855.logservice-instance-functions/300.manage-a-logservice-cluster/200.create-a-logservice-cluster.md)。



### 步骤三：创建 AI 集群

创建 AI 集群时关联对象存储和 Logservice：

1. 登录 OCP，进入 **集群** > **创建集群**。
2. 选择 **AI 集群** 类型。
3. 配置基本信息（集群名、密码、版本等）。
4. 选择已创建的对象存储配置。
5. 选择已创建的 Logservice 集群。
6. 单击完成创建。

详细操作请参见 [创建 AI 集群](../../600.cluster-functions/200.create-a-cluster/300.create-an-ai-cluster.md)。




## 其它相关操作

### AccessKey 轮换

定期更新 AccessKey 凭证时，建议采用以下流程：

1. **新建对象存储配置**：创建使用新凭证的配置。
2. **修改集群引用**：将 AI 集群的对象存储切换到新配置。
3. **等待生效**：等待至少一小时，确保所有节点完成凭证更新。
4. **删除旧配置**：确认集群正常后删除旧配置。

详细操作请参见 [编辑对象存储配置](300.edit-an-object-storage.md)。



### 删除集群

删除 AI 集群时需要注意：

* 删除 AI 集群不会删除对象存储上的数据。
* 关联的 Logservice 集群会被置为 DEPRECATED（已废弃）状态。
* 对象存储配置会保留，供其他集群使用。
