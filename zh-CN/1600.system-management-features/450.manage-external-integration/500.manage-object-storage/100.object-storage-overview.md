# 对象存储概述

对象存储（Object Storage）是 OceanBase 共享存储版本（AI 集群）的核心依赖组件。在创建 AI 集群时，需要通过外部集成模块预先配置对象存储的连接信息，包括 Bucket 路径、Endpoint 地址、AccessKey 凭证等。

## 背景信息

AI 集群采用存算分离架构，数据存储在对象存储服务上，而非本地磁盘。为了安全、便捷地管理对象存储的访问凭证，OCP 提供了外部集成模块来统一管理对象存储配置。

通过外部集成管理对象存储，可以：

* **统一管理**：集中管理多个集群使用的对象存储配置，避免分散管理导致的配置混乱。
* **生命周期管理**：管理对象存储的完整生命周期，包括创建、更新、删除操作。
* **凭证安全**：安全存储 AccessKey 凭证，在创建集群时自动注入，无需手动填写。

## 概念介绍

* **对象存储（Object Storage）**：一种分布式存储服务，支持通过 RESTful API 进行数据存取。常见的对象存储服务包括阿里云 OSS、AWS S3、腾讯云 COS、华为云 OBS 等。

* **Bucket**：对象存储的容器，用于存储对象（文件）。每个 Bucket 有唯一的域名和访问地址。

* **Endpoint**：对象存储服务的访问端点地址，不同地域有不同的 Endpoint。

* **AccessKey**：访问对象存储的凭证，包含 AccessKey ID 和 AccessKey Secret，用于身份验证。

## 用途和最佳实践

### 用途

对象存储是供 OceanBase AI 集群及其依赖服务 Logservice 主要存放数据的空间。AI 集群采用存算分离架构，所有数据文件、日志文件等均存储在对象存储服务上，而非本地磁盘。

### 最佳实践

* **独立 Bucket**：AI 集群和 Logservice 集群在创建时，应分别使用独立的 Bucket，不支持混用。建议为不同类型的集群配置独立的 Bucket，以确保数据隔离和安全性。

* **权限最小化**：为对象存储 AccessKey 配置最小必要权限，遵循最小权限原则。

* **定期轮换**：定期轮换 AccessKey，降低凭证泄露风险。

## 支持的存储类型

OCP 支持以下对象存储类型：

| 存储类型 | 协议 | 说明 |
|---------|------|------|
| 阿里云 OSS | S3 兼容协议 | 阿里云对象存储服务 |
| AWS S3 | S3 | 亚马逊云对象存储服务 |
| 腾讯云 COS | S3 兼容协议 | 腾讯云对象存储服务 |
| 华为云 OBS | S3 兼容协议 | 华为云对象存储服务 |

## 使用流程

对象存储管理的典型流程如下：

1. **创建对象存储配置**：在外部集成页面添加对象存储，填写 Bucket、Endpoint、AccessKey 等信息。
2. **创建 AI 集群**：在创建 AI 集群时，选择已配置的对象存储，系统将自动注入存储配置。
3. **管理对象存储**：根据需要更新 AccessKey（轮换）或删除未使用的配置。

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li>对象存储配置被 AI 集群引用时，无法直接删除，需先解除引用关系。</li>
<li>更新 AccessKey 时，建议采用"新建配置 → 修改集群引用 → 删除旧配置"的流程，而非原地更新。</li>
<li>集群替换新的 AccessKey 后，旧 AccessKey 不会立即从集群中失效，删除旧 AccessKey 前请确保等待至少一小时。</li>
</ul>
</main>
