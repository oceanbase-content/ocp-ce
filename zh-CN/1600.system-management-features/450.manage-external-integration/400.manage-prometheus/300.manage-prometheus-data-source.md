# 管理 Prometheus 数据源

本文为您介绍如何管理 Prometheus 数据源。

## 启用/禁用 Prometheus 数据源

Prometheus 数据源创建成功后，需手动启用后才可使用，您可参考本节内容对 Prometheus 数据源执行启用/禁用操作。禁用 Prometheus 数据源后，监控数据将仅写入 MonitorDB。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 在启用 Prometheus 数据源前，请务必已参考 [创建 Prometheus 数据源](200.create-prometheus-data-source.md) 完成 `prometheus.yaml` 配置文件修改和重启 Prometheus 服务。

### 操作步骤

1. 登录 OCP。

2. 单击左侧导航栏 **系统管理** > **外部集成**。

3. 单击 **Prometheus** 页签。

4. 在 **Prometheus 数据源** 页面，单击操作列的 **启用/禁用**，即可对 Prometheus 数据源进行启用/禁用操作。

## 验证 Prometheus 数据源

您可参考本节内容验证 Prometheus 数据源是否可用。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 已 [创建 Prometheus 数据源](200.create-prometheus-data-source.md)。

### 操作步骤

1. 登录 OCP。

2. 单击左侧导航栏 **系统管理** > **外部集成**。

3. 单击 **Prometheus** 页签。

4. 在 **Prometheus 数据源** 页面，单击操作列的 **验证**。

5. 在弹出的对话框中单击 **验证**。

6. 在气泡中查看验证结果。

## 编辑 Prometheus 数据源

您可参考本节内容对 Prometheus 数据源的配置信息进行更新或修改。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 已 [创建 Prometheus 数据源](200.create-prometheus-data-source.md)。

### 操作步骤

1. 登录 OCP。

2. 单击左侧导航栏 **系统管理** > **外部集成**。

3. 单击 **Prometheus** 页签。

4. 在 **Prometheus 数据源** 页面，单击操作列的 **...** > **编辑**。

5. 在弹出的对话框中，修改 Prometheus 数据源的配置信息。

   配置信息说明可参考 [创建 Prometheus 数据源](200.create-prometheus-data-source.md)。

6. 验证成功后单击 **保存**。

## 删除 Prometheus 数据源

您可参考本节内容删除 Prometheus 数据源。删除后，全部集群的监控历史数据将无法查看，且无法接入监控系统。删除后数据源将无法恢复，您需谨慎操作。

### 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 已 [创建 Prometheus 数据源](200.create-prometheus-data-source.md)，且该 Prometheus 数据源处于 **待启用** 或 **已禁用** 状态。

### 操作步骤

1. 登录 OCP。

2. 单击左侧导航栏 **系统管理** > **外部集成**。

3. 单击 **Prometheus** 页签。

4. 在 **Prometheus 数据源** 页面，单击操作列的 **...** > **删除**。

5. 在弹出的对话框中单击 **删除**。
