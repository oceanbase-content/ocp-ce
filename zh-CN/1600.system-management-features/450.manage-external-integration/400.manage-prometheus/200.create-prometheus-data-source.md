# 新建 Prometheus 数据源

本节为您介绍如何在 OCP 上新建 Prometheus 数据源，以及需要进行的后续操作。

## 前提条件

* 请确保当前 OCP 中未启用 SLS 数据源。
* 已部署 V2.28 及以上版本的 Prometheus 服务。
* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。

## 操作步骤

1. 登录 OCP。

2. 单击左侧导航栏 **系统管理** > **外部集成**。

3. 单击 **Prometheus** 页签。

4. 在 **Prometheus 数据源** 页面，单击 **新建 Prometheus 数据源**。

5. 在弹出的对话框中，填写 **Prometheus 数据源** 的相关信息。

   | 配置项    | 说明     |
   | --------- | ---------- |
   | 数据源名称 | Prometheus 数据源的名称。要求 2~32 字符，可包含中文、英文字母、数字、下划线（_），且具有唯一性。 |
   | 访问地址   | Prometheus 服务的访问 IP，`http/https` 开头，仅允许填写一个 IP 地址。 |
   | 端口       | Prometheus 服务的访问端口，默认为 9090，支持自定义。 |
   | 用户名     | Prometheus 服务授权账户的用户名，若无可不填写。 |
   | 密码       | Prometheus 服务授权账户的密码，若无可不填写。 |
   | 备注       | 添加关于 Prometheus 数据源的特殊说明。 |

6. 单击 **验证**，用于验证数据源联通性。

7. 验证成功后，单击 **新建**。

## 后续操作

数据源创建后，需按照以下步骤配置并启用 Prometheus 方可生效。

1. 在 Prometheus 的配置文件 `prometheus.yaml` 中添加以下配置信息（请注意仅展示一次密码信息）。

   ```yaml
   scrape_configs:
     - job_name: 'ocp_sd'
       scheme: 'http'
       fallback_scrape_protocol: "PrometheusText1.0.0"
       http_sd_configs:
         - url: 'http://xx.xx.xx.xx:8080/api/v2/monitor/prometheus_sd'
           basic_auth:   # 访问 OCP 获取 prometheus_sd 中所有 target
               username: "******"
               password: "******"
           basic_auth:   # 控制访问所有 target
               username: "******"
               password: "******"
   ```

2. 重启 Prometheus 服务，确保配置生效。

3. 在当前 OCP 平台中启用 Prometheus 配置。

   默认情况下，监控数据仅写入 Prometheus，如需同时将监控数据写入 MonitorDB，请将系统参数 `ocp.monitor.metric.collect.service.type` 的值变更为 `LOCAL`。
