# Prometheus 概述

## 功能介绍

Prometheus 是一套开源的监控、告警和时间序列数据库一体化解决方案。它提供了标准化的数据模型以及高效的数据采集、存储和查询接口，支持通过 HTTP 协议定期抓取被监控组件的运行状态。系统通过将监控查询对接至 Prometheus，可以有效减轻 OCP-Server 在数据采集和计算方面的负载压力，显著提升查询接口的整体吞吐性能。

## 使用流程

1. 新建 Prometheus 数据源。
2. 修改 `prometheus.yaml` 配置文件。
3. 重启 Prometheus 服务。
4. 启用 Prometheus 数据源。
5. （可选）对 Prometheus 数据源进行其他管理操作。

其中，步骤 1~ 步骤 3 请参考 [新建 Prometheus 数据源](200.create-prometheus-data-source.md)，步骤 4 ~ 步骤 5 请参考 [管理 Prometheus 数据源](300.manage-prometheus-data-source.md)。

## 注意事项

* 当 OCP 由低版本升级为 V4.4.2 时，若您在升级前已参考 [将 OCP 监控集成到 Prometheus](../../../1850.ocp-om-best-practices/1550.prometheus-http-sd.md) 接入 Prometheus 且未开启鉴权，此时新建 Prometheus 数据源将覆盖原有的 Prometheus 配置信息，且数据源新建成功后需要您手动开启鉴权。
* 同一个 OCP 上，SLS 和 Prometheus 只能启用其中一个。
* 为确保 OCP 与 Prometheus 服务成功建立连接，OCP 与 Prometheus 的接入方式需保持一致。推荐使用 HTTPS 方式接入，安全性更高但配置较复杂，详情可参考 [HTTPS 认证说明](../../../2100.appendix/1300.https-authentication-instructions.md)。若 OCP 采用 HTTP 方式，也可使用 HTTP 方式接入 Prometheus。
