# 管理租户参数

您可参考本节内容对不同租户设置差异化的可疑 SQL 诊断规则，以满足多样化的业务需求。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护** 或 **租户维护** 资源权限。
* 租户 **概览** 菜单权限。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **租户** ，系统默认进入 **租户列表** 页签。

3. 在 **租户列表** 中选择待操作的租户并单击其租户名，进入租户 **概览** 页面。

4. 单击右上角 **...** 图标，选择 **租户参数** 。

5. 在弹出的面板中，选择需要修改的参数，单击参数值右侧的编辑按钮。部分参数修改后需要重启 OCP 服务器才可生效，具体可见 **是否重启生效** 列。
