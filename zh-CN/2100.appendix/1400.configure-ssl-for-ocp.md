# 为 OCP 配置 SSL

当您需要使用 HTTPS 访问 OCP 时，可参考本节内容为 OCP 配置 SSL 证书。

## 查看 CA 证书

如果您已从权威 CA 机构获取证书，请确保证书文件（通常为 `.cer`, `.crt` 或 `.pem`）完整且未过期。

```bash
# 查看证书详细信息（以 ocp.cer 为例）
openssl x509 -in ocp.cer -text -noout

# 重点检查以下字段：
# - Not After: 证书有效期
# - Subject Alternative Name (SAN): 是否包含 OCP 的访问域名或 IP
```

## 配置 CA 证书

### 使用公网 CA 证书

如果您已拥有 CA 认证的证书，可以直接配置，客户端可以直接通过 HTTPS 访问 OCP。这里的 `ocp.cer` 就是签名好的 SSL 证书。

```bash
keytool -import -alias ocp -file ocp.cer -keystore ocp.keystore -storetype PKCS12 -storepass Oceanbase4321
```

### 无公网 CA 证书或内网环境

若您没有公网 CA 证书，可以使用 `keytool` 生成自签名证书。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>自签名证书必须包含所有 OCP 实例的 IP 和域名到 SAN 扩展中，否则多节点间互访会失败。客户端需要将根证书加入信任列表后才能访问服务。</p>
</main>

#### 生成自签名证书

您可以使用以下脚本生成自签名证书和根证书。执行前请根据实际情况修改域名、IP 地址等配置信息。

```bash
#!/bin/bash
set -euo pipefail

# ===================== 配置区 =====================
domain="ocp.oceanbase.com"
ips="30.142.17.125"
root_password='root4321'
ocp_password="Oceanbase4321"
validity_days=3650
# ==================================================

# 检查 keytool 是否可用
if ! command -v keytool &> /dev/null; then
    echo "未找到 keytool，请先安装 JDK 并确认 JAVA_HOME 已正确设置。"
    exit 1
fi

echo "使用 keytool: $(which keytool)"
echo "Domain: ${domain}"
echo "IPs:    ${ips}"

# 构建 DN 和 SAN
dname="CN=${domain}"
san="SAN=DNS:${domain}"
for ip in ${ips}; do
    san="${san},IP:${ip}"
done

# ---------- 1. 生成根 CA 证书 ----------
echo ">>> [1/8] 生成根 CA 证书..."
keytool -genkeypair \
    -keyalg RSA -keysize 4096 \
    -dname "CN=OCP Root CA" \
    -alias root \
    -keystore root.keystore \
    -storetype PKCS12 \
    -storepass "${root_password}" \
    -ext BasicConstraints=CA:TRUE \
    -ext KeyUsage=keyCertSign,cRLSign

# ---------- 2. 生成 OCP Server 密钥对 ----------
echo ">>> [2/8] 生成 OCP TLS 密钥对..."
keytool -genkeypair \
    -keyalg RSA -keysize 4096 \
    -validity ${validity_days} \
    -dname "${dname}" \
    -alias ocp \
    -keystore ocp.keystore \
    -storetype PKCS12 \
    -storepass "${ocp_password}" \
    -ext "${san}"

# ---------- 3. 创建证书签名请求 (CSR) ----------
echo ">>> [3/8] 创建 CSR..."
keytool -certreq \
    -file server.csr \
    -alias ocp \
    -keystore ocp.keystore \
    -storepass "${ocp_password}" \
    -ext "${san}"

# ---------- 4. 用根 CA 签发服务器证书 ----------
echo ">>> [4/8] 根 CA 签发服务器证书..."
keytool -gencert \
    -infile server.csr \
    -outfile server.cer \
    -alias root \
    -keystore root.keystore \
    -storepass "${root_password}" \
    -ext "${san}" \
    -rfc

# ---------- 5. 导出根证书 (DER) ----------
echo ">>> [5/8] 导出根证书..."
keytool -exportcert \
    -file root.cer \
    -alias root \
    -keystore root.keystore \
    -storepass "${root_password}"

# ---------- 6. 将根证书导入 OCP keystore ----------
echo ">>> [6/8] 导入根证书到 OCP keystore..."
keytool -importcert \
    -file root.cer \
    -alias root \
    -keystore ocp.keystore \
    -storepass "${ocp_password}" \
    -noprompt

# ---------- 7. 将签发的服务器证书导入 OCP keystore ----------
echo ">>> [7/8] 导入已签发的服务器证书..."
keytool -importcert \
    -file server.cer \
    -alias ocp \
    -keystore ocp.keystore \
    -storepass "${ocp_password}"

# ---------- 8. 导出 PEM 格式根证书（客户端信任用）----------
echo ">>> [8/8] 导出 PEM 格式根证书..."
keytool -exportcert \
    -file root.pem \
    -alias root \
    -keystore root.keystore \
    -storepass "${root_password}" \
    -rfc

# ---------- 清理临时文件 ----------
rm -f server.csr server.cer root.cer

echo "证书生成完成！产出文件："
echo "  ocp.keystore  - OCP Server 使用（包含完整证书链）"
echo "  root.pem      - 客户端添加信任使用"
```

使用方法：

```bash
chmod +x gen_ocp_tls.sh
./gen_ocp_tls.sh
```

如果需要添加更多 IP，修改脚本顶部 `ips` 变量，空格分隔即可：

```bash
ips="30.142.17.125 10.0.0.1 192.168.1.100"
```

#### 信任根证书

使用自签名证书时，需要将根证书添加到 OBServer、OBProxy 所在机器的信任证书列表中，以保证 OB、Proxy、Agent 等组件能正常访问 OCP。

其中，`root.pem` 是根证书文件。

```bash
# RHEL 系
sudo cp root.pem /etc/pki/ca-trust/source/anchors/
sudo update-ca-trust

# Debian 系
sudo cp root.pem /usr/local/share/ca-certificates/root.crt
sudo update-ca-certificates

# SUSE 系
sudo cp root.pem /usr/share/pki/trust/anchors
sudo update-ca-certificates
```

## 为 OCP 加载 SSL 配置

有了载有证书的 keystore 后，需要在 OCP 中加载。假定条件如下：

* keystore 文件名为 `ocp.keystore`
* keystore 挂载在 OCP 容器内的 `/home/admin/data/keystore` 目录
* keystore 类型为 PKCS12
* key 的 alias 为 `ocp`
* keystore 的密码为 `store_pswd`
* key 的密码为 `key_pswd`（如没有密码则不设置）

在 OCP 对应的 MetaDB 中执行以下 SQL，设置 SSL 相关配置：

```sql
UPDATE `config_properties` SET `value`='8443' WHERE `key`='server.port';
UPDATE `config_properties` SET `value`='true' WHERE `key`='server.ssl.enabled';
UPDATE `config_properties` SET `value`='ocp' WHERE `key`='server.ssl.key-alias';
UPDATE `config_properties` SET `value`='key_pswd' WHERE `key`='server.ssl.key-password';
UPDATE `config_properties` SET `value`='/home/admin/data/keystore/ocp.keystore' WHERE `key`='server.ssl.key-store';
UPDATE `config_properties` SET `value`='store_pswd' WHERE `key`='server.ssl.key-store-password';
UPDATE `config_properties` SET `value`='PKCS12' WHERE `key`='server.ssl.key-store-type';

UPDATE `config_properties` SET `value`='https://<OCP访问地址>:8443' WHERE `key`='ocp.site.url';
```

通过 Docker 运行 OCP 时，还需要在容器启动参数中添加挂载 keystore 的参数。例如，keystore 所在宿主机目录为 `/data/ocp/keystore`，在启动 OCP 容器时添加以下参数：

```bash
-v /data/ocp/keystore:/home/admin/data/keystore
```

重启 OCP 后，OCP 会使用 HTTPS 协议监听在 8443 端口。
