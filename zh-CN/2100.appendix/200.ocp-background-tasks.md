# 后台任务列表

OCP V4.4.x 的后台任务分为两类调度形态：

* **任务引擎调度任务**：通过 OCP 任务引擎注册到 `task_definition`/`task_template` 表中，每次调度都会产生一条 `task_instance` 记录，并拆分为若干 `subtask_instance`。排查时可通过 `task_definition.id = task_instance.task_definition_id` 以及 `task_instance.id = subtask_instance.task_instance_id` 进行 join 查询。

* **配置化定时任务**：通过 OCP Server 配置文件 `ocp.task.scheduled.*` 配置段加载，由 Spring 调度器触发，不会在 `task_definition`/`task_instance` 表中生成记录，历史只能通过 OCP 日志排查。可以通过 `ocp.task.scheduled.<group>.<taskName>.enabled: false` 关闭单个任务。

旧版本中的 `dag_schedule`/`dag_instance` 两张表在 OCP V4.4.x 已下线，历史调度记录会自动迁移到 `task_definition`/`task_instance`，升级后请改用新表查询。

关于后台任务执行的日志，可以进入 `logging.file.name` 配置参数指定的 OCP 日志文件中，根据特定关键字搜索。OCP 日志文件默认为 `${user.home}/logs/ocp/ocp.log`，任务子进程日志目录为 `${user.home}/logs/task/`。

以下是常驻后台任务列表，包含任务名、任务描述、调度表达式、状态排查等信息，可用于 OCP 系统管理员的参考和问题排查。

| fixAlarmTarget | 修复告警目标元信息不一致的问题。 | `initialDelay: 60s, fixedDelay: 60s` | 告警目标相关表。 | “Fix alarm target” 相关日志。 |
| cleanPreCheckData | 清理 7 天前的 `precheck_status`、`precheck_context` 记录。 | `fixedDelay: 1d` | `precheck_status`、`precheck_context`。 | “Start cleaning precheck data older than 7 days”、“Deleted xx records from precheck_status table”、“Deleted xx records from precheck_context table”。 |
| BackupAlarmCheckSchedule | 备份恢复相关的告警检测器（数据备份失败、日志备份延迟、备份超时、长时间无成功备份、二级备份失败、agent 状态、存储容量、离线集群等）。 | `fixedRate: 1min` | 备份告警相关表；分布式锁名 `BackupAlarmCheckSchedule`。 | “Backup alarm check schedule.” 及各检测子项日志；失败打印异常调用栈，关键字 `BackupAlarmService`。 |

**调度表达式**

调度使用的如下格式的 Cron 表达式，包含了 6 位字段，如下：

```code
second, minute, hour, day of month, month, day(s) of week
```

对于配置化定时任务，除 Cron 之外还支持 `fixedDelay`（上次执行结束到下次开始的间隔）、`fixedRate`（两次开始时间之间的间隔）、`initialDelay`（首次执行前的等待时间）三种字段，时间单位默认为秒，可通过 `timeUnit: MINUTES|HOURS|DAYS` 指定。同时，将 `enabled` 置为 `false` 可关闭单个任务。

**Cron 表达式字段和取值**

|   **字段名**    |    **取值范围**    | **支持的特殊字符** |
|--------------|----------------|-------------|
| second       | 0-59           | ,-\*/       |
| minute       | 0-59           | ,-\*/       |
| hour         | 0-23           | ,-\*/       |
| day of month | 1-31           | ,-\*/?      |
| month        | 1-12 或 JAN-DEC | ,-\*/       |
| day of week  | 1-7 或 MON-SUN  | ,-\*/?      |

**表达式示例：**

|          **表达式**           |                              **说明**                               |
|----------------------------|-------------------------------------------------------------------|
| **0 0 \* \* \* \***        | “0 秒 0 分” - 每小时运行一次，在 0 秒 0 分启动。                                  |
| **\*/10 \* \* \* \* \***   | 每 10 秒钟运行一次。                                                      |
| **0 0 8-10 \* \* \***      | 每天的 8、9 和 10 点钟运行一次，在 0 秒 0 分启动。                                 |
| **0 0/30 8-10 \* \* \***   | 每天 8:00、8:30、9:00、9:30、10:00 和 10:30 运行。                       |
| **0 0 9-17 \* \* MON-FRI** | 从周一到周五的上午 9 点到下午  5 点运行。                                          |
| **0 0 9-17 \* \* 1-5**     | 从周一到周五的上午 9 点到下午 5 点运行，使用数字表达周几，1 代表周一，7 代表周日。与 `crontab` 的表达式稍有不同。 |
| **0 0 0 25 12 ?**          | 每年 12/25 日凌晨 0 点 0 分 0 秒。                                        |
