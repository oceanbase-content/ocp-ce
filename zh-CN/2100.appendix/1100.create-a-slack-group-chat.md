# 创建 Slack 群聊并获取 Webhook 地址

在通过 Slack 通道发送告警消息前，需要先在 Slack 上获取自定义机器人 Webhook 地址。本文介绍如何获取 Slack 中的 Webhook 地址，并关联 Slack 群组。

## 操作步骤

### 步骤一：创建 Slack 频道

1. 进入 [Slack 官网](https://slack.com) 或者 Slack 桌面版。

2. 点击左侧 **频道** > **创建频道**，创建一个用于接收告警通知的 Slack 频道（类似一个群聊）。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01271050.png)

   频道创建成功页面如下。

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261659.png)

### 步骤二：添加 Incoming Webhook 应用

1. 在 Slack 中单击 **应用**，搜索 **Incoming Webhooks**，并前往应用。

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261700.png)

2. 在通道配置页面，选择 **步骤一** 中创建的 Slack 频道，单击 **Add Incoming WebHook Integration** 进行关联。

   ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261701.png)

### 步骤三：获取 WebHook URL

1. 关联成功后，Incoming Webhook 将自动生成 **WebHook URL**，如：`https://hooks.slack.com/services/xxx/xxx`。您可参考 Sending Messages 中的说明，选择使用任意一种告警消息格式。

   ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261702.png)

2. 执行如下脚本进行测试，检验告警消息是否可以正常发送到 Slack 群聊中。

    ```bash
    # https://hooks.slack.com/services/XXXX 为子步骤 3 中生成的 WebHook URL
    curl -X POST -H 'Content-type: application/json' \
    --data '{"text":"Hello, World!"}' \
    https://hooks.slack.com/services/XXXX
    ```

    当测试结果中输出：`ok`，并且在群聊中有 **Hello, World!** 语句时，代表 WebHook 连接正常，并且 Slack 群聊正常关联 WebHook。

    ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261415.png)
