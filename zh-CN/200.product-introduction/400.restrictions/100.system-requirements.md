# 系统要求

本​页面为您介绍 OceanBase 云平台的系统要求，包括：硬件要求、软件要求、操作系统要求和客户端要求。

## 硬件要求

OCP-Server 可以安装在物理机上，也支持安装运行在 Docker 容器中。OCP-Server 支持多节点高可用部署模式。

OCP-Server 节点最低硬件要求如下表所示。

| **硬件** | **要求**                                          |
|--------|-------------------------------------------------|
| CPU    | <li>X86_64，8 核</li><li>ARM aarch 64 架构，8 核</li> |
| 内存     | 可用内存 24G                                        |
| 网卡     | 万兆网卡                                            |


## 软件要求

### OCP-Server 软件要求

如果您通过 Docker 镜像方式安装 OCP，则相关依赖的软件已包含在 Docker 镜像包内。

如果您通过 RPM 方式安装 OCP，则其软件要求如下表所示。

| **软件** | **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Version">版本</UI-TERM>** |
|--------|-----------------------------------------------------------------------------|
| JDK    | Oracle JDK（17 及以上版本）或 Open JDK（17 及以上版本）                                    |
| Python | 3.8 及以上版本                                                                   |
| compat-openssl10 | 1.0.2 及以上版本                                                                 |
| openssh-clients | 8.0 及以上版本                                                                   |

为了方便排查问题，还推荐安装以下软件包：

```javascript
apt install -y wget
apt install -y unzip
apt install -y less
apt install -y vim
apt install -y obclient
apt install -y net-tools
apt install -y strace
apt install -y lsof
apt install -y nmap-ncat
```

### OCP-Agent 软件要求

在安装 OCP-Agent 时，会包含一些第三方软件包，这些第三方软件包会安装到 /home/admin/ocp_agent/site-packages/目录。

|---------|----------|

| Firefox | 78       |

### 显示器要求

为了具备最佳的使用体验，推荐使用分辨率大于 1440 x 810 的显示器。
