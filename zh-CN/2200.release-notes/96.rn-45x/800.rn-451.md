# OCP V4.5.1

OCP V4.5.1 面向复杂生产环境补强日常管控能力，重点解决高风险操作依赖人工经验、备份存储难以分层规划、租户容量问题发现偏晚等实际问题。

## 版本亮点

### 标准运维流程
新增标准运维流程，将复杂、风险较高的操作整理成可保存、可执行、可追踪的运维任务，减少人工确认步骤和操作遗漏。

本期内置以下流程：

+ 重建备租户
+ 副本异常时开启仲裁服务
+ OBServer 异常后的数据重建

运维人员可以查看每一步的执行进度，并在失败后重试。重建备租户支持已纳管的跨 OCP 主备租户场景；其他两类流程仅支持当前 OCP 管理的集群。

### 备份数据与归档日志分离存储
OceanBase 4.x 集群支持为备份数据和归档日志设置不同的存储位置，可按可靠性、容量和成本选择文件存储或对象存储。该能力覆盖备份策略、立即备份、备份扫描和租户恢复。

原有共用存储方式保持不变。需要使用分离存储时，建议先完成整套 OCP 升级，再启用新配置。

### Unit 数据盘配额
Shared-Nothing 集群的 Unit 规格支持设置数据盘配额，并在租户和资源视图中展示使用情况。使用率达到 80% 和 90% 时，系统分别产生警告和严重告警，便于在容量不足前安排扩容或数据治理。

该配额属于软限制，超过配额不会中断业务写入；适用于 OceanBase 4.0 及以上版本。

## 其他新增与优化

+ 备租户支持设置日志恢复延迟，并提供延迟状态监控与告警。
+ 新增日语界面，覆盖告警、监控、巡检、参数配置等主要产品文案。
+ 扩展透明数据加密场景下的 KMS 适配，新增阿里云专有云、信安世纪、江南科友（金融）等方案，并完善格尔 KMS 的 HTTPS 接入能力。
+ 软件包支持 SHA256 校验，并增加上传数量和总容量限制。
+ 告警事件增加资源标签，长事务告警补充日志流信息，便于定位具体租户和日志流。
+ SQL 查询接口支持指定数据库用户，便于按现有账号权限执行查询。
+ 新增全局备份信息解析和离线恢复接口，便于自动化恢复流程对接。
+ 优化 OCP 与 Agent 资源监控、实时监控查询和多语言搜索体验。

## 行为变更与适用范围

### 行为变更
+ 不再支持克隆主租户；备租户克隆能力不受影响。
+ 软件包上传增加数量和总容量限制，超过限制时系统会阻止上传。

### 适用范围
+ 数据与日志分离存储适用于 OceanBase 4.x 集群；OceanBase 3.x 集群继续使用同一存储位置。
+ Unit 数据盘配额适用于 Shared-Nothing 集群，不适用于 Shared-Storage 和 OceanBase AI 集群。
+ 开启备租户日志恢复延迟要求 OceanBase 4.4.2.2 及以上版本；取消延迟要求 OceanBase 4.4.1.9 及以上版本。

## 主要修复问题

+ 修复主备租户切换、恢复源调整和延迟恢复场景中的部分异常，提高跨集群容灾操作的稳定性。
+ 修复备份存储识别、日志备份检查和部分恢复场景中的问题。
+ 修复 AI 集群和 LogService 在停止 Zone、密钥轮转及任务回滚时的部分异常。
+ 修复实时监控查询慢、部分主机监控数据缺失以及 Agent 资源指标展示异常等问题。
+ 修复 Oracle 租户查询结果时间类型异常，以及数据库名称大小写导致索引信息为空的问题。
+ 修复 SOP 的权限校验、操作对象识别、任务重试和页面展示等问题。

修复若干权限校验、输入校验和敏感信息保护问题，建议升级到本版本。
