# 主机资源

本页面为您介绍部署 OCP 的资源要求，仅用于快速上手，如需在测试和生产环境中部署 OCP 请参考 [部署数据库](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000004475420)。

在企业版 OCP 部署中，通常采用 Docker 容器化方式；而社区版 OCP 则以 RPM 包形式部署。两种版本均可将 OCP-Server、MetaDB 和 MonitorDB 部署在同一台物理主机上。其中，MetaDB 和 MonitorDB 可配置为同一 OceanBase 集群中的不同租户。

主机总资源需求的计算公式如下：

**主机资源总量** = **OCP-Server 资源** + **MetaDB 租户资源** + **MonitorDB 租户资源** + **SYS 租户资源** + **System_Memory 资源** + **操作系统内核预留**（总资源的 20%，建议根据主机实际资源情况进行配置）。

## 硬件要求

OCP-Server 节点最低硬件要求如下表所示。

| **硬件** |     **最低要求**     |
|--------|--------|
| CPU    | <ul><li>单节点 OCP：<ul><li>X86_64，8 核</li><li>ARM aarch 64 架构，8 核</li></ul></li><li>高可用 OCP：<ul><li>X86_64，24 核</li><li>ARM aarch 64 架构，24 核</li></ul></li></li></ul> |
| 内存     | 可用内存 64 GiB      |
| 网卡     | 万兆网卡    |

## 操作系统要求

|  **服务器类型**  | **操作系统**  |  **支持版本**  |
|-------------|-----------|------------|
| x86_64      | RHEL      | 7.2 及以上版本  |
| x86_64      | CentOS    | 7.2 及以上版本  |
| x86_64      | AliOS     | 7.2 及以上版本  |
| x86_64      | openSUSE  | 12 SP3 及以上 |
| ARM aarch64 | AliOS     | 7.2 及以上版本  |
| ARM aarch64 | 中标麒麟      | 7.6        |
| ARM aarch64 | 华为 EulerOS | 2.0 SP8    |

## 示例

以管理 10 台业务 OBServer 节点所需的资源为例，所需资源如下：

|    容器分类    |       部署内容       | CPU（核） | 内存（GiB） |
|------------|------------------|--------|--------|
| OCP 容器            | OCP-Server       | 8      | 16     |
| OceanBase 容器      | MetaDB 租户    | 4      | 8      |
| OceanBase 容器      | MonitorDB 租户 | 4      | 16     |
| OceanBase 容器      | SYS 租户           | 5      | 28     |
| OceanBase 容器      | System_Memory   | 0      | 0     |

<main id="notice" type='explain'>
<h4>说明</h4>
<p><li>System_Memory 的内存容量默认为 0，表示系统会自动根据内存情况来调整内存使用策略，详情可参考 <a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002015843">system_memory</a>。</li>
<li>主机所需资源为 <strong>部署内容</strong> 列所有资源的累加值。如以上内容部署在一个 32C 192GiB 的物理机上，需将该物理机隔离为两个容器，分别运行 OCP-Server 和 OCP 依赖的 OceanBase 集群（MetaDB 租户、MonitorDB 租户和 SYS 租户）。</li></p>
</main>

|     部署单元      | 监听端口 | 协议类型 |  监听端口修改方式  |   备注       |
|---------------|------|------|-----------------|-------------|
| OCP-Server    | 8080 | http | 修改 OCP 系统参数 `server.port`，重启生效。 | OCP-Server web 服务监听端口，通常其它组件通过 SLB/DNS 地址访问 OCP-Server。 |
