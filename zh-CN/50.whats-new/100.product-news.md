# 产品动态

OCP 4.4.1 版本重磅发布！本版本全面升级 OceanBase 集群管理平台核心能力，为企业用户提供更稳定、更高效、更安全的数据库管理体验。

## 核心亮点

* **内核适配增强**：支持备租户克隆快速搭建测试环境、外表实现多源数据集成、ODPS Catalog 统一数据视图、Java UDF 自定义业务逻辑、非对称 Zone 动态资源调整等核心能力。
* **智能监控升级**：支持告警概览以及 200+ 告警智能解读能力，帮助用户发掘告警规律，提升告警处理效率。
* **安全能力强化**：TDE 加密适配三未信安、江南天安等第三方厂商的 KMS 服务。
* **增强平台化运维**：新增定时运维任务自动化和 OCP 自监控能力，满足企业级运维的标准化、自动化需求。

### 关键特性解读

### JVM 环境依赖服务

自 V4.3.5 BP1 版本开始，OceanBase 通过 JNI（Java Native Interface）桥接框架，实现了 C++ 与 Java 生态的无缝对接。基于 JNI 框架，OceanBase 已全面支持 ODPS 外表、HDFS 外表、Java UDF、ODPS Catalog 以及 MySQL 外表插件等功能，确保用户可以直接访问阿里云 MaxCompute 数据仓库及分布式文件系统，并利用 Java 编写的用户自定义函数，实现更灵活的数据处理和集成能力。

为了降低用户部署和运维复杂度，OCP 提供了全生命周期管理能力。在集群安装部署和运维管理阶段支持上传 jar 包、选择支持的服务类型、JVM 内存配置、升级时 jar 包兼容性检查、集群扩容时自动开启服务、以及灵活的变更或关闭服务等操作。

通过 OCP 的可视化运维能力，可以大幅降低部署门槛和用户的日常运维负担。同时这套技术方案既保留了 OBServer C++ 的高性能优势，又集成了 Java 生态的丰富资源，真正实现了 “高性能、易管理、强扩展” 的技术平衡，为企业构建现代数据平台提供了坚实的技术支撑。

#### 注意事项

* 开启/关闭 JVM 环境依赖服务需要重启集群。
* 确保集群内各主机预留充足内存资源，以保障服务稳定运行，避免因内存不足导致异常。
* 需提前通过软件包管理工具上传相关服务依赖的 jar 包库，确保 OBServer 可正常加载使用。
* JVM 环境依赖服务依赖 Java 环境，若集群下存在机器尚未配置 Java 环境，请自行配置，并确保 JDK 满足如下要求：
  * x86/x86_64 架构主机需安装 JDK 11 或更高版本。
  * ARM64（aarch64）架构主机需安装 JDK 15 或更高版本。

### 定时任务

在日益复杂的数据库运行环境中，OceanBase 数据库通过定时发起合并操作和在特定时间窗口收集统计信息，有力保障了系统的稳定性。然而，数据库始终处于动态变化之中——租户的持续转储行为、表的频繁 DML 操作不断更新着统计信息。在部分极端场景下，由于 LSM 树架构的特性，数据更新若未能及时感知，可能引起显著的 “读放大” 效应；同时，过期的统计信息会严重影响查询优化器对执行计划的精准判断，最终导致数据库整体响应延迟上升，对业务连续性构成威胁。

针对这一挑战，OCP 推出了定时任务管理功能。该功能依托智能调度引擎，提升运维操作自动化水平。用户可以根据业务运行规律，灵活配置多种关键任务的执行策略，包括租户合并、合并后统计信息收集以及表级别统计信息收集等。用户可以通过业务运行规律设置调度策略与调度过期策略，让运维时序更加贴合业务节奏。同时 OCP 提供了完整的任务全生命周期管理能力，可以便捷地开启或禁用定时任务，支持任务的强制执行、参数编辑、任务复制和删除操作，并能够随时查看详细的任务运行记录。通过自动化调度与智能优化，OCP 定时任务可以保障系统运行的稳定高效，帮助用户构建更加智能、自适应的运维新范式。

### 新功能

#### 基础运维

* **集群管理**：

  * 支持开启/关闭 JVM 环境依赖服务，方便用户使用 ODPS 外表/HDFS 外表/Java UDF/ODPS Catalog/MySQL 外表插件等功能。
  * 新增 Zone 以及升级集群的场景下支持用户在 Zone 级别选择不同软件包类型（EL7/EL8/AL8），同时支持部署 EL8 类型软件包的集群平滑升级至 EL7/AL8。
  * TDE 透明加密功能适配三未信安、江南天安等第三方厂商的 KMS 服务，为用户提供更强大的数据保护方案，支持的 OceanBase 版本范围为：[V4.2.5.4, V4.3.0.0)、[V4.3.5.2, +∞)）。
  * 支持在接管集群时配置 OCP Agent 的端口和规格配置。

* **租户管理**：

  * 支持非对称 Zone 功能，实现租户在不同 Zone 间的 Unit 个数差异化配置。该功能存在如下限制要求：
    * 各 Zone 内租户的全功能副本 Unit 数量不允许超过 2 种。
    * 支持的 OceanBase 版本范围为 [V4.2.5.5, V4.3.0.0)、[V4.4.2.0, V4.5.0.0)。
  * 支持备租户克隆，满足特定行业生产和测试环境属于同一套集群且需频繁做 DDL 变更的业务场景。
  * 创建 Oracle 类型租户时支持设置特定字符序。
  * 副本详情支持删除指定 Unit，支持的 OceanBase 版本范围为：[V3.0.0.0, V4.0.0.0)。
  * 副本详情支持删除指定 Unit Group，支持的 OceanBase 版本范围为：[V4.0.0.0, +∞)。

* **主机管理**：支持在添加主机时配置 OCP Agent 的端口和规格。

#### 监控告警

* 支持告警概览功能，提供全面的告警统计与分析能力，支持以时间维度、类型维度等多角度分析，帮助用户深度挖掘告警规律，实现主动运维。
* AI 助手支持智能解读 200+ 告警类型，帮助运维人员快速理解告警含义，减少告警分析时间。使用该功能时，请确保 OCP 的 MonitorDB 为 V4.3.5 BP3 及以上版本。
* 支持向量内存指标：占用大小、使用大小、使用限制、使用率展示以及向量使用率告警能力，支持的 OceanBase 版本范围为 [V4.3.5.3, V4.4.0.0)、[V4.4.1.0, +∞)。
* 支持在告警通道内设置恢复消息聚合能力，降低恢复消息数量。
* 实现在无法自动消除的告警详情页面新增解决功能。
* 新增支持 Slack 类型告警通道，方便系统推送告警信息至指定的 Slack 工作区。

### 主备租户容灾管理

* 实现级联和一主多备场景下支持基于网络和基于归档模式的灵活配置能力，方便用户构建更合适的数据同步方案。
* 当主租户无 standbyro 用户时，支持用户手动设置 standbyro 密码。
* 容灾切换时支持展示/复制原主租户服务名，方便用户故障演练时复制原主租户服务名，进而保持连接串不变。

### 运维管理

支持定时任务管理能力，包括创建定时运维任务，实现租户合并以及统计信息收集等任务类型，并支持对相关任务进行编辑、复制、查看等运维操作。

#### Binlog 管理

创建 Binlog 集群时支持设置 MetaDB 的访问地址和端口，避免单节点故障风险，提升系统高可用能力。

#### 备份恢复

* 支持对阿里云对象存储 OSS 设置高级属性 checksum_type，取值为 `md5`（默认）或 `no_checksum`。
* 支持对阿里云对象存储 OSS 设置合规保留策略 WORM（Write Once Read Many）特性，满足用户以不可删除、不可篡改的方式保存和使用数据。
* 支持查看物理备份自动清理记录（近 90 天）。

### 平台化能力

**系统管理** 支持 OCP 自身 10+ 监控指标展示，以及状态异常时的告警能力。

### 产品优化

#### 集群管理

* 集群 **概览** > **Zone 列表** 增加软件包类型（EL7/EL8/AL8）展示。
* 创建集群时前置预检查步骤，方便用户提前排查和解决集群创建的阻塞点。
* 对于内核临时版本增加风险提示 “当前集群基于非正式软件包（POC 或者调试所用）构建，该版本未经过完整测试验证，可能存在兼容性漏洞、功能缺陷或安全风险，进而导致服务异常、数据损坏等问题，同时本集群不支持升级至正式版。请务必采用正式发布版本以保障系统稳定。”，支持的 OceanBase 版本范围为 [V4.2.1.0, +∞)。
* 在 OBKV/Redis/HBase 性能监控界面增加提示语 “集群概览-更多-运维配置-参数管理-性能监控参数中确认 monagent.pipeline.obkv.collect.disabled 的值是否为 false。”。
* 修复特定场景下 datafile_next=0 时，OCP 数据盘大小显示仍取值 datafile_maxsize 而非 datafile_size 的问题，确保白屏界面显示与实际创建逻辑一致。

#### 租户管理

* **合并管理**：备租户增加合并设置提示 “备租户不支持独立合并，设置合并时间仅影响其转换为主租户之后的合并调度时间。”。
* **数据库管理**：MySQL 模式下创建数据库支持 REFERENCES、EXECUTE 权限类型。
  * REFERENCES 权限支持的 OceanBase 版本范围：[V4.2.4.0, V4.3.0.0)、[V4.3.3.0, +∞)。
  * EXECUTE 权限支持的 OceanBase 版本范围：[V4.2.2.0, V4.3.0.0)、[V4.3.2.0, +∞)。

#### 主机管理

新增配置 clockdiff 命令执行时 timeout 的参数 `ocp.host.clockdiff.timeout.millis`，参数值默认为 30 秒，避免特殊场景下预检查步骤失败。

### OBProxy 管理

OBProxy 集群 **概览** 页面增加软件包类型（EL7/EL8/AL8）展示。

### Binlog 服务

* 创建 Binlog 集群时前置预检查项目，方便用户提前排查和解决集群创建的阻塞点。
* 支持在 Binlog 集群 **概览** 页面展示 Binlog 集群的访问地址。

#### 其他

* 优化 OceanBase 主备租户与 OCP 多集群跨时区管理，确保不同区域时间展示正确，保障跨国业务连续性。
* **系统管理** > **用户管理** 中，用户以及角色名支持中划线（-）。
* **告警中心** 中，**告警通道** > **新建通道** > **自定义脚本** 的接收人字段增加可选字样，避免影响客户配置；禁止编辑/复制物化视图相关告警规则的检测规则。
* **备份恢复** 中，支持通过参数 `backup.dump.physical.file.timeout` 设置 OCP Agent 解析备份集超时时间，参数值默认为 30 秒。

### 产品行为变更

**自治服务** 变更为 **诊断服务**。
