# 参数模板

参数模板用于管理和批量应用 Logservice 集群的参数配置。您可以创建参数模板，定义一组参数值，然后在新建集群时选择应用该模板。

<main id="notice" type='notice'>
<h4>说明</h4>
<p>参数模板仅在 <b>新建集群</b> 时可选择应用。集群创建后，无法再通过参数模板修改参数，只能通过 <b>参数管理</b> 功能单独修改集群参数。</p>
</main>

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Logservice 管理** 资源权限。
* Logservice **参数模板** 菜单权限。

## 查看参数模板列表

1. 登录 OCP。

2. 在左侧导航栏中，选择 **Logservice 实例**。

3. 单击 **参数模板** 标签页，进入参数模板列表页面。

   在参数模板列表中，您可以查看以下信息：

   | 信息项 | 说明 |
   |-------|------|
   | 模板名称 | 参数模板的名称 |
   | 参数数量 | 模板中包含的参数数量 |
   | 备注 | 模板的描述信息 |
   | 创建人 | 创建模板的用户 |
   | 最后修改时间 | 上次修改模板的时间 |
   | 最后修改人 | 上次修改模板的用户 |

## 创建参数模板

1. 在参数模板列表页面，单击 **新建模板**。

2. 在新建模板对话框中，填写以下信息：

   | 信息项 | 说明 |
   |-------|------|
   | 模板名称 | 输入模板的名称。 |
   | 备注（可选） | 输入模板的描述信息。 |

3. 单击 **确定**，进入模板详情页面。

4. 在模板详情页面，添加需要管理的参数及其值：

   | 信息项 | 说明 |
   |-------|------|
   | 参数名 | 选择需要配置的参数。 |
   | 参数值 | 输入该参数的值。 |
   | 取值类型 | 显示参数的取值类型。 |
   | 取值范围 | 显示参数的允许取值范围。 |

5. 单击 **+ 添加参数**，可继续添加更多参数。

6. 完成参数配置后，单击 **新建**。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>如需删除已添加的参数，可单击对应参数行的 <b>删除</b> 操作按钮。</p>
</main>


创建参数模板后，您可以在新建 Logservice 集群时选择应用该模板。具体操作详见 [创建 Logservice 集群](300.manage-a-logservice-cluster/200.create-a-logservice-cluster.md)



## 相关操作

### 编辑参数模板

1. 在参数模板列表中，找到需要编辑的模板。

2. 单击模板名称，进入模板详情页面。

3. 您可以执行以下操作：

   * **修改参数值**：直接修改已有参数的参数值。
   * **添加参数**：单击 **+ 添加参数**，选择新的参数并设置值。
   * **删除参数**：单击参数行中的 **删除** 按钮，移除不需要的参数。
   * **修改备注**：在模板信息区域修改模板的备注信息。

4. 完成修改后，单击 **保存**。

### 复制参数模板

1. 在参数模板列表中，找到需要复制的模板。
2. 单击模板所在行的 **更多** 图标，或右键单击该模板。
3. 在操作菜单中，选择 **复制**。
4. 在弹出的复制对话框中，填写以下信息：

   | 信息项 | 说明 |
   |-------|------|
   | 模板名称 | 输入复制后模板的名称。 |
   | 备注（可选） | 输入模板的描述信息。 |

5. 单击 **确定**，完成模板复制。

### 删除参数模板

1. 在参数模板列表中，找到需要删除的模板。

2. 单击模板所在行的 **更多** 图标，或右键单击该模板。

3. 在操作菜单中，选择 **删除**。

4. 在确认弹窗中，确认删除操作。

   <main id="notice" type='explain'>
   <h4>说明</h4>
   <p>删除参数模板后，该模板将无法恢复。请确保该模板不再被任何集群使用。</p>
   </main>
