# 性能监控

在 Logservice 集群的性能监控页面，您可以查看集群的各项性能指标，包括日志接收、存储和 GC、线程池、资源监控等信息，帮助您了解集群的运行状态和性能瓶颈。

性能监控页面包含以下标签页：

::::tab
tab 日志监控
tab 性能监控
tab 存储和GC
tab 线程池
tab 资源监控
:::

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Logservice 只读** 资源权限。
* Logservice **性能监控** 菜单权限。

## 查看性能监控

1. 登录 OCP。

2. 在左侧导航栏中，选择 **Logservice 实例**。

3. 在集群列表中，单击目标集群名称进入集群详情页面。

4. 在左侧导航栏中，选择 **性能监控**。

   系统显示性能监控页面。

5. 您可以通过页面上方的筛选器选择查看范围：

   * **Zone**：选择要查看的 Zone，支持选择全部 Zone。
   * **LogServer**：选择要查看的 LogServer 节点，支持选择全部节点。
   * **时间范围**：选择查看的时间范围，如 1h、3h、12h 等。

6. 单击不同的标签页查看相应的性能指标。

## 时间范围

性能监控页面默认显示最近一段时间的数据。您可以通过页面上方的刷新按钮下方的时间选择器调整显示的时间范围，支持 1h、3h、12h 等选项。

<main id="notice" type='notice'>
<h4>说明</h4>
<p>性能指标数据可能存在一定的采集延迟，如果发现数据异常，请等待一段时间后刷新页面。</p>
</main>

## 导航栏操作

在性能监控页面，左侧导航栏包含以下功能：

* **功能介绍**：查看 Logservice 功能说明。
* **概览**：查看集群基本信息，详情参见 [Logservice 集群概览](../300.logservice-cluster-overview.md)。
* **性能监控**：当前页面，查看集群性能监控数据。
* **参数管理**：管理集群参数配置，详情参见 [参数管理](../500.logservice-parameter-management.md)。
