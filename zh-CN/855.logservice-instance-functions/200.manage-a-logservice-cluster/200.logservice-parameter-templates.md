# 参数模板

参数模板用于管理和批量应用 Logservice 集群的参数配置。您可以创建参数模板，定义一组参数值，然后将该模板应用到多个 Logservice 集群。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Logservice 管理** 资源权限。
* Logservice **参数模板** 菜单权限。

## 查看参数模板列表

1. 登录 OCP。

2. 在左侧导航栏中，选择 **Logservice 实例**。

3. 单击 **参数模板** 标签页，进入参数模板列表页面。

   在参数模板列表中，您可以查看以下信息：

   | 信息项 | 说明 |
   |-------|------|
   | 模板名称 | 参数模板的名称 |
   | 参数数量 | 模板中包含的参数数量 |
   | 备注 | 模板的描述信息 |
   | 创建人 | 创建模板的用户 |
   | 最后修改时间 | 上次修改模板的时间 |
   | 最后修改人 | 上次修改模板的用户 |

## 创建参数模板

1. 在参数模板列表页面，单击 **新建模板**。

2. 在新建模板对话框中，填写以下信息：

   * **模板名称**：输入模板的名称。
   * **备注**：输入模板的描述信息。

3. 单击 **确定**，创建空白模板。

4. 在模板详情页面，添加需要管理的参数及其值。

## 应用参数模板

创建参数模板后，您可以将其应用到 Logservice 集群。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>应用参数模板会覆盖集群当前的参数值，请谨慎操作。建议在非高峰期进行参数变更，并提前备份当前配置。</p>
</main>

## 相关操作

* 创建参数模板：定义参数模板及其默认值。
* 编辑参数模板：修改模板中的参数值。
* 删除参数模板：删除不再使用的模板。
* 应用参数模板：将模板参数应用到集群。
