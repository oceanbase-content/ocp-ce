# 参数模板

参数模板用于管理和批量应用 Logservice 集群的参数配置。您可以创建参数模板，定义一组参数值，然后将该模板应用到多个 Logservice 集群。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Logservice 管理** 资源权限。
* Logservice **参数模板** 菜单权限。

## 查看参数模板列表

1. 登录 OCP。

2. 在左侧导航栏中，选择 **Logservice 实例**。

3. 单击 **参数模板** 标签页，进入参数模板列表页面。

   在参数模板列表中，您可以查看以下信息：

   | 信息项 | 说明 |
   |-------|------|
   | 模板名称 | 参数模板的名称 |
   | 参数数量 | 模板中包含的参数数量 |
   | 备注 | 模板的描述信息 |
   | 创建人 | 创建模板的用户 |
   | 最后修改时间 | 上次修改模板的时间 |
   | 最后修改人 | 上次修改模板的用户 |

## 创建参数模板

1. 在参数模板列表页面，单击 **新建模板**。

2. 在新建模板对话框中，填写以下信息：

   | 信息项 | 说明 |
   |-------|------|
   | 模板名称 | 输入模板的名称。 |
   | 备注（可选） | 输入模板的描述信息。 |

3. 单击 **确定**，进入模板详情页面。

4. 在模板详情页面，添加需要管理的参数及其值：

   | 信息项 | 说明 |
   |-------|------|
   | 参数名 | 选择需要配置的参数。 |
   | 参数值 | 输入该参数的值。 |
   | 取值类型 | 显示参数的取值类型。 |
   | 取值范围 | 显示参数的允许取值范围。 |

5. 单击 **+ 添加参数**，可继续添加更多参数。

6. 完成参数配置后，单击 **新建**。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>如需删除已添加的参数，可单击对应参数行的 <b>删除</b> 操作按钮。</p>
</main>

## 应用参数模板

创建参数模板后，您可以将其应用到 Logservice 集群。具体操作步骤如下：

1. 在参数模板列表中，找到需要应用的模板。

2. 单击模板所在行的 **更多** 图标，或右键单击该模板。

3. 在操作菜单中，选择 **应用到集群**。

4. 在弹出的集群选择对话框中，勾选需要应用该模板的目标集群。

5. 单击 **确定**，开始应用参数模板。

6. 系统会显示应用进度，应用完成后，您可以在集群详情页面查看最新的参数配置。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>应用参数模板会覆盖集群当前的参数值，请谨慎操作。建议在非高峰期进行参数变更，并提前备份当前配置。</p>
</main>

## 相关操作

### 创建参数模板

1. 在参数模板列表页面，单击 **新建模板**。

2. 在新建模板对话框中，填写模板名称和备注信息。

3. 单击 **确定**，进入模板详情页面。

4. 在模板详情页面，添加需要管理的参数及其值。

5. 单击 **+ 添加参数**，可继续添加更多参数。

6. 完成参数配置后，单击 **新建**。

### 编辑参数模板

1. 在参数模板列表中，找到需要编辑的模板。

2. 单击模板名称，进入模板详情页面。

3. 您可以执行以下操作：

   * **修改参数值**：直接修改已有参数的参数值。
   * **添加参数**：单击 **+ 添加参数**，选择新的参数并设置值。
   * **删除参数**：单击参数行中的 **删除** 按钮，移除不需要的参数。
   * **修改备注**：在模板信息区域修改模板的备注信息。

4. 完成修改后，单击 **保存**。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>修改参数模板不会自动应用到已关联的集群，您需要手动执行应用操作。</p>
</main>

### 删除参数模板

1. 在参数模板列表中，找到需要删除的模板。

2. 单击模板所在行的 **更多** 图标，或右键单击该模板。

3. 在操作菜单中，选择 **删除**。

4. 在确认弹窗中，确认删除操作。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>删除参数模板后，该模板将无法恢复。请确保该模板不再被任何集群使用。</p>
   </main>

### 应用参数模板

1. 在参数模板列表中，找到需要应用的模板。

2. 单击模板所在行的 **更多** 图标，或右键单击该模板。

3. 在操作菜单中，选择 **应用到集群**。

4. 在弹出的集群选择对话框中，勾选需要应用该模板的目标集群。

5. 单击 **确定**，开始应用参数模板。

6. 系统会显示应用进度，应用完成后，您可以在集群详情页面查看最新的参数配置。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>应用参数模板会覆盖集群当前的参数值，请谨慎操作。建议在非高峰期进行参数变更，并提前备份当前配置。</p>
</main>
