# 新建 Logservice 集群

本文介绍如何在 OCP 中新建 Logservice 集群。

    <a href="../100.logservice-cluster-list.md">Logservice 集群列表</a>
    <a href="../../150.parameter-templates/200.logservice-parameter-templates.md">参数模板</a>
    <a href="../300.logservice-cluster-overview.md">Logservice 集群概览</a>
</p>

## 前提条件

* 当前登录用户需具备 **Logservice 管理** 资源权限。
* 已有可用的主机资源，详情参见 [主机资源要求](../../300.deployment-guide/100.deploying-enterprise-ocp/200.prepare-the-deployment-environment/200.standardized-host.md)。
* 已在 OCP 中上传 Logservice 软件包，详情参见 [上传软件包](../../1500.manage-software-packages/100.manage-software-packages.md)。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中，选择 **Logservice 实例**。

3. 在 **集群列表** 标签页，单击右上角的 **新建 Logservice 集群**。

4. 在新建集群页面，配置以下信息：

### 基本信息

| 配置项 | 说明 |
|-------|------|
| Logservice 集群名称 | 输入集群名称。命名规则：仅支持字母开头；字母或数字结尾；支持 2-32 个字符；特殊符号仅支持下划线。 |
| Logservice 版本 | 选择 Logservice 软件版本。 |

### 部署模式

配置 Logservice 集群的部署信息：

| 配置项 | 说明 |
|-------|------|
| Zone | 选择 Zone 名称，如 zone1、zone2、zone3。 |
| Region | 选择该 Zone 所属的 Region。 |
| 机型（可选） | 选择机器的机型。 |
| CPU 架构 | 选择 CPU 架构，如 x86_64。 |
| 主机 | 选择部署 Logservice 的主机。 |
| 软件包类型 | 选择操作系统软件包类型，如 el7。 |

<main id="notice" type='explain'>
<h4>说明</h4>
<p>Logservice 集群目前仅支持 1-1-1 部署形态，即部署 3 个 Zone，每个 Zone 部署一个 LogServer 节点，不支持其他部署形态。</p>
</main>

### 数据存储

| 配置项 | 说明 |
|-------|------|
| 对象存储配置 | 选择对象存储服务（如阿里云 OSS）。 |
| 存储目录 | 配置对象存储的路径，如 s3://bucket/data/1。 |

### 参数配置

根据需要勾选 **对集群的启动、运行参数等进行定制化修改**。勾选后，您可以在后续步骤中配置集群参数。

### 自定义配置

根据需要勾选 **支持执行集群级别用户配置（如操作系统属主用户）、路径设置（如软件安装路径、本地存储路径）**。

### 用户配置

| 配置项 | 说明 |
|-------|------|
| 操作系统属主用户 | Logservice 运行所属的用户，默认为 admin。 |

### 路径配置

| 配置项 | 说明 |
|-------|------|
| 软件安装路径 | Logservice 软件的安装目录，默认为 /home/admin/logservice。 |
| 本地存储路径 | Logservice 本地日志存储目录，默认为 /data/1/joblogservice。 |

### 端口设置

| 配置项 | 说明 |
|-------|------|
| SQL 端口 | Logservice 的 RPC 通信端口，默认为 7890。 |
| Web 端口 | Logservice 的 HTTP 服务端口，默认为 7891。 |

5. 完成配置后，单击 **确定** 开始创建集群。

6. 在弹出的确认对话框中，确认配置信息无误后，单击 **确定**。

   系统会创建一个异步任务来执行集群创建操作。您可以在 **系统管理 > 任务管理** 中查看任务进度。
