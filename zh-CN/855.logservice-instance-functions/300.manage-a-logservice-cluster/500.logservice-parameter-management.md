# 参数管理

在 Logservice 集群的参数管理页面，您可以查看和修改集群的各项参数配置。

    <a href="../300.logservice-cluster-overview.md">Logservice 集群概览</a>
    <a href="../400.logservice-performance-monitoring.md">性能监控</a>
</p>

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Logservice 管理** 资源权限。
* Logservice **参数管理** 菜单权限。

## 查看参数列表

1. 登录 OCP。

2. 在左侧导航栏中，选择 **Logservice 实例**。

3. 在集群列表中，单击目标集群名称进入集群详情页面。

4. 在左侧导航栏中，选择 **参数管理**。

   系统显示参数列表页面。

## 参数列表说明

参数列表中包含以下信息：

| 信息项 | 说明 |
|-------|------|
| 参数名 | 参数的唯一标识名称 |
| 当前值 | 参数当前的配置值 |
| 默认值 | 参数的默认值 |
| 取值类型 | 参数值的类型，如 INT、ENUM、STRING 等 |
| 作用域 | 参数的作用域，如集群级、Zone 级等 |
| 说明 | 参数的功能描述 |
| 是否重启生效 | 修改参数后是否需要重启服务才能生效 |
| 只读 | 参数是否为只读参数，不可修改 |

## 常见参数说明

以下是 Logservice 集群的一些常见参数：

### 日志流负载均衡

| 参数名 | 说明 | 默认值 |
|-------|------|-------|
| enable_rebalance | 是否开启日志流负载再均衡 | true |
| max_utilization_threshold | 负载均衡中节点资源利用率上限（百分比） | 60 |
| min_utilization_threshold | 负载均衡中节点资源利用率下限（百分比） | 30 |

### 日志盘配置

| 参数名 | 说明 | 默认值 |
|-------|------|-------|
| log_disk_throttling_percentage | 日志盘渐进限速起始阈值（百分比） | 70 |
| log_disk_throttling_maximum_duration | 日志盘渐进限速的最大延迟时长（毫秒） | 600000 |
| log_local_disk_utilization_threshold | 本地磁盘使用率阈值（百分比） | 80 |
| log_local_target_retention_sec | 每个 stream 本地日志的目标保留时长（秒） | 30 |

### 日志文件配置

| 参数名 | 说明 | 默认值 |
|-------|------|-------|
| max_syslog_file_count | 日志文件滚动后保留的文件数量 | 200 |

### 节点配置

| 参数名 | 说明 | 默认值 |
|-------|------|-------|
| node_permanent_offline_time_sec | 节点连续离线超过此秒数后被标记为永久离线 | 1800 |
| metric_sample_save_interval_sec | 监控指标采样保存间隔（秒） | 300 |

## 修改参数值

1. 在参数列表中，找到需要修改的参数。

2. 单击 **修改值** 按钮。

3. 在弹出的对话框中输入新的参数值。

4. 单击 **确定** 保存修改。

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li>修改参数可能会影响集群的运行行为，请谨慎操作。</li>
<li>某些参数修改后需要重启服务才能生效，此时系统会提示您进行重启。</li>
<li>建议在非高峰期进行参数变更，并提前评估对业务的影响。</li>
</ul>
</main>

## 搜索参数

您可以通过搜索框输入参数名，快速定位到目标参数。

## 导航栏操作

在参数管理页面，左侧导航栏包含以下功能：

* **功能介绍**：查看 Logservice 功能说明。
* **概览**：查看集群基本信息，详情参见 [Logservice 集群概览](../200.logservice-cluster-overview.md)。
* **性能监控**：查看集群性能监控数据，详情参见 [性能监控](../400.logservice-performance-monitoring.md)。
* **参数管理**：当前页面，管理集群参数配置。
