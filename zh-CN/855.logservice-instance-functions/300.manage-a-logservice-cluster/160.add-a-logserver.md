# 添加 LogServer

本文介绍如何为 Logservice 集群添加 LogServer 节点。

</p>

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：
  * **Logservice 管理** 资源权限。
  * Logservice **概览** 或 **集群列表** 菜单权限。
* 已有可用的主机资源。

## 操作步骤

添加 LogServer 有如下两个入口：

* **入口一**：在 **Logservice 集群** 列表中，找到待添加 LogServer 的集群，单击对应操作列的 **添加 LogServer**。
* **入口二**：在 **Logservice 集群** 列表中单击目标集群名称，进入集群概览页面，在 **LogServer** 列表区域单击 **添加 LogServer**。

以下操作步骤以 **入口二** 为例：

1. 登录 OCP。

2. 在左侧导航栏中，选择 **Logservice 实例**。

3. 在集群列表中选择需要操作的 Logservice 集群，进入集群详情页面。

4. 在 **LogServer** 列表区域，单击 **添加 LogServer**。

5. 在弹出的添加 LogServer 对话框中，配置以下信息：

### 基本信息

| 配置项 | 说明 |
|-------|------|
| 附属集群 | 显示当前操作的 Logservice 集群名称（仅展示，不可修改）。 |

### 软件包类型

| 配置项 | 说明 |
|-------|------|
| 软件包类型 | 选择操作系统软件包类型，如 el7。 |

### 部署模式

| 配置项 | 说明 |
|-------|------|
| Zone 名称 | 显示 Zone 名称，如 zone1、zone2、zone3（仅展示，不可修改）。 |
| Region | 显示该 Zone 所属的 Region（仅展示，不可修改）。 |
| 机型（可选） | 选择机器的机型。 |
| 主机 | 选择部署 LogServer 的主机。该下拉框中会显示可用的主机资源。 |

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li>每个 Zone 可添加多个 LogServer 节点。</li>
<li>添加 LogServer 时，系统会自动配置 RPC 端口和 HTTP 端口，默认分别为 7890 和 7891。</li>
</ul>
</main>

### 自定义配置

根据需要勾选 **支持执行集群级别用户配置（如操作系统属主用户）、路径设置（如软件安装路径、本地存储路径）**。

如果勾选此项，您可以查看自定义以下配置：

| 配置项 | 说明 |
|-------|------|
| 操作系统属主用户 | LogServer 运行所属的用户，默认为 admin。 |
| 软件安装路径 | LogServer 软件的安装目录。 |
| 本地存储路径 | LogServer 本地日志存储目录。 |

6. 完成配置后，单击 **确定**。

   系统会创建一个异步任务来执行添加 LogServer 操作。您可以在 **系统管理 > 任务管理** 中查看任务进度。
