# Logservice 集群概览

在 Logservice 集群概览页面，您可以查看集群的基本信息、Zone 信息和 LogServer 节点信息。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Logservice 只读** 资源权限。
* Logservice **概览** 菜单权限。

## 查看基本信息

在 **基本信息** 模块，您可以查看以下信息：

| 信息项 | 说明 |
|-------|------|
| 名称 | Logservice 集群的名称 |
| 版本号 | Logservice 集群的软件版本号 |
| 创建时间 | Logservice 集群的创建时间 |
| 软件安装路径 | Logservice 软件的安装目录 |
| 本地存储路径 | Logservice 本地日志存储目录 |
| 对象存储 | 配置的对象存储路径 |

## 查看 Zone 信息

在 **Zone** 模块，您可以查看 Logservice 集群中各 Zone 的信息：

| 信息项 | 说明 |
|-------|------|
| Zone 名称 | Zone 的名称，如 zone1、zone2、zone3 |
| 所属 Region | Zone 所属的 Region |
| 机器数量 | 该 Zone 下的机器数量 |
| 软件包类型 | 操作系统软件包类型，如 el7 |
| CPU 架构 | CPU 架构，如 x86_64 |
| 状态 | Zone 的运行状态 |

## 查看 LogServer 信息

在 **LogServer** 模块，您可以查看集群中各 LogServer 节点的信息：

| 信息项 | 说明 |
|-------|------|
| IP | LogServer 节点的 IP 地址 |
| RPC 端口 | RPC 通信端口 |
| HTTP 端口 | HTTP 服务端口 |
| 所属 Zone | LogServer 所属的 Zone |
| 机型 | 机器的 CPU 架构类型 |
| 状态 | LogServer 的运行状态 |


## 相关操作

* 添加 LogServer：为集群添加 LogServer 节点，详情参见 [添加 LogServer](../160.add-a-logserver.md)。
* 查看性能监控：进入性能监控页面，查看集群性能指标，详情参见 [Logservice 性能监控](../400.logservice-performance-monitoring.md)。
* 管理参数：进入参数管理页面，修改集群参数配置，详情参见 [Logservice 参数管理](../500.logservice-parameter-management.md)。
* 下载日志：下载 Logservice 集群的日志文件，详情参见 [下载日志](../../../../1300.log-service/200.download-log.md)。
