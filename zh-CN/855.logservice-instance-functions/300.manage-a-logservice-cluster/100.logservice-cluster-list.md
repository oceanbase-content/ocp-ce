# Logservice 集群列表

在 Logservice 集群列表页面，您可以查看所有 Logservice 集群的基本信息，包括名称、版本号、关联的 OB 集群、创建时间和状态等。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **Logservice 只读** 资源权限。
* Logservice **集群列表** 菜单权限。

## 查看集群列表

1. 登录 OCP。

2. 在左侧导航栏中，选择 **组件** > **Logservice 实例**。

   系统默认进入 **Logservice 集群** 页面的集群列表标签页。

3. 在集群列表中，您可以查看以下信息：

   | 信息项 | 说明 |
   |-------|------|
   | Logservice 集群名称 | Logservice 集群的名称 |
   | 版本号 | Logservice 集群的软件版本 |
   | 关联 OB 集群 | 关联的 OceanBase 集群，未关联时显示 "-" |
   | 创建时间 | Logservice 集群的创建时间 |
   | 状态 | Logservice 集群的运行状态 |

   Logservice 集群包含以下状态：

   | 状态 | 说明 |
   |-------|------|
   | 创建中 | 集群正在创建中 |
   | 正常运行 | 集群运行正常，可正常使用 |
   | 启动中 | 集群正在启动 |
   | 停止中 | 集群正在停止 |
   | 已停止 | 集群已停止运行 |
   | 重启中 | 集群正在重启 |
   | 删除中 | 集群正在删除 |
   | 运维中 | 集群处于运维状态 |
   | 密钥轮转中 | 集群正在进行密钥轮转 |
   | 不可用 | 集群不可用，可能存在异常 |
   | 已废弃 | 集群已废弃，不再使用 |

4. 您可以通过以下方式筛选集群：

   * 在搜索框中输入集群名称进行搜索。
   * 通过状态下拉框筛选特定状态的集群。

5. 单击集群名称进入集群详情页面，详情参见 [Logservice 集群概览](../300.logservice-cluster-overview.md)。

## 常见操作

在集群列表页面，您可以执行以下操作：

* **新建 Logservice 集群**：创建新的 Logservice 集群，详情参见 [新建 Logservice 集群](../200.create-a-logservice-cluster.md)。
* **添加 LogServer**：为 Logservice 集群添加 LogServer 节点，详情参见 [添加 LogServer](../160.add-a-logserver.md)。
* **查看详情**：单击集群名称查看集群详细信息。
* **管理参数**：进入集群后，可通过参数管理功能修改集群参数。
