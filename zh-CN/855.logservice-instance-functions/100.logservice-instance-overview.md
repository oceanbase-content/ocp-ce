# Logservice 实例功能概述

Logservice 是 OceanBase 分布式日志服务，用于接收、存储和管理 OceanBase 集群的日志数据。通过 OCP 您可以方便地管理 Logservice 集群，包括集群的创建、监控、参数配置等操作。

## 功能说明

通过 Logservice 实例功能，您可以：

* **集群管理**：查看和管理 Logservice 集群，包括集群列表、集群详情、Zone 信息和 LogServer 节点信息。
* **参数模板**：创建和管理参数模板，方便批量应用到多个 Logservice 集群。
* **性能监控**：监控 Logservice 集群的性能指标，包括日志接收量、磁盘读写性能等。
* **参数管理**：查看和修改 Logservice 集群的参数配置。

## 前提条件

* OCP 版本需支持 Logservice 集群管理功能。
* 当前登录用户需具备相应的资源权限和菜单权限。
