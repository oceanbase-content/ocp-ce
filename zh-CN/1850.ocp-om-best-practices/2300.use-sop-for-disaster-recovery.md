# 使用标准运维流程进行故障恢复

本节为您介绍如何使用 OCP 标准运维流程（SOP）完成 OceanBase 数据库的故障恢复操作。

## 应用场景

在 OceanBase 数据库的日常运维中，部分故障恢复操作涉及多个步骤且步骤之间存在依赖关系，手动执行容易出现操作遗漏或顺序错误。OCP 标准运维流程（SOP）将这些复杂操作编排为标准化的流程模板，支持自动执行与人工确认相结合，帮助您安全、规范地完成故障恢复。

SOP 适用于以下典型场景：

* **备租户数据异常恢复**：备租户数据损坏或同步异常，需要通过主租户数据重新构建备租户时，可使用"重建备租户"流程。

* **副本故障下的仲裁服务启用**：集群内副本出现异常，需通过仲裁服务保障租户可用性时，可使用"副本异常开启仲裁服务"流程。

* **OBServer 节点故障恢复**：OBServer 节点故障且无法恢复，需要替换节点并重建数据时，可使用"OBServer 异常后数据重建"流程。

## 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群管理**、**租户管理** 或 **主机管理** 任一资源权限（对应操作的目标资源需具备 **管理** 或 **维护** 权限）。
  * 运维管理 **标准流程** 菜单权限。

* SOP 功能仅适用于 OCP 企业版，OCP 社区版不提供此功能。

* 不同 SOP 类型还需满足如下条件：

  | SOP 类型 | 前置条件 |
  |---------|---------|
  | 重建备租户 | 主租户可用且数据完整；待重建的备租户为日志同步链路中最下游的备租户；备租户所属集群状态正常；若新备租户选择日志归档同步模式，且在 SOP 任务中要执行"备份主租户"，要求主租户已配置备份策略。 |
  | 副本异常开启仲裁服务 | 目标集群状态正常；具备可用的仲裁服务或仲裁服务组。 |
  | OBServer 异常后数据重建 | 目标集群状态正常；集群内存在其他可用 OBServer 节点；建议提前准备替代主机。 |

## 操作步骤

### 重建备租户

当备租户数据异常或同步中断无法恢复时，可通过 SOP 重建备租户。

1. 登录 OCP。

2. 在左侧导航栏中单击 **运维管理** > **标准流程**。

3. 单击 **新建**，在弹出的 **新建任务** 对话框中配置如下信息：

   1. **任务名称**：输入任务名称（2～32 个字符，以中文、英文或日文假名开头，以中文、英文、数字或日文假名结尾，中间可含下划线）。

   2. **任务类型**：选择 **重建备租户**。

   3. **备注**（可选）：输入任务备注信息。

   4. **立即执行**：根据需要选择是否创建后立即执行。建议首次操作时不勾选，先确认步骤配置后再手动启动。

   5. 单击 **新建**。

4. 在步骤配置页面，确认并调整各步骤的自动执行开关：

   | 步骤 | 说明 | 建议配置 |
   |------|------|---------|
   | 确认操作对象 | 确认待重建的备租户和主租户信息 | 自动执行 |
   | 备份主租户 | 对主租户执行数据备份 | **关闭自动执行**，人工确认后执行 |
   | 主备解耦 | 断开备租户与主租户的同步关系 | 自动执行 |
   | 锁定原备租户 | 锁定备租户防止新写入 | 自动执行 |
   | 删除原备租户 | 删除原备租户 | 自动执行 |
   | 新建备租户 | 创建新的备租户，需在该步骤执行前配置创建参数 | **关闭自动执行**，人工确认后执行 |
   | 验证主备同步 | 验证新备租户与主租户的同步状态 | 自动执行 |

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>"新建备租户"步骤需在执行前设置 <code>createStandbyTenantParamJson</code> 参数，包括新备租户名称、兼容模式、Zone 副本配置等。建议将该步骤设为人工确认，待参数配置完成后再推进。</p>
   </main>

5. 单击 **启动** 开始执行。

6. 执行到"创建备租户"步骤前，在执行详情页面更新该步骤的参数：

   * 单击步骤右侧的 **编辑**，在弹出的对话框中配置 `createStandbyTenantParamJson` 参数，包括新备租户名称、主租户 ID、备集群 ID、日志传输模式、Zone 副本配置和资源池规格等。

7. 确认参数无误后，单击 **执行下一步** 推进"创建备租户"步骤。

8. 后续步骤自动执行，直至"验证主备同步"完成。

### 副本异常开启仲裁服务

当集群内副本出现异常，需要通过仲裁服务保障租户可用性时，可使用此流程。

1. 登录 OCP。

2. 在左侧导航栏中单击 **运维管理** > **标准流程**。

3. 单击 **新建**，在弹出的 **新建标准运维流程** 对话框中配置如下信息：

   1. **任务名称**：输入任务名称。
   2. **任务类型**：选择 **副本异常开启仲裁服务**。
   3. 选择目标集群，并选择仲裁服务或仲裁服务组（二选一）。选择仲裁服务组时，系统将按服务组内的优先级自动选定关联的仲裁服务。
   4. 单击 **新建**。

4. 确认步骤配置后，单击 **启动** 开始执行。

   该流程包含确认操作对象、添加仲裁服务、删除租户副本、删除 OBServer、开启租户仲裁服务和验证租户仲裁服务可用等步骤。所有步骤默认自动执行，您可根据实际需要调整。

### OBServer 异常后数据重建

当 OBServer 节点故障且无法恢复时，可通过此流程替换节点并重建数据。

1. 登录 OCP。

2. 确认故障 OBServer 节点和可用的替代主机。

3. 在左侧导航栏中单击 **运维管理** > **标准流程**。

4. 单击 **新建**，在弹出的 **新建标准运维流程** 对话框中配置如下信息：

   1. **任务名称**：输入任务名称。
   2. **任务类型**：选择 **OBServer 异常后数据重建**。
   3. 选择目标集群。如有预选替代主机，可一并选择；也可在"添加 OBServer"步骤前再设置。
   4. 单击 **新建**。

5. 确认步骤配置后，单击 **启动** 开始执行。

   | 步骤 | 说明 | 建议配置 |
   |------|------|---------|
   | 确认操作对象 | 确认故障 OBServer 信息 | 自动执行 |
   | 删除租户副本 | 删除故障 OBServer 上的租户副本 | 自动执行 |
   | 删除 OBServer | 从集群中删除故障 OBServer 节点 | 自动执行 |
   | 强制删除主机（可选） | 从 OCP 中强制删除故障主机。该步骤为可选步骤，可在创建或编辑任务时决定是否启用 | **建议关闭自动执行**，人工确认后推进 |
   | 添加 OBServer | 添加新的 OBServer 节点，需设置替代主机 | **关闭自动执行**，配置替代主机后推进 |
   | 添加租户副本 | 在新 OBServer 上添加租户副本 | 自动执行 |
   | 验证租户副本重建成功 | 验证副本重建是否成功 | 自动执行 |

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>"强制删除主机"为可选步骤，可在创建或编辑任务时决定是否启用。该步骤会从 OCP 中移除故障主机记录，操作不可逆，启用后建议关闭自动执行并人工确认。"添加 OBServer"步骤需选择替代主机，请确保替代主机已添加至 OCP 且状态正常。</p>
   </main>

6. 执行到"添加 OBServer"步骤前，在执行详情页面更新该步骤参数：

   * 单击步骤右侧的 **编辑**，选择替代主机。请确保替代主机已添加至 OCP 且状态正常。

7. 确认参数后，单击 **执行下一步** 推进"添加 OBServer"步骤。

8. 后续步骤自动执行，直至"验证副本重建"完成。

## 常见问题

**Q：SOP 任务执行过程中步骤失败了怎么办？**

A：步骤执行失败时，任务状态变为 **失败**。您可以在执行详情页面查看失败步骤的错误信息，根据错误原因排查问题后：
* 若仅需重试单个失败步骤，单击该步骤的 **重试**。
* 若需重试所有失败步骤，单击页面上的 **重试所有失败步骤**。

**Q：SOP 任务可以修改步骤的执行顺序吗？**

A：创建或编辑任务时，模板中标记为 `userMovable=true` 的步骤可以在允许的序号范围内调整位置。但步骤标识（stepKey）和固定启用的步骤不可更改。

**Q：SOP 任务启动后可以编辑吗？**

A：任务一旦启动就无法编辑。未启动（待执行）状态的任务可以编辑名称、目标参数、步骤配置和备注。如需修改已启动任务中未执行步骤的自动执行开关或步骤参数，可使用步骤更新功能。

**Q："重建备租户"流程中，日志传输方式 NETWORK 和 LOG_BACKUP 有什么区别？**

A：
* **NETWORK**：基于网络传输日志，主备租户之间通过网络直接同步日志，延迟较小，但要求主备集群之间网络连通。
* **LOG_BACKUP**：基于日志备份传输日志，备租户从备份存储中拉取归档日志进行回放，不要求直接网络连通，但同步延迟通常较大。

**Q：SOP 任务执行完成后可以删除吗？**

A：可以。**已结束** 和 **失败** 状态的任务可以删除，**待执行** 状态的任务也可以直接删除。但 **等待确认** 和 **执行中** 状态的任务不允许删除。删除任务会级联清理执行实例和步骤执行记录。
