# 将 OCP 监控集成到 Prometheus

本节为您介绍如何使用 Prometheus 集成 OceanBase 业务监控。

## 应用场景

用户需要使用自有的 Prometheus 体系集成业务监控。

## 前提条件

* 请确保当前登录 OCP 的用户为 **ADMIN** 角色。
* 已部署 V2.28 及以上版本的 Prometheus 服务。
* 已部署 V4.4.2 及以上的 OCP 版本。

## 操作步骤

### 步骤一：新建 Prometheus 数据源

1. 登录 OCP 平台。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** > **外部集成**。

3. 单击 **Prometheus** 页签。

4. 在 **Prometheus 数据源** 页面，单击 **新建 Prometheus 数据源**。

5. 在弹出的对话框中，填写 **Prometheus 数据源** 的相关信息。

   | 配置项     | 说明      |
   | ---------- | ------------- |
   | 数据源名称 | Prometheus 数据源的名称。要求 2~32 字符，可包含中文、英文字母、数字、下划线（_），且具有唯一性。 |
   | 访问地址   | Prometheus 服务的访问 IP，`http/https` 开头，仅允许填写一个 IP 地址。 |
   | 端口       | Prometheus 服务的访问端口，默认为 9090，支持自定义。 |
   | 用户名     | Prometheus 服务授权账户的用户名，若无可不填写。 |
   | 密码       | Prometheus 服务授权账户的密码，若无可不填写。 |
   | 备注       | 添加关于 Prometheus 数据源的特殊说明。 |

6. 单击 **验证**，用于验证数据源联通性。

7. 验证成功后，单击 **新建**。

8. 复制弹窗中 Prometheus 的配置信息。

### 步骤二：修改 `prometheus.yaml` 配置文件

在 Prometheus 的配置文件 `prometheus.yaml` 中添加上一步骤复制的配置信息：

```yaml
scrape_configs:
  - job_name: 'ocp_sd'
    scheme: 'http'
    fallback_scrape_protocol: "PrometheusText1.0.0"  # 仅 Prometheus 3.x 版本需要配置该参数，2.x 版本无需配置
    http_sd_configs:
      - url: 'http://xx.xx.xx.xx:8080/api/v2/monitor/prometheus_sd'
        basic_auth:   # 访问 OCP 获取 prometheus_sd 中所有 Target
            username: "******"
            password: "******"
    basic_auth:   # 控制访问所有 Target
        username: "******"
        password: "******"
```

### 步骤三：重启 Prometheus 服务

1. 重启 Prometheus 服务，使配置生效。

2. 登录 Prometheus 服务控制台。

3. 选择 **Status** > **Target health**，观察接入的 job 是否正常工作，需确保所有 Target 的状态为 **UP**。

4. 在 **Query** 中输入 `executor_active_threads`、`ob_sysstat`，观察 OCP 和 Agent 的监控数据是否已正常接入。

### 步骤四：启用 Prometheus 数据源

1. 登录 OCP 平台。

2. 在左侧导航栏单击 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** > **外部集成**。

3. 单击 **Prometheus** 页签。

4. 在 **Prometheus 数据源** 页面，单击操作列的 **启用**。

   启用 Prometheus 数据源后，OCP 与 Prometheus 即可双向同步监控数据，即：支持 Prometheus 采集 OCP 的数据，也支持 OCP 从 Prometheus 读取监控数据。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>若您仅需要 Prometheus 采集 OCP 的数据，不需要 OCP 监控查询 Prometheus 数据源时，无需在 OCP 平台启用 Prometheus 数据源。</p>
</main>

## 更多说明

### 关于 Prometheus 基本认证

具体认证方式可参考 Prometheus 官网：[基本认证](https://prometheus.ac.cn/docs/guides/basic-auth/)。

其中，创建的 `web.yml` 文件可以与 `prometheus.yaml` 文件放置在同一目录下，即启动 docker 或者容器时添加 `--web.config.file=/etc/prometheus/web.yml` 字段。

以下示例中，`/home/admin` 为非容器的目录，统一存放 `prometheus.yaml` 和 `web.yml` 文件。

```yaml
docker run  -d --name prometheus -p 9090:9090 -v /home/admin/docker/prometheus/prometheus.yml:/etc/prometheus/prometheus.yml -v /home/admin/docker/prometheus/web.yml:/etc/prometheus/web.yml prom/prometheus:v3.3.0    --config.file=/etc/prometheus/prometheus.yml --storage.tsdb.path=/prometheus --web.config.file=/etc/prometheus/web.yml
```

### 关于 OCP 验证 Prometheus 可连接机制

OCP 会发送一个 http 请求，用于访问 Prometheus 的 `/api/v1/status/buildinfo` 接口。

**请求示例**：

```yml
# 有账号密码方式：
curl -H "Authorization: Basic $(echo -n 'Prometheus 账户:Prometheus 密码' | base64)" \
http://{PrometheusIP}:{Port}/api/v1/status/buildinfo

# 无账号密码方式：
curl -L http://{PrometheusIP}:{Port}/api/v1/status/buildinfo
```

**返回示例**：

```json
{
  "status": "success",  // 请求是否成功  
  "data": {
    "version": "3.3.0",  // Prometheus 的版本号
    "revision": "3c49e69330ceee9c587a1d994c78535695edff16",
    "branch": "HEAD",
    "buildUser": "root@b362765c931d",
    "buildDate": "20250415-13:32:00",
    "goVersion": "go1.24.1"
  }
}
```

### 关于 OCP 版本升级

默认情况下，OCP V4.4.2 版本可以兼容历史版本的 Prometheus 配置，但为方便后续维护，强烈建议您参考本节内容重新创建并配置 Prometheus 数据源。

### 关于 Prometheus 的配置文件

`http_sd_configs` 中存在两个 `basic_auth` 字段，其作用是 OCP 协助 Prometheus 生成一个访问秘钥，支持 Prometheus 有限访问 OCP 和有限访问 Agent 相关的 Exportor。

**您需注意的是**：请勿自行修改该配置信息，如有修改需求，可参考 [关于修改 Agent 授权秘钥](#modify-agent-auth-key) 在 OCP 上进行修改。

```yaml
global:
  scrape_interval:  10s
  evaluation_interval: 15s

scrape_configs:
  - job_name: 'ocp_sd'
    scheme: 'http'
    fallback_scrape_protocol: "PrometheusText1.0.0"  # 仅 Prometheus 3.x 版本需要配置该参数，2.x 版本无需配置
    http_sd_configs:
      - url: 'http://xx.xx.xx.xx:8080/api/v2/monitor/prometheus_sd'
        basic_auth:   # 访问 OCP 获取 prometheus_sd 中所有 Target
            username: "******"
            password: "******"
    basic_auth:   # 控制访问所有 Target
        username: "******"
        password: "******"
```

### 关于修改 Agent 授权秘钥<a id="modify-agent-auth-key"></a>

OCP 提供了修改 Agent 授权秘钥的接口，您可参考如下步骤进行操作：

1. 连接 metaDB，通过如下 SQL 语句查询秘钥 id：

   ```sql
   select id from profile_credential where access_target = 'PROMETHEUS'
   ```

2. 在 OCP 容器上执行如下命令修改秘钥：

   ```bash
   curl --location --request PUT 'http://OCP-IP:OCP-port/api/v2/integration/prometheus/changeAuthPd/{id}?id={id}' \
   --header 'Content-Type: application/json' \
   -u 'admin:OCP 密码'  \
   --data '{
       "newAuthPd": "******"
   }'
   ```

   其中，`{id}` 为上一步查询到的 id，`{OCP-IP}` 为 OCP 的 IP，`{OCP-port}` 为 OCP 的端口，`{admin:OCP 密码}` 为 OCP 的账号及密码，`{******}` 为修改后的新密码（建议尽量与 OCP 的密码格式保持一致）。

3. 查看返回结果是否为成功。

4. 修改 `prometheus.yaml` 文件，将 `basic_auth` 中的两个 `password` 更新为步骤 2 中修改的新密码。

5. 重启 Prometheus 容器，进入 Prometheus 控制台，选择 **Status** > **Target health**，观察接入的 job 是否正常工作，所有 Target 的状态为 **UP** 即说明修改成功。
