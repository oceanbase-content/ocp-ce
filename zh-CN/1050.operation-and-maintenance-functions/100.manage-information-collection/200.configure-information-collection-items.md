# 配置信息采集项

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

OCP 提供了内置的信息采集项。您可根据实际所需，参考本页面对采集触发源进行调整，关闭不需要的触发源。

开启采集触发源后，OCP 会自动收集对应事件信息，并生成信息采集记录报告；关闭采集触发源后，发生对应事件时系统将不再自动触发信息采集动作。

## 前提条件

请确保当前登录 OCP 的用户具备如下权限：

* **集群维护** 或 **租户维护** 资源权限。
* 运维管理 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.InformationCollection">信息采集</UI-TERM>** 菜单权限。

## 操作步骤

1. 登录 OCP 平台，在左侧导航栏选择 **运维管理 > 信息采集**。

2. 默认进入 **<UI-TERM key="ocp-v2.src.hook.useMenu.InformationCollection">信息采集</UI-TERM>** 记录的列表页面。

3. 单击右上角 **<UI-TERM key="ocp-v2.page.Information.InformationCollectionSettings">信息采集设置</UI-TERM>** 。

4. 在弹出的面板中关闭或开启信息采集项。

## 信息采集项说明

OCP 支持通过 **采集设置** 和 **采集内容** 对采集触发源进行配置。

### 采集设置

**采集设置** 页面提供了 OCP 支持的告警采集项，及所对应的信息采集场景。开启后，发生对应告警事件时系统将自动触发信息采集动作。

| 采集类型 | 事项 | 信息采集场景 |
| -------- | ------- | ------------ |
| 告警 | tenant_cpu_percent_over_threshold OceanBase 租户线程使用率超限 | tenant_high_cpu |
| 告警 | ob_tenant_cpu_usage_over_threshold OceanBase 租户 CPU 使用率超限 | tenant_high_cpu |
| 告警 | ob_tenant_large_trans_exist OceanBase 租户存在大事务 | tenant_tranction_monitor |
| 告警 | ob_tenant_long_trans_exist OceanBase 租户存在长事务 | tenant_tranction_monitor |
| 告警 | ob_tenant_expired_trans_exist OceanBase 租户存在悬挂事务 | tenant_tranction_monitor |
| 告警 | ob_tenant_exists_expired_xa_trans OceanBase 租户存在 XA 悬挂事务 | tenant_tranction_monitor |
| 告警 | observer_process_stop OBServer 进程停止 | observer_status_monitor |
| 告警 | os_observer_not_exist OceanBase server 进程不存在 | observer_status_monitor |
| 告警 | ob_server_stopped OceanBase 服务器停止服务 | observer_status_monitor |
| 告警 | ob_cannot_connected OceanBase 服务器无法连接 | observer_status_monitor |
| 告警 | os_observer_core_dump OceanBase server Core Dump | observer_status_monitor |
| 告警 | host_agent_goroutine_count_over_threshold 服务器 Agent 协程数超限 | ocp_agent_goroutine |
| 告警 | monagent_process_stop ocp_monagent 进程停止 | ocp_agent_status_monitor |
| 告警 | mgragent_process_stop ocp_mgragent 进程停止 | ocp_agent_status_monitor |
| 告警 | ob_tenant_session_kill_delay OceanBase 租户 Session Killed 延迟 | obstack_collect |
| 告警 | ob_log_mysql_request_full OceanBase 租户队列满 | tenant_request_full |

### 采集内容

**采集内容** 页面提供了在不同采集场景下系统采集的详细内容。开启后，OCP 会在发生采集事件时自动触发该信息采集。

| 采集场景 | 采集内容 |
| ------- | ------- |
| cluster_common_exception | 检查数据盘是否存在坏盘 |
| cluster_common_exception | 集群各 server 节点信息 |
| cluster_common_exception | 检查 sys 租户连通性 |
| cluster_common_exception | 获取 obstack 信息 |
| observer_status_monitor | core dump 信息 |
| observer_status_monitor | observer crash log |
| observer_status_monitor | df -H |
| observer_status_monitor | 日志中包含的 dump tenant info.tenant 信息 |
| observer_status_monitor | /var/log/messages |
| observer_status_monitor | 主机 top -H 信息 |
| observer_status_monitor | 获取主机 top 信息 |
| obstack_collect | 获取 obstack 信息 |
| ocp_agent_goroutine | 主机 agent goroutine 信息 |
| ocp_agent_goroutine | 获取主机 top 信息 |
| ocp_agent_status_monitor | mgragent 崩溃日志 |
| ocp_agent_status_monitor | monagent 崩溃日志 |
| ocp_agent_status_monitor | 获取主机 top 信息 |
| tail_ob_log | observer crash log |
| tail_ob_log | election.log |
| tail_ob_log | observer.log |
| tail_ob_log | rootservice.log |
| tenant_exception | （OceanBase 集群一键诊断）检查最近是否存在 CPU 占比过大的 SQL |
| tenant_exception | （OceanBase 集群一键诊断）检查最近是否存在报错的 SQL |
| tenant_exception | 事务占用存储统计 |
| tenant_exception | 节点上租户临时文件大小 |
| tenant_exception | （OceanBase 集群一键诊断）检查集群是否存在悬挂事务 |
| tenant_high_cpu | 获取主机 dump tenant 信息 |
| tenant_high_cpu | 获取 obstack 信息 |
| tenant_high_cpu | 主机 top -H 信息 |
| tenant_high_cpu | 获取主机 top 信息 |
| tenant_request_full | 获取主机 dump tenant 信息 |
| tenant_request_full | 获取 obstack 信息 |
| tenant_request_full | 主机 top -H 信息 |
| tenant_request_full | 获取主机 top 信息 |
| tenant_tranction_monitor | 日志中包含的 dump tenant info.tenant 信息 |
| tenant_tranction_monitor | 获取主机 dump tenant 磁盘 |
| tenant_tranction_monitor | 主机 top -H 信息 |
