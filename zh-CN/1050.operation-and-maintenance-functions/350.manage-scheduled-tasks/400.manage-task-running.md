# 管理任务运行

您可参考本节内容对定时任务的运行情况进行管理。

## 查看执行进度

您可参考本节内容，查看定时任务的执行进度。

### 前提条件

请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

### 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **运维管理** > **定时任务** 。

3. 进入 **运行记录** 页签。

4. 选择需要查看的运行记录，单击操作列 **查看执行进度**。

5. 页面将跳转至任务详情页，您可在此页面查看任务的执行详情，并进行相关运维操作，详情可参考 [管理任务](../../1600.system-management-features/600.manage-tasks.md)。
