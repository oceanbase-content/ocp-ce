# 查看定时任务详情

您可参考本节内容查看定时任务的配置信息及运行记录。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **运维管理** > **定时任务** 。

3. 在 **运行记录** 页签，展示了所有已运行的定时任务列表，您可查看每个任务的运行详情，包括 **任务名**、**执行对象**、**任务类型**、**预计执行时间**、**实际执行时间**、**任务状态** 及相关操作。

   * 支持通过右上方的执行状态对运行记录进行筛选。
   * 在搜索框输入任务名称，可对运行记录进行模糊查询。
   * 单击任务名，可查看该定时任务运行时的配置信息。若定时任务已被删除，将无法再查看相关信息。
   * 支持通过 **任务类型** 对运行记录进行筛选。
   * 支持通过 **预案执行时间** 和 **实际执行时间** 对任务记录进行排序。
   * 单击操作列的 **查看执行进度**，可跳转至任务执行页面查看任务执行详情。

4. 在 **任务列表** 页签，展示了所有已创建的定时任务列表，您可每个任务的配置详情，包括 **任务名**、**执行对象**、**任务类型**、**调度规划**、**下次执行时间**、**总执行次数**、**创建人**、**任务状态** 及相关操作。

   * 支持通过右上方任务状态对定时任务进行筛选。
   * 在搜索框输入任务名称，可对定时任务进行模糊查询。
   * 单击任务名，可查看该定时任务当前的配置详情。
   * 支持通过 **任务类型** 对定时任务进行筛选。
   * 支持通过 **下次执行时间** 对任务记录进行排序。
   * 支持对定时任务进行日常管理工作，包括强制执行、禁用/启用、编辑、复制和删除，详情可参见 [管理定时任务](300.manage-a-scheduled-task.md)。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   在查看配置详情时，若任务的执行对象为刚被删除、刚被迁出或当前登录用户无权限访问时，配置详情中该对象的状态变更可能存在延迟，建议您等待 3min 后再进行查看。
   </main>
