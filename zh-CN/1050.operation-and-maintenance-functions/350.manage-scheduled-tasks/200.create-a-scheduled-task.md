# 新建定时任务

您可参考本节内容新建一个定时任务。定时任务支持您对租户、库、表等执行对象，从分钟、天、星期、月等维度，配置自动执行的任务，提升您的运维效率。

## 前提条件

请确保当前登录 OCP 的用户为 **ADMIN** 角色或 **ORG_ADMIN** 角色。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **运维管理** > **定时任务** 。

3. 单击 **新建任务**。

4. 配置定时任务执行详情。

   a. 配置定时任务基本信息。

     | 参数      | 说明     |
     |-----------|----------|
     | 任务名称  | 定时任务的名称，具有唯一性，且需满足如下要求：<ul><li>仅支持以中文或英文字母开头，中文、数字或英文字母结尾。</li><li>支持 2~32 个字符。</li><li>特殊符号仅支持下划线（_）。</li></ul> |
     | 执行对象  | 支持通过租户、库、表三个维度选择执行对象。 |
     | 选择租户/所属租户 | 根据实际需求，选择任务的执行对象。当选择全部对象时，您可通过右侧的 **排除对象**，对不需要执行定时任务的对象进行排除。 |
     | 任务类型  | 选择定时任务的执行类型，包括收集统计信息、合并、合并并收集统计信息。<main id="notice" type='explain'><h4>说明</h4><ul><li>在进行自动收集统计信息时，OCP 针对收集方式、收集的并行度、收集的粒度等参数信息进行了默认配置。您可直接使用系统现有的配置，也可根据业务实际情况单击参数后的编辑按钮进行修改。关于统计信息收集参数的说明，详见 修改自动统计信息收集的参数信息。</li><li>此三种任务类型均会消耗 IO、CPU 等硬件资源，执行本消耗时请合理评估业务负载。</li></ul></main> |

   b. 配置定时任务执行参数。

     | 参数      | 说明     |
     |-----------|----------|
     | 调度规划  | 选择定时任务的执行方式，支持重复执行、表达式设定和仅执行一次三种类型。<ul><li>重复执行：可选择按分钟、按天、按星期、按月的执行频率，并设置具体的执行时间。当选择按分钟执行时，支持设置结束日期并配置是否允许多个相同对象的任务并发执行。</li><li>表达式设置：</li></ul> |
     | 执行频率  | 仅重复执行方式填写  |
     | 执行时间  |    |
     | 表达式    |    |
     | 结束日期  |    |
     | 是否允许多个相同对象的任务并发执行  |   |

   c. 配置定期任务过期策略。

     | 参数         | 说明     |
     |--------------|----------|
     | 调度过期策略 |   |
     | 最大延迟时间 |    |
     | 超过最大延迟时间后是否执行 |    |

5. 单击 **新建**。

   创建成功后，在定时任务执行的前 10 分钟，您将在 OCP 任意界面收到关于该任务即将执行的弹窗提醒。
