# 新建定时任务

您可参考本节内容新建一个定时任务。定时任务支持您对租户、表等执行对象，从分钟、天、周、月等维度，配置自动执行的任务，提升您的运维效率。

## 注意事项

定时任务的执行会消耗系统的 CPU、内存、IO 等硬件资源。建议您在创建定时任务前，根据当前系统的业务负载情况合理评估资源消耗，避免因任务执行影响正常业务运行。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏选择 **运维管理** > **定时任务** 。

3. 单击 **新建任务**。

4. 在 **新建定时任务** 面板中配置定时任务执行详情。

   a. 配置定时任务基本信息。

     | 参数      | 说明     |
     |-----------|----------|
     | 任务名称  | 定时任务的名称，具有唯一性，且需满足如下要求：<ul><li>仅支持以中文或英文字母开头，中文、数字或英文字母结尾。</li><li>支持 2~32 个字符。</li><li>特殊符号仅支持下划线（_）。</li></ul> |
     | 执行对象  | 支持通过 **租户** 和 **表** 两个维度选择执行对象。 |
     | 选择租户/所属租户 | 根据实际需求，选择任务的执行对象，需确保租户所属集群为 V4.2.1.0 及以上版本。<br>当执行对象为 **租户** 时：<ul><li>支持单击 **添加** 按钮添加多个租户。</li><li>集群或租户选择 **全部** 时，支持通过 **排除对象** 对不需要执行定时任务的对象进行排除。</li></ul> |
     | 任务类型  | 选择定时任务的执行类型。<ul><li>当执行对象为 **租户** 时，支持 **租户维度合并及统计信息收集** 和 **租户维度合并** 两种任务类型。<ul><li>**租户维度合并及统计信息收集**：定时触发租户合并及统计信息收集，优化存储空间和查询性能（仅主租户支持发起合并操作）。</li><li>**租户维度合并**：定时触发租户合并，优化存储空间和查询性能（仅主租户支持发起合并操作）。</li></ul></li><li>当执行对象为 **表** 时，仅支持 **表维度统计信息收集**，定时收集表的统计信息，用于优化查询性能。</li></ul> |
     | 可统计对象 | 当执行对象为 **表** 时，支持选择具体的库或表，最多支持选择 50 张表。 |
     | Schema 统计参数 | 当任务类型选择 **租户维度合并及统计信息收集** 或 **表维度统计信息收集** 时，OCP 针对收集方式、收集的并行度、收集的粒度等参数信息进行了默认配置。您可直接使用系统现有的配置，也可根据业务实际情况单击参数后的编辑按钮进行修改。关于参数的详细说明，可参考 [收集统计信息](../../700.tenant-functions/1450.manage-statistical-information/200.collect-statistics-information.md) 中的 **修改自动统计信息收集的参数信息**。</main>

   b. 配置定时任务执行参数。

     | 参数      | 说明     |
     |-----------|----------|
     | 调度规划  | 选择定时任务的执行方式，支持 **重复执行**、**表达式设定** 和 **仅执行一次** 三种类型。<ul><li>**重复执行**：按固定频率重复执行任务。</li><li>**表达式设定**：按照自定义表达式进行执行。</li><li>**仅执行一次**：任务仅运行一次。</li></ul> |
     | 执行频率  | 当调度规划为 **重复执行** 时填写，支持的执行频率包括按分钟、按天、按周和按月。   |
     | 表达式    | 当调度规划为 **表达式设定** 时填写，支持通过 Crontab 表达式配置任务的执行频率。关于 Crontab 表达式的字段和取值，可参考 [后台任务列表](../../2100.appendix/200.ocp-background-tasks.md) 中的 **调度表达式**。<main id="notice" type='notice'><h4>注意</h4><ul><li>定时任务暂不支持 `second` 字段，其余字段均可参考此文档进行配置。</li><li>请确保表达式格式输入准确，错误格式（如输入不存在的日期、表达式存在多余空格等）将会导致定时任务无法执行。</main>   |
     | 执行时间  | 选择定时任务的具体执行时间。   |
     | 结束日期  | 选择定时任务的结束时间，包括 **无限期** 及 **自定义** 两种类型。<ul><li>**无限期**：任务将一直执行，直到被手动停止。</li><li>**自定义**：设定具体时间，任务将在该时间点停止。</li></ul>   |
     | 是否允许多个相同对象的任务并发执行  | 当调度规划为 **重复执行** 或 **表达式设定** 时填写，当选择 **允许** 时，系统将在前一个任务未完成时就创建新的定时任务，且多个任务可以并行。  |

   c. 配置定时任务调度过期策略。

     | 参数         | 说明     |
     |--------------|----------|
     | 最大延迟时间 | 选择允许定时任务执行延迟的最大时间。   |
     | 超过最大延迟时间后是否执行 | 当任务执行超过最大延迟时间时，您可选择是否丢弃任务不再执行。   |

   d. 选择是否启用定时任务。开启后，该定时任务将在创建成功后立即生效。

5. （可选）补充定时任务的备注信息。

6. 单击 **新建**。

   创建成功后，在定时任务执行的前 10 分钟，您将在 OCP 任意界面收到关于该任务即将执行的弹窗提醒。
