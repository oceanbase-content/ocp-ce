# 查看标准运维流程执行详情

本节介绍如何查看标准运维流程（SOP）任务的执行详情，以及对执行中的任务进行运维操作。

## 前提条件

* 当前登录 OCP 的用户具备 **集群管理**、**租户管理** 或 **主机管理** 任一资源权限。
* 运维管理 **标准流程** 菜单权限。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

## 查看执行详情

1. 登录 OCP。

2. 在左侧导航栏中单击 **运维管理** > **标准流程**。

3. 在 **标准流程** 页面找到目标任务，单击任务名称或 **执行详情**，进入执行详情页面。

执行详情页面展示如下信息：

### 基本信息

展示任务的基本信息，包括任务名称、任务类型、执行对象、创建时间、创建人、开始时间、结束时间和当前状态。

### 执行进度

展示任务的总体执行进度，包括已完成步骤数和启用步骤总数（如 7/7），以及各步骤的执行状态。

### 步骤列表

展示所有步骤的详细执行信息：

| 参数 | 说明 |
|------|------|
| 步骤序号 | 步骤的执行序号。 |
| 步骤名称 | 步骤的展示名称。 |
| 步骤状态 | 步骤的当前状态：<ul><li>**PENDING**：等待执行。</li><li>**RUNNING**：执行中。</li><li>**SUCCESSFUL**：已成功完成。</li><li>**FAILED**：执行失败。</li></ul> |
| 自动执行 | 该步骤是否为自动执行模式。 |
| 关联任务 | 步骤执行过程中创建的 OCP 任务实例 ID。 |
| 重试次数 | 该步骤已重试的次数。 |
| 错误信息 | 步骤最近一次失败的错误信息。 |
| 开始时间 | 步骤开始执行的时间。 |
| 结束时间 | 步骤执行结束的时间。 |

## 运维操作

根据任务的不同状态，您可以执行以下操作：

### 启动任务

对 **待执行** 状态的任务，单击 **启动** 可创建执行实例并启动首步骤。

* 首步骤为自动执行时，返回状态取决于即时处理结果。
* 首步骤需人工执行时，返回状态为 **等待确认**。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>一个任务只能启动一次，启动后无法重新启动。</p>
</main>

### 执行下一步

当任务状态为 **等待确认** 或 **执行中**，且存在 `autoRun=false` 的已就绪步骤时，单击 **执行下一步** 可推进人工步骤。

* 若存在多个可推进的步骤，需选择要推进的步骤序号。
* 执行下一步时需显式确认，未确认不允许推进。

### 重试失败步骤

当步骤执行失败时，支持以下重试操作：

* **重试所有失败步骤**：当执行实例整体状态为 **FAILED** 时，可一次性重试全部失败步骤。

* **重试指定失败步骤**：对状态为 **FAILED** 的单个步骤进行重试。执行实例整体不要求处于 **FAILED** 状态，但指定步骤必须为 **FAILED**。

### 更新步骤配置

对已启动任务中处于 **PENDING** 状态的步骤，您可以更新其配置：

* **修改自动执行开关**：只有模板中标记为可编辑（editable=true）的步骤才允许修改。
* **设置步骤参数**：可在步骤执行前保存步骤级参数。不同 SOP 类型/步骤的可配置参数不同：
  * **OBServer 异常后数据重建** 的 **添加 OBServer** 步骤：可设置替代主机 ID（`replacementHostId`）和替代主机 IP（`replacementHostIp`）。
  * **重建备租户** 的 **创建备租户** 步骤：可设置创建新备租户的完整参数（`createStandbyTenantParamJson`），包括租户名称、兼容模式、主租户 ID、备集群 ID、日志传输方式、Zone 副本配置、租户参数等。

### 编辑任务

对 **待执行** 状态的任务，单击 **编辑** 可修改任务的名称、目标参数、步骤配置和备注。任务类型不可修改，服务端始终沿用任务原类型。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>已启动的任务不允许编辑。任务已有执行实例时将返回错误。</p>
</main>

### 删除任务

* **待执行** 状态的任务可直接删除。
* **已结束** 和 **失败** 状态的任务可删除。
* **等待确认** 和 **执行中** 状态的任务不允许删除。

删除任务会级联清理执行实例、步骤执行记录和步骤关联任务记录。

## 步骤标识说明

不同 SOP 类型的步骤标识如下，创建和编辑任务时步骤数组只能使用对应类型的标识。

| SOP 类型 | 步骤标识（按默认步骤顺序） |
|----------|------------------------|
| 重建备租户 | 确认备租户信息（CONFIRM_STANDBY_TENANT_INFO）、备份主租户（BACKUP_PRIMARY_TENANT）、断开备租户（DISCONNECT_STANDBY_TENANT）、锁定备租户（LOCK_STANDBY_TENANT）、删除备租户（DELETE_STANDBY_TENANT）、创建备租户（CREATE_STANDBY_TENANT）、验证主备同步（VERIFY_PRIMARY_STANDBY_SYNC） |
| 副本异常开启仲裁服务 | 确认仲裁目标（CONFIRM_ARBITRATION_TARGET）、添加仲裁服务（ADD_ARBITRATION_SERVICE）、删除租户副本（DELETE_TENANT_REPLICA）、删除 OBServer（DELETE_OBSERVER）、启用租户仲裁（ENABLE_TENANT_ARBITRATION）、验证租户仲裁（VERIFY_TENANT_ARBITRATION） |
| OBServer 异常后数据重建 | 确认 OBServer 目标（CONFIRM_OBSERVER_TARGET）、删除租户副本（DELETE_TENANT_REPLICA）、删除 OBServer（DELETE_OBSERVER）、强制删除主机（FORCE_DELETE_HOST）、添加 OBServer（ADD_OBSERVER）、添加租户副本（ADD_TENANT_REPLICA）、验证副本重建（VERIFY_REPLICA_REBUILD） |
