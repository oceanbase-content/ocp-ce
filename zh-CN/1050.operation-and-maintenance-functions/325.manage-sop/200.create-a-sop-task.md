# 新建标准运维流程

本节介绍如何在 OCP 中新建标准运维流程（SOP）任务。

## 前提条件

* 当前登录 OCP 的用户具备 **集群管理**、**租户管理** 或 **主机管理** 任一资源权限。
* 运维管理 **标准流程** 菜单权限。

<main id="notice" type='notice'>
<h4>功能适用性</h4>
<p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

## 背景说明

当您需要对 OceanBase 集群、租户或主机执行标准化的故障恢复操作时，可通过新建 SOP 任务来完成。OCP 提供了预置的流程模板，您只需选择任务类型并配置目标参数和步骤，即可创建标准运维流程任务。

## 操作步骤

1. 登录 OCP。

2. 在左侧导航栏中单击 **运维管理** > **标准流程**。

3. 在 **标准流程** 页面单击 **新建**，系统弹出 **新建标准运维流程** 对话框。

4. 在 **新建标准运维流程** 对话框中配置如下信息。

   1. 配置基础信息。

      | 参数 | 说明 |
      |------|------|
      | **任务名称** | 输入任务的名称。需满足以下规则：<ul><li>支持 2～32 个字符。</li><li>仅支持以中文、日文字符或英文字母开头。</li><li>仅支持以中文、日文字符、英文字母或数字结尾。</li><li>特殊符号仅支持下划线。</li></ul>任务名称全局唯一。 |
      | **任务类型** | 选择 SOP 任务类型。支持选择 **重建备租户**、**副本异常开启仲裁服务** 或 **OBServer 异常后数据重建**，各类型说明详情参见 [标准运维流程概述](100.sop-overview.md#sop-类型说明)。 |
      | **备注**（可选） | 输入任务的备注信息，用于记录任务用途或说明。 |
      | **立即执行** | 勾选后，任务创建成功后将立即启动执行；不勾选时，任务创建后状态为 **待执行**，您可稍后手动启动。 |

   2. 根据所选任务类型，配置目标参数。

      * **重建备租户**：需选择待重建的备租户所属集群和备租户，并选择日志传输方式（网络传输或日志备份）。

      * **副本异常开启仲裁服务**：需选择目标集群，并选择仲裁服务或仲裁服务组（二选一）。

      * **OBServer 异常后数据重建**：需选择目标集群，可选预选替代主机。若未选择替代主机，可在执行 **添加 OBServer** 步骤前设置。

   3. 配置步骤。

      系统会根据所选任务类型自动加载默认步骤模板。您可查看并调整各步骤的配置：

      | 参数 | 说明 |
      |------|------|
      | 步骤序号 | 步骤的执行顺序，从 1 开始。允许移动的步骤可在模板范围内调整位置。 |
      | 步骤名称 | 当前步骤的展示名称。 |
      | 步骤类型 | **EXECUTABLE**：执行类步骤，可能创建 OCP 任务实例；**CONFIRMATION**：确认类步骤，通过人工执行下一步确认推进。 |
      | **自动执行** | 开启后该步骤在前一步完成后自动触发；关闭后该步骤需要人工确认后才会推进。部分步骤的自动执行开关不可修改。 |
      | **启用** | 是否启用该步骤。部分步骤固定启用且不可关闭。需至少保留一个启用的步骤。 |

      <main id="notice" type='explain'>
      <h4>说明</h4>
      <p><ul><li>步骤的 <b>stepKey</b> 必须属于模板且不可重复。</li><li>固定启用的步骤必须保留，不可关闭。</li><li>步骤的自动执行开关是否可修改取决于模板中该步骤的 <b>editable</b> 属性。</li></ul></p>
      </main>

5. 单击 **新建**。

   * 若勾选了 **立即执行**，任务创建后自动启动执行，页面跳转至执行详情页面。
   * 若未勾选 **立即执行**，任务创建成功后状态为 **待执行**，您可在任务列表中查看，并随时启动执行。

## 后续操作

* 对 **待执行** 状态的任务，您可以启动执行、编辑任务配置或删除任务。
* 对执行中的任务，您可以查看执行详情、执行下一步、重试失败步骤或更新步骤配置，详情参见 [查看标准运维流程执行详情](300.view-sop-execution-details.md)。
