# 主备租户日常切换

本页面为您介绍主备租户日常切换的操作步骤。根据不同的业务需要，您可选择如下方式进行主备租户的日常切换。

* 方式一：对指定主备租户进行日常切换。
* 方式二：对集群下的所有主备租户进行日常切换。

## 方式一：对指定主备租户进行日常切换

该方式适用于将指定主租户切换为备租户的场景。

### 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概览</UI-TERM>** 菜单权限。

* 当前主租户存在可用备租户，且备租户处于 **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常运行</UI-TERM>** 状态。

### 注意事项

* 建议主备租户均已设置相同服务名，且主备租户所属的 OceanBase 集群已关联至相同的 OBProxy 集群，否则切主后无法实现自动路由。
* 若原主租户用于承载 Binlog Service 的 MetaDB 信息，主备租户切换将会导致 Binlog 服务不可用，请谨慎操作。
* 执行主备租户日常切换后，主备保护模式可能会发生变化：
  * 一主一备模式下，切换后的主备保护模式不受影响。
  * 一主多备模式下，若新主租户的原主备保护模式为最大保护，主备租户切换后，系统将自动延续该保护模式；若原为其它模式，则会统一将所有主备租户的保护模式切换为最大性能。

### 操作步骤

1. 登录 OceanBase 云平台，单击左侧导航栏 **<UI-TERM key="ocp-v2.src.constant.alarm.Tenant">租户</UI-TERM>** ，在 **<UI-TERM key="ocp-v2.component.TenantList.TenantList">租户列表</UI-TERM>** 中进入主租户。

2. 单击右上角更多图标，选择 **<UI-TERM key="ocp-v2.Detail.Component.SwitchoverModal.DailySwitchover">日常切换</UI-TERM>** 。

3. 在对话框中查看租户切换的信息，单击 **切换** 。

    * 当主租户下存在多个备租户时，需在 **<UI-TERM key="ocp-v2.Component.ChangeTenantView.NewMasterTenant">新主租户</UI-TERM>** 的下拉列表中指定需要切换的备租户。若开启了 OCP 多集群模式，下拉列表中还会包含远程 OCP 集群管理的备租户。
    * 当所选择备租户的同步方式为 **<UI-TERM key="ocp-v2.src.constant.tenant.ArchiveBased">基于归档</UI-TERM>** 且该备租户未启用归档时，需先配置归档地址。具体参数说明如下：

      |  参数  |  说明   |
      |--------|---------|
      | 存储类型  | 备份文件存储介质，取值范围：<ul><li>File：本地文件存储，一般为 NFS。</li><li>OSS：阿里云 OSS 对象存储，仅 OceanBase V2.2.76 及以上版本支持。</li></ul>|
      | 存储目录        | 备份文件在当前介质上的存储目录。<main id="notice" type='explain'><h4>说明</h4><p>主租户与备租户需具有该目录的读写权限。</p></main>  |
      | 访问域名        | 当 **<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageType">存储类型</UI-TERM>** 选择 OSS 时展示，填写备份文件云存储端的域名。支持在域名后添加端口号，如：`oss.ap-shanghai.myqcloud.com:8080`。 |
      | 访问用户        | 当 **<UI-TERM key="ocp-v2.src.component.ArchiveForm.StorageType">存储类型</UI-TERM>** 选择 OSS 时展示，填写访问阿里云存储端的 AccessKey ID。 |
      | 访问秘钥        | 当 **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.StorageType">存储类型</UI-TERM>** 选择 OSS 时展示，填写访问阿里云存储端的 AccessKey Secret。    |

4. 单击对话框中的任务 ID，查看任务进度。

## 方式二：对集群下的所有主备租户进行日常切换

该方式适用于集群运维操作前，为保证业务连续性，需要用备租户支持业务的场景。您可参考此方式，将集群下的所有主租户切换为备租户。

### 前提条件

* 请确保当前登录 OCP 的用户具备如下权限：

  * **集群维护** 或 **租户维护** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概览</UI-TERM>** 菜单权限。

* 当前集群下已创建主租户，且该主租户存在可用备租户。

* 主备租户所属的 OceanBase 集群已关联至相同的 OBProxy 集群，否则切主后无法实现自动路由。

### 注意事项

* 建议主备租户均已设置相同服务名，否则切主后无法实现自动路由。
* 主备租户日常切换可能存在如下影响，为了保证业务的连续性，您需谨慎操作：
  * 若原主租户用于承载 Binlog Service 的 MetaDB 信息时，主备租户切换将会导致 Binlog 服务不可用。
  * 导致新主租户所属集群业务压力过大，请合理评估新主集群的资源消耗情况，并建议在集群运维操作前执行。
* 租户日常切换通常在集群运维操作前执行。请合理评估新主集群的资源消耗情况，避免造成新主租户所属集群的业务高峰期压力过大，为了保证业务的连续性，请谨慎操作。

### 操作步骤

1. 登录 OceanBase 云平台，单击左侧导航栏 **<UI-TERM key="ocp-v2.page.Cluster.Cluster">集群</UI-TERM>** ，在 **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">集群列表</UI-TERM>** 中进入集群 **<UI-TERM key="ocp-v2.page.Overview.Overview">概览</UI-TERM>** 页面。

2. 单击右上角更多图标，选择 **<UI-TERM key="ocp-v2.Detail.Overview.TenantDailySwitching">租户日常切换</UI-TERM>** 。

3. 在对话框中勾选需要切换的租户，单击 **<UI-TERM key="ocp-v2.Detail.Component.SwitchoverModal.DailySwitchover">日常切换</UI-TERM>** 。

    * 当主租户下存在多个备租户时，需在 **<UI-TERM key="ocp-v2.Component.ChangeTenantView.NewMasterTenant">新主租户</UI-TERM>** 下拉列表中选择需要切换为主租户的备租户。若开启了 OCP 多集群模式，则下拉列表中还会包含远程 OCP 集群管理的备租户。

      在进行日常切换前，系统会对主备租户是否满足如下条件进行检查。若检查不通过，则不支持勾选租户进行日常切换：

      * 主备租户均处于 **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常运行</UI-TERM>** 状态。
      * 主备租户所属集群为 **Running** 状态，且集群版本一致。
      * 备租户的的同步延迟不能大于阈值，阈值默认为 5000ms，您可在 **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">系统管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">系统参数</UI-TERM>** 中通过修改 `ocp.standby.tenant.delay.threshold` 参数值来调整阈值大小。

    * 当所选择备租户的同步方式为 **<UI-TERM key="ocp-v2.src.constant.tenant.ArchiveBased">基于归档</UI-TERM>** 且该租户未启用归档时，需先配置归档地址。具体参数说明如下：

      |  参数  |  说明   |
      |--------|---------|
      | 存储类型  | 备份文件存储介质，取值范围：<ul><li>File：本地文件存储，一般为 NFS。</li><li>OSS：阿里云 OSS 对象存储，仅 OceanBase V2.2.76 及以上版本支持。</li></ul>|
      | 存储目录        | 备份文件在当前介质上的存储目录。  <main id="notice" type='explain'><h4>说明</h4><p>主租户与备租户需具有该目录的读写权限。</p></main>  |
      | 访问域名        | 当 **<UI-TERM key="ocp-v2.src.component.ArchiveForm.StorageType">存储类型</UI-TERM>** 选择 OSS 时展示，填写备份文件云存储端的域名。支持在域名后添加端口号，如：`oss.ap-shanghai.myqcloud.com:8080`。 |
      | 访问用户        | 当 **<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageType">存储类型</UI-TERM>** 选择 OSS 时展示，填写访问阿里云存储端的 AccessKey ID。 |
      | 访问秘钥        | 当 **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.StorageType">存储类型</UI-TERM>** 选择 OSS 时展示，填写访问阿里云存储端的 AccessKey Secret。    |

4. 单击对话框中的任务 ID，查看任务进度。
