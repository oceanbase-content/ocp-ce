# 管理活跃会话报告

本节为您介绍查看和下载活跃会话报告的方法。通过该报告，您能够了解历史诊断时间内占用数据库资源较高的 SQL，以及 OceanBase 集群历史会话的执行详情等信息。您可根据这些信息优化 SQL 从而提高 SQL 的执行效率。

您可通过以下两个入口查看及下载活跃会话报告：

* **入口一**：登录 OCP，在左侧导航栏单击 **诊断服务**，选择需要查看的集群，进入集群 **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">报告中心</UI-TERM>** 页面。

* **入口二**：登录 OCP，进入租户 **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概览</UI-TERM>** 页面。在左侧单击 **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">会话管理</UI-TERM>** ，并进入 **活跃会话报告** 页签。

<main id="notice" type='notice'>
  <h4>功能适用性</h4>
  <p>该内容仅适用于 OCP 企业版，OCP 社区版不提供此功能。</p>
</main>

## 前提条件

* 当通过 **入口一** 管理活跃会话报告时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 诊断服务 **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">报告中心</UI-TERM>** 菜单权限。

* 当通过 **入口二** 管理活跃会话报告时，请确保当前登录 OCP 的用户具备如下权限：

  * **集群只读** 或 **租户只读** 资源权限。
  * 租户 **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">会话管理</UI-TERM>** 菜单权限。

* 已在 [管理参数](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md) 中开启 **<UI-TERM key="ocp-v2.src.constant.parameter.ActiveSessionHistoryCollection">活跃会话历史采集</UI-TERM>** 模块参数。

## 操作步骤

以下操作均以 **入口一** 为例。

### 查看 ASH 报告

1. 登录 OCP。

2. 在左侧导航栏中，单击 **诊断服务**。

3. 在 **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">集群详情</UI-TERM>** 区域，单击需要查看的集群名称，系统默认进入 **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">实时诊断</UI-TERM>** 页面。

4. 单击左侧导航栏 **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">报告中心</UI-TERM>**，进入 **活跃会话报告** 页签。

5. 对 **租户**、**节点**、**时间范围**、**SQL ID**、**TraceID** 和 **WaitClass** 信息进行筛选和填写，单击 **查看 ASH 报告**。

6. 系统将跳转至 **ASH Report** 页面，并在该页面中为您展示满足筛选条件的报告内容。

### 下载 ASH 报告

1. 登录 OCP。

2. 在左侧导航栏中，单击 **诊断服务**。

3. 在 **集群详情** 区域，单击需要查看的集群名称，系统默认进入 **实时诊断** 页面。

4. 单击左侧导航栏 **报告中心**，进入 **活跃会话报告** 页签。

5. 对 **租户**、**节点**、**时间范围**、**SQL ID**、**TraceID** 和 **WaitClass** 信息进行筛选和填写，单击 **下载 ASH 报告**，即可将 html 格式的 ASH 报告下载到本地。
