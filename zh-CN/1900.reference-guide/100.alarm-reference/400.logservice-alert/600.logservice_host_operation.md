# logservice_host_operation LogService 集群节点运维操作提醒

## 告警描述

该告警表示 LogService 集群中某个 **节点发生了运维操作**（如添加节点、重启、替换等）。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

|  参数     |                      值                      |
|-----------|---------------------------------------------|
| 监控指标   | 无（事件类告警）  |
| 指标说明   | 由 OCP 在 LogService 节点运维操作完成时主动上报 |
| 监控表达式 | 事件触发（expression_type: Event） |
| 采集指标   | operation_name、operation_result、operator、task_result、host      |
| 指标来源   | OCP 运维事件（Event）       |
| 采集周期   | 实时事件触发       |

## 规则信息

|  监控指标      | 默认阈值 | 持续时间 |   检测周期    | 消除周期 |
|----------------|---------|----------|---------------|--------|
| - | -       | 0 秒    | 0 秒         | 5 分钟 |

> 默认状态：is_enabled: 0（默认关闭，可按需开启）

## 告警信息

|   告警触发方式   | 告警等级 | 范围  |
|------------|------|-----|
| 基于运维事件 | 提醒   | 主机（LogService） |

## 告警模板

* **告警概述**

  * 模板：\${alarm_target} ${operation_result}
  * 样例：logservice_cluster=my_ls_cluster:host=11.124.9.47 成功

* **告警详情**

  * 模板：LogService集群：${logservice_cluster}，节点：${host}，告警：${operation_name} ${operation_result}, 操作者 ${operator}，运行结果：${task_result}。
  * 样例：LogService集群：my_ls_cluster，节点：11.124.9.47，告警：重启节点 成功, 操作者 admin，运行结果：成功。

* **告警恢复**

  * 自动消除（auto_resolved: 1），消除周期 5 分钟。

## 对系统的影响

节点级运维可能导致该节点短暂不可用；操作失败时节点可能处于异常状态。

## 可能原因

* 管理员在 OCP 控制台对 LogService 集群节点执行了运维操作

## 处理方法

1. 确认是否为计划内节点运维
2. 操作完成后检查节点进程状态与监控指标
3. 若操作失败，根据任务详情排查并处理
