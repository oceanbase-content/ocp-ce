# logservice_cluster_operation_info LogService 集群运维操作提醒

## 告警描述

该告警表示 LogService 集群发生了 **运维操作**（如创建、扩容、升级等），用于操作审计与提醒。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

|  参数     |                      值                      |
|-----------|---------------------------------------------|
| 监控指标   | 无（事件类告警）  |
| 指标说明   | 由 OCP 在 LogService 集群运维操作完成时主动上报 |
| 监控表达式 | 事件触发（expression_type: Event） |
| 采集指标   | operation_name、operation_result、operator、task_result      |
| 指标来源   | OCP 运维事件（Event）       |
| 采集周期   | 实时事件触发       |

## 规则信息

|  监控指标      | 默认阈值 | 持续时间 |   检测周期    | 消除周期 |
|----------------|---------|----------|---------------|--------|
| - | -       | 0 秒    | 0 秒         | 5 分钟 |

> 默认状态：is_enabled: 0（默认关闭，可按需开启）

## 告警信息

|   告警触发方式   | 告警等级 | 范围  |
|------------|------|-----|
| 基于运维事件 | 提醒   | 集群（LogService） |

## 告警模板

* **告警概述**

  * 模板：\${alarm_target} ${operation_result}
  * 样例：logservice_cluster=my_ls_cluster 成功

* **告警详情**

  * 模板：LogService集群：${logservice_cluster}，告警：${operation_name} ${operation_result}，操作者 ${operator}，运行结果：${task_result}。
  * 样例：LogService集群：my_ls_cluster，告警：升级集群 成功，操作者 admin，运行结果：成功。

* **告警恢复**

  * 自动消除（auto_resolved: 1），消除周期 5 分钟。

## 对系统的影响

运维操作本身为计划内行为；若操作失败，可能影响 LogService 集群可用性或配置一致性。

## 可能原因

* 管理员在 OCP 控制台执行了 LogService 集群级运维操作

## 处理方法

1. 确认是否为计划内运维操作
2. 若 task_result 为失败，查看 OCP 任务详情与操作日志
3. 根据失败原因重试或回滚操作
