# tenant_macro_usage_percent_over_threshold OceanBase 租户宏块利用率百分比超限

## 告警描述

该告警监测 OceanBase 集群下，存在宏块利用率低于目标阈值的租户。

## 告警原理

## 对系统的影响

宏块利用率低，即代表存储空间的利用率低、业务表存在大量空洞，容易造成存储资源浪费，难以做到降本增效。当业务表空洞率较高时，磁盘使用率会快速攀升，从而引发一系列运维问题，例如集群停写、合并失败、备份失败以及分区迁移失败等。

## 可能原因

业务表空间空洞率较高。

## 处理方法

1. 登录目标业务租户，进入目标数据库，参考如下命令修改目标表的渐近合并模式：

    ```sql
    alter table eol_vin_security set progressive_merge_num=20;
    alter table eol_vin_security set pctfree = 1;
    ```

2. 通过 OCP 对集群执行多次合并（最多 20 次），合并过程中监控数据空洞率情况是否明显改善。

3. 合并完成后，登录目标业务租户，进入目标数据库，参考如下命令关闭表的渐近模式：

    ```sql
    alter table eol_vin_security set progressive_merge_num=0;
    alter table eol_vin_security set pctfree = 0;
    ``
