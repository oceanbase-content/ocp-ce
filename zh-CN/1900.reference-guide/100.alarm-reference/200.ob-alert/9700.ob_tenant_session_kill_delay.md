# ob_tenant_session_kill_delay 租户 Session Killed 延迟

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对 V4.2.1.0 及以上版本的 OceanBase 集群生效。
</main>

该告警监测 OceanBase 租户 Session 长时间处于 Kill 状态。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

|  参数        |  值      |
|--------------|----------|
|  监控指标    |  ob_tenant_session_kill_delay，该指标表示租户 Session Killed 的延迟时间，时长大于阈值时触发告警。   |
|  监控表达式  |  `max(session_kill_delay_second)`   |
|  采集指标    |  session_kill_delay_second   |
|  数据来源    |  SQL 采集：<ul><li>OceanBase V4.2.1.0 及以上、V4.2.5.7 以下版本：```select svr_ip, svr_port, tenant_id, tenant, id as session_id, time from oceanbase.__all_virtual_processlist where state='SESSION_KILLED';```</li><li>OceanBase V4.2.5.7 及以上、V4.3.0.0 版本以下：```select svr_ip, svr_port, tenant_id, tenant, id as session_id, time from oceanbase.__all_virtual_processlist where state='SESSION_KILLED'and top_info is null;```</li><li>OceanBase V4.3.0.0 及以上、V4.4.1.0 以下版本：```select svr_ip, svr_port, tenant_id, tenant, id as session_id, time from oceanbase.__all_virtual_processlist where state='SESSION_KILLED';```</li><li>OceanBase V4.4.1.0 及以上版本：```select svr_ip, svr_port, tenant_id, tenant, id as session_id, time from oceanbase.__all_virtual_processlist where state='SESSION_KILLED'and top_info is null;```</li></ul>   |
|  采集周期    |  5 秒   |

## 规则信息

|  监控指标  |  默认阈值（单位：秒）  |  持续时间  |  检测周期  |  消除周期   |
|------------|-----------------------|------------|-----------|--------------|
|  session_kill_delay_second  |  600  |  0 秒  |  60 秒  |  6 分钟   |

## 对系统的影响

会话长时间无法退出，会导致该会话持续占用线程资源。若存在多个会话无法退出，可能会影响正常请求的处理。

## 可能原因

* 对应会话正在执行不可被中断的数据库任务，需等待任务执行到 Session 状态检查点时才可退出。
* 数据库会话执行出现异常，导致会话无法退出。

## 处理方法

* 确认超时时间关系。检查会话无法被 Kill 的持续时间是否已超过对应租户的 SQL 语句超时时间（ob_query_timeout）。若尚未超时，可暂不干预，等待语句自然超时后，观察告警是否自动恢复。

* 评估资源影响并进行决策。若会话阻塞时间已超过 SQL 超时阈值，但告警仍未消除，且存在大量无法 Kill 的会话，这些会话可能持续占用线程资源，进而影响正常请求的处理。此时建议评估业务影响后，重启对应的 OBServer 节点以释放异常会话和相关资源，并收集告警对应的信息采集信息，联系技术支持协助解决。
