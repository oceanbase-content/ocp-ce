# ob_tenant_log_stream_leader_absent OceanBase 租户日志流无主

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对 V4.0.0.0 及以上版本的 OceanBase 集群生效。
</main>

该告警用于识别租户内日志流（LS）Leader 异常场景：当某个日志流 Leader 数量不为 1（无主或多主）时，判定该日志流异常并触发告警。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

| 参数    | 值      |
| ------- | ------- |
| 监控指标 | ob_tenant_log_stream_no_leader，该指标表示租户日志流是否存在无主，当值为 1 时触发告警。 |
| 监控表达式 | ob_tenant_log_stream_no_leader{@LABELS} |
| 采集指标 | ob_tenant_log_stream_no_leader |
| 指标来源 | OCP 定时任务巡检（非 Agent 采集），采集 SQL：<li>LS1 Leader 检查：`SELECT tenant_id FROM __all_virtual_log_stat WHERE ls_id = 1 AND role = 'LEADER'`</li><li>其他 LS Leader 统计：`SELECT a.tenant_id, a.ls_id, COUNT(*) as leader_count FROM CDB_OB_LS a INNER JOIN CDB_OB_LS_LOCATIONS b ON a.tenant_id = b.tenant_id AND a.ls_id = b.ls_id AND b.role = 'LEADER' WHERE a.status NOT IN ('creating', 'create_abort') GROUP BY a.tenant_id, a.ls_id`</li> |
| 检测周期  | 60 秒 |

## 规则信息

| 监控指标 | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
| -------- | -------- | -------- | ------- | ---------- |
| ob_tenant_log_stream_no_leader |  1 | 180 秒 | 60 秒 | 5 分钟 |

## 对系统的影响

* 对 OceanBase 租户的影响：日志流无主会影响该日志流的读写可用性与故障恢复能力。

* 对 OCP 的影响：OCP 会持续产生日志流维度告警，提示运维尽快恢复 Leader 选举状态。

* 对业务的影响：可能出现请求失败、延迟升高或部分业务不可用。

## 可能原因

* 多数派副本不可用，导致无法完成 Leader 选举。

* 节点宕机、网络分区或机房故障导致副本失联。

* 副本角色异常或日志流元信息不一致导致选主失败。

## 处理方法

1. 优先检查异常日志流所在租户与节点状态，恢复故障节点/网络连通性。

2. 检查副本分布与多数派是否满足，确认日志流具备选主条件。

3. 观察 ob_tenant_log_stream_no_leader 指标恢复为 0（同标签维度）后，确认告警自动恢复。

4. 若持续异常，结合日志流与副本诊断结果进行进一步修复（如副本重建、迁移、故障节点替换）。
