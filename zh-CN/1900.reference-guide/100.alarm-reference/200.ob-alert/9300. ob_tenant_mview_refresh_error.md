# ob_tenant_mview_refresh_error 租户物化视图自动刷新异常

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对 V4.3.5.0 及以上版本的 OceanBase 集群生效。
</main>

该告警监测租户下数据库中的物化视图刷新是否存在异常。若存在异常，则上报告警。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

| 参数 | 值  |
|------|------|
| 监控指标 | tenant_mview_refresh_error_count，该指标表示租户下数据库中物化视图的刷新异常个数，当其值大于阈值时触发告警。  |
| 监控表达式 | ``````  |
| 采集指标  | tenant_mview_refresh_error_count  |
| 数据来源 |   |
| 采集周期 | 5 秒  |

## 规则信息

| 监控指标 | 默认阈值 | 持续时间 | 检测周期 | 消除周期  |
|------|------|------|------|------|
| tenant_mview_refresh_error_count | 0 | 0 秒 | 10 秒 | 5 分钟  |

## 告警信息

| 告警触发方式 | 告警等级 | 范围  |
|------|------|--------|
| 基于监控指标的表达式 | 严重 | 租户  |

## 告警模板

* **告警概述**

  * 模板：${alarm_target} ${alarm_name}
  * 样例：alarm_template_id=0:ob_cluster=test471-11:tenant_name=mysqlTes:database=test:mview_name=test_mv_refresh_retry_mv2 租户物化视图自动刷新异常

* **告警详情**

  * 模板：OceanBase 集群 ${ob_cluster_name} 中租户 ${tenant_name} 中数据库 ${database} 中物化视图 ${mview_name} 异常，结果 ${result}，刷新时间 ${start_time}。
  * 样例：OceanBase 集群 test471 中租户 mysqlTes 中数据库 test 中物化视图 test_mv_refresh_retry_mv2 异常，结果 -5024，刷新时间 2025-11-14T16:13:55.026383+08:00。

* **告警恢复**

  * 模板：告警：${alarm_name}，OceanBase 租户 UNIT 是否可连接：\${recover_value}
  * 样例：告警：OceanBase 租户无法连接，OceanBase 租户 UNIT 是否可连接：1

## 对系统的影响

可能导致物化视图不再刷新数据。

## 可能原因

系统内部异常。

## 处理方法

1. 在默认配置下，物化视图刷新报错之后只能获取 Trace ID 及错误码，获取方式如下：

    ```sql
    SELECT D.tenant_name,
       A.database_name,
       B.table_name AS mview_name,
       B.last_refresh_trace_id,
       B.last_refresh_time
    FROM   oceanbase.__all_virtual_database A,
       oceanbase.__all_virtual_table B,
       oceanbase.__all_virtual_mview C
    WHERE A.tenant_id = B.tenant_id
       AND B.tenant_id = C.tenant_id
       AND A.database_id = B.database_id
       AND B.table_id = C.mview_id;
    ```

2. 通过 Trace ID、刷新时间等信息，在集群 observer 日志目录下收集相关错误日志，并联系 OCP 技术支持协助排查。
