# cluster_cgroup_value_inconsistent 集群下的 cgroup 值不一致

## 告警描述

该告警监测 OceanBase 集群中各节点的 enable_cgroup 参数配置是否一致。当集群内不同 OBServer 节点的 enable_cgroup 参数值不统一时触发告警。

## 告警原理

| 参数     | 值      |
| -------- | -------- |
| 监控指标 | cluster_cgroup_value |
| 监控表达式 | `max(cluster_cgroup_value{@LABELS}) by (@GBLABELS)` |
| 采集指标 | cluster_cgroup_value   |
| 指标来源 | OCP 主动检测 |
| 采集周期 | 60 秒 |

OCP 通过定时任务 CheckClusterCgroupValueTask 对每个 OceanBase 集群进行 cgroup 配置一致性检查。具体原理如下：

1. OCP 检查集群版本是否满足 cgroup 功能的最低版本要求，不满足则跳过。

2. 查询集群所有节点的 enable_cgroup 参数值。

3. 对查询结果做去重（distinct）操作，统计去重后的值数量。

4. 如果去重后的值数量不等于 1（即各节点的 enable_cgroup 值不完全一致），则将指标 cluster_cgroup_value 设为 1（告警状态）；否则设为 0（正常状态）。

当指标值等于 1 时，满足触发条件，产生告警。

## 规则信息

| 监控指标   | 默认阈值 | 持续时间 | 检测周期 | 消除周期 |
| ---------- | ------- | -------- | -------- | -------- |
| cluster_cgroup_value  | 1 | 120 秒 | 60 秒 | 300 秒 |

## 告警信息

| 告警触发方式 | 告警等级 | 范围     |
| ------------ | ------- | -------- |
| 基于监控指标的表达式 | 警告  | 集群 |

## 告警模板

* **告警概述**
  * 模板：${alarm_target} ${alarm_name}
  * 样例：ob_cluster=obcluster1 集群下的 cgroup 值不一致

* **告警详情**
  * 模板：OceanBase 集群 ${ob_cluster_name} 下的 cgroup 值可能不符合预期，请刷新 ${ob_cluster_name} 集群概览页，并查看 cgroup 值是否与概览页的一致，若不一致请修改，若一致此告警将自动消除。
  * 样例：OceanBase 集群 obcluster1 下的 cgroup 值可能不符合预期，请刷新 obcluster1 集群概览页，并查看 cgroup 值是否与概览页的一致，若不一致请修改，若一致此告警将自动消除。

* **告警恢复**
  * 模板：告警：${alarm_name}，集群下的 cgroup 值是否一致：${value_shown}
  * 样例：告警：集群下的 cgroup 值不一致，集群下的 cgroup 值是否一致：0

## 对系统的影响

集群内 enable_cgroup 参数值不一致意味着部分节点启用了 cgroup 资源隔离而部分节点未启用，可能造成以下影响：

* 资源隔离不统一：启用 cgroup 的节点可以限制租户 CPU 使用，未启用的节点则无此限制，导致租户在不同节点上的资源使用行为不一致。未启用 cgroup 的节点上，租户之间可能出现 CPU 资源争抢，影响业务稳定性。

* 性能表现不可预期：同一租户在不同节点上的性能表现可能出现差异，增加运维排障难度。

## 可能原因

* 运维人员手动修改了部分节点的 enable_cgroup 参数，但未全集群统一变更。

* 其他未知原因。

## 处理方法

1. 确认告警信息：根据告警中的集群名称（ob_cluster_name）定位到具体集群。

2. 查看当前 cgroup 配置：在 OCP 控制台打开对应集群的概览页，查看集群级别的 cgroup 配置状态。也可通过 SQL 查询各节点的参数值：

   ```sql
   SHOW PARAMETERS LIKE 'enable_cgroup';
   ```

   确认哪些节点的值不一致。

3. 统一 cgroup 配置：

   * 方式一（推荐）：通过 OCP 控制台的集群参数管理功能，统一修改所有节点的 enable_cgroup 参数，确保集群内所有节点配置一致。

   * 方式二：通过 SQL 命令在集群级别统一设置参数：

     ```sql
     ALTER SYSTEM SET enable_cgroup = 'True';
     ```

     或

     ```sql
     ALTER SYSTEM SET enable_cgroup = 'False';
     ```

4. 刷新集群概览：修改完成后，刷新 OCP 上对应集群的概览页，确认 cgroup 值已统一。

5. 验证修复结果：修复后等待下一个检测周期（60 秒），观察告警是否自动消除。如果配置已一致，告警将在消除周期（300 秒）内自动清除。
