# ob_tenant_mview_refresh_delay 租户物化视图自动刷新不及时

## 告警描述

<main id="notice" type='explain'>
<h4>说明</h4>
此告警仅针对 V4.3.5.0 及以上版本的 OceanBase 集群生效。
</main>

该告警监测租户下数据库中的物化视图刷新是否延迟。若存在延迟，则上报告警。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

| 参数 | 值  |
|------|------|
| 监控指标 | tenant_mview_refresh_delay，该指标表示租户下数据库中物化视图的刷新延迟时间，当其值大于阈值时触发告警。  |
| 监控表达式 | ``````  |
| 采集指标  | tenant_mview_refresh_delay  |
| 数据来源 |   |
| 采集周期 | 5 秒  |

## 规则信息

| 监控指标 | 默认阈值 | 持续时间 | 检测周期 | 消除周期  |
|------|------|------|------|------|
| tenant_mview_refresh_delay | 0 | 0 秒 | 10 秒 | 5 分钟  |

## 告警信息

| 告警触发方式 | 告警等级 | 范围  |
|------|------|--------|
| 基于监控指标的表达式 | 警告 | 租户  |

## 对系统的影响

将无法保障物化视图的时效性。

## 可能原因

增量数据太多或刷新计划不优。

## 处理方法

1. 参考如下命令查询物化视图相关的会话：

    ```sql
    select id, svr_ip, svr_port, tim, info
    from oceanbase.__all_virtual_processlist
    where info like '%test_mv_refresh_retry_mv1%'\G
    ```

2. 若存在执行时长过久的物化视图相关会话，参考如下命令进一步查看当前正在执行的计划：

    ```sql
    select dbms_xplan.display_active_session_plan(id, 'all', svr_ip, svr_port)\G
    ```

3. 分析计划信息，排查刷新耗时过长的问题。如有必要可联系 OCP 技术支持协助排查。
