# arbitration_node_connection_with_observer_error Arbitration 节点无法连接 observer

## 告警描述

该告警表示仲裁服务节点无法连接对应的 observer。

## 告警原理

下表列出了该告警监控逻辑中涉及的关键参数。

| 参数     | 值       |
| -------- | ---------- |
| 监控指标 | N/A |
| 监控表达式 | `{日志级别=EDIAG，关键字=arb active keepalive probe_connectivity，持续时长=0 秒，告警等级=停服}` |
| 采集指标 | arbitration_log |
| 指标来源 | 仲裁服务日志，例如 `/home/admin/oceanbase/log/observer.log`。 |
| 检测周期（毫秒） | 500 |

## 对系统的影响

仲裁副本和 Follower 网络隔离，可能导致 Leader 宕机时无法选举，影响 2F1A/4F1A 的高可用能力。故障发生时，将直接影响系统服务。

## 可能原因

* 硬件故障。
* 防火墙、iptable 等配置故障。
* 路由器、网关配置不通。

## 处理方法

1. 修复硬件。
2. 修复节点软件配置。
3. 修复路由器、网关配置。
