# ob_tenant_info_sync_failed OceanBase 租户信息同步失败

## 告警描述

该告警表示 OCP 从 OceanBase 集群同步租户信息失败。当后台执行 “同步租户” 任务时发生异常，OCP 会将该集群的系统租户（sys）标记为不可用，并发送本告警，用于提示管理员租户信息同步失败及失败原因。

* **告警详情**

  * 样例：集群：obcluster1，租户：sys:1，告警：OceanBase 租户信息同步失败。租户 sys:1 信息同步失败，报错为：Connection refused。

## 对系统的影响

租户信息同步失败可能造成：

* 集群系统租户显示不可用：系统租户在 OCP 侧为 UNAVAILABLE，直至同步成功并恢复状态。

* 租户视图不准确：该集群下租户列表、状态、规格等可能过期或错误，控制台展示与 OceanBase 中的信息实际不一致。

* 依赖租户信息的操作受限：创建/删除租户、修改白名单、扩缩容等依赖最新租户信息的操作可能失败或基于错误数据执行。

## 可能原因

* 集群不可达：因集群升级、重启等操作，导致 OCP 无法连接 OceanBase 集群。

* OCP 或元数据库异常：OCP 服务、元数据库异常导致同步任务执行失败。

## 处理方法

1. 确认告警信息：根据告警中的集群名（ob_cluster_name）、租户名（tenant_name，通常为 sys）、ob_tenant_id 和 error_message 定位集群与失败原因。

2. 根据 error_message 排查：

   * 连接类错误（Connection refused / timeout）：检查 OCP 到 OceanBase 网络、OceanBase 进程与端口、白名单。

   * 超时：检查 OceanBase 负载、慢 SQL、网络延迟，必要时调大超时时间。

   * 权限/语法错误：检查 OCP 连接账号权限及 OceanBase 版本兼容性。

3. 根据 error_message 错误类型进行修复并观察。
