# 进程文件句柄数

本节为您介绍主机进程的监控指标 **进程文件句柄数** 。

## 指标详解

| 项目 | 内容 |
| --- | --- |
| **OCP 展示名** | 进程文件句柄数 |
| **原始指标** | `process_fd_count` |
| **采集 API** | `proc.NumFDs()` |
| **Linux 数据源** | 统计 `/proc/<pid>/fd/` 目录下的条目数 |
| **含义** | 进程当前打开的 fd 数量（文件、socket、pipe 等） |
| **OCP 聚合** | `avg(process_fd_count{name="observer"})` |
| **关联指标** | `observer_fd_usage` = fd 数 ÷ `observer_ulimit_max_fd_count`（句柄使用率 %） |

### 多同名进程处理策略

当存在多个同名进程时，取 **最大值**（`math.Max()`）。

## observer 进程

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_fd_count | -     |

### 计算表达式

```
avg(process_fd_count{name="observer",@LABELS}) by (@GBLABELS)
```

### 句柄使用率计算表达式

```
round(100 * avg(process_fd_count{name="observer"}) / avg(observer_ulimit_max_fd_count))
```

### 验证命令

```bash
PID=$(pidof observer)

# 句柄总数
ls /proc/$PID/fd 2>/dev/null | wc -l

# 看 ulimit 上限
cat /proc/$PID/limits | grep "open files"

# 按类型粗看（socket 居多常见于 OB）
ls -l /proc/$PID/fd 2>/dev/null | awk '{print $NF}' | sed 's/.*\[//' | sed 's/\].*//' | sort | uniq -c | sort -rn | head
```
