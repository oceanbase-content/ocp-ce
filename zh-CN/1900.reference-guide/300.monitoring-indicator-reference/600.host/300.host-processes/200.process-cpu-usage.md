# 进程 CPU 使用率

本节为您介绍主机进程的监控指标 **进程 CPU 使用率** 。

## 指标详解

| 项目 | 内容 |
| --- | --- |
| **OCP 展示名** | 进程 CPU 使用率 |
| **原始指标** | `process_cpu_percent` |
| **采集 API** | `proc.Percent(1 * time.Second)` |
| **Linux 数据源** | `/proc/<pid>/stat` 字段 14（utime）+ 15（stime） |
| **采样方式** | 读一次 → **sleep 1s** → 再读一次，算增量 |
| **计算公式** | `(ΔCPU时间秒数 / 1秒) × 100` |
| **口径** | **每核满负载 = 100%**，多核累加；64 核无超线程理论峰值 **6400%** |
| **OCP 聚合** | `avg(process_cpu_percent{name="observer"})` |
| **归一化指标** | `observer_process_cpu_percent_per_cpu` = 进程 CPU ÷ `cpu_count`（0~100% 整机占比） |

### 多同名进程处理策略

当存在多个同名进程时，**直接覆盖**（取遍历到的最后一个）。

### utime / stime 含义

| 字段 | 含义 |
| --- | --- |
| utime | 用户态 CPU 时间（jiffies） |
| stime | 内核态 CPU 时间（jiffies） |
| 合计 | 进程所有线程的 CPU 时间之和 |

### 64 核无超线程场景说明

- 理论峰值 = 64 × 100% = **6400%**
- 若监控峰值超过 6400%（如 11405%），物理上不可能长期维持，更可能是**秒级采样尖刺**
- 建议同时查看 `observer_process_cpu_percent_per_cpu` 和主机 `cpu_percent` 交叉验证

## observer 进程

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_process_cpu_percent | %     |

### 计算表达式

```
avg(process_cpu_percent{name="observer",@LABELS}) by (@GBLABELS)
```

### 归一化计算表达式

```
sum(process_cpu_percent{name="observer",@LABELS}) by (@GBLABELS) / sum(cpu_count) by (@GBLABELS)
```

### 验证命令

```bash
PID=$(pidof observer)

# 推荐：与 agent 口径最接近
pidstat -p $PID 1 5

# 手工复现 1 秒采样
CLK=$(getconf CLK_TCK)
T1=$(awk '{print $14+$15}' /proc/$PID/stat)
sleep 1
T2=$(awk '{print $14+$15}' /proc/$PID/stat)
echo "scale=2; ($T2-$T1)/$CLK*100" | bc
```

## 交叉验证步骤（CPU 异常时）

```bash
# 1. 确认核数
lscpu | grep -E 'Thread|Core|Socket|^CPU\(s\)'
nproc

# 2. 确认 observer 进程数（应为 1）
pgrep -a observer
pgrep -c observer

# 3. OS 侧持续采样
pidstat -p $(pidof observer) 1 60

# 4. 在 OCP 同时查看
#    - observer_process_cpu_percent（原始累加值）
#    - observer_process_cpu_percent_per_cpu（整机占比 0~100%）
#    - cpu_percent（主机 CPU）
#    - process_count{name="observer"}（进程数）
```
