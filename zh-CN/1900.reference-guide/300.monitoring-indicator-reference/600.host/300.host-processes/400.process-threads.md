# 进程线程数

本节为您介绍主机进程的监控指标 **进程线程数** 。

## 指标详解

| 项目 | 内容 |
| --- | --- |
| **OCP 展示名** | 进程线程数 |
| **原始指标** | `process_thread_count` |
| **采集 API** | `proc.NumThreads()` |
| **Linux 数据源** | `/proc/<pid>/status` 的 `Threads` 字段 |
| **含义** | 进程当前存活线程总数（含 OB 工作线程、网络线程等） |
| **OCP 聚合** | `avg(process_thread_count{name="observer"})` |
| **特点** | 瞬时值；OBServer 线程数随负载变化，可辅助判断并发压力 |

### 多同名进程处理策略

当存在多个同名进程时，取 **最大值**（`math.Max()`）。

## observer 进程

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.src.template.Table.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_thread_count | -     |

### 计算表达式

```
avg(process_thread_count{name="observer",@LABELS}) by (@GBLABELS)
```

### 验证命令

```bash
PID=$(pidof observer)

grep Threads /proc/$PID/status
# 输出如：Threads:  512

ps -o pid,nlwp,comm -p $PID   # nlwp = number of light-weight processes (threads)
```
