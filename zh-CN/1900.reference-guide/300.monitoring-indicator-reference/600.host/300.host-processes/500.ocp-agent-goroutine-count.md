# OCP-Agent 进程协程数

本节为您介绍主机进程的监控指标 **OCP-Agent 进程协程数** 。

## 指标详解

| 项目 | 内容 |
| --- | --- |
| **OCP 展示名** | OCP-Agent 进程协程数 |
| **原始指标** | `go_goroutines`（Prometheus 标准指标） |
| **OCP 指标** | `monagent_goroutine_count` / `mgragent_goroutine_count` |
| **采集方式** | **不走 processInput**，由 `prometheusInput` 抓取 Agent 自身 HTTP 端点 |
| **抓取地址** | `http://127.0.0.1:${ocp.agent.monitor.http.port}/metrics/stat` |
| **数据来源** | Agent 内 `prometheus.NewGoCollector()` 暴露的 Go runtime 指标 |
| **含义** | `ocp_monagent` / `ocp_mgragent` 进程内 **goroutine 数量**（Go 协程，不是 OS 线程） |
| **采集周期** | 约 60s（比前 4 项更慢） |
| **适用范围** | 仅 Go 写的 Agent 进程；**observer / obproxy 无此指标** |

### 与「进程线程数」的区别

| 维度 | 进程线程数 | 协程数 |
| --- | --- | --- |
| 对象 | OS 线程（内核调度） | Go goroutine（用户态） |
| 数据源 | `/proc/pid/status` | Go runtime `runtime.NumGoroutine()` |
| 适用进程 | observer、obproxy、agent 等 | 仅 ocp_monagent、ocp_mgragent |

## monagent 进程

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| monagent | monagent_goroutine_count | -     |

### 计算表达式

```
max(go_goroutines{process="ocp_monagent",@LABELS}) by (@GBLABELS)
```

### 验证命令

```bash
# 在 Agent 主机上（端口以实际配置为准）
curl -s http://127.0.0.1:<monitor_port>/metrics/stat | grep go_goroutines

# 或通过 unix socket
curl -s --unix-socket $OCP_AGENT_HOME/run/ocp_monagent.*.sock \
  http://unix-socket-server/metrics/stat | grep go_goroutines
```
