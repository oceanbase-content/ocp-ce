# 进程常驻内存

本节为您介绍主机进程的监控指标 **进程常驻内存** 。

## 指标详解

| 项目 | 内容 |
| --- | --- |
| **OCP 展示名** | 进程常驻内存 |
| **原始指标** | `process_memory_rss_bytes` |
| **采集 API** | `proc.MemoryInfo().RSS` |
| **Linux 数据源** | `/proc/<pid>/status` 的 `VmRSS`，或 `/proc/<pid>/statm` 第 2 列 × 页大小 |
| **含义** | 进程实际占用的**物理内存**（Resident Set Size），不含 swap、不含未映射虚拟内存 |
| **单位** | 字节（byte） |
| **OCP 聚合** | `sum(process_memory_rss_bytes{name="observer"})` |
| **特点** | **瞬时值**，每次采集时点的快照，不做时间平均 |

### 多同名进程处理策略

当存在多个同名进程时（如仲裁 observer 短暂双进程），取 **最大值**（`math.Max()`）。

## observer 进程

### 指标参数说明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">指标项</UI-TERM>** | **指标名称** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">单位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_rss_memory | byte     |

### 计算表达式

```
sum(process_memory_rss_bytes{name="observer",@LABELS}) by (@GBLABELS)
```

### 验证命令

```bash
PID=$(pidof observer)

# 方式1：status
grep VmRSS /proc/$PID/status
# 输出如：VmRSS:  52428800 kB

# 方式2：ps（单位 KB）
ps -o pid,rss,comm -p $PID

# 方式3：与 agent 一致用 gopsutil 语义
cat /proc/$PID/statm | awk '{print "RSS pages:", $2, " bytes≈", $2*4096}'
```
