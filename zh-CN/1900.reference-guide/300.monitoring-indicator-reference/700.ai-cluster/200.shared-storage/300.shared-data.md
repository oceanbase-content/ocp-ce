# 共享数据

本节介绍 OB SS 模式下共享数据与共享 clog 占用空间相关指标。

<main id="notice" type='explain'>
<h4>说明</h4>
<p>以下监控分组适用于 <b>OceanBase 共享存储（SS）模式</b>，要求 OB 集群版本 <b>≥ 4.6.2.0</b>。采集条件为 <code>ob_mode_is_shared_storage</code>（仅在 SS 模式下采集）。</p>
</main>

## ob_shared_data_size

### 指标介绍

共享数据总量。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| ob_shared_data_size | ob_shared_data_size | byte |

### 计算表达式

```
max(ob_tenant_space_usage{space_type="Shared Data", @LABELS}) by (@GBLABELS)
```

### SQL 采集

OceanBase V4.3.5.1 及以上版本（SS 模式，仅在 RootService 节点采集）：

```sql
select TENANT_ID, TENANT_NAME, SPACE_TYPE, USAGE_BYTES from CDB_OB_SPACE_USAGE
```

其中 `SPACE_TYPE = 'Shared Data'` 对应共享数据总量。
