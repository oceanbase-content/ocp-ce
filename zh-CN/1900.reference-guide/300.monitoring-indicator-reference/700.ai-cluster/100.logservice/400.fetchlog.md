# FetchLog 操作

本节介绍 Logservice FetchLog 操作相关的监控指标。

## logservice_fetch_entries_total

### 指标介绍

FetchLog 取日志的条目数（每秒速率）。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| log_fetch_entries_total | logservice_fetch_entries_total | times/s |

### 计算表达式

```
sum(rate(log_fetch_entries_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus 采集

通过 `prometheusInput` 从 `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` 采集 `log_fetch_entries_total` 指标。

## logservice_fetch_P95_duration_ms

### 指标介绍

FetchLog 拉取耗时分位数（P95）。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| log_fetch_duration_seconds_bucket | logservice_fetch_P95_duration_ms | ms |

### 计算表达式

```
1000 * histogram_quantile(0.95, sum(rate(log_fetch_duration_seconds_bucket{@LABELS}[@INTERVAL])) by (@GBLABELS,le))
```

### Prometheus 采集

通过 `prometheusInput` 从 `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` 采集 `log_fetch_duration_seconds_bucket` 直方图指标。
