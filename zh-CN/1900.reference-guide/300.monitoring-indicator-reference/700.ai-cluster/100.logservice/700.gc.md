# GC 回收

本节介绍 Logservice GC（垃圾回收）相关的监控指标。

## logservice_storage_gc_reclaimed_blocks_total

### 指标介绍

GC 每秒回收的块数量，反馈 GC 进展程度。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| storage_gc_reclaimed_blocks_total | logservice_storage_gc_reclaimed_blocks_total | times/s |

### 计算表达式

```
sum(rate(storage_gc_reclaimed_blocks_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus 采集

通过 `prometheusInput` 从 `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` 采集 `storage_gc_reclaimed_blocks_total` 指标。
