# 进程资源

本节介绍 Logservice 进程资源相关的监控指标。

## logservice_process_cpu_percent

### 指标介绍

日志服务（oblogservice）进程 CPU 使用率。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| process_cpu_percent{name="oblogservice"} | logservice_process_cpu_percent | % |

### 计算表达式

```
sum(process_cpu_percent{name="oblogservice",@LABELS}) by (@GBLABELS)
```

### Prometheus 采集

OCP monagent 通过 `processInput` 插件采集 `process_cpu_percent{name="oblogservice"}` 指标。
