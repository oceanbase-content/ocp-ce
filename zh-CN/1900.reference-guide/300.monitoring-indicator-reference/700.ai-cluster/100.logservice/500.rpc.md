# RPC 请求

本节介绍 Logservice RPC 请求相关的监控指标。

## logservice_rpc_request_success_count

### 指标介绍

平均每秒 RPC 请求成功次数，按 `service`、`method` 维度区分。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| rpc_request_total{status="ok"} | logservice_rpc_request_success_count | times/s |

### 计算表达式

```
sum(rate(rpc_request_total{status="ok",@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus 采集

通过 `prometheusInput` 从 `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` 采集 `rpc_request_total` 指标。

## logservice_rpc_requestP95_duration_ms

### 指标介绍

RPC 处理耗时分位数（P95），按 `service`、`method` 维度区分。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| rpc_request_duration_seconds_bucket | logservice_rpc_requestP95_duration_ms | ms |

### 计算表达式

```
1000 * histogram_quantile(0.95, sum(rate(rpc_request_duration_seconds_bucket{@LABELS}[@INTERVAL])) by (@GBLABELS,le))
```

### Prometheus 采集

通过 `prometheusInput` 从 `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` 采集 `rpc_request_duration_seconds_bucket` 直方图指标。

---
