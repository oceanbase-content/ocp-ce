# 延迟与状态

本节介绍 Logservice 延迟与状态相关的监控指标。

## logservice_replica_committed_end_scn_delay

### 指标介绍

日志服务中已提交日志的 end SCN 延迟。用于 `logservice_replica_committed_end_scn_delay` 告警（阈值 ≥ 5000ms / ≥ 10000ms）。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| replica_committed_end_scn_delay | logservice_replica_committed_end_scn_delay | ms |

### 计算表达式

```
avg(replica_committed_end_scn_delay{@LABELS}) by (@GBLABELS) / 1000
```

### Prometheus 采集

通过 `prometheusInput` 从 `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` 采集 `replica_committed_end_scn_delay` 指标（原始单位为微秒，表达式中除以 1000 转换为毫秒）。

## logservice_boot_time_delta_seconds

### 指标介绍

oblogservice 进程启动时间差，用于检测进程重启。用于 `logservice_process_stop` 告警（阈值 > 10s）。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| process_boot_time_seconds{name="oblogservice"} | logservice_boot_time_delta_seconds | s |

### 计算表达式

```
max(delta(process_boot_time_seconds{name="oblogservice",@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus 采集

OCP monagent 通过 `processInput` 插件采集 `process_boot_time_seconds{name="oblogservice"}` 指标。

---

## logservice_process_exists

### 指标介绍

oblogservice 进程存活状态（1=存活，0=不存在）。用于 `logservice_process_dead` 告警（表达式：`logservice_process_exists == 0`）。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| process_exists{name="oblogservice"} | logservice_process_exists | - |

### 计算表达式

```
process_exists{name="oblogservice",@LABELS}
```

### Prometheus 采集

OCP monagent 通过 `processInput` 插件采集 `process_exists{name="oblogservice"}` 指标。
