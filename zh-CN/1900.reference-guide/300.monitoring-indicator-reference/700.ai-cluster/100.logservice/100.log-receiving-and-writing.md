# 日志接收与写入

本节介绍 Logservice 日志接收与写入相关的监控指标。

## logservice_receive_bytes_total

### 指标介绍

LogService 累计接收日志字节数（每秒速率）。

### 指标参数说明

| 指标项 | 指标名称 | 单位 |
|-------|---------|------|
| log_receive_bytes_total | logservice_receive_bytes_total | byte/s |

### 计算表达式

```
sum(rate(log_receive_bytes_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus 采集

通过 `prometheusInput` 从 `http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` 采集 `log_receive_bytes_total` 指标。
