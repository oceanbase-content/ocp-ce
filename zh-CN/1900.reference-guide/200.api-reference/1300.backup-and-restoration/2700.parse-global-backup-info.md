# 解析全局备份信息

## 功能说明

该接口使用当前 OCP 管理的主机访问指定备份存储，解析其中的源集群、源租户、数据备份点、日志备份区间和可恢复时间区间。

典型场景为：生产环境将租户备份到 OSS，测试环境与生产环境的 OCP、OceanBase 集群均无关联，但测试环境可以访问该 OSS。调用方可通过该接口解析备份信息，再选择可恢复时间并提交离线租户恢复任务。

## 调用说明

### 接口约束

* 调用者需要通过 OCP 应用服务鉴权，并拥有备份读取权限。
* 调用者需要对所选解析主机拥有读取权限，且解析主机能够访问指定备份存储。

### 请求路径

`POST /api/v2/backup/info`

### 请求参数

**Query 参数**

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| startTime | DateTime | 否 | 2026-09-02T10:00:00+08:00 | 查询时间范围的起始时间，使用 ISO 8601 格式。 |
| endTime | DateTime | 否 | 2026-09-09T10:00:00+08:00 | 查询时间范围的结束时间，使用 ISO 8601 格式。 |
| timeScopeType | String | 否 | LATEST_SEVEN_DAYS | 查询时间范围类型。取值包括 `LATEST_SEVEN_DAYS`、`LATEST_SIX_MONTHS`、`MONTHS`、`YEARS` 和 `USER_DEFINED`。默认值为 `LATEST_SEVEN_DAYS`。 |

**Body 参数**

**ParseObBackupInfoParam 的数据结构**

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| obBackupStorageBaseInfo | Object | 是 | - | 数据备份存储信息。数据结构参见 **ObBackupStorageBaseInfo 的数据结构**。 |
| hostIdList | LongArray | 是 | [3001] | 数据备份解析主机 ID 列表，至少传入一个当前 OCP 管理的主机 ID。 |
| logStorageMode | String | 否 | SAME_AS_DATA | 日志备份存储模式。`SAME_AS_DATA` 表示日志和数据使用相同存储；`INDEPENDENT` 表示日志使用独立存储。建议显式传入。 |
| logBackupStorageBaseInfo | Object | 条件必选 | - | `logStorageMode` 为 `INDEPENDENT` 时必选；为 `SAME_AS_DATA` 时必须省略。数据结构与 `obBackupStorageBaseInfo` 相同。 |
| logHostIdList | LongArray | 否 | [3002] | 独立日志备份的解析主机 ID 列表。省略或传空数组时复用 `hostIdList`。 |
| storageId | Long | 否 | 10 | 当前 OCP 中已有备份存储配置的 ID。应用服务调用时仍应传入完整的存储参数和对象存储访问凭据，不能只依赖该字段。 |

**ObBackupStorageBaseInfo 的数据结构**

| 参数 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- |
| backupStorageType | String | 是 | BACKUP_STORAGE_OSS | 存储类型。当前接口使用的类型包括 `BACKUP_STORAGE_FILE`、`BACKUP_STORAGE_OSS`、`BACKUP_STORAGE_COS`、`BACKUP_STORAGE_OBS` 和 `BACKUP_STORAGE_S3`。 |
| storageUrl | String | 是 | example-bucket/obbackup | 存储目录，最长 1024 个字符。无需包含 `file://`、`oss://`、`cos://`、`obs://` 或 `s3://` 前缀。 |
| ossAccessKey | Object | 条件必选 | - | OSS 访问信息，仅在 `backupStorageType` 为 `BACKUP_STORAGE_OSS` 时传入。 |
| cosAccessKey | Object | 条件必选 | - | COS 访问信息，仅在 `backupStorageType` 为 `BACKUP_STORAGE_COS` 时传入。 |
| obsAccessKey | Object | 条件必选 | - | OBS 访问信息，仅在 `backupStorageType` 为 `BACKUP_STORAGE_OBS` 时传入。 |
| s3AccessKey | Object | 条件必选 | - | S3 访问信息，仅在 `backupStorageType` 为 `BACKUP_STORAGE_S3` 时传入。 |
| customBackupRangeList | Array | 否 | [] | 自定义备份范围。没有自定义范围时省略或传空数组。 |
| advancedConfigList | Array | 否 | [] | 备份存储高级配置。没有高级配置时省略或传空数组。 |

**对象存储访问凭据的数据结构**

| 存储类型 | 参数 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- | --- |
| OSS | endpoint | String | 是 | OSS 服务端点。 |
| OSS | accessKeyId | String | 是 | OSS AccessKey ID。 |
| OSS | accessKeySecret | String | 是 | OSS AccessKey Secret。 |
| COS | endpoint | String | 是 | COS 服务端点。 |
| COS | accessKeyId | String | 是 | COS SecretId。 |
| COS | accessKeySecret | String | 是 | COS SecretKey。 |
| COS | appId | String | 是 | COS AppId。 |
| OBS | endpoint | String | 是 | OBS 服务端点。 |
| OBS | accessKeyId | String | 是 | OBS AccessKey ID。 |
| OBS | accessKeySecret | String | 是 | OBS Secret Access Key。 |
| S3 | endpoint | String | 是 | S3 兼容服务端点。 |
| S3 | accessKeyId | String | 是 | S3 AccessKey ID。 |
| S3 | accessKeySecret | String | 是 | S3 Secret Access Key。 |
| S3 | region | String | 否 | S3 Region。存储服务要求 Region 时必须传入。 |

<main id="notice" type='notice'>
<h4>注意</h4>
<p>对象存储凭据属于敏感信息，请勿将真实凭据写入文档、代码仓库或普通日志。</p>

当 `logStorageMode` 为 `INDEPENDENT` 时，还需满足以下约束：

* 独立日志存储仅支持 `BACKUP_STORAGE_FILE` 或 `BACKUP_STORAGE_S3`。
* 数据备份和日志备份的存储根目录不能相同或互相包含。
* `logBackupStorageBaseInfo` 必须填写完整；如果不单独指定 `logHostIdList`，OCP 将复用 `hostIdList`。

### 返回结果

**基础数据结构**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| data | Object | 返回数据。详情参见 **ObClusterBackupInfo 的数据结构**。 |
| ├─ contents | Array | 从备份存储中解析出的集群备份信息列表。 |
| successful | Boolean | 请求是否成功。 |
| timestamp | DateTime | 服务端完成请求的时间戳。 |
| duration | Long | 服务端处理请求的时间，单位为毫秒。 |
| status | Integer | 符合 HTTP Status 规范的状态码。 |
| traceId | String | 请求的 Trace ID，用于排查问题。 |
| server | String | 响应请求的 OCP 节点地址。 |

**ObClusterBackupInfo 的数据结构**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| clusterName | String | 备份源集群名称。 |
| obClusterId | Long | 备份源集群在 OceanBase 中的集群 ID。 |
| clusterId | Long | 备份源集群在当前 OCP 中的 ID。跨 OCP 离线备份通常为 `null`。 |
| online | Boolean | 备份源集群是否属于当前 OCP 的在线管理对象。 |
| tenantBackupInfos | Array | 租户备份信息列表，详情参见 **ObTenantBackupInfo 的数据结构**。 |
| obRecoverableInfoAggregation | Object | 集群维度的可恢复信息汇总，结构与租户维度相同。 |

**ObTenantBackupInfo 的数据结构**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| clusterName | String | 备份源集群名称。 |
| obClusterId | Long | 备份源集群在 OceanBase 中的集群 ID。 |
| clusterId | Long | 备份源集群在当前 OCP 中的 ID。跨 OCP 离线备份通常为 `null`。 |
| obTenantId | Long | 备份源租户在 OceanBase 中的租户 ID。 |
| tenantId | Long | 备份源租户在当前 OCP 中的 ID。跨 OCP 离线备份通常为 `null`。 |
| tenantName | String | 备份源租户名称。 |
| mode | String | 租户兼容模式，取值为 `MYSQL` 或 `ORACLE`。 |
| online | Boolean | 备份源租户是否属于当前 OCP 的在线管理对象。 |
| obRecoverableInfoAggregation | Object | 租户的可恢复信息汇总。 |

**ObRecoverableInfoAggregation 的数据结构**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| obQueryTimeScopeType | String | 本次响应使用的时间范围类型。 |
| latestSevenDaysAggregation | Object | 明细列表。`LATEST_SEVEN_DAYS`、`LATEST_SIX_MONTHS` 和 `USER_DEFINED` 使用该字段。 |
| ├─ obRecoverableSectionItems | Array | 数据备份点、日志备份区间和实际可恢复区间的列表。 |
| latestMonthsAggregation | Object | 按天聚合的备份信息，`MONTHS` 使用该字段。 |
| ├─ dayFormatAndRecoverableItems | Object | Key 为 `yyyy-MM-dd`，Value 为当天的备份信息列表。 |
| latestYearsAggregation | Object | 按月聚合的备份统计，`YEARS` 使用该字段。 |
| ├─ monthFormatAndRecoverableStatics | Object | Key 为 `yyyy-MM`，Value 包含数据备份个数和日志备份累计时长。 |

**ObRecoverableSectionItem 的数据结构**

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| obRecoverableSectionItemType | String | 节点类型。取值包括 `FULL_DATA_BACKUP`、`INCREMENTAL_DATA_BACKUP`、`LOG_BACKUP` 和 `RECOVERABLE`。 |
| backupMode | String | 备份模式。取值为 `PHYSICAL_BACKUP` 或 `LOGICAL_BACKUP`。 |
| backupDimension | String | 备份维度。取值为 `CLUSTER` 或 `TENANT`。 |
| dataBackupRecoverableInfo | Object | 数据备份信息，仅在节点类型为数据备份时有效。包含 `freezeTime`、`recoverableTime`、`dataVersion` 和 `fullBackupSetId`。 |
| logRecoverableTimeInterval | Object | 日志备份区间，仅在节点类型为 `LOG_BACKUP` 时有效。包含 `startTime` 和 `endTime`。 |
| realRecoverableTimeInterval | Object | 实际可恢复区间，仅在节点类型为 `RECOVERABLE` 时有效。包含 `startTime` 和 `endTime`。 |

## 示例

### 请求示例

解析 OSS 中最近七天的备份信息：

`POST /api/v2/backup/info?timeScopeType=LATEST_SEVEN_DAYS`

```json
{
  "obBackupStorageBaseInfo": {
    "backupStorageType": "BACKUP_STORAGE_OSS",
    "storageUrl": "example-bucket/obbackup",
    "ossAccessKey": {
      "endpoint": "oss-cn-hangzhou.aliyuncs.com",
      "accessKeyId": "${ACCESS_KEY_ID}",
      "accessKeySecret": "${ACCESS_KEY_SECRET}"
    }
  },
  "hostIdList": [3001],
  "logStorageMode": "SAME_AS_DATA"
}
```

使用文件系统或 NFS 时，将存储部分替换为：

```json
{
  "backupStorageType": "BACKUP_STORAGE_FILE",
  "storageUrl": "/data/obbackup"
}
```
