# 开启 JVM 环境依赖服务

## 功能说明

为集群开启 JVM 环境依赖服务。

## 调用说明

### 接口约束

* 调用者需具备接管 OceanBase 集群的权限。

  关于调用者的权限，详情可参见 [用户及权限概述](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)。

* 调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`POST /api/v2/ob/clusters/{id}/startJvmDepsService`

### 请求参数

**path：**

|  参数            |  类型     | 必选   | 示例值  |  描述   |
|------------------|-----------|--------|--------|----------|
|  id              | Long      |  是    |  160   | 目标集群在 OCP 端的 ID。  |

**body：**

|  参数            |  类型     | 必选   | 示例值  |  描述   |
|------------------|-----------|--------|--------|----------|
| jvmEnvServices   | Array     | 是     | ODPS External Table,HDFS External Table,Java UDF,ODPS Catalog,MySQL Plugin  | 环境依赖服务，取值范围：<li>ODPS_EXTERNAL_TABLE</li><li>HDFS_EXTERNAL_TABLE</li><li>JAVA_UDF</li><li>ODPS_CATALOG</li><li>MYSQL_PLUGIN</li>。  |
| maxJvmMemoryGiB  | Integer   | 是     | 1                              | 用户输入的最大内存大小，单位为 GiB。 |
| javaHomePath     | String    | 是     | `/usr/local/java/jdk-17.0.8`   | JAVA_HOME 路径。   |
| restartMode      | String    | 是     | FORCE                          | 重启方式，取值范围：<li>FORCE</li><li>ROLLING</li>   |
| freezeServer     | Boolean   | 是     | true                           | 停止进程前是否执行转储操作，取值范围：<li>true</li><li>false</li>   |

### 返回结果

**基础数据结构**

|  参数        |  类型      |  说明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 异步任务信息，详情参见 [任务返回结构](../400.task-return-structure.md)。  |
|  successful  |  Boolean   | 请求是否成功。                          |
|  timestamp   |  Datetime  | 服务端完成请求的时间戳。                     |
|  duration    |  Integer   | 服务端处理请求的时间（毫秒）。                  |
|  status      |  Integer   | 符合 HTTP Status 规范的编码。            |
|  traceId     |  String    | 请求的 Trace ID，用于排查问题。             |
|  server      |  String    | 响应请求的应用服务的地址。                    |
