# 获取资源单元规格列表

## 功能说明

该接口用于获取资源单元规格列表。

## 调用说明

### 接口约束

调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`GET /api/v2/ob/unitSpecs`

### 请求参数

**Query：**

|  参数  |  类型  |  必选  |  示例值  |  描述  |
|--------|--------|--------|---------|---------|
|  name  |  String  |  否  |  S1  |  资源单元规格名。  |
|  type  |  String  |  否  |  SYSTEM  |  资源单元规格类型，取值范围：<li>SYSTEM 系统默认。</li><li>CUSTOM 自定义。</li>|
|  clusterId  |  Long  |  否  |  1  |  集群 ID。  |
|  storageArchitecture  |  String  |  否  |  SN  |  存储架构。  |
|  page  |  Integer  |  否  |  1  |  页码，默认值为 1。  |
|  size  |  Integer  |  否  |  10  |  每页数量，默认值为全量返回。  |
|  sort  |  String  |  否  |  id,asc  |  排序字段，默认按 id 升序。  |

### 返回结果

**基础数据结构**

|  参数  |  类型  |  说明  |
|---------|--------|--------|
|  data        |  Object    |  资源单元规格的列表信息，详情参见 **UnitSpec 数据结构**。  |
|  successful  |  Boolean   |  请求是否成功。 |
|  timestamp   |  Datetime  |  服务端完成请求的时间戳。  |
|  duration    |  Integer   |  服务端处理请求的时间（毫秒）。  |
|  status      |  Integer   |  符合 HTTP Status 规范的编码。  |
|  traceId     |  String    |  请求的 Trace ID，用于排查问题。  |
|  server      |  String    |  响应请求的应用服务的地址。  |

**UnitSpec 数据结构**

|  参数  |  类型  |  说明  |
|--------|--------|--------|
|  id   |  Long |  资源单元规格的 ID。  |
|  name |  String  |  资源单元规格名称。 |
|  type |  String  |  资源单元规格类型，取值范围：<li>SYSTEM 系统默认。</li><li>CUSTOM 自定义</li>  |
|  maxCpuCoreCount |  Double  |  最大 CPU 核心数。  |
|  minCpuCoreCount |  Double  |  最小 CPU 核心数。  |
|  maxMemorySize |  Long  |  最大内存，单位 GB。 |
|  minMemorySize |  Long  |  最小内存，单位 GB。 |
|  logDiskSize |  Long  |  日志盘大小，单位 GB。  |
|  maxIops |  Long  |  最大 IOPS。  |
|  minIops |  Long  |  最小 IOPS。  |
|  iopsWeight |  Integer  |  IOPS 权重。  |
|  notRecommended |  Boolean  |  当指定了 OB 版本，且该版本的 OB 集群不适合使用该 unit 规格时，值为 true，表示不推荐使用。  |
|  dataDiskSize |  Long  |  本地缓存盘大小，单位 GB，仅 SS 使用。  |
|  dataDiskQuota |  Long  |  每 Unit 数据存储配额，单位 GiB，仅 SN 集群且 OB >= 4.0 生效。  |
|  maxNetBandwidth |  Long  |  网络带宽，单位 Mbps，仅 SS 使用。  |
|  storageArchitecture |  String  |  适用存储架构。NULL 表示通用（SN/SS 均可用），非 NULL 表示仅适用该架构。  |
