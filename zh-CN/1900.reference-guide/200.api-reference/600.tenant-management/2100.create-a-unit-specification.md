# 创建资源单元规格

## 功能说明

该接口用于创建资源单元规格。访问权限：`CLUSTER:*:READ`，至少要有任意集群的读权限才可操作此接口。

## 调用说明

### 接口约束

调用者需要通过 OCP 应用服务鉴权。

### 请求路径

`POST /api/v2/ob/unitSpecs`

### 请求参数

**body：**

|  参数  |  类型  |  必选  |  示例值  |  描述  |
|--------|--------|--------|----------|--------|
|  name  |  String  |  是  |  C1  |  资源单元规格名称。以字母开头，长度为 2~32 个字符，只能包含字母、数字和下划线。  |
|  group  |  String  |  否  |  Default  |  分组名。  |
|  maxCpuCoreCount  |  Double  |  是  |  1.5  |  最大 CPU 核心数，取值范围：0.5~999。  |
|  minCpuCoreCount  |  Double  |  否  |  1.5  |  最小 CPU 核心数，取值范围：0.5~999，未填时等于 maxCpuCoreCount。  |
|  maxMemorySize  |  Long  |  是  |  6  |  最大内存，单位 GB，取值范围：1~10000。  |
|  minMemorySize  |  Long  |  否  |  6  |  最小内存，单位 GB，取值范围：1~10000，未填时等于 maxMemorySize。  |
|  logDiskSize  |  Long  |  否  |  10  |  日志盘大小，单位 GB，取值范围：2~10000，仅在 OB 4.0 及以上版本生效。  |
|  maxIops  |  Long  |  否  |  10000  |  最大 IOPS，仅在 OB 4.0 及以上版本生效。  |
|  minIops  |  Long  |  否  |  10000  |  最小 IOPS，仅在 OB 4.0 及以上版本生效，未填时等于 maxIops。  |
|  iopsWeight  |  Integer  |  否  |  1  |  IOPS 权重，仅在 OB 4.0 及以上版本生效，未填且 maxIops 不为空时默认值为 1。  |
|  dataDiskSize  |  Long  |  否  |  10  |  本地缓存盘大小，单位 GB，仅 SS 使用。  |
|  dataDiskQuota  |  Long  |  否  |  5  |  每 Unit 数据存储配额，单位 GiB，填写时须 >= 2，仅 SN 集群且 OB >= 4.0 生效。  |
|  maxNetBandwidth  |  Long  |  否  |  100  |  网络带宽，单位 Mbps，仅 SS 使用。  |
|  storageArchitecture  |  String  |  否  |  SN  |  适用存储架构（StorageArchitecture 枚举名）。NULL 表示通用（SN/SS 均可用），非 NULL 表示仅适用该架构。  |

### 返回结果

**基础数据结构**

|  参数  |  类型  |  说明  |
|--------|--------|--------|
|  data  |  Object  |  资源单元规格的信息，详情参见 **UnitSpec 数据结构**。  |
|  successful  |  Boolean |  请求是否成功。 |
|  timestamp |  Datetime  |  服务端完成请求的时间戳。  |
|  duration |  Integer  |  服务端处理请求的时间（毫秒）。  |
|  status |  Integer  |  符合 HTTP Status 规范的编码。  |
|  traceId |  String  |  请求的 Trace ID，用于排查问题。  |
|  server  |  String  |  响应请求的应用服务的地址。  |

**UnitSpec 数据结构**

|  参数  |  类型  |  说明  |
|--------|--------|--------|
|  id    |  Long  |  资源单元规格的 ID。   |
|  name  |  String  |  资源单元规格名称。  |
|  type  |  String  |  资源单元规格类型，取值范围：<li>SYSTEM 系统默认。</li><li>CUSTOM 自定义</li>  |
|  maxCpuCoreCount  |  Double  |  最大 CPU 核心数。  |
|  minCpuCoreCount  |  Double  |  最小 CPU 核心数。  |
|  maxMemorySize  |  Long  |  最大内存，单位 GB。  |
|  minMemorySize  |  Long  |  最小内存，单位 GB。  |
|  logDiskSize  |  Long  |  日志盘大小，单位 GB。  |
|  maxIops  |  Long  |  最大 IOPS。  |
|  minIops  |  Long  |  最小 IOPS。  |
|  iopsWeight  |  Integer  |  IOPS 权重。  |
|  notRecommended  |  Boolean  |  当指定了 OB 版本，且该版本的 OB 集群不适合使用该 unit 规格时，值为 true，表示不推荐使用。  |
|  dataDiskSize  |  Long  |  本地缓存盘大小，单位 GB，仅 SS 使用。  |
|  dataDiskQuota  |  Long  |  每 Unit 数据存储配额，单位 GiB，仅 SN 集群且 OB >= 4.0 生效。  |
|  maxNetBandwidth  |  Long  |  网络带宽，单位 Mbps，仅 SS 使用。  |
|  storageArchitecture  |  String  |  适用存储架构。NULL 表示通用（SN/SS 均可用），非 NULL 表示仅适用该架构。  |
