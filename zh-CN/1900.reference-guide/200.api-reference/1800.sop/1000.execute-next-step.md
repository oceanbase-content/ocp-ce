# 执行下一步

## 功能说明

推进当前已就绪且 `autoRun=false` 的人工步骤。存在多个可推进步骤时必须指定 `stepIndex`。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:UPDATE` 权限及目标资源 `UPDATE` 权限。执行状态必须是 `WAITING_CONFIRM` 或 `RUNNING`，且必须显式确认。

### 请求路径

`POST /api/v2/sop/tasks/{taskId}/execution/next`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| taskId | Path | Long | 是 | `1001` | 任务 ID。 |
| stepIndex | Body | Integer | 否 | `5` | 要推进的已就绪人工步骤序号；存在多个就绪步骤时必填。 |
| confirmed | Body | Boolean | 是 | `true` | 必须传 `true`；未传、`null` 或 `false` 都不允许推进。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.id | Long | 执行实例 ID。 |
| data.sopTaskId | Long | 所属 SOP 任务 ID。 |
| data.status | String | 执行状态，取值 `WAITING_CONFIRM`、`RUNNING`、`FAILED` 或 `COMPLETED`。 |
| data.displayStatus | String | 用于展示的执行状态；当前与 `data.status` 相同。 |
| data.currentStepIndex | Integer | 当前最早未成功步骤的序号。 |
| data.totalSteps | Integer | 本次执行的步骤总数。 |
| data.readyManualStepIndexes | Array&lt;Integer&gt; | 更新后可人工推进的步骤序号。 |
| data.executor | String | 启动执行的用户名。 |
| data.startTime | Datetime | 执行开始时间。 |
| data.finishTime | Datetime \| null | 执行结束或失败时间；未结束时为 `null`。 |
| data.steps[] | Array | 全部步骤执行信息。每项字段为 `stepIndex`、`stepKey`、`stepName`、`status`、`autoRun`、`stepParam`、`taskInstanceIds`、`retryCount`、`errorMessage`、`startTime`、`finishTime`；其含义分别为步骤定位/展示、状态、自动执行开关、步骤参数、关联 OCP 任务、重试数、失败信息和步骤时间。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` | 任务不存在。 |
| 400 | `SOP10014` | 未启动，或执行状态不是 `WAITING_CONFIRM`/`RUNNING`。 |
| 400 | `SOP10020` | `confirmed` 不为 `true`。 |
| 400 | `SOP10013` | 存在多个可推进步骤但未指定 `stepIndex`。 |
| 404 | `SOP10015` | 指定步骤不存在。 |
| 400 | `SOP10016` | 指定步骤未就绪、不是人工步骤或当前无人工步骤可推进。 |
| 400 | `SOP10021` | 步骤前置校验或派发失败。 |
