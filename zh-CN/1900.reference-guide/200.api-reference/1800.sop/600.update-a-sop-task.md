# 编辑 SOP 任务

## 功能说明

完整更新未启动任务的名称、目标参数、步骤配置和备注。请求中的 `sopType` 不会切换任务类型，服务端始终沿用任务原类型。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:UPDATE` 权限及目标资源 `UPDATE` 权限；任务必须尚未启动。

### 请求路径

`PUT /api/v2/sop/tasks/{id}`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- | --- |
| id | Path | Long | 是 | 待编辑任务 ID。 |
| name | Body | String | 是 | 与创建接口相同：全局唯一，2–32 字符，字符规则相同。 |
| sopType | Body | String | 否 | 可传原任务类型以保持请求可读性；可填值仅为 `REBUILD_STANDBY_TENANT`、`ARBITRATION_FOR_FAULTY_REPLICA`、`OBSERVER_DATA_REBUILD`，但不用于修改任务类型。 |
| targetParam | Body | Object | 是 | 与创建接口相同，按原任务的 SOP 类型提供对应字段和约束。 |
| steps | Body | Array | 是 | 与创建接口相同；步骤不能为空，模板步骤不可重复，固定启用步骤必须提供。 |
| steps[].stepIndex | Body | Integer | 否 | 目标步骤序号；未传使用模板默认值，最终必须连续且不重复，只有允许移动的步骤可调整位置。 |
| steps[].stepKey | Body | String | 是 | 原任务类型模板中的步骤标识，不能重复。 |
| steps[].autoRun | Body | Boolean | 否 | 自动执行开关；未传保留模板默认值，不可编辑步骤不得修改默认值。 |
| steps[].enabled | Body | Boolean | 否 | 是否启用步骤；仅模板允许关闭的步骤可设为 `false`。 |
| comments | Body | String | 否 | 更新后的备注。 |
| startNow | Body | Boolean | 否 | `true` 时更新后立即启动；未传/`false` 不启动。 |

编辑时 `steps[].stepKey` 的允许值也由原任务类型决定：

| `sopType` | `steps[].stepKey` 可填值 |
| --- | --- |
| `REBUILD_STANDBY_TENANT` | `CONFIRM_STANDBY_TENANT_INFO`、`BACKUP_PRIMARY_TENANT`、`DISCONNECT_STANDBY_TENANT`、`LOCK_STANDBY_TENANT`、`DELETE_STANDBY_TENANT`、`CREATE_STANDBY_TENANT`、`VERIFY_PRIMARY_STANDBY_SYNC` |
| `ARBITRATION_FOR_FAULTY_REPLICA` | `CONFIRM_ARBITRATION_TARGET`、`ADD_ARBITRATION_SERVICE`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`ENABLE_TENANT_ARBITRATION`、`VERIFY_TENANT_ARBITRATION` |
| `OBSERVER_DATA_REBUILD` | `CONFIRM_OBSERVER_TARGET`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`FORCE_DELETE_HOST`、`ADD_OBSERVER`、`ADD_TENANT_REPLICA`、`VERIFY_REPLICA_REBUILD` |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.id | Long | 任务 ID。 |
| data.name | String | 更新后的任务名称。 |
| data.sopType | String | 原任务的 SOP 类型编码。 |
| data.sopTypeDisplayName | String | 当前 locale 下的 SOP 类型展示名。 |
| data.targetParam | Object | 保存后的任务级目标参数及服务端解析/补充字段。重建备租户包含 `standbyClusterId`、`standbyTenantId`、`logTransportMode` 等；仲裁类型包含 `clusterId` 和仲裁服务/服务组二选一；OBServer 重建包含 `clusterId` 和可选 `replacementHostId`。 |
| data.operationObjects | Object | 展示用已解析对象。重建备租户可能含原/新备租户、原/新备集群、主租户、主集群、各类 ID、日志传输方式和备份配置；仲裁类型可能含受影响租户、故障 IP、仲裁服务/服务组和服务连接信息；OBServer 重建可能含受影响租户、故障 IP、Zone、替代主机 ID/IP。不存在字段不返回。 |
| data.targetSummary.displayText | String | 目标摘要文字。 |
| data.targetSummary.kind | String | 目标类别。 |
| data.targetSummary.details[] | Array | 摘要明细；每项包含 `label`（名称）和 `value`（值）。 |
| data.steps[] | Array | 保存后的步骤；每项包含 `stepIndex`、`stepKey`、`stepName`、`stepKind`、`stepDescription`、`autoRun`、`enabled`、`blockNext`、`editable`、`userMovable`、`minStepIndex`、`maxStepIndex`。 |
| data.comments | String \| null | 更新后的备注。 |
| data.creator | String | 创建人用户名。 |
| data.createTime | Datetime | 任务创建时间。 |
| data.updateTime | Datetime | 任务最后更新时间。 |
| data.displayStatus | String | 更新后状态；未启动为 `NOT_STARTED`，立即启动时为实际执行状态。 |
| data.currentExecutionId | Long \| null | 执行实例 ID；未启动为 `null`。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

除创建接口的 `SOP10001`–`SOP10007` 外，还可能返回：

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` | 任务不存在。 |
| 400 | `SOP10009` (`SOP_TASK_ALREADY_STARTED`) | 任务已有执行实例，不能编辑。 |
