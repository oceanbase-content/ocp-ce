# 删除 SOP 任务

## 功能说明

删除任务。未启动任务可删除；已启动任务仅 `COMPLETED` 或 `FAILED` 时可删除。删除会级联清理执行实例、步骤执行记录和步骤关联任务记录。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:UPDATE` 权限。

### 请求路径

`DELETE /api/v2/sop/tasks/{id}`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- | --- |
| id | Path | Long | 是 | 任务 ID。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data | null | 删除没有业务返回数据，固定为 `null`。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` | 任务不存在。 |
| 409 | `SOP10010` (`SOP_TASK_DELETE_FORBIDDEN`) | 执行状态为 `WAITING_CONFIRM` 或 `RUNNING`，不允许删除。 |
