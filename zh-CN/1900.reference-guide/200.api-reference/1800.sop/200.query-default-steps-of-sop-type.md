# 查询指定类型的默认步骤

## 功能说明

查询指定 SOP 类型的默认步骤模板。创建或编辑任务时，应据此构造 `steps` 数组。

## 调用说明

### 接口约束

需要 `SOP_TASK:READ` 权限。

### 请求路径

`GET /api/v2/sop/types/{type}/steps`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| type | Path | String | 是 | `OBSERVER_DATA_REBUILD` | SOP 类型编码。可填值仅为：`REBUILD_STANDBY_TENANT`（重建备租户）、`ARBITRATION_FOR_FAULTY_REPLICA`（副本异常开启仲裁服务）、`OBSERVER_DATA_REBUILD`（OBServer 异常后数据重建）。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.contents | Array | 按 `stepIndex` 升序排列的默认步骤。 |
| data.contents[].stepIndex | Integer | 默认步骤序号，从 1 开始。 |
| data.contents[].stepKey | String | 步骤唯一标识；创建/编辑任务时必须使用模板中的值。 |
| data.contents[].stepName | String | 当前 locale 下的步骤展示名称。 |
| data.contents[].stepKind | String | `EXECUTABLE`：执行类步骤，可能创建 OCP 任务实例；`CONFIRMATION`：确认类步骤，通过"执行下一步"确认推进。 |
| data.contents[].stepDescription | String \| null | 当前 locale 下的步骤说明；无说明时为 `null`。 |
| data.contents[].autoRun | Boolean | 默认是否自动执行；`false` 表示等待人工推进。 |
| data.contents[].enabled | Boolean \| null | 默认是否启用。`null` 表示固定启用且不可关闭；`true/false` 表示可配置。 |
| data.contents[].blockNext | Boolean | 步骤失败时是否阻断后续自动推进。 |
| data.contents[].editable | Boolean | 是否允许修改该步骤的 `autoRun`。 |
| data.contents[].userMovable | Boolean | 是否允许在创建/编辑任务时移动步骤位置。 |
| data.contents[].minStepIndex | Integer \| null | 可移动时允许的最小步骤序号（含）；否则为 `null`。 |
| data.contents[].maxStepIndex | Integer \| null | 可移动时允许的最大步骤序号（含）；否则为 `null`。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 返回步骤标识取值

`data.contents[].stepKey` 不接受任意字符串；每种 `type` 的完整步骤标识如下。创建和编辑任务时，步骤数组只能使用对应类型的标识。

| `type` | `stepKey` 完整取值（按默认步骤顺序） |
| --- | --- |
| `REBUILD_STANDBY_TENANT` | `CONFIRM_STANDBY_TENANT_INFO`、`BACKUP_PRIMARY_TENANT`、`DISCONNECT_STANDBY_TENANT`、`LOCK_STANDBY_TENANT`、`DELETE_STANDBY_TENANT`、`CREATE_STANDBY_TENANT`、`VERIFY_PRIMARY_STANDBY_SYNC` |
| `ARBITRATION_FOR_FAULTY_REPLICA` | `CONFIRM_ARBITRATION_TARGET`、`ADD_ARBITRATION_SERVICE`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`ENABLE_TENANT_ARBITRATION`、`VERIFY_TENANT_ARBITRATION` |
| `OBSERVER_DATA_REBUILD` | `CONFIRM_OBSERVER_TARGET`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`FORCE_DELETE_HOST`、`ADD_OBSERVER`、`ADD_TENANT_REPLICA`、`VERIFY_REPLICA_REBUILD` |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 400 | `SOP10006` (`SOP_TYPE_UNSUPPORTED`) | `type` 不属于当前支持的 SOP 类型。 |
