# 重试指定失败步骤

## 功能说明

重试指定失败步骤。执行实例整体不要求处于 `FAILED`，但指定步骤必须为 `FAILED`。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:UPDATE` 权限及目标资源 `UPDATE` 权限。

### 请求路径

`POST /api/v2/sop/tasks/{taskId}/execution/steps/{stepIndex}/retry`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- | --- |
| taskId | Path | Long | 是 | 任务 ID。 |
| stepIndex | Path | Integer | 是 | 待重试步骤序号。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.id | Long | 执行实例 ID。 |
| data.sopTaskId | Long | 所属 SOP 任务 ID。 |
| data.status | String | 重试后的执行状态，取值为 `WAITING_CONFIRM`、`RUNNING`、`FAILED` 或 `COMPLETED`。 |
| data.displayStatus | String | 用于展示的执行状态；当前与 `data.status` 相同。 |
| data.currentStepIndex | Integer | 当前最早未成功步骤的序号。 |
| data.totalSteps | Integer | 本次执行的步骤总数。 |
| data.readyManualStepIndexes | Array&lt;Integer&gt; | 可人工推进步骤序号。 |
| data.executor | String | 启动执行的用户名。 |
| data.startTime | Datetime | 执行开始时间。 |
| data.finishTime | Datetime \| null | 执行结束或失败时间；未结束时为 `null`。 |
| data.steps[] | Array | 全部步骤。每项均含 `stepIndex`、`stepKey`、`stepName`、`status`、`autoRun`、`stepParam`、`taskInstanceIds`、`retryCount`、`errorMessage`、`startTime`、`finishTime`，含义分别为步骤定位/展示、状态、自动开关、参数、关联任务、重试数、失败信息和时间。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` | 任务不存在。 |
| 404 | `SOP10012` | 任务未启动，不存在执行实例。 |
| 404 | `SOP10015` | 步骤序号不存在。 |
| 400 | `SOP10022` | 指定步骤状态不是 `FAILED`。 |
