# 查询 SOP 执行详情

## 功能说明

查询任务执行状态及全部步骤状态。任务未启动时仍成功返回预览：执行 ID、当前步骤、执行者和时间为 `null`，状态为 `NOT_STARTED`，所有步骤为 `PENDING`。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:READ` 权限。

### 请求路径

`GET /api/v2/sop/tasks/{taskId}/execution`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- | --- |
| taskId | Path | Long | 是 | 任务 ID。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.id | Long \| null | 执行实例 ID；未启动时为 `null`。 |
| data.sopTaskId | Long | 所属任务 ID。 |
| data.status | String | 执行状态：`NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED` 或 `COMPLETED`。 |
| data.displayStatus | String | 展示状态；当前与 `data.status` 相同。 |
| data.currentStepIndex | Integer \| null | 当前最早未成功步骤序号；未启动预览时为 `null`。 |
| data.totalSteps | Integer | 执行或预览的步骤总数。 |
| data.readyManualStepIndexes | Array&lt;Integer&gt; | 当前可人工推进步骤序号；未启动时为空数组。 |
| data.executor | String \| null | 启动执行的用户名；未启动时为 `null`。 |
| data.startTime | Datetime \| null | 执行开始时间；未启动时为 `null`。 |
| data.finishTime | Datetime \| null | 执行结束或失败时间；未结束时为 `null`。 |
| data.context | Object \| null | 当前响应组装逻辑通常不赋值，调用方不可依赖其内容。 |
| data.steps[] | Array | 全部步骤执行信息。 |
| data.steps[].stepIndex | Integer | 步骤序号。 |
| data.steps[].stepKey | String | 步骤唯一标识。 |
| data.steps[].stepName | String | 步骤展示名称。 |
| data.steps[].status | String | `PENDING`、`RUNNING`、`SUCCESSFUL` 或 `FAILED`；未启动预览时均为 `PENDING`。 |
| data.steps[].autoRun | Boolean | 当前自动执行开关。 |
| data.steps[].stepParam | Object \| null | 已保存步骤参数；未设置时为 `null`。 |
| data.steps[].taskInstanceIds | Array&lt;Long&gt; | 关联 OCP 任务实例 ID；没有时为空数组。 |
| data.steps[].retryCount | Integer | 重试次数；未启动预览为 `0`。 |
| data.steps[].errorMessage | String \| null | 步骤失败信息。 |
| data.steps[].startTime | Datetime \| null | 步骤开始时间。 |
| data.steps[].finishTime | Datetime \| null | 步骤结束时间。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` | 任务不存在。 |
