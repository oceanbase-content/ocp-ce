# 更新未执行步骤的自动执行开关或步骤参数

## 功能说明

更新已启动任务中处于 `PENDING` 状态的步骤。可单独修改 `autoRun`、保存 `stepParam`，或同时修改二者。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:UPDATE` 权限及目标资源 `UPDATE` 权限。步骤必须为 `PENDING`；只有请求中传 `autoRun` 时，才要求模板 `editable=true`。

### 请求路径

`PATCH /api/v2/sop/tasks/{taskId}/execution/steps/{stepIndex}`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| taskId | Path | Long | 是 | `1001` | 任务 ID。 |
| stepIndex | Path | Integer | 是 | `5` | 已启动执行实例中的步骤序号。 |
| autoRun | Body | Boolean | 否 | `true` | 自动执行开关；不传不修改。传入时步骤必须允许编辑。 |
| stepParam | Body | Object | 否 | `{"replacementHostId":200}` | 步骤级参数；不传不修改，空对象会保存为空对象。执行时同名字段覆盖任务级参数。 |

`stepParam` 已明确的业务字段与约束：

| SOP 类型 / 步骤 | 字段 | 类型 | 必选 | 约束 |
| --- | --- | --- | --- | --- |
| `OBSERVER_DATA_REBUILD` / `ADD_OBSERVER` | `replacementHostId` | Long | 非空 `stepParam` 时是 | 必须为正数；只能单独出现，或与 `replacementHostIp` 同时出现。 |
| `OBSERVER_DATA_REBUILD` / `ADD_OBSERVER` | `replacementHostIp` | String | 否 | 必须为非空字符串；服务端会根据 `replacementHostId` 补充或覆盖实际内网 IP。 |
| `REBUILD_STANDBY_TENANT` / `CREATE_STANDBY_TENANT` | `createStandbyTenantParamJson` | Object 或 JSON String | 执行此步骤时是 | 创建新备租户的完整参数对象。必须在执行该步骤前设置；完整字段、嵌套字段和示例见下文。 |

#### `createStandbyTenantParamJson` 详细参数

推荐直接传 JSON 对象；也兼容传 JSON 字符串。若传字符串，服务端会尝试解析并在保存时转换为对象。该对象仅用于 `REBUILD_STANDBY_TENANT` 的 `CREATE_STANDBY_TENANT` 步骤，不能写入其他步骤。

| 字段 | 类型 | 必选 | 可填值/约束 | 说明 |
| --- | --- | --- | --- | --- |
| name | String | 是 | 必须非空；格式为 `^[a-zA-Z][a-zA-Z_0-9]{1,63}$`，即以英文字母开头，长度 2–64，仅含英文字母、数字、下划线。 | 新创建的备租户名称。 |
| primaryTenantId | Long | 是 | 正整数。 | 对应主租户 ID。 |
| standbyClusterId | Long | 是 | 正整数。 | 新备租户所在 OceanBase 集群 ID。若该集群不属于当前 OCP，还需要相应的资源访问授权。 |
| logTransportMode | String | 是 | 只能填 `NETWORK` 或 `LOG_BACKUP`，并且**必须与创建 SOP 任务时 `targetParam.logTransportMode` 完全一致**。 | 新备租户的日志传输模式。 |
| mode | String | 否 | `MYSQL` 或 `ORACLE`。未传时按后端默认 `MYSQL`。 | 新备租户兼容模式。 |
| primaryZone | String | 否 | 最长 128 字符。 | 新租户的 primary zone 配置。 |
| standbyROPassword | String | 否 | 字符串；敏感信息，不应记录到日志或文档示例。 | 备租户日志同步只读用户密码。 |
| primaryRootPassword | String | 否 | 字符串；仅内部场景使用，外部调用方不应传递或持久化。 | 主租户 root 密码。 |
| primaryOcpClusterId | Long | 否 | 正整数时为主租户所在 OCP 集群 ID。 | 多 OCP 场景下标识主租户所在 OCP。 |
| recoveryDelaySeconds | Long | 否 | 非负整数；`null` 或 `0` 表示不延迟。 | 备租户日志恢复延迟，单位秒。 |
| restoreTenant | Boolean | 否 | `true`/`false`；仅 `logTransportMode=NETWORK` 时有意义，默认 `false`。 | 是否基于备份集创建网络备租户。 |
| enableArbitration | Boolean | 否 | `true`/`false`，默认 `false`。 | 是否为新备租户开启仲裁。 |
| serviceName | String | 否 | 字符串。 | 新租户服务名。 |
| description | String | 否 | 字符串。 | 新租户描述。 |
| loadType | String | 否 | `EXPRESS_OLTP`、`COMPLEX_OLTP`、`HTAP`、`OLAP`、`KV`、`EXPRESS_OLTP_PERF`。 | 租户工作负载类型。 |
| zones | Array | 是 | 数组不可为空，元素结构见下表。 | 新租户副本 Zone 配置。 |
| parameters | Array | 否 | 未传时后端默认空数组 `[]`；显式传入时不可为 `null`，允许空数组。元素结构见下表。 | 租户参数及系统变量。 |
| backupConfig | Object | 否 | `LOG_BACKUP` 或需要备份/归档恢复时按下表填写。 | 备份恢复配置。 |

`zones[]` 的每一项都必须包含以下字段：

| 字段 | 类型 | 必选 | 可填值/约束 | 说明 |
| --- | --- | --- | --- | --- |
| zones[].name | String | 是 | 非空。 | Zone 名称。 |
| zones[].replicaType | String | 是 | `FULL`、`LOGONLY`、`READONLY`、`COLUMNSTORE`。 | 该 Zone 的副本类型。 |
| zones[].resourcePool | Object | 是 | 必须包含下列资源池字段。 | Zone 的资源池配置。 |
| zones[].resourcePool.unitSpecName | String | 是 | 非空。 | Unit 规格名称。 |
| zones[].resourcePool.unitCount | Long | 是 | 非空；建议填写正整数，实际可用范围由下游资源池校验决定。 | 此 Zone 使用的 Unit 数量。 |

`parameters[]` 的每一项字段如下：

| 字段 | 类型 | 必选 | 可填值/约束 | 说明 |
| --- | --- | --- | --- | --- |
| parameters[].name | String | 是 | 非空。 | 租户参数或系统变量名称。 |
| parameters[].value | String | 是 | 非空。 | 参数值。 |
| parameters[].parameterType | String | 否 | `OB_TENANT_PARAMETER`（租户配置项）或 `OB_SYSTEM_VARIABLE`（系统变量）。 | 参数类别；不传时由下游创建租户逻辑按默认行为处理。 |

`backupConfig` 的字段如下。`useCustomStorage=true` 时，`dataBackupUrl` 和 `logBackupUrl` 均不可为空；路径中的空白会被去除，连续斜杠会被归一化。

| 字段 | 类型 | 必选 | 说明 |
| --- | --- | --- | --- |
| backupConfig.useCustomStorage | Boolean | 否 | 是否使用自定义备份存储目录，默认 `false`。 |
| backupConfig.backupStorageType | String | 否 | 备份存储类型，值须为当前 OCP 支持的存储类型。 |
| backupConfig.storageUrl | String | 否 | 备份策略配置的存储路径。 |
| backupConfig.dataBackupUrl | String | 条件必选 | 自定义存储时必须填写的数据备份路径。 |
| backupConfig.logBackupUrl | String | 条件必选 | 自定义存储时必须填写的日志备份路径。 |
| backupConfig.ossSecretModel | Object | 否 | 对象存储访问凭据，字段为 `endpoint`、`accessKeyId`、`accessKeySecret`，三者使用时均不能为空；`region` 仅 AWS S3 场景可填；`appId` 用于 COS 场景。敏感字段不得写入日志。 |
| backupConfig.advancedConfigsList | Array | 否 | 高级备份参数数组；每项包含非空 `name` 和非空字符串数组 `values`。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.stepIndex | Integer | 更新后的步骤序号。 |
| data.stepKey | String | 步骤唯一标识。 |
| data.stepName | String | 步骤展示名称。 |
| data.status | String | 当前状态：`PENDING`、`RUNNING`、`SUCCESSFUL` 或 `FAILED`。 |
| data.autoRun | Boolean | 更新后的自动执行开关。 |
| data.stepParam | Object \| null | 更新后的已保存步骤参数；未设置时为 `null`。 |
| data.taskInstanceIds | Array&lt;Long&gt; | 已关联 OCP 任务实例 ID；没有时为空数组。 |
| data.retryCount | Integer | 当前重试次数。 |
| data.errorMessage | String \| null | 最近失败信息。 |
| data.startTime | Datetime \| null | 步骤开始时间。 |
| data.finishTime | Datetime \| null | 步骤结束时间。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` | 任务不存在。 |
| 404 | `SOP10015` | 任务未启动或步骤序号不存在。 |
| 400 | `SOP10018` | 步骤不是 `PENDING`，不能更新。 |
| 400 | `SOP10019` | 请求修改 `autoRun`，但步骤不允许编辑。 |
| 400 | `SOP10002` | 步骤参数不满足当前步骤的业务校验。 |

## 示例

### 请求示例

```json
PATCH /api/v2/sop/tasks/1001/execution/steps/5

{
  "stepParam": {
    "createStandbyTenantParamJson": {
      "name": "standby_tenant_new",
      "mode": "MYSQL",
      "primaryTenantId": 1002,
      "standbyClusterId": 1001,
      "logTransportMode": "NETWORK",
      "recoveryDelaySeconds": 0,
      "restoreTenant": false,
      "enableArbitration": false,
      "zones": [
        {
          "name": "zone1",
          "replicaType": "FULL",
          "resourcePool": {
            "unitSpecName": "unit_s1",
            "unitCount": 1
          }
        }
      ],
      "parameters": [
        {
          "name": "ob_compatibility_mode",
          "value": "mysql",
          "parameterType": "OB_TENANT_PARAMETER"
        }
      ]
    }
  }
}
```
