# 查询 SOP 类型列表

## 功能说明

查询当前可创建的 SOP 类型、展示名称、目标输入提示和前置约束说明。

## 调用说明

### 接口约束

需要 `SOP_TASK:READ` 权限。

### 请求路径

`GET /api/v2/sop/types`

### 请求参数

无。

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 请求是否成功；成功时固定为 `true`。 |
| data.contents | Array | SOP 类型数组。 |
| data.contents[].code | String | 类型编码。当前为 `REBUILD_STANDBY_TENANT`（重建备租户）、`ARBITRATION_FOR_FAULTY_REPLICA`（副本异常开启仲裁服务）、`OBSERVER_DATA_REBUILD`（OBServer 异常后数据重建）。 |
| data.contents[].displayName | String | 当前 locale 下的类型展示名称。 |
| data.contents[].targetParamHint | Array&lt;String&gt; | 操作目标的输入提示，按展示顺序返回；没有提示时为空数组。 |
| data.contents[].constraints | String \| null | 当前 locale 下的该类型业务约束说明；没有约束时为 `null`。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |
