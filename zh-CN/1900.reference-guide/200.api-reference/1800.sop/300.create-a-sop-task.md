# 创建 SOP 任务

## 功能说明

创建 SOP 任务定义。`startNow=true` 时，保存任务后立即创建并启动执行实例；否则任务状态为 `NOT_STARTED`。

## 调用说明

### 接口约束

需要 `SOP_TASK:UPDATE` 权限，以及所选集群、租户、仲裁服务/服务组或主机的 `UPDATE` 权限。

### 请求路径

`POST /api/v2/sop/tasks`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| name | Body | String | 是 | `rebuild-standby-tenant-1` | 全局唯一任务名。长度 2–32；首字符必须为中文、英文字母、平假名或片假名；末字符必须为中文、英文字母、数字、平假名或片假名；中间可含下划线。 |
| sopType | Body | String | 是 | `REBUILD_STANDBY_TENANT` | SOP 类型编码。可填值仅为：`REBUILD_STANDBY_TENANT`、`ARBITRATION_FOR_FAULTY_REPLICA`、`OBSERVER_DATA_REBUILD`。 |
| targetParam | Body | Object | 是 | 见下表 | 任务级目标参数；字段由 `sopType` 决定。 |
| steps | Body | Array | 是 | 见示例 | 步骤配置数组，不能为空。`stepKey` 必须属于模板且不可重复；固定启用步骤必须提供；至少保留一个启用步骤。 |
| steps[].stepIndex | Body | Integer | 否 | `1` | 步骤序号。未传使用模板默认值。最终必须连续、不重复（`1..N`）；只有 `userMovable=true` 的步骤可在模板范围内移动。 |
| steps[].stepKey | Body | String | 是 | `CONFIRM_STANDBY_TENANT_INFO` | 模板返回的步骤标识。 |
| steps[].autoRun | Body | Boolean | 否 | `true` | 是否自动执行。未传使用模板默认值；不可编辑步骤不能改变默认值。 |
| steps[].enabled | Body | Boolean | 否 | `true` | 是否启用该步骤；只允许关闭模板允许关闭的步骤。 |
| comments | Body | String | 否 | `月度演练` | 任务备注；当前服务端未定义长度限制。 |
| startNow | Body | Boolean | 否 | `false` | 仅为 `true` 时立即启动；未传或 `false` 均不启动。 |

`targetParam` 字段按 `sopType` 不同：

| SOP 类型 | 参数 | 类型 | 必选 | 约束与含义 |
| --- | --- | --- | --- | --- |
| `REBUILD_STANDBY_TENANT` | `standbyClusterId` | Long | 是 | 待重建备租户所属集群 ID，必须为正数。 |
| | `standbyTenantId` | Long | 是 | 待重建备租户 ID，必须为正数。 |
| | `logTransportMode` | String | 是 | 日志传输方式，仅可为 `NETWORK` 或 `LOG_BACKUP`。 |
| | `standbyClusterName`、`standbyTenantName` | String | 否 | 展示用名称，服务端可能补充。 |
| `ARBITRATION_FOR_FAULTY_REPLICA` | `clusterId` | Long | 是 | 集群 ID，必须为数值。 |
| | `arbitrationServiceId` | Long | 条件必选 | 仲裁服务 ID；与 `arbitrationGroupId` 二选一且只能传一个。 |
| | `arbitrationGroupId` | Long | 条件必选 | 仲裁服务组 ID；与 `arbitrationServiceId` 二选一且只能传一个。 |
| | `clusterName` | String | 否 | 展示用集群名称。 |
| `OBSERVER_DATA_REBUILD` | `clusterId` | Long | 是 | 集群 ID，必须为数值。 |
| | `replacementHostId` | Long | 否 | 预选替代主机 ID；传入时必须为正数，未传时可在 `ADD_OBSERVER` 步骤前设置。 |
| | `clusterName` | String | 否 | 展示用集群名称。 |

`steps[].stepKey` 的可填值完全由 `sopType` 决定：

| `sopType` | `steps[].stepKey` 可填值 |
| --- | --- |
| `REBUILD_STANDBY_TENANT` | `CONFIRM_STANDBY_TENANT_INFO`、`BACKUP_PRIMARY_TENANT`、`DISCONNECT_STANDBY_TENANT`、`LOCK_STANDBY_TENANT`、`DELETE_STANDBY_TENANT`、`CREATE_STANDBY_TENANT`、`VERIFY_PRIMARY_STANDBY_SYNC` |
| `ARBITRATION_FOR_FAULTY_REPLICA` | `CONFIRM_ARBITRATION_TARGET`、`ADD_ARBITRATION_SERVICE`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`ENABLE_TENANT_ARBITRATION`、`VERIFY_TENANT_ARBITRATION` |
| `OBSERVER_DATA_REBUILD` | `CONFIRM_OBSERVER_TARGET`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`FORCE_DELETE_HOST`、`ADD_OBSERVER`、`ADD_TENANT_REPLICA`、`VERIFY_REPLICA_REBUILD` |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.id | Long | 新建任务 ID。 |
| data.name | String | 已保存任务名称。 |
| data.sopType | String | SOP 类型编码。 |
| data.sopTypeDisplayName | String | 当前 locale 下的 SOP 类型展示名称。 |
| data.targetParam | Object | 已保存任务级目标参数；可包含服务端解析出的名称、关联对象或快照字段。 |
| data.operationObjects | Object | 已解析展示对象，仅返回当前存在字段。重建备租户可能含 `oldStandbyTenant`、`oldStandbyCluster`、`primaryTenant`、`primaryTenantId`、`primaryCluster`、`primaryClusterId`、`primaryOcpClusterId`、`logTransportMode`、`backupConfig`、`newStandbyTenantId`、`newStandbyClusterId`、`newStandbyTenant`、`newStandbyCluster`；仲裁类型可能含 `tenantNames`、`faultyObserverIp`、`arbitrationServiceId`、`arbitrationGroupId`、`resolvedArbitrationServiceId`、`arbitrationServiceIp`、`arbitrationServicePort`、`arbitrationServiceGroupName`；OBServer 重建可能含 `tenantNames`、`faultyObserverIp`、`zoneName`、`replacementHostId`、`replacementHostIp`。 |
| data.targetSummary.displayText | String | 可直接展示的目标摘要。 |
| data.targetSummary.kind | String | 目标类别，当前为 `TENANT` 或 `CLUSTER`。 |
| data.targetSummary.details[] | Array | 摘要明细，每项包含 `label`（名称）和 `value`（值）。 |
| data.steps[] | Array | 已保存步骤配置。 |
| data.steps[].stepIndex | Integer | 步骤序号。 |
| data.steps[].stepKey | String | 步骤唯一标识。 |
| data.steps[].stepName | String | 当前 locale 下的步骤展示名称。 |
| data.steps[].stepKind | String | `EXECUTABLE` 或 `CONFIRMATION`。 |
| data.steps[].stepDescription | String \| null | 步骤说明。 |
| data.steps[].autoRun | Boolean | 是否自动执行。 |
| data.steps[].enabled | Boolean \| null | 是否启用；`null` 表示固定启用。 |
| data.steps[].blockNext | Boolean | 失败时是否阻断后续自动推进。 |
| data.steps[].editable | Boolean | 是否允许修改自动执行开关。 |
| data.steps[].userMovable | Boolean | 是否允许调整步骤顺序。 |
| data.steps[].minStepIndex | Integer \| null | 可移动步骤允许的最小序号。 |
| data.steps[].maxStepIndex | Integer \| null | 可移动步骤允许的最大序号。 |
| data.comments | String \| null | 已保存备注。 |
| data.creator | String | 创建人的 OCP 用户名。 |
| data.createTime | Datetime | 任务创建时间。 |
| data.updateTime | Datetime | 任务最后更新时间。 |
| data.displayStatus | String | `NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED` 或 `COMPLETED`。未立即启动时为 `NOT_STARTED`。 |
| data.currentExecutionId | Long \| null | 当前执行实例 ID；未启动时为 `null`。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 400 | `SOP10001` | 任务名不合法。 |
| 400 | `SOP10002` | 目标参数字段缺失、类型错误或不满足场景约束。 |
| 400 | `SOP10003` | 步骤为空、模板步骤缺失、步骤重复/不在模板中、非法关闭或全部关闭。 |
| 400 | `SOP10004` | 修改不可编辑步骤的 `autoRun`。 |
| 400 | `SOP10005` | 步骤序号不合法。 |
| 400 | `SOP10006` | SOP 类型不支持。 |
| 400 | `SOP10007` | 任务名称已存在。 |

## 示例

### 请求示例

```json
POST /api/v2/sop/tasks

{
  "name": "rebuild-standby-tenant-1",
  "sopType": "REBUILD_STANDBY_TENANT",
  "targetParam": {
    "standbyClusterId": 1,
    "standbyTenantId": 2,
    "logTransportMode": "NETWORK"
  },
  "steps": [
    {"stepIndex": 1, "stepKey": "CONFIRM_STANDBY_TENANT_INFO", "autoRun": true},
    {"stepIndex": 2, "stepKey": "BACKUP_PRIMARY_TENANT", "autoRun": true, "enabled": true},
    {"stepIndex": 3, "stepKey": "DISCONNECT_STANDBY_TENANT", "autoRun": true},
    {"stepIndex": 4, "stepKey": "LOCK_STANDBY_TENANT", "autoRun": true},
    {"stepIndex": 5, "stepKey": "DELETE_STANDBY_TENANT", "autoRun": true},
    {"stepIndex": 6, "stepKey": "CREATE_STANDBY_TENANT", "autoRun": false},
    {"stepIndex": 7, "stepKey": "VERIFY_PRIMARY_STANDBY_SYNC", "autoRun": true}
  ],
  "comments": "月度演练",
  "startNow": false
}
```
