# 启动 SOP 任务

## 功能说明

创建唯一执行实例和所有启用步骤，并启动首步骤。首步骤自动执行时，返回状态取决于即时处理结果；首步骤需人工执行时返回 `WAITING_CONFIRM`。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:UPDATE` 权限及目标资源 `UPDATE` 权限；一个任务只能启动一次。

### 请求路径

`POST /api/v2/sop/tasks/{id}/start`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 描述 |
| --- | --- | --- | --- | --- |
| id | Path | Long | 是 | 任务 ID。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.id | Long | 新建执行实例 ID。 |
| data.sopTaskId | Long | 所属任务 ID。 |
| data.status | String | 执行状态：`WAITING_CONFIRM`、`RUNNING`、`FAILED` 或 `COMPLETED`。 |
| data.displayStatus | String | 展示状态；当前与 `data.status` 相同。 |
| data.currentStepIndex | Integer | 当前最早未成功步骤序号；全部成功后保留最后一个步骤序号。 |
| data.totalSteps | Integer | 启用步骤总数。 |
| data.readyManualStepIndexes | Array&lt;Integer&gt; | 当前已就绪、可人工推进且 `autoRun=false` 的步骤序号。 |
| data.executor | String | 启动执行的用户名。 |
| data.startTime | Datetime | 执行开始时间。 |
| data.finishTime | Datetime \| null | 执行结束或失败时间；未结束时为 `null`。 |
| data.steps[] | Array | 全部步骤执行信息。 |
| data.steps[].stepIndex | Integer | 步骤序号。 |
| data.steps[].stepKey | String | 步骤唯一标识。 |
| data.steps[].stepName | String | 步骤展示名称。 |
| data.steps[].status | String | `PENDING`、`RUNNING`、`SUCCESSFUL` 或 `FAILED`。 |
| data.steps[].autoRun | Boolean | 当前自动执行开关。 |
| data.steps[].stepParam | Object \| null | 已保存步骤参数，未设置时为 `null`。 |
| data.steps[].taskInstanceIds | Array&lt;Long&gt; | 关联 OCP 任务实例 ID；没有时为空数组。 |
| data.steps[].retryCount | Integer | 已重试次数。 |
| data.steps[].errorMessage | String \| null | 最近失败信息，最长保留 1024 个字符。 |
| data.steps[].startTime | Datetime \| null | 步骤开始时间。 |
| data.steps[].finishTime | Datetime \| null | 步骤结束时间。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` | 任务不存在。 |
| 400 | `SOP10009` | 任务已启动；并发启动时仅一个请求成功。 |
| 400 | `SOP10002` 及场景错误码 | 目标对象、拓扑或运行状态的重新校验失败。 |
