# 查询 SOP 任务列表

## 功能说明

按名称、类型和显示状态查询调用方可读取的任务，支持分页和排序。

## 调用说明

### 接口约束

需要 `SOP_TASK:READ` 权限。结果只包含调用方可读取的 SOP 任务。

### 请求路径

`GET /api/v2/sop/tasks`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 默认值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| name | Query | String | 否 | - | 任务名称关键词，包含匹配。 |
| displayStatus | Query | StringArray | 否 | - | 状态集合，可重复传递或逗号分隔：`NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED`、`COMPLETED`。 |
| sopType | Query | StringArray | 否 | - | SOP 类型集合，可重复传递或逗号分隔。 |
| sortBy | Query | String | 否 | - | `START_TIME`（执行开始时间）或 `FINISH_TIME`（执行结束时间）；未传时按任务 ID 倒序。 |
| sortOrder | Query | String | 否 | `DESC` | `DESC` 降序，`ASC` 升序。 |
| page | Query | Integer | 否 | `1` | 页码，从 1 开始。 |
| size | Query | Integer | 否 | `5` | 每页数量，默认最大值为 `5000`。 |
| sort | Query | String | 否 | `id,DESC` | Pageable 原生排序；只在未传 `sortBy` 时使用。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.contents | Array | 当前页任务数组。 |
| data.contents[].id | Long | 任务 ID。 |
| data.contents[].name | String | 任务名称。 |
| data.contents[].sopType | String | SOP 类型编码。 |
| data.contents[].sopTypeDisplayName | String | 当前 locale 下的 SOP 类型展示名。 |
| data.contents[].creator | String | 创建人用户名。 |
| data.contents[].createTime | Datetime | 任务创建时间。 |
| data.contents[].displayStatus | String | 派生状态：`NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED` 或 `COMPLETED`。 |
| data.contents[].displayStatusName | String | 当前 locale 下的状态展示名。 |
| data.contents[].targetSummary.displayText | String | 目标摘要文字。 |
| data.contents[].targetSummary.kind | String | 目标类别。 |
| data.contents[].targetSummary.details[] | Array | 摘要明细，每项含 `label` 和 `value`。 |
| data.contents[].executionId | Long \| null | 已启动时的执行实例 ID；未启动为 `null`。 |
| data.contents[].startTime | Datetime \| null | 执行开始时间；未启动时为 `null`。 |
| data.contents[].finishTime | Datetime \| null | 执行结束/失败时间；未结束时为 `null`。 |
| data.contents[].progress.completedSteps | Integer | 已成功完成的启用步骤数；未启动为 `0`。 |
| data.contents[].progress.totalSteps | Integer | 启用步骤总数。 |
| data.contents[].progress.steps[] | Array | 启用步骤的简明进度。 |
| data.contents[].progress.steps[].stepIndex | Integer | 步骤序号。 |
| data.contents[].progress.steps[].stepKey | String | 步骤唯一标识。 |
| data.contents[].progress.steps[].stepName | String | 步骤展示名。 |
| data.contents[].progress.steps[].status | String | `PENDING`、`RUNNING`、`SUCCESSFUL` 或 `FAILED`；未启动时均为 `PENDING`。 |
| data.contents[].progress.steps[].autoRun | Boolean | 自动执行开关。 |
| data.contents[].progress.steps[].editable | Boolean | 是否允许调整自动执行开关。 |
| data.page.totalElements | Long | 满足条件的总记录数。 |
| data.page.totalPages | Integer | 总页数。 |
| data.page.number | Integer | 当前页码，从 1 开始。 |
| data.page.size | Integer | 当前页大小。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |
