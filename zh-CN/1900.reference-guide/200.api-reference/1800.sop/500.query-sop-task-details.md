# 查询 SOP 任务详情

## 功能说明

查询任务定义、目标参数、步骤配置和派生状态。实时步骤执行信息请调用"查询 SOP 执行详情"。

## 调用说明

### 接口约束

需要该任务的 `SOP_TASK:READ` 权限。

### 请求路径

`GET /api/v2/sop/tasks/{id}`

### 请求参数

| 参数 | 位置 | 类型 | 必选 | 示例值 | 描述 |
| --- | --- | --- | --- | --- | --- |
| id | Path | Long | 是 | `1001` | 任务 ID。 |

### 返回结果

| 参数 | 类型 | 说明 |
| --- | --- | --- |
| successful | Boolean | 成功时为 `true`。 |
| data.id | Long | 任务 ID。 |
| data.name | String | 任务名称。 |
| data.sopType | String | SOP 类型编码。 |
| data.sopTypeDisplayName | String | 当前 locale 下的 SOP 类型展示名。 |
| data.targetParam | Object | 任务级目标参数及服务端解析/补充字段。重建备租户核心字段为 `standbyClusterId`、`standbyTenantId`、`logTransportMode`；仲裁类型为 `clusterId` 与仲裁服务/服务组二选一；OBServer 重建为 `clusterId` 和可选 `replacementHostId`。 |
| data.operationObjects | Object | 已解析的展示对象。重建备租户可能含原/新备租户、原/新备集群、主租户、主集群、各类 ID、日志传输方式与备份配置；仲裁类型可能含受影响租户、故障 IP、仲裁服务/服务组和服务连接信息；OBServer 重建可能含受影响租户、故障 IP、Zone、替代主机 ID/IP。不存在字段不返回。 |
| data.targetSummary.displayText | String | 目标摘要文字。 |
| data.targetSummary.kind | String | 目标类别。 |
| data.targetSummary.details[] | Array | 摘要明细；每项含 `label`（名称）和 `value`（值）。 |
| data.steps[] | Array | 当前任务步骤配置。 |
| data.steps[].stepIndex | Integer | 步骤序号。 |
| data.steps[].stepKey | String | 步骤唯一标识。 |
| data.steps[].stepName | String | 步骤展示名称。 |
| data.steps[].stepKind | String | `EXECUTABLE` 或 `CONFIRMATION`。 |
| data.steps[].stepDescription | String \| null | 步骤说明。 |
| data.steps[].autoRun | Boolean | 是否自动执行。 |
| data.steps[].enabled | Boolean \| null | 是否启用；`null` 表示固定启用。 |
| data.steps[].blockNext | Boolean | 失败时是否阻断后续自动推进。 |
| data.steps[].editable | Boolean | 是否允许调整自动执行开关。 |
| data.steps[].userMovable | Boolean | 是否允许调整步骤顺序。 |
| data.steps[].minStepIndex | Integer \| null | 可移动步骤允许的最小序号。 |
| data.steps[].maxStepIndex | Integer \| null | 可移动步骤允许的最大序号。 |
| data.comments | String \| null | 备注。 |
| data.creator | String | 创建人用户名。 |
| data.createTime | Datetime | 任务创建时间。 |
| data.updateTime | Datetime | 任务最后更新时间。 |
| data.displayStatus | String | `NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED` 或 `COMPLETED`。 |
| data.currentExecutionId | Long \| null | 当前执行实例 ID；未启动时为 `null`。 |
| timestamp | Datetime | 服务端创建响应的时间。 |
| duration | Long | 服务端处理耗时，单位毫秒。 |
| status | Integer | HTTP 状态码，成功时为 `200`。 |
| traceId | String | 请求链路 ID，用于日志排查。 |

### 错误码

| HTTP | 错误码 | 说明 |
| --- | --- | --- |
| 404 | `SOP10008` (`SOP_TASK_NOT_FOUND`) | 任务不存在。 |
