# マシンタイプ一覧の取得

## 機能説明

マシンタイプ情報の一覧を取得します。

## 呼び出し説明

### インターフェース制約

呼び出し元はHOST_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/compute/hostTypes`

### リクエストパラメータ

**body：**

|  パラメータ  |   型    | 必須 |  サンプル値   |              説明                             |
|------|---------|------|--------|-------------------------------------|
| page | Integer | いいえ  | 1      | ページ番号。1から始まります。                  |
| size | Integer | いいえ  | 10     | リクエストデータのページサイズ。デフォルト値：10、最大値：2000。 |
| sort | String  | いいえ  | id,asc | リクエストデータのソート規則。              |

### 戻り結果

**基本データ構造**

|     パラメータ      |    型    |           説明           |
|-------------|----------|------------------------|
| data        | Object   | リクエストされたデータ。                  |
| ├─ contents | Array    | HostTypeの配列。詳細は**HostTypeデータ構造**を参照してください。 |
| ├─ page     | Object   | ページ情報。詳細は**pageデータ構造**を参照してください。                   |
| successful  | Boolean  | リクエストが成功したかどうか。                 |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。            |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。         |
| status      | Integer  | HTTP Status仕様に準拠したコード   |
| traceId     | String   | リクエストのTrace ID。問題の調査に使用されます。    |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。           |

**HostTypeデータ構造**

|     パラメータ      |   型   |   説明   |
|-------------|--------|--------|
| id          | Long   | マシンID。  |
| name        | String | マシン名。   |
| description | String | マシンの説明情報。 |
| createTime  | String | マシン作成日時。 |
| updateTime  | String | マシン更新日時。 |
| hostCount   | Long   | このマシンタイプのホスト数。  |

**pageデータ構造**

|      パラメータ       |   型    |  説明   |
|---------------|---------|-------|
| totalElements | Integer | 総レコード数。  |
| totalPages     | Integer | 総ページ数。   |
| number        | Integer | 現在のページ番号。  |
| size          | Integer | 現在のページサイズ。 |

## 例

### リクエスト例

```json
GET /api/v2/compute/hostTypes?page=1&size=10
```
