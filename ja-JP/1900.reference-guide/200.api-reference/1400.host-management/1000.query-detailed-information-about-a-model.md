# マシンタイプの詳細を照会する

## 機能説明

マシンタイプIDに基づいて、ホストのデータセンター情報を照会します。

## 呼び出し説明

### インターフェース制約

呼び出し元はHOST_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/compute/hostTypes/{hostTypeId}`

### リクエストパラメータ

**path:**

|   パラメータ     |   型    | 必須 | サンプル値 |  説明   |
|------------|---------|------|------|-------|
| hostTypeId | Integer | はい   | 100  | マシンタイプID。 |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |          説明          |
|------------|----------|----------------------|
| data        | Object   | リクエストされたデータ。                  |
| ├─ contents | Array    | HostTypeの配列。詳細は**HostTypeデータ構造**を参照してください。 |
| ├─ page     | Object   | ページネーション情報。詳細は**pageデータ構造**を参照してください。                   |
| successful  | Boolean  | リクエストが成功したかどうか。                 |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。            |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。         |
| status      | Integer  | HTTP Status仕様に準拠したコード   |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。    |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。           |

**HostTypeデータ構造**

|     パラメータ      |   型   |   説明   |
|-------------|--------|--------|
| id          | Long   | マシンタイプID。  |
| name        | String | マシンタイプ名。   |
| description | String | マシンタイプの説明情報。 |
| createTime  | String | マシンタイプの作成時間。 |
| updateTime  | String | マシンタイプの変更時間。 |
| hostCount   | Long   | このマシンタイプのホスト数。  |

**pageデータ構造**

|      パラメータ       |   型    |  説明   |
|---------------|---------|-------|
| totalElements | Integer | 総レコード数。  |
| totalPages     | Integer | 総ページ数。   |
| number        | Integer | 現在のページ番号。  |
| size          | Integer | 現在のページサイズ。 |

### リクエスト例

```json
GET /api/v2/compute/hostTypes/100
```
