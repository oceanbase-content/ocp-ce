# ホストの削除

## 機能説明

ホスト情報を削除します。

## 呼び出し説明

### インターフェース制約

呼び出し元はHOST_MANAGER権限を持っている必要があります。

### リクエストパス

`DELETE /api/v2/compute/hosts/{hostId}`

### リクエストパラメータ

**path：**

|   パラメータ   |  タイプ  | 必須 | サンプル値 |  説明   |
|--------|------|----|-----|-------|
| hostId | Long |  はい  | 100 | ホストID。 |

### 戻り結果

**基本データ構造**

|     パラメータ     |    タイプ    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

```json
DELETE /api/v2/compute/hosts/100
```

### 戻り値例

```json
{
  "duration": 41,
  "server": "a83ad33525",
  "status": 200,
  "successful": true,
  "timestamp": "2021-08-25T16:00:19.895+08:00",
  "traceId": "c8e610e3b33a4b17"
}
```
