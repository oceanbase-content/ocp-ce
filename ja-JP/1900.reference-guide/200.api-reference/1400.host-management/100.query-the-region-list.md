# リージョンリストの取得

## 機能の概要

リージョン情報のリストを取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はHOST_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/compute/regions`

### リクエストパラメータ

**body:**

|  パラメータ  |   型    | 必須 |  サンプル値   |                             説明                             |
|------|---------|----|--------|------------------------------------------------------------|
| page | Integer | いいえ  | 1      | ページ番号。1から始まります。                                                |
| size | Integer | いいえ  | 10     | リクエストデータのページサイズ。デフォルト値：10、最大値：2000。 |
| sort | String  | いいえ  | id,asc | リクエストデータのソート規則。                                                  |

### 戻り値

**基本データ構造**

|        パラメータ        |    型    |          説明          |
|------------------|----------|----------------------|
| data             | Object   | リクエストされたデータ。                |
| ├─ contents      | Array    | Regionの配列。詳細は**Regionデータ構造**を参照してください。 |
| ├─ page          |  Object  | ページ情報。詳細は**pageデータ構造**を参照してください。    |
| successful       | Boolean  | リクエストが成功したかどうか。               |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status           | Integer  | HTTPステータスコード。 |
| traceId          | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server           | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**Regionデータ構造**

|     パラメータ      |   型    |    説明    |
|-------------|---------|----------|
| id          | Integer | リージョンID。    |
| name        | String  | リージョン名。     |
| description | String  | リージョンの説明情報。   |
| createTime  | String  | リージョン情報の作成日時。 |
| updateTime  | String  | リージョン情報の変更日時。 |
| hostCount   | Integer | リージョン内のホスト数。   |
| idcs        | Array   | リージョン内のデータセンターリスト。詳細は**IdcEntityデータ構造**を参照してください。  |

**IdcEntityデータ構造**

|    パラメータ     |   型    |    説明    |
|-------------|---------|----------|
| id          | Integer | データセンターID。   |
| name        | String  | データセンター名。   |
| description | String  | データセンターの説明情報。  |
| createTime  | String  | データセンター情報の作成日時。   |
| updateTime  | String  | データセンター情報の変更日時。  |
| region      | -       | リージョン情報。   |

**pageデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|--------|
|  totalElements  |  Integer  |  総レコード数。  |
|  totalPages     |  Integer  |  総ページ数。  |
|  number         |  Integer  |  現在のページ番号。  |
|  size           |  Integer  |  現在のページサイズ。   |

```json
GET /api/v2/compute/regions?page=1&size=10
```
