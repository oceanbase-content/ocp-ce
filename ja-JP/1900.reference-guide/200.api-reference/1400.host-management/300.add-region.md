# リージョン情報の追加

## 機能説明

ホストのリージョン情報を追加します。

## 呼び出し説明

### インターフェース制約

呼び出し元はHOST_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/compute/regions`

### リクエストパラメータ

**body：**

|    パラメータ     |  タイプ  | 必須 |   サンプル値   |   説明   |
|-------------|--------|------|---------|--------|
| name        | String | はい   | shanghai | リージョン名。   |
| description | String | いいえ   | 上海     | リージョンの説明情報。 |

### 戻り値

**基本データ構造**

|        パラメータ        |    タイプ    |          説明          |
|------------------|----------|----------------------|
| data             | Object   | Regionの配列。詳細は**Regionデータ構造**を参照してください。      |
| successful       | Boolean  | リクエストが成功したかどうか。               |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status           | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId          | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server           | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**Regionデータ構造**

|     パラメータ      |   タイプ    |    説明    |
|-------------|---------|----------|
| id          | Integer | リージョンID。    |
| name        | String  | リージョン名。     |
| description | String  | リージョンの説明情報。   |
| createTime  | String  | リージョン情報の作成日時。 |
| updateTime  | String  | リージョン情報の変更日時。 |
| hostCount   | Integer | リージョン内のホスト数。   |
| idcs        | Array   | リージョン内のデータセンターリスト。詳細は**IdcEntityデータ構造**を参照してください。  |

**IdcEntityデータ構造**

|    パラメータ     |   型    |    説明    |
|-------------|---------|----------|
| id          | Integer | データセンターID。   |
| name        | String  | データセンター名。   |
| description | String  | データセンターの説明情報。  |
| createTime  | String  | データセンター情報の作成日時。   |
| updateTime  | String  | データセンター情報の変更日時。  |
| region      | -       | リージョン情報。   |

## 例

### リクエスト例

```json
POST /api/v2/compute/regions' -H 'Content-Type: application/json' --data-raw '{"name":"shanghai","description":"上海"}'
```
