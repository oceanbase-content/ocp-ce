# ホストの一括削除

## 機能説明

ホスト情報を一括削除します。

## 呼び出し説明

### インターフェース制約

呼び出し元はHOST_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/compute/hosts/batchDelete`

### リクエストパラメータ

**body：**

|     パラメータ     |    型     | 必須 |      サンプル値      |    説明    |
|------------|-----------|----|---------------|----------|
| hostIdList | LongArray | はい  | \[1001,1002\] | ホストIDのリスト。 |

### 戻り値

**基本データ構造**

|     パラメータ      |    型    |             説明             |
|-------------|----------|----------------------------|
| data        | Object   | リクエストされたデータ。                      |
| ├─ contents | Array    | TaskInstanceの配列です。詳細は**TaskInstanceデータ構造**を参照してください。 |
| successful  | Boolean  | リクエストが成功したかどうか。                     |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。                |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。             |
| status      | Integer  | HTTP Status仕様に準拠したコード。       |
| traceId     | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。        |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。               |

**TaskInstanceデータ構造**

|        パラメータ        |     型      |    説明       |
|------------------|-------------|-------------|
| id               | Long        | ソフトウェアパッケージID。     |
| name             | String      | ソフトウェアパッケージ名。     |
| clusterId        | Long        | クラスタID。       |
| tenantId         | Long        | テナントID。   |
| hostId           | Long        | ホストID。     |
| type             | String      | タスクの種類。次の値が利用可能です：<li>MANUAL：手動で開始された運用保守タスク。</li><li>SYS_ONECE：システムが実行する1回限りのタスク。</li><li>SCHEDULED：組み込みではない定期実行タスク。</li><li>SYS_SCHEDULED：システム組み込みの定期実行タスク。</li>               |
| status           | Integer     | タスクの実行状態。次の値が利用可能です：<li>RUNNING：実行中。</li><li>FAILED：実行失敗。</li><li>SUCCESSFUL：実行成功。</li>    |
| creator          | String      | タスク作成者のユーザー名。     |
| operation        | String      | タスク操作。以下の操作があります：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li>SKIP：スキップ。</li><li>CANCEL：キャンセル。</li>    |
| executor         | String      | タスク実行ノードのアドレス。    |
| createTime       | String      | タスクの作成日時。    |
| startTime        | String      | タスクの開始時刻。     |
| finishTime       | String      | タスクの終了時刻。   |
| prohibitRollback | Boolean     | ロールバックを禁止するかどうか。     |
| subtasks         | ObjectArray | SubtaskInstanceの配列。サブタスクの集計情報については、**SubtaskInstanceデータ構造**を参照してください。   |

**SubtaskInstanceデータ構造**

|     パラメータ         |    型     |      説明     |
|------------------|-----------|----------|
| id               | Long      | サブタスクインスタンスID。   |
| name             | String    | サブタスク名。   |
| seriesId         | Long      | サブタスクシリーズID。          |
| description      | String    | サブタスクの説明情報。  |
| timeout          | Integer   | サブタスクのタイムアウト時間。単位は秒。    |
| status           | String    | サブタスクの状態。以下の状態があります：<li>PENDING：初期状態。上流ノードの実行完了を待機しています。</li><li>READY：準備中。依存ノードの実行が完了し、実行を待機しています。</li><li>RUNNING：実行中。</li><li>CANCELING：キャンセル中。</li><li>FAILED：終了状態。実行失敗。</li><li>SUCCESSFUL：終了状態：実行成功。</li>   |
| operation        | String    | サブタスク操作。以下の操作があります：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li>SKIP：スキップ。</li><li>CANCEL：キャンセル。</li>    |
| executor         | String    | サブタスク実行ノード情報。         |
| runTime          | Integer   | サブタスクの実行回数。        |
| createTime       | String    | サブタスクの作成日時。      |
| startTime        | String    | サブタスクの開始時刻。      |
| finishTime       | String    | サブタスクの終了時刻。         |
| nodeType         | String    | ノードタイプ。例：JAVA_TASK。      |
| paralleIdx       | Integer   | 並列サブタスクのインデックス値。-1は非並列サブタスクを示します。    |
| upstreams        | LongArray | 上流サブタスクIDのリスト。     |
| downstream       | LongArray | 下流サブタスクIDのリスト。      |
| prohibitRollback | Boolean   | サブタスクでロールバックを禁止するかどうか。         |
