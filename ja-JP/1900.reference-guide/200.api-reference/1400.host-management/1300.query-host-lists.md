# ホストリストのクエリ

## 機能の概要

ホスト情報リストを照会します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はHOST_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/compute/hosts`

### リクエストパラメータ

**body：**

|   パラメータ      |    型   | 必須 |      サンプル値         |     説明      |
|-----------|-------------|---------|----------|---------|
| status              | StringArray | いいえ  | ONLINE,NEW          | ホストの状態。以下のような状態があります：<li>NEW：新しく追加されたホストで、OCP Agentがインストールされておらず、初期化もされていません。</li><li>AVAILABLE：ホストはオンラインで空き状態です。</li><li>ONLINE：ホストはオンラインでサービスがデプロイ済みです。</li><li>OFFLINE：ホストはオフラインです。</li><li>DELETING：ホストの削除中です。</li>     |
| keyword             | String      | いいえ  | cluster1            | ホスト検索のキーワード。あいまい一致をサポートします。以下の情報と一致します：<li>hostname：ホスト名。</li><li>innerIpAddress：ホストIPアドレス。</li><li>service：ホスト上にデプロイされたサービス情報。</li>     |
| includedServiceType | StringArray | いいえ  | OB_CLUSTER,OB_PROXY | ホストリストに含めるサービスタイプ。以下のサービスタイプがあります：<li>OB_CLUSTER：OceanBaseクラスタ。</li><li>OB_PROXY：OceanBaseプロキシ。</li><li>OCP_AGENT：OCP Agent。</li><li>BACKUP_AGENT：バックアップAgent。</li><li>RESTORE_AGENT：リストアAgent。</li><li>BACKUP_RESTORE_AGENT：バックアップ・リストアAgent。</li><li>OMS：OMSサービス。</li>    |
| excludedServiceType | StringArray | いいえ  | OB_CLUSTER,OB_PROXY | ホストリストに含めてはならないサービスタイプ。以下のサービスタイプがあります：<li>OB_CLUSTER：OceanBaseクラスタ、</li><li>OB_PROXY：OceanBaseプロキシ。</li><li>OCP_AGENT：OCP Agent。</li><li>BACKUP_AGENT：バックアップAgent。</li><li>RESTORE_AGENT：リストアAgent。</li><li>BACKUP_RESTORE_AGENT：バックアップ・リストアAgent。</li><li>OMS：OMSサービス</li>   |
| page                | Integer     | いいえ  | 1                   | ページ番号。1から始まります。          |
| size                | Integer     | いいえ  | 10                  | リクエストデータのページングサイズ。デフォルト値：10、最大値：2000。       |
| sort                | String      | いいえ  | id,asc              | リクエストデータのソート規則。       |

### 戻り値

**基本データ構造**

|     パラメータ      |    型    |          説明          |
|-------------|----------|----------------------|
| data        | Object   | リクエストされたデータ。                |
| ├─ contents | Array    | Hostの配列。詳細は**Hostデータ構造**を参照してください。   |
| ├─ page     | Object   | ページング情報。詳細は**pageデータ構造**を参照してください。                 |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**Hostデータ構造**

|    パラメータ      |    型     |       説明     |
|--------------|-------------|-------------|
| id                     | Long        | ホストID。    |
| name                   | String      | ホスト名。    |
| alias                  | String      | ホストのエイリアス。      |
| description            | String      | ホストの説明情報。      |
| operatingSystem        | String      | オペレーティングシステム。      |
| operatingSystemRelease | String      | オペレーティングシステムのリリース名。        |
| architecture           | String      | ハードウェアアーキテクチャ。       |
| serialNumber           | String      | シリアル番号。        |
| innerIpAddress         | String      | ホストのIPアドレス。     |
| sshPort                | Integer     | SSHポート。          |
| kind                   | String      | ホストタイプ。次の2種類があります：<li>DEDICATED_PHYSICAL_MACHINE：物理マシン。</li><li>DEDICATED_ECS：ECS。</li>    |
| publishPorts           | String      | ポートマッピング。      |
| services               | ObjectArray | ServiceSummaryの配列。サービスのデプロイ状況をまとめた情報です。詳細については、**ServiceSummaryデータ構造**を参照してください。         |
| status                 | String      | ホストの状態。次の状態があります：<li>NEW：新規追加されたホストで、OCP Agentがインストールされておらず、初期化も行われていません。</li><li>AVAILABLE：ホストはオンラインで空き状態です。</li><li>ONLINE：ホストはオンラインで、サービスがデプロイ済みです。</li><li>OFFLINE：ホストはオフラインです。</li><li>DELETING：ホストの削除処理中です。</li>           |
| idcId                  | Long        | データセンターID。         |
| idcName                | String      | データセンター名。        |
| idcDescription         | String      | データセンターの説明情報。       |
| typeId                 | Long        | マシンタイプID。        |
| typeName               | String      | マシンタイプ名。        |
| typeDescription        | String      | マシンタイプの説明情報。        |
| regionId               | Long        | リージョンID。        |
| regionName             | String      | リージョン名。         |
| regionDescription      | String      | リージョンの説明情報。      |
| hostAgentId            | Long        | OCP Agent ID情報。       |
| hostAgentVersion       | String      | OCP Agentバージョン情報。         |
| hostAgentStatus        | String      | OCP Agentの状態情報。次の状態があります：<li>AVAILABLE：利用可能。</li><li>RESTARTING：再起動中。</li><li>STOPPING：停止中。</li><li>REINTSTALLING：再インストール中。</li><li>OFFLINE：オフライン中。</li><li>DELETED：削除済み。</li>    |
| createTime             | String      | ホストの作成時間。      |
| updateTime             | String      | ホストの変更時間。         |

**ServiceSummaryデータ構造**

|    パラメータ         |   型   |     説明     |
|-------------------|--------|---------------|
| name              | String | サービス名    |
| version           | String | サービスバージョン。    |
| type              | String | サービスタイプ。次のサービスタイプがあります：<li>OB_CLUSTER：OceanBaseクラスタ。</li><li>OB_PROXY：OceanBaseプロキシ。</li><li>OCP_AGENT：OCP Agent。</li><li>BACKUP_AGENT：バックアップAgent。</li><li>RESTORE_AGENT：リストアAgent。</li><li>BACKUP_RESTORE_AGENT：バックアップ・リストアAgent。</li><li>OMS：OMSサービス。</li>    |
| softwarePackageId | Long   | ソフトウェアパッケージID。     |

**pageデータ構造**

|    パラメータ       |   型    |  説明   |
|---------------|---------|-------|
| totalElements | Integer | 総レコード数。  |
| totalPages    | Integer | 総ページ数。   |
| number        | Integer | 現在のページ番号。  |
| size          | Integer | 現在のページのサイズ。 |

```json
GET /api/v2/compute/hosts?page=1&size=10
```
