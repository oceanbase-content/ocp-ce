# データセンターの詳細を照会する

## 機能の概要

データセンターIDに基づいて、ホストのデータセンター情報を照会します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はHOST_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/compute/idcs/{idcId}`

### リクエストパラメータ

**path：**

|  パラメータ   |   型    | 必須 | サンプル値 |   説明    |
|-------|---------|----|-----|---------|
| idcId | Integer | はい  | 100 | ホストのデータセンターID。 |

### 戻り結果

**基本データ構造**

|     パラメータ      |    型    |          説明          |
|-------------|----------|----------------------|
| data        | Object   | リクエストされたデータ。                |
| ├─ contents | Array    | Idcの配列、詳細は**Idcデータ構造**を参照してください。    |
| ├─ page     | Object   | ページネーション情報、詳細は**pageデータ構造**を参照してください。    |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**Idcデータ構造**

|   パラメータ      |   型   |     説明     |
|-------------|--------|------------|
| id          | Long   | データセンターID。      |
| name        | String | データセンター名。       |
| description | String | データセンターの説明情報。     |
| regionId    | Long   | データセンターが属するリージョンID。 |
| regionName  | String | データセンターが属するリージョン名。  |
| createTime  | String | データセンターの作成日時。     |
| updateTime  | String | データセンターの更新日時。     |
| hostCount   | Long   | データセンター内のホスト台数。   |

**pageデータ構造**

|    パラメータ       |   型    |  説明   |
|---------------|---------|-------|
| totalElements | Integer | 総レコード数。  |
| totalPages    | Integer | 総ページ数。   |
| number        | Integer | 現在のページ番号。  |
| size          | Integer | 現在のページサイズ。 |

### リクエスト例

```json
GET /api/v2/compute/idcs/100
```
