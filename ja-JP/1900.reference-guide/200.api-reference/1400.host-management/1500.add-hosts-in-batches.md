# ホストの一括追加

## 機能の概要

一括でホスト情報を追加します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は HOST_MANAGER 権限を持っている必要があります。

### リクエストパス

`POST /api/v2/compute/hosts/batchCreate`

### リクエストパラメータ

**body：**

|    パラメータ         |     型      | 必須 |            サンプル値             |         説明        |
|-----------------|-------------|------|----------------|---------------|
| hostBasicDataList | ObjectArray | はい  | --                         | HostBasicData配列、ホストの基本情報。詳細は**HostBasicDataデータ構造**を参照してください。   |
| sshPort           | Integer     | はい  | 22                         | ホストのSSHポート。      |
| kind              | String      | はい  | DEDICATED_PHYSICAL_MACHINE | ホストタイプ。以下の2種類があります：<li>DEDICATED_PHYSICAL_MACHINE：物理マシン。</li><li>DEDICATED_ECS：ECS。</li>    |
| idcId             | Long        | はい  | 100                        | データセンターID。 |
| vpcId             | Long        | いいえ  | 100                        | VPC ID。   |
| typeId            | Long        | はい  | 1001                       | マシンタイプID。   |
| credentialId      | Long        | はい  | 1001                       | 認証情報ID。認証情報はSSHがホストにアクセスするための情報です。   |
| alias             | String      | いいえ  | マシン1                     | ホストのエイリアス。単一マシンのみ追加時に設定可能です。  |
| description       | String      | いいえ  | テストマシン                   | ホストの説明情報。  |
| mgragentPort      | Integer     | いいえ  | 62889                      | OCP-Agent監視データリスニングポート。デフォルトは62889。 |
| monagentPort      | Integer     | いいえ  | 62888                      | OCP-Agent APIリスニングポート。デフォルトは62888。 |
| monagentCpuQuota  | number      | いいえ  | 2.0                        | ocp_monagentのCPU構成。0.5C以上が必要です。0.5Cの倍数で増やしてください。推奨最大値は6Cです。 |
| monagentMemoryQuota | Integer    | いいえ  | 2                         | ocp_monagentのメモリ構成。1GiB以上が必要です。1GiBの倍数で増やしてください。推奨最大値は12GiBです。 |

**HostBasicDataデータ構造**

|       パラメータ       |   型   | 必須 |     サンプル値     |    説明    |
|----------------|--------|----|-------------|----------|
| innerIpAddress | String | はい  | xxx.xxx.xxx.xxx | ホストのIPアドレス。 |
| serialNumber   | String | いいえ  | 6CU4120W67  | ホストのシリアル番号。    |

### 戻り結果

**基本データ構造**

|     パラメータ      |    型    |             説明             |
|-------------|----------|----------------------------|
| data        | Object   | リクエストされたデータ。                      |
| ├─ contents | Array    | TaskInstanceの配列。詳細は**TaskInstanceデータ構造**を参照してください。 |
| successful  | Boolean  | リクエストが成功したかどうか。                     |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。                |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。             |
| status      | Integer  | HTTPステータスコードに準拠するエンコード。       |
| traceId     | String   | リクエストのトレースID。問題の調査に使用されます。        |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。               |

**TaskInstanceデータ構造**

|        パラメータ        |     型      |    説明       |
|------------------|-------------|-------------|
| id               | Long        | ソフトウェアパッケージID。     |
| name             | String      | ソフトウェアパッケージ名。     |
| clusterId        | Long        | クラスタID。       |
| tenantId         | Long        | テナントID。    |
| hostId           | Long        | ホストID。     |
| type             | String      | タスクタイプ。次の値が利用可能です：<li>MANUAL：手動で開始された運用保守タスク。</li><li>SYS_ONECE：システムが実行する1回限りのタスク。</li><li>SCHEDULED：組み込みではない定期実行タスク。</li><li>SYS_SCHEDULED：システム組み込みの定期実行タスク。</li>               |
| status           | Integer     | タスクの実行状態。次の値が利用可能です：<li>RUNNING：実行中。</li><li>FAILED：実行失敗。</li><li>SUCCESSFUL：実行成功。</li>    |
| creator          | String      | タスク作成者のユーザー名。     |
| operation        | String      | タスク操作。次の操作が可能です：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li>SKIP：スキップ。</li><li>CANCEL：キャンセル。</li>    |
| executor         | String      | タスク実行ノードのアドレス。    |
| createTime       | String      | タスク作成日時。    |
| startTime        | String      | タスク開始時刻。     |
| finishTime       | String      | タスク終了時刻。   |
| prohibitRollback | Boolean     | ロールバックを禁止するかどうか。     |
| subtasks         | ObjectArray | SubtaskInstanceの配列。サブタスクの集計情報です。詳細は**SubtaskInstanceデータ構造**を参照してください。   |

**SubtaskInstanceデータ構造**

|     パラメータ         |    型     |      説明     |
|------------------|-----------|----------|
| id               | Long      | サブタスクインスタンスID。   |
| name             | String    | サブタスク名。   |
| seriesId         | Long      | サブタスクシリーズID。          |
| description      | String    | サブタスクの説明情報。  |
| timeout          | Integer   | サブタスクのタイムアウト時間。単位は秒。    |
| status           | String    | サブタスクの状態。次のような状態があります：<li>PENDING：初期状態。上流ノードの実行完了を待機します。</li><li>READY：準備中。依存ノードの実行が完了し、実行を待機します。</li><li>RUNNING：実行中。</li><li>CANCELING：キャンセル中。</li><li>FAILED：終了状態。実行失敗。</li><li>SUCCESSFUL：終了状態：実行成功。</li>   |
| operation        | String    | サブタスク操作。次の操作が可能です：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li>SKIP：スキップ。</li><li>CANCEL：キャンセル。</li>    |
| executor         | String    | サブタスク実行ノード情報。         |
| runTime          | Integer   | サブタスクの実行回数。        |
| createTime       | String    | サブタスク作成日時。      |
| startTime        | String    | サブタスク開始時刻。      |
| finishTime       | String    | サブタスク終了時刻。         |
| nodeType         | String    | ノードタイプ。例：JAVA_TASK。      |
| paralleIdx       | Integer   | 並列サブタスクのインデックス値。-1は非並列サブタスクを示します。    |
| upstreams        | LongArray | 上流サブタスクIDのリスト。     |
| downstream       | LongArray | 下流サブタスクIDのリスト。      |
| prohibitRollback | Boolean   | サブタスクでロールバックを禁止するかどうか。         |

```json

```
