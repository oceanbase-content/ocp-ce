# 新しいデータセンター情報の追加

## 機能の概要

ホストのデータセンター情報を追加します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はHOST_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/compute/idcs`

### リクエストパラメータ

**body:**

|   パラメータ      |   型   | 必須 |  サンプル値   |   説明   |
|-------------|--------|------|--------|--------|
| name        | String | はい  | idc-bj   | データセンター名。   |
| description | String | いいえ  | 北京 idc | データセンターの説明情報。 |
| regionId    | Long   | はい  | 100      | リージョンID。  |

### 戻り値

**基本データ構造**

|     パラメータ      |    型    |          説明          |
|-------------|----------|----------------------|
| data        | Object   | Idcの配列、詳細は**Idcデータ構造**を参照してください。     |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**Idcデータ構造**

|   パラメータ      |   型   |     説明     |
|-------------|--------|------------|
| id          | Long   | データセンターID。      |
| name        | String | データセンター名。       |
| description | String | データセンターの説明情報。     |
| regionId    | Long   | データセンターが属するリージョンID。 |
| regionName  | String | データセンターが属するリージョン名。  |
| createTime  | String | データセンターの作成日時。     |
| updateTime  | String | データセンターの変更日時。     |
| hostCount   | Long   | データセンター内のホスト数。   |

## 例

### リクエスト例

```json
POST /api/v2/compute/idcs -H 'Content-Type: application/json' --data-raw '{"name":"idc-bj","description":"北京データセンター","regionId":100}'
```
