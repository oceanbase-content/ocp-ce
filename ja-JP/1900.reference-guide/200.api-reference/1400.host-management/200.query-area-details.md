# リージョンの詳細を照会する

## 機能の概要

リージョンIDに基づいて、ホストのリージョン情報を照会します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はHOST_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/compute/regions/{id}`

### リクエストパラメータ

**path:**

|    パラメータ    |   型    | 必須 | サンプル値 |   説明    |
|----------|---------|----|-----|---------|
| id       | Integer | はい  | 2 | ホストリージョンID。 |

### 戻り値

**基本データ構造**

|        パラメータ        |    型    |          説明          |
|------------------|----------|----------------------|
| data             | Object   | リクエストされたデータ。                |
| ├─ contents      | Array    | Regionの配列。詳細は**Regionデータ構造**を参照してください。 |
| ├─ page          | Object   | ページネーション情報。                 |
| ├─ totalElements | Integer  | 総レコード数。                 |
| ├─ totalPages    | Integer  | 総ページ数。                  |
| ├─ number        | Integer  | 現在のページ番号。                 |
| ├─ size          | Integer  | 現在のページサイズ。                |
| successful       | Boolean  | リクエストが成功したかどうか。               |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration         | Integer  | サーバーがリクエストを処理した時間(ミリ秒)。       |
| status           | Integer  | HTTPステータスコード。 |
| traceId          | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server           | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**Regionデータ構造**

|     パラメータ      |   型    |    説明    |
|-------------|---------|----------|
| id          | Integer | リージョンID。    |
| name        | String  | リージョン名。     |
| description | String  | リージョンの説明情報。   |
| createTime  | String  | リージョン情報の作成時間。 |
| updateTime  | String  | リージョン情報の更新時間。 |
| hostCount   | Integer | リージョン内のホスト数。   |
| idcs        | Array   | リージョン内のデータセンターリスト。詳細は**IdcEntityデータ構造**を参照してください。  |

**IdcEntityデータ構造**

|    パラメータ     |   型    |    説明    |
|-------------|---------|----------|
| id          | Integer | データセンターID。   |
| name        | String  | データセンター名。   |
| description | String  | データセンターの説明情報。  |
| createTime  | String  | データセンター情報の作成時間。   |
| updateTime  | String  | データセンター情報の更新時間。  |
| region      | -       | リージョン情報。   |
