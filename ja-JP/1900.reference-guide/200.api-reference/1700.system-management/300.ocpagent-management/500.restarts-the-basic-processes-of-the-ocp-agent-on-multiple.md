# ホストのOCP Agentプロセスを一括再起動する

## 機能説明

ホスト上のOCP Agentプロセスを一括で再起動します。

## 呼び出し説明

### インターフェース制約

呼び出し元は対応するホスト管理権限を持っている必要があります。

### リクエストパス

`POST /compute/hosts/batchRestartAgents`

### リクエストパラメータ

|   パラメータ    |    型     | 必須 |      サンプル値      |    説明    |
|---------|-----------|-------|---------------|----------|
| hostIds | LongArray | はい  | \[1001,1002\] | ホストIDのリスト。 |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | 非同期DAGタスク情報。          |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

### リクエスト例

`POST /compute/hosts/batchRestartAgents`

```json
{
  "hostids": [2]
}
```
