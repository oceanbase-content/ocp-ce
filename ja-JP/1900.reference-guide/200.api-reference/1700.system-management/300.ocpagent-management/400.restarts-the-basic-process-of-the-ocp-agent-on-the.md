# ホストのOCP Agentプロセスを再起動する

## 機能の概要

指定されたホスト上のOCP Agentプロセスを再起動します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は対応するホストの管理権限を持っている必要があります。

### リクエストパス

`POST /compute/hosts/{hostId}/agent/restart`

### リクエストパラメータ

|   パラメータ   |  タイプ  | 必須 | サンプル値 |  説明   |
|--------|------|-------|-------|-------|
| hostId | Long |  はい  |  100   | ホストID。 |

### 戻り値

|   パラメータ     |    タイプ    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | 非同期タスク情報。               |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

`POST /compute/hosts/2/agent/restart`
