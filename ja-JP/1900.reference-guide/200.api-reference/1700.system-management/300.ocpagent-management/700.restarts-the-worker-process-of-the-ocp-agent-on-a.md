# ホストのOCP Agentのワーカープロセスを再起動する

## 機能の概要

ホスト上のOCP Agentの指定されたワーカープロセスを再起動します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は対応するホストの管理権限を持っている必要があります。

### リクエストパス

`POST /compute/hosts/{hostId}/agent/processes/{agentProcessId}/restart`

### リクエストパラメータ

|       パラメータ       |  タイプ  | 必須 | サンプル値 |     説明      |
|----------------|------|------|-------|-------------|
| hostId         | Long | はい  | 100 | ホストID。       |
| agentProcessId | Long | はい  | 200 | AgentプロセスID。 |

### 戻り値

|     パラメータ     |    タイプ    |              説明              |
|------------|----------|------------------------------|
| data       | Object   | 詳細については、**HostAgentProcessのデータ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                      |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                 |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。              |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。        |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。         |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                |

**HostAgentProcessのデータ構造**

|       パラメータ       |   タイプ    |            説明            |
|----------------|---------|--------------------------|
| id             | Long    | AgentプロセスID。              |
| hostId         | Long    | ホストID。                    |
| alias          | String  | プロセスのエイリアス。                     |
| pid            | Integer | プロセスPID。                   |
| user           | String  | プロセスユーザー。                     |
| startCommand   | String  | 起動コマンド。                     |
| ports          | String  | ポートを開放します。                     |
| elapsedTime    | Long    | 生存時間(秒)。                 |
| lastActiveTime | String  | 最終的に生存していた時間。                   |
| status         | String  | プロセスの状態。STOPPEDまたはSTARTEDのいずれかです。 |
| operable       | Boolean | ユーザーが操作できるかどうか。                  |
| logFilePattern | String  | ログファイル名のパターン。                  |
| createTime     | String  | 作成日時。                     |
| updateTime     | String  | 更新日時。                     |

### リクエスト例

`POST /compute/hosts/20/agent/processes/100/restart`
