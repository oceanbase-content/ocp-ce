# ホストのOCP Agent詳細を照会する

## 機能説明

指定されたホスト上のOCP Agentの詳細情報を取得します。

## 呼び出し説明

### インターフェース制約

呼び出し元は対象ホストの表示権限を持っている必要があります。

### リクエストパス

`GET /compute/hosts/{hostId}/agent`

### リクエストパラメータ

|   パラメータ   |  タイプ  | 必須 | サンプル値 |  説明   |
|--------|------|----|-----|-------|
| hostId | Long | はい  | 100 | ホストID |

### 戻り結果

|     パラメータ     |    タイプ    |            説明             |
|------------|----------|---------------------------|
| successful | Boolean  | リクエストが成功したかどうかを示します。                   |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。              |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。           |
| status     | Integer  | HTTP Status仕様に準拠したエンコードです。     |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。      |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。             |
| data       | Object   | 詳細については、**HostAgent情報のデータ構造**を参照してください。 |

**HostAgent情報のデータ構造**

|         パラメータ         |   タイプ   |               説明               |
|--------------------|--------|--------------------------------|
| id                 | Long   | Agent ID。                       |
| version            | String | Agentバージョン。                       |
| installHome        | String | Agentインストールディレクトリ。                     |
| logHome            | String | Agentログディレクトリ。                     |
| lastAvailableTime  | String | 最後のアクティブ時間。                         |
| hostId             | Long   | ホストID。                          |
| hostInnerIpAddress | String | ホストIP。                          |
| status             | String | Agentの状態。AVAILABLE、RESTARTING、STOPPING、REINSTALLING、OFFLINE、DELETEDのいずれかです。   |
| processes          | Array  | 詳細については、**HostAgentProcessのデータ構造**を参照してください。 |
| createTime         | String | 作成日時。                           |
| updateTime         | String | 更新日時。                           |

**HostAgentProcessのデータ構造**

|       パラメータ       |   型    |            説明            |
|----------------|---------|--------------------------|
| id             | Long    | AgentプロセスID。              |
| hostId         | Long    | ホストID。                    |
| alias          | String  | プロセスエイリアス。                     |
| pid            | Integer | プロセスPID。                   |
| user           | String  | プロセスユーザー。                     |
| startCommand   | String  | 起動コマンド。                     |
| ports          | String  | 開放ポート。                     |
| elapsedTime    | Long    | 生存時間（秒）。                 |
| lastActiveTime | String  | 最終活動時間。                   |
| status         | String  | プロセスの状態。STOPPEDまたはSTARTEDのいずれかです。 |
| operable       | Boolean | ユーザー操作が可能かどうか。                  |
| logFilePattern | String  | ログファイル名のパターン。                  |
| createTime     | String  | 作成日時。                     |
| updateTime     | String  | 更新日時。                     |
