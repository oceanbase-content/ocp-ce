# ホストのOCP Agentのワーカープロセスリストを照会する

## 機能説明

ホストのOCP Agentのワーカープロセスリストを照会します。

## 呼び出し説明

### インターフェース制約

呼び出し元は対応するホストの管理権限を持っている必要があります。

### リクエストパス

`GET /compute/hosts/{hostId}/agent/processes`

### リクエストパラメータ

|   パラメータ   |  タイプ  | 必須 | サンプル値 |  説明   |
|--------|------|------|-------|-------|
| hostId | Long | はい  | 100 | ホストID。 |

### 戻り結果

|        パラメータ        |    タイプ    |               説明                |
|------------------|----------|---------------------------------|
| data             | Object   | リクエストされたデータ。                          |
| ├─ contents      | Array    | 詳細は **HostAgentProcessのデータ構造** を参照してください。 |
| ├─ page          | Object   | ページ情報。                           |
| ├─ totalElements | Integer  | 総レコード数。                           |
| ├─ totalPages    | Integer  | 総ページ数。                            |
| ├─ number        | Integer  | 現在のページ番号。                           |
| ├─ size          | Integer  | 現在のページサイズ。                          |
| successful       | Boolean  | リクエストが成功したかどうか。                         |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。                    |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                 |
| status           | Integer  | HTTP Status仕様に準拠したエンコード。           |
| traceId          | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。            |
| server           | String   | リクエストに応答したアプリケーションサービスのアドレス。                   |

**HostAgentProcessのデータ構造**

|       パラメータ       |   タイプ    |            説明            |
|----------------|---------|--------------------------|
| id             | Long    | AgentプロセスID。              |
| hostId         | Long    | ホストID。                    |
| alias          | String  | プロセスのエイリアス。                     |
| pid            | Integer | プロセスPID。                   |
| user           | String  | プロセスユーザー。                     |
| startCommand   | String  | 起動コマンド。                     |
| ports          | String  | 開放ポート。                     |
| elapsedTime    | Long    | 生存時間（秒）。                 |
| lastActiveTime | String  | 最終活動時間。                   |
| status         | String  | プロセス状態。STOPPEDまたはSTARTEDのいずれかです。 |
| operable       | Boolean | ユーザー操作が可能かどうか。                  |
| logFilePattern | String  | ログファイル名のパターン。                  |
| createTime     | String  | 作成日時。                     |
| updateTime     | String  | 更新日時。                     |
