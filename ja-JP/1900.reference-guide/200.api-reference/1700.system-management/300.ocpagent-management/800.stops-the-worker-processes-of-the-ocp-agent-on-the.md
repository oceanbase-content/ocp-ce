# ホストのOCP Agentのワーカープロセスを停止する

## 機能説明

ホスト上のOCP Agentの指定されたワーカープロセスを停止します。

## 呼び出し説明

### インターフェース制約

呼び出し元は対応するホスト管理権限を持っている必要があります。

### リクエストパス

`POST /compute/hosts/{hostId}/agent/processes/{agentProcessId}/stop`

### リクエストパラメータ

|     パラメータ       |  タイプ  | 必須 | サンプル値 |     説明      |
|----------------|------|------|-------|-------------|
| hostId         | Long | はい  | 100 | ホストID。       |
| agentProcessId | Long | はい  | 200 | AgentプロセスID。 |

### 戻り値

|   パラメータ     |    タイプ    |              説明              |
|------------|----------|------------------------------|
| data       | Object   | 詳細は **HostAgentProcessのデータ構造** を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                      |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                 |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。              |
| status     | Integer  | HTTP Status仕様に準拠したコード。        |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。         |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                |

**HostAgentProcessのデータ構造**

|       パラメータ       |   タイプ    |            説明            |
|----------------|---------|--------------------------|
| id             | Long    | AgentプロセスID。              |
| hostId         | Long    | ホストID。                    |
| alias          | String  | プロセスのエイリアス。                     |
| pid            | Integer | プロセスPID。                   |
| user           | String  | プロセスユーザー。                     |
| startCommand   | String  | 起動コマンド。                     |
| ports          | String  | オープンポート。                     |
| elapsedTime    | Long    | 生存時間(秒)。                 |
| lastActiveTime | String  | 最後に稼働を確認した時刻。                   |
| status         | String  | プロセスの状態。STOPPEDまたはSTARTEDのいずれかです。 |
| operable       | Boolean | ユーザー操作が可能かどうかを示します。                  |
| logFilePattern | String  | ログファイル名のパターン。                  |
| createTime     | String  | 作成日時。                     |
| updateTime     | String  | 更新日時。                     |

### リクエスト例

`POST /compute/hosts/20/agent/processes/100/stop`
