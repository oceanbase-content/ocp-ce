# OCPアプリケーションの基本情報を照会する

## 機能説明

バージョン番号、ビルド日付、Javaバージョンなど、OCPアプリケーションの基本情報を照会します。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/info`

### リクエストパラメータ

なし。

### 戻り値

|        パラメータ         |    型    |       説明        |
|-------------------|----------|-----------------|
| name              | String   | アプリケーションサービス名。          |
| group             | Array    | ビルドしたMavenのグループ名。   |
| artifact          | Object   | ビルドしたアーティファクト名。          |
| buildTime         | Datetime | ビルド時間。            |
| buildVersion      | String   | ビルドバージョン。            |
| buildJavaVersion  | String   | ビルドで使用されたJavaバージョン。   |
| springBootVersion | String   | ビルドで使用されたSpringバージョン。 |

## 例

### リクエスト例

```json
GET /api/v2/info
```

### 返却例

```json
{
  "artifact": "ocp-server",
  "buildTime": "2025-04-25T16:42:34.536+08:00",
  "buildVersion": "4.3.6-SNAPSHOT",
  "commitBranch": "4.3.6_bp1_release",
  "commitId": "94801ef",
  "commitTime": "2025-04-25T06:36:05Z",
  "edition": "ENTERPRISE",
  "group": "com.oceanbase"
}
```
