# OCPサーバー側の時刻を照会する

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

OCPサーバー側の時刻を照会します。このAPIは、通常、ローカル時間とサーバー側の時間が同期しているかどうかを確認するために使用されます。

## **呼び出し説明**

**インターフェース制約**

このAPIは直接呼び出すことができ、認証は不要です。

**リクエストパス**

`GET /api/v2/time`

**リクエストパラメータ**

なし

**戻り値**

サーバー側の時刻をテキスト形式で返します。

## **例**

**リクエスト例**

```code
GET /api/v2/time
```

**返却例**

```code
2020-11-11T15:46:27.316+08:00
```
