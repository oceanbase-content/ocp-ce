# 過去のイベントを照会する

## 機能の概要

OCPの履歴イベントを照会します。イベントタイプ、操作イベント名、リソース名、操作者ID、イベント情報、イベントステータス、イベント発生の時間帯などの条件で履歴イベントを検索できます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

* 呼び出し元には履歴イベントの閲覧権限（AUDIT VIEWER）が付与されていなければなりません。

### リクエストパス

`GET /api/v2/audit/events`

### リクエストパラメータ

|     パラメータ       |       型     | 必須   |     サンプル値     |        説明        |
|----------------|----------------|--------|----------------|-------------|
| eventType      | StringArray    | いいえ  | COMPUTE_HOST_MANAGEMENT,OB_CLUSTER_MANAGEMENT | 詳細は **イベントタイプ** を参照してください。         |
| operationEvent | StringArray    | いいえ  | ADD_OB_ZONES, DELETE_OB_ZONES                 | 詳細は **操作イベント** を参照してください。       |
| resourceName   | String         | いいえ  | my_ob_cluster                                 | リソース名。OceanBaseクラスタ管理、バックアップ・リカバリではクラスタ名、ホスト管理ではホストIP、テナント管理では `クラスタ名:テナント名`、OCPユーザー管理ではOCPユーザー名、OCPクラスタ管理ではOCPクラスタ名となります。 |
| operatorId     | LongArray      | いいえ  | 1,2,3                                         | 操作者のID。OCPユーザーIDに対応します。       |
| eventInfo      | String         | いいえ  | {"clusterId":1}                               | イベント情報。操作イベント時のリクエストパラメータに対応します。        |
| status         | String         | いいえ  | SUCCESS                                       | イベントのステータス。現在、SUCCESSとFAILEDの2種類をサポートしています。     |
| startTime      | OffsetDateTime | いいえ  | 2021-09-07T19:04:42.768+08:00                 | イベント発生時間帯の開始時刻。    |
| endTime        | OffsetDateTime | いいえ  | 2021-09-08T19:04:42.768+08:00                 | イベント発生時間帯の終了時刻。     |
| page           | Integer        | いいえ  | 1                                             | ページネーションパラメータ。ページ数です。    |
| size           | Integer        | いいえ  | 10                                            | ページネーションパラメータ。1ページあたりのサイズです。      |
| order          | String         | いいえ  | startTime,desc                                | ページネーションパラメータ。ソートです。      |

### 戻り値

|   パラメータ      |    型    |                説明                |
|-------------|----------|----------------------------------|
| data        | Object   | リクエストされたデータ。                           |
| ├─ contents | Array    | 詳細は **AuditEventHistoryのデータ構造** を参照してください。 |
| ├─ page     | Object   | 詳細は **pageパラメータの詳細** を参照してください。             |
| successful  | Boolean  | リクエストが成功したかどうかを示します。                          |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプです。                     |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
| status      | Integer  | HTTPステータスコードです。            |
| traceId     | String   | リクエストのTrace IDで、問題の調査に使用されます。             |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**AuditEventHistoryのデータ構造**

|     パラメータ       |       型       |          説明       |
|----------------|----------------|-------------------|
| id             | Long           | 過去のイベントID。     |
| operationEvent | String         | 操作タイプ。上表 **操作イベント** を参照してください。   |
| eventType      | String         | イベントタイプ。上表 **イベントタイプ** を参照してください。   |
| resourceType   | String         | リソースタイプ。以下の7種類があります：COMPUTE_HOST（ホスト）、OB_TENANT（テナント）、OB_CLUSTER（OceanBaseクラスタ）、OB_PROXY_CLUSTER（OBProxyクラスタ）、OCP_USER（OCPユーザー）、OCP_ROLE（OCPロール）、OCP_CLUSTER（OCPクラスタ）。 |
| resourceId     | Long           | リソースID。ホストID、OceanBaseクラスタID、OBProxy ID、テナントIDなどです。    |
| resourceName   | String         | OceanBaseクラスタ名、ホストIP、テナント名などです。      |
| parentResource | String         | 親リソースがある場合、その親リソース名を示します。例：テナントの親リソースはクラスタであり、`resourceName` がテナント名の場合、`parentResource` はクラスタ名となります。    |
| operatorName   | String         | 操作者名、OCPユーザー名。     |
| operatorId     | Long           | 操作者ID、OCPユーザーID。       |
| status         | String         | イベントステータス。SUCCESS、FAILED。     |
| taskId         | Long           | タスクID。イベントが運用タスクの場合、このタスクのIDを示します。       |
| executionType  | String         | 運用タスクの実行タイプ。NEW（新規タスク）、RETRY（再試行タスク）。      |
| eventInfo      | String         | 操作を実行した際のリクエストパラメータです。        |
| clientIp       | String         | 操作を実行したクライアントのIPアドレスです。        |
| startTime      | OffsetDateTime | 操作の開始時間です。        |
| endTime        | OffsetDateTime | 操作の終了時間です。      |

**pageパラメータの詳細**

|    パラメータ       |   型    |   説明   |
|---------------|---------|--------|
| totalElements | Integer | 総レコード数。  |
| totalPages    | Integer | 総ページ数。   |
| number        | Integer | 現在のページ番号。  |
| size          | Integer | 現在のページのサイズ。 |
