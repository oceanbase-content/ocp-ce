# スローSQLのリストを照会する

## 機能の概要

このAPIは、スローSQLのリストを照会するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、指定されたテナントに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{clusterId}/tenants/{tenantId}/slowSql`

### リクエストパラメータ

|     名前   |   型    | 必須 |    サンプル値    |    説明    |
|------------|---------|--------|--------|----|
| clusterId  | Integer  | はい  |  1  | クラスタのID。      |
| tenantId   | Integer  | はい  |  10001  |  テナントのID。      |
| startTime  | Datetime | はい  | 2023-04-12T04:38:38Z        | スローSQL履歴パラメータの開始時間です。この時間はUTC時刻のみをサポートし、形式はYYYY-MM-DDThh:mm:ssZです。    |
| endTime    | Datetime | はい  | 2023-04-12T05:38:38Z        | スローSQL履歴パラメータの終了時間です。この時間はUTC時刻のみをサポートし、形式はYYYY-MM-DDThh:mm:ssZです。   |
| serverId   | Integer  | いいえ  | 300        | 指定されたOceanBaseサーバー上の計画のパフォーマンスを照会します。指定しない場合、SQLはすべてのサーバー上の計画のパフォーマンスを照会します。 |
| inner      | Boolean  | いいえ  |   false  |  内部SQLかどうか。  |
| sqlText    | String   | いいえ  |  hello      | SQLに含まれるキーワードです。キーワードは大文字小文字を区別しません。  |
| filterExpression  |  String  | いいえ  |  @avgCpuTime > 20 and @executions > 100  |   すべてのフィールドは@で参照されます。選択可能なフィールドについては、[SQLのパフォーマンス統計のクエリ](100.query-performance-indicators-of-an-sqL-statement.md)インターフェースが返すすべての列を参照してください。  |
| limit      | Integer  | いいえ  |  3  |   戻されるTOP数。 |
| sqlTextLength   |  Integer  | いいえ  |  65535   |  SQLテキストの最大長。  |

### 戻り値

* ベースデータ構造

  |     パラメータ    |    型  |          説明           |
  |-------------|----------|-------------------------|
  | data        | Object   | リクエストされたデータ。                |
  | ├─ contents | Array    | SlowSQLのデータリスト。データ構造は下表を参照。    |
  | successful  | Boolean  | リクエストが成功したかどうかを示します。               |
  | timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
  | status      | Integer  | HTTP Status仕様に準拠したコード。 |
  | traceId     | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。  |
  | server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

### リクエスト例

```javascript
GET /api/v2/ob/clusters/250/tenants/1196/slowSql?startTime=2024-07-28T00%3A00%3A00%2B08%3A00&endTime=2024-07-29T00%3A00%3A00%2B08%3A00
```
