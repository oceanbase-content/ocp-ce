# 実行計画のパフォーマンス統計の傾向を照会する

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

指定されたSQLに関連する実行計画のパフォーマンス傾向を照会します。

## **呼び出し説明**

**インターフェース制約**

呼び出し元は指定されたテナントに対する読み取り権限が必要です。

**リクエストパス**

`GET /api/v2/ob/clusters/{clusterId}/tenants/{tenantId}/plans/{uid}/trends`

**リクエストパラメータ**

|    パラメータ     |    型    | 必須 |               サンプル値                |   説明    |
|-----------|----------|----|----------------------------------|---------|
| clusterId | Integer  | はい  | 1                                | クラスタのID  |
| tenantId  | Integer  | はい  | 1001                             | テナントのID  |
| uid       | String   | はい  | AAAAAAAAAAEAAAAAAAKOvgAFs1_j8s3i | プランのUID |
| startTime | Datetime | はい  | 2020-02-16T05:32:16+08:00        | 開始時間    |
| endTime   | Datetime | はい  | 2020-02-16T07:32:16+08:00        | 終了時間    |

**戻り値**

* 基本データ構造

  |     パラメータ      |    型    |          説明           |
  |-------------|----------|-----------------------|
  | data        | Object   | リクエストされたデータ。                |
  | ├─ contents | Array    | プランのパフォーマンスサンプリングの配列、データ構造は下表を参照。    |
  | successful  | Boolean  | リクエストが成功したかどうか。               |
  | timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
  | duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
  | status      | Integer  | HTTPステータスコード。 |
  | traceId     | String   | リクエストのTrace Id、問題のトラブルシューティングに使用されます。  |
  | server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

* プランのパフォーマンスサンプリングのデータ構造

  |             パラメータ              |    型    |                説明                 |
  |-----------------------------|----------|-----------------------------------|
  | timestamp                   | Datetime | サンプリングしたタイムスタンプ                            |
  | executions                  | Integer  | 期間内の計画実行回数                       |
  | execPs                      | Float    | 期間内の計画による1秒あたりの平均実行回数                   |
  | maxExecTime                 | Float    | 期間内の計画による最大実行時間（ミリ秒）                 |
  | avgDiskReads                | Float    | 期間内の計画による平均ディスク読み取り回数                    |
  | avgDiskWrites               | Float    | 期間内の計画による平均ディスク書き込み回数                    |
  | avgBufferGets               | Float    | 期間内の計画による平均キャッシュ読み取り回数                    |
  | avgApplicationWaitTime      | Float    | 期間内の計画によるApplicationイベントの平均待機時間（ミリ秒） |
  | avgConcurrencyWaitTime      | Float    | 期間内の計画によるConcurrencyイベントの平均待機時間（ミリ秒） |
  | avgUserIoWaitTime           | Float    | 期間内の計画によるUserIOイベントの平均待機時間（ミリ秒）      |
  | avgRowProcessed             | Float    | 期間内の計画による平均処理行数                     |
  | avgElapsedTime              | Float    | 期間内の計画による平均応答時間                     |
  | avgCpuTime                  | Float    | 期間内の計画による平均CPU時間                  |
  | largeQueryPercentage        | Double    | 期間内の大規模クエリの割合                     |
  | timeoutCount        | Integer    | 期間内のタイムアウト回数                     |
  | delayedLargeQueryPercentage | Double    | 期間内にキューに入った大規模クエリの割合               |
  | timeoutPercentage           | Double    | 期間内に実行がタイムアウトした割合                    |
  | tableScan                   | Boolean  | 計画にフルテーブルスキャンが含まれているかどうかを示すメトリックです。                        |

## **例**

**リクエスト例**

クラスタIDが1、テナントIDが1001、計画UIDがAAAAAAAAAEAAAAAAAAJ_AAFszE_cnfRのパフォーマンス傾向を照会します。時間範囲は2020-11-03T19:00:00+08:00から2020-11-03T20:00です。

```code
/api/v2/ob/clusters/1/tenants/1001/plans/AAAAAAAAAAEAAAAAAAAJ_AAFszE_cnfR/trends?startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00
```
