# パフォーマンスレポートの生成

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

クラスタのパフォーマンスレポートを生成します。

## **呼び出し説明**

**インターフェース制約**

呼び出し元は、指定されたクラスタに対する読み取りおよび書き込み権限を持っている必要があります。

**リクエストパス**

`post  /api/v2/ob/clusters/{id}/performance/workload/reports`

**リクエストパラメータ**

|    パラメータ     |     型      | 必須 |   サンプル値    |                                                                                                                        説明                                                                                                                        |
|-----------|-------------|----|----------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| id | Integer     | はい  | 1        | 対象となるOceanBaseクラスタのID。                                                                                                                                                                                                                                         |
| startSnapshotId      | Long     | はい  | 123        | レポートの開始スナップショットポイント。                                                                                                                                                                                                                                         |
| endSnapshotId      | Long     | はい  | 125        | レポートの終了スナップショットポイント。                                                                                                                                                                                                                                         |
| name      | String     | はい  | report_name        | レポート名。                                                                                                                     |

**戻り値**

基本データ構造

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   |                 |
| ├─ id | Long   | レポートの一意のID。             |
| ├─ clusterName | String   | レポートが属するクラスタ名。           |
| ├─ obClusterId | Long   | レポートが属するクラスタのクラスタID。            |
| ├─ clusterId | Long   | OCP側で記録されているクラスタID。               |
| ├─ name | String   | レポート名。            |
| ├─ beginReportTime | String   | レポートの開始時間。            |
| ├─ endReportTime | String   | レポートの終了時間。              |
| ├─ generateTime | String   | レポート生成時間。             |
| ├─ status | String   | レポートの状態。CREATING/SUCCESSFUL/FAILEDの3種類があります。             |
| ├─ taskInstanceId | Long   | 関連するタスクインスタンスID。            |
| ├─ scope | String   | レポートの範囲。クラスタレベルとテナントレベルの2つのレベルがあります。現在はクラスタレベルのレポートのみサポートしています。             |
| ├─ creator | String   | 操作者。             |
| successful  | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠するコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |
