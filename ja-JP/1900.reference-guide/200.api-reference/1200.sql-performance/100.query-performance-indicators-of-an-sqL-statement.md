# SQLクエリのパフォーマンス統計の照会

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

テナントのSQLパフォーマンス統計を照会し、指定された時間範囲内でSQLのパフォーマンスを集計します。パフォーマンスデータには、クラスタ、テナント、サーバー、データベース、ユーザー、SQL_ID、応答時間、CPU時間、実行回数、エラー回数などが含まれます。**内部SQLかどうか、SQLテキストのキーワード、詳細検索** などの条件を使用して、特定のSQLのパフォーマンス指標を照会できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>このインターフェースのクエリは時間がかかります。応答時間が長い場合は、クエリの頻度、クエリの時間範囲、または同時リクエストの数を適宜減らしてください。同時に、OCP ServerとMonitor DBのリソース使用状況を確認し、必要に応じてスペック設定を調整することもできます。</p>
  </main>

## **呼び出しの説明**

**インターフェース制約**

呼び出し元は、指定したテナントに対する読み取り権限を持っている必要があります。

**リクエストパス**

`GET /api/v2/ob/clusters/{clusterId}/tenants/{tenantId}/topSql`

**リクエストパラメータ**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|------------|----------|----|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| clusterId  | Integer  | はい  | 1                         | クラスタのID                                                                                                                                                                                                                                                                                                                                                                        |
| tenantId   | Integer  | はい  | 1001                      | テナントのID                                                                                                                                                                                                                                                                                                                                                                        |

| inner      | Boolean  | いいえ  | false                     | 内部SQLを含むかどうかを示します。内部SQLとは、OceanBaseが発信するSQLを指します。デフォルトはfalse、つまり内部SQLは含まれません。                                                                                                                                                                                                                                                   |

## **例**

**リクエスト例**

クラスタIDが1、テナントIDが1001のSQLパフォーマンスを照会します。時間範囲は2020-11-03T19:00:00+08:00 から 2020-11-03T20:00 です。高度な検索条件として、実行回数が500以上であることを指定します。

```code
GET /api/v2/ob/clusters/1/tenants/1001/topSql?searchAttr=executions&searchOp=GE&searchVal=500&startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00
```
