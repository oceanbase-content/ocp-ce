# パフォーマンスレポートの取得

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

クラスタのパフォーマンスレポートを取得します。

## **呼び出しの仕方**

**インターフェース制約**

呼び出し元は、指定したクラスタに対する読み取りおよび書き込み権限が付与されていなければなりません。

**リクエストパス**

`get  /api/v2/ob/clusters/{id}/performance/workload/reports/{reportId}`

**リクエストパラメータ**

|             パラメータ              |   型    | 必須 | サンプル値  |                                                                                        説明                                                                                         |
|-----------------------------|---------|----|------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| id | Integer | はい  | 1 | 対象となるOceanBaseクラスタのIDです。    |
| reportId | Integer | はい  | 10 | パフォーマンスレポートのIDです。    |

**戻り値**

戻り値はバイナリストリームであり、HTMLファイルとして保存できます。

## **例**

**リクエスト例**

```code
get  /api/v2/ob/clusters/1/performance/workload/reports/10
```
