# スナップショットポイント情報のクエリ

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

指定されたクラスタのスナップショットポイント情報をクエリします。

## **呼び出し説明**

**インターフェース制約**

呼び出し元は、指定されたクラスタに対する読み取りおよび書き込み権限を持っている必要があります。

**リクエストパス**

`GET  /api/v2/ob/clusters/{id}/performance/workload/snapshots`

**リクエストパラメータ**

|    パラメータ     |     タイプ      | 必須 |   サンプル値    |                                                                                                                        説明                                                                                                                        |
|-----------|-------------|----|----------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| id | Integer     | はい  | 1        | 対象となるOceanBaseクラスタのID。                                                                                                                                                                                                                                         |
| snapshotId      | Long     | いいえ  | 123        | 返される結果の先頭のスナップショットポイント情報。                                                                                                                     |

**戻り値**

基本データ構造

|     パラメータ      |    タイプ    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   |                 |
| ├─ contents | Array   |              |
| ├─ snapshotId | Long   | スナップショットポイントID。             |
| ├─ snapshotTime | String   | スナップショットポイントが生成された時間。             |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**リクエスト例**

```code
GET  /api/v2/ob/clusters/1/performance/workload/snapshots
```
