# 実行計画の演算子構造のクエリ

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

実行計画の演算子構造をクエリします。戻り値は、順序付けられたツリー構造の操作演算子情報です。

## **呼び出し説明**

**インターフェース制約**

呼び出し元は、指定されたテナントに対する読み取り権限を持っている必要があります。

**リクエストパス**

`GET /api/v2/cluters/{clusterId}/tenants/{tenantId}/plans/{uid}/explain`

**リクエストパラメータ**

|    パラメータ     |    型    | 必須 |               サンプル値                |   説明    |
|-----------|----------|----|----------------------------------|---------|
| clusterId | Integer  | はい  | 1                                | クラスタのId  |
| tenantId  | Integer  | はい  | 1001                             | テナントのId  |
| uid       | String   | はい  | AAAAAAAAAAEAAAAAAAKOvgAFs1_j8s3i | プランのuid |
| startTime | Datetime | はい  | 2020-02-16T05:32:16+08:00        | 開始時間    |
| endTime   | Datetime | はい  | 2020-02-16T07:32:16+08:00        | 終了時間    |

**戻り結果**

基本データ構造

|        パラメータ         |    型    |          説明           |
|-------------------|----------|-----------------------|
| data              | Object   | リクエストされたデータ。                |
| ├─ data | Array    | 実行計画演算子の配列。実行計画演算子のデータ構造は下表1を参照。 |
| ├─ notEmpty | Boolean    | Plan Explain。 |
| ├─ planOperationSummery | Array    | 操作リストの配列。操作リストのデータ構造は下表2を参照。 |
| ├─ rootOperations | Array    | 操作演算子の配列。操作演算子のデータ構造は下表3を参照。 |
| successful        | Boolean  | リクエストが成功したかどうか。               |
| timestamp         | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration          | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status            | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId           | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。  |
| server            | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

実行計画演算子のデータ構造

|        パラメータ         |    型    |          説明           |
|-------------------|----------|-----------------------|
| ClusterName     | String | クラスタ名。                  |
| CollectTimeUs   | Long   | Planが収集された時間(マイクロ秒)。  |
| Cost            | Integer    | 演算子の実行コスト。         |
| CreateTime      | String | 作成時間。                |
| FirstLoadTimeUs | Long   | Planが初めて読み込まれた時間(マイクロ秒)。  |
| Id              | Long   | 演算子ID。  |
| ObClusterId     | Long   | OceanBaseクラスタID。  |
| ObServerId      | Long   | OceanBase側のServerId。  |
| ObTenantId      | Long   | OceanBaseテナントID。  |
| ObjectName      | String | 操作対象の名前。  |
| Operator        | String | 論理演算子。  |
| PlanId          | Long   | 実行計画ID。  |
| PlanUnionHash   | String | Planの一意の識別子で、Planの操作と対象を用いて計算されます。  |
| Property        | String | 出力フィルタリング。  |
| Rows            | Long   | 予測行数。  |

操作リストのデータ構造

|     パラメータ     |   型    |      説明      |
|------------|---------|--------------|
| operator   | String  | 論理演算子。       |
| objectName | String  | 操作対象。 |

操作演算子のデータ構造

|     パラメータ     |   型    |      説明      |
|------------|---------|--------------|
| operator   | String  | 演算子の名前。       |
| objectName | String  | 操作対象。通常はテーブル名です。 |
| rows       | Integer | 操作する行の規模。      |
| cost       | Integer | 操作のコスト。       |
| property   | String  | 操作の出力とフィルタリング。    |
| children   | Array   | 子操作の配列。      |

## **例**

**リクエスト例**

```javascript
GET /api/v2/ob/clusters/1/tenants/1001/plans/AAAAAAAAAAEAAAAAAAAJ_AAFszE_cnfR/explain?startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00
```
