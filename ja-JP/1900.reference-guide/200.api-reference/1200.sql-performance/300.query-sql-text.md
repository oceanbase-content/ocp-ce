# SQLテキストのクエリ

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

指定されたIDのSQLの全文をクエリします。

## **呼び出し説明**

**インターフェース制約**

呼び出し元は、指定されたテナントに対する読み取り権限を持っている必要があります。

**リクエストパス**

`GET /api/v2/ob/clusters/{clusterId}/tenants/{tenantId}/sqls/{sqlId}/text`

**リクエストパラメータ**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|-----------|----------|----|----------------------------------|---------|
| clusterId | Integer  | はい  | 1                                | クラスタのID  |
| tenantId  | Integer  | はい  | 1001                             | テナントのID  |
| sqlId     | String   | はい  | C9B3A63AFF8F2A408CCF3D5B0F36682D | SQLのID |
| startTime | Datetime | はい  | 2020-02-16T05:32:16+08:00        | 開始時間    |
| endTime   | Datetime | はい  | 2020-02-16T07:32:16+08:00        | 終了時間    |

**戻り値**

基本データ構造

| パラメータ | 型 | 説明 |
|-------------|----------|-----------------------|
| data        | Object   | リクエストされたデータ。                |
| ├─ fulltext | String   | SQLの全文。             |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。  |
| sqlId      | String   | SQLのID。         |
| statement      | String   | SQLパラメータ化後のテキスト。         |
| supportOutline      | Boolean   | SQLがoutlineにバインドできるかどうか。OBServer V2.2.70未満のバージョンでは、selectの最初の文字が必ずスペースである必要があります。         |
| tables      | String   | SQL内のテーブル名。         |
| userName      | String   | SQLのユーザー。         |
| dbName      | String   | データベース名。         |

## **例**

**リクエスト例**

クラスタIDが1、テナントIDが1001、SQL IDがC9B3A63AFF8F2A408CCF3D5B0F36682Dのテキストを照会します。時間範囲は2020-11-03T19:00:00+08:00 から 2020-11-03T20:00までです。

```code
GET /api/v2/ob/clusters/1/tenants/1001/C9B3A63AFF8F2A408CCF3D5B0F36682D/text?startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00
```
