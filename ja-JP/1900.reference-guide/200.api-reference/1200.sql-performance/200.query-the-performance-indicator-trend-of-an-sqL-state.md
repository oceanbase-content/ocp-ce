# クエリSQLのパフォーマンス統計の傾向を照会する

## **<UI-TERM key="ocp-v2.Tenant.New.ServiceName.Description">製品説明</UI-TERM>**

指定されたSQLのパフォーマンス統計における、特定の時間区間内のトレンドを照会します。パフォーマンスのトレンドは複数のサンプリングポイントで構成され、各サンプリングポイントには指定されたタイムスタンプにおけるパフォーマンス統計が含まれます。このインターフェースは、SQLのパフォーマンスが時間とともにどのように変化するかを観察するために使用できます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>より広範囲の時間区間を指定すると、返されるサンプリングポイントの数は約120個に収束します。</p>
  </main>

## **呼び出しの説明**

**インターフェース制約**

呼び出し元は、指定されたテナントに対する読み取り権限を持っている必要があります。

**リクエストパス**

`GET /api/v2/ob/clusters/{clusterId}/tenants/{tenantId}/sqls/{sqlId}/trends`

**リクエストパラメータ**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|-----------|----------|----|----------------------------------|-------------------------------------------------------|
| clusterId | Integer  | はい  | 1                                | クラスタのID                                                |
| tenantId  | Integer  | はい  | 1001                             | テナントのID                                                |
| sqlId     | String   | はい  | C9B3A63AFF8F2A408CCF3D5B0F36682D | SQLのID                                              |
| startTime | Datetime | はい  | 2020-02-16T05:32:16+08:00        | 開始時間                                                  |
| endTime   | Datetime | はい  | 2020-02-16T07:32:16+08:00        | 終了時間                                                  |
| serverId  | Integer  | いいえ  | 300                              | SQLが指定されたOceanBaseサーバーで実行されたパフォーマンス指標を照会します。指定しない場合、すべてのOceanBaseサーバーで実行されたパフォーマンス指標を照会します。 |
| dbName    | String   | いいえ  | oceanbase                        | SQLが指定されたデータベース内で実行されたパフォーマンス指標を照会します。指定しない場合、すべてのデータベースで実行されたパフォーマンス指標を照会します。    |

**戻り値**

* 基本データ構造

| パラメータ | 型 | 説明 |
|-------------|----------|--------------------------------|
| data        | Object   | リクエストされたデータ。                         |
| ├─ contents | Array    | SQLパフォーマンスサンプリングデータの配列です。SQLパフォーマンスサンプリングデータ構造は下表を参照してください。 |
| successful  | Boolean  | リクエストが成功したかどうか。                        |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。                   |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                |
| status      | Integer  | HTTP Status仕様に準拠したコード。          |
| traceId     | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。           |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。                  |

**リクエスト例**

```code
GET /api/v2/ob/clusters/1/tenants/1001/sqls/C9B3A63AFF8F2A408CCF3D5B0F36682D/trends?startTime=2020-11-03T19%3A00%3A00%2B08%3A00&endTime=2020-11-03T20%3A00%3A00%2B08%3A00&dbName=oceanbase&serverId=2
```
