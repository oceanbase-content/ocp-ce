# 点検対象一覧の取得

## 機能の概要

このAPIは、カテゴリに基づいて点検対象の一覧を取得することができます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/inspection/overview`

### リクエストパラメータ

**body：**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|--------|
|  objectIds             |  Array  |  いいえ  | 1            | 点検対象のOCP内のID。クラスタIDやテナントIDなど。複数のIDの場合は`,`で区切る。  |
|  inspectionObjectType  |  Array  |  はい  | OB_CLUSTER   | 対象タイプ。<li>OB_CLUSTER：クラスタ。</li><li>OB_TENANT：テナント。</li><li> HOST：ホスト。</li><li> OB_PROXY：OBProxy。</li>  |
|  scheduleStates        |  Array  |  いいえ  | ACTIVE       | スケジュール状態。<li>有効：ACTIVE。</li><li>無効：INACTIVE。</li><li>期限切れ：EXPIRED。</li>  |
|  name                  |  String |  いいえ  | cluster_test  | 点検対象名。  |
|  parentName            |  String |  いいえ  | AdminMeta     | 点検対象の親対象名。  |

### 戻り値

**基本データ構造**

|  パラメータ  |  型  | 説明       |
|--------|--------|----------------------------------|
|  data        |  Object   | リクエストされたデータ。 |
|  ├─ contents |  Array    | 詳細は **InspectionObjectOverview データ構造** を参照してください。    |
|  ├─ page     |  Object   | ページ情報。詳細は **page データ構造** を参照してください。    |
|  successful  |  Boolean  | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer  | HTTPステータスコード。            |
|  traceId     |  String   | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String   | リクエストに応答したアプリケーションサービスのアドレス。                    |

**InspectionObjectOverview データ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  inspectionObject  |  InspectionObject  |  詳細は**InspectionObjectデータ構造**を参照してください。  |
|  scheduleState  |  String  |  点検のスケジューリング状態です。  |
|  deadline  |  String  |  点検のスケジューリング締切時刻です。空の場合、締切時刻はありません。  |

**InspectionObjectデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  objectId  |  Integer  |  点検対象IDです。  |
|  inspectionObjectType  |  String  |  点検対象タイプです。<li>OB_CLUSTER：クラスタ。</li><li>OB_TENANT：テナント。</li><li>HOST：ホスト。</li><li>OB_PROXY：OBProxy。</li>  |
|  name  |  String  |  点検対象名です。  |

**pageデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|--------|
|  totalElements  |  Integer  |  総レコード数です。  |
|  totalPages     |  Integer  |  総ページ数です。  |
|  number         |  Integer  |  現在のページ番号です。  |
|  size           |  Integer  |  現在のページサイズです。   |

```json
GET /api/v2/inspection/overview
```
