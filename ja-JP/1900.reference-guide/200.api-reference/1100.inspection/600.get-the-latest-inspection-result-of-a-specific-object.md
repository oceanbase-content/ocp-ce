# 特定オブジェクトの直近の点検結果を取得する

## 機能の概要

点検対象のタイプ、点検シナリオ、点検対象ID（オプション）などの条件に基づいて、条件に合致するオブジェクトの直近の点検結果を取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET api/v2/inspection/report/info`

### リクエストパラメータ

**body：**

| パラメータ名 | 型 | 必須 | サンプル値 | 説明  |
|--------|--------|--------|---------|-------|
| tagId      | Long   | はい | 1 | 点検シナリオID。以下を含みます：<li>1：基本点検。</li><li>2：性能点検。</li><li>3：詳細点検。</li><li>4：設置点検。</li> |
| objectType | String | はい | OB_CLUSTER | 点検対象タイプ。以下を含みます：<li>OB_CLUSTER：クラスタ。</li><li>OB_TENANT：テナント。</li><li>HOST：ホスト。</li><li>OB_PROXY：OBProxy。</li> |
| objectId   | Long   | いいえ | 1 | オブジェクトID。 |

### 戻り値

**基本データ構造**

| パラメータ | 型 | 説明 |
|----------|----------|--------|
| data | Object  | リクエストされた業務データ。 |
| ├─ contents | Array | 点検結果の集計情報。詳細は**InspectionReportAggrInfoデータ構造**を参照してください。 |
| successful | Boolean | リクエストが成功したかどうか。 |
| timestamp | Datetime | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | Integer | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | Integer | HTTP Status仕様に準拠したコード。 |
| traceId | String | リクエストのTrace ID。問題の調査に使用されます。 |
| server | String | リクエストに応答したアプリケーションサービスのアドレス。 |

**InspectionReportAggrInfoデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| reportId | Long | 点検レポートID。 |
| objectId | Long | 点検対象ID。 |
| objectName | String | 点検対象名。 |
| objectType | String | 点検対象タイプ。 |
| tag | Object | 点検シナリオ。詳細は**InspectionTagデータ構造**を参照してください。 |
| startTime | Datetime | 点検開始時間。 |
| endTime | Datetime | 点検終了時間。 |
| itemResults | Array | 点検項目結果。詳細は**InspectionItemResultデータ構造**を参照してください。 |

**InspectionTagデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| id          | Long   | 点検シナリオID。 |
| name        | String | 点検シナリオ名。 |
| description | String | 点検シナリオの説明。 |
| configType  | String | 点検シナリオの設定タイプ。 |

**InspectionItemResultデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| itemId      | Long   | 点検項目ID。 |
| name        | String | 点検項目名。 |
| description | String | 点検項目の説明。 |
| rules       | Array  | 点検項目ルール。詳細は**InspectionItemRuleデータ構造**を参照してください。  |
| reportItems | Array  | 点検レポートアイテムリスト。詳細は**InspectionReportItemデータ構造**を参照してください。 |

**InspectionItemRuleデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| level | String | リスクレベル。**HIGH**、**MEDIUM**、**LOW** の3種類が含まれます。 |
| validator  | String  | リスク識別式。  |

**InspectionReportItemデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| itemId   | Long   | 点検項目ID。 |
| key      | String | 点検項目キー。 |
| value    | String | 点検項目値。 |
| rawValue | String | 点検項目の元の値。 |
| target   | String | 点検項目のターゲット。 |
| level    | String | リスクレベル。**HIGH**、**MEDIUM**、**LOW** の3種類が含まれます。 |

## 例

### リクエスト例

クラスタレベルでIDが3のオブジェクトの最新の基本点検結果を照会します。

```json
GET api/v2/inspection/report/info?objectType=OB_CLUSTER&tagId=1&objectId=3
```
