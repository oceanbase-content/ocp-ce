# インスペクションレポートの詳細を取得する

## 機能の概要

このAPIは、点検レポートの詳細を取得するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/inspection/report/{id}`

### リクエストパラメータ

**path：**

|  パラメータ  |  タイプ  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|--------|
|  id        |  Integer  |  はい  | 2   |  点検レポートID。  |

### 戻り結果

**基本データ構造**

|  パラメータ  |  タイプ  | 説明          |
|--------|--------|----------------------------------|
|  data        |  Object   | リクエストされたデータ。 |
|  ├─ contents |  Array    | 詳細は **InspectionReport データ構造** を参照してください。    |
|  ├─ page     |  Object   | ページ情報。詳細は **page データ構造** を参照してください。    |
|  successful  |  Boolean | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer  | HTTP Status仕様に準拠したコード。            |
|  traceId     |  String  | リクエストのTrace ID。問題のトラブルシューティングに使用されます。             |
|  server      |  String  | リクエストに応答したアプリケーションサービスのアドレス。                    |

**InspectionReport データ構造**

|  パラメータ  |  タイプ  |  説明  |
|--------|--------|--------|
|  id                |  Integer  |  点検レポートID。取得方法については、[すべての点検タスクのクエリ](100.get-all-inspection-task.md) APIを参照してください。  |
|  tag               |  InspectionTag  |  詳細は **InspectionTag データ構造** を参照してください。  |
|  inspectionObject  |  InspectionObject  |  詳細は **InspectionObject データ構造** を参照してください。  |
|  startTime         |  String  |  点検開始時間。  |
|  endTime           |  String  |  点検終了時間。タスク実行中はこのフィールドはありません。  |
|  taskId            |  Integer  |  点検タスクID。  |
|  itemTotalCount    |  Integer  |  点検項目の合計数。  |
|  itemFinishedCount |  Integer  |  完了した点検項目数。  |
|  highRiskCount     |  Integer  |  高リスク点検項目数。  |
|  mediumRiskCount   |  Integer  |  中リスク点検項目数。  |
|  lowRiskCount      |  Integer  |  低リスク点検項目数。  |
|  taskState         |  String  |  点検タスクの状態。  |
|  inspectionItems   |  Array  |  点検レポートに含まれるすべての点検項目の情報。詳細は**InspectionItemOverviewデータ構造**を参照してください。  |
|  reportItems       |  Array  |  すべての点検項目アイテム。詳細は**InspectionReportItemデータ構造**を参照してください。  |

**InspectionTagデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|-------|
|  id    |  Integer  |  点検シナリオタグID。   |
|  name  |  String  |  タグ名。  |
|  description  |  String  |  タグの説明。  |
|  configType   |  String  |  設定タイプ。  |

**InspectionObjectデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  objectId  |  Integer  |  点検オブジェクトID。  |
|  inspectionObjectType  |  String  |  点検オブジェクトタイプ。  |
|  name      |  String  |  点検オブジェクト名。  |

**InspectionItemOverviewデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  id          |  Integer  |  点検項目ID。  |
|  identifier  |  Integer  |  点検項目の一意の識別子。  |
|  name        |  String   |  点検項目名。  |
|  description |  String   |  点検項目の説明。  |
|  targetType  |  String   |  点検項目タイプ。  |
|  rules       |  Array    |  点検項目ルール。詳細は**InspectionItemRuleデータ構造**を参照してください。  |

**InspectionItemRuleデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  level      |  String  |  リスクレベル。  |
|  validator  |  String  |  リスク判別式。  |

**InspectionReportItemデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  itemId    |  Integer  |  点検項目ID。  |
|  rawValue  |  String   |  加工前の点検結果値。  |
|  value     |  String   |  点検結果値。  |
|  target    |  String   |  点検対象。  |
|  key       |  String   |  パトロール結果キー。  |
|  level     |  Array    |  パトロール結果レベル。  |

**pageデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|--------|
|  totalElements  |  Integer  |  総レコード数。  |
|  totalPages     |  Integer  |  総ページ数。  |
|  number         |  Integer  |  現在のページ番号。  |
|  size           |  Integer  |  現在のページサイズ。   |

## 例

### リクエスト例

```json
GET /api/v2/inspection/report/{id}
```
