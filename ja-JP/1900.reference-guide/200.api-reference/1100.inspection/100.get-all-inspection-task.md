# 巡検タスクリストの取得

## 機能説明

このAPIは、すべての巡検タスクを取得するために使用されます。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/inspection/task`

### リクエストパラメータ

**body：**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|---------|--------|
|  inspectionObjectTypes  |  Array  |  いいえ  |  OB_CLUSTER  | 巡検オブジェクトタイプ。次のものが含まれます：<li>OB_CLUSTER：クラスタ。</li><li>OB_TENANT：テナント。</li><li>HOST：ホスト。</li><li>OB_PROXY：OBProxy。</li>   |
|  tags  |  Array  |  いいえ  |  1  | 巡検シナリオタグ。タグIDは以下のとおりです：<li>1：基本巡検。</li><li>2：性能巡検。</li><li>3：詳細巡検。</li><li>4：設置巡検。</li>  |
|  taskStates  |  String  |  いいえ  |  SUCCESSFUL  | 巡検タスクの状態。次のものが含まれます：<li>実行中：RUNNING。</li><li>失敗：FAILED。</li><li>完了：SUCCESSFUL。</li>  |
|  name  |  String  |  いいえ  | cluster_test   | 巡検オブジェクト名。  |

### 戻り結果

**基本データ構造**

|  パラメータ  |  型  | 説明                               |
|--------|---------|----------------------------------|
|  data        |  Object   | リクエストされたデータ。 |
|  ├─ contents |  Array    | 詳細は **InspectionReportOverview データ構造** を参照してください。    |
|  ├─ page     |  Object   | ページ情報。詳細は **page データ構造** を参照してください。    |
|  successful  |  Boolean  | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer  | HTTP Status仕様に準拠したコード。            |
|  traceId     |  String   | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String   | リクエストに応答したアプリケーションサービスのアドレス。                    |

**InspectionReportOverview データ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|---------|
|  id                |  Integer  |  巡検レポートID。  |
|  tag               |  Array    |  詳細は **InspectionTagデータ構造** を参照してください。  |
|  inspectionObject  |  Array    |  詳細は **InspectionObjectデータ構造** を参照してください。  |
|  startTime         |  String   |  巡検開始時間。  |
|  endTime           |  String   |  巡検終了時間。タスク実行中はこのフィールドはありません。  |
|  taskId            |  Integer  |  巡検タスクID。  |
|  itemTotalCount    |  Integer  |  巡検項目の合計数。  |
|  itemFinishedCount |  Integer  |  完了した巡検項目数。  |
|  highRiskCount     |  Integer  |  高リスク巡検項目数。  |
|  mediumRiskCount   |  Integer  |  中リスク巡検項目数。  |
|  lowRiskCount      |  Integer  |  低リスク巡検項目数。  |
|  taskState         |  String   |  巡検タスク状態。  |

**InspectionTagデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|---------|
|  id          |  Integer |  巡検シナリオタグID。  |
|  name        |  String  |  タグ名。  |
|  description |  String  |  タグの説明。  |
|  configType  |  String  |  設定タイプ。  |

**InspectionObjectデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|--------|
|  objectId  |  Integer  |  巡検オブジェクトID。  |
|  inspectionObjectType  |  String  |  巡検オブジェクトタイプ。  |
|  name      |  String   |  巡検オブジェクト名。  |

**pageデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|--------|
|  totalElements  |  Integer  |  総レコード数。  |
|  totalPages     |  Integer  |  総ページ数。  |
|  number         |  Integer  |  現在のページ番号。  |
|  size           |  Integer  |  現在のページサイズ。   |
