# インスペクションの開始

## 機能の概要

このAPIは、指定されたオブジェクトに対して特定のシナリオのインスペクションを開始するために使用します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/inspection/run`

### リクエストパラメータ

**query：**

|  パラメータ  |  タイプ  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|--------|
|  inspectionObjectType  |  String  |  いいえ  |  OB_CLUSTER  |  インスペクション対象のタイプ。以下を含みます：<li>OB_CLUSTER：クラスタ。</li><li>OB_TENANT：テナント。</li><li>HOST：ホスト。</li><li>OB_PROXY：OBProxy。</li> |
|  objectIds  |  Array   |  いいえ  |  1002  |  OCP内のインスペクション対象のID。例：クラスタID、テナントID。複数のIDの場合は`,`で区切ります。 |
|  tag        |  Integer |  はい  |  1  |  シナリオタグ。タグIDは以下のとおりです：<li>1：基本インスペクション。</li><li>2：パフォーマンスインスペクション。</li><li>3：詳細インスペクション。</li><li>4：導入インスペクション。</li> |

### 戻り値

**基本データ構造**

|  パラメータ  |  タイプ  |  説明  |
|--------|--------|--------|
|  data  |  Object  |  リクエストされたデータ。  |
|  ├─ contents |  Array    | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。    |
|  successful  |  Boolean |  リクエストが成功したかどうか。 |
|  timestamp |  Datetime  |  サーバーがリクエストを完了したタイムスタンプ。  |
|  duration |  Integer  |  サーバーがリクエストを処理した時間（ミリ秒）。  |
|  status |  Integer  |  HTTP Status仕様に準拠したエンコード。  |
|  traceId |  String  |  リクエストのTrace ID。問題の調査に使用されます。  |
|  server  |  String  |  リクエストに応答したアプリケーションサービスのアドレス。  |

### リクエスト例

```json
POST /api/v2/inspection/run?inspectionObjectType=OB_CLUSTER&tag=1
```
