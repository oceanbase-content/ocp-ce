# 指定した点検項目の直近の点検結果を照会する

## 機能の概要

点検対象のタイプ、点検シナリオ、点検対象ID（オプション）などの条件に基づいて、指定した点検項目の直近の点検結果を照会します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/inspection/report/info/item/{itemId}`

### リクエストパラメータ

**path：**

| パラメータ名 | 型 | 必須 | サンプル値 | サンプル |
|---------|---------|--------|--------|---------|
| itemId  | Long | はい | 1 | 点検項目ID。 |

**body：**

| パラメータ名 | 型 | 必須 | サンプル値 | サンプル |
|---------|---------|--------|--------|---------|
| tagId      | Long   | はい | 1          | 点検シナリオID。範囲：<li>1：基本点検。</li><li>2：パフォーマンス点検。</li><li>3：詳細点検。</li><li>4：設置点検。</li> |
| objectType | String | はい | OB_CLUSTER | 点検対象タイプ。範囲：<li>OB_CLUSTER：クラスタ。</li><li>OB_TENANT：テナント。</li><li>HOST：ホスト。</li><li>OB_PROXY：OBProxy。</li> |
| objectId   | Long   | いいえ | 1          | 対象ID。 |

### 戻り結果

**基本データ構造**

| パラメータ | 型 | 説明 |
|----------|---------|---------|
| data | Object | リクエストされた業務データ。 |
| ├─ contents | Array | 点検結果の集計情報。詳細は **InspectionReportAggrInfo データ構造** を参照してください。 |
| successful | Boolean | リクエストが成功したかどうか。 |
| timestamp | Datetime | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | Integer | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | Integer | HTTP Status仕様に準拠したエンコード。 |
| traceId | String | リクエストのTrace ID。問題のトラブルシューティングに使用されます。 |
| server | String | リクエストに応答したアプリケーションサービスのアドレス。 |

**InspectionReportAggrInfo データ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| reportId | Long | 点検レポートID。 |
| objectId | Long | 巡検対象ID。 |
| objectName | String | 巡検対象名。 |
| objectType | String | 巡検対象タイプ。 |
| tag | Object | 巡検シナリオ。詳細は**InspectionTagデータ構造**を参照してください。 |
| startTime | Datetime | 巡検開始時間。 |
| endTime | Datetime | 巡検終了時間。 |
| itemResults | Array | 巡検項目の結果。詳細は**InspectionItemResultデータ構造**を参照してください。 |

**InspectionTagデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| id          | Long   | 巡検シナリオID。 |
| name        | String | 巡検シナリオ名。 |
| description | String | 巡検シナリオの説明。 |
| configType  | String | 巡検シナリオの設定タイプ。 |

**InspectionItemResultデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| itemId      | Long   | 巡検項目ID。 |
| name        | String | 巡検項目名。 |
| description | String | 巡検項目の説明。 |
| rules       | Array  | 巡検項目ルール。詳細は**InspectionItemRuleデータ構造**を参照してください。  |
| reportItems | Array  | 巡検レポートアイテムリスト。詳細は**InspectionReportItemデータ構造**を参照してください。 |

**InspectionItemRuleデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| level | String | リスクレベル。**HIGH**、**MEDIUM**、**LOW** の3種類が含まれます。 |
| validator  | String  | リスク識別式。  |

**InspectionReportItemデータ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| itemId   | Long   | 巡検項目ID。 |
| key      | String | 巡検項目キー。 |
| value    | String | 巡検項目値。 |
| rawValue | String | 巡検項目の元の値。 |
| target   | String | 巡検項目のターゲット。 |
| level    | String | リスクレベル。**HIGH**、**MEDIUM**、**LOW** の3種類が含まれます。 |

## 例

### リクエスト例

クエリで、チェック項目IDが14のクラスタレベルの最終の基本巡回検査結果を照会します。

```json
GET /api/v2/inspection/report/info/item/14?objectType=OB_CLUSTER&tagId=1
```
