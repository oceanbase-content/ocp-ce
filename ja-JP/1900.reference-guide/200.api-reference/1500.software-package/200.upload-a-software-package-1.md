# ソフトウェアパッケージのアップロード

## 機能の概要

ローカルのソフトウェアパッケージをOCPサーバーにアップロードします。ソフトウェアパッケージのリストは、パッケージ名のキーワード、タイプ、バージョン、OS、アーキテクチャ情報でフィルタリングでき、アップロード日時で並べ替えることもできます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はPACKAGE_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/software-packages`

### リクエストタイプ

`multipart/form-data`

### リクエストパラメータ

|  パラメータ  |   型   | 必須 | サンプル値  |     説明      |
|------|--------|----|------|-------------|
| file | Binary | はい  | ファイル情報 | サーバーにアップロードするファイル |

### 戻り値

|     パラメータ     |    型    |           説明           |
|------------|----------|------------------------|
| data       | Object   | SoftwarePackageMetaオブジェクト |
| successful | Boolean  | リクエストが成功したかどうかを示します                 |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ            |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）         |
| status     | Integer  | HTTP Status仕様に準拠したコード   |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます    |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス           |

SoftwarePackageMetaのデータ構造

|       パラメータ        |   型    |                                                                                                                                                                                          説明                                                                                                                                                                                          |
|-----------------|---------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| id              | Integer | ソフトウェアパッケージID                                                                                                                                                                                                                                                                                                                                                                               |
| name            | String  | ソフトウェアパッケージ名                                                                                                                                                                                                                                                                                                                                                                                |
| fileName        | String  | ソフトウェアパッケージのファイル名（フルネーム）                                                                                                                                                                                                                                                                                                                                                                             |
| extension       | String  | ソフトウェアパッケージの拡張子                                                                                                                                                                                                                                                                                                                                                                               |
| size            | Integer | ソフトウェアパッケージのサイズ（バイト単位）                                                                                                                                                                                                                                                                                                                                                                           |
| sha1            | String  | ソフトウェアパッケージのSHA1ハッシュ値                                                                                                                                                                                                                                                                                                                                                                            |
| downloadUrl     | String  | ソフトウェアパッケージのダウンロードURL                                                                                                                                                                                                                                                                                                                                                                              |
| type            | String  | ソフトウェアパッケージタイプ * OB_SERVER_INSTALL_PACKAGE：OceanBaseインストールパッケージ   * OCP_AGENT_INSTALL_PACKAGE：OCP Agentインストールパッケージ    <!-- --> * OBPROXY_INSTALL_PACKAGE：OBProxyインストールパッケージ   * OB_BACKUP_AGENT_INSTALL_PACKAGE：バックアップ・リカバリソフトウェアインストールパッケージ    |
| version         | String  | ソフトウェアパッケージのバージョン                                                                                                                                                                                                                                                                                                                                                                                |
| buildNumber     | String  | ソフトウェアパッケージのビルド番号                                                                                                                                                                                                                                                                                                                                                                               |
| operatingSystem | String  | ソフトウェアパッケージがサポートするOS                                                                                                                                                                                                                                                                                                                                                                           |
| architecture    | String  | ソフトウェアパッケージのアーキテクチャ                                                                                                                                                                                                                                                                                                                                                                                |
