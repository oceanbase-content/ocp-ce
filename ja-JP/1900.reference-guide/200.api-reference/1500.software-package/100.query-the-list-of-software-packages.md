# ソフトウェアパッケージの一覧を照会する

## 機能の概要

OCPが管理するソフトウェアパッケージ情報を照会します。パッケージ名のキーワード、タイプ、バージョン、OS、アーキテクチャ情報でソフトウェアパッケージのリストをフィルタリングでき、アップロード時間でリストをソートすることもできます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はPACKAGE_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/software-packages`

### リクエストパラメータ

|       パラメータ      |    型     | 必須 |        サンプル値       |       説明        |
|-----------------|-------------|------|--------------|-------------------------|
| keyword         | String      | いいえ  | agent         | ソフトウェアパッケージ検索のキーワードです。この情報に基づいてパッケージ名がフィルタリングされます。        |
| type            | StringArray | いいえ  | OB_SERVER_INSTALL_PACKAGE,OB_AGENT_INSTALL_PACKAGE | ソフトウェアパッケージのタイプフィールドで、複数のタイプでのフィルタリングをサポートしています。候補値は以下の通りです： <li>`OB_SERVER_INSTALL_PACKAGE`：OceanBaseインストールパッケージ。</li><li>`OCP_AGENT_INSTALL_PACKAGE`：OCP Agentインストールパッケージ。</li><li>`OBPROXY_INSTALL_PACKAGE`：OBProxyインストールパッケージ。</li><li>`OB_BACKUP_AGENT_INSTALL_PACKAGE`：バックアップ・リストアインストールパッケージ。</li><li>`BINLOG_SERVICE_INSTALL_PACKAGE`：Binlog Serviceインストールパッケージ。</li><li>`OTHERS_RPM`：その他のインストールパッケージ。</li>  |
| version         | StringArray | いいえ  | 3.1.0,3.1.1   | ソフトウェアパッケージのバージョンです。複数のバージョンでのフィルタリングをサポートしています。       |
| operatingSystem | StringArray | いいえ  | alios,el7     | OSタイプです。複数のタイプを同時にフィルタリングできます。       |
| architecture    | StringArray | いいえ  | x84_64,arm    | システムアーキテクチャです。複数のアーキテクチャを同時にフィルタリングできます。        |
| page            | Integer     | いいえ  | 1             | リクエストデータのページ番号です。値は1から始まります。デフォルト値：1。        |
| size            | Integer     | いいえ  | 10            | リクエストデータのページサイズです。デフォルト値：10、最大値：2000。     |
| sort            | String      | いいえ  | name,asc      | リクエストデータのソート規則です。       |

### 戻り値

|        パラメータ      |    型    |                説明                 |
|------------------|----------|-----------------------------------|
| data             | Object   | リクエストされたデータです。                             |
| ├─ contents      | Array    | SoftwarePackageMetaの配列です。詳細は**SoftwarePackageMetaのデータ構造**を参照してください。 |
| ├─ page          | Object   | ページ情報です。                              |
| ├─ totalElements | Integer  | 総レコード数です。                              |
| ├─ totalPages    | Integer  | 総ページ数です。                               |
| ├─ number        | Integer  | 現在のページ番号です。                              |
| ├─ size          | Integer  | 現在のページサイズです。                             |
| successful       | Boolean  | リクエストが成功したかどうかを示します。                            |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプです。                       |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）です。                    |
| status           | Integer  | HTTPステータスコードです。              |
| traceId          | String   | リクエストのTrace IDです。問題の調査に使用されます。               |
| server           | String   | リクエストに応答するアプリケーションサービスのアドレス。                      |

**SoftwarePackageMetaのデータ構造**

|       パラメータ        |   型    |      説明      |
|-----------------|---------|------------------|
| id              | Integer | ソフトウェアパッケージID。       |
| name            | String  | ソフトウェアパッケージ名。        |
| fileName        | String  | ソフトウェアパッケージのファイル名。     |
| extension       | String  | ソフトウェアパッケージの拡張子。     |
| size            | Integer | ソフトウェアパッケージのサイズ、バイト単位。      |
| sha1            | String  | ソフトウェアパッケージのSHA1。      |
| downloadUrl     | String  | ソフトウェアパッケージのダウンロードURL。      |
| type            | String  | ソフトウェアパッケージタイプ：<li>`OB_SERVER_INSTALL_PACKAGE`：OceanBaseインストールパッケージ。</li><li>`OCP_AGENT_INSTALL_PACKAGE`：OCP Agentインストールパッケージ。</li><li>`OBPROXY_INSTALL_PACKAGE`：OBProxyインストールパッケージ。</li><li>`OB_BACKUP_AGENT_INSTALL_PACKAGE`：バックアップ・リカバリインストールパッケージ。</li><li>`BINLOG_SERVICE_INSTALL_PACKAGE`：Binlog Serviceインストールパッケージ。</li><li>`OTHERS_RPM`：その他のインストールパッケージ。</li>    |
| version         | String  | ソフトウェアパッケージのバージョン。     |
| buildNumber     | String  | ソフトウェアパッケージのビルド番号。      |
| operatingSystem | String  | ソフトウェアパッケージがサポートするOS。       |
| architecture    | String  | ソフトウェアパッケージのアーキテクチャ。      |
| deletable       | Boolean | ソフトウェアパッケージを削除できるかどうか。        |
