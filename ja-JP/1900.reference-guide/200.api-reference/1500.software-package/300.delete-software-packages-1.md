# ソフトウェアパッケージの削除

## 機能説明

指定したソフトウェアパッケージ情報を削除します。

## 呼び出し説明

### インターフェース制約

呼び出し元はPACKAGE_MANAGER権限を持っている必要があります。

### リクエストパス

`DELETE /api/v2/software-packages/{id}`

### リクエストパラメータ

| パラメータ |   型    | 必須 | サンプル値 |   説明   |
|----|---------|----|-----|--------|
| id        | Integer  | はい  | 1   | ソフトウェアパッケージID |

### 戻り値

|     パラメータ     |    型    |          説明          |
|------------|----------|----------------------|
| successful | Boolean  | リクエストが成功したかどうか               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）       |
| status     | Integer  | HTTP Status仕様に準拠したコード |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス         |

## 例

### リクエスト例

`DELETE /api/v2/software-packages/1`
