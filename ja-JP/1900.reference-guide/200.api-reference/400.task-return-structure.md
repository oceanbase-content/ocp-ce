# タスク戻り値構造

### TaskInstanceデータ構造

|        パラメータ        |     型      |      説明       |
|------------------|-------------|-----------------|
| id               | Long        | タスクID。     |
| name             | String      | タスク名。      |
| clusterId        | Long        | クラスタID。       |
| tenantId         | Long        | テナントID。         |
| hostId           | Long        | ホストID。        |
| type             | String      | タスクタイプ。次の値が利用可能です：<li>MANUAL：手動で開始された運用保守タスク。</li><li>SYS_ONECE：システムが実行する単一タスク。</li><li>SCHEDULED：組み込みではない定期実行タスク。</li><li> SYS_SCHEDULED：システム組み込みの定期実行タスク。 </li>  |
| status           | String      | タスクの実行状態。次の値が利用可能です：<li>RUNNING：実行中。</li><li>FAILED：実行失敗。</li><li>SUCCESSFUL：実行成功。</li>   |
| creator          | String      | タスク作成者のユーザー名。     |
| operation        | String      | タスク操作。以下の操作があります：<li>EXECUTE：通常実行。</li><li> RETRY：再試行。</li> <li>ROLLBACK：ロールバック。</li><li> SKIP：スキップ。</li><li>CANCEL：キャンセル。</li>   |
| executor         | String      | タスク実行ノードのアドレス。     |
| context          | String      | タスクのコンテキスト情報（JSON形式）。       |
| createTime       | String      | タスク作成時間。     |
| startTime        | String      | タスク開始時間。     |
| finishTime       | String      | タスク終了時間。      |
| prohibitRollback | Boolean     | ロールバックを禁止するかどうか。     |
| subtasks         | ObjectArray | SubtaskInstanceの配列。サブタスクの集計情報については、**SubtaskInstanceデータ構造**を参照してください。     |

### SubtaskInstanceデータ構造

|        パラメータ        |    型     |  説明      |
|------------------|-----------|---------------|
| id               | Long      | サブタスクインスタンスID。     |
| name             | String    | サブタスク名。   |
| seriesId         | Long      | サブタスクシリーズID。      |
| description      | String    | サブタスクの説明情報。    |
| className        | String    | サブタスクに対応するクラス名。      |
| timeout          | Integer   | サブタスクのタイムアウト時間（秒単位）。    |
| status           | String    | サブタスクの状態。以下の状態があります：<li>PENDING：初期状態。上流ノードの実行完了を待機しています。</li><li>READY：準備中。依存ノードの実行が完了し、実行を待機しています。</li><li>RUNNING：実行中。</li><li>CANCELING：キャンセル中。</li><li>FAILED：終了状態。実行失敗。</li><li> SUCCESSFUL：終了状態：実行成功。</li>   |
| operation        | String    | サブタスク操作。以下の操作があります：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li> SKIP：スキップ。</li> <li>CANCEL：キャンセル。</li>       |
| executor         | String    | サブタスク実行ノード情報。     |
| runTime          | Integer   | サブタスクの実行回数。    |
| context          | String    | サブタスク実行時のコンテキスト情報。     |
| createTime       | String    | サブタスク作成時間。     |
| startTime        | String    | サブタスク開始時間。     |
| finishTime       | String    | サブタスク終了時間。      |
| nodeType         | String    | ノードタイプ（例：JAVA_TASK）。   |
| paralleIdx       | Integer   | 並列サブタスクのインデックス値。-1は非並列サブタスクを示します。     |
| upstreams        | LongArray | 上流サブタスクIDのリスト。      |
| downstream       | LongArray | 下流サブタスクIDのリスト。    |
| prohibitRollback | Boolean   | サブタスクのロールバックを禁止するかどうかを示します。     |
