# OBProxyクラスタリストの確認

## 機能の概要

OBProxyクラスタリスト情報を照会する際に使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/obproxy/clusters`

### リクエストパラメータ

なし。

### 戻り値

**基本データ構造**

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   | リクエストされたデータ。                |
| ├─ contents | Array    | OBProxyのクラスタ情報。詳細は**obproxyClusterデータ構造**を参照してください。    |
| ├─ page     | Object   | ページネーション情報。詳細は**pageデータ構造**を参照してください。                 |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**pageデータ構造**

|      パラメータ       |   型    |   説明   |
|---------------|---------|--------|
| totalElements | Integer | 総ページ数。   |
| totalPages     | Integer | ページ番号。    |
| number        | Integer | 現在のページ番号。     |
| size          | Integer | 現在のページサイズ。 |

**obproxyClusterデータ構造**

|        パラメータ        |       型       |                           説明                            |
|------------------|----------------|---------------------------------------------------------|
| id               | Long           | OBProxyクラスタID。                                           |
| name             | String         | OBProxyクラスタ名。                                            |
| parameterVersion | Long           | OBProxyクラスタパラメータバージョン。                                          |
| creatorId        | Long           | 作成者ID。                                                  |
| creatorName      | String         | 作成者名。                                                   |
| createTime       | OffsetDateTime | 作成日時。                                                    |
| updateTime       | OffsetDateTime | 更新日時。                                                    |
| configUrl        | String         | ConfigUrlアドレス。                                           |
| address          | String         | OBProxyクラスタのアクセスアドレス。                                          |
| port             | Integer        | OBProxyクラスタのアクセスポート。                                          |
| obLinks          | Array          | 接続可能なOceanBaseクラスタ情報。詳細は**ObLinkデータ構造**を参照してください。                               |
| versions         | Array          | OBProxyデプロイメントバージョン情報。バージョンごとにOBProxy数を集計します。詳細は**VersionStatInfoデータ構造**を参照してください。  |
| topo             | Array          | OBProxyデプロイメントのトポロジー情報。データセンターごとにOBProxy数を集計します。詳細は**IdcStatInfoデータ構造**を参照してください。 |
| obproxies        | Array          | クラスタ内のすべてのOBProxyリスト。詳細は**ObproxyServerデータ構造**を参照してください。          |

**ObLinkデータ構造**

|     パラメータ      |   型   |       説明      |
|-------------|--------|------------|
| clusterId   | Long   | クラスタのOCP側のクラスタID。        |
| clusterName | String | クラスタ名。          |
| username    | String | 接続ユーザー。          |
| status      | String | クラスタの状態。値の範囲：<li>RUNNING</li><li>UNAVAILABLE</li><li>STOPPED</li><li>CREATING</li><li>TAKINGOVER</li><li>DELETING</li><li>MOVINGOUT</li><li>RESTARTING</li><li>STARTING</li><li>STOPPING</li><li>SWITCHOVER</li><li>FAILOVER</li><li>UPGRADING</li><li>OPERATING</li><li>ABANDONED</li><li>DISCONNECTING</li><li>STARTING_IN_READ_ONLY</li><li>MOVED_OUT</li>     |
| connections | Double | クラスタ接続数。           |
| obClusterId | Long   | クラスタのOceanBase側のクラスタID。          |
| clusterType | String | クラスタタイプ。値の範囲：<li>PRIMARY</li><li>STANDBY</li>         |

**VersionStatInfoデータ構造**

|   パラメータ    |   型   |     説明     |
|---------|--------|------------|
| version | String | バージョン情報。       |
| count   | Long   | OBProxy数。 |

**IdcStatInfoデータ構造**

|   パラメータ    |   型   |     説明     |
|---------|--------|------------|
| idcName | String | IDC名。     |
| count   | Long   | OBProxy数。 |

**ObproxyServerデータ構造**

|        パラメータ        |       型       |        説明       |
|------------------|----------------|-----------------|
| id               | Long           | OBProxy Server ID。      |
| clusterId        | Long           | OBProxyが属するOBProxyクラスタID。     |
| hostId           | Long           | OBProxyが属するHost ID。     |
| idcName          | String         | OBProxyが配置されているデータセンター名。       |
| lastActiveTime   | OffsetDateTime | 最後に利用可能であることを確認した時刻。       |
| parameterVersion | Long           | パラメータバージョン。        |
| ip               | String         | IPアドレス。         |
| sqlPort          | Integer        | SQLポート。        |
| exporterPort     | Integer        | エクスポーターポート。         |
| version          | String         | OBProxyのバージョン情報。       |
| status           | String         | OBProxyの状態。値の範囲：<li>CREATING</li><li>RUNNING</li><li>RESTARTING</li><li>UPGRADING </li><li>REFRESHING</li><li>DELETING</li><li>UNAVAILABLE</li><li>TAKINGOVER</li><li>STARTING</li><li>STOPPING</li><li>STOPPED</li><li>MOVINGOUT</li>    |
| operateStatus    | String         | OBProxyの操作状態。値の範囲：<li>NORMAL</li><li>OPERATING</li>        |
| architecture     | String         | ホストのハードウェアアーキテクチャ情報。       |
