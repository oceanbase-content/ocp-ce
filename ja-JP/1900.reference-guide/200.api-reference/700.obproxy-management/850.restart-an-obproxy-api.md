# OBProxyの再起動

## 機能説明

OBProxy Serverを再起動するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は少なくともOBPROXY_MANAGERロールである必要があります。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/obproxy/clusters/{id}/servers/restart`

### リクエストパラメータ

**path：**

|   パラメータ     | 型  | 必須  | サンプル値   |        説明         |
|------------|-------|-------|---------|-------------------|
| id         | Long  | はい    | 13153189       | OBProxyクラスタID。     |

**body：**

|    パラメータ    | 型    | 必須  | サンプル値       |        説明         |
|------------|---------|-------|-------------|-------------------|
| obproxyIds | Long    | はい    | \[1,2,3\]   | 再起動対象のOBProxy Server ID。 |
| hotRestart | Boolean | はい    | false       | ホット再起動を使用するかどうか。OBProxyがV3.2.1以降のバージョンの場合にのみサポートされます。    |

### 戻り値

**基本データ構造**

|   パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したコード。                                            |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答するアプリケーションサービスのアドレスです。                                                    |

## 例

### リクエスト例

`POST /api/v2/obproxy/clusters/1/servers/restart`

```shell
{
  "obproxyServerIds": [
    1,
    2,
    3
  ],
  "hotRestart": false
}
```
