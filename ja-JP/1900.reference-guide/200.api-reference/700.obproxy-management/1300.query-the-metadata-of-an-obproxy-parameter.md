# OBProxyパラメータの説明情報を照会する

## 機能の概要

OBProxyパラメータの説明情報を照会します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/obproxy/parameterInfo`

### リクエストパラメータ

**body：**

|   パラメータ    |   型   | 必須 |       サンプル値        |     説明     |
|---------|--------|----|------------------|------------|
| name    | String | いいえ  | rootservice_list | パラメータ名。      |
| version | String | いいえ  | 1.9.1            | OBProxyバージョン。 |

### 戻り結果

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Array    | 詳細は **ParameterInfoデータ構造** を参照してください。    |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**ParameterInfoデータ構造**

|         パラメータ          |   型   |      説明       |
|---------------------|--------|-------------|
| id                  | Long   | パラメータID。        |
| name                | String | パラメータ名。      |
| version             | String | バージョン。      |
| type                | String | パラメータタイプ。値の範囲：<li>BOOL</li><li>CAPACITY</li><li>DOUBLE</li><li>INT</li><li>MOMENT</li><li>STRING</li><li>STRING_LIST</li><li>TIME</li>    |
| allowedStringValues | String | パラメータの許容文字列。      |
| maxValue            | String | パラメータの最大値。      |
| minValue            | String | パラメータの最小値。     |
| defaultValue        | String | パラメータのデフォルト値。      |
| needRestart         | Bool   | 再起動が必要かどうか。     |
| readonly            | Bool   | 読み取り専用かどうか。      |
| description         | String | パラメータの説明。       |
| explanation         | String | パラメータの解説。     |
