# OBProxyクラスタの削除

## 機能説明

OBProxyクラスタを削除するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`DELETE /api/v2/obproxy/clusters/{id}`

### リクエストパラメータ

**path：**

| パラメータ |  型  | 必須 | サンプル値 |      説明       |
|------|------|------|------|---------------|
| id   | Long | はい   | 31440    | OBProxyクラスタID。 |

### 戻り結果

**基本データ構造**

|     パラメータ     |    型    |                               説明                                |
|------------|----------|-----------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細は[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                         |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                    |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                 |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。                                           |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。                                            |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                   |

### リクエスト例

`DELETE /api/v2/obproxy/clusters/31440`
