# OBProxyクラスタパラメータの確認

## 機能の概要

OBProxyクラスタのパラメータ設定を確認します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/obproxy/clusters/{id}/parameters`

### リクエストパラメータ

| パラメータ |  型  | 必須 | サンプル値 |      説明       |
|-------|------|-------|-------|---------------|
| id | Long | はい  | 3   | OBProxyクラスタID。 |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |              説明              |
|------------|----------|------------------------------|
| data       | Array    | 詳細は **ObproxyClusterParameter データ構造** を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                      |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                 |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。              |
| status     | Integer  | HTTP Status仕様に準拠したコード。        |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。         |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                |

**ObproxyClusterParameter データ構造**

|     パラメータ      |   型   |            説明            |
|-------------|--------|--------------------------|
| name        | String | パラメータ名。                     |
| description | String | パラメータの説明。                     |
| needReboot  | Bool   | 再起動が必要かどうか。                   |
| values      | Array  | 詳細は **ObproxyParameterValue データ構造** を参照してください。 |

**ObproxyParameterValueデータ構造**

|    パラメータ     |   型   |     説明     |
|-----------|--------|------------|
| value     | String | パラメータ値。        |
| obproxies | Array  | OBProxyのリスト。 |
