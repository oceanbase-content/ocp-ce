# OBProxyクラスタに接続可能なOceanBaseクラスタを追加する

## 機能の概要

OBProxyクラスタに接続可能なOceanBaseクラスタを追加します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/obproxy/clusters/{id}/obLinks/batchAdd`

### リクエストパラメータ

**path：**

| パラメータ |  型  | 必須 | サンプル値 |      説明       |
|----|------|----|-----|---------------|
| id | Long | はい  | 1   | OBProxyクラスタID。 |

**body：**

|     パラメータ      |   型    | 必須 |   サンプル値   |    説明    |
|-------------|---------|----|---------|----------|
| obLinks        | Array   | はい  | -       | 接続可能なOceanBaseクラスタ情報。   |
| ├─ clusterName | String  | はい  | foo     | クラスタ名。   |
| ├─ obClusterId | Integer | -  | 1       | OceanBase側のクラスタID。<li>OBProxyクラスタの起動方式がRsListの場合、このパラメータは必須です。</li><li>OBProxyクラスタの起動方式がConfigUrlの場合、このパラメータは不要です。</li> |
| ├─ username    | String  | はい  | proxyro | クラスタに接続するユーザー。   |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

`POST /api/v2/obproxy/clusters/1/obLinks/batchAdd`

```json
{
    "username": "proxyro",
    "obClusterId": 1,
    "clusterName": "hooray"
}
```
