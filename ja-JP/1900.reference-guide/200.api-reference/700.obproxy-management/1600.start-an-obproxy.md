# OBProxyの起動

## 機能の概要

OBProxy Serverを起動するために使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/obproxy/clusters/{id}/servers/start`

### リクエストパラメータ

**path：**

|   パラメータ     |  タイプ  | 必須 | サンプル値  |        説明         |
|------------|-------|------|---------|-------------------|
| id         | Long  | はい   | 1       | OBProxyクラスタID。     |

**body：**

|    パラメータ               |  タイプ | 必須  | サンプル値  |        説明         |
|-----------------------|-------|------|---------|-------------------|
| obproxyServerIds      | Long  | はい   | \[1,2,3\]   | 起動対象のOBProxy Server IDのリスト。     |

### 戻り値

**基本データ構造**

|     パラメータ     |    タイプ    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |

## 例

### リクエスト例

`POST /api/v2/obproxy/clusters/1/servers/start`

```json
{
  "obproxyServerIds": [
    1,
    2,
    3
  ]
}
```
