# OBProxyの引き継ぎ

## 機能説明

OBProxyをOBProxyクラスタに引き継ぐ際に使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/obproxy/clusters/{id}/takeOver`

### リクエストパラメータ

**path：**

| パラメータ |  タイプ  | 必須 | サンプル値 |      説明       |
|---------|---------|--------|---------|---------------|
| id      | Long    | はい     | 33001   | OBProxyクラスタID。 |

**body：**

|  パラメータ   |  タイプ   | 必須 | サンプル値  |         説明          |
|-------|-------|---------|----------------------|
| hosts        | Array   | はい  | -      | 引き継ぐOBProxyが配置されているホスト情報。詳細は**ObproxyTakeOverParamデータ構造**を参照してください。 |
| rpcPort      | Integer | いいえ  | 2885   | 引き継ぐOBProxyのRPCポート。OBProxyがV4.3.0以降のバージョンの場合は必須です。 |
| exporterPort | Integer | いいえ  | 2884   | 引き継ぐOBProxyのExporterポート。 |

**ObproxyTakeOverParamデータ構造**

|   パラメータ    |   タイプ    | 必須 | サンプル値  |           説明           |
|---------|---------|--------|--------|------------------------|
| hostId  | Long    | はい  | 1    | 引き継ぐOBProxyが配置されているホストID。  |
| sqlPort | Integer | はい  | 2883 | 引き継ぐOBProxyのSQLポート。 |
| proxysysPasswd  | String    | いいえ  | xxxx    | ホスト上にデプロイされたobproxyプロセスのroot@proxysysパスワード。    |

### 戻り結果

**基本データ構造**

|     パラメータ     |    タイプ    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTPステータスコード規格に準拠したエンコードです。                                            |
| traceId    | String   | 問題の調査に使用されるリクエストのTrace IDです。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                                    |

## 例

### リクエスト例

`POST /api/v2/obproxy/clusters/33001/takeOver`

```json
{
    "hosts": [{
        "hostId": 1,
        "sqlPort": 2883
    }]
}
```
