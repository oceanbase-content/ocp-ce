# OBProxyの削除（非推奨）

## 機能説明

OBProxy Serverを削除するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`DELETE /api/v2/obproxy/clusters/{id}/obproxies/{obproxyIds}`

### リクエストパラメータ

**path：**

|   パラメータ     | 型  | 必須  | サンプル値   |        説明         |
|------------|-------|-------|---------|-------------------|
| id         | Long  | はい    | 33149   | OBProxyクラスタID。     |
| obproxyIds | Long  | はい    | 1,2,3,4 | OBProxy Server ID。 |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |

## 例

### リクエスト例

`DELETE /api/v2/obproxy/clusters/33149/obproxies/2`
