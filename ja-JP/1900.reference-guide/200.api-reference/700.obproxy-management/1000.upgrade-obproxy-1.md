# OBProxyのアップグレード（非推奨）

## 機能説明

OBProxy Serverをアップグレードする際に使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/obproxy/clusters/{id}/obproxies/{obproxyIds}/upgrade`

### リクエストパラメータ

**path：**

|   パラメータ     | 型 | 必須 | サンプル値 |       説明        |
|------------|------|------|--------|-------------------|
| id         | Long | はい   | 33149  | OBProxyクラスタID。   |
| obproxyIds | Long | はい   | 1,2    | OBProxy Server ID。 |

**body：**

|    パラメータ      |   型   | 必須 |               サンプル値                   |       説明         |
|--------------|---------|------|----------------------------------------|--------------------|
| shortRpmName | String  |  はい  | obproxy-1.9.1.1-1919579                | インストールパッケージ名。            |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |                               説明                                |
|------------|----------|-----------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細は[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                         |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                    |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                 |
| status     | Integer  | HTTPステータスコード。                                           |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。                                            |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                   |

## 例

### リクエスト例

`POST /obproxy/clusters/33149/obproxies/2/upgrade`

```json
{
    "shortRpmName": "obproxy-1.9.1.1-1919579"
}
```
