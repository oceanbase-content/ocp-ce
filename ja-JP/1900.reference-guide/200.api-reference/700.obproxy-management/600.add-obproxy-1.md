# OBProxyの追加

## 機能の概要

OBProxyクラスタにOBProxyを追加するために使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/obproxy/clusters/{id}/obproxies/batchAdd`

### リクエストパラメータ

**path：**

| パラメータ |  タイプ  | 必須 | サンプル値 |      説明       |
|------|------|------|------|---------------|
| id   | Long | はい   | 33001   | OBProxyクラスタID。 |

**body：**

|    パラメータ      |   タイプ    | 必須 |                  サンプル値                   |         説明         |
|--------------|---------|-------|----------------------------------------|--------------------|
| hostIds      | Array   | はい  | \[1,2\]                                | 追加対象のOBProxyが存在するホストID。 |
| sqlPort      | Integer | はい  | 2883                                   | SQLポート。             |
| exporterPort | Integer | はい  | 2884                                   | Exproterポート。        |
| rpcPort      | Integer | いいえ  | 2885                                   | RPCポート。OBProxyがV4.3.0以降の場合は必須です。            |
| version      | String  | はい  | obproxy-1.9.1.1-1919579.el7.x86_64.rpm | ソフトウェアパッケージのバージョン。              |

### 戻り値

**基本データ構造**

|     パラメータ     |    タイプ    |                               説明                                |
|------------|----------|-----------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細は[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                         |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                    |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                 |
| status     | Integer  | HTTP Status仕様に準拠したコード。                                           |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。                                            |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                   |

## 例

### リクエスト例

`POST /api/v2/obproxy/clusters/33001/obproxies/batchAdd`

```json
{
    "hostIds": [2],
    "sqlPort": 2883,
    "exporterPort": 2884,
    "version": "obproxy-1.9.1.1-1919579.el7.x86_64.rpm"
}
```
