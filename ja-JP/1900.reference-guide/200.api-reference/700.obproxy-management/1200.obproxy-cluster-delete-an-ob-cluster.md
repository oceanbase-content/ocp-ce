# OBProxyクラスタが接続可能なOceanBaseクラスタを削除する

## 機能の概要

OBProxyクラスタと接続可能なOceanBaseクラスタの関連付けを削除します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`DELETE /api/v2/obproxy/clusters/{id}/obLinks/{obClusterName}`

### リクエストパラメータ

**path:**

|      パラメータ       |   型   | 必須 |    サンプル値    |      説明       |
|---------------|--------|----|-----------|---------------|
| id            | Long   | はい  | 1         | OBProxyクラスタID。 |
| obClusterName | String | はい  | obcluster | 接続可能なOceanBaseクラスタ名。       |

### 戻り値

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

`DELETE /api/v2/obproxy/clusters/1/obLinks/obcluster`
