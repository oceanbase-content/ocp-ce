# 概要

APIを呼び出してOceanBaseクラスタのリソースを管理し、独自のアプリケーションを開発するために、OCPはREST規格に準拠したHTTP APIを公開しています。このドキュメントでは、OCPが公開するAPIの仕様、構文、および使用例について説明します。本記事は開発者向けです。インターフェースを呼び出す前に、OCPプラットフォームの関連概念を十分に理解していることを確認してください。
