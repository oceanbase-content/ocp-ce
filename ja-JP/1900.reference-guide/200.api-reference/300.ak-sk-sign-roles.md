# AK/SK署名の生成ルール

## 概要

HTTPリクエストをOCPに送信する際、OCPはリクエストに対して署名計算を実行し、認証文字列を生成します。これにより、リクエスターの身元を識別し、伝送途中のデータのセキュリティを保護し、リプレイ攻撃を防止します。

システムは、OCPのアクセスキーを使用して署名計算を行います。このアクセスキーには、アクセスキーID（Access Key Id、略称AK）と秘密アクセスキー（Secret Access Key、略称SK）が含まれます。

## 署名の概要

1. AK/SKを取得します。

   OCP管理コンソールにアクセスし、右上の**<UI-TERM key="ocp-v2.page.Settings.Profile.PersonalSettings">個人設定</UI-TERM>**をクリックし、ページ内で**ワンクリックでAccessKeyを作成**を選択します。

2. 署名対象の文字列を作成します。

   リクエスト情報および追加情報（アルゴリズム、リクエスト時間など）に基づいて、署名対象の文字列を作成します。

3. 署名を計算します。

   署名キー（Access Key Secret）を使用して、署名対象の文字列に対して暗号化ハッシュ操作を実行し、署名を計算します。署名キーをこの操作のハッシュキーとして使用します。

4. リクエストに署名を追加します。

   署名を計算した後、それをリクエストのHTTPヘッダーに追加します。

## 手順

### ステップ１：AK/SKを取得する

1. OCPにログインします。

2. 右上のユーザー名にカーソルを合わせ、ポップアップメニューバーで**<UI-TERM key="ocp-v2.page.Settings.Profile.PersonalSettings">個人設定</UI-TERM>**をクリックします。

3. **<UI-TERM key="ocp-v2.page.Settings.Profile.PersonalSettings">個人設定</UI-TERM>**ページに移動し、**AccessKey**モジュールで**ワンクリックでAccessKeyを作成**をクリックします。詳細については、[個人情報の設定](../../1600.system-management-features/700.manage-user-center/100.configure-personal-information.md)を参照してください。

   作成が成功したら、AK/SKを適切に保管してください。

### ステップ2：署名対象の文字列を作成する

改行文字で区切られた以下の文字列を連結し、署名対象の文字列を作成します。署名対象の文字列の形式は次のとおりです：

```shell
<HttpMethod>
<Md5Payload>
<ContentType>
<RequestTime>
<Host>
<OCP-headers>
<PathAndQueryParams>
```

署名対象の文字列の計算式は次のとおりです：

```java
toSignString = HttpMethod + "\n" + Md5Payload + "\n" + ContentType + "\n" + RequestDate + "\n" + Host + "\n" + OCP-Headers + "\n" + PathAndQueryParams
```

この式から、署名対象の文字列は**HttpMethod**、**Md5Payload**、**ContentType**、**RequestDateTime**、**Host**、**OCP-Headers**、**PathAndQueryParams**の7つのパラメータで構成されていることがわかります。それぞれの具体的な意味と計算方法は以下のとおりです：

* **HttpMethod**：HTTPリクエストメソッド。例：GET、POST、PUT、DELETEなど。
* **Md5Payload**：リクエストペイロードのmd5暗号化後の情報。リクエストに有効なペイロード情報が含まれない場合は、空文字（""）を渡します。有効なペイロードが含まれる場合は、md5化したペイロード情報(`md5(<payload>)`)を渡します。

* **ContentType**：リクエストタイプ。headers情報のcontent-typeの内容です。OCPにとって、ほとんどのリクエストタイプは`application/json`です。

* **RequestDateTime**：リクエストの日時です。この情報はリクエストヘッダーからDateまたはx-ocp-dateの内容を読み取ります。日時の形式はRFC-1123に準拠しており、例えば`Fri, 12 Apr 2024 07:15:32 GMT`のようになります。

* **Host**：リクエストのドメイン名です。`IP+Port`の場合は、IP:Portを指定します。例：`xxx.xxx.xxx.xxx:8080`。

* **OCP-Headers**：リクエストヘッダーのうち、`x-ocp-`で始まるヘッダーです。署名アルゴリズムでは、この種のヘッダーが計算に含まれます。複数のヘッダー情報はアルファベット順に並べ替えられ、改行文字で区切られます。

  ```java
  HeaderName1+":"+<value>+"\n"
  HeaderName2+":"+<value>+"\n"
  ...
  HeaderNameN+":"+<value>+"\n"
  ```

* **PathAndQueryParams**：リクエストパスとリクエストパラメータの組み合わせです。複数のパラメータは辞書順に並べ替えられます。例：`?a=1&b=2`。具体的な連結アルゴリズムは以下の通りです。

  ```java
  path?urlEncode(<param1>)+"="+URLEncode(<value>)+"&"+urlEncode(<param2>)+"="+URLEncode(<value>)+...+"&"+urlEncode(<paramN>)+"="+URLEncode(<value>)
  ```

#### 例

curlリクエストの例は以下の通りです：


* Md5PayLoad：空
* ContentType: `application/json`
* RequestDateTime：仮に`Mon, 15 Apr 2024 09:25:02 GMT`とします。
* Host：`xxx.xxx.xxx.xxx:8080`
* OCP-headers：`x-ocp-origin:for-test`
* PathAndQueryParams：
  * Path：`/api/v2/monitor/top`
  * QueryParams：`metrics=host_disk_total&labels=svr_ip:xxx.xxx.xxx.xxx&groupBy=app,svr_ip,device,mount_point&startTime=2024-04-15T14:29:55+08:00&endTime=2024-04-15T14:30:55+08:00&maxPoints=360`

### ステップ3：署名の計算

署名アルゴリズムは以下の通りです：

```java
//HMACSHA1
BASE64(HMAC-SHA1(<AccessKey Secret>, string-to-sign.getBytes("UTF-8")))

//HMACSHA256
BASE64(HMAC-SHA256(<AccessKey Secret>, string-to-sign.getBytes("UTF-8")))
```

### ステップ4：署名をリクエストに追加する

OCP APIを呼び出す際は、以下のルールに従う必要があります：

HTTPリクエストをOCPに送信する際は、HTTPヘッダーにAuthorizationフィールドとDateフィールドを含める必要があります。これにより、OCP-Serverがリクエストを認証できます。

* **Authorization**：リクエストの認証情報で、プレフィックス、署名アルゴリズム、AK、署名情報が含まれます。形式例は `OCP-ACCESS-KEY-HMACSHA1 {AK}:{Signature}` です。

  * **プレフィックス**：現在固定で `OCP-ACCESS-KEY-` です。

  * **署名アルゴリズム**：現在 `HMACSHA1` と `HMACSHA256` をサポートしています。ここでの `HMACSHA1/HMACSHA256` は大文字表記である点に注意してください。

  * **AK**：キーIDです。署名アルゴリズムとAKの間にはスペースがあることに注意してください。

  * **Signature**：計算された署名です。具体的な計算ルールについては、**手順3：署名の計算**を参照してください。

* **Date**：リクエストの送信時刻です。現在のリクエストが妥当な時間範囲内（サーバーがリクエストを受信してからの偏差が15分を超えないこと）に送信されたかどうかを検証するために使用されます。時間形式はRFC-1123形式に従い、例えば `Tue, 17 Jan 2023 03:36:01 GMT` のようになります。

OCP-Serverは、お客様からのリクエストを受信すると、署名情報およびリクエスト情報を解析し、検証を行います。検証に合格した場合はリクエストの処理を続けますが、不合格の場合はエラーを返します。

```java

curl -H "Authorization: OCP-ACCESS-KEY-HMACSHA256 <AK>:<signed-string>" -H "Date:Fri, 12 Apr 2024 07:15:32 GMT"  -H "x-ocp-origin:for-test" -H "Content-Type:application/json" -X GET "xxx.xxx.xxx.xxx:8080/api/v2/monitor/top?metrics=host_disk_total&labels=svr_ip:xxx.xxx.xxx.xxx&groupBy=app,svr_ip,device,mount_point&startTime=2024-04-15T14:29:55+08:00&endTime=2024-04-15T14:30:55+08:00&maxPoints=360"
```

## Java署名サンプルコード

```Java
package com.oceanbase.ocp.demo;

import org.junit.Assert;

import javax.crypto.Mac;
import javax.crypto.spec.SecretKeySpec;
import java.math.BigInteger;
import java.net.URLEncoder;
import java.nio.charset.StandardCharsets;
import java.security.InvalidKeyException;
import java.security.MessageDigest;
import java.security.NoSuchAlgorithmException;
import java.time.Instant;
import java.time.ZoneOffset;
import java.time.format.DateTimeFormatter;
import java.util.ArrayList;
import java.util.Base64;
import java.util.HashMap;
import java.util.List;
import java.util.Map;
import java.util.StringJoiner;
import java.util.stream.Collectors;

public class OcpSignDemo {

    public static void main(String[] args) throws Exception {
        Map<String, String> params = new HashMap<>();
        params.put("startTime", "2024-04-15T14:29:55+08:00");
        params.put("endTime", "2024-04-15T14:30:55+08:00");
        params.put("maxPoints", "360");
        params.put("metrics", "host_disk_total");
        params.put("labels", "svr_ip:xx.xx.xx.xx");
        params.put("groupBy", "app,svr_ip,device,mount_point");

        String path = "/api/v2/monitor/top";

        Map<String, String> headers = new HashMap<>();
        headers.put("x-ocp-origin", "for-test");
        headers.put("Content-Type", "application/json");

        String accessKeyId = "gDCcIqbkJJINjXBn";
        String accessKeySecret = "d75332c5eed8d440a84a35ac6248d397";
        String rfcDate = "Mon, 15 Apr 2024 09:25:02 GMT";

        String sign = getSign("xx.xx.xx.xx:8080", path, "GET", headers, params, null, accessKeySecret, rfcDate);

        Assert.assertEquals("To11kg1EsB/dPWyDnnpuUzIUoQk=", sign);
        // headers need add to request.
        System.out.println("Request Headers:");
        System.out.println("Authorization: OCP-ACCESS-KEY-HMACSHA1" + accessKeyId + ":" + sign);
        System.out.println("Date:" + rfcDate);

        // HmacSHA256の例
        System.out.println("\n--- HmacSHA256 Demo ---");
        String signSha256 = getSignSha256("xx.xx.xx.xx:8080", path, "GET", headers, params, null, accessKeySecret, rfcDate);
        System.out.println("Authorization: OCP-ACCESS-KEY-HMACSHA256" + accessKeyId + ":" + signSha256);
    }

    public static String getSign(String host, String path, String method, Map<String, String> headers, Map<String,
            String> params, byte[] body, String accessKeySecret) throws Exception {
        return getSign(host, path, method, headers, params, body, accessKeySecret, getRfcDate());
    }

    public static String getSign(String host, String path, String method, Map<String, String> headers, Map<String,
            String> params, byte[] body, String accessKeySecret, String rfcDate) throws Exception {
        StringJoiner strToSign = new StringJoiner("\n");
        // HTTPメソッドを追加します。
        strToSign.add(method);
        // ペイロードを追加します。
        if (body == null) {
            strToSign.add("");
        } else {
            strToSign.add(md5(body));
        }

        // Content-typeを追加します。
        if (headers == null || !headers.containsKey("Content-Type")) {
            strToSign.add("");
        } else {
            strToSign.add(headers.get("Content-Type"));
        }

        // リクエスト時間を追加します。
        strToSign.add(rfcDate);

        // ホストを追加します。
        strToSign.add(host);

        // ocp-headersを追加します。
        if (headers == null || headers.keySet().stream().noneMatch(s -> s.startsWith("x-ocp-"))) {
            strToSign.add("");
        } else {
            String ocpHeadersStr = headers.entrySet().stream()
                    .filter(e -> e.getKey().toLowerCase().startsWith("x-ocp"))
                    .sorted(Map.Entry.comparingByKey())
                    .map(e -> String.format("%s:%s", e.getKey(), String.join(",", e.getValue']))
                    .collect(Collectors.joining("\n"));
            strToSign.add(ocpHeadersStr);
        }

        // Append path and params
        if (params == null || params.isEmpty()) {
            strToSign.add(path);
        } else {
            List<Map.Entry<String, String>> toSort = new ArrayList<>(params.entrySet());
            toSort.sort(Map.Entry.comparingByKey());
            StringJoiner joiner = new StringJoiner("&");
            for (Map.Entry<String, String> e : toSort) {
                String enc = StandardCharsets.UTF_8.displayName();
                String format = String.format("%s=%s", URLEncoder.encode(e.getKey(), enc),
                        URLEncoder.encode(e.getValue(), enc));
                joiner.add(format);
            }
            String paramsStr = joiner.toString();
            strToSign.add(path + "?" + paramsStr);
        }
        return Base64.getEncoder().encodeToString(hmacSha1(accessKeySecret,
                strToSign.toString().getBytes(StandardCharsets.UTF_8)));
    }

    private static String getRfcDate() {
        return Instant.now().atOffset(ZoneOffset.UTC).format(DateTimeFormatter.RFC_1123_DATE_TIME);
    }

    private static String md5(byte[] bs) throws Exception {
        MessageDigest digest = MessageDigest.getInstance("MD5");
        digest.update(bs);
        String hex = new BigInteger(1, digest.digest()).toString(16).toUpperCase();
        return new String(new char[32 - hex.length()]).replace("\0", "0") + hex;
    }

    private static byte[] hmacSha1(String accessKeySecret, byte[] content) {
        try {
            Mac mac = Mac.getInstance("HmacSHA1");
            mac.init(new SecretKeySpec(accessKeySecret.getBytes(StandardCharsets.UTF_8), "HmacSHA1"));
            return mac.doFinal(content);
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException("Not supported signature method HmacSHA1", e);
        } catch (InvalidKeyException e) {
            throw new RuntimeException("Failed to calculate the signature", e);
        }
    }

    public static String getSignSha256(String host, String path, String method, Map<String, String> headers, Map<String,
            String> params, byte[] body, String accessKeySecret) throws Exception {
        return getSignSha256(host, path, method, headers, params, body, accessKeySecret, getRfcDate());
    }

    public static String getSignSha256(String host, String path, String method, Map<String, String> headers, Map<String,
            String> params, byte[] body, String accessKeySecret, String rfcDate) throws Exception {
        StringJoiner strToSign = new StringJoiner("\n");
        // Append method.
        strToSign.add(method);
        // Append payload.
        if (body == null) {
            strToSign.add("");
        } else {
            strToSign.add(sha256Hex(body));
        }

        // Append Content-type.
        if (headers == null || !headers.containsKey("Content-Type")) {
            strToSign.add("");
        } else {
            strToSign.add(headers.get("Content-Type"));
        }

        // Append request-time.
        strToSign.add(rfcDate);

        // Append host.
        strToSign.add(host);

        // Append ocp-headers.
        if (headers == null || headers.keySet().stream().noneMatch(s -> s.startsWith("x-ocp-"))) {
            strToSign.add("");
        } else {
            String ocpHeadersStr = headers.entrySet().stream()
                    .filter(e -> e.getKey().toLowerCase().startsWith("x-ocp"))
                    .sorted(Map.Entry.comparingByKey())
                    .map(e -> String.format("%s:%s", e.getKey(), String.join(",", e.getValue())))
                    .collect(Collectors.joining("\n"));
            strToSign.add(ocpHeadersStr);
        }

        // Append path and params
        if (params == null || params.isEmpty()) {
            strToSign.add(path);
        } else {
            List<Map.Entry<String, String>> toSort = new ArrayList<>(params.entrySet());
            toSort.sort(Map.Entry.comparingByKey());
            StringJoiner joiner = new StringJoiner("&");
            for (Map.Entry<String, String> e : toSort) {
                String enc = StandardCharsets.UTF_8.displayName();
                String format = String.format("%s=%s", URLEncoder.encode(e.getKey(), enc),
                        URLEncoder.encode(e.getValue(), enc));
                joiner.add(format);
            }
            String paramsStr = joiner.toString();
            strToSign.add(path + "?" + paramsStr);
        }
        return Base64.getEncoder().encodeToString(hmacSha256(accessKeySecret,
                strToSign.toString().getBytes(StandardCharsets.UTF_8)));
    }

    private static byte[] hmacSha256(String accessKeySecret, byte[] content) {
        try {
            Mac mac = Mac.getInstance("HmacSHA256");
            mac.init(new SecretKeySpec(accessKeySecret.getBytes(StandardCharsets.UTF_8), "HmacSHA256"));
            return mac.doFinal(content);
        } catch (NoSuchAlgorithmException e) {
            throw new RuntimeException("Not supported signature method HmacSHA256", e);
        } catch (InvalidKeyException e) {
            throw new RuntimeException("Failed to calculate the signature", e);
        }
    }

    private static String sha256Hex(byte[] bs) throws Exception {
        MessageDigest digest = MessageDigest.getInstance("SHA-256");
        digest.update(bs);
        String hex = new BigInteger(1, digest.digest()).toString(16).toUpperCase();
        return new String(new char[64 - hex.length()]).replace("\0", "0") + hex;
    }
```
