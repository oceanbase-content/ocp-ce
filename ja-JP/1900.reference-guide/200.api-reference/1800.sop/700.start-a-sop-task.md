# SOPタスクの開始

## 機能の概要

一意の実行インスタンスとすべての有効なステップを作成し、最初のステップを開始します。最初のステップが自動的に実行される場合、返されるステータスはその場での処理結果に依存します。最初のステップを手動で実行する必要がある場合、`WAITING_CONFIRM` を返します。

## 呼び出しの説明

### インターフェース制約

このタスクに対する `SOP_TASK:UPDATE` 権限と、ターゲットリソースに対する `UPDATE` 権限が必要です。1つのタスクは1回しか開始できません。

### リクエストパス

`POST /api/v2/sop/tasks/{id}/start`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| id | Path | Long | はい | タスクID。 |

### 実行結果

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は `true` です。 |
| data.id | Long | 新規実行インスタンスID。 |
| data.sopTaskId | Long | 所属タスクID。 |
| data.status | String | 実行状態：`WAITING_CONFIRM`、`RUNNING`、`FAILED` または `COMPLETED`。 |
| data.displayStatus | String | 表示状態。現在は `data.status` と同じです。 |
| data.currentStepIndex | Integer | まだ成功していないステップのうち、最初のステップ番号。全て成功した後は最後のステップ番号が保持されます。 |
| data.totalSteps | Integer | 有効なステップの総数。 |
| data.readyManualStepIndexes | Array&lt;Integer&gt; | 現在準備が整い、手動で進めることができ、かつ `autoRun=false` のステップ番号。 |
| data.executor | String | 実行を開始するユーザー名。 |
| data.startTime | Datetime | 実行開始時間。 |
| data.finishTime | Datetime \| null | 実行終了または失敗時間。終了していない場合は `null`。 |
| data.steps[] | Array | 全ステップの実行情報。 |
| data.steps[].stepIndex | Integer | ステップ番号。 |
| data.steps[].stepKey | String | ステップの一意の識別子。 |
| data.steps[].stepName | String | ステップの表示名。 |
| data.steps[].status | String | `PENDING`、`RUNNING`、`SUCCESSFUL` または `FAILED`。 |
| data.steps[].autoRun | Boolean | 現在の自動実行スイッチ。 |
| data.steps[].stepParam | Object \| null | 保存済みのステップパラメータ。設定されていない場合は `null`。 |
| data.steps[].taskInstanceIds | Array&lt;Long&gt; | 関連するOCPタスクインスタンスID。なしの場合は空配列。 |
| data.steps[].retryCount | Integer | リトライ回数。 |
| data.steps[].errorMessage | String \| null | 最近の失敗情報。最大1024文字を保持します。 |
| data.steps[].startTime | Datetime \| null | ステップ開始時刻。 |
| data.steps[].finishTime | Datetime \| null | ステップ終了時刻。 |
| timestamp | Datetime | サーバーがレスポンスを作成した時間。 |
| duration | Long | サーバー処理時間。単位はミリ秒です。 |
| status | Integer | HTTPステータスコード。成功時は`200`です。 |
| traceId | String | リクエストのトレースIDで、ログの調査に使用されます。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 404 | `SOP10008` | タスクが存在しません。 |
| 400 | `SOP10009` | タスクは既に開始されています。同時に開始がリクエストされた場合は、1つのリクエストのみが成功します。 |
| 400 | `SOP10002`およびシナリオエラーコード | 対象オブジェクト、トポロジ、または実行状態の再検証に失敗しました。 |
