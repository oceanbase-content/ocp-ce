# 次のステップを実行する

## 機能説明

現在準備が整い、かつ `autoRun=false` の手動ステップを進めます。進められるステップが複数ある場合は、`stepIndex` を指定する必要があります。

## 呼び出し説明

### インターフェース制約

このタスクに対する `SOP_TASK:UPDATE` 権限と、ターゲットリソースに対する `UPDATE` 権限が必要です。実行状態は `WAITING_CONFIRM` または `RUNNING` でなければならず、明示的に確認されている必要があります。

### リクエストパス

`POST /api/v2/sop/tasks/{taskId}/execution/next`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- | --- |
| taskId | Path | Long | はい | `1001` | タスクID。 |
| stepIndex | Body | Integer | いいえ | `5` | 前進させる準備が整った手動ステップの番号。複数の準備が整ったステップがある場合は必須です。 |
| confirmed | Body | Boolean | はい | `true` | `true` を指定する必要があります。指定しない場合、`null`、または `false` の場合は、進めることができません。 |

### 実行結果

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は `true` です。 |
| data.id | Long | 実行インスタンスID。 |
| data.sopTaskId | Long | 所属SOPタスクID。 |
| data.status | String | 実行状態。値は `WAITING_CONFIRM`、`RUNNING`、`FAILED`、または `COMPLETED` です。 |
| data.displayStatus | String | 表示に使用される実行状態。現在は `data.status` と同じです。 |
| data.currentStepIndex | Integer | 現在最も早く成功していないステップの番号。 |
| data.totalSteps | Integer | 今回実行されたステップの総数。 |
| dataREADYManualStepIndexes | Array lt;Integer gt; | 更新後に手動で進めることができるステップの番号。 |
| data.executor | String | 実行を開始したユーザー名。 |
| data startTime | Datetime | 実行開始時間。 |
| data.finishTime | Datetime \| null | 実行終了または失敗時間。終了していない場合は `null` です。 |
| data.steps[] | Array | 全ステップの実行情報。各項目は `stepIndex`、`stepKey`、`stepName`、`status`、`autoRun`、`stepParam`、`taskInstanceIds`、`retryCount`、`errorMessage`、`startTime`、`finishTime` です。それぞれの意味は、ステップの特定・表示、状態、自動実行スイッチ、ステップパラメータ、関連OCPタスク、リトライ回数、失敗情報、ステップ時間です。 |
| timestamp | Datetime | サーバーが応答を作成した時間。 |
| duration | Long | サーバー処理時間。単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功した場合は `200` です。 |
| traceId | String | ログ調査に使用されるリクエストパスID。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 404 | `SOP10008` | タスクが存在しません。 |
| 400 | `SOP10014` | タスクが開始されていない、または実行状態が `WAITING_CONFIRM`/`RUNNING` ではありません。 |
| 400 | `SOP10020` | `confirmed` が `true` ではありません。 |
| 400 | `SOP10013` | 実行可能なステップが複数存在するにもかかわらず、`stepIndex` が指定されていません。 |
| 404 | `SOP10015` | 指定したステップが存在しません。 |
| 400 | `SOP10016` | 指定したステップが準備中でない、または手動ステップではない、あるいは現在進める手動ステップがない場合。 |
| 400 | `SOP10021` | ステップの前提条件検証または配分に失敗しました。 |
