# SOPタスクの詳細を照会する

## 機能説明

タスクの定義、ターゲットパラメータ、手順設定、派生状態を照会します。リアルタイムの手順実行情報については、「SOP実行の詳細を照会する」を呼び出してください。

## 呼び出し説明

### インターフェース制約

タスクに対する `SOP_TASK:READ` 権限が必要です。

### リクエストパス

`GET /api/v2/sop/tasks/{id}`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- | --- |
| id | Path | Long | はい | `1001` | タスクID。 |

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は `true`。 |
| data.id | Long | タスクID。 |
| data.name | String | タスク名。 |
| data.sopType | String | SOPタイプコード。 |
| data.sopTypeDisplayName | String | 現在のlocaleにおけるSOPタイプの表示名。 |
| data.targetParam | Object | タスクレベルのターゲットパラメータおよびサーバー側で解析された補足フィールド。スタンバイテナントの再構築では、`standbyClusterId`、`standbyTenantId`、`logTransportMode` がコアフィールドとなります。アービトレーションタイプでは `clusterId` とアービトレーションサービス/サービスグループのいずれかを選択します。OBServer の再構築では `clusterId` とオプションの `replacementHostId` が含まれます。 |
| data.operationObjects | Object | 解析された表示オブジェクト。スタンバイテナントの再構築には、元の/新しいスタンバイテナント、元の/新しいスタンバイクラスタ、プライマリテナント、プライマリクラスタ、各種ID、ログ転送方式、バックアップ設定が含まれる可能性があります。アービトレーションタイプには、影響を受けるテナント、障害IP、アービトレーションサービス/サービスグループ、サービス接続情報が含まれる可能性があります。OBServer の再構築には、影響を受けるテナント、障害IP、ゾーン、代替ホストID/IPが含まれる可能性があります。存在しないフィールドは返されません。 |
| data.targetSummary.displayText | String | ターゲットの要約テキスト。 |
| data.targetSummary.kind | String | ターゲットのカテゴリ。 |
| data.targetSummary.details[] | Array | 要約の詳細。各項目には `label`（名前）と `value`（値）が含まれます。 |
| data.steps[] | Array | 現在のタスク手順設定。 |
| data.steps[].stepIndex | Integer | 手順番号。 |
| data.steps[].stepKey | String | 手順の一意の識別子。 |
| data.steps[].stepName | String | 手順の表示名。 |
| data.steps[].stepKind | String | `EXECUTABLE` または `CONFIRMATION`。 |
| data.steps[].stepDescription | String \| null | 手順の説明。 |
| data.steps[].autoRun | Boolean | 自動実行の有無。 |
| data.steps[].enabled | Boolean \| null | 有効かどうか。`null` は常に有効を意味します。 |
| data.steps[].blockNext | Boolean | 失敗した場合、後続の自動進行をブロックするかどうか。 |
| data.steps[].editable | Boolean | 自動実行スイッチの調整を許可するかどうか。 |
| data.steps[].userMovable | Boolean | ステップの順序を調整できるかどうか。 |
| data.steps[].minStepIndex | Integer \| null | 移動可能なステップの最小インデックス。 |
| data.steps[].maxStepIndex | Integer \| null | 移動可能なステップの最大インデックス。 |
| data.comments | String \| null | 備考。 |
| data.creator | String | 作成者ユーザー名。 |
| data.createTime | Datetime | タスクの作成時間。 |
| data.updateTime | Datetime | タスクの最終更新時間。 |
| data.displayStatus | String | `NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED`または`COMPLETED`。 |
| data.currentExecutionId | Long \| null | 現在の実行インスタンスID。開始前は`null`。 |
| timestamp | Datetime | サーバー側が応答を作成した時間。 |
| duration | Long | サーバー側の処理時間、単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功時は`200`。 |
| traceId | String | ログ調査に使用されるリクエストのトレースID。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 404 | `SOP10008` (`SOP_TASK_NOT_FOUND`) | タスクが存在しません。 |
