# 指定されたタイプのデフォルトステップを照会する

## 機能説明

指定されたSOPタイプのデフォルトステップテンプレートを照会します。タスクの作成または編集時に、このテンプレートに基づいて `steps` 配列を構築する必要があります。

## 呼び出し説明

### インターフェース制約

`SOP_TASK:READ` 権限が必要です。

### リクエストパス

`GET /api/v2/sop/types/{type}/steps`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- | --- |
| type | Path | String | はい | `OBSERVER_DATA_REBUILD` | SOPタイプコード。有効な値は以下のみ：`REBUILD_STANDBY_TENANT`（スタンバイテナントの再構築）、`ARBITRATION_FOR_FAULTY_REPLICA`（レプリカ異常時のアービトレーションサービス開始）、`OBSERVER_DATA_REBUILD`（OBServer異常後のデータ再構築）。 |

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は `true`。 |
| data.contents | Array | `stepIndex` の昇順で並べたデフォルトステップ。 |
| data.contents[].stepIndex | Integer | デフォルトステップの番号。1から始まる。 |
| data.contents[].stepKey | String | ステップの一意の識別子。タスクの作成・編集時には、テンプレート内の値を使用する必要があります。 |
| data.contents[].stepName | String | 現在のロケールにおけるステップの表示名。 |
| data.contents[].stepKind | String | `EXECUTABLE`：実行系ステップ。OCPタスクインスタンスを作成する可能性があります。`CONFIRMATION`：確認系ステップ。「次へ進む」を押すことで進行を確認します。 |
| data.contents[].stepDescription | String \| null | 現在のロケールにおけるステップの説明。説明がない場合は `null` です。 |
| data.contents[].autoRun | Boolean | デフォルトで自動実行するかどうか。`false` は手動での進行待ちを意味します。 |
| data.contents[].enabled | Boolean \| null | デフォルトで有効かどうか。`null` は固定で有効であり、無効化できないことを意味します。`true/false` は設定可能であることを意味します。 |
| data.contents[].blockNext | Boolean | ステップが失敗した場合、後続の自動進行をブロックするかどうか。 |
| data.contents[].editable | Boolean | このステップの `autoRun` を変更できるかどうか。 |
| data.contents[].userMovable | Boolean | タスクの作成・編集時にステップの位置を移動できるかどうか。 |
| data.contents[].minStepIndex | Integer \| null | 移動可能な場合の許容最小ステップ番号（含む）。そうでない場合は `null`。 |
| data.contents[].maxStepIndex | Integer \| null | 移動可能な場合の許容最大ステップ番号（含む）。そうでない場合は `null`。 |
| timestamp | Datetime | サーバー側が応答を作成した時間。 |
| duration | Long | サーバー処理時間。単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功した場合は `200`。 |
| traceId | String | リクエストのトレースID。ログの調査に使用されます。 |

### ステップキーの値

`data.contents[].stepKey` は任意の文字列を受け付けません。各 `type` の完全なステップキーは以下のとおりです。タスクの作成時および編集時には、ステップ配列には対応するタイプのキーのみを使用できます。

| `type` | `stepKey` の完全な値（デフォルトのステップ順序） |
| --- | --- |
| `REBUILD_STANDBY_TENANT` | `CONFIRM_STANDBY_TENANT_INFO`、`BACKUP_PRIMARY_TENANT`、`DISCONNECT_STANDBY_TENANT`、`LOCK_STANDBY_TENANT`、`DELETE_STANDBY_TENANT`、`CREATE_STANDBY_TENANT`、`VERIFY_PRIMARY_STANDBY_SYNC` |
| `ARBITRATION_FOR_FAULTY_REPLICA` | `CONFIRM_ARBITRATION_TARGET`、`ADD_ARBITRATION_SERVICE`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`ENABLE_TENANT_ARBITRATION`、`VERIFY_TENANT_ARBITRATION` |
| `OBSERVER_DATA_REBUILD` | `CONFIRM_OBSERVER_TARGET`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`FORCE_DELETE_HOST`、`ADD_OBSERVER`、`ADD_TENANT_REPLICA`、`VERIFY_REPLICA_REBUILD` |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 400 | `SOP10006` (`SOP_TYPE_UNSUPPORTED`) | `type` は現在サポートされている SOP タイプに属しません。 |
