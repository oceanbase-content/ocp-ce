# SOPタスクの作成

## 機能の概要

SOPタスク定義を作成します。`startNow=true` の場合、タスクを保存するとすぐに実行インスタンスを作成して起動します。それ以外の場合、タスクの状態は `NOT_STARTED` になります。

## 呼び出しの説明

### インターフェース制約

`SOP_TASK:UPDATE`権限と、対象のクラスタ、テナント、アービトレーションサービス/サービスグループ、またはホストに対する`UPDATE`権限が必要です。

### リクエストパス

`POST /api/v2/sop/tasks`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- | --- |
| name | Body | String | はい | `rebuild-standby-tenant-1` | グローバルで一意のタスク名。長さは2～32文字。最初の文字は漢字、英字、ひらがな、またはカタカナである必要があります。最後の文字は漢字、英字、数字、ひらがな、またはカタカナである必要があります。中間にはアンダースコアを含めることができます。 |
| sopType | Body | String | はい | `REBUILD_STANDBY_TENANT` | SOPタイプコード。有効な値は以下のみです：`REBUILD_STANDBY_TENANT`、`ARBITRATION_FOR_FAULTY_REPLICA`、`OBSERVER_DATA_REBUILD`。 |
| targetParam | Body | Object | はい | 下表参照 | タスクレベルのターゲットパラメータ。フィールドは`sopType`によって決定されます。 |
| steps | Body | Array | はい | サンプル参照 | ステップ設定配列。空でない配列を指定する必要があります。`stepKey`はテンプレートに属している必要があり、重複してはなりません。固定で有効なステップは必ず指定する必要があります。少なくとも1つの有効なステップを残す必要があります。 |
| steps[].stepIndex | Body | Integer | いいえ | `1` | ステップ番号。指定しない場合は、テンプレートのデフォルト値が使用されます。最終的には連続しており、重複してはなりません(`1..N`)。`userMovable=true`のステップのみが、テンプレートの範囲内で移動できます。 |
| steps[].stepKey | Body | String | はい | `CONFIRM_STANDBY_TENANT_INFO` | テンプレートが返すステップ識別子。 |
| steps[].autoRun | Body | Boolean | いいえ | `true` | 自動実行するかどうか。指定しない場合は、テンプレートのデフォルト値が使用されます。編集できないステップはデフォルト値を変更できません。 |
| steps[].enabled | Body | Boolean | いいえ | `true` | そのステップを有効にするかどうか。テンプレートで無効化が許可されているステップのみを無効化できます。 |
| comments | Body | String | いいえ | `月次演習` | タスクの備考です。現在、サーバー側では長さの制限は定義されていません。 |
| startNow | Body | Boolean | いいえ | `false` | `true`の場合のみ、即時に開始します。指定しない場合や`false`の場合は開始しません。 |

`targetParam`フィールドは`sopType`によって異なります：

| SOPタイプ | パラメータ | 型 | 必須 | 制約と意味 |
| --- | --- | --- | --- | --- |
| `REBUILD_STANDBY_TENANT` | `standbyClusterId` | Long | はい | 再構築対象のスタンバイテナントが属するクラスタID。正の数値である必要があります。 |
| | `standbyTenantId` | Long | はい | 再構築対象のスタンバイテナントID。正の数値である必要があります。 |
| | `logTransportMode` | String | はい | ログ転送方式。`NETWORK`または`LOG_BACKUP`のみ指定可能です。 |
| | `standbyClusterName`、`standbyTenantName` | String | いいえ | 表示用の名前です。サーバー側で補足される場合があります。 |
| `ARBITRATION_FOR_FAULTY_REPLICA` | `clusterId` | Long | はい | クラスタID。数値である必要があります。 |
| | `arbitrationServiceId` | Long | 条件必須 | アービトレーションサービスID。`arbitrationGroupId`とどちらか一方を選択し、どちらか一方のみ指定可能です。 |
| | `arbitrationGroupId` | Long | 条件必須 | アービトレーションサービスグループID。`arbitrationServiceId`とどちらか一方を選択し、どちらか一方のみ指定可能です。 |
| | `clusterName` | String | いいえ | 表示用のクラスタ名です。 |
| `OBSERVER_DATA_REBUILD` | `clusterId` | Long | はい | クラスタID。数値である必要があります。 |
| | `replacementHostId` | Long | いいえ | 事前に選択した代替ホストID。指定する場合は正の数値である必要があります。指定しない場合は、`ADD_OBSERVER`ステップの前に設定できます。 |
| | `clusterName` | String | いいえ | 表示用のクラスタ名です。 |

`steps[].stepKey`の指定可能な値は、完全に`sopType`によって決定されます：

| `sopType` | `steps[].stepKey`の指定可能な値 |
| --- | --- |
| `REBUILD_STANDBY_TENANT` | `CONFIRM_STANDBY_TENANT_INFO`、`BACKUP_PRIMARY_TENANT`、`DISCONNECT_STANDBY_TENANT`、`LOCK_STANDBY_TENANT`、`DELETE_STANDBY_TENANT`、`CREATE_STANDBY_TENANT`、`VERIFY_PRIMARY_STANDBY_SYNC` |
| `ARBITRATION_FOR_FAULTY_REPLICA` | `CONFIRM_ARBITRATION_TARGET`、`ADD_ARBITRATION_SERVICE`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`ENABLE_TENANT_ARBITRATION`、`VERIFY_TENANT_ARBITRATION` |
| `OBSERVER_DATA_REBUILD` | `CONFIRM_OBSERVER_TARGET`、`DELETE_TENANT_REPLICA`、`DELETE_OBSERVER`、`FORCE_DELETE_HOST`、`ADD_OBSERVER`、`ADD_TENANT_REPLICA`、`VERIFY_REPLICA_REBUILD` |

### 実行結果

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功時は `true`。 |
| data.id | Long | 新規タスクID。 |
| data.name | String | 保存されたタスク名。 |
| data.sopType | String | SOPタイプコード。 |
| data.sopTypeDisplayName | String | 現在のロケールにおけるSOPタイプの表示名。 |
| data.targetParam | Object | 保存されたタスクレベルのターゲットパラメータ。サーバー側で解析された名前、関連オブジェクト、またはスナップショットフィールドを含むことができます。 |
| data.operationObjects | Object | 解析された表示オブジェクト。現在存在するフィールドのみが返されます。再構築されるスタンバイテナントには `oldStandbyTenant`、`oldStandbyCluster`、`primaryTenant`、`primaryTenantId`、`primaryCluster`、`primaryClusterId`、`primaryOcpClusterId`、`logTransportMode`、`backupConfig`、`newStandbyTenantId`、`newStandbyClusterId`、`newStandbyTenant`、`newStandbyCluster` が含まれる可能性があります。アービトレーションタイプには `tenantNames`、`faultyObserverIp`、`arbitrationServiceId`、`arbitrationGroupId`、`resolvedArbitrationServiceId`、`arbitrationServiceIp`、`arbitrationServicePort`、`arbitrationServiceGroupName` が含まれる可能性があります。OBServerの再構築には `tenantNames`、`faultyObserverIp`、`zoneName`、`replacementHostId`、`replacementHostIp` が含まれる可能性があります。 |
| data.targetSummary.displayText | String | 直接表示可能なターゲットの概要。 |
| data.targetSummary.kind | String | ターゲットのカテゴリ。現在は `TENANT` または `CLUSTER` です。 |
| data.targetSummary.details[] | Array | 概要の詳細。各項目は `label`（名前）と `value`（値）を含みます。 |
| data.steps[] | Array | 保存された手順の設定。 |
| data.steps[].stepIndex | Integer | 手順番号。 |
| data.steps[].stepKey | String | 手順の一意の識別子。 |
| data.steps[].stepName | String | 現在のロケールにおける手順の表示名。 |
| data.steps[].stepKind | String | `EXECUTABLE` または `CONFIRMATION`。 |
| data.steps[].stepDescription | String \| null | 手順の説明。 |
| data.steps[].autoRun | Boolean | 自動実行の有無。 |
| data.steps[].enabled | Boolean \| null | 有効かどうか。`null` は常に有効を意味します。 |
| data.steps[].blockNext | Boolean | 失敗した場合、後続の自動進行をブロックするかどうか。 |
| data.steps[].editable | Boolean | 自動実行スイッチの変更を許可するかどうか。 |
| data.steps[].userMovable | Boolean | 手順の順序を調整することを許可するかどうか。 |
| data.steps[].minStepIndex | Integer \| null | 移動可能な手順の許容最小番号。 |
| data.steps[].maxStepIndex | Integer \| null | 移動可能な手順の許容最大番号。 |
| data.comments | String \| null | 保存されたコメント。 |
| data.creator | String | 作成者のOCPユーザー名。 |
| data.createTime | Datetime | タスクの作成時間。 |
| data.updateTime | Datetime | タスクの最終更新時間。 |
| data.displayStatus | String | `NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED` または `COMPLETED`。即座に起動しない場合は `NOT_STARTED` です。 |
| data.currentExecutionId | Long \| null | 現在の実行インスタンスID。起動していない場合は `null` です。 |
| timestamp | Datetime | サーバー側が応答を作成した時間。 |
| duration | Long | サーバー側の処理時間。単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功時は `200` です。 |
| traceId | String | ログ調査に使用されるリクエストのトレースID。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 400 | `SOP10001` | タスク名が無効です。 |
| 400 | `SOP10002` | ターゲットパラメータフィールドが欠落している、タイプが誤っている、またはシナリオの制約を満たしていない。 |
| 400 | `SOP10003` | ステップが空、テンプレートのステップが欠落している、ステップが重複している/テンプレートにない、無効化が許可されていないステップを無効化した、またはすべてのステップを無効化した。 |
| 400 | `SOP10004` | 編集できないステップの `autoRun` を変更しようとしました。 |
| 400 | `SOP10005` | ステップ番号が無効です。 |
| 400 | `SOP10006` | SOPタイプがサポートされていません。 |
| 400 | `SOP10007` | タスク名が既に存在します。 |

## 例

### リクエスト例

```json
POST /api/v2/sop/tasks

{
  "name": "rebuild-standby-tenant-1",
  "sopType": "REBUILD_STANDBY_TENANT",
  "targetParam": {
    "standbyClusterId": 1,
    "standbyTenantId": 2,
    "logTransportMode": "NETWORK"
  },
  "steps": [
    {"stepIndex": 1, "stepKey": "CONFIRM_STANDBY_TENANT_INFO", "autoRun": true},
    {"stepIndex": 2, "stepKey": "BACKUP_PRIMARY_TENANT", "autoRun": true, "enabled": true},
    {"stepIndex": 3, "stepKey": "DISCONNECT_STANDBY_TENANT", "autoRun": true},
    {"stepIndex": 4, "stepKey": "LOCK_STANDBY_TENANT", "autoRun": true},
    {"stepIndex": 5, "stepKey": "DELETE_STANDBY_TENANT", "autoRun": true},
    {"stepIndex": 6, "stepKey": "CREATE_STANDBY_TENANT", "autoRun": false},
    {"stepIndex": 7, "stepKey": "VERIFY_PRIMARY_STANDBY_SYNC", "autoRun": true}
  ],
  "comments": "月次演習",
  "startNow": false
}
```
