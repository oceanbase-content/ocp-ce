# SOP実行詳細の照会

## 機能説明

タスクの実行状態およびすべてのステップの状態を照会します。タスクが開始されていない場合でも、プレビューを正常に返します。この場合、実行ID、現在のステップ、実行者、時間は`null`、状態は`NOT_STARTED`、すべてのステップは`PENDING`となります。

## 呼び出し説明

### インターフェース制約

タスクに対する`SOP_TASK:READ`権限が必要です。

### リクエストパス

`GET /api/v2/sop/tasks/{taskId}/execution`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| taskId | Path | Long | はい | タスクID。 |

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は`true`。 |
| data.id | Long \| null | 実行インスタンスID。開始前は`null`。 |
| data.sopTaskId | Long | 所属タスクID。 |
| data.status | String | 実行状態：`NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED`または`COMPLETED`。 |
| data.displayStatus | String | 表示状態。現在は`data.status`と同じです。 |
| data.currentStepIndex | Integer \| null | 現在最も早く未完了のステップ番号。プレビューが開始されていない場合は`null`。 |
| data.totalSteps | Integer | 実行またはプレビューのステップ数。 |
| data.readyManualStepIndexes | Array&lt;Integer&gt; | 現在人手で進めることができるステップ番号。開始前は空配列です。 |
| data.executor | String \| null | 実行を開始したユーザー名。開始前は`null`。 |
| data startTime | Datetime \| null | 実行開始時間。開始前は`null`。 |
| data.finishTime | Datetime \| null | 実行終了または失敗時間。終了していない場合は`null`。 |
| data.context | Object \| null | 現在の応答組み立てロジックは通常値を設定せず、呼び出し元はその内容に依存できません。 |
| data.steps[] | Array | すべてのステップの実行情報。 |
| data.steps[].stepIndex | Integer | ステップ番号。 |
| data.steps[].stepKey | String | ステップの一意の識別子。 |
| data.steps[].stepName | String | ステップの表示名。 |
| data.steps[].status | String | `PENDING`、`RUNNING`、`SUCCESSFUL`または`FAILED`。プレビューが開始されていない場合はすべて`PENDING`です。 |
| data.steps[].autoRun | Boolean | 現在の自動実行スイッチ。 |
| data.steps[].stepParam | Object \| null | 保存されたステップパラメータ。設定されていない場合は`null`。 |
| data.steps[].taskInstanceIds | Array lt;Long gt; | 関連するOCPタスクインスタンスID。存在しない場合は空配列です。 |
| data.steps[].retryCount | Integer | リトライ回数。プレビューが開始されていない場合は`0`です。 |
| data.steps[].errorMessage | String \| null | ステップの失敗メッセージ。 |
| data.steps[].startTime | Datetime \| null | ステップ開始時間。 |
| data.steps[].finishTime | Datetime \| null | ステップ終了時間。 |
| timestamp | Datetime | サーバーが応答を作成した時間。 |
| duration | Long | サーバー処理時間、単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功時は`200`です。 |
| traceId | String | リクエストのパスIDで、ログの調査に使用されます。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 404 | `SOP10008` | タスクが存在しません。 |
