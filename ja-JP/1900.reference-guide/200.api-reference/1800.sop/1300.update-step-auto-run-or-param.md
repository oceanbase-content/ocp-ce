# 実行されていないステップの自動実行スイッチまたはステップパラメータを更新する

## 機能の概要

開始済みタスク内の、`PENDING` 状態にあるステップを更新します。`autoRun` のみを変更したり、`stepParam` を保存したり、またはその両方を同時に変更することができます。

## 呼び出しの説明

### インターフェース制約

このタスクには `SOP_TASK:UPDATE` 権限と対象リソースに対する `UPDATE` 権限が必要です。ステップは `PENDING` でなければなりません。リクエストに `autoRun` を指定した場合のみ、テンプレートの `editable=true` が必要です。

### リクエストパス

`PATCH /api/v2/sop/tasks/{taskId}/execution/steps/{stepIndex}`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- | --- |
| taskId | Path | Long | はい | `1001` | タスクID。 |
| stepIndex | Path | Integer | はい | `5` | 開始済みの実行インスタンス内のステップ番号。 |
| autoRun | Body | Boolean | いいえ | `true` | 自動実行スイッチ。指定しない場合は変更されません。指定する場合は、ステップが編集可能である必要があります。 |
| stepParam | Body | Object | いいえ | `{"replacementHostId":200}` | ステップレベルのパラメータ。指定しない場合は変更されません。空のオブジェクトは空のまま保存されます。実行時に同名のフィールドはタスクレベルのパラメータを上書きします。 |

`stepParam` で明示的に定義されたビジネスフィールドと制約：

| SOPタイプ / ステップ | フィールド | 型 | 必須 | 制約 |
| --- | --- | --- | --- | --- |
| `OBSERVER_DATA_REBUILD` / `ADD_OBSERVER` | `replacementHostId` | Long | 空でない `stepParam` が指定されている場合は必須 | 正の数値である必要があります。単独で指定するか、`replacementHostIp` と同時に指定する必要があります。 |
| `OBSERVER_DATA_REBUILD` / `ADD_OBSERVER` | `replacementHostIp` | String | いいえ | 空ではない文字列である必要があります。サーバー側は `replacementHostId` に基づいて実際のプライベートIPを補完または上書きします。 |
| `REBUILD_STANDBY_TENANT` / `CREATE_STANDBY_TENANT` | `createStandbyTenantParamJson` | Object または JSON String | このステップを実行する場合は必須 | 新しいスタンバイテナントを作成するための完全なパラメータオブジェクト。このステップを実行する前に設定する必要があります。完全なフィールド、ネストされたフィールド、および例は以下を参照してください。 |

#### `createStandbyTenantParamJson` の詳細なパラメータ

JSONオブジェクトを直接指定することを推奨します。JSON文字列の指定もサポートされています。文字列を指定した場合、サーバー側は解析を試み、保存時にオブジェクトに変換します。このオブジェクトは `REBUILD_STANDBY_TENANT` の `CREATE_STANDBY_TENANT` ステップでのみ使用され、他のステップには書き込むことはできません。

| フィールド | 型 | 必須 | 値の範囲/制約 | 説明 |
| --- | --- | --- | --- | --- |
| name | String | はい | 空ではないこと。形式は `^[a-zA-Z][a-zA-Z_0-9]{1,63}$`、つまり英字で始まり、長さは2〜64文字で、英字、数字、アンダースコアのみを含むこと。 | 新しく作成するスタンバイテナント名。 |
| primaryTenantId | Long | はい | 正の整数。 | 対応するプライマリテナントID。 |
| standbyClusterId | Long | はい | 正の整数。 | 新しいスタンバイテナントが存在するOceanBaseクラスタID。このクラスタが現在のOCPに属していない場合は、対応するリソースアクセス権限も必要です。 |
| logTransportMode | String | はい | `NETWORK` または `LOG_BACKUP` のみを指定でき、**SOPタスク作成時の `targetParam.logTransportMode` と完全に一致している必要があります**。 | 新しいスタンバイテナントのログ転送モード。 |
| mode | String | いいえ | `MYSQL` または `ORACLE`。指定しない場合は、バックエンドのデフォルトである `MYSQL` が適用されます。 | 新しいスタンバイテナントの互換モード。 |
| primaryZone | String | いいえ | 最長128文字。 | 新しいテナントのプライマリゾーン設定。 |
| standbyROPassword | String | いいえ | 文字列。機密情報であり、ログやドキュメントの例に記録すべきではありません。 | スタンバイテナントのログ同期の読み取り専用ユーザーパスワード。 |
| primaryRootPassword | String | いいえ | 文字列。内部シナリオでのみ使用し、外部呼び出し元は渡したり永続化したりしてはなりません。 | プライマリテナントrootパスワード。 |
| primaryOcpClusterId | Long | いいえ | 正の整数の場合は、プライマリテナントが存在するOCPクラスタID。 | 複数OCPシナリオで、プライマリテナントが存在するOCPを識別するために使用されます。 |
| recoveryDelaySeconds | Long | いいえ | 非負の整数。`null` または `0` は遅延なしを意味します。 | スタンバイテナントのログ復元遅延、単位は秒。 |
| restoreTenant | Boolean | いいえ | `true`/`false`。`logTransportMode=NETWORK` の場合のみ意味があり、デフォルトは `false` です。 | バックアップセットに基づいてネットワークスタンバイテナントを作成するかどうか。 |
| enableArbitration | Boolean | いいえ | `true`/`false`、デフォルトは `false`。 | 新しいスタンバイテナントでアービトレーションを有効にするかどうか。 |
| serviceName | String | いいえ | 文字列。 | 新しいテナントのサービス名。 |
| description | String | いいえ | 文字列。 | 新しいテナントの説明。 |
| loadType | String | いいえ | `EXPRESS_OLTP`、`COMPLEX_OLTP`、`HTAP`、`OLAP`、`KV`、`EXPRESS_OLTP_PERF`。 | テナントのワークロードタイプ。 |
| zones | Array | はい | 配列を空にすることはできません。要素構造は下表を参照してください。 | 新しいテナントのレプリカゾーン設定。 |
| parameters | Array | いいえ | 指定しない場合、バックエンドのデフォルトの空配列 `[]` が使用されます。明示的に指定する場合は `null` にできませんが、空配列は許容されます。要素構造は下表を参照してください。 | テナントパラメータおよびシステム変数。 |
| backupConfig | Object | いいえ | `LOG_BACKUP` の場合、またはバックアップ/アーカイブの復元が必要な場合は、下表に従って入力してください。 | バックアップ復元設定。 |

`zones[]` の各要素には、以下のフィールドを含める必要があります。

| フィールド | 型 | 必須 | 値の範囲/制約 | 説明 |
| --- | --- | --- | --- | --- |
| zones[].name | String | はい | 空ではない。 | ゾーン名。 |
| zones[].replicaType | String | はい | `FULL`、`LOGONLY`、`READONLY`、`COLUMNSTORE`。 | そのゾーンのレプリカタイプ。 |
| zones[].resourcePool | Object | はい | 以下のリソースプールフィールドを含める必要があります。 | ゾーンのリソースプール設定。 |
| zones[].resourcePool.unitSpecName | String | はい | 空ではない。 | ユニット仕様名。 |
| zones[].resourcePool.unitCount | Long | はい | 空ではない。正の整数を入力することを推奨します。実際の利用可能範囲は、ダウンストリームのリソースプール検証によって決定されます。 | このゾーンで使用されるUnit数。 |

`parameters[]` の各要素のフィールドは以下のとおりです。

| フィールド | 型 | 必須 | 値の範囲/制約 | 説明 |
| --- | --- | --- | --- | --- |
| parameters[].name | String | はい | 空ではない。 | テナントパラメータまたはシステム変数名。 |
| parameters[].value | String | はい | 空ではない。 | パラメータ値。 |
| parameters[].parameterType | String | いいえ | `OB_TENANT_PARAMETER`（テナント構成パラメータ）または `OB_SYSTEM_VARIABLE`（システム変数）。 | パラメータの種類。指定しない場合、ダウンストリームのテナント作成ロジックがデフォルト動作で処理します。 |

`backupConfig` のフィールドは以下のとおりです。`useCustomStorage=true` の場合、`dataBackupUrl` と `logBackupUrl` はどちらも空でない値を指定する必要があります。パス内の空白は削除され、連続するスラッシュは正規化されます。

| フィールド | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| backupConfig.useCustomStorage | Boolean | いいえ | カスタムバックアップストレージディレクトリを使用するかどうか。デフォルトは `false`。 |
| backupConfig.backupStorageType | String | いいえ | バックアップストレージタイプ。値は現在のOCPでサポートされているストレージタイプである必要があります。 |
| backupConfig.storageUrl | String | いいえ | バックアップポリシーで設定されたストレージパス。 |
| backupConfig.dataBackupUrl | String | 条件必須 | カスタムストレージを使用する場合に入力する必要があるデータバックアップパス。 |
| backupConfig.logBackupUrl | String | 条件必須 | カスタムストレージを使用する場合に入力する必要があるログバックアップパス。 |
| backupConfig.ossSecretModel | Object | いいえ | オブジェクトストレージアクセス資格情報。フィールドは `endpoint`、`accessKeyId`、`accessKeySecret` で、使用する場合はすべて空でない値を指定する必要があります。`region` はAWS S3シナリオでのみ入力可能です。`appId` はCOSシナリオで使用されます。機密フィールドはログに書き込まないでください。 |
| backupConfig.advancedConfigsList | Array | いいえ | 詳細バックアップパラメータ配列。各要素には、空ではない `name` と空ではない文字列配列 `values` が含まれます。 |

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は `true`。 |
| data.stepIndex | Integer | 更新後のステップ番号。 |
| data.stepKey | String | ステップの一意な識別子。 |
| data.stepName | String | ステップの表示名。 |
| data.status | String | 現在の状態：`PENDING`、`RUNNING`、`SUCCESSFUL` または `FAILED`。 |
| data.autoRun | Boolean | 更新後の自動実行スイッチ。 |
| data.stepParam | Object \| null | 更新後の保存済みステップパラメータ。設定されていない場合は `null`。 |
| data.taskInstanceIds | Array&lt;Long&gt; | OCPタスクインスタンスID。関連付けられていない場合は空配列。 |
| data.retryCount | Integer | 現在のリトライ回数。 |
| data.errorMessage | String \| null | 最近の失敗情報。 |
| data.startTime | Datetime \| null | ステップ開始時間。 |
| data.finishTime | Datetime \| null | ステップ終了時間。 |
| timestamp | Datetime | サーバーが応答を作成した時間。 |
| duration | Long | サーバー処理時間、単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功した場合は `200`。 |
| traceId | String | ログ調査に使用されるリクエストのトレースID。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 404 | `SOP10008` | タスクが存在しません。 |
| 404 | `SOP10015` | タスクが起動していないか、ステップ番号が存在しません。 |
| 400 | `SOP10018` | ステップが `PENDING` 以外の場合、更新できません。 |
| 400 | `SOP10019` | `autoRun` の変更を要求しましたが、ステップは編集できません。 |
| 400 | `SOP10002` | ステップパラメータが現在のステップのビジネス検証を満たしていません。 |

## 例

### リクエスト例

```json
PATCH /api/v2/sop/tasks/1001/execution/steps/5

{
  "stepParam": {
    "createStandbyTenantParamJson": {
      "name": "standby_tenant_new",
      "mode": "MYSQL",
      "primaryTenantId": 1002,
      "standbyClusterId": 1001,
      "logTransportMode": "NETWORK",
      "recoveryDelaySeconds": 0,
      "restoreTenant": false,
      "enableArbitration": false,
      "zones": [
        {
          "name": "zone1",
          "replicaType": "FULL",
          "resourcePool": {
            "unitSpecName": "unit_s1",
            "unitCount": 1
          }
        }
      ],
      "parameters": [
        {
          "name": "ob_compatibility_mode",
          "value": "mysql",
          "parameterType": "OB_TENANT_PARAMETER"
        }
      ]
    }
  }
}
```
