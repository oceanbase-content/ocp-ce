# SOPタイプ一覧の取得

## 機能の概要

現在作成可能なSOPタイプを照会し、タイプ名、操作対象の入力ヒント、事前制約の説明を表示します。

## 呼び出しの仕様

### インターフェース制約

`SOP_TASK:READ`権限が必要です。

### リクエストパス

`GET /api/v2/sop/types`

### リクエストパラメータ

なし。

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | リクエストの成功・失敗。成功した場合は常に`true`となります。 |
| data_contents | Array | SOPタイプの配列。 |
| data_contents[].code | String | タイプコード。現在は`REBUILD_STANDBY_TENANT`（スタンバイテナントの再構築）、`ARBITRATION_FOR_FAULTY_REPLICA`（レプリカ異常時のアービトレーションサービス開始）、`OBSERVER_DATA_REBUILD`（OBServer異常後のデータ再構築）が使用されています。 |
| data_contents[].displayName | String | 現在のロケール設定におけるタイプ名。 |
| data_contents[].targetParamHint | Array lt;String gt; | 操作対象の入力ヒント。表示順に返されます。ヒントがない場合は空配列です。 |
| data_contents[].constraints | String \| null | 現在のロケール設定におけるタイプの業務上の制約説明。制約がない場合は`null`となります。 |
| timestamp | Datetime | サーバー側が応答を作成した時間。 |
| duration | Long | サーバー側で処理にかかった時間。単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功した場合は`200`となります。 |
| traceId | String | リクエストの経路ID。ログの調査に使用されます。 |
