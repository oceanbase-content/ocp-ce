# すべての失敗したステップを再試行する

## 機能の概要

インスタンス全体の実行状態が `FAILED` の場合、すべての失敗したステップを再試行し、実行状態を再計算します。

## 呼び出しの説明

### インターフェース制約

このタスクに対する `SOP_TASK:UPDATE` 権限と、ターゲットリソースに対する `UPDATE` 権限が必要です。

### リクエストパス

`POST /api/v2/sop/tasks/{taskId}/execution/retry`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| taskId | Path | Long | はい | タスクID。 |

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は `true`。 |
| data.id | Long | 実行インスタンスID。 |
| data.sopTaskId | Long | 所属SOPタスクID。 |
| data.status | String | 再試行後の実行状態。値は `WAITING_CONFIRM`、`RUNNING`、`FAILED`、または `COMPLETED` です。 |
| data.displayStatus | String | 表示用の実行状態。現在は `data.status` と同じです。 |
| data.currentStepIndex | Integer | 現在最も早く未成功なステップの番号。 |
| data.totalSteps | Integer | 今回の実行でのステップの総数。 |
| data.readyManualStepIndexes | Array&lt;Integer&gt; | 手動で進めることができるステップの番号。 |
| data.executor | String | 実行を開始したユーザー名。 |
| data startTime | Datetime | 実行開始時刻。 |
| data.finishTime | Datetime \| null | 実行終了または失敗時刻。終了していない場合は `null`。 |
| data.steps[] | Array | 全ステップ。各項目は `stepIndex`、`stepKey`、`stepName`、`status`、`autoRun`、`stepParam`、`taskInstanceIds`、`retryCount`、`errorMessage`、`startTime`、`finishTime` を含み、それぞれステップの特定・表示、状態、自動オン/オフ、パラメータ、関連タスク、リトライ回数、失敗情報、時間を表します。 |
| timestamp | Datetime | サーバーが応答を作成した時間。 |
| duration | Long | サーバー処理時間。単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功した場合は `200`。 |
| traceId | String | ログ調査に使用されるリクエストパスID。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 404 | `SOP10008` | タスクが存在しません。 |
| 400 | `SOP10017` | タスクに実行インスタンスが存在しない、または実行インスタンスの状態が `FAILED` ではありません。 |
