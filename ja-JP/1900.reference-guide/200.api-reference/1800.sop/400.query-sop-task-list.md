# SOPタスクリストの取得

## 機能説明

名前、タイプ、表示状態で、呼び出し元が読み取り可能なタスクを検索します。ページネーションとソートに対応しています。

## 呼び出し説明

### インターフェース制約

`SOP_TASK:READ`権限が必要です。結果には呼び出し元が読み取り可能なSOPタスクのみが含まれます。

### リクエストパス

`GET /api/v2/sop/tasks`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | デフォルト値 | 説明 |
| --- | --- | --- | --- | --- | --- |
| name | Query | String | いいえ | - | タスク名のキーワード。含む一致です。 |
| displayStatus | Query | StringArray | いいえ | - | 状態の集合。重複して指定するか、カンマで区切ります：`NOT_STARTED`、`WAITING_CONFIRM`、`RUNNING`、`FAILED`、`COMPLETED`。 |
| sopType | Query | StringArray | いいえ | - | SOPタイプの集合。重複して指定するか、カンマで区切ります。 |
| sortBy | Query | String | いいえ | - | `START_TIME`(実行開始時間)または`FINISH_TIME`(実行終了時間)。指定しない場合はタスクIDの降順です。 |
| sortOrder | Query | String | いいえ | `DESC` | `DESC`は降順、`ASC`は昇順です。 |
| page | Query | Integer | いいえ | `1` | ページ番号。1から始まります。 |
| size | Query | Integer | いいえ | `5` | 1ページあたりの数。デフォルトの最大値は`5000`です。 |
| sort | Query | String | いいえ | `id,DESC` | Pageableネイティブソート。`sortBy`が指定されていない場合にのみ使用されます。 |

| data_contents[].targetSummary.kind | String | ターゲットの種類。 |
