# SOPタスクの削除

## 機能の概要

タスクを削除します。開始前のタスクは削除できますが、開始済みのタスクは`COMPLETED`または`FAILED`状態の場合にのみ削除できます。削除すると、実行インスタンス、ステップの実行履歴、およびステップ関連タスクの記録が連鎖的にクリーンアップされます。

## 呼び出しの説明

### インターフェース制約

タスクに対する`SOP_TASK:UPDATE`権限が必要です。

### リクエストパス

`DELETE /api/v2/sop/tasks/{id}`

### リクエストパラメータ

| パラメータ | 位置 | 型 | 必須 | 説明 |
| --- | --- | --- | --- | --- |
| id | Path | Long | はい | タスクID。 |

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | 成功した場合は`true`。 |
| data | null | 削除による業務上の戻りデータはなく、固定で`null`です。 |
| timestamp | Datetime | サーバー側が応答を作成した時間。 |
| duration | Long | サーバー側の処理時間、単位はミリ秒。 |
| status | Integer | HTTPステータスコード。成功した場合は`200`。 |
| traceId | String | リクエストの経路IDで、ログの調査に使用されます。 |

### エラーコード

| HTTP | エラーコード | 説明 |
| --- | --- | --- |
| 404 | `SOP10008` | タスクが存在しません。 |
| 409 | `SOP10010` (`SOP_TASK_DELETE_FORBIDDEN`) | 実行状態が`WAITING_CONFIRM`または`RUNNING`の場合、削除は許可されません。 |
