# タスクの再試行

## 機能の概要

タスク内のすべての失敗したサブタスクの再実行をトリガーします。

## 呼び出しの説明

### インターフェース制約

呼び出し元はTASK_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/tasks/instances/{taskInstanceId}/retry`

### リクエストパラメータ

**path:**

|     パラメータ       |  型  | 必須 | サンプル値  |   説明    |
|----------------|------|------|------|---------|
| taskInstanceId | Long | はい   | 1000 | タスクインスタンスID。 |

### 戻り値

|    パラメータ     |    型    |              説明              |
|------------|----------|------------------------------|
| data       | Object   | WrappedTaskInstanceオブジェクトに格納されたリクエストデータ。詳細は**WrappedTaskInstanceデータ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                      |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                 |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。              |
| status     | Integer  | HTTPステータスコードに準拠したエンコードです。        |
| traceId    | String   | リクエストのTrace IDで、問題の調査に使用されます。         |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                |

**WrappedTaskInstanceデータ構造**

|      パラメータ        |     型      |   説明    |
|------------------|-------------|--------|
| id               | Long        | ソフトウェアパッケージID。 |
| name             | String      | ソフトウェアパッケージ名。 |
| taskDefinitionId | Long        | タスク定義ID。 |
| cluster          | Object      | クラスタ情報。詳細は**clusterデータ構造**を参照してください。 |
| tenant           | Object      | テナント情報。詳細は**tenantデータ構造**を参照してください。 |
| creator          | Object      | タスク作成者情報。詳細は**creatorデータ構造**を参照してください。 |
| status           | Integer     | タスクの実行状態。以下の値が選択可能です：<li>RUNNING：実行中。</li><li>FAILED：実行失敗。</li><li>SUCCESSFUL：実行成功。</li>   |
| type             | String      | タスクタイプ。以下の値が選択可能です：<li>MANUAL：手動で開始された運用保守タスク。</li><li>SYS_ONECE：システムが実行する1回限りのタスク。</li><li>SCHEDULED：組み込みではない定期実行タスク。</li><li>SYS_SCHEDULED：システム組み込みの定期実行タスク。</li>            |
| operation        | String      | タスク操作。以下の操作があります：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li>SKIP：スキップ。</li><li>CANCEL：キャンセル。</li>    |
| executor         | String      | タスクを実行するホスト情報。         |
| prohibitRollback | Boolean     | ロールバックを禁止するかどうかを示します。  |
| subtasks         | ObjectArray | WrappedSubtaskInstance配列のサブタスク集計情報。詳細は**WrappedSubtaskInstanceデータ構造**を参照してください。     |
| createTime       | String      | タスク作成日時。 |
| startTime        | String      | タスク開始時刻。 |
| finishTime       | String      | タスク終了時刻。  |
| prohibitSkip     | Boolean     | スキップを禁止するかどうかを示します。  |
| tags             | Array       | タグ情報。詳細は**InstanceFullTagデータ構造**を参照してください。  |
| isRemote         | Boolean     | リモートかどうかを示します。  |
