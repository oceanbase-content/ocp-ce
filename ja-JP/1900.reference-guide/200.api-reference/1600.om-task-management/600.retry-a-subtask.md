# サブタスクの再試行

## 機能の概要

失敗したサブタスクを再実行します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はTASK_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/tasks/instances/{taskInstanceId}/subtasks/{subtaskInstanceId}/retry`

### リクエストパラメータ

**path:**

|      パラメータ         |  タイプ  | 必須 |  サンプル値  |    説明    |
|-------------------|-------|-------|-------|----------|
| taskInstanceId    | Long  | はい    | 1000  | タスクインスタンスID。  |
| subtaskInstanceId | Long  | はい    | 10001 | サブタスクインスタンスID。 |

### 戻り値

|     パラメータ     |   タイプ    |            説明             |
|------------|----------|---------------------------|
| data       | Object   | SubtaskInstanceオブジェクト。詳細については、**SubtaskInstanceデータ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                   |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。              |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。           |
| status     | Integer  | HTTPステータスコードです。     |
| traceId    | String   | リクエストのTrace IDで、問題の調査に使用されます。      |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。             |

**SubtaskInstanceデータ構造**

|        パラメータ        |    タイプ     |        説明      |
|------------------|-----------|---------|
| id               | Long      | サブタスクインスタンスID。  |
| name             | String    | サブタスク名。  |
| seriesId         | Long      | サブタスクシリーズID。  |
| description      | String    | サブタスクの説明情報。   |
| timeout          | Integer   | サブタスクのタイムアウト時間。単位：秒。   |
| status           | String    | サブタスクの状態。次のような状態があります：<li>PENDING：初期状態。上流ノードの実行完了を待機しています。</li><li>READY：準備中。依存ノードはすでに実行完了し、実行を待機しています。</li><li>RUNNING：実行中。</li><li>CANCELING：キャンセル中。</li><li>FAILED：終了状態。実行失敗。</li><li>SUCCESSFUL：終了状態。実行成功。</li>    |
| operation        | String    | サブタスクの操作。次のような操作があります：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li>SKIP：スキップ。</li><li>CANCEL：キャンセル。</li>          |
| executor         | String    | サブタスクの実行ノード情報。  |
| runTime          | Integer   | サブタスクの実行回数。   |
| context          | String    | サブタスクの実行コンテキスト情報。   |
| createTime       | String    | サブタスクの作成時間。    |
| startTime        | String    | サブタスクの開始時間。   |
| finishTime       | String    | サブタスクの終了時間。   |
| nodeType         | String    | ノードタイプ。例：JAVA_TASK。  |
| paralleIdx       | Integer   | パラレルサブタスクのインデックス値。`-1`は非パラレルサブタスクを示します。   |
| upstreams        | LongArray | 上流サブタスクIDのリスト。   |
| downstream       | LongArray | 下流サブタスクIDのリスト。  |
| prohibitRollback | Boolean   | サブタスクのロールバックを禁止するかどうか。   |
| taskId           | Long      | タスクID。 |
| prohibitSkip     | Boolean   | スキップを禁止するかどうか。    |
