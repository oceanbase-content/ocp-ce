# ロールバックタスク

## 機能の概要

すべての失敗したサブタスクノードからロールバックを開始します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はTASK_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/tasks/instances/{taskInstanceId}/rollback`

### リクエストパラメータ

**path：**

|     パラメータ       |  タイプ  | 必須 | サンプル値  |   説明    |
|----------------|------|------|------|---------|
| taskInstanceId | Long | はい   | 1000 | タスクインスタンスID。 |

### 戻り値

|     パラメータ     |    タイプ    |              説明              |
|------------|----------|------------------------------|
| successful | Boolean  | リクエストが成功したかどうか。                      |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                 |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。              |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。        |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。         |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                |

## 例

### リクエスト例

`POST /api/v2/tasks/instances/1000/rollback`

### レスポンス例

```json
{

  "server": "a83ad33525",

}
```
