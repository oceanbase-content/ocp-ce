# サブタスクのスキップ

## 機能の概要

失敗したサブタスクの実行をスキップし、サブタスクを成功としてマークします。

## 呼び出しの説明

### インターフェース制約

呼び出し元はTASK_MANAGER権限を持っている必要があります。

### リクエストパス

`POST /api/v2/tasks/instances/{taskInstanceId}/subtasks/{subtaskInstanceId}/skip`

### リクエストパラメータ

**path:**

|        パラメータ         |  タイプ  | 必須 |  サンプル値  |    説明    |
|-------------------|------|----|-------|----------|
| taskInstanceId    | Long | はい  | 1000  | タスクインスタンスID。  |
| subtaskInstanceId | Long | はい  | 10001 | サブタスクインスタンスID。 |

### 戻り値

|     パラメータ     |    タイプ    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコードに準拠するエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |
| status     | Integer  | HTTPステータスコードに準拠するエンコード。 |

## 例

### リクエスト例

`POST api/v2/tasks/instances/1000/subtasks/10001/skip`

### レスポンス例

```json
{
  "duration": 55,
  "server": "a83ad33525",
  "status": 200,
  "successful": true,
  "timestamp": "2021-08-25T15:10:13.176+08:00",
  "traceId": "0bc49000675d41af"
}
```
