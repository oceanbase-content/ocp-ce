# タスクリストの取得

## 機能の概要

タスクのリストを照会し、さまざまなパラメータでフィルタリングできます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はTASK_VIEWER権限を持っている必要があります。

### リクエストパス

`GET /api/v2/tasks/instances`

### リクエストパラメータ

**body：**

|     パラメータ     |     型      | 必須 |      サンプル値       |    説明      |
|------------|-------------|------|----------------|------------|
| name       | String      | いいえ  | Prepare host   | タスク名の検索キーワードです。あいまい一致をサポートします。   |
| status     | StringArray | いいえ  | RUNNING,FAILED | タスクの実行状態です。以下の値が選択可能です：<li>RUNNING：実行中。</li><li>FAILED：実行失敗。</li><li> SUCCESSFUL：実行成功。</li>   |
| type       | String      | いいえ  | MANUAL         | タスクのタイプです。以下の値が選択可能です：<li>MANUAL：手動で開始された運用保守タスク。</li><li>SYS_ONECE：システムが実行する1回限りのタスク。</li><li>SCHEDULED：組み込みではない定期実行タスク。</li><li>SYS_SCHEDULED：システムに組み込まれた定期実行タスク。</li>    |
| cluterName | String      | いいえ  | meta           | クラスタ名の検索キーワードです。あいまい一致をサポートします。    |
| clusterId  | Long        | いいえ  | 100            | OCP側のクラスタID。    |
| tenantName | String      | いいえ  | SYS            | テナント名です。`clusterId`と併用して使用する必要があります。    |
| tenantId   | Long        | いいえ  | 100            | OCP側のテナントID。     |
| hostId     | Long        | いいえ  | 100            | ホストID。     |
| page       | Integer     | いいえ  | 1              | ページ番号です。1から始まります。    |
| size       | Integer     | いいえ  | 10             | リクエストデータのページングサイズです。デフォルト値：10、最大値：2000。       |
| sort       | String      | いいえ  | id,asc         | リクエストデータのソート規則です。     |

### 戻り値

|     パラメータ      |    型    |                説明                |
|-------------|----------|----------------------------------|
| data        | Object   | リクエストしたデータ。                           |
| ├─ contents | Array    | BasicTaskInstanceの配列です。詳細は**BasicTaskInstanceデータ構造**を参照してください。 |
| ├─ page     | Object   | ページ情報です。詳細は**pageデータ構造**を参照してください。             |
| successful  | Boolean  | リクエストが成功したかどうかを示します。                          |
| timestamp   | Datetime | サーバー側でリクエストが完了したタイムスタンプです。                     |
| duration    | Integer  | サーバー側でリクエストを処理する時間（ミリ秒）。                  |
| status      | Integer  | HTTPステータスコードです。            |
| traceId     | String   | リクエストのTrace IDです。問題のトラブルシューティングに使用されます。             |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**BasicTaskInstanceデータ構造**

|     パラメータ     |     型      |     説明       |
|------------|-------------|-----------|
| id         | Integer     | ソフトウェアパッケージID。   |
| name       | String      | ソフトウェアパッケージ名。    |
| cluster    | Object      | クラスタ情報です。詳細は**clusterデータ構造**を参照してください。    |
| tenant     | Object      | テナント情報です。詳細は**tenantデータ構造**を参照してください。  |
| creator    | Object      | タスク作成者情報です。詳細は**creatorデータ構造**を参照してください。    |
| status     | Integer     | タスクの実行状態です。以下の値が選択可能です：<li>RUNNING：実行中。</li><li>FAILED：実行失敗。</li><li>SUCCESSFUL：実行成功。</li>   |
| startTime  | String      | タスク開始時間。     |
| finishTime | String      | タスク終了時間。    |
| subtasks   | ObjectArray | BasicSubtaskInstanceの配列です。サブタスクの集計情報です。詳細は**BasicSubtaskInstanceデータ構造**を参照してください。    |
| operation  | String      | タスク操作です。以下が含まれます：execute、retry、rollback。   |
| tags       | Array       | タグリストです。詳細は**InstanceFullTagデータ構造**を参照してください。    |

**clusterデータ構造**

|     パラメータ      |   型   |       説明        |
|-------------|--------|--------------|
| id          | Long   | OCP側のクラスタID。   |
| name        | String | クラスタ名。    |
| obClusterId | Long   | OceanBase側のクラスタID。     |
| type        | String | クラスタタイプです。以下のタイプがあります：<li>PRIMARY：プライマリクラスタ。</li><li>STANDBY：スタンバイクラスタ。</li>    |

**tenantデータ構造**

|     パラメータ      |   型   |     説明       |
|-------------|--------|-----------|
| id          | Long   | OCP側のテナントID 。   |
| name        | String | テナント名。    |
| obClusterId | Long   | OceanBase側のテナントID。     |
| mode        | String | テナントモードです。以下のモードがあります：<li>ORACLE：Oracle互換モード。</li><li>MYSQL：MySQL互換モード。</li>    |

**creatorデータ構造**

| パラメータ | 型 | 説明 |
|------|--------|----------|
| id | Long | 作成者ユーザーID。 |
| name | String | 作成者のユーザー名。 |

**BasicSubtaskInstanceデータ構造**

| パラメータ | 型 | 説明 |
|-------------|--------|-----------|
| id | Long | サブタスクインスタンスID。 |
| name | String | サブタスク名。 |
| description | String | サブタスクの説明情報。 |
| status | String | サブタスクの状態。次のような状態があります：<li>PENDING：初期状態。上流ノードの実行完了を待機しています。</li><li>READY：準備中。依存ノードはすでに実行完了し、実行を待機しています。</li><li>RUNNING：実行中。</li><li>CANCELING：キャンセル中。</li><li>FAILED：終了状態。実行失敗。</li><li>SUCCESSFUL：終了状態。実行成功。</li> |
| operation | String | サブタスクの操作。次のような操作があります：<li>EXECUTE：通常実行。</li><li>RETRY：再試行。</li><li>ROLLBACK：ロールバック。</li><li>SKIP：スキップ。</li><li>CANCEL：キャンセル。</li> |

**InstanceFullTagデータ構造**

| パラメータ | 型 | 説明 |
|-----------------------------|--------|-----------|
| clusterName | String | クラスタ名。 |
| clusterId | Long | OCP側のクラスタID。 |
| obClusterId | Long | OceanBase側のクラスタID。 |
| clusterType | String | クラスタタイプ。<li>PRIMARY：プライマリ/スタンバイデータベースのプライマリクラスタ。</li><li>STANDBY：プライマリ/スタンバイデータベースのスタンバイクラスタ。</li> |
| zoneName | String | ゾーン名。 |
| tenantName | String | テナント名。 |
| tenantId | Long | OCP側のテナントID。 |
| obTenantId | Long | OceanBase側のテナントID。 |
| tenantMode | String | テナントモード。<li>MYSQLモード。</li><li>ORACLEモード。</li> |
| tenantRole | String | テナントロール。<li>PRIMARY</li><li>STANDBY</li><li>CLONE</li><li>RESTORE</li><li>UNKNOWN</li> |
| obVersion | String | OceanBaseのバージョン。 |
| serverId | Long | OBServer ID。 |
| arbitrationServiceId | Long | アービトレーションサービスID。 |
| arbitrationServiceGroupName | String | アービトレーションサービスグループ名。 |
| arbitrationServiceGroupId | Long | アービトレーションサービスグループID。 |
| arbitrationServiceSvrPort | Integer | アービトレーションサービスポート。 |
| obproxyClusterName | String | OBProxyクラスタ名。 |
| obproxyClusterId | Long | OBProxyクラスタID。 |
| obproxyServerId | Long | OBProxy Server ID。 |
| hostId | Long | ホストID。 |
| svrIp | Long | ホストIPアドレス。 |
| objectType | String | タスク関連オブジェクトのタイプ。 |
| deleted | Boolean | 現在のタスク関連情報が削除されたかどうかを示すフラグ。 |
| binlogClusterName | String | Binlogクラスタ名。 |
| binlogClusterId | Long | BinlogクラスタID。 |
| binlogServerId | Long | Binlog Server ID。 |
| tenantBinlogServiceId | Long | BinlogインスタンスID。 |
| binlogInstanceName | String | Binlogインスタンス名。 |

**pageデータ構造**

|      パラメータ       |   型    |  説明   |
|---------------|---------|-------|
| totalElements | Integer | 総レコード数。  |
| totalPages    | Integer | 総ページ数。   |
| number        | Integer | 現在のページ番号。  |
| size          | Integer | 現在のページサイズ。 |
