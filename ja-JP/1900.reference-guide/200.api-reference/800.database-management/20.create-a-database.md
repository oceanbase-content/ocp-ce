# データベースの作成

## 機能の概要

データベース作成時に使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

* 呼び出し元には、指定されたテナントの変更権限が付与されていなければなりません。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/databases`

### リクエストパラメータ

パスパラメータ

|    パラメータ    |   型    | 必須 | サンプル値 |  説明   |
|----------|---------|----|-----|-------|
| id       | Integer | はい  | 1   | クラスタID |
| tenantId | Integer | はい  | 5   | テナントID |

ボディパラメータ

|     パラメータ      |   型    | 必須 |        サンプル値         |                                                                                                                                                                                                                                                    説明                                                                                                                                                                                                                                                    |
|-------------|---------|----|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| dbName      | String  | はい  | db1                | データベース名                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| collation   | String  | いいえ  | utf8mb4_general_ci | 照合順序。取り得る範囲： <li> binary   </li><li>utf8mb4    </li><li> gbk   </li><li>gb18030  </li>  デフォルトはutf8mb4_general_ci。ORACLEテナントは現時点ではこのパラメータをサポートしていません |
| primaryZone | String  | いいえ  | zone1;zone2,zone3  | ゾーンの優先順位                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| readonly    | Boolean | はい  | false              | 読み取り専用かどうか                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

### 戻り値

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | データベースオブジェクト。データベースのデータ構造は下表を参照してください。    |
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

データベースのデータ構造

|           パラメータ            |    型    |                                                                    説明                                                                     |
|-------------------------|----------|-------------------------------------------------------------------------------------------------------------------------------------------|
| dbName                  | String   | データベース名                                                                                                                                      |
| charset                 | String   | 文字セット                                                                                                                                       |
| collation               | String   | 照合順序                                                                                                                                       |
| readonly                | Boolean  | 読み取り専用かどうかを示します。                                                                      |
| createTime              | Datetime | 作成日時                                                                                                                                      |
| connectionUrls          | Array    | OBProxyと接続文字列のリスト                                                                                                                            |
| ├─ connectionStringType | String   | 接続文字列のタイプ。取り得る範囲： <li> OBPROXY   </li><li>DIRECT 直接接続 </li>   |
| ├─ obProxyAddress       | String   | OBProxyのアドレス。接続文字列のタイプがOBPROXYの場合にのみ有効です。                                                                                           |
| ├─ obProxyPort          | Integer  | OBProxyポート。接続文字列のタイプがOBPROXYの場合にのみ有効です。                                                                                           |
| ├─ connectionString     | String   | 接続文字列                                                                                                                                       |
| requiredSize            | Integer  | データベースのrequired_size                                                                                                                        |
| id                      | Integer  | データベースのID                                                                                                                                   |

## 例

### リクエスト例

クラスタ1、テナント1000001にデータベースを作成します。

`POST /api/v2/ob/clusters/1/tenants/1000001/databases?id=1&tenantId=1000001`

```java
{
  "dbName": "db1",
  "collation": "utf8mb4_general_ci",
  "readonly": false,
}
```
