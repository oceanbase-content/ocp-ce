# データベースユーザーの詳細を取得する

## 機能の概要

データベースユーザーの詳細を取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/users/{username}`

### リクエストパラメータ

**パスパラメータ**

|    パラメータ    |   型    | 必須 | サンプル値  |  説明   |
|----------|---------|-------|------|-------|
| id       | Integer | はい  | 1    | クラスタID |
| tenantId | Integer | はい  | 5    | テナントID |
| username | String  | はい  | root | ユーザー名   |
| hostName | String  | いいえ  | 33.47.251.%        | ホスト名 |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | データベースユーザー。データベースユーザーデータ構造は下表を参照してください。   |
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace IDで、問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |

**データベースユーザーデータ構造**

|           パラメータ            |     型      |         説明     |
|-------------------------|-------------|--------|
| username                | String      | ユーザー名。     |
| globalPrivileges        | StringArray | グローバル権限のリスト：<li>MySQLテナントの場合、グローバル権限のリストを表します。</li><li>Oracleテナントの場合、システム権限のリストを表します。</li>    |
| dbPrivileges            | Array       | データベース権限のリスト。</br>**<UI-TERM key="ocp-v2.Alarm.Rule.Detail.Description">説明</UI-TERM>**：MySQLテナントにのみ存在し、Oracleテナントにはこのフィールドはありません。     |
| ├─ dbName               | String      | データベース名。     |
| ├─ privileges           | StringArray | データベースの権限リスト。    |
| objectPrivileges        | Array       | オブジェクト権限のリスト。</br>**<UI-TERM key="ocp-v2.TakeOver.Component.ParameterDiffDrawer.Description">説明</UI-TERM>**：Oracleテナントにのみ存在し、MySQLテナントにはこのフィールドはありません。     |
| ├─ dbObject             | Object      | データベースオブジェクト。      |
| ├─ privileges           | StringArray | オブジェクトの権限リスト。    |
| grantedRoles            | String      | ユーザーが付与されたロール。</br>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Description">説明</UI-TERM>**：Oracleテナントにのみ存在し、MySQLテナントにはこのフィールドはありません。  |
| isLocked                | Bool        | ユーザーがロックされているかどうか。      |
| createTime              | Datetime    | ユーザー作成日時。    |
| connectionStrings       | Array       | OBProxyと接続文字列のリスト。     |
| ├─ connectionStringType | String      | 接続文字列タイプ。取り得る範囲：<li>OBPROXY。</li><li>DIRECT 直接接続。</li>      |
| ├─ obProxyAddress       | String      | OBProxyアドレス。</br>**<UI-TERM key="ocp-v2.Auth.Role.New.Description">説明</UI-TERM>**：接続文字列タイプがOBProxyの場合に有効です。     |
| ├─ obProxyPort          | Integer     | OBProxyポート。</br>**<UI-TERM key="ocp-v2.src.template.Table.Description">説明</UI-TERM>**：接続文字列タイプがOBProxyの場合に有効です。        |
| ├─ connectionString     | String      | 接続文字列。     |
| accessibleDatabases     | StringArray | アクセス可能なデータベース。</br>**<UI-TERM key="ocp-v2.Alarm.Template.Detail.Description">説明</UI-TERM>**：Oracleテナントにのみ存在し、MySQLテナントにはこのフィールドはありません。    |

**dbObjectパラメータの説明**

|     パラメータ     |   型   |         説明      |
|------------|--------|---------------|
| objectType | String | データベースオブジェクトのタイプ。取り得る範囲：<li>TABLE テーブル。</li><li>VIEW ビュー。</li><li>STORED_PROCEDURE ストアドプロシージャ。</li>    |
| objectName | String | データベースオブジェクト名、すなわちテーブル名、ビュー名、またはストアドプロシージャ名。      |
| schemaName | String | スキーマ名。通常、ユーザー名と同じです。     |

## 例

### リクエスト例

`GET /api/v2/ob/clusters/1/tenants/1000001/users/root?id=1&tenantId=1000001&username=root`
