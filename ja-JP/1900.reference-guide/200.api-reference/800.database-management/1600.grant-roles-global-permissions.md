# ロールにグローバル権限を付与する

## 機能の概要

ロールにグローバル権限を付与します。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

* 呼び出し元は指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/roles/{roleName}/grantGlobalPrivilege`

### リクエストパラメータ

**pathパラメータ：**

|  パラメータ    |   型    | 必須 |  サンプル値  |  説明   |
|----------|---------|------|-------|-------|
| id       | Integer | はい  | 1     | クラスタID。 |
| tenantId | Integer | はい  | 5     | テナントID。 |
| roleName | String  | はい  | ROLE1 | ロール名。   |

**bodyパラメータ：**

|        パラメータ     |     型     | 必須 |    サンプル値    |        説明      |
|-----------------|-------------|------|---------------|--------------|
| globalPrivileges | ArrayString | はい  | \[CREATE_SESSION, CREATE_TABLE\] | 付与するシステム権限のリスト。  |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

クラスタ1、テナント1000001において、ROLE1ロールにCREATE_SESSION権限を付与します。

`POST /api/v2/ob/clusters/1/tenants/2000001/roles/ROLE1/grantGlobalPrivilege?id=1&tenantId=2000001&username=USER1`

```json
{
  "globalPrivileges": [
    "CREATE_SESSION"
  ]
}
```
