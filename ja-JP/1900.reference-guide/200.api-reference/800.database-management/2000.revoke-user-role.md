# ユーザーのロールを取り消す

## 機能の概要

ユーザーのロールを取り消します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元には、指定されたテナントの変更権限が付与されていなければなりません。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/users/{username}/revokeRole`

### リクエストパラメータ

pathパラメータ

|    パラメータ    |   型    | 必須 | サンプル値  |  説明   |
|----------|---------|----|------|-------|
| id       | Integer | はい  | 1    | クラスタID |
| tenantId | Integer | はい  | 5    | テナントID |
| username | String  | はい  | root | ユーザー名   |

bodyパラメータ

|  パラメータ   |     型      | 必須 |    サンプル値     |    説明     |
|-------|-------------|----|------------|-----------|
| roles | StringArray | はい  | \[R1, R2\] | 取り消すロールのリスト。 |

### 戻り値

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

クラスタ1、テナント1000001の下でユーザーUSER1のCONNECTロールを取り消します。

`POST /api/v2/ob/clusters/1/tenants/2000001/users/USER1/revokeRole?id=1&tenantId=2000001&username=USER1`
