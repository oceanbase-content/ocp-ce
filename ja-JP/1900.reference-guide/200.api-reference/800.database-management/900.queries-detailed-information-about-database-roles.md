# データベースロールの詳細を取得する

## 機能の概要

データベースロールの詳細を取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/roles/{roleName}`

### リクエストパラメータ

パスパラメータ

|    パラメータ    |   型    | 必須 | サンプル値  |  説明   |
|----------|---------|----|------|-------|
| id       | Integer | はい  | 1    | クラスタID |
| tenantId | Integer | はい  | 5    | テナントID |
| roleName | String  | はい  | root | ロール名   |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | データベースロール。データベースロールのデータ構造は下表を参照してください。   |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

データベースロールのデータ構造

|        パラメータ        |     型      |     説明      |
|------------------|-------------|-------------|
| name             | String      | ロール名         |
| createTime       | Datetime    | ユーザー作成日時      |
| updateTime       | Datetime    | ロール更新日時      |
| globalPrivileges | StringArray | システム権限リスト      |
| objectPrivileges | Array       | オブジェクト権限リスト      |
| ├─ dbObject      | Object      | データベースオブジェクト       |
| ├─ privileges    | StringArray | オブジェクトの権限リスト     |
| grantedRoles     | StringArray | ロールが付与されているロール    |
| userGrantees     | StringArray | このロールが付与されているユーザー |
| roleGrantees     | StringArray | このロールが付与されているロール |

dbObjectパラメータ説明

|     パラメータ     |   型   |                                                                                                               説明                                                                                                                |
|------------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| objectType | String | データベースオブジェクトタイプ。値の範囲： * TABLE テーブル   * VIEW ビュー    <!-- --> * STORED_PROCEDURE ストアドプロシージャ    |
| objectName | String | データベースオブジェクト名。テーブル名、ビュー名、またはストアドプロシージャ名を指定します。                                                                                                                                                                                                           |
| schemaName | String | スキーマ名。通常、ユーザー名と同じです。                                                                                                                                                                                                              |

## 例

### リクエスト例

クラスタ1、テナント1000001の下のROLE1ロールの詳細を取得します。

`GET /api/v2/ob/clusters/1/tenants/2000001/roles/ROLE1?id=1&tenantId=2000001&roleName=ROLE1`
