# データベースユーザーリストの取得

## 機能の概要

データベースユーザーリストを取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は、指定されたテナントに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/users`

### リクエストパラメータ

パスパラメータ

|    パラメータ    |   型    | 必須 | サンプル値 |  説明   |
|----------|---------|----|-----|-------|
| id       | Integer | はい  | 1   | クラスタID |
| tenantId | Integer | はい  | 5   | テナントID |

### 戻り値

|     パラメータ      |    型    |           説明           |
|-------------|----------|------------------------|
| data        | Object   | contentsを含みます。           |
| ├─ contents | Array    | データベースユーザーのリスト。データベースユーザーデータ構造は下表を参照してください。 |
| successful  | Boolean  | リクエストが成功したかどうかを示します。                |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプです。           |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。        |
| status      | Integer  | HTTPステータスコード   |
| traceId     | String   | リクエストのTrace IDで、問題の調査に使用されます。   |
| server      | String   | リクエストに応答したサーバーのアドレスです。           |

データベースユーザーデータ構造

|           パラメータ            |     型      |                                                                                 説明                                                                                 |
|-------------------------|-------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| username                | String      | ユーザー名                                                                                                                                                                |
| globalPrivileges        | StringArray | グローバル権限リスト： * MySQLテナントの場合、グローバル権限のリストを表します。   * Oracleテナントの場合、システム権限のリストを表します。    |
| dbPrivileges            | Array       | データベース権限リスト **<UI-TERM key="ocp-v2.MultiAzone.Parameter.Description">説明</UI-TERM>**  MySQLテナントにのみ存在し、Oracleテナントにはこのフィールドはありません。                                                                                       |
| ├─ dbName               | String      | データベース名                                                                                                                                                               |
| ├─ privileges           | StringArray | データベースの権限リスト                                                                                                                                                           |
| objectPrivileges        | Array       | オブジェクト権限リスト **<UI-TERM key="ocp-v2.MultiAzone.Detail.Description">説明</UI-TERM>**  Oracleテナントにのみ存在し、MySQLテナントにはこのフィールドはありません。                                                                                        |
| ├─ dbObject             | Object      | データベースオブジェクト。詳細は下表のdbObjectパラメータ説明を参照してください。                                                                                                                                        |
| ├─ privileges           | StringArray | オブジェクトの権限リスト                                                                                                                                                            |
| grantedRoles            | StringArray | ユーザーに付与されたロール **<UI-TERM key="ocp-v2.Auth.Role.New.Description">説明</UI-TERM>**  Oracleテナントにのみ存在し、MySQLテナントにはこのフィールドはありません。                                                                                      |
| isLocked                | Bool        | ユーザーがロックされているかどうかを示します。                                                                                                                                                            |
| createTime              | Datetime    | ユーザー作成日時                                                                                                                                                             |
| connectionStrings       | Array       | OBProxyと接続文字列のリスト                                                                                                                                                     |
| ├─ connectionStringType | String      | 接続文字列タイプ。取り得る範囲： * OBPROXY   * DIRECT 直接接続                             |
| ├─ obProxyAddress       | String      | OBProxyアドレス **<UI-TERM key="ocp-v2.Settings.Credential.Host.Description">説明</UI-TERM>**  接続文字列タイプがOBProxyの場合に有効です                                                                                            |
| ├─ obProxyPort          | Integer     | OBProxyポート **<UI-TERM key="ocp-v2.src.component.AddHostDrawer.DescriptionOptional">説明</UI-TERM>**  接続文字列タイプがOBProxyの場合に有効です                                                                                            |
| ├─ connectionString     | String      | 接続文字列                                                                                                                                                                |
| accessibleDatabases     | StringArray | アクセス可能なデータベース **<UI-TERM key="ocp-v2.MultiAzone.Parameter.Description">説明</UI-TERM>**  MySQLテナントにのみ存在し、Oracleテナントにはこのフィールドはありません。                                                                                       |

dbObjectパラメータ説明

|     パラメータ     |   型   |                                                                                                               説明                                                                                                                |
|------------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| objectType | String | データベースオブジェクトのタイプ。値の範囲は以下のとおりです： * TABLE　テーブル   * VIEW　ビュー    <!-- --> * STORED_PROCEDURE　ストアドプロシージャ    |
| objectName | String | データベースオブジェクト名、つまりテーブル名、ビュー名、またはストアドプロシージャ名です。                                                                                                                                                                                                           |
| schemaName | String | スキーマ名で、通常はユーザー名と同じです。                                                                                                                                                                                                              |
