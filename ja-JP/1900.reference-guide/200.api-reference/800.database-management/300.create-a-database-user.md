# データベースユーザーの作成

## 機能の概要

データベースユーザーを作成します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元には、指定されたテナントの変更権限が付与されている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/users`

### リクエストパラメータ

**pathパラメータ**

|    パラメータ    |   型    | 必須 | サンプル値 |  説明   |
|----------|---------|----|-----|-------|
| id       | Integer | はい  | 1   | クラスタID |
| tenantId | Integer | はい  | 5   | テナントID |

**bodyパラメータ**

|        パラメータ        |     型      | 必須 |        サンプル値         |     説明    |
|------------------|-------------|-------|----------------|-------|
| hostName         | String      | いいえ  | 33.47.251.%        | ホスト名 |
| username         | String      | はい  | user1              | ユーザー名。     |
| password         | String      | はい  | ******             | パスワード。    |
| globalPrivileges | ArrayString | いいえ  | \[SELECT, CREATE\] | 付与するグローバル権限のリスト。<li>MySQLテナントの場合、グローバル権限のリストを表します。</li><li>Oracleテナントの場合、システム権限のリストを表します。</li>    |
| dbPrivileges     | Array       | いいえ  |                    | 付与するデータベース権限のリスト。</br>**<UI-TERM key="ocp-v2.component.RecentCompaction.Description">説明</UI-TERM>**：MySQLテナントにのみ存在し、Oracleテナントにはこのフィールドはありません。    |
| ├─ dbName        | String      | はい  | db1                | データベース名    |
| ├─ privileges    | StringArray | はい  | \[ALTER, INDEX\]   | データベースの権限リスト   |
| roles            | StringArray | いいえ  | \[R1, R2\]         | 付与するロールのリスト。</br>**<UI-TERM key="ocp-v2.Alarm.Rule.New.Description">説明</UI-TERM>**：Oracleテナントにのみ存在し、MySQLテナントにはこのフィールドはありません。     |

### 戻り値

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | データベースユーザー。データベースユーザーデータ構造は下表を参照してください。   |
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコード。 |
| traceId    | String   | リクエストのトレースIDで、問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |

**データベースユーザーのデータ構造**

|           パラメータ            |     型      |      説明      |
|-------------------------|-------------|----------------|
| username                | String      | ユーザー名。    |
| globalPrivileges        | StringArray | グローバル権限のリスト：<li>MySQLテナントの場合、グローバル権限のリストを表します。</li><li>Oracleテナントの場合、システム権限のリストを表します。</li>     |
| dbPrivileges            | Array       | データベース権限のリスト。Oracleテナントにはこのフィールドはありません。    |
| ├─ dbName               | String      | データベース名。     |
| ├─ privileges           | StringArray | データベースの権限リスト。       |
| objectPrivileges        | Array       | オブジェクト権限のリスト。MySQLテナントにはこのフィールドはありません。     |
| ├─ dbObject             | Object      | データベースオブジェクト。     |
| ├─├─ objectType         | String      | データベースオブジェクトのタイプ。値の範囲：<li>TABLE テーブル。</li><li>VIEW ビュー。</li><li>STORED_PROCEDURE ストアドプロシージャ。</li>    |
| ├─├─ objectName         | String      | データベースオブジェクト名、つまりテーブル名、ビュー名、またはストアドプロシージャ名。     |
| ├─├─ schemaName         | String      | スキーマ名。通常はユーザー名と同じです。     |
| ├─ privileges           | StringArray | オブジェクトの権限リスト。       |
| grantedRoles            | String      | ユーザーに付与されたロール。</br>**<UI-TERM key="ocp-v2.page.Settings.Profile.Description">説明</UI-TERM>**：Oracleテナントにのみ存在し、MySQLテナントにはこのフィールドはありません。     |
| isLocked                | Bool        | ユーザーがロックされているかどうかを示します。     |
| createTime              | Datetime    | ユーザーの作成日時。       |
| connectionStrings       | Array       | OBProxyと接続文字列のリスト      |
| ├─ connectionStringType | String      | 接続文字列のタイプ。値の範囲：<li>OBPROXY。</li><li>DIRECT 直接接続。</li>     |
| ├─ obProxyAddress       | String      | OBProxyのアドレス。</br>**<UI-TERM key="ocp-v2.component.OperationConfig.List.Description">説明</UI-TERM>**：接続文字列のタイプがOBProxyの場合に有効です。     |
| ├─ obProxyPort          | Integer     | OBProxyポート。</br>**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Description">説明</UI-TERM>**：接続文字列のタイプがOBProxyの場合に有効です。     |
| ├─ connectionString     | String      | 接続文字列。      |
| accessibleDatabases     | StringArray | アクセス可能なデータベース。</br>**<UI-TERM key="ocp-v2.Alarm.Rule.Description">説明</UI-TERM>**：MySQLテナントにのみ存在し、Oracleテナントにはこのフィールドはありません。   |

## 例

### リクエスト例

クラスタ1、テナント1000001にuser1ユーザーを作成します。

`POST /api/v2/ob/clusters/1/tenants/1000001/users?id=1&tenantId=1000001`

```java
{
  "username": "user1",
  "password": "******",
  "globalPrivileges": [
    "DELETE",
    "SELECT",
    "INDEX"
  ],
  "dbPrivileges": [
    {
      "dbName": "db1",
      "privileges": [
        "ALTER",
        "CREATE",
        "SELECT"
      ]
    }
  ]
}
```
