# ロールオブジェクト権限の付与

## 機能の概要

ロールオブジェクトに権限を付与します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/roles/{roleName}/grantObjectPrivilege`

### リクエストパラメータ

pathパラメータ

|    パラメータ    |   型    | 必須 |  例値  |  説明   |
|----------|---------|----|-------|-------|
| id       | Integer | はい  | 1     | クラスタID |
| tenantId | Integer | はい  | 5     | テナントID |
| roleName | String  | はい  | ROLE1 | ロール名   |

bodyパラメータ

|        パラメータ        |     型      | 必須 |        例値         |     説明     |
|------------------|-------------|----|--------------------|------------|
| objectPrivileges | Array       | はい  | --                 | 付与するオブジェクト権限のリスト |
| ├─ dbObject      | Object      | はい  | --                 | データベースオブジェクト      |
| ├─ privileges    | StringArray | はい  | \[SELECT, UPDATE\] | オブジェクトの権限リスト    |

dbObjectパラメータの説明

|     パラメータ     |   型   |  例値   |                                                                                                               説明                                                                                                                |
|------------|--------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| objectType | String | TABLE  | データベースオブジェクトのタイプ。取り得る範囲： * TABLE テーブル   * VIEW ビュー    <!-- --> * STORED_PROCEDURE ストアドプロシージャ    |
| objectName | String | table1 | データベースオブジェクト名、つまりテーブル名またはビュー名。                                                                                                                                                                                                                  |
| schemaName | String | USER1  | スキーマ名。通常はユーザー名と同じです。                                                                                                                                                                                                              |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコードです。 |
| traceId    | String   | リクエストのTrace Idで、問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |

## 例

### リクエスト例

クラスタ1、テナント1000001の下で、ROLE1ロールに対してテーブルU1.T1のSELECT、UPDATE権限を付与します。

`POST /api/v2/ob/clusters/1/tenants/2000001/roles/ROLE1/grantObjectPrivilege?id=1&tenantId=2000001&username=USER1`
