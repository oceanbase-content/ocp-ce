# データベースロールの作成

## 機能の概要

データベースロールを作成します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は、指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/roles`

### リクエストパラメータ

pathパラメータ

|    パラメータ    |   型    | 必須 | サンプル値 |  説明   |
|----------|---------|----|-----|-------|
| id       | Integer | はい  | 1   | クラスタID |
| tenantId | Integer | はい  | 5   | テナントID |

bodyパラメータ

|        パラメータ        |     型      | 必須 |        サンプル値         |     説明     |
|------------------|-------------|----|--------------------|------------|
| roleName         | String      | はい  | ROLE1              | ロール名        |
| globalPrivileges | ArrayString | いいえ  | \[SELECT, CREATE\] | 付与するシステム権限のリスト |
| roles            | StringArray | いいえ  | \[R1, R2\]         | 付与するロールのリスト   |

### 戻り値

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | データベースロール。データベースロールのデータ構造は下表を参照してください。   |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答するアプリケーションサービスのアドレス。         |

データベースロールのデータ構造

|        パラメータ        |     型      |             説明              |
|------------------|-------------|-----------------------------|
| name             | String      | ロール名                         |
| createTime       | Datetime    | ユーザー作成時間                      |
| updateTime       | Datetime    | ロール更新時間                      |
| globalPrivileges | StringArray | システム権限リスト                      |
| objectPrivileges | Array       | オブジェクト権限リスト                      |
| ├─ dbObject      | Object      | データベースオブジェクト。詳細は下表のdbObjectパラメータ説明を参照してください。 |
| ├─ privileges    | StringArray | オブジェクトの権限リスト                     |
| grantedRoles     | StringArray | ロールが付与されたロール                    |
| userGrantees     | StringArray | このロールが付与されたユーザー                 |
| roleGrantees     | StringArray | このロールが付与されたロール                 |

dbObjectパラメータ説明

|     パラメータ     |   型   |                                                                                                               説明                                                                                                                |
|------------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| objectType | String | データベースオブジェクトタイプ。取り得る範囲： * TABLE テーブル   * VIEW ビュー    <!-- --> * STORED_PROCEDURE ストアドプロシージャ    |
| objectName | String | データベースオブジェクト名、つまりテーブル名、ビュー名、またはストアドプロシージャ名。                                                                                                                                                                                                           |
| schemaName | String | スキーマ名。通常、ユーザー名と同じです。                                                                                                                                                                                                              |

## 例

### リクエスト例

クラスタ1、テナント1000001でロールROLE1を作成します。

`POST /api/v2/ob/clusters/1/tenants/2000001/roles?id=1&tenantId=2000001`

```unknow
{

    "CREATE_TABLE",

    "ALTER_ANY_TABLE"
  ],
  "roles": [
    "PUBLIC",
    "CONNECT"
  ]
}
```
