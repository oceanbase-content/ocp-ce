# ユーザーへのロールの付与

## 機能の概要

ユーザーに付与するロールを指定します。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

* 呼び出し元は指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/users/{username}/grantRole`

### リクエストパラメータ

**pathパラメータ：**

|  パラメータ    |   型    | 必須 | サンプル値  |  説明   |
|----------|---------|-------|---------|-------|
| id       | Integer | はい  | 1    | クラスタID。 |
| tenantId | Integer | はい  | 5    | テナントID。 |
| username | String  | はい  | root | ユーザー名。   |

**bodyパラメータ：**

|  パラメータ |   型      | 必須 |    サンプル値     |      説明      |
|-------|-------------|-------|------------|------|
| roles | StringArray | はい  | \[R1, R2\] | 付与するシステム権限のリスト。    |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

クラスタ1、テナント1000001の下で、ユーザーUSER1にCONNECTロールを付与します。

`POST /api/v2/ob/clusters/1/tenants/2000001/users/USER1/grantRole?id=1&tenantId=2000001&username=USER1`

```json
{
  "roles": [
    "CONNECT"
  ]
}
```
