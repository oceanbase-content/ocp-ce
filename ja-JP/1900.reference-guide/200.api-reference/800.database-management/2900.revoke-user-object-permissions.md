# ユーザーのオブジェクト権限の取り消し

## 機能説明

ユーザーのオブジェクト権限を取り消します。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/users/{username}/revokeObjectPrivilege`

### リクエストパラメータ

pathパラメータ

|    パラメータ    |   型    | 必須 | サンプル値  |  説明   |
|----------|---------|----|------|-------|
| id       | Integer | はい  | 1    | クラスタID |
| tenantId | Integer | はい  | 5    | テナントID |
| username | String  | はい  | root | ユーザー名   |

bodyパラメータ

|        パラメータ        |     型      | 必須 |        サンプル値         |                                                                                                               説明                                                                                                                |
|------------------|-------------|----|--------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| objectPrivileges | Array       | はい  | --                 | 取り消すオブジェクト権限のリスト。                                                                                                                                                                                                                     |
| ├─ dbObject      | Object      | はい  | --                 | データベースオブジェクト。詳細については、dbObjectパラメータの説明を参照してください。                                                                                                                                                                                                      |
| ├─├─ objectType  | String      | はい  | TABLE              | データベースオブジェクトのタイプ。取り得る範囲： * TABLE テーブル   * VIEW ビュー    <!-- --> * STORED_PROCEDURE ストアドプロシージャ    |
| ├─├─ objectName  | String      | はい  | table1             | データベースオブジェクト名、つまりテーブル名、ビュー名、またはストアドプロシージャ名                                                                                                                                                                                                            |
| ├─├─ schemaName  | String      | はい  | USER1              | スキーマ名。通常、ユーザー名と同じです                                                                                                                                                                                                                |
| ├─ privileges    | StringArray | はい  | \[SELECT, UPDATE\] | オブジェクトの権限リスト                                                                                                                                                                                                                         |

dbObjectパラメータの説明

|     パラメータ     |   型   |  サンプル値   |                                                                                                               説明                                                                                                                |
|------------|--------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| objectType | String | TABLE  | データベースオブジェクトのタイプ。取り得る範囲： * TABLE テーブル   * VIEW ビュー    <!-- --> * STORED_PROCEDURE ストアドプロシージャ    |
| objectName | String | table1 | データベースオブジェクト名、つまりテーブル名、ビュー名。                                                                                                                                                                                                                  |
| schemaName | String | USER1  | スキーマ名。通常はユーザー名と同じです。                                                                                                                                                                                                              |

### 実行結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコードです。 |
| traceId    | String   | リクエストのトレースIDで、問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |
