# データベースユーザーのパスワードを変更する

## 機能の概要

データベースユーザーのパスワードを変更します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/users/{username}/changePassword`

### リクエストパラメータ

**pathパラメータ**

|    パラメータ    |   型    | 必須 | サンプル値  |  説明   |
|----------|---------|----|------|-------|
| id       | Integer | はい  | 1    | クラスタID |
| tenantId | Integer | はい  | 5    | テナントID |
| username | String  | はい  | root | ユーザー名   |
| hostName | String  | いいえ  | 33.47.251.%        | ホスト名 |

**bodyパラメータ**

|        パラメータ        |   型    | 必須 |  サンプル値   |             説明             |
|------------------|---------|----|--------|----------------------------|
| newPassword      | String  | はい  | xxxxxx | 新しいパスワード                        |

### 戻り値

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

クラスタ1、テナント1000001のユーザーuser1のパスワードを変更します。

`POST /api/v2/ob/clusters/1/tenants/1000001/users/user1/changePassword?id=1&tenantId=1000001&username=user1`

