# ユーザーのデータベース権限を変更する

## 機能の概要

このAPIは、ユーザーのデータベースに対する権限を変更するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/users/{username}/modifyDbPrivilege`

### リクエストパラメータ

**pathパラメータ**

|    パラメータ    |   型    | 必須 | サンプル値  |  説明   |
|----------|---------|-------|------|-------|
| id       | Integer | はい  | 1    | クラスタID |
| tenantId | Integer | はい  | 5    | テナントID |
| username | String  | はい  | root | ユーザー名   |
| hostName | String  | いいえ  | 33.47.251.%        | ホスト名 |

**bodyパラメータ**

|      パラメータ       |     型      | 必須 |       サンプル値        |      説明      |
|---------------|-------------|--------|------------------|--------------|
| dbPrivileges  | Array       | いいえ  | NA               | 変更後のデータベース権限リスト |
| ├─ dbName     | String      | はい  | db1              | データベース名         |
| ├─ privileges | StringArray | はい  | \[ALTER, INDEX\] | データベースの権限リスト     |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |
