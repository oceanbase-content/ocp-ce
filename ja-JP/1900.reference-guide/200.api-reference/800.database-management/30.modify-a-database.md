# データベースの変更

## 機能の概要

データベースを変更するために使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントの変更権限を持っている必要があります。

### リクエストパス

`PUT /api/v2/ob/clusters/{id}/tenants/{tenantId}/databases/{dbName}`

### リクエストパラメータ

pathパラメータ

|    パラメータ    |   型    | 必須 | サンプル値 |  説明   |
|----------|---------|----|-----|-------|
| id       | Integer | はい  | 1   | クラスタID |
| tenantId | Integer | はい  | 5   | テナントID |
| dbName   | String  | はい  | db1 | データベース名  |

bodyパラメータ

|     パラメータ      |   型    | 必須 |        サンプル値         |                                                                                                                                                                                                                                                    説明                                                                                                                                                                                                                                                    |
|-------------|---------|----|--------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| collation   | String  | いいえ  | utf8mb4_general_ci | 照合順序。値の範囲： <li> binary   </li> <li>utf8mb4   </li><li> gbk   </li><li> gb18030  </li> デフォルトはutf8mb4_general_ci。ORACLEテナントはこのパラメータをサポートしていません |
| readonly    | Boolean | はい  | false              | 読み取り専用かどうか                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

### 戻り値

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | データベースオブジェクト。データベースのデータ構造は下表を参照してください。    |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコード。 |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

データベースのデータ構造

|           パラメータ            |    型    |                                                                    説明                                                                     |
|-------------------------|----------|-------------------------------------------------------------------------------------------------------------------------------------------|
| dbName                  | String   | データベース名                                                                                                                                      |
| charset                 | String   | 文字セット                                                                                                                                       |
| collation               | String   | 照合順序                                                                                                                                       |
| primaryZone             | String   | ゾーンの優先順位                                                                                                                                  |
| readonly                | Boolean  | 読み取り専用かどうか                                                                                                                                      |
| createTime              | Datetime | 作成日時                                                                                                                                      |
| connectionUrls          | Array    | OBProxyと接続文字列のリスト                                                                                                                            |
| ├─ connectionStringType | String   | 接続文字列タイプ。取り得る範囲：<li> OBPROXY  </li><li> DIRECT 直接接続 </li>   |
| ├─ obProxyAddress       | String   | OBProxyアドレス。接続文字列タイプがOBPROXYの場合にのみ有効                                                                                           |
| ├─ obProxyPort          | Integer  | OBProxyポート。接続文字列タイプがOBPROXYの場合にのみ有効                                                                                           |
| ├─ connectionString     | String   | 接続文字列                                                                                                                                       |
| requiredSize            | Integer  | データベースのrequired_size                                                                                                                        |
| id                      | Integer  | データベースID                                                                                                                                   |

## 例

### リクエスト例

クラスタ1、テナント1000001配下のデータベースdb1を変更します。

`PUT /api/v2/ob/clusters/1/tenants/1000001/databases/db1?id=1&tenantId=1000001&dbName=db1`

```java
{
  "collation": "utf8mb4_general_ci",
  "readonly": false,
}
```
