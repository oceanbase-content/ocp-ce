# データベースリストの取得

## 機能説明

データベースリストを取得するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

* 呼び出し元は指定されたテナントに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/databases`

### リクエストパラメータ

**path:**

|    パラメータ    |   型    | 必須 | サンプル値 |  説明   |
|----------|---------|----|-----|-------|
| id       | Integer | はい  | 1   | OCP側のクラスタID。 |
| tenantId | Integer | はい  | 1000001   | OCP側のテナントID。 |

### 戻り結果

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   | リクエストされた業務データ。          |
| ├─ contents | Array    | データベースのリスト。詳細は**データベースデータ構造**を参照。    |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したサーバーのアドレス。          |

**データベースデータ構造**

|    パラメータ            |    型    |      説明       |
|-------------------------|----------|----------------------|
| dbName                  | String   | データベース名      |
| charset                 | String   | 文字セット      |
| collation               | String   | 照合順序         |
| primaryZone             | String   | Zoneの優先順位              |
| readonly                | Boolean  | 読み取り専用かどうか       |
| createTime              | Datetime | 作成時間        |
| connectionUrls          | Array    | OBProxyと接続文字列のリスト       |
| ├─ connectionStringType | String   | 接続文字列タイプ。取り得る範囲：<li>OBPROXY：OBProxy</li><li>DIRECT：直接接続</li>    |
| ├─ obProxyAddress       | String   | OBProxyアドレス。接続文字列タイプがOBPROXYの場合に有効です。       |
| ├─ obProxyPort          | Integer  | OBProxyポート。接続文字列タイプがOBPROXYの場合に有効です。     |
| ├─ connectionString     | String   | 接続文字列。        |
| ├─ forBinlogService     | Boolean  | Binlogサービスに対応するかどうか。        |
| requiredSize            | Integer  | データベースのrequired_size。       |
| id                      | Integer  | データベースのID。     |

## 例

### リクエスト例

クラスタ1、テナント1000001配下のデータベースリストを取得します。

`GET /api/v2/ob/clusters/1/tenants/1000001/databases?id=1&tenantId=1000001`
