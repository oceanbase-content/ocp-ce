# データベースオブジェクトリストの取得

## 機能の概要

データベースオブジェクトのリストを取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

呼び出し元は指定されたテナントに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/objects`

### リクエストパラメータ

パスパラメータ

|    パラメータ    |   型    | 必須 | サンプル値 |  説明   |
|----------|---------|----|-----|-------|
| id       | Integer | はい  | 1   | クラスタID |
| tenantId | Integer | はい  | 5   | テナントID |

### 戻り値

|     パラメータ      |    型    |           説明           |
|-------------|----------|------------------------|
| data        | Object   | contentsを含みます。           |
| ├─ contents | Array    | データベースオブジェクトのリスト。データベースオブジェクトのデータ構造は下表を参照してください。 |
| successful  | Boolean  | リクエストが成功したかどうかを示します。                |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプです。           |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。        |
| status      | Integer  | HTTPステータスコード。  |
| traceId     | String   | リクエストのTrace IDで、問題の調査に使用されます。   |
| server      | String   | リクエストに応答したサーバーのアドレスです。           |

データベースオブジェクトのデータ構造

|     パラメータ     |   型   |                                                                                                               説明                                                                                                                |
|------------|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| objectType | String | データベースオブジェクトのタイプ。取り得る範囲： * TABLE テーブル   * VIEW ビュー    <!-- --> * STORED_PROCEDURE ストアドプロシージャ    |
| objectName | String | データベースオブジェクト名。テーブル名、ビュー名、またはストアドプロシージャ名です。                                                                                                                                                                                                           |
| schemaName | String | スキーマ名。通常、ユーザー名と同じです。                                                                                                                                                                                                              |

## 例

### リクエスト例

クラスタ1、テナント1000001の下のオブジェクトリストを取得します。

`GET /api/v2/ob/clusters/1/tenants/2000001/objects?id=1&tenantId=2000001`
