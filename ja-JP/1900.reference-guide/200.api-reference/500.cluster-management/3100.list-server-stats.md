# クラスタ内のすべてのOBServerノードのリソース統計情報を取得する

## 機能説明

このAPIは、クラスタ内のすべてのOBServerノードのリソース統計情報を取得するために使用されます。

## 呼び出し説明

### API制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/serverStats`

### リクエストパラメータ

**path:**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|------|-----------|------|-----|-----------|
|  id        |  Integer  |  はい  |  -   | クラスタID。  |

### 戻り値

**基本データ構造**

|  パラメータ    |  型      | 説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **ServerResourceStatsのデータ構造** を参照してください。 |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題のトラブルシューティングに使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

**ServerResourceStatsのデータ構造**

|  パラメータ                 |  型     |  説明     |
|-----------------------|-----------|----------|
|  ip                   |  String   |  OBServer IP。  |
|  port                 |  Integer  |  OBServerポート番号。  |
|  zone                 |  String   |  ゾーン名。  |
|  partitionCount       |  Long     |  パーティション数（全レプリカ数ではなく、リーダーレプリカ数）。  |
|  timestamp            |  Long     |  タイムスタンプ。  |
|  unitCount            |  Long     |  Unit数。  |
|  cpuTotal             |  Number   |  CPU総量。  |
|  cpuAssigned          |  Number   |  CPU割り当て量。  |
|  cpuTotalMin          |  Double   |  オーバーコミットを有効にした場合にのみ確認が必要です。実際のCPU総量を表します。  |
|  cpuTotalMax          |  Double   |  オーバーコミットを有効にした場合にのみ確認が必要です。オーバーコミット後のCPU総量、すなわち実際のCPU総量 × オーバーコミット率を表します。  |
|  cpuAssignedMin       |  Double   |  オーバーコミットを有効にした場合にのみ確認が必要です。CPUの最小割り当て量、すなわちすべてのテナントの最小CPU割り当て量の合計を表します。  |
|  cpuAssignedMax       |  Double   |  オーバーコミットを有効にした場合にのみ確認が必要です。CPUの最大割り当て量、すなわちすべてのテナントの最大CPU割り当て量の合計を表します。  |
|  memoryTotalByte      |  Long     |  メモリ総量、単位はbyteです。  |
|  memoryAssignedByte   |  Long     |  メモリ割り当て量、単位はbyteです。  |
|  logDiskTotalByte     |  Long     |  ログディスクの総容量、単位はbyteです。  |
|  logDiskAssignedByte  |  Long     |  ログディスクの割り当て量、単位はbyteです。  |
|  logDiskUsedByte      |  Long     |  ログディスクの使用量、単位はbyteです。  |
|  dataDiskTotalByte    |  Long     |  データディスクの総容量、単位はbyteです。  |
|  dataDiskUsedByte     |  Long     |  データディスクの使用量、単位はbyteです。  |
|  systemMemoryByte     |  Long     |  テナント500のシステムメモリ、単位はbyteです。  |
