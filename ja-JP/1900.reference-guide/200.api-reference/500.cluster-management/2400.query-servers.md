# OceanBaseクラスタのOBServerノードの一覧を取得する

## 機能の概要

このAPIは、対象となるOceanBaseクラスタのすべてのOBServerノード情報を取得するために使用されます。

## 呼び出しの説明

### インターフェース制約

* ユーザーは、対象となるOceanBaseクラスタに対する読み取り専用権限が付与されている必要があります。

  ユーザー権限の詳細については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* ユーザーはOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{clusterId}/servers`

### リクエストパラメータ

|     パラメータ     |   型    | 必須 |   サンプル値   |        説明        |
|------------|---------|----|---------|------------------|
| clusterId  | Integer | はい  | 1       | 対象クラスタのID。        |
| regionName | String  | いいえ  | Beijing | 指定したリージョン内のOceanBaseサーバーを照会します。 |
| idcName    | String  | いいえ  | AZ1     | 指定したデータセンター内のOceanBaseサーバーを照会します。 |

### 戻り値

**基本データ構造**

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   | リクエストされた業務データ。              |
| ├─ contents | Array    | 詳細は**サーバー情報のデータ構造**を参照してください。     |
| successful  | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp   | Datetime | サーバー側がリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバー側がリクエストを処理した時間(ミリ秒)。       |
| status      | Integer  | HTTPステータスコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**サーバーのデータ構造**

|         パラメータ          |     型      |    説明                  |
|---------------------|-------------|------------|
| id                  | Integer     | サーバーのID。             |
| ip                  | String      | サーバーのIPアドレス。           |
| port                | Integer     | サーバーのRPCポート。           |
| sqlPort             | Integer     | サーバーのSQLポート。         |
| runUser             | String      | OSユーザー。      |
| runPath             | String      | 実行パス。      |
| installPath         | String      | インストールパス。      |
| version             | String      | サーバーのOceanBaseバージョン。        |
| withRootServer      | Boolean     | Root Serviceの有無。        |
| status              | String      | サーバーの状態。値の範囲：<li>CREATING：作成中。</li><li>RUNNING：実行中。</li><li>STOPPING：停止中。</li><li>STOPPED：停止済み。</li><li>STARTING：起動中。</li><li>RESTARTING：再起動中。</li><li>DELETING：削除中。</li><li>UNAVAILABLE：利用不可。OPERATING：運用中。</li><li>DELETED：削除済み。</li>    |
| updateTime          | Datetime    | サーバーの最終更新時刻。          |
| innerStatus         | Enum        | OceanBase内部状態。値の範囲：<li>ACTIVE</li><li>INACTIVE</li><li>DELETING</li><li>TAKEOVER_BY_RS</li>      |
| clusterId           | Integer     | サーバーが属するクラスタのID。          |
| zoneName            | String      | サーバーが属するゾーンの名前。        |
| regionName          | String      | サーバーが属するリージョンの名前。          |
| idcName             | String      | サーバーが属するデータセンターの名前。          |
| hostId              | Integer     | サーバーのホストID。         |
| hostTypeName        | String      | サーバーのホストタイプ。        |
| hostStatus          | Enum  | ホストの状態。値の範囲：<li>NEW。</li><li>ONLINE：現在サービスを実行中。</li><li>OFFLINE：現在アクセスできません - 接続できません。</li><li>AGENT_RESTARTING：Agentの再起動状態。</li><li>AGENT_REINSTALLING：Agentの再インストール状態。</li><li>SHUTDOWN：シャットダウン。</li><li>DELETING：削除。</li><li>AVAILABLE：アクセス可能。</li>      |
| startTime           | Datetime    | サーバーの起動時間。            |
| stopTime            | Datetime    | サーバーの停止時間。       |
| availableOperations | StringArray | サーバーの利用可能な操作リスト。           |
| arbitrationStatus   | Enum  | OceanBaseのアービトレーションサービスの接続状況。OceanBase V4.2.0.0以降でのみサポートされます。値の範囲：<li>ACTIVE</li><li>INACTIVE</li>     |
| onlineCpuCoreRange  | String  | OceanBaseのCPUコア範囲。      |
