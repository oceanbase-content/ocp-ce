# アービトレーションサービスグループの更新

## 機能の概要

指定したアービトレーションサービスグループの情報を変更します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、アービトレーションサービスリストに含まれるすべてのアービトレーションサービスに対する **ARBITRATION:UPDATE** 権限を持っている必要があります。

### リクエストパス

`PATCH /api/v2/arbitration/services/groups/{id}`

### リクエストパラメータ

**path：**

|  パラメータ                   |  型     | 必須   | サンプル値      |  説明   |
|-------------------------|-----------|--------|-------------|----------|
|  id                     | Long      |  はい    |  1    | 更新対象のアービトレーションサービスグループID。  |

**body：**

|  パラメータ                    |  型        | 必須   | サンプル値      |  説明   |
|--------------------------|--------------|--------|-------------|----------|
|  name                     | String      |  はい    |  group_a    | アービトレーションサービスグループ名。  |
|  arbitrationServiceIdList | List<Long>  |  はい    |  21,22      | グループ内のアービトレーションサービスIDのリスト。IDは半角カンマで区切ります。  |
|  autoReplace              | Boolean     |  はい    |  true       | 自動切り替えを有効にするかどうか。  |
|  autoReplaceStrategy      | Object      |  はい    |  -          | 詳細については、**自動切り替えポリシー**を参照してください。  |
|  description              | String      |  いいえ    |  arbitrationServiceGroup  | 備考情報。  |

**自動切り替えポリシー：**

|  パラメータ             |  型   | 説明   |
|-------------------|---------|---------|
|  strategyType     | String  | 自動切り替えポリシーのタイプ。  |
|  threshold        | Integer | 閾値。**strategyType**によって異なります。<li>UNIT_COUNT：個数</li><li>UNIT_PERCENTAGE：割合</li><li>DEFAULT：空</li>  |
|  duration         | Long    | 持続時間（秒単位）。0はトリガー条件が発生したら即座に切り替えることを意味します。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  型      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **アービトレーションサービスグループ情報** を参照してください。             |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコードです。            |
|  traceId     |  String    | リクエストのTrace IDで、問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**アービトレーションサービスグループ情報**

|  パラメータ                 |  型            |  説明                               |

|  arbitrationServices  |  List<Object>    |  詳細は **グループ内のアービトレーションサービス一覧** を参照してください。  |

|  updateTime           |  OffsetDateTime  |  最終変更日時。  |

**自動切り替えポリシー**

|  パラメータ             |  型   |  説明   |
|-------------------|---------|---------|
|  strategyType     | String  | 自動切り替えポリシーのタイプ。  |

|  duration         | Long    | 持続時間、秒単位。0はトリガー条件が即座に切り替わることを意味します。  |
