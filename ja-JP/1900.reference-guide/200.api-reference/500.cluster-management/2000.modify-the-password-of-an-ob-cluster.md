# OceanBaseクラスタのパスワードを変更する

## 機能の概要

このAPIは、対象となるOceanBaseクラスタのsysテナントの管理者パスワードを変更するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、対象となるOceanBaseクラスタに対する更新権限を持っている必要があります。

  呼び出し元の権限については、[ユーザーおよび権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/changePassword`

**パス：**

| パラメータ |   型    | 必須 | サンプル値 |    説明     |
|----|---------|----|-----|-----------|
| id | Integer | はい  | 1   | 対象クラスタのID。 |

### リクエストパラメータ

|        パラメータ        |   型    | 必須 | サンプル値  |    説明     |
|------------------|---------|----|------|-----------|
| newPassword      | String  | はい  | foo  | 新しいパスワード。      |

### 戻り結果

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス          |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1/changePassword`
