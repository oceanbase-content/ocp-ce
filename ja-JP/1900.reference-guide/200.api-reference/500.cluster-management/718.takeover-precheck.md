# OceanBaseクラスタの引き継ぎ前チェック

## 機能の概要

このインターフェースは、OceanBaseクラスタの移行前に事前チェックを行うために使用されます。この操作はオプションですが、移行をスムーズに進めるために、OceanBaseクラスタの移行前に必ず事前チェックを実行することを推奨します。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、OceanBaseクラスタの引き継ぎ権限を持っている必要があります。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過する必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/takeOverPreCheck`

### リクエストパラメータ

**Bodyパラメータ：**

|     パラメータ        |   型  | 必須 |    サンプル値        |   説明    |
|-----------------|---------|-----|-------------------|-----------|
| rootSysPassword | String  | はい  | ******            | root@sysのパスワード。 |
| address         | String  | はい  | xxx.xxx.xxx.xxx   | クラスタ接続アドレス。 |
| port            | Integer | はい  | 2881              | クラスタ接続ポート。 |
| connectionMode  | String  | いいえ  | direct            | 接続モード。`direct`または`proxy`を指定できます。デフォルトは`direct`です。 |
| clusterName     | String  | いいえ  | ob01              | 接続モードが`proxy`の場合は必須です。 |
| obClusterId     | Integer | いいえ  | 1001              | 接続モードが`proxy`で、かつ引き継ぐクラスタがスタンバイクラスタの場合は必須です。 |
| vpcName         | String  | いいえ  | xxx               | VPC名。 |
| vpcId           | Long    | いいえ  | 1L                | VPC ID。 |
| proxyroPassword | String  | いいえ  | ******            | proxyro@sysユーザーのパスワード。 |
| saveToCredential | Boolean | いいえ | true              | パスワードボックスに保存するかどうか。 |
