# OceanBaseクラスタの起動

## 機能説明

このAPIは、OceanBaseクラスタを起動するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、OceanBaseクラスタを起動する権限を持っている必要があります。

  呼び出し元の権限については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/start`

**path：**

| パラメータ |  タイプ  | 必須 | サンプル値 |          説明           |
|----|------|----|-----|-----------------------|
| id | Long | はい  | 1   | 起動するOceanBaseクラスタのID |

### 戻り値

基本データ構造

|     パラメータ     |    タイプ    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したコード。                                            |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1/start`
