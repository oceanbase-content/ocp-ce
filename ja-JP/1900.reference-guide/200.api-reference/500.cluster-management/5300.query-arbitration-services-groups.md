# アービトレーションサービスグループ情報の取得

## 機能の概要

指定されたアービトレーションサービスグループの情報を取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、アービトレーションサービスリストに含まれるすべてのアービトレーションサービスに対する読み取り専用権限を持っている必要があります。

### リクエストパス

`GET /api/v2/arbitration/services/groups/{id}`

### リクエストパラメータ

**path：**

|  パラメータ          |  型     | 必須   | サンプル値      |  説明   |
|----------------|-----------|--------|-------------|----------|
|  id            | Long      |  はい    |  1    | 更新対象のアービトレーションサービスグループID。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  型      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **アービトレーショングループ情報** を参照してください。             |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコードです。            |
|  traceId     |  String    | リクエストのTrace IDで、問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**アービトレーショングループ情報**

|  パラメータ                 |  型            |  説明                               |
|-----------------------|------------------|----------------------------------|
|  id                   |  Long            |  アービトレーショングループIDです。  |
|  name                 |  String          |  アービトレーショングループ名です。  |
|  autoReplace          |  Boolean         |  自動切り替えを有効にするかどうかを示します。  |
|  autoReplaceStrategy  |  Object          |  詳細は **自動切り替えポリシー** を参照してください。  |
|  arbitrationServices  |  List<Object>    |  詳細は **グループ内のアービトレーションサービス一覧** を参照してください。  |
|  description          |  String          |  備考です。  |
|  updateTime           |  OffsetDateTime  |  最終変更日時です。  |

**自動切り替えポリシー**

|  パラメータ             |  型   |  説明   |
|-------------------|---------|---------|
|  strategyType     | String  | 自動切り替えポリシーのタイプです。  |
|  threshold        | Integer | 閾値。**strategyType** によって異なります。<li>UNIT_COUNT：個数</li><li>UNIT_PERCENTAGE：パーセンテージ</li><li>DEFAULT：空</li>  |
|  duration         | Long    | 持続時間、秒単位です。0はトリガー条件が発生したら即座に切り替えることを意味します。  |

**グループ内のアービトレーションサービス一覧**

|   パラメータ                    |  型          |  説明   |
|---------------------------|----------------|---------|
|  id                       |  Long          |  アービトレーションサービスIDです。  |
|  hostId                   |  Long          |  アービトレーションサービスが配置されているホストIDです。  |
|  svrIp                    |  String        |  アービトレーションサービスが配置されているホストのIPアドレスです。  |
|  svrPort                  |  Integer       |  アービトレーションサービスのサービスポートです。  |
|  status                   |  String        |  アービトレーションサービスの状態です。  |
|  groupId                  |  Long          |  所属するアービトレーショングループIDです。  |
|  groupName                |  String        |  所属するアービトレーショングループ名です。  |
|  priority                 |  Integer       |  アービトレーションサービスのサービスグループ内での優先順位です。  |
|  operatingTaskInstanceId  |  Long          |  運用中のタスクIDです。  |
|  statusAnalysis           |  Object        |  詳細は **異常状態の原因分析** を参照してください。  |
|  version                  |  String        |  アービトレーションサービスのバージョンです。  |
|  installPath              |  String        |  アービトレーションサービスのインストールディレクトリです。  |
|  runPath                  |  String        |  アービトレーションサービスの実行ディレクトリ。  |
|  runUser                  |  String        |  アービトレーションサービスの実行ユーザー。  |
|  architecture             |  String        |  アービトレーションサービスが配置されているホストのアーキテクチャ情報。  |
|  description              |  String        |  アービトレーションサービスの説明。  |
|  clusters                 |  List<Object>    |  詳細については、**アービトレーションサービス関連のクラスタ情報**を参照してください。  |
|  createTime               |  OffsetDateTime  |  アービトレーションサービスの作成日時。  |
|  updateTime               |  OffsetDateTime  |  アービトレーションサービスの変更日時。  |
|  startupParameters        |  Object          |  詳細については、**アービトレーションサービス起動パラメータ**を参照してください。  |
|  tags                     |  List<Object>    |  タグ情報。  |

**異常状態の原因分析**

|   パラメータ             |  型            |  説明   |
|--------------------|------------------|---------|
|  startTime         |  OffsetDateTime  |  状態開始時間。  |
|  reason            |  String  |  状態の発生原因。  |
|  action            |  String  |  解決策。  |
|  reasonType        |  String  |  状態の発生原因タイプ。  |
|  diagnosisType     |  String  |  診断タイプ。  |
|  diagnosisContent  |  Object  |  診断内容。  |

**アービトレーションサービス関連のクラスタ情報**

|   パラメータ         |  型            |  説明   |
|----------------|------------------|---------|
|  id            |  Long            |  クラスタID。  |
|  name          |  String          |  クラスタ名。  |
|  obClusterId   |  Long            |  クラスタ内部ID。  |
|  status        |  String          |  クラスタの状態。  |
|  tags          |  List<Object>    |  詳細については、**タグ情報**を参照してください。  |
|  tenants       |  List<Object>    |  詳細については、**クラスタ内のテナント情報**を参照してください。  |

**クラスタ内のテナント情報**

|   パラメータ              |  型        |  説明   |
|---------------------|--------------|---------|
|  id                 |  Long        |  テナントID。  |
|  name               |  String      |  テナント名。  |
|  obTenantId         |  Long        |  OceanBase内部テナントID。  |
|  arbitrationStatus  |  String      |  アービトレーションの状態。  |
|  degradedLsIdList   |  List<Long>  |  ダウングレードされたログストリームのIDリスト。  |

**アービトレーションサービス起動パラメータ**

|  パラメータ   |  型    |  説明   |
|---------|----------|---------|
|  name   |  String  |  パラメータ名。  |
|  value  |  String  |  パラメータ値。  |

**タグ情報**

|  パラメータ   |  型          |  説明   |
|---------|----------------|---------|
|  id     |  Long          |  タグID。  |
|  key    |  String        |  タグのキー。  |
|  value  |  String        |  タグの値。  |
|  refs   |  List<Object>  |  詳細は**タグリソース一覧**を参照してください。  |

**タグリソース一覧**

|   パラメータ         |  型    |  説明   |
|----------------|----------|---------|
|  id            |  Long    |  タグID。  |
|  name          |  String  |  タグ名。  |
|  resourceType  |  String  |  リソースタイプ。  |
