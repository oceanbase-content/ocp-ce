# OceanBaseクラスタのリソース統計情報を取得する

## 機能説明

このAPIは、OceanBaseクラスタのリソース統計情報を取得するために使用されます。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/stats`

### リクエストパラメータ

**path:**

|  パラメータ  |  型  |  必須  | サンプル値 |  説明  |
|------|-----------|------|-----|------------|
|  id        |  Integer  |  はい  | 1   |  クラスタID。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  型      | 説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **ClusterResourceStatsのデータ構造** を参照してください。 |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

**ClusterResourceStatsのデータ構造**

|  パラメータ                 |  型     |  説明  |
|-----------------------|-----------|----------|
|  clusterId            |  Integer  |  クラスタID。  |
|  clusterName          |  String   |  クラスタ名。  |
|  obClusterId          |  Integer  |  OceanBase側のクラスタID。  |
|  clusterType          |  String   |  クラスタタイプ。値の範囲：<li>PRIMARY：プライマリクラスタ。</li><li>STANDBY：スタンバイクラスタ。</li> |
|  syncStatus           |  Enum     |  プライマリ/スタンバイ同期状態。値の範囲：<li>VALID：有効な状態。</li><li>DISABLED：データ同期を禁止した状態。</li><li>DISABLED_WITH_READ_ONLY：読み取り専用状態。</li><li>SYNCHRONIZING：同期中(OceanBase側では現在この状態は存在しません)。</li><li>UNKNOWN：不明な状態。</li> |
|  tenantCount          |  Long     |  テナント数。 |
|  unitCount            |  Long     |  Unit数。 |
|  cpuTotal             |  Number   |  CPU総数。  |
|  cpuAssigned          |  Number   |  CPU割り当て量。  |
|  cpuTotalMin          |  Double   |  オーバーコミットが有効な場合にのみ確認が必要です。実際のCPU総数を表します。 |
|  cpuTotalMax          |  Double   |  オーバーコミットが有効な場合にのみ確認が必要です。オーバーコミット後のCPU総数、すなわち実際のCPU総数 × オーバーコミット率を表します。 |
|  cpuAssignedMin       |  Double   |  オーバーコミットが有効な場合にのみ確認が必要です。CPUの最小割り当て量、すなわちすべてのテナントの最小CPU割り当て量の合計を表します。 |
|  cpuAssignedMax       |  Double   |  オーバーコミットが有効な場合にのみ確認が必要です。CPUの最大割り当て量、すなわちすべてのテナントの最大CPU割り当て量の合計を表します。 |
|  memoryTotalByte      |  Long     |  メモリ総量、単位はbyteです。  |
|  memoryAssignedByte   |  Long     |  メモリ割り当て量、単位はbyteです。  |
|  logDiskTotalByte     |  Long     |  ログディスクの総容量、単位はbyteです。  |
|  logDiskAssignedByte  |  Long     |  ログディスクの割り当て量、単位はbyteです。  |
|  logDiskUsedByte      |  Long     |  ログディスクの使用量、単位はbyteです。  |
|  dataDiskTotalByte    |  Long     |  データディスクの総容量、単位はbyteです。  |
|  dataDiskUsedByte     |  Long     |  データディスクの使用量、単位はbyteです。  |
|  systemMemoryByte     |  Long     |  テナント500のシステムメモリ、単位はbyteです。 |
