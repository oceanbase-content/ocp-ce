# OceanBaseクラスタのゾーンを新規作成

## 機能説明

このAPIは、OceanBaseクラスタにゾーンを追加するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、対象のOceanBaseクラスタに対する管理権限を持っている必要があります。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/zones`

**path：**

| パラメータ |   型    | 必須 | サンプル値 |    説明     |
|----|---------|----|-----|-----------|
| id | Integer | はい  | 1   | 対象クラスタのID。 |

### リクエストパラメータ

|      パラメータ                |  型  | 必須 | サンプル値 |    説明    |
|--------------------------|--------|-----|---------|----------|
| name                     | String | はい  | foo     | ゾーン名。   |
| idcName                  | String | はい  | idc1    | データセンター名。      |
| servers                  | Array  | はい  | \[1,2\] | ホストIDのリスト。 |
| architecture             | String | いいえ  | x86_64  | CPUアーキテクチャ。 |
| packageOperatingSystem   | String | いいえ  | xx      | クラスタソフトウェアパッケージのOS。未入力の場合、デフォルトでクラスタ設定が使用されます。 |
| startupParameters Object | Object | いいえ  | -       | 起動パラメータ。 |
| ├─name                   | String | いいえ  | -       | パラメータ名。 |
| ├─value                  | String | いいえ  | -       | パラメータ値。 |
| addReplicaParams         | Array  | いいえ  | -       | テナントレプリカ設定関連パラメータ。 |
| ├─zoneName               | String | はい  | zone1   | ゾーン名。 |
| ├─replicaType            | Enum   | はい  | FULL    | レプリカタイプ。 |
| ├─resourcePool           | Object | はい  | -       | リソースプール情報。 |
|   ├─unitSpecName         | String | はい  | S1      | ユニット仕様名。 |
|   ├─unitCount            | Long   | はい  | 1L      | Unit数。 |
| ├─tenantId               | Long   | はい  | 1L      | テナントID。 |
| ├─tenantName             | String | いいえ  | tenant1 | テナント名。 |

### 実行結果

**基本データ構造**

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTPステータスコードです。                                            |
| traceId    | String   | リクエストのトレースIDであり、問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1/zones`

body:

```json
{
  "name": "zone2",
  "idcName": "hz2",
  "servers": [
    1
  ]
}
```
