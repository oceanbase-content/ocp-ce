# OceanBaseクラスタの作成

## 機能の概要

このAPIは、OceanBaseクラスタを作成するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元には、OceanBaseクラスタを作成する権限が付与されていなければなりません。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters`

### リクエストパラメータ

**body：**

|    パラメータ       |  タイプ   | 必須 |    サンプル値     |     説明          |
|---------------|---------|-----|---------------|---------|
| name          | String  | はい  | foo           | クラスタ名。     |
| vpcName       | String  | いいえ  | -             | このパラメータは廃止されました。今後のバージョンで削除されます。     |
| vpcId         | Long    | いいえ  | 1L            | クラスタが存在するVPCのIDです。クラシックネットワークでは値は1に設定します。スタンバイクラスタ作成時は、このフィールドは無効です。     |
| obClusterId   | Integer | いいえ  | 1L            | OceanBaseクラスタID。     |
| fullVersion   | String  | いいえ  | 4.3.3.0-200000142024073011   | 対象バージョンの完全なバージョン番号。     |
| rpmName       | String  | はい  | oceanbase-2.2.76-20210219154519.el7.x86_64.rpm | RPMパッケージ名。        |
| type          | String  | はい  | PRIMARY       | クラスタタイプ。取り得る範囲：<li>PRIMARY</li><li>STANDBY</li>   |
| password      | String  | はい  | bar           | クラスタのsysテナント内rootアカウントのパスワード。      |
| primaryZone   | String  | いいえ  | Zone1         | Zoneの優先順位。 |
| zones         | Object  | はい  | -             | Zoneの情報。    |
| ├─name            | String  | はい  | zone1         | Zone名。       |
| ├─idcName         | String  | はい  | idc1          | データセンター名。       |
| ├─servers         | Array   | はい  | \[1,2\]       | ホストIDのリスト。     |
| ├─architecture    | String  | いいえ  | x86_64        | ソフトウェアパッケージがサポートするシステムアーキテクチャ。     |
| ├─rpmName         | String  | いいえ  | oceanbase-3.2.0-20210813141857.el7.x86_64.rpm   | RPMパッケージ名。     |
| ├─rootServer      | Long    | いいえ  | -             | Root Server。     |
| startupParameters | Array   | いいえ  | -             | 起動パラメータ。     |
| ├─name            | String  | いいえ  | -             | パラメータ名。     |
| ├─value           | String  | いいえ  | -             | パラメータ値。     |
| obproxyClusterIds     | Array  | いいえ  | [1,2]   | 関連するOBProxyクラスタIDのリスト。     |
| obproxyClusterKeyList | Array  | いいえ  | -       | マルチクラスタモードで有効です。OBProxyクラスタのリスト。     |
| ├─ocpClusterId        | Long   | いいえ  | 1L      | OBProxyクラスタが属するOCPクラスタID。     |
| ├─obproxyClusterId    | Long   | いいえ  | 1L      | OBProxyクラスタID。     |
| obproxyUserName       | String | いいえ  | proxyro | OBProxyユーザー名。     |
| obproxyUserPassword   | String | いいえ  | ******  | proxyroユーザーのパスワード。指定しない場合、OCPがランダムに生成します(マルチクラウドシナリオでのみ使用)。     |
| attributes            | Object | いいえ  | -       | クラスタ属性。     |
| ├─installPath         | String | いいえ  | `/home/admin/oceanbase`   | クラスタのインストールパス。     |
| ├─runPath             | String | いいえ  | `/home/admin/oceanbase`   | 実行パス。     |
| ├─dataDiskPath        | String | いいえ  | `/data/1`                 | データディスクのパス。     |
| ├─logDiskPath         | String | いいえ  | `/data/log1`              | ログディスクのパス。     |
| ├─diskPathStyle       | Enum   | いいえ  | DEAULT                    | <li>OBD</li><li>DEFAULT</li>     |
| ├─operatingSystemUser | String | いいえ  | admin                     | ホストOSのユーザー。     |
| ├─svrPort             | Integer| いいえ  | 2882                      | RPCポート番号。    |
| primaryClusterInfo  | Object   | いいえ   | -   | プライマリクラスタ情報。    |
| ├─rootSysPassword   | String   | いいえ   | ******    | root@sysユーザーのパスワード。    |
| ├─obClusterId       | Long     | いいえ   | 1L  | OceanBaseクラスタID。    |
| ├─vpcName           | String   | いいえ   | -   | OceanBaseクラスタが属するVPC名。    |
| ├─vpcId             | Long     | いいえ   | 1L  | OceanBaseクラスタが属するVPCのID。    |
| arbitrationServiceId  | Long      | いいえ   | 1L    | アービトレーションサービスID。    |
| oversellingFactor     | Integer   | いいえ   | 100   | リソースオーバーコミット係数。[100, 200]の範囲で、オーバーコミット率[100%, 200%]を表します。デフォルト値は100で、オーバーコミットを行わないことを意味します。    |
| cgroupEnabled         | Boolean   | いいえ   | true  | クラスタでCgroupが有効になっているかどうか。無効の場合、テナント内のリソース制限は適用されません。このパラメータはOceanBase V4.0以降のバージョンでのみ有効です。    |
| createExtraTenant     | Boolean   | いいえ   | false   | スタンドアロンモードで新しいテナントを作成するかどうかを選択します。    |
| supportObsBackup      | Boolean   | いいえ   | false   | Huawei Cloud OBSに基づくバックアップ・リストアをサポートするかどうか。    |
| simplifiedCreateTenantParam   | Object   | いいえ   | -   | シングルゾーン構成でテナントを作成するための簡略化パラメータ。    |
| ├─name   | String   | いいえ   | -   | テナント名。    |
| ├─mode   | Enum   | いいえ   | MYSQL   | テナントモード。<li>ORACLE</li><li>MYSQL</li>の範囲で指定します。    |
| loadType    | Enum    | いいえ  | EXPRESS_OLTP  | ロードタイプ。<li>EXPRESS_OLTP</li><li>COMPLEX_OLTP</li><li>HTAP</li><li>OLAP</li><li>KV</li>の範囲で指定します。 |
| jvmEnvConfig       | Object  | いいえ  | -   | JVM環境依存サービスの設定情報。   |
| ├─jvmEnvServices   | Array   | はい  | <li>ODPS_EXTERNAL_TABLE</li><li>HDFS_EXTERNAL_TABLE</li><li>JAVA_UDF</li><li>ODPS_CATALOG</li><li>MYSQL_PLUGIN</li>  | 環境依存サービス。   |
| ├─maxJvmMemoryGiB  | Integer | はい  | 1   | ユーザー入力の最大メモリサイズ。単位はGiBです。  |
| ├─javaHomePath     | String  | はい  | `/usr/local/java/jdk-17.0.8`  | JAVA_HOMEのパス。   |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                                    |
