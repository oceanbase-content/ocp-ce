# JVM環境依存サービスの開始

## 機能の概要

クラスタでJVM環境依存サービスを有効にします。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、OceanBaseクラスタを引き継ぐ権限が必要です。

  呼び出し元の権限については、詳細は [ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md) を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過する必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/startJvmDepsService`

### リクエストパラメータ

**path：**

|  パラメータ            |  型     | 必須   | サンプル値  |  説明   |
|------------------|-----------|--------|--------|----------|
|  id              | Long      |  はい    |  160   | 対象クラスタのOCP側のID。  |

**body：**

|  パラメータ            |  型     | 必須   | サンプル値  |  説明   |
|------------------|-----------|--------|--------|----------|
| jvmEnvServices   | Array     |  はい     | ODPS External Table,HDFS External Table,Java UDF,ODPS Catalog,MySQL Plugin  | 環境依存サービス。値の範囲：<li>ODPS_EXTERNAL_TABLE</li><li>HDFS_EXTERNAL_TABLE</li><li>JAVA_UDF</li><li>ODPS_CATALOG</li><li>MYSQL_PLUGIN</li>。  |
| maxJvmMemoryGiB  | Integer   |  はい     | 1                              | ユーザー入力の最大メモリサイズ。単位はGiB。 |
| javaHomePath     | String    |  はい     | `/usr/local/java/jdk-17.0.8`   | JAVA_HOMEのパス。   |
| restartMode      | String    |  はい     | FORCE                          | リスタート方式。値の範囲：<li>FORCE</li><li>ROLLING</li>   |
| freezeServer     | Boolean   |  はい     | true                           | プロセス停止前にダンプ操作を実行するかどうか。値の範囲：<li>true</li><li>false</li>   |

### 戻り結果

**基本データ構造**

|  パラメータ        |  型      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細は [タスク戻り構造](../400.task-return-structure.md) を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコードに準拠したエンコードです。            |
|  traceId     |  String    | リクエストのトレースIDで、問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |
