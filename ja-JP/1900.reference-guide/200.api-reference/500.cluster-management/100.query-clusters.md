# OceanBaseクラスタリストの取得

## 機能の概要

このAPIは、OCPが管理するOceanBaseクラスタ情報を照会するために使用されます。

クエリ範囲は、クラスタ名のキーワードやクラスタの状態などの条件で絞り込むことができます。プライマリ/スタンバイデプロイメントモードの場合、返される結果にはプライマリクラスタとスタンバイクラスタの両方が含まれており、その属性からクラスタのロールを確認できます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は少なくともCLUSTER_VIEWERロールである必要があります。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters`

### リクエストパラメータ

|     パラメータ      |     型      | 必須 |       サンプル値        |  説明     |
|-------------|-------------|----|------------------|-------------|
| page        | Integer     | いいえ  | 1                | リクエストデータのページ番号です。値は1から始まり、デフォルト値：1です。    |
| size        | Integer     | いいえ  | 10               | リクエストデータのページングサイズです。デフォルト値：10、最大値：2000。     |
| sort        | String      | いいえ  | name,asc         | リクエストデータのソート規則です。    |
| name        | String      | いいえ  | foo              | クラスタ名のキーワードです。大文字小文字を区別せずに一致します。    |
| status      | StringArray | いいえ  | CREATING,RUNNING | クラスタの状態です。取り得る範囲：<li>RUNNING：実行中。</li><li>CREATING：作成中。</li><li>DELETING：削除中。</li><li> STARTING：起動中。</li><li>RESTARTING：再起動中。</li><li> STOPPING：停止中。</li><li>STOPPED：停止済み。</li><li> TAKINGOVER：引き継ぎ中。</li><li>MOVINGOUT：移出中。</li><li> SWITCHOVER：プライマリ/スタンバイクラスタ切り替え中。</li><li>FAILOVER：スタンバイクラスタの障害回復中。</li><li>OPERATING：運用中。</li>    |
| withRemote  | Enum        | いいえ  | NONE             | リモートOCP配下のOceanBaseクラスタを含むかどうかです。取り得る範囲：<li>NONE：取得しない。</li><li>ALL：すべてを取得する。</li><li>RELATED：このOCPとプライマリ/スタンバイ関係にあるものを取得する。</li>    |
| foldStandby | -           | -   | -                | 現在は廃止されており、今後のバージョンでこのパラメータは削除されます。   |
