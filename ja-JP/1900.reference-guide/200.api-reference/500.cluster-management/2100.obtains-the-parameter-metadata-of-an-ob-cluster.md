# OceanBaseクラスタパラメータの説明情報を取得する

## 機能の概要

このAPIは、OceanBaseクラスタのパラメータ説明情報を取得するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、少なくともOceanBaseクラスタに対する読み取り専用権限を持っている必要があります。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過する必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/parameterInfo`

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Array    | 詳細は **ParameterInfoデータ構造** を参照してください。     |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**ParameterInfoデータ構造**

|         パラメータ          |   型    |       説明       |
|---------------------|---------|--------------------|
| name                | String  | パラメータ名。   |
| version             | String  | OceanBaseクラスタのバージョン。          |
| section             | String  | パラメータのグループ。   |
| type                | String  | パラメータタイプ。取り得る範囲：<li>BOOL</li><li>CAPACITY</li><li>DOUBLE</li><li>INT</li><li>MOMENT</li><li>STRING</li><li>STRING_LIST</li><li>TIME</li>    |
| parameterType       | Enum    | クラスタパラメータのタイプ。取り得る範囲：<li>OB_CLUSTER_PARAMETER：OceanBaseクラスタ構成パラメータ。</li><li>OB_TENANT_PARAMETER：OceanBaseテナント構成パラメータ。</li>旧バージョンの動作との互換性のため、指定しない場合はデフォルトでOB_CLUSTER_PARAMETERとなります。  |
| editionCompatibleType  | Enum  | パラメータが互換可能なリリース。取り得る範囲：<li>ALL：商用版とコミュニティ版の両方に適用されます。</li><li>COMMERCIAL：商用版にのみ適用されます。</li><li>COMMUNITY：コミュニティ版にのみ適用されます。</li>  |
| allowedStringValues | String  | パラメータの選択可能な文字列。        |
| maxValue            | String  | パラメータの最大値。            |
| minValue            | String  | パラメータの最小値。       |
| valueRange          | Object  | クラスタパラメータとテナントパラメータの取り得る範囲。   |
| ├─type              | String  | 値の範囲タイプ。   |
| ├─allowedValues     | String  | 許可される値の範囲。`type`がENUMの場合に有効です。カンマ区切りで指定します（例：`TRUE,FALSE`）。   |
| ├─maxValue          | String  | 最大値。   |
| ├─minValue          | String  | 最小値。   |
| defaultValue        | String  | パラメータのデフォルト値。            |
| needRestart         | Boolean | リスタートが必要かどうかを示します。          |
| readonly            | Boolean | 読み取り専用かどうかを示します。          |
| description         | String  | パラメータの説明。     |
