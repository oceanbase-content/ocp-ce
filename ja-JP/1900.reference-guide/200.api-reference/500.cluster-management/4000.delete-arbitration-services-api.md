# アービトレーションサービスの削除

## 機能説明

指定されたアービトレーションサービスを削除します。

## 呼び出し説明

### インターフェース制約

呼び出し元はアービトレーションサービスに対する **ARBITRATION:DELETE** 権限が付与されていなければなりません。

### リクエストパス

`DELETE /api/v2/arbitration/services/{id}/delete`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  id              | Long     |  はい    | 4901         | 削除するアービトレーションサービスID。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細については、[タスク戻り値構造](../400.task-return-structure.md)を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコードです。            |
|  traceId     |  String    | リクエストのTrace IDで、問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

## 例

### リクエスト例

`DELETE /api/v2/arbitration/services/4192/delete`
