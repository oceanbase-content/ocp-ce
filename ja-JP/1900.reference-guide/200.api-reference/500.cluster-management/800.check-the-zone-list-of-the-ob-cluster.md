# OceanBaseクラスタのゾーンリストを照会する

## 機能の概要

このAPIは、OceanBaseクラスタのゾーンリストを照会するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、OceanBaseクラスタを参照する権限が必要です。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過する必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/zones`

**path:**

| パラメータ |   型    | 必須 | サンプル値 |               説明               |
|----|---------|----|-----|--------------------------------|
| id | Integer | はい  | 100 | ゾーンリストを照会するOceanBaseクラスタのID。 |

### 戻り値

**基本データ構造**

|        パラメータ        |    型    |          説明           |
|------------------|----------|-----------------------|
| data             | Object   | リクエストされたデータ。                |
| ├─ contents      | Object   | 詳細は**Zoneデータ構造**を参照してください。   |
| ├─ page          | Object   | ページネーション情報。                 |
| ├─ totalElements | Integer  | 総レコード数。                 |
| ├─ totalPages    | Integer  | 総ページ数。                  |
| ├─ number        | Integer  | 現在のページ番号。                 |
| ├─ size          | Integer  | 現在のページサイズ。                |
| successful       | Boolean  | リクエストが成功したかどうか。               |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration         | Integer  | サーバーがリクエストを処理した時間(ミリ秒)。       |
| status           | Integer  | HTTPステータスコード。 |
| traceId          | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server           | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**Zoneデータ構造**

|     パラメータ      |   型    |        説明        |
|-------------|---------|------------------|
| name        | String  | ゾーン名。           |
| idcName     | String  | 所属IDC名。            |
| regionName  | String  | 所属リージョン。             |
| servers     | Object  | 詳細は **Serverデータ構造** を参照してください。        |
| clusterId   | Long    | マシンID。            |
| obClusterId | Long    | OceanBaseクラスタのID。 |
| serverCount | Integer | Server数。         |
| hostCount   | Integer | ホスト数。              |
| architecture | String | CPUアーキテクチャ。          |
| status      | Enum    | ゾーンの状態。値の範囲：<li>RUNNING：実行中。</li><li>UNAVAILABLE：利用不可。</li><li>SERVICE_STOPPED：サービスが停止されています。</li><li>STOPPED：停止済み。</li><li>DELETED：削除済み。</li><li>CREATING：作成中（運用保守の中間状態）。</li><li>STOPPING：停止中（運用保守の中間状態）。</li><li>STARTING：起動中（運用保守の中間状態）。</li><li>RESTARTING：再起動中（運用保守の中間状態）。</li><li>DELETING：削除中（運用保守の中間状態）。</li><li>OPERATING：運用中（運用保守の中間状態）。</li>    |
| innerStatus | Enum    | OceanBase ゾーンの内部状態。内部テーブル`__all_zone status`の値。値の範囲：<li>ACTIVE</li><li>INACTIVE</li>  |
| compactionStatus  | Enum  | メジャーコンパクションの状態。値の範囲：<li>IDLE：アイドル状態。</li><li>MERGING：メジャーコンパクション中。</li><li>INDEXING：インデックス作成中。MERGING後にINDEXが実行されます。OceanBase V2.2以降ではINDEX状態は使用されなくなりました。</li><li>ERROR：エラー状態。</li><li>TIMEOUT：タイムアウト状態。</li><li>MOST_MERGED：メジャーコンパクション完了。</li>    |
| rootServer  | Object  | Root Serverのリスト。          |

**Serverデータ構造**

|       パラメータ       |    型    |       説明        |
|----------------|----------|-----------------|
| id             | String   | OBserver ID。    |
| ip             | String   | OBserver IP。    |
| port           | Integer  | ポート。              |
| sqlPort        | Integer  | SQLポート。           |
| runUser        | String   | オペレーティングシステムユーザー。    |
| runPath        | String   | 実行パス。    |
| installPath    | String   | インストールパス。    |
| version        | String   | バージョン。              |
| withRootserver | Boolean  | Root Serviceを含むかどうか。 |
| status         | String   | ステータス。              |
| innerStatus    | Enum     | OceanBaseの内部状態。値の範囲：<li>ACTIVE</li><li>INACTIVE</li><li>DELETING</li><li>TAKEOVER_BY_RS</li>    |
| clusterId      | Long     | 所属クラスタID。          |
| zoneName       | String   | 所属ゾーン名。        |
| regionName     | String   | 所属リージョン。            |
| idcName        | String   | 所属IDC。            |
| hostId         | Long     | 対応するホストID。          |
| hostTypeName   | String   | マシンタイプ名。            |
| hostStatus     | Enum     | ホストの状態。値の範囲：<li>NEW。</li><li>ONLINE：現在サービスが実行中です。</li><li>OFFLINE：現在アクセスできません - 接続できません。</li><li>AGENT_RESTARTING：Agentの再起動状態。</li><li>AGENT_REINSTALLING：Agentの再インストール状態。</li><li>SHUTDOWN：シャットダウン。</li><li>DELETING：削除。</li><li>AVAILABLE：アクセス可能。</li>    |
| startTime      | DateTime | 起動時間。            |
| stopTime       | DateTime | 停止時間。            |
| arbitrationStatus  | Enum  | OceanBaseのアービトレーションサービスの接続状況。OceanBase V4.2.0.0以降でのみサポートされます。値の範囲：<li>ACTIVE</li><li>INACTIVE</li>   |
| onlineCpuCoreRange  | String | OceanBaseのCPUコア範囲。    |
