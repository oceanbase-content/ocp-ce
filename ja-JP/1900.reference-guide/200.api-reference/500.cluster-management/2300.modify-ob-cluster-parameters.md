# OceanBaseクラスタパラメータの変更

## 機能説明

このAPIは、対象となるOceanBaseクラスタのパラメータを変更するために使用します。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、対象となるOceanBaseクラスタに対する更新権限を持っている必要があります。

  呼び出し元の権限について詳細は、[ユーザーおよび権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`PUT /api/v2/ob/clusters/{id}/parameters`

### リクエストパラメータ

**path：**

| パラメータ |   型    | 必須 | サンプル値 |    説明     |
|------|---------|------|------|-----------|
| id | Integer | はい  | 1   | 対象クラスタのID。 |

**body：**

|            パラメータ          |  型   | 必須 | サンプル値 |                    説明                     |
|--------------------------|-------|------|------|-------------------------------------------|
| SetClusterParameterParam | Array | はい  | NA  | 詳細は **SetClusterParameterParamデータ構造** を参照してください。 |

**SetClusterParameterParamデータ構造**

|  パラメータ         |  型  | 必須 |  説明  |
|---------------|--------|------|------|
| name          | String | はい  | パラメータ名。 |
| value         | String | はい  | パラメータ値。 |
| parameterType | Enum   | いいえ  | クラスタパラメータのタイプ。取り得る範囲：<li>OB_CLUSTER_PARAMETER：OceanBaseクラスタ構成パラメータ。</li><li>OB_TENANT_PARAMETER：OceanBaseテナント構成パラメータ。</li>旧バージョンの動作との互換性のため、指定しない場合はデフォルトでOB_CLUSTER_PARAMETERとなります。 |
| zones         | List<String>  | いいえ  | 有効なZoneのリストを指定します。`servers`と同時に指定することはできません。`zones`と`servers`の両方を指定しない場合、すべてのZoneに適用されます。 |
| servers       | List<String>  | いいえ  | 有効なOBServerのリストを指定します。`zones`と同時に指定することはできません。`zones`と`servers`の両方を指定しない場合、すべてのOBServerに適用されます。 |
| tenants       | List<String>  | いいえ  | 有効なテナントのリストを指定します。`parameterType`がOB_TENANT_PARAMETERの場合にのみ有効です。 |

### 実行結果

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）です。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコードです。 |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |

## 例

### リクエスト例

`PUT /api/v2/ob/clusters/1/parameters`

**body：**

* Zone範囲で有効：

  ```json
  {
  "name": "enable_rereplication",
  "value": "false",
  "parameterType": "OB_CLUSTER_PARAMETER",
  "zones": [
    "zone1"
    ]
  }
  ```

* Server範囲で有効：

  ```json
  {
  "name": "enable_rereplication",
  "value": "false",
  "parameterType": "OB_CLUSTER_PARAMETER",
  "servers": [
    "xx.xx.xx.xx:xx"
    ]
  }
  ```

* クラスタ範囲で有効：

  ```json
  [
  {
    "name": "enable_rereplication",
    "value": "True",
    "parameterType": "OB_CLUSTER_PARAMETER"
  }
  ]
  ```
