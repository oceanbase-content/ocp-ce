# OceanBaseクラスタの移出

## 機能の概要

このAPIは、OceanBaseクラスタを移出するために使用されます。このAPIを直接呼び出すと、クラスタの資格情報が失われるため、事前にクラスタの資格情報ファイルをエクスポートしてから、OceanBaseクラスタを移出することを推奨します。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、OceanBaseクラスタを移出する権限を持っている必要があります。

  呼び出し元の権限については、詳細は [ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md) を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/moveOut`

### リクエストパラメータ

**Pathパラメータ：**

|     パラメータ        |   型  | 必須 |       サンプル値     |   説明    |
|-----------------|---------|-----|-------------------|-----------|
| id              | Long    | はい  |    1              | 移出対象のOceanBaseクラスタID。 |

**Bodyパラメータ：**

|     パラメータ               |   型  | 必須 |  サンプル値  |   説明    |
|------------------------|---------|------|---------|-----------|
| deleteHost             | Boolean | いいえ   | true    | クラスタ移出時にそのクラスタ下のすべてのホストも同時に削除するかどうかを示します。 |
| deleteHostIds          | Array   | いいえ   | [1,2]   | 削除するホストIDのリスト。 |
| skipOperationHostIds   | Array   | いいえ   | [1,2]   | オペレーションをスキップするホストIDのリスト（ホスト異常時に使用）。 |
| force                  | Boolean | いいえ   | false   | クラスタの移出とホストの削除を強制的に実行するかどうかを示します（メタデータのみ削除）。デフォルトは`false`で、マルチクラウド環境での使用を前提としています。 |
| retainClusterInfo      | Boolean | いいえ   | false   | クラスタ情報を保持するかどうかを示します。`true`の場合、OCPはConfig Serverサービスで使用するためにクラスタ情報を保持します。 |
| targetConfigAddress    | String  | いいえ   | http://xxx.xxx.xxx.xxx:xxx   | クラスタ移出時にそのクラスタに指定する新しいConfig Serverアドレス。形式は `http://xxx.xxx.xxx.xxx:xxx`。` |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したコードです。                                            |
| traceId    | String   | 問題の調査に使用されるリクエストのTrace IDです。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                                    |
