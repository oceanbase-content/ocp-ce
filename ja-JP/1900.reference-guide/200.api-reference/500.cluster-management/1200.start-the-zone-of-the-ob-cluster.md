# OceanBaseクラスタのZone起動

## 機能説明

このAPIは、対象のOceanBaseクラスタのZoneを起動するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、対象のOceanBaseクラスタに対する管理権限を持っている必要があります。

  呼び出し元の権限については、[ユーザーおよび権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/zones/{zoneName}/start`

**path：**

|    パラメータ    |   型    | 必須 | サンプル値 |    説明     |
|----------|---------|----|-----|-----------|
| id       | Integer | はい  | 1   | 対象クラスタのID。 |
| zoneName | String  | はい  | 1   | Zone名。   |

### 戻り結果

基本データ構造

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。                                            |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |

### リクエスト例

`POST /api/v2/ob/clusters/1/zones/zone2/start`
