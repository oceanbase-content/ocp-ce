# アービトレーションサービス一覧の取得

## 機能の概要

すべてのアービトレーションサービスの情報リストを取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、少なくともアービトレーションサービスの読み取り専用権限を持っている必要があります。

### リクエストパス

`GET /api/v2/arbitration/services`

### リクエストパラメータ

**path:**

|  パラメータ    |  型           |  必須   |  サンプル値    |  説明     |
|--------------|---------------|-------|--------------|----------|
|  hostId      | Long          | いいえ  | 1002         | アービトレーションサービスが存在するホストID。 |
|  keyword     | String        | いいえ  | arbitration  | キーワード。       |
|  statusList  | List<String>  | いいえ  | RUNNING,UNAVAILABLE,STOPPED      | アービトレーションサービスの状態リスト。 |
|  tagIdList   | List<Long>    | いいえ  | 1,2,3        | タグのリスト。 |

### 戻り値

**基本データ構造**

|  パラメータ    |  型          | 説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">アービトレーションサービス一覧</UI-TERM>** を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコードです。            |
|  traceId     |  String    | リクエストのTrace IDで、問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">アービトレーションサービス一覧</UI-TERM>**

|  パラメータ                     |  型           | 説明                               |
|---------------------------|-----------------|----------------------------------|
|  contents                 | List<Object>    | 詳細は **アービトレーションサービス情報** を参照してください。  |
|  page                     | Page            | 詳細は **ページネーションパラメータ** を参照してください。  |

**アービトレーションサービス情報**

|  パラメータ                     |  型           | 説明                               |
|---------------------------|-----------------|----------------------------------|
|  id                       | Long            | アービトレーションサービスID。  |
|  hostId                   | Long            | アービトレーションサービスが配置されているホストID。  |
|  svrIp                    | String          | アービトレーションサービスが配置されているホストのIPアドレス。  |
|  svrPort                  | Integer         | アービトレーションサービスのサービスポート。  |
|  status                   | String          | アービトレーションサービスの状態。  |
|  groupId                  | Long            | 所属するアービトレーションサービスグループID。  |
|  groupName                | String          | 所属するアービトレーションサービスグループ名。  |
|  priority                 | Integer         | サービスグループ内でのアービトレーションサービスの優先順位。  |
|  operatingTaskInstanceId  | Long            | 運用中のタスクID。  |
|  statusAnalysis           | Object          | 詳細は **異常状態の原因分析** を参照してください。  |
|  version                  | String          | アービトレーションサービスのバージョン。  |
|  installPath              | String          | アービトレーションサービスのインストールディレクトリ。  |
|  runPath                  | String          | アービトレーションサービスの実行ディレクトリ。  |
|  runUser                  | String          | アービトレーションサービスの実行ユーザー。  |
|  architecture             | String          | アービトレーションサービスが配置されているホストのアーキテクチャ情報。  |
|  description              | String          | アービトレーションサービスの説明。  |
|  clusters                 | List<Object>    | 詳細は **アービトレーションサービス関連クラスタ情報** を参照してください。  |
|  createTime               | OffsetDateTime  | アービトレーションサービスの作成日時。  |
|  updateTime               | OffsetDateTime  | アービトレーションサービスの更新日時。  |
|  startupParameters        | Object          | 詳細は **アービトレーションサービス起動パラメータ** を参照してください。  |
|  tags                     | List<Object>    | タグ情報。  |

**異常状態の原因分析**

|  パラメータ              |  型          |  説明          |
|--------------------|----------------|----------------|
|  startTime         | OffsetDateTime | ステータス開始時刻。  |
|  reason            | String         | ステータス発生の原因。  |
|  action            | String         | 解決策。  |
|  reasonType        | String         | ステータス発生原因のタイプ。  |
|  diagnosisType     | String         | 診断タイプ。  |
|  diagnosisContent  | Object         | 診断内容。  |

**アービトレーションサービス関連クラスタ情報**

|  パラメータ          |  タイプ         |  説明        |
|----------------|---------------|--------------|
|  id            | Long          | クラスタID。  |
|  name          | String        | クラスタ名。  |
|  obClusterId   | Long          | クラスタ内部ID。  |
|  status        | String        | クラスタ状態。  |
|  tenants       | List<Object>  | 詳細は**クラスタ内のテナント情報**を参照してください。  |
|  tags          | List<Object>  | 詳細は**タグ情報**を参照してください。  |

**クラスタ内のテナント情報**

|  パラメータ              |  タイプ        |  説明        |
|--------------------|--------------|--------------|
|  id                | Long         | テナントID。  |
|  name              | String       | テナント名。  |
|  obTenantId        | Long         | OceanBase内部テナントID。  |
|  arbitrationStatus | String       | アービトレーションステータス。  |
|  degradedLsIdList  | List<Long>   | ダウングレードされたログストリームIDのリスト。  |

**タグ情報**

|  パラメータ     |  タイプ        |  説明        |
|-----------|--------------|--------------|
|  id       | Long         | タグID。  |
|  key      | String       | タグのキー。  |
|  value    | String       | タグの値。  |
|  refs     | List<Object> | 詳細は**タグリソース一覧**を参照してください。  |

**タグリソース一覧**

|  パラメータ          |  タイプ        |  説明        |
|----------------|--------------|--------------|
|  id            |  Long        |  タグID。   |
|  name          |  String      |  タグ名。    |
|  resourceType  |  String      |  リソースタイプ。  |

**アービトレーションサービス起動パラメータ**

|  パラメータ          |  タイプ    |  説明     |
|----------------|----------|----------|
| name           | String   | パラメータ名。  |
| value          | String   | パラメータ値。  |

**ページネーションパラメータ**

|  パラメータ          |  タイプ     |  説明     |
|----------------|-----------|----------|
| number         | Integer   | ページ番号。  |
| size           | Integer   | 1ページあたりのサイズ。  |
| totalElements  | Integer   | 総レコード数。  |
| totalPages     | Integer   | 総ページ数。  |
