# アービトレーションサービスグループの削除

## 機能の概要

指定されたアービトレーションサービスグループを削除します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、アービトレーションサービスリスト内のすべてのアービトレーションサービスに対する **ARBITRATION:UPDATE** 権限を持っている必要があります。

### リクエストパス

`DELETE /api/v2/arbitration/services/groups/{id}`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ     | 必須   | サンプル値  |  説明   |
|------------------|-----------|--------|--------|----------|
|  id              | Long      |  はい    |  1     | 削除するアービトレーションサービスグループID。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

## 例

### リクエスト例

`DELETE /api/v2/arbitration/services/groups/1`
