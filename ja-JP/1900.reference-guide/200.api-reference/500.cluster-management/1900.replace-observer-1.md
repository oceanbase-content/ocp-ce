# OBServerノードの置換

## 機能の概要

このAPIは、対象となるOceanBaseクラスタ内のOBServerノードを置き換えるために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、対象となるOceanBaseクラスタに対する更新権限を持っている必要があります。

  呼び出し元の権限については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/servers/{serverId}/replace`

**path：**

|    パラメータ    |   型    | 必須 | サンプル値 |         説明          |
|----------|---------|----|-----|---------------------|
| id       | Integer | はい  | 1   | 対象クラスタのID。           |
| serverId | Integer | はい  | 1   | 置き換えるOBServerノードのID。 |

### リクエストパラメータ

|   パラメータ                 |   型  | 必須  | サンプル値 |   説明    |
|------------------------|---------|------|-------|---------|
| hostId                 | Integer | はい   | 1     | ホストのID。 |
| skipHostOperation      | Boolean | いいえ   | false | ホストの運用をスキップするかどうか（ホスト異常時に使用）。 |
| packageOperatingSystem | String  | いいえ   | xx    | クラスタソフトウェアパッケージのOS。未入力の場合、デフォルトでクラスタ設定が使用されます。 |
| startupParameters      | Array   | いいえ   | -     | 起動パラメータ。 |
| ├─name                 | String  | いいえ   | -     | パラメータ名。 |
| ├─value                | String  | いいえ   | -     | パラメータ値。 |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | 非同期タスク情報。               |
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）です。       |
| status     | Integer  | HTTPステータスコードに準拠したエンコードです。 |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1/servers/{serverId}/replace`

body:

```json
{
  "hostId": 1
}
```
