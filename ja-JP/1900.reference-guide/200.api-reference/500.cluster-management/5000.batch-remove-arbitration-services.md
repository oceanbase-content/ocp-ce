# クラスタの関連付けの一括解除

## 機能説明

OceanBaseクラスタからアービトレーションサービスを一括で解除します。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は対象アービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が付与されていなければなりません。
* 呼び出し元は、クラスタIDリスト内のすべてのクラスタに対する **CLUSTER:UPDATE** 権限が付与されていなければなりません。

### リクエストパス

`POST /api/v2/ob/clusters/batchRemoveArbitration`

### リクエストパラメータ

**body：**

|  パラメータ                    |  型        | 必須   | サンプル値      |  説明   |
|--------------------------|--------------|--------|-------------|----------|
|  arbitrationServiceId    | Long         |  はい    |  25         | 対象アービトレーションサービスID。  |
|  clusterIdList           | List<Long>   |  はい    |  83,84      | アービトレーションサービスを解除するOceanBaseクラスタのIDリスト。クラスタIDは半角カンマで区切ります。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  型      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。             |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコードです。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/batchRemoveArbitration`

```JSON
{
  "arbitrationServiceId":25,
  "clusterIdList":[83,84]
}
```
