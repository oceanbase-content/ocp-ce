# 一括置換アービトレーションサービスの事前チェック

## 機能説明

OceanBaseクラスタのアービトレーションサービスを一括置き換えるための事前チェックを実行します。

## 呼び出し説明

### インターフェース制約

* 呼び出し元には、対象アービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が付与されていなければなりません。
* 呼び出し元には、クラスタIDリスト内のすべてのクラスタに対する **CLUSTER:UPDATE** 権限が付与されていなければなりません。

### リクエストパス

`POST /api/v2/ob/clusters/batchReplaceArbitrationPreCheck`

### リクエストパラメータ

**body：**

|  パラメータ                    |  型        | 必須   | サンプル値      |  説明   |
|--------------------------|--------------|--------|-------------|----------|
|  arbitrationServiceId    | Long         |  はい    |  1          | 対象アービトレーションサービスID。  |
|  clusterIdList           | List<Long>   |  はい    |  83,84      | 置き換えるアービトレーションサービスを持つOceanBaseクラスタのIDリスト。クラスタIDは半角カンマで区切ります。  |

### 戻り結果

**基本データ構造**

|  パラメータ        |  型      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **事前チェック結果** を参照してください。              |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコードです。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**事前チェック結果**

|  パラメータ         |  型         |  説明               |
|---------------|---------------|--------------------|
|  valid        |  Boolean      |  チェックが成功したかどうかを示します。   |
|  checkResults |  List<Object> |  詳細については、**エラーメッセージ一覧**を参照してください。   |

**エラーメッセージ一覧**

|  パラメータ          |  型      |  説明        |
|----------------|------------|------------------|
|  errorCode     |  String    |  エラーコード。  |
|  args          |  Object[]  |  エラーコードのパラメータ。  |
|  errorMessage  |  String    |  国際化されたエラーメッセージ。  |
|  extraInfo     |  Object    |  追加情報。  |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/batchReplaceArbitrationPreCheck`

```JSON
{
  "clusterIdList":[83,84],
  "arbitrationServiceId":21
}
```
