# フェイルオーバーの事前チェック

## 機能の概要

フェイルオーバーの事前チェックでは、プライマリクラスタとスタンバイクラスタの現在の状態を確認し、OceanBaseクラスタのフェイルオーバーを正常に実行できるかどうかを判断します。

## 呼び出しの説明

### インターフェース制約

なし。

### リクエストパス

`POST /api/v2/ob/clusters/{id:[\\d]+}/failoverPreCheck`

### リクエストパラメータ

なし。

### 戻り値

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   | スイッチオーバーの事前チェック結果。    |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

### フェイルオーバーの事前チェック結果

|  パラメータ   |     型    |   説明    |
|-------|-------------|--------|
| clusterId           | Long        | OceanBaseクラスタID。   |
| clusterName         | String      | OceanBaseクラスタ名。  |
| result              | Object      | チェック結果の詳細。    |

### チェック結果の詳細

|  パラメータ   |     型    |   説明    |
|-------|-------------|--------|
| valid               | Boolean        | チェックに合格したかどうか。   |
| messages            | List<String>   | エラーメッセージのリスト。  |
