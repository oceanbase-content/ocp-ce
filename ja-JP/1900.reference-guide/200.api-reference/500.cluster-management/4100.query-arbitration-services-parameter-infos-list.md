# アービトレーションサービスのパラメータ情報リストを取得する

## 機能説明

アービトレーションサービスのパラメータ情報リストを取得します。

## 呼び出し説明

### インターフェース制約

呼び出し元は、アービトレーションサービスに対する読み取り専用権限を少なくとも持っている必要があります。

### リクエストパス

`GET /api/v2/arbitration/services/parameterInfos`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  name            | String   |  いいえ    | foo          | パラメータ名。  |
|  version         | String   |  いいえ    | 4.2.0.0      | OceanBaseクラスタのバージョン。  |

### 戻り結果

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **アービトレーションサービスのパラメータ情報リスト** を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

**アービトレーションサービスのパラメータ情報リスト**

|  パラメータ            |  タイプ      |  説明                               |
|------------------|------------|----------------------------------|
|  id              |  Long     |  パラメータメタ情報ID。    |
|  name            |  String   |  パラメータ名。    |
|  version         |  String   |  OceanBaseクラスタのバージョン。    |
|  valueRange      |  Object   |  詳細については、**<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.ValidValues">値の範囲</UI-TERM>**を参照してください。    |
|  defaultValue    |  String   |  デフォルト値。    |
|  recommendValue  |  String   |  推奨値。    |
|  description     |  String   |  説明。    |
|  needRestart     |  Boolean  |  再起動が必要かどうか。    |
|  readonly        |  Boolean  |  読み取り専用かどうか。    |

**<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.ValidValues">値の範囲</UI-TERM>**

|  パラメータ           |  型    |  説明                               |
|-----------------|----------|----------------------------------|
|  type           |  String  |  値の範囲のタイプ。   |
|  allowedValues  |  String  |  許可される値の範囲。**type**が`ENUM`の場合に有効です。複数の値はカンマで区切ります（例：`TRUE,FALSE`）。   |
|  maxValue       |  String  |  最大値。   |
|  minValue       |  String  |  最小値。   |
