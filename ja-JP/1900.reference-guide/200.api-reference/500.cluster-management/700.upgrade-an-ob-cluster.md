# OceanBaseクラスタのアップグレード

## 機能説明

このAPIは、OceanBaseクラスタをアップグレードするために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、OceanBaseクラスタをアップグレードする権限を持っている必要があります。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/upgrade`

**path：**

| パラメータ |  種類  | 必須 | サンプル値 |          説明           |
|----|------|----|-----|-----------------------|
| id | Long | はい  | 1   | アップグレード対象のOceanBaseクラスタID。 |

### リクエストパラメータ

|     パラメータ        |   種類  | 必須  |     サンプル値     |   説明    |
|-----------------|---------|-------|---------------|---------|
| upgradeMode     | Enum    | はい    | ROLLING       | アップグレードモード。デフォルトはローリングアップグレード。取り得る範囲：<li>ROLLING：ローリングアップグレード。</li><li>ORDINARY：通常アップグレード（サービス停止の可能性あり）。</li> |
| destVersion     | String  | はい    | 2.2.77-202204041221 | ターゲットバージョン。 |
| zoneRpmList     | Array   | はい    | -             | ゾーンのターゲットソフトウェアパッケージリスト。  |
| ├─zoneNameList  | Array   | はい    | zone1,zone2,zone3   | Zone名。 |
| ├─rpmName       | String  | はい    | oceanbase-4.4.0.0-100000682023020119.el7.x86_64.rpm    | RPMパッケージ名。 |
| ├─packageOperatingSystem | String | はい  | el8       | ソフトウェアパッケージのOS。 |
| operatingSystem | String  | はい    | el7           | 現在は廃止されており、今後のバージョンでこのパラメータは削除されます。 |
| freezeServer    | Boolean | いいえ    | false         | Serverを停止する前にダンプが必要かどうか。 |
| zoneOrder       | Array   | いいえ    | [zone1,zone2] | プライマリクラスタをアップグレードする際のZoneのアップグレード順序。 |

### 戻り結果

**基本データ構造**

|     パラメータ     |    種類    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したコードです。                                            |
| traceId    | String   | 問題の調査に使用されるリクエストのTrace IDです。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/22/upgrade`

body:

```json
{
  "upgradeMode": "ROLLING",
  "destVersion": "4.3.5-2024024041221",
  "zoneRpmList": [
    {
      "zoneNameList": [
        "zone1,zone2,zone3"
      ],
      "rpmName": "oceanbase-4.4.0.0-100000682023020119.el7.x86_64.rpm",
      "packageOperatingSystem": "el8"
    }
  ],
  "freezeServer": false,
  "zoneOrder": [
    "[zone1,zone2]"
  ]
}
```
