# OBServerノードの追加

## 機能の概要

このAPIは、対象のOceanBaseクラスタにOBServerノードを追加するために使用します。

## 呼び出しの説明

### インターフェース制約

* ユーザーは対象のOceanBaseクラスタに対する管理権限が付与されていなければなりません。

  ユーザー権限の詳細については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* ユーザーはOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/servers`

**path：**

| パラメータ |  種類   | 必須 | サンプル値 |          説明          |
|------|---------|-----|-----|----------------------|
| id   | Integer | はい  | 1   | 対象OceanBaseクラスタのID。 |

### リクエストパラメータ

|    パラメータ                |  種類  | 必須 | サンプル値  |    説明     |
|------------------------|--------|-----|---------|-----------|
| zoneName               | String | はい  | foo     | ゾーン名。   |
| servers                | Array  | はい  | \[1,2\] | ホストIDのリスト。 |
| packageOperatingSystem | String | いいえ  | xxx     | クラスタソフトウェアパッケージのOS。未入力の場合、デフォルトでクラスタ設定が使用されます。   |
| startupParameters      | Object | いいえ  | -       | OBServerの起動パラメータ。クラスタの起動パラメータを上書きします。   |
| ├─name                 | String | いいえ  | -       | パラメータ名。   |
| ├─value                | String | いいえ  | -       | パラメータ値。   |

### 戻り値

**基本データ構造**

|     パラメータ     |    種類    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTPステータスコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1/servers`

body:

```json
{
  "zoneName": "zone2",
  "servers": [
    1
  ]
}
```
