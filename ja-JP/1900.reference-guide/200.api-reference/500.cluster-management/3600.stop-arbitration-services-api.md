# アービトレーションサービスの停止

## 機能の概要

指定したアービトレーションサービスを停止します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、アービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が付与されている必要があります。

### リクエストパス

`POST /api/v2/arbitration/services/{id}/stop`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  id              | Long     |  はい    | 4901         | 停止するアービトレーションサービスのID。  |

**body：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  clientToken     | String   |  いいえ    | aBCDefGHIjk     | 冪等リクエストのトークンです。長さは8～64文字で、グローバルに一意である必要があります。 |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細については、[タスク戻り構造](../400.task-return-structure.md)を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコードです。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |
