# アービトレーションサービスグループのアップグレード

## 機能の概要

指定したアービトレーションサービスグループをアップグレードします。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、アービトレーションサービスリスト内のすべてのアービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が付与されている必要があります。

### リクエストパス

`POST /api/v2/arbitration/services/groups/{id}/upgrade`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ     | 必須   | サンプル値  |  説明   |
|------------------|-----------|--------|--------|----------|
|  id              | Long      |  はい    |  1     | アップグレード対象のアービトレーションサービスグループID。  |

**body：**

|  パラメータ            |  タイプ     | 必須   | サンプル値  |  説明   |
|------------------|-----------|--------|--------|----------|
|  fullVersion     | String    |  はい     | 4.3.3.0-200000142024073011  |  ターゲットバージョンの完全なバージョン番号（アーキテクチャサフィックスのない `.rpm` ファイル）。 |
|  operatingSystem | String    |  はい     | el7   |  クラスタソフトウェアパッケージのOS。  |

### 戻り結果

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細については、[タスク戻り構造](../400.task-return-structure.md)を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコードです。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

## 例

### リクエスト例

`POST /api/v2/arbitration/services/groups/1/upgrade`

```JSON
{
  "fullVersion": "4.3.4.0-200000022024070119",
  "operatingSystem": "el7"
}
```
