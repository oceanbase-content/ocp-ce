# アービトレーションサービスの引き継ぎ

## 機能の概要

アービトレーションサービスがデプロイされているホストを選択して引き継ぎます。選択したホストは、既にOceanBaseクラスタがデプロイされているホストであってはなりません。

## 呼び出しの説明

### インターフェース制約

呼び出し元はアービトレーションサービスの **ARBITRATION:CREATE** 権限を持っている必要があります。

### リクエストパス

`POST /api/v2/arbitration/services/takeOver`

### リクエストパラメータ

**body：**

|  パラメータ          |  タイプ     | 必須   | サンプル値     |  説明   |
|----------------|-----------|--------|------------|----------|
|  hostId        | Long      |  はい    |  1          | アービトレーションサービスが配置されているホストID。  |
|  svrPort       | Integer   |  はい    |  2883       | アービトレーションサービスのサービスポート。  |
|  description   | String    |  いいえ    |  takeover   |  説明情報。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **アービトレーションサービス情報** を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

**アービトレーションサービス情報**

|  パラメータ                     |  タイプ           | 説明                               |
|---------------------------|-----------------|----------------------------------|
|  id                       | Long            | アービトレーションサービスID。  |

|  svrPort                  | Integer         | アービトレーションサービスのサービスポート。  |
|  status                   | String          | アービトレーションサービスの状態。  |
|  groupId                  | Long            | 所属するアービトレーションサービスグループID。  |
|  groupName                | String          | 所属するアービトレーションサービスグループ名。  |
|  priority                 | Integer         | サービスグループ内でのアービトレーションサービスの優先順位。  |
|  operatingTaskInstanceId  | Long            | 運用中のタスクID。  |
|  statusAnalysis           | Object          | 詳細については、**異常状態の原因分析**を参照してください。  |
|  version                  | String          | アービトレーションサービスのバージョン。  |
|  installPath              | String          | アービトレーションサービスのインストールディレクトリ。  |

|  runUser                  | String          | アービトレーションサービスの実行ユーザー。  |
|  architecture             | String          | アービトレーションサービスが配置されているホストのアーキテクチャ情報。  |
|  description              | String          | アービトレーションサービスの説明。  |
|  clusters                 | List<Object>    | 詳細については、**アービトレーションサービス関連のクラスタ情報**を参照してください。  |

|  updateTime               | OffsetDateTime  | アービトレーションサービスの変更時間。  |
|  startupParameters        | Object          | 詳細については、**アービトレーションサービス起動パラメータ**を参照してください。  |
|  tags                     | List<Object>    | タグ情報。  |

**異常状態の原因分析**

**タグリソース一覧**

**アービトレーションサービス起動パラメータ**

|  パラメータ          |  タイプ    |  説明     |
|----------------|----------|----------|
