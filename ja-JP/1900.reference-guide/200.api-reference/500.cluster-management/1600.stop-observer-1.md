# OBServerノードの停止

## 機能の概要

このAPIは、対象となるOceanBaseクラスタのOBServerノードを停止するために使用します。

## 呼び出しの説明

### インターフェース制約

* ユーザーは対象となるOceanBaseクラスタに対する管理権限を持っている必要があります。

  ユーザー権限の詳細については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* ユーザーはOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/servers/{serverId}/stop`

**パス：**

|    パラメータ    |   型    | 必須 | サンプル値 |       説明       |
|----------|---------|----|-----|----------------|
| id       | Integer | はい  | 1   | 対象クラスタのID。      |
| serverId | Integer | はい  | 1   | OBServerノードのID。 |

### リクエストパラメータ

|  パラメータ    |   型  | 必須 |  サンプル値  |   説明    |
|--------------|---------|-----|-------|---------|
| freezeServer | Boolean | はい  | false        | OBServerノードを停止する前にダンプを実行するかどうかを示します。 |
| force        | Boolean | いいえ  | false        | 現在は廃止されており、今後のバージョンでこのパラメータは削除されます。 |
| type         | Enum    | いいえ  | STOP_SERVICE | OBServerノードの停止タイプです。<li>STOP_SERVICE</li><li>STOP_PROCESS</li> |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTPステータスコードに準拠したエンコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |
