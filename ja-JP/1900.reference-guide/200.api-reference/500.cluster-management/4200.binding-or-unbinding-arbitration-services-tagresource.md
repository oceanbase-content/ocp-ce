# アービトレーションサービスへの指定タグ集合の紐付け/解除

## 機能説明

アービトレーションサービスに指定タグ集合を紐付け、または解除します。

## 呼び出し説明

### インターフェース制約

呼び出し元はアービトレーションサービスに対する **ARBITRATION:UPDATE** 権限を持っている必要があります。

### リクエストパス

`POST /api/v2/arbitration/services/{id}/tagResource`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  id              | Long     |  はい    | 4901         | 紐付けまたは解除する指定タグ集合を持つアービトレーションサービスID。  |

**body：**

|  パラメータ        |  タイプ          | 必須   | サンプル値     |  説明   |
|--------------|----------------|--------|------------|----------|
|  requests    | List<Object>   |  いいえ    | -          | 詳細は **リソース使用量に基づくタグの紐付け/解除** を参照してください。  |

**リソース使用量に基づくタグの紐付け/解除**

|  パラメータ     |  タイプ    |  説明   |
|-----------|----------|--------|
|  tagId    | Long     | タグID。  |
|  action   | String   | タグの紐付け/解除。  |
