# OceanBaseクラスタの引き継ぎ

## 機能の概要

このAPIは、OceanBaseクラスタを引き継ぐために使用します。OceanBaseクラスタを引き継ぐ前に、[OceanBaseクラスタの引き継ぎに関する事前チェック](718.takeover-precheck.md)を参照して、クラスタの事前チェックを実行してください。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、OceanBaseクラスタを引き継ぐ権限を持っている必要があります。

  呼び出し元の権限については、詳細は[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過する必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/takeOver`

### リクエストパラメータ

**Bodyパラメータ：**

|     パラメータ        |   型  | 必須 |        サンプル値             |   説明    |
|-----------------|---------|-----|----------------------------|-----------|
| rootSysPassword | String  | はい  | ******           | root@sysのパスワード。 |
| address         | String  | はい  | xxx.xxx.xxx.xxx  | クラスタの接続アドレス。 |
| port            | Integer | はい  | 2883             | クラスタの接続ポート。 |
| saveToCredential| Boolean | いいえ  | true             | パスワードボックスに保存するかどうか。デフォルトは`true`。 |
| connectionMode  | String  | いいえ  | direct           | 接続モード。`direct`または`proxy`を指定できます。デフォルトは`direct`です。 |
| clusterName     | String  | いいえ  | ob01             | 接続モードが`proxy`の場合は必須です。 |
| obClusterId     | Integer | いいえ  | 1001             | 接続モードが`proxy`で、かつ引き継ぐクラスタがスタンバイクラスタの場合は必須です。 |
| switchConfigUrl | Boolean | いいえ  | true             | ターゲットクラスタのConfig URLを本OCPに切り替えるかどうか。デフォルトは`true`です。 |
| hostInfo        | Object  | いいえ  | -                | クラスタ内のすべてのホストが事前にOCPに引き継がれている場合は、この項目を指定する必要はありません。クラスタ内にOCPに引き継がれていないホストが存在する場合は、その未引き継ぎホストの以下のプロパティを指定する必要があります。 |
| ├─ kind         | String  | いいえ  | DEDICATED_PHYSICAL_MACHINE | ホストタイプ。取り得る範囲：DEDICATED_PHYSICAL_MACHINEまたはDEDICATED_ECS。デフォルトはDEDICATED_PHYSICAL_MACHINEです。 |
| ├─ hostTypeId   | Integer | はい  | 281              | ホストマシンタイプID。 |
| ├─ credentialId | Integer | はい  | 32765            | ホスト資格ID。 |
| ├─ sshPort      | Integer | いいえ  | 22               | ホストSSHポート。デフォルトは22です。 |
| ├─ mgragentPort | Integer | いいえ  | 62889            | OCP-Agent監視データリスニングポート。デフォルトは62889です。 |
| ├─ monagentPort    | Integer | いいえ  | 62888            | OCP-Agent APIリスニングポート。デフォルトは62888です。 |
| ├─ monagentCpuQuota    | number | いいえ  | 2.0           | ocp_monagentのCPU設定。0.5C以上である必要があります。0.5Cの倍数で増やしてください。推奨される最大値は6Cです。 |
| ├─ monagentMemoryQuota    | Integer | いいえ  | 2         | ocp_monagentのメモリ設定。1GiB以上である必要があります。1GiBの倍数で増やしてください。推奨される最大値は12GiBです。 |
| vpcId           | Long    | いいえ  | 1L               | VPC ID。 |
| vpcName         | String  | いいえ  | xxx              | VPC名。 |
| proxyroPassword | String  | いいえ  | *****            | proxyro@sysユーザーのパスワード。 |
| saveToCredential| Boolean | いいえ  | true             | パスワードボックスに保存するかどうか。デフォルトは`true`。 |

### 実行結果

**基本データ構造**

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間(ミリ秒)。                                                  |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |
