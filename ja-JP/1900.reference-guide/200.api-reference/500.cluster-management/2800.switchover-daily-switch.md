# スイッチオーバーの日常的な切り替え

## 機能の概要

日常的な切り替えでは、指定されたスタンバイクラスタをプライマリクラスタに切り替えると同時に、現在のプライマリクラスタをスタンバイクラスタに切り替えます。

## 呼び出しの説明

### インターフェース制約

なし。

### リクエストパス

`POST /api/v2/ob/clusters/{id:[\\d]+}/switchover`

### リクエストパラメータ

なし。

### 戻り値

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   | 非同期タスク情報。詳細は[タスク返却構造](../400.task-return-structure.md)を参照してください。    |
| successful  | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId     | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |
