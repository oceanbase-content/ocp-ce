# OceanBaseクラスタのパラメータリストを取得する

## 機能の概要

このAPIは、対象のOceanBaseクラスタのパラメータリストを取得するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、対象のOceanBaseクラスタに対する読み取り専用権限を少なくとも持っている必要があります。

  呼び出し元の権限について詳細は、[ユーザーおよび権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過する必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/parameters`

**path**

| パラメータ |   型    | 必須 | サンプル値 |          説明          |
|----|---------|----|-----|----------------------|
| id        | Integer  | はい  | 100 | 対象OceanBaseクラスタのID。 |

### 戻り結果

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Array    | 詳細は **ClusterParameter リスト** を参照してください。   |
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace IDで、問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**ClusterParameter データ構造**

|      パラメータ      |   型    |             説明              |
|--------------|---------|-----------------------------|
| name         | String  | パラメータ名。                       |
| section      | String  | パラメータの分類。                       |
| parameterType          | Enum    | クラスタパラメータのタイプ。値の範囲：<li>OB_CLUSTER_PARAMETER：OceanBaseクラスタ構成パラメータ。</li><li>OB_TENANT_PARAMETER：OceanBaseテナント構成パラメータ。</li>旧バージョンの動作との互換性のため、指定しない場合はデフォルトでOB_CLUSTER_PARAMETERに設定されます。  |
| editionCompatibleType  | Enum    | パラメータが互換可能なリリース。値の範囲：<li>ALL：商用版とコミュニティ版の両方に適用されます。</li><li>COMMERCIAL：商用版にのみ適用されます。</li><li>COMMUNITY：コミュニティ版にのみ適用されます。</li>  |
| defaultValue | String  | デフォルト値。                        |
| valueRange   | Object  | 詳細については、**ValueRangeデータ構造**を参照してください。            |
| currentValue | Object  | 詳細については、**ClusterParameterValueデータ構造**を参照してください。 |
| needRestart  | Boolean | 再起動が必要かどうか。                     |
| readonly     | Boolean | 読み取り専用かどうか。                       |
| description  | String  | パラメータの説明。                       |

**ValueRangeデータ構造**

|      パラメータ       |   タイプ   |   説明    |
|---------------|--------|---------|
| type          | String | パラメータタイプ。   |
| allowedValues | String | 許容される値のリスト。 |
| maxValue      | String | パラメータの最大値。  |
| minValue      | String | パラメータの最小値。  |

**ClusterParameterValueデータ構造**

|       パラメータ       |  タイプ   |        説明         |
|----------------|-------|-------------------|
| values         | Array | 値のリスト。              |
| valueToServers | Map   | OBServer値のリスト。     |
| obParameters   | Array | 詳細については、**ObParameterデータ構造**を参照してください。 |

**ObParameterデータ構造**

|   パラメータ    |   タイプ    |       説明       |
|---------|---------|----------------|
| zone    | String  | Zone名。       |
| svrIp   | String  | OBServerノードのIPアドレス。 |
| svrPort | Integer | OBServerノードのポート番号。   |
| name    | String  | パラメータ名。           |
| value   | String  | パラメータ値。           |
