# JVM環境依存サービスの編集

## 機能の概要

クラスタのJVM環境依存サービス設定を変更します。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元はOceanBaseクラスタを引き継ぐ権限が必要です。

  呼び出し元の権限の詳細については[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過する必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/modifyJvmDepsService`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ     | 必須   | サンプル値  |  説明   |
|------------------|-----------|--------|--------|----------|
|  id              | Long      |  はい    |  160   | 対象クラスタのOCP側のID。  |

**body：**

|  パラメータ            |  タイプ     | 必須   | サンプル値  |  説明   |
|------------------|-----------|--------|--------|----------|
| jvmEnvServices   | Array     | いいえ     | ODPS External Table,HDFS External Table,Java UDF,ODPS Catalog,MySQL Plugin  | 環境依存サービス。値の範囲：<li>ODPS_EXTERNAL_TABLE</li><li>HDFS_EXTERNAL_TABLE</li><li>JAVA_UDF</li><li>ODPS_CATALOG</li><li>MYSQL_PLUGIN</li>。  |
| maxJvmMemoryGiB  | Integer   | いいえ     | 1                              | ユーザー入力の最大メモリサイズ。単位はGiB。 |
| restartMode      | String    | はい     | FORCE                          | リスタート方式。値の範囲：<li>FORCE</li><li>ROLLING</li>   |
| freezeServer     | Boolean   | はい     | true                           | プロセス停止前にダンプ操作を実行するかどうか。値の範囲：<li>true</li><li>false</li>  |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細は[タスク返却構造](../400.task-return-structure.md)を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題のトラブルシューティングに使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/160/modifyJvmDepsService`

```JSON
{
  "jvmEnvServices": ["ODPS External Table", "HDFS External Table", "Java UDF", "ODPS Catalog", "MySQL Plugin"],
  "maxJvmMemoryGiB": 1,
  "restartMode": "FORCE",
  "freezeServer": true
}
```
