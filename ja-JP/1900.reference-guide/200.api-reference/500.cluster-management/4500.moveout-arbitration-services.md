# アービトレーションサービスの移出

## 機能説明

指定されたアービトレーションサービスを移出します。

## 呼び出し説明

### インターフェース制約

呼び出し元は、アービトレーションサービスに対する **ARBITRATION:DELETE** 権限を持っている必要があります。

### リクエストパス

`POST /api/v2/arbitration/services/{id}/moveOut`

### リクエストパラメータ

**path：**

|  パラメータ    |  型     |  必須   |  サンプル値    |  説明   |
|-------------|----------|--------|--------------|----------|
|  id         | integer   |  はい    | 100001     | アービトレーションサービスID。 |

### 戻り値

**基本データ構造**

|  パラメータ    |  型     |  説明                               |
|--------------|------------|----------------------------------|
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

## 例

### リクエスト例

`POST /api/v2/arbitration/services/100001/moveOut`
