# アービトレーションサービスの起動

## 機能説明

指定したアービトレーションサービスを起動します。

## 呼び出し説明

### インターフェース制約

呼び出し元はアービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が付与されていなければなりません。

### リクエストパス

`POST /api/v2/arbitration/services/{id}/start`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  id              | Long     |  はい    | 4901         | 起動対象のアービトレーションサービスID。  |

**body：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  clientToken     | String   |  いいえ    | aBCDefGHIjk     | パワーコンシステントリクエストのトークンです。長さは8文字以上64文字以下で、グローバルに一意である必要があります。 |

### 戻り結果

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細については、[タスク返却構造](../400.task-return-structure.md)を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコードです。            |
|  traceId     |  String    | リクエストのTrace IDです。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |
