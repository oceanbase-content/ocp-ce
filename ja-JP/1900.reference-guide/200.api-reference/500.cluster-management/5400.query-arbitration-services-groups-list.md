# アービトレーションサービスグループの一覧を取得する

## 機能の概要

指定されたアービトレーションサービスグループのリストを取得します。

## 呼び出しの説明

### インターフェース制約

なし。

### リクエストパス

`GET /api/v2/arbitration/services/groups`

### リクエストパラメータ

**path：**

|  パラメータ            |  型           | 必須   | サンプル値      |  説明   |
|------------------|-----------------|--------|-------------|----------|
|  keyword         | String          |  いいえ    |  arbitrationServiceGroup    | キーワード。  |
|  status          | List<String>    |  いいえ    |  RUNNING,STOPPED    | アービトレーションサービスの状態リスト。  |

### 戻り値

**基本データ構造**

|  パラメータ    |  型          |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細については、**アービトレーショングループ一覧**を参照してください。             |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコードです。            |
|  traceId     |  String    | リクエストのTrace IDで、問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**アービトレーショングループ一覧**

|  パラメータ    |  型          |  説明                               |
|--------------|---------------|----------------------------------|
|  contents    |  List<Object> |  詳細については、**アービトレーショングループ情報**を参照してください。   |
|  page        |  Page         |  詳細については、**ページネーションパラメータ**を参照してください。   |

**アービトレーショングループ情報**

|  パラメータ                 |  型            |  説明                               |
|-----------------------|------------------|----------------------------------|
|  id                   |  Long            |  アービトレーショングループIDです。  |
|  name                 |  String          |  アービトレーショングループ名です。  |
|  autoReplace          |  Boolean         |  自動切り替えを有効にするかどうかを示します。  |
|  autoReplaceStrategy  |  Object          |  詳細については、**自動切り替えポリシー**を参照してください。  |
|  arbitrationServices  |  List<Object>    |  詳細については、**グループ内のアービトレーションサービス一覧**を参照してください。  |
|  description          |  String          |  備考です。  |
|  updateTime           |  OffsetDateTime  |  最終変更日時です。  |

**自動切り替えポリシー**

|  パラメータ             |  型   |  説明   |
|-------------------|---------|---------|
|  strategyType     | String  | 自動切り替えポリシーのタイプです。  |
|  threshold        | Integer | 閾値。`strategyType`によって異なります。<li>UNIT_COUNT：個数</li><li>UNIT_PERCENTAGE：パーセンテージ</li><li>DEFAULT：空</li>  |
|  duration         | Long    | 持続時間、秒単位です。0はトリガー条件が満たされると即座に切り替えることを意味します。  |

**グループ内のアービトレーションサービス一覧**

|   パラメータ                    |  型          |  説明   |
|---------------------------|----------------|---------|
|  id                       |  Long          |  アービトレーションサービスIDです。  |
|  hostId                   |  Long          |  アービトレーションサービスが存在するホストIDです。  |
|  svrIp                    |  String        |  アービトレーションサービスが存在するホストのIPアドレスです。  |
|  svrPort                  |  Integer       |  アービトレーションサービスのサービスポートです。  |
|  status                   |  String        |  アービトレーションサービスの状態です。  |
|  groupId                  |  Long          |  アービトレーションサービスグループID。  |
|  groupName                |  String        |  アービトレーションサービスグループ名。  |
|  priority                 |  Integer       |  サービスグループ内のアービトレーションサービスの優先順位。  |
|  operatingTaskInstanceId  |  Long          |  運用中のタスクID。  |
|  statusAnalysis           |  Object        |  詳細は**異常状態の原因分析**を参照してください。  |
|  version                  |  String        |  アービトレーションサービスのバージョン。  |
|  installPath              |  String        |  アービトレーションサービスのインストールディレクトリ。  |
|  runPath                  |  String        |  アービトレーションサービスの実行ディレクトリ。  |
|  runUser                  |  String        |  アービトレーションサービスの実行ユーザー。  |
|  architecture             |  String        |  アービトレーションサービスが配置されているホストのアーキテクチャ情報。  |
|  description              |  String        |  アービトレーションサービスの説明。  |
|  clusters                 |  List<Object>    |  詳細は**アービトレーションサービス関連のクラスタ情報**を参照してください。  |
|  createTime               |  OffsetDateTime  |  アービトレーションサービスの作成時間。  |
|  updateTime               |  OffsetDateTime  |  アービトレーションサービスの変更時間。  |
|  startupParameters        |  Object          |  詳細は**アービトレーションサービス起動パラメータ**を参照してください。  |
|  tags                     |  List<Object>    |  タグ情報。  |

**異常状態の原因分析**

|   パラメータ             |  型            |  説明   |
|--------------------|------------------|---------|
|  startTime         |  OffsetDateTime  |  状態開始時間。  |
|  reason            |  String  |  状態が発生した原因。  |
|  action            |  String  |  解決策。  |
|  reasonType        |  String  |  状態が発生した原因タイプ。  |
|  diagnosisType     |  String  |  診断タイプ。  |
|  diagnosisContent  |  Object  |  診断内容。  |

**アービトレーションサービス関連のクラスタ情報**

|   パラメータ         |  型            |  説明   |
|----------------|------------------|---------|
|  id            |  Long            |  クラスタID。  |
|  name          |  String          |  クラスタ名。  |
|  obClusterId   |  Long            |  クラスタ内部ID。  |
|  status        |  String          |  クラスタ状態。  |
|  tags          |  List<Object>    |  詳細は**タグ情報**を参照してください。  |
|  tenants       |  List<Object>    |  詳細は**クラスタ内のテナント情報**を参照してください。  |

**クラスタ内のテナント情報**

|   パラメータ              |  型        |  説明   |
|---------------------|--------------|---------|
|  id                 |  Long        |  テナントID。  |
|  name               |  String      |  テナント名。  |
|  obTenantId         |  Long        |  OceanBase内部テナントID。  |
|  arbitrationStatus  |  String      |  アービトレーション状態。  |
|  degradedLsIdList   |  List<Long>  |  ダウングレードされたログストリームIDのリスト。  |

**アービトレーションサービス起動パラメータ**

| パラメータ | 型 | 説明 |
|---------|----------|---------|
|  name   |  String  | パラメータ名。  |
|  value  |  String  | パラメータ値。  |

**タグ情報**

| パラメータ | 型 | 説明 |
|---------|----------------|---------|
|  id     |  Long          | タグID。  |
|  key    |  String        | タグのキー。  |
|  value  |  String        | タグの値。  |
|  refs   |  List<Object>  | 詳細は**タグリソース一覧**を参照してください。  |

**タグリソース一覧**

|   パラメータ         |  型    |  説明   |
|----------------|----------|---------|
|  id            |  Long    |  タグID。  |
|  name          |  String  |  タグ名。  |
|  resourceType  |  String  |  リソースタイプ。  |

**ページネーションパラメータ**

|  パラメータ          |  型    |  説明           |
|----------------|----------|---------------|
|  number        |  Integer |  ページ番号。   |
|  size          |  Integer |  1ページあたりのサイズ。   |
|  totalElements |  Integer |  総レコード数。   |
|  totalPages    |  Integer |  総ページ数。   |
