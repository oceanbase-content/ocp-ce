# アービトレーションサービスのアップグレード

## 機能説明

指定したアービトレーションサービスをアップグレードします。

## 呼び出し説明

### インターフェース制約

呼び出し元はアービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が付与されていなければなりません。

### リクエストパス

`POST /api/v2/arbitration/services/{id}/upgrade`

### リクエストパラメータ

**path：**

|  パラメータ            |  タイプ    | 必須   | サンプル値        |  説明   |
|------------------|----------|--------|--------------|----------|
|  id              | Long     |  はい    | 4901         | アップグレード対象のアービトレーションサービスID。  |

**body：**

|  パラメータ                |  タイプ    | 必須   | サンプル値        |  説明  |
|----------------------|----------|--------|--------------|----------|
|  rpmName              | String   |  はい    | oceanbase-4.1.0.0-100000682023020119.el7.x86_64.rpm     | 対象バージョンのRPMパッケージ名。  |
|  clientToken          | String   |  いいえ    | aBCDefGHIjk     | パワーアイドルリクエストトークン。長さは8～64文字で、グローバルに一意である必要があります。 |

### 戻り結果

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細については、[タスク戻り値構造](../400.task-return-structure.md)を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコードです。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

## 例

### リクエスト例

`POST /api/v2/arbitration/services/4190/upgrade`

```JSON
{
  "rpmName":"oceanbase-4.3.4.0-200000022024070119.el7.x86_64.rpm"
}
```
