# OceanBaseクラスタの一括関連付け事前チェック

## 機能説明

OceanBaseクラスタにアービトレーションサービスを一括追加するための事前チェックを実行します。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、対象アービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が必要です。
* 呼び出し元は、クラスタIDリスト内のすべてのクラスタに対する **CLUSTER:UPDATE** 権限が必要です。

### リクエストパス

`POST /api/v2/ob/clusters/batchAddArbitrationPreCheck`

### リクエストパラメータ

**body：**

|  パラメータ                    |  タイプ        | 必須   | サンプル値      |  説明   |
|--------------------------|--------------|--------|-------------|----------|
|  arbitrationServiceId    | Long         |  はい    |  25         | 対象アービトレーションサービスID。  |
|  clusterIdList           | List<Long>   |  はい    |  83,84      | アービトレーションサービスを追加するOceanBaseクラスタIDのリスト。クラスタIDは半角カンマで区切ります。  |
|  enabledArbitration      | Boolean      |  はい    |  true       | 2F/4Fのアービトレーションサービスを自動開始するかどうか。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **事前チェック結果** を参照してください。             |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTP Status仕様に準拠したコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

**事前チェック結果**

|  パラメータ         |  タイプ         |  説明               |
|---------------|---------------|--------------------|
|  valid        |  Boolean      |  チェックに合格したかどうか。   |
|  checkResults |  List<Object> |  詳細は **エラーメッセージ一覧** を参照してください。   |

**エラーメッセージ一覧**

|  パラメータ    |  型         |  説明        |
|----------------|------------|------------------|
|  errorCode     |  String    |  エラーコード。  |
|  args          |  Object[]  |  エラーコードの引数。  |
|  errorMessage  |  String    |  国際化されたエラーメッセージ。  |
|  extraInfo     |  Object    |  追加情報。  |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/batchAddArbitrationPreCheck`

```JSON
{
  "arbitrationServiceId":25,
  "clusterIdList":[83,84],
  "enabledArbitration":true
}
```
