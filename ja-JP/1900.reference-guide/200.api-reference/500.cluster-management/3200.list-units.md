# OceanBaseクラスタのUnitリストを照会する

## 機能説明

このインターフェースは、OceanBaseクラスタのUnitリストを照会するために使用されます。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/units`

### リクエストパラメータ

**path：**

|  パラメータ         |  タイプ     |  必須   |  サンプル値 |  説明  |
|---------------|-----------|------|-------|----------|
|  id           |  Integer  |  はい  |  1    |  クラスタID。  |
|  tenantId     |  Long     |  いいえ  |  1L   |  テナントID。 |
|  serverIp     |  String   |  いいえ  |  xx   |  OBServer IPアドレス。 |
|  serverPort   |  Integer  |  いいえ  |  2881 |  OBServerポート。 |
|  obUnitIdList |  Array    |  いいえ  |  -    |  Unit IDの集合。 |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      | 説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **UnitInfoのデータ構造** を参照してください。 |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

**UnitInfoのデータ構造**

|  パラメータ  |  タイプ  |  説明  |
|--------------------------|--------------|-----------|
|  obUnitId                |  Integer     |  Unit ID。  |
|  tenantId                |  Integer     |  テナントID。  |
|  tenantName              |  String      |  テナント名。  |
|  obTenantId              |  Integer     |  OceanBase側テナントID。  |
|  svrIp                   |  String      |  OBServer IPアドレス。  |
|  svrPort                 |  Integer     |  OBServerポート。  |
|  zone                    |  String      |  ゾーン名。  |
|  unitConfig              |  UnitConfig  |  詳細については、**ユニット仕様のデータ構造**を参照してください。  |
|  status                  |  String      |  Unitの状態。  |
|  resourcePoolId          |  Long        |  リソースプールID。  |
|  resourcePoolName        |  String      |  リソースプール名。  |
|  migrateType             |  String      |  Unit移行タイプ。  |
|  migrateOppositeSvrIp    |  String      |  移行先または移行元のOBServer IPアドレス。  |
|  migrateOppositeSvrPort  |  Integer     |  移行先または移行元のOBServerポート。  |
|  manualMigrate           |  Boolean     |  手動移行かどうか。  |
|  logDiskUsedByte         |  Integer     |  ログディスク使用量、単位byte、OceanBase V4.0以降のバージョンでのみ適用されます。  |
|  dataDiskUsedByte        |  Integer     |  データディスク使用量、単位byte、OceanBase V4.0以降のバージョンでのみ適用されます。  |

**UnitConfigのデータ構造**

|  パラメータ             |  型     |  説明        |
|-------------------|-----------|--------------|
|  maxCpuCoreCount  |  Number   |  最大CPUコア数。  |
|  minCpuCoreCount  |  Number   |  最小CPUコア数。  |
|  maxMemoryByte    |  Integer  |  最大メモリサイズ、単位byte。  |
|  minMemoryByte    |  Integer  |  最小メモリサイズ、単位byte。  |
|  logDiskSizeByte  |  Integer  |  ログディスクサイズ、単位byte。  |
|  maxIops          |  Integer  |  最大IOPS。  |
|  minIops          |  Integer  |  最小IOPS。  |
|  iopsWeight       |  Integer  |  IOPS重み。  |
|  logDiskSize      |  Integer  |  ログディスクサイズ、単位GiB。  |
|  minMemorySize    |  Integer  |  最小メモリサイズ、単位GiB。  |
|  maxMemorySize    |  Integer  |  最大メモリサイズ、単位GiB。  |
