# OBServerノードの一括削除

## 機能説明

このAPIは、対象となるOceanBaseクラスタ内のOBServerノードを一括削除するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、対象となるOceanBaseクラスタに対する管理権限を持っている必要があります。

  呼び出し元の権限の詳細については [ユーザーおよび権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/servers/batchDelete`

**path：**

| パラメータ |   型    | 必須 | サンプル値 |    説明     |
|----|---------|----|-----|-----------|
| id | Integer | はい  | 1   | 対象クラスタのID。 |

### リクエストパラメータ

|   パラメータ    |  型   | 必須 |   サンプル値   |    説明     |
|---------|-------|----|---------|-----------|
| servers | Array | はい  | \[1,2\] | ホストIDのリスト。 |

### 戻り値

基本データ構造

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細は [タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTPステータスコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1/servers/batchDelete`

body:

```unknow
{
  "servers": [
    1
  ]
}
```
