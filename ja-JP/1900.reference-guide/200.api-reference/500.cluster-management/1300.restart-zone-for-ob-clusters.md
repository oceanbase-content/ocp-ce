# OceanBaseクラスタのゾーン再起動

## 機能説明

このAPIは、指定されたOceanBaseクラスタのゾーンを再起動するために使用します。

## 呼び出し説明

### インターフェース制約

* ユーザーは対象となるOceanBaseクラスタの管理権限を持っている必要があります。

  ユーザー権限の詳細については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* ユーザーはOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/zones/{zoneName}/restart`

**パス：**

|    パラメータ    |   型    | 必須 | サンプル値 |             説明              |
|----------|---------|----|-----|-----------------------------|
| id       | Integer | はい  | 1   | ゾーンを再起動するOceanBaseクラスタID。 |
| zoneName | String  | はい  | 1   | 再起動するゾーンの名前。              |

### 戻り値

基本データ構造

|     パラメータ     |    型    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細は[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTPステータスコードです。                                            |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1/zones/zone2/restart`
