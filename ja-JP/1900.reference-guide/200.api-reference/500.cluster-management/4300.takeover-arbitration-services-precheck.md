# アービトレーションサービスの引き継ぎに関する事前チェック

## 機能の概要

引き継ぐ対象のアービトレーションサービスが稼働しているホストが既に存在するかどうか、およびそのホスト上でobserverプロセスが実行されているかどうかを確認し、ホストがアービトレーションサービスの引き継ぎを正常に実行できるかどうかを判断します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はアービトレーションサービスの **ARBITRATION:CREATE** 権限を持っている必要があります。

### リクエストパス

`POST /api/v2/arbitration/services/takeOverPreCheck`

### リクエストパラメータ

**body：**

|  パラメータ          |  タイプ     | 必須   | サンプル値     |  説明   |
|----------------|-----------|--------|------------|----------|
|  hostId        | Long      |  はい    |  1          | アービトレーションサービスが配置されているホストID。  |
|  svrPort       | Integer   |  はい    |  2883       | アービトレーションサービスのサービスポート。  |
|  description   | String    |  いいえ    |  takeoverPreCheck     |  説明情報。  |

### 戻り結果

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 詳細は **アービトレーションサービスの引き継ぎに関する事前チェックの結果** を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうか。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

**アービトレーションサービスの引き継ぎに関する事前チェックの結果**

|  パラメータ                |  タイプ        | 説明                               |
|----------------------|--------------|----------------------------------|
|  checkSuccess        | boolean      | チェックが成功したかどうか。  |
|  errorInfos          | List<Object> | 詳細については、**エラー情報/警告情報**を参照してください。  |
|  warningInfos        | List<Object> | 詳細については、**エラー情報/警告情報**を参照してください。  |
|  hostId              | Long         | ホストID。  |
|  ipAddress           | String       | IPアドレス。  |
|  svrPort             | Integer      | サービスポート。  |
|  installPath         | String       | アービトレーションサービスのインストールディレクトリ。  |
|  runPath             | String       | アービトレーションサービスの実行パス。  |
|  version             | String       | アービトレーションサービスのバージョン。  |
|  runUser             | String       | アービトレーションサービスプロセスの所有者ユーザー。  |
|  startupParameters   | Object       | 詳細については、**アービトレーションサービスプロセス起動パラメータ**を参照してください。 |
|  relatedClusters     | List<Object> | 詳細については、**アービトレーションサービス関連クラスタ情報**を参照してください。  |

**エラー情報/警告情報**

|  パラメータ            |  型    | 説明                               |
|------------------|----------|----------------------------------|
|  warning         | boolean  | 警告かどうかを示します。  |
|  errorCode       | String   | エラーコード。  |
|  args            | Object[] | 携帯されるその他のプロパティ。  |
|  errorMessage    | String   | 国際化されたエラーメッセージ。  |

**アービトレーションサービスプロセス起動パラメータ**

|  パラメータ          |  型    |  説明     |
|----------------|----------|----------|
| name           | String   | パラメータ名。  |
| value          | String   | パラメータ値。  |

**アービトレーションサービス関連クラスタ情報**

|  パラメータ          |  型         |  説明        |
|----------------|---------------|--------------|
|  id            | Long          | クラスタID。  |
|  name          | String        | クラスタ名。  |
|  obClusterId   | Long          | クラスタ内部ID。  |
|  status        | String        | クラスタ状態。  |
|  tenants       | List<Object>  | 詳細については、**クラスタ下のテナント情報**を参照してください。  |
|  tags          | List<Object>  | 詳細については、**タグ情報**を参照してください。  |

**クラスタ下のテナント情報**

|  パラメータ              |  型        |  説明        |

|  obTenantId        | Long         | OceanBase内部テナントID。  |

**タグ情報**

|  パラメータ     |  型        |  説明        |
|-----------|--------------|--------------|
|  id       | Long         | タグID。  |
|  key      | String       | タグのキー。  |

**タグリソース一覧**

|  パラメータ          |  型        |  説明        |
|----------------|--------------|--------------|
|  id            |  Long        |  タグID。   |
|  name          |  String      |  タグ名。    |
|  resourceType  |  String      |  リソースタイプ。  |
