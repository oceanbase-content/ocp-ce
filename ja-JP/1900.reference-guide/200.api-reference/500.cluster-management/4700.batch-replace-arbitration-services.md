# アービトレーションサービスの一括置換

## 機能の概要

OceanBaseクラスタのアービトレーションサービスを一括で置き換えます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、対象のアービトレーションサービスに対する **ARBITRATION:UPDATE** 権限が必要です。
* 呼び出し元は、クラスタIDリスト内のすべてのクラスタに対する **CLUSTER:UPDATE** 権限が必要です。

### リクエストパス

`POST /api/v2/ob/clusters/batchReplaceArbitration`

### リクエストパラメータ

**body：**

|  パラメータ                    |  タイプ        | 必須   | サンプル値      |  説明   |
|--------------------------|--------------|--------|-------------|----------|
|  arbitrationServiceId    | Long         |  はい    |  1          | 対象のアービトレーションサービスID。  |
|  clusterIdList           | List<Long>   |  はい    |  83,84      | 置き換えるアービトレーションサービスを持つOceanBaseクラスタのIDリスト。クラスタIDは半角カンマで区切ります。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細は [タスク情報](../400.task-return-structure.md) を参照してください。             |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコード。            |
|  traceId     |  String    | リクエストのTrace ID。問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。                    |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/batchReplaceArbitration`

```JSON
{
  "clusterIdList":[83,84],
  "arbitrationServiceId":21
}
```
