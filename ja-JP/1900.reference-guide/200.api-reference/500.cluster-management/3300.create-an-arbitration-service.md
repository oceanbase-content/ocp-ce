# アービトレーションサービスの作成

## 機能の概要

ホストとサービスのバージョンを選択し、新しいアービトレーションサービスを作成します。

## 呼び出しの説明

### インターフェース制約

呼び出し元には、アービトレーションサービスの **ARBITRATION:CREATE** 権限が付与されていなければなりません。

### リクエストパス

`POST /api/v2/arbitration/services`

### リクエストパラメータ

**body：**

|  パラメータ                |  タイプ    | 必須   | サンプル値        |  説明  |
|----------------------|----------|--------|--------------|----------|
| hostId               | Long     |  はい    | 1002                        | アービトレーションサービスが配置されるホストID。  |
| rpmName              | String   |  はい    | oceanbase-4.1.0.0-100000682023020119.el7.x86_64.rpm     | アービトレーションサービスRPMパッケージ名。  |
| installPath          | String   |  はい    | `/home/admin/oceanbase`     | アービトレーションサービスのインストールディレクトリ。 |
| runPath              | String   |  いいえ    | `/home/admin/oceanbase`     | アービトレーションサービスの実行ディレクトリ。 |
| runUser              | String   |  はい    | admin                       | アービトレーションサービスの実行ユーザー。 |
| svrPort              | Integer  |  はい    | 2886                        | アービトレーションサービスのサービスポート。 |
| description          | String   |  いいえ    | arbitration_service_1       | 説明情報。 |
| clogSymbolicLinkPath | String   |  いいえ    | `/data/log1/clog`           | アービトレーションレプリカclogのソフトリンクが接続する外部ディスクディレクトリ。 |
| startupParameters    | Object   |  いいえ    | -                           | 詳細については、**アービトレーションサービス起動パラメータ**を参照してください。 |
| clientToken          | String   |  いいえ    | aBCDefGHIjk                 | 幂等リクエストのためのトークン。長さは8～64文字で、グローバルに一意である必要があります。 |

**アービトレーションサービス起動パラメータ：**

|  パラメータ          |  タイプ    |  説明     |
|----------------|----------|----------|
| name           | String   | パラメータ名。  |
| value          | String   | パラメータ値。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  タイプ      | 説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | 非同期タスク情報。詳細については、[タスク戻り値構造](../400.task-return-structure.md)を参照してください。  |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコードに準拠したエンコードです。            |
|  traceId     |  String    | リクエストのTrace IDであり、問題のトラブルシューティングに使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

## 例

### リクエスト例

`POST /api/v2/arbitration/services`

```shell
{
  "hostId": 1002,
  "rpmName": "oceanbase-4.1.0.0-100000682023020119.el7.x86_64.rpm",
  "installPath": "/home/admin/oceanbase",
  "svrPort": 2882,
  "runUser": "admin",
  "startupParameters":[
    {
      "name": "devname",
      "value": "bond0"
    }
  ],
  "description":"arbitration_service_1"
}
```
