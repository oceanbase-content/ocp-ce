# モニタリングデータのクエリ

## 機能の概要

指定されたメトリクスのモニタリングデータを照会します。クエリの時間範囲とメトリクスの配列を指定する必要があります。タグを使用してクエリの範囲を指定し、データを指定されたタグで集計します。結果は時系列形式で出力されます。

どのような時間範囲を選択しても、結果データの規模は1440個のサンプルポイントに収束します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/monitor/metric`

### リクエストパラメータ

**body：**

|     パラメータ     |     型      | 必須 |            サンプル値             |       説明        |
|------------|-------------|----|----------------------------|-----------------|
| startTime | Datetime    | はい  | 2020-02-16T05:32:16+08:00  | モニタリングデータの開始時間。      |
| endTime   | Datetime    | はい  | 2020-02-16T07:32:16+08:00  | モニタリングデータの終了時間。      |
| metrics    | StringArray | はい  | io_read_time,io_write_time | モニタリングメトリクスの配列。        |
| groupBy    | StringArray | はい  | app,ob_cluster_name,ob_cluster_id | モニタリングデータの集計タグ。ここで：<li>app：モニタリングデータ収集のソース。`host`、`ob`、`obproxy`のいずれかの値を取り得ます。それぞれホスト監視、OceanBase監視、OBProxy監視を表します。</li> <li>ob_cluster_name：監視対象のOceanBaseクラスタ名。</li> <li>ob_cluster_id：監視対象のOceanBaseクラスタID。</li>      |
| interval   | Integer     | はい  | 60                         | モニタリングデータの時間粒度、単位は秒です。 |
| minStep    | Integer     | いいえ   | 10                         | クエリのサンプリング間隔、最小モニタリング結果のサンプリング時間間隔を表します。デフォルト値は0です。 |
| maxPoints  | Integer     | いいえ   | 360                        | モニタリング結果の最大返却ポイント数、デフォルト値は1440です。        |
| labels     | StringArray | はい  | app:ob,ob_cluster_name=foo        | モニタリングデータのフィルタリング条件。      |

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OCP V4.2.1から、<code>obregion</code>パラメータ名が<code>ob_cluster_name</code>に更新されました。このパラメータを使用してインターフェースを呼び出している場合は、影響を受けません。</p>

### 戻り値

**基本データ構造**

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   | リクエストされたデータ。                |
| ├─ contents | Array    | モニタリングサンプリングの配列で、データ構造はクエリしたモニタリング指標によって決定されます。詳細は **モニタリングサンプリングデータ構造** を参照してください。      |
| successful  | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）です。       |
| status      | Integer  | HTTP Status仕様に準拠したコードです。 |
| traceId     | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したサーバーのアドレスです。          |

**モニタリングサンプリングデータ構造**

|    パラメータ     |   型    |                 説明                 |
|-----------|---------|------------------------------------|
| timestamp | Integer | サンプリング時点の時刻で、1970年1月1日00:00:00からの秒数です。 |
| 指標名A   | Float   | 対応する指標のサンプリング値です。                           |
| 指標名B   | Float   | 対応する指標のサンプリング値です。                           |

## 例

### リクエスト例

2020-11-11 18:30:00.000+08:00 から 2020-11-11 19:00:00.000+08:00 のモニタリングデータをリクエストします。リクエストのモニタリング指標は `net_recv` と `net_send` で、サンプリング間隔は60秒です。指標値は app=ob, ob_cluster_name=ob1,ob_cluster_id=1 です。モニタリングデータは app、ob_cluster_name、ob_cluster_id の3つのラベルで集計されます。

```json
GET /api/v2/monitor/metric?startTime=2020-11-11T18%3A30%3A00.000%2B08%3A00&endTime=2020-11-11T19%3A00%3A00.000%2B08%3A00&interval=60&metrics=net_recv%2Cnet_send&labels=app%3Aob%2Cob_cluster_name%3Aob1%2Cob_cluster_id%3A1&groupBy=app%2Cob_cluster_name%2Cob_cluster_id
```
