# モニタリング指標の説明情報を照会する

## 機能の概要

OCPアプリケーションが現在提供しているメトリクスの説明情報を照会します。ユーザーはこの説明情報に基づいて、対応する監視データをさらに照会できます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/monitor/metricGroups`

### リクエストパラメータ

**body：**

|  パラメータ   |   型    | 必須 |   サンプル値    |       説明     |
|-------|---------|----|----------|----------------------------|
| page  | Integer | いいえ  | 1        | リクエストデータのページ番号です。値は1から始まり、デフォルト値は1です。     |
| size  | Integer | いいえ  | 10       | リクエストデータのページサイズです。デフォルト値は10、最大値は2000です。     |
| sort  | String  | いいえ  | asc,name | リクエストデータのソート規則です。デフォルトではIDの昇順でソートされます。    |
| type  | String  | はい  | TOP      | 照会するメトリクスのタイプ：<li>TOP：トップメトリクスのメタデータを照会します。</li><li>NORMAL：通常メトリクスのメタデータを照会します。<li>     |
| scope | String  | はい  | CLUSTER  | 照会するメトリクスの範囲：<li>CLUSTER：クラスタのメトリクス。</li><li>TENANT：テナントのメトリクス。</li><li>HOST：ホストのメトリクス。</li><li>OBPROXY：OBProxyのメトリクス。</li>    |
| target | String  | いいえ  | OBCLUSTER  | メトリクスメタ情報のタイプ：<li>OBCLUSTER：OceanBaseクラスタ。</li><li>OBPROXY：OBProxyクラスタ。</li>    |
| targetId | Integer    | いいえ  | 1  | メトリクスメタ情報ID：<li>`target`がOBCLUSTERの場合、OceanBaseクラスタIDを指定します。</li><li>`target`がOBPROXYの場合、OBProxyクラスタIDを指定します。</li>    |

### 戻り結果

**基本データ構造**

|        パラメータ        |    型    |          説明           |
|------------------|----------|-----------------------|
| data             | Object   | リクエストしたデータ。                |

| ├─ page          | Object   | ページ情報です。詳細は**pageデータ構造**を参照してください。                 |
| ├─ totalElements | Integer  | 総レコード数。                 |
| ├─ totalPages     | Integer  | 総ページ数。                  |
| ├─ number        | Integer  | 現在のページ番号。                 |
| ├─ size          | Integer  | 現在のページサイズ。                |
| successful       | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status           | Integer  | HTTP Status仕様に準拠したエンコードです。 |
| traceId          | String   | リクエストのTrace IDです。問題の調査に使用されます。  |
| server           | String   | リクエストに応答したサーバーのアドレスです。          |

**メトリクス大分類データ構造**

|      パラメータ      |   型    |     説明    |
|--------------|---------|-------------|
| id           | Integer | 指標カテゴリのID。   |
| key          | String  | 指標カテゴリのコード名。     |
| name         | String  | 指標カテゴリ名。国際化対応。   |
| description  | String  | 指標カテゴリの説明情報。国際化対応。  |
| scope        | String  | 指標範囲：<li>CLUSTER：クラスタの指標。</li><li>TENANT：テナントの指標。</li><li>HOST：ホストの指標。</li><li>OBPROXY：OBProxyの指標</li>    |
| type         | String  | 指標タイプ：<li>TOP：トップ指標のメタデータを照会します。</li><li>NORMAL：通常指標のメタデータを照会します。</li>    |
| metricGroups | Array   | 指標グループの配列。詳細は**指標グループデータ構造**を参照してください。       |
| dimensions   | Array   | 含まれる次元のリスト。    |
| defaultDimension | String  | デフォルトの次元。    |

**指標グループデータ構造**

|     パラメータ      |   型    |           説明              |
|-------------|---------|-----------------------------------|
| id          | Integer | 指標グループのID。                      |

| name        | String  | 指標グループ名。国際化対応。      |
| description | String  | 指標グループの説明情報。国際化対応。    |
| metrics     | Array   | 指標メタデータの配列。詳細は**指標メタデータデータ構造**を参照してください。       |
| withLabel   | Boolean | ラベル付きの監視データグループであるかどうか。             |
| dimension   | String  | 次元。                                 |

**指標メタデータデータ構造**

|        パラメータ        |   型    |       説明       |
|------------------|---------|----------------|
| id               | Integer | 指標のID。        |
| key              | String  | 指標のコード名。       |
| name             | String  | 指標名。国際化対応。   |
| description      | String  | 指標の説明情報。国際化対応。 |
| unit             | String  | 指標の単位。          |
| displayByDefault | Boolean | デフォルトで表示するかどうか。         |

**pageデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|---------|--------|
|  totalElements  |  Integer  |  総レコード数。  |
|  totalPages     |  Integer  |  総ページ数。  |
|  number         |  Integer  |  現在のページ番号。  |
|  size           |  Integer  |  現在のページサイズ。   |

## 例

### リクエスト例

クラスタ範囲のTopタイプメトリクスのメタデータを照会します。

```json
GET /api/v2/monitor/metricGroups?scope=CLUSTER&type=TOP
```
