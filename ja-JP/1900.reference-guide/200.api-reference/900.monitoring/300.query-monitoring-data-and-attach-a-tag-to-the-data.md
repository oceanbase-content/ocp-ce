# タグ別にモニタリングデータを照会する

## 機能の概要

指定されたメトリクスのモニタリングデータを照会し、グループ化タグの値を添付します。照会する時間区間とメトリクスの配列を指定する必要があります。タグで照会範囲を指定し、データを指定されたタグで集計します。照会結果には複数のグループが含まれ、各グループ内は時系列データです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/monitor/metricsWithLabel`

### リクエストパラメータ

**body：**

|     パラメータ     |     型      | 必須 |            サンプル値             |       説明        |
|------------|-------------|----|----------------------------|-----------------|
| startTime | Datetime    | はい  | 2020-02-16T05:32:16+08:00  | モニタリングデータの開始時間。      |
| endTime   | Datetime    | はい  | 2020-02-16T07:32:16+08:00  | モニタリングデータの終了時間。      |
| metrics    | StringArray | はい  | io_read_time,io_write_time | モニタリングメトリクスの配列。        |
| groupBy    | StringArray | はい  | app,ob_cluster_name,ob_cluster_id | モニタリングデータの集計タグ。      |
| interval   | Integer     | はい  | 60                         | モニタリングデータの時間粒度、単位は秒。 |
| minStep    | Integer     | いいえ  | 10                         | 照会サンプリング間隔、最小モニタリング結果のサンプリング時間間隔を表す。デフォルト値は0。 |
| maxPoints  | Integer     | いいえ  | 360                        | モニタリング結果の最大返却ポイント数、デフォルト値は1440。         |
| labels     | StringArray | はい  | app:ob,ob_cluster_name=foo        | モニタリングデータのフィルター条件。      |

### 戻り値

**基本データ構造**

|     パラメータ      |    型    |          説明           |
|-------------|----------|-----------------------|
| data        | Object   | リクエストされたデータ。                |
| ├─ contents | Array    | モニタリングサンプリンググループの配列、データ構造はグループのタグによって決定されます。詳細は**モニタリングサンプリンググループデータ構造**を参照してください。     |
| successful  | Boolean  | リクエストが成功したかどうか。               |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status      | Integer  | HTTPステータスコード。 |
| traceId     | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server      | String   | リクエストに応答したサーバーのアドレス。          |

**モニタリングサンプリングデータ構造**

|  パラメータ  |   型   |       説明        |
|--------|--------|-----------------|
| タグA  | String | 対応するタグの値          |
| タグB  | String | 対応するタグの値          |
| data   | Array  | モニタリングサンプリングの配列。データ構造はクエリしたモニタリングメトリクスによって決定されます。詳細については、**モニタリングサンプリングデータ構造**を参照してください。 |

**モニタリングサンプリングデータ構造**

|    パラメータ     |   型    |                 説明                 |
|-----------|---------|------------------------------------|
| timestamp | Integer | サンプリング時刻。1970年1月1日00:00:00からの秒数です。 |
| メトリクス名A      | Float   | 対応するメトリクスのサンプリング値                           |
| メトリクス名B      | Float   | 対応するメトリクスのサンプリング値                           |

## 例

### リクエスト例

2020-11-11 18:30:00.000+08:00 から 2020-11-11 19:00:00.000+08:00 のモニタリングデータを取得します。リクエストのモニタリングメトリクスは `sql_all_count`、出力されるモニタリングデータの時間粒度は1秒です。モニタリングデータのフィルタ条件は app=ob です。モニタリングデータは app、ob_cluster_name、ob_cluster_id の3つのタグで集計されます。

```json
api/v2/monitor/metricsWithLabel?labels=app%3Aob&groupBy=app%2Cob_cluster_name%2Cob_cluster_id&metrics=sql_all_count&interval=1&limit=5&startTime=2025-05-19T18%3A30%3A00.000%2B08%3A00&endTime=2025-05-19T19%3A00%3A00.000%2B08%3A00
```
