# テナントのレプリカを追加する

## 機能の概要

指定したテナントに新しいレプリカを追加します。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/addReplica`

**パス：**

|    パラメータ    |  タイプ  | 必須 | サンプル値 |  説明   |
|----------|------|------|------|-------|
| id       | Long | はい  | 1000001   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 1000005   | 対象テナントのOCP側のテナントID。 |

### リクエストパラメータ

|       パラメータ       |   タイプ    | 必須 | サンプル値  |      説明        |
|----------------|---------|----|------|-----------|
| zoneName      | String  | はい  | foo  | テナント名。クラスタ内で一意である必要があります。    |
| replicaType    | String  | はい  | FULL | レプリカタイプ。<li>FULL</li><li>LOGONLY</li><li>READONLY</li><li>COLUMNSTORE</li>   |
| resourcePool   | Object  | はい  | --   | リソースプール情報。      |
| ├─unitSpecName | Object  | はい  | S1   | "Unit規格管理"ページで規格リストを確認できます。     |
| ├─unitCount    | Integer | はい  | 1    | Unit数。      |

### 戻り値

**基本データ構造**

|     パラメータ     |    タイプ    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間(ミリ秒)。                                                  |
| status     | Integer  | HTTPステータスコード。                                            |
| traceId    | String   | リクエストのトレースID。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答するアプリケーションサービスのアドレス。                                                    |

## 例

### リクエスト例

**パス：**

`POST /api/v2/ob/clusters/1000001/tenants/1000005/addReplica`

**ボディ：**

```json
[
  {
    "zoneName": "zone1",
    "replicaType": "FULL",
    "resourcePool": {
      "unitSpecName": "S0",
      "unitCount": 1
    }
  }
]
```
