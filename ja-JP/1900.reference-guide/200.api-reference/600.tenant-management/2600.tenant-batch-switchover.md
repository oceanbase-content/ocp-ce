# バッチ日常スイッチオーバー

## 機能説明

このAPIは、プライマリおよびスタンバイテナントのバッチ日常スイッチオーバー（Switchover）を実行するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元はテナントを変更する権限が必要です。

  呼び出し元の権限については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/switchover`

### リクエストパラメータ

**path：**

| パラメータ | 型    | 必須 | サンプル値 | 説明           |
|------|---------|------|--------|-----------------|
| id   | Integer | はい   | 3000010     | プライマリテナントが属するクラスタのOCP側のクラスタID。 |

**body：**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|---------|----------|----------|----------|----------|
| tenantParamList | SwitchoverObTenantParam | はい | - | 各Itemはスイッチオーバー対象のプライマリ・スタンバイテナントです。詳細は**SwitchoverObTenantParamデータ構造**を参照してください。 |

**SwitchoverObTenantParamデータ構造**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|----------|----------|----------|-----------|----------|
| tenantId        | Long | はい | 2000025 | プライマリテナントのOCP側のテナントID。 |
| standbyTenantId | Long | はい | 2000002 | スタンバイテナントのOCP側のテナントID。 |
| standbyOcpClusterId | Long   | いいえ   | 100001   | スタンバイテナントが存在するOCPクラスタID。OCPがマルチクラスタモードの場合は必須です。 |

### 戻り結果

| パラメータ | 型 | 説明 |
|-----------|-----------|------------|
| data       | TaskInstance | 複数の非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean      | リクエストが成功したかどうかを示します。 |
| timestamp  | Datetime     | サーバーがリクエストを完了したタイムスタンプです。 |
| duration   | Integer      | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status     | Integer      | HTTP Status仕様に準拠したコードです。 |
| traceId    | String       | リクエストのTrace ID。問題のトラブルシューティングに使用されます。 |
| server     | String       | リクエストに応答したアプリケーションサービスのアドレス。 |

## 例

### リクエスト例

**パス：**

`POST /api/v2/ob/clusters/3000010/tenants/switchover`

**ボディ：**

```json
{
  "tenantParamList":[
    {
      "tenantId": 2000025,
      "standbyTenantId": 2000002
    }
  ]
}
```
