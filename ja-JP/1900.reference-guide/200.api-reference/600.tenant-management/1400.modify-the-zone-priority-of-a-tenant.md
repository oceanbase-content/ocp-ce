# テナントのZone優先順位の変更

## 機能説明

指定したテナントのZone優先順位を変更するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/modifyPrimaryZone`

### リクエストパラメータ

**path：**

|    パラメータ    |  タイプ  | 必須 | サンプル値 |  説明   |
|----------|------|------|------|-------|
| id       | Long | はい  | 1000001   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 1000002   | 対象テナントのOCP側のテナントID。 |

**body：**

|     パラメータ      |   タイプ   | 必須 |        サンプル値        |    説明    |
|-------------|--------|------|-------------------|----------|
| primaryZone | String | はい  | zone1;zone2,zone3 | Zone優先順位。 |

### 戻り結果

基本データ構造

|     パラメータ     |    タイプ    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

**パス：**

`POST /api/v2/ob/clusters/1000001/tenants/1000002/modifyPrimaryZone`

**ボディ：**

```json
{
  "primaryZone": "zone1;zone2,zone3"
}
```
