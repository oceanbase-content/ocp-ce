# テナントのホワイトリストを変更する

## 機能の概要

指定したテナントのホワイトリストを変更するために使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/modifyWhitelist`

### リクエストパラメータ

**path：**

|    パラメータ    |  タイプ  | 必須 | サンプル値 |  説明   |
|----------|------|-------|------|-------|
| id       | Long | はい  | 1000001   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 1000002   | 対象テナントのOCP側のテナントID。 |

**body：**

|    パラメータ     |   タイプ   | 必須 |   サンプル値   |    説明    |
|-----------|--------|--------|---------|------------------|
| whitelist | String | はい  | xxx.xxx.xxx.xxx | アクセスホワイトリスト。<li>IPアドレス（例：xxx.xxx.xxx.xxx）、IPセグメント（例：xxx.xxx.xxx.1-3 は xxx.xxx.xxx.1、xxx.xxx.xxx.2、xxx.xxx.xxx.3 の3つのIPを表す）、またはサブネット/マスク（例：xxx.xxx.xxx.xxx/24）を入力できます。</li><li>複数のIPは半角カンマで区切ります。例：xxx.xxx.xxx.xxx,xxx.xxx.xxx.xxx/24 </li><li>xxx.xxx.xxx.xxx は任意のIPアドレスからのアクセスを禁止することを意味します。 </li>   |

### 戻り結果

**基本データ構造**

|     パラメータ     |    タイプ    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1000001/tenants/1000002/modifyWhitelist`

body:

```json
{
  "whitelist": "xxx.xxx.xxx.xxx"
}
```
