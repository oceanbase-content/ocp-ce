# 日常的な切り替えの事前チェック

## 機能説明

このAPIは、プライマリテナントとスタンバイテナントの日常的な切り替え(Switchover)の事前チェックに使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元にはテナントを変更する権限が付与されている必要があります。

  呼び出し元の権限については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/switchoverPreCheck`

### リクエストパラメータ

**path：**

| パラメータ | 型    | 必須 | サンプル値 | 説明           |
|------|---------|------|--------|-----------------|
| id       | Long | はい  | 3000009   | プライマリテナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 2000022   | プライマリテナントのOCP側のテナントID。     |

**body：**

| パラメータ  |  型  |  必須  | サンプル値  |  説明  |
|-------|--------|---------|---------|---------|
| tenantId        | Long   |  はい  | 2000022   | プライマリテナントのOCP側のテナントID。 |
| standbyTenantId | Long   | はい   | 2000025   | スタンバイテナントのOCP側のテナントID。 |
| standbyOcpClusterId | Long   | いいえ   | 100001   | スタンバイテナントが存在するOCPクラスタID。OCPがマルチクラスタモードの場合は必須です。 |

### 戻り値

|  パラメータ  |  型  |  説明  |
|---------|---------|---------|
|  data        |  SwitchoverPreCheckResult  | チェック結果。詳細については、**SwitchoverPreCheckResultデータ構造**を参照してください。 |
|  successful  |  Boolean  |  リクエストが成功したかどうか。  |
|  timestamp   |  Datetime  |  サーバーがリクエストを完了したタイムスタンプ。  |
|  duration    |  Integer  |  サーバーがリクエストを処理した時間(ミリ秒)。  |
|  status      |  Integer  |  HTTPステータスコード。  |
|  traceId     |  String  |  リクエストのトレースID。問題の調査に使用されます。  |
|  server      |  String  |  リクエストに応答したアプリケーションサービスのアドレス。  |

**SwitchoverPreCheckResultデータ構造**

|  パラメータ  |  型     |  説明    |
|-----------|---------|------------|
| valid               | Boolean | 事前チェックに合格したかどうか。 |
| tenantId            | Long    | OCP側のプライマリテナントID。 |
| name                | String  | プライマリテナント名。 |
| clusterId           | Long    | OCP側のクラスタID。 |
| clusterName         | String  | プライマリテナントのクラスタ名。 |
| standbyCheckResults | ObTenantPreCheckResult    | 詳細は **ObTenantPreCheckResultデータ構造** を参照してください。 |

**ObTenantPreCheckResultデータ構造**

|  パラメータ  |  型     |  説明    |
|--------------------------|---------------------|-----------|
| valid                    | Boolean             | スタンバイテナントの切り替えが許可されているかどうか。 |
| tenantId                 | Long                | OCP側のスタンバイテナントID。 |
| name                     | String              | スタンバイテナント名。 |
| clusterId                | Long                | OCP側のスタンバイテナントのクラスタID。 |
| clusterName              | String              | スタンバイテナントのクラスタ名。 |
| syncScn                  | Long                | スタンバイテナントの同期遅延。 |
| primaryTenantServiceName | String              | プライマリテナントサービス名。 |
| checkResults             | PreCheckResult      | 失敗情報のリスト。詳細は **PreCheckResultデータ構造** を参照してください。 |

**PreCheckResultデータ構造**

|  パラメータ  |  型     |  説明    |
|--------------|---------|-----------|
| warning      | Boolean | 警告の有無。`true` の場合は警告で、切り替えプロセスに影響しません。`false` の場合はエラーで、切り替えに影響します。 |
| errorCode    | String  | エラーコード。 |
| errorMessage | String  | エラーメッセージ。 |
