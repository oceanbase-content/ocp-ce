# テナントレプリカの削除

## 機能説明

指定したテナントのレプリカを削除するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/deleteReplica`

### リクエストパラメータ

**path：**

|    パラメータ    |  タイプ  | 必須 | サンプル値 |  説明   |
|----------|------|------|------|-------|
| id       | Long | はい  | 9    | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 18   | 対象テナントのOCP側のテナントID。 |

**body：**

|    パラメータ     |   タイプ   | 必須 | サンプル値 |     説明     |
|-----------|--------|----|-----|------------|
| zoneName | String | はい  | foo | テナント名。クラスタ内で一意である必要があります。 |

### 戻り値

**基本データ構造**

|     パラメータ     |    タイプ    |                                説明                                |
|------------|----------|------------------------------------------------------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                  |
| status     | Integer  | HTTPステータスコード。                                            |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。                                             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                    |

### リクエスト例

**パス：**

`POST /api/v2/ob/clusters/9/tenants/18/addReplica`

**ボディ：**

```json
[
  {
    "zoneName": "zone1"
  },
  {
    "zoneName": "zone2"
  }
]
```
