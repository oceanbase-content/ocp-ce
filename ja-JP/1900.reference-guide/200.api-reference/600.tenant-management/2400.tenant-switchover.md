# 日常スイッチオーバー

## 機能説明

このAPIは、プライマリテナントとスタンバイテナントの日常的な切り替え（Switchover）を行うために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元はテナントを変更する権限が付与されている必要があります。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/switchover`

### リクエストパラメータ

**path：**

| パラメータ | 型    | 必須 | サンプル値 | 説明           |
|------|---------|------|--------|-----------------|
| id       | Long | はい  | 3000009   | プライマリテナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 2000022  | プライマリテナントのOCP側のテナントID。     |

**body：**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|---------|---------|----------|---------|----------|
| tenantId        | Long  |  はい  |  2000022  | プライマリテナントのOCP側のテナントID。 |
| standbyTenantId | Long  | はい   |  2000002  | スタンバイテナントのOCP側のテナントID。 |
| standbyOcpClusterId | Long   | いいえ   | 100001   | スタンバイテナントが存在するOCPクラスタID。OCPがマルチクラスタモードの場合は必須です。 |

### 戻り値

|  パラメータ  |  型  |  説明  |
|-----------|----------|----------|
|  data  |  TaskInstance  | 非同期タスク情報。詳細は[タスク情報](../400.task-return-structure.md)を参照してください。 |
|  successful  |  Boolean  |  リクエストが成功したかどうか。  |
|  timestamp  |  Datetime  |  サーバーがリクエストを完了したタイムスタンプ。  |
|  duration  |  Integer  |  サーバーがリクエストを処理した時間（ミリ秒）。  |
|  status  |  Integer  |  HTTPステータスコードに準拠するエンコード。  |
|  traceId  |  String  |  リクエストのトレースID。問題の調査に使用されます。  |
|  server  |  String  |  リクエストに応答したアプリケーションサービスのアドレス。  |

**パス：**

`POST /api/v2/ob/clusters/3000009/tenants/2000022/switchover`

**ボディ：**

```json
{
  "tenantId": 2000022,
  "standbyTenantId": 2000002
}
```
