# ディザスタリカバリ切り替えの事前チェック

## 機能説明

このAPIは、ネットワークを基盤としたプライマリ/スタンバイテナントのディザスタリカバリ切り替え(Failover)の事前チェックに使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元はテナントを変更する権限が必要です。

  呼び出し元の権限については、詳細は [ユーザーおよび権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/failoverPreCheck`

### リクエストパラメータ

**path：**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|----------|-----------|----------|----------|----------|
| id       | Integer    | はい   | 3000010   | スタンバイテナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Integer    | はい   | 2000025   | スタンバイテナントのOCP側のテナントID。 |

### 戻り値

| パラメータ | 型 | 説明 |
|-----------|----------|------------|
| data       | ObTenantPreCheckResult | チェック結果。詳細は **ObTenantPreCheckResult データ構造** を参照してください。 |
| successful | Boolean                | リクエストが成功したかどうか。 |
| timestamp  | Datetime               | サーバーがリクエストを完了したタイムスタンプ。 |
| duration   | Integer                | サーバーがリクエストを処理した時間(ミリ秒)。 |
| status     | Integer                | HTTP Status仕様に準拠したコード。 |
| traceId    | String                 | リクエストのTrace ID。問題の調査に使用されます。 |
| server     | String                 | リクエストに応答したアプリケーションサービスのアドレス。 |

**ObTenantPreCheckResult データ構造**

| パラメータ | 型 | 説明 |
|------------|-----------|-----------|
| valid                    | Boolean        | スタンバイテナントの切り替えを許可するかどうか。 |
| tenantId                 | Long           | OCP側におけるスタンバイテナントのテナントID。 |
| name                     | String         | スタンバイテナント名。 |
| clusterId                | Long           | スタンバイテナントが属するクラスタのOCP側でのクラスタID。 |
| clusterName              | String         | スタンバイテナントのクラスタ名。 |
| syncScn                  | Long           | スタンバイテナントの同期遅延。 |
| primaryTenantServiceName | String         | プライマリテナントサービス名。 |
| checkResults             | PreCheckResult | 失敗情報のリスト。詳細は**PreCheckResultデータ構造**を参照してください。 |

**PreCheckResultデータ構造**

| パラメータ | 型 | 説明 |
|----------|----------|-----------|
| warning      | Boolean | 警告かどうか。値が`true`の場合は警告であり、切り替えプロセスには影響しません。値が`false`の場合はエラーであり、切り替えに影響します。 |
| errorCode    | String  | 例外コード。 |
| errorMessage | String  | 例外情報。 |
