# テナントのレプリカを変更する

## 機能の概要

指定したテナントのレプリカを変更するために使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/modifyReplica`

### リクエストパラメータ

**path：**

|    パラメータ    |  タイプ  | 必須 | サンプル値 |  説明   |
|----------|------|------|------|-------|
| id       | Long | はい  | 20   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 3    | 対象テナントのOCP側のテナントID。 |

**body：**

|       パラメータ       |   タイプ    | 必須 | サンプル値  |        説明      |
|----------------|---------|------|------|---------------|
| zoneName       | String  | はい  | foo  | テナント名。クラスタ内で一意である。       |
| replicaType    | String  | いいえ  | FULL | レプリカタイプ。<li>FULL</li><li>LOGONLY</li><li>READONLY</li><li>COLUMNSTORE</li>   |
| resourcePool   | Object  | いいえ  | --   | リソースプール情報。     |
| ├─unitSpecName | Object  | いいえ  | S1   | 「ユニット仕様管理」ページで仕様リストを確認できます。      |
| ├─unitCount    | Integer | いいえ  | 1    | ユニット数。      |

### 戻り値

**基本データ構造**

|     パラメータ     |    タイプ    |                                         説明                                          |
|------------|----------|-------------------------------------------------------------------------------------|
| data       | Object   | 作成されたテナント情報、非同期DAGタスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                                             |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                                        |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                                     |
| status     | Integer  | HTTPステータスコード。                                                               |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。                                                                |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                                       |

## 例

### リクエスト例

**パス：**

`POST /api/v2/ob/clusters/20/tenants/3/modifyReplica`

**ボディ：**

```json
[
  {
    "zoneName": "zone1",
    "replicaType": "FULL",
    "resourcePool": {
      "unitSpecName": "S1",
      "unitCount": 1
    }
  }
]
```
