# テナントのUnitリストを照会する

## 機能の概要

テナントのUnitリストを照会します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、指定されたクラスタに対する読み取り権限が必要です。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/units`

### リクエストパラメータ

**path：**

|    パラメータ     |  タイプ  | 必須 | サンプル値 |      説明       |
|-----------|------|------|------|---------------|
| id       | Long | はい  | 1000001   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 1000005   | 対象テナントのOCP側のテナントID。 |

**body：**

|    パラメータ    |   タイプ   | 必須 |  サンプル値  |   説明    |
|----------|--------|------|-------|---------|
| zoneName | String | いいえ  | zone1 | ゾーン名。 |

### 戻り値

**基本データ構造**

|        パラメータ        |    タイプ    |          説明           |
|------------------|----------|-----------------------|
| data             | Object   | リクエストされた業務データ。               |
| ├─ contents      | Array    | Unitのデータ。詳細は**Unitのデータ構造**を参照してください。    |
| ├─ page          | Object   | ページ情報。                 |
| ├─ totalElements | Integer  | 総レコード数。                 |
| ├─ totalPages    | Integer  | 総ページ数。                  |
| ├─ number        | Integer  | 現在のページ番号。                 |
| ├─ size          | Integer  | 現在のページサイズ。                |
| successful       | Boolean  | リクエストが成功したかどうか。               |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status           | Integer  | HTTPステータスコード。 |
| traceId          | String   | リクエストのトレースID。問題の調査に使用されます。  |
| server           | String   | リクエストに応答したサーバーのアドレス。          |

**Unitのデータ構造**

|       パラメータ       |   型    |       説明       |
|----------------|---------|----------------|
| id             | Integer | Uint ID。        |
| resourcePoolId | Integer | 所属リソースプールID。       |
| serverId       | Integer | 所属OBServerノードID。 |
| serverIp       | String  | 所属OBServerノードIP。 |
| serverPort     | Integer | 所属OBServerノードポート。 |
| zoneName       | String  | ゾーン名。        |
| status         | String  | Unitの状態。        |

## 例

### リクエスト例

IDが1000001のクラスタ内のすべてのテナントを照会します。

`GET /api/v2/ob/clusters/1000001/tenants/1000005/units`
