# テナントのロック解除

## 機能説明

指定されたクラスタ内で、指定されたテナントのロックを解除するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/unlock`

**path：**

|    パラメータ    |  タイプ  | 必須 | サンプル値 |  説明   |
|----------|------|------|------|-------|
| id       | Long | はい  | 1000001   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 1000005   | 対象テナントのOCP側のテナントID。 |

### 戻り値

**基本データ構造**

|     パラメータ     |    タイプ    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

## 例

### リクエスト例

`POST /api/v2/ob/clusters/1000001/tenants/1000005/unlock`
