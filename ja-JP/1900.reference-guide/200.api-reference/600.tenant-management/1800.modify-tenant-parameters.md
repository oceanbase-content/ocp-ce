# テナントパラメータの変更

## 機能の概要

このAPIは、テナントのパラメータを変更するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、対象テナントの更新権限を持っている必要があります。

  呼び出し元の権限については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`PUT /api/v2/ob/clusters/{id}/tenants/{tenantId}/parameters`

### リクエストパラメータ

**path：**

|    パラメータ    |  タイプ  | 必須 | サンプル値 |      説明       |
|----------|------|----|-----|---------------|
| id       | Long | はい  | 1000001   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 1000002  | 対象テナントのOCP側のテナントID。     |

**body：**

|          パラメータ          |  タイプ   | 必須 | サンプル値 |            説明            |
|----------------------|-------|----|-----|--------------------------|
| TenantParameterParam | Array | はい  | -  | 詳細は**TenantParameterParamデータ構造**を参照してください。 |

**TenantParameterParamデータ構造**

|  パラメータ   |   タイプ   | 必須 |          サンプル値           |       説明        |
|-------|--------|----|------------------------|-----------------|
| name  | String | はい  | ob_default_replica_num | パラメータ。OceanBaseのデフォルトレプリカ数を表します。 |
| value | String | はい  | 2                      | パラメータ値。            |
| parameterType | String | はい  | OB_SYSTEM_VARIABLE  | パラメータタイプ。値はOB_SYSTEM_VARIABLE(変数)またはOB_TENANT_PARAMETER(パラメータ)です。  |

### 戻り結果

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコードに準拠したエンコード。 |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |

## 例

### リクエスト例

**パス：**

`PUT /api/v2/ob/clusters/1000001/tenants/1000002/parameters`

**ボディ：**

```json
[
  {
    "name": "query_response_time_range_base",
    "value": 10,
    "parameterType": "OB_TENANT_PARAMETER"
  }
]
```

### レスポンス例

```json
{
  "duration": 3464,
  "server": "a83ad33525",
  "status": 200,
  "successful": true,
  "timestamp": "2021-09-05T23:38:06.907+08:00",
  "traceId": "9d3721be71e94f25"
}
```
