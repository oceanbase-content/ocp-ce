# すべてのテナントリストの確認

## 機能の概要

すべてのテナントリストを照会します。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

* 呼び出し元にクラスタ読み取り権限が付与されているテナントのみが返されます。

### リクエストパス

`GET /api/v2/ob/tenants`

### リクエストパラメータ

**body：**

|    パラメータ  |     型    | 必須 |   サンプル値  |        説明     |
|----------|-------------|------|----------|------------------|
| page     | Integer     | いいえ   | 1        | リクエストデータのページ番号。値は1から始まり、デフォルト値：1。      |

| name     | String      | いいえ   | foo      | キーワードを含むテナント名で検索します。大文字小文字は区別しません。      |
| mode     | StringArray | いいえ   | ORACLE   | 指定されたモードのテナントを検索します。取り得る範囲：<li>ORACLE：Oracleモード。</li><li>MYSQL：MySQLモード。</li>     |
| locked   | Boolean     | いいえ   | false    | テナントのロック状態に基づいて検索します。取り得る範囲：<li>指定しない場合、すべてのテナントを検索します。</li><li>値が `true` の場合、ロック状態のテナントのみを検索します。</li><li>値が `false` の場合、ロックされていないテナントのみを検索します。</li>      |

| readonly | Boolean     | いいえ   | false    | テナントの読み取り専用状態に基づいて検索します。取り得る範囲：<li>指定しない場合、すべてのテナントを検索します。</li><li>値が `true` の場合、読み取り専用状態のテナントのみを検索します。</li><li>値が `false` の場合、読み取り専用状態ではないテナントのみを検索します。</li> |
| status   | StringArray | いいえ   | NORMAL   | 指定された状態のテナントを検索します。取り得る範囲：<li>NORMAL：実行中。</li><li>CREATING：作成中。</li><li>MODIFYING：変更中。</li><li>UNAVAILABLE：利用不可。</li><li>OPERATING：運用中。</li><li>CLONING：クローン中。</li><li>RESTORING：復元中。</li><li>DISCONNECTING：切断中。</li><li>FAILOVER：フェイルオーバー。</li><li>SWITCHOVER：日常切り替え。</li><li>TDE_ENABLING：TDE暗号化中。</li>    |

| tagId    | Array       | いいえ   | -         | タグIDの集合。   |

## 例

### リクエスト例

テナント名にキーワード「foo」が含まれ、テナントの状態が「実行中」または「作成中」のテナントリストを照会します。リクエストのページネーションサイズが10の場合、2ページ目のデータです。

```json
GET /api/v2/ob/tenants?name=foo&status=NORMAL,CREATING&page=2&size=10
```
