# リソースユニット仕様の作成

## 機能説明

このインターフェースは、リソースユニット仕様を作成するために使用されます。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/unitSpecs`

### リクエストパラメータ

**body：**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|--------|
|  name  |  String  |  はい  |  C1  |  リソースユニット仕様名。  |
|  maxCpuCoreCount  |  Number  |  はい  |  1.5  |  CPUコア数。  |
|  maxMemorySize  |  Integer  |  はい  |  6  |  メモリ、単位はGiBです。  |

### 戻り結果

**基本データ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  data  |  Object  |  UnitSpecの情報。詳細は**UnitSpecデータ構造**を参照してください。  |
|  successful  |  Boolean |  リクエストが成功したかどうか。 |
|  timestamp |  Datetime  |  サーバーがリクエストを完了したタイムスタンプ。  |
|  duration |  Integer  |  サーバーがリクエストを処理した時間（ミリ秒）。  |
|  status |  Integer  |  HTTP Status仕様に準拠したエンコード。  |
|  traceId |  String  |  リクエストのTrace ID。問題の調査に使用されます。  |
|  server  |  String  |  リクエストに応答したアプリケーションサービスのアドレス。  |

**UnitSpecデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  id    |  Integer  | Unit仕様のID。   |
|  name  |  String  |  リソースユニット仕様名。  |
|  type  |  String  |  リソースユニット仕様タイプ。  |
|  maxCpuCoreCount  |  Number  |  最大CPUコア数。  |
|  minCpuCoreCount  |  Number  |  最小CPUコア数。  |
|  maxMemorySize  |  Integer  |  最大メモリ、単位はGiBです。  |
|  minMemorySize  |  Integer  |  最小メモリ、単位はGiBです。  |

## 例

### リクエスト例

`POST /api/v2/ob/unitSpecs`

```JSON
{
  "name": "C1",
  "maxCpuCoreCount": 1.5,
  "maxMemorySize": 6
}
```
