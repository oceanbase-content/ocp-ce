# リソースユニット仕様の作成

## 機能説明

このインターフェースは、ユニット仕様を作成するために使用されます。アクセス権限は`CLUSTER:*:READ`です。このインターフェースを使用するには、少なくともいずれかのクラスタに対する読み取り権限が必要です。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/unitSpecs`

### リクエストパラメータ

**body：**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|--------|
| name | String | はい | C1 | ユニット仕様名。空にすることはできません。英字で始まる2～32文字で、英字、数字、アンダースコアのみを使用できます。 |
| group | String | いいえ | Default | グループ名。 |
| maxCpuCoreCount | Double | はい | 1.5 | 最大CPUコア数。空にすることはできません。0.5～999の範囲で、0.5の整数倍を指定します。 |
| minCpuCoreCount | Double | いいえ | 1.5 | 最小CPUコア数。0.5～999の範囲で、0.5の整数倍を指定します。省略時はmaxCpuCoreCountと同じ値になります。maxCpuCoreCount以下である必要があります。 |
| maxMemorySize | Long | はい | 6 | 最大メモリ。単位はGiBです。空にすることはできません。値の範囲は1～10000です。 |
| minMemorySize | Long | いいえ | 6 | 最小メモリ。単位はGiBです。値の範囲は1～10000で、maxMemorySize以下である必要があります。省略時はmaxMemorySizeと同じ値になります。 |
| logDiskSize | Long | いいえ | 10 | ログディスクのサイズ。単位はGiBです。値の範囲は2～10000で、OB 4.0以降でのみ有効です。 |
| maxIops | Long | いいえ | 10000 | 最大IOPS。1024以上を指定します。OB 4.0以降でのみ有効です。 |
| minIops | Long | いいえ | 10000 | 最小IOPS。1024以上かつmaxIops以下を指定します。OB 4.0以降でのみ有効です。省略時はmaxIopsと同じ値になります。 |
| iopsWeight | Integer | いいえ | 1 | IOPSの重み。OB 4.0以降でのみ有効です。省略され、かつmaxIopsが空でない場合のデフォルト値は1です。 |
| dataDiskSize | Long | いいえ | 10 | ローカルキャッシュディスクのサイズ。単位はGiBです。SSでのみ使用されます。指定する場合は正の整数で、ceil(minCpuCoreCount × 2) GiB以上である必要があります。 |
| dataDiskQuota | Long | いいえ | 5 | Unitごとのデータストレージ割り当て量。単位はGiBです。指定する場合は2以上である必要があります。OB 4.0以降のSNクラスタでのみ有効です。 |
| maxNetBandwidth | Long | いいえ | 100 | ネットワーク帯域幅。単位はMbpsです。SSでのみ使用されます。指定する場合は0より大きい値である必要があります。 |
| storageArchitecture | String | いいえ | SHARED_NOTHING | 適用するストレージアーキテクチャ。指定可能な値はSHARED_NOTHING（分散型および集中型）とSHARED_STORAGE（AIクラスタ）です。NULLは汎用（SN/SSの両方で使用可能）を意味し、NULL以外の場合は指定したアーキテクチャにのみ適用されます。 |

### 戻り値

**基本データ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  data  |  Object  |  UnitSpecの情報。詳細は**UnitSpecデータ構造**を参照してください。  |
|  successful  |  Boolean |  リクエストが成功したかどうか。 |
|  timestamp |  Datetime  |  サーバーがリクエストを完了したタイムスタンプ。  |
|  duration |  Integer  |  サーバーがリクエストを処理した時間（ミリ秒）。  |
|  status |  Integer  |  HTTPステータスコード。  |
|  traceId |  String  |  リクエストのTrace ID。問題の調査に使用されます。  |
|  server  |  String  |  リクエストに応答したアプリケーションサービスのアドレス。  |

**UnitSpecデータ構造**

|  パラメータ  |  型  |  説明  |
|--------|--------|--------|
|  id    | Long  | ユニット仕様のID。   |
|  name  |  String  |  リソースユニット仕様名。  |
|  type  |  String  |  リソースユニット仕様タイプ。  |
|  maxCpuCoreCount  | Double  |  最大CPUコア数。0.5～999の範囲で、0.5の整数倍です。  |
|  minCpuCoreCount  | Double  |  最小CPUコア数。0.5～999の範囲で、0.5の整数倍です。  |
|  maxMemorySize  | Long  |  最大メモリ、単位はGiBです。  |
|  minMemorySize  | Long  |  最小メモリ、単位はGiBです。  |
| logDiskSize | Long | ログディスクのサイズ。単位はGiBです。 |
| maxIops | Long | 最大IOPS。1024以上です。 |
| minIops | Long | 最小IOPS。1024以上です。 |
| iopsWeight | Integer | IOPSの重み。 |
| notRecommended | Boolean | OBバージョンが指定されており、そのバージョンのOBクラスタでこのユニット仕様を使用することが適切でない場合はtrueとなり、使用が推奨されないことを示します。 |
| dataDiskSize | Long | ローカルキャッシュディスクのサイズ。単位はGiBです。SSでのみ使用されます。 |
| dataDiskQuota | Long | Unitごとのデータストレージ割り当て量。単位はGiBです。OB 4.0以降のSNクラスタでのみ有効です。 |
| maxNetBandwidth | Long | ネットワーク帯域幅。単位はMbpsです。SSでのみ使用されます。指定する場合は0より大きい値である必要があります。 |
| storageArchitecture | String | 適用するストレージアーキテクチャ。指定可能な値はSHARED_NOTHING（分散型および集中型）とSHARED_STORAGE（AIクラスタ）です。NULLは汎用（SN/SSの両方で使用可能）を意味し、NULL以外の場合は指定したアーキテクチャにのみ適用されます。 |
| unitSpecLimit | Object | OBバージョンが指定されており、そのバージョンのOBクラスタでこのユニット仕様を使用することが適切でない場合に返されます。制限の説明を含むオブジェクトです。 |

## 例

### リクエスト例

`POST /api/v2/ob/unitSpecs`

```JSON
{
  "name": "C1",
  "maxCpuCoreCount": 1.5,
  "maxMemorySize": 6
}
```
