# テナント詳細のクエリ

## 機能説明

指定したテナントの詳細を照会します。

## 呼び出し説明

### インターフェース制約

呼び出し元は、指定されたクラスタに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}`

**パス：**

|    パラメータ     |  タイプ  | 必須 | サンプル値 |      説明       |
|-----------|------|----|-----|---------------|
| id        | Long | はい  | 1000014   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId  | Long | はい  | 1000007   | 対象テナントのOCP側のテナントID。      |

### 戻り値

**基本データ構造**

|     パラメータ     |    タイプ    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | テナント詳細。詳細については、**テナント詳細のデータ構造**を参照してください。    |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコード。 |
| traceId    | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server     | String   | リクエストに応答したサーバーのアドレス。          |

**テナント詳細のデータ構造**

|     パラメータ      |    タイプ    |     説明    |
|-------------|----------|--------------|
| id          | Long     | OCP側のテナントID。 |
| name        | String   | テナント名。   |
| clusterName | String   | テナントが属するクラスタ名。    |
| clusterId   | Long     | テナントが属するクラスタのOCP側のクラスタID。      |
| obClusterId | Long     | テナントが属するクラスタのOceanBase側のクラスタID。     |
| clusterType | String   | テナントが属するクラスタのタイプ。値の範囲：<li>PRIMARY：プライマリクラスタ。</li><li>STANDBY：スタンバイクラスタ。</li>     |
| mode        | String   | テナントのモード。値の範囲：<li>ORACLE：Oracleモード。</li><li>MYSQL：MySQLモード。</li>     |
| createTime  | Datetime | テナントの作成日時。      |
| primaryZone | String   | テナントのゾーン優先順位。      |
| zoneList    | String   | テナントのゾーンリスト。       |
| locality    | String   | テナントのレプリカ分散。     |
| status      | String   | テナントの状態。 値の範囲：<li>NORMAL：正常。</li><li>UNAVAILABLE：利用不可。</li><li>CREATING：作成中。</li><li>OPERATING：運用中。</li><li>MODIFYING：変更中。</li><li>CLONING：クローン中。</li><li>RESTORING：テナントの復元中。</li><li>DISCONNECTING：分離中。</li><li>FAILOVER：災害復旧切り替え。</li><li>SWITCHOVER：日常切り替え。</li><li>MOVED_OUT：移出済み。</li><li>TDE_ENABLING：透過的データ暗号化（TDE）の有効化中。</li>    |
| locked      | Boolean  | テナントがロック状態にあるかどうか。       |
| readonly    | Boolean  | テナントが読み取り専用状態にあるかどうか。       |
| obVersion   | String   | テナントが属するクラスタのOceanBaseバージョン。        |
| description | String   | テナントの説明情報。        |
| charset     | String   | 文字セット。     |
| collation   | String   | 照合規則。    |
| zones       | Array    | 詳細は**TenantZoneデータ構造**を参照してください。       |
| whitelist   | String   | 許可リスト。     |
| loadType    | Enum     | 負荷タイプ：<li>EXPRESS_OLTP</li><li>COMPLEX_OLTP</li><li>HTAP</li><li>OLAP</li><li>KV</li> |

**TenantZoneデータ構造**

|      パラメータ      |   型   |        説明         |
|--------------|--------|-------------------|
| name         | String | ゾーン名。             |
| replicaType  | String | レプリカタイプ。              |
| resourcePool | Object | 詳細は**ResourcePoolデータ構造**を参照してください。 |
| units        | Array  | 詳細は**Unitデータ構造**を参照してください。           |

**ResourcePoolデータ構造**

|     パラメータ     |   型    |       説明        |
|------------|---------|-----------------|
| id         | String  | リソースプールID。          |
| name       | String  | リソースプール名。           |
| unitCount  | Integer | Unit数。         |
| unitConfig | Object  | 詳細は**UnitConfigデータ構造**を参照してください。 |

**UnitConfigデータ構造**

|       パラメータ        |   型    |     説明     |
|-----------------|---------|------------|
| maxCpuCoreCount | Double  | 最大CPUコア数。  |
| minCpuCoreCount | Double  | 最小CPUコア数。  |
| maxMemorySize   | Integer | 最大メモリ、単位GiB。 |
| minMemorySize   | Integer | 最小メモリ、単位GiB。 |

**Unitデータ構造**

|       パラメータ       |   型    |       説明       |
|----------------|---------|----------------|
| id             | Integer | Uint ID。        |
| resourcePoolId | Integer | 所属リソースプールID。       |
| serverId       | Integer | 所属OBServerノードID。 |
| serverIp       | String  | 所属OBServerノードIP。 |
| serverPort     | Integer | 所属OBServerノードポート。 |
| zoneName       | String  | ゾーン名。        |
| status         | String  | Unitの状態。        |
