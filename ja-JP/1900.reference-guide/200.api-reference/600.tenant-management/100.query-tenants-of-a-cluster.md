# クラスタのテナントリストを取得する

## 機能の概要

クラスタのテナントリストを取得します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、指定されたクラスタに対する読み取り権限を持っている必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants`

### リクエストパラメータ

**path：**

|   パラメータ    |    型     | 必須 |  サンプル値  |          説明      |
|-----------|-------------|------|----------|-----------------------|
| id        | Integer     | はい   |   1000002      | OCP側のクラスタID。      |

**body：**

|   パラメータ    |    型    | 必須 |   サンプル値    |          説明      |
|-----------|-------------|------|----------|-----------------------|
| page      | Integer     | いいえ  | 0        | リクエストデータのページ番号。値は1から始まり、デフォルト値は1です。        |
| size      | Integer     | いいえ  | 10       | リクエストデータのページサイズ。デフォルト値：10、最大値：2000。      |
| sort      | String      | いいえ  | asc,name | ソート規則。         |
| name      | String      | いいえ  | foo      | クラスタ名のキーワード。大文字と小文字は区別されません。           |
| mode      | String      | いいえ  | MYSQL    | テナントモード：MYSQL、ORACLE。         |
| locked    | Boolean     | いいえ  | true     | ロックされているかどうか。        |
| readonly  | Boolean     | いいえ  | Boolean  | 読み取り専用かどうか。        |
| status    | StringArray | いいえ  | CREATING | テナントの状態：<li>NORMAL：実行中。</li><li>CREATING：作成中。</li><li>MODIFYING：変更中。</li><li>UNAVAILABLE：利用不可。</li><li>OPERATING：運用中。</li><li>CLONING：クローン中。</li><li>RESTORING：復元中。</li><li>DISCONNECTING：切断中。</li><li>FAILOVER：災害復旧切り替え。</li><li>SWITCHOVER：日常切り替え。</li><li>TDE_ENABLING：TDE暗号化中。</li>    |

### 戻り値

**基本データ構造**

|        パラメータ        |    型    |          説明           |
|------------------|----------|-----------------------|
| data             | Object   | リクエストされた業務データ。               |
| ├─ contents      | Array    | 詳細は **テナント情報のデータ構造** を参照してください。     |
| ├─ page          | Object   | ページ情報。                 |
| ├─ totalElements | Integer  | 総レコード数。                 |
| ├─ totalPages    | Integer  | 総ページ数。                  |
| ├─ number        | Integer  | 現在のページ番号。                 |
| ├─ size          | Integer  | 現在のページサイズ。                |
| successful       | Boolean  | リクエストが成功したかどうか。               |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status           | Integer  | HTTPステータスコード。 |
| traceId          | String   | リクエストのトレースID。問題の調査に使用されます。  |
| server           | String   | リクエストに応答したサーバーのアドレス。          |

**テナント情報のデータ構造**

|     パラメータ    |    型    |     説明        |
|-------------|----------|-------------|
| id          | Integer  | OCP側のテナントID。    |
| name        | String   | テナント名。     |
| clusterName | String   | テナントが属するクラスタ名。     |
| clusterId   | Integer  | テナントが属するクラスタのOCP側でのクラスタID。      |
| obClusterId | Integer  | テナントが属するクラスタのOceanBase側でのクラスタID。      |
| clusterType | String   | テナントが属するクラスタのタイプ。値の範囲：<li>PRIMARY：プライマリクラスタ。</li><li>STANDBY：スタンバイクラスタ。</li>       |
| mode        | String   | テナントのモード。値の範囲：<li>ORACLE：Oracleモード。</li><li>MYSQL：MySQLモード。</li>           |
| createTime  | Datetime | テナントの作成日時。     |
| primaryZone | String   | テナントのゾーン優先順位。        |
| zoneList    | String   | テナントのゾーンリスト。     |
| locality    | String   | テナントのレプリカ配置。        |
| status      | String   | テナントの状態。値の範囲：<li>NORMAL：稼働中。</li><li>CREATING：作成中。</li><li>MODIFYING：変更中。</li><li>UNAVAILABLE：利用不可。</li><li>OPERATING：運用中。</li><li>CLONING：クローン中。</li><li>RESTORING：復元中。</li><li>DISCONNECTING：切断中。</li><li>FAILOVER：フェイルオーバー。</li><li>SWITCHOVER：日常切り替え。</li><li>TDE_ENABLING：TDE暗号化中。</li>    |
| locked      | Boolean  | テナントがロック状態にあるかどうか。    |
| readonly    | Boolean  | テナントが読み取り専用状態にあるかどうか。      |
| obVersion   | String   | テナントが属するクラスタのOceanBaseバージョン。       |
| description | String   | テナントの説明情報。       |
| loadType    | Enum     | ロードタイプ：<li>EXPRESS_OLTP</li><li>COMPLEX_OLTP</li><li>HTAP</li><li>OLAP</li><li>KV</li> |
| arbitrationStatus   | Enum     | アービトレーションサービスの状態。値の範囲：<li>ENABLED：有効。</li><li>ENABLING：起動中。</li><li>DISABLED：無効。</li><li>DISABLING：無効化中。</li>     |

```json
GET /api/v2/ob/clusters/1000002/tenants
```
