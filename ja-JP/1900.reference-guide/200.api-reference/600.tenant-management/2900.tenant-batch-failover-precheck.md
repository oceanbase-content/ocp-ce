# 災害復旧フェイルオーバーの一括実行の事前チェック

## 機能説明

このAPIは、ネットワークを基盤としたプライマリ/スタンバイテナントの災害復旧フェイルオーバーの一括実行の事前チェックに使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元にはテナントを変更する権限が付与されていなければなりません。

  呼び出し元の権限については、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/failoverPreCheck`

### リクエストパラメータ

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|---------|---------|---------|---------|----------|
| id   | Integer | はい   | 3000010      | スタンバイテナントが属するクラスタのOCP側のクラスタID。 |

### 戻り値

| パラメータ | 型 | 説明 |
|----------|----------|----------|
| data       | ObTenantPreCheckResult | チェック結果。詳細は**ObTenantPreCheckResultデータ構造**を参照してください。 |
| successful | Boolean                | リクエストが成功したかどうか。 |
| timestamp  | Datetime               | サーバーがリクエストを完了したタイムスタンプ。 |
| duration   | Integer                | サーバーがリクエストを処理した時間(ミリ秒)。 |
| status     | Integer                | HTTP Status仕様に準拠したコード。 |
| traceId    | String                 | リクエストのTrace ID。問題のトラブルシューティングに使用されます。 |
| server     | String                 | リクエストに応答したアプリケーションサービスのアドレス。 |

**ObTenantPreCheckResultデータ構造**

| パラメータ | 型 | 説明 |
|-----------|----------|----------|
| valid                    | Boolean        | スタンバイテナントの切り替えが許可されているかどうか。 |
| tenantId                 | Long           | OCP側のスタンバイテナントID。 |
| name                     | String         | スタンバイテナント名。 |
| clusterId                | Long           | スタンバイテナントが属するクラスタのOCP側でのクラスタID。 |
| clusterName              | String         | スタンバイテナントのクラスタ名。 |
| syncScn                  | Long           | スタンバイテナントの同期遅延。 |
| primaryTenantServiceName | String         | 元のプライマリテナントサービス名。 |
| serviceName              | String         | 新しいプライマリテナントサービス名。 |
| checkResults             | PreCheckResult | 失敗情報リスト。詳細は**PreCheckResultデータ構造**を参照してください。 |

**PreCheckResultデータ構造**

| パラメータ | 型 | 説明 |
|----------|----------|-----------|
| warning      | Boolean | 警告かどうか。値が`true`の場合は警告で、切り替えプロセスに影響しません。値が`false`の場合はエラーで、切り替えに影響します。 |
| errorCode    | String  | 例外コード。 |
| errorMessage | String  | 例外情報。 |
