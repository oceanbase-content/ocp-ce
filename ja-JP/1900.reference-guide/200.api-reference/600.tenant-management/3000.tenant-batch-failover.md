# バッチディザスタリカバリフェイルオーバー

## 機能の概要

このAPIは、ネットワークベースでプライマリ・スタンバイテナントのバッチディザスタリカバリフェイルオーバーを実行するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元にはテナントを変更する権限が付与されていなければなりません。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/failover`

### リクエストパラメータ

**path：**

| パラメータ | 型    | 必須 | サンプル値 | 説明           |
|------|---------|------|--------|-----------------|
| id   | Integer | はい   | 3000010      | スタンバイテナントが属するクラスタのOCP側のクラスタID。 |

**body：**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|----------|---------|--------|--------|---------|
| failoverTenantItemList | FailoverTenantItem  | いいえ | SERVICE_A | 切り替えるスタンバイテナントのリスト。詳細は**FailoverTenantItemデータ構造**を参照してください。 |

**FailoverTenantItemデータ構造**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|---------|---------|---------|---------|---------|
| tenantId    | Long   | はい | 2000025   | スタンバイテナントのOCP側のテナントID。 |
| serviceName | String | いいえ | serviceA  | 新しいプライマリテナントのサービス名。 |

### 戻り結果

| パラメータ | 型 | 説明 |
|----------|---------|---------|
| data       | TaskInstance | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean      | リクエストが成功したかどうかを示します。 |
| timestamp  | Datetime     | サーバー側がリクエストを完了したタイムスタンプです。 |
| duration   | Integer      | サーバー側がリクエストを処理した時間（ミリ秒）です。 |
| status     | Integer      | HTTP Status仕様に準拠したコードです。 |
| traceId    | String       | 問題の調査に使用されるリクエストのTrace IDです。 |
| server     | String       | リクエストに応答したアプリケーションサービスのアドレスです。 |

## 例

### リクエスト例

**パス：**

`POST /api/v2/ob/clusters/3000010/tenants/failover`

**ボディ：**

```json
{
  "failoverTenantItemList":[
    {
      "tenantId" : 2000025,
      "serviceName": "serviceA"
    }
  ]
}
```
