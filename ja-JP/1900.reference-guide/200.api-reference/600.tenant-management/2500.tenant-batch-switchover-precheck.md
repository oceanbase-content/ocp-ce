# バッチ日常スイッチオーバーの事前チェック

## 機能説明

このAPIは、プライマリテナントとスタンバイテナントのバッチ日常スイッチオーバー(Switchover)の事前チェックに使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元にはテナントを変更する権限が付与されていなければなりません。

  呼び出し元の権限について詳細は、[ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md)を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/switchoverPreCheck`

### リクエストパラメータ

**path：**

| パラメータ | 型    | 必須 | サンプル値 | 説明           |
|------|---------|------|--------|-----------------|
| id   | Integer | はい   | 3000010      | プライマリテナントが属するクラスタのOCP側のクラスタID。 |

**body：**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|---------|----------|----------|----------|----------|
| tenantParamList | SwitchoverObTenantParam | はい | - | スイッチオーバー対象のプライマリ/スタンバイテナントごとのアイテムです。詳細は**SwitchoverObTenantParamデータ構造**を参照してください。 |

**SwitchoverObTenantParamデータ構造**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|---------|---------|---------|---------|---------|
| tenantId        | Long | はい | 2000025 | プライマリテナントのOCP側のテナントID。 |
| standbyTenantId | Long | はい | 2000022 | スタンバイテナントのOCP側のテナントID。 |
| standbyOcpClusterId | Long   | いいえ   | 100001   | スタンバイテナントが存在するOCPクラスタID。OCPがマルチクラスタモードの場合は必須です。 |

### 戻り結果

| パラメータ | 型 | 説明 |
|----------|-----------|-----------|
| data       | SwitchoverPreCheckResult  | 複数のチェック結果データ構造については、**SwitchoverPreCheckResult データ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。 |
| timestamp  | Datetime | サーバー側がリクエストを完了したタイムスタンプです。 |
| duration   | Integer  | サーバー側がリクエストを処理した時間（ミリ秒）。 |
| status     | Integer  | HTTP Status仕様に準拠したエンコードです。 |
| traceId    | String   | リクエストのTrace IDであり、問題のトラブルシューティングに使用されます。 |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。 |

**SwitchoverPreCheckResult データ構造**

| パラメータ | 型 | 説明 |
|----------|----------|-----------|
| valid       | Boolean | プリフライトチェックの結果です。 |
| tenantId    | Long    | プライマリテナントのOCP側のテナントIDです。 |
| name        | String  | プライマリテナント名です。 |
| clusterId   | Long    | プライマリテナントが属するクラスタのOCP側のクラスタIDです。 |
| clusterName | String  | プライマリテナントのクラスタ名です。 |
| standbyCheckResults | ObTenantPreCheckResult | 詳細については、**ObTenantPreCheckResult データ構造**を参照してください。 |

**ObTenantPreCheckResult データ構造**

| パラメータ | 型 | 説明 |
|--------|--------|---------|
| valid        | Boolean | スタンバイテナントの切り替えが許可されているかどうかを示します。 |
| tenantId     | Long    | スタンバイテナントのOCP側のテナントIDです。 |
| name         | String  | スタンバイテナント名です。 |
| clusterId    | Long    | スタンバイテナントが属するクラスタのOCP側のクラスタIDです。 |
| clusterName  | String  | スタンバイテナントのクラスタ名です。 |
| syncScn      | Long    | スタンバイテナントの同期遅延です。 |
| primaryTenantServiceName | String | プライマリテナントのサービス名です。 |
| checkResults | PreCheckResult | 失敗情報のリストです。詳細については、**PreCheckResult データ構造**を参照してください。 |

**PreCheckResult データ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| warning | Boolean | 警告かどうかを示します。値が `true` の場合は警告であり、切り替えプロセスに影響しません。値が `false` の場合はエラーであり、切り替えに影響します。 |
| errorCode | String | 例外コードです。 |
| errorMessage | String | 例外情報です。 |
