# スタンバイテナントの作成

## 機能の概要

このAPIは、指定されたOceanBaseクラスタにスタンバイテナントを作成するために使用します。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元はクラスタの変更権限を持っている必要があります。

  呼び出し元の権限については、詳細は [ユーザーと権限の概要](../../../1600.system-management-features/200.manage-users/50.user-management-overview.md) を参照してください。

* 呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/createStandbyTenant`

### リクエストパラメータ

**path：**

| パラメータ | 型    | 必須 | サンプル値 | 説明           |
|------|---------|------|--------|-----------------|
| id   | Integer | はい   | 3000010      | 対象テナントが属するクラスタのOCP側のクラスタID。 |

**body：**

| パラメータ              | 型 | 必須 | サンプル値 | 説明 |
|-------------------|---------|--------|--------|---------|
| name              | String      | はい | standbyA | テナント名。 |
| primaryZone       | String      | いいえ | zone1;zone2;zone3 | primaryZoneの設定。 |
| primaryTenantId   | Integer     | はい | 1 | プライマリテナントの主キーID、すなわちプライマリテナントのOCP側のテナントID。 |
| standbyROPassword | String      | いいえ | tenantA | スタンバイテナントのログ同期用読み取り専用ユーザーのパスワード。 |
| logTransportMode  | String      | はい | NETWORK | ネットワーク（NETWORK）とログバックアップ（LOG_BACKUP）を含みます。|
| restoreTenant     | Boolean     | いいえ | false | バックアップセットを使用してスタンバイテナントを復元するかどうか。`logTransportMode`が`NETWORK`の場合のみ有効です。バックアップセットに基づいてネットワークスタンバイデータベースを作成するかどうかを示します。 |
| enableArbitration | Boolean     | いいえ | false | アービトレーションを有効にするかどうか。 |
| backupConfig      | BackupConfigParam    | いいえ | - | バックアップセット情報。ネットワークスタンバイデータベースを直接作成する場合、またはOCPの既存のバックアップポリシーを使用してスタンバイデータベースを作成する場合は、このパラメータを指定する必要はありません。詳細については、**BackupConfigParamデータ構造**を参照してください。 |
| serviceName       | String      | いいえ | Service_A | サービス名。 |
| zones             | ZoneParam   | はい | - | 詳細については、**ZoneParamデータ構造**を参照してください。 |
| parameters        | TenantParameterParam | いいえ | - | 詳細については、**TenantParameterParamデータ構造**を参照してください。 |
| description       | String      | いいえ | this is standby tenant | 説明。 |
| loadType          | Enum        | いいえ | EXPRESS_OLTP       | ロードタイプ：<li>EXPRESS_OLTP</li><li>COMPLEX_OLTP</li><li>HTAP</li><li>OLAP</li><li>KV</li> |

**BackupConfigParamデータ構造**

| パラメータ              | 型    | 必須   | サンプル値   | 説明  |
|-------------------|---------|-------|----------|-------|
| useCustomStorage  | boolean | いいえ    | true     | カスタムストレージディレクトリを使用するかどうか。この値がtrueの場合、dataBackupUrlとlogBackupUrlは空にできません。  |
| backupStorageType | Enum    | はい    | BACKUP_STORAGE_FILE | <li>BACKUP_STORAGE_FILE：NFSストレージ。<li></li>BACKUP_STORAGE_OSS: OSSストレージ。<li></li>BACKUP_STORAGE_S3: S3ストレージ。</li> |
| storageUrl        | String  | はい    | バックアップポリシー内のストレージパスURL。プロトコルなしのディレクトリ、例えば `/obbackup/` または `osstest/backup` に設定してください。    |
| dataBackupUrl     | String  | はい    | `/obbackup/clusterA/tenantA/data` | データバックアップディレクトリ。 |
| logBackupUrl      | String  | はい    | `/obbackup/clusterA/tenantA/clog` | ログバックアップディレクトリ。 |
| ossSecretModel    | ObjectStorageSecretParam       | いいえ    | - | オブジェクトストレージキー情報。ストレージモードがOSS/S3の場合にのみこのパラメータを指定する必要があります。詳細については、**ObjectStorageSecretParamデータ構造**を参照してください。 |

**ObjectStorageSecretParamデータ構造**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|-----------------|--------|------|-------|--------|
| endpoint        | String | はい | `oss.endpoint.sahnghai.com` | オブジェクトストレージのドメイン名。 |
| accessKeyId     | String | はい | - | オブジェクトストレージAK。 |
| accessKeySecret | String | はい | - | オブジェクトストレージSK。 |
| region          | String | いいえ | - | リージョン情報。空でも構いません。AWSネイティブS3ストレージメディアのみで入力が必要です。  |

**ZoneParamデータ構造**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|-----------------|--------|------|-------|--------|
| name         | String | はい | zone1 | クラスタ内のゾーン名。 |
| replicaType  | String | はい | FULL  | 値の範囲：<li>FULL</li><li>LOGONLY</li><li>READONLY</li><li>COLUMNSTORE</li>   |
| resourcePool | Object | はい | -     | リソースプール。 |

**TenantParameterParamデータ構造**

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
|---------------|--------|----|------------------------|-----------------|
| name          | String | はい  | ob_default_replica_num | パラメータ。OceanBaseのデフォルトレプリカ数を表します。 |
| value         | String | はい  | 2                      | パラメータ値。            |
| parameterType | String | はい  | OB_SYSTEM_VARIABLE  | パラメータタイプ。値はOB_SYSTEM_VARIABLE（変数）またはOB_TENANT_PARAMETER（パラメータ）です。  |

### 実行結果

**基本データ構造**

| パラメータ | 型 | 説明 |
|---------|---------|---------|
| data | Object | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。 |
| successful | Boolean | リクエストが成功したかどうか。 |
| timestamp | Datetime | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | Integer | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | Integer | HTTPステータスコード。 |
| traceId | String | リクエストのTrace ID。問題の調査に使用されます。 |
| server | String | リクエストに応答したアプリケーションサービスのアドレス。 |
