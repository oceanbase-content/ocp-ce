# テナントパラメータリストの取得

## 機能説明

テナントパラメータリストを取得するために使用するインターフェースです。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/parameters`

### リクエストパラメータ

**path:**

|    パラメータ    |   型    | 必須 | サンプル値 |       説明        |
|----------|---------|-------|-------|-----------------|
| id       | Long | はい  | 1000001   | 対象テナントが属するクラスタのOCP側のクラスタID。 |
| tenantId | Long | はい  | 1000002   | 対象テナントのOCP側のテナントID。 |

### 戻り値

**基本データ構造**

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Array    | TenantParameterのリスト。詳細は**TenantParameterデータ構造**を参照してください。    |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコード。 |
| traceId    | String   | リクエストのTrace ID。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**TenantParameterデータ構造**

|       パラメータ       |   型    |      説明          |
|----------------|---------|----------------------|
| name           | String  | パラメータ名。   |
| compatibleType | String  | 互換タイプ。取り得る範囲：<li>ORACLE</li><li>MYSQL</li>    |
| readonly       | Boolean | 読み取り専用かどうかを示します。  |
| defaultValue   | String  | デフォルト値です。  |
| currentValue   | String  | 現在の値です。   |
| description    | String  | パラメータの説明です。  |
| valueRange     | Object  | 詳細については、**ValueRangeデータ構造**を参照してください。     |

**ValueRangeデータ構造**

|      パラメータ       |   型   |   説明   |
|---------------|--------|--------|
| type          | String | パラメータタイプです。   |
| allowedValues | String | 許可される値のリストです。 |
| maxValue      | String | パラメータの最大値です。  |
| minValue      | String | パラメータの最小値です。  |
