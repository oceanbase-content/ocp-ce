# テナントの作成

## 機能の概要

指定されたクラスタ内に単一のテナントを作成する際に使用するインターフェースです。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/createTenant`

### リクエストパラメータ

**path：**

| パラメータ |   型    | 必須 | サンプル値 |  説明   |
|----|---------|----|-----|-------|
| id | Integer | はい  | 2000017   | 対象テナントが属するクラスタのOCP側でのクラスタID。 |

### 戻り値

基本データ構造

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | 非同期タスク情報。詳細については、[タスク情報](../400.task-return-structure.md)を参照してください。            |
| successful | Boolean  | リクエストが成功したかどうかを示します。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTPステータスコードです。 |
| traceId    | String   | リクエストのTrace IDであり、問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。         |
