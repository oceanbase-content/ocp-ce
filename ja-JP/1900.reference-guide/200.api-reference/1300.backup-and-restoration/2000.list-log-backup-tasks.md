# テナントのログバックアップタスクを表示する

## 機能の概要

このAPIは、テナントのログバックアップタスクを表示するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/task/logBackupTasks`

### リクエストパラメータ

**Pathパラメータ**

|  パラメータ      |  タイプ     |  必須  |  サンプル値  |  説明       |
|------------|-----------|--------|----------|-------------|
|  id        |  Integer  |  はい    |  1002    |  クラスタID。  |
|  tenantId  |  Integer  |  はい    |  108     |  テナントID。  |

**Queryパラメータ**

|  パラメータ       |  タイプ    |  必須  |  サンプル値                    |  説明     |
|-------------|----------|--------|----------------------------|------------|
|  startTime      |  String  |  いいえ     |  2024-08-06T00:00:00Z       |   開始時間。この時間はUTC時刻のみをサポートし、形式はYYYY-MM-DDThh:mm:ssZです。         |
|  endTime        |  String  |  いいえ     |  2024-08-07T00:00:00Z       |   終了時間。この時間はUTC時刻のみをサポートし、形式はYYYY-MM-DDThh:mm:ssZです。         |
|  status     |  Array   |  いいえ    |  STARTING                  |  タスクの状態。<li>STARTING：起動中。 </li><li> INPROGRESS：進行中。 </li><li> STOPPING：停止中。 </li><li> STOPPED：停止済み。 </li><li> FAILED：失敗。 </li><li> INTERRUPTED：中断された。 </li><li> UNKNOWN：不明。 </li>  |

### 戻り値

**基本データ構造**

|  パラメータ  |  タイプ  | 説明                               |
|---------|----------|----------------------------------|
|  data  |  Object  | 詳細は **`LogBackupWrapperTask` のデータ構造** を参照してください。 |
|  successful  |  Boolean | リクエストが成功したかどうか。                          |
|  timestamp |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status |  Integer  | HTTP Status仕様に準拠したエンコード。            |
|  traceId |  String  | リクエストのTrace ID。問題のトラブルシューティングに使用されます。             |
|  server  |  String  | リクエストに応答するアプリケーションサービスのアドレス。                    |

**`LogBackupWrapperTask`のデータ構造**

|     パラメータ    |    型   |            説明            |
|-------------|-----------|--------------------------|
| backupDimension       | String  | バックアップの次元。例えば、CLUSTERはクラスタバックアップを表し、TENANTはテナントバックアップを表します。 |
| createTime  | Timestamp | 作成日時。                    |
| modifyTime  | Timestamp | 更新日時。                    |
| clusterName | String    | クラスタ名。                     |
| clusterId   | Long      | クラスタID。                   |
| obClusterId | Long      | OceanBaseクラスタID。                |
| obTenantId  | Long      | OceanBase側のテナントID。               |
| clusterType | String    | クラスタタイプ。以下を含みます：<li>PRIMARY：プライマリクラスタ。</li><li>STANDBY：スタンバイクラスタ。</li> |
| tenantId    | Long      | テナントID。                   |
| tenantName  | String    | テナント名。                     |
| status      | String    | ステータス。                      |
| errorMsg    | String    | エラーメッセージ。                    |
| backupUri   | String    | バックアップパス。                    |
| checkpoint  | Timestamp | 最新チェックポイント。                    |
| backupMode  | String    | バックアップモード。                    |
| delay       | Long      | ログの遅延時間。単位は秒です。               |
