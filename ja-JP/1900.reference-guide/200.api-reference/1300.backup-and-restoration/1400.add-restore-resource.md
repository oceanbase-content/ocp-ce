# リストアリソースの追加

## 機能の概要

このAPIは、リストアリソースのパスを手動で追加するために使用されます。

## 呼び出しの説明

### インターフェース制約

なし

### リクエストパス

`POST /api/v2/ob/backup/restore/addRestoreSource`

### リクエストパラメータ

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- |
| restoreClusterId | Integer | はい | 1001 | リストア時のターゲットクラスタのID。 |
| restoreSources | Array | はい | file:///obbackup/backup_3245/1704259760/incarnation_1/1002/data/backup_set_24_full_20240406, file:///obbackup/backup_3245/1704259760/incarnation_1/1002/clog/6_38_20240405 | リストアリソースのパスの集合。 |

### 戻り結果

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | リクエストが成功したかどうか。 |
| timestamp | Datetime | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | Integer | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | Integer | HTTP Status仕様に準拠したコード。 |
| traceId | String | リクエストのTrace Id。問題のトラブルシューティングに使用されます。 |
| server | String | リクエストに応答したアプリケーションサービスのアドレス。 |

## 例

### リクエスト例

```json
restoreClusterId:14
restoreSources:file:///obbackup/backup_3245/1704259760/incarnation_1/1002/data/backup_set_24_full_20240406, file:///obbackup/backup_3245/1704259760/incarnation_1/1002/clog/6_38_20240405
```
