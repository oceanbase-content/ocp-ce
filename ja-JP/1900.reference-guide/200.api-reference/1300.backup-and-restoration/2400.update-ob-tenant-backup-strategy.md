# テナントのバックアップポリシーを更新する

## 機能の概要

このAPIは、テナントのバックアップポリシーを更新するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`PATCH /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/config/backupStrategy`

### リクエストパラメータ

**パスパラメータ**

|  パラメータ      |  型     | 必須  |  サンプル値 |  説明   |
|------------|-----------|------|--------|---------|
|  id        |  Integer  |  はい  | 1002   |  クラスタID  |
|  tenantId  |  Integer  |  はい  | 108    |  テナントID  |

**ボディパラメータ**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|--------|
|  backupMode  |  String  |  はい  | LOGICAL_BACKUP |  バックアップモード。<li>LOGICAL_BACKUP：論理バックアップ。</li><li>PHYSICAL_BACKUP：物理バックアップ。</li>    |
|  obBackupScheduleConfig  |  Obbackupscheduleconfig  |  はい  |   NA  | バックアップスケジュール設定。詳細については、**`obBackupScheduleConfig`のデータ構造**を参照してください。       |
|  obBackupThresholdConfig  |  Obbackupthresholdconfig  |  はい  | NA  | バックアップアラートしきい値設定。詳細については、**`obBackupThresholdConfig`のデータ構造**を参照してください。 |
|  obBackupServiceStorageConfig  |  Obbackupservicestorageconfig  |  はい  | NA  | バックアップストレージ設定。詳細については、**`obBackupServiceStorageConfig`のデータ構造**を参照してください。  |

**`obBackupScheduleConfig`のデータ構造**

|   パラメータ    |     型     | 必須 |      説明     |
|-----------|--------------|------|---------------|
| backupScheduleMode       | String     | はい  | バックアップスケジュール周期。<li>WEEK：週。</li><li>MONTH：月。</li>    |
| backupScheduleEnabled    | Boolean    | いいえ  | バックアップスイッチ。     |
| backupScheduleTime       | OffsetTime | はい  | バックアップスケジュール時間。"02:00:00.000+08:00"など。  |
| dayAndDataBackupModelMap | Map        | はい  | スケジュール日とそのデータバックアップ方式。例えば、{ "2": "FULL_BACKUP", "4": "FULL_BACKUP", "6": "INCREMENTAL_BACKUP" }は、火曜日と木曜日にフルデータバックアップを行い、土曜日に増分データバックアップを行うことを表します。 |
| startLogBackup           | Boolean    | はい  | ログバックアップを同時に開始するかどうか。通常は`true`に設定します。      |
| cleanEnabled             | Boolean    | いいえ  | 期限切れデータのクリーンアップスイッチ。       |
| backupDataRetentionDays  | Long       | いいえ  | バックアップデータの保持日数。例えば7日は、直近7日間のバックアップデータを最低限保持することを意味します。`cleanEnabled=true`の場合にのみ有効です。    |
| cleanScheduleTime        | OffsetTime | いいえ  | 期限切れデータのクリーンアップスケジュール時間。     |

**`obBackupThresholdConfig`のデータ構造**

|               パラメータ              |  型  | 必須   |             説明              |
|---------------------------------|--------|-------|-----------------------------|
| dataBackupTimeoutMinutes        | Long | はい  | データバックアップスケジュールのタイムアウト時間。単位は分です。           |
| noSuccessfulDataBackupAlarmDays | Long | はい  | 成功したデータバックアップアラートがトリガーされない最大日数。           |
| libObLogExpireDays              | Long | いいえ  | liboblogの保持日数。論理バックアップモードでのみ有効です。 |
| logBackupDelaySeconds           | Long | はい  | ログバックアップ遅延アラートのしきい値。単位は秒です。            |

**`obBackupServiceStorageConfig`のデータ構造**

|     パラメータ  |   型     | 必須   |   説明     |
|-----------|----------|-------|---------------|
| configName                                 | String | はい  | ストレージ設定名。    |
| obBackupStorageBaseInfo                    | Object | はい  | ストレージ設定の基本パラメータ。   |
| \|--backupStorageType                      | String | はい  | ストレージタイプ。現在 `BACKUP_STORAGE_FILE`、`BACKUP_STORAGE_OSS`、`BACKUP_STORAGE_S3` タイプをサポートしています。   |
| \|--storageUrl                             | String | はい  | ストレージディレクトリ。プロトコルなしのディレクトリに設定してください。例：`/obbackup/` または `osstest/backup`。    |
| \|--ossAccessKey                           | Object | いいえ  | OSS情報。`backupStorageType=BACKUP_STORAGE_OSS` の場合にのみ有効です。    |
| \|--endpoint                               | String | はい  | アクセスドメイン名。     |
| \|--accessKeyId                            | String | はい  | アクセスユーザー。      |
| \|--accessKeySecret                        | String | はい  | アクセスキー。      |
| \|--endpoint                               | String | はい  | アクセスドメイン名。       |
| \|--accessKeyId                            | String | はい  | アクセスユーザー。        |
| \|--accessKeySecret                        | String | はい  | アクセスキー。      |
| \|--appId                                  | String | はい  | アプリケーションID。        |
| \|--s3AccessKey                            | Object | いいえ  | S3情報。`backupStorageType=BACKUP_STORAGE_S3` の場合にのみ有効です。      |
| \|--endpoint                               | String | はい  | アクセスドメイン名。       |
| \|--accessKeyId                            | String | はい  | アクセスユーザー。        |
| \|--accessKeySecret                        | String | はい  | アクセスキー。      |
| \|--region                                 | String | はい  | リージョン。  |
| \|--customBackupRangeList        | Array   | いいえ  | カスタムバックアップ範囲。サポートされているOBServerバージョン：[4.2.5.2, 4.3.0) および [4.2.1.11, 4.2.2)。       |
| \|--backupType        | Enum   | はい  | バックアップタイプ。DATAとLOGをサポートします。       |
| \|--nodeType        | Enum   | はい  | バックアップノードタイプ。ZONE、REGION、IDCをサポートします。       |
| \|--nodeList        | Array   | はい  | バックアップノードの集合。同じインデックスのノードは優先順位が同じであり、同じインデックスの複数のノードはカンマで区切ります。例：["zone1,zone2", "zone3"]。       |
| \|--alarmStoragePercentageThreshold        | Long   | はい  | バックアップストレージ容量アラートのしきい値。パーセンテージで設定してください。       |
| storageId                                  | Long   | いいえ  | ストレージ設定ID。       |
| serviceType                                | String | いいえ  | サービスタイプ。以下を含みます：<li>BACKUP_RESTORE_SERVICE：バックアップ・リストアサービス（論理バックアップ・リストア）。</li><li>OB_CLUSTER：OceanBaseクラスタ（物理バックアップ・リストア）。</li><li>OTHERS：その他。</li>   |
| serviceId  | Long   | いいえ  | サービスID。 <li>サービスタイプが **BACKUP_RESTORE_SERVICE** の場合、バックアップ・リストアサービスIDを表します。  </li><li>サービスタイプが **OB_CLUSTER** の場合、クラスタIDを表します。 </li>   |
| serviceName                                | String | いいえ  | サービス名。 <li>サービスタイプが **BACKUP_RESTORE_SERVICE** の場合、バックアップ・リストアサービス名を表します。</li>  <li>サービスタイプが **OB_CLUSTER** の場合、クラスタ名を表します。</li>    |
| hostIdList                                 | Array  | いいえ  | ホストIDリスト。グローバル復元の解決ホストリストに使用されます。<li> サービスタイプが **BACKUP_RESTORE_SERVICE** の場合、バックアップ・リストアサービスのホストIDリストを表します。 </li><li>サービスタイプが **OB_CLUSTER** の場合、クラスタのホストIDリストを表します。</li>    |

### 戻り値

**基本データ構造**

|  パラメータ  |  型  | 説明                               |
|--------|--------|----------------------------------|
|  data  |  Object  | 詳細は **`BackupCommonResponse` のデータ構造** を参照してください。 |
|  successful  |  Boolean | リクエストが成功したかどうかを示します。                          |
|  timestamp |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status |  Integer  | HTTPステータスコードに準拠したエンコードです。            |
|  traceId |  String  | 問題の調査に使用されるリクエストのトレースIDです。             |
|  server  |  String  | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**`BackupCommonResponse` のデータ構造**

|            パラメータ             |   型    |                       説明                        |
|---------------------------|---------|-------------------------------------------------|
| obBackupTaskType          | String  | バックアップ操作のタイプ。例："CREATE_BACKUP_STRATEGY"。              |
| backupObjectOpsResultList | Array   | バックアップオブジェクト操作結果セット。                                      |
| \|--obBackupObjectList    | Array   | バックアップオブジェクトリスト。                                         |
| \|--clusterId             | Long    | クラスタID。                                          |
| \|--tenantId              | Long    | テナントID。                                          |
| \|--backupDimension       | String  | バックアップの次元。例：CLUSTERはクラスタバックアップ、TENANTはテナントバックアップを表します。 |
| \|--beSuccessful          | Boolean | 操作が成功したかどうかを示します。                                         |
| \|--taskIdList            | Array   | タスク番号リスト。非同期タスクがある場合に返されます。                               |
| \|--errorCode             | Object  | エラーコード。                                            |
| \|--hint                  | String  | ヒント情報。                                           |
