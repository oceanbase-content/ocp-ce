# テナントのデータバックアップタスクを表示する

## 機能説明

このAPIは、テナントのデータバックアップタスクを表示するために使用されます。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/task/dataBackupTasks`

### リクエストパラメータ

**Pathパラメータ**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|--------|
|  id        |  Integer  |  はい  |  1002  |  クラスタID。  |
|  tenantId  |  Integer  |  はい  |  108  |  テナントID。  |

**Queryパラメータ**

|  パラメータ         |  型    |  必須  |  サンプル値               |  説明         |
|---------------|----------|--------|-----------------------|--------------|
|  startTime      |  String  |  いいえ     |  2024-08-06T00:00:00Z       |   開始時間。UTC時刻のみ対応します。形式：YYYY-MM-DDThh:mm:ssZ。         |
|  endTime        |  String  |  いいえ     |  2024-08-07T00:00:00Z       |   終了時間。UTC時刻のみ対応します。形式：YYYY-MM-DDThh:mm:ssZ。         |
|  status       |  Array   |  いいえ    |  DONE                 |  タスクの状態。<li>BEGINNING：開始中。 </li><li> INITIALIZING：初期化中。 </li><li> DOING：実行中。 </li><li> DONE：完了。 </li><li> FAILED：失敗。 </li><li> CANCELING：キャンセル中。 </li><li> CANCELED：キャンセル済み。 </li><li> OVERDUE：期限切れ。 </li><li> UNKNOWN：不明。 </li>  |
|  backupSetId  |  Integer |  いいえ    |  1                    |  データバックアップセットID。  |

### 戻り値

**基本データ構造**

|  パラメータ  |  型  | 説明                               |
|--------|----------|----------------------------------|
|  data  |  Object  | 詳細は **`DataBackupHistoryWrapperTask` のデータ構造** を参照してください。 |
|  successful  |  Boolean | リクエストが成功したかどうか。                          |
|  timestamp |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status |  Integer  | HTTPステータスコード。            |
|  traceId |  String  | リクエストのTrace ID。問題の調査に使用されます。             |
|  server  |  String  | リクエストに応答したアプリケーションサービスのアドレス。                    |

**`DataBackupHistoryWrapperTask` のデータ構造**

|             パラメータ           |    型   |                     説明                     |
|----------------------------|-----------|--------------------------------------------|
| backupDimension            | String    | バックアップの次元。例えば、CLUSTERはクラスタバックアップを、TENANTはテナントバックアップを表します。 |
| taskId                     | Long      | タスクID。                                     |
| backupType                 | String    | バックアップタイプ。                                      |
| taskType                   | String    | タスクタイプ。                                      |
| clusterName                | String    | クラスタ名。                                       |
| clusterId                  | Long      | クラスタID。                                     |
| obClusterId                | Long      | OceanBaseクラスタID。                                  |
| obTenantId                 | Long      | OceanBase側のテナントID。                                 |
| clusterType                | String    | クラスタタイプ。以下を含みます：<li>PRIMARY：プライマリクラスタ。</li><li>STANDBY：スタンバイクラスタ。</li>     |
| tenantId                   | Long      | テナントID。                                     |
| tenantName                 | String    | テナント名。                                       |
| startTime                  | Timestamp | 開始時間。                                      |
| finishTime                 | Timestamp | 終了時間。                                      |
| status                     | String    | ステータス。                                        |
| errorMsg                   | String    | エラーメッセージ。                                      |
| dataVersion                | Long      | データバージョン番号。                                     |
| backupUri                  | String    | バックアップパス。                                      |
| dataType                   | String    | データタイプ。                                      |
| schemaVersion              | Long      | Schemaバージョン番号。                                |
| backupSetId                | Long      | データバックアップセットID。                                  |
| backupMode                 | String    | バックアップモード。                                      |
| dataBackupTaskType         | String    | データバックアップタスクタイプ。                                  |
| dataSecondaryBackupTaskIds | Arrays    | このデータバックアップセットIDに基づいて実行されたセカンダリバックアップタスクのIDリストです。このフィールドは物理バックアップの場合にのみ意味があります。 |
