# 追加されたリストアリソースのクリア

## 機能説明

このAPIは、追加されたリストアリソースのパスをクリアするために使用されます。

## 呼び出し説明

### インターフェース制約

なし

### リクエストパス

`POST /api/v2/ob/backup/restore/clearRestoreSource`

### リクエストパラメータ

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- |
| restoreClusterId | Integer | はい | 1001 | リストア時のターゲットクラスタのID。 |

### 戻り値

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| successful | Boolean | リクエストが成功したかどうか。 |
| timestamp | Datetime | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | Integer | サーバーがリクエストを処理した時間（ミリ秒）。 |
| status | Integer | HTTPステータスコード。 |
| traceId | String | リクエストのTrace Id。問題のトラブルシューティングに使用されます。 |
| server | String | リクエストに応答したアプリケーションサービスのアドレス。 |

## 例

### リクエスト例

```json
restoreClusterId:14
```

### レスポンス例

```json
{
    "duration": 32,
    "server": "d21b8dbaea",
    "status": 200,
    "successful": true,
    "timestamp": "2024-04-25T19:27:01.66+08:00",
    "traceId": "a5f6ea4f0a294eb7"
}
```
