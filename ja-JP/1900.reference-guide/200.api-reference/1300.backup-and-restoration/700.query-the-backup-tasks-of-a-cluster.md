# 特定クラスタのデータバックアップタスクの照会

## 機能説明

このインターフェースは、指定されたクラスタのデータバックアップタスクを照会するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、少なくともそのクラスタのバックアップ・リストアに対する読み取り専用権限を持っている必要があります。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/backup/task/dataBackupTasks`

### リクエストパラメータ

|     パラメータ      |       型       | 必須 |              サンプル値              |       説明       |
|-------------|----------------|----|-------------------------------|----------------|
| id          | Long           | はい  | 1                             | クラスタID。         |
| startTime   | OffsetDateTime | いいえ  | 2021-09-16T15:14:51.397+08:00 | 時間範囲の開始時刻。     |
| endTime     | OffsetDateTime | いいえ  | 2021-09-16T15:20:51.397+08:00 | 時間範囲の終了時刻。     |
| backupSetId | Long           | いいえ  | 23                            | データバックアップセットID。      |
| page        | Long           | はい  | 1                             | ページ数、つまり、どのページの内容を照会するか。 |
| size        | Long           | はい  | 10                            | 1ページあたりの表示件数。      |

### 戻り結果

|        パラメータ        |    型    |                                        説明                                         |
|------------------|----------|-----------------------------------------------------------------------------------|
| data             | Object   | リクエストされたデータ。                                                                            |
| ├─ contents      | Array    | DataBackupHistoryWrapperTaskの配列です。詳細なデータ構造については、**DataBackupHistoryWrapperTaskのデータ構造**を参照してください。 |
| ├─ page          | Object   | ページ情報。                                                                             |
| ├─ totalElements | Integer  | 総レコード数。                                                                             |
| ├─ totalPages    | Integer  | 総ページ数。                                                                              |
| ├─ number        | Integer  | 現在のページ番号。                                                                             |
| ├─ size          | Integer  | 現在のページサイズ。                                                                            |
| successful       | Boolean  | リクエストが成功したかどうか。                                                                           |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                                      |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                                                   |
| status           | Integer  | HTTP Status仕様に準拠したエンコード。                                                             |
| traceId          | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。                                                              |
| server           | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                                     |

**DataBackupHistoryWrapperTaskのデータ構造**

|             パラメータ             |    型     |                     説明                     |
|----------------------------|-----------|--------------------------------------------|
| taskId                     | Long      | タスクID。                                     |
| backupType                 | String    | バックアップタイプ。                                      |
| taskType                   | String    | タスクタイプ。                                      |
| clusterName                | String    | クラスタ名。                                       |
| clusterId                  | Long      | クラスタID。                                     |
| obClusterId                | Long      | OceanBaseクラスタID。                                  |
| obTenantId                 | Long      | OceanBase側テナントID。                                 |
| clusterType                | String    | クラスタタイプ。PRIMARY、STANDBYを含む。                   |
| tenantId                   | Long      | テナントID。                                     |
| tenantName                 | String    | テナント名。                                       |
| startTime                  | Timestamp | 開始時間。                                      |
| finishTime                 | Timestamp | 終了時間。                                      |
| status                     | String    | ステータス。                                        |
| errorMsg                   | String    | エラーメッセージ。                                      |
| dataVersion                | Long      | データバージョン番号。                                     |
| backupUri                  | String    | バックアップパス。                                      |
| dataType                   | String    | データタイプ。                                      |
| schemaVersion              | Long      | Schemaバージョン番号。                                |
| backupSetId                | Long      | データバックアップセットID。                                  |
| backupMode                 | String    | バックアップモード。                                      |
| dataBackupTaskType         | String    | データバックアップタスクタイプ。                                  |
| dataSecondaryBackupTaskIds | Arrays    | このデータバックアップセットIDに対して実行されたセカンダリバックアップタスクのIDリスト。物理バックアップの場合にのみこのフィールドは意味を持ちます。 |
