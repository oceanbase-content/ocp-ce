# テナントのバックアップスケジューリングを一時停止する

## 機能説明

このAPIは、テナントのバックアップスケジューリングを一時停止するために使用されます。

## 呼び出し説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/config/backupStrategy/stopSchedule`

### リクエストパラメータ

パスパラメータ:

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|-------|--------|-------|---------|--------|
|  id        |  Integer  |  はい  |  -   |  クラスタID。  |
|  tenantId  |  Integer  |  はい  |  -   |  テナントID。  |

### 戻り値

基本データ構造

|  パラメータ  |  型  | 説明                               |
|--------|-------|-----------------------------------|
|  data  |  Object  | BackupCommonResponseの情報。詳細は下表を参照。 |
|  successful  |  Boolean | リクエストが成功したかどうか。                          |
|  timestamp |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status |  Integer  | HTTPステータスコード。            |
|  traceId |  String  | リクエストのTrace ID。問題の調査に使用されます。             |
|  server  |  String  | リクエストに応答したアプリケーションサービスのアドレス。                    |

`BackupCommonResponse` のデータ構造

|  パラメータ  |  型  |  説明  |
|--------|-------|-------|
|  obBackupTaskType  |  String  |  タスクタイプ。  |
|  backupObjectOpsResultList  |  Array  |  操作対象の操作結果セット。  |

### リクエスト例

`POST /api/v2/ob/clusters/1000002/tenants/1000012/backup/config/backupStrategy/stopSchedule`
