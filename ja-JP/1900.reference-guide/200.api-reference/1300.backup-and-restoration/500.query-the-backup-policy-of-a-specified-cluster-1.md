# 指定クラスタのバックアップポリシーを照会する

## 機能説明

このインターフェースは、OceanBaseクラスタのバックアップポリシーの詳細を照会するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、少なくともそのクラスタのバックアップ・リストアに対する読み取り専用権限を持っている必要があります。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/backup/config/backupStrategy`

### リクエストパラメータ

| パラメータ |   型    | 必須 | サンプル値  |       説明        |
|----|---------|----|------|-----------------|
| id | Integer | はい  | 1001 | バックアップポリシーを照会するクラスタのID。 |

### 戻り結果

|     パラメータ     |    型    |                              説明                              |
|------------|----------|--------------------------------------------------------------|
| data       | Object   | バックアップポリシーの詳細。**OcpBackupStrategy** の**データ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                      |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                 |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                              |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。                                        |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。                                         |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                |

**OcpBackupStrategyのデータ構造**

|               パラメータ                |   型   |                                                       説明                                                       |
|---------------------------------|--------|----------------------------------------------------------------------------------------------------------------|
| id                              | Long   | ポリシーID。                                                                                                         |
| createTime                      | Date   | 作成日時。                                                                                                          |
| updateTime                      | Date   | 更新日時。                                                                                                          |
| clusterName                     | String | クラスタ名。                                                                                                           |
| obClusterId                     | Long   | OceanBaseクラスタID。                                                                                                      |
| clusterId                       | Long   | クラスタID。                                                                                                         |
| backupDimension | String | バックアップの次元。CLUSTERとTENANTをサポートします。現在はクラスタレベルのバックアップのみサポートされています。                                                                             |
| tenantName                      | String | テナント名。                                                                                                           |
| obTenantId                      | Long   | テナントID（OceanBase側のID）。                                                                                                 |
| tenantId                        | Long   | テナントID（OCP側のID）。                                                                                                |
| type                            | String | バックアップの目的タイプ。**BACKUP、SECONDARY_BACKUP** をサポートします。                                                                        |
| obBackupServiceStorageConfig    | Object | バックアップストレージ設定。詳細については、[クラスタのバックアップポリシーの作成](200.create-a-backup-policy-for-the-cluster-1.md) の **ObBackupServiceStorageConfigのデータ構造** を参照してください。 |
| backupMode      | String | バックアップ・リストアモード。**LOGICAL_BACKUP** と **PHYSICAL_BACKUP** の2種類をサポートします。                                         |
| serviceConfigName               | String | サービス設定名。                                                                                                         |
| obBackupScheduleConfig          | Object | バックアップスケジュール設定。詳細については、[クラスタのバックアップポリシーの作成](200.create-a-backup-policy-for-the-cluster-1.md) の **obBackupScheduleConfigのデータ構造** を参照してください。       |

### リクエスト例

IDが1のOceanBaseクラスタのバックアップポリシーを照会します。

`GET /api/v2/ob/clusters/1/backup/config/backupStrategy`
