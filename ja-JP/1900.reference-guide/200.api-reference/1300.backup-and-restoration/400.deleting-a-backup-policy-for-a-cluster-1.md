# クラスタのバックアップポリシーを削除する

## 機能説明

このインターフェースは、クラスタのバックアップポリシーを削除するために使用されます。バックアップポリシーを削除すると、クラスタは自動バックアップのスケジューリングや関連するアラートの検出を行わなくなります。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、対象クラスタのバックアップ・リストアに対する削除権限を持っている必要があります。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`DELETE /api/v2/ob/clusters/{id}/backup/config/backupStrategy`

**path:**

| パラメータ |   型    | 必須 | サンプル値 |       説明        |
|----|---------|----|-----|-----------------|
| id | Integer | はい  | 1   | 削除するバックアップポリシーを持つクラスタのID。 |

## 例

### リクエスト例

`DELETE /api/v2/ob/clusters/1/backup/config/backupStrategy`
