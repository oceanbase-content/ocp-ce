# テナントのバックアップポリシーを照会する

## 機能の概要

このAPIは、テナントのバックアップポリシーを照会するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/config/backupStrategy`

### リクエストパラメータ

**パスパラメータ**

|  パラメータ      |  型     |  必須  |  サンプル値  |  説明   |
|------------|-----------|--------|---------|----------|
|  id        |  Integer  |  はい    |  1002   |  クラスタID。  |
|  tenantId  |  Integer  |  はい    |  108    |  テナントID。  |

### 戻り値

**基本データ構造**

|  パラメータ        |  型      |  説明                               |
|--------------|------------|----------------------------------|
|  data        |  Object    | バックアップポリシーの詳細です。詳細については、**`OcpBackupStrategy` のデータ構造** を参照してください。 |
|  successful  |  Boolean   | リクエストが成功したかどうかを示します。                          |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status      |  Integer   | HTTPステータスコードです。            |
|  traceId     |  String    | リクエストのトレースIDで、問題の調査に使用されます。             |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**`OcpBackupStrategy` のデータ構造**

|  パラメータ                          |  型                          |  説明        |
|--------------------------------|--------------------------------|-------------|
|  id                            |  Integer                       |  ポリシーID。  |

|  updateTime                    |  String                        |  更新日時。  |
|  clusterName                   |  String                        |  クラスタ名。  |
|  obClusterId                   |  Integer                       |  OceanBaseクラスタID。  |
|  clusterId                     |  Integer                       |  クラスタID。  |
|  backupDimension               |  String                        |  バックアップの次元です。例えば、CLUSTERはクラスタバックアップを、TENANTはテナントバックアップを表します。  |
|  tenantName                    |  String                        |  テナント名。  |
|  obTenantId                    |  Integer                       |  OceanBase側のテナントID。 |
|  tenantId                      |  Integer                       |  テナントID。  |
|  type                          |  String                        |  バックアップの目的タイプ。  |
|  obBackupServiceStorageConfig  |  ObBackupServiceStorageConfig  |  バックアップストレージ設定です。詳細については、**`ObBackupServiceStorageConfig` のデータ構造** を参照してください。  |
|  backupMode                    |  String                        |  バックアップ・リストアモードです。<li>LOGICAL_BACKUP：論理バックアップ。</li><li>PHYSICAL_BACKUP：物理バックアップ。</li>  |
|  serviceConfigName             |  String                        |  サービス設定名。  |

|  obBackupThresholdConfig       |  ObBackupThresholdConfig       |  バックアップアラートのしきい値設定です。詳細については、**`ObBackupThresholdConfig` のデータ構造** を参照してください。  |

**`ObBackupServiceStorageConfig` のデータ構造**

|  パラメータ                             |  型     |  説明  |
|-----------------------------------|-----------|------------------|
|  configName                       |  String   |  ストレージ設定名。  |
|  obBackupStorageBaseInfo          |  ObBackupStorageBaseInfo  |  バックアップストレージ情報です。詳細については、**`ObBackupStorageBaseInfo` のデータ構造** を参照してください。  |
|  alarmStoragePercentageThreshold  |  Integer  |  バックアップストレージ容量のアラートしきい値です。パーセンテージで設定してください。  |
|  storageId                        |  Integer  |  ストレージ設定ID。  |
|  serviceType                      |  String   |  サービスタイプです。<li>BACKUP_RESTORE_SERVICE：バックアップ・リストアサービス（論理バックアップ・リストア）。</li><li>OB_CLUSTER：OceanBaseクラスタ（物理バックアップ・リストア）。</li><li>OTHERS：その他。</li>  |
|  serviceId                        |  Integer  |  サービスIDです。サービスタイプがBACKUP_RESTORE_SERVICEの場合はバックアップ・リストアサービスIDを、サービスタイプがOB_CLUSTERの場合はクラスタIDを表します。  |
|  serviceName                      |  String   |  サービス名です。サービスタイプがBACKUP_RESTORE_SERVICEの場合はバックアップ・リストアサービス名を、サービスタイプがOB_CLUSTERの場合はクラスタ名を表します。  |
|  hostIdList                       |  Array    |  ホストIDリストです。グローバルリストア時の解析に使用するホストのリストです。サービスタイプがBACKUP_RESTORE_SERVICEの場合はバックアップ・リストアサービスのホストIDリストを、サービスタイプがOB_CLUSTERの場合はクラスタのホストIDリストを表します。     |

**`ObBackupStorageBaseInfo` のデータ構造**

|  パラメータ               |  型          |  説明  |
|---------------------|----------------|----|
|  backupStorageType  |  String        |  ストレージタイプ。現在 `BACKUP_STORAGE_FILE`、`BACKUP_STORAGE_OSS`、`BACKUP_STORAGE_S3` タイプをサポートしています。  |
|  storageUrl         |  String        |  ストレージディレクトリです。プロトコルなしのディレクトリ（例：`/obbackup/` または `osstest/backup`）に設定してください。  |
|  ossAccessKey       |  OssAccessKey  |  OSS情報。`backupStorageType=BACKUP_STORAGE_OSS` の場合にのみ有効です。詳細については、**`OssAccessKey`のデータ構造**を参照してください。  |
|  s3AccessKey       |  S3AccessKey  |  S3情報。`backupStorageType=BACKUP_STORAGE_S3` の場合にのみ有効です。詳細については、**`S3AccessKey`のデータ構造**を参照してください。  |
|  customBackupRangeList       |  Array  |  カスタムバックアップ範囲。対応するOBServerバージョン：[4.2.5.2, 4.3.0) および [4.2.1.11, 4.2.2)。詳細については、**`customBackupRange`のデータ構造**を参照してください。  |

**`OssAccessKey`のデータ構造**

|  パラメータ             |  型     |  説明     |
|-------------------|----------|-------------|
|  endpoint         |  String  |  アクセスドメイン名。  |
|  accessKeyId      |  String  |  アクセスユーザー。  |
|  accessKeySecret  |  String  |  アクセスキー。  |

**`S3AccessKey`のデータ構造**

|  パラメータ             |  型    |  説明         |
|-------------------|----------|---------------|
|  endpoint         |  String  |  アクセスドメイン名。   |
|  accessKeyId      |  String  |  アクセスユーザー。  |
|  accessKeySecret  |  String  |  アクセスキー。  |
|  region           |  String  |  リージョン。  |

**`customBackupRange`のデータ構造**

| パラメータ | 型 | 説明 |
|-------------------|----------|---------------|
|  backupType      |  Enum  |  必須パラメータ。バックアップタイプ。DATAおよびLOGを含みます。  |
|  nodeType  |  Enum  |  必須パラメータ。バックアップノードタイプ。ZONE、REGION、IDCを含みます。  |
|  nodeList           |  Array  |  必須パラメータ。バックアップノードの集合です。同一インデックスのノードは優先順位が同じであり、同一インデックスの複数のノードはカンマで区切ります。例：["zone1,zone2", "zone3"]。  |

**`ObBackupScheduleConfig`のデータ構造**

| パラメータ | 型 | 説明 |
|----------------------------|-----------|------------------|
|  backupScheduleMode        |  String   |  バックアップスケジュールの周期です。<li>WEEK：週。</li><li>MONTH：月。</li>  |
|  backupScheduleEnabled     |  Boolean  |  バックアップのスイッチです。  |
|  backupScheduleTime        |  Object   |  バックアップスケジュールの時間です。"02:00:00.000+08:00" のように指定します。  |
|  dayAndDataBackupModelMap  |  Object   |  スケジュール日とそのデータバックアップ方式です。例えば、{ "2": "FULL_BACKUP", "4": "FULL_BACKUP", "6": "INCREMENTAL_BACKUP" }は、火曜日と木曜日にフルデータバックアップを行い、土曜日に増分データバックアップを行うことを表します。  |
|  startLogBackup            |  Boolean  |  ログバックアップを同時に開始するかどうかです。通常は`true`に設定します。  |
|  cleanEnabled              |  Boolean  |  期限切れデータのクリーンアップスイッチです。  |
|  backupDataRetentionDays   |  Integer  |  バックアップデータの保持日数です。例えば、7日は少なくとも直近7日間のバックアップデータを保持することを意味します。`cleanEnabled=true`の場合にのみ有効になります。  |
|  cleanScheduleTime         |  Object   |  期限切れデータのクリーンアップのスケジュール時間です。  |

**`ObBackupThresholdConfig`のデータ構造**

| パラメータ | 型 | 説明 |
|---------------------------------|--------|-----------------------------|
| dataBackupTimeoutMinutes        | Long | データバックアップスケジュールのタイムアウト時間です。単位は分です。           |
| noSuccessfulDataBackupAlarmDays | Long | データバックアップが成功していない場合にアラートを発生させるまでの最大日数です。           |
| libObLogExpireDays              | Long | liboblogの保持日数です。論理バックアップモードでのみ有効です。 |
| logBackupDelaySeconds           | Long | ログバックアップ遅延アラートのしきい値です。単位は秒です。            |
