# クラスタのバックアップ能力の確認

## 機能の概要

このAPIは、OceanBaseクラスタのバックアップ機能を照会するために使用されます。具体的には、バックアップが可能かどうか、サポートされているバックアップ方式などです。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、対象クラスタに対するバックアップ・リストアの読み取り専用権限を持っている必要があります。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/backup/ability`

### リクエストパラメータ

| パラメータ |   型    | 必須 | サンプル値  |       説明        |
|----|---------|----|------|-----------------|
| id | Integer | はい  | 1001 | バックアップ機能を照会するクラスタのIDです。 |

### 戻り値

|     パラメータ     |    型    |                             説明                             |
|------------|----------|------------------------------------------------------------|
| data       | Object   | ObBackupAbilityパラメータのデータ構造および説明については、**ObBackupAbilityのデータ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                                                    |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                                               |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）です。                                            |
| status     | Integer  | HTTPステータスコード仕様に準拠したエンコードです。                                      |
| traceId    | String   | リクエストのTrace IDであり、問題のトラブルシューティングに使用されます。                                       |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                                              |

**ObBackupAbilityのデータ構造**

|                     パラメータ                      |       型       |                                                                                                       説明                                                                                                        |
|---------------------------------------------|----------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| backupAbility               | String         | バックアップサポート能力。値は以下のとおりです： LOGICAL_BACKUP、PHYSICAL_BACKUP、LOGICAL_AND_PHYSICAL。    |
| backupMode  | String         | バックアップ方式。値は以下のとおりです： LOGICAL_BACKUP、PHYSICAL_BACKUP。                                                                |
| obDataBackupSupportAbility                  | Object         | OceanBaseデータバックアップのサポート能力。主に以下の3つの能力を含みます。                                                                                                                                                                                     |
| \|--fullBackupEnabled                       | Boolean        | クラスタがフルバックアップをサポートするかどうか。                                                                                                                                                                                                     |
| \|--incrementBackupEnabled                  | Boolean        | クラスタが増分バックアップをサポートするかどうか。                                                                                                                                                                                                     |
| \|--canDoIncrementalBackup                  | Boolean        | クラスタが現在増分バックアップを実行できるかどうか。                                                                                                                                                                                                   |
| \|--hint                                    | String         | ヒント情報。                                                                                                                                                                                                           |
| obBackupCondition                           | Object         | バックアップ・リストアに必要な条件。以下の3つの条件を含みます。                                                                                                                                                                                          |
| \|--needAgentToBackup                       | Boolean        | バックアップにコンポーネントが必要かどうか。                                                                                                                                                                                                       |
| \|--needAgentToRestore                      | Boolean        | リストアにコンポーネントが必要かどうか。                                                                                                                                                                                                       |
| \|--agentMetaDbSchema                       | String         | バックアップコンポーネントのメタデータベース名。                                                                                                                                                                                                     |
| obRestoreConditionCheckResult               | Object         | リストアに必要な条件のチェック結果。以下のセルの内容を含みます。                                                                                                                                                                                         |
| \|--backupTaskType                          | String         | バックアップタスクのタイプ。                                                                                                                                                                                                        |
| \|--beReady                                 | Boolean        | バックアップが可能かどうか。                                                                                                                                                                                                         |
| \|--needDependentOnAgents                   | String         | バックアップに依存コンポーネントが必要かどうか。                                                                                                                                                                                                     |
| \|--serviceNameList                         | List\<String\> | バックアップが依存コンポーネントに対応するバックアップ・リストアサービス名。                                                                                                                                                                                             |
| \|--agentMetaDbSchema                       | String         | メタデータベースSchema。                                                                                                                                                                                                    |
| \|--errorCodes                              | String         | エラーコード。                                                                                                                                                                                                            |
| \|--hint                                    | String         | ヒント情報。                                                                                                                                                                                                           |
