# テナントデータのバックアップを開始する

## 機能説明

このAPIは、テナントデータのバックアップを開始するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/backupNow`

### リクエストパラメータ

**パスパラメータ**

|     パラメータ   |  型     |  必須  |  サンプル値  |  説明      |
|------------|-----------|--------|---------|-------------|
|  id        |  Integer  |  はい    |  1002   |  クラスタID。  |
|  tenantId  |  Integer  |  はい    |  108    |  テナントID。  |

**ボディパラメータ**

|  パラメータ  |  型  |  必須  |  サンプル値  |  説明  |
|--------|--------|--------|----------|---------|
|  obBackupObject  |  Obbackupobject  |  いいえ  |  NA  |  バックアップオブジェクト。自動入力されます。  |
|  backupMode  |  String  |  はい  |   LOGICAL_BACKUP |  バックアップモード。<li>LOGICAL_BACKUP：論理バックアップ。</li><li>PHYSICAL_BACKUP：物理バックアップ。</li>    |
|  dataBackupMode  |  String  |  はい  | FULL_BACKUP    | データバックアップモード。<li>FULL_BACKUP：フルバックアップ。</li><li> INCREMENTAL_BACKUP：増分バックアップ。</li>  |
|  obBackupServiceStorageConfig  |  Obbackupservicestorageconfig  |  はい  | NA    | バックアップストレージ設定。詳細については、**`obBackupServiceStorageConfig`のデータ構造**を参照してください。|

**`obBackupServiceStorageConfig`のデータ構造**

|     パラメータ  |   型   | 必須 |   説明     |
|-----------|----------|-------|---------------|
| configName                                 | String | はい  | ストレージ設定名。    |
| obBackupStorageBaseInfo                    | Object | はい  | ストレージ設定の基本パラメータ。   |
| \|--backupStorageType                      | String | はい  | ストレージタイプ。現在、`BACKUP_STORAGE_FILE`、`BACKUP_STORAGE_OSS`、`BACKUP_STORAGE_S3`タイプをサポートしています。   |
| \|--storageUrl                             | String | はい  | ストレージディレクトリ。プロトコルなしのディレクトリ（例：`/obbackup/`または`osstest/backup`）を設定してください。    |
| \|--ossAccessKey                           | Object | いいえ  | OSS情報。`backupStorageType=BACKUP_STORAGE_OSS`の場合にのみ有効です。    |
| \|--endpoint                               | String | はい  | アクセスドメイン名。     |
| \|--accessKeyId                            | String | はい  | アクセスユーザー。      |
| \|--accessKeySecret                        | String | はい  | アクセスキー。      |
| \|--endpoint                               | String | はい  | アクセスドメイン名。       |
| \|--accessKeyId                            | String | はい  | アクセスユーザー。        |
| \|--accessKeySecret                        | String | はい  | アクセスキー。      |
| \|--appId                                  | String | はい  | アプリケーションID。        |
| \|--s3AccessKey                            | Object | いいえ  | S3情報。`backupStorageType=BACKUP_STORAGE_S3`の場合にのみ有効です。      |
| \|--endpoint                               | String | はい  | アクセスドメイン名。       |
| \|--accessKeyId                            | String | はい  | アクセスユーザー。        |
| \|--accessKeySecret                        | String | はい  | アクセスキー。      |
| \|--region                                 | String | はい  | リージョン。  |
| \|--customBackupRangeList        | Array   | いいえ  | カスタムバックアップ範囲。サポートされているOBServerバージョン：[4.2.5.2, 4.3.0)および[4.2.1.11, 4.2.2)。       |
| \|--backupType        | Enum   | はい  | バックアップタイプ。DATAとLOGをサポートします。       |
| \|--nodeType        | Enum   | はい  | バックアップノードタイプ。ZONE、REGION、IDCをサポートします。       |
| \|--nodeList        | Array   | はい  | バックアップノードの集合です。同じインデックスのノードは優先順位が同じで、複数のノードがある場合はカンマで区切ります。例：["zone1,zone2", "zone3"]。       |
| \|--alarmStoragePercentageThreshold        | Long   | はい  | バックアップストレージ容量のアラートしきい値を設定します。値はパーセンテージで指定してください。       |
| storageId                                  | Long   | いいえ  | ストレージ設定IDです。       |
| serviceType                                | String | いいえ  | サービスタイプ。次のものが含まれます：<li>BACKUP_RESTORE_SERVICE：バックアップ・リストアサービス（論理バックアップ・リストア）。</li><li>OB_CLUSTER：OceanBaseクラスタ（物理バックアップ・リストア）。</li><li>OTHERS：その他。</li>   |
| serviceId  | Long   | いいえ  | サービスID。 <li>サービスタイプが **BACKUP_RESTORE_SERVICE** の場合、バックアップ・リストアサービスのIDを表します。  </li><li>サービスタイプが **OB_CLUSTER** の場合、クラスタIDを表します。 </li>   |
| serviceName                                | String | いいえ  | サービス名。 <li>サービスタイプが **BACKUP_RESTORE_SERVICE** の場合、バックアップ・リストアサービス名を表します。</li>  <li>サービスタイプが **OB_CLUSTER** の場合、クラスタ名を表します。</li>    |
| hostIdList                                 | Array  | いいえ  | ホストIDのリストです。グローバル復元時の解析に使用するホストのリストです。<li> サービスタイプが **BACKUP_RESTORE_SERVICE** の場合、バックアップ・リストアサービスのホストIDリストを表します。 </li><li>サービスタイプが **OB_CLUSTER** の場合、クラスタのホストIDリストを表します。</li>    |

### 戻り値

**基本データ構造**

|  パラメータ  |  型  | 説明                               |
|--------|---------|----------------------------------|
|  data  |  Object  | BackupCommonResponseの情報。詳細は下表を参照してください。 |
|   successful   |  Boolean | リクエストが成功したかどうかを示します。                          |
|   timestamp  |   Datetime   | サーバーがリクエストを完了したタイムスタンプです。                     |
| duration | Integer | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status  |  Integer  | HTTPステータスコード。            |
|  traceId  |  String  | リクエストのトレースID。問題の調査に使用されます。             |
|  server  |  String  | リクエストに応答したアプリケーションサービスのアドレス。                    |

**`BackupCommonResponse`のデータ構造**

|            パラメータ             |   型    |                       説明                        |
|---------------------------|---------|-------------------------------------------------|
| obBackupTaskType          | String  | バックアップ操作タイプ。例："CREATE_BACKUP_STRATEGY"。              |
| backupObjectOpsResultList | Array   | バックアップオブジェクト操作結果セット。                                      |
| \|--obBackupObjectList    | Array   | バックアップオブジェクトリスト。                                         |
| \|--clusterId             | Long    | クラスタID。                                          |
| \|--tenantId              | Long    | テナントID。                                          |
| \|--backupDimension       | String  | バックアップ次元。例：CLUSTERはクラスタバックアップ、TENANTはテナントバックアップを表します。 |
| \|--beSuccessful          | Boolean | 操作が成功したかどうかを示します。                                         |
| \|--taskIdList            | Array   | タスク番号リスト。非同期タスクがある場合に返されます。                               |
| \|--errorCode             | Object  | エラーコード。                                            |
| \|--hint                  | String  | ヒント情報。                                           |
