# クラスタバックアップ情報の解析

## 機能の概要

このAPIは、クラスタのバックアップ情報を解析するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、少なくともそのクラスタのバックアップ・リストアに対する読み取り専用権限を持っている必要があります。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/backup/info`

### リクエストパラメータ

|    パラメータ     |       型       | 必須 |              サンプル値              |       説明       |
|-----------|----------------|----|-------------------------------|----------------|
| id        | Integer        | はい  | 1001                          | バックアップ情報を解析するクラスタID。 |
| startTime | OffsetDateTime | いいえ  | 2021-09-16T15:14:51.397+08:00 | 解析の開始時間。       |
| endTime   | OffsetDateTime | いいえ  | 2021-09-16T15:20:51.397+08:00 | 解析の終了時間。       |

### 戻り値

|     パラメータ     |    型    |                             説明                             |
|------------|----------|------------------------------------------------------------|
| data       | Object   | ObClusterBackupInfo 。詳細については、**ObClusterBackupInfoのデータ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうか。                                                    |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                               |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                            |
| status     | Integer  | HTTP Status仕様に準拠したエンコード。                                      |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。                                       |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                                              |

**ObClusterBackupInfoのデータ構造**

|                      パラメータ                      |   型    |                                  説明                                  |
|----------------------------------------------|---------|----------------------------------------------------------------------|
| clusterName                                  | String  | クラスタ名。                                                                 |
| obClusterId                                  | Long    | OceanBaseクラスタID。                                                            |
| clusterId                                    | Long    | クラスタID。                                                               |
| online                                       | Boolean | オンラインかどうか。                                                                |
| tenantBackupInfos                            | Array   | テナントのバックアップ情報セット。要素の詳細については、**ObTenantBackupInfoのデータ構造**を参照してください。                        |
| obRecoverableInfoAggregation | Object  | 復元可能な時間区間。すべてのテナントの最大集合です。tenantBackupInfos内のobRecoverableInfoAggregationと同じです。 |

**ObTenantBackupInfoのデータ構造**

|                パラメータ                |   型    |                               説明                               |
|----------------------------------|---------|----------------------------------------------------------------|
| clusterName                      | String  | クラスタ名。                                                           |
| obClusterId                      | Long    | OceanBaseクラスタID。                                                      |
| clusterId                        | Long    | クラスタID。                                                         |
| obTenantId                       | Long    | OceanBaseテナントID。                                                      |
| tenantId                         | Long    | テナントID。                                                         |
| tenantName                       | String  | テナント名。                                                           |
| online                           | Boolean | オンラインかどうか。                                                          |
| obRecoverableInfoAggregation     | Object  | 復元可能な時間区間。                                                       |
| \|----latestSevenDaysAggregation | Object  | 最近の一定日数の復元可能なデータの集約集合です。詳細については、**LatestSevenDaysAggregationのデータ構造**を参照してください。 |

**LatestSevenDaysAggregationのデータ構造**

|                    パラメータ                     |       型       |                                                                                                                                   説明                                                                                                                                    |
|-------------------------------------------|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| obRecoverableSectionItems | Array          | 復元可能時間区間のリスト。                                                                                                                                                                                                                                                              |
| \|----obRecoverableSectionItemType        | String         | 復元可能時間区間内のノードタイプ。FULL_DATA_BACKUP、INCREMENTAL_DATA_BACKUP、LOG_BACKUP、RECOVERABLEを含む。    |
| \|----backupMode                          | String         | バックアップ方式。論理バックアップまたは物理バックアップ。                                                                                                                                                                                                                                                         |
| \|----dataBackupRecoverableInfo           | Object         | データバックアップの復元可能情報。ノードタイプがデータバックアップの場合にのみ有効です。                                                                                                                                                                                                                                              |
| \|----freezeTime                          | OffsetDateTime | データバックアップに対応するフリーズ時間。                                                                                                                                                                                                                                                            |
| \|----recoverableTime                     | OffsetDateTime | データバックアップの復元可能時間。                                                                                                                                                                                                                                                             |
| \|----dataVersion                         | Long           | データバージョン。                                                                                                                                                                                                                                                                   |
| \|----fullBackupSetId                     | Long           | フルバックアップセットID。物理バックアップにおけるフルデータバックアップと増分データバックアップの関係を示すために使用されます。IDが同じフルバックアップと増分バックアップは対応しています。                                                                                                                                                                                                                 |
| \|----logRecoverableTimeInterval          | Object         | ログバックアップの時間区間。ノードタイプがログバックアップ区間の場合にのみ有効です。                                                                                                                                                                                                                                             |
| \|----startTime                           | OffsetDateTime | 開始時間。                                                                                                                                                                                                                                                                   |
| \|----endTime                             | OffsetDateTime | 終了時間。                                                                                                                                                                                                                                                                   |
| \|----logRecoverableTimeInterval          | Object         | 実際の復元可能時間区間。ノードタイプが復元可能時間区間の場合にのみ有効です。                                                                                                                                                                                                                                           |
| \|----startTime                           | OffsetDateTime | 開始時間。                                                                                                                                                                                                                                                                   |
| \|----endTime                             | OffsetDateTime | 終了時間。                                                                                                                                                                                                                                                                   |
