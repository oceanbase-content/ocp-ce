# 特定クラスタのリストアタスクを照会する

## 機能の概要

このAPIは、特定のクラスタのリストアタスクを照会するために使用されます。

## 呼び出しの説明

### インターフェース制約

* 呼び出し元は、少なくともそのクラスタのバックアップ・リストアに対する読み取り専用権限を持っている必要があります。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/backup/task/restoreTasks`

### リクエストパラメータ

|    パラメータ     |       型       | 必須 |              サンプル値              |    説明     |
|-----------|----------------|----|-------------------------------|-----------|
| id        | Long           | はい  | 1                             | クラスタID      |
| startTime | OffsetDateTime | いいえ  | 2021-09-16T15:14:51.397+08:00 | 時間範囲の開始時刻 |
| endTime   | OffsetDateTime | いいえ  | 2021-09-16T15:20:51.397+08:00 | 時間範囲の終了時刻 |
| page      | Long           | はい  | 1                             | 照会するタスクのページ番号。 |
| size      | Long           | はい  | 10                            | 1ページあたりに表示するタスク数。 |

### 戻り値

|        パラメータ        |    型    |                              説明                               |
|------------------|----------|---------------------------------------------------------------|
| data             | Object   | リクエストされたデータ。                                                        |
| ├─ contents      | Array    | RestoreHistoryTaskの配列。詳細なデータ構造については、**RestoreHistoryTaskのデータ構造** を参照してください。 |
| ├─ page          | Object   | ページ情報。                                                         |
| ├─ totalElements | Integer  | 総レコード数。                                                         |
| ├─ totalPages    | Integer  | 総ページ数。                                                          |
| ├─ number        | Integer  | 現在のページ番号。                                                         |
| ├─ size          | Integer  | 現在のページサイズ。                                                        |
| successful       | Boolean  | リクエストが成功したかどうか。                                                       |
| timestamp        | Datetime | サーバーがリクエストを完了したタイムスタンプ。                                                  |
| duration         | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                                               |
| status           | Integer  | HTTPステータスコード。                                         |
| traceId          | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。                                          |
| server           | String   | リクエストに応答したアプリケーションサービスのアドレス。                                                 |

**RestoreHistoryTaskのデータ構造**

|         パラメータ         |    型     |                   説明                    |
|--------------------|-----------|-----------------------------------------|
| id                 | Long      | リストアタスクID。                                |
| ocpJobId           | Long      | リストアタスクの外部番号。OCPから発行されます。物理リストアタスクを抽出検査する場合にのみ、この値は0より大きくなります。 |
| backupMode         | String    | 復元モード。バックアップモードのフィールドを再利用します。論理復元または物理復元が含まれます。              |
| createTime         | Timestamp | 作成時間。                                   |
| finishTime         | Timestamp | 完了時間。                                   |
| backupClusterId    | Long      | バックアップクラスタID。                                |
| backupClusterName  | String    | バックアップクラスタ名。                                  |
| backupObClusterId  | Long      | バックアップクラスタID (OceanBase側)。                          |
| backupObTenantId   | Long      | バックアップテナントID (OceanBase側)。                          |
| backupTenantId     | Long      | バックアップテナントID。                                |
| backupTenantName   | String    | バックアップテナント名。                                  |
| restoreClusterName | String    | 復元クラスタ名。                                  |
| restoreObClusterId | Long      | 復元クラスタID (OceanBase側)。                         |
| restoreClusterId   | Long      | 復元クラスタID。                                |
| restoreTenantName  | String    | 復元テナント名。                                  |
| restorePoolListStr | String    | 復元リソースプールリスト。複数のリソースプールは、カンマで区切ります。                    |
| restoreUri         | String    | バックアップディレクトリ。                                   |
| restoreEndTime     | Timestamp | 復元時間。                                   |
| status             | String    | 復元状態。                                   |
| errorMsg           | String    | エラーメッセージ。                                   |
