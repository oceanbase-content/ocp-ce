# 特定クラスタの即時バックアップ

## 機能説明

このAPIは、特定のクラスタに対して即時バックアップを実行するために使用されます。

## 呼び出し説明

### インターフェース制約

* ユーザーは、そのクラスタのバックアップ・リストアの作成権限を持っている必要があります。

* ユーザーはOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/backup/backupNow`

**path:**

| パラメータ |   型    | 必須 | サンプル値 |       説明       |
|----|---------|----|-----|----------------|
| id | Integer | はい  | 1   | 即時バックアップを実行するクラスタID。 |

### リクエストパラメータ

|              パラメータ              |   型   | 必須 |      サンプル値       |                                                                                        説明                                                                                        |
|------------------------------|--------|----|----------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| obBackupObject               | Object | いいえ  | NA             | バックアップオブジェクト。自動入力されます。                                                                                                                                                                      |
| backupMode                   | String | はい  | LOGICAL_BACKUP | バックアップモード。 値の範囲： <li>LOGICAL_BACKUP：論理バックアップ</li><li>PHYSICAL_BACKUP：物理バックアップ</li>    |
| dataBackupMode               | String | はい  | FULL_BACKUP    | データバックアップモード。 **FULL_BACKUP、**  **INCREMENTAL_BACKUP**を含みます                                                                                                               |
| obBackupServiceStorageConfig | Object | はい  | NA             | バックアップストレージ設定。[クラスタのバックアップポリシーの作成](200.create-a-backup-policy-for-the-cluster-1.md) の具体的なデータ構造を参照してください。                                                                                                     |

### 戻り値

|     パラメータ     |    型    |                説明                |
|------------|----------|----------------------------------|
| data       | Object   | バックアップオブジェクトの汎用応答。詳細はBackupCommonResponseを参照。 |
| successful | Boolean  | リクエストが成功したかどうか。                          |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。                     |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
| status     | Integer  | HTTP Status仕様に準拠したコード。            |
| traceId    | String   | リクエストのTrace Id。問題の調査に使用されます。             |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。                    |

**BackupCommonResponseのデータ構造**

|                    パラメータ                     |   型    |                       説明                        |
|-------------------------------------------|---------|-------------------------------------------------|
| obBackupTaskType          | String  | バックアップ操作タイプ。例："CREATE_BACKUP_STRATEGY"。              |
| backupObjectOpsResultList | Array   | バックアップオブジェクト操作結果セット。                                      |
| \|--obBackupObjectList    | Array   | バックアップオブジェクトリスト。                                         |
| \|--clusterId                             | Long    | クラスタID。                                          |
| \|--tenantId                              | Long    | テナントID。                                          |
| \|--backupDimension                       | String  | バックアップ次元。例：CLUSTER、TENANTはそれぞれクラスタバックアップ、テナントバックアップを表します。現在、テナントバックアップはサポートされていません。 |
| \|--beSuccessful                          | Boolean | 操作の成功・失敗を示します。                                         |
| \|--taskIdList                            | Array   | タスク番号リスト。非同期タスクがある場合に返されます。                               |
| \|--errorCode                             | Object  | エラーコード。                                            |
| \|--hint                                  | String  | ヒント情報。                                           |
