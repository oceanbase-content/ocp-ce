# テナント/データベース/テーブルの復元を開始する

## 機能の概要

このAPIは、バックアップ済みのテナント/データベース/テーブルをターゲットクラスタに復元するために使用されます。

グローバルビューから複数のOCP間でオフラインテナント復元を開始する場合（ソースクラスタが現在のOCPによって管理されている必要がない場合）、[グローバルからのテナント復元の開始](2800.global-initiate-tenant-recovery.md)を参照してください。

## 呼び出しの説明

### インターフェース制約

* テナント/データベース/テーブルを作成する権限が、復元対象のクラスタに対して付与されている必要があります。

* OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/backup/restore`

### リクエストパラメータ

| パラメータ |   型    | 必須 | サンプル値  |     説明     |
|-------|---------|-------|------|------------|
| id | Integer | はい  | 1001 | バックアップ済みクラスタのID。 |

### 戻り値

|     パラメータ     |    型    |                 説明                  |
|------------|----------|-------------------------------------|
| data       | Object   | **`BackupCommonResponse`のデータ構造**を参照してください。 |
| successful | Boolean  | リクエストが成功したかどうかを示します。                             |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプです。                        |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                     |
| status     | Integer  | HTTPステータスコードに準拠したエンコードです。               |
| traceId    | String   | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。                |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレスです。                       |

**`BackupCommonResponse`のデータ構造**

|            パラメータ             |   型    |                       説明                        |
|---------------------------|---------|-------------------------------------------------|
| obBackupTaskType          | String  | バックアップ操作タイプ。例："CREATE_BACKUP_STRATEGY"。              |
| backupObjectOpsResultList | Array   | バックアップオブジェクト操作結果セット。                                      |
| \|--obBackupObjectList    | Array   | バックアップオブジェクトリスト。                                         |
| \|--clusterId             | Long    | クラスタID。                                          |
| \|--tenantId              | Long    | テナントID。                                          |
| \|--backupDimension       | String  | バックアップ次元。例：CLUSTERはクラスタバックアップ、TENANTはテナントバックアップを表します。 |
| \|--beSuccessful          | Boolean | 操作が成功したかどうかを示します。                                         |
| \|--taskIdList            | Array   | タスク番号リスト。非同期タスクがある場合に返されます。                               |
| \|--errorCode             | Object  | エラーコード。                                            |
| \|--hint                  | String  | ヒント情報。                                           |
