# クラスタのバックアップ概要を照会する

## 機能説明

このインターフェースは、クラスタの基本情報、最新のデータバックアップ時間、ログバックアップポイント、ログ遅延時間、およびバックアップサイズなど、クラスタのバックアップ概要を照会するために使用されます。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、少なくともそのクラスタのバックアップ・リストアに対する読み取り専用権限を持っている必要があります。

* 呼び出し元は、OCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/backup/overview`

### リクエストパラメータ

| パラメータ |   型    | 必須 | サンプル値  |       説明       |
|----|---------|----|------|----------------|
| id        | Integer | はい  | 1001 | バックアップ概要を照会するクラスタID。 |

### 戻り結果

|     パラメータ     |    型    |          説明           |
|------------|----------|-----------------------|
| data       | Object   | バックアップ概要。                 |
| successful | Boolean  | リクエストが成功したかどうか。               |
| timestamp  | Datetime | サーバーがリクエストを完了したタイムスタンプ。          |
| duration   | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。       |
| status     | Integer  | HTTP Status仕様に準拠したコード。 |
| traceId    | String   | リクエストのTrace Id。問題のトラブルシューティングに使用されます。  |
| server     | String   | リクエストに応答したアプリケーションサービスのアドレス。         |

**ClusterBackupInfoDetailのデータ構造**

|            パラメータ             |    型     |                              説明                               |
|---------------------------|-----------|---------------------------------------------------------------|
| clusterId                 | Long      | クラスタID。                                                        |
| obClusterId               | Long      | OceanBaseクラスタID。                                                     |
| clusterName               | String    | クラスタ名                                                           |
| obTenantId                | Long      | OceanBase側テナントID。                                                    |
| tenantId                  | Long      | テナントID                                                         |
| tenantName                | String    | テナント名                                                           |
| obClusterType             | String    | クラスタタイプ。PRIMARYとSTANDBYを含みます。                                    |
| obClusterStatus           | String    | クラスタの状態                                                          |
| compactionStatus          | String    | クラスタのメジャーコンパクションの状態                                                        |
| primaryAndStandbyMode     | Boolean   | プライマリ/スタンバイモードかどうか                                                        |
| obVersion                 | String    | OceanBaseのバージョン                                                         |
| obClusterBackupStatus     | String    | バックアップの状態。HAS_BACKUP_STRATEGY、NO_BACKUP_STRATEGYを含みます。                |
| obBackupAbility           | Object    | バックアップ能力。                                                         |
| \|----backupAbility       | String    | バックアップ能力。LOGICAL_BACKUP、PHYSICAL_BACKUP、LOGICAL_AND_PHYSICALを含みます。 |
| \|----backupMode          | String    | バックアップ方式。LOGICAL_BACKUP、PHYSICAL_BACKUPを含みます。                       |
| backupDimension           | String    | バックアップの次元。CLUSTERとTENANTを含みます。                                     |
| backupScheduleStatus      | String    | バックアップスケジュールの状態。NONE、NORMAL、PAUSED、WAITING、ABNORMALを含みます。                |
| lastDataBackupTime        | Timestamp | 最近のデータバックアップ時間。                                                    |
| latestLogBackupCheckpoint | Timestamp | 最新のログバックアップチェックポイント。                                                    |
| logBackupDelaySeconds     | Long      | ログバックアップの遅延時間。単位は秒です。                                                |
| backupSize                | Double    | バックアップサイズ。                                                         |
| obStorageVolumeUnit       | String    | バックアップ単位。B、KB、MB、GB、TB、PBを含みます。                                     |

### リクエスト例

クラスタIDが1のバックアップ概要を照会します。

`GET /api/v2/ob/clusters/1/backup/overview`
