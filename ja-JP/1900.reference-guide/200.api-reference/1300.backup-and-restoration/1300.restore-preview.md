# リストアのプレビュー

## 機能説明

このAPIは、リストアタスクをプレビューし、すべてのバックアップリソースのパスを返します。

## 呼び出し説明

### インターフェース制約

* 呼び出し元は、リストア対象クラスタに対するテナント作成権限が必要です。

### リクエストパス

`POST /api/v2/ob/clusters/{id}/backup/restore/preview`

### リクエストパラメータ

| パラメータ | 型 | 必須 | サンプル値 | 説明 |
| --- | --- | --- | --- | --- |
| id | Integer | はい | 1001 | バックアップ済みクラスタのID。 |

**RestoreTenantParamのデータ構造**

| パラメータ | 型 | 必須 | 説明 |
| --- | --- | --- | --- |
| backupTenantStatus | String | はい | バックアップテナントの状態。ONLINEまたはOFFLINE。 |
| restoreOnlineTenantRequiredParam | Object | いいえ | バックアップテナントがオンラインの場合、このパラメータは必須です。 |
| ├─ backupClusterId | Long | はい | バックアップクラスタID。 |
| ├─ backupTenantId | Long | はい | バックアップテナントID。 |
| ├─ restoreClusterId | Long | はい | リストアクラスタID。 |
| ├─ restoreEndTime | OffsetDateTime | はい | 特定の時刻まで復元します。 |
| ├─ restoreTenantInfoParam | Object | はい | リストア対象のテナントモデル。 |
| ├─ name | String | はい | テナント名。 |
| ├─ primaryZone | String | いいえ | プライマリゾーン。 |
| ├─ zones | Arrays | はい | ゾーン設定。 |
| ├─ name | String | はい | ゾーン名。 |
| ├─ replicaType | String | はい | レプリカタイプ。FULL、LOGONLY、READONLYをサポートします。 |
| ├─ resourcePool | Object | はい | リソースプール設定。 |
| ├─ unitSpecName | String | はい | スペック名。 |
| ├─ unitCount | Long | はい | スペック数。 |
| restoreOfflineTenantRequiredParam | Object |  | バックアップテナントがオフラインの場合、このパラメータは必須です。 |
| ├─ backupMode | String | はい | バックアップ方式。 |
| ├─ backupClusterName | String | はい | バックアップクラスタ名。 |
| ├─ backupObClusterId | Long | いいえ | バックアップクラスタID（OceanBase側）。 |
| ├─ backupTenantName | String | はい | バックアップテナント名。 |
| ├─ backupObTenantId | Long | いいえ | バックアップテナントID (OceanBase側)。 |
| ├─ restoreClusterId | Long | はい | 復元クラスタID。 |
| ├─ obBackupStorageBaseInfo | Object | はい | バックアップストレージ情報。[クラスタのバックアップポリシーの作成](https://docs.oceanbase.com/ocp/V4.4.2-create-a-backup-policy-for-the-cluster-of-api)<br /> の具体的なデータ構造を参照してください。 |
| ├─ restoreEndTime | OffsetDateTime | はい | 特定の時刻まで復元します。 |
| ├─ restoreTenantInfoParam | Object | はい | 復元先のテナントモデル。オンライン復元時のモデルと同じです。 |

### 実行結果

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| data | Array | **RestorePreviewItemのデータ構造** を参照してください。 |
| successful | Boolean | リクエストが成功したかどうか。 |
| timestamp | Datetime | サーバーがリクエストを完了したタイムスタンプ。 |
| duration | Integer | サーバーがリクエストを処理した時間(ミリ秒)。 |
| status | Integer | HTTPステータスコード。 |
| traceId | String | リクエストのTraceId。問題の調査に使用されます。 |
| server | String | リクエストに応答したアプリケーションサービスのアドレス。 |

**RestorePreviewItemのデータ構造**

| パラメータ | 型 | 説明 |
| --- | --- | --- |
| backupDest | String | バックアップパス。 |
| backupId | Long | バックアップID。 |
| backupType | String | バックアップセットまたはバックアップスライス。 |
| copyId | Long | コピーID。 |
