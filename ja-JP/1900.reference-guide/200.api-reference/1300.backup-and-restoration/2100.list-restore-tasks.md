# リストアンドタスクの表示

## 機能の概要

このAPIは、リストアタスクを確認するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/task/restoreTasks`

### リクエストパラメータ

**Pathパラメータ**

|  パラメータ      |  タイプ     |  必須  |  サンプル値    |  説明   |
|------------|-----------|--------|-----------|----------|
|  id        |  Integer  |  はい    |  1002     |  クラスタID。  |
|  tenantId  |  Integer  |  はい    |  108      |  テナントID。  |

**Queryパラメータ**

|  パラメータ                |  タイプ    |  必須   |  サンプル値  |  説明        |
|----------------------|----------|--------|----------|---------------|
|  startTime      |  String  |  いいえ     |  2024-08-06T00:00:00Z       |   開始時間。この時間はUTC時間のみ対応しており、形式は：YYYY-MM-DDThh:mm:ssZです。         |
|  endTime        |  String  |  いいえ     |  2024-08-07T00:00:00Z       |   終了時間。この時間はUTC時間のみ対応しており、形式は：YYYY-MM-DDThh:mm:ssZです。         |
|  restoreClusterName  |  Array   |  いいえ    |  ob_0807  |  リストアクラスタ名のフィルタリスト。  |
|  status              |  Array   |  いいえ    |    |  タスクの状態。以下を含みます：<ul><li>物理バックアップ<ul><li>THE TENANT IS BEING CREATED：テナント作成中。 </li><li> RECOVERING SYSTEM REPLICAS：システムレプリカのリストア中。 </li><li> PRE-UPGRADE CHECK：アップグレード前チェック。 </li><li> POST-UPGRADE CHECK：アップグレード後チェック。 </ li><li> MODIFYING SCHEMAS：スキーマの変更中。 </ li><li> THE USER PARTITIONS ARE BEING CREATED：ユーザーパーティションの作成中。 </ li><li> RECOVERING USER REPLICAS：ユーザーレプリカのリストア中。 <li> THE INDEX IS BEING CREATED：インデックスの作成中。 </ li><li> IN PROGRESS：インデックスのチェック中。 </ li><li> COMPLETED：完了しました。 </ li><li> FAILED：失敗しました。 </ li><li> SET PARAMETERS：パラメータの設定。 </ li><li> CREAT BASELINE LOG STREAM：ベースラインログストリームの作成。 </ li><li> RESTORING THE BASELINE LOG STREAM：ベースラインログストリームのリストア中。 </ li><li> SET STANDBY TENANT：スタンバイテナントの設定。 </ li><li> UPGRADING THE TENANT：テナントのアップグレード中。 </ li><li> WAITING FOR THE TENANT RECOVERY TO COMPLETE：テナントのリストア終了を待機中。 </ li><li> RECOVERING：リストア中。 </ li></ul></li><li>論理バックアップ<ul><li>START：開始。 </ li><li> RECOVERING：リストア中。 </ li><li> CANCELED：キャンセルされました。 </ li><li> FAILED：失敗しました。 </ li><li> COMPLETED：完了しました。 </ li><li> RECOVERING DATA：データのリストア中。 </ li><li> RECOVERING LOGS：ログのリストア中。 </ li><li> AN ERROR OCCURRED WHILE RECOVERING DATA：データのリストアに失敗しました。 </ li><li> FAILED TO RECOVER LOGS：ログのリストアに失敗しました。 </ li></ul></li></ul>  |

### 戻り結果

**基本データ構造**

|  パラメータ  |  タイプ  | 説明                               |
|--------|--------|----------------------------------|
|  data  |  Object  | 詳細は **`RestoreHistoryTask` のデータ構造** を参照してください。 |
|  successful  |  Boolean | リクエストが成功したかどうか。                          |
|  timestamp |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。                     |
|  duration |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status |  Integer  | HTTP Status仕様に準拠したエンコード。            |
|  traceId |  String  | リクエストのTrace ID。問題のトラブルシューティングに使用されます。             |
|  server  |  String  | リクエストに応答したアプリケーションサービスのアドレス。                    |

**`RestoreHistoryTask` のデータ構造**

|  パラメータ                |  タイプ      |  説明  |
|----------------------|-----------|-------------|
|  id                  |  Integer  |  リストアタスク番号。  |
|  backupMode          |  String   |  リストアモード。バックアップモードフィールドを再利用します。値の範囲：<li>LOGICAL_BACKUP：論理バックアップ。</li><li>PHYSICAL_BACKUP：物理バックアップ。</li>  |
|  triggerType         |  String   |  トリガータイプ。リストアまたは抽出タスクを示します。  |
|  createTime          |  String   |  作成時間。  |
|  finishTime          |  String   |  完了時間。  |
|  backupClusterName   |  String   |  バックアップクラスタ名。  |
|  backupTenantName    |  String   |  バックアップテナント名。  |
|  backupObTenantId    |  Integer  |  バックアップテナントOceanBase側ID。  |
|  restoreClusterId    |  Integer  |  リストアクラスタID。  |
|  restoreClusterName  |  String   |  リストアクラスタ名。  |
|  restoreObClusterId  |  Integer  |  リストアクラスタOceanBase側ID。  |
|  restoreTenantName   |  String   |  リストアテナント名。  |
|  restorePoolListStr  |  String   |  リストアリソースプールリスト。複数のリソースプールはカンマで区切ります。  |
|  restoreUri          |  String   |  バックアップディレクトリ。  |
|  restoreEndTime      |  String   |  リストア終了時間。  |
|  status              |  String   |  リストア状態。  |
|  statusDesc          |  String   |  リストア状態の説明。  |
|  progress            |  String   |  リストア進捗状況。論理バックアップのリストア中のベースラインリストアでは進捗状況を確認できません。増分リストアの場合、ここに`checkpoint`を入力します。  |
|  errorMsg            |  String   |  エラーメッセージ。  |
