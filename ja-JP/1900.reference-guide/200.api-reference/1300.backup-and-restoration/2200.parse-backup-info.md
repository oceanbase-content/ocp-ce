# テナントのバックアップ情報を解析する

## 機能の概要

このAPIは、テナントのバックアップ情報を解析するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/ob/clusters/{id}/tenants/{tenantId}/backup/info`

### リクエストパラメータ

**Pathパラメータ**

|  パラメータ      |  タイプ     |  必須  |  サンプル値  |  説明  |
|------------|-----------|--------|--------|----------|
|  id        |  Integer  |  はい    |  1002  |  クラスタID。  |
|  tenantId  |  Integer  |  はい    |  108   |  テナントID。  |

**Queryパラメータ**

|  パラメータ           |  タイプ    |  必須   |  サンプル値                    |  説明    |
|-----------------|----------|---------|----------------------------|---------------------|
|  startTime      |  String  |  いいえ     |  2024-08-06T00:00:00Z       |   開始時間。UTC時刻のみ対応しており、形式はYYYY-MM-DDThh:mm:ssZです。         |
|  endTime        |  String  |  いいえ     |  2024-08-07T00:00:00Z       |   終了時間。UTC時刻のみ対応しており、形式はYYYY-MM-DDThh:mm:ssZです。         |

### 戻り結果

**基本データ構造**

|  パラメータ  |  タイプ  | 説明                               |
|--------|--------|----------------------------------|
|  data  |  Object  | 詳細は **`ObTenantBackupInfo` のデータ構造** を参照してください。 |
|  successful  |  Boolean | リクエストが成功したかどうかを示します。                          |
|  timestamp |  Datetime  | サーバーがリクエストを完了したタイムスタンプです。                     |
|  duration |  Integer  | サーバーがリクエストを処理した時間（ミリ秒）。                  |
|  status |  Integer  | HTTP Status仕様に準拠したコードです。            |
|  traceId |  String  | リクエストのTrace IDで、問題のトラブルシューティングに使用されます。             |
|  server  |  String  | リクエストに応答したアプリケーションサービスのアドレスです。                    |

**`ObTenantBackupInfo`のデータ構造**

| パラメータ | 型 | 説明 |
|--------|--------|--------|
| clusterName | String | クラスタ名。 |
| obClusterId | Integer | OceanBaseクラスタID。 |
| clusterId | Integer | クラスタID。 |
| obTenantId | Integer | OceanBaseテナントID。 |
| tenantId | Integer | テナントID。 |
| tenantName | String | テナント名。 |
| online | Boolean | オンラインかどうか。 |
| obRecoverableInfoAggregation | ObRecoverableInfoAggregation | 復元可能時間区間。詳細は、**`ObRecoverableInfoAggregation`のデータ構造**を参照してください。 |

**`ObRecoverableInfoAggregation`のデータ構造**

| パラメータ | 型 | 説明 |
|--------|--------|--------|
| obQueryTimeScopeType | String | クエリ時間範囲タイプ。現在、主に復元可能区間とストレージ傾向に使用されます。 |
| latestSevenDaysAggregation | LatestSevenDaysAggregation | 最近の一定日数の復元可能データの集約集合。詳細は、**`LatestSevenDaysAggregation`のデータ構造**を参照してください。 |

**`LatestSevenDaysAggregation`のデータ構造**

| パラメータ | 型 | 説明 |
|-----------|---------------|----------------|
| obRecoverableSectionItems | Array | 復元可能時間区間リスト。 |
| \|----obRecoverableSectionItemType | String | 復元可能時間区間内のノードタイプ。以下を含みます：<li> FULL_DATA_BACKUP：フルデータバックアップ。  </li><li>INCREMENTAL_DATA_BACKUP：増分データバックアップ。   </li><li>LOG_BACKUP：ログバックアップ。  </li><li>RECOVERABLE：復元可能時間。 </li>   |
| \|--backupDimension | String | バックアップの次元。例えば、CLUSTERはクラスタバックアップ、TENANTはテナントバックアップを表します。 |
| \|----backupMode | String | バックアップ方式。以下を含みます：<li>LOGICAL_BACKUP：論理バックアップ。</li><li>PHYSICAL_BACKUP：物理バックアップ。</li>    |
| \|----dataBackupRecoverableInfo | Object | データバックアップの復元可能情報。ノードタイプが**フルデータバックアップ**および**増分データバックアップ**の場合にのみ有効です。     |
| \|----freezeTime | OffsetDateTime | データバックアップに対応するフリーズ時間。  |
| \|----recoverableTime | OffsetDateTime | データバックアップの復元可能時間。    |
| \|----dataVersion | Long | データバージョン。       |
| \|----fullBackupSetId | Long | フルバックアップセットID。物理バックアップ内のフルデータバックアップと増分データバックアップの関係を示すために使用されます。IDが同じフルバックアップと増分バックアップは対応しています。    |
| \|----logRecoverableTimeInterval | Object | ログバックアップの時間区間。ノードタイプが**<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.LogBackup">ログのバックアップ</UI-TERM>**の場合にのみ有効です。    |
| \|----startTime | OffsetDateTime | 開始時間。   |
| \|----endTime | OffsetDateTime | 終了時間。      |
| \|----realRecoverableTimeInterval | Object | 実際の復元可能時間区間。ノードタイプが**復元可能時間**の場合にのみ有効です。     |
| \|----startTime | OffsetDateTime | 開始時間。       |
| \|----endTime | OffsetDateTime | 終了時間。    |
