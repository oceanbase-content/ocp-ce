# アラート履歴の取得

## 機能の概要

このAPIは、アラート履歴を取得するために使用されます。

## 呼び出しの説明

### インターフェース制約

呼び出し元はOCPアプリケーションサービスの認証を通過している必要があります。

### リクエストパス

`GET /api/v2/alarm/alarms/history`

### リクエストパラメータ

**body：**

|  パラメータ           |  型    |  必須   |  サンプル値  |  説明  |
|-----------------|----------|------|-------------------------------|-------------------|
|  appType        |  String  |  いいえ  | OceanBase                     | アプリケーションカテゴリ（アラートソース）。値の範囲：<ul><li>OceanBase</li><li>OCP</li><li>OMS</li><li>OBProxy</li><li>Binlog</li><li>Log</li>OBLB</li><li>OBDNS</li><li>ODP</li></ul>    |
|  scope          |  String  |  いいえ  | Cluster                       | アラートの範囲。値の範囲：<ul><li>Cluster</li><li>Tenant</li><li>Host</li><li>Service</li><li>BinlogService</li><li>Arbitration</li><li>Backup</li><li>OceanBaseLog</li><li>OBProxyLog</li><li>HostLog</li></ul> |
|  target         |  Array   |  いいえ  | alarm_template_id=0:ob_cluster=TEST_CLUSTER-12:tenant_name=oracle:trans_hash=10609937150880685421    | アラートの対象オブジェクト。アラートルールに基づいてターゲットテンプレートから生成されます。    |
|  alarmType      |  String  |  いいえ  | ob_tenant_exists_expired_xa_trans  | アラートタイプ。  |
|  level          |  Array   |  いいえ  | 1                             | アラートレベル \[1\~5\]。それぞれの対応関係は以下のとおりです：Down、Critical、Alert、Caution、Info       |
|  alarmGroupIds  |  integer |  いいえ  | [1,2,3]                       | アラートグループのIDリスト。複数のIDは半角カンマで区切ります。    |
|  status         |  Array   |  いいえ  | Active                        | アラートステータス。値の範囲：<ul><li>Active</li><li>Inactive</li><li>Silenced</li><li>Inhibited</li></ul>   |
|  activeAtStart  |  String  |  いいえ  | 2020-11-11T11:12:13.127+08:00 | アラートが発生した開始時刻。      |
|  activeAtEnd    |  String  |  いいえ  | 2020-11-11T17:11:13.127+08:00 | アラートが発生した終了時刻。      |
|  keyword        |  String  |  いいえ  | hello                         | キーワード一致検索。     |

### 戻り値

**基本データ構造**

|  パラメータ    |  型        |      説明             |
|--------------|------------|-----------------------|
|  data        | Object     | リクエストされたデータ。                |
|  ├─ contents | Array      | アラートの詳細情報。詳細は **OcpAlarm データ構造** を参照してください。   |
|  ├─ page     | Object     | ページネーション情報。詳細は **page データ構造** を参照してください。                 |
|  successful  |  Boolean   | リクエストが成功したかどうか。    |
|  timestamp   |  Datetime  | サーバーがリクエストを完了したタイムスタンプ。    |
|  duration    |  Integer   | サーバーがリクエストを処理した時間（ミリ秒）。   |
|  status      |  Integer   | HTTP ステータスコードに準拠したエンコード。     |
|  traceId     |  String    | リクエストのトレースID。問題の調査に使用されます。  |
|  server      |  String    | リクエストに応答したアプリケーションサービスのアドレス。    |

**OcpAlarm データ構造**

|  パラメータ             |  型         |  説明      |
|-------------------|---------------|------------|
|  gmtCreate        |  String       |  作成日時。  |
|  gmtModified      |  String       |  変更日時。  |
|  id               |  Integer      |  アラートイベントID。 |
|  alarmId          |  Integer      |  アラートID。  |
|  alarmTemplateId  |  Integer      |  アラートテンプレートID。  |
|  appType          |  String       |  アプリケーションタイプ。値の範囲：<ul><li>OceanBase</li><li>OCP</li><li>OMS</li><li>OBProxy</li><li>Binlog</li><li>Log</li>OBLB</li><li>OBDNS</li><li>ODP</li></ul>   |
|  alarmType        |  String       |  アラートタイプ。  |
|  scope            |  String       |  アラートの範囲。値の範囲：<ul><li>Cluster</li><li>Tenant</li><li>Host</li><li>Service</li><li>BinlogService</li><li>Arbitration</li><li>Backup</li><li>OceanBaseLog</li><li>OBProxyLog</li><li>HostLog</li></ul>  |
|  level            |  Integer      |  アラートレベル \[1\~5\]。それぞれの対応：Down、Critical、Alert、Caution、Info。  |
|  status           |  String       |  アラートステータス。値の範囲：<ul><li>Active</li><li>Inactive</li><li>Silenced</li><li>Inhibited</li></ul>  |
|  target           |  String       |  アラートの対象オブジェクト。アラートルールに基づいて生成されるターゲットテンプレートに基づきます。  |
|  alarmTarget      |  Object       |  アラートオブジェクト情報。詳細は **AlarmTarget データ構造** を参照してください。  |
|  obCluster        |  Object       |  クラスタ関連情報。詳細は **AlarmTarget データ構造** を参照してください。  |
|  name             |  String       |  アラート名。  |
|  summary          |  String       |  アラートの概要。アラートルールに基づいて生成される概要テンプレートに基づきます。  |
|  description      |  String       |  アラートの詳細。アラートルールに基づいて生成される詳細テンプレートに基づきます。  |
|  activeAt         |  String       |  アラート生成日時。  |
|  resolvedAt       |  String       |  アラート解消日時。  |
|  updatedAt        |  String       |  アラート更新日時。  |
|  statusUpdatedAt  |  String       |  アラートステータス更新日時。  |
|  labels           |  Object       |  アラートイベントのラベルと値。  |
|  targetLabels     |  Object       |  アラートオブジェクトのラベルと値。例：`svr_ip`、`ob_tenant_id`など。  |
|  metricGroup      |  Object       |  メトリックグループの配列。詳細は **MetricGroup データ構造** を参照してください。  |
|  messagePush      |  Object       |  アラートプッシュの詳細。詳細は **MessagePush データ構造** を参照してください。  |
|  alarmGroups      |  Array        |  アラートグループリスト。  |
|  originalAlarmId  |  Integer      |  元のアラートID。  |
|  containSnapshot  |  Boolean      |  異常スナップショットが含まれているかどうか。  |
|  containSelfcure  |  Boolean      |  自己回復が含まれているかどうか。  |
|  resolveComment   |  String       |  アラート解決の備考情報。  |

**AlarmTargetデータ構造**

|  パラメータ            |  型    |  説明  |
|------------------|----------|--------|
|  appType         |  String  | アプリケーションタイプ。値の範囲：<ul><li>OceanBase</li><li>OCP</li><li>OMS</li><li>OBProxy</li><li>Binlog</li><li>Log</li>OBLB</li><li>OBDNS</li><li>ODP</li></ul>   |
|  scope           |  String  | アラートの範囲。値の範囲：<ul><li>Cluster</li><li>Tenant</li><li>Host</li><li>Service</li><li>BinlogService</li><li>Arbitration</li><li>Backup</li><li>OceanBaseLog</li><li>OBProxyLog</li><li>HostLog</li></ul> |
|  includeTargets  |  Array   | アラート対象（正選択）。   |
|  excludeTargets  |  Array   | アラート対象の除外（逆選択）。   |

**MetricGroupデータ構造**

|  パラメータ         |  型     |  説明  |
|---------------|-----------|--------|
|  id           |  Integer  | 指標グループのID。   |
|  key          |  String   | 指標グループのコード名。  |
|  className    |  String   | 指標グループに対応するクラス名。  |
|  name         |  String   | 指標グループ名。国際化をサポートしています。   |
|  description  |  String   | 指標グループの説明情報。国際化をサポートしています。   |
|  metrics      |  Array    | 指標メタデータの配列。   |
|  dimension    |  String   | 指標グループの次元。     |
|  withLabel    |  Boolean  | ラベル付きのモニタリングデータグループかどうか。デフォルトは`false`です。   |
|  order        |  Integer  | ソートパラメータ。   |

**MessagePushデータ構造**

|  パラメータ  |  型  |  説明  |
|--------------|-----------|---------|
|  configured  |  Boolean  | アラートプッシュが設定されているかどうか。   |
|  successCount  |  Integer  | メッセージの送信に成功した回数。   |
|  noSuccessCount  |  Integer  | メッセージの送信に失敗した回数。   |

**pageデータ構造**

|  パラメータ         |  型    |      説明             |
|---------------|----------|-----------------------|
| totalElements | Integer  | 総レコード数。                 |
| totalPage     | Integer  | 総ページ数。                  |
| number        | Integer  | 現在のページ番号。                 |
| size          | Integer  | 現在のページに含まれるレコード数。                |
