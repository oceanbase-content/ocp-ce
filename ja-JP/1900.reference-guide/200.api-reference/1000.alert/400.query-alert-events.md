# アラートイベントのクエリ

## 機能の概要

指定したアラートイベントの詳細情報を照会します。

## 呼び出しの説明

### インターフェース制約

呼び出し元は、アラート機能に対する読み取り権限が必要です。

### リクエストパス

`GET /api/v2/alarm/alarms/{id}`

### リクエストパラメータ

**path:**

| 名前    | 型    | サンプル値 | 説明          |
| ------- | ------- | ------ | ------------- |
| id      | Integer | 1023   | アラートイベントのID。 |

### 戻り値

**基本データ構造**

| パラメータ        | 型     | 説明                             |
| ----------- | -------- | -------------------------------- |
| data        | Object   | リクエストされたデータ。                     |
| ├─ contents | Object   | アラートイベント情報。詳細は**アラートイベントデータ構造**を参照してください。 |
| successful  | Boolean  | リクエストが成功したかどうか。                   |
| timestamp   | Datetime | サーバーがリクエストを完了したタイムスタンプ。         |
| duration    | Integer  | サーバーがリクエストを処理した時間（ミリ秒）。   |
| status      | Integer  | HTTP Status仕様に準拠したコード。    |
| traceId     | String   | リクエストのTrace ID。問題の調査に使用されます。  |
| server      | String   | リクエストに応答したアプリケーションサービスのアドレス。       |

**アラートイベントデータ構造**

| パラメータ        | 型     | 説明            |
| ----------- | -------- | --------------------- |
| id          | Integer  | アラートイベントのID。      |
| appType     | String   | アプリケーションタイプ。取り得る値：<ul><li>OceanBase</li><li>OCP</li><li>OMS</li><li>OBProxy</li><li>Binlog</li><li>Log</li>OBLB</li><li>OBDNS</li><li>ODP</li></ul>  |
| alarmType   | String   | アラートタイプ。       |
| scope       | String   | アラートの範囲。取り得る値：<ul><li>Cluster</li><li>Tenant</li><li>Host</li><li>Service</li><li>BinlogService</li><li>Arbitration</li><li>Backup</li><li>OceanBaseLog</li><li>OBProxyLog</li><li>HostLog</li></ul>  |
| level       | Integer  | アラートレベル[1～5]。それぞれDown、Critical、Alert、Caution、Infoに対応します。      |
| status      | String   | アラート状態。取り得る値：<ul><li>Active</li><li>Inactive</li><li>Silenced</li><li>Inhibited</li></ul>   |
| target      | String   | アラートイベントのターゲットオブジェクト。アラートルールのターゲットテンプレートに基づいて生成されます。       |
| summary     | String   | アラートイベントの概要。アラートルールの概要テンプレートに基づいて生成されます。    |
| description | String   | アラートイベントの詳細。アラートルールの詳細テンプレートに基づいて生成されます。     |
| activeAt    | Datetime | アラートイベントの生成時間。       |
| resolvedAt  | Datetime | アラートイベントの解消時間。     |
| updatedAt   | Datetime | アラートイベントの更新時間。      |
| labels      | Object   | アラートイベントのラベルと値。       |

```json
GET /api/v2/alarm/alarms/100159
```
