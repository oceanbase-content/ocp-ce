# テナントの一時ファイル使用容量の収集

## 収集の概要

ノード上でテナントが生成した一時ファイルのサイズを確認します。

## 収集の仕組み

```sql
SELECT svr_ip, svr_port, file_type, round(sum(data_size) / 1024 / 1024 / 1024, 3) AS size_gb
FROM __all_space_usage
WHERE file_type = 'tenant tmp data'
GROUP BY svr_ip, svr_port;
```

## 想定される影響

詳細については、[一時ファイルのトラブルシューティングマニュアル](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000685638?back=kb)または[OceanBaseデータベースにおける一時ファイルのディスク容量使用状況の確認方法](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000209899)を参照してください。
