# テナントKVCACHE情報の収集

## 収集の概要

`__all_virtual_kvcache_info` テーブルを参照して、テナントのKVCACHE情報を確認します。

## バージョン要件

OceanBase V4.0.0以降が必要です。

## 収集の仕組み

```sql
SELECT
  IFNULL(t.tenant_name, k.tenant_id) tenant_name,
  k.*
FROM
  __all_virtual_kvcache_info k
  LEFT JOIN __all_tenant t ON k.tenant_id = t.tenant_id
HAVING
  tenant_name = ?
ORDER BY
  cache_size DESC
LIMIT 10
```
