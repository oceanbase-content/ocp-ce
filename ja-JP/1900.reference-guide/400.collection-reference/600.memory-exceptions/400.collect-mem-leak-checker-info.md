# メモリリーク検出情報の収集

## 収集の概要

`__all_virtual_mem_leak_checker_info` テーブルからメモリリーク検出データを確認します。

## バージョン制限

OceanBase V4.0.0以降が対象です。

## 収集の仕組み

```sql
SELECT
  svr_ip,
  svr_port,
  mod_name,
  mod_type,
  alloc_count,
  alloc_size,
  back_trace
FROM
  __all_virtual_mem_leak_checker_info
```
