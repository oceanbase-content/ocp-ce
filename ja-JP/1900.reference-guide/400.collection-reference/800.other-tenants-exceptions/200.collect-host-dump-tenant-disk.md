# ホストから「dump tenant disk usage」というキーワードを含むログの収集

## 収集の概要

`observer.log` に、指定したテナントの「dump tenant disk usage.*disk_usage」などのキーワードを含むログが存在するかどうかを確認します。

## 収集の仕組み

OBServerログディレクトリ（デフォルトは `/home/admin/oceanbase/log`）内の `observer.log` ファイルを照会し、「dump tenant disk usage.*disk_usage={tenant_id:」などのキーワードを含むINFOレベルのログが存在するかどうかを確認します。

以下のコマンドを実行して収集します。`ob_tenant_id` を対応するテナントIDに置き換えてください：

```shell
grep 'dump tenant disk usage.*disk_usage={tenant_id:${ob_tenant_id}' ${observer.log.path}/observer.log
```

<main id="notice" type='explain'>
<h4>説明</h4>
この種類のログは、テナントのディスク使用状況に基づき、10秒ごとに出力されます。
</main>

以下のような収集結果が得られます：

```shell
[2023-05-15 17:30:59.055858] INFO  [STORAGE] ob_tenant_disk_usage_mgr.cpp:69 [87424][0][Y0-0000000000000000-0-0] [lt=11] [dc=0] dump tenant disk usage update info(disk_usage={tenant_id:1, max_disk_size:0, used_data_size:935329792, used_meta_size:56623104})  
```

各パラメータの説明は以下の通りです：

* tenant_id：テナントID。
* max_disk_size：テナントのディスク上限（OceanBase V4.x より前のバージョンではテナントのディスク使用量に制限はありません）。
* used_data_size：テナント内のユーザーデータが使用するディスク容量。
* used_meta_size：テナント内の管理データが使用するディスク容量。
