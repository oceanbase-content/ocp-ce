# observer rootserviceタスク情報の収集

## 収集の概要

Root Serviceタスクレコードを取得し、マージに関連するタスクがないか確認します。

## 収集の仕組み

```sql
SELECT * FROM __all_rootservice_job;
```

## 処理方法

フィールド定義については、[__all_rootservice_job](https://www.oceanbase.com/docs/enterprise-oceanbase-database-cn-1000000000008730)を参照してください。
