# メジャーコンパクション問題診断情報の収集

## 収集の概要

指定したクラスタのメジャーコンパクション問題診断情報を確認し、長時間にわたってメジャーコンパクションが完了していないパーティションについて、診断テーブルを用いて異常が発生していないか診断します。

## 収集の仕組み

OceanBase V3.2.4以降のバージョン：

```sql
SELECT * FROM __all_virtual_compaction_diagnose_info;
```

## 対処方法

詳細については、[oceanbase.__all_virtual_compaction_diagnose_info](https://www.oceanbase.com/docs/enterprise-oceanbase-database-cn-1000000000008739)および[compaction_diagnoseビュー使用ガイド](https://www.oceanbase.com/knowledge-base/oceanbase-database-1000000000209906)を参照してください。
