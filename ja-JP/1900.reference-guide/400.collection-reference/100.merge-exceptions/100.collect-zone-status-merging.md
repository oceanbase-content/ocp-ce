# クラスタZoneのメジャーコンパクション状態情報の収集

## 収集の概要

指定されたクラスタ内のZoneのメジャーコンパクション状態を確認します。

## 収集の仕組み

OceanBase V4.0.0以前のバージョン：

```sql
SELECT zone, info as status, gmt_modified from __all_zone WHERE name='merge_status' AND zone != '';
```

OceanBase V4.0.0以降のバージョン：

```sql
SELECT c.TENANT_ID tenant_id, t.tenant_name, c.ZONE zone, c.STATUS status, c.LAST_FINISH_TIME, c.IS_ERROR, c.INFO
FROM CDB_OB_ZONE_MAJOR_COMPACTION c
INNER JOIN __all_tenant t ON c.tenant_id=t.tenant_id;
```

## 対処方法

Zoneの状態に基づいて、非IDLEのメジャーコンパクション状態がないか調査します。メジャーコンパクションの状態は以下のとおりです：

* IDLE：メジャーコンパクションが実行されていないことを示します。
* ERROR：メジャーコンパクションでエラーが発生したことを示します。
* TIMEOUT：メジャーコンパクションがタイムアウトしましたが、コンパクションは一時停止せずに継続されます。タイムアウトフラグが設定されるだけです。
* MERGING：メジャーコンパクションが実行中であることを示します。

`STATUS`列が`IDLE`の行では、`gmt_modified`列の値が最終メジャーコンパクション完了時刻を表します。
