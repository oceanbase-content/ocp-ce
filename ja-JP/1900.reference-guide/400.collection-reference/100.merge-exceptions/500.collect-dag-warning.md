# OBカーネルDAG警告情報の収集

## 収集の概要

ダンプまたはマージ失敗の場合、`__all_virtual_dag_warning_history` 仮想テーブルをクエリして失敗原因とTrace IDを取得できます。

## 収集の仕組み

OceanBase V3.2.0以降のバージョン：

```sql
SELECT * FROM __all_virtual_dag_warning_history;
```

## 対処方法

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E5%BC%82%E5%B8%B8%E6%A3%80%E6%9F%A51.png)

Trace IDを取得した後、`gmt_modified` を参照して対応する時間範囲内のobserver logを確認し、具体的な失敗原因を調査します。
