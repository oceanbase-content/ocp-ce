# メジャーコンパクション関連パラメータ設定の収集

## 収集の概要

メジャーコンパクションに関連するパラメータ設定を照会します。

## 収集の原理

OceanBase V4.0.0 より前のバージョン：

```sql
SELECT NULL tenant_id,zone,svr_ip,svr_port,name,value,info,section,scope,edit_level 
                              FROM __all_virtual_sys_parameter_stat 
                              WHERE name IN (
                                  'merge_thread_count', 
                                  'minor_freeze_times',
                                  'zone_merge_timeout',
                                  'zone_merge_concurrency',
                                  'default_progressive_merge_num',
                                  'merger_check_interval'
                              )
```

OceanBase V4.0.0 以降のバージョン：

```sql
SELECT tenant_id,zone,svr_ip,svr_port,name,value,info,section,scope,edit_level 
                            FROM __all_virtual_tenant_parameter_info 
                            WHERE name IN (
                                'compaction_low_thread_score', 
                                'major_freeze_duty_time',
                                'major_compact_trigger',
                                'default_progressive_merge_num',
                                'merger_check_interval'
                            )
```

パラメータの意味と説明：

* `merge_thread_count` ：日次メジャーコンパクション処理のスレッド数を設定します。
* `minor_freeze_times` ：何回のダンプで1回のグローバルメジャーコンパクションをトリガーするかを設定します。
* `zone_merge_timeout` ：単一ゾーンのメジャーコンパクションタイムアウト時間を設定します。
* `zone_merge_concurrency` ：メジャーコンパクション時に、いくつのゾーンの並列処理をサポートするかを設定します。値が0の場合、システムがデプロイ状況に応じて最適な並列度を自動選択します。
* `default_progressive_merge_num` ：新規テーブル作成時のデフォルトのプログレッシブメジャーコンパクション回数を設定します。
* `merger_check_interval` ：メジャーコンパクション状態チェックスレッドのスケジューリング間隔を設定します。
* `compaction_low_thread_score` ：低優先順位コンパクションのワーカースレッドがCPUタイムスライスを占有する重みを設定します。
* `major_freeze_duty_time` ：日次定時フリーズおよびメジャーコンパクションのトリガー時刻を設定します。
* `major_compact_trigger` ：何回のダンプで1回のグローバルメジャーコンパクションをトリガーするかを設定します。
