# メジャーコンパクション履歴に基づく提案情報の収集

## 情報収集の概要

指定したクラスタのメジャーコンパクションに関する提案情報を確認します。

## 情報収集の仕組み

OceanBase V3.2.4以降のバージョン：

```sql
SELECT * FROM __all_virtual_compaction_suggestion;
```

## 対処方法

過去のコンパクション記録に基づいて提示される提案情報を表示します。これには、以下の内容が含まれますが、これらに限定されません：

1. データテーブルのパーティションデータ量が過大で、実行時間が長すぎる場合。
2. 処理データ量に対して実行時間が不相応で、ハードウェア障害が疑われる場合。
3. 大規模テーブルへのランダム挿入により、マクロブロックの再利用率が低い場合。
4. パラレルコンパクションにおけるRange分割が不適切などの場合。
