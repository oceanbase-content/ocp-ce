# mgragentパニックログの収集

## 収集の概要

ホストからmgragentパニックログ情報を取得します。

## 収集の原理

```bash
cat ${ocp.agent.home.path}/log/ocp_mgragent.error.log | grep -80 panic || true
```

パニックは通常、プロセスの実行が想定通りに行われないことが原因で発生します。例えば、設定ミスによりプログラムが誤動作する場合などです。OCPテクニカルサポートにお問い合わせいただき、対応をご依頼いただくことを推奨します。
