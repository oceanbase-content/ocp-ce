# Agent goroutine情報の収集

## 収集の概要

ホストからagentプロセスのgoroutineプロファイル情報を取得します。

## 収集の仕組み

```bash
curl -s --unix-socket ${ocp.agent.home.path}/run/ocp_monagent.$(cat ${ocp.agent.home.path}/run/ocp_monagent.pid).sock http://unix-socket-server/debug/pprof/goroutine?debug=1
```

## 手順

収集された`pprof/goroutine`は、現在のプロセスにおけるすべてのgoroutineのスタック情報であり、読みやすいテキスト形式で表示されます。OCPサポートチームにお問い合わせいただき、対応をご依頼いただくことを推奨します。
