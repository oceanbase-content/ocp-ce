# monagentパニックログの収集

## 収集の概要

ホストからmonagentのパニックログ情報を取得します。

## 収集の仕組み

```bash
cat ${ocp.agent.home.path}/log/ocp_monagent.error.log | grep -80 panic || true
```

パニックは通常、プロセスの実行が想定通りに行われないことが原因で発生します。例えば、設定ミスによりプログラムが誤動作する場合などです。OCPサポートチームにお問い合わせいただき、対応をご依頼いただくことを推奨します。
