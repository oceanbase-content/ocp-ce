# observerスレッドのtop情報を収集する

## 収集の概要

クラスタノード上のobserverスレッドのtop情報を確認します。

## 収集の原理

```bash
ob_pid=$(pgrep observer|head -n 1); if [[ ! -z "$ob_pid" ]]; then top -H -b -n 2 -d 5 -p "$ob_pid" | tail -n +2 | grep "^top -" -A36 ; fi
```

## 手順

observerプロセス内でCPU使用率が最も高いスレッド、およびテナント関連のスレッドのCPU使用率（例：`TNT_L0_1001`）を取得します。
