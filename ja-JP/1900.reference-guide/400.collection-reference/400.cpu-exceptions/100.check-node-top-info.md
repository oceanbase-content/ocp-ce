# クラスタノード上のCPU使用率が高いプロセスのtop情報を収集する

## 収集の概要

ホスト上でtopコマンドを実行した結果を確認します。

## 収集の仕組み

```bash
top -b -n 2 -d 5 | tail -n +2 | grep  "^top -" -A36
```

## 手順

現在のマシン上でCPU使用率が高いプロセスを特定し、プロセスの状況に応じてさらなる調査を行うために使用されます。
