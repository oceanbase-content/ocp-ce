# クラスタノード上のobstack情報を収集する

## 収集の概要

ホスト上でobstack（現在はx86_64のみサポート）コマンドを実行し、コマンド実行結果を収集します。

## 収集の原理

```sql
${ocp.agent.home.path}/bin/obstack_x86_64 $(pgrep observer) -o
```

## その他

obstackツール内部でも `kill -60 $observer` コマンドが呼び出されます。その利点は、スレッドスタックのアドレス情報を直接関数名に解析し、簡単に集約できることであり、ユーザーがOBServerノード上のすべてのスレッドのスタックコード実行ホットスポットを迅速に特定できるようにすることです。
