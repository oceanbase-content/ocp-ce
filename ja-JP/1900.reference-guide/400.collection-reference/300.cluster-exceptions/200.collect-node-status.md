# クラスタのserverノード情報を収集する

## 収集の概要

不良ディスクが存在するかどうかを確認します。戻り値が空の場合、不良ディスクとしてマークされているディスクはないことを意味します。

## 収集の原理

```SQL
SELECT /*+READ_CONSISTENCY(WEAK),query_timeout(100000000)*/ *
FROM __all_server
WHERE status = "active"
	OR start_service_time = 0
	OR stop_time > 0;
```

## 手順

* システムテーブル `__all_server` に表示される stop_time が0ではないが、status が active の場合、observer プロセスは存在するもののサービスを提供できず、stop 状態にあることを示します。
* 起動したOBServerはRootServiceとハートビートを確立しており、この時点でOceanBaseデータベースはそのOBServerの状態をACTIVEとしてマークします。

この時、`__all_server` 仮想テーブルをクエリすると、起動したOBServerの状態はACTIVEですが、start_service_time は0であることが確認できます。詳細は以下のとおりです。

```sql
obclient> select svr_ip,status,start_service_time from __all_server;
+----------------+--------+--------------------+
| svr_ip         | status | start_service_time |
+----------------+--------+--------------------+
| xxx.xx.xxx.1 | active |                  0 |
| xxx.xx.xxx.2 | active |   1617702133437712 |
| xxx.xx.xxx.3 | active |   1617702146772849 |
+----------------+--------+--------------------+
3 rows in set (0.00 sec)
```
