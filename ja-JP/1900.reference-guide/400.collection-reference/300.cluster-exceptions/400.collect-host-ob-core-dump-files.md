# OBServerコアダンプファイルの存在を確認する

## 収集の概要

ホスト上でコマンドを実行し、OBServerコアダンプファイルが存在するかどうかを確認します。

## 収集の仕組み

`observer.coredump.path`構成パラメータは、ホストagentディレクトリ内の`conf/module_config/monitor_ob_custom.yaml`ファイルで確認できます。

```shell
ls -l ${observer.coredump.path} --full-time | grep '.*core-observer' || true
```
