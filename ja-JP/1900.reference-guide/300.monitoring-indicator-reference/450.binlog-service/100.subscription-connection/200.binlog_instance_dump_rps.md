# Send RPS

このセクションでは、Binlogインスタンスのサブスクリプション接続監視メトリクス **<UI-TERM key="ocp-v2.Instance.Overview.Monitor.SendRps">送信 RPS</UI-TERM>** について説明します。統計範囲を指定することで、Binlogインスタンスのサブスクリプションに関する **<UI-TERM key="ocp-v2.Instance.Overview.SendRps">送信 RPS</UI-TERM>** データを照会できます。

## メトリクスの概要

BinlogサブスクリプションのSend RPS。
