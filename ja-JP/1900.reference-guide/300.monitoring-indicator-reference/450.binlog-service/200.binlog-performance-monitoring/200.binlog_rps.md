# Binlog RPS

このセクションでは、Binlogインスタンスのパフォーマンス監視指標である **Binlog RPS** について説明します。この指標は、Binlogインスタンスの読み取りRPS（read）と書き込みRPS（write）を統計します。統計範囲を指定することで、Binlogインスタンスの読み取り/書き込みRPSデータを照会できます。

## read

### 指標の紹介

Binlog読み取りRPS。

## 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|---------------|--------|
| read     | binlog_instance_convert_fetch_rps | -      |

## 計算式

sum(binlog_instance_convert_fetch_rps{@LABELS}) by (@GBLABELS)
