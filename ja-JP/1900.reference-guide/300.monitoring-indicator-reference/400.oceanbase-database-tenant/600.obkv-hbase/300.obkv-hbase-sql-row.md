# 平均操作行数

このセクションでは、テナントのOBKV_HBaseタイプモニタリングメトリクスである**平均操作行数**について説明します。このメトリクスは、テナントが1秒間に平均して処理するSQL行数を統計します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントのOBKV_HBaseタイプの**平均操作行数**データを照会できます。
