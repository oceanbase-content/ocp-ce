# オブジェクト数

このセクションでは、OceanBaseテナントの監視指標である **オブジェクト数** について説明します。オブジェクト数は、ユーザーが作成したテーブルおよびグローバルインデックスのプライマリパーティション/レプリカパーティションの数のみを集計します。集計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **オブジェクト数** を照会できます。

## primary_leaders

### 指標の紹介

集計範囲内のテナントプライマリパーティションのリーダー数。

### 指標パラメータの説明

|   **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**   |         **指標名**          | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|-------------|-----------------------|--------|
|  primary_leaders | primary_leaders_cnt | -     |

### 計算式

sum(primary_leaders_cnt{@LABELS}) by (@GBLABELS)

### 収集SQL

OceanBase V4.0.0.0以降のバージョン：

```sql
SELECT TENANT_ID, SVR_IP, SVR_PORT, COUNT(*) AS cnt FROM CDB_OB_TABLE_LOCATIONS WHERE ROLE = 'LEADER' AND (TENANT_ID=1 AND TABLE_ID > 500000 OR LS_ID > 1) GROUP BY TENANT_ID, SVR_IP, SVR_PORT
```

## log_stream_leaders

### 指標の紹介

統計範囲内のテナントログストリームのリーダー数。

### 指標パラメータの説明

|   **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**   |         **指標名**          | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|-------------|-----------------------|--------|
|   log_stream_leaders | log_stream_leaders_cnt | -      |

### 計算式

sum(log_stream_leaders_cnt{@LABELS}) by (@GBLABELS)

### 取得SQL

OceanBase V4.0.0.0以降のバージョン：

```sql
SELECT tenant_id, SVR_IP, SVR_PORT, count(*) as cnt FROM CDB_OB_LS_LOCATIONS  WHERE ROLE = 'leader' GROUP BY TENANT_ID, SVR_IP, SVR_PORT
```
