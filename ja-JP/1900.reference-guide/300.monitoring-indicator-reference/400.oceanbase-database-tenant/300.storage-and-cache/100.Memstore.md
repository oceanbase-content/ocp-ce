# MEMStore

このセクションでは、OceanBaseテナントの監視指標 **MEMStore** について説明します。OCPでは、統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **MEMStore** データを照会できます。

## total

### 指標の紹介

統計範囲内で、テナント用に割り当てられたMEMStoreのサイズです。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |      **指標名**       | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|---------|---------------------|--------|
| total   | total_memstore_used | Byte     |

### 計算式

sum(ob_sysstat{stat_id="130001",@LABELS}) by (@GBLABELS) / 1048576

### 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (130001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (130001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

## trigger

### 指標の紹介

統計範囲内でメジャーコンパクションをトリガーするMEMStoreのサイズです。アクティブなMemStoreのサイズがこの値に達すると、メジャーコンパクションがトリガーされます。

### メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |       **指標名**       | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------|----------------------|--------|
| trigger | major_freeze_trigger | Byte     |

### 計算式

sum(ob_sysstat{stat_id="130002",@LABELS}) by (@GBLABELS) / 1048576

### 取得SQL

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (130002) and (con_id > 1000 or con_id = 1) and class < 1000

* OceanBase V4.0以降のバージョン：

  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (130002) and (con_id > 1000 or con_id = 1) and class < 1000

## limit

### 指標の紹介

MEMStoreの最大使用制限値です。totalの値がこの値以上になると、書き込み停止がトリガーされます。

### メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **メトリクス名**    | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|----------------|--------|
| limit   | memstore_limit | Byte     |

### 計算式

sum(ob_sysstat{stat_id="130004",@LABELS}) by (@GBLABELS) / 1048576

### クエリの収集

  ```
