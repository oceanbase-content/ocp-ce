# 物理I/Oスループット

このセクションでは、OceanBaseテナントのパフォーマンス指標である**物理I/Oスループット**について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のOceanBaseテナントの**物理I/Oスループット**を照会できます。

## ssstore_read

### 指標の紹介

統計範囲内で、テナントが毎秒SSStoreから読み取るデータ量です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**   | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------|--------------|--------|
| ssstore_read   | io_read_size | Byte     |

### 計算式

sum(rate(ob_sysstat{stat_id="60002",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (60002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (60002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
