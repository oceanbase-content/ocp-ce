# データディスク

このセクションでは、OceanBaseテナントの監視メトリック **<UI-TERM key="ocp-v2.Component.OBServerList.Disk">データディスク</UI-TERM>** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **<UI-TERM key="ocp-v2.Detail.Capacity.Disk">データディスク</UI-TERM>** のデータを照会できます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>テナントが属するクラスタがAIクラスタ(共有ストレージ形態)の場合、データディスク関連メトリックはキャッシュディスクのメトリックとして表示され、オブジェクトストレージ上のデータ量ではなくローカルキャッシュディスクの使用状況を反映します。</p>
</main>

## data_disk_size

### メトリック紹介

統計範囲内のテナントデータディスクのデータ量。

### メトリックパラメータ説明

|   **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**   |         **メトリック名**          | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">単位</UI-TERM>** |
|-------------|-----------------------|--------|
|  data_disk_size | ob_tenant_data_size | Byte      |

### 計算式

sum(ob_tenant_server_data_size{@LABELS}) by (@GBLABELS)

## data_index_size

### 指標の紹介

統計範囲内のテナントデータディスクのインデックスサイズを示します。

### 指標パラメータの説明

|   **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**   |         **指標名**          | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">単位</UI-TERM>** |
|-------------|-----------------------|--------|
|  data_index_size | ob_tenant_data_index_size | Byte      |

### 計算式

sum(ob_tenant_server_data_index_data_size{@LABELS}) by (@GBLABELS)

### クエリSQL

* OceanBase V4.0.0.0未満のバージョン：

  ```sql
  select /*+ READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(50000000) */ a.tenant_id, b.svr_ip, b.svr_port, sum(size) as data_size from __all_virtual_table_mgr b left join __all_virtual_table a on a.tenant_id = b.tenant_id and a.table_id = b.index_id where a.table_type = 5 group by 1, 2, 3
  ```

* OceanBase V4.0.0.0以降のバージョン：

  ```sql
  select  /*+ READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(50000000) */ a.tenant_id,a.svr_ip,a.svr_port,sum(a.data_size) as data_size FROM CDB_OB_TABLET_REPLICAS as a join (select b.tenant_id, b.tablet_id from  __all_virtual_tablet_to_ls as b right join (select tenant_id, table_id from __all_virtual_table where table_type = 5 and table_id > 500000) as c on b.tenant_id = c.tenant_id and b.table_id = c.table_id union all select tenant_id, table_id as tablet_id from __all_virtual_table where table_type = 5 and table_id < 500000 ) as d on a.tenant_id = d.tenant_id and a.tablet_id = d.tablet_id group by a.tenant_id,a.svr_ip,a.svr_port
  ```
