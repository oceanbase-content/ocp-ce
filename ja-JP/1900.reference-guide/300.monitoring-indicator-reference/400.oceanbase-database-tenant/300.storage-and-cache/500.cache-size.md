# キャッシュサイズ

このセクションでは、OceanBaseテナントのモニタリング指標である **<UI-TERM key="ocp-performance-report.pages.AWR.CacheSize">キャッシュサイズ</UI-TERM>** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **<UI-TERM key="ocp-performance-report.pages.AWR.ReportContent.CacheSize">キャッシュサイズ</UI-TERM>** を照会できます。

## block_cache

### 指標の概要

統計範囲内のブロックキャッシュサイズです。

ブロックキャッシュ（Block Cache）は、OracleのBuffer Cacheに似ており、具体的なデータブロックをキャッシュします。実際には、Block Cache内のキャッシュは解凍されたマイクロブロックであり、サイズは可変長です。

### 指標パラメータの説明

|   **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**   |     **指標名**     | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|-------------|------------------|--------|
| block_cache | block_cache_size | Byte     |

### 計算式

sum(ob_cache_size_bytes{cache_name="user_block_cache",@LABELS}) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ tenant_id, cache_name, cache_size from __all_virtual_kvcache_info where svr_ip = ? and svr_port = ?
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ tenant_id, cache_name, cache_size from GV$OB_KVCACHE where svr_ip = ? and svr_port = ?
  ```

## row_cache

### 指標の概要

統計範囲内の行キャッシュサイズです。

行キャッシュ（Row Cache）は、具体的なデータ行をキャッシュします。Get/MultiGetクエリを実行する際、対応するデータ行をRow Cacheに格納することがあります。これにより、ホットスポット行のクエリ時にクエリパフォーマンスを大幅に向上させることができます。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |    **指標名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|-----------|----------------|--------|
| row_cache | row_cache_size | Byte     |

### 計算式

sum(ob_sysstat{stat_id="120008",@LABELS}) by (@GBLABELS)

### クエリの収集

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (120008) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (120008) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
