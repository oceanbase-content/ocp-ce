# ベクトルインデックスデータサイズ

このセクションでは、OceanBaseテナントの監視メトリクスである**ベクトルインデックスデータサイズ**について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**ベクトルインデックスデータサイズ**を照会できます。

## mem_hold_size

### メトリクス紹介

OceanBaseテナントのベクトルインデックスデータのメモリ使用量。

### メトリクスパラメータ説明

| メトリクス項目  | メトリクス名  | 単位  |
|---------|-----------|--------|
| ob_tenant_vector_mem_hold | mem_hold_size | byte |

### 計算式

sum(ob_tenant_vector_mem_hold{@LABELS}) by (@GBLABELS)

### SQL収集

OceanBase V4.3.5.3以降のバージョン：

```sql
select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ tenant_id,svr_ip,svr_port,vector_mem_hold,vector_mem_used,vector_mem_limit from GV$OB_VECTOR_MEMORY
```
