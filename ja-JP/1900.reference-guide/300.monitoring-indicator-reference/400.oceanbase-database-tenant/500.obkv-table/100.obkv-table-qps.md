# QPS

このセクションでは、テナントのOBKV_Tableタイプのモニタリング項目であるパフォーマンス指標QPS（Query Per Second、1秒あたりのSQL文処理数）について説明します。Select文、Insert文、Update文、Replace文、Delete文、Query and mutate文に対する指標およびすべての文タイプに対する詳細な指標が含まれます。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントのOBKV_Tableタイプの**QPS**データを照会できます。
