# トランザクションログ量

このセクションでは、OceanBaseテナントのモニタリング指標である**トランザクションログ量**について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**トランザクションログ量**を照会できます。

## 指標の概要

統計範囲内で、1秒間にコミットされるトランザクションログのサイズです。

## 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |         **指標名**          | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|---------------------------|--------|
| log_size   | clog_trans_log_total_size | Byte     |

## 計算式

sum(rate(ob_sysstat{stat_id="80057",@LABELS}[@INTERVAL])) by (@GBLABELS)

## 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (80057) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (80057) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
