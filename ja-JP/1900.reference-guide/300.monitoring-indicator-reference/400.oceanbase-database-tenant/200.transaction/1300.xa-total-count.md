# XAステートメント数

このセクションでは、OceanBaseテナントのパフォーマンス指標である **XAステートメント数** について説明します。**XAステートメント数** 指標は、OceanBaseテナントのXAステートメントの総数を集計するために使用されます。この指標は、xa_start_total_count、xa_end_total_count、xa_prepare_total_count、xa_commit_total_count、xa_rollback_total_count の5つのサブ指標に細分化され、テナントのXAステートメント数を集計します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **XAステートメント数** を照会できます。

## xa_start_total_count

### 指標の紹介

OceanBaseテナント内のxa_startステートメント数。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |  **指標名**  | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|-----------|----------|--------|
| xa_start_total_count | xa_start_total_count | -  |

### 計算式

sum(rate(ob_sysstat{stat_id="30200",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

OceanBase V4.2.2.0以降のバージョン：

```sql
select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30200) and (con_id > 1000 or con_id = 1) and class < 1000
```
