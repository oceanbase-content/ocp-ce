# パーティション

このセクションでは、OceanBaseテナントの監視メトリクス **<UI-TERM key="ocp-v2.Detail.Resource.Top.Partition">パーティション</UI-TERM>** について説明します。このメトリクスは、OceanBaseのバージョンに応じて4つの指標に細分化されており、それぞれ
log_stream_replica_absent_count（テナントログストリームの欠落レプリカ数）、
log_stream_no_leader（テナントログストリームのリーダーなし数）、leader_absent_count（テナントのリーダーなしパーティション数）、
replica_absent_count（テナントの欠落レプリカパーティション数）です。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **<UI-TERM key="ocp-v2.Detail.Resource.Top.Partition">パーティション</UI-TERM>** データを照会できます。

## log_stream_replica_absent_count

### メトリクスの紹介

統計範囲内のテナントログストリームの欠落レプリカ数。

### メトリクスパラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |       **メトリック名**        | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------------|-----------------------|--------|
| log_stream_replica_absent_count | tenant_log_stream_replica_absent_count | -      |

### 計算式

max(log_stream_replica_absent_count{@LABELS}) by (@GBLABELS)

### クエリSQL

OceanBase V4.0以降のバージョン：

```sql
SELECT /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(5000000) */ t.tenant_id, t.tenant_name, COUNT(DISTINCT CASE WHEN (r.replica_count IS NULL OR r.replica_count < t.expected_replica_count) THEN ls.ls_id ELSE NULL END) as cnt FROM (SELECT tenant_id, tenant_name, LENGTH(locality) - LENGTH(REPLACE(locality, '@', '')) as expected_replica_count FROM DBA_OB_TENANTS WHERE tenant_type IN ('SYS', 'USER') AND locality IS NOT NULL) t INNER JOIN CDB_OB_LS ls ON t.tenant_id = ls.tenant_id AND ls.status NOT IN ('creating', 'create_abort') LEFT JOIN (SELECT tenant_id, ls_id, COUNT(DISTINCT CONCAT(zone, ':', replica_type)) as replica_count FROM CDB_OB_LS_LOCATIONS WHERE zone IS NOT NULL AND replica_type IS NOT NULL GROUP BY tenant_id, ls_id) r ON ls.tenant_id = r.tenant_id AND ls.ls_id = r.ls_id GROUP BY t.tenant_id, t.tenant_name
```

## log_stream_no_leader

### メトリクスの紹介

統計範囲内のテナントログストリームのリーダーなし状態数。

### メトリクスパラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |      **メトリック名**       | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------------|---------------------|--------|
| log_stream_no_leader | ob_tenant_log_stream_no_leader | -      |

### 計算式

ob_tenant_log_stream_no_leader{@LABELS}

### クエリSQL

OceanBase V4.0以降のバージョン：

* LS1リーダー検査：

  ```sql
  SELECT tenant_id FROM __all_virtual_log_stat WHERE ls_id = 1 AND role = 'LEADER'
  ```

* その他のLSリーダー統計：

  ```sql
  SELECT a.tenant_id, a.ls_id, COUNT(*) as leader_count FROM CDB_OB_LS a INNER JOIN CDB_OB_LS_LOCATIONS b ON a.tenant_id = b.tenant_id AND a.ls_id = b.ls_id AND b.role = 'LEADER' WHERE a.status NOT IN ('creating', 'create_abort') GROUP BY a.tenant_id, a.ls_id
  ```

## leader_absent_count

### 指標の紹介

統計範囲内で、テナントの無リーダーパーティション数を示します。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |       **指標名**        | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------------|-----------------------|--------|
| leader_absent_count | tenant_partition_leader_absent_count | -      |

### 計算式

max(partition_leader_absent_count{@LABELS}) by (@GBLABELS)

### 取得SQL

OceanBase V4.0未満のバージョン：

```sql
SELECT /*+ MONITOR_AGENT QUERY_TIMEOUT(20000000) */ tenant.tenant_id, tenant.tenant_name, IFNULL(stat.cnt, 0) cnt FROM __all_tenant tenant LEFT JOIN (SELECT /*+QUERY_TIMEOUT(20000000)*/ tenant.tenant_id, count(distinct a.table_id,a.partition_id) cnt FROM v$ob_cluster cluster, __all_tenant tenant JOIN __all_virtual_meta_table a ON a.tenant_id=tenant.tenant_id LEFT JOIN __all_virtual_meta_table b ON a.table_id=b.table_id AND a.partition_id=b.partition_id WHERE (cluster.cluster_role='PRIMARY' and b.role=1 or cluster.cluster_role='STANDBY' and b.role=3) and b.tenant_id IS NULL GROUP BY tenant.tenant_id) stat ON stat.tenant_id=tenant.tenant_id
```

## replica_absent_count

### 指標の紹介

統計範囲内で、テナントのレプリカ欠落パーティション数を示します。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |      **指標名**       | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------------|---------------------|--------|
| replica_absent_count | tenant_partition_replica_absent_count | -      |

### 計算式

max(partition_replica_absent_count{@LABELS}) by (@GBLABELS)

### 取得SQL

OceanBase V4.0 より前のバージョン：

```sql
SELECT /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) QUERY_TIMEOUT(20000000) */ tenant.tenant_id, tenant.tenant_name, IFNULL(stat.cnt, 0) cnt FROM __all_tenant tenant LEFT JOIN (SELECT table_id>>40 AS tenant_id, COUNT(1) cnt FROM __all_virtual_election_info WHERE member_list NOT LIKE CONCAT(replica_num,'{%') AND SUBSTR(member_list, 1, 1) != '0' GROUP BY tenant_id) stat ON tenant.tenant_id=stat.tenant_id where stat.tenant_id not in (select tenant_id from __all_rootservice_job where job_type='ALTER_TENANT_LOCALITY' and job_status='INPROGRESS')
```
