# トランザクション数

このセクションでは、OceanBaseテナントのパフォーマンス指標である **トランザクション数** について説明します。**トランザクション数** 指標は、OceanBaseテナントが1秒間に処理するトランザクションの回数を統計するために使用されます。この指標は、テナントのトランザクション数を統計するために、2つのサブ指標に細分化されています：transaction_single_partition_count（1秒間の通常トランザクション数）と transaction_multi_partition_count（1秒間の分散トランザクション数）です。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **トランザクション数** を照会できます。

## transaction_single_partition_count

### 指標の紹介

OceanBaseテナントが1秒間に処理する通常トランザクションの回数。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |  **指標名**  | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|-----------|----------|--------|
| transaction_single_partition_count | transaction_single_partition_count | times/s  |

### 計算式

sum(rate(ob_sysstat{stat_id="30012",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30012) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30012) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
