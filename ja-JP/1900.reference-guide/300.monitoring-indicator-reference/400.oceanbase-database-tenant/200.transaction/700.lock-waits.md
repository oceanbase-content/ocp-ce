# トランザクションロック待機回数

このセクションでは、OceanBaseテナントのモニタリング指標である**トランザクションロック待機回数**について説明します。この指標は、テナント範囲内でのトランザクションロックの待機成功および失敗回数を集計したものです。トランザクションロックの待機成功とは、待機後にトランザクションロックを正常に取得できた場合を指します。取得できなかった場合は、トランザクションロックの待機失敗とみなされます。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの**トランザクションロック待機回数**データを照会できます。

## success

### 指標の紹介

統計範囲内での書き込みロック待機成功回数。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |            **指標名**            | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------|--------------------------------|--------|
| success | memstore_write_lock_succ_count | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="60021",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (60021) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (60021) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
