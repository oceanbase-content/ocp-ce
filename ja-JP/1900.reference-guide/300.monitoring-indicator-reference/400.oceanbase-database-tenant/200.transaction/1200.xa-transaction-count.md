# XAトランザクション数

このセクションでは、OceanBaseテナントのパフォーマンス指標である **XAトランザクション数** について説明します。 **XAトランザクション数** 指標は、OceanBaseテナントのXAトランザクションの総数を集計するために使用されます。この指標は、xa_trans_start_count、xa_read_only_trans_total_count、xa_one_phase_commit_total_count の3つのサブ指標に細分化され、テナントのXAトランザクション数を集計します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **XAトランザクション数** を照会できます。

## xa_trans_start_count

### 指標の紹介

OceanBaseテナント内で既に開始済みのXAトランザクションの総数（終了したものを含む）。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |  **指標名**  | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|-----------|----------|--------|
| xa_trans_start_count | xa_trans_start_count | -  |

### 計算式

sum(rate(ob_sysstat{stat_id="30220",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

OceanBase V4.2.2.0以降のバージョン：

```sql
select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30220) and (con_id > 1000 or con_id = 1) and class < 1000
```
