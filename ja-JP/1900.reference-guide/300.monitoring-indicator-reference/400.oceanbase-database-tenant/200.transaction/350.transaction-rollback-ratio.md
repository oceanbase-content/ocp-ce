# トランザクションロールバック比率

このセクションでは、OceanBaseテナントの監視指標である**トランザクションロールバック比率**について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの**トランザクションロールバック比率**データを照会できます。

## 指標の概要

統計範囲内のすべてのトランザクションのロールバック比率です。

## 指標パラメータの説明

|   指標項目   |     指標名     |  単位   |
|---------|----------------|--------|
| transaction_rollback_ratio     | transaction_rollback_ratio | %     |

## 計算式

100 * 1 / (1 + sum(rate(ob_sysstat{stat_id="30007",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_sysstat{stat_id="30009",@LABELS}[@INTERVAL])) by (@GBLABELS))'

## 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30007, 30009) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以上のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30007, 30009) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
