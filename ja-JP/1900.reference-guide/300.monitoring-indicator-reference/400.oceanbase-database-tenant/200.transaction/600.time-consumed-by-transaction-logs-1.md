# トランザクションログの処理時間

このセクションでは、OceanBaseテナントのモニタリング指標である **トランザクションログの処理時間** について説明します。これには、トランザクションログのネットワーク同期平均時間とトランザクションログのディスク書き込み平均時間が含まれます。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの **トランザクションログの処理時間** を照会できます。

## sync_time

### 指標の概要

統計範囲内で、各トランザクションログのネットワーク同期にかかる平均時間です。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |         **指標名**         | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">単位</UI-TERM>** |
|-----------|--------------------------|--------|
| sync_time | trans_commit_log_sync_rt | μs     |

### 計算式

sum(rate(ob_sysstat{stat_id="30000",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_sysstat{stat_id="30001",@LABELS}[@INTERVAL])) by (@GBLABELS)

### クエリSQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30000, 30001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30000, 30001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
