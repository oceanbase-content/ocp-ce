# トランザクションログ数

このセクションでは、OceanBaseテナントの監視メトリックである**トランザクションログ数**について説明します。トランザクションのACID完全性を保証するためには、トランザクションログによる追跡が不可欠です。各操作は、データベースに実際に書き込まれる前に、まずログファイルに書き込まれます。トランザクションがコミットされると、そのトランザクション内のSQL文が一括してディスク上のデータベースファイルに同期されます。ログファイルのログがディスクに同期されると、使用済み容量は自動的に解放されます。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの**トランザクションログ数**を照会できます。

## トランザクションログ数

### メトリック紹介

統計範囲内で、テナントが1秒間にコミットするトランザクションログ数。

### メトリックパラメータ説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |        **メトリック名**        | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|------------------------|--------|
| log_count      | trans_commit_log_count | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="30002",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 以下バージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降バージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
