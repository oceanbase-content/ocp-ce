# XAステートメントの実行時間

このセクションでは、OceanBaseテナントのパフォーマンス指標である **XAステートメントの実行時間** について説明します。**XAステートメントの実行時間** 指標は、OceanBaseテナントのXAステートメントの実行時間を統計するために使用されます。この指標は、xa_start_total_rt、xa_end_total_rt、xa_prepare_total_rt、xa_commit_total_rt、xa_rollback_total_rt の5つのサブ指標に細分化され、テナントのXAステートメントの実行時間を統計します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **XAステートメントの実行時間** を照会できます。

## xa_start_total_rt

### 指標の紹介

OceanBaseテナントのxa_start ステートメントの実行時間。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |  **指標名**  | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">単位</UI-TERM>** |
|-----------|----------|--------|
| xa_start_total_rt | xa_start_total_rt | μs  |

### 計算式

sum(rate(ob_sysstat{stat_id="30201",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_sysstat{stat_id="30200",@LABELS}[@INTERVAL])) by (@GBLABELS)

### クエリSQL

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30200, 30201) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30200, 30201) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
