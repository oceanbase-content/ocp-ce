# トランザクションテーブル読み取りリクエストヒット数

このセクションでは、OceanBaseテナントのパフォーマンス指標である**トランザクションテーブル読み取りリクエストヒット数**について説明します。**トランザクションテーブル読み取りリクエストヒット数**指標は、OceanBaseテナントのトランザクションテーブルに対する1秒間の読み取りリクエストのヒット数を統計するために使用されます。この指標は、Mini_Cache_Hit_Count（トランザクションテーブル読み取りリクエストがミニキャッシュにヒットした数）、KV_Cache_Hit_Count（トランザクションテーブル読み取りリクエストがKVキャッシュにヒットした数）、TX_CTX_Hit_Count（トランザクションテーブル読み取りリクエストがトランザクションコンテキストテーブルにヒットした数）、TX_Data_Memtable_Hit_Count（トランザクションテーブル読み取りリクエストがMemTableにヒットした数）の5つのサブ指標に細分化され、テナントのトランザクションテーブル読み取りリクエストのヒット数を統計します。
）およびTX_Data_SStable_Hit_Count（トランザクションテーブルの読み取りリクエストがヒットしたsstableの数）です。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの**トランザクションテーブルの読み取りリクエストヒット数**を照会できます。

## Mini_Cache_Hit_Count

### 指標の紹介

トランザクションテーブルの読み取りリクエストがミニキャッシュにヒットした数。

### メトリクスパラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |  **指標名**  | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|-----------|----------|--------|
| Mini_Cache_Hit_Count | tx_data_hit_mini_cache_count | times/s  |

### 計算式

sum(rate(ob_sysstat{stat_id="30082",@LABELS}[@INTERVAL])) by (@GBLABELS)

### クエリの収集

OceanBase V4.2.0.0以降のバージョン：

```sql
select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30082) and (con_id > 1000 or con_id = 1) and class < 1000
```
