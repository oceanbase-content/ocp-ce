# トランザクション応答時間の詳細

このセクションでは、OceanBaseテナントの監視メトリクスである**トランザクション応答時間の詳細**について説明します。トランザクション応答時間の詳細とは、テナントが単一のトランザクションを処理するために要する時間を指し、具体的にはサーバーがトランザクションリクエストを受信してからリクエスト結果を返すまでの期間を指します。トランザクションのコミット結果に基づき、OCPはこのメトリクスを以下のように細分化しています：all（トランザクションの平均処理時間）、trans_commit_rt（正常にコミットされたトランザクションの平均処理時間）、trans_rollback_rt（ロールバックトランザクションの平均処理時間）。統計範囲を指定することで、単一のZoneまたはOBServerノード上のテナントの**トランザクション応答時間の詳細**データを照会できます。

## all

### メトリクス紹介

統計範囲内で、テナントが処理するすべてのトランザクションの平均所要時間です。

### メトリクスパラメータ説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **メトリクス名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">単位</UI-TERM>** |
|---------|----------------|--------|
| all     | tps_rt | μs     |

### 計算式

sum(rate(ob_sysstat{stat_id="30006",@LABELS}[@INTERVAL])) by (@GBLABELS) / (sum(rate(ob_sysstat{stat_id="30009",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="30007",@LABELS}[@INTERVAL])) by (@GBLABELS))

### クエリSQL

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30006, 30007, 30009) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30006, 30007, 30009) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
