# RPCデリバリ失敗

このセクションでは、OceanBaseテナントのモニタリング指標である**RPCデリバリ失敗**について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの**RPCデリバリ失敗**を照会できます。

## 指標の概要

サンプリング期間内のRPC転送失敗回数。

## 指標パラメータの説明

|   指標項目  |     指標名      |   単位   |
|---------|-------------------|--------|
| rpc_deliver_fail_count    | delta_rpc_packet_deliver_fail_count |   -   |

## 計算式

sum(delta(ob_sysstat{stat_id="10004",@LABELS}[@INTERVAL])) by (@GBLABELS)

## 取得SQL

* OceanBase V2.2.70以降、V4.0未満のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10004) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10004) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
