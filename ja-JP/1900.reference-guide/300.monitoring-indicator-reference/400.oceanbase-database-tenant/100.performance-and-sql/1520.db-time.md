# DB Time

このセクションでは、OceanBaseテナントの監視指標であるDB Timeについて説明します。DB Timeとは、テナントデータベースの処理時間に関する指標の監視を指します。OCPは、DB Timeをさらに細分化した指標を提供しており、それには以下が含まれます：db_cpu（データベースインスタンスがデータベースコマンドを実行する際に消費するON CPU時間。バックグラウンドタスクは除く）、
non_idle_wait_time（データベースインスタンスがデータベースコマンドを実行する際に消費する非アイドル待機時間。バックグラウンドタスクは除く）、
background_db_cpu（データベースバックグラウンドタスクが消費するON CPU時間）
）、background_non_idle_wait_time（データベースバックグラウンドタスクが消費する非アイドル待機時間）。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**DB Time**データを照会できます。

## db_cpu

### 指標の紹介

統計範囲内で、データベースインスタンスがデータベースコマンドを実行する際に消費するON CPU時間。バックグラウンドタスクは除く。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |     **指標名**      | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|-------------------|--------|
| db_cpu     | db_cpu |   μs    |

### 計算式

sum(rate(ob_sysstat{stat_id="200002",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

OceanBase V4.2.2.0以降、V4.3.0.0未満のバージョン：

```sql
select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (200002) and (con_id > 1000 or con_id = 1) and con_id in (select tenant_id from DBA_OB_TENANTS WHERE tenant_type<>'META')
```
