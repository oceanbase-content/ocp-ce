# リクエスト待機キューのサイズ

このセクションでは、OceanBaseテナントのモニタリング指標である**リクエスト待機キューのサイズ**について説明します。この指標は、
request_queue（OceanBaseテナントのリクエストキューのサイズ）と
large_request_queue（OceanBaseテナントの大規模クエリキューのサイズ）の2つの指標に細分化されます。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**リクエスト待機キューのサイズ**データを照会できます。

## request_queue

### 指標の紹介

統計範囲内のテナントリクエストキューの長さ。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |       **指標名**        | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------------|-----------------------|--------|
| request_queue | ob_tenant_request_queue_size | -      |

### 計算式

sum(ob_tenant_request_queue_total_size{@LABELS}) by (@GBLABELS)

### 取得SQL

```sql
select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ tenant_id, req_queue_total_size as total_size, large_queued as large_size from __all_virtual_dump_tenant_info where (tenant_id > 1000 or tenant_id = 1) and svr_ip = ? and svr_port = ?
```

## large_request_queue

### 指標の紹介

統計範囲内のOceanBaseテナントの大規模クエリキューのサイズ。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |      **指標名**       | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------------|---------------------|--------|
| large_request_queue | ob_tenant_request_queue_large_size | -      |

### 計算式

sum(ob_tenant_request_queue_large_size{@LABELS}) by (@GBLABELS)

### 取得SQL

```sql
select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ tenant_id, req_queue_total_size as total_size, large_queued as large_size from __all_virtual_dump_tenant_info where (tenant_id > 1000 or tenant_id = 1) and svr_ip = ? and svr_port = ?
```
