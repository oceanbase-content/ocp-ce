# フロントエンドワークロード

このセクションでは、OceanBaseテナントのモニタリング指標であるフロントエンドワークロードについて説明します。この指標は、on_cpu（CPUを使用してデータベースコマンドを実行しているアクティブセッション数）、application（APPLICATIONタイプの待機イベントを待っているアクティブセッション数）、configuration（CONFIGURATIONタイプの待機イベントを待っているアクティブセッション数）、administrative（ADMINISTRATIVEタイプの待機イベントを待っているアクティブセッション数）、concurrency（CONCURRENCYタイプの待機イベントを待っているアクティブセッション数）、commit（COMMITタイプの待機イベントを待っているアクティブセッション数）、idle（IDLEタイプの待機イベントを待っているアクティブセッション数）、network（NETWORKタイプの待機イベントを待っているアクティブセッション数）、user_io（USER_IOタイプの待機イベントを待っているアクティブセッション数）、system_io（SYSTEM_IOタイプの待機イベントを待っているアクティブセッション数）、cluster（CLUSTERタイプの待機イベントを待っているアクティブセッション数）、other（OTHERタイプの待機イベントを待っているアクティブセッション数）の12個の指標に細分化されています。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**フロントエンドワークロード**データを照会できます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p><b>待機イベント</b>のタイプの説明については、<a href="https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000000749691">待機イベント</a>を参照してください。</p>
</main>

## on_cpu

### 指標の紹介

統計範囲内で、CPUを占有してデータベースコマンドを実行しているアクティブセッション数。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |     **指標名**      | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------|-------------------|--------|
| on_cpu     | ob_foreground_on_cpu_waitevent_cnt |   -    |

### 計算式

sum(ob_foreground_waitevent_cnt{wait_class="ON_CPU",@LABELS}) by (@GBLABELS)

### 取得SQL

OceanBase V4.2.0.0以降、V4.3.0.0未満のバージョン：

  ```sql
  SELECT /*+ MONITOR_AGENT */ ash.tenant_id tenant_id, if (ash.event_no is null or ash.event_no = 0, 'ON_CPU', wait_class) wait_class, count(*) as cnt FROM oceanbase.__all_virtual_ash ash LEFT JOIN oceanbase.v$event_name name on ash.event_no = name.`event#` WHERE sample_time between now() - INTERVAL 1 SECOND and now() and (wait_class <> 'IDLE' or wait_class is null) and session_type = 0 group by wait_class, tenant_id
  ```
