# ウェイトイベント

このセクションでは、OceanBaseテナントの監視メトリクスである**ウェイトイベント**について説明します。ウェイトイベントとは、1秒間に発生するウェイトイベントの回数を指します。OCPはウェイトイベントのタイプに基づき、以下の11個の詳細メトリクスを提供し、異なるタイプのウェイトイベントが1秒間に発生する回数をそれぞれ集計します。具体的には、all（1秒間のウェイトイベント回数）、application_wait（1秒間のapplicationウェイトイベント回数）、configuration_lock_wait（1秒間のconfigurationイベント回数）、administrative_wait（1秒間のadministrativeウェイトイベント回数）、concurrency_wait（1秒間のconcurrencyウェイトイベント回数）、commit_wait（1秒間のcommitウェイトイベント回数）、network_wait（1秒間のnetworkウェイトイベント回数）、user_io_wait（1秒間のuser_ioウェイトイベント回数）、system_io_wait（1秒間のsystem_ioウェイトイベント回数）、cluster_wait（1秒間のclusterウェイトイベント回数）、other_wait（1秒間のその他のウェイトイベント回数）です。集計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**ウェイトイベント**データを照会できます。

## all

### 指標の紹介

統計範囲内で、テナントが1秒間に発生させる待機イベントの数を示します。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |     **指標名**     | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------|------------------|--------|
| all     | wait_event_count | times/s      |

### 計算式

sum(rate(ob_waitevent_wait_total{@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, sum(total_waits) as total_waits, sum(time_waited_micro) / 1000000 as time_waited from v$system_event where v$system_event.wait_class <> 'IDLE' and (con_id > 1000 or con_id = 1) group by tenant_id
  ```

* OceanBase V4.0 以上のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, sum(total_waits) as total_waits, sum(time_waited_micro) / 1000000 as time_waited from v$system_event where v$system_event.wait_class <> 'IDLE' and (con_id > 1000 or con_id = 1) group by tenant_id
  ```
