# RPCパケットスループット

このセクションでは、OceanBaseテナントのモニタリング指標である **RPCパケットスループット** について説明します。この指標は、**集計期間** 内におけるテナントの受信および送信RPCパケットのデータ量を集計します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの **RPCパケットスループット** データを照会できます。

## in

### 指標の概要

**集計期間** 内に、テナントが受信したRPCパケットの総データ量です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**    | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|---------------|--------|
| in      | rpc_packet_in | Byte   |

### 計算式

sum(rate(ob_sysstat{stat_id="10001",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

## out
