# RPCネットワーク遅延

このセクションでは、OceanBaseテナントのモニタリング指標である **RPCネットワーク遅延** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの **RPCネットワーク遅延** を照会できます。

## 指標の概要

サンプリング期間内のRPCネットワーク遅延です。

## 指標パラメータの説明

|  指標項目   |     指標名      |   単位   |
|---------|-------------------|--------|
| rpc_packet_net_delay    | rpc_packet_net_delay |   μs   |

## 計算式

sum(delta(ob_sysstat{stat_id="10005",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(delta(ob_sysstat{stat_id="10006",@LABELS}[@INTERVAL])) by (@GBLABELS)

## 取得SQL

* OceanBase V2.2.70以降、V4.0未満のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10005, 10006) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (10005, 10006) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
