# オープンカーソル数

このセクションでは、OceanBaseテナントの監視メトリックである **オープンカーソル数** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード内のセッションがキャッシュしているカーソル数を照会できます。

## メトリックの概要

統計範囲内で、セッションがキャッシュしているカーソル数。

## メトリックパラメータの説明

|      メトリック項目       |         メトリック名         | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">単位</UI-TERM>** |
|----------------|----------------------|--------|
| open_cursors | opened_cursors_count | -      |

## 計算式

sum(delta(ob_sysstat{stat_id="40030",@LABELS}[@INTERVAL])) by (@GBLABELS)

## 取得SQL

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (40030) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (40030) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
