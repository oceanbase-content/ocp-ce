# パラレル実行ワーカースレッド利用率

このセクションでは、OceanBaseテナントの監視メトリクスである **パラレル実行ワーカースレッド利用率** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの **パラレル実行ワーカースレッド利用率** データを照会できます。

## メトリクスの概要

統計範囲内でCPUを占有し、データベースコマンドを実行しているアクティブなセッション数です。

## メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |     **メトリクス名**      | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------|-------------------|--------|
| px_worker_usage    | px_worker_usage |   %    |

## 計算式

max(px_target_usage{@LABELS}) by (@GBLABELS)

## 取得SQL

OceanBase V4.0.0.0以降のバージョン：

```sql
select max(t2.tenant_name) as tenant_name, avg(100 * t1.PEER_TARGET_USED / t1.PEER_TARGET) as usage_percentage from GV$OB_PX_TARGET_MONITOR t1 left join DBA_OB_TENANTS t2 on t1.TENANT_ID = t2.TENANT_ID where t2.TENANT_TYPE <> 'META' group by t1.TENANT_ID;
```
