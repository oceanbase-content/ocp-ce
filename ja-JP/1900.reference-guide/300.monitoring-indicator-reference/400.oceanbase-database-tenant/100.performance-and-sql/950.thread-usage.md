# テナントスレッド使用率

このセクションでは、OceanBaseテナントの監視指標である **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.TenantThreadUsage">テナントスレッド使用率</UI-TERM>** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **<UI-TERM key="ocp-v2.Capacity.Resource.Trend.TenantThreadUsage">テナントスレッド使用率</UI-TERM>** データを照会できます。

## 指標の概要

アクティブスレッド数 / テナントの最大スレッド数。

## 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **指標名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------|----------------|--------|
| テナントスレッド使用率       | ob_tenant_thread_percent | %      |

## 計算式

100 * sum(ob_sysstat{stat_id="140006",@LABELS}) by (@GBLABELS) / sum(ob_sysstat{stat_id="140005",@LABELS}) by (@GBLABELS)

## 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (140005, 140006) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以上のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (140005, 140006) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
