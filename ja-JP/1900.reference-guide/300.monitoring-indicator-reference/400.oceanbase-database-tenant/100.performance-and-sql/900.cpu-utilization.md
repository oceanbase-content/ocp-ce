# テナントCPU消費

このセクションでは、OceanBaseテナントのモニタリング指標である **<UI-TERM key="ocp-v2.src.constant.monitor.TenantCpuConsumption">テナントのCPU消費量</UI-TERM>** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるテナントの **<UI-TERM key="ocp-v2.src.constant.monitor.TenantCpuConsumption">テナントのCPU消費量</UI-TERM>** データを照会できます。

## 指標の概要

テナントCPU使用量 × 100 / テナントCPU割り当て量。

## 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **指標名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|---------|----------------|--------|
| テナントCPU消費       | ob_tenant_cpu_percent | %      |

## 計算式

sum(rate(ob_sysstat{stat_id="140013",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(ob_sysstat{stat_id="140005",@LABELS}) by (@GBLABELS) / 100

## 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (140005, 140013) and (con_id > 1000 or con_id = 1)
  ```

* OceanBase V4.0 以上バージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (140005, 140013) and (con_id > 1000 or con_id = 1)
  ```
