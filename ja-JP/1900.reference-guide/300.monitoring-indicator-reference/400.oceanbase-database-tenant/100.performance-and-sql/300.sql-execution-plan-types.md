# SQL実行計画の種類

このセクションでは、OceanBaseテナントの監視指標である **SQL実行計画の種類** について説明します。この指標は、SQL実行計画の種類ごとに、現在の統計範囲内で1秒間に実行される計画数を監視します。統計範囲を指定することで、単一のゾーンまたはOBServerノード上のテナントの **SQL実行計画の種類** データを照会できます。

## sql_local_count

### 指標の概要

統計範囲内で、毎秒ローカル実行計画を処理する回数。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **指標名**     | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|-----------------|--------|
| sql_local_count   | sql_local_count | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="40010",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (40010) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (40010) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
