# SQL実行段階

このセクションでは、OceanBaseテナントのモニタリング指標であるSQL実行段階について説明します。この指標は13個の指標に細分化されており、それぞれin_parse（SQL PARSEを実行中のアクティブセッション数）、in_pl_parse（PL PARSEを実行中のアクティブセッション数）、in_plan_cache（plan cacheにアクセス中のアクティブセッション数）、in_sql_optimize（SQL最適化を実行中のアクティブセッション数）、in_sql_execution（SQL文を実行中のアクティブセッション数）、in_px_execution（PX SQL並列実行中のアクティブセッション数）、in_sequence_load（自動インクリメント列またはSEQUENCEから値を取得中のアクティブセッション数）、in_committing（トランザクションコミット段階にあるアクティブセッション数）、in_storage_read（ストレージ層読み取りを実行中のアクティブセッション数）、in_storage_write（ストレージ層書き込みを実行中のアクティブセッション数）、in_remote_das_execution（リモートDASで実行中のアクティブセッション数）、in_plsql_compilation（PLコンパイル中のアクティブセッション数）、in_plsql_execution（plsql execution状態の実行イベント数）です。統計範囲を指定することで、単一ゾーンまたはOBServerノードのテナントの**SQL実行段階**データを照会できます。
