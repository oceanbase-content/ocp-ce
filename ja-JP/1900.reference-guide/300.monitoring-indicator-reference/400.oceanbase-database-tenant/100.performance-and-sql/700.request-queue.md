# リクエスト待機キュー

このセクションでは、OceanBaseテナントのモニタリング指標である**リクエスト待機キュー**について説明します。この指標は、
request_enqueue_count（処理キューに入るリクエスト数）と
dequeue_count（処理キューから出るリクエスト数）の2つの指標に細分化されます。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**リクエスト待機キュー**データを照会できます。

## request_enqueue_count

### 指標の紹介

統計範囲内で、1秒間に待機キューに入るSQL数の平均値です。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |       **指標名**        | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">単位</UI-TERM>** |
|---------------|-----------------------|--------|
| request_enqueue_count | request_enqueue_count | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="20000",@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (20000) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (20000) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

## request_dequeue_count

### 指標の紹介

統計範囲内で、1秒間に待機キューから出るSQL数の平均値です。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**    |      **指標名**       | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|---------------|---------------------|--------|
| request_dequeue_count | request_queue_count | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="20001",@LABELS}[@INTERVAL])) by (@GBLABELS)

### クエリの収集

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (20001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (20001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
