# イベント待機時間

このセクションでは、OceanBaseテナントの監視メトリクスである**イベント待機時間**について説明します。このメトリクスは、さまざまなタイプのイベント待機時間を集計したもので、以下が含まれます：all（イベント平均待機時間）、application_wait（applicationイベント平均待機時間）、configuration_wait（configurationイベント平均待機時間）、administrative_wait（administrativeイベント平均待機時間）、concurrency_wait（concurrencyイベント平均待機時間）、commit_wait（commitイベント平均待機時間）、network_wait（networkイベント平均待機時間）、user_io_wait（user_ioイベント平均待機時間）、system_io_wait（system_ioイベント平均待機時間）、cluster_wait（clusterイベント平均待機時間）、other_wait（その他のイベント平均待機時間）。集計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの**イベント待機時間**データを照会できます。

## all

### 指標の紹介

統計範囲内のテナントの待機イベントの平均待機時間です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|---------|---------------|--------|
| all     | wait_event_rt | μs    |

### 計算式

sum(rate(ob_waitevent_wait_seconds_total{@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_waitevent_wait_total{@LABELS}[@INTERVAL])) by (@GBLABELS)

### 取得SQL

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, sum(total_waits) as total_waits, sum(time_waited_micro) / 1000000 as time_waited from v$system_event where v$system_event.wait_class <> 'IDLE' and (con_id > 1000 or con_id = 1) group by tenant_id
  ```

* OceanBase V4.0 以上のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, sum(total_waits) as total_waits, sum(time_waited_micro) / 1000000 as time_waited from v$system_event where v$system_event.wait_class <> 'IDLE' and (con_id > 1000 or con_id = 1) group by tenant_id
  ```
