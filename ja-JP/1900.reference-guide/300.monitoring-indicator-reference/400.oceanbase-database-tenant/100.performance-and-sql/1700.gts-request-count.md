# GTSリクエスト数

このセクションでは、OceanBaseテナントの監視指標である **GTSリクエスト数** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のテナントの **GTSリクエスト数** を照会できます。

## 指標の概要

統計範囲内のGTSリクエスト数。

## 指標パラメータの説明

| 指標項目  |     指標名     |   単位    |
|---------|-------------------|--------|
| gts_request_count    | gts_request_count |   -    |

## 計算式

sum(rate(ob_sysstat{stat_id="30053",@LABELS}[@INTERVAL])) by (@GBLABELS)

## 取得SQL

* OceanBase V2.2.70以降、V4.0未満のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30053) and (con_id > 1000 or con_id = 1)      
  ```

* OceanBase V4.0以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30053) and (con_id > 1000 or con_id = 1) and con_id in (select tenant_id from DBA_OB_TENANTS WHERE tenant_type<>'META')
  ```
