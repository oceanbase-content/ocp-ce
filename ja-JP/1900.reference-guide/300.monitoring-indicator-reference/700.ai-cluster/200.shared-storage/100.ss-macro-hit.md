# SSマクロブロックヒット率

このセクションでは、OB SSモードにおけるマクロブロックキャッシュのヒット率に関する指標について説明します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>以下の監視グループは <b>OceanBase共有ストレージ(SS)モード</b> に適用され、OBクラスタのバージョンは <b>≥ 4.6.2.0</b> である必要があります。収集条件は <code>ob_mode_is_shared_storage</code> です(SSモードでのみ収集)。</p>
</main>

## ob_ss_macro_cache_hit_ratio

### 指標の概要

OB SSモードにおけるマクロブロックキャッシュ全体のヒット率。

### 指標パラメータの説明

| 指標項目 | 指標名 | 単位 |
|-------|---------|------|
| ob_ss_macro_cache_hit_ratio | ob_ss_macro_cache_hit_ratio | % |

### 計算式

```
100 * avg(rate(ob_ss_macro_cache_hit_cnt{@LABELS}[@INTERVAL])) by (@GBLABELS) / (avg(rate(ob_ss_macro_cache_hit_cnt{@LABELS}[@INTERVAL])) by (@GBLABELS) + avg(rate(ob_ss_macro_cache_miss_cnt{@LABELS}[@INTERVAL])) by (@GBLABELS))
```

### SQL収集

基盤指標 `ob_ss_macro_cache_hit_cnt`、`ob_ss_macro_cache_miss_cnt` は、OB SSモードのマクロブロックキャッシュ統計項目からエクスポートされます：

```sql
select tenant_id,TOTAL_HIT_CNT as hit_cnt,TOTAL_MISS_CNT as miss_cnt from GV$OB_LOCAL_CACHE where cache_name = "ss_macro_cache" and svr_ip = ? and svr_port = ?
```

適用バージョン：OceanBase V4.6.2.0 以降 (SSモード)

