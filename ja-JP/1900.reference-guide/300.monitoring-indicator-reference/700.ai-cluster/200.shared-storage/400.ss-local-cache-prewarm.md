# ローカルキャッシュのプリウォーム

このセクションでは、OB SSモードにおけるローカルキャッシュのプリウォームマクロブロック数に関するメトリクスについて説明します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>以下の監視グループは <b>OceanBase Shared Storage (SS)モード</b> に適用され、OBクラスタのバージョンは <b>≥ 4.6.2.0</b> である必要があります。収集条件は <code>ob_mode_is_shared_storage</code> (SSモードでのみ収集) です。</p>
</main>

## ob_ss_local_cache_major_compaction_prewarm_count

### メトリクスの紹介

OB SSモードにおけるメジャーコンパクションのプリウォームマクロブロック数。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| ob_ss_local_cache_major_compaction_prewarm_count | ob_ss_local_cache_major_compaction_prewarm_count | - |

### SQL収集

```sql
select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value
from v$sysstat
where stat_id IN (240205) and (con_id > 1000 or con_id = 1)
```
