# 共有データ

このセクションでは、OB SSモードにおける共有データと共有clogの使用容量に関するメトリクスについて説明します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>以下の監視グループは <b>OceanBase共有ストレージ(SS)モード</b> に適用され、OBクラスタのバージョンは <b>≥ 4.6.2.0</b> である必要があります。収集条件は <code>ob_mode_is_shared_storage</code> です(SSモードでのみ収集)。</p>
</main>

## ob_shared_data_size

### メトリクスの紹介

共有データの合計サイズ。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| ob_shared_data_size | ob_shared_data_size | byte |

### 計算式

```
max(ob_tenant_space_usage{space_type="Shared Data", @LABELS}) by (@GBLABELS)
```

### SQL収集

OceanBase V4.3.5.1以降のバージョン(SSモード、RootServiceノードでのみ収集)：

```sql
select TENANT_ID, TENANT_NAME, SPACE_TYPE, USAGE_BYTES from CDB_OB_SPACE_USAGE
```

ここで `SPACE_TYPE = 'Shared Data'` は共有データの合計サイズに対応します。

---

## ob_shared_clog_size

### メトリクスの紹介

OB共有clogの合計サイズ。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| ob_shared_clog_size | ob_shared_clog_size | byte |

### SQL収集

```sql
select TENANT_ID, TENANT_NAME, SPACE_TYPE, USAGE_BYTES from CDB_OB_SPACE_USAGE
```

ここで、`SPACE_TYPE = 'Clog Data'` は共有clogの合計に対応します。
