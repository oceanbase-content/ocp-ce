# SSマクロブロックキャッシュサイズ

このセクションでは、OB SSモードにおけるマクロブロックキャッシュの使用容量に関するメトリクスについて説明します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>以下の監視グループは <b>OceanBase共有ストレージ(SS)モード</b> に適用され、OBクラスタのバージョンは <b>≥ 4.6.2.0</b> である必要があります。収集条件は <code>ob_mode_is_shared_storage</code> です(SSモードでのみ収集)。</p>
</main>

## ob_ss_macro_cache_alloc_disk_size

### メトリクス紹介

OB SSモードでマクロブロックキャッシュに割り当てられたディスク容量。

### メトリクスパラメータ説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| ob_ss_macro_cache_alloc_disk_size | ob_ss_macro_cache_alloc_disk_size | byte |

### SQL収集

```sql
select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value
from v$sysstat
where stat_id IN (245058) and (con_id > 1000 or con_id = 1)
```
