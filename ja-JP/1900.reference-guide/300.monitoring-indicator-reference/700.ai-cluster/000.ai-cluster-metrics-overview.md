# AIクラスタ監視メトリクスの概要

このドキュメントでは、OCP 4.5.0で追加されたAIクラスタ関連の監視メトリクスについて説明します。これには、Logserviceの監視メトリクスとOceanBase共有ストレージ（SS）モードの監視メトリクスが含まれます。

## 監視メトリクスの分類

AIクラスタの監視メトリクスは、以下の2つのカテゴリに分類されます：

### Logserviceの監視メトリクス

Logserviceの監視は、独立してデプロイされた**oblogservice**プロセスを対象とし、監視の次元は`LOG_SERVICE`です。

Logserviceの監視メトリクスには、以下のカテゴリが含まれます：

* [ログ受信と書き込み](100.logservice/100.log-receiving-and-writing.md)
* [ログ遅延](100.logservice/200.log-latency.md)
* [ログ読み取り](100.logservice/300.log-reading.md)
* [FetchLog操作](100.logservice/400.fetchlog.md)
* [RPCリクエスト](100.logservice/500.rpc.md)
* [HTTPリクエスト](100.logservice/600.http.md)
* [GC回収](100.logservice/700.gc.md)
* [オブジェクトストレージアップロード](100.logservice/800.object-storage-upload.md)
* [スレッドプール](100.logservice/900.thread-pool.md)
* [プロセスリソース](100.logservice/1000.process-resources.md)
* [遅延と状態](100.logservice/1100.delay-and-status.md)

### OceanBase共有ストレージ（SS）モードの監視メトリクス

以下の監視グループは、**OceanBase共有ストレージ（SS）モード**に適用され、OBクラスタのバージョンは**≥ 4.6.2.0**が必要です。

共有ストレージの監視メトリクスには、以下のカテゴリが含まれます：

* [SSマクロブロックヒット率](200.shared-storage/100.ss-macro-hit.md)
* [SSマクロブロックキャッシュサイズ](200.shared-storage/200.ss-macro-cache-size.md)
* [共有データ](200.shared-storage/300.shared-data.md)
* [ローカルキャッシュのウォームアップ](200.shared-storage/400.ss-local-cache-prewarm.md)
