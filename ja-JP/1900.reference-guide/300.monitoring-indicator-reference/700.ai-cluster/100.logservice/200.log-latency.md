# ログ遅延

このセクションでは、LogServiceのログ遅延に関連する監視メトリクスについて説明します。

## logservice_receiveP95_duration_ms

### メトリクスの紹介

単一の`receive_log`エンドツーエンド処理時間の分位数（P95）で、ログ書き込みの遅延を反映します。

### メトリクスパラメータの説明

| メトリック項目 | メトリック名 | 単位 |
|-------|---------|------|
| log_receive_duration_seconds_bucket | logservice_receiveP95_duration_ms | ms |

### 計算式

```
1000 * histogram_quantile(0.95, sum(rate(log_receive_duration_seconds_bucket{@LABELS}[@INTERVAL])) by (@GBLABELS,le))
```

### Prometheus収集

`prometheusInput`を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics`から`log_receive_duration_seconds_bucket`ヒストグラムメトリクスを収集します。
