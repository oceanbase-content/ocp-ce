# FetchLog操作

このセクションでは、Logservice FetchLog操作に関連する監視メトリクスについて説明します。

## logservice_fetch_entries_total

### メトリクスの紹介

FetchLogで取得したログのエントリ数（1秒あたりのレート）。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| log_fetch_entries_total | logservice_fetch_entries_total | times/s |

### 計算式

```
sum(rate(log_fetch_entries_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` から `log_fetch_entries_total` メトリクスを収集します。

## logservice_fetch_P95_duration_ms

### メトリクスの紹介

FetchLog の取得時間分位数（P95）。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| log_fetch_duration_seconds_bucket | logservice_fetch_P95_duration_ms | ms |

### 計算式

```
1000 * histogram_quantile(0.95, sum(rate(log_fetch_duration_seconds_bucket{@LABELS}[@INTERVAL])) by (@GBLABELS,le))
```

### Prometheusによる収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` から `log_fetch_duration_seconds_bucket` ヒストグラムメトリクスを収集します。
