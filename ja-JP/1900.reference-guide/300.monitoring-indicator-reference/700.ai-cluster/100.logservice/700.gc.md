# GC回収

このセクションでは、Logservice GC（ガベージコレクション）に関連する監視メトリクスについて説明します。

## logservice_storage_gc_reclaimed_blocks_total

### メトリクスの紹介

GCが1秒間に回収するブロック数で、GCの進捗状況を示します。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| storage_gc_reclaimed_blocks_total | logservice_storage_gc_reclaimed_blocks_total | times/s |

### 計算式

```
sum(rate(storage_gc_reclaimed_blocks_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` から `storage_gc_reclaimed_blocks_total` メトリクスを収集します。
