# ログの受信と書き込み

このセクションでは、LogServiceのログ受信および書き込みに関連する監視メトリクスについて説明します。

## logservice_receive_bytes_total

### 指標の紹介

LogServiceが累計で受信したログバイト数（1秒あたりのレート）。

### メトリクスパラメータの説明

| 指標項目 | 指標名 | 単位 |
|-------|---------|------|
| log_receive_bytes_total | logservice_receive_bytes_total | byte/s |

### 計算式

```
sum(rate(log_receive_bytes_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` から `log_receive_bytes_total` メトリクスを収集します。
