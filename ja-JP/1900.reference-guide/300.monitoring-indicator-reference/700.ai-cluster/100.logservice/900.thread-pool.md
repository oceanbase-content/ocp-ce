# スレッドプール

このセクションでは、Logserviceスレッドプールに関連する監視メトリクスについて説明します。

## logservice_nonblocking_thread_pool_worker_count

### メトリクスの紹介

nonblockingスレッドプールのワーカースレッド数であり、スレッドプールの混雑度を反映します。`module` の次元で区別されます。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| thread_pool_worker_count{pool_type="nonblocking"} | logservice_nonblocking_thread_pool_worker_count | - |

### 計算式

```
sum(rate(thread_pool_worker_count{pool_type="nonblocking",@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` から `thread_pool_worker_count` メトリクスを収集します。

## logservice_nonblocking_thread_pool_queue_depth

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| thread_pool_queue_depth{pool_type="nonblocking"} | logservice_nonblocking_thread_pool_queue_depth | - |

### 計算式

```
avg(thread_pool_queue_depth{pool_type="nonblocking",@LABELS}) by (@GBLABELS)
```

### Prometheus収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` から `thread_pool_queue_depth` メトリクスを収集します。

## logservice_nonblocking_thread_pool_active_task_count

### メトリクスの紹介

非ブロッキングスレッドプールで実行中だが終了していないタスク数。スレッドプールのワークロードを反映し、`module` ごとに区別されます。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| thread_pool_active_task_count{pool_type="nonblocking"} | logservice_nonblocking_thread_pool_active_task_count | - |

### 計算式

```
sum(rate(thread_pool_active_task_count{pool_type="nonblocking",@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheusによる収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics` から `thread_pool_active_task_count` メトリクスを収集します。
