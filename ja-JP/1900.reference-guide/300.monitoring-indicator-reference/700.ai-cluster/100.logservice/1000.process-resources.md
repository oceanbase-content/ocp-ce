# プロセスリソース

このセクションでは、Logserviceプロセスのリソースに関する監視メトリクスについて説明します。

## logservice_process_cpu_percent

### メトリクスの紹介

ログサービス（oblogservice）プロセスのCPU使用率。

### メトリクスパラメータの説明

| メトリック項目 | メトリック名 | 単位 |
|-------|---------|------|
| process_cpu_percent{name="oblogservice"} | logservice_process_cpu_percent | % |

### 計算式

```
sum(process_cpu_percent{name="oblogservice",@LABELS}) by (@GBLABELS)
```

### Prometheus収集

OCP monagentは、`processInput` プラグインを使用して `process_cpu_percent{name="oblogservice"}` メトリクスを収集します。

## logservice_rss_memory

### メトリクスの紹介

ログサービス（oblogservice）プロセスの常駐メモリ（RSS）使用量。

### メトリクスパラメータの説明

| メトリック項目 | メトリック名 | 単位 |
|-------|---------|------|
| process_memory_rss_bytes{name="oblogservice"} | logservice_rss_memory | byte |

### 計算式

```
sum(process_memory_rss_bytes{name="oblogservice",@LABELS}) by (@GBLABELS)
```

### Prometheus収集

OCP MonAgentは、`processInput` プラグインを使用して `process_memory_rss_bytes{name="oblogservice"}` 指標を収集します。
