# 遅延とステータス

このセクションでは、LogServiceの遅延とステータスに関連する監視メトリクスについて説明します。

## logservice_replica_committed_end_scn_delay

### メトリクスの紹介

ログサービスにおけるコミット済みログのend SCNの遅延です。`logservice_replica_committed_end_scn_delay` アラート（しきい値 ≥ 5000ms / ≥ 10000ms）に使用されます。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| replica_committed_end_scn_delay | logservice_replica_committed_end_scn_delay | ms |

### 計算式

```
avg.replica_committed_end_scn_delay{@LABELS}) by (@GBLABELS) / 1000
```

### Prometheus収集

`prometheusInput` を使用して、`http://127.0.0.1:${monagent.logservice.exporter.port}/metrics`` から `replica_committed_end_scn_delay` メトリクスを収集します（元の単位はマイクロ秒で、式では1000で割ってミリ秒に変換します）。

## logservice_boot_time_delta_seconds

### メトリクスの紹介

oblogserviceプロセスの起動時間差で、プロセスの再起動を検出するために使用されます。`logservice_process_stop` アラート（しきい値 > 10s）に使用されます。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| process_boot_time_seconds{name="oblogservice"} | logservice_boot_time_delta_seconds | s |

### 計算式

```
max(delta(process_boot_time_seconds{name="oblogservice",@LABELS}[@INTERVAL])) by (@GBLABELS)
```

### Prometheus収集

OCP monagentは、`processInput`プラグインを通じて`process_boot_time_seconds{name="oblogservice"}`メトリクスを収集します。

---

## logservice_process_exists

### メトリクスの紹介

oblogserviceプロセスの生存状態（1=生存中、0=存在しない）。`logservice_process_dead`アラートに使用されます（式：`logservice_process_exists == 0`）。

### メトリクスパラメータの説明

| メトリクス項目 | メトリクス名 | 単位 |
|-------|---------|------|
| process_exists{name="oblogservice"} | logservice_process_exists | - |

### 計算式

```
process_exists{name="oblogservice",@LABELS}
```

### Prometheus収集

OCP monagentは、`processInput`プラグインを通じて`process_exists{name="oblogservice"}`メトリクスを収集します。
