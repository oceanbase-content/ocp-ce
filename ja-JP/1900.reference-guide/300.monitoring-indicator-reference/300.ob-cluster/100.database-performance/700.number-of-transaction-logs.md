# トランザクションログ数

このセクションでは、OceanBaseクラスタのパフォーマンス指標である **トランザクションログ数** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のOceanBaseクラスタの **トランザクションログ数** を照会できます。

## トランザクションログ数

### 指標の概要

1秒間にコミットされるトランザクションログ数です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **指標名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------|------------------|--------|
| log_count       | trans_commit_log_count | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="30002",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30002) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
