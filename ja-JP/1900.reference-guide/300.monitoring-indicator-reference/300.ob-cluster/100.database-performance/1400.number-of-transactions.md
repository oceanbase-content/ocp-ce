# トランザクション数

このセクションでは、OceanBaseクラスタのパフォーマンス指標である**トランザクション数**について説明します。**トランザクション数**は、OceanBaseクラスタが1秒間に処理するトランザクションの回数を統計する指標です。この指標は、trans_single_partition_count（1秒間の通常トランザクション数）とtrans_multi_partition_count（1秒間の分散トランザクション数）という2つのサブ指標に細分化されています。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のOceanBaseクラスタの**トランザクション数**を照会できます。

## trans_single_partition_count

### 指標の紹介

OceanBaseクラスタが1秒間に処理する通常トランザクションの回数。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |     **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|-----------|----------|--------|
| trans_single_partition_count | transaction_single_partition_count | times/s  |

### 計算式

sum(rate(ob_sysstat{stat_id="30012",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30012) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30012) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
