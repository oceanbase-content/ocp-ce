# 物理I/O回数

このセクションでは、OceanBaseクラスタのパフォーマンス指標である**物理I/O回数**について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のOceanBaseクラスタの物理I/O回数を照会できます。

## ssstore_read

### 指標の紹介

統計範囲内で、クラスタが1秒間にSSStoreを読み取る回数です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| ssstore_read    | io_read_count | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="60000",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0 より前のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (60000) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (60000) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
