# トランザクション応答時間

このセクションでは、OceanBaseクラスタのパフォーマンス指標である **トランザクション応答時間** について説明します。この指標は3つに細分化されており、クラスタのトランザクション処理平均時間、トランザクションコミット平均時間、トランザクションロールバック平均時間をそれぞれ集計します。集計範囲を指定することで、単一ゾーンまたはOBServerノード上のOceanBaseクラスタの **トランザクション応答時間** データを照会できます。

## all

### 指標の概要

OceanBaseクラスタがトランザクションを処理する平均時間です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **指標名**    | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|----------------|--------|
| all     | tps_rt | μs     |

### 計算式

sum(rate(ob_sysstat{stat_id="30006",@LABELS}[@INTERVAL])) by (@GBLABELS) / (sum(rate(ob_sysstat{stat_id="30009",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="30007",@LABELS}[@INTERVAL])) by (@GBLABELS))

### SQL収集

* OceanBase V4.0未満のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30006, 30007, 30009) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30006, 30007, 30009) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
