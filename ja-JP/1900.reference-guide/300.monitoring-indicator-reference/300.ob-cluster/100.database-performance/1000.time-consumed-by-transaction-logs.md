# トランザクションログの処理時間

このセクションでは、OceanBaseクラスタのパフォーマンス指標である **トランザクションログの処理時間** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるOceanBaseクラスタの **トランザクションログの処理時間** を照会できます。

## write_disk

### 指標の概要

トランザクションログのディスク書き込み1回あたりの平均処理時間です。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**   |      **指標名**      | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|------------|--------------------|--------|
| write_disk | clog_write_disk_rt | μs     |

### 計算式

sum(rate(ob_sysstat{stat_id="80041",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_sysstat{stat_id="80040",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0 以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (80040, 80041) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0 以上、V4.1.0.3 以下のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (80040, 80041) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

## clog_write

### 指標の概要

clogの書き込み1回あたりの平均処理時間です。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**   |      **指標名**      | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|------------|--------------------|--------|
| clog_write | clog_io_write_rt | μs     |

### 計算式

sum(rate(ob_sysstat{stat_id="80003",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_sysstat{stat_id="80001",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

OceanBase V4.1.0.3以降のバージョン：

```sql
select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (80001, 80003) and (con_id > 1000 or con_id = 1) and class < 1000
```

## sync_time

### 指標の紹介

トランザクションログのネットワーク同期にかかる平均時間です。

### 指標パラメータの説明

|  **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**  |         **指標名**         | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|-----------|--------------------------|--------|
| sync_time | trans_commit_log_sync_rt | μs     |

### 計算式

sum(rate(ob_sysstat{stat_id="30000",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_sysstat{stat_id="30001",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0以下のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30000, 30001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0以上のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30000, 30001) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
