# TPS

このセクションでは、OceanBaseクラスタのパフォーマンス指標であるTPS（Transactions Per Second）について説明します。この指標は、クラスタのトランザクションを統計するために4つのサブ指標に細分化されており、それぞれ以下の通りです：all（1秒あたりのトランザクション処理数）、trans_commit_count（1秒あたりのトランザクションコミット数）、trans_rollback_count（1秒あたりのトランザクションロールバック数）、trans_timeout_count（1秒あたりのタイムアウトトランザクション数）。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のOceanBaseクラスタの**TPS**データを照会できます。

## all

### 指標紹介

OceanBaseクラスタが1秒間に処理するトランザクション数。

### 指標パラメータ説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |     **指標名**      | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|-------------------|--------|
| all     | tps | times/s      |

### 計算式

sum(rate(ob_sysstat{stat_id="30005",@LABELS}[@INTERVAL])) by (@GBLABELS)

### SQL収集

* OceanBase V4.0未満のバージョン：

  ```sql
  select /*+ MONITOR_AGENT READ_CONSISTENCY(WEAK) */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30005) and (con_id > 1000 or con_id = 1) and class < 1000
  ```

* OceanBase V4.0以降のバージョン：

  ```sql
  select /* MONITOR_AGENT */ con_id tenant_id, stat_id, value from v$sysstat where stat_id IN (30005) and (con_id > 1000 or con_id = 1) and class < 1000
  ```
