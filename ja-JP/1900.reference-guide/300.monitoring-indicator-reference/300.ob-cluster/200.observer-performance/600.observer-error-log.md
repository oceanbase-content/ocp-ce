# エラーログ

このセクションでは、OceanBaseクラスタのパフォーマンス指標である **エラーログ** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード内のOceanBaseクラスタの **エラーログ** を照会できます。

## observer

### 指標の概要

統計範囲内のクラスタOBServerノードのERRORログ数。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">単位</UI-TERM>** |
|---------|--------------|--------|
| observer   | observer_log_error_count | -     |

### 計算式

sum(rate(ob_log_level_count{level="ERROR",logSourceType="observer",@LABELS}[@INTERVAL])) by (@GBLABELS)
