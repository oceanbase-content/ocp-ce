# プロセスファイルハンドル

このセクションでは、OceanBaseクラスタのパフォーマンスメトリクスである **プロセスファイルハンドル** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるOceanBaseクラスタの **プロセスファイルハンドル** の監視情報を照会できます。

## observer_fd

### メトリクスの概要

統計範囲内のクラスタOBServerノードのファイルハンドル数。

### メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **メトリクス名**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------|--------------|--------|
| observer_fd   | observer_fd_count | -     |

### 計算式

avg(process_fd_count{name="observer",@LABELS}) by (@GBLABELS)

## observer_fd_usage

### メトリクスの概要

統計範囲内のクラスタOBServerノードのファイルハンドル使用率。

### メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **メトリクス名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">単位</UI-TERM>** |
|---------|---------------|--------|
| observer_fd_usage   | observer_fd_usage | %     |

### 計算式

round(100 * avg(process_fd_count{name="observer",@LABELS}) by (@GBLABELS) / avg(observer_ulimit_max_fd_count{@LABELS}) by (@GBLABELS))
