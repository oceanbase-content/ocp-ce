# プロセススレッド数

このセクションでは、OceanBaseクラスタのパフォーマンス指標である **プロセススレッド数** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノード上のOceanBaseクラスタの **プロセススレッド数** を照会できます。

## 指標の概要

統計範囲内のクラスタOBServerノードのプロセススレッド数です。
