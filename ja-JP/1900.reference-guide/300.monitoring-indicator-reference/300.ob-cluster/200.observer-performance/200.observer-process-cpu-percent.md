# プロセスCPU利用率

このセクションでは、OceanBaseクラスタのパフォーマンス指標である **プロセスCPU利用率** について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるOceanBaseクラスタの **プロセスCPU利用率** を照会できます。

## 指標の概要

統計範囲内のクラスタOBServerノードにおけるプロセスCPUの利用率を示します。

## 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**   | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|--------------|--------|
| observer_cpu_usage   | observer_process_cpu_percent | %     |
