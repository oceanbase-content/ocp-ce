# プロセスメモリ

このセクションでは、OceanBaseクラスタのパフォーマンス指標である**プロセスメモリ**について説明します。統計範囲を指定することで、単一ゾーンまたはOBServerノードにおけるOceanBaseクラスタの**プロセスメモリ**を照会できます。

## 指標の概要

統計範囲内のクラスタOBServerノード上のプロセスが使用するメモリサイズです。
