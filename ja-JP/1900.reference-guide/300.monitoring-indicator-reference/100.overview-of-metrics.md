# モニタリング指標の概要

OCPは、OceanBaseクラスタ、テナント、OBProxyクラスタ、およびホストに対するパフォーマンス監視とリソース監視を含むモニタリングサービスを提供します。モニタリングデータを確認することで、対象オブジェクトの状態、パフォーマンス、およびリソース使用量を把握し、後続のビジネスを継続するためにリソース使用を適時に調整できます。また、現在のビジネスで発生している障害の分析と解決にも役立ちます。

## 概要

本章では、監視指標について以下の4つの側面から説明します。細分化された指標がある場合も、同様に以下の4つの側面から順に説明します。

|次元| 説明  |
|--------|--------|
| 指標紹介   | 当該指標の統計内容について簡潔に説明します。 |
| 指標パラメータ説明 | このセクションには以下の3項目が含まれます。 <li> 指標項目：OCPインターフェース上で表示される細分化指標の名前です。細分化指標がない場合は「-」となります。   </li><li> 指標名：バックエンドにクエリリクエストを送信する際に使用され、実際に監視データを格納します。   </li><li> 単位：指標から返されるデータの単位。 </li>   |
| 計算式  | 当該指標のデータソースを示します。  |
|SQL 采集|監視指標の収集SQLソース。OceanBaseのバージョンによってSQL収集は異なります。実際の状況に応じて確認してください。<main id="notice" type='explain'><h4>説明</h4><p><li>一部の監視指標はSQL収集に関与していません。そのような指標の説明にはSQL収集に関する内容は含まれません。</li><li>SQL収集ステートメントにホストIPアドレスとポート情報が含まれている場合、例えば <code>where svr_ip = ? and svr_port = ?</code> のように、このステートメントを実行する際には、<code>?</code> を実際のホストIPアドレスとRPCポートに置き換える必要があります。ポート番号はデフォルトで2882です。</li></p></main>|

## 監視の原理

以下の図は、監視データの出所とデータフローを簡潔に示しています。

![1213](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2821871461/p368530.png)

1. 監視データは、OCP-Agentのocp_exporterプロセスが指標収集に基づいて取得します。

   取得したデータを収集データと呼びます。

2. OCP-Serverは、ocp_exporter_address内のinstanceに基づいて収集をトリガーし、最終的に監視データベースに保存します。

3. 収集データは計算式によって集約・計算され、最終的にページリクエストで取得するデータが得られます。以下の計算式を例にします：

   ```sql
   sum(rate(ob_sysstat{stat_id="40000",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="40002",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="40004",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="40006",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="40008",@LABELS}[@INTERVAL])) by (@GBLABELS) + sum(rate(ob_sysstat{stat_id="40018",@LABELS}[@INTERVAL])) by (@GBLABELS)
   ```

   * LABELSはフィルタリングの次元であり、これらのラベルに基づいてデータをフィルタリングします。

   * GBLABELSは集約の次元であり、選択された結果に対してこれらの情報に基づいて集約を行います。

   * INTERVALは集約の時間粒度を表し、その内容はユーザー定義の統計期間によって決定されます。

4. このデータは監視指標によって運ばれ、画面上ではトレンドグラフの形で表示され、ご覧いただけます。

   当該指標に細分化指標がある場合、データは細分化指標によって運ばれ、OCP画面に伝達されます。

## モニタリングデータの表示

OCPのモニタリングページで、モニタリングウィンドウ、集計期間、集計範囲を指定することで、注目したいモニタリングデータを照会できます。モニタリングデータについては、以下の2点に注意してください：

* OCPは、バックグラウンドの非同期タスクを通じて、画面上でモニタリングされるデータを事前に計算し、毎回のリアルタイムクエリを回避することで、CPU負荷のピークを削減し、モニタリングインターフェースの読み込み速度を向上させます。<code>ocp(metric.async-compute.enabled</code>パラメータを変更することで、モニタリングの非同期計算機能を有効にするかどうかを決定できます。詳細な操作手順については、[システムパラメータの変更](../../1600.system-management-features/500.manage-system-parameter/200.modify-system-parameters.md)を参照してください。</p>

* OCPは、収集されたソースデータを集約し、秒単位のデータを分単位に、分単位のデータを時間単位にダウンサンプリングするロジックにより、データ量を削減し、保存期間を延長します。これにより、クエリ速度を向上させると同時に、モニタリングデータのトレンドと特性を可能な限り保持します。システムはデフォルトで最大値(Max)をダウンサンプリングロジックとして使用します。つまり、1分間の秒単位のデータの最大値を、その分の現在時刻のデータとして使用します。`ocp.monitor.metric.collect.rollup.type`パラメータを変更することで、平均値(Avg)または初期値(FIRST)として表示するかどうかを決定できます。

### OceanBaseクラスタのモニタリングデータの表示

* 方法1：

  1. OCPにログインします。

  2. **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">クラスタ</UI-TERM>**ページの**<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>**エリアで、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

  3. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**をクリックします。

* 方法2：

  1. OCPにログインします。

  2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**をクリックすると、システムはデフォルトで**<UI-TERM key="ocp-v2.Auth.Org.SharedResourceDrawer.OceanbaseCluster">OceanBase クラスタ</UI-TERM>**タブに移動します。

クラスタの**データベースパフォーマンス**および**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostPerformance">ホストパフォーマンス</UI-TERM>**のモニタリングデータを確認できます。詳細な確認方法については、[データベースパフォーマンスの表示](../../880.manage-performance-monitoring/100.performance-monitoring-overview/200.view-clusters-performance.md)および[ホストパフォーマンスの表示](../../880.manage-performance-monitoring/100.performance-monitoring-overview/300.view-host-performance.md)を参照してください。

## 関連する概念

* 収集周期：OCPが対象オブジェクトの監視データを収集する頻度です。収集間隔は収集指標の種類に応じて、秒単位、分単位、時間単位に分かれています。

* 監視ウィンドウ：OCPインターフェース上で監視データを表示する時間範囲を指します。

* 統計周期：OCPがデータを集計する時間粒度を指します。選択肢は「毎分」または「毎秒」です。「毎分」を選択した場合、画面には分単位で集計された統計データが表示され、「毎秒」を選択した場合、秒単位で集計された統計データが表示されます。

* 統計範囲：OceanBaseは分散データベースとして、クラスタやテナントの監視データはすべてのゾーンまたはすべてのサーバーの監視データを集約して作成されます。インターフェースではデフォルトでクラスタまたはテナントレベルの監視データが表示されますが、実際にはOCPは個別のゾーンやOBServerノードの監視データのクエリも提供しています。個別のゾーンやOBServerノードを統計範囲として指定することで、その範囲内の監視データのみを表示できます。
