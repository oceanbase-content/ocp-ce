# プロセススレッド数

このセクションでは、ホストプロセスの監視指標である **プロセススレッド数** について説明します。

## 指標の詳細

| 項目 | 内容 |
| --- | --- |
| **OCP表示名** | プロセススレッド数 |
| **元の指標** | `process_thread_count` |
| **収集API** | `proc.NumThreads()` |
| **Linuxデータソース** | `/proc/<pid>/status` の `Threads` フィールド |
| **意味** | プロセスの現在生存しているスレッドの総数（OBワーカースレッド、ネットワークスレッドなどを含む） |
| **OCP集計** | `avg(process_thread_count{name="observer"})` |
| **特徴** | 瞬間値。OBServerのスレッド数は負荷によって変化するため、同時実行負荷を判断するのに役立ちます |

### 同一名称の複数プロセス処理ポリシー

同名のプロセスが複数存在する場合、**最大値**（`math.Max()`）を取得します。

## observerプロセス

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_thread_count | -     |

### 計算式

```
avg(process_thread_count{name="observer",@LABELS}) by (@GBLABELS)
```

### 検証コマンド

```bash
PID=$(pidof observer)

grep Threads /proc/$PID/status
# 出力例：Threads:  512

ps -o pid,nlwp,comm -p $PID   # nlwp = number of light-weight processes (threads)
```
