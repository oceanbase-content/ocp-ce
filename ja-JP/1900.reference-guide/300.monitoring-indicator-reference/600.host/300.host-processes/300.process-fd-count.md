# プロセスファイルハンドル数

このセクションでは、ホストプロセスのモニタリング指標である **プロセスファイルハンドル数** について説明します。

## 指標の詳細

| 項目 | 内容 |
| --- | --- |
| **OCP表示名** | プロセスファイルハンドル数 |
| **元の指標** | `process_fd_count` |
| **収集API** | `proc.NumFDs()` |
| **Linuxデータソース** | `/proc/<pid>/fd/` ディレクトリ下のエントリ数を統計する |
| **意味** | プロセスが現在開いているファイルディスクリプタ（fd）の数（ファイル、ソケット、パイプなど） |
| **OCP集計** | `avg(process_fd_count{name="observer"})` |
| **関連指標** | `observer_fd_usage` = fd数 ÷ `observer_ulimit_max_fd_count`（ハンドル使用率 %） |

### 同名プロセスが複数存在する場合の処理ポリシー

同名のプロセスが複数存在する場合、**最大値**（`math.Max()`）を取得します。

## observerプロセス

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_fd_count | -     |

### 計算式

```
avg(process_fd_count{name="observer",@LABELS}) by (@GBLABELS)
```

### ハンドル使用率の計算式

```
round(100 * avg(process_fd_count{name="observer"}) / avg(observer_ulimit_max_fd_count))
```

### 検証コマンド

```bash
PID=$(pidof observer)

# ハンドルの総数
ls /proc/$PID/fd 2>/dev/null | wc -l

# ulimitの上限を確認する
cat /proc/$PID/limits | grep "open files"

# タイプ別に概観する（socketが多い場合はOBで一般的）
ls -l /proc/$PID/fd 2>/dev/null | awk '{print $NF}' | sed 's/.*\[//' | sed 's/\].*//' | sort | uniq -c | sort -rn | head
```
