# OCP-Agentプロセスのゴルーチン数

このセクションでは、ホストプロセスのモニタリング指標である **OCP-Agentプロセスのゴルーチン数** について説明します。

## 指標の詳細

| 項目 | 内容 |
| --- | --- |
| **OCP表示名** | OCP-Agentプロセスのゴルーチン数 |
| **元の指標** | `go_goroutines`（Prometheus標準指標） |
| **OCP指標** | `monagent_goroutine_count` / `mgragent_goroutine_count` |
| **収集方法** | **processInputを経由せず**、`prometheusInput`がAgent自身のHTTPエンドポイントを取得する |
| **取得アドレス** | `http://127.0.0.1:${ocp.agent.monitor.http.port}/metrics/stat` |
| **データソース** | Agent内の`prometheus.NewGoCollector()`が公開するGoランタイム指標 |
| **意味** | `ocp_monagent` / `ocp_mgragent` プロセス内の **ゴルーチン数**（Goゴルーチン、OSスレッドではない） |
| **収集サイクル** | 約60秒（前の4項目よりも遅い） |
| **適用範囲** | Goで記述されたAgentプロセスのみ。**observer / obproxyにはこの指標はありません** |

### 「プロセススレッド数」との違い

| 比較項目 | プロセススレッド数 | ゴルーチン数 |
| --- | --- | --- |
| 対象 | OSスレッド（カーネルスケジューリング） | Goゴルーチン（ユーザー空間） |
| データソース | `/proc/pid/status` | Goランタイム `runtime.NumGoroutine()` |
| 適用プロセス | observer、obproxy、agentなど | ocp_monagent、ocp_mgragentのみ |

## monagentプロセス

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| monagent | monagent_goroutine_count | -     |

### 計算式

```
max(go_goroutines{process="ocp_monagent",@LABELS}) by (@GBLABELS)
```

### 検証コマンド

```bash
# Agentホスト上（ポートは実際の設定に準ずる）
curl -s http://127.0.0.1:<monitor_port>/metrics/stat | grep go_goroutines

# またはUnixソケット経由で
curl -s --unix-socket $OCP_AGENT_HOME/run/ocp_monagent.*.sock \
  http://unix-socket-server/metrics/stat | grep go_goroutines
```

## カスタマーシナリオにおける測定値の推奨

| 指標 | 測定方法 |
| --- | --- |
| **ゴルーチン** | Agentにgoroutineリークが発生していないかのトラブルシューティングにのみ使用され、OBServerのCPU使用率が高いこととは直接的な関係はありません |
