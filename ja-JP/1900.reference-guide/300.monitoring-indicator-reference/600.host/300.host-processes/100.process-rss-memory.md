# プロセス常駐メモリ

このセクションでは、ホストプロセスの監視指標である **プロセス常駐メモリ** について説明します。

## 指標の詳細

| 項目 | 内容 |
| --- | --- |
| **OCP表示名** | プロセス常駐メモリ |
| **元の指標** | `process_memory_rss_bytes` |
| **収集API** | `proc.MemoryInfo().RSS` |
| **Linuxデータソース** | `/proc/<pid>/status` の `VmRSS`、または `/proc/<pid>/statm` の2列目 × ページサイズ |
| **意味** | プロセスが実際に使用している**物理メモリ**（Resident Set Size）。swapやマッピングされていない仮想メモリは含まれません |
| **単位** | バイト（byte） |
| **OCP集計** | `sum(process_memory_rss_bytes{name="observer"})` |
| **特徴** | **瞬時値**。各収集時点のスナップショットであり、時間平均は行いません。

### 同一名称を持つ複数プロセスの処理ポリシー

複数の同名プロセスが存在する場合（例：アービトレーションobserverの一時的な二重プロセス）、**最大値**（`math.Max()`）を取得します。

## observerプロセス

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_rss_memory | byte     |

### 計算式

```
sum(process_memory_rss_bytes{name="observer",@LABELS}) by (@GBLABELS)
```

### 検証コマンド

```bash
PID=$(pidof observer)

# 方法1：status
grep VmRSS /proc/$PID/status
# 出力例：VmRSS:  52428800 kB

# 方法2：ps（単位KB）
ps -o pid,rss,comm -p $PID

# 方法3：agentと同様にgopsutilのセマンティクスを使用する
cat /proc/$PID/statm | awk '{print "RSS pages:", $2, " bytes≈", $2*4096}'
```
