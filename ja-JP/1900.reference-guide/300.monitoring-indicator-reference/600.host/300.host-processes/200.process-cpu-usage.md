# プロセスCPU利用率

このセクションでは、ホストプロセスの監視指標である**プロセスCPU利用率**について説明します。

## 指標の詳細

| 項目 | 内容 |
| --- | --- |
| **OCP表示名** | プロセスCPU利用率 |
| **元の指標** | `process_cpu_percent` |
| **収集API** | `proc.Percent(1 * time.Second)` |
| **Linuxデータソース** | `/proc/<pid>/stat` のフィールド14（utime）+ 15（stime） |
| **サンプリング方式** | 1回読み取り → **1秒間待機** → もう一度読み取り、増分を計算 |
| **計算式** | `(ΔCPU時間秒数 / 1秒) × 100` |
| **算出基準** | **各コアのフル負荷 = 100%**、マルチコアは累積。64コアでハイパースレッディングを使用しない場合の理論的ピーク値は **6400%** |
| **OCP集計** | `avg(process_cpu_percent{name="observer"})` |
| **正規化指標** | `observer_process_cpu_percent_per_cpu` = プロセスCPU ÷ `cpu_count`（0〜100%がマシン全体の割合） |

### 重複する同名プロセスの処理ポリシー

同名のプロセスが複数存在する場合、**最後に見つかったもので上書き**します。

### utimeとstimeの意味

| フィールド | 意味 |
| --- | --- |
| utime | ユーザー空間CPU時間（jiffies） |
| stime | カーネル空間CPU時間（jiffies） |
| 合計 | プロセス内すべてのスレッドのCPU時間の合計 |

### 64コアでハイパースレッディングを使用しない場合の説明

- 理論的ピーク値 = 64 × 100% = **6400%**
- 監視されたピーク値が6400%を超える場合（例：11405%）、物理的に長時間維持することは不可能であり、おそらくは**1秒間隔のサンプリングによるスパイク**です。
- `observer_process_cpu_percent_per_cpu` とホストの `cpu_percent` を同時に確認し、相互に検証することを推奨します。

## observerプロセス

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| observer | observer_process_cpu_percent | %     |

### 計算式

```
avg(process_cpu_percent{name="observer",@LABELS}) by (@GBLABELS)
```

### 正規化計算式

```
sum(process_cpu_percent{name="observer",@LABELS}) by (@GBLABELS) / sum(cpu_count) by (@GBLABELS)
```

### 検証コマンド

```bash
PID=$(pidof observer)

# 推奨：agentの算出基準に最も近いもの
pidstat -p $PID 1 5

# 手動で1秒サンプリングを再現する
CLK=$(getconf CLK_TCK)
T1=$(awk '{print $14+$15}' /proc/$PID/stat)
sleep 1
T2=$(awk '{print $14+$15}' /proc/$PID/stat)
echo "scale=2; ($T2-$T1)/$CLK*100" | bc
```

## 交差検証手順（CPU異常時）

```bash
# 1. コア数の確認
lscpu | grep -E 'Thread|Core|Socket|^CPU\(s\)'
nproc

# 2. observerプロセス数の確認（1である必要があります）
pgrep -a observer
pgrep -c observer

# 3. OS側での継続的サンプリング
pidstat -p $(pidof observer) 1 60

# 4. OCPでも同時に確認する
#    - observer_process_cpu_percent（元の累積値）
#    - observer_process_cpu_percent_per_cpu（マシン全体の割合 0～100%）
#    - cpu_percent（ホストCPU）
#    - process_count{name="observer"}（プロセス数）
```
