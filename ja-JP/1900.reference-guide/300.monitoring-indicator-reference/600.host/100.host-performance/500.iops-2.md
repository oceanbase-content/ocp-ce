# IOPS

このセクションでは、ホストのパフォーマンス指標である **IOPS（Input/Output Operations Per Second）** について説明します。IOPSは、コンピュータのストレージデバイスが1秒間に読み書き操作を行う回数を示します。

## 背景

ホスト監視では、IOPSを複数ディスクに対して表示することができます。ホストに複数のディスクがマウントされている場合、sda：io_read、sda：io_write、sdb：io_read、sdb：io_writeなど、複数の読み書き指標項目が表示されます。

これらの読み書き指標における指標パラメータと式はすべて同じです。

## read

### 指標の紹介

1秒間にディスクから読み取る回数。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| read    | io_read  | times/s      |

### 計算式

avg(rate(node_disk_reads_completed_total{@LABELS}[@INTERVAL])) by (@GBLABELS)

## write

### 指標の紹介

1秒間にディスクに書き込む回数。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| write   | io_write | times/s      |

### 計算式

avg(rate(node_disk_writes_completed_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
