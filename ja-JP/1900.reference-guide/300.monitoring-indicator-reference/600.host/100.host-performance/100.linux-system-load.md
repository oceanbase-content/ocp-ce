# Linux システム負荷

このセクションでは、ホストのパフォーマンスを監視する指標である **Linux システム負荷** について説明します。load 1、load5、load15 のトレンドグラフから、現在のホストが過負荷状態にあるかどうかを判断できます。load5 または load15 の値が常に現在のホストの CPU 総コア数を上回っている場合、そのホストは過負荷状態にあります。現在のホストの CPU コア数は、`grep 'model name' /proc/cpuinfo | wc -l` コマンドで取得できます。

## load1

### 指標の紹介

過去1分間のシステム平均負荷。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** | **指標名** | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Unit">単位</UI-TERM>** |
|---------|----------|--------|
| load1   | load1    | -      |

### 計算式

avg(node_load1{@LABELS}) by (@GBLABELS)
