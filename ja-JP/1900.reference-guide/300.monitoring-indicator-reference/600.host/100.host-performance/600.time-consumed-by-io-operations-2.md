# IO時間

このセクションでは、ホストのパフォーマンス指標である **IO時間** について説明します。

## 背景

ホスト監視はIOPSをサポートしており、複数のディスクがマウントされている場合、sda：io_read、sda：io_write、sdb：io_read、sdb：io_writeなど、複数の読み書き指標項目が表示されます。これらの指標のパラメータと式はすべて同じです。

## read

### 指標の概要

1回の読み取り操作にかかる平均時間。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|---------|--------------|--------|
| read    | io_read_time | μs     |

### 計算式

1000000 * (avg(rate(node_disk_read_time_seconds_total{@LABELS}[@INTERVAL])) by (@GBLABELS)) / (avg(rate(node_disk_reads_completed_total{@LABELS}[@INTERVAL])) by (@GBLABELS))

## write

### 指標の概要

1回の書き込み操作にかかる平均時間。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**    | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">単位</UI-TERM>** |
|---------|---------------|--------|
| write   | io_write_time | μs     |

### 計算式

1000000 * (avg(rate(node_disk_write_time_seconds_total{@LABELS}[@INTERVAL])) by (@GBLABELS)) / (avg(rate(node_disk_writes_completed_total{@LABELS}[@INTERVAL])) by (@GBLABELS))
