# CPU使用率

このセクションでは、ホストのパフォーマンス指標である **<UI-TERM key="ocp-v2.Compaction.DetailV4.CpuAndMemoryChart.CpuUsage">CPU使用率</UI-TERM>** について説明します。

## all

### 指標の概要

ホストのCPU使用率です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |  **指標名**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">単位</UI-TERM>** |
|---------|-------------|--------|
| all | cpu_percent | %      |

### 計算式

100 * (1 - sum(rate(node_cpu_seconds_total{mode="idle",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(node_cpu_seconds_total{@LABELS}[@INTERVAL])) by (@GBLABELS))

## system

### 指標の概要

システムCPU使用率です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |  **指標名**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.Unit">単位</UI-TERM>** |
|---------|-------------|--------|
| system  | cpu_system | %      |

### 計算式

100 * sum(rate(node_cpu_seconds_total{mode="system", @LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(node_cpu_seconds_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
