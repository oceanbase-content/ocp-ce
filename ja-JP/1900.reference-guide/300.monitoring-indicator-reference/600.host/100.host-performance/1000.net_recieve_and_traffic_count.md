# ネットワークパケット送受信

このセクションでは、ホストの**ネットワークパケット送受信**に関連する監視メトリクスについて説明します。

## net_receive_drop_count

### メトリクスの紹介

サーバーのネットワークパケットドロップ数。

### メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **メトリクス名**    | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|----------------|--------|
| net_receive_drop_count       | net_receive_drop_count | -     |

### 計算式

sum(rate(node_network_receive_drop_total{@LABELS}[@INTERVAL])) by (@GBLABELS)
