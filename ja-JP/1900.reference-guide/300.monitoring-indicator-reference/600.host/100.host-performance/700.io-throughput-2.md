# I/Oスループット

このセクションでは、ホストのパフォーマンス指標である **I/Oスループット** について説明します。

## 背景

ホスト監視はIOPSをサポートしており、ホストに複数のディスクがマウントされている場合、sda：io_read、sda：io_write、sdb：io_read、sdb：io_writeなど、複数の読み書き指標項目が表示されます。

これらの読み書き指標の指標パラメータと式はすべて同じです。

## read

### 指標の紹介

1秒間にディスクから平均的に読み取られるデータ量。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**   | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.Unit">単位</UI-TERM>** |
|---------|--------------|--------|
| read    | io_read_byte | Byte     |

### 計算式

avg(rate(node_disk_read_bytes_total{@LABELS}[@INTERVAL])) by (@GBLABELS) / 1048576

## write

### 指標の紹介

1秒間にディスクに平均的に書き込まれるデータ量。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |   **指標名**    | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|---------------|--------|
| write   | io_write_byte | Byte     |

### 計算式

avg(rate(node_disk_written_bytes_total{@LABELS}[@INTERVAL])) by (@GBLABELS) / 1048576
