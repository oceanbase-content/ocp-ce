# Inode 使用率

このセクションでは、ホストの**Inode使用率**に関する監視メトリクスについて説明します。

## メトリクスの概要

サーバーのinode使用率です。

## メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |    **メトリクス名**    | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|----------------|--------|
| file_inode_usage       | file_inode_usage | %     |

## 計算式

round(100 - 100 * sum(node_filesystem_files_free{@LABELS}) by (@GBLABELS) / sum(node_filesystem_files{@LABELS}) by (@GBLABELS))
