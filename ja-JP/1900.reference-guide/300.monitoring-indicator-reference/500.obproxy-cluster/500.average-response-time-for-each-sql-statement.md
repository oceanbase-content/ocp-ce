# SQL応答時間

このセクションでは、OBProxyのモニタリングメトリクスである**SQL応答時間**について説明します。応答時間とは、OBProxyがSQLを転送してから、OBProxyがOBServerノードからの応答を受信するまでの総時間を指します。

## commit

### メトリクス紹介

commitリクエストを転送するたびの平均時間です。

### メトリクスパラメータ説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |      **メトリクス名**       | **<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>** |
|---------|---------------------|--------|
| commit  | request_cost_commit | μs     |

### 計算式

sum(rate(odp_sql_cost_total{timeType="total",sqltype="COMMIT", @LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(odp_sql_request_total{sqltype="COMMIT", @LABELS}[@INTERVAL])) by (@GBLABELS)
