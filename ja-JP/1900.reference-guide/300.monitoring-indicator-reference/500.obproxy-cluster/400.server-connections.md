# サーバー接続

このセクションでは、OBProxyの監視メトリクスである **サーバー接続** について説明します。

## server

### メトリクスの紹介

OBProxyクラスタが現在時点でサーバーと確立している接続数です。

### メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |        **メトリクス名**        | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Unit">単位</UI-TERM>** |
|---------|------------------------|--------|
| server       | current_session_server | -      |

### 計算式

sum(odp_current_session{sessionType="server",@LABELS}) by (@GBLABELS)

## server_connection_usage

### メトリクスの紹介

OBProxyサーバー接続数 / max_connections。

### メトリクスパラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |        **メトリクス名**        | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|---------|------------------------|--------|
| server_connection_usage       | server_connection_used_percent | %      |

### 計算式

100 * sum(odp_current_session{sessionType="server",@LABELS}) by (@GBLABELS) / sum(obproxy_server_max_connections{@LABELS}) by (@GBLABELS)
