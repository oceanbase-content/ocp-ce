# RPCセッション数

このセクションでは、OBProxyのモニタリング指標である **RPCセッション数** について説明します。

## rpc_session_client

### 指標の概要

現在のクライアント側のODP RPCセッション数です。

### 指標パラメータの説明

|    **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**     |          **指標名**           | **<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>** |
|----------------|-----------------------------|--------|
| rpc_session_client | odp_current_rpc_session_client | -  |

### 計算式

sum(rate(odp_current_rpc_session{sessionType="client", @LABELS}[@INTERVAL])) by (@GBLABELS)'
