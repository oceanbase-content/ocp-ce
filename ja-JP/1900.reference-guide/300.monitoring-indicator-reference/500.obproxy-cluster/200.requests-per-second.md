# QPS

このセクションでは、OBProxyの監視指標である**QPS**について説明します。

## commit

### 指標の概要

OBProxyクラスタが1秒間に平均して転送するcommitリクエスト数です。

### 指標パラメータの説明

| **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** |       **指標名**       | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Unit">単位</UI-TERM>** |
|---------|----------------------|--------|
| commit  | request_total_commit | -      |

### 計算式

sum(rate(odp_sql_request_total{sqltype="COMMIT", @LABELS}[@INTERVAL])) by (@GBLABELS)
