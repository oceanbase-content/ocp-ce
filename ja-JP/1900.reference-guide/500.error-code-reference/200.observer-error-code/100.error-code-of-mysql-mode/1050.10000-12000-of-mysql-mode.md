## ERROR 11032 (HY000) : HDFS path message %s

* OceanBase エラーコード：11032

* エラーの原因：HDFS path message %s エラーが発生しました。一般的に以下のシナリオで発生します：

  1. Kerberos認証を有効にしたHDFS環境で、特定のHDFS外部テーブルにアクセスする際、権限不足によりアクセスできない場合、-11032 エラーが発生します。

  2. Kerberos認証の設定が正しいにもかかわらず、HDFS: path not found エラーが発生する場合、外部テーブル作成ステートメントで指定された外部テーブルパスが誤っており、存在しないパスを指している可能性があります。

  3. 外部テーブルへのアクセスは初期段階では正常だったが、クエリ実行後しばらくして11032 エラーが発生する場合、HDFSの対応する外部テーブルパス配下のファイルに不良ブロックが存在する可能性があります。つまり、HDFS DataNodeがそのデータブロックにエラーがあり、アクセスできないと報告し、それによってエラーがトリガーされることがあります。

* 解決策：
  1. Kerberos認証のkeytab、principalが有効であり、対応するユーザーがHDFSクラスタへのアクセス権限を持っていることを確認し、外部テーブルの権限を再設定してKerberos認証を有効にします。

  2. 対応するHDFSパスが正しく存在することを確認し、外部テーブルのHDFSパスマッピングを再構築します。

  3. 顧客の運用保守チームにフィードバックし、データの不良ブロック状況を確認した上で、不良ブロックの調整または環境の変更を検討し、検証を続けます。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このエラーコードはV4.5.0バージョンから導入されました。</p>
</main>

## ERROR 11126 (HY000) : unit \'%.*s\' not recognized

* OceanBase エラーコード：11126
* エラー原因：日付切り捨て関数（DATE_TRUNCやDATETRUNCなど）を呼び出す際、指定された時間単位パラメータが認識されませんでした。

* 解決策：SQLステートメント内の日付切り捨て関数の最初のパラメータを確認し、その綴りが正しく、OceanBaseデータベースでサポートされている有効な時間単位キーワードであることを確認してください。
