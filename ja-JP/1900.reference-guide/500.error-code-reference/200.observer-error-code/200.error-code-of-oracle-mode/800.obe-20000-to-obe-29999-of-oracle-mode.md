## OBE-20000：operator binding does not exist

* OceanBase エラーコード：7299

* SQLSTATE：42000

* エラーの原因：操作を実行しようとした際、指定された演算子バインディング（operator binding）が見つかりませんでした。

* 解決策：使用している演算子または関数名にスペルミスなどの誤りがないか確認してください。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>V4.3.x系では、このエラーコードはV4.3.2バージョンから導入されました。</li><li>V4.2.x系では、このエラーコードはV4.2.4バージョンから導入されました。</li></ul>
</main>

## OBE-20000：'%.*s' invalid partition name

* OceanBase エラーコード：11002

* SQLSTATE：HY000

* エラーの原因：パーティション名 '%.*s' は無効です。
* 解決策：パーティション名 '%.*s' が正しく、パーティション名の命名規則に準拠しているか確認してください。有効なパーティション名を使用して操作を実行してください。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <p>このエラーコードはV4.3.0バージョンから導入されました。</p>
</main>

## OBE-20000： The stored procedure  'raise_application_error' was called which causes this error to be  generated", "ORA%06ld: %.*s

* OceanBase エラーコード：20000

* SQLSTATE：HY000

* エラーの原因：プロシージャのカスタムエラーコード `RAISE_APPLICATION_ERROR` が呼び出されたことで、このエラーが発生しました。

* 解決策：エラーメッセージの指示に従って問題を修正するか、アプリケーション管理者またはDBAに連絡して詳細をお尋ねください。

## OBE-21560：argument %.\*s is null, invalid, or out of range

* OceanBase エラーコード：5934

* SQLSTATE：HY000

* エラー原因：渡されたパラメータ値が `NULL`、無効、または範囲外です。例えば、`LOB / FILE` の位置またはサイズパラメータの値が1から(4 GB - 1)の範囲を超えている場合や、無効な開きモードでファイルを開いた場合などです。

* 解決策：プログラムを確認し、`NULL`、無効、または範囲外のパラメータ値を渡さないよう修正してください。

## OBE-22003：value is out of range

* OceanBase エラーコード：4157

* SQLSTATE：22003

* エラー原因：指定された `TCP/IP` 関数 `func` の実行時に予期しない通信エラーが発生しました。`TCP/IP` 関数の戻りコードは `rc`、関数 `func` のパラメータは `parm` です。

* 解決策：テクニカルサポートにお問い合わせいただき、調査をご依頼ください。

## OBE-22928：invalid privilege on directories

* OceanBase エラーコード：5374

* SQLSTATE：HY000

* エラー原因：ディレクトリに対する権限の付与または取り消しを試みましたが、その権限はディレクトリに対して無効です。

* 解決策：ディレクトリに対しては `CREATE`、`DELETE`、`READ`、`WRITE`、`EXECUTE` 権限のみを付与または取り消すことができます。その他の権限については付与または取り消さないでください。

## OBE-22950：cannot ORDER objects without MAP or ORDER method

* OceanBase エラーコード：7412
* SQLSTATE：42000
* エラー原因：オブジェクトを比較する際、そのオブジェクトにMAPまたはORDERメソッドが定義されていません。
* 解決策：
   1. MAPまたはORDERメソッドの定義：オブジェクトの定義内でMAPまたはORDERメソッドを定義し、ソート時に使用します。MAPメソッドはオブジェクトをスカラー値にマッピングするために使用され、ORDERメソッドは2つのオブジェクトの大小を比較するために使用されます。
   2. ソート方法の変更：MAPまたはORDERメソッドを定義できない場合は、ソート方法を変更し、他の方法でソートすることを検討してください。例えば、他の列を使用してソートすることができます。

  <h4>説明</h4>
  <p>このエラーコードはV4.2.0バージョンから導入されました。</p>
</main>
