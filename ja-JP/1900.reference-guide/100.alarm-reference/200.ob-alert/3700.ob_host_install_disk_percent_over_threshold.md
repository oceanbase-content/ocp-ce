# ob_host_install_disk_percent_over_threshold OceanBase サーバーのインストールディレクトリのディスク使用率がしきい値を超えた場合

## アラートの説明

OBServerノードのインストールディレクトリのマウントポイントのディスク容量使用率がしきい値を超えた場合にこのアラートがトリガーされます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OBServerノードのインストールディレクトリは、デフォルトで <code>/home/admin/oceanbase</code> です。</p>
  </main>

## アラートの仕組み

以下の表は、このアラートの監視ロジックに関連する主要なパラメータを示しています。

| パラメータ | 値 |
|-------|----------|
| 監視指標 | ob_install_disk_usage_percent。この指標はOBServerノードのインストールディレクトリのディスク使用率を示し、使用率がしきい値を超えるとアラートがトリガーされます。    |
| 監視式 | ```100 * (1 - avg(node_filesystem_avail_bytes{is_ob_disk="1",mount_label="install_path",@LABELS}) by (@GBLABELS) / avg(node_filesystem_size_bytes{is_ob_disk="1",mount_label="install_path",@LABELS}) by (@GBLABELS))```      |
| 取得指標 | node_filesystem_avail_bytes、node_filesystem_size_bytes       |
| データソース | このアラートの指標ソースはやや特殊で、OCP-Agentは `df -B1` コマンドを実行してOBServerノードのディスク使用量をチェックし、ディスクに関連するラベルを追加します。ラベルは以下の通りです：<li>インストールディレクトリがあるディスク：`mount_lable="install_path"`</li><li>データディレクトリがあるディスク：`mount_lable="data_path"`</li><li>ログディレクトリがあるディスク：`mount_lable="log_path"`</li>  |
| 取得サイクル | 5秒      |

## ルール情報

|        監視指標                | デフォルトしきい値（単位：%） | 持続時間 | 検出サイクル | 解消サイクル |
|--------------------------------|------------|------|------|------|
| ob_install_disk_usage_percent  |<li>ob_install_disk_usage_percent > 95</li><li>ob_install_disk_usage_percent > 97</li>   | 0秒  | 10秒 | 5分 |

## アラート情報

|   アラートトリガー方法   | アラートレベル | 対象範囲  |
|------------|------|-----|
| 監視指標の式に基づく | <li>ob_install_disk_usage_percent > 95：重大</li><li>ob_install_disk_usage_percent > 97：サービス停止</li>   | ホスト |

## システムへの影響

`/home` ディレクトリがいっぱいになると、OBServerノードはプログラムのログファイルを書き込むことができません。

## 考えられる原因

他のプログラムが生成したファイルが多すぎる。

## 解決策

1. `df` コマンドを実行して、`/home/` のディスク使用率が限度を超えていないか確認します。

2. 限度を超えている場合、以下のコマンドを実行して、最も容量を占有しているディレクトリとファイルを特定します。

   ```shell
   # 最も容量を占有している5つのディレクトリを見つける
   du -a /home/admin | sort -n -r | head -n 5

   # サイズが最大の5つのファイルを見つける
   cd /home/admin && find -type f -exec du -Sh {} + | sort -rh | head -n 5
   ```

3. 不要なファイルを削除します。
