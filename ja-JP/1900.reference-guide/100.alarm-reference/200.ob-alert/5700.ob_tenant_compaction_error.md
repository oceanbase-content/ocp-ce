# ob_tenant_compaction_error OceanBaseテナントのメジャーコンパクションエラー

## アラートの概要

OceanBase V4.0以降では、テナントごとにメジャーコンパクションを実行できます。テナントのメジャーコンパクション中にエラーが発生した場合、このアラートがトリガーされます。

## アラートの仕組み

| パラメータ     | 値 |
| -------- | ------- |
| モニタリング指標 | compaction_is_error。この指標は、OceanBaseテナントのメジャーコンパクションにエラーが発生したかどうかを示します。指標値が`0`の場合はテナントのメジャーコンパクションが正常であり、指標値が`1`の場合はテナントのメジャーコンパクションにエラーが発生し、アラートがトリガーされます。 |
| モニタリング式 | ```max(ob_compaction_is_error{@LABELS}) by (@GBLABELS)``` |
| 収集指標 | ob_compaction_is_error |
| 指標の出典 | 内部ビューから収集。収集SQL：```select tenant_id, frozen_scn as frozen_version, LAST_SCN as last_version, case is_error when 'YES' then 1 else 0 end as is_error, case is_suspended when 'YES' then 1 else 0 end as is_suspended, time_to_usec(start_time) as start_time, time_to_usec(frozen_time) as frozen_time, time_to_usec(now()) as current from CDB_OB_MAJOR_COMPACTION```  |
| 収集サイクル | 5秒   |

## ルール情報

| モニタリング式 | デフォルトしきい値 | 持続時間  | 検出サイクル | 解消サイクル |
| -------- | -------- | -------- | ------- | ------- |
| compaction_is_error  | 1 | 0秒 | 20秒 | 5分 |

## アラート情報

| アラートのトリガー方法 | アラートレベル | 対象範囲     |
| ---------- | --------- | ---------- |
| モニタリング指標の式に基づく | 重大 | テナント |

## アラートテンプレート

* **アラートの概要**

  * テンプレート：\${alarm_target} \${alarm_name}
  * 例：alarm_template_id=0:ob_cluster=C1-1000:tenant_name=T1 OceanBaseテナントのメジャーコンパクションエラー

* **アラートの詳細**

  * テンプレート：クラスタ：\${ob_cluster_name}、テナント：\${tenant_name}、アラート：\${alarm_name}。
  * 例：クラスタ：obcluster、テナント：T1、アラート：OceanBaseテナントのメジャーコンパクションエラー。

* **アラートの回復**

  * テンプレート：アラート：${alarm_name}、OceanBaseテナントのメジャーコンパクションエラーマーク：\${recover_value}
  * 例：アラート：OceanBaseテナントのメジャーコンパクションエラー、OceanBaseテナントのメジャーコンパクションエラーマーク：0

## システムへの影響

OceanBaseクラスタの一部のレプリカデータに不整合が生じる可能性があります。例えば、レプリカ間での不整合や、主表とインデックス表間での不整合が発生する場合があります。

## 考えられる原因

理論上は極端なシナリオが存在しますが、一般的な原因はありません。
