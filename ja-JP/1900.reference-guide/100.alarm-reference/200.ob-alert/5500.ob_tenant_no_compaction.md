# ob_tenant_no_compaction OceanBaseテナントが長時間メジャーコンパクションを実行していない

## アラートの概要

OceanBase V4.0以降では、テナントごとにメジャーコンパクションを実行できます。テナントが長時間メジャーコンパクションを実行していない場合、このアラートがトリガーされます。

## アラートの仕組み

| パラメータ | 値 |
| ------- | -------- |
| モニタリング指標 | no_compaction_seconds。この指標は、OceanBaseテナントの前回のメジャーコンパクションからの経過時間を示します。時間がしきい値を超えた場合にアラートがトリガーされます。 |
| モニタリング式 | ```(max(ob_compaction_current_timestamp{@LABELS}) by (@GBLABELS) - max(ob_compaction_start_time{@LABELS}) by (@GBLABELS)) / 1000000```   |
| 取得指標 | ob_compaction_current_timestamp、ob_compaction_start_time  |
| 指標ソース | 内部ビューから取得します。取得SQL：```select tenant_id, frozen_scn as frozen_version, LAST_SCN as last_version, case is_error when 'YES' then 1 else 0 end as is_error, case is_suspended when 'YES' then 1 else 0 end as is_suspended, time_to_usec(start_time) as start_time, time_to_usec(frozen_time) as frozen_time, time_to_usec(now()) as current from CDB_OB_MAJOR_COMPACTION```   |
| 取得サイクル | 5秒   |

## ルール情報

| モニタリング式 | デフォルトしきい値（単位：秒） | 継続時間  | 検出サイクル | 解消サイクル |
| ---------- | ------- | ---------- | -------- | ---------- |
| no_compaction_seconds | 108000    | 0秒  | 20秒 | 5分 |

## アラート情報

| アラートトリガー方法 | アラートレベル | 対象範囲 |
| ------------ | -------- | -------- |
| モニタリング指標の式に基づく | 重大 | テナント |

## アラートテンプレート

* **アラート概要**

  * テンプレート：\${alarm_target} \${alarm_name}
  * 例：ob_cluster=C1-1000:tenant_name=T1 OceanBaseテナントが長時間メジャーコンパクションを実行していない

* **アラート詳細**

  * テンプレート：クラスタ：\${ob_cluster_name}、テナント：\${tenant_name}、アラート：\${alarm_name}。前回のメジャーコンパクションからの時間は${value_shown}秒で、${alarm_threshold}秒を超えています。
  * 例：クラスタ：obcluster、テナント：T1、アラート：OceanBaseテナントが長時間メジャーコンパクションを実行していない。前回のメジャーコンパクションからの時間は216000秒で、108000秒を超えています。

* **アラート回復**

  * テンプレート：アラート：${alarm_name}、OceanBaseテナントの前回のメジャーコンパクションからの経過時間：\${value_shown}
  * 例：アラート：OceanBaseテナントが長時間メジャーコンパクションを実行していない、OceanBaseテナントの前回のメジャーコンパクションからの経過時間：9560秒

## システムへの影響

長期間凍結またはメジャーコンパクションを実行しない場合、ディスク使用量が増加し、ディスクが満杯になって業務上の書き込みに影響を及ぼします。

## 考えられる原因

Root Serviceが異常に一時停止した場合によく見られます。例えば、リーダー不在やプロセス異常などです。

## 解決策

[ob_cluster_no_frozen OceanBaseクラスタが長期間凍結されていない](../200.ob-alert/900.ob_cluster_no_frozen.md) を参照して、具体的な原因を調査し解決してください。
