# ob_tenant_no_frozen OceanBaseテナントが長時間凍結されていない

## 警報の概要

OceanBase V4.0以降ではテナント単位での凍結がサポートされており、テナントが長時間凍結されていない場合にこの警報がトリガーされます。

## 警報の仕組み

| パラメータ | 値 |
| --------- | -------- |
| モニタリング指標 | no_frozen_seconds。この指標は、OceanBaseテナントが最後に凍結されてからの経過時間を示します。時間がしきい値を超えた場合に警報がトリガーされます。 |
| モニタリング式 | ```(max(ob_compaction_current_timestamp{@LABELS}) by (@GBLABELS) - max(ob_compaction_frozen_time{@LABELS}) by (@GBLABELS)) / 1000000```   |
| 取得指標 | ob_compaction_current_timestamp、ob_compaction_frozen_time  |
| 指標の出典 | 内部ビューから取得します。取得SQL：```select tenant_id, frozen_scn as frozen_version, LAST_SCN as last_version, case is_error when 'YES' then 1 else 0 end as is_error, case is_suspended when 'YES' then 1 else 0 end as is_suspended, time_to_usec(start_time) as start_time, time_to_usec(frozen_time) as frozen_time, time_to_usec(now()) as current from CDB_OB_MAJOR_COMPACTION```  |
| 取得間隔 | 5秒 |

## ルール情報

| モニタリング式 | デフォルトのしきい値（単位：秒） | 継続時間 | 検出間隔 | 解消間隔 |
| ---------- | ------- | ---------- | -------- | ---------- |
| no_frozen_seconds | 90000  | 0秒  | 20秒 | 5分 |

## 警報情報

| 警報のトリガー方法 | 警報レベル | 対象範囲 |
| ----------- | -------- | --------- |
| モニタリング指標の式に基づく | 重大 | テナント |

## 警報テンプレート

* **警報の概要**

  * テンプレート：\${alarm_target} \${alarm_name}
  * サンプル：alarm_template_id=0:ob_cluster=C1-1000:tenant_name=T1 OceanBaseテナントが長時間凍結されていない

* **警報の詳細**

  * テンプレート：クラスタ：\${ob_cluster_name}、テナント：\${tenant_name}、警報：\${alarm_name}。最後に凍結されてからの時間は ${value_shown} 秒で、${alarm_threshold} 秒を超えています。
  * サンプル：クラスタ：obcluster、テナント：T1、警報：OceanBaseテナントが長時間凍結されていない。最後に凍結されてからの時間は 130000 秒で、90000 秒を超えています。

* **警報の回復**

  * テンプレート：警報：${alarm_name}、OceanBaseテナントが最後に凍結されてからの間隔：\${recover_value}
  * サンプル：警報：OceanBaseテナントが長時間凍結されていない、OceanBaseテナントが最後に凍結されてからの間隔：8600 秒

## システムへの影響

長期間フリーズまたはマージを実行しない場合、ディスク容量が増加し、ディスクが満杯になって業務上の書き込みに影響を与えます。

## 考えられる原因

* 日次マージが無効になっているか、アップグレードモードのパラメータが有効になっています。
* Root Serviceが異常に一時停止しています。例：ノードが存在しない、またはプロセスが異常に一時停止しています。
