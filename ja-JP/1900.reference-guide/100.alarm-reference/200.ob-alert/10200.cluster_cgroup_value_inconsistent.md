# cluster_cgroup_value_inconsistent クラスタ内のcgroup値が一致しない

## アラートの概要

このアラートは、OceanBaseクラスタ内の各ノードのenable_cgroupパラメータ設定が一致しているかどうかを監視します。クラスタ内の異なるOBServerノード間でenable_cgroupパラメータの値が統一されていない場合にアラートがトリガーされます。

## アラートの仕組み

| パラメータ     | 値      |
| -------- | -------- |
| 監視指標 | cluster_cgroup_value |
| 監視式 | `max(cluster_cgroup_value{@LABELS}) by (@GBLABELS)` |
| 取得指標 | cluster_cgroup_value   |
| 指標ソース | OCPによる能動的な検出 |
| 取得周期 | 60秒 |

OCPは、定期タスクCheckClusterCgroupValueTaskを通じて、各OceanBaseクラスタのcgroup設定の一貫性をチェックします。具体的な仕組みは以下のとおりです：

1. OCPは、クラスタのバージョンがcgroup機能の最小バージョン要件を満たしているかどうかをチェックし、満たしていない場合はスキップします。

2. クラスタ内のすべてのノードのenable_cgroupパラメータ値を照会します。

3. 照会結果に対して重複除去（distinct）操作を行い、重複除去後の値の数を集計します。

4. 重複除去後の値の数が1と等しくない場合（つまり、各ノードのenable_cgroup値が完全に一致しない場合）、指標cluster_cgroup_valueを1（アラート状態）に設定します。そうでない場合は0（正常状態）に設定します。

指標値が1に等しい場合、トリガー条件を満たし、アラートが発生します。

## ルール情報

| 監視指標   | デフォルトしきい値 | 持続時間 | 検出周期 | 解消周期 |
| ---------- | ------- | -------- | -------- | -------- |
| cluster_cgroup_value  | 1 | 120秒 | 60秒 | 300秒 |

## アラート情報

| アラートトリガー方式 | アラートレベル | 対象範囲     |

## システムへの影響

クラスタ内のenable_cgroupパラメータ値が一致しないことは、一部のノードでcgroupリソース分離が有効になっており、一部のノードでは無効であることを意味し、以下の影響を及ぼす可能性があります：

* リソース分離の不統一：cgroupを有効にしたノードではテナントのCPU使用量を制限できますが、無効なノードではこの制限がないため、テナントの異なるノード上でのリソース使用動作が一致しません。cgroupを無効にしたノードでは、テナント間でCPUリソースの競合が発生し、ビジネスの安定性に影響を与える可能性があります。

* パフォーマンスの予測不能：同一テナントの異なるノード上でのパフォーマンスに差異が生じる可能性があり、運用保守におけるトラブルシューティングが困難になります。

## 考えられる原因

* 運用保守担当者が一部ノードのenable_cgroupパラメータを手動で変更したものの、クラスタ全体で一貫して変更していない。

* その他の未知の原因。

## 解決策

1. アラート情報の確認：アラートに記載されているクラスタ名（ob_cluster_name）に基づいて、該当するクラスタを特定します。

2. 現在のcgroup設定の確認：OCPコンソールで対応するクラスタの概要ページを開き、クラスタレベルのcgroup設定状態を確認します。SQLを使用して各ノードのパラメータ値を確認することもできます：

   ```sql
   SHOW PARAMETERS LIKE 'enable_cgroup';
   ```

   どのノードの値が一致しないかを確認します。

3. cgroup設定の統一：

   * 方法1（推奨）：OCPコンソールのクラスタパラメータ管理機能を使用して、すべてのノードのenable_cgroupパラメータを一括変更し、クラスタ内のすべてのノードの設定が一致するようにします。

   * 方法2：SQLコマンドを使用して、クラスタレベルでパラメータを一括設定します：

     ```sql
     ALTER SYSTEM SET enable_cgroup = 'True';
     ```

     または

     ```sql
     ALTER SYSTEM SET enable_cgroup = 'False';
     ```

4. クラスタ概要の更新：変更後、OCP上の対応するクラスタの概要ページを更新し、cgroup値が統一されていることを確認します。

5. 修復結果の検証：修復後、次の検出サイクル（60秒）を待ち、アラートが自動的に解消されるか観察します。設定が一致していれば、アラートは解消サイクル（300秒）内に自動的にクリアされます。
