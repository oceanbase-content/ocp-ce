# ob_host_task_timeout OBServerタスクのタイムアウト

## 警報の概要

OBServerノードでのタスク実行時間が3時間を超えた場合にこの警報がトリガーされます。タスクには以下が含まれます：

* DELETE_SERVER（task_type）：サーバー削除タスク。

## 警報の仕組み

| パラメータ | 値 |
| -------- | --------- |
| モニタリング指標 | ob_server_task_max_duration_seconds。この指標はOBServerノードでのタスク実行時間を示し、時間がしきい値を超えると警報がトリガーされます。 |
| モニタリング式 | ```max(ob_server_task_max_duration_seconds{@LABELS}) by (@GBLABELS)``` |
| 取得指標 | ob_server_task_max_duration_seconds |
| 指標の出典 | 内部ビューから取得。取得SQL：```SELECT job_type as task_type, TIMESTAMPDIFF(SECOND, START_TIME, CURRENT_TIMESTAMP) as max_sys_task_duration_seconds, svr_ip FROM DBA_OB_SERVER_JOBS WHERE job_status='INPROGRESS'``` |
| 取得間隔 | 5秒 |

## ルール情報

| モニタリング式 | デフォルトしきい値(秒) | 持続時間 | 検出周期 | 解消周期 |
| ---------- | ------------- | -------- | -------- | -------- |
| ob_server_task_max_duration_seconds | 10800 | 0秒 | 20秒 | 5分 |

## 警報情報

| 警報のトリガー方法 | 警報レベル | 対象範囲 |
| ------------ | -------- | ------ |
| モニタリング指標の式に基づく | 重大 | ホスト |

## 警報テンプレート

* **警報の概要**

  * テンプレート：\${alarm_target} \${alarm_name}
  * サンプル：alarm_template_id=0:ob_cluster=C1-1000:host=xxx.xxx.xxx.xxx OBServerタスクのタイムアウト

* **警報の詳細**

  * テンプレート：クラスタ：\${ob_cluster_name}、ホスト：\${host}（zone：\${obzone}）、警報：OBServerノードタスクのタイムアウト。タスクタイプ：\${task_type}、実行時間 \${value_shown}、しきい値 \${alarm_threshold} 秒を超えました。
  * サンプル：クラスタ：C1、ホスト：xxx.xxx.xxx.xxx（zone：Z1）、警報：OBServerノードタスクのタイムアウト。タスクタイプ：DELETE_SERVER、実行時間4時間、しきい値10800秒を超えました。

* **警報の回復**

  * テンプレート：警報：${alarm_name}、OBServerタスクの実行時間：\${value_shown}
  * 例：アラート：OBServerタスクがタイムアウトしました、OBServerタスクの実行時間：2時間

## システムへの影響

* タスクの実行時間が長すぎると、OceanBaseのタスク処理スケジューリングに影響を及ぼし、タスク処理のスループットが低下します。
* リソースを長時間占有したまま解放しないと、システムの安定性に影響します。

## 考えられる原因

一般的な原因はありません。

## 解決策

`observer.log.wf` のERRORエラーに注目し、関連情報を収集した後、技術サポートに連絡して調査を依頼してください。
