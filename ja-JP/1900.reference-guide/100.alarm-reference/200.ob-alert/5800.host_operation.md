# host_operation ホスト運用保守操作のリマインダー

## アラートの概要

OCPが管理するホストに対して運用保守タスクを実行すると、**<UI-TERM key="ocp-v2.src.constant.alarm.Reminder">注意</UI-TERM>** レベルのアラートが発報されます。アラートレベルは他のレベルに変更できます。

<main id="notice" type='explain'>
<h4>注意</h4>
OCPのページから開始されたホスト運用保守タスクのみがアラートを生成します。コマンドラインで直接実行した場合はアラートが発生しません。
</main>

運用保守タスクの一覧：

* ホストの追加
* OCP-Agentの再起動
* OCP-Agentの再インストール
* ホストの削除
* ホストの標準化

## アラートの仕組み

なし。

## アラートテンプレート

* アラートの概要

  * テンプレート：\${alarm_target} \${alarm_name}
  * サンプル：alarm_template_id=0:host=xxx.xxx.xxx.xxx:operation_name=Delete host SUCCESS

* アラートの詳細

  * テンプレート：サーバー：\${host}、アラート：\${operation_name} \${operation_result}、操作者 \${operator}、実行結果：\${task_result}。
  * サンプル：サーバー：xxx.xxx.xxx.xxx、アラート：Delete host SUCCESS、操作者 admin、実行結果：success。

## システムへの影響

システム障害は日常的な運用保守でよく発生します。運用保守後にシステムに異常が発生していないか注意深く観察し、具体的な状況に応じて分析する必要があります。

## 考えられる原因

一般的な原因はありません。

## 解決策

1. 運用保守後に異常が発生した場合は、テクニカルサポートに連絡し、解決を依頼してください。
2. 業務に重大な影響が生じた場合は、速やかに運用保守操作をロールバックしてください。
