# ob_tenant_exists_expired_xa_trans OceanBaseテナントにXA一時停止トランザクションが存在する

## アラートの説明

OceanBaseテナントに未処理のXAトランザクションが存在する場合、このアラートがトリガーされます。XAプロトコルは2段階コミットプロトコル（PrepareとCommitの2つの段階）を採用しており、XAトランザクションがPrepared状態にある時間が許容範囲のしきい値（アラートのしきい値、デフォルトで20分）を超えた場合、未処理のXAトランザクションが存在すると判断されます。現在、OracleテナントのみがXAトランザクションの未処理状態検出をサポートしています。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>未処理トランザクションとは、クライアントとOBProxy間の接続が切断された後も、OBProxyとOceanBase間の接続が長時間にわたってタイムアウトしないトランザクションを指します。</p>
  </main>

## システムへの影響

ステータスの保留されたトランザクションはMemTableのRefを保持し続けます。トランザクションが長時間終了しない場合、MemStoreがフリーズして解放できなくなり、メモリ不足を引き起こす可能性があります。さらに、ステータスの保留されたトランザクションは、システムの安定性に深刻な脅威をもたらします。例えば、clogディスクの満杯やシステムの書き込み停止などが発生する可能性があります。

## 考えられる原因

* パラメータ設定が不適切です。

  クエリタイムアウト時間（テナントパラメータob_query_timeout、デフォルト10秒）とトランザクションタイムアウト時間（テナントパラメータob_trx_timeout、デフォルト100秒）が設定されています。使用上の問題によりトランザクションが長時間終了せず、システムの安定性に影響を与えることを避けるため、適切に設定することを推奨します。

* デッドロックやロック競合が原因です。

## 対処方法

スペンディングトランザクションが発生した場合、まずはそのスペンディングトランザクションを終了させる必要があります。以下の方法を参考に終了させてください：

1. アラートが発生したテナントのxidを取得します。

   xidは主に3つの部分で構成されています：gtrid、bqual、format_idです。注意点として、gtridとbqualはバイナリ形式である可能性があり、文字情報では表示できないため、16進数に変換する必要があります。

   * システムテナントの場合、対象テナントIDを1003と仮定し、以下のステートメントを実行して、懸念されるスペンディングブランチのxidを取得します：

     ```sql
     SELECT hex(gtrid), hex(bqual), format_id
     FROM __all_virtual_global_transaction
     WHERE tenant_id = 1003
           AND format_id <> -2
           AND state = 3
           AND gmt_modified < date_sub(now(), INTERVAL 1800 SECOND);
     ```

   * 通常テナント（Oracleテナント）の場合、以下のクエリ方法を使用します：

     ```sql
     SELECT rawtohex(gtrid), rawtohex(bqual), format_id
     FROM sys.all_virtual_tenant_global_transaction_agent
     WHERE format_id <> -2
           AND state = 3
           AND ROUND((sysdate - cast(GMT_MODIFIED as date)) * 86400) > 1800;
     ```

2. 対応するテナントで以下のステートメントを実行し、xidに対応するトランザクションをロールバックします。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>以下のSQLステートメント内のl_xid.formatid、l_xid.gtrid、l_xid.bqualの値を、手順1で取得したIDに置き換えてください。</p>
   </main>

   ```sql
   declare
   l_xid DBMS_XA_XID;
   l_ret PLS_INTEGER;
   BEGIN
   l_xid.
   formatid
    := 123;
   l_xid.
   gtrid
    := hextoraw('616263313238');
   l_xid.
   bqual
    := hextoraw('656667');
   l_ret := DBMS_XA.XA_ROLLBACK(xid => l_xid);
   dbms_output.put_line(l_ret);
   END;
   /
   ```
