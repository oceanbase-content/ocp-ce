# OceanBaseクラスタのトラフィックを制限する

このセクションでは、OceanBaseクラスタのトラフィックを制限する方法について説明します。OceanBaseクラスタの業務トラフィックは主にテナントが実行するSQLによって発生するため、SQLの実行速度を制限することでOceanBaseクラスタのトラフィックを制限できます。

## 背景

OceanBaseクラスタの業務トラフィックは主にテナントが実行するSQLによって発生します。SQLの処理速度が速すぎると、以下の問題が発生します：

* アクティブメモリがフラッシュされる間もなくなります。

* 書き込み型のSQLが高速に処理されると、一時的なメモリ負荷が高くなります。

SQLの並列実行数を制限することで、SQLの処理速度を低下させ、OceanBaseクラスタのトラフィックを制限することができます。これにより、リソース不足や業務トラフィックが多い場合に上記の問題を回避できます。

## 手順

1. 当該OceanBaseクラスタで実行頻度の高いSQLを特定します。

   1. OCPにログインします。

   2. **<UI-TERM key="ocp-v2.component.alarm.Search.Tenant">テナント</UI-TERM>**画面の**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**から当該クラスタのテナントを見つけ、テナント名をクリックします。

      システムはデフォルトで**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>**ページに移動します。

   3. **<UI-TERM key="ocp-v2.page.Iframe.SqlDiagnosis">SQL 診断</UI-TERM>**を選択し、次に**TopSQL**タブを選択します。

   4. 業務状況に応じてカスタム時間を設定した後、実行回数の多いSQLテキストを見つけ、それらのテキストとSQLテキストのIDを記録します。

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>記録したテキストは実行並列数が制限されます。具体的にどのような高実行頻度のSQLテキストを制限するかは、業務に応じてご自身で判断する必要があります。例えば以下のようなシナリオが考えられます：</p>
     <ul>
     <li>業務において書き込みがクエリより重要である場合、高頻度でクエリを実行するSQLの並列数を制限することを推奨します。</li>
     <li>書き込み処理によりメモリ負荷が高くなる場合、高頻度で書き込みを行うSQLの並列数を制限することを推奨します。</li>
     </ul>
     </main>

2. これらのSQLに対して並列実行制限のHintを追加します。

   1. 当該SQLが実行されるデータベースにログインします。

   2. これらのSQLテキストにHINTインデックス**`/*+max_concurrent(1)*/`**を追加します。このインデックスにより、このSQLテキストの並列数が1に制限され、結果としてSQLの実行速度が制限されます。[プランのバインド](https://www.oceanbase.com/docs/common-oceanbase-database-cn-1000000002016227)や以下のステートメントを参考にしてトラフィックを制限できます。

      ```javascript
      #otl_idxはインデックス名であり、カスタマイズが必要です。SQLIDはSQLテキストのIDです。
      CREATE OUTLINE otl_idx_c2 ON "SQLID"
           USING HINT
      /*+max_concurrent(1)*/
       ;
      #例：
      create outline  otl_name  on "ED570339F2C856BA96008A29EDF04C74" using hint
      /*+max_concurrent(1)*/
      ;
      ```

      上記のステートメントにより、IDが "ED570339F2C856BA96008A29EDF04C74" のSQLテキストの単一OBServerノード上での実行並列数は1に制限されます。

   3. ステップ1で記録した各SQLテキストに対し、2.a ～ 2.b の手順で並列数の制限を順次追加します。
