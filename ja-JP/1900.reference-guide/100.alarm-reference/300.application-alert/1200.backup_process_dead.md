# backup_process_dead バックアップ・リストアサービスがオフラインになりました

## アラートの概要

このアラートは、バックアップ・リストアサービスがオフラインになっていないかどうかを監視します。バックアップ・リストアコンポーネントのプロセスが停止した場合にアラートが報告されます。

## アラートの仕組み

OCP-ServerはAgentを通じて以下のコマンドを実行し、バックアップサービスとリストアサービスがオフラインになっていないかどうかを個別に検出します。

```shell
cd /home/admin/oceanbase && bash ./bin/agent.sh exist_restore
cd /home/admin/oceanbase && bash ./bin/agent.sh exist_backup
```

戻り値が1の場合はサービスがオンラインであることを示し、それ以外の場合はサービスがオフラインであることを示します。オフラインの場合、アラートがトリガーされます。

## アラートテンプレート

* **アラートの概要**

  * テンプレート: \${alarm_target} \${alarm_name}
  * 例: alarm_template_id=0:host=xxx.xxx.xxx.xxx バックアップ・リストアサービスがオフラインになりました

* **アラートの詳細**

  * テンプレート: ホスト：\${host}、アラート：バックアップ・リストアプロセス ${agent_type} がオフラインです。確認してください！
  * 例: ホスト：xxx.xxx.xxx.xxx、アラート：バックアップ・リストアプロセス backup-1 がオフラインです。確認してください！

## システムへの影響

このサービスに対応するクラスタのバックアップができなくなります。

## 考えられる原因

コンポーネントの異常動作または設定ミス。

## 対処方法

具体的な原因については、コンポーネントのログを確認して異常の原因を特定してください。

コンポーネントのログは、バックアップ・リストアサービスが稼働しているサーバーの `/home/admin/oceanbase/log` ディレクトリにあり、agentserver.log と agentrestore.log が含まれます。
