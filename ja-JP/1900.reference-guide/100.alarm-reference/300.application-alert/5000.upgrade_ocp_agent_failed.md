# upgrade_ocp_agent_failed OCP-Agentのアップグレード失敗

## アラートの概要

OCPをアップグレードする際には、OCP-Agentのバージョンもアップグレードする必要があります。OCP-Agentのアップグレードに失敗した場合、このアラートが生成されます。

## アラートの仕組み

なし。

## システムへの影響

OCP-Agentは、OCPが管理するホスト上にデプロイされるプロセスであり、管理（運用）プロセスと監視プロセスに分かれています。OCP-Agentのアップグレードに失敗し、OCP-AgentのバージョンとOCP-Serverのバージョンが一致しない場合、以下の問題が発生します：

1. 運用手順を実行できません。例えば、OB、OBProxy、ホストなどの日常的な運用手順です。
2. 新バージョンの監視データを収集できません。

## 考えられる原因

アップグレード失敗の原因は多岐にわたり、一般的な原因はありません。具体的な状況を分析する必要があります。

アップグレードに失敗した場合は、当直担当者までお問い合わせください。
