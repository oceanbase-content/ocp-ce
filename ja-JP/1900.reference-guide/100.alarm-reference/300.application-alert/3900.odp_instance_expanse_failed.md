# odp_instance_expanse_failed OBProxyインスタンスの拡張失敗

## アラートの概要

OBProxyコンソールログ（OBShardingモード）を監視し、拡張失敗が発生した場合にこのアラートがトリガーされます。

## アラートの仕組み

| パラメータ | 値 |
|------|------|
| 監視指標 | instance_expanse_failed_count。この指標はOBProxyインスタンスの拡張失敗の有無を示します。パラメータ値が0より大きい場合にアラートがトリガーされます。    |
| 監視式 | なし。  |
| 取得指標 | なし。  |
| 指標の出典 | OBProxyコンソールログを監視し、拡張失敗回数を集計します。ログキーワード：`create instance unit is failed`。 |
| 取得サイクル | 5秒 |

## ルール情報

| 監視指標   | デフォルトしきい値 | 持続時間 | 検出サイクル | 解消サイクル |
|------------|----------|---------|----------|----------|
| instance_expanse_failed_count | 0 | 0秒 | 60秒 | 5分 |

## アラート情報

| アラートトリガー方法 | アラートレベル | 対象範囲 |
|--------------|---------|-------|
| ログ解析に基づく | 重大 | サービス |

## アラートテンプレート

* **アラートの概要**

  * テンプレート：${alarm_target} ${alarm_name}
  * サンプル：alarm_template_id=0:obproxy_cluster=obproxy_ocp:host=xxx.xxx.xxx.xxx OBProxyインスタンスの拡張失敗

* **アラートの詳細**

  * テンプレート：OBProxyインスタンス：${obproxy_cluster}、デプロイメントユニット：${host}、アラート：インスタンス内のデプロイメントユニット拡張失敗。
  * サンプル：OBProxyインスタンス：obproxy_ocp、デプロイメントユニット：xxx.xxx.xxx.xxx、アラート：インスタンス内のデプロイメントユニット拡張失敗。

* **アラートの回復**

  * テンプレート：アラート：${alarm_name}、OBProxyインスタンス拡張失敗回数：\${recover_value}
  * サンプル：アラート：OBProxyインスタンス拡張失敗、OBProxyインスタンス拡張失敗回数：0

## システムへの影響

OBProxyのスケールアウト失敗により、スケールアウトの目的を達成できませんでした。影響範囲は詳細な分析が必要です。

## 考えられる原因

一般的な原因はありません。

## 解決策

OBProxyコンソールのログを収集し、テクニカルサポートに連絡して調査を依頼します。
