# ob_host_monitordb_disconnected OCP-Agentがmonitordbに接続できない

## アラートの概要

OCP-Agentは、診断データを直接monitordb（OCPの監視データベース）に書き込みます。診断データはサービス診断に使用されるデータであり、データ量が多いため、テーブルに直接書き込む方がパフォーマンスに優れています。OCP-Agentがmonitordbに接続できない場合、このアラートが発生します。

## アラートの仕組み

| パラメータ    | 値      |
| ------- | ------- |
| 監視指標 | monitordb_connectable。この指標は、OCP-Agentがmonitordbに接続できるかどうかを示します。指標値が`1`の場合は正常に接続できることを意味し、指標値が`0`の場合は接続できず、アラートがトリガーされます。  |
| 監視式 | ```min(oceanbase_connectivity{target="monitordb",@LABELS}) by (@GBLABELS)```  |
| 収集指標 | oceanbase_connectivity |
| 指標の出典 | OCP-Agentの設定ファイル内の接続文字列に従ってmonitordbに接続し、`select 1`を実行してmonitordbに接続できるかどうかを確認します。 |
| 収集間隔 | 5秒 |

## ルール情報

| 監視指標  | デフォルトしきい値 | 持続時間  | 検出周期 | 解消周期 |
| --------- | -------- | -------- | -------- | -------- |
| monitordb_connectable | 0 | 30秒 | 10秒 | 5分 |

## アラート情報

| アラートのトリガー方法 | アラートレベル | 対象範囲 |
| ------------ | ------- | ------ |
| 監視指標の式に基づく | 重大 | ホスト |

## アラートテンプレート

* **アラートの概要**

  * テンプレート：${alarm_target} ${alarm_name}
  * サンプル：alarm_template_id=0:ob_cluster=Test-1:host=xxx.xxx.xxx.xxx OCP-Agentがmonitordbに接続できない

* **アラートの詳細**

  * テンプレート：クラスタ：${ob_cluster_name}、ホスト：${host}、アラート：${alarm_name}。
  * サンプル：クラスタ：Test、ホスト：xxx.xxx.xxx.xxx、アラート：OCP-Agentがmonitordbに接続できない。

* **アラートの回復**

  * テンプレート：アラート：${alarm_name}、OCP monitordb接続状態：\${recover_value}
  * サンプル：アラート：OCP-Agentがmonitordbに接続できない、OCP monitordb接続状態：1

## システムへの影響

OCP-Agentがmonitordbに接続する目的は、SQL監査、プランキャッシュ、トランザクションなど、診断サービスが依存する診断データを直接書き込むことです。OCP-Agentがmonitordbに接続できない場合、診断データを取得できず、診断サービスに影響が及び、システムに問題が発生した際に根本原因を特定できない可能性があります。

## 考えられる原因

* OCP-Agentが受信したアカウントとパスワードが間違っており、monitordbにアクセスできません。
* OCP-Agentからmonitordbへのネットワークが切断されています。例：iptablesによるネットワーク制限が設定されている場合。

## 解決策

OCP-Agentが稼働しているホスト上で、OCPのmonitordbに接続し、アクセスできるか確認します。次のような原因が考えられます：

* アカウントとパスワードが間違っています

  `ERROR 1045 (42000): Access denied for user 'root'@'xxx.xxx.xxx.xxx' (using password: YES)` エラーが表示されます。この場合、指定されたアカウントとパスワードが正しいか確認する必要があります。

  アカウントとパスワードが誤っている場合、CLIを使用して以下のSQLステートメントを実行し、`config_properties` テーブル内の関連システムパラメータを変更できます。値にはシングルクォートを使用する必要があります：

  ```sql
  update config_properties set value='' where `key`=''
  ```

  関連するシステムパラメータは以下のとおりです：

  * `ocp.monitordb.host`
  * `ocp.monitordb.port`
  * `ocp.monitordb.database`
  * `ocp.monitordb.username`
  * `ocp.monitordb.password`

* ネットワークが切断されています

  対応するドメイン名にアクセスできない、またはコマンド実行後に結果が得られずに停止する場合があります。この場合、iptablesルールを確認するなど、ネットワークの原因を調査し、ネットワークが正常に接続されていることを確認する必要があります。
