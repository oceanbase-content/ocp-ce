# host_agent_version_not_same ホストのOCP-Agentバージョンが期待バージョンと一致しない

## アラートの概要

OCP Dockerコンテナには、現在のOCPバージョンに対応するOCP-AgentのRPMパッケージが組み込まれています。OCPをデプロイする際、管理対象のホストにインストールされているOCP-Agentのバージョンは、組み込みバージョンと一致している必要があります。バージョンが一致しない場合、このアラートが発生します。
OCPのバージョン番号は3つの数字で構成されており、例えば4.2.1のようになります。さらに、バージョン番号の後には8文字のビルド番号が付加されます。デフォルトでは3つの数字のバージョン番号のみがチェックされます。8文字のビルド番号もチェックするには、`ocp.build.version.check`設定をtrueに変更する必要があります。

## アラートの仕組み

なし。

* **アラートの詳細**

  * サンプル：クラスタ：Test、ホスト：xxx.xxx.xxx.xxx、アラート：ホストのOCP-Agentバージョンが期待バージョンと一致しない。期待されるOCP-Agentバージョン：4.2.1-20230928、ホストのOCP-Agentバージョン：4.2.0-20230921。

## システムへの影響

OCP-Agentは、OCPが管理するホスト上にデプロイされるプロセスであり、管理（運用）プロセスと監視プロセスに分かれています。OCP-AgentのバージョンがOCP-Serverのバージョンと一致しない場合、以下の問題が発生します：

1. 運用作業が実行できなくなります。運用作業とは、OB、OBProxy、ホストなどの日常的な運用タスクを指します。
2. 新バージョンの監視データを収集できなくなります。

## 考えられる原因

* OCP-Agentのアップグレードに失敗しました。OCP-Agentが何らかの理由でアップグレードに失敗し、OCP-Serverは正常にアップグレードされました。
* ホストにインストールされているOCP-Agentのバージョンが低い。

## 解決策

OCP-Serverと同じバージョンのOCP-Agentをインストールする必要があります。BPのバージョンが異なる場合でも、同じバージョンへのアップグレードを推奨します。OCP-Serverで組み込みバージョンを選択し、OCP-Agentを再インストールするだけで済みます。
