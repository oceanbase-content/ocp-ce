# ob_license_expired OBライセンスの有効期限切れ

## アラートの概要

<main id="notice" type='explain'>
<h4>説明</h4>
このアラートは、単一マシンにのみ適用されます。
</main>

現在、OCPが管理するOceanBaseの単一マシンでライセンスの有効期限が切れている状況を検出します。

## アラートの仕組み

| パラメータ | 値 |
|------------|-------|
| モニタリング指標 | ob_license_expired_second_duration。この指標はOceanBaseライセンスの有効期限を表し、異なる指標値によって異なるレベルのアラートがトリガーされます。  |
| モニタリング式 | ```min(ob_license_expired_second_duration{@LABELS}) by (@GBLABELS)```  |
| 取得指標 | ob_license_expired_second_duration |
| 指標ソース | 単一マシンのライセンス有効期限が現在時刻からどの程度離れているかを検出し、アラート要件と照合します。   |
| 取得サイクル | 5秒 |

## ルール情報

| モニタリング式 | デフォルトしきい値 | 持続時間 | 検出サイクル | 解消サイクル |
|------------|---------|----------|----------|----------|
| ob_license_expired_second_duration | この指標には3つのデフォルトしきい値があります：<li>ob_license_expired_second_duration == 0</li><li>ob_license_expired_second_duration > 0 and ob_license_expired_second_duration < 2592000</li><li>ob_license_expired_second_duration >= 2592000 and ob_license_expired_second_duration < 5184000</li> | 0秒 | 60秒 | 7200秒 |

## アラート情報

| アラートトリガー方式 | アラートレベル | 対象範囲 |
|--------------|---------|----------|
| モニタリング指標の式に基づく | <li>ob_license_expired_second_duration == 0：サービス停止</li><li>ob_license_expired_second_duration > 0 and ob_license_expired_second_duration < 2592000：重大</li><li>ob_license_expired_second_duration >= 2592000 and ob_license_expired_second_duration < 5184000：警告</li> | サービス |

## アラートテンプレート

* **アラート概要**

  * テンプレート：${alarm_target} ${alarm_name}
  * サンプル：expired_time=2025-10-10 OBライセンスの有効期限切れ

* **アラート詳細**

  * テンプレート：OceanBase単一マシン版クラスタID ${ob_cluster_id}、ライセンスが有効期限切れまたは間もなく切れます。有効期限は ${expired_time} です。サービス中断を避けるため、速やかに単一マシン版ライセンスを更新してください。
  * サンプル：OceanBase単一マシン版クラスタID 10003、ライセンスが有効期限切れまたは間もなく切れます。有効期限は 2025-10-10 です。サービス中断を避けるため、速やかに単一マシン版ライセンスを更新してください。

## システムへの影響

単一マシンのライセンスが期限切れになると、クラスタは停止状態となり、通常のサービスを提供できなくなります。

## 考えられる原因

単一マシンのライセンスが期限切れになっているか、期限切れの60日前にあたります。

## 解決策

新しいライセンスを申請し、[ライセンスのインポート](../../../600.cluster-functions/300.manage-a-cluster/1400.import-license.md) を参照して再度インポートします。OCPはライセンスの有効期限などの情報を自動的に更新します。
