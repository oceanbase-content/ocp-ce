# ssl_certificate_is_expired SSL証明書期限切れアラート

## アラートの概要

<main id="notice" type='explain'>
<h4>説明</h4>
このアラートは、V4.0.0.0以降のOceanBaseクラスタでのみ有効です。
</main>

ユーザーが**証書管理**でアップロードしたSSL証明書が期限切れになると、このアラートが発報され、ユーザーに証明書の更新を促します。

## アラートの仕組み

次の表は、このアラートの監視ロジックに関連する主要パラメータを示しています。

| パラメータ | 値 |
| -------- | ---------- |
| 監視指標 | ssl_certificate_expired_status。この指標はSSL証明書が期限切れかどうかを示します。指標値が`0`の場合、証明書ファイルが期限切れではないことを意味します。指標値が`1`の場合、証明書ファイルが期限切れであり、アラートがトリガーされます。   |
| 監視式 | ```max(ssl_certificate_expired_status{@LABELS}) by (@GBLABELS)``` |
| 取得指標 | ssl_certificate_expired_status |
| データソース | OCP-Serverが定期的に期限切れ証明書の有無を照会します。 |
| 取得サイクル | 5秒 |

## ルール情報

| 監視指標 | デフォルトしきい値 | 持続時間 | 検出サイクル | 解消サイクル |
| -------- | -------- | -------- | ------- | -------- |
| ssl_certificate_expired_status | 0 | 0秒 | 60秒 | 5分 |

## アラート情報

| アラートトリガー方法 | アラートレベル | 対象範囲 |
| ------------- | ---------- | --------- |
| 監視指標の式に基づく | サービス停止 | サービス |

## アラートテンプレート

* **アラート概要**

  * テンプレート：\${alarm_target} \${alarm_name}
  * サンプル：alarm_template_id=0:certificate_group=real_chain:certificate_file=ca_chain.pem:expired_time=1970-01-01T08:02:01+08:00 SSL証明書期限切れアラート

* **アラート詳細**

  * テンプレート：SSL証明書グループ\${certificate_group}内の証明書ファイル\${certificate_file}が期限切れになりました。期限は\${expired_time}です。速やかに証明書を更新し、ネットワーク接続が確立できず業務が停止するのを防いでください。
  * 例：SSL証明書グループreal_chain内の証明書ファイルca_chain.pemが期限切れになりました。期限日は1970-01-01T08:02:01+08:00です。ネットワーク接続が確立できずサービスが停止するのを防ぐため、速やかに証明書を更新してください。

* **アラートの復旧**

  * テンプレート：アラート：${alarm_name}、SSL証明書の有効期限状態：\${recover_value}
  * 例：アラート：SSL証明書期限切れアラート、SSL証明書の有効期限状態：0

## システムへの影響

SSL証明書が期限切れになると、そのSSL証明書を使用しているOceanBaseクラスタやOBProxyクラスタがSQLおよびRPC接続を確立できなくなり、サービスが停止する可能性があります。

## 考えられる原因

SSL証明書が期限切れになりました。

## 解決策

1. CA証明書を再発行してサーバー証明書を取得します。
2. OCPで[証明書をアップロードします](../../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md).
3. OceanBaseクラスタの[SSLリンク暗号化の管理](../../../600.cluster-functions/1200.manage-security-configuration/100.manage-ssl-link-encryption-of-an-ob-cluster.md)およびOBProxyクラスタの[SSLリンク暗号化の管理](../../../800.obproxy-functions/550.manage-ssl-link-encryption-of-an-obproxy-cluster.md)を参照し、期限切れの証明書を使用しているOceanBaseクラスタやOBProxyクラスタの証明書を更新します。
