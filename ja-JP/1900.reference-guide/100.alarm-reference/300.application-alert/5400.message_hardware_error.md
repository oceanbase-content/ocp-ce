# message_hardware_error ホストのハードウェア障害

## アラートの概要

ホストのメモリハードウェアに障害が発生し、「Hardware Error」というログが出力された場合、このアラートがトリガーされます。

## アラートの仕組み

ホスト上の `/var/log/messages` ファイル内のキーワード「Hardware Error」と一致する場合、アラートがトリガーされます。

## ルール情報

| モニタリング指標 | デフォルトしきい値 | 持続時間 | 検出サイクル | 解消サイクル |
| -------- | ------- | -------- | -------- | -------- |
| NA       | NA      | 0秒     | NA       | 5分 |

## アラート情報

| アラートのトリガー方法 | アラートレベル  | 対象範囲    |
| ------------ | -------- | -------- |
| ログ解析     | 極めて重要     | ホスト   |

## アラートテンプレート

* **アラートの概要**

  * テンプレート：${alarm_target} ${alarm_name}
  * サンプル：alarm_template_id=0:ob_cluster=obcluster-10006:host=xx.xx.xx.xx:server_type=kern:error_code=-1:keyword=Hardware Error システム message ログ

* **アラートの詳細**

  * テンプレート：[\${alarm_name}] クラスタ：\${ob_cluster_name}、ホスト：\${host}、ログタイプ：\${server_type}、ログファイル：\${filename}、ログレベル：\${log_level}、キーワード=\${keyword}、エラーコード=\${error_code}、ログの詳細=\${error_message}。
  * サンプル：[システム message ログ] クラスタ：danxue_422、ホスト：xx.xx.xx.xx、ログタイプ：kern、ログファイル：/var/log/messages、ログレベル：ERROR、キーワード=Hardware Error、エラーコード=-1、ログの詳細=Mar 21 18:07:34 sqaappecsv62s2011162217016.sa128 su[267465]: [Hardware Error] pam_unix(su:session): session closed for user root。

ここで：

* ${alarm_name}：アラート名を表します。例：OceanBaseログアラート。
* ${ob_cluster_name}：アラートが発生したクラスタ名を表します。
* ${host}：アラートが発生したサーバーのIPまたはホスト名を表します。
* ${server_type}：ログのタイプを表します。
* ${filename}：ログファイル。
* ${log_level}：ログレベル。
* ${keyword}：キーワード。
* ${error_code}：エラーコード。
* ${error_message}：ログの詳細。

## システムへの影響

プロセスがこの不良メモリを使用すると、コアダンプが発生します。

## 考えられる原因

ホストメモリに修復可能なエラーが存在します。

## 解決策

できるだけ早くメモリを交換することを推奨します。
