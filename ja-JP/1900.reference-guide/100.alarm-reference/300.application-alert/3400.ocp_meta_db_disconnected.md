# ocp_meta_db_disconnected OCPメタデータベース接続切断

## アラートの概要

OCP monitor DBに3分間接続できない場合、接続切断検出アラートが発生します。

## アラートの仕組み

| パラメータ | 値 |
|------|------|
| モニタリング指標 | ocp_meta_db_health。この指標はOCPメタデータベースへの接続可能性を示し、指標値が`1`の場合は接続可能、指標値が`0`の場合は接続失敗となりアラートがトリガーされます。 |
| モニタリング式 | ```ocp_meta_db_health{@LABELS}``` |
| 取得指標 | ocp_meta_db_health   |
| 指標ソース | OCP Server内の計測処理で取得したデータ。 |
| 取得サイクル | 5秒|

## ルール情報

| モニタリング指標 | デフォルトしきい値 | 継続時間 | 検出サイクル | 解消サイクル |
|----------|---------|----------|----------|----------|
| ocp_meta_db_health | 0 | 60秒 | 15秒 | 5分 |

## アラート情報

| アラートトリガー方法 | アラートレベル | 対象範囲 |
| ------------ | -------- | ------ |
| モニタリング指標の式に基づく | サービス停止 | サービス |

## アラートテンプレート

* **アラート概要**

  * テンプレート：${alarm_target} ${alarm_name}
  * サンプル：alarm_template_id=0:db=monitor OCPメタデータベース接続切断

* **アラート詳細**

  * テンプレート：[${alarm_name}] OCP ${db} データベースへの接続が切断されました。
  * サンプル：[OCPメタデータベース接続切断] OCP monitorデータベースへの接続が切断されました。

* **アラート回復**

  * テンプレート：アラート：${alarm_name}、OCP meta DB健康状態：\${recover_value}
  * サンプル：アラート：OCPメタデータベース接続切断、OCP meta DB健康状態：1

## システムへの影響

継続的な接続切断は、OCPの機能異常を引き起こし、OCPが動作しなくなる可能性があります。また、OCP monitor DBの監視データが失われます。

## 考えられる原因

* ネットワークが不安定です。
* monitor DBサービスに異常が発生しています。

## 解決策

1. 手動で接続してみて、接続切断が再現するか確認してください。

2. 接続が頻繁に切断される場合は、monitor DBの状態やネットワーク環境を確認してください。

3. monitor DBを再起動してみてください。それでも解決しない場合は、ログを確認し、管理者に連絡して調査を依頼してください。
