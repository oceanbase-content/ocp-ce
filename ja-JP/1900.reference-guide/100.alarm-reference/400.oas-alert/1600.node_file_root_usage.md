# node_file_root_usage サーバーのルートディレクトリ使用率が高すぎる

## アラートの説明

ホストのルートディレクトリ使用率が95%を超えた場合にこのアラートがトリガーされます。

## アラートの仕組み

| パラメータ | 値 |
| --- | --- |
| モニタリング指標 | root_disk_usage |
| 指標の出典 | ホストの基本モニタリング、node_exporterから収集</br>`df -B1` を実行すると、各ディレクトリのディスク使用率を確認できます |
| 収集指標 | node_filesystem_avail_bytes, node_filesystem_size_bytes |
| モニタリング式 | 100 *(1 - avg(node_filesystem_avail_bytes{mountpoint="/",@LABELS}) by (@GBLABELS) / avg(node_filesystem_size_bytes{mountpoint="/",@LABELS}) by (@GBLABELS)) |
| 収集サイクル | 1秒 |

## ルール情報

| モニタリング指標 | デフォルトしきい値(パーセンテージ) | 持続時間 | 検出サイクル | 解消サイクル |
| --- | --- | --- | --- | --- |
| root_disk_usage | 95 | 0秒 | 10秒 | 5分 |

## アラート情報

| アラートのトリガー方法 | アラートレベル | 対象範囲 |
| --- | --- | --- |
| モニタリング指標の式に基づく | 重大 | ホスト |

## システムへの影響

ルートディレクトリには通常ファイルを配置せず、システムが組み込むディレクトリ（例：`/bin`、`/etc`、`/tmp`、`/var`など）のみを配置します。ルートディレクトリが満杯になると、システムの正常な動作に影響を与える可能性があります。

### 考えられる原因

* ルートディレクトリのパーティションが小さすぎる。
* ログファイルが占有する容量が大きすぎる。
* ゾンビプロセスが占有するディスク領域が解放されていない。

## 解決策

1. ルートディレクトリの使用状況を確認し、パーティションが小さすぎることが原因かどうかを確認します。

   ```yaml
   df -h
   ```

2. ファイルの容量使用状況を確認し、無効なファイルを削除します。

   ```yaml
   ## 対象ディレクトリに移動
   cd /target-path
   ## ディレクトリサイズの確認
   du -h -x --max-depth=1
   ## 無効なファイルの削除
   rm -rf invalid-files
   ```

3. ゾンビプロセスがディスク領域を占有していないか確認します。

   ```yaml
   ## ゾンビプロセスの有無を確認
   lsof | grep deleted
   ## ゾンビプロセスの削除
   lsof | grep deleted | awk '{print $2}' | xargs kill -9
   ```
