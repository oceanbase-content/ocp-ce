# OCPクラスタの災害復旧フェイルオーバー

このページでは、OCPのスタンバイクラスタをディザスタリカバリフェイルオーバーによりプライマリクラスタに切り替える操作について説明します。プライマリクラスタが接続不能な場合、ディザスタリカバリフェイルオーバーによりスタンバイクラスタをプライマリクラスタに切り替えることができます。Failover操作実行後、対応するスタンバイクラスタのロールはPRIMARYに変わり、元のプライマリクラスタとの関連性はなくなります。マルチクラスタモードが必要な場合は、新たにプライマリ/スタンバイのOCPクラスタを構築する必要があります。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能を提供していません。</p>
</main>

## 背景

OCPのプライマリ/スタンバイクラスタ間のネットワーク接続に障害が発生した場合、実際のビジネスシナリオに応じてスタンバイクラスタを選択し、ディザスタリカバリフェイルオーバーによりスタンバイクラスタをプライマリクラスタに切り替えることができます。ディザスタリカバリフェイルオーバー完了後、そのスタンバイクラスタは正常に接続可能なすべてのOCPクラスタのプライマリクラスタとなります。ディザスタリカバリフェイルオーバーの具体的なシナリオについては、[マルチクラスタモードの概要](../300.ocp-multi-cluster-mode/100.overview-of-multi-cluster-mode.md)を参照してください。

## 前提条件

* 現在OCPにログインしているユーザーが**ADMIN**ロールであることを確認してください。
* ディザスタリカバリフェイルオーバーを実行する際、すべてのOCPスタンバイクラスタが正常であることを確認してください。

## 手順

1. OCPクラウドプラットフォームにログインします。

2. 左側のナビゲーションバーで**システム管理\>OCPマルチクラスタモード**をクリックします。

3. **<UI-TERM key="ocp-v2.page.MultiCluster.MasterSlaveDetails">プライマリ/スタンバイの詳細</UI-TERM>**タブの**現在のOCP基本情報**欄で、**<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchToPrimaryOcp">メインOCPに切り替える</UI-TERM>**をクリックします。

   ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5895772261/p280268.png)

4. **<UI-TERM key="ocp-v2.Detail.Component.FailoverDrawer.DisasterRecoverySwitch">フェイルオーバー</UI-TERM>**をクリックします。

   ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5895772261/p280272.png)

5. 切り替え後は**<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>**で進捗状況を確認できます。詳細については、[タスク管理](../../1600.system-management-features/600.manage-tasks.md)を参照してください。

## 次のステップ

ディザスタリカバリフェイルオーバー後のプライマリクラスタリストには、以下の2つのケースが存在します：

1. 元のOCPプライマリクラスタはこの時点でハートビートタイムアウトのスタンバイクラスタとなり、元のOCPプライマリクラスタ情報を手動で削除する必要があります。詳細については、[OCPクラスタの削除](../300.ocp-multi-cluster-mode/700.delete-an-ocp-cluster.md)を参照してください。

2. 元のOCPプライマリクラスタがディザスタリカバリフェイルオーバー後に正常に稼働を回復した場合、まず元のOCPプライマリクラスタ内から他のOCPクラスタを削除する必要があります。次に、そのOCPクラスタのロールをFOLLOWERに変更し、登録プロセスを経て新しいOCPプライマリクラスタに登録します。詳細については、[OCPクラスタの削除](../300.ocp-multi-cluster-mode/700.delete-an-ocp-cluster.md)および[OCPクラスタの登録](../300.ocp-multi-cluster-mode/200.register-an-ocp-cluster.md)を参照してください。
