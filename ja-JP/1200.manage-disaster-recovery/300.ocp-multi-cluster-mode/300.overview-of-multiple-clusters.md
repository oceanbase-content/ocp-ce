# プライマリ/スタンバイ詳細ページの説明

このセクションでは、マルチクラスタモードで各OCPの情報と相互関係を確認する方法について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能を提供していません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが**ADMIN**ロールであることを確認してください。
* 現在ログインしているOCPでマルチクラスタモードが有効になっていることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\> OCPマルチクラスタモード** をクリックします。

3. **<UI-TERM key="ocp-v2.page.MultiCluster.MasterSlaveDetails">プライマリ/スタンバイの詳細</UI-TERM>** タブをクリックします。

   この画面は **<UI-TERM key="ocp-v2.MultiCluster.Detail.BasicOcpInformation">現在のOCP基本情報</UI-TERM>** と **<UI-TERM key="ocp-v2.MultiCluster.Detail.ActiveStandbyList">プライマリ/スタンバイリスト</UI-TERM>** の2部分で構成されています。
   * **<UI-TERM key="ocp-v2.MultiCluster.Detail.BasicOcpInformation">現在のOCP基本情報</UI-TERM>**

     現在のOCPの基本情報を表示します。現在のOCPの状態、ロール、バージョン、ハートビート、同期、アクセスアドレスなどの情報が含まれます。また、そのOCPに関連する操作エントリも提供されます。
     * **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Version">バージョン</UI-TERM>** ：このOCPのバージョンがプライマリOCPのバージョンと一致しない場合、**！** のアラートが表示されます。

     * **<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchToPrimaryOcp">メインOCPに切り替える</UI-TERM>** ：このエントリは、現在のOCPがスタンバイOCPの場合にのみ表示されます。

     * **<UI-TERM key="ocp-v2.MultiCluster.Detail.DisassociateTheActiveStandbyRelationship">プライマリ/スタンバイ関係の解除</UI-TERM>** ：このエントリは、現在のOCPがスタンバイOCPの場合にのみ表示されます。

   * **<UI-TERM key="ocp-v2.MultiCluster.Detail.ActiveStandbyList">プライマリ/スタンバイリスト</UI-TERM>**

     現在のクラスタ内のすべてのOCPとその基本情報を表示します。ロール、バージョン、状態、アクセスアドレスなどの情報が含まれます。また、これらのOCPを操作するためのエントリも提供されます。
     * **<UI-TERM key="ocp-v2.Cluster.Arbitration.Version">バージョン</UI-TERM>** ：このOCPのバージョンがプライマリOCPのバージョンと一致しない場合、**！** のアラートが表示されます。

     * **<UI-TERM key="ocp-v2.page.Tags.TagList.Delete">削除</UI-TERM>** ：スタンバイOCPのハートビートが異常な場合にのみ、プライマリOCP環境に表示されます。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>プライマリ/スタンバイリストが全く表示されない場合：プライマリ/スタンバイリストのデータはプライマリOCPのMetaDBから取得されます。クラスタ内にプライマリOCPが存在しない場合、プライマリ/スタンバイリストはデータソースを失うため、表示されません。これは、<a href="500.switch-an-ocp-cluster-in-daily-maintenance.md">日常的なOCPクラスタの切り替え</a>や<a href="600.switch-an-ocp-cluster-in-a-failover.md">災害復旧時のOCPクラスタ切り替え</a>の操作中に一時的に発生することがあります。</li>
    <li>プライマリ/スタンバイリストが完全には表示されない場合：リストに新しく追加されたスタンバイクラスタが表示されないことがあります。これは、ocp.multi-cluster.replication.interval.secondsの現在の値が、そのスタンバイクラスタとプライマリクラスタ間のデータ同期間隔を制御しているためです。当事クラスタ以外のクラスタが同期間隔内にプライマリOCPクラスタにデータを同期しない限り、新しく追加されたスタンバイクラスタは表示されません。</li>
    </ul>
    </main>
