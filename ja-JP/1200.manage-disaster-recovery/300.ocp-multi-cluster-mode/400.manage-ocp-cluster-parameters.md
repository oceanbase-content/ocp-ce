# OCPクラスタパラメータの管理

このセクションでは、OCPマルチクラスタモードに関連するパラメータの確認と変更方法を説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能を提供していません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。
* 現在ログインしているOCPでマルチクラスタモードが有効になっていることを確認してください。詳細については、[マルチクラスタモードスイッチ](../300.ocp-multi-cluster-mode/900.multi-cluster-mode-switch.md)の**通常のOCPのマルチクラスタモードを有効にする**を参照してください。

## OCPマルチクラスタパラメータの確認

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\> OCPマルチクラスタモード** をクリックします。

3. **<UI-TERM key="ocp-v2.page.MultiCluster.CurrentOcpParameters">現在の OCP パラメータ一覧</UI-TERM>** タブを選択します。

   このタブのパラメータリストには、すべてのOCPマルチクラスタ関連パラメータの基本情報が表示されます。デフォルト値、現在値、パラメータの意味、有効タイプ、変更日時などが含まれます。

   ![06031557](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1507872261/p280232.png)

   パラメータの説明が長くて完全には表示されない場合、説明にマウスカーソルを合わせると、システムが完全な説明を表示します。

## OCPマルチクラスタパラメータの変更

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\> OCPマルチクラスタモード** をクリックします。

3. **<UI-TERM key="ocp-v2.page.MultiCluster.CurrentOcpParameters">現在の OCP パラメータ一覧</UI-TERM>** タブを選択します。

   パラメータリストには、すべてのOCP関連パラメータが表示されます。

4. 変更するパラメータを見つけ、そのパラメータの **<UI-TERM key="ocp-v2.Auth.Role.Operation">操作</UI-TERM>** 列の **修正** **する** をクリックします。

   システムはパラメータ変更ダイアログボックスをポップアップ表示します。

   ![06031603](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1507872261/p280240.png)

5. ポップアップボックスにパラメータ値を入力します。

6. **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Submit">送信</UI-TERM>** をクリックします。

   プロンプト **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterValueModified">パラメータ値の変更に成功しました</UI-TERM>** が表示されます。

   この時点で、**<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">パラメータリスト</UI-TERM>** 内の当該パラメータの **<UI-TERM key="ocp-v2.component.OperationConfig.List.CurrentValue">現在の値</UI-TERM>** は、先ほど変更した値に更新されます。変更を有効にするには、**適用タイプ** 列を参照して再起動が必要かどうかを判断してください。
