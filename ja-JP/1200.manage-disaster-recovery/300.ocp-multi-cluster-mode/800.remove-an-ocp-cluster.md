# OCPクラスタの非稼働化

このセクションでは、スタンバイOCPとプライマリOCPの関係を解除する方法について説明します。スタンバイOCPが他の用途で利用可能な場合は、このセクションを参照してプライマリ/スタンバイ関係を解除した後、他の業務実装に使用できます。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能を提供しません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが**ADMIN**ロールであることを確認してください。

* スタンバイOCPは[OCPクラスタの登録](../300.ocp-multi-cluster-mode/200.register-an-ocp-cluster.md)を実行済みであること。

* 現在のスタンバイOCPとプライマリOCPクラスタ間の通信が正常であること。異常な場合は、[OCPクラスタの削除](../300.ocp-multi-cluster-mode/700.delete-an-ocp-cluster.md)を実行して問題のあるスタンバイOCPを非稼働化できます。

## スタンバイOCPクラスタの非稼働化

1. スタンバイOCPにログインします。

2. 左側のナビゲーションバーで、**システム管理 \> OCPマルチクラスタモード** をクリックします。

3. **<UI-TERM key="ocp-v2.page.MultiCluster.MasterSlaveDetails">プライマリ/スタンバイの詳細</UI-TERM>** タブをクリックします。

4. **<UI-TERM key="ocp-v2.MultiCluster.Detail.BasicOcpInformation">現在のOCP基本情報</UI-TERM>** の **<UI-TERM key="ocp-v2.MultiCluster.Detail.DisassociateTheActiveStandbyRelationship">プライマリ/スタンバイ関係の解除</UI-TERM>** ボタンをクリックします。

   ![06032000](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/3306772261/p280379.png)システムは、OCPのプライマリ/スタンバイ関係を解除するかどうかの確認ダイアログをポップアップ表示します。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>プライマリ/スタンバイ関係を解除すると、スタンバイOCPは他のプライマリOCPにバインドするか、通常モードに戻すことができます。慎重に操作してください。</p>
    </main>

5. ポップアップダイアログで、**<UI-TERM key="ocp-v2.MultiCluster.Detail.DisassociateTheActiveStandbyRelationship">プライマリ/スタンバイ関係の解除</UI-TERM>** をクリックします。

## プライマリOCPクラスタの非稼働化

1. 正常なスタンバイOCPにログインします。

2. [OCPクラスタの日常的な切り替え](../300.ocp-multi-cluster-mode/500.switch-an-ocp-cluster-in-daily-maintenance.md)を参照して、このスタンバイOCPをプライマリに切り替えます。

   切り替えが成功するのを待ちます。

3. 元のプライマリOCPにログインします。

   この時点で、このOCPはスタンバイOCPになっています。

4. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\> OCPマルチクラスタモード** をクリックします。

5. **<UI-TERM key="ocp-v2.page.MultiCluster.MasterSlaveDetails">プライマリ/スタンバイの詳細</UI-TERM>** タブの **<UI-TERM key="ocp-v2.MultiCluster.Detail.BasicOcpInformation">現在のOCP基本情報</UI-TERM>** で、**<UI-TERM key="ocp-v2.MultiCluster.Detail.DisassociateTheActiveStandbyRelationship">プライマリ/スタンバイ関係の解除</UI-TERM>** をクリックします。

   プロンプト **<UI-TERM key="ocp-v2.MultiCluster.Detail.TheActiveStandbyRelationshipIs">プライマリ/スタンバイ関係の解除に成功しました</UI-TERM>** が表示されます。システムは **<UI-TERM key="ocp-v2.MultiCluster.RegisterOcp.WelcomeToMultiClusterMode">マルチクラスタモードへようこそ</UI-TERM>** に戻ります。

   これにより、元のプライマリOCPはクラスタから削除されます。以前のプライマリOCPクラスタや他のプライマリOCPに再びバインドするか、通常のOCPとして外部にサービスを提供することができます。
