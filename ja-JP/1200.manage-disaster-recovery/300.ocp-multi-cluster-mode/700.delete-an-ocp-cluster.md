# OCPクラスタの削除

この記事では、クラスタからハートビートに異常があるスタンバイOCPを削除する方法について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionではこの機能は提供されません。</p>
</main>

## 背景

シナリオ例：

フェイルオーバーが発生すると、プライマリ・スタンバイリストに表示されるOCPは、元のプライマリOCPクラスタに対してハートビートを報告しなくなります。そのため、元のプライマリOCPの **<UI-TERM key="ocp-v2.MultiCluster.Detail.ActiveStandbyList">プライマリ/スタンバイリスト</UI-TERM>** には、ハートビート検出に異常があるOCPが表示されることがあります。この時点で、元のプライマリOCPには他のOCP情報が残っています。

このシナリオでは、削除機能を使用して、元のプライマリOCPクラスタ内に残っているOCPおよびそれが管理するOceanBaseクラスタ情報を削除できます。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールを持っていることを確認してください。

* [OCPクラスタの登録](../300.ocp-multi-cluster-mode/200.register-an-ocp-cluster.md) を実行済みであること。

* 現在のOCPの **<UI-TERM key="ocp-v2.MultiCluster.Detail.ActiveStandbyList">プライマリ/スタンバイリスト</UI-TERM>** にハートビートに異常があるOCPクラスタが存在すること。かつ、クラスタが以下の条件を満たしていること：

  * 現在のクラスタでは、ハートビートに異常があるOCPのMetaDBに接続できない。

  * 現在のクラスタでは、ハートビートに異常があるOCPのMetaDBに接続できるが、接続後にそのプライマリクラスタが現在のOCPクラスタではないことが判明した場合。

* 削除対象のOCPクラスタに、OCP間で管理されるプライマリ/スタンバイモードのプライマリOceanBaseクラスタが存在しないこと。

  もしそのようなクラスタが存在する場合は、以下のシナリオに応じて適切な処理を行った後に、OCPを削除してください。
  * 当該プライマリOceanBaseクラスタに異常がある場合は、[プライマリ/スタンバイデータベースのフェイルオーバー](../300.ocp-multi-cluster-mode/600.switch-an-ocp-cluster-in-a-failover.md) を参照し、当該プライマリOceanBaseクラスタを他のOCPが管理するものに切り替えてください。

  * 当該プライマリOceanBaseクラスタが正常な場合、原則としてそのOCPクラスタを削除することは推奨されません。削除したい場合は、まず [プライマリ/スタンバイデータベースの日常的な切り替え](../300.ocp-multi-cluster-mode/500.switch-an-ocp-cluster-in-daily-maintenance.md) を参照し、当該プライマリOceanBaseクラスタを他のOCPが管理するものに切り替えてから、そのOCPクラスタを削除してください。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OCPクラスタを削除する際には、以下の操作が実行されます：</p>
    <ul>
    <li>OCPプライマリクラスタから当該OCPクラスタ情報を削除します。</li>
    <li>OCPプライマリクラスタから、当該OCPクラスタが管理するOceanBaseクラスタ情報を削除します。</li>
    </ul>
   </main>

  他のスタンバイOCPクラスタがプライマリクラスタからこれらの情報を同期するにつれて、当該OCPクラスタおよびそれが管理するOceanBaseクラスタ情報は、マルチクラスタから完全に削除されます。

  もしこのOCPがOceanBaseのプライマリクラスタを管理しており、そのOceanBaseのプライマリクラスタのスタンバイクラスタが他のOCPクラスタにある場合、このOCPクラスタを削除すると、このOceanBaseのスタンバイクラスタはOCPのマルチクラスタ環境全体で関連するプライマリクラスタを見つけられなくなり、このOceanBaseのスタンバイクラスタに関連するフェイルオーバー、スイッチオーバー、アップグレードはすべて失敗します。

## OCPの削除

1. OCPにログインします。

2. 左側のナビゲーションバーで、**システム管理 \> OCPマルチクラスタモード** をクリックします。

3. **<UI-TERM key="ocp-v2.page.MultiCluster.MasterSlaveDetails">プライマリ/スタンバイの詳細</UI-TERM>** タブをクリックします。

4. **<UI-TERM key="ocp-v2.MultiCluster.Detail.ActiveStandbyList">プライマリ/スタンバイリスト</UI-TERM>** から削除するOCPを見つけ、その後ろの **<UI-TERM key="ocp-v2.User.Component.DeleteUserModal.Delete">削除</UI-TERM>** ボタンをクリックします。

   <!-- ![06032016](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0406772261/p280384.png) -->

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><strong>削除</strong> エントリが表示されるのは、OCPのハートビート検出に異常がある場合のみです。</p>
   </main>

   システムは以下のように提示します。

   <!-- ![06031630](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0406772261/p280286.png) -->

5. **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Detail.Delete">削除</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.MultiCluster.Detail.TheSecondaryOcpIsDeleted">OCPの削除に成功しました</UI-TERM>** というメッセージが表示されます。
