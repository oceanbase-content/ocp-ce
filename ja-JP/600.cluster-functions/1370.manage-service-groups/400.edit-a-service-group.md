# サービスグループの編集

このセクションでは、アービトレーションサービスグループの情報を編集する方法について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **アービトレーションサービスメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* サービスグループが **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">正常に稼働</UI-TERM>** 状態である必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.pages.AWR.Cluster">クラスタ</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.Cluster.Component.RepalceDrawer.ArbitrationService">アービトレーションサービス</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Arbitration.ServiceGroup">サービスグループ</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.Cluster.Arbitration.ServiceGroup">サービスグループ</UI-TERM>** リストページに移動します。

4. 編集するサービスグループを選択し、操作列で **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.Alarm.Rule.Editing">編集</UI-TERM>** を選択します。

5. ポップアップウィンドウでサービスグループの関連情報を変更します。詳細については、[サービスグループの新規作成](200.create-a-service-group.md)を参照してください。

6. **<UI-TERM key="ocp-v2.component.FormEditTable.Determine">確定</UI-TERM>** をクリックします。
