# サービスグループのアップグレード

この記事では、アービトレーションサービスグループのアップグレード方法について説明します。アップグレード中はアービトレーションサービスが停止し、強制的に実行すると関連するクラスタの高可用性が損なわれる可能性があるため、慎重に操作してください。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **アービトレーションサービスメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* サービスグループが **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">正常に稼働</UI-TERM>** 状態にあること。
* サービスグループに関連付けられたテナントでログストリームの降格がないこと。
* サービスグループが既にOceanBaseクラスタに関連付けられている場合、アップグレード後のサービスグループはOceanBaseクラスタのメジャーバージョン番号とマイナーバージョン番号と一致している必要があります。例えば、OceanBaseクラスタのバージョンとアービトレーションサービスのバージョンがどちらもV4.2.x.xである必要があります。そうでない場合、アップグレードは失敗します。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.Search.Cluster">クラスタ</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.ArbitrationService">アービトレーションサービス</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.CreateArbitrationGroup.ServiceGroup">サービスグループ</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationGroupDrawer.ServiceGroup">サービスグループ</UI-TERM>** リストページに移動します。

4. アップグレード対象のサービスグループを選択し、操作列で **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Upgrade">アップグレード</UI-TERM>** を選択します。

5. ポップアップウィンドウでサービスグループのアップグレード情報を確認し、アップグレードするバージョンのソフトウェアパッケージを選択します。選択可能なバージョンがない場合、**<UI-TERM key="ocp-v2.src.component.PackageSelect.UploadASoftwarePackage">ソフトウェアパッケージをアップロード</UI-TERM>** をクリックすると、ポップアップウィンドウで必要なバージョンのソフトウェアパッケージをアップロードできます。

6. **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Upgrade">アップグレード</UI-TERM>** をクリックします。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>現在のバージョンより高いバージョンのソフトウェアパッケージのみを選択でき、パッケージのCPUアーキテクチャは現在のサービスグループのハードウェアアーキテクチャと一致している必要があります。</p>
    </main>
