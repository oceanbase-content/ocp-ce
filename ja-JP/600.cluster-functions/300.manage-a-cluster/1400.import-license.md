# Licenseのインポート

<main id="notice" type='notice'>
<h4>適用対象</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能をサポートしていません。</p>
</main>

単一マシン環境では、ライセンスファイルをOCPプラットフォームにアップロードし、ライセンスで許諾された範囲に応じて対応する機能コンポーネントを有効化できるようにする必要があります。

## 適用シナリオ

* シングルマシンにはデフォルトで有効期限180日間の試用Licenseが付属しています。試用Licenseが期限切れ間近または期限切れの場合は、速やかに正規版Licenseをインポートする必要があります。
* 正規版Licenseが期限切れ間近または期限切れの場合、新たに取得したLicenseをインポートする必要があります。
* Licenseの機能コンポーネントを変更した後、Licenseを再インポートする必要があります。

## 前提条件

* 現在のOceanBaseがシングルマシンであることを確認してください。

* ライセンスファイルを取得済みであること。

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. クラスタリストから操作対象のクラスタを選択し、クラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動し、右上の **...** アイコンをクリックして、**<UI-TERM key="ocp-v2.Detail.Overview.ImportLicense">ライセンスのインポート</UI-TERM>** を選択します。

5. ローカルにダウンロードしたLicenseファイルを選択し、アップロードを完了します。

    * 一度にアップロードできるLicenseファイルは1つのみです。
    * アップロードに成功した後に再度アップロードすると、古いLicenseファイルが新しいLicenseファイルに置き換えられます。
