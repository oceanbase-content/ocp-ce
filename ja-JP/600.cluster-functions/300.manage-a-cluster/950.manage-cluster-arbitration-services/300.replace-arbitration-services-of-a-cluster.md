# アービトレーションサービスの置換

アービトレーションサービスが稼働しているマシンに障害が発生した場合、このセクションを参照して新しいマシンにアービトレーションサービスをデプロイし、障害のあるアービトレーションサービスを置き換えることができます。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* 置き換え先のアービトレーションサービスは、**<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常に稼働</UI-TERM>** 状態である必要があります。
* アービトレーションサービスに関連付けられたテナントでログストリームの降格が発生していないこと。
* OceanBaseクラスタと置き換え先のアービトレーションサービスのメジャーバージョン番号とマイナーバージョン番号が一致していること。例えば、OceanBaseクラスタのバージョンと置き換え先のアービトレーションサービスのバージョンがどちらもV4.2.x.xである必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.ReportTables.LockStatInfo.LatchStatTable.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">アービトレーションサービス一覧</UI-TERM>** モジュールで、サービスを置き換えるクラスタを選択し、操作列の **<UI-TERM key="ocp-v2.src.constant.oceanbase.ReplacementService">サービスの置き換え</UI-TERM>** をクリックします。

5. ポップアップパネルで既存のアービトレーションサービスを選択します。または、リストの下部で **<UI-TERM key="ocp-v2.Cluster.New.CreateAService">新規サービス</UI-TERM>** をクリックして、クラスタに新しいアービトレーションサービスを作成することもできます。詳細については、[アービトレーションサービスの作成](../../1350.manage-arbitration-services/200.create-arbitration-services.md)を参照してください。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>置き換え中はアービトレーションサービスが提供できなくなり、テナントレプリカの高可用性が影響を受ける可能性があります。</p>
    </main>

6. **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">送信</UI-TERM>** をクリックします。
