# アービトレーションサービスの削除

アービトレーションサービスを使用しなくなった場合は、このセクションを参照してクラスタから削除できます。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* アービトレーションサービスは **<UI-TERM key="ocp-v2.page.Overview.Stopped">停止済み</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">正常に稼働</UI-TERM>**、または **<UI-TERM key="ocp-v2.src.constant.oceanbase.Unavailable">利用不可</UI-TERM>** の状態である必要があります。
* OceanBaseクラスタがこのアービトレーションサービスを使用している場合は、削除できません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Monitor.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">アービトレーションサービス一覧</UI-TERM>** モジュールで、サービスを削除するクラスタを選択し、操作列の **サービスの削除** をクリックします。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>サービスを削除すると、このクラスタはアービトレーションによる高可用性機能を持たなくなります。</p>
    </main>
