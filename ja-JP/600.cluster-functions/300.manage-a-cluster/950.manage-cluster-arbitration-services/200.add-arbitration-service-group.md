# サービスグループの追加

この記事では、クラスタにアービトレーションサービスグループを追加する方法について説明します。

<main id="notice" type='notice'>
<h4>適用対象</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* OceanBase Centralized Enterprise Editionはサービスグループの追加をサポートしていません。
* OceanBaseクラスタとサービスグループはどちらも **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">正常に稼働</UI-TERM>** 状態であること。
* OceanBaseクラスタとサービスグループのメジャーバージョン番号とマイナーバージョン番号が一致していること。例えば、OceanBaseクラスタのバージョンとアービトレーションサービスのバージョンがどちらもV4.2.x.xであること。
* 各クラスタには1つのサービスグループしか追加できません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">クラスタ</UI-TERM>** をクリックし、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページで、以下の2つの方法のいずれかを使用して、クラスタにアービトレーションサービスグループを追加できます。

   * 右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationGroupDrawer.AddServiceGroup">サービスグループを追加</UI-TERM>** を選択します。
   * **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">アービトレーションサービス一覧</UI-TERM>** モジュールで、**<UI-TERM key="ocp-v2.Detail.LoadBalance.AddObproxyLoadBalanceAppDrawer.Add">追加</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Component.ReplaceArbitrationServerDrawer.ServiceGroup">サービスグループ</UI-TERM>** を選択します。

5. ポップアップパネルで、クラスタのサービスグループ関連情報を選択します。

    |  パラメータ         |   説明   |
    |---------------|----------|
    |  サービスグループ        | 既存のサービスグループを選択できます。または、リスト下部の **<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationGroupSelect.CreateAServiceGroup">サービスグループを新規作成</UI-TERM>** をクリックして、クラスタに新しいサービスグループを作成することもできます。詳細については、[新規サービスグループの作成](../../1370.manage-service-groups/200.create-a-service-group.md)を参照してください。  |
    |  アービトレーションサービスのURL  | リストから既存のアービトレーションサービスのURLを選択するか、リスト下部の **<UI-TERM key="ocp-v2.src.component.AddArbitrationDrawer.CreateArbitrationService">新規アービトレーションサービス</UI-TERM>** をクリックして、必要なバージョンのアービトレーションサービスを作成できます。詳細については、[新規アービトレーションサービスの作成](../../1350.manage-arbitration-services/200.create-arbitration-services.md)を参照してください。  |
    |  4F/2Fテナントのアービトレーションサービスを有効にする      | これを選択すると、クラスタ内のテナントのアービトレーションサービスが同期して有効になります。  |

6. **<UI-TERM key="ocp-v2.Alarm.Rule.New.Add">追加</UI-TERM>** をクリックします。
