# アービトレーションサービスの追加

このセクションでは、クラスタにアービトレーションサービスを追加する方法について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **アービトレーションサービスのメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* OceanBase Centralized Enterprise Editionはアービトレーションサービスの追加をサポートしていません。
* OceanBaseクラスタはV4.1.0以降のバージョンであること。
* OceanBaseクラスタとアービトレーションサービスの主要なバージョン番号と副次的なバージョン番号が一致していること。例えば、OceanBaseクラスタのバージョンとアービトレーションサービスのバージョンがどちらもV4.2.x.xであること。
* OceanBaseクラスタが **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">正常に稼働</UI-TERM>** 状態にあること。
* 各クラスタには1つのアービトレーションサービスしか追加できません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">クラスタ</UI-TERM>** をクリックします。システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページで、以下の2つの方法のいずれかでクラスタにアービトレーションサービスを追加できます。

   * 右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Cluster.New.AddArbitrationService">アービトレーションサービスを追加する</UI-TERM>** を選択します。
   * **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationServiceList">アービトレーションサービス一覧</UI-TERM>** モジュールで、**<UI-TERM key="ocp-v2.Detail.LoadBalance.AddObproxyLoadBalanceAppDrawer.Add">追加</UI-TERM>** > **<UI-TERM key="ocp-v2.Component.OCPObjscope.ArbitrationService">アービトレーションサービス</UI-TERM>** を選択します。

5. **<UI-TERM key="ocp-v2.Detail.Overview.AddArbitrationService">アービトレーションサービスを追加する</UI-TERM>** パネルで、クラスタにアービトレーションサービスのアドレスを選択します。または、リストの下部で **<UI-TERM key="ocp-v2.Cluster.New.CreateAService">新規サービス</UI-TERM>** をクリックして新しいアービトレーションサービスを作成することもできます。詳細については、[アービトレーションサービスの新規作成](../../1350.manage-arbitration-services/200.create-arbitration-services.md)を参照してください。

6. **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">送信</UI-TERM>** をクリックします。
