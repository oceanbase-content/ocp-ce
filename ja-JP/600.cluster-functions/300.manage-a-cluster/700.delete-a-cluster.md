# クラスタの削除

ビジネスニーズに応じて、不要なOceanBaseクラスタを削除できます。クラスタを削除すると、そのOceanBaseクラスタが占有していたすべてのホストが解放され、ホスト上の業務もクリアされます。慎重に操作してください。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ管理** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

* お使いのOceanBaseクラスタが現在のOCPで管理されていること。現在のOCPで管理されていない場合は、[クラスタの引き継ぎ](../300.manage-a-cluster/400.take-over-a-cluster.md)を参照して、OceanBaseクラスタを現在のOCPに引き継いでください。

* 削除対象のOceanBaseクラスタが **停止**、**使用不可**、**廃棄**、または **移出済み** の状態にあること。
* プライマリOceanBaseクラスタを削除する際は、そのスタンバイクラスタが既に削除されていることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">クラスタ</UI-TERM>** をクリックし、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Cluster.Detail.DeleteACluster">クラスタを削除</UI-TERM>** を選択します。

5. 表示された **<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.DeleteACluster">クラスタを削除</UI-TERM>** ダイアログボックスに、deleteと入力します。

6. **<UI-TERM key="ocp-v2.Host.Detail.Delete">削除</UI-TERM>** をクリックします。

   ポップアップダイアログの **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、進捗状況や失敗原因を確認できます。

   **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でもこのタスクの進捗状況を確認できます。

   このタスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつ **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">クラスタ</UI-TERM>** ページの **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** にそのOceanBaseクラスタが表示されなくなったら、削除は成功です。
