# CPUバインディング設定の管理

CPUバインディングとは、特定のプロセスやスレッドを特定のCPUコアに結びつける技術です。重要なタスクを固定のCPUコアに結びつけることで、タスクが異なるコア間で頻繁に切り替わるのを防ぎ、コンテキストスイッチングのオーバヘッドを削減してシステム全体のパフォーマンスを向上させます。

ただし、CPUバインディングを過度に使用すると、一部のコアが過負荷になり、他のコアがアイドル状態になる可能性があり、システムのリソース利用率に影響を与える可能性があるため注意が必要です。実際の運用では、具体的な状況に応じてCPUバインディングの使用を慎重に判断し、適切にバインディング戦略を調整することで、最適なパフォーマンスとリソース利用効果を実現する必要があります。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

## CPUバインディング範囲の設定

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. クラスタリストから操作対象のクラスタを選択し、クラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動し、右上の **...** アイコンをクリックして、**<UI-TERM key="ocp-v2.Detail.Overview.CpuCoreBindingConfiguration">CPUコアバインディング構成</UI-TERM>** を選択します。

5. **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.ConfigureCpuBindingRange">CPUバインディング範囲の設定</UI-TERM>** をクリックすると、複数のZoneに同じCPUバインディング範囲を設定するか、異なるZoneに異なるCPUバインディング範囲を設定するかを選択できます。

   * **複数のZoneに同じCPUバインディング範囲を設定する場合**

     * バインディング対象の選択：複数のZoneをバインディング対象として選択できます。システムはデフォルトでそのクラスタのすべてのZoneを選択します。CPUバインディングが必要なZoneを選択すると、システムはこれらのZoneのOBServerプロセスに対してCPUバインディング設定を行います。

     * CPUバインディング範囲の入力：CPUバインディング範囲欄の **<UI-TERM key="ocp-v2.component.CreateTagDrawer.Add">追加</UI-TERM>** をクリックすると、Zoneに複数のCPUバインディング範囲を設定できます。

   * **異なるZoneに異なるCPUバインディング範囲を設定する場合**

     CPUバインディング設定の下部にある **<UI-TERM key="ocp-v2.Alarm.Rule.New.Add">追加</UI-TERM>** をクリックすると、複数のZone CPUバインディング情報を追加できます。バインディング対象となるZoneは一意であり、重複選択はサポートされません。

    <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E7%BB%91%E6%A0%B8.png) -->

6. 設定完了後、**<UI-TERM key="ocp-v2.TrendAndOutline.SQLHistory.Ok">確定</UI-TERM>** をクリックします。

7. ダイアログボックスでタスクIDをクリックすると、タスクの進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** で、かつクラスタの状態が **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常に稼働</UI-TERM>** の場合、そのクラスタのCPUバインディング設定は成功したことを意味します。

## CPUバインディング設定の無効化/有効化

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. クラスタリストで操作対象のクラスタを選択し、クラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動し、右上の **...** アイコンをクリックして、**<UI-TERM key="ocp-v2.Detail.Overview.CpuCoreBindingConfiguration">CPUコアバインディング構成</UI-TERM>** を選択します。

5. 操作対象のCPUバインディング設定を選択し、有効または無効にします。

6. ポップアップダイアログで **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Determine">確定</UI-TERM>** をクリックします。
