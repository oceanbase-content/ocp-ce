# パラメータ変更履歴の表示

**<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ModifyHistory">変更履歴</UI-TERM>** タブで、現在のクラスタで実施されたすべての運用保守設定パラメータの変更履歴を確認できます。各パラメータ変更について、パラメータ名、変更前後のパラメータ値、変更日時、パラメータタイプ、操作ユーザーが表示されます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.CardAbnormalTable.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Detail.Overview.OMConfiguration">運用管理設定</UI-TERM>** を選択します。デフォルトで **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>** タブに移動します。

5. **<UI-TERM key="ocp-v2.Detail.Parameter.ModificationHistory">変更履歴</UI-TERM>** タブをクリックします。

6. **<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">更新日</UI-TERM>** または **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Parameter">パラメータ名</UI-TERM>** でフィルタリング検索を実行します。**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Parameter">パラメータ名</UI-TERM>** はあいまい検索をサポートします。

7. クエリ結果で、パラメータの変更履歴を確認します。
