# パラメータの管理

このセクションでは、運用保守設定パラメータの確認と変更の操作について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**リソース権限。
  * クラスタの**<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>**メニュー権限。

* 運用保守設定パラメータを変更すると、OCPの一部機能の正常な使用に影響を与える可能性があります。慎重に操作し、OCPテクニカルサポートの支援を受けることをお勧めします。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.Overview.Cluster">クラスタ</UI-TERM>**をクリックすると、システムはデフォルトで**<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>**で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの**<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>**ページで、右上の**...**アイコンをクリックし、**<UI-TERM key="ocp-v2.component.OperationConfig.OMConfiguration">運用設定</UI-TERM>**を選択すると、デフォルトで**<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">パラメータ管理</UI-TERM>**タブに移動します。

5. **<UI-TERM key="ocp-v2.page.Property.ParameterList">パラメータリスト</UI-TERM>**タブをクリックして、運用保守設定パラメータを管理します。

   * **パラメータの有効化/無効化**

     **<UI-TERM key="ocp-v2.src.constant.parameter.SqlDiagnosticCollection">SQL 診断収集</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OperationConfig.List.TransactionDiagnosticCollection">トランザクション診断収集</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.parameter.ActiveSessionHistoryCollection">アクティブセッション履歴の収集</UI-TERM>** の後ろにあるスイッチボタンをクリックすると、該当モジュールのパラメータを有効または無効にできます。パラメータを無効にすると、ocp-agentは対応するデータの収集を停止し、同時にそのモジュールの他の運用パラメータリストも表示されなくなります。

   * **<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.ModifyParameterValues">パラメータ値を変更する</UI-TERM>**

     パラメータモジュールが有効な状態の場合、操作対象のパラメータを選択し、**<UI-TERM key="ocp-v2.Detail.Session.List.Actions">操作</UI-TERM>**列の**<UI-TERM key="ocp-v2.Detail.Parameter.ModifyValue">値を変更する</UI-TERM>**をクリックすると、そのパラメータを変更できます。すべてのパラメータの詳細については、[概要](100.om-configuration-overview.md)の**パラメータリスト説明**を参照してください。

     パラメータの変更は、現在のクラスタ内のすべてのノードに反映されます。変更を送信した後、**<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>**でタスクの実行結果を確認できます。

   * **パラメータの検索**

     検索ボックスにパラメータ名を入力して、パラメータのあいまい検索を行うことができます。

   * **変更されたパラメータの表示**

     **<UI-TERM key="ocp-v2.component.OperationConfig.List.ViewOnlyModifiedParameters">変更されたパラメータのみを表示</UI-TERM>**を選択すると、システムは変更されたパラメータをフィルタリングして表示します。
