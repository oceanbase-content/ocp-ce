# OCP Agentリソースの設定

**OCP Agentリソース設定**タブでは、クラスタ内のすべてのOCP Agentに対して一括してリソースを設定できます。特定のホストのOCP Agent仕様を個別に変更する必要がある場合は、[ホストの詳細を見る](../../../850.host-features/100.manage-a-host/150.view-a-host-overview.md) の **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.ChangeSpecifications">仕様変更</UI-TERM>** の内容を参照して操作してください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

## 注意事項

高いビジネス負荷やストレステストのシナリオでは、リソース不足によるOOM（Out Of Memory、メモリ不足）や監視データの損失を防ぐため、OCP Agentのリソース仕様を引き上げることを推奨します。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">クラスタ</UI-TERM>** をクリックし、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.component.OperationConfig.OMConfiguration">運用設定</UI-TERM>** を選択します。デフォルトで **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">パラメータ管理</UI-TERM>** タブに移動します。

5. **OCP Agentリソース設定** タブをクリックします。ページには、現在のクラスタ内のすべてのホストのホストIPアドレス、ホスト名、Zone、プロセス、および仕様情報が表示されます。

6. 右上の **<UI-TERM key="ocp-v2.component.OperationConfig.ChangeSpecifications">仕様変更</UI-TERM>** をクリックし、**OCP Agent仕様** パネルで、クラスタ内のすべてのOCP AgentのCPUとメモリ仕様を一括調整します。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>推奨される最大仕様は6C/12GiBです。</li><li>ocp_monagentのメモリ設定は、クラスタ内の各ホストの利用可能な物理メモリサイズよりも低く設定することを推奨します。そうでない場合、リソース設定が失敗する可能性があります。ホストの利用可能な物理メモリサイズは、<b>パフォーマンス監視</b> > <b>ホストパフォーマンス</b> > <b>ホスト次元</b> > <b>メモリ</b> から確認できます。</li><li>この操作を実行すると、システムはデフォルトでそのクラスタ内のすべてのOCP Agentの仕様を変更します。ホストのCPUとメモリリソースが十分であることを確認してください。そうでない場合、システムのパフォーマンスが低下する可能性があります。</li><li>OCP Agentの仕様を変更するには、<a href="../../../850.host-features/100.manage-a-host/400.restart-the-ocp-agent.md">OCP Agentの再起動</a>が必要です。再起動中はOCPでの運用操作ができず、一部の監視データが失われるため、慎重に操作してください。</li></ul></p>
    </main>
