# クラスタの停止

ビジネスニーズに応じてクラスタを停止できます。クラスタを停止すると、クラスタ内のすべてのノードで実行されているobserverプロセスが停止します。慎重に操作してください。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

* OceanBaseクラスタの業務負荷が少ない時間帯を選択し、**<UI-TERM key="ocp-v2.Topo.TopoGraph.StopTheCluster">クラスタを停止</UI-TERM>** 操作を実行します。

  クラスタを停止すると業務が停止し、現時点ではその影響を回避する方法はありません。慎重に操作してください。この機能は、クラスタが不要な場合にのみ使用することを推奨します。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Cluster.Detail.StopTheCluster">停止クラスタ</UI-TERM>** を選択します。

5. ダイアログボックスで、プロセス停止前にダンプ操作を実行するかどうかを選択し（デフォルトで実行）、**<UI-TERM key="ocp-v2.src.constant.oceanbase.Stop.4">停止する</UI-TERM>** をクリックします。

   ダンプ操作を実行すると、プロセス停止の応答時間が長くなりますが、OBServerの復旧時間を大幅に短縮できます。

   <!-- ![11161438](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E5%81%9C%E6%AD%A2%E9%9B%86%E7%BE%A4.png) -->

6. クラスタ停止タスクが送信された後、ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">タスクを確認する</UI-TERM>** をクリックすると、停止進捗状況を確認できます。

   **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でもこのタスクの停止進捗状況を確認できます。

   タスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつ **<UI-TERM key="ocp-v2.Clubbing.ClubbingGroup.UpgradeArbitrationGroup.Cluster">クラスタ</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で、そのクラスタの状態が **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>** になったら、クラスタの停止は成功です。

7. クラスタを起動します。

   クラスタが停止した後、再度OceanBaseクラスタを有効にしたい場合は、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページの右上にある **<UI-TERM key="ocp-v2.Cluster.Detail.StartTheCluster">クラスタを起動する</UI-TERM>** をクリックして、再度有効にできます。
