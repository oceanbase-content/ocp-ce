# テナントレベル情報の表示

このページでは、クラスタ内のテナントレベルのプライマリ/スタンバイ関係、メジャーコンパクションの詳細、およびデータバックアップの進捗状況を確認する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが少なくとも以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

* 現在のクラスタがV4.0.0.0以降のバージョンであること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Cluster.Import.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. クラスタリストから操作対象のクラスタを選択し、クラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動し、右上の **...** アイコンをクリックして、**<UI-TERM key="ocp-v2.Detail.Overview.ViewTenantLevelInformation">テナントレベルの情報を確認する</UI-TERM>** を選択します。

5. ポップアップパネルで、異なるタブを使用してクラスタのテナントレベル情報をそれぞれ確認します。

   * **<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.PrimaryAndSecondaryTenants">プライマリ/スタンバイテナント</UI-TERM>**：クラスタ内のプライマリ/スタンバイテナントの詳細。プライマリテナント（形式：`クラスタ名/プライマリテナント名`）、スタンバイテナント（形式：`クラスタ名/スタンバイテナント名`）、ステータス、同期方式、プライマリ/スタンバイ保護モード、保護レベル、ログ遅延時間が含まれます。**<UI-TERM key="ocp-v2.Detail.Component.PrimaryAndBackupTenantList.ViewDelay">遅延の表示</UI-TERM>** および **同期の一時停止/開始** 操作をサポートしています。

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <p><b>プライマリ/スタンバイテナント</b> の一部の情報は、特定の条件を満たした場合にのみ表示されます。詳細については、<a href='../../700.tenant-functions/600.manage-a-tenant/100.overview-of-the-tenant-details-page.md'>テナント詳細ページの概要</a>の <b>プライマリ/スタンバイ関係の表示</b> の関連説明を参照してください。</p>
     </main>

   * **<UI-TERM key="ocp-v2.Component.TenantLevelInfoDrawer.TenantConsolidation">テナントメジャーコンパクション</UI-TERM>**：クラスタ内のテナントメジャーコンパクションの詳細。テナント名、最終メジャーコンパクション開始時間、最終メジャーコンパクション終了時間、所要時間、ステータス、およびメジャーコンパクションのトリガー理由が含まれます。
   * **<UI-TERM key="ocp-v2.Backup.Component.BackupNowClusterDrawer.DataBackup">データバックアップ</UI-TERM>**：クラスタ内のテナントのデータバックアップ詳細。テナント名、バックアップ方式、直近1回のバックアップ開始時間、直近1回のバックアップ終了時間、所要時間、ステータス、および進捗状況が含まれます。
