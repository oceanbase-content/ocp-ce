# クラスタの再起動

ビジネスニーズに応じて、クラスタ内のすべてのノードのobserverプロセスを再起動するか、特定のZoneのobserverプロセスを再起動できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* 再起動が必要なOceanBaseクラスタはマルチレプリカクラスタであり、そのレプリカ数は3以上である必要があります。この場合、OceanBaseクラスタはローリング方式で再起動され、業務は中断しません。

  OceanBaseクラスタのレプリカ数が3未満の場合、再起動時に業務が中断しますので、ご注意ください。

* シングルマシンでは、**<UI-TERM key="ocp-v2.Detail.Component.RestartModal.ForceRestart">強制再起動</UI-TERM>** モードのみサポートされています。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.component.TenantLabel.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動し、右上の **...** アイコンをクリックして、**<UI-TERM key="ocp-v2.Detail.Overview.RestartTheCluster">クラスタを再起動する</UI-TERM>** を選択します。

5. ダイアログボックスで以下の設定を行い、設定完了後に **<UI-TERM key="ocp-v2.src.constant.backup.Restart">再起動</UI-TERM>** をクリックします。

   * 再起動範囲の選択：**<UI-TERM key="ocp-v2.Alarm.LogFilter.All">すべて</UI-TERM>**、特定のZoneの再起動、またはいくつかのZoneの再起動を含みます。

     * **<UI-TERM key="ocp-v2.Component.ArbitrationTransfer.All">すべて</UI-TERM>** を選択した場合、システムはクラスタ内のすべてのノードのobserverプロセスを再起動します。

     * 特定のZoneを選択した場合、システムはそれらのZoneのobserverプロセスを再起動します。

   * 再起動モードの選択：**<UI-TERM key="ocp-v2.Component.ZoneList.Restart">再起動</UI-TERM>** または **<UI-TERM key="ocp-v2.Component.CgroupEditModal.ForceRestart">強制再起動</UI-TERM>** を含みます。

     * 再起動（推奨）：業務によるデータベースへのアクセスを中断しません。

     * 強制再起動：業務によるデータベースへのアクセスを中断し、業務を利用できなくなります。

   * プロセス停止前にダンプ操作を実行するかどうかの選択（デフォルトで実行）：ダンプ操作を実行すると、プロセス停止の応答時間が長くなりますが、OBServerの復旧時間を大幅に短縮できます。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E9%87%8D%E5%90%AF%E9%9B%86%E7%BE%A4.png) -->

6. クラスタの再起動タスクが送信された後、ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、再起動の進捗状況を確認できます。

   **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** で、このタスクの再起動進捗状況を確認することもできます。

   タスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">ゾーンリスト</UI-TERM>** に表示されている該当ゾーンの状態がすべて **<UI-TERM key="ocp-v2.src.constant.compute.Running">実行中</UI-TERM>** になった場合、再起動は成功したことを示します。
