# クラスタ詳細の表示

特定のクラスタページに移動すると、現在のクラスタの基本情報、リソース使用状況、アラート概要、過去7日間のシステムイベント、ゾーンリスト、OBServerリスト、およびアービトレーションサービスリストを確認できます。また、クラスタの日常的なメンテナンス操作も実行できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

## 基本情報の表示

クラスタ概要ページでは、**クラスタ名、クラスタID、クラスタタイプ、OceanBaseバージョン番号、リージョン数、デプロイメントモード、CPUアーキテクチャ、Cgroup設定、CPUオーバーコミット、マシン数、負荷タイプ、パーティション数、テナント数、作成者、起動時間、稼働時間、OBProxyクラスタ、保護モード、ソフトウェアインストールパス、データディスクパス**、**ConfigUrl**、**<UI-TERM key="ocp-v2.page.Host.Label">タグ</UI-TERM>**などのクラスタ基本情報を確認できます。

## 保護モード

<main id="notice" type='explain'>
<h4>説明</h4>
<p>保護モードは従来型クラスタ(Shared-nothingモード)にのみ適用されます。AIクラスタ(Shared-storageモード)はプライマリ/スタンバイ構成をサポートしていません。</p>
</main>

* 最大パフォーマンスモード：プライマリクラスタのパフォーマンスを最大限に確保しつつ、ユーザーデータを保護します。このモードでは、すべてのスタンバイクラスタとプライマリクラスタ間のログ転送は非同期です。

* 最大可用性モード：通常状態では、プライマリクラスタと同期ログ転送を維持しているスタンバイクラスタは1つだけです。

* 最大保護モード：プライマリクラスタと同期ログ転送を維持しているスタンバイクラスタは1つだけで、他のスタンバイクラスタはすべて非同期ログ転送となります。
