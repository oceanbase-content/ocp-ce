# Licenseの表示

<main id="notice" type='notice'>
<h4>適用対象</h4>

</main>

Licenseを表示することで、現在の単一マシンのLicense状態および関連情報を確認できます。

## 前提条件

* 現在のOceanBaseが単一マシンであることを確認してください。

* [Licenseのインポート](1400.import-license.md)が完了していること。

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**リソース権限。
  * クラスタ**<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>**メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">クラスタ</UI-TERM>**をクリックすると、システムはデフォルトで**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>**タブに移動します。

3. クラスタリストで操作対象のクラスタを選択し、クラスタ名をクリックします。

4. クラスタの**<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>**ページに移動し、右上の**...**アイコンをクリックして、**<UI-TERM key="ocp-v2.Detail.Overview.ViewLicense">ライセンスを確認する</UI-TERM>**を選択します。

5. ポップアップウィンドウでLicense情報を確認します。各フィールドの詳細説明は以下の通りです。

   | フィールド  |  説明   |
   |-------|---------|
   | クラスタID   | OceanBaseがOCP側で付与するクラスタID。クラスタ起動時に自動生成されます。    |
   | 権限付与ユーザー名  | 権限付与されたユーザー名。  |
   | License ID  | LicenseのID。OceanBaseによって生成されます。  |
   | Licenseコード | Licenseのコード。契約番号で構成されています。  |
   | Licenseタイプ | Licenseのタイプ。以下の2種類に分類されます：<ul><li>Commercial：商用版</li><li>Trial：試用版</li></ul>   |
   | 製品タイプ   | 以下の2種類に分類されます：<ul><li>SE：集中型エンタープライズ版</li><li>DE：分散型エンタープライズ版</li></ul>   |
   | License発行日   | Licenseの発行日。    |
   | License有効化日   | Licenseの有効化日。    |
   | License期限日   | Licenseの期限日。    |
   | Licenseオプション   | Licenseに含まれる機能オプション。以下の種類が含まれます：<ul><li>EE：OceanBase集中型エンタープライズ版基本機能</li><li>PS：OceanBase単一マシンクラスタ間レプリケーションオプション</li><li>MT：OceanBase単一マシンマルチテナントオプション</li><li>AP：OceanBase単一マシンOLAPオプション</li><li></li></ul>    |
   | 権限付与ノード数   | 権限付与ノード数。単一マシンの場合は1です。    |
