# 自動デッドロック検出の有効化

ビジネスニーズに応じて、自動デッドロック検出を有効にすることができます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

* 現在のクラスタバージョンがV3.2.0以上であり、かつクラスタが読み取り専用クラスタではないこと。

* クラスタで自動デッドロック検出機能が有効になっていないこと。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>クラスタバージョンがV4.0以上の場合、システムはデフォルトで自動デッドロック検出を有効にします。この機能を無効にした後でも、再度有効にすることができます。</p>
  </main>

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.Search.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Topo.TopoGraph.EnableAutomaticDeadlockDetection">デッドロック自動検出を有効にする</UI-TERM>** を選択します。

5. ダイアログボックスで **<UI-TERM key="ocp-v2.Inspection.Item.Ok">確定</UI-TERM>** をクリックすると、デッドロック検出機能が有効になります。

   デッドロック検出の自動化を有効にすると、OceanBaseはデッドロックを自動的に検出し、ロールバックを実行します。また、過去7日間のデッドロックレコードを保存できます。詳細については、[デッドロック分析の表示](../../1000.diagnosis-and-tuning-fuctions/300.manage-session/300.view-deadlock-analysis.md)を参照してください。

   ![Image 29](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%AD%BB%E9%94%81.png)

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>デッドロック検出の自動化を有効にすると、パフォーマンスが約2%低下します。慎重に操作してください。</p>
    </main>
