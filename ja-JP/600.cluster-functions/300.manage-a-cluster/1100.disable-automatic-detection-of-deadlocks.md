# デッドロックの自動検出を無効にする

ビジネスニーズに応じて、デッドロックの自動検出を無効にできます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**リソース権限。
  * クラスタ**<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>**メニュー権限。

* 現在のクラスタバージョンがV3.2.0以上であること。

* クラスタでデッドロックの自動検出機能が有効になっていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">クラスタ</UI-TERM>**をクリックし、システムはデフォルトで**<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>**で操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの**<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>**ページで、右上の**...**アイコンをクリックし、**<UI-TERM key="ocp-v2.Topo.TopoGraph.DisableAutomaticDeadlockDetection">デッドロック自動検出を無効にする</UI-TERM>**を選択します。

5. ダイアログボックスで**<UI-TERM key="ocp-v2.page.Inspection.Ok">確定</UI-TERM>**をクリックすると、デッドロックの自動検出機能が無効になります。
