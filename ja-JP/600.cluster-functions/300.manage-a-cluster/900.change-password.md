# パスワードの変更

ビジネスニーズに応じて、管理しているクラスタのsysテナントのrootユーザーパスワードを変更できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.plan.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Auth.User.ChangePassword">パスワードの変更</UI-TERM>** を選択します。

5. **<UI-TERM key="ocp-v2.Auth.User.ChangePassword">パスワードの変更</UI-TERM>** ダイアログボックスで、新しいパスワードを入力し、確認します。

   <!-- ![07051016](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E4%BF%AE%E6%94%B9%E9%9B%86%E7%BE%A4%E5%AF%86%E7%A0%81.png) -->

   入力するパスワードは、8文字以上32文字以下であり、数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（<code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>）の4種類のうち、少なくとも3種類を含む必要があります。

6. **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Determine">確定</UI-TERM>** をクリックします。
