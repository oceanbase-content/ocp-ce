# TDEの管理

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版ではこの機能は提供されません。</p>
</main>

OceanBaseデータベースは、データストレージ層での暗号化、すなわちTDE（Transparent Data Encryption）をサポートしています。

TDEは、ディスク上に保存される機密データを暗号化することができます。データはストレージデバイスに書き込む前に自動的に暗号化され、読み取り時に自動的に復号化されます。このプロセスはユーザーに対して透過的であり、データベースで認証されたユーザーは制限なくデータにアクセスできます。ストレージ媒体が盗まれた場合でも、TDEにより、認証されていないユーザーが媒体に保存された機密データにアクセスするのを防ぎます。ストレージ媒体が紛失してもデータの損失を防ぎ、ユーザーデータのセキュリティを最大限に保護します。

このページでは、TDEの操作手順について説明します。TDEの有効化方法およびテナントのためのテーブルスペースの作成方法が含まれます。

## TDEの有効化

このセクションを参照して、クラスタでTDEを有効にすることができます。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>TDEを有効にした後は無効にできません。また、データベースのパフォーマンスが低下します。今後復号化が必要な場合は、テーブルを暗号化テーブルスペースから移動し、フルコンパクションを実行してください。</p>
</main>

### 前提条件

* 現在OCPにログインしているユーザーが**ADMIN**ロールまたは**ORG_ADMIN**ロールであることを確認してください。
* 暗号化を有効にするテナントの状態が**正常稼働**中であること。
* OCPが提供するキーを使用する場合は、OceanBaseクラスタがV4.x以降のバージョンであることを確認してください。
* サードパーティベンダーが提供するキーを使用する場合は、OceanBaseクラスタが以下のいずれかのバージョン要件を満たしていることを確認してください：
  * [V4.2.5.4, V4.3.0)
  * [V4.3.5.2, +∞)
* サードパーティベンダー**格尔**が提供するキーを使用する場合は、サービスタイプに応じて、事前に以下のパラメータ設定を完了する必要があります：
  * **標準版**：<code>ocp.kms.tde.koal.useTLS.enabled</code> と <code>ocp.kms.tde.koal.kcsp.mode.enabled</code> のパラメータ値をどちらもfalseに設定します。
  * **パスワード**：<code>ocp.kms.tde.koal.useTLS.enabled</code> と <code>ocp.kms.tde.koal.kcsp.mode.enabled</code> のパラメータ値をどちらもtrueに設定します。
  パラメータの詳細については、本文中の**パラメータ説明**を参照してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Binlog.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.component.SecurityCard.TdeTransparentEncryption">TDE 透過的データ暗号化</UI-TERM>** タブに切り替えます。

6. 暗号化を有効にするテナントを選択し、操作列の **<UI-TERM key="ocp-v2.SecurityCard.TDE.TurnOnEncryption">暗号化を開始</UI-TERM>** をクリックします。

7. ダイアログボックスでキーのタイプを選択します。

   * OCPが提供するキーの使用：OCPが自動生成するキー。この方法では `tde_method` の値は internal となり、これはマスターキーがOceanBaseの内部テーブルに保存されていることを意味します。
   * サードパーティベンダーが提供するキーの使用：KMSが管理するキー。設定が必要なキー情報は以下の通りです。

      |  パラメータ    |  説明   |
      |-----------|---------|
      | ベンダー    | **<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.AlibabaCloud">Alibaba Cloud</UI-TERM>**、**<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.TencentCloud">Tencent Cloud</UI-TERM>**、**<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.JiangnanTianan">江南天安</UI-TERM>**、**<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.Geer">ゲール</UI-TERM>**、**Xin'an Century**、**<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.JiangnanKeyou">江南科友</UI-TERM>**、および **Alibaba Cloud Apsara Stack** などのベンダータイプをサポートしています。  |
      | サービスタイプ | ベンダーが **<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.Geer">ゲール</UI-TERM>** の場合に選択し、KMSのサービスタイプを指定します。<ul><li>**<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.StandardEdition">スタンダード版</UI-TERM>**：KMS Standardサービスのバージョンが2.0以上であることを確認してください。</li><li>**<UI-TERM key="ocp-v2.Prometheus.Component.CreateDataSourceModal.Password">パスワード</UI-TERM>**：KMS Passwordサービスのバージョンが3.2.0以上であることを確認してください。   |
      | アクセスドメイン名 | KMSのendpoint情報。  |
      | AK        | 署名認証を行うaccess_key_id。 |
      | SK        | 署名認証を行うaccess_key_secret。 |
      | SKバージョン番号 | ベンダーが **<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.Geer">ゲール</UI-TERM>** かつサービスタイプが **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.Password">パスワード</UI-TERM>** の場合に入力します。SKの具体的なバージョン番号。   |
      | マスターキーID | ユーザーのマスターキーID。   |
      | リージョン      | メーカーが **<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.TencentCloud">Tencent Cloud</UI-TERM>** の場合に入力する、KMSのリージョン情報。  |

8. **<UI-TERM key="ocp-v2.Detail.SqlAudit.Open">有効にする</UI-TERM>** をクリックします。

### パラメータ説明

| パラメータ  | 説明  | 反映に再起動が必要か  |
|-------|-------|--------------------|
| <code>ocp.kms.tde.koal.useTLS.enabled</code>  | GEL KMS暗号化設定でTLS（Transport Layer Security）プロトコルを使用するかどうかを構成します。このパラメータはOCP MetaDBの<code>config_properties</code>テーブルに保存され、デフォルト値は<code>false</code>です。サーバーアドレスが<code>https</code>の場合、パラメータ値は<code>true</code>に設定する必要があります。  | いいえ  |
| <code>ocp.kms.tde.koal.kcsp.mode.enabled</code> | GEL KMS暗号化でkcspバージョンを使用するかどうかを構成します。このパラメータはOCPの<b>システム管理</b> > <b>システムパラメータ</b>で画面上から設定でき、デフォルト値は<code>true</code>です。  | いいえ  |

## テーブルスペースの作成

OceanBaseは、tablespace単位で透過的データ暗号化（TDE）を有効にし、データの安全な格納を実現します。

### 前提条件

* 現在OCPにログインしているユーザーが**ADMIN**ロールまたは**ORG_ADMIN**ロールであることを確認してください。
* OceanBaseクラスタがV4.x以降のバージョンであることを確認してください。
* TDEが有効になっていることを確認してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-performance-report.ReportTables.LockStatInfo.LatchStatTable.Cluster">クラスタ</UI-TERM>**をクリックすると、システムはデフォルトで**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>**ページに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>**で操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの**<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>**ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>**をクリックします。

5. **<UI-TERM key="ocp-v2.component.SecurityCard.TdeTransparentEncryption">TDE 透過的データ暗号化</UI-TERM>**タブに切り替えます。

6. 操作対象のテナントを選択し、操作列の**<UI-TERM key="ocp-v2.SecurityCard.TDE.CreateTableSpace.CreateATablespace">テーブルスペースを作成</UI-TERM>**をクリックします。

7. ダイアログボックスに以下の情報を入力または選択します。

   | 情報   | 説明   |
   |--------|---------|
   | 暗号化テーブルスペース名  | 同一テナント内で複数の暗号化テーブルスペースを作成できます。各テーブルスペース名は一意である必要があります。英字で始まり、英字、数字、アンダースコアを含み、長さが2～30文字である必要があります。  |
   | 暗号化アルゴリズム      | 暗号化アルゴリズムは一度設定すると変更できず、型変換もできません。また、OceanBaseの異なるバージョンでサポートされている暗号化アルゴリズムは異なる場合があるため、OceanBaseの公式ドキュメントに基づいて適切な暗号化アルゴリズムを選択してください。  |

8. 暗号化テーブルスペース名を入力し、暗号化アルゴリズムを選択して、**<UI-TERM key="ocp-v2.src.constant.iam.Create">作成する</UI-TERM>**をクリックします。

9. TDEを有効にし、暗号化テーブルスペースを作成した後、データを暗号化するには、暗号化テーブルを作成するDDL操作を実行する必要があります。暗号化テーブルを作成するDDLは以下のとおりです：

   ```sql
   CREATE TABLE t1 (id int,id2 int) TABLESPACE sectest_ts1;
   ```

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>既存のテーブルを暗号化テーブルスペースに追加した後、データを暗号化して永続化するために、一度フルコンパクションを実行してください。そうでない場合、既存のテーブルのデータは暗号化できません。</p>
   </main>

10. 暗号化テーブルスペース名をクリックすると、右側のパネルで暗号化テーブルの詳細を確認できます。これには、所属テナント、暗号化テーブル名、暗号化状態、暗号化進捗状況などの情報が含まれます。暗号化進捗状況は、現在のデータテーブル内で暗号化が完了したデータブロックの割合を示します。
