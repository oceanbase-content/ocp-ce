# SSLリンク暗号化の管理

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionではこの機能は提供されません。</p>
</main>

リンクのセキュリティを向上させるため、OceanBaseデータベース接続はSSL（Secure Sockets Layer）リンク暗号化を有効にすることができます。伝送層でネットワーク接続を暗号化することで、各ノード間の通信トラフィックが盗聴や改ざんされないようにし、通信データのセキュリティを高めます。SSLリンク暗号化は、OceanBase間のRPC通信、OBProxyとOceanBaseの通信、業務アプリケーションとOBProxyの通信に適用されます。SSLリンク暗号化を有効にした後、クライアントはSSL認証または通常認証のいずれかの方法で接続を確立できます。

このページでは、SSLリンク暗号化の操作手順について説明します。

## SSLリンク暗号化の有効化

SSLリンク暗号化を有効にすると、クラスタのパフォーマンスがわずかに低下します（データの送受信時の暗号化および復号化には一定の計算リソースが消費されるため）。外部ネットワークへの接続が必要な場合、または伝送の暗号化が必要な場合にのみ、クラスタのSSLリンク暗号化を有効にすることを推奨します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 機構または **ORG_ADMIN** 機構であることを確認してください。

* OceanBaseクラスタがV4.x以降のバージョンであること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Alarm.LogFilter.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.pages.Alarm.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックします。デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. **<UI-TERM key="ocp-v2.pages.PlatformMonitor.Open">有効にする</UI-TERM>** をクリックし、ダイアログボックスでSSLサーバー証書名を選択して、**<UI-TERM key="ocp-v2.Information.Detail.InformationCollectDrawer.Enable">有効にする</UI-TERM>** をクリックします。

   プルダウンリストに必要な証書がない場合は、[証書をアップロード](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) をクリックして追加できます。

## SSLリンク暗号化の無効化

このセクションでは、SSLリンク暗号化を無効にする方法について説明します。SSLリンク暗号化の無効化は数分程度の操作ですので、しばらくお待ちください。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 機構または **ORG_ADMIN** 機構であることを確認してください。

* OceanBaseクラスタがV4.x以降のバージョンであること。

* SSLリンク暗号化が有効になっていること。

* SSLサーバー証書が期限切れになっていないこと。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.Search.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. 右上の **<UI-TERM key="ocp-v2.component.SecurityCard.TurnOffEncryption">暗号化を無効にする</UI-TERM>** をクリックし、ダイアログボックスで **<UI-TERM key="ocp-v2.Detail.Component.ShowParameterListDrawer.Closed">閉じる</UI-TERM>** をクリックします。

## SSLサーバー証書の更新

SSLサーバー証書が期限切れ間近または期限切れの場合、オンラインでSSLサーバー証書を更新できます。暗号化証書を再生成した後、過去に作成されたSSLリンクは引き続き有効となり、新しいリンクは失敗します。関連する変更にご注意ください。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 機構または **ORG_ADMIN** 機構であることを確認してください。

* OceanBaseクラスタがV4.x以降のバージョンであること。

* SSLリンク暗号化が有効になっていること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ParameterTemplate.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.pages.Alarm.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. 右上の **SSLサーバー証書の更新** をクリックし、ダイアログボックスでSSLサーバー証書名を選択して、**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLLimit.Update">更新</UI-TERM>** をクリックします。

   プルダウンリストに必要な証書がない場合は、[証書をアップロード](../../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) をクリックして追加できます。

## CA証書のダウンロード

CA証書を圧縮ファイル形式でローカルにダウンロードして保存することができます。圧縮ファイルには以下の3つのファイルが含まれています：

* `p7b` ファイル：WindowsシステムでCA証書をインポートするために使用します。

* `pem` ファイル：その他のシステムやアプリケーションでCA証書をインポートするために使用します。

* `jks` ファイル：Javaのtruststore証書格納ファイルで、パスワードは一律にOceanBaseとなります。JavaプログラムでCA証書チェーンをインポートするために使用します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 機構または **ORG_ADMIN** 機構であることを確認してください。

* OceanBaseクラスタがV4.x以降のバージョンであること。

* SSLリンク暗号化が有効になっていること。

* SSLサーバー証書が期限切れではないこと。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.pages.AWR.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. **<UI-TERM key="ocp-v2.src.constant.security.DownloadCaCertificate">CA証明書をダウンロードする</UI-TERM>** をクリックします。
