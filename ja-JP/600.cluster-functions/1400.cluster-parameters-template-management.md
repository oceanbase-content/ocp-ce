# クラスタパラメータテンプレートの管理

クラスタパラメータテンプレートは、クラスタのパラメータを事前に設定したものです。構成が類似する一連のクラスタを作成する必要がある場合、各クラスタの作成時にこのテンプレートを直接適用することで、繰り返しクラスタパラメータを設定する手間を省くことができます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>クラスタがAIクラスタ（共有ストレージ形態）の場合、一部のパラメータの意味が変更されます（例えば、<code>datafile_size</code>はキャッシュ容量を表します）。また、<code>datafile_next</code>や<code>datafile_maxsize</code>などのパラメータはサポートされなくなります。共有ストレージクラスタ用のパラメータテンプレートを作成または編集する際は、関連するパラメータの適用範囲にご注意ください。詳細については、[クラスタパラメータタイプの説明](1300.manage-cluster-parameters/100.cluster-parameters-type.md)を参照してください。</p>
</main>

## 前提条件

* クラスタパラメータテンプレート情報を確認する際は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* パラメータテンプレートの新規作成、編集、コピー、削除を行う際は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.inspection.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ParameterTemplate">パラメータテンプレート</UI-TERM>** タブをクリックすると、**クラスタパラメータテンプレートリスト** ページに移動します。

4. **クラスタパラメータテンプレートリスト** ページでは、クエリ、新規作成、編集、コピー、削除、インポート、エクスポートなどの管理操作をクラスタパラメータテンプレートに対して実行できます。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>システム組み込みのクラスタパラメータテンプレートは、編集および削除操作を行うことはできません。</p>
   </main>

### パラメータテンプレートの新規作成

よく使うパラメータをパラメータテンプレートとして設定することで、今後これらのパラメータを繰り返し設定する手間を省くことができます。

1. **クラスタパラメータテンプレートリスト** ページで **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">パラメータテンプレートを新規作成</UI-TERM>** をクリックします。
   または、**<UI-TERM key="ocp-v2.Cluster.Component.Welcome.CreateNewCluster">新規クラスタ</UI-TERM>** の **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">パラメータ管理</UI-TERM>** モジュールで **クラスタパラメータテンプレートの新規作成** を選択します。

2. **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">パラメータテンプレートを新規作成</UI-TERM>** パネルで、テンプレート名を定義し、関連するパラメータを設定します。

   **+ <UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.AddParameters">パラメータを追加</UI-TERM>** ボタンをクリックすることで、複数のパラメータ項目を追加し、パラメータ値を設定できます。

3. **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">送信</UI-TERM>** をクリックします。

### パラメータテンプレートの編集

実際の状況に応じて、パラメータテンプレートの関連情報を更新できます。

1. **クラスタパラメータテンプレート一覧** ページで、編集するパラメータテンプレートを選択し、操作列で **... > <UI-TERM key="ocp-v2.component.FormEditTable.Editing">編集</UI-TERM>** を選択します。

2. **クラスタパラメータテンプレートの編集** パネルで、**<UI-TERM key="ocp-v2.Alarm.Template.New.TemplateName">テンプレート名</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.DomainNamePopover.Remarks">備考</UI-TERM>**、および **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.TemplateParameterSettings">テンプレートパラメータ設定</UI-TERM>** を変更します。

3. **<UI-TERM key="ocp-v2.component.Compaction.DumpPolicyDrawer.Submit">送信</UI-TERM>** をクリックします。

### パラメータテンプレートのコピー

この操作により、既存の複雑なテンプレートAをコピーしてBという名前に変更できます。Bテンプレートの内容は、Aをベースに簡単に修正するだけで済み、多くのパラメータを再設定する必要はありません。

1. **クラスタパラメータテンプレート一覧** ページで、コピーするパラメータテンプレートを選択し、操作列で **... > <UI-TERM key="ocp-v2.component.ParameterTemplate.Copy">コピー</UI-TERM>** を選択します。

2. **クラスタパラメータテンプレートのコピー** ページで、**<UI-TERM key="ocp-v2.component.ParameterTemplate.TemplateName">テンプレート名</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Description">備考</UI-TERM>**、および **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.TemplateParameterSettings">テンプレートパラメータ設定</UI-TERM>** を変更します。

3. **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Submitted">送信</UI-TERM>** をクリックします。

### パラメータテンプレートの削除

クラスタパラメータテンプレートが不要になった場合、削除できます。

1. **クラスタパラメータテンプレート一覧** ページで、削除するパラメータテンプレートを選択し、操作列で **... > <UI-TERM key="ocp-v2.Restore.SamplingStrategy.Delete">削除</UI-TERM>** を選択します。

2. ポップアップウィンドウで **<UI-TERM key="ocp-v2.component.FormEditTable.Determine">確定</UI-TERM>** をクリックします。

### パラメータテンプレートのエクスポート

異なるOCPで同じパラメータテンプレートを使用したい場合、エクスポート機能を使用してテンプレートファイルをローカルに保存し、別のOCPでこのファイルをインポートして使用できます。

1. **クラスタパラメータテンプレート一覧** ページで、エクスポートするパラメータテンプレートを選択し、操作列で **... > エクスポート** を選択します。

2. ブラウザでファイルの保存先を選択することで、パラメータテンプレートをローカルにエクスポートできます。

### パラメータテンプレートのインポート

ローカルに保存されたテナントのパラメータテンプレートを選択してインポートし、同じパラメータ情報の重複設定を回避します。

1. **クラスタパラメータテンプレート一覧** ページで **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">パラメータテンプレートを新規作成</UI-TERM>** をクリックします。
   または、**<UI-TERM key="ocp-v2.Cluster.Component.Welcome.CreateNewCluster">新規クラスタ</UI-TERM>** の **<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">パラメータ管理</UI-TERM>** モジュールで **新規クラスタパラメータテンプレート** を選択します。

2. **<UI-TERM key="ocp-v2.component.ParameterTemplate.CreateAParameterTemplate">パラメータテンプレートを新規作成</UI-TERM>** パネルで **<UI-TERM key="ocp-v2.Monitor.Dashboard.Import">インポート</UI-TERM>** をクリックし、インポートするyamlテンプレートファイルを選択します。テンプレートファイル内の各パラメータ値はOceanBase/OBProxy/Binlogサービスの製品仕様に準拠しており、互いに重複していない必要があります。

3. **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">送信</UI-TERM>** をクリックします。
