# Zoneの編集

このページでは、Zoneが属するリージョン（地域）およびデータセンター情報を変更する方法について説明します。変更後、当該Zone内のすべてのホストのリージョンまたはデータセンター属性も同時に変更されますので、ご注意ください。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

* お使いのOceanBaseクラスタが現在のOCPで管理されていること。もしそうでない場合は、[クラスタの引き継ぎ](../300.manage-a-cluster/400.take-over-a-cluster.md)を参照して、OceanBaseクラスタを現在のOCPに引き継いでください。

* クラスタがV3.x以降のバージョンであること。

* 編集対象のZoneが **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">正常に稼働</UI-TERM>** 状態であること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.pages.AWR.Cluster">クラスタ</UI-TERM>** をクリックし、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">ゾーンリスト</UI-TERM>** 領域で、**<UI-TERM key="ocp-v2.Component.ZoneList.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Auth.User.Editing">編集</UI-TERM>** をクリックします。

   <!-- ![11181800](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/433/%E4%BF%AE%E6%94%B9%E6%9C%BA%E6%88%BF.png) -->

5. ダイアログボックスで、Zoneに新しいリージョン（地域）とデータセンターを選択し、**<UI-TERM key="ocp-v2.TakeOver.Component.LoadBalancer.Ok">確定</UI-TERM>** をクリックします。
