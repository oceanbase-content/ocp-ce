# Zoneの削除

このページでは、クラスタ内のZoneを削除する操作手順について説明します。この操作により、OceanBaseクラスタから現在のZone上のすべてのOBServerノードとデータが削除され、ホストが解放されます。慎重に操作してください。

## 背景

* クラスタのZone数が偶数の場合、データの高可用性要件を満たせず、データセキュリティ上のリスクがあります。設定を調整し、奇数のゾーン構成を維持するか、クラスタ/テナントでアービトレーションサービスを有効にすることを推奨します。
* クラスタを単一Zone・複数ホスト構成に変更すると、OceanBaseサービスの計算能力は拡張されますが、マルチレプリカによる高可用性機能は備えていません。開発・テスト環境に適しています。
* クラスタを単一Zone・単一ホスト構成に変更すると、データレプリカは1つしかなく、マルチレプリカやスケーラビリティ機能を利用できません。ストレージまたはハードウェア障害が発生した場合、データ損失のリスクがあります。重要な業務システムについては、定期的なバックアップの実施や、テナントのプライマリ/スタンバイデータベース、マルチレプリカによる災害復旧などの高可用性対策を構築し、単一障害点を回避することを推奨します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

* お使いのOceanBaseクラスタが現在のOCPで管理されていること。

  もしそうでない場合は、[クラスタの引き継ぎ](../300.manage-a-cluster/400.take-over-a-cluster.md)を参照して、OceanBaseクラスタを現在のOCPに引き継いでください。

* スタンドアロンマシンではZoneの削除はサポートされていません。

* 削除対象のZoneにテナントのプライマリレプリカが配置されていないことを確認してください。プライマリレプリカが配置されている場合は、そのテナントに他のフル機能レプリカが存在し、使用可能であることを確認してください。そうでない場合、そのZoneを削除すると業務が停止し、回復不能になる可能性があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">ゾーンリスト</UI-TERM>** エリアで、**<UI-TERM key="ocp-v2.Alarm.Subscriptions.Operation">操作</UI-TERM>** 列の **詳細 > 削除** をクリックします。

   ![11181759](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%88%A0%E9%99%A4zone.png)

   システムは、削除を確認するメッセージをポップアップ表示します。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Delete">削除</UI-TERM>** をクリックします。

   ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、削除の進捗状況を確認できます。また、**<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** でそのタスクの進捗状況を確認することもできます。

   タスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Component.ZoneList.ZoneList">ゾーンリスト</UI-TERM>** にそのZoneが表示されなくなったら、削除は成功です。
