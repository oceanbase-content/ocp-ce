# SQL Auditの管理

SQL Auditの管理機能は、データベース監査ログを外部ストレージシステム（ElasticSearchやSLSなど）へシームレスに転送することをサポートし、データベース操作の可視性とセキュリティを大幅に向上させます。効率的なログ管理と詳細な分析機能により、企業はきめ細かな運用とリスク管理を実現し、データセキュリティと事業継続性を確保するとともに、コンプライアンス要件に対応できます。

本記事では、SQL Auditの管理に関する操作手順を紹介します。

### 前提条件

* クラスタパラメータ：enable_sql_audit を true に変更して、グローバルSQL監査機能を有効にしてください。
* 外部ストレージデータソースとして、ElasticSearchまたはSLSが設定されていることを確認してください。詳細については、[SQL AuditとElasticSearchの連携](../1600.system-management-features/450.manage-external-integration/300.manage-sql-audit/300.manage-es.md)または[SQL AuditとSLSの連携](../1600.system-management-features/450.manage-external-integration/300.manage-sql-audit/200.manage-sls.md)を参照してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Cluster">クラスタ</UI-TERM>** をクリックします。システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.SqlAuditAdministration">SQL Audit管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.BasicInformation">基本情報</UI-TERM>** セクションで、**<UI-TERM key="ocp-v2.Detail.SqlAudit.Configuration">設定</UI-TERM>** をクリックし、ダイアログでテナントを選択します。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <ul><li>選択したテナントのSQL Auditデータは、以下の外部ストレージに転送されます。新規テナントの追加や既存テナントの削除があった場合、SQL Auditデータの同期漏れやテナント名の重複を避けるため、システムは自動的にOCP Agentのパラメータを更新します。</li><li><strong>すべて</strong>を選択した場合、現在のすべてのテナントおよび今後新規作成されるテナントのSQL Auditデータが、後で設定される外部ストレージに転送されます。<strong>除外対象</strong>でフィルタリングできます。</li></ul>
</main>

6. 外部ストレージを選択します。

7. **<UI-TERM key="ocp-v2.Detail.SqlAudit.Logstore">ログストア</UI-TERM>**、つまりSLSサービスのlogstore名を設定します。

8. **<UI-TERM key="ocp-v2.src.constant.schedule.Save">保存する</UI-TERM>** をクリックします。

9. 確認ダイアログで、**<UI-TERM key="ocp-v2.component.Compaction.DumpPolicyDrawer.Ok">確定</UI-TERM>** をクリックします。

## 関連操作

* **<UI-TERM key="ocp-v2.Detail.SqlAudit.SqlAuditConfigModal.EditSqlAudit">SQL Audit の編集</UI-TERM>**：**<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Detail.BasicInformation">基本情報</UI-TERM>** セクションの右上隅にある **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">編集</UI-TERM>** をクリックします。表示されるダイアログで関連情報を修正し、**<UI-TERM key="ocp-v2.pages.Kubernetes.Save">保存</UI-TERM>** をクリックします。

* **SQL Auditの削除**：**<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.BasicInformation">基本情報</UI-TERM>** セクションで、**<UI-TERM key="ocp-v2.Detail.SqlAudit.EnabledStatus">有効化状態</UI-TERM>** スイッチをオフにします。表示されるダイアログで **<UI-TERM key="ocp-v2.src.constant.schedule.Disable">無効にする</UI-TERM>** をクリックします。次に、**<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step2.BasicInformation">基本情報</UI-TERM>** セクションの右上隅で、**<UI-TERM key="ocp-v2.Prometheus.Component.Main.Delete">削除</UI-TERM>** をクリックします。最後に、確認ダイアログで、**<UI-TERM key="ocp-v2.Detail.Component.FailoverDrawer.Determine">確定</UI-TERM>** をクリックします。

* **<UI-TERM key="ocp-v2.Component.SqlAuditViewModal.ViewSqlAudit">SQL Auditの表示</UI-TERM>**：**<UI-TERM key="ocp-v2.page.External.SSOInfoDrawer.BasicInformation">基本情報</UI-TERM>** セクションの下部で、**<UI-TERM key="ocp-v2.Detail.SqlAudit.NumberOfWriteObjectStores">オブジェクトストレージの書き込み件数</UI-TERM>** を確認できます。右上の時間フィルターボックスで、カスタムの時間を設定できます。
