# クラスタパラメータタイプの説明

現在のOceanBaseは、BOOL、CAPACITY、DOUBLE、INT、MOMENT、STRING、STRING_LIST、TIMEなど、多様なパラメータタイプをサポートしています。

主なタイプとデフォルトの値の単位は以下の通りです：

|     パラメータ |     説明   |
|-------------|---------|
| BOOL        | boolean型（ブール）。true/falseをサポートします。 |
| CAPACITY    | 容量単位。b（バイト）、k（KB、キロバイト）、m（MB、メガバイト）、g（GB、10億バイト）、t（TB、1兆バイト）、p（PB、1000億バイト）をサポートします。単位の大文字と小文字は区別されません。デフォルトはmです。 |
| DOUBLE      | 厳密浮動小数点数。64ビットのストレージ容量を使用し、小数点以下15位まで正確で、有効桁数は16位です。 |
| INT         | int64整数型。正の整数、負の整数、および0をサポートします。 |
| MOMENT      | 時刻。形式はhh:mm（例：'02:00'）です。または、時間を指定しないことを示す特別値disableがあります。現在はmajor_freeze_duty_timeパラメータでのみ使用されます。  |
| STRING      | 文字列。ユーザーが入力する文字列の値は、OceanBaseドキュメントに記載されている対応するパラメータの要件に基づきます。  |
| STRING_LIST | 文字列リスト。`;` で区切られた複数の文字列です。 |
| TIME        | 時間型。us（マイクロ秒）、ms（ミリ秒）、s（秒）、m（分）、h（時間）、d（日）などの単位をサポートします。接尾辞を付けない場合、デフォルトは秒（s）です。単位の大文字と小文字は区別されません。   |

## 共有ストレージモードにおけるパラメータの意味の変更

クラスタがAIクラスタ（共有ストレージ形態、`ob_startup_mode=shared_storage`）の場合、一部のクラスタパラメータの意味が変更されます。詳細は以下の通りです：

|     パラメータ     |     説明   |
|-------------|---------|
| datafile_size | 共有ストレージ形態では、このパラメータはキャッシュ容量のサイズを表し、データファイルのサイズではありません。 |
| datafile_disk_percentage | 共有ストレージ形態では、このパラメータはキャッシュ容量の割合を表します。 |
| datafile_next | 共有ストレージ形態では、このパラメータはサポートされていません。 |
| datafile_maxsize | 共有ストレージ形態では、このパラメータはサポートされていません。 |
| _datafile_usage_upper_bound_percentage | 共有ストレージ形態では、このパラメータはサポートされていません。 |
| _datafile_usage_lower_bound_percentage | 共有ストレージ形態では、このパラメータはサポートされていません。 |

さらに、共有ストレージ形態では、以下のテナントレベルパラメータが追加されています：

|     パラメータ     |     説明   |
|-------------|---------|
| shared_log_retention | 共有ログの保持時間。デフォルト値は1d、取り得る範囲は[0d, 14d]です。 |
| read_cache_disk_percentage | 読み込みキャッシュのディスク割合。デフォルト値は40、取り得る範囲は[0, 90]です。 |
| cache_disk_memory_limit | キャッシュディスクのメモリ制限。デフォルト値は10、取り得る範囲は[5, 50]です。 |
