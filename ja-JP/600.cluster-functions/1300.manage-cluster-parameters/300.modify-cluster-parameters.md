# パラメータの変更

必要に応じて、クラスタまたはテナントのパラメータ値および有効範囲を変更できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Cluster.Import.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

5. （オプション）**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterList">パラメータリスト</UI-TERM>** ページ上部の検索ボックスに、パラメータ名などの関連情報を入力して、あいまい検索を実行します。

   ![Image 107](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%82%E6%95%B0%E5%88%97%E8%A1%A81.png)

6. 変更対象のパラメータを見つけ、対応する **<UI-TERM key="ocp-v2.User.MySQL.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.component.OperationConfig.List.ModifyValue">値の修正</UI-TERM>** をクリックします。

7. ポップアップダイアログで、パラメータの値、有効範囲、および適用対象を変更し、**<UI-TERM key="ocp-v2.Detail.Component.FailoverStandbyTenantModal.Ok">確定</UI-TERM>** をクリックします。以下の図は、クラスタ範囲のパラメータを変更する例です。

   ![Image 108](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5895199461/p429966.png)

   パラメータごとに有効範囲が異なるため、値を変更する際は、業務ニーズに応じて有効範囲を選択してください。

   * 有効範囲が **<UI-TERM key="ocp-v2.Detail.Parameter.List.ClusterScope">クラスタ範囲</UI-TERM>** または **<UI-TERM key="ocp-v2.Detail.Parameter.List.CustomRange">カスタム範囲</UI-TERM>** の場合、デフォルトの有効範囲は **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">クラスタ</UI-TERM>** です。ゾーンまたはOBServerノードの有効範囲に調整する必要がある場合は、**<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.EffectiveRange">適用範囲</UI-TERM>** のドロップダウンリストから **Zone** または **OBServer** を選択します。有効範囲を選択した後、適用対象を選択すると、この値の変更は選択した適用対象の範囲内で有効になります。

   * 有効範囲が **<UI-TERM key="ocp-v2.Detail.Parameter.List.TenantScope">テナントの範囲</UI-TERM>** の場合、**<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.EffectiveObject">適用対象</UI-TERM>** のドロップダウンリストから特定のテナントを選択するか、リスト内の **<UI-TERM key="ocp-v2.Component.ScheduleModeAndDayList.SelectAll">すべて選択</UI-TERM>** ボタンをクリックしてすべてのテナントを選択すると、この値の変更は選択した適用対象の範囲内で有効になります。

   パラメータの値を変更し、異なる範囲で同時に有効にする必要がある場合（例えば、**backup_concurrency** を **Zone 1** で **10**、**Zone 2** で **12**、**Server 1** で **20** に変更する場合）、**<UI-TERM key="ocp-v2.component.ModifyClusterParameterDrawer.AddValue">値を追加</UI-TERM>** をクリックして3行のレコードを新規作成できます。各行のレコードで対応する有効範囲を選択できます。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><ul><li><strong>値の追加</strong> をクリックした後に複数行の変更値が表示された場合、クラスタのパラメータ変更は最初の行から順に実行され、実行ごとに <strong>変更履歴</strong> タブに履歴レコードが生成されます。</li><li>容量関連のパラメータを設定する際は単位を記入する必要があります。記入しない場合、設定は失敗します。</li></ul></p>
    </main>
