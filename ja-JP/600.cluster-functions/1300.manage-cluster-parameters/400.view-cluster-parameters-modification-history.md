# パラメータ変更履歴の表示

変更履歴ページでは、ユーザーがOCPを通じて現在のクラスタに対して実施したすべてのパラメータ変更の履歴記録を確認できます。各パラメータ変更のパラメータ名、変更前後のパラメータ値、変更日時、および操作ユーザーが含まれます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Component.UpgradeDrawer.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Detail.Parameter.ModifyHistory">変更履歴</UI-TERM>** タブをクリックします。

6. **<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">更新日</UI-TERM>** または **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">パラメータ名称</UI-TERM>** でフィルタリング検索を実行します。

   なお、**<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">パラメータ名称</UI-TERM>** はあいまい検索をサポートします。

   ![パラメータの表示](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E4%BF%AE%E6%94%B9%E5%8E%86%E5%8F%B21.png)

7. クエリ結果で、パラメータの履歴変更情報を確認します。
