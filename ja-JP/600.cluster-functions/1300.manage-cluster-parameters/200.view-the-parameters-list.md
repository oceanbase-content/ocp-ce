# パラメータ一覧の表示

パラメータ一覧では、現在のクラスタにおけるすべてのパラメータの名前、カテゴリ、値の種類、値の範囲、デフォルト値、現在値、説明、再起動が必要かどうか、読み取り専用かどうかを確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックすると、クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

   システムはデフォルトで **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">パラメータリスト</UI-TERM>** ページに移動します。ここでは、**<UI-TERM key="ocp-v2.page.MultiAzone.ParameterList">パラメータリスト</UI-TERM>** で現在のクラスタのすべてのパラメータ情報を確認できます。右上の **<UI-TERM key="ocp-v2.component.OperationConfig.List.ViewOnlyModifiedParameters">変更されたパラメータのみを表示</UI-TERM>** をチェックすると、OCPで変更されたパラメータのリストを確認できます。

   ![Image 106](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%82%E6%95%B0%E5%88%97%E8%A1%A81.png)

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><strong>現在値</strong> 列で、値の後に <strong>(クラスタ)</strong> と表示されている場合、その値はクラスタ全体で統一されて設定されていることを意味します。上記の例で <strong>autoinc_cache_refresh_interval</strong> の現在値が <strong>3600s(クラスタ)</strong> となっているのは、3600sがクラスタ全体で有効であることを示しています。</li>
    <li><strong>現在値</strong> 列で、値の後に <strong>(カスタム)</strong> と表示されている場合、その値はクラスタ全体で統一されていないことを意味します。<strong>2d;1d(カスタム</strong>)</li> のように、ユーザーがカスタマイズした <strong>2d</strong> は特定のゾーンに対する値であり、<strong>1d</strong> は特定のOBServerノードに対する値です。これら2つの値がそれぞれ対象とするオブジェクトを確認するには、その値をクリックしてご覧ください。</li>
    </ul>
   </main>
