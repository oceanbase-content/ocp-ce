# メジャーコンパクションレコードの表示

クラスタの過去3日間のメジャーコンパクションレコードを確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">メジャーコンパクション管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.monitor.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックすると、クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Compaction.MergeManagement">メジャーコンパクション管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Detail.Compaction.MergeDetails">メジャーコンパクションの詳細</UI-TERM>** または **<UI-TERM key="ocp-v2.Detail.Compaction.MergeConfiguration">メジャーコンパクション構成</UI-TERM>** タブの右上隅にある **<UI-TERM key="ocp-v2.Detail.Compaction.ViewMergeRecords">メジャーコンパクション記録を確認する</UI-TERM>** をクリックすると、そのクラスタの過去3日間のすべてのメジャーコンパクションレコードを確認できます。記録される情報には、テナント名/ID、開始時間、終了時間、合計時間、バージョン番号、メジャーコンパクション状態などが含まれます。
