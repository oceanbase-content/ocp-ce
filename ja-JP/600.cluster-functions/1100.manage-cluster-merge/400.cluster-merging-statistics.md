# マージ統計の表示

クラスタのマージ統計情報を確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.Detail.Compaction.MergeManagement">メジャーコンパクション管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.pages.AWR.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックすると、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Compaction.MergeManagement">メジャーコンパクション管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Detail.Compaction.MergeDetails">メジャーコンパクションの詳細</UI-TERM>** タブの **<UI-TERM key="ocp-v2.Compaction.Detail.CompactionLatest3.LastMerges">直近3 回のメジャーコンパクション</UI-TERM>** セクションで、マージ統計情報を確認します。

   ![マージ統計](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%9C%80%E8%BF%913%E6%AC%A1%E5%90%88%E5%B9%B6.png)

   マージ統計では、直近3回のマージに関する2つの統計グラフが提供されています。これらは以下の通りです：

   * テナントの平均ダンプ回数トップ5

   * マージ前のテナントメモリ使用率ピークトップ5

   マージはクラスタ全体のパフォーマンスに影響を与えるため、マージの所要時間とパフォーマンスデータはOceanBaseクラスタの健全性を観察するための補助手段として使用されます。一般的に、日次マージは設定された日次マージ時間にのみ実行されることが望ましいです。テナントのダンプ回数やメモリ使用率が限度を超えるとクラスタのマージがトリガーされるため、テナントの対応する指標を観察することで、テナントに割り当てられたリソースが十分かどうかを判断できます。テナントのリソース仕様を向上させることで、単一のテナントのリソース不足によるクラスタマージのトリガーを回避できます。
