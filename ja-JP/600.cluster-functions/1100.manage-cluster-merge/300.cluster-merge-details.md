# メジャーコンパクションの詳細を表示する

メジャーコンパクション（Major freeze）は、動的および静的データをマージする操作であり、時間がかかります。ダンプによって生成された増分データが一定量に達すると、メジャーコンパクションによってメジャーバージョンのメジャーコンパクションが実現されます。
クラスタのメジャーコンパクションの詳細では、クラスタ全体のメジャーコンパクション状況を確認できます。クラスタ内でメジャーコンパクション異常が発生したテナントがある場合は、[テナントのメジャーコンパクションの詳細](../../700.tenant-functions/1400.manage-tenant-merge/200.details-of-tenant-major-compaction.md) を参照して関連情報を確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">メジャーコンパクション管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">メジャーコンパクション管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Detail.Compaction.MergeDetails">メジャーコンパクションの詳細</UI-TERM>** タブで、メジャーコンパクションの基本情報を確認します。

   ![p168813](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E5%90%88%E5%B9%B6%E5%9F%BA%E6%9C%AC%E4%BF%A1%E6%81%AF1.png)

   メジャーコンパクションの基本情報には、クラスタのメジャーコンパクション状態、直近のメジャーコンパクション開始時刻、直近のメジャーコンパクション終了時刻が表示されます。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>メジャーコンパクション中のバージョンについては、<strong>直近のメジャーコンパクション開始時刻</strong> の後に、そのメジャーコンパクションの開始時刻が表示されます。メジャーコンパクション終了後は、<strong>直近のメジャーコンパクション終了時刻</strong> の後に自動的にメジャーコンパクション終了時刻が表示されます。</p>
    </main>

6. クラスタのメジャーコンパクション進捗状況を確認します。

   ![p168813](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/433/%E7%A7%9F%E6%88%B7%E5%90%88%E5%B9%B6%E8%BF%9B%E5%BA%A6.png)

   メジャーコンパクションの進捗状況は、一般的にテナントの直近のメジャーコンパクションを表示します。現在メジャーコンパクション中の場合は、そのバージョンが表示されます。現在アイドル状態、つまりメジャーコンパクション状態にない場合は、前回のメジャーコンパクションバージョンの詳細が表示されます。

   * メジャーコンパクションの進捗状況には、すべてのテナントのメジャーコンパクション状態が表示されます。これには、**<UI-TERM key="ocp-v2.src.constant.compaction.Exception">異常</UI-TERM>**、**メジャーコンパクション中/メジャーコンパクション一時停止中**、**<UI-TERM key="ocp-v2.page.Information.Completed">完了済み</UI-TERM>** が含まれます。
   * テナントのメジャーコンパクションにかかった時間にカーソルを合わせると、**<UI-TERM key="ocp-v2.TraceDetail.TraceContent.StartTime.1">開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Transaction.Detail.EndTime">終了時間</UI-TERM>**、**<UI-TERM key="ocp-v2.TraceDetail.TraceContent.TimeConsumed">所要時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.State">ステータス</UI-TERM>** を含む具体的なメジャーコンパクション情報を確認できます。

7. テナントのMemStore消費量を確認します。

   ![p168813](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E7%A7%9F%E6%88%B7mems%E6%B6%88%E8%80%97.png)

   以下のテキストは、トレンドグラフでMemStore消費データをよりよく確認し分析するのに役立ちます：

   * 特定期間の詳細なトレンドを見る：マウスで該当する範囲をドラッグして選択すると、システムはその範囲のトレンド情報を拡大表示します。このトレンドグラフをダブルクリックすると元に戻ります。
   * 他のテナントのデータを非表示にする：他のテナントアイコンをクリックして灰色にすると、そのテナントの情報はトレンドグラフに表示されません。または、特定のテナントの右側にある ![p168813](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E5%8F%8D%E9%80%89.png) ボタンをクリックすると、そのテナント以外の他のテナント情報を非表示にできます。
   * 特定時刻の詳細データを見る：カーソルをトレンドグラフ上の特定の時刻に合わせます。
   * テナントのフィルタリング：システムはデフォルトでMemStore消費量が上位5位のテナントを表示します。トレンドグラフの右上隅にある **<UI-TERM key="ocp-v2.Component.RecoverableTimeRange.SelectTenant">テナントを選択する</UI-TERM>** をクリックすると、表示するテナントを自由に選択できます。最大10個のテナントを表示できます。

8. クラスタのリソース消費状況を確認します。

   ![p168813](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E7%A7%9F%E6%88%B7%E9%9B%86%E7%BE%A4%E8%B5%84%E6%BA%90%E6%B6%88%E8%80%97.png)

   以下のポイントを参考にすると、トレンドグラフ上でクラスタのリソース消費データをより効果的に確認し分析できます：

   * 特定期間の詳細なトレンドを見る：マウスで該当する範囲をドラッグして選択すると、システムはその範囲のトレンド情報を拡大表示します。このトレンドグラフをダブルクリックすると元に戻ります。
   * 他のテナントのデータを非表示にする：他のテナントアイコンをクリックして灰色にすると、そのテナントの情報はトレンドグラフに表示されません。
   * 特定時刻の詳細データを見る：カーソルをトレンドグラフ上の特定の時刻に合わせます。
