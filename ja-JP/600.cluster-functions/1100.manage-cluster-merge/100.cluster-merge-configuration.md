# クラスタのメジャーコンパクション設定を変更する

ビジネスニーズに応じて、クラスタレベルでメジャーコンパクションポリシーとダンプポリシーを設定し、日次メジャーコンパクションを実行できます。
クラスタレベルで設定されたポリシーは、クラスタ内のすべてのテナントに適用されます。これは、クラスタ内のすべてのテナントのメジャーコンパクション設定を一元的に管理する必要があるシナリオに適しています。個々のテナントに対して異なるメジャーコンパクションポリシーとダンプポリシーを設定する必要がある場合は、[テナントのメジャーコンパクション設定を変更する](../../700.tenant-functions/1400.manage-tenant-merge/100.modify-major-compaction-settings-of-a-tenant.md) を参照してカスタマイズしてください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">メジャーコンパクション管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">クラスタ</UI-TERM>** をクリックします。システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Compaction.MergeManagement">メジャーコンパクション管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Detail.Compaction.MergeConfiguration">メジャーコンパクション構成</UI-TERM>** タブをクリックします。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>クラスタ内のテナントに異なるポリシー設定が存在する場合、システムはポリシー値に基づいてテナントをグループ化して表示します。</p>
   </main>

   <!-- ![09161958](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E5%90%88%E5%B9%B6%E9%85%8D%E7%BD%AE1.png) -->

6. メジャーコンパクションポリシーを設定します。

   1. **<UI-TERM key="ocp-v2.Compaction.Settings.MergePolicy">メジャーコンパクション戦略</UI-TERM>** エリアで、**<UI-TERM key="ocp-v2.page.External.CreateDrawer.Edit">編集</UI-TERM>** をクリックします。

   2. 各構成パラメータの ![Image 17.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8048190061/p168332.png "Image 17.png") アイコンにマウスカーソルを合わせ、システムの指示に従ってメジャーコンパクションポリシーを設定します。

   3. 完了後、**<UI-TERM key="ocp-v2.Compaction.Settings.EditCard.Save">保存する</UI-TERM>** をクリックします。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>メジャーコンパクションの速度が遅い場合は、メジャーコンパクションタスクの重みを適宜引き上げることができます。ただし、この操作はOceanBase内で実行中の他のタスク（バックアップ・リストアタスクなど）の重みを低下させます。そのため、OceanBaseで複数のタスクが同時に進行している場合は、タスクの優先順位に基づいてメジャーコンパクションタスクの重みを変更するかどうかを判断する必要があります。</p>
   </main>

7. ダンプポリシーを設定します。

   1. **<UI-TERM key="ocp-v2.Compaction.Settings.DumpPolicy">ダンプポリシー</UI-TERM>** エリアで、**<UI-TERM key="ocp-v2.page.External.Edit">編集</UI-TERM>** をクリックします。

   2. 各構成パラメータの ![Image 17.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8048190061/p168332.png "Image 17.png") アイコンにカーソルを合わせ、システムの指示に従ってダンプポリシーを設定します。

   3. 完了後、**<UI-TERM key="ocp-v2.Compaction.Settings.EditCard.Save">保存する</UI-TERM>** をクリックします。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>現在のクラスタのテナントポリシー設定が一致していない場合、変更されたポリシーはクラスタ内のすべてのテナントに適用されます。慎重に操作してください。</p>
    </main>
