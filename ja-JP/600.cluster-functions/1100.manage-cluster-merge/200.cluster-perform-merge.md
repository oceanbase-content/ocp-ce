# メジャーコンパクションの実行

クラスタが **<UI-TERM key="ocp-v2.src.constant.oceanbase.Idle">空き</UI-TERM>** 状態の場合、いつでもメジャーコンパクションをトリガーできます。クラスタでメジャーコンパクションエラーが発生した場合、エラーの調査後に異常をクリアしてメジャーコンパクションを続行できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">メジャーコンパクション管理</UI-TERM>** メニュー権限。

* OceanBaseがV4.0以降のバージョンの場合、クラスタレベルのメジャーコンパクション操作はサポートされなくなりました。クラスタ内のメジャーコンパクション操作は、クラスタ内のプライマリテナントに対して一括でメジャーコンパクションを開始するためにのみ使用されます。スタンバイテナントのメジャーコンパクションは、プライマリテナントのメジャーコンパクション状態を同期した後に自動的に開始されるものであり、手動でメジャーコンパクションを開始することはできません。

* `enable_manual_merge` パラメータは、手動メジャーコンパクションを有効にするかどうかを設定します。OceanBaseクラスタがV1.x〜V3.xバージョンの場合、メジャーコンパクションをトリガーする前に、**クラスタ > パラメータ管理** の `enable_manual_merge` パラメータの値がFalseであることを確認するか、`enable_manual_merge` がTrueの場合はSQLコマンドを使用して手動でメジャーコンパクションプロセスを実行する必要があります。具体的な操作手順については、[メジャーコンパクションの手動制御](https://docs.oceanbase.com/oceanbase-database/V4.2.1-manual-trigger-major-compaction)を参照してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックすると、クラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Compaction.MergeManagement">メジャーコンパクション管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Detail.Compaction.MergeDetails">メジャーコンパクションの詳細</UI-TERM>** タブの **<UI-TERM key="ocp-v2.Alarm.Event.Detail.BasicInformation">基本情報</UI-TERM>** 領域でメジャーコンパクション情報を確認します。

   <!-- ![メジャーコンパクションの実行](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E5%90%88%E5%B9%B6%E5%9F%BA%E6%9C%AC%E4%BF%A1%E6%81%AF1.png) -->

6. **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Log.State">ステータス</UI-TERM>** が **<UI-TERM key="ocp-v2.src.constant.oceanbase.Idle">空き</UI-TERM>** であることを確認した後、**<UI-TERM key="ocp-v2.Compaction.Detail.InitiateAMerge">メジャーコンパクションを開始する</UI-TERM>** をクリックすると、システムはクラスタ内のすべてのテナントに対してメジャーコンパクションを開始します。

   メジャーコンパクションを開始すると、**<UI-TERM key="ocp-performance-report.ReportTables.BasicInfo.ServerInfoServerTable.State">ステータス</UI-TERM>** の後ろのパーセンテージでメジャーコンパクションの進捗状況を確認できます。

7. 状態が **<UI-TERM key="ocp-v2.src.constant.compaction.TenantMerging">テナントメジャーコンパクション中</UI-TERM>** の場合、**<UI-TERM key="ocp-v2.Compaction.DetailV4.ViewTenants">テナント一覧を見る</UI-TERM>** をクリックして、現在メジャーコンパクション中のテナントリストを確認できます。

8. テナントのメジャーコンパクションで異常が発生した場合、**<UI-TERM key="ocp-v2.Compaction.DetailV4.ViewTenants">テナント一覧を見る</UI-TERM>** から異常なテナントを特定できます。
   メジャーコンパクションエラーを手動で分析・調査した後、**<UI-TERM key="ocp-v2.Compaction.DetailV4.ClearException">異常をクリアする</UI-TERM>** をクリックしてメジャーコンパクションエラーマークをクリアし、メジャーコンパクションを続行できます。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>メジャーコンパクションエラーが発生した場合、まず専門家に連絡して問題を確認することをお勧めします。エラーを調査せずに直接メジャーコンパクションエラーをクリアする操作は、エラーの範囲が拡大する可能性があります。</p>
   </main>
