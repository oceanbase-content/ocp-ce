# クラスタテナント管理の概要を表示する

管理しているクラスタ内のすべてのテナントのリソース分布情報、テナントリスト、およびテナントモニタリングのトップ5を確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.Detail.Tenant.TenantManagement">テナント管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.ReportTables.LockStatInfo.LatchStatTable.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックすると、クラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Tenant.TenantManagement">テナント管理</UI-TERM>** をクリックすると、**<UI-TERM key="ocp-v2.Detail.Tenant.TenantManagement">テナント管理</UI-TERM>** ページに移動します。

5. **<UI-TERM key="ocp-v2.Cluster.Detail.NewTenant">新しいテナントを作成</UI-TERM>** をクリックすると、そのクラスタに新しいテナントを作成できます。詳細については、[新規テナントの作成](../700.tenant-functions/300.create-a-tenant.md)を参照してください。

6. **<UI-TERM key="ocp-v2.Detail.Capacity.OverviewOfCapacityUsage">容量使用量の概要</UI-TERM>** モジュールで、リソース分布情報を確認します。

   リソース分布情報には、各テナントがクラスタ内のCPU、メモリ、ログディスク、データディスクリソースに占める割合、およびシステムの残りのCPU、メモリ、ログディスク、データディスクリソースの割合が主に含まれます。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <ul>
   <li>クラスタがAIクラスタ（共有ストレージ形態）の場合、<b>データディスク</b>は<b>キャッシュディスク</b>として表示され、ローカルキャッシュディスクのリソース割り当てと使用状況を反映します。</li>
   <li>現在、OCPではAIクラスタやLogserviceクラスタのオブジェクトストレージ上のデータ使用量を確認することはできません。具体的な使用量については、クラウドベンダーのオブジェクトストレージコンソールでご確認ください。</li>
   </ul>
   </main>

   カーソルを円グラフ内の特定のテナントの位置に合わせると、そのテナントが使用するリソースの具体的な数値が表示されます。**<UI-TERM key="ocp-v2.Component.OBServerList.Disk">データディスク</UI-TERM>** の右上にある **<UI-TERM key="ocp-v2.Detail.Capacity.ViewUsageTrends">使用傾向を確認する</UI-TERM>** ボタンをクリックすると、時間を指定して特定の期間内のデータディスク使用傾向をフィルタリングできます。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p><ul><li>テナントが属するクラスタでCPUオーバーコミットが有効になっている場合、<b>容量使用状況</b>には、クラスタ内の各テナントの最大CPU割り当てコア数と最小CPU割り当てコア数が表示されます。</li><li>OceanBaseがV4.0未満のバージョンの場合、<b>ログディスク</b>データの確認はサポートされていません。</li><li>クラスタがAIクラスタ（共有ストレージ形態）の場合、<b>データディスク</b>は<b>キャッシュディスク</b>として表示されます。</li></ul></p>
   </main>

   ![Image 79](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%AE%B9%E9%87%8F%E4%BD%BF%E7%94%A8%E6%80%BB%E8%A7%88.png)

7. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** エリアで、テナント名、タグ、OceanBaseバージョン番号、テナントモード、Zone優先順位、読み取り専用かどうか、ロックされているかどうか、ステータス、作成日時などの基本情報を確認します。

   * テナントタグ上にカーソルを合わせると、そのテナントのすべてのタグ情報を確認できます。編集アイコンをクリックしてタグを管理することもできます。操作の詳細については、[タグの管理](../1600.system-management-features/300.manage-tags/100.tags-overview.md)を参照してください。
   * テナントのロックおよびクローン操作をサポートしています。詳細については、[テナントのロック](../700.tenant-functions/600.manage-a-tenant/300.locked-a-tenant.md)および[テナントのクローン](../700.tenant-functions/600.manage-a-tenant/350.clone-a-tenant.md)を参照してください。

   ![16](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E9%9B%86%E7%BE%A4%E5%85%8B%E9%9A%86%E7%A7%9F%E6%88%B7.png)

8. **テナントパフォーマンスTOP5**セクションでは、現在のクラスタ内でワークロードが最も高い上位5つのテナントのパフォーマンス情報を確認できます。これには、QPS、TPS、SQL応答時間、トランザクション応答時間、セッション数、イベント待機回数、イベント待機時間、容量_テーブル数、容量_パーティション数などのパフォーマンス監視指標が含まれます。また、ビジネスニーズに応じて、直近1時間、直近1日、または直近1週間の監視情報を確認することもできます。

   ![18](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4772988061/p200735.png)

   パフォーマンス監視指標の説明は以下の表のとおりです。

   |   指標名    |          説明          |           データソース            |
   |----------|----------------------|---------------------------|
   | QPS      | 1秒あたりの平均SQL文処理数（回/s）  | v$sysstat                 |
   | TPS      | 1秒あたりの平均トランザクション処理数（回/s）       | v$sysstat                 |
   | SQL応答時間 | SQL応答時間（μs）         | v$sysstat                 |
   | トランザクション応答時間   | サーバー側の各トランザクションの平均処理時間（μs）    | v$sysstat                 |
   | セッション数      | 現在のアクティブセッション数（個）と現在のセッション数（個） | __all_virtual_processlist |
   | イベント待機回数  | 1秒あたりの平均イベント待機回数（回/s）       | v$system_event            |
   | イベント待機時間  | 待機中の各イベントの平均待機時間（μs）    | v$system_event            |
   | 容量_テーブル数量   | テーブル数（個）               | gv$table                  |
   | 容量_パーティション数量  | パーティション数（個）              | v$partition               |
