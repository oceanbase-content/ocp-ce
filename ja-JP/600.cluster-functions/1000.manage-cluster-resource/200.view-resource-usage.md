# リソース使用状況の確認

リソース使用状況で、現在のクラスタのリソース使用傾向を確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.util.menu.ResourceManagement">リソース管理</UI-TERM>** メニュー権限。

## リソース使用傾向の確認

**<UI-TERM key="ocp-v2.Detail.Resource.Trend.ResourceUsageTrends">リソース使用傾向</UI-TERM>** モジュールで、現在のクラスタの **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.AllocatedCpu">割り当てられたCPU</UI-TERM>**、**<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.AllocatedMemory">割り当てられたメモリ</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Resource.Trend.LogDiskUsed">使用済みログディスク</UI-TERM>**、**<UI-TERM key="ocp-v2.Resource.Component.Block.UsedDisks">データディスクはすでに使用されています</UI-TERM>**、および **<UI-TERM key="ocp-v2.Detail.Resource.Trend.PartitionCopy">パーティションレプリカ</UI-TERM>** のトレンドグラフを確認できます。

そのうち、**<UI-TERM key="ocp-v2.Resource.Component.Block.AllocatedCpu">割り当て済みのCPU</UI-TERM>** と **<UI-TERM key="ocp-v2.Resource.Component.Block.AllocatedMemory">割り当て済みのメモリ</UI-TERM>** はリソース割り当て状況の傾向を示し、**<UI-TERM key="ocp-v2.Detail.Resource.Trend.LogDiskUsed">使用済みログディスク</UI-TERM>** と **<UI-TERM key="ocp-v2.Detail.Resource.Trend.UsedDisks">データディスクはすでに使用されています</UI-TERM>** はリソース使用状況の傾向を示します。**<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.AllocatedCpu">割り当てられたCPU</UI-TERM>** と **<UI-TERM key="ocp-v2.Cluster.Component.WaterLevel.AllocatedMemory">割り当てられたメモリ</UI-TERM>** の使用傾向曲線上で、マウスカーソルをリソース変更の時間点に合わせると、現在の時間点でのリソース割り当てが前回のリソース割り当て時点と比較したイベントを確認できます。このイベント情報は、2つのリソース割り当てデータの差分分析に基づいて生成されるため、すべての関連イベントが含まれているわけではありません。

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>クラスタがV4.0以降のバージョンの場合、<strong>パーティションレプリカ</strong>のリソース使用傾向グラフは表示されません。</li>
<li>クラスタがV4.0未満のバージョンの場合、<strong>使用済みログディスク</strong>のリソース使用傾向グラフは表示されません。</li>
<li>リソース傾向のデータは1時間ごとに1点収集されるため、リソース割り当て・使用の履歴傾向を確認するのに適しており、リソースのリアルタイム変化を観察するのには適していません。</li>
<li>クラスタがAIクラスタ（共有ストレージ形態）の場合、<strong>使用済みデータディスク</strong>は<strong>使用済みキャッシュディスク</strong>として表示され、ローカルキャッシュディスクの使用状況を反映します。</li>
</ul>
</main>

* **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.OBServerWithExclude.All">すべて</UI-TERM>** をクリックし、ドロップダウンリストから **全部、zone1、zone2** または **zone3** を選択すると、異なる範囲のリソース使用状況の傾向をそれぞれ確認できます。

* **<UI-TERM key="ocp-v2.src.component.RangeTimeDropdown.LastWeek">最近1週間</UI-TERM>** をクリックし、ドロップダウンリストから直近1週間、直近1ヶ月、直近6ヶ月、または直近1年を選択すると、異なる期間のリソース使用状況の傾向を確認できます。

* **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.CreateArbitrationGroup.Percentage">パーセント</UI-TERM>** または **<UI-TERM key="ocp-v2.Detail.Resource.Trend.AbsoluteValue">絶対値</UI-TERM>** をクリックすると、トレンドグラフの表示モードを切り替えることができます。

* 各トレンドグラフのフィルターアイコンをクリックすると、異なるZoneのリソース使用状況をそれぞれ確認できます。

## リソース割り当ての確認

リソース割り当てセクションでは、**テナント名、割り当て済みCPU(コア)、割り当て済みメモリ(G)、割り当て済みログディスク、使用済みデータディスク**、および **<UI-TERM key="ocp-performance-report.ReportTable.BasicInfo.TenantBasicInfo.NumberOfReplicas">レプリカ数</UI-TERM>** を確認できます。テナント名をクリックすると、対応するテナント概要ページに移動できます。

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>クラスタがV4.0以降のバージョンの場合、<strong>レプリカ数</strong>列のデータは表示されません。</li>
<li>クラスタがV4.0未満のバージョンの場合、<strong>割り当て済みログディスク</strong>列のデータは表示されません。</li>
<li>クエリコストが高いため、テナントのリソース割り当て統計クエリではキャッシュが使用され、現在の実際の状況と最大で2分の偏差が生じる可能性があります。一部の割り当て済みリソースがどのテナントにも属していない場合、そのテナント列にはN/Aと表示され、解放可能なリソースを示します。</li>
<li>クラスタがAIクラスタ(共有ストレージ形態)の場合、<strong>使用済みデータディスク</strong>は<strong>使用済みキャッシュディスク</strong>として表示されます。</li>
</ul>
</main>
