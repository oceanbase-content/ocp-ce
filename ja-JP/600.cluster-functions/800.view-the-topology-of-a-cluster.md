# クラスタのトポロジーダイアグラムを表示する

OCPは新しいトポロジーダイアグラム機能を提供しており、クラスタやテナント内の各ゾーンとOBServerノード間の論理的な関係を確認できます。

## 前提条件

クラスタの **<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">トポロジーダイアグラム</UI-TERM>** ページでは、操作によってユーザーが持つ必要がある権限が異なります。

* **トポロジーダイアグラム情報の表示**

  OceanBaseクラスタのID、クラスタタイプ（プライマリまたはスタンバイ）、クラスタの現在の状態、スタンバイデータベースの遅延時間、クラスタのアービトレーションサービスのアドレス、アービトレーションサービスの現在の状態、アービトレーションサービスの詳細情報、クラスタ内のテナントでアービトレーションサービスが有効な場合、ゾーン名、ゾーンの現在の状態、ゾーン内の実行情報、サーバーIPアドレス、サーバーの現在の状態、サーバー内の実行情報などを確認するには、OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">トポロジーダイアグラム</UI-TERM>** メニュー権限。

* **運用保守操作の実行**

  スタンバイクラスタの作成、ゾーンの追加、ゾーンの編集、OBServerノードの追加、バージョンのアップグレード、パスワードの変更、クラスタの再起動、クラスタの停止、クラスタの削除、スタンバイクラスタからプライマリクラスタへの切り替え、クラスタの表示、ゾーンの再起動、ゾーンの停止、ゾーンの削除、再起動、OBServerの起動、OBServerサービスの停止、observerプロセスの停止、OBServerの交換、OBServerの削除などを実行するには、OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">トポロジーダイアグラム</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.Search.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のクラスタを選択し、そのクラスタ名をクリックすると、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.TopologicalGraph">トポロジーダイアグラム</UI-TERM>** をクリックすると、クラスタのトポロジーダイアグラムページに移動します。

   * クラスタのバージョンがV4.0以下の場合、ページの左上に保護モードの情報が表示されます。詳細については、[クラスタ概要ページの概要](300.manage-a-cluster/200.overview-of-the-cluster-details-page.md)を参照してください。

   * スタンバイクラスタの上には同期状態が表示されます。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%9B%86%E7%BE%A4%E4%BB%B2%E8%A3%81%E6%9C%8D%E5%8A%A1.png)

   ページの右上にはいくつかの機能ボタンがあり、これらのボタンを使用してトポロジーダイアグラムのサイズを調整したり、現在のトポロジーダイアグラムを更新したりできます。

   トポロジーダイアグラムは上から下にかけて、クラスタ、クラスタアービトレーションサービス、ゾーン、サーバーの4層に分かれています。ゾーンの下にある **+** をクリックすると、そのゾーンのすべてのサーバーを展開して表示できます。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p><b>クラスタアービトレーションサービス</b> は、クラスタにアービトレーションサービスが追加された後にのみ表示されます。追加されていない場合は表示されません。</p>
   </main>

### クラスタ

クラスタアイコンには、OceanBaseクラスタのID、クラスタタイプ（プライマリまたはスタンバイ）、およびクラスタの現在の状態が表示されます。スタンバイクラスタのアイコンには、現在のスタンバイデータベースの遅延時間も表示されます。また、トポロジーマップ上にはクラスタの管理エントリも提供されています。

プライマリクラスタでは、新しいスタンバイクラスタの作成、Zoneの追加、Zoneの編集、OBServerノードの追加、バージョンのアップグレード、パスワードの変更、クラスタの再起動、クラスタの停止、およびクラスタの削除などの操作を実行できます。スタンバイクラスタでは、プライマリクラスタへの切り替えやクラスタの表示などの操作を実行できます。

### クラスタアービトレーションサービス

クラスタアービトレーションサービスアイコンには、クラスタアービトレーションサービスのアドレスとそのサービスの状態が表示されます。

マウスカーソルをクラスタアービトレーションサービスアイコンに合わせると、アービトレーションサービスの完全な情報や、クラスタ内のテナントでアービトレーションサービスが有効になっている状況を確認できます。

### Zone

Zoneアイコンには、Zone名とZoneの現在の状態が表示されます。

マウスカーソルをZoneアイコンに合わせると、現在のZoneで稼働している情報、QPS、接続数、Unit数を確認できます。

また、トポロジーマップ上にはZoneの管理エントリも提供されており、Zoneに対してOBServerノードの追加、再起動、停止、およびZoneの削除などの操作を実行できます。

### Server

Serverアイコンには、ServerのIPアドレスとServerの現在の状態が表示されます。

マウスカーソルをServerアイコンに合わせると、現在のServerで稼働している情報、QPS、接続数、SQLポートを確認できます。

また、トポロジーマップ上にはServerの管理エントリも提供されており、Serverに対して再起動、起動、サービスの停止、プロセスの停止、置換、削除などの操作を実行できます。
