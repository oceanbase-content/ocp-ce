# observerプロセスの停止

このページでは、observerプロセスを停止する操作について説明します。observerプロセスを停止すると、OBServerノードが使用できなくなり、サービスを提供できなくなるため、慎重に操作してください。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**リソース権限。
  * クラスタ**<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>**メニュー権限。

* お使いのOceanBaseクラスタが現在のOCPで管理されていること。

  現在のOCPで管理されていない場合は、[クラスタの引き継ぎ](../300.manage-a-cluster/400.take-over-a-cluster.md)を参照して、OceanBaseクラスタを現在のOCPに引き継いでください。

* スタンドアロンではobserverプロセスの停止はサポートされていません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ClusterWithExclude.Cluster">クラスタ</UI-TERM>**をクリックすると、システムはデフォルトで**<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>**で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの**<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>**エリアで、停止するOBServerノードを選択し、操作列の**<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.StopProcess">プロセスを停止する</UI-TERM>**をクリックします。

   ![Image 169](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E5%81%9C%E6%AD%A2%E8%BF%9B%E7%A8%8B.png)

5. ダイアログボックスで、プロセス停止前にダンプ操作を実行するかどうかを選択し（デフォルトで実行）、**<UI-TERM key="ocp-v2.src.constant.oceanbase.StopProcess">プロセスを停止する</UI-TERM>**をクリックします。

   ダンプ操作を実行すると、プロセス停止の応答時間が長くなりますが、OBServerの復旧時間を大幅に短縮できます。

6. タスクが送信された後、ポップアップウィンドウの**<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">タスクを確認する</UI-TERM>**ボタンをクリックすると、停止の進捗状況を確認できます。また、**<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>**でそのタスクの進捗状況を確認することもできます。

   そのタスクの状態が**<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>**であり、かつクラスタの**<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>**ページの**<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>**におけるそのobserverプロセスの状態が**<UI-TERM key="ocp-v2.page.Overview.Stopped">停止済み</UI-TERM>**の場合、停止は成功です。
