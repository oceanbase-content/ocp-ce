# OBServerノードの再インストール

このページでは、OBServerノードの再インストール操作について説明します。OBServerノードを再インストールすると、現在のホスト上からOBServerノードが削除され、再インストールされます。これにより、問題のあるOBServerノードを迅速に復元できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* お使いのOceanBaseクラスタが現在のOCPで管理されていること。

  もし現在のOCPで管理されていない場合は、[クラスタの引き継ぎ](../300.manage-a-cluster/400.take-over-a-cluster.md)を参照して、OceanBaseクラスタを現在のOCPに引き継いでください。

* 操作対象のホストがオンライン状態にあること。

* スタンドアロンではOBServerノードの再インストールはサポートされていません。

* クラスタ内のZoneにOBServerノードが1つしかなく、そのノードにレプリカが存在する場合は、再インストールを行うことはできません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Cluster.New.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>** エリアで、再インストールが必要なOBServerノードを選択し、操作列の **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Host.Reload">再インストール</UI-TERM>** をクリックします。

   ![09161858](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E9%87%8D%E8%A3%851.png)

5. ポップアップウィンドウに **reinstall** と入力し、**<UI-TERM key="ocp-v2.src.constant.oceanbase.Reload">再インストール</UI-TERM>** をクリックします。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>再インストールを確認する前に、再インストールが必要なOBServerノードの情報を確認する必要があります。これには、ホストIPアドレス、所属クラスタ、所属zone、CPUアーキテクチャが含まれます。</li>
    <li>再インストールにより、このOBServerノードのすべてのデータがクリーンアップされます。慎重に操作してください。</li>
    </ul>
   </main>

    ![09161858](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E9%87%8D%E8%A3%85observer1.png)

6. **<UI-TERM key="ocp-v2.Binlog.Component.StopBinlogModal.Ok">確定</UI-TERM>** をクリックして、再インストール操作を再度確認します。

7. ポップアップウィンドウ内のタスクIDをクリックすると、再インストールの進捗状況を確認できます。また、**<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でそのタスクの進捗状況を確認することもできます。

   タスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>** にこのOBServerノードが表示されない場合、削除は成功です。
