# OBServerノードの削除

このページでは、OBServerノードの削除操作について説明します。削除処理中、そのOBServerノード上のUnitは同一ゾーン内の他のOBServerノードに自動的に移行されます。同一ゾーン内の他のOBServerノードの利用可能なリソースが不足している場合、Unitの移行が失敗し、削除対象のOBServerノード上の他のデータと共に削除され、復元できなくなるため、ご注意ください。

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>クラスタがAIクラスタ（共有ストレージ形態）の場合、OBServerノードを削除しても、そのオブジェクトストレージ上のデータは即座に削除されず、徐々に回収されます。</li>
<li>OBServerノードを削除した後、オブジェクトストレージの使用容量がすぐに減少しないことがあります。容量が逼迫している状況で、すぐに新しいテナントを作成したり、大量のデータをインポートしたりすると、共有ストレージ容量が不足する可能性があります。事前にストレージ容量を計画しておいてください。</li>
</ul>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* お使いのOceanBaseクラスタが現在のOCPで管理されていること。

  もしお使いのOceanBaseクラスタが現在のOCPで管理されていない場合は、[クラスタの引き継ぎ](../300.manage-a-cluster/400.take-over-a-cluster.md)を参照して、OceanBaseクラスタを現在のOCPに引き継いでください。

* スタンドアロンではOBServerノードの削除はサポートされていません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>** エリアで、停止するOBServerノードを選択し、操作列の **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Credential.Binlog.Delete">削除</UI-TERM>** をクリックします。

   ![09161858](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%88%A0%E9%99%A4observer.png)

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.component.TenantList.Delete">削除</UI-TERM>** をクリックします。

   ポップアップウィンドウの **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、削除の進捗状況を確認できます。また、**<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** でこのタスクの進捗状況を確認することもできます。

   このタスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>** にそのOBServerノードが表示されなくなったら、削除は成功です。
