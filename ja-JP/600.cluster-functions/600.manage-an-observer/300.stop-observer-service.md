# OBServerノードサービスの停止

このページでは、OBServerノードを停止する操作について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* お使いのOceanBaseクラスタが現在のOCPで管理されていること。

  もしお使いのOceanBaseクラスタが現在のOCPで管理されていない場合は、[クラスタの引き継ぎ](../300.manage-a-cluster/400.take-over-a-cluster.md)を参照して、OceanBaseクラスタを現在のOCPに引き継いでください。

* スタンドアロンではOBServerノードサービスの停止はサポートされていません。

* （オプション）OBServerノードを停止しても業務に影響を与えたくない場合は、停止対象のOBServerノードが存在するZone内に他のOBServerノードがあり、リソースが十分である必要があります。

  この場合、OBServerノードを停止すると、その上のUnitは自動的に他のOBServerノードに切り替わり、業務への影響はありません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Cluster">クラスタ</UI-TERM>** をクリックします。システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のクラスタを選択し、そのクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>** エリアで、停止するOBServerノードを選択し、操作列の **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.StopService">サービス停止</UI-TERM>** をクリックします。

   ![09161854](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%81%9C%E6%AD%A2%E6%9C%8D%E5%8A%A1.png)

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.src.constant.oceanbase.StopService">サービス停止</UI-TERM>** をクリックして、OBServerノードサービスを停止します。

   ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、停止の進捗状況を確認できます。また、**<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でこのタスクの進捗状況を確認できます。

   このタスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Component.OBServerList.ObserverList">OBServerリスト</UI-TERM>** におけるそのOBServerノードの状態が **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">停止済み</UI-TERM>** になったら、停止は成功です。
