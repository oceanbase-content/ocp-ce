# 新規クラスタの関連付け

このセクションでは、アービトレーションサービスに新規クラスタを関連付ける方法について説明します。アービトレーションサービスには、1つまたは複数のクラスタを関連付けることができます。新規クラスタを関連付ける前に、アービトレーションサービスのリソース構成（CPU/メモリ/ディスク容量）を適切に評価し、異常な状況下で単一のアービトレーションサービスがビジネス負荷をサポートできないことを防いでください。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **アービトレーションサービスのメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* アービトレーションサービスが **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常に稼働</UI-TERM>** 状態であること。
* 関連付けるOceanBaseクラスタとアービトレーションサービスのメジャーバージョン番号およびマイナーバージョン番号が一致していること。例：OceanBaseクラスタのバージョンとアービトレーションサービスのバージョンがどちらもV4.2.x.xである場合。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-performance-report.ReportTables.SqlInfo.SQLInfoTable.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ArbitrationService">アービトレーションサービス</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.src.constant.information.ArbitrationService">アービトレーションサービス</UI-TERM>** リストページに移動します。

4. クラスタを関連付けるアービトレーションサービスを選択し、操作列で **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.Cluster.Component.AssociateNewClusterDrawer.AssociateANewCluster">新しいクラスタの関連付け</UI-TERM>** を選択します。

5. ポップアップパネルで、関連付けるOceanBaseクラスタを選択します。また、4F/2Fタイプのテナントのアービトレーションサービスを有効にするかどうかを選択します。有効にすると、クラスタ配下のテナントも自動的にテナントアービトレーションサービスが有効になります。

6. **<UI-TERM key="ocp-v2.Cluster.Component.AssociateNewClusterDrawer.Association">関連</UI-TERM>** をクリックします。
