# アービトレーションサービスの起動

この記事では、アービトレーションサービスの起動方法について説明します。アービトレーションサービスが停止状態の場合、この機能を使用して起動できます。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **アービトレーションサービスのメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* アービトレーションサービスが **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">停止済み</UI-TERM>** 状態にあること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.Cluster.1">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Detail.Component.ReplaceArbitrationServerDrawer.ArbitrationService">アービトレーションサービス</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.src.constant.plan.ArbitrationService">アービトレーションサービス</UI-TERM>** リストページに移動します。

4. 起動するアービトレーションサービスを選択し、右側の操作列の **<UI-TERM key="ocp-v2.src.constant.oceanbase.StartTheService">サービスを開始する</UI-TERM>** をクリックします。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.src.util.component.Start">起動</UI-TERM>** をクリックします。

    サービスを起動すると、関連付けられたクラスタとテナントは引き続きそのアービトレーションサービスを使用します。
