# アービトレーションサービスの削除

この記事では、ホスト上からアービトレーションサービスを削除する方法について説明します。この操作により、アービトレーションサービスのサービスプロセスと関連データが削除されます。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationServiceManagement">アービトレーションサービス管理</UI-TERM>** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* アービトレーションサービスが **<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常に稼働</UI-TERM>** 状態である必要があります。
* OceanBaseクラスタがこのアービトレーションサービスを使用している場合は、削除できません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationService">アービトレーションサービス</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.Cluster.New.ArbitrationService">アービトレーションサービス</UI-TERM>** リストページに移動します。

4. 削除するアービトレーションサービスを選択し、操作列で **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.DeleteAService">サービスの削除</UI-TERM>** を選択します。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.User.Component.DeleteUserModal.Delete">削除</UI-TERM>** をクリックします。
