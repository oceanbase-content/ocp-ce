# アービトレーションサービスの再起動

この記事では、アービトレーションサービスを再起動する方法について説明します。

<main id="notice" type='notice'>
<h4>適用対象</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **アービトレーションサービスメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* アービトレーションサービスが **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常に稼働</UI-TERM>**、または **<UI-TERM key="ocp-v2.page.Overview.Unavailable">利用不可</UI-TERM>** のいずれかの状態であること。
* アービトレーションサービスに関連付けられたテナントでログストリームの降格が発生していないこと。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.inspection.Cluster">クラスタ</UI-TERM>** をクリックします。システムはデフォルトで **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.RepalceDrawer.ArbitrationService">アービトレーションサービス</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.ArbitrationService">アービトレーションサービス</UI-TERM>** リストページに移動します。

4. 再起動するアービトレーションサービスを選択し、操作列で **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.RestartTheService">サービスの再起動</UI-TERM>** を選択します。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Plan.Component.UpdateDrawer.Confirm">確認</UI-TERM>** をクリックします。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>再起動中は、アービトレーションサービスに関連付けられたクラスタやテナントがそのアービトレーションサービスを利用できなくなります。慎重に操作してください。</p>
    </main>
