# アービトレーションサービスの停止

アービトレーションサービスを使用しなくなった場合、この機能を使用して停止できます。

<main id="notice" type='notice'>
<h4>適用対象</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Arbitration Service Maintenance** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* アービトレーションサービスが **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">正常に稼働</UI-TERM>** 状態にあること。
* アービトレーションサービスに関連付けられたテナントでログストリームの降格がないこと。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Overview.Cluster">クラスタ</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.component.HostSelect.ArbitrationService">アービトレーションサービス</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.src.constant.auth.ArbitrationService">アービトレーションサービス</UI-TERM>** リストページに移動します。

4. 停止するアービトレーションサービスを選択し、右側の操作列の **<UI-TERM key="ocp-v2.src.constant.oceanbase.StopService">サービス停止</UI-TERM>** をクリックします。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.src.util.component.Stop">停止</UI-TERM>** をクリックします。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>アービトレーションサービスを停止すると、そのサービスに関連付けられたクラスタやテナントはアービトレーションサービスを利用できなくなります。慎重に操作してください。</p>
    </main>
