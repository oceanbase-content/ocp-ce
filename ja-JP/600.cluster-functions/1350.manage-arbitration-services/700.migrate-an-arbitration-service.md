# アービトレーションサービスの移出

この記事では、アービトレーションサービスを移出する方法について説明します。OCPでのアービトレーションサービスの管理を続けたくない場合は、この記事を参考に移出してください。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **<UI-TERM key="ocp-v2.Cluster.Arbitration.ArbitrationServiceManagement">アービトレーションサービス管理</UI-TERM>** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

* アービトレーションサービスは、**<UI-TERM key="ocp-v2.page.Overview.Stopped">停止済み</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常に稼働</UI-TERM>**、または **<UI-TERM key="ocp-v2.page.Overview.Unavailable">利用不可</UI-TERM>** の状態である必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.Cluster">クラスタ</UI-TERM>** をクリックします。システムはデフォルトで **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.RepalceDrawer.ArbitrationService">アービトレーションサービス</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.ArbitrationService">アービトレーションサービス</UI-TERM>** リストページに移動します。

4. 移出したいアービトレーションサービスを選択し、操作列で **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.oceanbase.RelocationService">転出サービス</UI-TERM>** を選択します。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Cluster.Arbitration.MoveOut">転出</UI-TERM>** をクリックします。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>アービトレーションサービスの移出は、アービトレーションサービスとOCPの関連付けを解除するだけであり、アービトレーションサービス自体の状態には影響しません。</p>
    </main>

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E8%BF%81%E5%87%BA%E4%BB%B2%E8%A3%81%E6%9C%8D%E5%8A%A11.png)

6. アービトレーションサービスを移出した後、該当アービトレーションサービスに関連付けられたテナントは、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページでアービトレーションサービスを無効にできます。
