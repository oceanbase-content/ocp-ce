# リアルタイム監視の表示

リアルタイム監視は、クラスタリソースの分布と関連性をグローバルな視点で表示し、システム状況の把握、業務監視、障害の迅速な特定を支援します。これにより、システム性能の管理と最適化を効果的に行い、システムの安定性と信頼性を向上させることができます。

## 背景

分散データベース環境におけるエンドツーエンドのパフォーマンス監視と障害特定の複雑さに対応するため、OCPはエンドツーエンドのリアルタイム監視ソリューションを導入しました。OBProxy – OceanBaseクラスタ – テナント – ホスト – Unitにわたる5層の監視体系を構築し、3つのコア機能によって運用保守体験を再構築します。

* **3Dトポロジー可視化によるアーキテクチャ全体の透視**

動的3D可視化エンジンを採用し、OBProxyとクラスタ、クラスタとホスト、テナントとOBServer間の論理関係と物理配置を立体的に表現します。トポロジーレベルのドリルダウンに対応しており、グローバルアーキテクチャから個々のUnitまで段階的に詳細を見ることができ、リソースの分布と依存関係を直感的に示します。これにより、分散アーキテクチャの「ブラックボックス」とされる運用状態を可視化します。

* **全方位のメトリクス監視による秒単位での異常特定**

QPS、TPS、RT、接続数、CPU/メモリ使用率など10種類以上のコアパフォーマンスメトリクスをリアルタイムに集約し、パフォーマンス監視の傾向比較分析と組み合わせることで、パフォーマンスの転換点を正確に特定します。トポロジーマップ上で関連するアラート数を直接確認し、アラートセンターにジャンプすることができます。これにより、メトリクスの異常から障害の根本原因までワンクリックで追跡でき、障害特定の効率が向上します。

* **デュアルモードのデータ表示による多次元運用保守シナリオへの対応**

構造化されたテーブル形式のデータビューを提供し、グラフィカル情報と数値情報の補完により、管理者のグローバルな状況認識ニーズを満たすとともに、技術者に深層分析のためのデータサポートを提供します。これにより、分散システムの理解と管理のハードルを効果的に低くします。

## 前提条件

* リアルタイム監視の表示は、OceanBase V4.x以降のバージョンでのみサポートされています。
* 3Dビューは最大30台のホストの表示をサポートします。ホスト数がこの制限を超える場合は、テーブルビューでのみ表示が可能です。

## 注意事項

* クラスタに多数のホスト、テナント、Unitリソースが含まれる場合、リアルタイム監視ではパフォーマンスの制限が生じる可能性があります。各種監視指標を確認するために、テーブルビューに切り替えることを推奨します。
* 一部の監視対象のメトリクス収集時刻に差異があるため、データの時系列に不整合が生じる可能性があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.Overview.Cluster">クラスタ</UI-TERM>**をクリックすると、システムはデフォルトで**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>**ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>**で操作対象のクラスタを選択し、そのクラスタ名をクリックすると、クラスタの**<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>**ページに移動します。

4. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.RealTimeMonitoring">リアルタイム監視</UI-TERM>**をクリックします。

### 3Dビューでのリアルタイム監視データの表示

システムはデフォルトで3Dビューでリアルタイム監視データを表示します。3Dビューの画面上では、リアルタイム監視データが左側のデータパネルと右側のトポロジーマップという2つのモジュールを通じて動的に表示されます。

**概要データの確認**

* 左側のデータパネルには、現在のクラスタのリソースオブジェクト概要とアラート統計概要が表示されます。

* 右側のトポロジーダイアグラムは、現在のクラスタに関連付けられたサービスのリソース情報を表示します。OBProxyクラスター、OceanBaseクラスター、ゾーン間のトポロジー関係と全体的な概要を直感的に確認できます。

  * 関連付けられたサービスのすべてのリソースオブジェクトを表示できます。これには、すべてのOBProxy Serverリソース、すべてのテナントリソース、およびすべてのホストリソースが含まれます。

  * 異なる色を用いてリソースオブジェクトの健全性を示します。色ごとに異なるレベルのアラート情報が存在することを示しており、具体的には：紫色がサービス停止アラート、赤色が重大アラート、オレンジ色が警告アラート、緑色がアラートなしを表します。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/09181106.png)

**詳細データの表示**

表示したいリソースオブジェクトをクリックするか、カーソルを合わせると詳細データを確認できます。

* 左側のデータパネルには、そのリソースの基本情報、アラート概要、およびパフォーマンスの主要指標が表示されます。表示される指標情報はリソースオブジェクトによって異なります。以下の表を参照してください。

  |  オブジェクトタイプ   |  指標情報   |
  |-------------|-------------|
  | OBProxyクラスタ | クラスタ名、状態、QPS、TPS、RT、リクエスト失敗回数、クライアント接続数、クライアント接続利用率、プロセスメモリ使用率。  |
  | OBProxy Server | IP、状態、QPS、TPS、RT、リクエスト失敗回数、クライアント接続数、クライアント接続利用率、プロセスメモリ使用率。  |
  | OceanBaseクラスタ | クラスタ名、状態、QPS、TPS、セッション数、アクティブセッション数、リーダーレプリカ数、RT。   |
  | テナント  | テナント名、状態、QPS、TPS、RT、セッション数、アクティブセッション数、スレッド利用率、CPU消費量、リーダーレプリカ数、リクエスト待ち行列時間、リクエスト待ち行列サイズ、およびテナントのすべてのUnit情報。<br><ul>ここで：<li>Unit指標情報には、所属OBServer、仕様、QPS、TPS、RT、セッション数、アクティブセッション数、スレッド利用率、CPU消費量、リーダーレプリカ数、リクエスト待ち行列サイズ、リクエスト待ち行列時間が含まれます。Unitはデフォルトですべての監視項目を表示します。特定の監視項目に注目する必要がない場合は、フィルターボタンをクリックして、パネル内でその監視項目のチェックを外すことができます。</li><li>所属OBServerのIPをクリックするか、カーソルを合わせると、そのIPのOBServerとホストの指標情報を確認できます。</li></ul> |
  | OBServer | IP、状態、QPS、TPS、セッション数、アクティブセッション数、リーダーレプリカ数、および対応するUnit情報。<br><ul>ここで：<li>Unit指標情報には、所属テナント、仕様、QPS、TPS、RT、セッション数、アクティブセッション数、スレッド利用率、CPU消費量、リーダーレプリカ数、リクエスト待ち行列サイズ、リクエスト待ち行列時間が含まれます。Unitはデフォルトですべての監視項目を表示します。特定の監視項目に注目する必要がない場合は、フィルターボタンをクリックして、パネル内でその監視項目のチェックを外すことができます。</li><li>所属テナントをクリックするか、カーソルを合わせると、そのテナントの指標情報を確認できます。</li></ul>  |
  | ホスト  | IP、状態、CPU使用率、メモリ使用率、ディスクI/O使用率、TCP再送信率、ディスク使用率、NTP時刻ずれ、ネットワークスループット（送信）、ネットワークスループット（受信）。 |

* 右側のトポロジーダイアグラムは、流れるような線でリソースオブジェクトの上下流依存関係を示しています。

## 関連操作

* **自動更新頻度の変更**：システムはデフォルトで30秒ごとに監視データを更新します。実際の状況に応じて、**<UI-TERM key="ocp-v2.Component.overview.Seconds">10秒</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.RealtimeMonitor.utils.Seconds.2">20秒</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.RealtimeMonitor.utils.Minute">1分</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.RealtimeMonitor.utils.Minutes">2分</UI-TERM>**、または **<UI-TERM key="ocp-v2.src.constant.Minutes.1">5 分間</UI-TERM>** に変更できます。変更後、システムは選択した頻度で自動的に監視データを更新します。
* **アラートの詳細を見る**：モニタリング対象にアラートが存在する場合、該当するアラートレベルをクリックすると、アラートページに移動してアラートの詳細を確認できます。
* **トポロジーダイアグラムの調整**：
  * 画面上の空白部分をマウスでドラッグすることで、トポロジーダイアグラムを自由に移動できます。
  * ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/09181117.png) をクリックすると、トポロジーダイアグラムを全画面モードに切り替えることができます。
  * 拡大/縮小アイコンをクリックするか、マウスホイールを上下にスクロールすることで、トポロジーダイアグラムを拡大または縮小できます。
  * ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/09151453.png) をクリックすると、トポロジーダイアグラムを元のサイズに素早く戻すことができます。
  * ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/09151456.png) をクリックすると、トポロジーダイアグラムがキャンバスのサイズに自動的に調整されます。
