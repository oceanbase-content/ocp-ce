# ソフトウェアパッケージのアップロード

ソフトウェアパッケージ機能を使用して、OceanBaseインストールパッケージ、OCP Agentインストールパッケージ、OBProxyインストールパッケージ、Binlogインストールパッケージ、バックアップ・リカバリインストールパッケージ、その他のインストールパッケージをアップロードできます。また、ソフトウェアパッケージの名前、タイプ、バージョン、システム、ハードウェアアーキテクチャ、サイズ、アップロード時間などの情報を確認でき、ダウンロードや削除も行えます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* システム管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.SoftwarePackageManagement">ソフトウェアパッケージ管理</UI-TERM>** メニュー権限。

## 手順

1. 左側のナビゲーションバーで **システム管理 > ソフトウェアパッケージ管理** をクリックし、ソフトウェアパッケージページに移動します。

2. **<UI-TERM key="ocp-v2.Component.UpgradeDrawer.Upload">アップロード</UI-TERM>** をクリックし、ポップアップウィンドウで **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.SelectFile">ファイルを選択してください</UI-TERM>** をクリックして、ローカルにアップロードするソフトウェアパッケージを選択し、**<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.Ok">確定</UI-TERM>** をクリックします。

   サポートされているインストールパッケージのタイプは、OceanBase、Binlog、OCP Agent、OBProxy、バックアップ・リカバリ、その他です。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li><code>.rpm</code> または <code>tar.gz</code> 形式のインストールパッケージを最大10個まで一括アップロードできます。</li><li>お使いのシステムのバージョンが <code>debian</code> で、OCP Agentのインストールディレクトリをカスタマイズする必要がある場合は、<code>tar.gz</code> 拡張子を持つOCP Agentインストールパッケージを使用し、<code>ocp.agent.home.path.prefix</code> システムパラメータでインストールディレクトリをカスタマイズすることを推奨します。</li><li>アップロードするソフトウェアパッケージが非公式パッケージの場合、一定のリスクが伴うため、本番クラスタ環境へのデプロイは推奨されません。</li><li>Enterprise Edition OCPはアップロードされたソフトウェアパッケージに対して署名検証を行います。検証に失敗した場合は、ソフトウェアパッケージをアップロードできません。他のソフトウェアパッケージを選択して再アップロードすることを推奨します。</li></ul></p>
   </main>

3. アップロード完了後、ソフトウェアパッケージリストでパッケージ情報を確認できます。

## 次のステップ

ソフトウェアパッケージリストで、**ソフトウェアパッケージ名**、**タイプ**、**バージョン**、**システム**、**ハードウェアアーキテクチャ**、**サイズ(MiB)**、**アップロード時間** などの情報を確認できます。

* **タイプ**、**バージョン**、**システム**、**ハードウェアアーキテクチャ** でソフトウェアパッケージをフィルタリングできます。

* **ソフトウェアパッケージ名** と **<UI-TERM key="ocp-v2.page.Package.UploadTime">アップロード時間</UI-TERM>** でソフトウェアパッケージを並べ替えることができます。
