# ユーザーの作成

このセクションでは、ユーザーの作成方法について説明します。

## 背景

OCPでは、異なる権限を持つユーザーによる運用と管理を推奨しています。ユーザーに必要最小限の権限のみを付与することで、各ユーザーは自身の権限範囲内でのみ操作が可能となり、非専門家による誤操作や情報漏洩を防ぎ、情報セキュリティと伝統的なセキュリティを実現できます。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** 役割または **ORG_ADMIN** 役割であることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.src.constant.auditEvent.User">ユーザー</UI-TERM>** タブの右上にある **<UI-TERM key="ocp-v2.Auth.User.New.CreateAUser">ユーザー作成</UI-TERM>** をクリックします。

4. 新規ユーザーの基本情報を設定します。

   |  パラメータ     |       説明         |
   |-----------|---------------------------------------|
   | ユーザー名    | 必須。ルール：ユーザー名は小文字の英字で始まり、小文字の英字、数字、アンダースコア、ハイフン、および '.' の組み合わせで、長さは4～48文字です。ユーザー名は作成後変更できません。   |
   | パスワード      | 必須。ルール：長さは8～32文字で、数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字の4種類のうち、少なくとも3種類を含む必要があります。サポートされている特殊文字は <code>~!@#%^&*_-+=\|(){}[]:;,.?/$`'"<>\\</code> です。 |
   | メールアドレス      | 必須。         |
   | 携帯電話番号  | 任意。         |
   | 組織      | 必須。ログインユーザーが組織管理者（ORG_ADMIN）役割の場合、組織はグレーアウトされ選択できません。</br>対応する組織がない場合、ドロップダウンリストの **<UI-TERM key="ocp-v2.Auth.Role.AddRole.CreateAnOrganization">組織の作成</UI-TERM>** をクリックして、すぐに新しい組織を作成できます。          |
   | 部門      | 任意。         |
   | 説明      | 任意。         |

   ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/202412091405.png)

5. 新規ユーザーのロール情報を設定します。

   * 実際のニーズに応じて既存のロールを選択できます。少なくとも1つは選択する必要があります。

   * 既存のロールが適切でない場合、エリアの右上にある **<UI-TERM key="ocp-v2.User.Oracle.CreateARole">新しいロールを作成</UI-TERM>** をクリックし、[新規ロールの作成](../1600.system-management-features/200.manage-users/200.manage-a-role/100.create-a-role.md) を参照して設定するか、新しいロールを作成して新規ユーザーに割り当てることができます。

   * ログインユーザーが組織管理者（ORG_ADMIN）役割の場合、選択可能なのは組織内に存在するロールのみです。

   ![050807](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/202412091406.png)

6. **<UI-TERM key="ocp-v2.Auth.User.New.AccessControl">アクセス制御</UI-TERM>** のスイッチをオンにして、そのユーザーのアクセス制御を設定します。

   * アクセス回数の上限：ユーザーが1単位時間にOCPシステムにアクセスできる最大回数を設定します。

   * 厳密なアクセス制御：ユーザーが1時間にホスト、テナント、アラート、監視リソースにアクセスできる回数の上限を設定します。

   ![050806](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/202412091407.png)

7. ページの右下にある **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.Submitted">送信</UI-TERM>** をクリックします。
