# プライマリテナントの作成

テナントは、さまざまなデータベースオブジェクトのコンテナであると同時に、リソース（CPU、メモリ、I/Oなど）のコンテナでもあります。ビジネスニーズに応じて、クラスタ内にプライマリテナントを作成できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* テナントを作成するクラスタはプライマリクラスタであり、かつ実行中の状態である必要があります。

* 同一クラスタ内でテナント名が重複してはなりません。

* シングルマシンではデフォルトで1つのテナントしか作成できません。シングルマシンで複数のプライマリテナントを作成したい場合は、対応する機能オプションを購入し、[Licenseのインポート](../600.cluster-functions/300.manage-a-cluster/1400.import-license.md)を再度行う必要があります。

* テナントでアービトレーションサービスを有効にする前に、以下の情報を確認する必要があります：

  * テナントが属するクラスタにアービトレーションサービスが追加されており、アービトレーションサービスが **RUNNING** 状態にあること。

  * アービトレーションサービスを有効にするテナントのローカリティが2F（F：フル機能レプリカ）または4Fであること。

  * アービトレーションサービスが配置されているホストの残りリソースがリソース要件を満たしていること。

    このリソース要件はシステムパラメータで実際の状況に応じて変更できます。変更が必要なパラメータは以下の通りです。操作の詳細については、[システムパラメータの変更](../700.tenant-functions/1600.manage-tenant-parameters/200.modify-a-tenant-parameter.md)を参照してください。

    * `ocp.arbitration.min.remain.disk.size`：テナントアービトレーションを有効にする場合、アービトレーションサービスホストのCLOGディスクの残り最小値。単位はMBです。データ形式 (a,b) はテナントレプリカがそれぞれ2F、4Fの場合の値を表します。デフォルトは [12,24] です。
    * `ocp.arbitration.max.cpu.used.percentage`：テナントアービトレーションを有効にする場合、アービトレーションサービスホストの最大CPU利用率。単位は % です。デフォルト値は90です。
    * `ocp.arbitration.max.memory.used.percentage`：テナントアービトレーションを有効にする場合、アービトレーションサービスホストの最大メモリ利用率。単位は % です。デフォルト値は90です。

* AL 8以降の新しいLinuxカーネルを使用する場合、テナント作成時にOBServerが配置されているホストにPythonのシンボリックリンクが作成されていることを保証する必要があります。作成コマンドは `ln -s /usr/bin/python3 /usr/bin/python` を参考にしてください。同時に、OceanBaseの一部バージョンはPython3に対応しています。テナントが属するクラスタがV4.2.1.10、V4.2.5.1、V4.3.5、またはV4.4.xバージョンの場合、手動でPython3シンボリックリンクを作成する必要はありません。

* RHEL 8以降の新しいLinuxカーネルを使用する場合、ホストがPython3方式のインポートのみをサポートする場合：

  * デプロイされたOceanBase（el7/el8/al8）RPMパッケージがPython3とPython2の両方の方式をサポートする場合、Python3方式でインポートするのは以下のOceanBaseバージョンのみです：
    * (V4.2.1.7, V4.2.2)
    * (V4.2.4, V4.2.5.2)
    * (V4.3.2, V4.3.5.2)
  * デプロイされたOceanBase（el7/el8/al8）RPMパッケージがPython2方式のみをサポートする場合、以下のOceanBaseバージョンはインポートできません。この場合、Python2をサポートするホストにホストを交換する必要があります。
    * [V4.0.0, V4.2.1.7]
    * [V4.2.2, V4.2.4]
    * [V4.3.0, V4.3.2]

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.monitor.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Detail.Tenant.NewTenant">新規テナント</UI-TERM>** をクリックします。

     |   形式   |     例     |
     |--------|-------|
     | IPアドレス   | xxx.xxx.xxx.1,xxx.xxx.xxx.2    |
     | サブネット/マスク  | xxx.xxx.xxx.1/24     |
     | あいまい一致   | xxx.xxx.xxx.% または xxx.xxx.xxx._   |
     | 複数形式の混合 | xxx.xxx.xxx.1,xxx.xxx.xxx.2,xxx.xxx.xxx.%,xxx.xxx.xxx._,xxx.xxx.xxx.1/24 |
     | 特記事項   | % はすべてのクライアントが接続できることを表します      |

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>OCPマシンのアドレスおよび依存するOBProxyのアドレスは、このリストに含まれている必要があります。そうでない場合、OCPはこのテナントを管理できません。</p>
      </main>

7. **<UI-TERM key="ocp-v2.Cluster.New.ParameterConfiguration">パラメータ設定</UI-TERM>**モジュールを開き、テナントのパラメータを設定します。

    * **<UI-TERM key="ocp-v2.Tenant.New.BasicSettings">基本設定</UI-TERM>**で負荷タイプを設定した場合、システムはその負荷タイプに対応するパラメータテンプレートをデフォルトで選択します。

    * 起動パラメータ項目を個別に追加し、値を設定することができます。

    * また、**<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.SelectAParameterTemplate">パラメータテンプレートを選択</UI-TERM>**をクリックしてパラメータテンプレートを選択することもできます。システムは、選択したテンプレートのパラメータと設定を自動的にここに入力します。テナント用のパラメータテンプレートが作成されていない場合は、**新規テナントテンプレート**をクリックして、テナント用のパラメータテンプレートを作成できます。詳細については、[テナントパラメータテンプレートの管理](../700.tenant-functions/1700.manage-tenant-parameter-templates.md)を参照してください。

         システムでは、以下の4種類の組み込みテンプレートを提供しており、各テンプレートには一般的なパラメータ設定が含まれています。これらのテンプレートを直接適用して、クラスタの初期設定を行うことができます。システムの組み込みテンプレートについては、以下に具体的に説明します。

         | テンプレート | 説明 |
         |------|----------|
         | COMPLEX_OLTP デフォルトパラメータテンプレート   |  **Complex OLTP**負荷タイプに対応します。このテンプレートはOceanBase V4.2.5以降のバージョンでのみ使用できます。   |
         | HTAP デフォルトパラメータテンプレート   |   **HTAP**負荷タイプに対応します。このテンプレートはOceanBase V4.2.5以降のバージョンでのみ使用できます。 |
         | OLAP デフォルトパラメータテンプレート   |   **OLAP**負荷タイプに対応します。このテンプレートはOceanBase V4.3.0以降のバージョンでのみ使用できます。   |
         | EXPRESS_OLTP デフォルトパラメータテンプレート   |  **Express OLTP**負荷タイプに対応します。このテンプレートはOceanBase V4.2.5以降のバージョンでのみ使用できます。   |

    <main id="notice" type='explain'>
    <h4>説明</h4>
    テナントモードがMySQLであり、選択したパラメータテンプレートにOracle専用のパラメータが含まれている場合、テンプレートを適用した後、これらのパラメータを手動で削除する必要があります。
    </main>
