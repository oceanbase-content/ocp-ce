# ホストの追加

クラスタを作成する前に、使用するホストをOCPに追加する必要があります。1-1-1のクラスタを作成するには、4台のホストを追加する必要があります。3つのZoneはそれぞれ1台のホストを占有し、OBProxyが1台のホストを占有します。

## 前提条件

現在OCPにログインしているユーザーが**ADMIN**ロールまたは**ORG_ADMIN**ロールであること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.Host">ホスト</UI-TERM>**をクリックします。

3. **<UI-TERM key="ocp-v2.Report.Page.apiMapper.Host">ホスト</UI-TERM>**タブで、ページの右上隅にある**<UI-TERM key="ocp-v2.component.HostSelect.AddHost">ホストを追加する</UI-TERM>**をクリックします。

4. **<UI-TERM key="ocp-v2.src.component.AddHostDrawer.IpAddress">IPアドレス</UI-TERM>**と**SSHポート番号**を入力します。新しいホストのIPv4/IPv6アドレスを入力します。複数のIPアドレスを同時に追加することもできます（複数のIPアドレスは半角カンマで区切ります）。SSHポート番号はデフォルトで22です。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>ホストのIPアドレスがIPv6アドレスの場合、以下の制限があります：<ul>
   <li>OceanBase、OBClient、OBProxyのデプロイ時：<ul>
   <li>OceanBaseのバージョンは[V4.2.5 BP3 Hotfix3, V4.3.0)または[V4.3.5 BP2 Hotfix1, +∞)である必要があります。</li>
   <li>OBClientのバージョンは[V2.2.9, +∞)である必要があります。</li>
   <li>OBProxyのバージョンは[V4.3.4, +∞)である必要があります。</li>
   </ul></li></ul>
   <ul><li>Binlogサービスは、現在IPv6デプロイをサポートしていません。</li></ul>
   </ul>
   </p>
   </main>

5. マシンタイプを選択します。対応するマシンタイプがない場合、**<UI-TERM key="ocp-v2.src.component.HostTypeSelect.NewModel">機種を追加</UI-TERM>**をクリックすると、OCPに新しいマシンタイプを即座に追加できます。

   詳細な操作については、[マシンタイプの管理](../850.host-features/200.manage-host-type.md)を参照してください。

6. データセンターを選択します。対応するデータセンターがない場合、**<UI-TERM key="ocp-v2.src.component.IdcSelect.NewDataCenter">データセンターを追加</UI-TERM>**をクリックすると、OCPに新しいデータセンターを即座に追加できます。

   詳細な操作については、[データセンターの管理](../850.host-features/300.manage-idc.md)および[リージョンの管理](../850.host-features/400.mange-region.md)を参照してください。

7. ホストタイプを選択し、ホストの接続資格情報を選択して設定し、ホストのエイリアスを設定します。

   | パラメータ  |   説明   |
   |-------|----------|
   | ホストタイプ  |  追加するホストのタイプを選択します。物理マシンとECSが含まれます。  |
   | 資格情報  |  パスワードボックスから資格情報を選択します。対応する資格情報がない場合、**<UI-TERM key="ocp-v2.src.component.CredentialSelect.AddSecrets">認証情報を追加</UI-TERM>**をクリックして、そのホスト用に新しい接続資格情報を作成できます。<br><ul><li>資格情報名：英字で始まり、英字または数字で終わる、2～32文字の長さで、英字、数字、アンダースコアを含むことができます。</li><li>認証タイプ：**ユーザー名/パスワード**、**SSH秘密鍵**、**<UI-TERM key="ocp-v2.src.constant.compute.ConfiguredPasswordFree">パスワード不要の設定は既に完了しています</UI-TERM>**の3種類が含まれます。</li><li>ユーザータイプ：サーバーに接続するユーザータイプ。**<UI-TERM key="ocp-v2.src.constant.computeROOTUser">rootユーザー</UI-TERM>**と**<UI-TERM key="ocp-v2.src.constant.compute.OrdinaryUsers">一般ユーザー</UI-TERM>**の2種類がサポートされています。<ul><li>**<UI-TERM key="ocp-v2.src.constant.computeROOTUser">rootユーザー</UI-TERM>**：ROOT権限を持つSSHユーザー。</li><li>**<UI-TERM key="ocp-v2.src.constant.compute.OrdinaryUsers">一般ユーザー</UI-TERM>**：ROOT権限を持つ一般ユーザーです。このユーザーは、まず`/etc/sudoers`ファイルで一部のコマンドのsudo実行をパスワードレスで設定する必要があります。詳細については、本文末の**sudo権限の設定**を参照してください。</li></ul></li><li>ユーザー名：ユーザータイプが**<UI-TERM key="ocp-v2.src.constant.compute.OrdinaryUsers">一般ユーザー</UI-TERM>**の場合に入力します。サーバーに接続するユーザーを入力します。</li><li>パスワード：認証タイプが**ユーザー名/パスワード**の場合に入力します。サーバーに接続するパスワードを入力します。</li><li>秘密鍵：認証タイプが**SSH秘密鍵**の場合に入力します。サーバーにSSH資格情報を追加します。</li><li>OCPホスト秘密鍵ファイルパス：認証タイプが**<UI-TERM key="ocp-v2.src.constant.compute.ConfiguredPasswordFree">パスワード不要の設定は既に完了しています</UI-TERM>**の場合に入力します。ホスト秘密鍵ファイルの保存パスを入力します。デフォルトは`/home/admin/.ssh/id_rsa`です。OCPのデプロイ方法がDockerの場合は、秘密鍵ファイルにDocker内のファイルパスを使用してください。</li><li>説明：資格情報に追加の情報を補足します。</li></ul> |
   | ホストエイリアス  |  オプションです。ホストに他の名前を設定します。   |

8. （オプション）ホストの説明を入力します。

9. **<UI-TERM key="ocp-v2.page.Information.Ok">確定</UI-TERM>** をクリックします。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>エージェントのポート番号をカスタマイズする必要がある場合は、OCPサポートチームにお問い合わせください。</p>
</main>

## sudo権限の設定

以下のコマンドを参照して、関連するコマンドに対するsudoのパスワードレス実行を設定してください：

```shell
# プロセスを終了する
Cmnd_Alias KILL_CMD = /bin/kill -9 *
# ポート使用状況を確認する
Cmnd_Alias NETSTAT_CMD = /bin/netstat -ant
# エージェント設定を動的に変更する
Cmnd_Alias AGENT_CONFIG_UPDATE = /home/admin/ocp_agent*/bin/ocp_agentctl -c /home/admin/ocp_agent*/conf/agentctl.yaml config --update *
# エージェントプロセスを再起動する
Cmnd_Alias AGENT_RESTART = /home/admin/ocp_agent*/bin/ocp_agentctl restart
# エージェントプロセスを開始する
Cmnd_Alias AGENT_START = /home/admin/ocp_agent*/bin/ocp_agentctl start
# ディレクトリを削除する
Cmnd_Alias RM_CMD = /bin/rm -rf */tmp/*, /bin/rm -rf */home/admin/ocp_agent*/*
# ソフトウェアパッケージをコピーする
Cmnd_Alias CP_CMD = /bin/cp -r */tmp/* */home/admin/ocp_agent/pkg_store*
# RPM操作
Cmnd_Alias RPM_CMD = /bin/rpm *, /bin/rpm -Uvh *, /bin/rpm -e *
# ソフトウェアパッケージをダウンロードする
Cmnd_Alias CURL_CMD = /usr/bin/curl -s -S -k -o /tmp/* *
# ファイルの検証
Cmnd_Alias SHA1SUM_CMD = /usr/bin/sha1sum *
# Agentサービス管理
Cmnd_Alias AGENT_SERVICE_CMD = /home/admin/ocp_agent*/bin/ocp_agentctl service start *, /home/admin/ocp_agent*/bin/ocp_agentctl service stop *

# Debian系システム専用
test ALL=(ALL) NOPASSWD: /usr/bin/install -D * *
# Debian系システム専用
test ALL=(ALL) NOPASSWD: /usr/bin/alien -k -i *
# Debian系システム専用
test ALL=(ALL) NOPASSWD: /usr/bin/dpkg -P *

# ユーザー権限の設定
test ALL=(ALL) NOPASSWD:KILL_CMD, NETSTAT_CMD, AGENT_CONFIG_UPDATE, AGENT_START, AGENT_RESTART, RM_CMD, CP_CMD, RPM_CMD, CURL_CMD, SHA1SUM_CMD, AGENT_SERVICE_CMD
```
