# OceanBaseクラウドプラットフォームの操作プロセス
OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、OCP）は、クラスタの作成、管理、運用保守、監視機能を提供します。OCPでは、ソフトウェアパッケージのアップロード、ホストの追加、クラスタの新規作成、クラスタの引き継ぎ、テナントの作成、ユーザーの作成、OBProxyクラスタの作成、アラートの設定などの操作を実行できます。

<!-- 以下の図は、上記の操作の論理関係を示しています： -->

<!-- ![1225](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6672988061/p206162.png) -->

| 順序 |                              操作                              |                                                                                説明                                                                                |
|----|--------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 1 | [ソフトウェアパッケージのアップロード](../500.quickstart/300.quickstart-upload-a-software-package.md) | OBProxyインストールパッケージをアップロードします。ソフトウェアパッケージ機能では、OceanBase、OCP Agent、バックアップ・リストア用のインストールパッケージやその他のパッケージもアップロードできます。 |
| 1  | [ホストの追加](../500.quickstart/400.quickstart-add-a-host.md)          | オンプレミスの機器をOCPコンソールに追加します。                                                                                                                                               |
| 2  | [クラスタの新規作成](../500.quickstart/500.quickstart-create-a-cluster.md)          | 1-1-1クラスタを作成します。                                                                                                                                                     |
| 3  | [テナントの新規作成](../500.quickstart/600.quickstart-create-a-tenant.md)          | クラスタ内にテナントを作成します。新規テナントの作成方法は以下の2つです： <li> テナント概要ページでテナントを作成します。  </li><li> 指定したクラスタのテナント管理ページでテナントを作成します。</li>    |
| 4  | [ユーザーの作成](../500.quickstart/700.quickstart-create-a-user.md)          | 情報セキュリティや従来のセキュリティなどの観点から、ユーザー作成時には必要最小限の権限を付与することを推奨します。OCPの最小権限セットはPROFILEロールであり、このロールを持つユーザーは個人情報センターへのアクセス、個人情報の変更、パスワードボックスの変更などが可能です。                                                                   |
| 5  | [OBProxyクラスタの作成](../500.quickstart/800.quickstart-create-an-obproxy-cluster.md) | 基本情報、デプロイメントモード、詳細設定などの情報を入力することで、新しいOBProxyクラスタを作成できます。これは、OBProxyの追加やOceanBaseクラスタとの連携に使用されます。                                                                                                |
