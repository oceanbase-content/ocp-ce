# Binlogクラスタの概要を表示する

特定のクラスタページに移動すると、現在のBinlogクラスタの基本情報、Binlogインスタンス情報、およびBinlog Server情報を確認できます。また、クラスタの日常的な運用保守操作もサポートしています。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っている場合にのみ、Binlogクラスタの概要データを表示できます。

* **Binlogサービス読み取り専用** リソース権限。
* Binlogサービス **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

## クラスタ基本情報

**<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページでは、クラスタの基本情報を確認できます。これには、**<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.BinlogClusterName">Binlogクラスタ名</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.Basic.State">ステータス</UI-TERM>**、**<UI-TERM key="ocp-v2.Binlog.Component.UpgradeBinlogModal.VersionNumber">バージョン番号</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Overview.CdcVersion">CDC版</UI-TERM>**、**<UI-TERM key="ocp-v2.page.External.CreationTime">作成日時</UI-TERM>**、**<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ZoneParamInfoTable.ModificationTime">更新日時</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Overview.MetadbInformation">MetaDB情報</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Overview.Endpoint">アクセスアドレス</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Overview.SoftwareInstallationDirectory">ソフトウェアのインストールディレクトリ</UI-TERM>**、および **Binlogファイル生成ディレクトリ** の情報が含まれます。

| パラメータ          |  説明  |
|---------------|--------|
| Binlogクラスタ名 | Binlogクラスタ名。  |
| 状態          | クラスタの現在の実行状態。**<UI-TERM key="ocp-v2.Detail.Statistics.utils.Running">実行中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.obproxy.Creating">作成中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.binlog.OM">運用中</UI-TERM>**、**<UI-TERM key="ocp-v2.Topo.TopoGraph.Deleting">削除中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.Starting">起動中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.compute.Restarting">再起動中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.compute.Stopping">停止中</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Overview.Unavailable">利用不可</UI-TERM>**、および **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>** が含まれます。  |
| バージョン番号        | 現在のBinlogクラスタのバージョン番号。   |
| CDCバージョン      | 現在のクラスタのOceanBase CDCバージョン番号。    |
| 作成日時      | 現在のクラスタの作成日時。   |
| 変更日時      | 現在のクラスタの最終変更日時。   |
| MetaDB情報   | **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.View">表示</UI-TERM>** をクリックし、ポップアップウィンドウで現在のBinlogクラスタが使用するMetaDB設定情報を確認します。   |
| アクセスアドレス      | 現在のBinlogクラスタの接続アクセスアドレス。右側のコピーボタンをクリックして、クラスタアクセスアドレスをコピーできます。  |
| ソフトウェアインストールディレクトリ  | Binlogのインストールパスです。ここには、[Binlogクラスタの作成](../200.create-a-binlog-cluster.md)時に入力したパスが表示されます。   |
| Binlogファイル生成ディレクトリ   |  Binlogのデータ保存パスです。デフォルト値は `ソフトウェアインストールディレクトリ/run` です。  |

## Binlogインスタンスリストの表示

**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** には、Binlogクラスタのすべてのインスタンス情報がリストアップされています。異なるビジネステナント内のBinlogインスタンス情報を確認でき、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceName">Binlogインスタンス名</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.NodeIp">ノードIP</UI-TERM>**、**変換遅延**、**変換RPS**、**サブスクリプション接続数**、および **<UI-TERM key="ocp-v2.component.TaskBubble.State">ステータス</UI-TERM>** の情報を確認できます。また、Binlogインスタンスに対して **<UI-TERM key="ocp-v2.src.constant.binlog.ConfigureThrottling">レート制限の設定</UI-TERM>**、**<UI-TERM key="ocp-v2.Cluster.Arbitration.Stop">停止する</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.binlog.Start">起動</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.Restart">再起動</UI-TERM>**、**切り替え**、および **Binlogインスタンスの削除</UI-TERM>** 操作を実行できます。詳細については、[Binlogインスタンスの管理](../400.manage-binlog-instance/100.binlog-instance-overview.md)を参照してください。

## Binlog Serverリストの表示

**Binlog Serverリスト** では、Binlog Serverの **IP**、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Hostname">ホスト名</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.WaterLevel.ResourceWaterLevel">リソース使用率</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddHostDrawer.HostType">ホストタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.OBProxy.New.ModelOptional">機種</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ComputerRoom">データセンター</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.Region">リージョン</UI-TERM>**、および **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.State">ステータス</UI-TERM>** の情報を確認できます。また、Binlog Serverに対して **<UI-TERM key="ocp-v2.Component.BinlogServerList.Stop">停止する</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.Start">起動</UI-TERM>**、および **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Delete">削除</UI-TERM>** などの運用保守操作を実行できます。詳細については、[Binlog Serverの管理](../500.manage-binlog-server/100.add-a-binlog-server.md)を参照してください。

## クラスタ管理操作

**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページでは、クラスタに対するその他の基本的な管理操作も実行できます。詳細については、[バージョンのアップグレード](150.upgrade-a-binlog-cluster.md)、[ノードの追加](../500.manage-binlog-server/100.add-a-binlog-server.md)、[Binlogクラスタの停止/起動](200.stop-and-start-a-binlog-cluster.md)、[Binlogクラスタの再起動](300.restart-a-binlog-cluster.md)、[Binlogクラスタの削除](400.delete-a-binlog-cluster.md)、[ログの表示](../../1300.log-service/100.log-query.md)を参照してください。

同時に、左側のナビゲーションバーからクラスタの日常的な運用保守操作も実行できます。詳細については、[Binlogクラスタパラメータの管理](500.manage-binlog-cluster-parameters.md)を参照してください。

## Binlogクラスタの切り替え

他のBinlogクラスタの概要情報を表示する場合、**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>**ページの左上にあるBinlogクラスタ名から、表示したいクラスタを選択します。すると、現在の概要ページが選択したBinlogクラスタの概要ページに切り替わります。
