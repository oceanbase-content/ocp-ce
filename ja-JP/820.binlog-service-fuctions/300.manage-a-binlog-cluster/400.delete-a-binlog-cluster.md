# Binlogクラスタの削除

ビジネスニーズに応じて、不要なBinlogクラスタを削除できます。Binlogクラスタは削除後に復元できません。関連するBinlogサブスクリプションタスクもクリーンアップされ、クラスタ内のすべてのBinlogインスタンスの実行も停止します。慎重に操作してください。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービス管理** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

* 削除対象のBinlogクラスタが **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常に稼働</UI-TERM>** または **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>** 状態にあること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Binlog.Component.DeleteBinlogModal.DeleteABinlogCluster">Binlogクラスタを削除する</UI-TERM>** を選択します。

5. ダイアログボックスに **delete** と入力し、**<UI-TERM key="ocp-v2.component.FormEditTable.Delete">削除</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でタスクの実行進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** になり、かつ **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** にそのBinlogクラスタが表示されなくなったら、削除は成功です。
