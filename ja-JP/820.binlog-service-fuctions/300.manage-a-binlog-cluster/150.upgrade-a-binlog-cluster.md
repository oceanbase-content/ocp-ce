# バージョンアップグレード

ビジネスニーズに応じて、Binlogクラスタのバージョンをアップグレードできます。アップグレード中、クラスタ内のBinlogインスタンスがシングルレプリカモードの場合、ダウンストリーム業務に数分単位の遅延が発生する可能性があります。クラスタ内のBinlogインスタンスがマルチレプリカモードの場合、システムはデフォルトでリーダー切り替えを実行するため、ダウンストリーム業務に秒単位の遅延が発生する可能性があります。慎重に操作してください。

OCPでは、Binlogクラスタをアップグレードする方法は以下の2つです：

* **方法1**：**<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** の操作列にある **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.UpgradedVersion">アップグレードバージョン</UI-TERM>** をクリックします。
* **方法2**：**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページの右上にある **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.UpgradedVersion">アップグレードバージョン</UI-TERM>** をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

* アップグレード対象のBinlogクラスタおよびその下のBinlogインスタンスがすべて **<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常に稼働</UI-TERM>** 状態にあること。
* V4.2.0.0以降のバージョンへのアップグレードのみサポートされています。

## 手順

以下の手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** から操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページで、右上の **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.UpgradedVersion">アップグレードバージョン</UI-TERM>** をクリックします。

5. ダイアログボックスでアップグレードバージョンのソフトウェアパッケージを選択し、**<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Upgrade">アップグレード</UI-TERM>** をクリックします。

   対応するソフトウェアパッケージがない場合、**<UI-TERM key="ocp-v2.src.component.PackageSelect.UploadASoftwarePackage">ソフトウェアパッケージをアップロード</UI-TERM>** をクリックして、必要なソフトウェアパッケージのバージョンをアップロードできます。

6. **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** でタスクの実行進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** で、かつそのクラスタの状態が **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">正常に稼働</UI-TERM>** の場合、クラスタのアップグレードは成功です。
