# Binlogクラスタの停止・起動

ビジネスニーズに応じて、Binlogクラスタを停止または開始できます。Binlogクラスタの停止はクラスタ管理にのみ影響し、Binlogインスタンスの正常な稼働や業務によるBinlogデータへの接続・消費には影響しません。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

* 停止操作を実行する際、停止対象のBinlogクラスタが **<UI-TERM key="ocp-v2.src.constant.oceanbase.NormalOperation">正常に稼働</UI-TERM>** 状態にあること。
* 起動操作を実行する際、起動対象のBinlogクラスタが **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>** 状態にあること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページで、右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Detail.Overview.StopBinlogCluster">Binlogクラスタの停止</UI-TERM>** を選択します。

5. ダイアログボックスで **<UI-TERM key="ocp-v2.Component.BinlogServerList.Stop">停止する</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** でタスクの実行進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** になり、かつそのクラスタの状態が **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">停止済み</UI-TERM>** になったら、クラスタの停止は成功です。

6. クラスタを起動します。

   クラスタが停止した後、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページの右上にある **<UI-TERM key="ocp-v2.Detail.Overview.StartTheBinlogCluster">Binlogクラスタを起動する</UI-TERM>** をクリックすることで、そのBinlogクラスタを再度有効にできます。
