# Binlogクラスタパラメータの管理

パラメータリストでは、現在のBinlogクラスタのすべてのパラメータ名、値、説明、再起動が必要かどうかなどの情報を確認でき、必要に応じてパラメータの値を変更できます。

## 前提条件

* Binlogクラスタのパラメータ情報を確認する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービス読み取り専用** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

* Binlogクラスタのパラメータを変更する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックします。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

5. システムはデフォルトで **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">パラメータリスト</UI-TERM>** ページに移動します。ここで **<UI-TERM key="ocp-v2.page.Property.ParameterList">パラメータリスト</UI-TERM>** から、現在のBinlogクラスタのすべてのパラメータ情報を確認できます。

6. （オプション）**<UI-TERM key="ocp-v2.page.MultiAzone.ParameterList">パラメータリスト</UI-TERM>** ページ上部の検索ボックスに、パラメータ名などの関連情報を入力して、あいまい検索を実行します。

7. 変更対象のパラメータを見つけ、対応する **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.component.OperationConfig.List.ModifyValue">値の修正</UI-TERM>** をクリックします。

8. ポップアップダイアログで、パラメータの値を変更し、**<UI-TERM key="ocp-v2.MultiCluster.Detail.SwitchoverModal.Determine">確定</UI-TERM>** をクリックします。
