# プライマリ/スタンバイインスタンスの切り替え

このページでは、プライマリ/スタンバイインスタンスの切り替え手順について説明します。プライマリインスタンスが利用不能な場合、スタンバイインスタンスをプライマリインスタンスに切り替えてBinlogサービスを引き継ぐことができます。

OCPでは、プライマリ/スタンバイインスタンスの切り替え方法は以下の2通りです：

* **方法1**：**<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** から切り替えるスタンバイインスタンスを選択し、操作列の **... > 切り替え** をクリックします。
* **方法2**：スタンバイインスタンスの **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > 切り替え** をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **Binlogクラスタ概要** メニュー権限。

* 切り替えるBinlogインスタンスがスタンバイインスタンスであり、そのインスタンスが対応するBinlogクラスタが **正常稼働** 状態であること。

## 手順

以下の操作手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.plan.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogサービスの **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックすると、**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** エリアで、切り替えるBinlogスタンバイインスタンスを選択し、インスタンス名をクリックします。

5. **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > 切り替え** をクリックします。

6. ダイアログボックスで切り替え方式を選択し、**<UI-TERM key="ocp-v2.Instance.Overview.Switch">切り替え</UI-TERM>** をクリックします。

   * **<UI-TERM key="ocp-v2.Binlog.Component.InstanceSwitchoverModal.CutMasterRecommend">プライマリへの切り替え(推奨)</UI-TERM>**：新しい接続は新しいプライマリインスタンス上に作成され、古い接続は古いプライマリインスタンス上に保持され、古いプライマリインスタンスへの業務アクセスは中断しません。
   * **<UI-TERM key="ocp-v2.Binlog.Component.InstanceSwitchoverModal.StopTheServiceAndCut.1">サービス停止を伴うプライマリへ切り替え</UI-TERM>**：古いプライマリインスタンスへの業務アクセスが中断し、業務に利用不可の影響を与えます。

   お客様は **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でタスクの実行進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** で、かつ該当インスタンスの状態が **<UI-TERM key="ocp-v2.Topo.TopoGraph.Normal">正常に稼働</UI-TERM>** の場合、切り替えは成功したことを意味します。
