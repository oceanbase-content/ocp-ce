# Binlogインスタンスの停止/起動

ビジネスニーズに応じて、Binlogインスタンスを停止または起動できます。Binlogインスタンスを停止すると、そのインスタンスの実行および関連するサブスクリプションタスクに影響します。操作は慎重に行ってください。

OCPでは、Binlogインスタンスを停止または起動する方法は以下の2つです：

* **方法1**：**<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** から停止したいインスタンスを選択し、操作列の **... > Binlogインスタンスの停止/起動** をクリックします。
* **方法2**：**<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > Binlogインスタンスの停止/起動** をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

* 停止操作を実行する際、停止対象のBinlogインスタンスが **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常に稼働</UI-TERM>** 状態にあること。
* 起動操作を実行する際、起動対象のBinlogインスタンスが **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>** 状態にあること。

## 手順

以下の手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックして **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** エリアで、停止したいBinlogインスタンスを選択し、インスタンス名をクリックします。

5. **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > Binlogインスタンスの停止** をクリックします。

6. ダイアログボックスに **stop** と入力し、**<UI-TERM key="ocp-v2.MultiCluster.Detail.FailoverModal.Determine">確定</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** でタスクの実行進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** で、かつ該当インスタンスの状態が **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>** の場合、インスタンスの停止は成功です。

7. インスタンスを起動します。

   インスタンスが停止した後、**<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページの右上にある **<UI-TERM key="ocp-v2.Instance.Overview.StartTheBinlogInstance">Binlog インスタンスを起動</UI-TERM>** をクリックすると、そのインスタンスを再起動できます。
