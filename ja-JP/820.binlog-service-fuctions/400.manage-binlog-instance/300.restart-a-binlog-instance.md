# Binlogインスタンスの再起動

ビジネスニーズに応じて、Binlogインスタンスを再起動できます。Binlogインスタンスの再起動はサブスクリプション接続を切断するため、慎重に操作してください。

OCPでは、Binlogインスタンスを再起動する方法は以下の2つです：

* **方法1**：**<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** から再起動するインスタンスを選択し、操作列の **... > Binlogインスタンスの再起動** をクリックします。
* **方法2**：**<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > Binlogインスタンスの再起動** をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

* 再起動対象のBinlogインスタンスが **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常に稼働</UI-TERM>** または **<UI-TERM key="ocp-v2.page.Overview.Unavailable">利用不可</UI-TERM>** 状態にあること。

## 手順

以下の手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックして **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** エリアで、再起動するBinlogインスタンスを選択し、インスタンス名をクリックします。

5. **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > Binlogインスタンスの再起動** をクリックします。

6. ダイアログボックスで **<UI-TERM key="ocp-v2.src.util.component.Restart">再起動</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でタスクの実行進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** で、かつ該当インスタンスの状態が **<UI-TERM key="ocp-v2.src.constant.compute.NormalOperation">正常に稼働</UI-TERM>** の場合、再起動は成功したことを意味します。
