# Binlogインスタンスの削除

このページでは、スタンバイBinlogインスタンスを削除する手順について説明します。

OCPでは、スタンバイインスタンスを削除する方法は以下の2つです：

* **方法1**：**<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** から削除対象のスタンバイインスタンスを選択し、操作列の **... > Binlogインスタンスの削除** をクリックします。
* **方法2**：スタンバイインスタンスの **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > Binlogインスタンスの削除** をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **Binlogクラスタ概要** メニュー権限。

* 削除対象のBinlogインスタンスがスタンバイインスタンスであり、かつインスタンスに対応するBinlog ServerおよびBinlogクラスタが **正常稼働** 状態であること。

## 手順

以下の操作手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogサービスの **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックして **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** エリアで、削除対象のBinlogスタンバイインスタンスを選択し、インスタンス名をクリックします。

5. **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、右上の **... > Binlogインスタンスの削除** をクリックします。

6. ダイアログボックスで **<UI-TERM key="ocp-v2.Component.OBServerList.Delete">削除</UI-TERM>** をクリックします。
