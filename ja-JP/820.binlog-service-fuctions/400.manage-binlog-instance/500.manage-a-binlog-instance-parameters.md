# Binlogインスタンスパラメータの管理

このページを参照して、Binlogインスタンスのパラメータ値を変更できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Binlogサービスメンテナンス** リソース権限。
* Binlogサービス **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックして **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** エリアで、特定のBinlogインスタンスを選択し、インスタンス名をクリックします。

5. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

6. （オプション）**<UI-TERM key="ocp-v2.page.Property.ParameterList">パラメータリスト</UI-TERM>** ページ上部の検索ボックスに、パラメータ名などの関連情報を入力して、あいまい検索を実行します。

7. 変更対象のパラメータを見つけ、対応する **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Operation">操作</UI-TERM>** 列で、**<UI-TERM key="ocp-v2.Detail.Parameter.ModifyValue">値を変更する</UI-TERM>** をクリックします。

8. ポップアップダイアログで、パラメータの値を変更し、**<UI-TERM key="ocp-v2.component.Compaction.MergePolicyDrawer.Ok">確定</UI-TERM>** をクリックします。
