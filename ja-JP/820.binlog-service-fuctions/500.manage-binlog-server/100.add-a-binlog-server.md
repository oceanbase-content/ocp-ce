# Binlog Serverの追加

ビジネスニーズに応じて、このセクションを参照して管理するBinlogクラスタにBinlogノードを追加し、クラスタの拡張を実現できます。

OCPでは、クラスタにBinlog Serverを追加する方法は以下の2つです：

* **方法1**：**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で、操作列の **<UI-TERM key="ocp-v2.Binlog.Component.AddBinlogNodeModal.AddNode">ノードを追加</UI-TERM>** をクリックします。
* **方法2**：**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページで、右上の **<UI-TERM key="ocp-v2.Binlog.Component.AddBinlogNodeModal.AddNode">ノードを追加</UI-TERM>** をクリックします。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Binlogサービスメンテナンス** リソース権限。
* Binlogサービス **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

## 手順

以下の手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Binlog.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックします。

4. **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページで、右上の **<UI-TERM key="ocp-v2.src.constant.binlog.AddNode">ノードを追加</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.src.constant.binlog.AddNode">ノードを追加</UI-TERM>** ダイアログボックスで、追加するBinlogノードのデータセンター、マシンタイプ、およびBinlogノードが配置されるホストを指定します（複数選択可能）。

    デフォルトでは1つのBinlogノードのみが追加されます。複数のBinlogノードを追加する必要がある場合は、下部の **Binlog Serverの追加** ボタンをクリックできます。

6. **<UI-TERM key="ocp-v2.Detail.Component.DailyChangeTenantModal.Ok">確定</UI-TERM>** をクリックして、ノードの追加タスクを送信します。

   タスクの進捗状況は **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** で確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** になり、かつクラスタ概要ページの **Binlog Serverリスト** にある該当OBServerノードの状態がすべて **<UI-TERM key="ocp-v2.src.constant.obproxy.NormalOperation">正常に稼働</UI-TERM>** になったら、ノードの追加は成功です。
