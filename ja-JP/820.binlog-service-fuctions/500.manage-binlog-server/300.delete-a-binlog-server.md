# Binlog Serverの削除

この記事では、Binlogクラスタ内のBinlog Serverを削除する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

* 削除対象のBinlog Serverが属するBinlogクラスタが **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常に稼働</UI-TERM>** または **<UI-TERM key="ocp-v2.src.constant.backup.Stopped">停止済み</UI-TERM>** 状態であること。
* BinlogクラスタにBinlog Serverが1台しか存在しない場合、そのクラスタのBinlog Serverを削除するには、そのBinlogクラスタを削除する必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックして **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **Binlog Serverリスト** モジュールで、削除するノードを選択し、操作列の **<UI-TERM key="ocp-v2.src.constant.compute.Delete">削除</UI-TERM>** をクリックします。

5. ダイアログボックスに **delete** と入力し、**<UI-TERM key="ocp-v2.src.constant.iam.Delete">削除</UI-TERM>** をクリックします。

   タスクの進捗状況は **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** で確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** になり、かつ **Binlog Serverリスト** に該当するBinlog Serverが表示されなくなったら、削除は成功です。

## 次のステップ

Binlog Serverを削除した後、ノード上のBinlogインスタンスは手動で必要に応じて処理する必要があります。詳細については、[ホスト上のBinlogインスタンスのクリーンアップ](400.clean-binlog-instance-on-a-host.md)を参照してください。
