# Binlog Serverの停止・起動

この記事では、Binlog Serverの停止と起動の操作について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **Binlogサービスメンテナンス** リソース権限。
  * Binlogサービス **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

* 停止操作を実行する際、停止対象のBinlog Serverおよびその所属するBinlogクラスタは、どちらも **<UI-TERM key="ocp-v2.src.constant.tenant.NormalOperation">正常に稼働</UI-TERM>** 状態である必要があります。
* 起動操作を実行する際、起動対象のBinlog Serverは **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">停止済み</UI-TERM>** 状態であり、所属するBinlogクラスタは **<UI-TERM key="ocp-v2.page.Overview.Content.NormalOperation">正常に稼働</UI-TERM>** または **<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">停止済み</UI-TERM>** 状態である必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックすると、**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **Binlog Serverリスト** モジュールで、停止するノードを選択し、操作列の **<UI-TERM key="ocp-v2.src.constant.obproxy.Stop">停止する</UI-TERM>** をクリックします。

5. ダイアログボックスで、**<UI-TERM key="ocp-v2.Component.BinlogServerList.Stop">停止する</UI-TERM>** をクリックします。

   タスクの進捗状況は **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** で確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** になり、かつ **Binlog Serverリスト** 内の該当OBServerノードの状態が **<UI-TERM key="ocp-v2.src.constant.binlog.Stopped.3">停止済み</UI-TERM>** になったら、タスクは成功です。

6. Binlog Serverを起動します。

   Binlog Serverが停止した後、**Binlog Serverリスト** 内の操作列の **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Start">起動</UI-TERM>** をクリックすると、そのBinlog Serverを再起動できます。
