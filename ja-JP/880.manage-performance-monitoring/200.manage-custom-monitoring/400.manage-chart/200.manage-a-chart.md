# チャートの管理

**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>** ページで、カスタムチャートに対して **<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.Edit">編集</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Copy">コピー</UI-TERM>**、および **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Delete">削除</UI-TERM>** 操作を実行できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* パフォーマンス監視 **<UI-TERM key="ocp-v2.component.alarm.Search.All">すべて</UI-TERM>** メニュー権限。

## 手順

### チャートの編集

チャートの設定を変更する必要がある場合、OCPではチャートの編集操作をサポートしています。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>** タブを選択します。

5. 編集したいチャートを選択し、操作列の **<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.Edit">編集</UI-TERM>** をクリックします。

6. 右側に表示されたパネルでチャート情報を変更します。

7. **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.Ok">確定</UI-TERM>** をクリックします。

### チャートのコピー

作成するチャートの設定が既存のチャートと一部のみ異なる場合、チャートをコピーして迅速に設定・作成できます。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Monitor.Monitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>** タブを選択します。

5. コピーしたいチャートを選択し、操作列の **<UI-TERM key="ocp-v2.component.ParameterTemplate.Copy">コピー</UI-TERM>** をクリックします。

6. （オプション）右側に表示されたパネルでチャート情報を変更します。

7. **<UI-TERM key="ocp-v2.MultiCluster.Detail.Determine">確定</UI-TERM>** をクリックします。

### チャートの削除

作成したチャートが不要になった場合、削除できます。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>** タブを選択します。

5. 削除するチャートを選択し、操作列の **<UI-TERM key="ocp-v2.Binlog.Component.DeleteBinlogModal.Delete">削除</UI-TERM>** をクリックします。

6. ポップアップダイアログで **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Determine">確定</UI-TERM>** をクリックします。
