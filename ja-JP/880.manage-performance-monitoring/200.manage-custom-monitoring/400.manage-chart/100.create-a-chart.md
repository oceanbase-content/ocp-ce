# チャートの作成

このセクションでは、チャートをカスタム作成する方法について説明します。カスタムメトリクス項目を作成すると、OCPはその実行結果をチャート形式で表示できます。

以下の3つのエントリポイントからチャートを作成できます：

* **エントリポイント1**：**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>**ページに移動し、右上の**<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.CreateAChart">グラフを作成する</UI-TERM>**をクリックします。
* **エントリポイント2**：チャートを作成したことがない場合、**<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>**の**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>**タブに移動し、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.CreateAChart">グラフを作成する</UI-TERM>**をクリックします。
* **エントリポイント3**：メトリクス項目を作成済みの場合、**<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>**の**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**タブに移動し、指定したメトリクス項目のチャートを作成します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または**ホスト読み取り専用**のいずれかのリソース権限。
* パフォーマンス監視 **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

## 手順

以下の手順は **エントリポイント1** を例に説明します：

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページに移動し、ページ右上の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.CreateAChart">グラフを作成する</UI-TERM>** をクリックします。

5. 右側に表示されたパネルに、チャート情報を入力します。

    | パラメータ | パラメータ説明 |
    |------|---------|
    | チャート名 | チャート名。大文字・小文字、数字、アンダースコアを含めることができ、長さは2～48文字です。 |
    | チャート説明 | チャートの説明情報を追加します。  |
    | チャートの場所 | チャートの表示場所を選択します。オプション：<ul><li>クラスタ > データベースパフォーマンス</li><li>クラスタ > ホストパフォーマンス</li><li>クラスタ > OBServerパフォーマンス</li><li>テナント > パフォーマンスとSQL</li><li>テナント > トランザクション</li><li>テナント > ストレージとキャッシュ</li><li>ホストパフォーマンス</li><li>ホストリソース</li><li>ホストプロセス</li></ul> <main id="notice" type='note'><h4>説明</h4><p>特定のメトリクス項目のチャートを作成する場合、チャートの場所はメトリクス項目に基づいて自動生成されます。</p></main> |
    | モニタリング項目 | <ul><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">メトリクス項目の選択</UI-TERM>**：ドロップダウンリストから具体的なメトリクス項目を選択します。選択可能なメトリクス項目は **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.ChartLocation">グラフの位置</UI-TERM>** と関連付けられています。リストに必要なメトリクス項目がある場合は、直接選択できます。ない場合は、リスト下部の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.AddMetricItems">メトリクス項目の新規追加</UI-TERM>** をクリックして必要なメトリクス項目を作成できます。詳細については、[メトリクス項目の作成](../300.manage-indicator-items/100.create-a-indicator-item.md)を参照してください。<br>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">メトリクス項目の選択</UI-TERM>** には、OCPの組み込みメトリクス項目とユーザー定義メトリクス項目が含まれます。OCPの組み込みメトリクス項目の詳細については、[監視メトリック参照](../../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md)を参照してください。</li><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.DisplayIndicatorName">メトリクス名を表示</UI-TERM>**：メトリクス項目がチャートで表示される名前です。システムは **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">メトリクス項目の選択</UI-TERM>** に基づいて自動入力し、編集も可能です。</li><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.IndicatorItemDescription">メトリクス項目の説明</UI-TERM>**：メトリクス項目の説明情報です。システムは **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">メトリクス項目の選択</UI-TERM>** に基づいて自動入力し、編集も可能です。</li><li>**<UI-TERM key="ocp-v2.src.template.Table.Unit">単位</UI-TERM>**：メトリクス項目の単位です。システムは **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.SelectAMetricItem">メトリクス項目の選択</UI-TERM>** に基づいて自動入力し、編集も可能です。</li></ul><main id="notice" type='note'><h4>説明</h4><p><ul><li>チャートに複数のモニタリング項目を設定する必要がある場合は、**データ行の追加**をクリックしてメトリクス項目情報を追加します。不要なモニタリング項目を削除する必要がある場合は、モニタリング項目の右側にある操作バーの **<UI-TERM key="ocp-v2.User.Component.DeleteUserModal.Delete">削除</UI-TERM>** をクリックします。</li><li>メトリクス項目は、監視データのクエリ時にサーバーの一定のリソースを消費します。監視チャートに複数のメトリクス項目を設定した場合、サーバーリソースが不足しているとデータクエリが遅くなる可能性があります。サーバーの実際のリソース状況に応じてメトリクス項目を追加することを推奨します。</li></ul></p></main>  |
    | グラフィックススタイル | チャートの表示スタイルです。現在、折れ線グラフのみをサポートしています。   |
