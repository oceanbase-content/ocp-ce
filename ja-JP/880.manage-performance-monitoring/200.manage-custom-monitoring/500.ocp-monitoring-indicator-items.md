# OCPモニタリング指標の説明

## OCP計算式の説明

OCPの計算式はPromQLに似た形式の式テンプレートであり、対応する収集項目の時系列データを計算するために使用されます。例：

| メトリクス（metric） | 式 |
|------------------|--------|
| qps | sum(rate(ob_sysstat{stat_id="40000",@LABELS}[@INTERVAL])) by (@GBLABELS) |
| qps_rt | sum(rate(ob_sysstat{stat_id="40001",@LABELS}[@INTERVAL])) by (@GBLABELS) / sum(rate(ob_sysstat{stat_id="40000",@LABELS}[@INTERVAL])) by (@GBLABELS) |

OCPはワイルドカード`@LABELS`、`@INTERVAL`、`@GBLABELS`を式の共通部分に代入し、実際の条件に基づいてクエリ時に置き換えます。例えば、`avg(rate(node_cpu_seconds_total_native{mode="idle",@LABELS}[@INTERVAL])) by (@GBLABELS)`は、実際にクエリするホストに応じて以下の形式に置き換えられます：

```SQL
100 * avg(rate(node_cpu_seconds_total_native{mode="idle",svr_ip="xxx.xxx.xxx.1"}[1])) by (svr_ip)
100 * avg(rate(node_cpu_seconds_total_native{mode="idle",svr_ip="xxx.xxx.xxx.2"}[1])) by (svr_ip)
100 * avg(rate(node_cpu_seconds_total_native{mode="idle",svr_ip="xxx.xxx.xxx.3"}[1])) by (svr_ip)
```

### ワイルドカードの説明

| プレースホルダー | 意味の説明 |
|------------------|--------|
| @LABELS | フィルタリングに使用されるラベルを表します。実際のクエリロジックでは、`ob_cluster_id="1"`、`svr_ip="xxx.xxx.xxx.xxx"`などの実際の条件に置き換えられます。 |
| @INTERVAL | PromQLの範囲クエリの範囲ベクトルセレクター（range-vector-selector）を表します。rate、deltaなどの関数でのみ使用が必要です。 |
| @GBLABELS | 集計の次元を表します。実際のクエリロジックでは、`ob_cluster_id`、`svr_ip`などに置き換えられ、SQL構文の`group by`に類似します。 |

例：`sum(metric{@LABELS}) by (@GBLABELS)`は、metricをGBLABELSの次元で集計して合計することを意味します。

現在、OCPの式はPrometheusの以下の汎用関数をサポートしています：

|  関数  |  説明  |
|--------|--------|
|  abs  | 絶対値 |
|  sum  | 合計   |
|  avg  | 平均値 |
|  min  | 最小値 |
|  max  | 最大値 |
| count | カウント |
| rate  | 1秒あたりの平均増加率 |
| delta | 時系列要素の最初の値と最後の値の差 |
| round | 最も近い整数に四捨五入 |
