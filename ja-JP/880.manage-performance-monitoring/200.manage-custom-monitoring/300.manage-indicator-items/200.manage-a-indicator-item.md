# メトリクスの管理

**メトリクスの管理**ページでは、カスタムメトリクスに対して、**<UI-TERM key="ocp-v2.Component.ServiceName.Edit">編集</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.Role.Copy">コピー</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.Delete">削除</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CreateAChart">グラフを作成する</UI-TERM>**、および **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CreateAlertRules">アラートルールを作成する</UI-TERM>** の操作を実行できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* パフォーマンス監視 **<UI-TERM key="ocp-v2.Alarm.LogFilter.All">すべて</UI-TERM>** メニュー権限。

## 手順

### メトリクスの編集

メトリクスの設定を変更する必要がある場合、OCPはメトリクスの編集操作をサポートしています。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Realtime.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** タブを選択します。

5. 編集するメトリクスを選択し、操作列の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Edit">編集</UI-TERM>** をクリックします。

6. 右側に表示されたパネルでメトリクス情報を変更します。

7. **<UI-TERM key="ocp-v2.page.Information.Ok">確定</UI-TERM>** をクリックします。

### メトリクスのコピー

新規作成するメトリクスが既存のメトリクスと設定が一部異なる場合、メトリクスをコピーすることで、迅速に設定を作成できます。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** タブを選択します。

5. コピーするメトリクスを選択し、操作列の **<UI-TERM key="ocp-v2.Alarm.Template.Copy">コピー</UI-TERM>** をクリックします。

6. （オプション）右側に表示されたパネルでメトリクス情報を変更します。

7. **<UI-TERM key="ocp-v2.Detail.Monitor.Determine">確定</UI-TERM>** をクリックします。

### 指標項目の削除

作成した指標項目が不要になった場合、削除できます。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** タブを選択します。

5. 削除する指標項目を選択し、操作列で **その他 > 削除** を選択します。

6. ポップアップダイアログで **<UI-TERM key="ocp-v2.component.TagFilterDropDown.Ok">確定</UI-TERM>** をクリックします。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>指標項目がチャートやアラートルールに適用されている場合、その指標項目を削除すると、対応するチャートやアラートルールも同期して削除されます。</p>
</main>

### チャートの作成

作成した指標項目を監視チャートに適用できます。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** タブを選択します。

5. チャートを作成する指標項目を選択し、操作列で **その他 > チャートの作成** を選択します。

   詳細については [チャートの作成](../400.manage-chart/100.create-a-chart.md)を参照してください。

### アラートルールの作成

指標項目に対してアラートルールを作成できます。指定したしきい値を超えた場合、システムは特定の受信者にアラートメッセージを送信します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Monitor.Monitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** タブを選択します。

5. アラートルールを作成する指標項目を選択し、操作列で **その他 > アラートルールの作成** を選択します。

6. ページが **<UI-TERM key="ocp-v2.Alarm.Rule.CreateAlertRule">新しいアラートルールを作成する</UI-TERM>** に移動します。詳細については、[アラートルールの作成](../../../860.alert-management/300.manage-alert-rules/100.create-an-alert-rule.md)を参照してください。
