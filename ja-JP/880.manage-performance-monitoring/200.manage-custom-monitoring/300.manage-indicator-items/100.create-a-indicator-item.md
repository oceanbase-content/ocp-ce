# メトリクスの作成

このセクションでは、モニタリングメトリクスをカスタマイズする方法について説明します。

メトリクスは以下の3つの方法で作成できます：

* **方法1**：**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>**ページに移動し、右上の**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CreateIndicatorItems">メトリクス項目の作成</UI-TERM>**をクリックします。
* **方法2**：**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CustomMonitoring">カスタム監視</UI-TERM>**ページに移動し、メトリクスを作成したことがない場合は、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**タブに移動して、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CreateIndicatorItems">メトリクス項目を作成する</UI-TERM>**をクリックします。
* **方法3**：**<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>**ページに移動し、チャートを作成したことがない場合は、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>**タブに移動して、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CreateIndicatorItems">メトリクス項目の作成</UI-TERM>**をクリックします。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または**ホスト読み取り専用**のいずれかのリソース権限。
* パフォーマンス監視 **<UI-TERM key="ocp-v2.component.alarm.RuleSelect.All">すべて</UI-TERM>** メニュー権限。

## 手順

以下の手順は **方法1** を例に説明します：

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.src.hook.useMenu.Monitoring">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページに移動し、右上の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CreateIndicatorItems">メトリクス項目の作成</UI-TERM>** をクリックします。

5. 右側に表示されたパネルにメトリクス情報を入力します。

    | メトリクス | メトリクスの説明 |
    |------|---------|
    | メトリクス名 | OCP内でメトリクスを一意に識別する名前です。英字で始まり、英字または数字で終わる必要があります。大文字・小文字、数字、アンダースコアを含めることができ、長さは2～48文字です。 |
    | メトリクスの説明 | メトリクスの補足説明を記述します。  |
    | 作成モード | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.SelectExpression">式の選択</UI-TERM>** と **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CustomExpression">カスタム表現</UI-TERM>** が含まれます。<ul><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.SelectExpression">式の選択</UI-TERM>** モードでは、OCPに組み込まれている **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CollectionItem">収集項目</UI-TERM>** および **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CalculationExpression">計算式</UI-TERM>** を直接使用できます。</li><li>**<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CustomExpression">カスタム表現</UI-TERM>** モードでは、メトリクスに対して **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CalculationExpression">計算式</UI-TERM>** を手動で作成する必要があります。</li></ul>  |
    | 収集項目 | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CreateMode">作成モード</UI-TERM>** が **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.SelectExpression">式の選択</UI-TERM>** の場合に表示されます。収集項目名にカーソルを合わせると、ポップアップウィンドウでその収集項目の詳細情報を確認できます。<br> リストにはOCPに組み込まれているすべての収集項目が含まれています。詳細については [収集項目の確認](../200.view-collection-item.md)を参照してください。  |
    | 計算式 | OCPで使用されるPromQLに類似した式で、このメトリクスのデータソースを表します。<ul><li>LABELSはフィルタリングの次元を表し、システムはこのラベルに基づいてデータをフィルタリングします。</li><li>GBLABELSは集計の次元を表し、システムはこの情報に基づいて選択された結果に対して集計を行います。</li><li>INTERVALはpromQLの範囲クエリの範囲ベクトルセレクター(range-vector-selector)を表し、rate、deltaなどの関数でのみ使用が必要です。</li></ul>関連する詳細説明については [OCP計算式の説明](../500.ocp-monitoring-indicator-items.md)を参照してください。  |
    | 単位 | （オプション）メトリクスの単位を設定します。 <ul><li>-（デフォルト値）</li><li>Data（Metric）：<ul><li>bits</li><li>bytes</li><li>KB</li><li>MB</li><li>GB</li><li>TB</li><li>PB</li></ul></li><li>時間：<ul><li>マイクロ秒 (µs)</li><li>ミリ秒 (ms)</li><li>秒 (s)</li><li>分 (minute)</li></ul></li><li>その他：%</li></ul>  |

6. **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Determine">確定</UI-TERM>** をクリックします。
