# 取得項目の表示

OCPシステムには取得項目が組み込まれており、このページを参照して取得項目をフィルタリングおよび表示することができます。

取得項目を表示するには、以下の3つのエントリがあります：

* **エントリ1**：**<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CollectionItem">収集項目</UI-TERM>** タブをクリックします。
* **エントリ2**：**<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページに移動し、指標項目を作成したことがない場合は、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** タブに移動し、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.ViewCollectionItems">収集項目を表示する</UI-TERM>** をクリックします。
* **エントリ3**：**<UI-TERM key="ocp-v2.page.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページに移動し、チャートを作成したことがない場合は、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>** タブに移動し、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.ViewCollectionItems">収集項目を表示する</UI-TERM>** をクリックします。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* パフォーマンス監視 **<UI-TERM key="ocp-v2.Alarm.LogFilter.All">すべて</UI-TERM>** メニュー権限。

## 手順

以下の手順は **エントリ1** を例に説明します：

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** の概要ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.Host.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CollectionItem">収集項目</UI-TERM>** タブを選択します。

   取得項目リストで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.CollectionItemName">収集項目名</UI-TERM>**、**<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.Description">説明</UI-TERM>**、**<UI-TERM key="ocp-v2.src.template.Table.Features">特徴</UI-TERM>**、**<UI-TERM key="ocp-v2.src.template.Table.CollectionInterval">収集間隔</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.ShowLimitsModal.Unit">単位</UI-TERM>**、**lable**、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.ObjectDimension">オブジェクトのディメンション</UI-TERM>**、および **<UI-TERM key="ocp-v2.page.External.CreateDrawer.Type">タイプ</UI-TERM>** を含む詳細情報を確認できます。

    | 指標 | 指標説明 |
    |------|---------|
    | 取得項目名 | 取得指標の一意の名前。 |
    | 説明 | 指標項目に関する補足説明です。  |
    | 特徴 | **Counter** と **Gauge** が含まれます。<ul><li>Counter：増加のみで減少しないカウンター。Counterタイプの指標は、システムがリセットされない限り、カウンターと同じように増加のみで減少しません。セッション数やクライアントリクエスト数など、一般的な監視指標がこれに該当します。</li><li>Gauge：増減可能なメーター。Gaugeタイプの指標は、システムの現在の状態を反映することに重点を置いています。一般的な指標としては、CPU使用率やメモリ使用率などがあります。</li></ul>  |
    | 取得間隔 | **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Seconds">秒単位</UI-TERM>** と **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.MinuteLevel">分単位</UI-TERM>** が含まれます。   |
    | 単位 |  <ul><li>-（デフォルト値）</li><li>Data（Metric）：<ul><li>bits</li><li>bytes</li><li>KB</li><li>MB</li><li>GB</li><li>TB</li><li>PB</li></ul></li><li>時間：<ul><li>マイクロ秒 (µs)</li><li>ミリ秒 (ms)</li><li>秒 (s)</li><li>分 (minute)</li></ul></li><li>その他：Percent（0〜100）</li></ul>  |
    | lable | 取得項目がデータ収集時に取得したラベル情報。  |
    | オブジェクト次元 |  **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Host">ホスト</UI-TERM>**、**OceanBase**、および **OBProxy** が含まれます。  |
    | タイプ | **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Custom">カスタマイズ</UI-TERM>** と **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.CreateArbitrationGroup.Default">デフォルト</UI-TERM>** の2種類に分類されます。カスタム指標項目が必要な場合は、OCPテクニカルサポートにお問い合わせください。   |

   * 取得項目のページネーション検索、およびキーワードによる取得項目名の検索をサポートします。
   * **<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.CollectionInterval">収集間隔</UI-TERM>**、**<UI-TERM key="ocp-v2.src.template.Table.ObjectDimension">オブジェクトのディメンション</UI-TERM>**、**<UI-TERM key="ocp-v2.page.External.Type">タイプ</UI-TERM>** で取得項目をフィルタリングできます。
