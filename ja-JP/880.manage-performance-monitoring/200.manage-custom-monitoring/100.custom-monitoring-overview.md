# カスタムモニタリングの概要

このセクションでは、OCPのカスタムモニタリング機能について説明します。これには、収集項目、メトリクス、グラフの作成とクエリ、およびアラートの関連付け方法が含まれます。

カスタムモニタリングは主に、OCPの組み込みモニタリングではユーザーのモニタリング要件を満たせない場合に解決策となります。必要に応じて、OceanBaseサービス、OBProxy、ホストなどのシステムレベルのモニタリングメトリクスやグラフをカスタマイズできます。

カスタムモニタリングは、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CollectionItem">収集項目</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>**、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>** の3つのモジュールに分かれています。詳細は以下の通りです：

* **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.CollectionItem">収集項目</UI-TERM>** とは、異なるデータソースから収集された生のモニタリングデータを指します。

* **<UI-TERM key="ocp-v2.Monitor.AddMonitor.IndicatorItem">メトリクス項目</UI-TERM>** とは、収集項目に基づいて生成される計算メトリクスを指します。各メトリクスは、PromQL構文に基づいて異なる収集項目から生成されたPrometheus式に対応しています。

* **<UI-TERM key="ocp-v2.Monitor.AddMonitor.Chart">グラフ</UI-TERM>** には、1つ以上のメトリクスの計算結果である時系列データが含まれます。

上記の3種類のメタデータ表示に加えて、OCPはメトリクスとグラフのカスタム作成、およびメトリクスからアラートルールを関連付けて生成する機能も提供しています。

## 前提条件

OCPにログインしたユーザーが以下の権限を持っている場合にのみ、収集項目、メトリクス、グラフの関連情報を表示できます：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* パフォーマンスモニタリング **<UI-TERM key="ocp-v2.component.common.OBProxyClusterSelect.All">すべて</UI-TERM>** メニュー権限。

## 収集項目

**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMetricDrawer.CollectionItem">収集項目</UI-TERM>** タブでは、収集項目名でキーワード検索が可能です。ここには、カスタムメトリクスの作成に使用できるすべての収集項目が含まれています。
