# パフォーマンスモニタリングの表示

このセクションでは、SQL診断におけるパフォーマンスモニタリングデータの表示方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
* 診断サービス **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.pages.Diagnosis.DiagnosticServices">診断サービス</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>** エリアで、表示するクラスタ名をクリックします。

4. デフォルトで **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** の **<UI-TERM key="ocp-v2.Detail.Monitor.SqlDiagnosis">SQL 診断</UI-TERM>** ページに移動します。**<UI-TERM key="ocp-v2.Detail.Realtime.ViewPerformanceMonitoring">パフォーマンス監視を確認する</UI-TERM>** ボタンをクリックすると、ポップアップパネルで時間をフィルタリングし、現在のテナントの読み書き応答時間、読み書きリクエスト数、CPU使用率のパフォーマンスモニタリングトレンドグラフを表示できます。詳細については、[パフォーマンスモニタリング](../100.performance-monitoring-overview/300.view-host-performance.md)を参照してください。
