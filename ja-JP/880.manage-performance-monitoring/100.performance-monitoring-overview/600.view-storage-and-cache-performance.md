# ストレージとキャッシュの表示

このページでは、OCPにおけるテナントのストレージとキャッシュの監視機能について説明します。以下の2つの方法で表示できます：

* **方法1**：OCPにログインし、テナント概要ページに移動して、左側のナビゲーションバーの **<UI-TERM key="ocp-v2.Detail.Realtime.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** をクリックします。

* **方法2**：OCPにログインし、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** をクリックして、**<UI-TERM key="ocp-v2.Task.TaskObjectAndType.OceanbaseTenants">OceanBase テナント</UI-TERM>** タブに移動します。

## 前提条件

* **方法1** でテナントのストレージとキャッシュの監視データを表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** メニュー権限。

* **方法2** でテナントのストレージとキャッシュの監視データを表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
  * パフォーマンス監視の **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ArbitrationServiceWithExclude.All">すべて</UI-TERM>** メニュー権限。

## バージョン制限

* <b>MEMStoreのフリーズ</b> 監視メトリクスが適用されるOceanBaseのバージョンは [-∞, V4.0.0.0) です。

* <b>ベクトルインデックスデータサイズ</b>、<b>ベクトルインデックスデータ実際使用率</b> 監視メトリクスが適用されるOceanBaseのバージョンは [V4.3.5.3, +∞) です。

* <b>ログディスク</b> 監視メトリクスが適用されるOceanBaseのバージョンは [V4.0.0.0, +∞) です。

* <b>物理I/O回数</b>、<b>物理I/O時間</b>、<b>物理I/Oスループット</b> 監視メトリクスのうち、詳細指標項目 <code>clog_read</code>、<code>clog_write</code> が適用されるOceanBaseのバージョンは [V4.1.0.3, +∞) です。

* <b>ダンプパーティション</b> 監視メトリクスが適用されるOceanBaseのバージョンは [V4.2.0.0, +∞) です。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>テナントが属するクラスタがAIクラスタ(共有ストレージ形態)の場合、ストレージとキャッシュの監視において、データディスク関連の指標はキャッシュディスクの指標として表示され、オブジェクトストレージの読み書き性能を監視するために、<b>オブジェクトストレージIOPS</b> と <b>オブジェクトストレージ帯域幅</b> の監視メトリクスが追加されます。</p>
</main>

## 手順

以下の手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.OceanbaseTenants">OceanBase テナント</UI-TERM>** タブを選択します。

4. **<UI-TERM key="ocp-v2.component.MonitorSearch.DataFiltering">データフィルタリング</UI-TERM>** セクションで、モニタリングデータのフィルタリング条件を設定します。

   フィルタリング条件の説明は以下の表のとおりです。

   |     フィルタリング条件  |  説明  |
   |---------------|---------|
   | 更新  | モニタリングデータを更新します。自動更新を有効にすることができますが、デフォルトでは無効です。自動更新を有効にした場合、更新頻度を設定できます。|
   | 時間の選択（モニタリングウィンドウとも呼ばれる） | 自動更新モードでは表示されません。特定の期間を選択すると、その期間内のデータが返されます。  |
   | テナント | 特定のテナントを選択し、そのテナントのモニタリングを行います。  |
   | Zone  | デフォルトではすべてのZoneをモニタリングします。|
   | OBServer | デフォルトではすべてのOBServerノードをモニタリングします。|

5. **ストレージとキャッシュ** タブをクリックし、そのタブで関連するモニタリングデータを確認します。

   * OCPは、テナントとUnitの2つの次元でモニタリングデータを表示することをサポートしています。デフォルトではテナント次元で表示されます。異なる次元では、表示可能なモニタリング指標が異なります。
   * システムはデフォルトで現在の次元のすべてのモニタリング項目を表示します。特定のモニタリング項目に注目する必要がない場合、領域の右側にある **<UI-TERM key="ocp-v2.Detail.Monitor.IndicatorSelection">選択したグラフ</UI-TERM>** パネルで、そのモニタリング項目のチェックを外すことができます。
   * すべてのモニタリング項目は、各サブ指標の最大値（max）、平均値（avg）、現在値（current）の表示をサポートしています。
   * すべてのモニタリング項目の具体的な意味と値の出典については、[モニタリング指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md) を参照してください。統計範囲に複数のOBServerノードが含まれる場合、集約値が表示されます。

   以下の機能は、トレンドグラフで詳細なパフォーマンスモニタリングデータをより良く確認し、分析するのに役立ちます。

   <!-- ![Image 114](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1426.png) -->

   * 他のサブ指標のデータの表示と非表示：指標エリアにカーソルを合わせ、マウスホイールを上下にスクロールすると、トレンドグラフに表示されているすべてのサブ指標データを確認できます。他のサブ指標のアイコンをクリックして灰色にすると、その指標情報はトレンドグラフに表示されなくなります。

   * トレンドグラフ上の特定の時刻にカーソルを合わせると、その時刻の詳細データを確認できます。カーソルをドラッグして範囲を選択すると、システムはその範囲のトレンド情報を拡大表示し、その期間における指標の詳細なトレンドを確認できます。このトレンドグラフをダブルクリックすると元に戻ります。

   * トレンドグラフの拡大：トレンドグラフの右上隅にある拡大アイコンをクリックします。上記の詳細データの表示とサブ指標の表示・非表示の機能は、拡大されたトレンドグラフでも同様に適用されます。

   * モニタリング指標の編集：トレンドグラフの右上隅にある編集アイコンをクリックすると、注目すべきサブ指標のみを表示するよう選択できます。

   * ドリルダウンして異なる次元のモニタリングデータを確認する：**<UI-TERM key="ocp-performance-report.pages.AWR.ReportContent.Tenant">テナント次元</UI-TERM>** タブで、テナントのモニタリングデータに異常が見つかった場合、例えば物理I/Oの処理時間が高すぎる場合、ドリルダウン分析することで、応答時間の異常を引き起こしているサーバーを特定できます。トレンドグラフの右上隅にある **<UI-TERM key="ocp-v2.component.MetricChart.Item.DrillDownAnalysis">ドリルダウン分析</UI-TERM>** アイコンをクリックすると、ドリルダウン分析の詳細を確認できます。**ストレージとキャッシュ** でサポートされているドリルダウン次元は、**テナント \> OBServer** です。

       上記の詳細データの表示とサブ指標の表示・非表示の機能は、ドリルダウンページのトレンドグラフでも同様に適用されます。さらに、以下の操作もできます：

       * ドリルダウンページでフィルタリング条件を再設定します。設定していない場合は、上位レベルの設定が自動的に継承されます。

       * 当該指標にサブ指標が存在する場合、サブ指標を選択して確認できます。

       * トレンドグラフには **ホストパフォーマンスモニタリングへ** 機能が提供されています。**ホストパフォーマンスモニタリングへ** のリンクにカーソルを合わせ、確認したいホストを選択すると、関連するホストの **<UI-TERM key="ocp-v2.src.util.menu.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** ページに移動し、ホストのモニタリング詳細を確認できます。
