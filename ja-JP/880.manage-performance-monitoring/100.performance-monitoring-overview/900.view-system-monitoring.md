# システム監視の表示

OCPは、OBProxyクラスタのシステム監視機能を提供します。関連する監視データは、以下の2つのエントリから確認できます：

* **エントリ1**：OCPにログインし、OBProxyの概要ページに移動して、左側のナビゲーションバーの**<UI-TERM key="ocp-v2.Detail.Realtime.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**をクリックします。

* **エントリ2**：OCPにログインし、左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.Monitor.Monitoring">パフォーマンス監視</UI-TERM>**をクリックし、**<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.ObproxyCluster">OBProxyクラスタ</UI-TERM>**タブに移動します。

## 前提条件

* **エントリ1**からOBProxyクラスタのシステム監視データを表示する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxy読み取り専用**リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**メニュー権限。

* **エントリ2**からOBProxyクラスタのシステム監視データを表示する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxy読み取り専用**リソース権限。
  * パフォーマンス監視 **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.All">すべて</UI-TERM>**メニュー権限。

## 手順

以下の手順は、**エントリ2**を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Monitor.AddMonitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>**を選択します。

3. **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.ObproxyCluster">OBProxyクラスタ</UI-TERM>**タブをクリックします。

4. **<UI-TERM key="ocp-v2.component.MonitorSearch.DataFiltering">データフィルタリング</UI-TERM>**エリアで、監視データのフィルタリング条件を設定します。

   フィルタリング条件の説明は以下の表のとおりです：

   |     フィルタリング条件  |  説明  |
   |---------------|---------|
   | 更新  | 監視データを更新します。自動更新を有効にできますが、デフォルトでは無効です。自動更新を有効にした場合、更新頻度を設定できます。|
   | 時間範囲（別名：監視ウィンドウ） | 自動更新モードでは表示されません。特定の期間を選択すると、その期間内のデータを返します。  |
   | クラスタ | 特定のOBProxyクラスタを選択し、そのクラスタを監視します。  |

    ![11221550](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/obproxy%E7%9B%91%E6%8E%A7.png)

5. **<UI-TERM key="ocp-v2.Detail.Monitor.SystemMonitoring">システム監視</UI-TERM>**タブに移動し、関連する監視データを確認します。

   1. **OBProxy IPデータ**エリアでは、現在のOBProxyクラスタ内の各OBProxyノードのパフォーマンス状況を確認できます。

      * すべての監視項目は、各サブ指標の最大値（max）、平均値（avg）、現在値（current）の表示をサポートしています。
      * **<UI-TERM key="ocp-v2.Component.filter.ColumnManagement">カラム管理</UI-TERM>** をクリックすると、表示するモニタリング指標情報を選択できます。
      * **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.ViewAll">すべてを見る</UI-TERM>** をクリックすると、OBProxy IPのシステム負荷分析データを確認できます。

   2. **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** エリアでは、現在のOBProxyクラスタのモニタリングトレンドグラフを確認できます。これには、**Linux システム負荷**、**<UI-TERM key="ocp-v2.Compaction.DetailV4.CpuAndMemoryChart.CpuUsage">CPU使用率</UI-TERM>**、**I/O 使用率**、**I/O キュー長**、**IOPS**、**I/O 消費時間**、**I/O スループット**、**ネットワークスループット**、**TCP 再送信率**、**ネットワーク送受信パケット**、**NTP クロックオフセット**、**Inode 使用率**、**<UI-TERM key="ocp-v2.src.component.DeleteUnitSpecModal.Memory">メモリ</UI-TERM>**、**メモリ使用率**、**ディスク**、**プロセス常駐メモリ**、**プロセス CPU 使用率**、**プロセスファイルハンドル数**、**プロセススレッド数**、および **OCP-Agent プロセスコルーチ数** が含まれます。

      * すべてのモニタリング項目では、各サブ指標の最大値（max）、平均値（avg）、および現在値（current）の表示をサポートしています。
      * すべてのモニタリング項目の具体的な意味と値の出典については、[モニタリング指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md)を参照してください。

      以下の機能を利用すると、トレンドグラフ上で詳細なパフォーマンスモニタリングデータをより効果的に確認および分析できます。画像と以下の説明を組み合わせてご理解ください。

        ![Image 114](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/442/04161501.png)

        1. 特定の指標の特定の期間の詳細なトレンドを見る：マウスでその範囲をドラッグして選択すると、システムはその範囲のトレンド情報を拡大表示します。このトレンドグラフをダブルクリックすると元に戻ります（上図の①）。

        2. 他のサブ指標のデータを非表示にする：他のサブ指標のアイコンをクリックして灰色にすると、トレンドグラフにその指標情報が表示されなくなります（上図の②）。

        3. 特定の時点の詳細データを見る：トレンドグラフ上の特定の時点にマウスカーソルを合わせます（上図の③）。

        4. トレンドグラフの右上にある拡大アイコンをクリックすると、トレンドグラフを拡大できます（上図の④）。上記の①、②、③の機能は、他のモニタリングトレンドグラフにも同様に適用されます。

        5. モニタリング指標を編集する：トレンドグラフの右上にある編集アイコンをクリックすると、注目すべきサブ指標のみを表示するよう選択できます（上図の⑤）。

        6. ドリルダウンして異なる次元のモニタリングデータを見る：モニタリングデータに異常が見られた場合、例えばLinuxシステム負荷が高すぎる場合、ドリルダウン分析を通じて、応答時間の異常を引き起こしたOBProxy IPを特定できます。トレンドグラフの右上にある **<UI-TERM key="ocp-v2.component.MetricChart.Item.DrillDownAnalysis">ドリルダウン分析</UI-TERM>** アイコンをクリックすると、ドリルダウン分析の詳細を見ることができます（上図の⑥）。

           上図の①、②、③の機能は、ドリルダウンページのトレンドグラフにも同様に適用されます。さらに、以下の操作も可能です：

           * ドリルダウンページでフィルター条件を再設定することができます。設定していない場合は、上位レベルの設定が自動的に継承されます。

           * 当該指標にサブ指標が存在する場合、サブ指標を選択して確認することができます。
