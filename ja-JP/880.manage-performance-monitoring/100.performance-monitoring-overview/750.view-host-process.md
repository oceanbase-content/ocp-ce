# ホストプロセスの表示

この記事では、OCPのホストプロセス監視機能について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* ホストの **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. **<UI-TERM key="ocp-v2.src.component.TakeOverArbitrationDrawer.Host">ホスト</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.HostList">ホスト一覧</UI-TERM>** エリアで、操作対象のホストを選択し、そのホストのIPアドレスをクリックします。

4. 表示されたページで、**<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** タブをクリックします。

5. **<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.HostProcess">ホストプロセス</UI-TERM>** タブをクリックし、監視データのフィルタリング条件を設定します。

   フィルタリング条件の説明は以下の表のとおりです：

   |     フィルタリング条件  |  説明  |
   |---------------|---------|
   | 更新  | 監視データを更新します。自動更新を有効にすることができますが、デフォルトでは無効です。自動更新を有効にした場合、更新頻度を設定できます。 |
   | 選択時間（別名：監視ウィンドウ） | 自動更新モードでは表示されません。特定の期間を選択すると、その期間内のデータを返します。  |

6. ホストのプロセス監視データを確認します。

   * すべての監視項目は、各サブ指標の最大値（max）、平均値（avg）、現在値（current）の表示をサポートしています。
   * すべての監視項目の具体的な意味と値の出典については、[監視指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md) を参照して理解することができます。

   以下の機能を利用すると、トレンドグラフ上でプロセス監視データをより容易に確認および分析できます。画像と以下の説明を組み合わせて理解してください。

   ![1129](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1643.png)

   * 他のサブ指標のデータの表示と非表示：カーソルを指標エリアに合わせ、マウスホイールを上下にスワイプすると、トレンドグラフに表示されているすべてのサブ指標データを確認できます。他のサブ指標のアイコンをクリックして灰色にすると、その指標情報はトレンドグラフに表示されなくなります。

   * トレンドグラフ上の特定の時点にカーソルを合わせると、その時点の詳細データを確認できます。カーソルをドラッグして範囲を選択すると、システムはその範囲のトレンド情報を拡大表示し、その期間における指標の詳細なトレンドを確認できます。このトレンドグラフをダブルクリックすると元に戻ります。

   * トレンドグラフの拡大：トレンドグラフの右上隅にある拡大アイコンをクリックします。上記の図にある①、②の機能も拡大されたトレンドグラフで同様に適用されます。

   * 監視指標の編集：トレンドグラフの右上隅にある編集アイコンをクリックすると、注目すべきサブ指標のみを表示するよう選択できます。

7. **<UI-TERM key="ocp-v2.Detail.Monitor.CustomMonitoring">カスタム監視</UI-TERM>** をクリックすると、必要に応じてモニタリング指標やグラフをカスタマイズできます。詳細については、[カスタムモニタリングの概要](../200.manage-custom-monitoring/100.custom-monitoring-overview.md)を参照してください。
