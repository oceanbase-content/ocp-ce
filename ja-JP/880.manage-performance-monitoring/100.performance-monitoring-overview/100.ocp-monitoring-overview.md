# OceanBaseクラウドプラットフォームの概要

OceanBaseクラウドプラットフォームの概要ページでは、OCPで管理されているOceanBaseクラスタ、OceanBaseテナント、OBProxyクラスタ、ホストなど、さまざまなリソースの全体像を提供します。各リソースのアラート、診断、リソース使用状況を確認することで、問題を迅速に特定し解決するのに役立ちます。

## 前提条件

現在OCPにログインしているユーザーがADMINロールまたはADMIN_VIEWERロールであること。

## 基本リソース情報

OceanBaseクラスタ、OceanBaseテナント、OBProxyクラスタ、ホストの稼働状態を確認し、状態異常のリソースオブジェクトに対して適時に運用保守管理を行えます。

**<UI-TERM key="ocp-v2.Auth.Org.SharedResourceDrawer.OceanbaseCluster">OceanBase クラスタ</UI-TERM>** の後ろの **？** アイコンにカーソルを合わせると、クラスタデプロイメントコア数の統計情報を確認できます。

## タスクと診断情報

タスク情報と診断情報を確認できます。

* タスク情報：過去7日間のアラート状態、アラートレベル、バックアップタスク、運用保守タスク、およびメジャーコンパクションに時間がかかった上位5回の情報を確認できます。
* 診断情報：
  * SQL診断：過去6時間以内に疑わしいSQLがあったクラスタ、SlowSQLがあったクラスタ、新規SQLが追加されたクラスタの数を表示します。
  * トランザクション診断：長時間トランザクションがあるクラスタとハングしたトランザクションがあるクラスタの数をリアルタイムで表示します。
  * セッション診断：過去7日間にデッドロックが発生したクラスタの数を表示します。
  * セキュリティ診断：過去7日間に高リスクSQLがあったクラスタの数を表示します。
  * 最適化履歴：過去7日間に最適化履歴があるクラスタの数を表示します。

## クラスタリソース割り当てTop5

CPU割り当て率、メモリ割り当て率、ディスク使用率が上位5位のOceanBaseクラスタデータを表示します。各指標の詳細については、[監視指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md)を参照してください。

## テナントリソース使用量Top5

CPU割り当て率、メモリ割り当て率、データ量（GB）が上位5位のOceanBaseテナントデータを表示します。各指標の詳細については、[監視指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md)を参照してください。

## SQLパフォーマンス監視Top5

異なる時間帯のQPS、TPS、SQL応答時間、セッション数、トランザクション応答時間、イベント待機時間が上位5位のOceanBaseクラスタまたはOceanBaseテナントデータを表示します。各指標の詳細については、[監視指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md)を参照してください。
