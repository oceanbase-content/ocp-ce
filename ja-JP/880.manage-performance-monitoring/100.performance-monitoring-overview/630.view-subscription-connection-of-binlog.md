# サブスクリプション接続モニタリングチャートの表示

このセクションでは、Binlogインスタンスのサブスクリプション接続のモニタリングデータを表示する方法について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能をサポートしていません。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Binlogサービス読み取り専用** リソース権限。
* Binlogサービス **<UI-TERM key="ocp-v2.Detail.Overview.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックすると、**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** エリアで、特定のBinlogインスタンスを選択し、インスタンス名をクリックします。

5. **<UI-TERM key="ocp-v2.Instance.Overview.BinlogInstanceOverview">Binlog インスタンスの概要</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Instance.Overview.SubscriptionConnectionList">サブスクリプション接続リスト</UI-TERM>** モジュールでモニタリング期間を設定します。

    デフォルトでは **<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes">直近5分間</UI-TERM>** のモニタリングデータが表示されます。期間ドロップダウンボックスから **<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong">直近5分間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong.1">直近10分間</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyMinutes.1">直近15分間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong.2">直近30分間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearlyHours">直近3時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearlyHours.1">直近6時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearlyHours.2">過去12時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearHours">過去24時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.LastDays">過去7日間</UI-TERM>** を選択して期間を簡単に指定できます。また、ドロップダウンボックスでカスタム時間を選択し、開始時刻と終了時刻を設定することもできます。

6. サブスクリプション接続 **<UI-TERM key="ocp-v2.component.common.ObUserSelectUserName">ユーザー名</UI-TERM>** の左側にある **+** ボタンをクリックすると、**<UI-TERM key="ocp-v2.Instance.Overview.Monitor.SendDelay">送信遅延</UI-TERM>**、**<UI-TERM key="ocp-v2.Instance.Overview.Monitor.SendRps">送信 RPS</UI-TERM>**、**<UI-TERM key="ocp-v2.Instance.Overview.Monitor.NetworkTraffic">ネットワークトラフィック</UI-TERM>** のリアルタイムモニタリングチャートを表示できます。
