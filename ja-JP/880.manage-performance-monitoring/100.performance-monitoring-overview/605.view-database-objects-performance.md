# データベースオブジェクトの表示

このページでは、OCPにおけるテナントデータベースオブジェクトの監視機能について説明します。以下の2つの方法で表示できます：

* **方法1**：OCPにログインし、テナントの概要ページに移動して、左側のナビゲーションバーの **<UI-TERM key="ocp-v2.page.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** をクリックします。

* **方法2**：OCPにログインし、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Realtime.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** をクリックして、**<UI-TERM key="ocp-v2.page.Monitor.OceanbaseTenants">OceanBaseテナント</UI-TERM>** タブに移動します。

## 前提条件

* **方法1** でテナントデータベースオブジェクトの監視データを表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Detail.Monitor.Title.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** メニュー権限。

* **方法2** でテナントデータベースオブジェクトの監視データを表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用** または **ホスト読み取り専用** のいずれかのリソース権限。
  * パフォーマンス監視の **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.All">すべて</UI-TERM>** メニュー権限。

## バージョン制限

OceanBaseがV4.0.0.0以上のバージョンである場合にのみ、**データベースオブジェクト** の監視データを表示できます。

## 手順

以下の手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.OceanbaseTenants">OceanBaseテナント</UI-TERM>** タブを選択します。

4. **<UI-TERM key="ocp-v2.component.MonitorSearch.DataFiltering">データフィルタリング</UI-TERM>** 領域で、監視データのフィルタリング条件を設定します。

   フィルタリング条件の説明は以下の表のとおりです：

   |     フィルタリング条件  |  説明  |
   |---------------|---------|
   | 更新  | 監視データを更新します。自動更新を有効にすることができますが、デフォルトでは無効です。自動更新を有効にした場合は、更新頻度を設定できます。|
   | 選択時間（別名：監視ウィンドウ） | 自動更新モードでは表示されません。特定の期間を選択して、その期間内のデータを返します。  |
   | テナント | 特定のテナントを選択して、そのテナントを監視します。  |
   | Zone  | デフォルトではすべてのZoneを監視します。|
   | OBServer | デフォルトではすべてのOBServerノードを監視します。|

5. **データベースオブジェクト** タブをクリックし、そのタブで関連する監視データを確認します。

   * OCPは、テナントとUnitの2つの次元でモニタリングデータを表示することをサポートしており、デフォルトではテナント次元で表示されます。異なる次元では表示可能なモニタリング指標が異なります。
   * システムはデフォルトで現在の次元におけるすべてのモニタリング項目を表示します。特定のモニタリング項目に注目する必要がない場合は、領域の右側にある **<UI-TERM key="ocp-v2.Detail.Monitor.IndicatorSelection">選択したグラフ</UI-TERM>** パネルでそのモニタリング項目のチェックを外すことができます。
   * 各細分化指標の最大値（max）、平均値（avg）、現在値（current）を表示することができます。
   * すべてのモニタリング項目の具体的な意味と値の出典については、[モニタリング指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md) を参照してください。統計範囲に複数のOBServerノードが含まれる場合は、集約値が表示されます。

   以下の機能は、トレンドグラフ上で詳細なパフォーマンスモニタリングデータをより良く確認し、分析するのに役立ちます。画像と以下の説明を組み合わせて理解してください。

   ![Image 114](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1527.png)

   * 他の細分化指標のデータの表示と非表示：指標エリアにカーソルを合わせ、マウスホイールを上下にスクロールすると、トレンドグラフに表示されているすべての細分化指標データを確認できます。他の細分化指標のアイコンをクリックしてグレーアウトさせると、その指標情報はトレンドグラフに表示されなくなります。

   * トレンドグラフ上の任意の時刻にカーソルを合わせると、その時刻の詳細データを確認できます。カーソルをドラッグして特定の領域を選択すると、システムはその領域のトレンド情報を拡大表示し、その期間における指標の詳細なトレンドを確認できます。このトレンドグラフをダブルクリックすると元に戻ります。

   * トレンドグラフの拡大：トレンドグラフの右上隅にある拡大アイコンをクリックします。上記の図にある①、②の機能は、拡大されたトレンドグラフでも同様に適用されます。

   * モニタリング指標の編集：トレンドグラフの右上隅にある編集アイコンをクリックすると、注目すべき細分化指標のみを表示するよう選択できます。

   * 異なる次元のモニタリングデータのドリルダウン表示：**<UI-TERM key="ocp-performance-report.pages.AWR.Tenant">テナント次元</UI-TERM>** タブで、テナントのモニタリングデータに異常が見られた場合、ドリルダウン分析を通じて、応答時間の異常を引き起こしたサーバーを特定できます。トレンドグラフの右上隅にある **<UI-TERM key="ocp-v2.component.MetricChart.Item.DrillDownAnalysis">ドリルダウン分析</UI-TERM>** アイコンをクリックすると、ドリルダウン分析の詳細を確認できます。**データベースオブジェクト** でサポートされているドリルダウンの次元は、**テナント \> OBServer** です。

       上記の図にある①、②の機能は、ドリルダウンページのトレンドグラフでも同様に適用されます。さらに、以下の操作も可能です：

       * ドリルダウンページでフィルター条件を再設定することができます。設定していない場合は、上位レベルの設定が自動的に継承されます。

       * 当該指標に細分化指標が存在する場合、それらを選択して確認することができます。

       * トレンドグラフには **ホストパフォーマンスモニタリングへ** 機能が提供されています。**ホストパフォーマンスモニタリングへ** のリンクにカーソルを合わせ、確認したいホストを選択すると、関連するホストの **<UI-TERM key="ocp-v2.Detail.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** ページに移動し、ホストのモニタリング詳細を確認できます。
