# Binlogパフォーマンス監視の表示

このセクションでは、Binlogインスタンスのパフォーマンス監視データを表示する方法について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Binlogサービス読み取り専用** リソース権限。
* Binlogサービス **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogService">Binlogサービス</UI-TERM>** をクリックすると、システムはデフォルトでBinlogの **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で操作対象のBinlogクラスタを選択し、そのクラスタ名をクリックすると、**<UI-TERM key="ocp-v2.src.hook.useMenu.BinlogClusterOverview">Binlogクラスタの概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.BinlogInstanceList">Binlogインスタンス一覧</UI-TERM>** エリアで、特定のBinlogインスタンスを選択し、インスタンス名をクリックします。

5. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** をクリックします。

6. デフォルトで **Binlogパフォーマンス監視** タブが表示されます。データフィルタリングエリアで、監視データのフィルタリング条件を設定します。

   フィルタリング条件の説明は以下の表のとおりです：

   |     フィルタリング条件  |  説明  |
   |---------------|---------|
   | 更新  | 監視データを更新します。自動更新を有効にできますが、デフォルトは無効です。自動更新を有効にした場合、更新頻度を設定できます。 |
   | 選択時間（別名：監視ウィンドウ） | 自動更新モードでは表示されません。特定の期間を選択すると、その期間内のデータを返します。  |

7. Binlogパフォーマンス監視データを表示します。

   * すべての監視項目では、各サブ指標の最大値（max）、平均値（avg）、現在値（current）を表示できます。
   * すべての監視項目の具体的な意味と値の出典については、[監視指標の概要](../../1900.reference-guide/300.monitoring-indicator-reference/100.overview-of-metrics.md)を参照してください。

   以下の機能は、トレンドグラフでBinlogインスタンスのパフォーマンス監視データをより良く表示および分析するのに役立ちます。画像と以下の説明を組み合わせて理解してください。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/1547.png)

   * 他のサブ指標のデータの表示と非表示：指標エリアにカーソルを合わせ、マウスホイールを上下にスクロールすると、トレンドグラフに表示されているすべてのサブ指標データを見ることができます。他のサブ指標のアイコンをクリックして灰色にすると、その指標情報はトレンドグラフに表示されなくなります。

   * チャート上の任意の時点にカーソルを合わせると、その時点の詳細データを確認できます。カーソルをドラッグして範囲を選択すると、システムがその範囲のトレンド情報を拡大表示し、その期間における指標の詳細な推移を確認できます。この表示はダブルクリックすると元に戻ります。

   * トレンドチャートを拡大する：トレンドチャートの右上にある拡大アイコンをクリックします。上記の①、②の機能も拡大表示されたチャートで同様に適用されます。

   * 監視指標の編集：トレンドチャートの右上にある編集アイコンをクリックすると、注目すべきサブ指標のみを表示するよう選択できます。
