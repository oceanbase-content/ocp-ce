# チャートの管理

ダッシュボードを作成した後、注目したいモニタリングチャートを新たに追加できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
  * **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** メニュー権限。

* 異なるユーザーが作成したダッシュボードは互いに隔離されており、自身の名義で管理されているモニタリングダッシュボードのみを表示および管理できます。
* 各ダッシュボードには最大32個のモニタリングチャートを追加できます。

## 手順

### チャートの追加

OCPでは、以下の3つの方法でチャートを追加できます。

* 方法1：ダッシュボードの右上にある **<UI-TERM key="ocp-v2.Dashboard.Detail.AddChart">グラフを追加する</UI-TERM>** をクリックします。
* 方法2：ダッシュボードにチャートが表示されていない場合、ダッシュボード内の **<UI-TERM key="ocp-v2.component.AddChartDrawer.AddChart">グラフを追加</UI-TERM>** ボタンをクリックして追加します。
* 方法3：ダッシュボードで特定のグループを選択し、そのグループ内の ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%86%E7%BB%84%E6%96%B0%E5%A2%9E%E5%9B%BE%E8%A1%A8.png) アイコンをクリックし、ドロップダウンリストから **<UI-TERM key="ocp-v2.Dashboard.component.AddPanelDropdown.AddChart">グラフを追加する</UI-TERM>** を選択します。

以下の手順は、**方法1** を例としています。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** を選択します。

3. チャートを追加するダッシュボードのページに移動し、右上の **<UI-TERM key="ocp-v2.component.AddChartDrawer.AddChart">グラフを追加</UI-TERM>** をクリックします。

4. パネルにチャートの関連情報を入力し、**<UI-TERM key="ocp-v2.Cluster.Component.TakeOverArbitrationDrawer.Ok">確定</UI-TERM>** をクリックします。

### 関連操作

ダッシュボード内の監視チャートに対して、以下の運用保守操作を実行できます。

* **チャートの移動**：チャートの上部をドラッグすると、ダッシュボード内で自由に位置を調整できます。
* **詳細情報の表示**：トレンドチャートの特定の時刻にカーソルを合わせると、その時刻の詳細データを確認できます。カーソルをドラッグして範囲を選択すると、システムはその範囲のトレンド情報を拡大表示し、その期間における指標の詳細なトレンドを確認できます。このトレンドチャートをダブルクリックすると元の表示に戻ります。
* **凡例情報の非表示**：トレンドチャート下部の凡例アイコンをクリックして灰色にすると、トレンドチャートにその凡例に関する情報が表示されなくなります。この機能を使用して、他の凡例データを非表示にすることもできます。
* **<UI-TERM key="ocp-v2.widgets.Chart.MonitorDrillDown">モニタリングのドリルダウン</UI-TERM>**：下図の①にある **<UI-TERM key="ocp-v2.component.MetricChart.Item.DrillDownAnalysis">ドリルダウン分析</UI-TERM>** アイコンをクリックすると、異なる次元の監視データを詳しく見ることができます。監視対象のデータに異常が見られた場合、ドリルダウン分析を通じて、応答時間の異常を引き起こしたサーバーを特定できます。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>モニタリングのドリルダウン機能は、<b>折れ線グラフ</b>でのみサポートされており、監視対象は単一のOceanBaseクラスタまたはテナントである必要があります。</p>
    </main>

* **<UI-TERM key="ocp-v2.widgets.Chart.MonitoringComparison">モニタリングの比較</UI-TERM>**：下図の②にある **<UI-TERM key="ocp-v2.widgets.Chart.MonitoringComparison">モニタリングの比較</UI-TERM>** アイコンをクリックし、比較する期間をカスタマイズすると、その期間の監視データを、直前の期間、前日の同じ時間帯、前週の同じ時間帯、前月の同じ時間帯のデータと比較できます。
* **<UI-TERM key="ocp-v2.src.constant.credential.Edit">編集</UI-TERM>**：下図の③にある **<UI-TERM key="ocp-v2.Monitor.AddMonitor.AddMonitorDrawer.EditChart">グラフを編集する</UI-TERM>** アイコンをクリックすると、チャート情報を変更できます。
* **<UI-TERM key="ocp-v2.src.constant.compute.Delete">削除</UI-TERM>**：下図の④にある **<UI-TERM key="ocp-v2.widgets.Chart.DeleteChart">グラフの削除</UI-TERM>** アイコンをクリックすると、そのチャートをダッシュボードから削除できます。
* **特定のトレンドチャートの拡大**：下図の⑤にある **<UI-TERM key="ocp-v2.widgets.Chart.zoomInToView">拡大表示</UI-TERM>** アイコンをクリックします。**詳細情報の表示**および**詳細指標の非表示**機能は、拡大表示されたトレンドチャートにおいても同様に適用されます。
* **チャートサイズの調整**：下図の⑥にある調整アイコンをクリックすると、チャート全体を拡大または縮小できます。上記のすべての機能は、拡大または縮小されたトレンドチャートにおいても同様に適用されます。
