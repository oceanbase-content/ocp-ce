# モニタリングダッシュボードの概要

このセクションでは、モニタリングダッシュボード機能について説明します。機能の紹介、使用プロセス、およびサポートされているチャートのシナリオを含みます。

## 機能の紹介

モニタリングダッシュボードは、ユーザーの「ダッシュボード監視」シナリオと、ユーザー定義のモニタリングビューの要件を満たすことを主な目的としています。

モニタリングダッシュボードページでは、複数のモニタリングダッシュボードタブを作成できます。各モニタリングダッシュボードタブでは、ユーザーの複数インスタンスや複数指標のモニタリングビューの関連表示、単一または複数のクラスタの異なるモニタリング指標など、さまざまな指標とデータを表示するために複数のチャートを追加できます。同時に、モニタリングダッシュボードは **<UI-TERM key="ocp-v2.widgets.Chart.CompareModal.RingRatio">前期間比</UI-TERM>**、**<UI-TERM key="ocp-v2.widgets.Chart.CompareModal.DailyYoy">日次前年同日比</UI-TERM>**、**<UI-TERM key="ocp-v2.widgets.Chart.CompareModal.ZhouYoy">週次前年同期週比</UI-TERM>**、**<UI-TERM key="ocp-v2.widgets.Chart.CompareModal.MonthOnYear">月次前年同月比</UI-TERM>** の4種類のモニタリング比較方式を提供し、データのパターンを簡単に発見するのに役立ちます。また、データの特性とニーズに応じて、折れ線グラフ、円グラフ、テーブルなど7種類の異なるチャートタイプを選択することもでき、データの理解と分析を深めることができます。

さらに、モニタリングダッシュボードはグループ化機能も提供しており、関連する指標やオブジェクトを同一グループに入れて一元管理することで、データベースの状況をより効果的に監視・分析できます。モニタリングダッシュボードは、チャートのドラッグ＆ドロップ、チャートの拡大、モニタリングのドリルダウン（単一指標シナリオ）、チャートタイプの変更など、豊富な機能をサポートしており、データベースシステム全体のパフォーマンスと運用状態を監視する目標の達成を支援します。

## 使用プロセス

利用可能なモニタリングダッシュボードを作成するには、以下の3つのステップがあります：

1. [新しいダッシュボードの作成](200.manage-dashboard.md)：同時に確認したいモニタリングチャートを同一ページに定義するために使用します。
2. （オプション）[新しいグループの作成](300.manage-groups.md)：追加するモニタリングチャートを事前に分類するために使用します。
3. [新しいモニタリングチャートの作成](400.manage-monitoring-charts.md)：ダッシュボードに注目したいモニタリングチャートを新規追加します。

## サポートされているチャートシナリオ

OCPモニタリングダッシュボードは現在、**単一オブジェクト単一指標** チャート、**単一オブジェクト複数指標** チャート、**複数オブジェクト単一指標** チャート、および **複数オブジェクト複数指標** チャートの4種類のチャートシナリオをサポートしています。

* **単一オブジェクト単一指標**：チャートを追加する際に、単一の **モニタリングオブジェクト** と単一の **モニタリング指標** を選択します。このシナリオは、特定のモニタリングオブジェクトの下の特別なモニタリング指標に重点的に注目する必要がある場合に適しています。

    以下の図のように、チャートで特定のホストの `cpu_percent` モニタリング指標に注目します。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%8D%95%E5%AF%B9%E8%B1%A1%E5%8D%95%E6%8C%87%E6%A0%87.png)

* **単一オブジェクト複数指標**：チャートを追加する際に、単一の **モニタリングオブジェクト** と複数の **モニタリング指標** を選択します。このシナリオは、単一のモニタリングオブジェクトの下の複数の関連指標に同時に注目する必要がある場合に適しています。

    以下の図のように、1つのチャートで特定のOBProxyクラスタの `obproxy_fd_count` と `transaction_total` の2つのモニタリング指標に同時に注目できます。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%8D%95%E5%AF%B9%E8%B1%A1%E5%A4%9A%E6%8C%87%E6%A0%87.png)

* **複数オブジェクト単一指標**：チャートを追加する際に、複数の **モニタリングオブジェクト** と単一の **モニタリング指標** を選択します。このシナリオは、複数のモニタリングオブジェクトの同一モニタリング指標に同時に注目する必要がある場合に適しています。

    以下の図のように、1つのチャートで3つのOceanBaseクラスタの `io_read_size` 指標に同時に注目できます。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%A4%9A%E5%AF%B9%E8%B1%A1%E5%8D%95%E6%8C%87%E6%A0%871.png)

* **複数オブジェクト複数指標**：チャートを追加する際に、複数の **モニタリングオブジェクト** と複数の **モニタリング指標** を選択します。このシナリオは、複数のモニタリングオブジェクトの異なるモニタリング指標を観察・比較する必要がある場合に適しています。

    以下の図のように、チャートで2つのOceanBaseクラスタの `sql_select_count` 指標と `sql_insert_count` 指標を同時に確認できます。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%A4%9A%E5%AF%B9%E8%B1%A1%E5%A4%9A%E6%8C%87%E6%A0%87.png)
