# ダッシュボードの管理

OCPでは、指標を事前に同一ページに定義することで、注目するモニタリング指標の一部をカスタマイズできます。各ダッシュボードはタブとなり、注目するモニタリングチャートを分類しやすくします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
  * **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** メニュー権限。

* 別々のユーザーが作成したダッシュボードは互いに隔離されており、自身の名義で作成されたモニタリングダッシュボードのみを閲覧および管理できます。

## 手順

### ダッシュボードの新規作成

モニタリングチャートを追加する前に、まずダッシュボードを作成する必要があります。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** を選択します。

3. ページの右上隅にある **<UI-TERM key="ocp-v2.Dashboard.component.AddDashboardModal.CreateADashboard">新規ダッシュボード作成</UI-TERM>** をクリックします。

4. ポップアップウィンドウでダッシュボード名を入力し、**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Determine">確定</UI-TERM>** をクリックします。

    ダッシュボード名は一意でなければならず、長さは2～64文字である必要があります。

### ダッシュボードのインポート

ローカルに保存されているダッシュボードファイルをインポートすることで、同じモニタリングダッシュボード情報の重複設定を回避できます。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** を選択します。

3. ページの右上隅にある **<UI-TERM key="ocp-v2.Monitor.Dashboard.Import">インポート</UI-TERM>** をクリックします。

4. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.SelectFile">ファイルを選択してください</UI-TERM>** をクリックし、インポートするダッシュボードのjsonファイルをアップロードします。

5. **<UI-TERM key="ocp-v2.page.Information.Ok">確定</UI-TERM>** をクリックします。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OCPダッシュボードのjsonドキュメントのインポートのみをサポートしています。</p>
</main>

### ダッシュボードのエクスポート

OCPは、**<UI-TERM key="ocp-v2.Monitor.Dashboard.ExportOcpDashboard">OCP ダッシュボードをエクスポートする</UI-TERM>** および **Grafanaダッシュボードをエクスポート** をサポートしています。ダッシュボードをエクスポートすると、OCPはローカルにJSONファイルを保存し、他のOCPや他の監視プラットフォームでその監視ダッシュボードデータを使用できます。

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** を選択します。

3. 右上の **<UI-TERM key="ocp-v2.Monitor.Dashboard.Export">エクスポート</UI-TERM>** をクリックし、ドロップダウンリストからエクスポートするダッシュボードのタイプを選択します。

4. ポップアップウィンドウで、エクスポートするダッシュボード名を選択します。

5. **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLLimit.Determine">確定</UI-TERM>** をクリックします。

### 関連操作

OCPは、監視ダッシュボードに対して以下の運用保守操作をサポートしています。

* **<UI-TERM key="ocp-v2.Cluster.New.Switch">切り替え</UI-TERM>**：すべてのダッシュボードはタブ形式で表示されます。ダッシュボード名をクリックすると、ダッシュボードを切り替えることができます。
* **<UI-TERM key="ocp-v2.Main.Filter.SortFilter.Sorting">並べ替え</UI-TERM>**：ダッシュボード名を左右にドラッグすると、ダッシュボードの順序を変更できます。
* **<UI-TERM key="ocp-v2.Compaction.SettingsV4.Modify">修正</UI-TERM>**：下図の①にある **<UI-TERM key="ocp-v2.Monitor.Dashboard.ModifyName">名称変更</UI-TERM>** ボタンをクリックすると、ダッシュボードの名前を変更できます。
* **<UI-TERM key="ocp-v2.Detail.TakeOver.Delete">削除</UI-TERM>**：下図の②にある **<UI-TERM key="ocp-v2.Monitor.Dashboard.DeleteDashboard">ダッシュボードを削除する</UI-TERM>** ボタンをクリックすると、ダッシュボードを削除できます。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>ダッシュボードを削除すると復元できませんので、ご注意ください。</p>
   </main>

* **<UI-TERM key="ocp-v2.Detail.Transaction.AutomaticRefresh">自動更新</UI-TERM>**：下図の③にある **<UI-TERM key="ocp-v2.Session.Deadlock.Refresh">更新</UI-TERM>** ボタンをクリックすると、即時更新またはダッシュボードの自動更新頻度を設定できます。自動更新を設定すると、ダッシュボードは設定された頻度で自動的に監視データを更新し、この機能を利用してダッシュボード内の監視グラフの最新状況を確認できます。選択可能な更新頻度は5秒、10秒、30秒で、デフォルトは **Off** 状態です。
* **時間フィルタリング**：下図の④にある時間選択器をクリックし、特定の期間を選択すると、その期間内の監視データをダッシュボードで確認できます。
* **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLinkage">グラフ連動</UI-TERM>**：下図の⑤にある **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLinkage">グラフ連動</UI-TERM>** ボタンをクリックします。チャート連動を有効にした後、グラフの特定の時刻にカーソルを合わせると、同一ダッシュボード内の他のグラフも同じ時刻の横軸の位置を同時に表示します。この機能を利用して、異なる指標を監視・比較できます。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>現在、<b>折れ線グラフ</b> と <b>面積グラフ</b> のみがチャート連動をサポートしています。</p>
   </main>

* **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLayout">グラフのレイアウト</UI-TERM>**：下図の⑥にある **<UI-TERM key="ocp-v2.Dashboard.Detail.ChartLayout">グラフのレイアウト</UI-TERM>** メニューをクリックすると、各行に表示する監視指標のトレンドグラフの数を設定できます。**<UI-TERM key="ocp-v2.Dashboard.Detail.OneInARow">1行に1個</UI-TERM>**、**<UI-TERM key="ocp-v2.Dashboard.Detail.InARow">1行に2個</UI-TERM>**、**<UI-TERM key="ocp-v2.Dashboard.Detail.InARow.1">1行に3個</UI-TERM>**、**<UI-TERM key="ocp-v2.Dashboard.Detail.InARow.2">1行に4個</UI-TERM>** の4種類のレイアウトモードをサポートしており、デフォルトでは各行に2つの監視指標のトレンドグラフが表示されます。
