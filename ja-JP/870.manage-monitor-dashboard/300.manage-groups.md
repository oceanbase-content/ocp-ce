# グループの管理

グループは各モニタリングチャートを簡単に分類するために使用されます。関連するメトリクスを同じグループに配置して一元管理することで、データベースの状況をより効果的に監視および分析できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または**ホスト読み取り専用** のいずれかのリソース権限。
  * **<UI-TERM key="ocp-v2.src.hook.useMenu.MonitoringDashboard">モニタリングダッシュボード</UI-TERM>** メニュー権限。

* 異なるユーザーが作成したダッシュボードは互いに隔離されており、自身の名義で作成されたモニタリングダッシュボードのみを閲覧および管理できます。

## 手順

### グループの作成

新しいダッシュボードを作成した後、追加予定のモニタリングチャートごとにグループを作成できます。同じグループ内のチャートは同一のモジュール内に表示されます。

OCPでは以下の2つの方法でグループを新規作成できます：

* 方法1：ダッシュボードの **<UI-TERM key="ocp-v2.Dashboard.Detail.AddChart">グラフを追加する</UI-TERM>** 右側の ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/01232108.png)ボタンをクリックし、ドロップダウンリストから **<UI-TERM key="ocp-v2.Dashboard.component.AddPanelDropdown.AddGroup">グループを追加する</UI-TERM>** を選択します。新しく作成されたグループはデフォルトで最上部に表示されます。
* 方法2：ダッシュボード内で特定のグループを選択し、そのグループ内の ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%86%E7%BB%84%E6%96%B0%E5%A2%9E%E5%9B%BE%E8%A1%A8.png)アイコンをクリックします。ドロップダウンリストで **<UI-TERM key="ocp-v2.Dashboard.component.AddPanelDropdown.AddGroup">グループを追加する</UI-TERM>** を選択すると、そのグループの上に新しいグループが作成されます。

以下の手順では **方法1** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** を選択します。

3. チャートを追加するダッシュボードのページに移動し、ダッシュボードの **<UI-TERM key="ocp-v2.Dashboard.Detail.AddChart">グラフを追加する</UI-TERM>** 右側の ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/01232108.png)ボタンをクリックします。ドロップダウンリストで **<UI-TERM key="ocp-v2.Dashboard.component.AddPanelDropdown.AddGroup">グループを追加する</UI-TERM>** を選択します。

4. グループに名前を付けます。

    グループの作成が完了すると、右側のナビゲーションバーにダッシュボード内のすべてのグループが表示されます。このナビゲーションバーを使用して、グループ間を素早く切り替えることができます。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/435/01232114.png)

### 関連操作

OCPでは、作成したグループに対して以下の運用保守操作をサポートしています。

* **<UI-TERM key="ocp-v2.Alarm.Rule.Rename">改名</UI-TERM>**：下図の①のグループ名をクリックすると、グループ名を変更できます。
* **<UI-TERM key="ocp-v2.component.ZoneFormCardList.Add">新規追加</UI-TERM>**：下図の②の新規追加ボタンをクリックすると、グループにチャートを追加したり、そのグループの下に新しいグループを作成したりできます。
* **移動**：下図の③の移動ボタンをクリックすると、グループを上または下に移動できます。
* **<UI-TERM key="ocp-v2.Detail.Database.Delete">削除</UI-TERM>**：下図の④の削除ボタンをクリックすると、グループを削除できます。
