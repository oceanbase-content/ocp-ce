# OceanBase Cloud Platform（OCP）とは

OceanBase Cloud Platform（OCP）は、OceanBaseデータベースと共に生まれた、OceanBaseを核とするエンタープライズ向けデータベース管理プラットフォームです。OceanBase V2.2.76からV4.xのすべての主要バージョンをサポートしています。

OCPは、OceanBaseクラスタやテナントなどのコンポーネントに対するライフサイクル全体の管理サービスを提供するだけでなく、OceanBase関連のリソース（ホスト、ネットワーク、ソフトウェアパッケージなど）の管理サービスも提供します。これにより、OceanBaseクラスタをより効率的に管理し、企業のIT運用コストを削減できます。

OceanBaseを核とするエンタープライズ向けデータベース管理プラットフォームとして、OCPは豊富な製品機能を備えています：

* 効率的なOceanBaseクラスタ管理

  * 高可用性をサポートします。

  * 秒単位で応答できます。

* 明確な情報フレームワーク

  * 新しいオブジェクト指向アーキテクチャにより、個々のクラスタやテナントの管理に集中できる画面を提供し、ユーザーが直感的に操作できるようにしています。

  * DBAの業務に合わせてナビゲーションの機能モジュールを分類し、必要な機能にアクセスしやすくしています。

* スムーズで効率的な操作の流れ

  * 主要なジョブのタスクを一連の流れとして設計しており、手順が明確で、操作を途切れることなく進められます。

  * 運用タスクへのクイックアクセスを提供し、すべてのページからタスクに素早く切り替えられます。

* 可視化された体験

  * タスク詳細では、フローチャートと自然で柔軟なキャンバスインタラクションを提供し、タスク進捗の管理がより直感的かつ効率的です。

  * クラスタとテナントのトポロジーマップが新たに追加され、分散環境の業務ロジック、稼働状態、重要なデータを可視化します。

* 専門的な機能

  * OceanBaseクラスタのライフサイクル全体の管理を提供します。

  * OceanBaseの特性に合わせて設計された管理機能です。

  * クラスタからセッションへと段階的に管理する機能です。

  * 細部まで配慮して設計されたトポロジーマップ機能です。
