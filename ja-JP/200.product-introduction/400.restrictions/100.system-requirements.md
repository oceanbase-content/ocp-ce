# システム要件

このページでは、OceanBaseクラウドプラットフォームのシステム要件について説明します。ハードウェア要件、ソフトウェア要件、OS要件、クライアント要件が含まれます。

## ハードウェア要件

OCP-Serverは物理マシンにインストールできるほか、Dockerコンテナ上での実行もサポートしています。OCP-Serverは、マルチノードの高可用性デプロイメントモードをサポートしています。

OCP-Serverノードの最低ハードウェア要件は以下の表のとおりです。

| **ハードウェア** | **要件**                                          |
|--------|-------------------------------------------------|
| CPU    | <li>x86_64、8コア</li><li>ARM AArch64アーキテクチャ、8コア</li> |
| メモリ     | 利用可能メモリ24GB                                        |
| NIC     | 10ギガビットNIC                                            |

## ソフトウェア要件

### OCP-Serverソフトウェア要件

Dockerイメージを使用してOCPをインストールする場合、関連する依存ソフトウェアはすべてDockerイメージパッケージに含まれています。

RPMを使用してOCPをインストールする場合、そのソフトウェア要件は以下の表のとおりです。

| **ソフトウェア** | **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Version">バージョン</UI-TERM>** |
|--------|-----------------------------------------------------------------------------|
| JDK    | Oracle JDK（17以降）またはOpenJDK（17以降）                                    |
| Python | 3.8以降                                                                       |
| compat-openssl10 | 1.0.2以降                                                                 |
| openssh-clients | 8.0以降                                                                       |

問題の調査・トラブルシューティングを容易にするため、以下のソフトウェアパッケージのインストールも推奨されます：

```javascript
apt install -y wget
apt install -y unzip
apt install -y less
apt install -y vim
apt install -y obclient
apt install -y net-tools
apt install -y strace
apt install -y lsof
apt install -y nmap-ncat
```

### OCP-Agentソフトウェア要件

OCP-Agentをインストールする際、いくつかのサードパーティソフトウェアパッケージが含まれます。これらのサードパーティソフトウェアパッケージは/home/admin/ocp_agent/site-packages/ディレクトリにインストールされます。

## クライアント要件

一般ユーザーはWebブラウザを通じてOCPサービスにアクセスするため、クライアントに関する要件は以下のとおりです。

### ブラウザ要件

| **ブラウザ** | **最小バージョン** |
|---------|----------|
| Chrome  | 88       |
| Firefox | 78       |
| Edge    | 88       |

### iOSシステム要件

iOSオペレーティングシステムを搭載したデバイスからOCPにアクセスする場合、バージョン要件は以下の表のとおりです。

| **<UI-TERM key="ocp-v2.Host.Detail.Basic.OperatingSystem">オペレーティングシステム</UI-TERM>** | **最小バージョン** |
|----------|----------|
| ios      | 10       |

### ディスプレイ要件

最適な使用体験を得るために、解像度が1440 × 810を超えるディスプレイの使用を推奨します。
