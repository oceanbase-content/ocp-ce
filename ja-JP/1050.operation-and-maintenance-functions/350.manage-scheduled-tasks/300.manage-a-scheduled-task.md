# スケジュールタスクの管理

本記事では、スケジュールタスクの日常管理方法について説明します。

## スケジュールタスクの強制実行

このセクションを参照して、作成済みのスケジュールタスクを強制的に実行できます。強制実行はタスクを即座に実行しますが、タスクのスケジューリング計画には影響せず、次回の実行時刻に再び実行されます。

### 前提条件

実行対象のスケジュールタスクが **正常** 状態であることを確認してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.pages.Schedule.TaskList">タスクリスト</UI-TERM>** タブに移動します。

4. 強制実行するスケジュールタスクを選択し、操作列で **...** > **<UI-TERM key="ocp-v2.src.constant.schedule.Enforcement">強制実行</UI-TERM>** を選択します。

## スケジュールタスクの無効化

このセクションを参照して、作成済みのスケジュールタスクを無効化できます。無効化後、タスクはスケジューリング計画に従って実行されなくなります。

### 前提条件

実行対象のスケジュールタスクが **正常** 状態であることを確認してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.pages.Schedule.TaskList">タスクリスト</UI-TERM>** タブに移動します。

4. 無効化するスケジュールタスクを選択し、操作列で **...** > **<UI-TERM key="ocp-v2.pages.Schedule.List.Disable">無効にする</UI-TERM>** を選択します。

## スケジュールタスクの有効化

このセクションを参照して、無効化されたスケジュールタスクを再有効化できます。有効化後、タスクはスケジューリング計画に従い、次回の実行時刻に実行が再開されます。

### 前提条件

実行対象のスケジュールタスクが **無効** 状態であることを確認してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.pages.Schedule.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.pages.Schedule.TaskList">タスクリスト</UI-TERM>** タブに移動します。

4. 有効にするスケジュールタスクを選択し、操作列で **...** > **<UI-TERM key="ocp-v2.Alarm.Rule.Enable">有効にする</UI-TERM>** を選択します。

## スケジュールタスクの編集

このセクションを参照して、スケジュールタスクのスケジューリング計画を変更できます。

### 前提条件

実行待ちのスケジュールタスクが **正常** または **無効** の状態であることを確認してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.pages.Task.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.pages.Schedule.TaskList">タスクリスト</UI-TERM>** タブに移動します。

4. 有効にするスケジュールタスクを選択し、操作列で **...** > **<UI-TERM key="ocp-v2.component.FormEditTable.Editing">編集</UI-TERM>** を選択します。

5. **<UI-TERM key="ocp-v2.src.constant.schedule.EditScheduledTasks">スケジュールされたタスクを編集する</UI-TERM>** パネルでタスクの設定情報を変更し、**<UI-TERM key="ocp-v2.pages.Kubernetes.ConfigureZoneModal.Save">保存</UI-TERM>** をクリックします。

## スケジュールタスクのコピー

このセクションを参照して、作成済みのスケジュールタスクをコピーし、類似したスケジュールタスクを迅速に作成して、時間コストを削減できます。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** タブに移動します。

4. 有効にするスケジュールタスクを選択し、操作列で **...** > **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetail.Copy">コピー</UI-TERM>** を選択します。

5. 必要に応じてスケジュールタスクの設定情報を変更し、**<UI-TERM key="ocp-v2.src.constant.backup.Copy">コピー</UI-TERM>** をクリックします。

## スケジュールタスクの削除

このセクションを参照して、作成済みのスケジュールタスクを削除できます。削除後はタスクの設定を復元できませんので、ご注意ください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** タブに移動します。

4. 有効にしたいスケジュールタスクを選択し、操作列で **...** > **<UI-TERM key="ocp-v2.Detail.Component.LinkList.Delete">削除</UI-TERM>** を選択します。

5. 再確認ダイアログで、**<UI-TERM key="ocp-v2.User.MySQL.Delete">削除</UI-TERM>** をクリックします。
