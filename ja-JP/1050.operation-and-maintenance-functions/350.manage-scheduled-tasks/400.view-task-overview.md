# スケジュールタスクの詳細を見る

このセクションでは、スケジュールタスクの設定情報と実行履歴を確認する方法について説明します。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.pages.Schedule.RunningRecords">実行履歴</UI-TERM>** タブには、実行済みのすべてのスケジュールタスクのリストが表示されます。各タスクの実行詳細を確認できます。詳細には、**<UI-TERM key="ocp-v2.component.TaskBubble.TaskName">タスク名</UI-TERM>**、**<UI-TERM key="ocp-v2.CreateTaskDrawer.ObServerError.ObjectOfExecution">実行対象</UI-TERM>**、**<UI-TERM key="ocp-v2.pages.Schedule.CreateTaskDrawer.TaskType">タスクの種類</UI-TERM>**、**予定実行時間**、**<UI-TERM key="ocp-v2.pages.Schedule.History.ActualExecutionTime">実際の実行時間</UI-TERM>**、**タスク状態**、および関連する操作が含まれます。

   * 右上の実行状態で実行履歴をフィルタリングできます。
   * 検索ボックスにタスク名を入力すると、実行履歴をあいまい検索できます。
   * タスク名をクリックすると、そのスケジュールタスクの実行時の設定情報を確認できます。
   * **<UI-TERM key="ocp-v2.pages.Schedule.CreateTaskDrawer.TaskType">タスクの種類</UI-TERM>** で実行履歴をフィルタリングできます。
   * **予定実行時間** と **<UI-TERM key="ocp-v2.pages.Schedule.History.ActualExecutionTime">実際の実行時間</UI-TERM>** でタスクレコードをソートできます。
   * 操作列の **<UI-TERM key="ocp-v2.pages.Schedule.History.ViewExecutionProgress">実行進捗を確認</UI-TERM>** をクリックすると、タスクの実行ページに移動して実行詳細を確認できます。

4. **<UI-TERM key="ocp-v2.pages.Schedule.TaskList">タスクリスト</UI-TERM>** タブには、作成済みのすべてのスケジュールタスクのリストが表示されます。各タスクの設定詳細を確認できます。詳細には、**<UI-TERM key="ocp-v2.component.TaskBubble.TaskName">タスク名</UI-TERM>**、**<UI-TERM key="ocp-v2.Main.TaskDetail.RebuildStandbyDetail.ObjectOfExecution">実行対象</UI-TERM>**、**<UI-TERM key="ocp-v2.pages.Schedule.TaskDetailDrawer.TaskType">タスクの種類</UI-TERM>**、**<UI-TERM key="ocp-v2.pages.Schedule.TaskDetailDrawer.SchedulingPlanning">スケジュール計画</UI-TERM>**、**<UI-TERM key="ocp-v2.pages.Schedule.List.NextExecutionTime">次回実行時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.TotalExecutionTimes">総実行回数</UI-TERM>**、**<UI-TERM key="ocp-v2.component.ParameterTemplate.Founder">作成者</UI-TERM>**、**タスク状態**、および関連する操作が含まれます。

   * 右上のタスク状態でスケジュールタスクをフィルタリングできます。
   * 検索ボックスにタスク名を入力すると、スケジュールタスクをあいまい検索できます。
   * タスク名をクリックすると、そのスケジュールタスクの現在の設定詳細を確認できます。
   * **<UI-TERM key="ocp-v2.Sop.CreateTaskDrawer.TaskType">タスクの種類</UI-TERM>** でスケジュールタスクをフィルタリングできます。
   * **<UI-TERM key="ocp-v2.pages.Schedule.List.NextExecutionTime">次回実行時間</UI-TERM>** でタスクレコードをソートできます。
   * スケジュールタスクの日常的な管理作業（強制実行、無効化/有効化、編集、コピー、削除）をサポートしています。詳細については、[スケジュールタスクの管理](300.manage-a-scheduled-task.md)を参照してください。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   設定詳細を確認する際、タスクの実行対象が直前に削除されたり、移出されたりした場合、または現在アクセス権限がない場合、システムが状態の更新を同期するのに時間がかかることがあります。最新の状態情報を取得するために、約3分待つことをお勧めします。
   </main>
