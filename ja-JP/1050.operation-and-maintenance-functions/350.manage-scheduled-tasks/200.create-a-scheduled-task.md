# スケジュールタスクの作成

このセクションを参照して、スケジュールタスクを新規作成できます。スケジュールタスクは、テナントやテーブルなどの実行対象に対し、分、日、週、月などの単位で自動実行タスクを設定することができ、運用効率を向上させます。

## 注意事項

スケジュールタスクの実行は、システムのCPU、メモリ、I/Oなどのハードウェアリソースを消費します。スケジュールタスクを作成する前に、現在のシステムの業務負荷状況を踏まえてリソース消費を適切に評価し、タスクの実行が通常の業務運用に影響を与えないようにしてください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.pages.Task.ScheduledTasks">スケジュールされたタスク</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.pages.Sop.Welcome.CreateNewTask">新しいタスクを作成</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.src.constant.schedule.NewScheduledTask">新しいスケジュールされたタスクを作成</UI-TERM>** パネルで、スケジュールタスクの実行詳細を設定します。

   a. スケジュールタスクの基本情報を設定します。

     | パラメータ      | 説明     |
     |-----------|----------|
     | タスク名  | スケジュールタスクの名前です。一意である必要があり、以下の要件を満たす必要があります：<ul><li>中国語または英字で始まり、中国語、数字、または英字で終わる必要があります。</li><li>2～32文字をサポートします。</li><li>特殊文字はアンダースコア（_）のみサポートします。</li></ul> |
     | 実行対象  | **<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.Tenant">テナント</UI-TERM>** と **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Table">テーブル</UI-TERM>** の2つの次元で実行対象を選択できます。 |
     | テナントの選択/所属テナント | 実際のニーズに応じて、タスクの実行対象を選択します。テナントが属するクラスタがV4.2.1.0以上であることを確認してください。<br>実行対象が **<UI-TERM key="ocp-v2.component.MonitorSearch.Tenant">テナント</UI-TERM>** の場合：<ul><li>**<UI-TERM key="ocp-v2.Detail.LoadBalance.AddObproxyLoadBalanceAppDrawer.Add">追加</UI-TERM>** ボタンをクリックして、複数のテナントを追加できます。</li><li>クラスタまたはテナントで **<UI-TERM key="ocp-v2.Component.LogTypeSelect.All">すべて</UI-TERM>** を選択した場合、**<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterWithExclude.ExcludeObjects">除外対象</UI-TERM>** を使用して、スケジュールタスクを実行しない対象を除外できます。</li></ul> |
     | タスクタイプ  | スケジュールタスクの実行タイプを選択します。<ul><li>実行対象が **<UI-TERM key="ocp-v2.Cluster.Arbitration.Tenant">テナント</UI-TERM>** の場合、**テナント単位のメジャーコンパクションおよび統計情報収集** と **テナント単位のメジャーコンパクション** の2種類のタスクタイプをサポートします。<ul><li>**テナント単位のメジャーコンパクションおよび統計情報収集**：スケジュールされたタイミングでテナントのメジャーコンパクションおよび統計情報収集をトリガーし、ストレージ容量とクエリパフォーマンスを最適化します（メジャーコンパクション操作を開始できるのはプライマリテナントのみです）。</li><li>**テナント単位のメジャーコンパクション**：スケジュールされたタイミングでテナントのメジャーコンパクションをトリガーし、ストレージ容量とクエリパフォーマンスを最適化します（メジャーコンパクション操作を開始できるのはプライマリテナントのみです）。</li></ul></li><li>実行対象が **<UI-TERM key="ocp-v2.Detail.Resource.Top.Table">テーブル</UI-TERM>** の場合、**テーブル単位の統計情報収集** のみをサポートします。スケジュールされたタイミングでテーブルの統計情報を収集し、クエリパフォーマンスの最適化に利用します。</li></ul> |
     | 統計対象 | 実行対象が **<UI-TERM key="ocp-v2.Session.LockAnalysis.Table">テーブル</UI-TERM>** の場合、特定のデータベースまたはテーブルを選択できます。最大50個のテーブルをサポートします。 |
     | Schema統計パラメータ | タスクタイプとして **テナント単位のメジャーコンパクションおよび統計情報収集** または **テーブル単位の統計情報収集** を選択した場合、OCPは収集方法、収集の並列度、収集の粒度などのパラメータ情報に対してデフォルト設定を行っています。システムの既存設定を直接使用するか、業務の実際の状況に応じてパラメータ後の編集ボタンをクリックして変更できます。パラメータの詳細な説明については、[統計情報の収集](../../700.tenant-functions/1450.manage-statistical-information/200.collect-statistics-information.md)の **自動統計情報収集のパラメータ情報の変更** を参照してください。</main>

   b. スケジュールタスクの実行パラメータを設定します。

     | パラメータ      | 説明     |
     |-----------|----------|
     | スケジュール計画  | スケジュールタスクの実行方式を選択します。**<UI-TERM key="ocp-v2.src.constant.schedule.RepeatExecution">繰り返し実行</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.schedule.ExpressionSetting">式の設定</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.schedule.ExecuteOnlyOnce">1回のみ実行</UI-TERM>** の3種類をサポートします。<ul><li>**<UI-TERM key="ocp-v2.src.constant.schedule.RepeatExecution">繰り返し実行</UI-TERM>**：固定の頻度でタスクを繰り返し実行します。</li><li>**<UI-TERM key="ocp-v2.src.constant.schedule.ExpressionSetting">式の設定</UI-TERM>**：カスタム式に従って実行します。</li><li>**<UI-TERM key="ocp-v2.src.constant.schedule.ExecuteOnlyOnce">1回のみ実行</UI-TERM>**：タスクは1回のみ実行されます。</li></ul> |
     | 実行頻度  | スケジュール計画が **<UI-TERM key="ocp-v2.src.constant.schedule.RepeatExecution">繰り返し実行</UI-TERM>** の場合に入力します。サポートされている実行頻度は、分、日、週、月です。   |
     | 式    | スケジュール計画が **<UI-TERM key="ocp-v2.src.constant.schedule.ExpressionSetting">式の設定</UI-TERM>** の場合に入力します。Crontab式を使用してタスクの実行頻度を設定できます。Crontab式のフィールドと値については、[バックグラウンドタスクリスト](../../2100.appendix/200.ocp-background-tasks.md)の **スケジュール式** を参照してください。<main id="notice" type='notice'><h4>注意</h4><ul><li>Crontab式では `second` フィールドの設定はサポートされていません。その他のフィールドは、このドキュメントを参照して設定できます。</li><li>式の形式入力が正確であることを確認してください。誤った形式（例：存在しない日付の入力、式に余分なスペースがある場合など）では、スケジュールタスクが実行できません。</main>   |
     | 実行時間  | スケジュールタスクの具体的な実行時間を選択します。   |
     | 終了日時  | スケジュールタスクの終了時間を選択します。**<UI-TERM key="ocp-v2.Schedule.components.Strategy.Indefinite">期限なし</UI-TERM>** と **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Custom">カスタマイズ</UI-TERM>** の2種類をサポートします。<ul><li>**<UI-TERM key="ocp-v2.components.CorntabConfig.Indefinite">無期限</UI-TERM>**：タスクは手動で停止されるまで継続的に実行されます。</li><li>**<UI-TERM key="ocp-v2.src.constant.oceanbase.Custom">カスタマイズ</UI-TERM>**：具体的な時間を設定すると、タスクはその時刻に停止します。</li></ul>   |
     | 同一対象の複数タスクの同時実行を許可するかどうか  | スケジュール計画が **<UI-TERM key="ocp-v2.src.constant.schedule.RepeatExecution">繰り返し実行</UI-TERM>** または **<UI-TERM key="ocp-v2.src.constant.schedule.ExpressionSetting">式の設定</UI-TERM>** の場合に入力します。**<UI-TERM key="ocp-v2.src.constant.schedule.Permitted">許可</UI-TERM>** を選択した場合、システムは前のタスクが完了する前に新しいスケジュールタスクを作成し、複数のタスクを並行実行できます。  |

   c. スケジュールタスクのスケジュール期限切れポリシーを設定します。

     | パラメータ         | 説明     |
     |--------------|----------|
     | 最大遅延時間 | スケジュールタスクの実行遅延を許容する最大時間を選択します。   |
     | 最大遅延時間を超えた場合の実行 | タスクの実行が最大遅延時間を超えた場合、タスクを破棄して実行しないかどうかを選択できます。   |

   d. スケジュールタスクを有効にするかどうかを選択します。有効にすると、このスケジュールタスクは作成成功後すぐに実行されます。

5. （オプション）スケジュールタスクの備考情報を追加します。

6. **<UI-TERM key="ocp-v2.External.Component.DataSourceTable.New">新規作成</UI-TERM>** をクリックします。
