# レポートセンターの管理

レポートセンターでは、**クラスタ**、**テナント**、**OBProxy**、**ホスト**、**Binlog**、**アービトレーションサービス** などの管理対象に関する基本情報、リソース割り当て状況、使用状況のレポートデータを生成およびダウンロードできます。

運用保守担当者はレポートを通じてリソース異常をリアルタイムに監視し、潜在的なリスクに迅速に対処できます。リソース計画担当者は、履歴データとリアルタイムデータに基づいて、リソース割り当てや拡張計画を精密に立案できます。ビジネス責任者は業務リソースコストを明確に把握し、投資対効果を科学的に評価することで、企業のリソース最適化と意思決定を強力なデータで支え、全体のリソース管理効率を効果的に向上させることができます。

## レポートの新規作成

このセクションでは、管理対象に対して新しいレポートを追加する方法について説明します。

### 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持っていることを確認してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">レポートセンター</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.pages.ReportCenter.ReportCenter">レポートセンター</UI-TERM>** ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.pages.ReportCenter.NewReport">新規レポート</UI-TERM>** をクリックします。

4. 右側のパネルでレポート関連情報を設定します。各パラメータの説明は以下のとおりです。

    |  パラメータ   |  説明   |
    |---------|---------|
    | レポート名  | <ul><li>中国語または英字で始まり、中国語、英字、または数字で終わる必要があります。</li><li>2文字から32文字をサポートします。</li><li>特殊文字はアンダースコアのみサポートします。</li></ul>    |
    | タイプ      | 管理対象のタイプを選択します。**<UI-TERM key="ocp-v2.Cluster.Import.Cluster">クラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.component.MonitorSearch.Tenant">テナント</UI-TERM>**、**OBProxy**、**<UI-TERM key="ocp-v2.Component.OCPObjscope.Host">ホスト</UI-TERM>**、**Binlog**、**<UI-TERM key="ocp-v2.Detail.Overview.ArbitrationService">アービトレーションサービス</UI-TERM>** の6種類をサポートします。    |
    | 対象の選択  | 実際のニーズに応じて、具体的な管理対象を選択します。<br>すべての対象を選択した場合、右側の **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterWithExclude.ExcludeObjects">除外対象</UI-TERM>** をチェックすることで、レポートの生成が不要な対象を除外できます。    |
    | プロパティ      | レポートに表示されるプロパティ情報です。選択する **<UI-TERM key="ocp-v2.page.External.SSOInfoDrawer.Type">タイプ</UI-TERM>** によって、表示されるプロパティ情報は異なります。     |
    | 備考      | レポートに補足説明を追加します。     |

5. **<UI-TERM key="ocp-v2.Cluster.Component.TakeOverArbitrationDrawer.Ok">確定</UI-TERM>** をクリックします。

## レポートの表示とダウンロード

レポートが生成された後、生成されたレポートのリストを表示し、レポートをローカルにダウンロードして、管理対象のレポートデータを即座に確認できます。レポートはデフォルトで30日後に自動的に削除されるため、有効期間内にダウンロードすることを推奨します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持っていることを確認してください。

* 現在のユーザーが自身で作成したレポートの表示とダウンロードのみをサポートします。

* **新規レポート** が作成されていること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.pages.ReportCenter.ReportCenter">レポートセンター</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.src.hook.useMenu.ReportCenter">レポートセンター</UI-TERM>** ページに移動します。

3. ダウンロードするレポートを選択し、操作列の **...** から **<UI-TERM key="ocp-v2.Information.Detail.DownloadCollectDrawer.Download">ダウンロード</UI-TERM>** をクリックします。

4. これで、このレポートをローカルにダウンロードして閲覧できます。

## レポートの削除

システムが自動的にレポートを削除する場合を除き、生成されたレポートを手動で削除することもできます。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持っていることを確認してください。

* 現在のユーザーが自身で作成したレポートのみを削除できます。

* **新規レポート** が作成されていること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">レポートセンター</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">レポートセンター</UI-TERM>** ページに移動します。

3. ダウンロードするレポートを選択し、操作列の **...** から **<UI-TERM key="ocp-v2.Host.Detail.Delete">削除</UI-TERM>** をクリックします。

4. ダイアログボックスで **<UI-TERM key="ocp-v2.component.TenantList.Delete">削除</UI-TERM>** をクリックすると、このレポートは即座に削除されます。

## レポートの保持期間の変更

レポートはデフォルトで30日間のみ保持されます。**システム管理** > **システムパラメータ** で、`ocp.report.center.report.retention.days` パラメータを使用してレポートの保持期間を変更できます。操作の詳細については、[システムパラメータの変更](../1600.system-management-features/500.manage-system-parameter/200.modify-system-parameters.md)を参照してください。
