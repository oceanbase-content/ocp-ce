# グローバルスケジューリングルールの設定

このページでは、OCPで管理されるオブジェクトに統一されたスケジューリングルールを設定する方法について説明します。オブジェクトの特性に応じて個別のスケジューリングルールを設定する必要がある場合は、[単一オブジェクトのスケジューリングルールの設定](../200.configure-the-rules/100.configure-single-rules.md)を参照してください。

## 背景

グローバルスケジューリングルールを設定すると、OCPはそのルールに従って、管理下のOceanBaseクラスタ、OceanBaseテナント、およびOBProxyクラスタに対して定期的な巡回検査を実行します。詳細については、[巡回検査機能](../100.inspection-management.md)を参照してください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**または**テナントメンテナンス**リソース権限。
* オペレーション管理**<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>**メニュー権限。

## 手順

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** を選択します。

3. デフォルトで、**<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionList">巡回点検リスト</UI-TERM>** ページに移動します。

4. ページの右上隅にある **<UI-TERM key="ocp-v2.page.Inspection.ConfigureGlobalSchedulingRules">グローバルスケジューリングルールの設定</UI-TERM>** ボタンをクリックし、**<UI-TERM key="ocp-v2.page.Inspection.ConfigureGlobalSchedulingRules">グローバルスケジューリングルールの設定</UI-TERM>** ページに移動します。

5. スケジューリングルールが適用される **<UI-TERM key="ocp-v2.Inspection.Task.InspectionObject">対象</UI-TERM>** を選択します。

   **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.ObjectsWithNoSchedulingRulesConfigured">スケジューリングルールが設定されていない対象</UI-TERM>** および **すべてのオブジェクト（スケジューリングルールが設定されていないオブジェクトと既にスケジューリングルールが設定されているオブジェクトを含む）** にスケジューリングルールを設定できます。
   * スケジューリングルールが設定されていないオブジェクト：個別のスケジューリングルールが設定されていないオブジェクトにのみスケジューリングルールを設定します。既にスケジューリングルールが設定されているオブジェクトは、既存のルールに従って巡回検査を続けます。
   * すべてのオブジェクト（スケジューリングルールが設定されていないオブジェクトと既にスケジューリングルールが設定されているオブジェクトを含む）：すべてのオブジェクトに対してスケジューリングルールを再設定します。**すべてのオブジェクト** にスケジューリングルールを設定する場合、今回設定するスケジューリングルールが、巡回検査対象の既存の個別スケジューリングルールを上書きします。

6. **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.ConfigureSchedulingRules">スケジューリングルールの設定</UI-TERM>** ページで、異なる巡回検査シナリオに対してスケジュール周期とスケジューリング時間を設定し、スケジューリングの締め切り時刻とスケジューリングルールの有効化を設定します。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    少なくとも1つの巡回検査シナリオに対してスケジュール周期とスケジューリング時間を設定する必要があります。
   </main>

7. **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">送信</UI-TERM>** をクリックします。
