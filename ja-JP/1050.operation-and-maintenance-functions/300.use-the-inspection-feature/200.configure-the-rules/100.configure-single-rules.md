# 単一検査対象のスケジューリングルールを設定する

このページでは、検査対象に対して個別のスケジューリングルールを設定する方法について説明します。OCPで管理されるすべての対象に統一されたスケジューリングルールを適用する場合は、[グローバルスケジューリングルールの設定](../200.configure-the-rules/200.configure-global-rules.md)を参照してください。

## 背景

単一の検査対象にスケジューリングルールを設定すると、OCPはそのルールに従って定期的な検査を実行します。詳細については、[検査機能](../100.inspection-management.md)を参照してください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**または**テナントメンテナンス**のリソース権限。
* オペレーション管理**<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>**メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>**を選択します。

3. デフォルトで**<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.InspectionList">巡回点検リスト</UI-TERM>**ページに移動します。

4. 検査対象があるタブをクリックします。

5. リストから検査を開始する対象を選択し、操作列の**<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.ConfigureSchedulingRules">スケジューリングルールの設定</UI-TERM>**をクリックします。

6. **<UI-TERM key="ocp-v2.src.constant.inspection.ConfigureSchedulingRules">スケジューリングルールの設定</UI-TERM>**ページで、異なる検査シナリオに対してスケジュール周期とスケジュール時間を設定し、スケジュールの締め切り時刻とスケジューリングルールの有効化を設定します。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    少なくとも1つの検査シナリオに対してスケジュール周期とスケジュール時間を設定する必要があります。
   </main>

7. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.Submit">送信</UI-TERM>**をクリックします。
