# 点検タスクの表示

このページでは、点検タスクページの詳細内容について説明します。点検タスクページでは、タスクの基本情報を確認し、レポートの表示およびダウンロード操作を実行できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** または **テナント読み取り専用** リソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡回検査の履歴</UI-TERM>** タブをクリックします。

4. 点検タスクリストで、点検タスクIDをクリックしてタスク詳細ページに移動します。**<UI-TERM key="ocp-v2.Inspection.Task.TaskStatus">ステータス</UI-TERM>**、**<UI-TERM key="ocp-v2.Task.Detail.CurrentProgress">現在の進捗状況</UI-TERM>**、**<UI-TERM key="ocp-v2.TraceDetail.TraceContent.StartTime">実行開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Task.Detail.AccumulatedTaskTime">タスクの累積時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Task.Detail.TaskInitiator">タスクの実行者</UI-TERM>** などの情報を確認できます。

5. **<UI-TERM key="ocp-v2.Task.Detail.LogView">ログビュー</UI-TERM>** または **<UI-TERM key="ocp-v2.Task.Detail.FlowView">フロービュー</UI-TERM>** をクリックすると、ビューを切り替えることができます。

6. **<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">現在の進捗状況を確認する</UI-TERM>** をクリックして、タスクの実行進捗状況を確認します。

7. **<UI-TERM key="ocp-v2.Detail.Log.LogCard.DownloadLogs">ログをダウンロードする</UI-TERM>** をクリックして、ログ情報をローカルにダウンロードして確認します。
