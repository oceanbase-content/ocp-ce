# 巡検の概要

このセクションでは、巡検の機能について説明します。これには、巡検項目の設定、スケジュールルールの設定、巡検の開始、および巡検履歴の確認が含まれます。

## 機能紹介

巡検は、システムの安定した効果的な運用を保証するために不可欠なプロセスであり、システムに存在する潜在的な問題を迅速に発見することを目的としています。OCPの巡検機能は、管理対象のOceanBaseシステムおよびその環境が期待通りに機能しているかどうかをチェックし、監視やアラートのシナリオではカバーできないセキュリティ上のリスクをレポートで明らかにし、レポートのダウンロード機能も提供します。

ユーザーは巡検ルールを設定することで、OCPシステムにクラスタのパーティション情報、シリアル番号、パラメータの定期または単発チェックを実行させ、巡検結果のフィードバックによってクラスタのメンテナンスを実現し、OCP内のクラスタの正常な稼働を保証します。

初めて巡検機能を使用する場合の操作手順は以下のとおりです：

1. [巡検項目の設定](150.configure-inspection-items.md)。実際の状況に応じて、使用する巡検項目を確認します。

2. 巡検のスケジュールルールを設定します。[個別オブジェクトのスケジュールルール設定](200.configure-the-rules/100.configure-single-rules.md)と[グローバルオブジェクトのスケジュールルール設定](200.configure-the-rules/200.configure-global-rules.md)があります。

3. 巡検対象に対してその他の操作を実行します。[個別オブジェクトの基本巡検の開始](400.initate-a-inspection/100.initate-single-inspection.md)および[グローバル基本巡検の開始](400.initate-a-inspection/200.initiate-global-inspection.md)が含まれます。

4. [巡検タスクの確認](500.view-an-inspection-task.md)、[巡検レポートの確認](600.manage-inspection-report/100.view-inspection-report.md)、[巡検レポートのダウンロード](600.manage-inspection-report/200.download-inspection-report.md)を行います。

## 巡検項目の設定

**<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.InspectionItems">巡回検査項目</UI-TERM>** は、OCPが管理するリソースのリスク判断基準を定義します。巡検モジュールは、巡検項目の設定ルールに基づいてリソースをチェックし、指定されたリスクレベルを返します。

**<UI-TERM key="ocp-v2.src.constant.inspection.ConfigureInspectionItems">巡回検査項目の設定</UI-TERM>** ページでは、巡検項目名、巡検項目タイプ、巡検項目シナリオ、説明、巡検ルールなどの情報を確認できます。また、巡検項目の有効化または無効化操作もサポートしています。詳細については、[巡検項目の設定](150.configure-inspection-items.md)を参照してください。

| **<UI-TERM key="ocp-v2.component.ParameterTemplate.Parameter">パラメータ</UI-TERM>** | **<UI-TERM key="ocp-v2.component.alarm.RuleDetail.Description">説明</UI-TERM>** |
| --- | --- |
| 巡検項目 | システムで設定された巡検項目名で、グローバルに一意です。|
| 巡検項目タイプ | この巡検項目が指定する巡検項目タイプ。例：OceanBaseクラスタ、テナント、ホスト。 |
| 巡検対象タイプ | 巡検項目が適用される対象タイプ。異なる巡検対象には設定可能な巡検項目が異なります。巡検対象には、OceanBaseクラスタ、テナント、OBProxyクラスタが含まれます。 |
| 巡検項目シナリオ | 巡検が適用されるシナリオ。基本巡検、性能巡検、詳細巡検が含まれます。 |
| 説明 | 巡検項目に関する説明。 |
| 巡検ルール | 巡検項目の設定ルール。 |

## スケジュールルールの設定

**<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.SchedulingRules">スケジューリングルール</UI-TERM>** は、巡検タスクの実行テンプレートを定義します。巡検タスクは、巡検スケジュールルールで定義された各ルールに従って巡検作業を実行します。

実際の状況に応じて、個々のオブジェクトに対してカスタマイズされた設定を行うか、すべてのオブジェクトに対して統一されたスケジュールルールを作成できます。スケジュール周期、スケジュール時間、スケジュール締切日、スケジュールの有効化の有無などを含みます。詳細については、[個別オブジェクトのスケジュールルール設定](200.configure-the-rules/100.configure-single-rules.md)および[グローバルオブジェクトのスケジュールルール設定](200.configure-the-rules/200.configure-global-rules.md)を参照してください。

| **<UI-TERM key="ocp-v2.component.ParameterTemplate.Parameter">パラメータ</UI-TERM>** | **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.Description">説明</UI-TERM>** |
| --- | --- |
| スケジュール周期 | 月、週、日単位でのスケジュールをサポートします。 |
| スケジュール時間 | 巡検の実行時間を選択します。 |
|スケジュール締切時間|この時間を超えると、自動巡回検査は行われなくなります。デフォルトでは無効です。|
|スケジュールの有効化|デフォルトでは無効です。無効の場合、自動巡回検査は行われません。|

## 巡回検査の開始

巡回検査を開始すると、OCPは設定された検査項目に従ってクラスタを即座にチェックします。OCPの巡回検査項目には、以下のシナリオが含まれます：

* 基礎巡回検査：OCPが管理するリソースの基本状態（クラスタ状態、レプリカ状態など）をチェックします。日常的な巡回検査業務に適しています。
* パフォーマンス巡回検査：OCPが管理するリソースのパフォーマンス（大規模トランザクション、スロークエリなど）をチェックします。パフォーマンス分析業務に適しています。
* 深層巡回検査：OCPが管理するリソースに対して詳細なチェックを行い、隠れたリスクを発見します。ビジネスのピーク時前の巡回検査業務に適しています。

単一のオブジェクトに対して特定のシナリオで巡回検査を開始するか、すべてのオブジェクトに対して特定のシナリオでグローバルな巡回検査を開始できます。詳細については、[単一オブジェクトの基礎巡回検査の開始](400.initate-a-inspection/100.initate-single-inspection.md)および[グローバル基礎巡回検査の開始](400.initate-a-inspection/200.initiate-global-inspection.md)を参照してください。

## 巡回検査履歴

**<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡回検査の履歴</UI-TERM>** には、開始されたすべての巡回検査タスクが表示され、巡回検査対象に存在するセキュリティ上のリスクのレベルと数が概要的に表示されます。

**<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡回検査の履歴</UI-TERM>** タブでは、巡回検査タスクID、巡回検査対象、巡回検査対象タイプ、巡回検査シナリオ、巡回検査開始時間、巡回検査終了時間、タスク状態、巡回検査結果を確認できます。また、[巡回検査タスクの表示](500.view-an-inspection-task.md)、[巡回検査レポートの表示](600.manage-inspection-report/100.view-inspection-report.md)、[レポートのダウンロード](600.manage-inspection-report/200.download-inspection-report.md)などの一般的な操作も行えます。
