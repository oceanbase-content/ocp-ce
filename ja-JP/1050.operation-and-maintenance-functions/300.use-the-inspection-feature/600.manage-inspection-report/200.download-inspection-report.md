# レポートのダウンロード

このページでは、点検レポートをダウンロードする方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。
2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** を選択します。
3. **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡回検査の履歴</UI-TERM>** タブをクリックします。
4. 点検履歴リストで、表示したいタスクを選択し、操作列の **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.DownloadReport">レポートをダウンロード</UI-TERM>** をクリックすると、点検レポートがHTML形式でローカルにダウンロードされ、閲覧できます。

   レポートでは点検の詳細を確認できます。詳細については、[点検レポートの表示](../600.manage-inspection-report/100.view-inspection-report.md)を参照してください。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><strong>実行中</strong> または <strong>実行失敗</strong> の状態にある点検タスクは、点検レポートを表示またはダウンロードできません。点検タスクIDをクリックすると、タスクの現在の進捗状況や実行失敗の原因を確認できます。</p>
   </main>
