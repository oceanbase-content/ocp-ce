# 巡回点検レポートの表示

このページでは、巡回点検レポートの表示方法について説明します。巡回点検レポートは、以下の2つの方法で表示できます：

* **方法1**：**<UI-TERM key="ocp-v2.page.Inspection.InspectionList">巡回点検リスト</UI-TERM>** ページの点検進捗状況で、**<UI-TERM key="ocp-v2.src.constant.inspection.ViewReports">レポートを表示</UI-TERM>** をクリックします。
* **方法2**：**<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡回検査の履歴</UI-TERM>** ページで表示します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** メニュー権限。

## 手順

以下の手順は **方法2** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** を選択します。

3. **<UI-TERM key="ocp-v2.page.Inspection.InspectionHistory">巡回検査の履歴</UI-TERM>** タブをクリックします。

4. 巡回点検履歴リストで、表示したいタスクを選択し、操作列の **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.Inspection.Item.ViewReports">レポートを表示</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.page.Report.InspectionReport">巡回検査報告書</UI-TERM>** ページに移動し、点検の詳細を確認します。**<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.BasicInformation">基本情報</UI-TERM>**、**<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.OverviewOfInspectionResults">巡回点検結果の概要</UI-TERM>**、およびリスクの詳細が含まれます。

   **<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.SummaryByRisk">リスク別集計</UI-TERM>** と **<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.SummaryByInspectionItems">巡回点検項目別集計</UI-TERM>** の2つの方法で詳細なリスク情報を表示できます。**<UI-TERM key="ocp-v2.Report.Inspection.ReportContent.SummaryByRisk">リスク別集計</UI-TERM>** では、リスクレベルで点検結果をフィルタリングできます。

## 関連操作

OCPでは、システムパラメータを通じて履歴巡回点検レポートを定期的にクリーンアップできます：

1. `ocp.inspection.report.expired_cleanup.enabled` は巡回点検レポートの期限切れクリーンアップスイッチで、デフォルトは `false` です。`true` に設定すると、OCPは `ocp.inspection.report.expired.days` パラメータで指定された日数以前のすべての巡回点検レポートを自動的にクリーンアップします。

2. `ocp.inspection.report.expired.days` は巡回点検レポートの有効期限を設定するために使用され、デフォルトは15日です。自動クリーンアップ機能が有効になっている場合、OCPは毎日午前0時になると、このパラメータで指定された日数以前のすべての巡回点検レポート（ホスト標準化のチェックレポートは除く）をクリーンアップします。
