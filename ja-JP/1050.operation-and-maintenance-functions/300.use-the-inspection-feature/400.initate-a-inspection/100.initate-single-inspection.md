# 単一オブジェクトの点検を開始する

このページでは、単一オブジェクトの点検を開始する手順について説明します。グローバルな点検を開始する場合は、[グローバル点検の開始](../400.initate-a-inspection/200.initiate-global-inspection.md)を参照してください。

## 背景

点検を開始すると、OCPは設定された点検ルールに従ってクラスタのチェックを即座に実行します。詳細については、[点検機能](../100.inspection-management.md)を参照してください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**または**テナントメンテナンス**リソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** メニュー権限。

## 手順

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** を選択します。

3. デフォルトで **<UI-TERM key="ocp-v2.page.Inspection.InspectionList">巡回点検リスト</UI-TERM>** ページに移動します。

4. 点検対象があるタブをクリックします。

5. リストから点検を開始したいオブジェクトを選択し、操作列の **<UI-TERM key="ocp-v2.Inspection.Item.InitiateInspection">巡回点検を開始する</UI-TERM>** にカーソルを合わせます。ドロップダウンリストから必要な点検シナリオを選択します。

6. ポップアップウィンドウの **<UI-TERM key="ocp-v2.Oracle.Component.AddObjectPrivilegeDrawer.Determine">確定</UI-TERM>** をクリックします。

7. ポップアップウィンドウのタスクIDをクリックするか、**<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** でタスクの進捗状況を確認します。詳細については、[タスク管理](../../../1600.system-management-features/600.manage-tasks.md)を参照してください。
