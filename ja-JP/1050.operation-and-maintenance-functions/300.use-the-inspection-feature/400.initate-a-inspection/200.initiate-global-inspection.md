# グローバル検査の開始

このページでは、グローバル検査を開始する手順について説明します。単一のオブジェクトに対して検査を開始する場合は、[単一オブジェクトの検査の開始](../400.initate-a-inspection/100.initate-single-inspection.md)を参照してください。

## 背景

検査開始操作を実行すると、OCPは直ちに検査項目に設定された内容に従って、管理下のOceanBaseクラスタ、OceanBaseテナント、およびOBProxyクラスタをチェックします。詳細については、[検査機能](../100.inspection-management.md)を参照してください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**または**テナントメンテナンス**リソース権限。
* メンテナンス管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** メニュー権限。

## 手順

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** を選択します。

3. デフォルトで **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.InspectionList">巡回点検リスト</UI-TERM>** ページが表示されます。

4. ページの右上隅にある **<UI-TERM key="ocp-v2.page.Inspection.InitiateAGlobalInspection">グローバル検査を開始する</UI-TERM>** にカーソルを合わせ、ドロップダウンリストから必要な検査シナリオを選択します。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Ok">確定</UI-TERM>** をクリックします。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li>選択したシナリオで検査中のクラスタがある場合、そのクラスタはスキップされます。</li>
    <li>選択したシナリオで検査中のホストがある場合、そのホストはスキップされます。</li>
    </ul>
   </main>

6. ポップアップウィンドウのタスクIDをクリックするか、**<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** でタスクの進捗状況を確認します。詳細については、[タスク管理](../../../1600.system-management-features/600.manage-tasks.md)を参照してください。
