# 点検項目の設定

このページでは、点検対象に対する点検項目の設定方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.OMManagement">運用および保守管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.InspectionService">ヘルスチェックサービス</UI-TERM>** を選択します。

3. デフォルトで **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionList">巡回点検リスト</UI-TERM>** ページに移動します。

4. 点検対象があるタブをクリックします。

5. リストから点検項目を設定する対象を選択し、操作列の **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.inspection.ConfigureInspectionItems">巡回検査項目の設定</UI-TERM>** をクリックします。

6. **<UI-TERM key="ocp-v2.src.constant.inspection.ConfigureInspectionItems">巡回検査項目の設定</UI-TERM>** ページで、OCPのすべての組み込み点検項目情報を確認します。これには、点検項目名、点検項目タイプ、点検項目シナリオ、説明、点検ルール、および有効状態が含まれます。

   * **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionItems">巡回点検項目</UI-TERM>** 列の検索アイコンをクリックすると、点検項目のあいまい検索が可能です。
   * **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.InspectionItemScenario">巡回点検項目のシナリオ</UI-TERM>** 列と **<UI-TERM key="ocp-v2.src.constant.backup.Enable">有効にする</UI-TERM>** 列で点検項目をフィルタリングできます。

7. 点検対象の実際の状況に応じて、点検項目を有効または無効にします。
