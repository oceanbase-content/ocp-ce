# 情報収集項目の設定

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能を提供していません。</p>
</main>

OCPは組み込みの情報収集項目を提供しています。実際のニーズに応じて、このページを参照して収集トリガーのソースを調整し、不要なトリガーのソースを無効にすることができます。

収集トリガーのソースを有効にすると、OCPは対応するイベント情報を自動的に収集し、情報収集レコードレポートを生成します。収集トリガーのソースを無効にすると、対応するイベントが発生してもシステムは情報収集アクションを自動的にトリガーしません。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.InformationCollection">情報収集</UI-TERM>** メニュー権限。

## 手順

1. OCPプラットフォームにログインし、左側のナビゲーションバーから **オペレーション管理 > 情報収集** を選択します。

2. デフォルトで **<UI-TERM key="ocp-v2.src.hook.useMenu.InformationCollection">情報収集</UI-TERM>** レコードのリストページに入ります。

3. 右上の **<UI-TERM key="ocp-v2.page.Information.InformationCollectionSettings">情報収集設定</UI-TERM>** をクリックします。

4. ポップアップパネルで情報収集項目を無効または有効にします。

## 情報収集項目の説明

OCPでは **収集設定** と **収集内容** を通じて収集トリガーのソースを設定できます。

### 収集設定

**収集設定** ページでは、OCPがサポートするアラート収集項目と、それぞれに対応する情報収集シナリオが提供されています。有効にすると、対応するアラートイベントが発生した際にシステムが自動的に情報収集アクションをトリガーします。

| 収集タイプ | 項目 | 情報収集シナリオ |
| -------- | ------- | ------------ |
| アラート | tenant_cpu_percent_over_threshold OceanBaseテナントスレッド使用率がしきい値を超えた場合 | tenant_high_cpu |
| アラート | ob_tenant_cpu_usage_over_threshold OceanBaseテナントCPU使用率がしきい値を超えた場合 | tenant_high_cpu |
| アラート | ob_tenant_large_trans_exist OceanBaseテナントに大規模トランザクションが存在する場合 | tenant_tranction_monitor |
| アラート | ob_tenant_long_trans_exist OceanBaseテナントに長時間トランザクションが存在する場合 | tenant_tranction_monitor |
| アラート | ob_tenant_expired_trans_exist OceanBaseテナントにハングトランザクションが存在する場合 | tenant_tranction_monitor |
| アラート | ob_tenant_exists_expired_xa_trans OceanBaseテナントにXAハングトランザクションが存在する場合 | tenant_tranction_monitor |
| アラート | observer_process_stop OBServerプロセスが停止した場合 | observer_status_monitor |
| アラート | os_observer_not_exist OceanBaseサーバープロセスが存在しない場合 | observer_status_monitor |
| アラート | ob_server_stopped OceanBaseサーバーがサービスを停止した場合 | observer_status_monitor |

| アラート | mgragent_process_stop ocp_mgragentプロセスが停止した場合 | ocp_agent_status_monitor |
