# 情報収集タスクの作成

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionではこの機能は提供されません。</p>
</main>

このページを参照して、収集タスクを手動でトリガーし、収集対象の異常情報を即座に取得することができます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.page.Information.InformationCollection">情報収集</UI-TERM>** メニュー権限。

## 手順

1. OCPプラットフォームにログインし、左側のナビゲーションバーから **オペレーション管理 > 情報収集** を選択します。

2. デフォルトで **<UI-TERM key="ocp-v2.src.hook.useMenu.InformationCollection">情報収集</UI-TERM>** レコードのリストページに入ります。

3. 右上の **<UI-TERM key="ocp-v2.page.Information.CreateInformationCollection">情報収集を作成する</UI-TERM>** ボタンをクリックします。

4. ポップアップパネルで情報収集に関する情報を設定し、完了後に **<UI-TERM key="ocp-v2.User.Oracle.UserList.Determine">確定</UI-TERM>** をクリックします。

    設定情報の説明は以下のとおりです。

    |  パラメータ  |  説明   |
    |--------|---------|
    |  対象タイプ  | 異常情報を収集する対象タイプを選択します。**<UI-TERM key="ocp-v2.Task.TaskObjectAndType.OceanbaseCluster">OceanBase クラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Monitor.OceanbaseTenants">OceanBaseテナント</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.inspection.ObproxyCluster">OBProxyクラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.src.util.cluster.Host">ホスト</UI-TERM>** の4種類がサポートされています。   |
    |  対象      | 情報収集の具体的な対象を選択します。   |
    |  収集時間  | 情報収集の時間を選択します。**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyMinutes.1">直近10分間</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyMinutes.1">直近15分間</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyMinutes.2">直近30分間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearlyHour">直近1時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyHours">直近3時間</UI-TERM>** がサポートされています。   |
    |  情報収集シナリオ  | **<UI-TERM key="ocp-v2.Oracle.Component.AddObjectPrivilegeDrawer.ObjectType">オブジェクトタイプ</UI-TERM>** によって、情報収集のシナリオが異なります。各対象がサポートする収集シナリオは以下のとおりです：<ul><li><b>OceanBaseクラスタ</b><ul><li>obproxy異常</li><li>OCP Agent異常</li><li>データディスク異常</li><li>マージ異常</li><li>クラスタ異常</li><li>メモリ異常</li><li>CPU異常</li></ul></li><li><b>OceanBaseテナント</b><ul><li>データディスク異常</li><li>マージ異常</li><li>メモリ異常</li><li>CPU異常</li></ul></li><li><b>OBProxyクラスタ</b><ul><li>obproxy異常</li><li>CPU異常</li></ul></li><li><b>ホスト</b><ul><li>OCP Agent異常</li><li>CPU異常</li></ul></li></ul> <main id="notice" type='notice'><h4>注意</h4><p><b>クラスタ異常</b> の情報収集シナリオは慎重に選択してください。クラスタ異常シナリオでは収集項目が多く、収集時間も長くなります。情報収集時はしばらくお待ちください。</p></main>    |
