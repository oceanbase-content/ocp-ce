# 情報収集の概要

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionではこの機能は提供されません。</p>
</main>

OceanBaseデータベースはネイティブ分散型データベースシステムであり、障害が発生した場合、その原因となる要因はマシン環境、設定パラメータ、稼働負荷など多岐にわたります。そのため、根本原因分析を行う過程で、ユーザーが調査に必要な情報を収集する作業は通常煩雑であり、調査に時間がかかり効率が低下するだけでなく、障害がエスカレートする（長時間放置され影響範囲が拡大する）こともあります。

OCPは統一された情報収集機能を提供しており、情報収集は主に指定された時間範囲内の重要な情報や異常情報を取得し、障害の調査や運用保守を支援します。アラートイベントが発生すると、OCPはシステム稼働中の揮発性情報を収集し、さまざまな障害シナリオに対する管理とカスタマイズされた障害処理を容易にします。

OCPの情報収集は、各収集タスクのメタ情報を保存します。主な項目は **<UI-TERM key="ocp-v2.page.Information.InformationCollectionId">情報収集ID</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Information.ObjectType">オブジェクトタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.Role.Detail.Object">対象</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.InformationCollectionInterval">情報収集区間</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.CollectionStartAndEndTime">収集開始・終了時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Optimize.Status">ステータス</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.InformationCollectionScenario">情報収集シナリオ</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.EventType">イベントタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.EventName">イベント名</UI-TERM>** などです。また、収集タスクに対する運用保守操作もサポートしています。

* **<UI-TERM key="ocp-v2.page.Information.InformationCollectionId">情報収集ID</UI-TERM>** または **<UI-TERM key="ocp-v2.Statistics.components.TaskTable.ObjectName">オブジェクト名</UI-TERM>** で収集情報を検索できます。

* **<UI-TERM key="ocp-v2.src.constant.tenant.Running">実行中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.package.Failed">失敗</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.Canceled">キャンセル済み</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.plan.Completed">完了済み</UI-TERM>** の各状態にある情報収集タスクを確認できます。状態に応じて、以下の操作を実行できます：

  * **<UI-TERM key="ocp-v2.src.constant.compute.Running">実行中</UI-TERM>** の情報収集タスクについては、**<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.Cancel">キャンセル</UI-TERM>** を実行できます。

  * **<UI-TERM key="ocp-v2.src.constant.backup.Completed">完了済み</UI-TERM>** の情報収集タスクについては、**<UI-TERM key="ocp-v2.Detail.Backup.See">確認する</UI-TERM>** および **<UI-TERM key="ocp-v2.page.Information.Download">ダウンロード</UI-TERM>** 操作を実行できます。

## 前提条件

OCPにログインしたユーザーが以下の権限を持っている場合にのみ、情報収集リストの情報を表示できます：

* **クラスタ読み取り専用** または **テナント読み取り専用** リソース権限。
* 運用管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.InformationCollection">情報収集</UI-TERM>** メニュー権限。

## 手順

情報収集は主に以下の4つのステップに分かれます：

1. [情報収集項目の設定](200.configure-information-collection-items.md)。情報収集項目とは情報収集のトリガーソースです。組み込みの収集項目から、収集のトリガーソースを調整し、不要なトリガーソースを無効にできます。

2. [情報収集タスクの作成](300.create-a-information-collection.md)。手動で収集タスクをトリガーし、収集対象の異常情報を即座に取得できます。

3. [情報収集の詳細を確認する](400.view-information-collection.md)。障害情報収集の詳細を確認します。これには **<UI-TERM key="ocp-v2.Detail.Backup.Details">詳細</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.CollectBasicInformationAboutObjects">収集対象の基本情報</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.AlarmSummaryInformation">アラート概要情報</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.RegularCheck">定期検査</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.RecentChanges">最近の変更</UI-TERM>**、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.InternalEvents">内部イベント</UI-TERM>** が含まれます。必要な情報を抽出して障害原因を特定できます。

4. [情報収集レポートのダウンロード](500.manage-information-collection-reports.md)。情報収集レポートをローカルにダウンロードして確認できます。

|  オブジェクトタイプ  | **<UI-TERM key="ocp-v2.component.MonitorSearch.Cluster">クラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.Tenant">テナント</UI-TERM>**、**OBProxy**、**<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.Host">ホスト</UI-TERM>** の4種類に分類されます  |  絞り込み検索をサポートします。  |
|  オブジェクト  |  **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.ObjectType">オブジェクトタイプ</UI-TERM>** と一対一で対応します  |  ホストはクラスタ（OceanBaseクラスタ & OBProxyクラスタ）ごとに表示され、絞り込み検索をサポートします。  |
|  情報収集区間 |  イベントの情報収集範囲  |  収集がトリガーされた後、システムはデフォルトで直近10分間の情報を収集します。ユーザーが手動で情報収集タスクを作成する場合、情報収集区間はユーザーの設定に従います。 |
|  収集開始・終了時間  |  情報収集の開始時刻および終了時刻  |  -  |
|  ステータス  |  **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Running">実行中</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Statistics.utils.Failed">失敗</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Information.Canceled">キャンセル済み</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.plan.Completed">完了済み</UI-TERM>**  |  絞り込み検索が可能です。  |

|  イベント名  |  情報収集をトリガーしたイベント名  |  イベント名は **<UI-TERM key="ocp-v2.page.Information.Alert">アラート</UI-TERM>** タイプのイベントにのみ存在します。  |
