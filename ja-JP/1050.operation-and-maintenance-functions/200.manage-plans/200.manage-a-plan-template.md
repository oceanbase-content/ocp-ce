# プランの管理

このセクションでは、プランの管理方法について説明します。

<main id="notice" type='notice'>
<h4>機能の適用対象</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionはこの機能をサポートしていません。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**または**テナントメンテナンス**リソース権限。
* オペレーション管理 **<UI-TERM key="ocp-v2.page.Plan.PlanManagement">緊急対応プラン管理</UI-TERM>** メニュー権限。

## 手順

### プランの作成

既存のプランがビジネスシナリオに合致しない場合、実際のビジネス要件に基づいてカスタマイズされたプランを作成できます。例えば、プランの対象範囲、拡張率、自動実行の有無などを設定できます。

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで **オペレーション管理 > プラン管理** を選択します。

3. **<UI-TERM key="ocp-v2.src.constant.auth.Plan">緊急対応プラン</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.src.constant.auth.Plan">緊急対応プラン</UI-TERM>** リストページに移動します。

4. 右上の **<UI-TERM key="ocp-v2.page.Plan.CreateAPlanTemplate">緊急対応プランを新規作成</UI-TERM>** をクリックします。

5. ポップアップパネルでプラン情報を設定し、完了後に **<UI-TERM key="ocp-v2.Instance.Overview.Ok">確定</UI-TERM>** をクリックします。

    プランのパラメータの説明は以下の通りです。

    |  パラメータ  |  説明  |
    |--------|---------|
    |  プラン名  |  カスタムプランの名前。 |
    |  プランタイプ  |  具体のプランタイプを選択します。プランタイプの説明については、[概要](100.plans-overview.md)の**プランタイプの説明**を参照してください。 |
    |  対象の選択  |  実際のニーズに応じて、プランがサポートする具体的な対象を選択します。対象のタイプは **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.PlanType">緊急対応プランの種類</UI-TERM>** の選択によって異なります。対象として **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.All">すべて</UI-TERM>** を選択した場合、プランがサポートする対象には、現在および将来新規に追加されるすべての同一タイプの対象が含まれます。右側の **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.ExcludeObjects">除外対象</UI-TERM>** をチェックすることで、このプランを適用しない対象を除外できます。  |
    |  拡張係数  |  **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.PlanType">緊急対応プランの種類</UI-TERM>** が **テナントメモリ上限超過後のテナントメモリ拡張**、**テナントCPU上限超過後のテナントCPU拡張**、**OBProxy接続数不足時の自動構成拡張** の場合に表示され、拡張率を設定します。設定範囲は1% ～ 100% で、デフォルトは20% です。|
    |  サーバーメモリ最大使用率  |  **<UI-TERM key="ocp-v2.Plan.Component.CreateDrawer.PlanType">緊急対応プランの種類</UI-TERM>** が **OBProxy接続数不足時の自動構成拡張** の場合に表示され、OBProxyクラスタのサーバーメモリ最大使用率を設定します。設定範囲は50% ～ 99% で、デフォルトは90% です。|
    |  自動実行  |  プランを自動実行するかどうかを選択します。デフォルトはオフです。 |

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E6%96%B0%E5%BB%BA%E9%A2%84%E6%A1%88.png)

### プランの無効化/有効化

プラン管理により、緊急事態や危機により適切に対応し、損失を軽減してデータベースの安定した運用を保証できます。プランはビジネスシナリオと密接に関連しており、実際の状況に応じて有効または無効にする必要があります。

* POCプロセス中に高可用性テストを実施する場合は、**OBServerプロセス異常終了時の再起動** プランの自動実行を無効にしてください。これにより、テスト結果が想定通りにならないのを防ぎます。
* 同様に、SQL関連のプランの自動実行も無効にすることを推奨します。関連するSQLを確認した上で手動で実行することで、業務運用の異常を防ぎます。

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで **運用管理 > プラン管理** を選択します。

3. **<UI-TERM key="ocp-v2.src.constant.auth.Plan">緊急対応プラン</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.src.constant.auth.Plan">緊急対応プラン</UI-TERM>** リストページに移動します。

4. 操作対象のプランを選択し、操作列の **<UI-TERM key="ocp-v2.Alarm.Template.Disable">禁止</UI-TERM>** または **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Enable">有効にする</UI-TERM>** をクリックします。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E7%A6%81%E7%94%A8%E9%A2%84%E6%A1%88.png)

### プランの実行

自動実行が設定されていないプランについては、該当するイベントが発生した後に手動で実行できます。

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで **運用管理 > プラン管理** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Plan.PlanExecutionList">緊急対応プラン実行リスト</UI-TERM>** タブに移動します。

3. 操作対象のプランを選択し、操作列の **<UI-TERM key="ocp-v2.src.constant.task.Execute">実行</UI-TERM>** をクリックします。

4. ポップアップパネルで **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Confirm">OK</UI-TERM>** をクリックします。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>プランの操作にはご注意ください。その他の問題を引き起こす可能性があります。</p>
</main>

### プランの編集

このセクションを参考にカスタムプランを変更できます。システムの組み込みプランは、現在変更をサポートしていません。

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで **運用管理 > プラン管理** を選択します。

3. **<UI-TERM key="ocp-v2.src.constant.auth.Plan">緊急対応プラン</UI-TERM>** タブをクリックし、**<UI-TERM key="ocp-v2.src.constant.auth.Plan">緊急対応プラン</UI-TERM>** リストページに移動します。

4. 操作対象のプランを選択し、操作列の **<UI-TERM key="ocp-v2.page.Settings.Profile.Edit">編集</UI-TERM>** をクリックします。

5. ポップアップパネルでプラン情報を変更します。

    詳細なパラメータ説明については、**<UI-TERM key="ocp-v2.Plan.Component.CreateDrawer.CreateAPlanTemplate">新たな緊急対応プラン</UI-TERM>** を参照してください。

### プランの削除

カスタムのプランがビジネスシナリオに適用されなくなった場合、このセクションを参照して削除できます。システム組み込みのプランは、現在削除することはできません。

1. OCPプラットフォームにログインします。

2. 左側のナビゲーションバーで、**運用管理 > プラン管理**を選択します。

3. **<UI-TERM key="ocp-v2.src.constant.auth.Plan">緊急対応プラン</UI-TERM>**タブをクリックし、**<UI-TERM key="ocp-v2.page.Plan.PlanTemplate">緊急対応プラン</UI-TERM>**リストページに移動します。

4. 操作対象のプランを選択し、操作列の**<UI-TERM key="ocp-v2.component.ZoneFormCardList.Delete">削除</UI-TERM>**をクリックします。

5. ダイアログボックスで、**<UI-TERM key="ocp-v2.Detail.TakeOver.Confirm">確認</UI-TERM>**をクリックします。
