# セキュリティ設定の管理

<main id="notice" type='notice'>
<h4>適用対象</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionではこの機能は提供されません。</p>
</main>

通信経路のセキュリティを強化するため、OceanBaseデータベース接続ではSSL（Secure Sockets Layer）リンク暗号化を有効にできます。トランスポート層でネットワーク接続を暗号化することで、各ノード間の通信トラフィックが盗聴や改ざんされるのを防ぎ、通信データのセキュリティを向上させます。SSLリンク暗号化は、OceanBase間のRPC通信、OBProxyとOceanBaseの通信、業務アプリケーションとOBProxyの通信に適用されます。SSLリンク暗号化を有効にすると、クライアントはSSL認証または通常認証のいずれかの方法で接続を確立できます。

このページでは、SSLリンク暗号化の操作手順について説明します。

## SSLリンク暗号化の有効化

SSLリンク暗号化を有効にすると、クラスタのパフォーマンスがわずかに低下します（データの送受信時の暗号化および復号化に一定の計算リソースが消費されるため）。外部ネットワークへの接続が必要な場合、または伝送暗号化が求められる場合にのみ、クラスタのSSLリンク暗号化を有効にすることを推奨します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持つことを確認してください。

* OBProxyクラスタがV2.0以降のバージョンであること。

* SSLリンク暗号化機能は、直接接続先のアドレスには適用されません。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックします。デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. **<UI-TERM key="ocp-v2.Detail.Overview.Enable">開始する</UI-TERM>** をクリックし、ダイアログボックスでSSLサーバー証明書名を選択して、**<UI-TERM key="ocp-v2.SecurityCard.SSL.Open">有効にする</UI-TERM>** をクリックします。

   プルダウンリストに必要な証明書がない場合は、[証明書をアップロード](../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) をクリックして追加できます。

## SSLリンク暗号化の無効化

このセクションでは、SSLリンク暗号化を無効にする方法について説明します。SSLリンク暗号化の無効化は数分程度かかりますので、しばらくお待ちください。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持つことを確認してください。

* SSLリンク暗号化が有効になっていること。

* SSL Server証明書が期限切れになっていないこと。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. 右上の **<UI-TERM key="ocp-v2.component.SecurityCard.TurnOffEncryption">暗号化を無効にする</UI-TERM>** をクリックし、ダイアログボックスで **<UI-TERM key="ocp-v2.Component.CgroupEditModal.Close">閉じる</UI-TERM>** をクリックします。

## SSL Server証明書の更新

SSL Server証明書が期限間近または期限切れになった場合、オンラインでSSL Server証明書を更新できます。暗号化証明書を再生成すると、過去に作成されたSSLリンクは引き続き有効となり、新しいリンクは失敗します。関連する変更にご注意ください。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持つことを確認してください。

* SSLリンク暗号化が有効になっていること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. 右上の **SSL Server証書の更新** をクリックし、ダイアログボックスでSSL Server証明書名を選択して **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLLimit.Update">更新</UI-TERM>** をクリックします。

   プルダウンリストに必要な証明書がない場合、[証明書をアップロード](../1600.system-management-features/150.manage-certificates/200.upload-certificates.md) をクリックして追加できます。

## CA証明書のダウンロード

CA証明書を圧縮ファイル形式でローカルにダウンロードして保存することができます。圧縮ファイルには以下の3つのファイルが含まれています：

* `p7b` ファイル：WindowsシステムでCA証明書をインポートするために使用されます。

* `pem` ファイル：その他のシステムやアプリケーションでCA証明書をインポートするために使用されます。

* `jks` ファイル：Javaのtruststore証明書格納ファイルで、パスワードは一律にOceanBaseとなっており、JavaプログラムでCA証明書チェーンをインポートするために使用されます。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持つことを確認してください。

* SSLリンク暗号化が有効になっていることを確認してください。

* SSLサーバー証明書が期限切れになっていないことを確認してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.SecurityConfiguration">セキュリティ設定</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.component.SecurityCard.SslLinkEncryption">SSLリンク暗号化</UI-TERM>** タブが表示されます。

5. **<UI-TERM key="ocp-v2.SecurityCard.SSL.DownloadCaCertificate">CA証明書をダウンロード</UI-TERM>** をクリックします。
