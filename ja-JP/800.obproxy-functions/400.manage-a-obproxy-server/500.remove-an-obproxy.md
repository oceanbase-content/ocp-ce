# OBProxyのオフライン化

このページでは、OBProxyをオフライン化する手順について説明します。OBProxyがオフライン化されると、ノードのロードバランサーにおける重みが0になり、新規接続はそのノードをトラフィックの入口として使用しなくなります。これによりパフォーマンスに影響を与える可能性があるため、慎重に操作してください。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

* 操作対象のOBProxyが引き継ぎ待ちまたは削除状態にないこと。
* 操作対象のOBProxyがオンライン状態であること。
* OBProxyクラスタに少なくとも1つのロードバランシングインスタンスが存在すること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. OBProxyリストで操作対象のOBProxyを選択し、カーソルを **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** に合わせて、ポップアップメニューで **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Offline">オフライン</UI-TERM>** をクリックします。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%B8%8B%E7%BA%BFobproxy.png)

5. ポップアップダイアログで **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Offline">オフライン</UI-TERM>** をクリックします。

6. OBProxyノードがオフライン化された後、カーソルをOBProxyノードの **<UI-TERM key="ocp-v2.src.constant.binlog.Offline">オフライン</UI-TERM>** アイコンに合わせると、吹き出しに関連情報が表示されます。その情報内の **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ViewLoadBalancing">ロードバランシングを表示する</UI-TERM>** をクリックすると、そのOBProxyノードのロードバランシング設定情報を確認できます。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%B7%B2%E4%B8%8B%E7%BA%BFobproxy.png)
