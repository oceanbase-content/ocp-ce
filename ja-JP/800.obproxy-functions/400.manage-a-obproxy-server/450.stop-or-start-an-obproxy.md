# OBProxyの停止・起動

このページでは、OBProxyの停止・起動操作について説明します。OBProxyを停止すると業務が中断するため、ご注意ください。

OBProxyを停止した後、**<UI-TERM key="ocp-v2.src.constant.backup.Start">起動</UI-TERM>** をクリックして、そのOBProxyを再起動できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **OBProxyメンテナンス** リソース権限。
* OBProxy **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. OBProxyリストから停止するOBProxyを選択し、**<UI-TERM key="ocp-v2.Instance.Overview.Operation">操作</UI-TERM>** 列で **詳細 > 停止** を選択します。

   <!-- ![1116](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%81%9C%E6%AD%A2obproxy.png) -->

   複数のOBProxyを選択して、**<UI-TERM key="ocp-v2.src.constant.obproxy.BatchStop">一括停止</UI-TERM>** をクリックすることもできます。

   <!-- ![1114](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E5%81%9C%E6%AD%A2obproxy.png) -->

   OBProxyクラスタ内のすべてのOBProxyを停止する必要がある場合は、[OBProxyクラスタの停止・起動](../300.manage-a-obproxy-cluster/700.restarts-all-obproxy-nodes-in-the-obproxy-cluster.md)を実行してください。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Instance.Overview.Ok">確定</UI-TERM>** をクリックします。

6. タスクが送信された後、ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、停止の進捗状況を確認できます。

   このタスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** であり、かつクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** におけるそのOBProxyの状態が **<UI-TERM key="ocp-v2.src.constant.backup.Stopped">停止済み</UI-TERM>** の場合、タスクは正常に実行されました。

7. OBProxyを起動します。

    OBProxyを停止した後、再度そのOBProxyを有効にしたい場合は、OBProxyリストで **<UI-TERM key="ocp-v2.Detail.Backup.Start">起動</UI-TERM>** をクリックして、そのOBProxyを再度有効にできます。複数のOBProxyを選択して、**<UI-TERM key="ocp-v2.src.constant.obproxy.BatchStart">一括起動</UI-TERM>** を行うこともできます。
