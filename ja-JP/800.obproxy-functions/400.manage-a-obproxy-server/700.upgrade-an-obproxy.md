# OBProxyのアップグレード

このページでは、OBProxyをアップグレードする手順について説明します。アップグレード中は、該当するOBProxyのサービスが停止します。OBProxyのロードバランシングが設定されており、現在のOBProxyクラスタ内の他のOBProxyが引き続きサービスを正常に提供できる場合は、ロード管理を通じて業務リクエストを他の正常なOBProxyに送信することで、業務への影響を避けることができます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

* OBProxyが **<UI-TERM key="ocp-v2.src.constant.tenant.Running">実行中</UI-TERM>** 状態にあること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. OBProxyリストからアップグレード対象のOBProxyを選択し、**<UI-TERM key="ocp-v2.page.Task.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Upgrade">アップグレード</UI-TERM>** をクリックします。

   ![1544](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%8D%87%E7%BA%A7obproxy.png)

   複数のOBProxyを選択して **<UI-TERM key="ocp-v2.src.constant.obproxy.BatchUpgrade">一括アップグレード</UI-TERM>** をクリックすることもできます。

   ![1546](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E5%8D%87%E7%BA%A7obproxy.png)

   OBProxyクラスタ内のすべてのOBProxyをアップグレードする必要がある場合は、[OBProxyクラスタのアップグレード](../300.manage-a-obproxy-cluster/600.upgrade-an-obproxy-cluster.md)を参照してください。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Cluster.Detail.UpgradedVersion">アップグレード版</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Component.AddOBServerDrawer.Ok">確定</UI-TERM>** をクリックします。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>アップグレード先のソフトウェアパッケージのバージョンは、現在のOBProxyバージョンより高く、かつパッケージのハードウェアアーキテクチャは現在のホストのハードウェアアーキテクチャと一致している必要があります。</p>
    </main>

   ![1543](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%87%E7%BA%A7%E5%8D%95%E4%B8%AAobproxy1.png)

6. アップグレードタスクが送信された後、ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、進捗状況を確認できます。

   タスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** であり、かつクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** におけるそのOBProxyの状態が **<UI-TERM key="ocp-v2.Detail.Statistics.utils.Running">実行中</UI-TERM>** の場合、アップグレードは成功です。
