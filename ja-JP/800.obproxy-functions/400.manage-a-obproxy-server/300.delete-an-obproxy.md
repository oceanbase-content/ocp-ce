# OBProxyの削除

このページでは、OBProxyを削除する操作について説明します。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OBProxyクラスタ内にオフライン状態のホストがある場合、システムはそのホストのクリーンアップ操作を実行できません。そのため、OBProxyクラスタを削除する際にはこの手順がスキップされます。お客様は手動でホスト環境をクリーンアップすることを推奨します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

* このOBProxyの削除が業務に影響しないことを確認してください。

  * このOBProxyが存在するクラスタに接続可能なOceanBaseクラスタがない、またはそのOceanBaseクラスタも廃棄されている。

  * 現在のOBProxyのクラスタ内で、削除対象のOBProxy以外の他のOBProxyはすべて正常に使用できること。また、負荷分散管理を設定し、業務リクエストを他の利用可能なOBProxyに転送していること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. OBProxyリストから削除対象のOBProxyを選択し、**<UI-TERM key="ocp-v2.page.Task.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Delete">削除</UI-TERM>** をクリックします。

   ![1634](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%A0%E9%99%A4obproxy.png)

   複数のOBProxyを選択し、**<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.More">もっと見る</UI-TERM>** の **<UI-TERM key="ocp-v2.Component.OBServerList.BatchDelete">一括削除</UI-TERM>** をクリックすることもできます。

   ![1636](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4obproxy.png)

   OBProxyクラスタ内のすべてのOBProxyを削除する必要がある場合は、[OBProxyクラスタの削除](../300.manage-a-obproxy-cluster/500.delete-an-obproxy-cluster.md)を参照してください。

5. ポップアップダイアログに **delete** と入力し、**<UI-TERM key="ocp-v2.Detail.LoadBalance.Delete">削除</UI-TERM>** をクリックします。

6. タスクが送信された後、ポップアップボックス内の **<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、削除の進捗状況を確認できます。

   このタスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** からそのOBProxyがなくなった場合、削除は成功です。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p><ul><li>削除するOBProxyがOBProxyクラスタの最後のOBProxyである場合、削除後はアプリケーションが対応するデータベースに接続できなくなります。慎重に操作してください。</li><li>OBProxyを削除すると、そのOBProxyはロードバランシングポリシーの設定から除外され、所属するアプリケーションに影響を与えます。</li></p>
   </main>
