# OBProxy設定のリフレッシュ

このページでは、OBProxy設定をリフレッシュする手順について説明します。OBProxy設定のリフレッシュ操作は、個々のOBProxyのパラメータ設定を現在のOBProxyクラスタのパラメータ設定と一致させます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* OBProxyクラスタの概要ページのOBProxyリストで、**<UI-TERM key="ocp-v2.Backup.Service.Detail.State">ステータス</UI-TERM>** 列が **<UI-TERM key="ocp-v2.src.constant.compute.Running">実行中</UI-TERM>** であり、かつ **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ParameterVersion">パラメータバージョン</UI-TERM>** 列に **！** が表示されている場合、そのOBProxyのパラメータバージョンが現在のOBProxyクラスタのパラメータバージョンと一致しないことを意味し、そのOBProxyの設定をリフレッシュする必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. OBProxyリストから操作対象のOBProxyを選択し、**<UI-TERM key="ocp-v2.Instance.Overview.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.src.constant.obproxy.RefreshConfigurations">構成の更新</UI-TERM>** をクリックします。

   <!-- ![1623](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%B7%E6%96%B0%E9%85%8D%E7%BD%AE.png) -->

   複数のOBProxyの設定をリフレッシュする必要がある場合は、複数のOBProxyを選択して **<UI-TERM key="ocp-v2.src.constant.obproxy.BatchRefresh">一括更新</UI-TERM>** をクリックすることもできます。

   <!-- ![11241629](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E5%88%B7%E6%96%B0%E9%85%8D%E7%BD%AE.png) -->

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Ok">確定</UI-TERM>** を選択します。

6. タスクが送信された後、ポップアップウィンドウ内の **<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、進捗状況を確認できます。

   そのタスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** であり、かつクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** 内の **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ParameterVersion">パラメータバージョン</UI-TERM>** 列に **！** のアイコンが表示されていない場合、リフレッシュは成功です。
