# OBProxyの追加

このページでは、OBProxyを追加する操作について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

* OBProxyクラスタがV4.0以上の場合は、V4.0.0以上のOBProxyソフトウェアパッケージのみを選択できます。OBProxyクラスタがV3.x以下の場合は、V1.8.0以上、V4.0.0未満のOBProxyソフトウェアパッケージのみを選択できます。
* クラスタ内に既に存在するバージョンのOBProxyソフトウェアパッケージのみを追加できます。ソフトウェアパッケージのアーキテクチャは、現在のOBProxyクラスタノードのハードウェアアーキテクチャと一致させることを推奨します。
* V4.3.0以上のOBProxyでのみRPCポートの設定がサポートされています。

## 手順

OBProxyを追加するには、以下の2つの方法があります：

* **方法1**：OBProxyの **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** から、OBProxyの追加先クラスタを見つけ、対応する操作列の **<UI-TERM key="ocp-v2.OBProxy.New.DeployMode.AddObproxy">OBProxyを追加</UI-TERM>** をクリックします。
* **方法2**：**<UI-TERM key="ocp-v2.page.OBProxy.ClusterList">クラスタ一覧</UI-TERM>** で、OBProxyの追加先クラスタ名をクリックし、そのOBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。**<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページの右上にある **<UI-TERM key="ocp-v2.Detail.Overview.AddObproxy">OBProxyを追加する</UI-TERM>** をクリックします。

以下の手順では、**方法2** を例に説明します：

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Detail.Component.AddOBProxyDrawer.AddObproxy">OBProxyを追加する</UI-TERM>** をクリックします。

   <!-- ![09162140](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E6%B7%BB%E5%8A%A0obproxy.png) -->

5. ポップアップウィンドウでOBProxyソフトウェアパッケージを選択し、**<UI-TERM key="ocp-v2.Cluster.New.SqlPort">SQLポート</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ExporterPort">Exporter ポート</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.RpcPort">RPCポート</UI-TERM>**、**<UI-TERM key="ocp-v2.OBProxy.New.DeployMode.ComputerRoom">データセンター</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.TakeOver.Models">機種</UI-TERM>**、**<UI-TERM key="ocp-v2.Task.TaskObjectAndType.Host">ホスト</UI-TERM>**などの情報を設定します。詳細については、[OBProxyクラスタの作成](../../500.quickstart/800.quickstart-create-an-obproxy-cluster.md)を参照してください。

   <!-- ![1122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/432/%E6%B7%BB%E5%8A%A0obproxy.png) -->

   <main id="explain" type='explain'>
   <h4>説明</h4>
   <p>OBProxyクラスタ内にOBProxyが作成または引き継がれていない場合、OBProxyを追加する際にSQLポート、Exporterポート、RPCポートをカスタマイズできます。OBProxyクラスタ内に既にOBProxyが存在する場合、SQLポート、Exporterポート、RPCポートは、<a href="../../500.quickstart/800.quickstart-create-an-obproxy-cluster.md">OBProxyクラスタの作成</a>でOBProxyをデプロイする際に設定されたポート番号をデフォルトで継承し、カスタマイズはサポートされません。</p>
   </main>

6. **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.Determine">確定</UI-TERM>** をクリックします。
