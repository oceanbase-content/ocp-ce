# OBProxyのオンライン化

このページでは、OBProxyをオンラインにする手順について説明します。OBProxyがオンラインになると、ノードのロードバランシング重み設定が復元され、新規接続はロードバランシングルールに従ってそのノードをトラフィックの入口として使用し、業務リクエストをそのOBProxyに送信することで、システムの業務負荷を軽減します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* 操作対象のOBProxyが引き継ぎ待ちまたは削除状態にないこと。
* 操作対象のOBProxyがオフライン状態であること。
* OBProxyクラスタに少なくとも1つのロードバランシングインスタンスが存在すること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. OBProxyリストから操作対象のOBProxyを選択し、カーソルを **···** に合わせて、ポップアップメニューバーで **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Online">オンライン</UI-TERM>** をクリックします。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%B8%8A%E7%BA%BFobproxy.png)

5. ポップアップダイアログで **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Online">オンライン</UI-TERM>** をクリックします。
