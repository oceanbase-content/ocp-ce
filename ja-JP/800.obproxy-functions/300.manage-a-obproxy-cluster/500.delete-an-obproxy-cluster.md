# OBProxyクラスタの削除

このページでは、OBProxyクラスタを削除する操作について説明します。OBProxyクラスタを削除すると、クラスタ内のすべてのOBProxyサービスが各ホストからアンインストールされ、ホスト上でOBProxyサービスが占有していたリソースが解放されます。同時に、OBProxyクラスタおよび関連するOBLB設定も削除されます。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>OBProxyクラスタのホストがオフライン状態の場合、システムはそのホストのクリーンアップ操作を実行できません。OBProxyクラスタを削除する際にはこの手順がスキップされるため、手動でホスト環境をクリーンアップすることを推奨します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxy管理** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* 現在のOBProxyクラスタが業務でのリバースプロキシサービスを提供していないことを確認してください。

  そのOBProxyの **接続可能なOceanBaseクラスタ** リストが空であるか、またはリスト内のOceanBaseクラスタも既に廃止されていること。

* 削除対象のOBProxyクラスタが **停止**、**使用不可**、または **空クラスタ** の状態にあること。

## 手順

OBProxyクラスタを削除するには、以下の2つの方法があります：

* **方法1**：**OBProxy** ページに移動し、操作対象のOBProxyクラスタをクラスタリストから選択して、**その他 > 削除** をクリックします。
* **方法2**：OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動し、**...** にカーソルを合わせて、**<UI-TERM key="ocp-v2.Cluster.Detail.DeleteACluster">クラスタを削除</UI-TERM>** をクリックします。

以下の手順は **方法2** を例に説明します：

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. **...** にカーソルを合わせて、**<UI-TERM key="ocp-v2.Cluster.Detail.DeleteACluster">クラスタを削除</UI-TERM>** をクリックします。

   ![09162145](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%A0%E9%99%A4%E9%9B%86%E7%BE%A4.png)

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Auth.Role.Delete">削除</UI-TERM>** をクリックし、OBProxyクラスタの削除操作を完了します。

6. 削除タスクが送信された後、ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、進捗状況を確認できます。

   そのタスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつ **OBProxy** ページの **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** にそのOBProxyクラスタが表示されなくなったら、削除は成功です。
