# 接続済みのOceanBaseクラスタを削除する

このページでは、接続済みのOceanBaseクラスタを削除する操作手順について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **OBProxyメンテナンス** リソース権限。
* OBProxy **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. **接続可能なOceanBaseクラスタ** エリアで、該当するクラスタの後ろにある **<UI-TERM key="ocp-v2.Detail.Component.DeleteUnitModal.Delete">削除</UI-TERM>** をクリックします。

   <!-- ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6620460261/p271769.png) -->

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Statistics.components.EditAutoBasicInfoDrawer.Ok">確定</UI-TERM>** をクリックします。
