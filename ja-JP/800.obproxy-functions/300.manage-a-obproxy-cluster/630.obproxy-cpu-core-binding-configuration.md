# CPUバインディングの管理

CPUバインディングとは、特定のプロセスやスレッドを特定のCPUコアに固定する技術です。重要なタスクを固定のCPUコアにバインドすることで、タスクが異なるコア間で頻繁に切り替わるのを防ぎ、コンテキストスイッチングのオーバヘッドを削減してシステム全体のパフォーマンスを向上させます。

ただし、CPUバインディングを過度に使用すると、一部のコアが過負荷になり他のコアがアイドル状態になる可能性があり、システムのリソース利用率に影響を与えるおそれがあります。実際の運用では、状況に応じて慎重にCPUバインディングの有無を判断し、最適なパフォーマンスとリソース利用効率を得るために、バインディング戦略を適切に調整する必要があります。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **OBProxyメンテナンス** リソース権限。
* OBProxy **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## CPUバインディング範囲の設定

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、クラスタ名をクリックします。

4. クラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動し、右上の **...** アイコンをクリックして、**<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.CpuCoreBindingConfiguration">CPUのコア固定設定</UI-TERM>** を選択します。

5. **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.ConfigureCpuBindingRange">CPUバインディング範囲の設定</UI-TERM>** をクリックします。

6. ポップアップウィンドウで、現在のOBProxyクラスタ下のすべてのOBProxy ServerプロセスのCPUバインディング設定を行います。設定完了後、**<UI-TERM key="ocp-v2.MultiCluster.Detail.FailoverModal.Determine">確定</UI-TERM>** をクリックします。

7. ダイアログボックスでタスクIDをクリックするとタスクの進捗状況を確認できます。タスクの状態が **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** で、かつOBProxyクラスタの状態が **<UI-TERM key="ocp-v2.src.constant.backup.NormalOperation">正常に稼働</UI-TERM>** の場合、OBProxyクラスタのCPUバインディング設定は成功したことを意味します。

## CPUバインディング設定の無効化/有効化

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックし、クラスタリストから操作対象のOBProxyクラスタを選択して、クラスタ名をクリックします。

3. クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動し、右上の **...** アイコンをクリックして、**<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.CpuCoreBindingConfiguration">CPUのコア固定設定</UI-TERM>** を選択します。

4. 操作対象のCPUバインディング設定を選択し、有効化スイッチをクリックします。

5. ポップアップダイアログで **<UI-TERM key="ocp-v2.Component.ZoneList.EditZoneModal.Ok">確定</UI-TERM>** をクリックします。
