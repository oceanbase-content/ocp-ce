# proxyroアカウントのパスワードを変更する

このページでは、proxyroアカウントのパスワードを変更する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** メニュー権限。

* proxyroアカウントのパスワード変更は、V4.0.0未満のOBProxyクラスタでのみサポートされます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. **proxyroアカウントのパスワードを変更する** をクリックします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%BF%AE%E6%94%B9proxyro%E8%B4%A6%E5%8F%B7%E7%9A%84%E5%AF%86%E7%A0%81.png) -->

5. ポップアップウィンドウにproxyroアカウントの新しいパスワードを入力します。

6. **<UI-TERM key="ocp-v2.Detail.Component.FailoverDrawer.Determine">確定</UI-TERM>** をクリックします。

    <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E4%BF%AE%E6%94%B9%E5%AF%86%E7%A0%811.png) -->

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>OBProxyはクライアントのデータリクエストを対応するOBServerノードに転送するために使用されます。proxyroアカウントのパスワードを変更すると、関連するすべてのOBProxyクラスタとOceanBaseクラスタに同期されますので、慎重に操作してください。</li>
    <li>関連するOceanBaseクラスタまたはOBProxyクラスタが <strong>メンテナンス中</strong> の状態にある場合、proxyroのパスワードを変更できません。</li>
    </ul>
   </main>

7. ポップアップウィンドウのタスクIDをクリックすると、proxyroアカウントのパスワードを変更するタスクの詳細を確認できます。
