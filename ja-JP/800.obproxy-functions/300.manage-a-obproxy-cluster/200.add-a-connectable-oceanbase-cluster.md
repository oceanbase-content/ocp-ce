# 接続可能なOceanBaseクラスタの追加

このページでは、接続可能なOceanBaseクラスタを追加する手順について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* OBProxyクラスタがV3.x以下のバージョンの場合は、V4.0未満のバージョンのOceanBaseクラスタのみを選択できます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. **接続可能なOceanBaseクラスタの追加** をクリックします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%AF%E8%BF%9E%E6%8E%A5ob%E9%9B%86%E7%BE%A41.png) -->

5. ポップアップウィンドウで接続可能なOceanBaseクラスタを選択します。

   OceanBaseクラスタのproxyroパスワードがOBProxyクラスタのproxyroパスワードと一致している場合にのみ、proxyroは対応するOceanBaseクラスタにアクセスできます。OceanBaseクラスタがproxyroアカウントのパスワードで接続できない場合は、以下の2つの方法で解決できます：

   * OBProxyクラスタのproxyroパスワードを変更します。詳細については、[proxyroアカウントのパスワードの変更](../300.manage-a-obproxy-cluster/400.change-the-password-of-the-proxyro-user.md)を参照してください。
   * OceanBaseクラスタのproxyroユーザーパスワードを変更します。このパスワードはクラスタのsysテナントに保存されています。[テナントユーザー管理](../../700.tenant-functions/1200.manage-users-and-permissions-under-tenants/100.user-management-under-a-mysql-tenant.md)の操作手順を参照して変更してください。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%B7%BB%E5%8A%A0%E5%8F%AF%E8%BF%9E%E6%8E%A5ob%E9%9B%86%E7%BE%A41.png) -->

6. **<UI-TERM key="ocp-v2.Binlog.Component.StopBinlogModal.Ok">確定</UI-TERM>** をクリックして、追加を完了します。
