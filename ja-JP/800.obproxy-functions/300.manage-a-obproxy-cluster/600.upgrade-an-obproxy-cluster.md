# OBProxyクラスタのアップグレード

このページでは、OBProxyクラスタ内のすべてのOBProxyをアップグレードする操作について説明します。アップグレード対象のOBProxyクラスタに複数の異なるアーキテクチャが含まれる場合でも、OCPはすべてを一括でアップグレードする機能を提供します。

クラスタのアップグレードは、OBProxyクラスタ内のすべてのOBProxyを同時にアップグレードするため、そのOBProxyクラスタは外部サービスを停止します。現在のOBProxyクラスタが既に業務を担っている場合は、現在設定されているロードバランシングに基づき、[OBProxyのアップグレード](../400.manage-a-obproxy-server/700.upgrade-an-obproxy.md)の方法で、クラスタ内のOBProxyを複数回に分けてアップグレードすることを推奨します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **OBProxyメンテナンス** リソース権限。
* OBProxy **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Detail.Overview.UpgradeAll">すべてをアップグレード</UI-TERM>** をクリックします。

   <!-- ![09162144](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%8D%87%E7%BA%A7obproxy%E9%9B%86%E7%BE%A4.png) -->

5. ポップアップウィンドウでアップグレードバージョンを選択します。

   <!-- ![08161435](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8D%87%E7%BA%A7obproxy1.png) -->

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <ul>
    <li><strong>最高バージョン</strong> より高いソフトウェアパッケージのバージョンのみを選択できます。</li>
    <li>複数のCPUアーキテクチャを持つOBProxyクラスタをアップグレードする際、特定の <strong>CPU アーキテクチャ</strong> で選択したインストールパッケージのバージョンが欠けている場合、アップグレードできません。</li>
    </ul>
    </main>

6. **<UI-TERM key="ocp-v2.MultiCluster.Detail.Determine">確定</UI-TERM>** をクリックします。

   ポップアップウィンドウの **<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、アップグレードの進捗状況を確認できます。

   タスクの状態が **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.Complete">完成しました</UI-TERM>** になり、かつクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.ObproxyList">OBProxyリスト</UI-TERM>** にある各OBProxyの状態が **<UI-TERM key="ocp-v2.src.constant.tenant.Running">実行中</UI-TERM>** になったら、アップグレードは成功です。
