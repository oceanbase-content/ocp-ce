# proxysysのパスワードを変更する

このページでは、OBProxyクラスタのroot@proxysysのパスワードを変更する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **OBProxyメンテナンス** リソース権限。
* OBProxy **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. **proxysysのパスワードを変更する** をクリックします。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%BF%AE%E6%94%B9proxysys%E5%AF%86%E7%A0%81.png)

5. ポップアップウィンドウで新しいroot@proxysysアカウントのパスワードを入力し、**<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.Ok">確定</UI-TERM>** をクリックします。

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E7%A1%AE%E8%AE%A4proxysys%E5%AF%86%E7%A0%81.png)

6. ポップアップウィンドウのタスクIDをクリックすると、root@proxysysアカウントのパスワードを変更したタスクの詳細を確認できます。
