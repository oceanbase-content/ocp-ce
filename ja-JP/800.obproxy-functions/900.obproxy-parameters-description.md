# OBProxyパラメータの説明

このページでは、OBProxyのパラメータについて説明します。OBProxyクラスタを作成する際に、**<UI-TERM key="ocp-v2.Component.AddZoneDrawer.ParameterSettings">パラメータ設定</UI-TERM>**で起動パラメータを設定できます。

## 起動パラメータ

OBProxyクラスタを作成する際、以下の説明を参考に起動パラメータを設定してください。設定しない場合、システムはデフォルト値でOBProxyを作成します。

| パラメータ名 | デフォルト値 | 値の範囲 | 説明 |
|-------|--------|--------|-------|
| app_name | dropship |-| Proxyのアプリケーションサービス名。|
| automatic_match_work_thread  | true| <li>true</li><li> false</li> | CPUコア数に応じて自動的にワーカースレッドを作成するかどうか。このオプションがtrueの場合、上限はwork_thread_numです。 |
| block_thread_num| 1 | [1, 4]| OBProxyのブロッキングタスクのスレッド数。スレッドの初期化に使用されます。 |
| enable_cpu_topology| false| <li>true   </li><li> false</li>  | CPUアフィニティを有効にするかどうか。つまり、各ワーカースレッドを異なるCPUにバインドするかどうか。|
| enable_metadb_used| false | <li>true   </li><li> false</li>  | OBProxyの実行時にOCPのMetaDBにアクセスできるかどうか。|
| enable_strict_kernel_release | false  | <li>true   </li><li> false</li> | OSカーネルの検証が必要かどうか。 値の範囲： <li> true：5u/6u/7u仕様のRedHat OSのみ検証をサポートします。  </li><li> false：OSカーネルを検証しませんが、Proxyが不安定になる可能性があります。</li> |
| frequent_accept| true | <li>true   </li><li> false</li> | net acceptパラメータを初期化するかどうか。 |
| grpc_client_num  | 9   | [9,16] | grpcクライアント数。|
| grpc_thread_num | 8 | [8,16] | grpcスレッド数。|
| listen_port | 2883 | (1024, 65536) | OBProxyのリスニングポート。 |
| local_bound_ip | xxx.xxx.xxx.xxx          | -| OBProxyのローカルIP。 |
| net_accept_threads | 2 | [0, 8] | acceptを実行するスレッド数。 |
| prometheus_cost_ms_unit | false            | <li>true   </li><li> false</li> | prometheusのコストの単位としてミリ秒を使用するかどうか。デフォルトはマイクロ秒です。 |
| prometheus_listen_port  | 2884             | (1024, 65536) | OBProxy prometheusリスニングポート。 |
| proxy_id  | 0  | [0,255]| OBProxyのID。各OBProxyを識別するために使用されます。proxy_service_modeがserverに設定されている場合、proxy_idを0に設定することはできません。|
| proxy_service_mode | client | <li> client </li><li>   server</li>    | OBProxyのデプロイメントおよびサービスモード。|
| skip_proxy_sys_private_check | true | <li> true  </li><li> false  </li>     | OBProxyのプライベートサブネット検査をスキップするかどうか。 |
| stack_size | 1 MB              | [1 MB, 10 MB]  | スレッドのスタックサイズ。スレッドの作成に使用されます。 |
| task_thread_num | 2 | [1, 4] | OBProxyタスクスレッド数。|
| work_thread_num  | 128 | [1, 128]| OBProxyワーカースレッド数。 automatic_match_work_threadがtrueの場合、最大ワーカースレッド数を表します。|
