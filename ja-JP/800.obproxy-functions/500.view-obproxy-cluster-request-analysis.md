# OBProxyクラスタのリクエスト分析を表示する

OBProxyクラスタのリクエスト分析は、クライアントからOBProxyクラスタへのリクエストデータを提供します。

**<UI-TERM key="ocp-v2.alarm.FormListWithExclude.OBServerWithExclude.All">すべて</UI-TERM>**または**<UI-TERM key="ocp-v2.Detail.Analyze.Failed">失敗</UI-TERM>**の統計軸で、**<UI-TERM key="ocp-v2.src.constant.log.NearFenZhong.2">直近30分間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.NearlyHour">直近1時間</UI-TERM>**、**過去3時間**、**過去6時間**、**本日**、またはカスタム時間内のリクエストデータを確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **OBProxyメンテナンス** リソース権限。
* OBProxy **<UI-TERM key="ocp-v2.src.hook.useMenu.RequestAnalysis">リクエスト分析</UI-TERM>** メニュー権限。

## リクエスト数のトレンド

リクエスト数のトレンドモジュールでは、**OceanBaseクラスタリクエスト数** のトレンドグラフと **OceanBaseテナントリクエスト数** のトレンドグラフを確認できます。

* OceanBaseクラスタリクエスト数：クラスタ単位で集計され、クライアントからOBProxyクラスタへのリクエスト数が表示されます。
* OceanBaseテナントリクエスト数：テナント単位で集計され、クライアントからOBProxyクラスタへのリクエスト数が表示されます。

以下の機能を利用すると、トレンドグラフ上で詳細なリクエスト分析データをより効果的に確認および分析できます。トレンドグラフとあわせて以下の説明を参照してください。

* データのフィルタリング：
  * 特定の指標の特定期間の詳細なトレンドを見る：マウスでその範囲をドラッグして選択すると、システムはその範囲のトレンド情報を拡大表示します。このトレンドグラフをダブルクリックすると元に戻ります。
  * 他のサブ指標のデータを非表示にする：他のサブ指標のアイコンをクリックして灰色にすると、その指標情報はトレンドグラフに表示されません。
  * 特定の時刻の詳細データを見る：トレンドグラフ上の特定の時刻にマウスカーソルを合わせます。
* 特定のトレンドグラフを拡大する：トレンドグラフの右上隅にある拡大アイコンをクリックします。上記のa、b、cの機能は拡大したトレンドグラフでも同様に適用されます。
* すべてのクラスタまたはテナントのリクエスト数を見る：トレンドグラフ上で、トレンドグラフの右上隅にある ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%9B%BE%E6%A0%871.png) アイコンをクリックすると、すべてのクラスタまたはテナントのリクエスト数を確認できます。

## OBProxyリクエスト数

リクエスト数のトレンドモジュールでは、**<UI-TERM key="ocp-v2.Detail.Analyze.ObproxyRequests">OBProxy リクエスト回数</UI-TERM>** リストを確認できます。
