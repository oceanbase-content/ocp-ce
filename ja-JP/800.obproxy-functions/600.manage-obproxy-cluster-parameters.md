# OBProxyクラスタパラメータの管理

**<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">パラメータ管理</UI-TERM>** ページで、OBProxyクラスタの **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ParameterList">パラメータリスト</UI-TERM>** と **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ModifyHistory">変更履歴</UI-TERM>** を確認できます。

## 前提条件

* OBProxyクラスタのパラメータ情報およびパラメータ変更履歴を確認する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxy読み取り専用** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

* OBProxyクラスタのパラメータを変更する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

## パラメータの確認・変更

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">パラメータ管理</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterList">パラメータリスト</UI-TERM>** タブが表示されます。

   <!-- ![1122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/obproxy%E5%8F%82%E6%95%B0%E7%AE%A1%E7%90%86.png) -->

   このページでは、以下の操作が可能です：
   * パラメータの確認：検索ボックスにパラメータ名を入力し、検索ボタンをクリックして指定したパラメータを確認できます。あいまい検索もサポートしています。

   * パラメータの変更：

     1. 指定したパラメータの **<UI-TERM key="ocp-v2.Component.BinlogService.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.component.OperationConfig.List.ModifyValue">値の修正</UI-TERM>** ボタンをクリックします。

     2. **<UI-TERM key="ocp-v2.Component.SQLCondition.Value">値</UI-TERM>** を入力し、**<UI-TERM key="ocp-v2.Detail.Component.Event.Determine">確定</UI-TERM>** をクリックします。

     3. 対象となるすべてのパラメータの値の変更が完了したら、**<UI-TERM key="ocp-v2.Detail.Parameter.SubmitModification">修正を送信する</UI-TERM>** をクリックします。

        <!-- ![11221625](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E4%BF%AE%E6%94%B9%E5%8F%82%E6%95%B0.png) -->

     4. ポップアップパネルで変更情報を確認し、**<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.ConfirmModification">修正を確認する</UI-TERM>** をクリックします。変更タスクの実行が完了すると、変更は成功です。

     5. パラメータの変更が完了した後、パラメータの **<UI-TERM key="ocp-v2.Detail.Parameter.List.WhetherTheRestartTakesEffect">再起動して有効にする</UI-TERM>** 情報を確認し、パラメータが有効になる方法を判断する必要があります：

        * 再起動が不要なパラメータ：パラメータの変更が成功すると約3分で反映されます。
        * 再起動が必要なパラメータ：OBProxyを再起動してから有効になります。

      <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><b>読み取り専用</b> パラメータは、パラメータ値の変更をサポートしていません。</p>
      </main>

## パラメータ変更履歴の表示

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>** をクリックすると、デフォルトで **<UI-TERM key="ocp-v2.page.MultiAzone.ParameterList">パラメータリスト</UI-TERM>** タブが表示されます。

5. **<UI-TERM key="ocp-v2.Detail.Parameter.ModifyHistory">変更履歴</UI-TERM>** タブを選択します。

   **<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">更新日</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">パラメータ名称</UI-TERM>** の情報を入力し、**<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Query">クエリ</UI-TERM>** をクリックしてパラメータをフィルタリングし、該当するパラメータの情報を確認します。パラメータリストでは、**<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterDrawer.Parameter">パラメータ名</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Parameter.History.ValueBeforeChange">値－変更前</UI-TERM>**（変更前のパラメータ値）、**<UI-TERM key="ocp-v2.Detail.Parameter.History.ValueAfterChange">値－変更後</UI-TERM>**（変更後のパラメータ値）、**<UI-TERM key="ocp-v2.Detail.Overview.ModificationTime">更新日時</UI-TERM>**、および **<UI-TERM key="ocp-v2.Detail.Parameter.History.OperationUser">ユーザー操作</UI-TERM>** を確認できます。
