# OCP-Agentによる時系列モニタリングデータの取得方法

OCP-Agentは、収集したモニタリングデータを取得する機能を提供しています。

## OCP-Agentの監視

OCP-Agentはホスト上にデプロイされる管理・監視プロセスであり、3つの常駐プロセスと1つのCLIツールで構成されています。

* ocp_mgragentは管理プロセスで、OceanBaseおよびOBProxyの運用管理コマンドを実行します。

* ocp_monagentは監視プロセスで、OceanBase、OBProxy、およびホストのモニタリングデータを収集します。

* ocp_agentdは、管理プロセスと監視プロセスのデーモンです。

* ocp_agentctlはCLIベースの運用管理ツールです。

OCP-Agentは、Prometheus形式の時系列モニタリングデータを2種類生成します。

1. ビジネスモニタリングデータ：ホストモニタリング、OceanBaseクラスタモニタリング、テナントモニタリングなど。

2. OCP-Agentプロセス自己モニタリングデータ：OCP-Agent自身の稼働状態を監視するためのデータで、リソース使用状況や内部コンポーネントの稼働状態などが含まれます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>時系列データ以外に、OCP-AgentはOceanBaseのSQL監査データも収集できます。これらのデータはSQL診断分析やアラートに利用でき、ログデータは障害原因の特定に役立ちます。非時系列データは本説明の対象外です。</p>
  </main>

## 時系列モニタリングデータの取得方法

OCP V3.2.0以降、OCP-Agentの監視インターフェースに認証が追加されました。認証パスワードはランダム値であり、外部から認証パスワードを照会するインターフェースは提供されていません。OCP V3.3.2では、監視インターフェースの認証を無効にする機能が提供されています。認証を無効にすると、pullモードでモニタリングデータを取得できます。

監視インターフェースのスイッチ：`ocp.agent.auth.metric-auth-enabled`、デフォルト値はtrue（認証有効）です。OCP **<UI-TERM key="ocp-v2.page.Property.SystemParameters">システムパラメータ</UI-TERM>**でこのパラメータの値をfalseに変更すると、pullモードでモニタリングデータを取得できます。

監視インターフェースは以下のとおりです：

|      exporter       | 推奨収集間隔  | 対象内容  |
|-----------------|----------|--------|
| `http://<ip>:62889/metrics/node/host`     | 1 ～ 15秒 | ホストモニタリング。node_exporterから収集されます。  |
| `http://<ip>:62889/metrics/node/ob` | 1 ～ 15秒 | OceanBaseデプロイ後のホストレベルモニタリング。OceanBase可用性モニタリングやOceanBaseプロセス状態モニタリングなどが含まれます。 |
| `http://<ip>:62889/metrics/ob/basic`     | 1 ～ 15秒 | OceanBaseシステムテーブルのデータを収集します。  |
| `http://<ip>:62889/metrics/node/obproxy` | 1 ～ 15秒 | OBProxyデプロイ後のホストレベルモニタリング。OBProxyプロセス状態モニタリングなどが含まれます。 |
| `http://<ip>:62889/metrics/obproxy`     | 1 ～ 15秒 | OBProxyのモニタリング。`http://localhost:2884/metrics`から収集されます。 |
| `http://<ip>:62889/metrics/ob/extra` | 1分 | OceanBaseシステムテーブルのデータを収集します。 |
| `http://<ip>:62888/metrics/stat`    | 1分 | 管理agent（ocp_mgragent）プロセスの自己モニタリング。主にプロセスが使用するリソースの監視です。  |
| `http://<ip>:62889/metrics/stat` | 1分 | 監視agent（ocp_monagent）プロセスの自己モニタリング。主にプロセスが使用するリソースの監視と、モニタリングデータ収集パイプラインの監視です。 |
