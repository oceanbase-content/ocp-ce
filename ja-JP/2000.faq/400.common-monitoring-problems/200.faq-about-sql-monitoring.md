# SQLモニタリングに関するよくある質問
このセクションでは、グローバルSQLモニタリングに関する一般的な質問について説明します。

## SQLパフォーマンス

**Q1: システムパラメータocp.perf.sql.sql-hist-level0-retentionの値を1週間などに引き上げたい場合、ストレージ容量の増加以外に、クリーンアップにかかる時間など、考慮すべき点はありますか？**
A: いいえ。主に考慮すべき点はディスク負荷です。

**Q2: OCPにおけるQPS/TPSはどのように計算されますか？**

A: システムビュー`v$sysstat`で照会します。詳細な収集および計算方法については、[QPS](../../1900.reference-guide/300.monitoring-indicator-reference/400.oceanbase-database-tenant/100.performance-and-sql/100.qps-1.md)および[TPS](../../1900.reference-guide/300.monitoring-indicator-reference/400.oceanbase-database-tenant/200.transaction/100.tps-1.md)を参照してください。
