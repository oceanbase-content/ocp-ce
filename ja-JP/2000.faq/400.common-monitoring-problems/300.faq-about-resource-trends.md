# リソーストレンドに関するよくある質問
このセクションでは、グローバルなリソーストレンドに関するよくある質問について説明します。

## リソーストレンド

**Q1: OceanBaseクラスタのディスク容量と使用量を確認するにはどうすればよいですか？**
A: __all_virtual_disk_stat テーブルの total_size フィールド値の合計がそのクラスタのディスク総容量、used_size フィールド値の合計がそのクラスタのディスク使用量です。以下の方法で total_size と used_size の値を照会できます。

* V4.0.0 より前のバージョン：

    ```shell
    #root@sysユーザーを使用して、このOceanBaseクラスタのoceanbaseデータベースに接続します。
    obclient -hxxx.xxx.xxx.xxx -P2881 -u<username> -p_******_ -Doceanbase -A
    #OceanBaseクラスタ内の各OBServerのディスク容量（total_size）と使用量（used_size）を照会します。
    select total_size,used_size,svr_ip from __all_virtual_disk_stat;
    ```

* V4.0.0 以降のバージョン：

    ```shell
    #root@sysユーザーを使用して、このOceanBaseクラスタのoceanbaseデータベースに接続します。
    obclient -hxxx.xxx.xxx.xxx -P2881 -u<username> -p_******_ -Doceanbase -A
    #OceanBaseクラスタ内の各OBServerのディスク容量（total_size）と使用量（used_size）を照会します。
    select data_disk_capacity as disk_total, LOG_DISK_IN_USE+DATA_DISK_IN_USE as used_size, svr_ip from GV$OB_SERVERS;
    ```
