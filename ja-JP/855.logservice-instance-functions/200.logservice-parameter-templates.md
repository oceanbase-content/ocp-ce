# パラメータテンプレート

パラメータテンプレートは、Logserviceクラスタのパラメータ設定を管理および一括適用するために使用されます。パラメータテンプレートを作成し、一連のパラメータ値を定義しておくことで、新規クラスタ作成時にそのテンプレートの適用を選択できます。

<main id="notice" type='notice'>
<h4>説明</h4>
<p>パラメータテンプレートは、<b>新規クラスタ</b>作成時にのみ適用を選択できます。クラスタ作成後は、パラメータテンプレートを通じてパラメータを変更することはできません。<b>パラメータ管理</b>機能を使用して個別にクラスタパラメータを変更する必要があります。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Logservice管理**リソース権限。
* Logservice **パラメータテンプレート**メニュー権限。

## パラメータテンプレート一覧の表示

1. OCPにログインします。

2. 左側のナビゲーションバーで、**Logserviceインスタンス**を選択します。

3. **パラメータテンプレート**タブをクリックし、パラメータテンプレート一覧ページに移動します。

   パラメータテンプレート一覧では、以下の情報を確認できます：

   | 情報項目 | 説明 |
   |-------|------|
   | テンプレート名 | パラメータテンプレートの名前 |
   | パラメータ数 | テンプレート内に含まれるパラメータの数 |
   | 備考 | テンプレートの説明情報 |
   | 作成者 | テンプレートを作成したユーザー |
   | 最終変更日時 | テンプレートを最後に変更した日時 |
   | 最終変更者 | テンプレートを最後に変更したユーザー |

## パラメータテンプレートの作成

1. パラメータテンプレート一覧ページで、**新規テンプレート**をクリックします。

2. 新規テンプレートダイアログボックスで、以下の情報を入力します：

   | 情報項目 | 説明 |
   |-------|------|
   | テンプレート名 | テンプレートの名前を入力します。 |
   | 備考（オプション） | テンプレートの説明情報を入力します。 |

3. **<UI-TERM key="ocp-v2.TrendAndOutline.SQLHistory.Ok">確定</UI-TERM>** をクリックし、テンプレートの詳細ページに移動します。

4. テンプレートの詳細ページで、管理するパラメータとその値を追加します。

   | 情報項目 | 説明 |
   |-------|------|
   | パラメータ名 | 設定するパラメータを選択します。 |
   | パラメータ値 | そのパラメータの値を入力します。 |
   | 値の種類 | パラメータの値の種類を表示します。 |
   | 値の範囲 | パラメータの許容される値の範囲を表示します。 |

5. **+ パラメータを追加** をクリックすると、さらにパラメータを追加できます。

6. パラメータ設定が完了したら、**<UI-TERM key="ocp-v2.Component.AddBackupStrategy.New">新規作成</UI-TERM>** をクリックします。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>追加したパラメータを削除する場合は、該当するパラメータ行の <b>削除</b> アクションボタンをクリックしてください。</p>
</main>

パラメータテンプレートを作成後、新しいLogserviceクラスタを作成する際にこのテンプレートを適用することができます。具体的な操作については、[Logserviceクラスタの作成](300.manage-a-logservice-cluster/200.create-a-logservice-cluster.md)を参照してください。

## 関連操作

### パラメータテンプレートの編集

1. パラメータテンプレートのリストから、編集するテンプレートを見つけます。

2. テンプレート名をクリックし、テンプレートの詳細ページに移動します。

3. 以下の操作を実行できます：

   * **<UI-TERM key="ocp-v2.Detail.Component.ModifyParameterModal.ModifyParameterValues">パラメータ値を変更する</UI-TERM>**：既存のパラメータの値を直接変更します。
   * **<UI-TERM key="ocp-v2.component.ParameterTemplate.SetParameterEditableProTable.AddParameters">パラメータを追加</UI-TERM>**：**+ パラメータを追加** をクリックし、新しいパラメータを選択して値を設定します。
   * **<UI-TERM key="ocp-v2.Component.ObjectStoragePerformanceParamsField.DeleteParameter">削除パラメータ</UI-TERM>**：パラメータ行の **<UI-TERM key="ocp-v2.Binlog.Component.DeleteBinlogModal.Delete">削除</UI-TERM>** ボタンをクリックし、不要なパラメータを削除します。
   * **<UI-TERM key="ocp-v2.Detail.Overview.ModifyRemarks">備考を変更する</UI-TERM>**：テンプレート情報エリアでテンプレートの備考情報を変更します。

4. 変更が完了したら、**<UI-TERM key="ocp-v2.ObjectStorage.Component.CreateDataSourceModal.Save">保存</UI-TERM>** をクリックします。

### パラメータテンプレートのコピー

1. パラメータテンプレートのリストから、コピーするテンプレートを見つけます。
2. テンプレートの行の **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** アイコンをクリックするか、そのテンプレートを右クリックします。
3. 操作メニューで、**<UI-TERM key="ocp-v2.Detail.Session.List.Copy">コピー</UI-TERM>** を選択します。
4. 表示されたコピーダイアログで、以下の情報を入力します：

   | 情報項目 | 説明 |
   |-------|------|
   | テンプレート名 | コピー後のテンプレート名を入力します。 |
   | 備考（オプション） | テンプレートの説明情報を入力します。 |

5. **<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Ok">確定</UI-TERM>** をクリックして、テンプレートのコピーを完了します。

### パラメータテンプレートの削除

1. パラメータテンプレートのリストで、削除するテンプレートを見つけます。

2. テンプレートの行にある **詳細** アイコンをクリックするか、そのテンプレートを右クリックします。

3. 操作メニューで、**削除** を選択します。

4. 確認ポップアップウィンドウで、削除操作を確認します。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>パラメータテンプレートを削除すると、復元できません。そのテンプレートが他のクラスタで使用されていないことを確認してください。</p>
   </main>
