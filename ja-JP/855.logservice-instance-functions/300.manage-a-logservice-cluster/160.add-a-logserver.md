# LogServerの追加

本記事では、LogServiceクラスタにLogServerノードを追加する方法について説明します。

<p class="relate-doc">
    <a href="100.logservice-cluster-list.md">LogServiceクラスタリスト</a>
    <a href="300.logservice-cluster-overview.md">LogServiceクラスタ概要</a>
    <a href="500.logservice-parameter-management.md">パラメータ管理</a>
</p>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：
  * **LogService管理** リソース権限。
  * LogService **概要** または **クラスタリスト** メニュー権限。
* 利用可能なホストリソースがあること。

## 手順

LogServerを追加するには、以下の2つの方法があります：

* **方法1**：**LogServiceクラスタ** リストで、LogServerを追加するクラスタを見つけ、対応する操作列の **<UI-TERM key="ocp-v2.components.AddLogServerDrawer.AddLogserver">LogServerを追加する</UI-TERM>** をクリックします。
* **方法2**：**LogServiceクラスタ** リストで対象のクラスタ名をクリックし、クラスタ概要ページに移動します。**LogServer** リストエリアで **<UI-TERM key="ocp-v2.src.constant.logservice.AddLogserver">LogServerを追加する</UI-TERM>** をクリックします。

以下の手順は、**方法2** を例に説明します：

1. OCPにログインします。

2. 左側のナビゲーションバーで、**LogServiceインスタンス** を選択します。

3. クラスタリストで操作対象のLogServiceクラスタを選択し、クラスタ詳細ページに移動します。

4. **LogServer** リストエリアで、**<UI-TERM key="ocp-v2.src.constant.logservice.AddLogserver">LogServerを追加する</UI-TERM>** をクリックします。

5. 表示されたLogServer追加ダイアログボックスで、以下の情報を設定します：

### 基本情報

| パラメータ | 説明 |
|-------|------|
| 附属集群 | 現在操作しているLogServiceクラスタの名前を表示します（表示のみで、変更はできません）。 |

### ソフトウェアパッケージタイプ

| パラメータ | 説明 |
|-------|------|
| ソフトウェアパッケージタイプ | オペレーティングシステムのソフトウェアパッケージタイプを選択します。例：el7。 |

### デプロイモード

| パラメータ | 説明 |
|-------|------|
| Zone名 | ゾーン名を表示します。例：zone1、zone2、zone3（表示のみで、変更はできません）。 |
| Region | そのゾーンが属するリージョンを表示します（表示のみで、変更はできません）。 |
| マシンタイプ（オプション） | マシンのタイプを選択します。 |
| ホスト | LogServerをデプロイするホストを選択します。このドロップダウンリストには利用可能なホストリソースが表示されます。 |

<main id="notice" type='notice'>
<h4>注意</h4>
<ul>
<li>各ゾーンには複数のLogServerノードを追加できます。</li>
<li>LogServerを追加すると、システムはRPCポートとHTTPポートを自動設定します。デフォルトはそれぞれ7890と7891です。</li>
</ul>
</main>

### カスタム設定

必要に応じて、**クラスタレベルのユーザー設定（オペレーティングシステムの所有者ユーザーなど）やパス設定（ソフトウェアのインストールパス、ローカルストレージパスなど）をサポートする** を選択します。

このオプションを選択すると、以下の設定をカスタマイズできます。

| パラメータ | 説明 |
|-------|------|
| オペレーティングシステムの所有者ユーザー | LogServerを実行するユーザー。デフォルトはadminです。 |
| ソフトウェアのインストールパス | LogServerソフトウェアのインストールディレクトリ。 |
| ローカルストレージパス | LogServerのローカルログストレージディレクトリ。 |

6. 設定が完了したら、**<UI-TERM key="ocp-v2.Host.Component.ReinstallModal.Determine">確定</UI-TERM>** をクリックします。

   システムは、LogServerの追加操作を実行するための非同期タスクを作成します。タスクの進捗状況は **システム管理 > タスク管理** で確認できます。
