# Logserviceクラスターリスト

Logserviceクラスターリストページでは、すべてのLogserviceクラスターの基本情報を確認できます。これには、名前、バージョン番号、関連するOBクラスター、作成日時、状態などが含まれます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Logservice読み取り専用** リソース権限。
* Logservice **クラスターリスト** メニュー権限。

## クラスターリストの表示

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.Component">コンポーネント</UI-TERM>** > **Logserviceインスタンス** を選択します。

   システムはデフォルトで **Logserviceクラスター** ページのクラスターリストタブに移動します。

3. クラスターリストでは、以下の情報を確認できます：

   | 情報項目 | 説明 |
   |-------|------|
   | Logserviceクラスター名 | Logserviceクラスターの名前 |
   | バージョン番号 | Logserviceクラスターのソフトウェアバージョン |
   | 関連OBクラスター | 関連するOceanBaseクラスター。関連しない場合は "-" を表示 |
   | 作成日時 | Logserviceクラスターの作成日時 |
   | 状態 | Logserviceクラスターの稼働状態。以下を含む：作成中、正常稼働中、起動中、停止中、停止済み、再起動中、削除中、メンテナンス中、キーローテーション中、利用不可、廃棄済み |

4. 以下の方法でクラスターをフィルタリングできます：

   * 検索ボックスにクラスター名を入力して検索します。
   * 状態ドロップダウンリストから特定の状態のクラスターをフィルタリングします。

5. クラスター名をクリックしてクラスター詳細ページに移動します。詳細については、[Logserviceクラスター概要](300.logservice-cluster-overview.md)を参照してください。

## 一般的な操作

クラスターリストページでは、以下の操作を実行できます：

* **新しいLogserviceクラスターの作成**：新しいLogserviceクラスターを作成します。詳細については、[新しいLogserviceクラスターの作成](200.create-a-logservice-cluster.md)を参照してください。
* **LogServerの追加**：LogserviceクラスターにLogServerノードを追加します。詳細については、[LogServerの追加](160.add-a-logserver.md)を参照してください。
* クラスターの再起動および停止。
