# Logservice クラスタ概要

Logserviceクラスタの概要ページでは、クラスタの基本情報、ゾーン情報、LogServerノード情報を確認できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Logservice読み取り専用** リソース権限。
* Logservice **概要** メニュー権限。

## 基本情報の確認

**基本情報** モジュールでは、以下の情報を確認できます：

| 情報項目 | 説明 |
|-------|------|
| 名前 | Logserviceクラスタの名前 |
| バージョン番号 | Logserviceクラスタのソフトウェアバージョン番号 |
| 作成日時 | Logserviceクラスタの作成日時 |
| ソフトウェアインストールパス | Logserviceソフトウェアのインストールディレクトリ |
| ローカルストレージパス | Logserviceローカルログストレージディレクトリ |
| オブジェクトストレージ | 設定されたオブジェクトストレージパス |

## ゾーン情報の確認

**Zone** モジュールでは、Logserviceクラスタ内の各ゾーンの情報を確認できます：

| 情報項目 | 説明 |
|-------|------|
| Zone名 | ゾーンの名前。例：zone1、zone2、zone3 |
| 所属Region | ゾーンが属するリージョン |
| マシン数 | そのゾーンに属するマシンの数 |
| ソフトウェアパッケージタイプ | オペレーティングシステムのソフトウェアパッケージタイプ。例：el7 |
| CPUアーキテクチャ | CPUアーキテクチャ。例：x86_64 |
| ステータス | ゾーンの稼働状態 |

## LogServer情報の確認

**LogServer** モジュールでは、クラスタ内の各LogServerノードの情報を確認できます：

| 情報項目 | 説明 |
|-------|------|
| IPアドレス | LogServerノードのIPアドレス |
| RPCポート | RPC通信ポート |
| HTTPポート | HTTPサービスポート |
| ゾーン | LogServerが属するゾーン |
| マシンタイプ | マシンのCPUアーキテクチャタイプ |
| ステータス | LogServerの実行状態 |

## 関連操作

* LogServerの追加：クラスタにLogServerノードを追加します。詳細については、[LogServerの追加](160.add-a-logserver.md)を参照してください。
* パフォーマンス監視の表示：パフォーマンス監視ページに移動し、クラスタのパフォーマンスメトリクスを確認します。詳細については、[Logserviceのパフォーマンス監視](400.logservice-performance-monitoring.md)を参照してください。
* パラメータの管理：パラメータ管理ページに移動し、クラスタパラメータ設定を変更します。詳細については、[Logserviceのパラメータ管理](500.logservice-parameter-management.md)を参照してください。
* ログのダウンロード：Logserviceクラスタのログファイルをダウンロードします。詳細については、[ログのダウンロード](../../1300.log-service/200.download-log.md)を参照してください。
