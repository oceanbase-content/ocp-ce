# Logserviceクラスタの新規作成

本記事では、OCPにおいてLogserviceクラスタを新規作成する方法について説明します。

## 前提条件

* 現在ログインしているユーザーが **ADMIN** または **ORG_ADMIN** ロールを持っていること。

* 利用可能なホストリソースがあること。詳細については、[ホストリソース要件](../../300.deployment-guide/100.deploying-enterprise-ocp/200.prepare-the-deployment-environment/200.standardized-host.md)を参照してください。

* **メモリ計画**：LogserviceクラスタとAIクラスタが同一マシンにデプロイされている場合（同居構成）、メモリ不足が発生しないよう事前にメモリ使用量を計画する必要があります。Logserviceクラスタを作成する際には、`memory_limit`パラメータを設定してそのメモリ使用を制限することを推奨します。ログ量と業務要件に応じて、Logserviceのメモリを適切な範囲（例：4GB～8GB）に制限することを推奨します。

  <main id="notice" type='explain'>
  <h4>説明</h4>
  <p>AIクラスタとLogserviceクラスタを同一マシンにデプロイする場合、メモリ使用を個別に制限しないと、両者間でメモリ競合が発生し、OOM（メモリ不足）問題を引き起こしてクラスタの安定性に影響を与える可能性があります。そのため、計画段階では、ホストの利用可能なメモリリソースに基づき、両者のmemory_limitパラメータ値を適切に割り当て、制限する必要があります。</p></main>

* Logserviceソフトウェアのインストールディレクトリを手動で作成します。デフォルトは /home/admin/logservice です。ローカルログストレージディレクトリは、デフォルトで /data/logservice1 です。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**Logservice インスタンス** を選択します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** タブで、右上の **Logserviceクラスタの新規作成** をクリックします。

4. 新規クラスタページで、以下の情報を設定します：

  * 基本情報

  | パラメータ | 説明 |
  |-------|------|
  | Logserviceクラスタ名 | クラスタ名を入力します。命名規則：英字で始まり、英字または数字で終わること。2文字以上32文字以下。特殊文字はアンダースコアのみサポートします。 |
  | Logserviceバージョン | Logserviceソフトウェアのバージョンを選択します。 |

  * デプロイメントモード

  Logserviceクラスタのデプロイメント情報を設定します：

  | パラメータ | 説明 |
  |-------|------|
  | Zone | ゾーン名を選択します。例：zone1、zone2、zone3。 |
  | Region | そのゾーンが属するリージョンを選択します。 |
  | マシンタイプ（オプション） | マシンのタイプを選択します。 |
  | CPUアーキテクチャ | CPUアーキテクチャを選択します。例：x86_64。 |
  | ホスト | Logserviceをデプロイするホストを選択します。 |
  | ソフトウェアパッケージタイプ | オペレーティングシステムソフトウェアパッケージタイプを選択します。例：el7。 |

  <main id="notice" type='explain'>
  <h4>説明</h4>
  <p>現在、1-1-1デプロイメント形態のみをサポートしています。つまり、3つのゾーンに各1つずつLogServerノードをデプロイする形態であり、その他のデプロイメント形態はサポートされていません。</p>
  </main>

  * データストレージ

  | パラメータ | 説明 |
  |-------|------|
  | オブジェクトストレージ設定 | オブジェクトストレージサービス（例：Alibaba Cloud OSS）を選択します。 |
  | ストレージディレクトリ | オブジェクトストレージのパスを設定します。例：s3://bucket/data/1。 |

  * パラメータ設定

  必要に応じて、**クラスタの起動・実行パラメータなどをカスタマイズ**を選択します。選択後、後続の手順でクラスタパラメータを設定できます。

  <main id="notice" type='explain'>
  <h4>説明</h4>
  <p>LogserviceクラスタとAIクラスタが同一マシンにデプロイされている場合（同居構成）、パラメータ設定で`memory_limit`パラメータを設定し、Logserviceのメモリ使用量を制限することを推奨します。ログ量と業務要件に基づき、Logserviceのメモリを適切な範囲に制限することで、AIクラスタとのメモリ競合を回避できます。</p></main>

  * カスタム設定

  必要に応じて、**クラスタレベルのユーザー設定（OS所有者ユーザーなど）やパス設定（ソフトウェアインストールパス、ローカルストレージパスなど）をサポートする**を選択します。

    * ユーザー設定

    | パラメータ | 説明 |
    |-------|------|
    | OS所有者ユーザー | Logserviceを実行するユーザーです。デフォルトはadminです。 |

    * パス設定

    | パラメータ | 説明 |
    |-------|------|
    | ソフトウェアインストールパス | Logserviceソフトウェアのインストールディレクトリです。デフォルトは/home/admin/logserviceです。 |
    | ローカルストレージパス | Logserviceのローカルログストレージディレクトリです。デフォルトは/data/logservice1です。 |

    * ポート設定

    | パラメータ | 説明 |
    |-------|------|
    | SQLポート | LogserviceのSQLポートです。デフォルトは7890です。 |
    | Webポート | LogserviceのHTTPサービスポートです。デフォルトは7891です。 |

5. 設定完了後、**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.FieldListDrawer.Determine">確定</UI-TERM>**をクリックしてクラスタの作成を開始します。

6. 表示された確認ダイアログで、設定情報に誤りがないことを確認し、**<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">確定</UI-TERM>**をクリックします。

   システムは非同期タスクを作成してクラスタの作成操作を実行します。タスクの進捗状況は**システム管理 > タスク管理**で確認できます。
