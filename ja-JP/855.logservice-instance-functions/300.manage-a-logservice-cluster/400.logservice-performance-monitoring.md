# パフォーマンス監視

Logserviceクラスタのパフォーマンス監視ページでは、ログ受信、ストレージ、GC、スレッドプール、リソース監視など、クラスタの各種パフォーマンス指標を確認できます。これにより、クラスタの稼働状態とパフォーマンスボトルネックを把握することができます。

パフォーマンス監視ページには、以下のタブが含まれています：

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Logservice読み取り専用** リソース権限。
* Logservice **パフォーマンス監視** メニュー権限。

## パフォーマンス監視の表示

1. OCPにログインします。

2. 左側のナビゲーションバーで、**Logserviceインスタンス** を選択します。

3. クラスタリストで、対象のクラスタ名をクリックしてクラスタ詳細ページに移動します。

4. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Instance.Monitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** を選択します。

   システムはパフォーマンス監視ページを表示します。

5. ページ上部のフィルターで表示範囲を選択できます：

   * **Zone**：表示するZoneを選択します。すべてのZoneを選択することもできます。
   * **LogServer**：表示するLogServerノードを選択します。すべてのノードを選択することもできます。
   * **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.TimeRange">時間範囲</UI-TERM>**：表示する時間範囲を選択します。例えば、1h、3h、12hなどです。

6. 別々のタブをクリックして、ログ監視、パフォーマンス監視、ストレージとGC、スレッドプール、リソース監視など、該当するパフォーマンス指標を確認します。詳細な指標については、[AIクラスタ監視指標](../../1900.reference-guide/300.monitoring-indicator-reference/700.ai-cluster/000.ai-cluster-metrics-overview.md)を参照してください。

## 時間範囲

パフォーマンス監視ページは、デフォルトで直近の期間のデータを表示します。ページ上部の更新ボタンの下にある時間選択器を使用して、表示する時間範囲を調整できます。1h、3h、12hなどのオプションをサポートしています。

<main id="notice" type='notice'>
<h4>説明</h4>
<p>パフォーマンス指標データには、一定の収集遅延が生じる可能性があります。データに異常が見られた場合は、しばらく待ってからページを更新してください。</p>
</main>
