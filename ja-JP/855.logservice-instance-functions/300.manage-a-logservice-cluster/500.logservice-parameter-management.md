# パラメータ管理

Logserviceクラスタのパラメータ管理ページでは、クラスタの各種パラメータ設定を確認および変更できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **Logservice管理** リソース権限。
* Logservice **パラメータ管理** メニュー権限。

## パラメータリストの表示

1. OCPにログインします。

2. 左側のナビゲーションバーで、**Logserviceインスタンス** を選択します。

3. クラスタリストで、対象のクラスタ名をクリックしてクラスタ詳細ページに移動します。

4. 左側のナビゲーションバーで、**パラメータ管理** を選択します。システムはパラメータリストページを表示します。

## パラメータ値の変更

1. パラメータリストで、変更するパラメータを見つけます。

2. **値の変更** ボタンをクリックします。

3. ポップアップダイアログに新しいパラメータ値を入力します。

4. **OK** をクリックして変更を保存します。

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>パラメータを変更すると、クラスタの動作に影響を与える可能性があります。慎重に操作してください。</li>
<li>一部のパラメータは変更後、サービスの再起動が必要になります。その際、システムから再起動を促すメッセージが表示されます。</li>
<li>パラメータの変更はオフピーク時に行い、事前に業務への影響を評価することを推奨します。</li>
</ul>
</main>

## パラメータの検索

検索ボックスにパラメータ名を入力すると、対象のパラメータをすばやく特定できます。
