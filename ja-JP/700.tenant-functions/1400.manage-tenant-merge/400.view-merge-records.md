# メジャーコンパクションレコードの表示

テナントの過去3日間のメジャーコンパクションレコードを確認できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナント **<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">メジャーコンパクション管理</UI-TERM>** メニュー権限。

* テナントが属するクラスタがV4.0.0.0以降のバージョンであること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.MonitorSearch.Tenant">テナント</UI-TERM>** をクリックすると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で操作対象のテナントを選択し、そのテナント名をクリックすると、テナントの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. ページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.MergeManagement">メジャーコンパクション管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Detail.Compaction.MergeDetails">メジャーコンパクションの詳細</UI-TERM>** または **<UI-TERM key="ocp-v2.Detail.Compaction.MergeConfiguration">メジャーコンパクション構成</UI-TERM>** タブの右上隅にある **<UI-TERM key="ocp-v2.component.RecentCompaction.ViewMergeRecords">メジャーコンパクション記録を見る</UI-TERM>** をクリックすると、そのテナントの過去3日間のすべてのメジャーコンパクションレコードを確認できます。レコード情報には、メジャーコンパクションの開始時間、終了時間、所要時間、バージョン番号、メジャーコンパクション状態などが含まれます。
