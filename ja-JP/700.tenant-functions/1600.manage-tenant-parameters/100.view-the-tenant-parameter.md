# パラメータ一覧の表示

テナントのパラメータ一覧では、現在のテナントにおけるすべてのパラメータの名前、カテゴリ、値の種類、値の範囲、デフォルト値、現在の値、説明、および再起動後に有効になるかどうかを確認できます。リスト上部の検索ボックスでは、パラメータ名によるあいまい検索が可能です。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナント **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

* パスワードボックスに保存されている当該テナントのrootユーザーのパスワードが正しいかどうか、およびテナントのホワイトリスト設定が正しいかどうかを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックすると、テナントの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Parameter.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">パラメータリスト</UI-TERM>** ページでは、現在のクラスタのすべてのパラメータ情報を確認できます。

   * 表示情報には、各パラメータの名前、値の種類、値の範囲、デフォルト値、現在の値、説明、および読み取り専用かどうかなどの情報が含まれます。

   * **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.DefaultValue">デフォルト値</UI-TERM>** は新規テナントのデフォルト値を表します。読み取り専用は、そのパラメータが変更可能かどうかを示します。変更可能なパラメータの場合、**<UI-TERM key="ocp-v2.Detail.TakeOver.Operation">操作</UI-TERM>** 列に値を変更するボタンが表示されます。

   * 右上の **<UI-TERM key="ocp-v2.component.OperationConfig.List.ViewOnlyModifiedParameters">変更されたパラメータのみを表示</UI-TERM>** を選択すると、OCP内で変更されたパラメータのリストを確認できます。
