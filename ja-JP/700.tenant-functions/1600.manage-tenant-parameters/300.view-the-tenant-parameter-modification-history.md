# パラメータ変更履歴の表示

変更履歴ページでは、テナントパラメータの変更履歴を確認できます。これには、パラメータ名、変更前の値、変更後の値、変更日時、および操作ユーザーが含まれます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
* テナント **<UI-TERM key="ocp-v2.src.util.menu.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.component.OperationConfig.Parameter.ModifyHistory">変更履歴</UI-TERM>** タブをクリックします。

6. **<UI-TERM key="ocp-v2.component.OperationConfig.History.ModifiedDate">更新日</UI-TERM>** または **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter.1">パラメータ名称</UI-TERM>** でフィルター検索を行います。

   ここで、**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Parameter">パラメータ名</UI-TERM>** はあいまい検索をサポートします。

7. クエリ結果で、テナントパラメータの変更履歴を確認します。
