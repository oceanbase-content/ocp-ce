# パラメータの変更

必要に応じてテナントパラメータの値を変更できます。すべてのテナントパラメータの値は変更後、リアルタイムで反映されます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>テナントがAIクラスタ（共有ストレージ形態）に属している場合、以下のテナントレベルパラメータが追加されます：<ul><li><b>shared_log_retention</b>：共有ログの保持時間。デフォルト値は1日。[0日、14日]の範囲です。</li><li><b>read_cache_disk_percentage</b>：読み取りキャッシュのディスク割合。デフォルト値は40。[0、90]の範囲です。</li><li><b>cache_disk_memory_limit</b>：キャッシュディスクのメモリ制限。デフォルト値は10。[5、50]の範囲です。</li></ul></p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
* テナント **<UI-TERM key="ocp-v2.page.Iframe.ParameterManagement">パラメータ管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 表示されたページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.component.OperationConfig.ParameterManagement">パラメータ管理</UI-TERM>** をクリックします。

5. （オプション）**<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">パラメータリスト</UI-TERM>** ページ上部の検索ボックスに、パラメータ名などの関連情報を入力して、あいまい検索を実行します。

6. 変更対象のパラメータを見つけて、**<UI-TERM key="ocp-v2.Detail.Parameter.ModifyValue">値を変更する</UI-TERM>** ボタンをクリックします。

   ![09071422](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%82%E6%95%B0%E5%88%97%E8%A1%A83.png)

7. ポップアップダイアログで、パラメータの値を変更します。

   ![09071420](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E4%BF%AE%E6%94%B9%E5%8F%82%E6%95%B01.png)

8. **<UI-TERM key="ocp-v2.component.Compaction.MergePolicyDrawer.Submit">送信</UI-TERM>** をクリックします。
