# データベースの管理

データベース管理では、テナント内のデータベース一覧情報を提供するほか、データベースの作成、削除、変更などの機能を提供します。

## 前提条件

* データベースリスト情報を表示する場合は、OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.page.Iframe.DatabaseManagement">データベース管理</UI-TERM>** メニュー権限。

* 新規データベースの作成、データベース情報の変更、データベースの削除などの運用操作を実行する場合は、OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.Detail.Database.DatabaseManagement">データベース管理</UI-TERM>** メニュー権限。

* この機能はMySQL互換モードのプライマリテナントを対象としています。

* 現在のユーザーパスワードボックスにそのテナントのrootパスワードが存在すること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ParameterTemplate.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で、操作対象のMySQLテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.DatabaseManagement">データベース管理</UI-TERM>** をクリックして、データベース管理ページに移動します。

   * **データベース情報の表示**

     データベースリストで **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.DatabaseName">データベース名</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.Detail.CharacterSet">文字セット</UI-TERM>**、**Collation**、**<UI-TERM key="ocp-v2.component.TenantList.ZonePriority">ゾーンの優先度</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Database.DiskUsage">ディスク使用量</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.Detail.CreationTime">作成日時</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.ReadOnly">読み取り専用</UI-TERM>**、および **<UI-TERM key="ocp-v2.Detail.Database.JdbcConnectionString">JDBC接続文字列</UI-TERM>** を確認できます。

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <p>OceanBaseのバージョンがV2.2.1未満の場合、作成日時は表示されません。</p>
     </main>

     <!-- ![Image 151](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0756189461/p429268.png) -->

   * **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.CreateADatabase">データベースの新規作成</UI-TERM>**

     ページの右上隅にある **<UI-TERM key="ocp-v2.Detail.Database.CreateADatabase">新しいデータベースを作成する</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.Detail.Database.CreateADatabase">新しいデータベースを作成する</UI-TERM>** パネルに **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.DatabaseName">データベース名</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.New.CharacterSet">文字セット</UI-TERM>**、**Collation** の情報を入力し、読み取り専用かどうかを選択して、**<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">送信</UI-TERM>** をクリックします。

     |    **<UI-TERM key="ocp-v2.Detail.SqlAudit.Configuration">設定</UI-TERM>**     | **<UI-TERM key="ocp-v2.Auth.Role.Detail.Description">説明</UI-TERM>** |
     |---------------|---------|
     | **<UI-TERM key="ocp-v2.Detail.Overview.DatabaseName">データベース名</UI-TERM>**  | 2文字以上64文字以下の任意の文字列を設定できます。数字(0～9)、大文字(A～Z)、小文字(a～z)、アンダースコア(_)、ハイフン(-)を含めることができます。データベース名に含まれる大文字は、デフォルトで小文字に変換されます。 |
     | **<UI-TERM key="ocp-v2.Tenant.New.CharacterSet">文字セット</UI-TERM>**    | 使用可能な文字セットはutf8mb4、binary、gbk、gb18030、latin1、gb18030_2022です。デフォルトはgbkです。 |
     | **照合順序** | 文字セットに対応する詳細なソート規則。 |

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <ul>
     <li>データベースの優先順位は、デフォルトでテナントのゾーン優先順位設定を継承します。テナントの優先順位を変更する必要がある場合は、<a href="600.manage-a-tenant/670.modify-a-zone-priority.md">ゾーン優先順位の変更</a>を参照してください。</li>
     <li>データベースの優先順位がテナントの優先順位と一致しない場合、<strong>テナントと同じに変更</strong>ボタンをクリックして変更できます。</li>
     </ul>
     </main>

   * **データベース情報の変更**

     データベースの**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.Operation">操作</UI-TERM>**列の**<UI-TERM key="ocp-v2.src.constant.credential.Edit">編集</UI-TERM>**をクリックし、**文字セット、照合順序、読み取り専用**の情報を変更します。

     <main id="notice" type='explain'>
     <h4>説明</h4>
     <ul>
     <li>データベースの優先順位は、デフォルトでテナントのゾーン優先順位設定を継承します。テナントの優先順位を変更する必要がある場合は、<a href="600.manage-a-tenant/670.modify-a-zone-priority.md">ゾーン優先順位の変更</a>を参照してください。</li>
     <li>データベースの優先順位がテナントの優先順位と一致しない場合、<strong>テナントと同じに変更</strong>ボタンをクリックして変更できます。</li>
     </ul>
     </main>

     <!-- ![Image 153](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E7%BC%96%E8%BE%91%E6%95%B0%E6%8D%AE%E5%BA%93.png) -->

   * **<UI-TERM key="ocp-v2.Detail.Database.DeleteADatabase">データベースを削除する</UI-TERM>**

     データベースの**<UI-TERM key="ocp-v2.MultiAzone.Parameter.Operation">操作</UI-TERM>**列の**<UI-TERM key="ocp-v2.Alarm.Channel.Delete">削除</UI-TERM>**をクリックし、**delete**と入力して操作を確認し、データベースを削除します。

     <main id="notice" type='notice'>
     <h4>注意</h4>
     <p>データベースを削除するとデータは復元できません。ご注意ください。</p>
     </main>
