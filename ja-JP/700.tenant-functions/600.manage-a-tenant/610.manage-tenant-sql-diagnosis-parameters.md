# テナントパラメータの管理

このセクションを参照して、テナントごとに疑わしいSQLの診断ルールを設定し、多様なビジネスニーズに対応できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
* テナント **概要** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.CardSqlDiagnoseAdvices.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で操作対象のテナントを選択し、そのテナント名をクリックすると、テナントの **<UI-TERM key="ocp-v2.pages.Alarm.Overview">概要</UI-TERM>** ページに移動します。

4. 右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.Overview.components.TenantActionMenu.TenantParameters">テナントパラメータ</UI-TERM>** を選択します。

5. ポップアップパネルで、変更が必要なパラメータを選択し、パラメータ値の右側にある編集ボタンをクリックします。一部のパラメータは変更後、OCPサーバーを再起動しないと変更が有効になりません。詳細は **<UI-TERM key="ocp-v2.Detail.Parameter.List.WhetherToRestartEntryInto">再起動して有効にする</UI-TERM>** 列をご確認ください。
