# スタンバイテナントの作成

プライマリテナントまたはスタンバイテナントが1つある場合、そのテナントに対してスタンバイテナントを作成できます。OCPでは、1つのプライマリテナントに対して複数のスタンバイテナントを作成する（1対多）場合と、スタンバイテナントに対してさらにスタンバイテナントを作成する（カスケード）場合の2つのシナリオをサポートしています。

## 背景

OceanBaseはV4.1.0バージョンから、物理スタンバイデータベースの製品形態をテナントレベルのプライマリ/スタンバイに変更しました。これにより、プライマリまたはスタンバイの役割情報はテナントに属し、プライマリテナントとスタンバイテナントに分かれます。クラスタにはプライマリ/スタンバイの概念がなくなり、単なるテナントを格納するコンテナとなりました。プライマリテナントはユーザーが作成する業務テナントであり、クエリ、DML、DDLなどの完全なデータベースサービス機能をサポートします。一方、スタンバイテナントは災害復旧および読み取り専用サービスの機能のみを提供します。一つのプライマリテナントと複数のスタンバイテナントが組み合わさることで、テナントレベルの物理スタンバイデータベースによる高可用性ソリューションが構成されます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* テナントレベルのプライマリ/スタンバイデータベースの設定は、OceanBase V4.2以降のバージョンでのみサポートされています。

* スタンバイテナントが属するクラスタの状態が実行中であること。

* シングルマシンではデフォルトでテナントを1つしか作成できません。シングルマシンでスタンバイテナントを作成したい場合は、対応する機能オプションを購入し、再度[Licenseをインポート](../../600.cluster-functions/300.manage-a-cluster/1400.import-license.md)する必要があります。

* OceanBase V4.2.1.8未満のバージョンでスタンバイテナントを作成する場合は、30日前のベースラインバックアップデータを使用して物理スタンバイデータベースを復元しないでください。これにより、物理スタンバイデータベースの機能異常やテナントのメジャーコンパクションへの影響が発生する可能性があります。

* テナントのためにアービトレーションサービスを有効にする前に、以下の情報を確認する必要があります：

  * テナントが属するクラスタにアービトレーションサービスが追加されており、アービトレーションサービスが **RUNNING** 状態にあること。

  * アービトレーションサービスを有効にするテナントのローカリティが2F（F：フル機能レプリカ）または4Fであること。

  * アービトレーションサービスが配置されているホストの残りリソースがリソース要件を満たしていること。

    このリソース要件はシステムパラメータで実際の状況に応じて変更できます。変更が必要なパラメータは以下の通りです。操作の詳細については [システムパラメータの変更](../../700.tenant-functions/1600.manage-tenant-parameters/200.modify-a-tenant-parameter.md) を参照してください。

    * `ocp.arbitration.min.remain.disk.size`：テナントアービトレーションを有効にする場合のアービトレーションサービスホストCLOGディスクの残り最小値。単位はMBです。データ形式 (a,b) はテナントレプリカがそれぞれ2F、4Fの場合の値を表し、デフォルトは [12,24] です。
    * `ocp.arbitration.max.cpu.used.percentage`：テナントアービトレーションを有効にする場合のアービトレーションサービスホストの最大CPU利用率。単位は%です。デフォルト値は90です。
    * `ocp.arbitration.max.memory.used.percentage`：テナントアービトレーションを有効にする場合のアービトレーションサービスホストの最大メモリ利用率。単位は%です。デフォルト値は90です。

* プライマリテナントが存在するクラスタでSSLリンク暗号化が有効になっており、プライマリ/スタンバイ同期方式が **ネットワークベース** の場合、スタンバイテナントが存在するクラスタでもSSLリンク暗号化を有効にする必要があります。また、ルート証明書はプライマリテナントが存在するクラスタと一致している必要があります。

## 手順

スタンバイテナントを新規作成するには、以下の4つの方法があります：

* **方法1**：OCPにログインし、**<UI-TERM key="ocp-v2.src.constant.information.Tenant">テナント</UI-TERM>** ページに移動して、右上の **<UI-TERM key="ocp-v2.Tenant.New.NewTenant">新規テナント</UI-TERM>** をクリックします。

* **方法2**：OCPにログインし、クラスタの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動して、右上の **<UI-TERM key="ocp-v2.Tenant.New.NewTenant">新規テナント</UI-TERM>** をクリックします。

* **方法3**：OCPにログインし、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動します。左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Tenant.TenantManagement">テナント管理</UI-TERM>** を選択し、右上の **<UI-TERM key="ocp-v2.Cluster.Detail.NewTenant">新しいテナントを作成</UI-TERM>** をクリックします。

* **方法4**：OCPにログインし、テナントの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。右上のメニューアイコンをクリックし、**<UI-TERM key="ocp-v2.page.Tenant.NewTenant">新しいテナントを作成</UI-TERM>** を選択します。

1. OCPにログインします。

7. **<UI-TERM key="ocp-v2.Cluster.New.ParameterConfiguration">パラメータ設定</UI-TERM>** モジュールを開き、テナントのパラメータを設定します。

    * **<UI-TERM key="ocp-v2.Tenant.New.BasicSettings">基本設定</UI-TERM>** で負荷タイプを設定した場合、システムはその負荷タイプに対応するパラメータテンプレートをデフォルトで選択します。

    * 図①のように、起動パラメータを1つずつ追加し、値を設定できます。

    * 図②のように、**<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.SelectAParameterTemplate">パラメータテンプレートを選択</UI-TERM>** をクリックしてパラメータテンプレートを選択することもできます。システムは、選択したテンプレートのパラメータと設定を自動的にここに入力します。テナントのパラメータテンプレートが作成されていない場合は、**新規テナントテンプレート** をクリックして、テナント用にパラメータテンプレートを作成できます。詳細については、[テナントパラメータテンプレートの管理](../1700.manage-tenant-parameter-templates.md)を参照してください。

         システムでは、一般的なパラメータ設定を含む以下の4種類の組み込みテンプレートを提供しています。これらのテンプレートを直接適用することで、クラスタの初期設定を行うことができます。システムの組み込みテンプレートについては、以下に詳述します。

         | テンプレート | 説明 |
         |------|-------|
         | COMPLEX_OLTP デフォルトパラメータテンプレート   |  **Complex OLTP** ロードタイプに対応します。このテンプレートはOceanBase V4.2.5以降のバージョンでのみ適用されます。   |
         | HTAP デフォルトパラメータテンプレート   |   **HTAP** ロードタイプに対応します。このテンプレートはOceanBase V4.2.5以降のバージョンでのみ適用されます。 |
         | OLAP デフォルトパラメータテンプレート   |   **OLAP** ロードタイプに対応します。このテンプレートはOceanBase V4.3.0以降のバージョンでのみ適用されます。   |
         | EXPRESS_OLTP デフォルトパラメータテンプレート   |  **Express OLTP** ロードタイプに対応します。このテンプレートはOceanBase V4.2.5以降のバージョンでのみ適用されます。   |
