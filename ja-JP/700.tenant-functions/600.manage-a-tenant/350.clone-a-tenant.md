# テナントのクローン

このページでは、テナントのクローン方法について説明します。テナントをクローンすることで、指定したテナントを基に新しいテナントを作成できます。クローンされた新しいテナントのユニット数および各OBServerノード上のユニットの配置は、ソーステナントと一致します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OceanBaseデータベースV4.3.x以降では、プライマリテナントのクローン機能の使用は推奨されません。OceanBase V4.4.2 BP2以降では、プライマリテナントを選択してクローン操作を実行すると、システムは直接エラーを返し、操作を完了できません。既に本番環境でプライマリテナントのクローン機能を使用している場合は、今後のバージョンアップグレードによる業務への影響を避けるため、速やかにOceanBaseサポートチームに連絡し、リスク評価と移行の指導を受けてください。</p>
<p>スタンバイテナントのクローン機能は実験的な機能です。使用する前に、必ず利用範囲を確認し、関連するリスクを十分に理解してください。スタンバイテナントのクローンは主に、スタンバイデータベースの演習に適用されます。</p>
</main>

テナントのクローンには、以下の2つの方法があります：

* **テナント一覧**ページでテナントをクローンします。

* 指定したテナントの**概要**ページでテナントをクローンします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**リソース権限。
  * テナントの**<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>**メニュー権限。

* ソーステナントは、[新規テナントレベルバックアップポリシーの作成](../../1100.backup-and-restoration-functions/500.regular-backup/200.manage-tenant-backup-strategy/100.creat-a-tenant-backup-stategy.md)を参照してログアーカイブ設定を完了していること。

## 注意事項

* ソーステナントの状態は、正常稼働またはロックされている必要があります。
* ユニットなどのテナント固有の構成のみをクローンでき、サービス名やタグのクローンはサポートされていません。
* スタンバイテナントをクローンする場合、スタンバイテナントが属するクラスタがV4.3.2.0以上であることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.Tenant">テナント</UI-TERM>**を選択すると、システムはデフォルトで**<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>**で操作対象のテナントを選択し、操作列の**<UI-TERM key="ocp-v2.component.TenantList.Clone">クローンする</UI-TERM>**をクリックします。

4. ポップアップウィンドウで新しいテナントの関連情報を設定します。詳細は以下のとおりです。

    * **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.TenantName">テナント名</UI-TERM>**：クローンされた新しいテナント名は、英字で始まり、英字または数字で終わるものにする必要があります。英字、数字、アンダースコアを含むことができ、長さは2～32文字です。
    * **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.WhetherToCloneTenantParameters">テナントパラメータをクローンしますか</UI-TERM>**：ソーステナントと同じパラメータ設定を使用するかどうか。デフォルトで有効です。
    * **<UI-TERM key="ocp-v2.Tenant.Detail.CopyDetails">レプリカの詳細</UI-TERM>**：クローンされた新しいテナントのユニット仕様を設定します。ユニットのサイズはクローン速度に影響するため、システムはデフォルトでソーステナントの中でより高い仕様のユニットを選択します。また、各ゾーン内のユニット仕様は一致させる必要があります。
    * **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.Whitelist">許可リスト</UI-TERM>**：デフォルトではソーステナントと一致します。テナントクローン後、テナント概要ページで変更できます。
    * **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.DumpBeforeCloningATenant">テナントをクローンする前にダンプ操作を実行してください</UI-TERM>**：テナントのクローンを即座に実行したい場合、クローン前にダンプ操作を選択して実行できます。ダンプの実行はプロセス停止の応答時間を延ばしますが、OBServerの復旧時間を大幅に短縮できます。

5. **<UI-TERM key="ocp-v2.User.Oracle.UserList.Determine">確定</UI-TERM>** をクリックします。
