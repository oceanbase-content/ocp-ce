# テナントのエンドツーエンド・トレースの設定

本記事では、テナントのエンドツーエンド・トレースの設定を有効または無効にする方法と使用方法について説明します。

## 背景

エンドツーエンド・トレースを有効にすると、以下が可能になります：

* **<UI-TERM key="ocp-v2.page.Log.LogService">ログサービス</UI-TERM>** > **<UI-TERM key="ocp-v2.Log.Trace.LinkQuery">リンククエリ</UI-TERM>** で異常なSQLのエンドツーエンド診断結果を照会できます。詳細については、[リンクのクエリ](../../1300.log-service/400.trace-query.md)を参照してください。
* **<UI-TERM key="ocp-v2.Detail.Monitor.SqlDiagnosis">SQL 診断</UI-TERM>** > **SlowSQL** > **<UI-TERM key="ocp-v2.Component.SQLDetail.SQLTraceTable.SqlSampling">SQLサンプリング</UI-TERM>** で、呼び出しリンクの表示を選択できます。詳細については、[SlowSQLの診断](../../1000.diagnosis-and-tuning-fuctions/100.manage-sql-diagnosis/600.slowsql-diagnostics.md)を参照してください。

OCP V4.2.1バージョンでは、テナントレベルおよびセッションレベルのエンドツーエンド・トレース設定が新たにサポートされ、必要に応じて指定した対象のトレースを有効または無効にできます。

<main id="notice" type='notice'>
  <h4>注意</h4>
  <p>エンドツーエンド・トレースはデフォルト設定ではOceanBaseデータベースサービスのパフォーマンスに約2%の影響を与えます。パフォーマンスが重要なシナリオでは、この機能を無効にすることを推奨します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナント **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* エンドツーエンド・トレース関連の設定が有効になっていること。詳細については、[リンククエリ関連パラメータの設定](../../1300.log-service/300.configuration-trace-paremeters.md)を参照してください。

## テナントのエンドツーエンド・トレースの設定

テナント概要ページのエンドツーエンド・トレース設定で、エンドツーエンド・トレース機能を有効または無効にします。

<main id="notice" type='explain'>
  <h4>説明</h4>
  <ul><li>業務テナントがロック状態の場合、エンドツーエンド・トレースの有効化はサポートされません（sysテナントを除く）。</li><li>テナントまたはセッションのエンドツーエンド・トレースが有効でも、業務テナントをロックできます。ロックすると、エンドツーエンド・トレース機能はデフォルトで無効になります。</li><li>テナントまたはセッションのエンドツーエンド・トレースが有効でも、業務テナントを削除できます。</li><li>テナントレベルのエンドツーエンド・トレースを無効にすると、そのテナント下のすべてのセッションのエンドツーエンド・トレースも無効になります。</li><li>テナントレベルのエンドツーエンド・トレースの変更は、そのテナント下のすべてのセッションに適用されます。</li></ul>
</main>

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.plan.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 右上の **...** アイコンをクリックし、**<UI-TERM key="ocp-v2.src.component.TraceConfigModal.FullLinkDiagnosticConfiguration">エンドツーエンド・トレースの設定</UI-TERM>** を選択します。

    <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/OAS/%E5%85%A8%E9%93%BE%E8%B7%AF%E8%BF%BD%E8%B8%AA-2.png) -->

5. パラメータを設定します。

    <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/OAS/%E5%85%A8%E9%93%BE%E8%B7%AF%E8%BF%BD%E8%B8%AA-1.png) -->

    | パラメータ | 説明 |
    |-----|------|
    | トレースレベル | レベル1、レベル2、レベル3を選択できます。レベル1はモジュールレベルの粗い粒度で、レベル3が最も細かい粒度です。 |
    | サンプリング比率 | デフォルトは10%で、0～100%の範囲で設定できます。 |
    | サンプリング内容 | <ul><li>ALL：サンプリングされたすべてのログを出力します。</li><li>ONLY_SLOW_QUERY：サンプリングされたすべてのログのうち、スロークエリ(slow query)に該当するもののみをログファイルに出力し、その他は破棄します。この出力ポリシーでは、「slow」はサーバーからフィードバックされるクエリのスローしきい値です(デフォルト値)。</li><li>SAMPLE_AND_SLOW_QUERY：サンプリングされたすべてのログのうち、スロークエリ(ONLY_SLOW_QUERY)を出力し、さらに1万分の1の確率でサンプリングされたログを出力します(ALL)。この場合は、force flushを設定する必要があります。</li></ul> |
    | 有効化の有無 | デフォルトで有効です。無効にすると、エンドツーエンド・トレース機能が無効になります。 |

## セッションレベルのエンドツーエンド・トレースの設定

セッション管理ページのエンドツーエンド・トレース設定で、エンドツーエンド・トレース機能を有効または無効にできます。

* テナントレベルのエンドツーエンド・トレースが有効な場合、個々のセッションレベルのスイッチを個別にオフにできます。
* セッションレベルのエンドツーエンド・トレースの変更は、現在のセッションにのみ適用されます。

操作手順：

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Information.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. テナントページの左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">セッション管理</UI-TERM>** を選択します。

5. テナントのセッションリストで、操作対象のセッションを選択し、**<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** の **<UI-TERM key="ocp-v2.src.component.TraceConfigModal.FullLinkDiagnosticConfiguration">エンドツーエンド・トレースの設定</UI-TERM>** を選択します。
