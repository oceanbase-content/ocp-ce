# sysテナントのパスワードを変更する

このページでは、sysテナントのパスワードを変更する操作について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**または**テナントメンテナンス**のリソース権限。
  * テナントの**<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>**メニュー権限。

* sysテナントのパスワード変更は、プライマリテナントでのみサポートされます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Tenant">テナント</UI-TERM>**を選択すると、システムはデフォルトで**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>**で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの**<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。

4. 右上の**...**アイコンをクリックし、**<UI-TERM key="ocp-v2.src.component.ModifyUserPasswordModal.ChangePassword">パスワードの変更</UI-TERM>**を選択します。

   ![10141042](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%BF%AE%E6%94%B9%E5%AF%86%E7%A0%81.png)

5. ポップアップウィンドウで新しいパスワードを入力し、もう一度パスワードを確認します。入力した2つのパスワードが一致していることを確認してください。

   パスワードの形式要件：長さは8～32文字で、数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（<code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>）の4種類のうち、少なくとも3種類を含む必要があります。

   ![1122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E4%BF%AE%E6%94%B9%E7%A7%9F%E6%88%B7%E5%AF%86%E7%A0%81.png)

6. **<UI-TERM key="ocp-v2.component.TagFilterDropDown.Ok">確定</UI-TERM>**をクリックすると、新しいレプリカの作成操作が完了します。
