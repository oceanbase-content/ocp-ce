# テナントのコピー

このページでは、テナントのコピー操作について説明します。テナントをコピーすると、選択したテナントの設定情報（テナントモード、文字セット、照合順序、ユニット構成など）を新しいテナントの作成に利用でき、テナントの作成時間を短縮できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** リソース権限。
* テナント **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** で操作対象のテナントを選択し、操作列の **<UI-TERM key="ocp-v2.User.Component.AccessKeyCardTable.Copy">コピー</UI-TERM>** をクリックします。

4. テナントコピーページに以下の情報を入力します。詳細については [新規テナントの作成](../../500.quickstart/600.quickstart-create-a-tenant.md) を参照してください。

5. **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">送信</UI-TERM>** をクリックします。
