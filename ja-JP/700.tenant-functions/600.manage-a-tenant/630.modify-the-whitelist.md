# テナントの許可リストを変更する

このページでは、テナントの許可リストを変更する操作について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**または**テナントメンテナンス**リソース権限。
  * テナントの**<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>**メニュー権限。

* テナントの許可リストの変更は、プライマリテナントでのみサポートされます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.src.constant.monitor.Tenant">テナント</UI-TERM>**を選択すると、システムはデフォルトで**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>**で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの**<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。

4. **<UI-TERM key="ocp-v2.Detail.Component.CloneTenantModal.Whitelist">許可リスト</UI-TERM>**モジュールで、**<UI-TERM key="ocp-v2.Compaction.Settings.Modify">修正</UI-TERM>**をクリックします。

5. ポップアップウィンドウで許可リスト設定を行います。

   * すべてのIPからアクセス可能：すべてのIPがこのテナントにアクセスできます。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>この方法にはアクセスのセキュリティ上のリスクが伴います。慎重に操作してください。</p>
      </main>

   * カスタム：ログインを許可するクライアント端末のリストを指定します。サポートされている形式は、IPアドレス、IPアドレス範囲、サブネット/マスク、あいまい一致、複数形式の混合、および特記事項です。例：

     |   フォーマット       |     例     |
     |--------------|--------------|
     | IP アドレス      | xxx.xxx.xxx.1,xxx.xxx.xxx.2    |
     | IP アドレス範囲      | xxx.xxx.xxx.1-3  <main id="notice" type='explain'><h4>説明</h4><p><ul><li>xxx.xxx.xxx.1-3 は、xxx.xxx.xxx.1、xxx.xxx.xxx.2、xxx.xxx.xxx.3 の3つのIPアドレスを一度に追加することを表します。</li><li>IPアドレス範囲の追加は、IPV4ネットワークでのみサポートされており、IPV6ネットワークは現在サポートされていません。</li></ul></p></main>  |
     | サブネット/マスク    | xxx.xxx.xxx.1/24     |
     | あいまい一致     | xxx.xxx.xxx.% または xxx.xxx.xxx._   |
     | 複数形式の混合 | xxx.xxx.xxx.1,xxx.xxx.xxx.2,xxx.xxx.xxx.%,xxx.xxx.xxx._,xxx.xxx.xxx.1/24 |
     | 特記事項     | % はすべてのクライアントが接続できることを意味します      |

6. **<UI-TERM key="ocp-v2.Detail.Component.SwitchoverModal.Determine">確定</UI-TERM>**をクリックして、変更を完了します。
