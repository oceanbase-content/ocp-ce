# レプリカの追加

このページでは、テナントにレプリカを追加する手順について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
* テナント **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## 注意事項

* テナントが属するデータベースが単一マシンの場合、レプリカの追加はサポートされません。
* `sys` テナントではゾーン内のリソースが一貫している必要があります。`sys` テナントにレプリカを追加する際は、Unit数の変更はサポートされません。
* 非 `sys` テナントが属するクラスタがV4.x以降のバージョンで非対称ゾーンが有効な場合、フル機能レプリカは最大でも2種類の異なるUnit数のみを設定できます。
* レプリカの追加はパーティションレプリカの移行操作を引き起こし、OBServerのストレージI/OおよびOBServer間のネットワークトラフィックが増加します。突発的なトラフィックを制御する必要がある場合は、<code>ha_high_thread_score</code>、<code>ha_mid_thread_score</code> のパラメータ値を変更するか、バックグラウンドタスク <code>HA_HIGH</code>、<code>HA_MID</code> に対してリソース分離を行うことを推奨します。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. ページの右上隅にある **<UI-TERM key="ocp-v2.Topo.TopoGraph.NewCopy">新規追加レプリカ</UI-TERM>** をクリックします。

   ![10141027](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%96%B0%E5%A2%9E%E5%89%AF%E6%9C%AC1.png)

5. ポップアップウィンドウで、**<UI-TERM key="ocp-v2.Detail.Component.BatchModifyUnitModal.TargetZone">目標ゾーン</UI-TERM>**、**<UI-TERM key="ocp-v2.Restore.SamplingStrategy.Detail.ReplicaType">レプリカタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Tenant.UnitSpecification">ユニット仕様</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.AddReplicaModal.NumberOfUnits">ユニット数</UI-TERM>** の情報を選択します。複数のゾーンにレプリカを追加することもできます。

   |   パラメータ    |   説明  |
   |-----------|---------|
   | ターゲットゾーン | 新しいレプリカが配置されるゾーンです。現在のクラスタのゾーンから選択できます。  |
   | レプリカタイプ    | レプリカタイプを選択します。複数のフル機能レプリカタイプを選択し、フル機能レプリカタイプが多数派になるようにしてください。詳細については、[テナントの作成](../300.create-a-tenant.md)のレプリカタイプの説明を参照してください。 |
   | Unit仕様     | 新しいレプリカのUnit仕様を選択します。詳細については、[テナントの作成](../300.create-a-tenant.md)のUnit仕様の説明を参照してください。    |
   | Unit数     | 新しいレプリカのUnit数を選択します。詳細については、[テナントの作成](../300.create-a-tenant.md)のUnit数の説明を参照してください。   |

6. **<UI-TERM key="ocp-v2.component.TagFilterDropDown.Ok">確定</UI-TERM>** をクリックすると、レプリカの追加操作が完了します。
