# レプリカの変更

このセクションでは、OCP上でテナントのレプリカ情報を変更する方法について説明します。このセクションを参考に、指定されたレプリカを変更したり、複数のレプリカを一括して変更したりできます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
* テナントの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

## 注意事項

テナントのレプリカ情報を変更する前に、以下の点にご注意ください：

* **レプリカタイプの変更について**

  * レプリカタイプが <b>読み取り専用カラムストア型レプリカ</b> の場合、他のレプリカタイプへの変更はサポートされません。レプリカタイプが <b>フル機能型レプリカ</b> または <b>読み取り専用型レプリカ</b> の場合、<b>読み取り専用カラムストア型レプリカ</b> への変更はサポートされません。
  * テナントが属するデータベースが単一マシンの場合、レプリカタイプの変更はサポートされません。
  * 複数のレプリカを一括変更する場合、レプリカタイプの変更はサポートされません。

* **ユニット仕様の変更について**

  * V4.0.0.0以降のバージョンのクラスタでは、ユニット仕様にデフォルトで制限がかかります。クラスタのデフォルト構成より小さいUnitを選択する必要がある場合、<code>__min_full_resource_pool_memory</code> パラメータを使用してユニット仕様の最小値制限を調整できます。V4.1.0.0のクラスタを例にすると、パラメータの変更手順は <a href="https://docs.oceanbase.com/oceanbase-database/V4.2.1-system-management-set-parameters">クラスタ項目設定の変更</a> を参照してください。
  * ユニット仕様の変更はパーティションレプリカの移行操作を引き起こし、OBServerのストレージI/OおよびOBServer間のネットワークトラフィックが増加します。突発的なトラフィックを制御する必要がある場合は、<code>ha_high_thread_score</code>、<code>ha_mid_thread_score</code> のパラメータ値を変更するか、バックグラウンドタスク <code>HA_HIGH</code>、<code>HA_MID</code> に対してリソース分離を行うことを推奨します。
  * Unitのスケールイン中に追加のストレージ容量が消費される可能性があります。ストレージ容量不足によるUnitスケールインの失敗を避けるため、可能な限り十分な容量を確保してください。
  * テナント内のゾーンごとのUnitのリソースを統一することを推奨します。

* **Unit数の変更について**

  * テナントが属するデータベースが単一マシンの場合、Unit数の変更はサポートされません。
  * テナントが属するクラスタのバージョンが以下の場合、テナントで非対称ゾーンが有効になっていることを確認してください。
    * [V4.2.5.5, V4.3.0.0)
    * [V4.4.2.0, V4.5.0.0)
  * 同一テナント内で、すべてのフル機能型レプリカに対して最大でも2種類の異なるUnit数のみを構成できます。
  * テナントが属するクラスタがV4.2.0.0以上のバージョンで、かつテナントパラメータ `enable_rebalance` がfalseの場合、ゾーンのUnit数を変更することはできません。
  * Unit数の一括変更はすべてのゾーンのUnit数に影響します。慎重に操作してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. **<UI-TERM key="ocp-v2.Tenant.Detail.CopyDetails">レプリカの詳細</UI-TERM>** モジュールでは、以下の操作を実行できます：

   * 指定したゾーンの操作列にある **<UI-TERM key="ocp-v2.TrendAndOutline.SQLLimit.Modify">修正</UI-TERM>** をクリックし、現在のゾーンの **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.ReplicaType">レプリカタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.DeleteUnitModal.UnitSpecifications">ユニット仕様</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.ModifyResourcePoolModal.UnitQuantity">ユニット数</UI-TERM>** を変更します。変更後、**<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Save">保存する</UI-TERM>** をクリックします。
   * 右上の **<UI-TERM key="ocp-v2.Detail.Component.BatchModifyUnitModal.BatchModification">一括修正</UI-TERM>** をクリックし、表示されたダイアログで、テナント内のすべてのゾーンの **<UI-TERM key="ocp-v2.Detail.Component.ModifyResourcePoolModal.UnitSpecification">ユニット仕様</UI-TERM>** と **<UI-TERM key="ocp-v2.Detail.Component.BatchModifyUnitModal.NumberOfUnits">ユニット数</UI-TERM>** を変更します。変更後、**<UI-TERM key="ocp-v2.pages.Kubernetes.Save">保存</UI-TERM>** をクリックします。
