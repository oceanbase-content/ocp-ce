# 統計情報タスクの管理

このセクションでは、統計情報タスクを管理する方法について説明します。

## 前提条件

* 統計情報タスクを表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsManagement">統計情報管理</UI-TERM>** メニュー権限。

* 統計情報タスクをキャンセルする場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.src.hook.useMenu.StatisticsManagement">統計情報管理</UI-TERM>** メニュー権限。

* 統計情報タスクのキャンセルは、OceanBase V4.2.2以降のバージョンでのみサポートされます。

## 統計情報タスクの表示

**<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsTask">統計情報タスク</UI-TERM>** テーブルは、過去30日間のタスク情報のみを保持します。有効期間内にご確認いただくことをお勧めします。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ParameterTemplate.Tenant">テナント</UI-TERM>** を選択します。システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.StatisticsManagement">統計情報管理</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsManagement">統計情報管理</UI-TERM>** の概要ページに移動します。

5. **<UI-TERM key="ocp-v2.Detail.Statistics.StatisticsTask">統計情報タスク</UI-TERM>** モジュールで、右上の **<UI-TERM key="ocp-v2.Detail.Statistics.AutomaticStatistics">自動統計</UI-TERM>** と **<UI-TERM key="ocp-v2.Detail.Statistics.ManualStatistics">手動統計</UI-TERM>** タブを切り替えることで、異なるタイプの統計情報タスクリストを表示できます。

## その他の操作

* **<UI-TERM key="ocp-v2.Detail.Optimize.Status">ステータス</UI-TERM>** で統計情報タスクをフィルタリングできます。タスクの状態は **<UI-TERM key="ocp-v2.src.constant.backup.Canceled">キャンセル済み</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Information.Completed">完了済み</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Statistics.utils.Running">実行中</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.package.Failed">失敗</UI-TERM>** です。

* **<UI-TERM key="ocp-v2.page.Information.Running">実行中</UI-TERM>** の統計情報タスクをキャンセルできます。
