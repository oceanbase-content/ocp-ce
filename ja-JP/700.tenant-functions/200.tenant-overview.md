# テナント概要の表示

テナントは論理的な概念であり、OceanBaseではリソース割り当ての単位であり、データベースオブジェクト管理とリソース管理の基盤となります。システム運用保守、特にクラウドデータベースの運用保守において重要な影響を与えます。

OCPにログインした後、左側のナビゲーションバーでテナントをクリックすると、テナント概要ページに移動します。このページには、ログインユーザーが閲覧権限を持つテナントリスト、テナントモニタリングのトップ5情報がデフォルトで表示され、同時にテナント関連の管理操作も実行できます。詳細については、[Unit仕様の管理](1660.ocp-resource-unit-specifications.md)、[テナントの作成](../500.quickstart/600.quickstart-create-a-tenant.md)、[テナントのロック](600.manage-a-tenant/300.locked-a-tenant.md)、[テナントのクローン](600.manage-a-tenant/350.clone-a-tenant.md)を参照してください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っている場合にのみ、テナント概要データを表示できます：

* **クラスタ読み取り専用**または**テナント読み取り専用**リソース権限。
* テナントの**<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>**メニュー権限。

## テナントリスト

**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**では、**テナント名、テナントID、所属クラスタ、タグ、OceanBaseバージョン番号、テナントモード、Zone優先順位、読み取り専用、ロック、作成日時、状態**、および**<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.Operation">操作</UI-TERM>**などの情報を確認できます。ここでは、テナント名を複数選択して一括検索でき、各テナント名はスペースで区切られます。

* テナント名をクリックすると、そのテナントの概要ページに移動します。詳細については、[テナント詳細ページの概要](600.manage-a-tenant/100.overview-of-the-tenant-details-page.md)を参照してください。

* テナントIDの右側にあるコピーボタンをクリックすると、テナントIDをコピーできます。

* カーソルをテナントのプライマリ/スタンバイアイコンに合わせると、ポップアップウィンドウでプライマリ/スタンバイテナントの情報を確認できます。**<UI-TERM key="ocp-v2.src.component.TenantLabel.MasterSlaveRelationshipTopology">プライマリ/スタンバイ関係のトポロジー図</UI-TERM>**をクリックすると、トポロジーページに移動し、トポロジー上で現在のテナントの詳細なプライマリ/スタンバイ情報を確認できます。詳細については、[テナント関係トポロジーの表示](900.manage-tenant-topulogy/200.view-primary-standby-tenants-topology.md)を参照してください。

* カーソルをテナントのタグに合わせると、そのテナントのすべてのタグ情報を確認できます。編集アイコンをクリックしてタグを管理できます。操作の詳細については、[タグの管理](../1600.system-management-features/300.manage-tags/100.tags-overview.md)を参照してください。

* テナント名の右側にあるコピーボタンをクリックすると、テナント名をコピーできます。

* **<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.BelongsCluster">所属クラスタ</UI-TERM>**のソート操作をサポートしています。クラスタ名をクリックすると、クラスタテナント管理ページに移動します。詳細については、[クラスタ詳細ページの概要](../600.cluster-functions/300.manage-a-cluster/200.overview-of-the-cluster-details-page.md)を参照してください。

* テナントが運用保守状態にある場合、**操作列**の**<UI-TERM key="ocp-v2.page.Welcome.ViewTasks">タスクを確認する</UI-TERM>**ボタンをクリックすると、テナント運用保守のタスク詳細ページに移動します。タスク詳細ページでは、タスクログの表示、ロールバック、再試行などの操作を実行できます。詳細については、[タスクの管理](../1600.system-management-features/600.manage-tasks.md)を参照してください。

## テナントモニタリングトップ5

テナントモニタリングモジュールでは、直近1時間、1日、または1週間の**QPS、TPS、応答時間、トランザクション応答時間、セッション数、イベント待機回数、イベント待機時間**、および**容量_テーブル数**を確認できます。

右上のアイコンをクリックすると拡大でき、モニタリング期間もカスタマイズできます。

![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1912730261/p265457.png)

|   モニタリング項目    |                          説明                           |
|----------|-------------------------------------------------------|
| QPS      | 1秒間に処理されるSQL文の平均数 (times/s)                              |
| TPS      | 1秒間に処理されるトランザクションの平均数 (times/s)                                   |
| 応答時間 | SQL応答時間 (μs)                                         |
| トランザクション応答時間   | サーバー側での各トランザクションの平均処理時間 (μs)                                    |
| セッション数      | 現在のセッション数(個)と現在アクティブなセッション数(個)を含みます。データソース：__all_virtual_processlist |
| イベント待機回数  | 1秒間にイベントを待機する平均回数 (times/s)                                   |
| イベント待機時間  | 待機中の各イベントの平均待機時間 (μs)                                    |
| 容量_テーブル数   | テーブル数                                                   |
