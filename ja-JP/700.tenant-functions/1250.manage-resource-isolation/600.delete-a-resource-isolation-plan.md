# リソース分離計画の削除

ビジネス上、特定のリソース分離計画が不要になった場合、その計画を削除できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">リソースの隔離</UI-TERM>** メニュー権限。

* リソース分離機能はCgroupに依存しています。テナントが属するクラスタでCgroupを有効にしておいてください。
* リソース分離計画が作成済みであること。
* 削除対象のリソース分離計画が有効ではないこと。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.AuditEvent.Tenant">テナント</UI-TERM>** を選択します。システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側に表示されるナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">リソースの隔離</UI-TERM>** をクリックし、そのテナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔離計画</UI-TERM>** ページに移動します。

5. 削除するリソース分離計画を選択し、その計画のページで、右側の **<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Delete">削除</UI-TERM>** ボタンをクリックします。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>削除操作は計画本体のみに関わり、計画と制限は同期して削除されますが、リソースグループ名とルールは保持されます。</p>
    </main>

6. ダイアログボックスで **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.Ok">確定</UI-TERM>** をクリックします。
