# リソース分離計画の作成

テナントのリソース分離を詳細に設定する必要がある場合、OCPは視覚的な方法でテナントのリソースを分離・分割する機能を提供します。システムは設定されたリソース分離計画に従ってリソースを対応するリソースグループに割り当て、テナントリソースの管理複雑さを低減します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">リソースの隔離</UI-TERM>** メニュー権限。

* リソース分離機能はCgroupに依存しています。テナントが属するクラスタでCgroupを有効にしておいてください。
* リソース分離計画の作成は、OceanBase V4.1以降のバージョンでのみサポートされています。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.MetricChart.DrilldownDrawer.SubDrilldownDrawer.Tenant">テナント</UI-TERM>** を選択します。システムはデフォルトで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 左側に表示されるナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">リソースの隔離</UI-TERM>** をクリックし、そのテナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔離計画</UI-TERM>** ページに移動します。

5. **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateAnIsolationPlan">隔離計画を作成する</UI-TERM>** ボタンをクリックし、**<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.CreateAResourceIsolationPlan">リソース隔離計画の作成</UI-TERM>** ページに移動します。

6. **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.PlanName">計画名称</UI-TERM>** および **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.Description">備考</UI-TERM>** などの計画の基本情報を入力します。

    |  パラメータ  |  説明   |
    |--------|---------|
    |  計画名      |  リソース分離計画の名前を指定します。英字、数字、アンダースコアの組み合わせが可能で、長さは2～24文字です。       |
    |  説明          |  （オプション）リソース分離計画の備考情報を設定します。任意の文字をサポートし、長さは1000文字以内です。       |

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E8%B5%84%E6%BA%90%E9%9A%94%E7%A6%BB%E8%AE%A1%E5%88%92.png)

    **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step1.NextStep">次のステップ</UI-TERM>** をクリックします。

7. リソース分離計画にリソースグループを選択します。

    **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupConfig.SelectGroupName.ResourceGroupName">リソースグループ名</UI-TERM>** から既に作成済みの **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceGroup">リソースグループ</UI-TERM>** を選択すると、システムは下部にそのリソースグループのリソース分離方式およびマッチングルール情報を自動的に入力します。リソースグループの重複選択はサポートされておらず、各リソースグループは1つのリソース分離計画にのみ適用されます。

    * テナントにリソースグループが作成されていない場合、**<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.ResourceGroupName">リソースグループ名</UI-TERM>** 内の **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.CreateAResourceGroup">リソースグループを新規作成</UI-TERM>** をクリックして、テナントに新しいリソースグループを作成できます。操作の詳細については、[リソースグループの作成](200.create-a-resource-group.md)を参照してください。
    * **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.AddAResourceGroup">リソースグループの追加</UI-TERM>** をクリックすると、このリソース分離計画に複数のリソースグループを設定できます。
    * リソースグループの右上にある削除アイコンをクリックすると、そのリソースグループをリソース分離計画から削除できます。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E8%B5%84%E6%BA%90%E7%BB%84%E9%85%8D%E7%BD%AE.png)

    **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.NextStep">次のステップ</UI-TERM>** をクリックします。

8. リソースグループのリソース分離制限を設定します。

    |  パラメータ  |  説明   |
    |--------|---------|
    |  CPU上限      |  （オプション）UTILIZATION_LIMIT：リソースグループが使用するCPUリソースの上限を指定します。このパラメータのデフォルト値は100で、取り得る範囲は[0, 100]です。IOPS下限はIOPS上限を超えてはなりません       |
    |  CPU重み      |  （オプション）MGMT_P1：システムがフル負荷の状態で、このリソースグループに割り当てることを約束するCPUの割合を指定します。デフォルト値は100です。 </br> 計算方法：現在のMGMT_P1設定値 × 100 / 現在の分離計画におけるすべてのリソースグループのMGMT_P1設定値の合計。      |
    |  IOPS下限      |  （オプション）MIN_IOPS：I/O競合が発生した場合に、リソースグループが予約するIOPSリソースです。合計は100を超えてはならず、デフォルト値は0です。このリソースグループで設定可能な最大値は他のリソースグループの影響を受けます。<ul><li>テナント内のすべてのリソースグループのIOPS仕様が同じ場合、このリソースグループが予約するIOPSの統一値のみが表示されます。</li><li>テナント内のすべてのリソースグループのIOPS仕様が異なる場合、このリソースグループの異なるゾーンごとに予約されたIOPS値が表示されます。</li></ul>       |
    |  IOPS上限      |  （オプション）MAX_IOPS：リソースグループが使用できる最大IOPSリソースを指定するために使用されます。合計は100を超えることができ、デフォルト値は100です。<ul><li>テナント内のすべてのリソースグループのIOPS仕様が同じ場合、このリソースグループが使用できる最大IOPSの統一値のみが表示されます。</li><li>テナント内のすべてのリソースグループのIOPS仕様が異なる場合、このリソースグループの異なるゾーンごとに使用できる最大IOPS値が表示されます。</li></ul> <main id="notice" type='notice'><h4>注意</h4><p>IOPS上限はIOPS下限よりも大きくする必要があります。</p></main>      |
    |  IOPS重み      |  （オプション）WEIGHT_IOPS：IOPSの重み値を指定するために使用されます。すべてのリソースグループの予約IOPSを満たす前提の下で、このリソースグループが追加で割り当てられるIOPSの割合を指定します。合計は100を超えることができ、デフォルト値は0です。<br>計算方法：現在のWEIGHT_IOPS設定値 × 100 / 現在の分離計画におけるすべてのリソースグループのWEIGHT_IOPS設定値の合計。      |

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>重みの計算は他のリソースグループの設定の影響を受け、動的に変化します。</p>
    </main>

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E8%B5%84%E6%BA%90%E9%9A%94%E7%A6%BB%E9%99%90%E5%88%B6.png)

    **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.NextStep">次のステップ</UI-TERM>** をクリックします。

9. 設定を確認します。

    設定したリソース分離計画の情報が正しいかどうか確認し、**<UI-TERM key="ocp-v2.Detail.Component.FailoverStandbyTenantModal.Ok">確定</UI-TERM>** をクリックして送信します。
