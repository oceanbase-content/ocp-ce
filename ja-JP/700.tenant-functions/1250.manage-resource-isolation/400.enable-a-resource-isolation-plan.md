# リソース分離計画の有効化/無効化

リソースグループにリソース分離計画を作成した後、その計画を有効化することでリソース分離が実際に適用されます。有効化されると、テナント内のリソース割り当ては選択したリソース分離計画の設定に従います。不要になった場合は、その計画を無効化できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**または**テナントメンテナンス**のリソース権限。
  * テナントの**<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">リソースの隔離</UI-TERM>**メニュー権限。

* リソース分離機能はCgroupに依存しているため、まずテナントが属するクラスタでCgroupを有効にしてください。
* テナントにリソース分離計画が作成されていること。
* 1つのテナントで有効化できるリソース分離計画は1つのみです。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.Overview.Tenant">テナント</UI-TERM>**を選択すると、システムはデフォルトで**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>**で操作対象のテナントを選択し、その名前をクリックして、テナントの**<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。

4. 左側に表示されるナビゲーションバーで**<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">リソースの隔離</UI-TERM>**をクリックすると、そのテナントの**<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔離計画</UI-TERM>**ページに移動します。

5. 分離計画を有効化するには、以下の2つの方法があります。

    * 方法1：

        テナントで有効なリソース分離計画がない場合、ページのヒントテキストにある**<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.EnableResourceIsolationPlan">リソース分離プランの有効化</UI-TERM>**をクリックし、ポップアップの**<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.ResourceIsolationPlan">リソース分離プラン</UI-TERM>**ドロップダウンリストから有効にしたい計画を選択し、**<UI-TERM key="ocp-v2.Detail.Monitor.Determine">確定</UI-TERM>**をクリックします。

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E5%90%AF%E7%94%A8%E9%9A%94%E7%A6%BB%E8%AE%A1%E5%88%92.png)

    * 方法2：

        有効化したい計画のページに移動し、右側の**<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.Enable">有効にする</UI-TERM>**ボタンをクリックします。表示されたダイアログで**<UI-TERM key="ocp-v2.Monitor.AddMonitor.MetricTable.Ok">確定</UI-TERM>**をクリックします。

        ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E5%90%AF%E7%94%A8%E8%AE%A1%E5%88%92.png)

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>既に古いリソース分離計画が有効な状態で新しい計画を有効にすると、テナント内のリソース割り当ては新しい計画の設定に従うようになり、古い計画は無効になります。</p>
    </main>

6. リソース分離計画がテナントに適用されなくなった場合、**<UI-TERM key="ocp-v2.ResourceManager.ResourcePlanTab.Disable">無効化</UI-TERM>**機能を使用してそのリソース分離を停止できます。
