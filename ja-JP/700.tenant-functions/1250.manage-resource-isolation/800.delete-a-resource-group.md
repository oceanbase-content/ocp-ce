# リソースグループの削除

ビジネス上、特定のリソースグループによるリソース分離が不要になった場合、このセクションを参照してそのリソースグループを削除できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">リソースの隔離</UI-TERM>** メニュー権限。

* リソース分離機能はCgroupに依存しています。テナントが属するクラスタでCgroupを有効にしておいてください。
* テナントに対してリソースグループが作成済みであること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.UpgradeArbitrationGroup.Tenant">テナント</UI-TERM>** を選択します。システムはデフォルトで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 左側に表示されたナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">リソースの隔離</UI-TERM>** をクリックし、そのテナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔離計画</UI-TERM>** ページに移動します。

5. **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceGroup">リソースグループ</UI-TERM>** タブをクリックします。

6. 変更するリソースグループを選択し、**<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Delete">削除</UI-TERM>** をクリックします。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>リソースグループが既にリソース分離計画で使用されている場合、リソースグループを削除すると、リソース分離計画はそのリソースグループを使用してテナントのリソース使用を制限できなくなります。</p>
    </main>

7. **<UI-TERM key="ocp-v2.Detail.Component.SwitchoverModal.Determine">確定</UI-TERM>** をクリックします。
