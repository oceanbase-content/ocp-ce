# リソース分離計画の変更

リソース分離計画の設定を再調整する必要がある場合は、このセクションを参照してリソース分離計画の情報を変更できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolation">リソースの隔離</UI-TERM>** メニュー権限。

* リソース分離機能はCgroupに依存しています。テナントが属するクラスタでCgroupを有効にしておいてください。
* リソース分離計画が既に作成されていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側に表示されたナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.ResourceIsolation">リソースの隔離</UI-TERM>** をクリックすると、そのテナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔離計画</UI-TERM>** ページに移動します。

5. 変更するリソース分離計画を選択し、その計画のページで右側の **<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.Editing">編集</UI-TERM>** ボタンをクリックします。

    計画内の **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceGroup">リソースグループ</UI-TERM>** および **<UI-TERM key="ocp-v2.Detail.ResourceManager.CreateResourcePlan.ResourceIsolationLimits">リソース隔離制限</UI-TERM>** の情報を変更できます。具体的な設定方法については、[リソース分離計画の作成](300.create-a-resource-isolation-plan.md)を参照してください。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E7%BC%96%E8%BE%91%E8%B5%84%E6%BA%90%E9%9A%94%E7%A6%BB%E8%AE%A1%E5%88%92.png)

6. **<UI-TERM key="ocp-v2.Detail.Component.Event.Determine">確定</UI-TERM>** をクリックします。
