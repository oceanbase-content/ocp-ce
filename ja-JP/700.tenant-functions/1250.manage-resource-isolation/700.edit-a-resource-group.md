# リソースグループの変更

リソースグループ内のリソース構成情報が適用されなくなった場合、このセクションを参照してリソースグループ情報を変更できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">リソースの隔離</UI-TERM>** メニュー権限。

* リソース分離機能はCgroupに依存しています。テナントが属するクラスタでCgroupを有効にしておいてください。
* テナントに対してリソースグループが作成済みであること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ZoneFormCardList.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で、操作対象のテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側に表示されたナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceIsolation">リソースの隔離</UI-TERM>** をクリックすると、そのテナントの **<UI-TERM key="ocp-v2.Detail.ResourceManager.QuarantinePlan">隔離計画</UI-TERM>** ページに移動します。

5. **<UI-TERM key="ocp-v2.Detail.ResourceManager.ResourceGroup">リソースグループ</UI-TERM>** タブをクリックします。

6. 変更するリソースグループを選択し、**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Modify">修正</UI-TERM>** をクリックします。

    リソースグループの **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.ResourceIsolationMethod">リソース分離方式</UI-TERM>** および対応するリソース分離内容を変更できます。具体的な設定については、[リソースグループの作成](200.create-a-resource-group.md)を参照してください。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/420/%E7%BC%96%E8%BE%91%E8%B5%84%E6%BA%90%E7%BB%84.png)

7. **<UI-TERM key="ocp-v2.component.OperationConfig.ModifyParameterDrawer.Submit">送信</UI-TERM>** をクリックします。
