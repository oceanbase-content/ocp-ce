# ユニット仕様の管理

テナント概要ページで「ユニット仕様管理」をクリックすると、新規ユニット仕様の追加、仕様の変更、仕様の削除を行えます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**または**テナントメンテナンス**リソース権限。
* テナントの**<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>**メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.src.constant.plan.Tenant">テナント</UI-TERM>**を選択すると、システムはデフォルトで**<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.Tenant.New.UnitSpecifications">ユニット仕様</UI-TERM>**タブに切り替えて、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.UnitList">ユニット仕様リスト</UI-TERM>**ページに入ります。

   **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.UnitList">Unit リスト</UI-TERM>**では、すべてのユニットの**<UI-TERM key="ocp-v2.Tenant.UnitSpec.Specification">仕様名</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.CpuCores">CPUコア数</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.MemoryGb">メモリ（GiB）</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.LogDiskGb">ログディスク（GiB）</UI-TERM>**、**IOPS**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.Type">仕様タイプ</UI-TERM>**、および**<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Operation">操作</UI-TERM>**情報を確認できます。

   * **<UI-TERM key="ocp-v2.Host.Detail.Basic.CpuCores">CPU コア数</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.MemoryGb">メモリ（GiB）</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.LogDiskGb">ログディスク（GiB）</UI-TERM>**、**IOPS**のサイズで仕様を並べ替えることができます。

   * **<UI-TERM key="ocp-v2.Tenant.UnitSpec.Type">仕様タイプ</UI-TERM>**で仕様をフィルタリングできます。仕様タイプには**<UI-TERM key="ocp-v2.src.constant.oceanbase.Default">システムデフォルト</UI-TERM>**と**<UI-TERM key="ocp-v2.Monitor.AddMonitor.CollectTable.Custom">カスタマイズ</UI-TERM>**が含まれます。

   * 操作には以下のものが含まれます：**<UI-TERM key="ocp-v2.Auth.User.Editing">編集</UI-TERM>**と**<UI-TERM key="ocp-v2.component.ZoneFormCardList.Delete">削除</UI-TERM>**。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><ul><li>テナントが属するクラスタがV4.0未満のバージョンの場合、<b>ログディスク(GiB)</b>列および<b>IOPS</b>列の表示や変更はサポートされません。</li><li>テナントが属するクラスタがAIクラスタ(共有ストレージ形態)の場合、ユニット仕様リストには<b>キャッシュディスク(GiB)</b>(DATA_DISK_SIZE)と<b>最大ネットワーク帯域幅</b>(MAX_NET_BANDWIDTH)列が追加で表示されます。</li></ul></p>
    </main>

   <!-- ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/unit%E8%A7%84%E6%A0%BC%E5%88%97%E8%A1%A8.png) -->

4. **<UI-TERM key="ocp-v2.Tenant.UnitSpec.NewUnitSpecifications">ユニット仕様を追加</UI-TERM>**をクリックし、**仕様名、CPU(コア)**、および**<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.MemoryGb">メモリ（GiB）</UI-TERM>**を入力します。

   各パラメータの説明は以下のとおりです。

   |  パラメータ  |  説明  |
   |--------|--------|
   |  シナリオ名  |  追加するユニット仕様名を入力します。   |
   |  CPU  |  ユニット仕様のCPU(コア)数を設定します。CPUの最小構成コア数は0.5コアなので、0.5の整数倍を入力してください。<br>テナントが属するクラスタがV4.0以上のバージョンの場合、**<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.AdvancedCpuSettings">CPUの詳細設定</UI-TERM>**を通じてCPUオーバーコミットを割り当てることができます。詳細設定を有効にすると、最小CPU(コア)数と最大CPU(コア)数を個別に設定できます。<main id="notice" type='explain'><h4>説明</h4><p>テナントが属するクラスタがV4.0以上のバージョンの場合、1C未満のCPU仕様を選択することはできません。</p></main>   |
   |  メモリ  |  ユニット仕様のメモリ(GiB)を設定します。メモリの最小構成サイズは1GiBなので、1の整数倍を入力してください。   |
   |  設定の詳細(オプション)  | **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.LogDiskGb">ログディスク（GiB）</UI-TERM>**、**<UI-TERM key="ocp-v2.Tenant.UnitSpec.DataStorageCapacity">データストレージクォータ</UI-TERM>**、および**IOPS**の設定情報を入力します。<main id="notice" type='explain'><h4>説明</h4><p><ul><li>テナントが属するクラスタがV4.0未満のバージョンの場合、<b>ログディスク(GiB)</b>と<b>IOPS</b>の設定はサポートされません。</li><li>テナントが属するクラスタがAIクラスタ(共有ストレージ形態)の場合、<b>キャッシュディスク(GiB)</b>(DATA_DISK_SIZE、デフォルト値はメモリの2倍、最小値はmax(2G, メモリサイズ))、<b>最大ネットワーク帯域幅</b>(MAX_NET_BANDWIDTH)、および<b>ネットワーク帯域幅重み</b>(NET_BANDWIDTH_WEIGHT)を追加で設定できます。</li></ul></p></main>   |
