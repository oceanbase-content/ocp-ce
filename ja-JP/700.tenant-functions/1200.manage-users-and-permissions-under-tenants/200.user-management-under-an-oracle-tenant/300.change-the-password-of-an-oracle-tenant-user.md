# Oracleテナントユーザーのパスワードを変更する

このページでは、Oracleテナントのユーザーパスワードを変更する手順について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community EditionはMySQLテナントのみを提供します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Auth.User.New.UserManagement">ユーザー管理</UI-TERM>** メニュー権限。

* Oracleテナントのユーザーパスワードを変更できるのは、プライマリテナントのみです。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Tenant">テナント</UI-TERM>** を選択します。システムはデフォルトで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** で、操作対象のOracleテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.UserManagement">ユーザー管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.User.MySQL.UserList">ユーザー一覧</UI-TERM>** ページで、パスワードを変更するユーザーを選択し、操作列の **...** で **<UI-TERM key="ocp-v2.src.component.ModifyUserPasswordModal.ChangePassword">パスワードの変更</UI-TERM>** をクリックします。

6. ポップアップウィンドウで新しいパスワードを入力し、確認のため再入力します。

7. **<UI-TERM key="ocp-v2.component.TagFilterDropDown.Ok">確定</UI-TERM>** をクリックします。
