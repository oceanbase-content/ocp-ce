# Oracleテナントユーザー概要

ユーザー管理では、現在のOracleテナントのユーザーリストとロールリストを表示する機能が提供されます。

<main id="notice" type='notice'>
<h4>適用対象</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community EditionはMySQLテナントのみを提供します。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っている場合にのみ、Oracleテナントのユーザーリスト情報とロールリスト情報を表示できます：

* **クラスタ読み取り専用**または**テナント読み取り専用**リソース権限。
* テナントの**<UI-TERM key="ocp-v2.User.MySQL.UserManagement">ユーザー管理</UI-TERM>**メニュー権限。

## ユーザーリスト情報

ユーザーとは、データベースで定義された、オブジェクトへの接続とアクセスを許可された名前です。**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.UserList">ユーザー一覧</UI-TERM>**タブで、**ユーザー名、システム権限の所有、アクセス可能なオブジェクト、所有ロール、作成日時**、**<UI-TERM key="ocp-v2.User.Oracle.UserList.LogonConnectionString">ログイン接続文字列</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Overview.Status">ステータス</UI-TERM>**などの情報を確認できます。また、ユーザーに対して**ロック、パスワードの変更**、**<UI-TERM key="ocp-v2.Detail.Overview.Delete">削除</UI-TERM>**などの操作もサポートされています。

|   パラメータ   |                                                                              説明                                                                               |
|--------|---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| ユーザー名    | ユーザー作成時にカスタマイズした名前。数字(0～9)、大文字(A～Z)、小文字(a～z)、アンダースコア(\_)、ハイフン(-)を含むことができ、長さは2～64文字です。この列のユーザー名をクリックするとユーザー詳細ページに移動します。詳細については[ユーザー情報の管理](../200.user-management-under-an-oracle-tenant/600.manage-users-information.md)を参照してください。                              |
| システム権限の所有 | そのユーザーが持つユーザー権限です。詳細については[システム権限一覧](../300.system-privileges-in-a-mysql-tenant.md)を参照してください。                                                                                        |
| アクセス可能なオブジェクト | ロール作成後に追加できます。詳細については[ロール情報の管理](../200.user-management-under-an-oracle-tenant/700.manage-roles-information.md)を参照してください。                                                                                        |
| 所有ロール   | そのユーザーが持つロールです。詳細については[Oracleテナントロールの作成](../200.user-management-under-an-oracle-tenant/500.create-a-role-under-an-oracle-tenant.md)を参照してください。                                                                                  |
| 作成日時   | ユーザー作成時の時間です。                                                                                                                                                     |
| ログイン接続文字列  | ログイン接続文字列をコピーできます。                                                                                                                                                 |
| ロック     | ユーザーのロックおよびロック解除操作を行えます。SYSユーザーはロック操作をサポートしません。                                                                                                                               |
| 操作     | sysユーザー以外のユーザーに対して、パスワードの変更や削除などの操作を行えます。詳細については[Oracleテナントユーザーのパスワード変更](300.change-the-password-of-an-oracle-tenant-user.md)、[Oracleテナントユーザーの削除](400.delete-an-oracle-tenant-user.md)を参照してください。 |

## ロールリスト情報

ロールは、システム権限とオブジェクト権限の組み合わせです。ロールには他のロールを含めることもできます。1人のユーザーに複数のロールを付与でき、1つのロールを複数のユーザーに割り当てることもできます。

**<UI-TERM key="ocp-v2.User.Oracle.RoleList">ロール一覧</UI-TERM>**タブで、**ロール名、システム権限の所有、所有ロール、アクセス可能なオブジェクト、以下のロールとオブジェクトによって参照されている**、**<UI-TERM key="ocp-v2.component.ParameterTemplate.LastModificationTime">最終更新日時</UI-TERM>**などの情報を確認できます。また、ユーザーに対して**<UI-TERM key="ocp-v2.Component.OBServerList.Delete">削除</UI-TERM>**操作を行うこともできます。

|     パラメータ     |                                     説明                                      |
|------------|-----------------------------------------------------------------------------|
| ロール名        | ロール名をクリックすると、ロール管理ページに移動します。詳細については[ロール情報の管理](700.manage-roles-information.md)を参照してください。 |
| システム権限の所有     | ロール作成時に設定した権限です。変更が必要な場合の詳細については[ロール情報の管理](700.manage-roles-information.md)を参照してください。 |
| 所有ロール       | そのロールに含まれる他のロールです。                                                                |
| アクセス可能なオブジェクト      | ロール作成後に追加できます。詳細については[ロール情報の管理](700.manage-roles-information.md)を参照してください。       |
| 以下のロールとユーザーによって参照されている | そのロールを使用しているユーザーとロールを表示します。                                                             |
| 操作         | デフォルトロール以外のロールに対して、削除などの操作を行えます。                                                          |
