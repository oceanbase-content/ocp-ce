# ロール情報の管理

このページでは、ロールのシステム権限の変更、ロールの変更、アクセス可能なオブジェクトの追加に関する操作方法を説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community EditionはMySQLテナントのみを提供します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Auth.User.New.UserManagement">ユーザー管理</UI-TERM>** メニュー権限。

* ロール管理権限はプライマリテナントのみが持ちます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で、操作対象のOracleテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Auth.UserManagement">ユーザー管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.RoleList">ロールリスト</UI-TERM>** タブを選択し、**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.RoleList">ロールリスト</UI-TERM>** ページに移動します。

6. **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.RoleList">ロールリスト</UI-TERM>** 内で操作対象のロール名をクリックし、ロールの詳細ページに移動します。

   この詳細ページでは、以下の操作を実行できます：

   1. ロールのシステム権限の変更：**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.ModifySystemPermissions">システム権限の変更</UI-TERM>** をクリックし、ポップアップウィンドウで権限を変更します。

   2. ロールに付与するロールの変更：**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.ModifyARole">ロールの変更</UI-TERM>** をクリックし、ポップアップウィンドウでロールを選択します。

   3. ロールにアクセス可能なオブジェクトの追加：**<UI-TERM key="ocp-v2.Oracle.Component.AddObjectPrivilegeDrawer.AddObjects">オブジェクトの追加</UI-TERM>** をクリックし、ポップアップウィンドウで以下の情報を選択します：

      |  パラメータ  |       説明     |
      |------|-----------|
      | オブジェクトタイプ | 選択可能：**<UI-TERM key="ocp-v2.src.constant.tenant.Table">テーブル</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.tenant.View">ビュー</UI-TERM>**、**<UI-TERM key="ocp-v2.Oracle.Component.DbObjectTreeSelect.StoredProcedure">ストアドプロシージャ</UI-TERM>**。一度に1種類のタイプしか選択できないため、複数のタイプのオブジェクトを追加する場合は、複数回に分けて追加する必要があります。  |
      | オブジェクト     | 他のユーザーのオブジェクトを選択すると、現在のユーザーはその他のユーザーのオブジェクトにアクセスできるようになります。`ユーザー名.オブジェクト名`（例：`schemaname.tablename`）の形式で、複数のオブジェクトを入力ボックスに一括貼り付けることができます。半角カンマで区切ります。<ul><li>オブジェクトを選択する際、既に追加されたアクセスオブジェクトはフィルタリングされ、追加されていないアクセスオブジェクトのみを選択できます。</li><li>一度に1種類のタイプしか選択できないため、複数のタイプのオブジェクトを追加する場合は、複数回に分けて追加する必要があります。</li></ul> |
      | 権限の付与 | 必要な権限を選択します。詳細については、[システム権限リスト](../300.system-privileges-in-a-mysql-tenant.md)を参照してください。     |

   4. アクセス可能なオブジェクトの削除：**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.AccessibleObjects">アクセス可能なオブジェクト</UI-TERM>** リストで、削除対象のオブジェクトを選択し、操作列の **<UI-TERM key="ocp-v2.src.constant.iam.Delete">削除</UI-TERM>** をクリックします。または、削除対象の複数のオブジェクトを選択し、**<UI-TERM key="ocp-v2.Tenant.Detail.BatchDelete">一括削除</UI-TERM>** をクリックすると、対応するアクセス可能なオブジェクトが削除されます。

      <main id="notice" type='notice'>
      <h4>注意</h4>
      <p>アクセス可能オブジェクトを削除すると、そのユーザーは削除されたオブジェクトに対するアクセス操作ができなくなります。</p>
      </main>

   5. オブジェクト権限の変更：**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.AccessibleObjects">アクセス可能なオブジェクト</UI-TERM>** リストで、削除するオブジェクトを選択し、操作列の **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeModal.ModifyPermissions">権限の変更</UI-TERM>** をクリックします。または、変更対象の複数のオブジェクトを選択し、**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.ModifyPermissions.2">権限の一括修正</UI-TERM>** をクリックすると、オブジェクトの権限を変更できます。
