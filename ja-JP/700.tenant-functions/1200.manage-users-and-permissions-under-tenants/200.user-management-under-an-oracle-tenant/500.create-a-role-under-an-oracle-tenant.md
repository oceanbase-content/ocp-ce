# Oracleテナントのロール作成

このページでは、Oracleテナントユーザーロールを新規作成する手順について説明します。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community EditionはMySQLテナントのみを提供します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**または**テナントメンテナンス**リソース権限。
  * テナントの**<UI-TERM key="ocp-v2.Auth.Role.New.UserManagement">ユーザー管理</UI-TERM>**メニュー権限。

* 主テナントのみがOracleテナントロールを新規作成する権限を持っています。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.AuditEvent.Tenant">テナント</UI-TERM>**を選択すると、システムはデフォルトで**<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**で操作対象のOracleテナントを選択し、そのテナント名をクリックして、テナントの**<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。

4. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Auth.User.New.UserManagement">ユーザー管理</UI-TERM>**をクリックします。

5. 右上の**<UI-TERM key="ocp-v2.User.Oracle.CreateARole">新しいロールを作成</UI-TERM>**をクリックし、ポップアップウィンドウに以下の情報を入力します。

   |   パラメータ   |     説明    |
   |--------|--------------|
   | ロール名    | 英字で始まり、長さが2～64文字であるようにカスタマイズできます。数字（0～9）、大文字（A～Z）、小文字（a～z）、アンダースコア（_）、ハイフン（-）を含むことができます。ロール名内の小文字はデフォルトで大文字に変換されます。 |
   | システム権限の所有 | オプションです。[システム権限一覧](../300.system-privileges-in-a-mysql-tenant.md)を参照してください。      |
   | ロールの所有   | オプションです。  |

6. **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Submit">送信</UI-TERM>**をクリックします。作成が成功すると、ロールリストで確認できます。
