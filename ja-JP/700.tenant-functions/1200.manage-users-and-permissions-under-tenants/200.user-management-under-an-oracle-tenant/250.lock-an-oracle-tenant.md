# Oracleテナントユーザーのロック

このページでは、Oracleテナントユーザーをロックする手順について説明します。ロックされたユーザーはログインできなくなりますので、ご注意ください。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community EditionはMySQLテナントのみを提供します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **ユーザー管理** メニュー権限。

* `sys` ユーザーのロックはサポートされていません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Overview.Tenant">テナント</UI-TERM>** を選択します。システムはデフォルトで **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で、操作対象のOracleテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Iframe.UserManagement">ユーザー管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.User.Oracle.UserList">ユーザー一覧</UI-TERM>** ページで、ロックするユーザーを選択し、操作列の **...** から **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Lock">ロック</UI-TERM>** をクリックします。複数のユーザーを選択した場合は、リスト下部の **<UI-TERM key="ocp-v2.Statistics.components.StatTable.Lock">ロック</UI-TERM>** をクリックします。

6. ダイアログボックスで **<UI-TERM key="ocp-v2.User.Oracle.UserList.Determine">確定</UI-TERM>** をクリックします。
