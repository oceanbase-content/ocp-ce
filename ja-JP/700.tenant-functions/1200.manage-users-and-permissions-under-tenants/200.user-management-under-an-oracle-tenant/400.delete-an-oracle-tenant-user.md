# Oracleテナントユーザーの削除

このページでは、Oracleテナントユーザーを削除する手順について説明します。ユーザーを削除すると、そのユーザー配下のすべてのオブジェクトとデータも削除されるため、慎重に操作してください。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community EditionはMySQLテナントのみを提供します。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.Auth.User.Detail.UserManagement">ユーザー管理</UI-TERM>** メニュー権限。

* 主テナントのみがOracleテナントユーザーを削除する権限を持っています。

* システムのデフォルトユーザーの削除はサポートされていません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.component.TenantLabel.Tenant">テナント</UI-TERM>** を選択します。システムはデフォルトで **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** で操作対象のOracleテナントを選択し、そのテナント名をクリックして、テナントの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">ユーザー管理</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.User.MySQL.UserList">ユーザー一覧</UI-TERM>** ページで、削除するユーザーを選択し、操作列の **...** から **<UI-TERM key="ocp-v2.src.constant.binlog.Delete">削除</UI-TERM>** をクリックします。

6. ダイアログボックスでユーザー情報を確認し、**delete** と入力します。

7. **<UI-TERM key="ocp-v2.Detail.Database.Delete">削除</UI-TERM>** をクリックします。
