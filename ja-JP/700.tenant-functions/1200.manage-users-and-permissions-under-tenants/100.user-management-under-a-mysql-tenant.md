# MySQLテナントユーザーの管理

ユーザー管理では、現在のMySQLユーザーリストの表示、新規ユーザーの作成、ユーザーの削除、ユーザー権限の付与、ユーザー権限の取り消しなどの機能を提供します。

## 前提条件

* MySQLユーザーリスト情報を表示する場合は、OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.src.hook.useMenu.UserManagement">ユーザー管理</UI-TERM>** メニュー権限。

* 新規ユーザーの作成、ユーザーのロック、パスワードの変更、権限の変更、ユーザーの削除などの運用操作を実行する場合は、OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.Auth.Role.Detail.UserManagement">ユーザー管理</UI-TERM>** メニュー権限。

* ユーザー管理権限はプライマリテナントのみが持ちます。

* システムのデフォルトユーザーに対するロック、権限の変更、削除操作はサポートされていません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.MonitorSearch.Tenant">テナント</UI-TERM>** を選択すると、システムはデフォルトで **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.component.TenantList.TenantList">テナント一覧</UI-TERM>** で操作対象のテナントを選択し、そのテナント名をクリックすると、テナントの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動します。

4. ナビゲーションバーで **<UI-TERM key="ocp-v2.Auth.User.loginHistory.UserManagement">ユーザー管理</UI-TERM>** をクリックすると、ユーザー管理ページに移動します。

5. ユーザーリストの表示：ユーザーリストでは、**<UI-TERM key="ocp-v2.Cluster.Component.OBProxyClusterAndUserSelectUserName">ユーザー名</UI-TERM>**、**<UI-TERM key="ocp-v2.User.MySQL.AccessibleDatabases">アクセス可能なデータベース</UI-TERM>**、**<UI-TERM key="ocp-v2.User.Oracle.UserList.LogonConnectionString">ログイン接続文字列</UI-TERM>**、**<UI-TERM key="ocp-v2.components.licenseList.LicenseFilesTab.Status">ステータス</UI-TERM>**、**<UI-TERM key="ocp-v2.User.Oracle.RolesList.Operation">操作</UI-TERM>** の情報を確認できます。

6. 新規ユーザーの作成：ページの右上隅にある **<UI-TERM key="ocp-v2.User.Oracle.CreateUser">新規ユーザーの作成</UI-TERM>** をクリックします。

   1. **<UI-TERM key="ocp-v2.component.common.ObUserSelectUserName">ユーザー名</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.BinlogServerList.Hostname">ホスト名</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.New.Password">パスワード</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.ChangePasswordModal.ConfirmPassword">パスワードの確認</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.GlobalPermissions">グローバル権限</UI-TERM>**（オプション）、**<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.DatabasePermissions">データベース権限</UI-TERM>**（オプション）を入力します。

      |  パラメータ   |        説明       |
      |-------|---------|
      | ユーザー名   | 2～64文字でカスタマイズ可能です。数字（0～9）、大文字（A～Z）、小文字（a～z）、アンダースコア（_）、ハイフン（-）を含むことができます。 |
      | ホスト名   | サポートされている形式は以下のとおりですが、これらに限定されません：<ul><li> `%` 。</li><li>`localhost` 。</li><li>IPアドレス（例：`192.168.1.1`）やサブネットマスク（例：`192.168.1.%`）。</li><li>ドメイン名。</li></ul>  |
      | パスワード    | 長さは8～32文字で、少なくとも数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字（<code>~!@#%^&*_-+=\|(){}[]:;,.?/</code>）の4種類のうち3種類を含む必要があります。 |
      | パスワードの確認 | 新しいパスワードと一致している必要があります。 |
      | グローバル権限  | オプションです。[システム権限一覧](300.system-privileges-in-a-mysql-tenant.md)を参照してください。このパラメータはすべてのデータベースに適用されます。   |
      | データベース権限 | オプションです。[システム権限一覧](300.system-privileges-in-a-mysql-tenant.md)を参照してください。このパラメータは、指定したデータベース内のすべてのターゲットに適用されます。新規ユーザーがアクセスできるデータベースを選択し、**\>** アイコンをクリックしてターゲットデータベースを右側の領域に移動し、追加する権限を選択します。 |

   2. **<UI-TERM key="ocp-v2.Alarm.Rule.New.Submit">送信</UI-TERM>** をクリックして、新規ユーザーの作成を完了します。

7. ユーザーのロック：操作列 **...** の **<UI-TERM>ロックする</UI-TERM>** をクリックするか、複数のユーザーを選択して **<UI-TERM key="ocp-v2.User.MySQL.Lock">ロックする</UI-TERM>** をクリックすると、該当するユーザーがロックされます。ユーザーがロックされるとログインできなくなりますので、ご注意ください。

8. パスワードの変更：操作列 **...** の **<UI-TERM key="ocp-v2.Tenant.Detail.ChangePassword">パスワードの変更</UI-TERM>** をクリックし、ポップアップウィンドウでパスワードを変更します。

9. 権限の変更：操作列 **...** の **<UI-TERM key="ocp-v2.Oracle.Component.ModifyObjectPrivilegeModal.ModifyPermissions">権限の変更</UI-TERM>** をクリックし、ユーザーのグローバル権限とデータベース権限を変更します。

10. ユーザーの削除：操作列 **...** の **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupConfig.SelectGroupName.Delete">削除</UI-TERM>** をクリックします。ユーザーを削除すると、そのユーザーを使用している業務に影響を与える可能性がありますので、ご注意ください。
