# システム権限一覧

このページでは、システム権限の一覧を紹介します。

## MySQLテナント権限タイプ

### グローバル権限

#### 汎用権限

|  権限     |   説明                          |
|----------------|-----------------------------------------------------------|
| ALTER          | `ALTER TABLE`の権限。                                           |
| CREATE         | `CREATE TABLE`の権限。                                          |
| DELETE         | `DELETE`の権限。                                                |
| DROP           | `DROP`の権限。                                                  |
| INSERT         | `INSERT`の権限。                                                |
| SELECT         | `SELECT`の権限。                                                |
| UPDATE         | `UPDATE`の権限。                                                |
| INDEX          | `CREATE INDEX`、`DROP INDEX`の権限。                               |
| CREATE VIEW    | ビューの作成・削除権限。                                                |
| SHOW VIEW      | `SHOW CREATE VIEW`権限。                                        |
| GRANT OPTION   | `GRANT OPTION`の権限。                                          |

| PROCESS   | `PROCESS`の権限。   |

#### 管理者権限

## Oracleテナントの権限タイプ

### 汎用権限

|   権限                  |     説明                        |
|-------------------------|---------------------------|
| CREATE SESSION          | セッションを作成する権限。              |
| CREATE TABLE            | テーブルを作成する権限。              |
| CREATE VIEW             | ビューを作成する権限。           |
| CREATE PROCEDURE        | ユーザーにストアドプロシージャを作成する権限。             |
| CREATE SYNONYM          | ユーザーにシノニムを作成する権限。          |
| CREATE PUBLIC SYNONYM   | パブリックシノニムを作成する権限。         |
| DROP PUBLIC SYNONYM     | パブリックシノニムを削除する権限。       |
| CREATE SEQUENCE         | ユーザーにシーケンスを作成する権限。             |
| CREATE TRIGGER          | ユーザーにトリガーを作成する権限。             |
| CREATE TYPE             | 型を作成する権限。         |
| SHOW PROCESS            | すべてのユーザースレッドを表示する権限。 |
| CREATE DATABASE LINK    | データベースリンクを作成する権限。    |
| CREATE PUBLIC DATABASE LINK   | パブリックデータベースリンクを作成する権限。          |
| DROP DATABASE LINK      | データベースリンクを削除する権限。        |
| ALTER SESSION           | セッションを変更する権限。        |

|   権限                  |     説明                        |
|-------------------------|---------------------------|
| CREATE ANY TABLE        | 任意のテーブルを作成する権限。       |
| ALTER ANY TABLE         | 任意のテーブルを変更する権限。     |
| BACKUP ANY TABLE        | 任意のテーブルをバックアップする権限。      |
| DROP ANY TABLE          | 任意のテーブルを削除する権限。         |
| LOCK ANY TABLE          | 任意のテーブルをロックする権限。      |
| COMMENT ANY TABLE       | 任意のテーブルにコメントを追加する権限。      |
| SELECT ANY TABLE        | 任意のテーブルを使用する権限。       |
| INSERT ANY TABLE        | 任意のテーブルに行を挿入する権限。        |
| UPDATE ANY TABLE        | 任意のテーブルの行を変更する権限。     |
| DELETE ANY TABLE        | 任意のテーブルデータを削除する権限。     |
| FLASHBACK ANY TABLE     | 任意のテーブルをフラッシュバックする権限。        |
| DROP ANY ROLE           | 任意のロールを削除する権限。        |
| GRANT ANY ROLE          | 任意のロールを付与する権限。       |
| ALTER ANY ROLE          | 任意のロールを変更する権限。       |
| AUDIT ANY               | 任意のオブジェクトに監査オプションを設定する権限。        |
| GRANT ANY PRIVILEGE     | ユーザーに任意のシステム権限を付与する権限。         |
| GRANT ANY OBJECT PRIVILEGE   | ユーザーに任意のオブジェクト権限を付与する権限。      |
| CREATE ANY INDEX        | 任意のインデックスを作成する権限。       |
| ALTER ANY INDEX         | 任意のインデックスを変更する権限。      |
| DROP ANY INDEX          | 任意のインデックスを削除する権限。       |
| CREATE ANY VIEW         | ビューを作成する権限。      |
| DROP ANY VIEW           | 任意のビューを削除する権限。          |
| SELECT ANY DICTIONARY   | 任意のデータディクショナリを使用する権限。         |
| CREATE ANY PROCEDURE    | ユーザーに任意のストアドプロシージャを作成する権限。        |
| ALTER ANY PROCEDURE     | 任意のストアドプロシージャを変更する権限。       |
| DROP ANY PROCEDURE      | 任意のストアドプロシージャを削除する権限。         |
| EXECUTE ANY PROCEDURE   | 任意のストアドプロシージャを実行する権限。        |
| CREATE ANY SYNONYM      | ユーザーに任意のシノニムを作成する権限。       |
| DROP ANY SYNONYM        | 任意のシノニムを削除する権限。      |
| CREATE ANY SEQUENCE     | 任意のシーケンスを作成する権限。       |
| ALTER ANY SEQUENCE      | 任意のシーケンスを変更する権限。       |
| DROP ANY SEQUENCE       | 任意のシーケンスを削除する権限。          |
| SELECT ANY SEQUENCE     | 任意のシーケンスを使用する権限。         |
| CREATE ANY TRIGGER      | ユーザーに任意のトリガーを作成する権限。         |
| ALTER ANY TRIGGER       | 任意のトリガーを変更する権限。          |
| DROP ANY TRIGGER        | 任意のトリガーを削除する権限。             |
| CREATE ANY TYPE         | 任意の型を作成する権限。       |
| ALTER ANY TYPE          | 任意の型を変更する権限。       |
| DROP ANY TYPE           | 任意の型を削除する権限。         |
| EXECUTE ANY TYPE        | 任意の型を実行する権限。           |
| UNDER ANY TYPE          | `SYS`ユーザー以外のすべてのユーザーの`Schema`内にある`TYPE`に基づいて、`SUBTYPE`を作成する権限。        |
| CREATE ANY OUTLINE      | 任意の実行計画を作成する権限。     |
| ALTER ANY OUTLINE       | 任意の実行計画を変更する権限。        |
| DROP ANY OUTLINE        | 任意の実行計画を削除する権限。          |
