# バックアップタスクの表示

このセクションでは、時間を条件に一般バックアップのデータバックアップタスクリスト、ログバックアップタスクリスト、バックアップクリーンアップリストをフィルタリングして表示し、タスクの開始・停止などの管理操作を行う方法について説明します。

バックアップデータの表示は、以下の3つのエントリから行えます：

* **エントリ1**：OCPにログインし、**バックアップ・リストア > バックアップ**に移動します。**<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">バックアップタスク</UI-TERM>**タブで、バックアップ関連情報を確認します。

* **エントリ2**：OCPにログインし、クラスタの**<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>**ページに移動します。左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">バックアップと復元</UI-TERM>**を選択し、下にスクロールして**<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">バックアップタスク</UI-TERM>**タブを見つけて、クラスタのバックアップ関連情報を確認します。

* **エントリ3**：OCPにログインし、テナントの**<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>**ページに移動します。左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">バックアップと復元</UI-TERM>**を選択し、下にスクロールして**<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">バックアップタスク</UI-TERM>**タブを見つけて、テナントのバックアップ関連情報を確認します。

## 前提条件

**<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">バックアップタスク</UI-TERM>** ページでは、操作によってユーザーが持つ必要がある権限が異なります。

* **タスク情報の表示**

  * **エントリ1** でバックアップタスク情報を表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

    * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
    * バックアップ・リストア **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">バックアップ</UI-TERM>** メニュー権限。

  * **エントリ2** でバックアップタスク情報を表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

    * **クラスタ読み取り専用** のリソース権限。
    * クラスタ **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

  * **エントリ3** でバックアップタスク情報を表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

    * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
    * テナント **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

* **バックアップタスクの停止** または **バックアップタスクの開始**

  * **エントリ1** でバックアップタスクを停止または開始する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

    * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
    * バックアップ・リストア **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">バックアップ</UI-TERM>** メニュー権限。

  * **エントリ2** でバックアップタスクを停止または開始する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

    * **クラスタメンテナンス** のリソース権限。
    * クラスタ **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

  * **エントリ3** でバックアップタスクを停止または開始する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

    * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
    * テナント **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

## 手順

以下の手順では、**エントリー１** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **バックアップ・リストア > バックアップ** をクリックし、デフォルトで **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">バックアップタスク</UI-TERM>** タブに移動します。

3. データバックアップタスクを確認します。

    **<UI-TERM key="ocp-v2.Backup.Overview.Task.DataBackup">データバックアップ</UI-TERM>** タブで、データの **ID**、**<UI-TERM key="ocp-v2.Detail.Component.DeleteTenantModal.BelongsCluster">所属クラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.plan.Tenant">テナント</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.DataBackupMethod">データバックアップ方法</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Data.BackupSetId">バックアップセット ID</UI-TERM>**、**<UI-TERM key="ocp-v2.Trace.Visualizer.StartTime">開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.TraceDetail.TraceContent.EndTime">終了時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.RecoverablePointInTime">回復可能な時点</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.WhetherDoneSecondaryBackup">二次バックアップを行ったことがありますか</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.State">ステータス</UI-TERM>**、および **<UI-TERM key="ocp-v2.Backup.Service.Operation">操作</UI-TERM>** を確認し、異なる状態に応じてバックアップタスクを表示します。詳細は下表を参照してください。

    右上の時間オプションから **<UI-TERM key="ocp-v2.Information.Detail.CreateCollectDrawer.NearlyHour">直近1時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NearlyHours">過去24時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.log.LastDays">過去7日間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NearlyDays">過去30日間</UI-TERM>**、または **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">カスタム時間</UI-TERM>** を選択すると、時間別にデータバックアップタスクをフィルタリングできます。

    | **<UI-TERM key="ocp-v2.component.ParameterTemplate.Parameter">パラメータ</UI-TERM>** | **<UI-TERM key="ocp-v2.page.Settings.Profile.Description">説明</UI-TERM>** |
    | --- | --- |
    | ID | IDの左側にある **+** ボタンをクリックすると、**<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.BackupMethod">バックアップ方法</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.BackupDuration">バックアップ期間</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Data.DataVersion">データバージョン</UI-TERM>**、および **<UI-TERM key="ocp-v2.src.component.ArchiveForm.StorageDirectory">ストレージディレクトリ</UI-TERM>** を展開して表示できます。 |
    | 所属クラスタ | **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.BelongsCluster">所属クラスタ</UI-TERM>** をクリックすると、そのクラスタの **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。 |
    | テナント | **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.TenantWithExclude.Tenant">テナント</UI-TERM>** をクリックすると、そのテナントの **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。 |
    | データバックアップ方式 | **<UI-TERM key="ocp-v2.src.constant.backup.Total">フル</UI-TERM>** と **<UI-TERM key="ocp-v2.src.constant.backup.Incremental">増分</UI-TERM>** が含まれます。 |
    | バックアップセットID | 物理バックアップにおけるフルデータバックアップと増分データバックアップの関係を示すために使用されます。IDが同じフルバックアップと増分バックアップは対応しています。 |
    | 開始時間 | バックアップの開始時刻です。 |
    | 終了時間 | バックアップの終了時刻です。 |
    | 復元可能な時点 | バックアップ復元で選択可能な時間点です。 |
    | 2次バックアップ実施済みかどうか | 値が **<UI-TERM key="ocp-v2.Session.Deadlock.DeadlockHistoryTable.Yes">はい</UI-TERM>** の場合、**<UI-TERM key="ocp-v2.Detail.Component.OBProxyAndConnectionStringModal.Yes">はい</UI-TERM>** をクリックすると、このデータに対するすべての2次バックアップタスクを確認できます。 |
    | 状態 | データバックアップの状態です。バックアップ状態でフィルタリングできます。<blockquote>**<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Description">説明</UI-TERM>**</br>OceanBaseがV2.2.77以上、V4.0未満のバージョンの場合、タスク進捗率のパーセンテージを確認できます。</blockquote> |
    | 操作 | データバックアップタスクが失敗した場合、**<UI-TERM key="ocp-v2.Component.ZoneList.Operation">操作</UI-TERM>** の下の **<UI-TERM key="ocp-v2.src.constant.backup.ViewReasons">原因を確認する</UI-TERM>** をクリックします。 |

4. ログバックアップタスクを確認します。

    **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.LogBackup">ログのバックアップ</UI-TERM>** タブで、データの **所属クラスタ、テナント、バックアップ方式、サービスが属するホストIP、最新バックアップ時点、遅延(s)、保存先ディレクトリ、開始時間、状態** および **<UI-TERM key="ocp-v2.Settings.Credential.Host.Operation">操作</UI-TERM>** を確認し、異なる状態に応じてバックアップタスクを表示します。詳細は下表を参照してください。

    右上の時間オプションから **過去1時間、過去24時間、過去7日間、過去30日間** または **<UI-TERM key="ocp-v2.component.RangeTimeDropdown.CustomTime">カスタム時間</UI-TERM>** を選択すると、時間別にログバックアップタスクをフィルタリングできます。

    | **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.TenantParamInfoTable.Parameter">パラメータ</UI-TERM>** | **<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.Description">説明</UI-TERM>** |
    | --- | --- |
    | 所属クラスタ | **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.BelongsCluster">所属クラスタ</UI-TERM>** をクリックすると、そのクラスタの **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。 |
    | テナント | **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Tenant">テナント</UI-TERM>** をクリックすると、そのテナントの **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。 |
    | バックアップ方式 | クラスタのバックアップ方式。**<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.LogicalBackup">論理バックアップ</UI-TERM>** および **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.PhysicalBackup">物理バックアップ</UI-TERM>** が含まれます。 |
    | サービスが属するホストIPアドレス | ホストのIPアドレス。  |
    | 最終バックアップ時刻 | 現在時点までに完了したログバックアップの時刻。 |
    | データの遅延時間 (秒) | バックアップデータと実際のデータとの時間差です。 |
    | ストレージディレクトリ | バックアップデータの保存ディレクトリ。 |
    | 開始時間 | バックアップの開始時刻。 |
    | 状態 | ログバックアップの状態。バックアップ状態でフィルタリングできます。 |
    | 操作 | **<UI-TERM key="ocp-v2.src.constant.backup.Starting">起動中</UI-TERM>** または **<UI-TERM key="ocp-v2.src.constant.backup.InProgress">進行中</UI-TERM>** のクラスタに対しては、**<UI-TERM key="ocp-v2.Cluster.Detail.Stop">停止する</UI-TERM>** 操作を実行できます。また、**<UI-TERM key="ocp-v2.src.constant.oceanbase.Stopped">停止済み</UI-TERM>** のクラスタに対しては、**<UI-TERM key="ocp-v2.Component.BinlogServerList.Start">起動</UI-TERM>** 操作を実行できます。<blockquote>**<UI-TERM key="ocp-v2.Cluster.Arbitration.Description">備考</UI-TERM>**</br>ログバックアップを停止する操作を実行する場合：<ul><li>バックアップポリシーが有効な場合、ログバックアップを永久に無効にするには、バックアップポリシーも同時に終了または削除してください。</li><li>バックアップポリシーが有効な場合、または手動でデータバックアップを開始した場合、システムはデフォルトでログバックアップを有効にします。</li><li>ログバックアップを停止すると、システムは任意の時点での復元をサポートせず、データの安全性を保証できなくなります。ご注意ください。</li></ul></blockquote> |

5. バックアップクリーンアップタスクの表示

    **<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupCleanup">バックアップのクリーンアップ</UI-TERM>** タブで、データの **ID**、**<UI-TERM key="ocp-v2.Sop.components.BackupPrimaryTable.Cluster">所属クラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.component.TaskBubble.StartTime">開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.component.RecentCompaction.EndTime">終了時間</UI-TERM>**、および **<UI-TERM key="ocp-v2.page.Host.State">ステータス</UI-TERM>** を確認し、異なる状態に基づいてバックアップタスクを表示できます。

    右上の時間オプションから、**<UI-TERM key="ocp-v2.component.OCPRangePicker.constant.NearlyHour">直近1時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NearlyHours">過去24時間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.LastDays">過去7日間</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.backup.NearlyDays">過去30日間</UI-TERM>**、または **<UI-TERM key="ocp-v2.component.OCPRangePicker.CustomTime">カスタム時間</UI-TERM>** を選択し、時間に基づいてバックアップクリーンアップタスクをフィルタリングできます。
