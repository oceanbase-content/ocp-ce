# 二次バックアップタスクの表示

時間を条件にフィルタリングして、データの二次バックアップリストとログの二次バックアップリストを表示できます。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>OceanBase 4.x系では二次バックアップはサポートされていません。
   </p>
   </main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**または**テナント読み取り専用**のリソース権限。
* バックアップ・リストアの**<UI-TERM key="ocp-v2.src.constant.compute.Backup">バックアップ</UI-TERM>**メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**バックアップ・リストア > バックアップ**をクリックし、デフォルトで**<UI-TERM key="ocp-v2.Backup.Overview.Task.BackupTask">バックアップタスク</UI-TERM>**タブに移動します。

3. **<UI-TERM key="ocp-v2.Backup.Overview.Task.SecondaryBackupTask">二次バックアップタスク</UI-TERM>**タブをクリックします。

    **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.SecondaryDataBackup">データの二次バックアップ</UI-TERM>**タスクタブで、データの**ID、所属クラスタ、テナント、バックアップセットID、開始時間、終了時間**、**<UI-TERM key="ocp-v2.Backup.SecondaryBackup.Log.StorageDirectory">ストレージディレクトリ</UI-TERM>**、**<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.State">ステータス</UI-TERM>**を確認できます。異なる状態に応じてバックアップタスクを表示できます。具体的には：

      * **<UI-TERM key="ocp-v2.Inspection.Item.Cluster">所属クラスタ</UI-TERM>**列：クラスタ名をクリックすると、そのクラスタの**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>**ページに移動します。クラスタの検索もサポートされています。

      * **<UI-TERM key="ocp-v2.Backup.Backup.Data.BackupSetId">バックアップセット ID</UI-TERM>**列：IDをクリックすると、そのバックアップセットのすべてのデータバックアップタスクを表示できます。

      * **<UI-TERM key="ocp-v2.Detail.Backup.State">ステータス</UI-TERM>**列：バックアップ状態のフィルタリングがサポートされており、**スケジューリング中、実行中、クリーンアップ中、完了、キャンセル、失敗**および**<UI-TERM key="ocp-v2.src.constant.binlog.Unknown">不明</UI-TERM>**の各状態を指定できます。

    右上の時間オプションから**過去24時間、過去7日間、過去30日間**または**<UI-TERM key="ocp-v2.alarm.ExpressionFormList.MultipleExpressionFormList.Custom">カスタマイズ</UI-TERM>**を選択することで、時間に基づいてデータの二次バックアップタスクをフィルタリングできます。

    <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%95%B0%E6%8D%AE%E4%BA%8C%E6%AC%A1%E5%A4%87%E4%BB%BD.png) -->

4. ログの二次バックアップタスクを表示します。

    **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.SecondaryLogBackup">ログの二次バックアップ</UI-TERM>**タブで、データの**所属クラスタ、最新バックアップ時刻、ストレージディレクトリ**、**<UI-TERM key="ocp-v2.TraceContent.PlanOperation.StartTime">開始時間</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Task.State">ステータス</UI-TERM>**を確認できます。

      * **<UI-TERM key="ocp-v2.Backup.Backup.Data.Cluster">所属クラスタ</UI-TERM>**列：クラスタ名をクリックすると、そのクラスタの**<UI-TERM key="ocp-v2.Detail.Monitor.Monitor.Overview">総覧</UI-TERM>**ページに移動します。クラスタの検索もサポートされています。

      * **<UI-TERM key="ocp-v2.Detail.Optimize.Status">ステータス</UI-TERM>**列：バックアップ状態のフィルタリングがサポートされており、**実行中、停止済み**および**<UI-TERM key="ocp-v2.src.constant.backup.Unknown">不明</UI-TERM>**の各状態を指定できます。

    右上の時間オプションから**過去24時間、過去7日間、過去30日間**または**<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Custom">カスタマイズ</UI-TERM>**を選択することで、時間に基づいてログの二次バックアップタスクをフィルタリングできます。
