# 抽样策略の表示

このページでは、バックアップ・リストアの抜取り検査戦略を確認する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
* バックアップ・リストア **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.New.Recovery">リストア</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.constant.compute.Recovery">リストア</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.src.util.menu.Recovery">リストア</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Backup.Restore.SamplingPolicy">サンプリング検査戦略</UI-TERM>** タブをクリックし、時間でフィルタリングして、**<UI-TERM key="ocp-v2.Backup.Restore.SamplingPolicy">サンプリング検査戦略</UI-TERM>** リスト情報を確認できます。

| **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ZoneParamInfoTable.Parameter">パラメータ</UI-TERM>** | **<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.Description">説明</UI-TERM>** |
| --- | --- |
| 戦略名 | **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.PolicyName">戦略名</UI-TERM>** をクリックすると、戦略の概要ページに移動し、その戦略を **停止、編集** および **削除** できます。 |
| 抽取対象クラスタ | **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.SpotCheckCluster">サンプリング検査クラスタ</UI-TERM>** をクリックすると、クラスタの概要ページに移動します。 |
| バックアップ方式 | **<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.PhysicalBackup">物理バックアップ</UI-TERM>** と **<UI-TERM key="ocp-v2.src.constant.backup.LogicalBackup">論理バックアップ</UI-TERM>** が含まれます。 |
| 対象クラスタ | データを復元するクラスタ。バックアップしたクラスタのデータを対象クラスタに復元します。 |
| 対象テナント | データを復元するテナント。バックアップしたテナントのデータを対象テナントに復元します。 |
| 作成日時 | この戦略の作成日時です。 |
| ステータス | **開始、データ復元中、ログ復元中、データ復元失敗、ログ復元失敗、完了** などが含まれます。 |
| 操作 | 操作後の **停止、編集** および **<UI-TERM key="ocp-v2.src.constant.binlog.Delete">削除</UI-TERM>** を通じて、現在の抜取り検査戦略を操作できます。 |
