# サービスのインストール

論理バックアップおよびリストアを実行するには、このセクションで説明するバックアップ・リストアサービスをインストールしておく必要があります。

<main id="notice" type='explain'>
<h4>説明</h4>
<p><b>サービス</b>機能は、<b>論理バックアップ</b>シナリオでのみ適用され、バックアップ対象のクラスタバージョンはV2.2.60より低い必要があります。</p>
</main>

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **ホストメンテナンス**リソース権限。
  * バックアップ・リストア **<UI-TERM key="ocp-v2.Alarm.Subscriptions.TargetLayout.Service">サービス</UI-TERM>** メニュー権限。

* バックアップ・リストアサービスパッケージ `oceanbase-data-maintain-x.x.xx-YYYYMMDDhhmmss.el7.x86_64` または `oceanbase-data-maintain-x.x.xx-YYYYMMDDhhmmss.el7.aarch64` を取得済みであること。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>対象となるOceanBaseクラスタと同じバージョンのパッケージを取得することを推奨します。例えば、OceanBase V2.2.52のクラスタをバックアップする場合は、パッケージ <code>oceanbase-data-maintain-2.2.52-20210331185950.el7.x86_64.rpm</code> を取得します。</p>
  </main>

* [ホストの追加](../../850.host-features/100.manage-a-host/200.add-a-host.md)を参照済みであること。
* OceanBaseデータベースのNFSデプロイメントの章を参照し、追加したホストにNFSサーバーをデプロイ済みであること。

## 手順

1. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.util.menu.Service">サービス</UI-TERM>** をクリックします。

2. サービスページの右上隅で、**<UI-TERM key="ocp-v2.Backup.Service.Install.InstallationService">設置サービス</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.src.component.AddUnitSpecModal.BasicConfiguration">基本設定</UI-TERM>** の情報を入力します。
   <!-- ![7](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4740482161/p240669.png) -->

   |     パラメータ     |   説明   |
   |------------|-----|
   | サービス名       | 英字で始まり、英字または数字で終わる2～32文字の長さで、英字、数字、アンダースコアを含むことができます。   |
   | サービスバージョン       | <ul><li>既存のサービスバージョンを選択します。</li><li>**バージョンの追加**をクリックして新しいバージョンをアップロードします。</li></ul>  |
   | インストールタイプ       | サービスタイプを選択します。選択肢は以下のとおりです：<ul><li> **<UI-TERM key="ocp-v2.src.constant.compute.Backup">バックアップ</UI-TERM>** ：バックアップサービスのみをインストールします。</li><li> **<UI-TERM key="ocp-v2.Restore.SamplingStrategy.New.Recovery">リストア</UI-TERM>** ：リストアサービスのみをインストールします。   </li><li> **バックアップ+リストア** ：バックアップとリストアの両方のサービスをインストールします。 </li></ul>   |
   | サービスログファイルのクリーンアップしきい値 | サービスログファイルがこのしきい値を超えた場合、クリーンアップを促すアラートが表示されます。デフォルトは80%で、実際の状況に応じて調整できます。   |
   | ホストの選択       | サービスをインストールするホストを選択します。  |

4. **<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageConfiguration">ストレージ設定</UI-TERM>** の情報を入力し、**<UI-TERM key="ocp-v2.src.component.ArchiveForm.Test">テスト</UI-TERM>** をクリックして、ストレージ設定が正常に設定されているか確認します。

   <!-- ![6](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4740482161/p240668.png) -->

   |     パラメータ  |  説明  |
   |------------|----|
   | ストレージ構成名     | 英字で始まり、英字または数字で終わる、英字・数字・アンダースコアを含む2～32文字の文字列です。     |
   | ストレージタイプ       | バックアップファイルの保存媒体。オプションは以下のとおりです。<li>OSS：クラウドストレージ</li><li>File：ハードデバイスストレージ</li>    |
   | ストレージディレクトリ       | バックアップファイルの保存ディレクトリです。adminユーザーに対して読み書き権限が付与されていなければなりません。   |
   | バックアップストレージ容量アラートしきい値 | バックアップストレージ容量がこのしきい値を超えた場合にアラートを表示します。デフォルトは80%ですが、実際の状況に応じて調整できます。  |
   | アクセスドメイン       | ストレージタイプがOSSの場合のみ入力が必要です。クラウドストレージ側のアクセスドメインです。    |
   | アクセスユーザー       | ストレージタイプがOSSの場合のみ入力が必要です。クラウドストレージのAccessKey IDです。   |
   | アクセスシークレットキー       | ストレージタイプがOSSの場合のみ入力が必要です。クラウドストレージのAccessKey Secretです。    |

5. **<UI-TERM key="ocp-v2.Backup.Service.Detail.BackupConfiguration">バックアップ構成</UI-TERM>** の情報を入力します。

   * 実際のニーズに応じて、**<UI-TERM key="ocp-v2.Backup.Service.Detail.BackupMetadatabaseConfiguration">MetaDBの設定をバックアップ</UI-TERM>** を入力します。不要な場合はデフォルト値のままにしてください。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>バックアップメタデータベースはサードパーティ製であり、バックアップ・リストアのパラメータテーブル設定やバックアップタスクの管理を行います。システムは一定間隔でメタデータベースをクエリし、バックアップタスクの有無を確認することで、ベースラインデータおよび増分データのバックアップ開始・中止を制御し、タスクの進捗に伴うステータスの更新も行います。</p>
    </main>

     MetaDBを作成する際、バックアップメタデータベースも同時に作成されます。

     <!-- ![5](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4740482161/p240664.png) -->

   * 実際のニーズに応じて、**Common** の情報を入力します。不要な場合はデフォルト値のままにしてください。

      <!-- ![4](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4740482161/p240663.png) -->クラスタリストのURLは、バックアップメタデータベースが存在するクラスタのURLを指します。

   * 実際のニーズに応じて、**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerMonitor.Other">その他</UI-TERM>** の情報を入力します。不要な場合はデフォルト値のままにしてください。

      <!-- ![3](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4740482161/p240662.png) -->

6. **<UI-TERM key="ocp-v2.Backup.Service.Detail.RestoreConfigurations">設定の復元</UI-TERM>** の情報を入力します。

   * 実際のニーズに応じて、**<UI-TERM key="ocp-v2.Component.InstallService.RestoreMetadatabaseConfigurations">MetaDBの設定を復元する</UI-TERM>** を入力します。不要な場合はデフォルト値のままにしてください。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>リストア用メタデータベースもサードパーティ製であり、システムはこのメタデータベース内の管理テーブルをクエリすることで、リストアタスクのスケジューリングと制御を行います。バックアップとリストアで使用されるメタデータベースは、同一のMetaDB上にデプロイできます。</p>
    </main>

     <!-- ![2](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4740482161/p240661.png) -->

   * 実際のニーズに応じて、**<UI-TERM key="ocp-v2.page.Overview.Other">その他</UI-TERM>** の情報を入力します。不要な場合はデフォルト値のままにしてください。

      <!-- ![1](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4740482161/p240660.png) -->

7. **<UI-TERM key="ocp-v2.Component.InstallService.Mounting">インストール</UI-TERM>** をクリックします。
