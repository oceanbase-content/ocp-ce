# 運用保守タスクの表示

このセクションを参照することで、ホスト上のバックアップ・リストアサービスに関する操作履歴を確認できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**または**テナント読み取り専用**のリソース権限。
  * バックアップ・リストア **<UI-TERM key="ocp-v2.src.util.menu.Service">サービス</UI-TERM>** メニュー権限。

* [サービスのインストール](../1000.manage-backup-and-recovery-service/200.installation-services.md) を参照してバックアップ・リストアサービスをインストール済みであること。

## 手順

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Backup.Service.Service">サービス</UI-TERM>** をクリックします。

2. 操作対象のサービスを見つけて、そのサービス名をクリックします。

   システムはそのサービスの詳細ページにジャンプします。

   ![ser_start](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9370249161/p268027.png)

3. **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">サービスノード</UI-TERM>** リストで表示したいノードを見つけ、そのノードの操作列にある **<UI-TERM key="ocp-v2.src.constant.backup.ViewOMTasks">運用管理タスクを確認する</UI-TERM>** または **...** の **運用保守タスクの表示** をクリックします。

   システムは **ノード xxx.xxx.xxx.xxx の運用保守タスク** ページをポップアップ表示します。

   このページには、xxx.xxx.xxx.xxx 上のバックアップ・リストアサービス関連タスクの簡単な情報が記録されています。

   `Install backup agent`タスクを例にすると、タスクID、タスクの発行者、タスク状態、実行進捗、タスクの開始・終了時間などが表示されます。

4. **ノード xxx.xxx.xxx.xxx の運用保守タスク** ページで、タスク名（例：`Install backup agent`）をクリックします。

   システムは **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** インターフェースの `Install backup agent` タスクの詳細画面にジャンプします。[タスク管理](../../1600.system-management-features/600.manage-tasks.md) を参照して、このタスクの詳細情報を確認できます。
