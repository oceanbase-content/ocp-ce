# ノードサービスの停止

このセクションでは、ホスト上のバックアップ・リストアサービスを停止する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * バックアップ・リストア **<UI-TERM key="ocp-v2.Backup.Service.Service">サービス</UI-TERM>** メニュー権限。

* [サービスのインストール](../1000.manage-backup-and-recovery-service/200.installation-services.md) を参照して、バックアップ・リストアサービスをインストール済みであること。

## 手順

1. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Backup.Service.Install.Service">サービス</UI-TERM>** をクリックします。

2. 操作対象のサービスを見つけ、そのサービス名をクリックします。

   システムはそのサービスの詳細ページにジャンプします。

   <!-- ![ser_stop](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5337270261/p268008.png) -->

3. サービスノードリストで停止するノードを見つけ、**<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Stop">停止する</UI-TERM>** をクリックします。

   システムは「ノード「xxx.xxx.xxx.xxx」のサービスを停止しますか？」という確認メッセージを表示します。

4. **<UI-TERM key="ocp-v2.Component.ZoneList.Stop">停止する</UI-TERM>** をクリックします。
