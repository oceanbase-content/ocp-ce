# サービスノードの追加

このセクションを参考に、既にサービスがインストールされている状態でノードを追加すると、バックアップ時に複数のホストに同時に保存できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * バックアップ・リカバリ **<UI-TERM key="ocp-v2.Backup.Service.Edit.Service">サービス</UI-TERM>** メニュー権限。

* [サービスのインストール](../1000.manage-backup-and-recovery-service/200.installation-services.md) を参照して、バックアップ・リカバリサービスをインストール済みであること。

* 追加するノードを [ホストの追加](../../850.host-features/100.manage-a-host/200.add-a-host.md) によりOCPに追加済みであること。

## 手順

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Backup.Service.Service">サービス</UI-TERM>** をクリックします。

2. ノードを追加するサービスを見つけ、そのサービスの操作列にある **<UI-TERM key="ocp-v2.Service.Component.ServiceModal.AddNode">ノードの追加</UI-TERM>** をクリックします。

   システムは **<UI-TERM key="ocp-v2.Service.Component.ServiceModal.AddNode">ノードの追加</UI-TERM>** ダイアログを表示します。

3. **ホストの選択** の入力欄をクリックし、追加するノードを選択します。

   <!-- ![p267885](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%B7%BB%E5%8A%A0%E8%8A%82%E7%82%B91.png) -->

4. **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.Determine">確定</UI-TERM>** をクリックします。
