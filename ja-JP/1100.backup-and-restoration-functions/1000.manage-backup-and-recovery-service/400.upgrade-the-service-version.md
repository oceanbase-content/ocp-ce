# サービスバージョンのアップグレード

インストール済みのバックアップ・リストアサービスをアップグレードします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * バックアップ・リストア **<UI-TERM key="ocp-v2.Backup.Service.Install.Service">サービス</UI-TERM>** メニュー権限。

* [サービスのインストール](200.installation-services.md) を参照してバックアップ・リストアサービスをインストールしていること。

## 手順

1. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.util.menu.Service">サービス</UI-TERM>** をクリックします。

2. アップグレード対象のサービスを見つけ、そのサービスの操作列にある **<UI-TERM key="ocp-v2.src.constant.backup.UpgradedVersion">バージョンをアップグレード</UI-TERM>** をクリックします。

   システムは **<UI-TERM key="ocp-v2.Detail.Component.UpgradeObproxiesModal.UpgradedVersion">アップグレードバージョン</UI-TERM>** ダイアログを表示します。

3. アップグレードするバージョンを選択します。

   **バージョンの追加** をクリックし、ターゲットバージョンのrpmパッケージをアップロードします。選択可能なリストにターゲットバージョンがある場合は、直接選択できます。再度アップロードする必要はありません。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>現在のサービスバージョンより高いソフトウェアパッケージのみを選択できます。<strong>バージョンアップグレード</strong> 用に選択したパッケージは、アップグレード対象サービスが配置されているホストのハードウェアアーキテクチャと互換性がある必要があります。</p>
    <ul>
    <li>ホストがX86アーキテクチャの場合は、パッケージ名の拡張子が .x86_64.rpm のソフトウェアパッケージを選択します。</li>
    <li>ホストがARMアーキテクチャの場合は、パッケージ名の拡張子が .aarch64.rpm のソフトウェアパッケージを選択します。</li>
    </ul>
    </main>

   ![serv_version](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E5%8D%87%E7%BA%A7%E6%9C%8D%E5%8A%A1%E7%89%88%E6%9C%AC.png)

4. **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Determine">確定</UI-TERM>** をクリックします。
