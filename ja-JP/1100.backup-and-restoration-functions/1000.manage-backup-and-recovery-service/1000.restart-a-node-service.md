# ノードサービスの再起動

このセクションでは、特定のホスト上のバックアップ・リストアサービスを再起動する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * バックアップ・リストア **<UI-TERM key="ocp-v2.src.util.menu.Service">サービス</UI-TERM>** メニュー権限。

* [サービスのインストール](../1000.manage-backup-and-recovery-service/200.installation-services.md) を参照してバックアップ・リストアサービスをインストール済みであること。

## 手順

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Backup.Service.Service">サービス</UI-TERM>** をクリックします。

2. 操作対象のサービスを見つけ、そのサービス名をクリックします。

   システムはそのサービスの詳細ページに移動します。

   ![p268021](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6927270261/p268315.png)

3. **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">サービスノード</UI-TERM>** リストで再起動するノードを見つけ、**<UI-TERM key="ocp-v2.Detail.Overview.Restart">再起動</UI-TERM>** をクリックします。

   システムは「ノード「xxx.xxx.xxx.xxx」のサービスを再起動しますか？」というメッセージを表示します。

4. **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Restart">再起動</UI-TERM>** をクリックします。
