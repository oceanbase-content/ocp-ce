# ノードのアンインストール

このセクションでは、ホスト上のバックアップ・リストアサービスをアンインストールする方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * バックアップ・リストア **<UI-TERM key="ocp-v2.Alarm.Subscriptions.TargetLayout.Service">サービス</UI-TERM>** メニュー権限。

* [サービスのインストール](../1000.manage-backup-and-recovery-service/200.installation-services.md) を参照してバックアップ・リストアサービスをインストール済みであること。

* 当該ノードで [ノードサービスの停止](../1000.manage-backup-and-recovery-service/900.stop-a-node-service.md) を実行済みであること。

## 手順

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Alarm.Subscriptions.TargetLayout.Service">サービス</UI-TERM>** をクリックします。

2. 操作対象のサービスを見つけ、そのサービス名をクリックします。

   システムはそのサービスの詳細ページにジャンプします。

   <!-- ![ser_start](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/9370249161/p268027.png) -->

3. **<UI-TERM key="ocp-v2.Backup.Service.Detail.ServiceNode">サービスノード</UI-TERM>** リストでアンインストールするノードを見つけ、**...** をクリックして **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">アンインストール</UI-TERM>** を選択します。

   システムは「ノード「xxx.xxx.xxx.xxx」のサービスをアンインストールしますか？」という確認ダイアログを表示します。

4. **<UI-TERM key="ocp-v2.src.constant.backup.Uninstall">アンインストール</UI-TERM>** をクリックします。
