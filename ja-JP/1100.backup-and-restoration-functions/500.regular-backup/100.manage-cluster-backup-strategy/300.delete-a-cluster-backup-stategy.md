# クラスタレベルのバックアップポリシーを削除する

この記事では、クラスタレベルのバックアップポリシーを削除する方法について説明します。

クラスタレベルのバックアップポリシーは、以下の2つの方法で削除できます：

* **方法1**：OCPにログインし、クラスタの**<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">バックアップと復元</UI-TERM>**を選択し、右側のドロップダウンメニューで**その他 > バックアップポリシーの削除**を選択します。

* **方法2**：OCPにログインし、クラスタの**<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>**ページに移動します。左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">バックアップと復元</UI-TERM>**を選択し、**<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">バックアップポリシー</UI-TERM>**タブに移動します。**···**の中で**<UI-TERM key="ocp-v2.Backup.Service.Detail.Delete">削除</UI-TERM>**をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**リソース権限。
  * クラスタの**<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">バックアップと復元</UI-TERM>**メニュー権限。

* クラスタにバックアップポリシーが作成されていること。

## 手順

以下の手順は**方法1**を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.Information.Cluster">クラスタ</UI-TERM>**をクリックし、クラスタページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>**から対象クラスタをクリックすると、デフォルトでクラスタの**<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>**ページに移動します。

4. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">バックアップと復元</UI-TERM>**をクリックし、そのクラスタの**<UI-TERM key="ocp-v2.Backup.Component.RestoreNow.BackupAndRestoration">バックアップと復元</UI-TERM>**ページに移動します。

5. ページの右上隅で**その他 > バックアップポリシーの削除**を選択します。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>クラスタレベルのバックアップポリシーを削除すると、クラスタおよびすべてのテナントのバックアップポリシーがなくなり、ログバックアップもデフォルトで無効になります。システムではデータの安全性を保証できませんので、ご注意ください。</p>
    </main>

6. ポップアップウィンドウで**<UI-TERM key="ocp-v2.Settings.Credential.Host.Delete">削除</UI-TERM>**をクリックします。
