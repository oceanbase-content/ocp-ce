# クラスタレベルのバックアップポリシーを表示する

この記事では、クラスタレベルのバックアップポリシーの詳細設定を表示する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** リソース権限。
* クラスタ **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.Cluster">クラスタ</UI-TERM>** をクリックし、クラスタページに移動します。

3. **<UI-TERM key="ocp-v2.page.Cluster.ClusterList">クラスタ一覧</UI-TERM>** で対象のクラスタをクリックすると、デフォルトでクラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">バックアップと復元</UI-TERM>** をクリックし、そのクラスタの **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。

5. **<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">バックアップポリシー</UI-TERM>** タブをクリックし、そのクラスタのクラスタレベルバックアップポリシー情報とテナントレベルバックアップポリシー情報を確認します。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>クラスタレベルバックアップポリシーのストレージ設定では、データバックアップの保存パスとログバックアップの保存パスが表示されます(OceanBase V4.0以降のバージョンでは、ログバックアップの保存パスを個別に設定できます)。テナントにテナントレベルのバックアップポリシーが設定されていない場合は、<strong>テナントレベルバックアップポリシー</strong> 関連の内容は表示されません。</p>
    </main>
