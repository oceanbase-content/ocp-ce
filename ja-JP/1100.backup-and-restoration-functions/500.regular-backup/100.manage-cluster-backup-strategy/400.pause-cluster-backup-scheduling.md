# バックアップスケジューリングの一時停止

作成したバックアップポリシーを一時的に使用しなくなった場合、そのクラスタの自動バックアップタスクのスケジューリングを一時停止できます。スケジューリングが一時停止されると、システムは自動的にバックアップを行いません。一時停止されたバックアップスケジューリングは、**<UI-TERM key="ocp-v2.src.constant.backup.StartBackupScheduling">バックアップスケジューリングを開始</UI-TERM>** をクリックすることで再開できます。

クラスタのバックアップスケジューリングを一時停止するには、以下の2つの方法があります：

* **方法1**：OCPにログインし、クラスタの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">バックアップと復元</UI-TERM>** を選択し、右側のドロップダウンメニューから **詳細 > バックアップスケジューリングの一時停止** を選択します。

* **方法2**：OCPにログインし、クラスタの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">バックアップと復元</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">バックアップポリシー</UI-TERM>** タブに移動します。**···** の中で **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SuspendScheduling">スケジュールの一時停止</UI-TERM>** をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

* クラスタにバックアップポリシーが作成されていること。

## 手順

以下の手順は **方法1** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Information.Cluster">クラスタ</UI-TERM>** をクリックし、クラスタページに移動します。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** で対象クラスタをクリックすると、デフォルトでクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">バックアップと復元</UI-TERM>** をクリックし、そのクラスタの **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Edit.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。

5. ページの右上隅で **詳細 > バックアップスケジューリングの一時停止** を選択します。

6. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Detail.Backup.Pause">一時停止</UI-TERM>** をクリックすると、クラスタの自動バックアップスケジューリングタスクが一時停止されます。
