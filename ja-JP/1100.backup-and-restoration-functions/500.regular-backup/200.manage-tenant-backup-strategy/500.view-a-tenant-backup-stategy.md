# テナントレベルのバックアップポリシーを表示する

この記事では、テナントレベルのバックアップポリシーの詳細設定を確認する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.src.util.menu.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

* テナントでバックアップポリシーが作成されていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Tenant">テナント</UI-TERM>** をクリックし、テナントページに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で対象テナントをクリックすると、デフォルトでテナントの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">バックアップと復元</UI-TERM>** をクリックし、そのテナントの **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">バックアップポリシー</UI-TERM>** タブをクリックして、バックアップポリシーの詳細を確認します。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>バックアップポリシーの詳細には、データバックアップの保存パスとログバックアップの保存パスが表示されます（ログバックアップの保存パスは、OceanBase V4.0以降でのみ個別設定が可能です）。</p>
    </main>
