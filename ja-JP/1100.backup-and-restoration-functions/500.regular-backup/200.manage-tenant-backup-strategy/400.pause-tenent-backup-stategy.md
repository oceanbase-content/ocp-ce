# バックアップスケジューリングの一時停止

作成したバックアップポリシーを一時的に使用しなくなった場合、そのテナントの自動バックアップタスクのスケジューリングを一時停止できます。スケジューリングが一時停止されると、システムは自動的にバックアップを実行しません。一時停止されたバックアップスケジューリングは、**<UI-TERM key="ocp-v2.src.constant.backup.StartBackupScheduling">バックアップスケジューリングを開始</UI-TERM>** をクリックすることで再開できます。

テナントのバックアップスケジューリングを一時停止するには、以下の2つの方法があります：

* **方法1**：OCPにログインし、テナントの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">バックアップと復元</UI-TERM>** を選択し、右側のドロップダウンメニューから **その他 > バックアップスケジューリングの一時停止** を選択します。

* **方法2**：OCPにログインし、テナントの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">バックアップと復元</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Detail.Backup.BackupPolicy">バックアップポリシー</UI-TERM>** タブに移動します。**···** の中で **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SuspendScheduling">スケジュールの一時停止</UI-TERM>** をクリックします。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ保守** または **テナント保守** リソース権限。
  * テナント **<UI-TERM key="ocp-v2.src.constant.auditEvent.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

* テナントにバックアップポリシーが作成されていること。

## 手順

以下の手順では、**方法1** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.ZoneFormCardList.Tenant">テナント</UI-TERM>** をクリックし、テナントページに移動します。

3. **<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>** で対象テナントをクリックすると、デフォルトでテナントの **<UI-TERM key="ocp-v2.Detail.Overview.Overview">概要</UI-TERM>** ページに移動します。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.package.BackupAndRestoration">バックアップと復元</UI-TERM>** をクリックし、そのテナントの **<UI-TERM key="ocp-v2.Backup.Guide.BackupAndRestoration">バックアップと復元</UI-TERM>** ページに移動します。

5. ページの右上隅で **その他 > バックアップスケジューリングの一時停止** を選択します。

6. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Detail.Backup.Pause">一時停止</UI-TERM>** をクリックし、テナントの自動バックアップスケジューリングタスクを一時停止します。
