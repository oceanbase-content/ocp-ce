# クラスタの即時バックアップ

この章を参照して、クラスタの即時バックアップを実行できます。

クラスタのバックアップは、以下の2つの方法で行えます：

* **方法1**：OCPにログインし、**バックアップ・リストア > バックアップ**に移動します。ページの右上にある **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.BackUpNow">今すぐバックアップ</UI-TERM>** のドロップダウンリストから、**<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.BackupCluster">バックアップクラスタ</UI-TERM>** を選択します。

* **方法2**：OCPにログインし、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動します。左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">バックアップと復元</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.BackUpNow">今すぐバックアップ</UI-TERM>** をクリックします。

## 前提条件

* **方法1** でクラスタを即時バックアップする場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * バックアップ・リストア **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">バックアップ</UI-TERM>** メニュー権限。

* **方法2** でクラスタを即時バックアップする場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

* バックアップ対象のクラスタが論理バックアップの場合、データのフルバックアップのみをサポートします。バックアップ対象のクラスタが物理バックアップの場合、フルバックアップと増分バックアップをサポートします。

* OceanBaseクラスタが **<UI-TERM key="ocp-v2.src.constant.obproxy.Upgrade.1">アップグレード中</UI-TERM>** 状態にないこと。

* OceanBaseは、ロックされた状態のテナントのバックアップをサポートしていません。

## 手順

以下の手順では、**方法1** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Backup.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.Backup">バックアップ</UI-TERM>** をクリックし、ページの右上にある **<UI-TERM key="ocp-v2.Detail.Backup.BackUpNow">今すぐバックアップ</UI-TERM>** のドロップダウンリストから、**<UI-TERM key="ocp-v2.Component.AddBackupStrategy.BackupCluster">バックアップクラスタ</UI-TERM>** を選択します。

3. バックアップ対象を選択します。

   **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.BackupCluster">バックアップクラスタ</UI-TERM>** のドロップダウンリストから、バックアップ対象を選択します。システムは、クラスタの **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.ObVersion">OceanBase バージョン</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Restore.RestoreTask.BackupMethod">バックアップ方法</UI-TERM>** を自動的に認識し、**<UI-TERM key="ocp-v2.Component.BackupStrategyDetail.StorageConfiguration">ストレージ設定</UI-TERM>** を自動入力します。

   クラスタの **<UI-TERM key="ocp-v2.Detail.Backup.BackupMethod">バックアップ方法</UI-TERM>** が論理バックアップの場合、[サービスのインストール](../1000.manage-backup-and-recovery-service/100.service-features.md)を参照してバックアップサービスをインストールしてから、バックアップを実行してください。

4. ストレージ設定を入力します。

   * バックアップ対象のクラスタに既存のバックアップ戦略がある場合、ストレージ設定は自動的に入力されます。

   * バックアップ対象のクラスタにバックアップ戦略がない場合、手動でストレージ設定を入力する必要があります。画面上の指示に従って入力するか、[新しいクラスタレベルバックアップ戦略の作成](../500.regular-backup/100.manage-cluster-backup-strategy/100.create-a-cluster-backup-strategy.md)の手順4を参照して入力してください。

     全ての項目を入力したら、**<UI-TERM key="ocp-v2.OBProxy.New.Test">テスト</UI-TERM>** をクリックし、ストレージ設定をテストします。

5. データバックアップ方式を選択します。

   物理バックアップを行う場合は、データバックアップ方式を選択する必要があります。論理バックアップではフルバックアップのみサポートされています。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>物理バックアップを行う場合、増分バックアップを実行する前に、一度のフルデータバックアップが必要です。そうでない場合、<code>Check if ready to data backup</code> のステップで「full data backup needed before incremental data backup」というエラーが表示されます。</li>
    <li>フルバックアップ中に <code>Start cluster compact if necessary</code> のステップで「Cluster compaction needed before full data backup」というエラーが発生した場合、<a href="../../600.cluster-functions/1100.manage-cluster-merge/200.cluster-perform-merge.md">メジャーコンパクションの実行</a> を試してから、<strong>再試行</strong> ボタンをクリックしてバックアップを続行できます。</li>
    </ul>
    </main>

6. **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.BackUpNow">今すぐバックアップ</UI-TERM>** をクリックします。
