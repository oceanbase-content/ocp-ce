# テナントの即時バックアップ

この章を参照して、テナントの即時バックアップを実行できます。

テナントのバックアップは、以下の2つの方法で実行できます：

* **方法1**：OCPにログインし、**バックアップ・リストア > バックアップ**に移動します。ページの右上にある **<UI-TERM key="ocp-v2.src.constant.backup.BackUpNow">今すぐバックアップ</UI-TERM>** のドロップダウンリストから、**<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">バックアップテナント</UI-TERM>** を選択します。

* **方法2**：OCPにログインし、テナントの **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** ページに移動します。左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Backup.BackupStrategy.New.BackupAndRestoration">バックアップと復元</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.Backup.Component.BackupNowDrawer.BackUpNow">今すぐバックアップ</UI-TERM>** をクリックします。

## 前提条件

* **方法1** でテナントの即時バックアップを実行する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * バックアップ・リストアの **<UI-TERM key="ocp-v2.Component.AddBackupStrategy.Backup">バックアップ</UI-TERM>** メニュー権限。

* **方法2** でテナントの即時バックアップを実行する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** または **テナントメンテナンス** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">バックアップと復元</UI-TERM>** メニュー権限。

* OceanBase V3.2.2-20220304134610以降のバージョンのテナントである必要があります。
* OceanBaseは、ロック状態のテナントのバックアップをサポートしていません。

## 手順

以下の手順では、**方法1** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.compute.BackupAndRestoration">バックアップと復元</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.constant.backup.Backup">バックアップ</UI-TERM>** をクリックし、ページの右上にある **<UI-TERM key="ocp-v2.Detail.Backup.BackUpNow">今すぐバックアップ</UI-TERM>** のドロップダウンリストから、**<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">バックアップテナント</UI-TERM>** を選択します。

3. バックアップ対象を選択します。

   **<UI-TERM key="ocp-v2.Backup.Backup.BackupTenant">バックアップテナント</UI-TERM>** のドロップダウンリストから、バックアップする対象を選択します。システムは、テナントの **<UI-TERM key="ocp-v2.Cluster.New.ObVersion">OceanBaseのバージョン</UI-TERM>**、**<UI-TERM key="ocp-v2.Backup.Backup.Log.BackupMethod">バックアップ方法</UI-TERM>** を自動的に認識し、**<UI-TERM key="ocp-v2.Backup.Service.Detail.StorageConfiguration">ストレージ設定</UI-TERM>** を自動入力します。

4. ストレージ設定を入力します。

   * バックアップ対象のテナントに既存のバックアップ戦略がある場合、ストレージ設定は自動的に入力されます。

   * バックアップ対象のテナントにバックアップ戦略がない場合、手動でストレージ設定を入力する必要があります。画面上の指示に従って入力するか、[新規テナントレベルバックアップ戦略の作成](../500.regular-backup/200.manage-tenant-backup-strategy/100.creat-a-tenant-backup-stategy.md)の手順4を参照して入力してください。

     入力完了後、**<UI-TERM key="ocp-v2.Cluster.New.Test">テスト</UI-TERM>** をクリックして、ストレージ設定をテストします。

5. （オプション）カスタムバックアップ範囲機能のスイッチをオンにします。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>現在、カスタムバックアップ範囲をサポートしているOceanBaseのバージョンは、[4.2.1.11, 4.2.0)および[4.2.5.2, 4.3.0)です。</li>
    <li>テナントレベルのバックアップポリシーが設定されている場合、即時バックアップではカスタムバックアップ範囲を指定できません。</li>
    <li>データバックアップはデフォルトでフォロワーレプリカから、ログバックアップはデフォルトでリーダーレプリカからバックアップデータを読み取ります。</li>
    <li>バックアップ対象のゾーンを選択する際には優先順位を設定する必要があります。設定しない場合、バックアップ失敗やデータセンター間のトラフィック発生の原因となる可能性があります。</li>
    <li>カスタムバックアップ範囲機能のスイッチをオンにした場合、Primary Zoneをrandomに設定することは推奨されません。</li>
    </ul>
    </main>

   1. データバックアップのタイプを選択します：Zone、リージョン、またはデータセンター。次に、シャトルボックスを使用してZone、リージョン、またはデータセンターの優先順位を設定します。

   2. ログバックアップのタイプを選択します：Zone、リージョン、またはデータセンター。次に、シャトルボックスを使用してZone、リージョン、またはデータセンターの優先順位を設定します。

      ![Image 49](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/436/%E8%87%AA%E5%AE%9A%E4%B9%89%E5%A4%87%E4%BB%BD%E8%8C%83%E5%9B%B4.jpg)

6. データバックアップ方式を選択します。

   物理バックアップの場合はデータバックアップ方式を選択する必要がありますが、論理バックアップの場合はフルバックアップのみがサポートされます。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <ul>
    <li>物理バックアップを実行する前に、必ず一度のフルデータバックアップが必要です。そうでない場合、<code>Check if ready to data backup</code> ステップで「full data backup needed before incremental data backup」というエラーが表示されます。</li>
    <li>フルバックアップ中に <code>Start cluster compact if necessary</code> ステップでエラーが発生し、「Cluster compaction needed before full data backup」と表示された場合は、<a href="../../600.cluster-functions/1100.manage-cluster-merge/200.cluster-perform-merge.md">メジャーコンパクションの実行</a> を試してから、<strong>再試行</strong> ボタンをクリックしてバックアップを続行できます。</li>
    </ul>
    </main>

7. **<UI-TERM key="ocp-v2.Detail.Backup.BackUpNow">今すぐバックアップ</UI-TERM>** をクリックします。
