# OCP V3.2.3

<!--#RNDate#2021-12-27-->

OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、OCP）V3.2.3バージョンでは、ログのWeb画面でのクエリ機能とパラメータテンプレート機能が新たに追加されました。同時に、監視およびアラート機能にも飛躍的な更新が行われています。パフォーマンス監視ではドリルダウン分析をサポートし、一部のパフォーマンス指標を細分化して、ビジネスの包括的な理解と分析を容易にしました。SQL診断では、SQLスロットリング、実行計画の紐づけ、クエリの履歴紐づけの設定が可能です。パフォーマンスレポートでは、PRC、メモリ、パラメータ設定変更の統計情報の表示が追加されました。アラート機能はこのバージョンで複数のしきい値をサポートするだけでなく、10個の組み込みアラートも新たに追加され、OCPのOceanBaseクラスターに対する運用保守能力が強化されました。

## バージョン情報

* **バージョン番号：** V3.2.3

* **前バージョン：** V3.1.5

* **バージョンリリース日：** 2021年12月27日

* **サポートされるアップグレードパス：** OCP V2.3.x以降のバージョンからは、このバージョンへ直接アップグレードできます。OCP V2.3.0以前のバージョンからは、まずV2.3.xバージョンにアップグレードしてから、このバージョンにアップグレードする必要があります。

## サポートされるOceanBaseデータベースのバージョン

OceanBaseクラウドプラットフォームV3.2.3バージョンは、以下の表に記載されているバージョンのOceanBaseデータベースをサポートします。

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

## 新機能

* クラスターとテナントの **<UI-TERM key="ocp-v2.Monitor.AddMonitor.PerformanceMonitoring">パフォーマンス監視</UI-TERM>** では、監視データのドリルダウン分析が可能になりました。

  ドリルダウン機能を使用すると、監視指標を直接テナントまたはOBServerノードの次元に掘り下げて、その次元での指標データを確認できます。これにより、テナントの **<UI-TERM key="ocp-v2.page.Monitor.Monitoring">パフォーマンス監視</UI-TERM>** ページやホストの **<UI-TERM key="ocp-v2.Host.Detail.Surveillance">監視</UI-TERM>** タブに移動する必要がなくなりました。

* ログクエリ機能が新たに追加されました。この機能を使用すると、OCPインターフェース上でクエリ条件を設定し、必要なログを確認できます。クエリ範囲は、OBServerノード、OBProxy、ホストなど、すべてのログタイプをカバーしています。これにより、ダウンロードせずに簡単にログ検索が可能になります。

* SQL診断機能では、SQL詳細ページでSQLにインデックスを紐づけ、実行計画を紐づけ、SQLスロットリングおよび履歴クエリの紐づけが可能になりました。

* 10個の組み込みアラート項目が新たに追加され、アクティブセッション数、clog同期遅延、OCPクロスクラウド管理など、あらゆる側面の監視と予警が実現されました。同時に、アラートは複数のしきい値をサポートしており、OceanBaseクラスターのパフォーマンスと安定性をより確固たるものにします。

* パラメータテンプレート機能が新たに追加されました。同じ構成のテナントやクラスターを複数作成する場合、まずパラメータテンプレートを作成し、その後 **<UI-TERM key="ocp-v2.Detail.Tenant.NewTenant">新規テナント</UI-TERM>** または **<UI-TERM key="ocp-v2.page.Cluster.CreateANewCluster">クラスタを作成する</UI-TERM>** の際にテンプレートを適用することができます。これにより、**<UI-TERM key="ocp-v2.Tenant.New.CreateACluster">クラスタを作成する</UI-TERM>** または **<UI-TERM key="ocp-v2.Cluster.Detail.NewTenant">新しいテナントを作成</UI-TERM>** の際に、クラスター/テナントのパラメータを繰り返し設定する手間が省けます。

  * テンプレートの作成方法については、以下を参照してください：[クラスターパラメータテンプレートの管理](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377800)。

  * クラスターまたはテナントの作成方法については、以下を参照してください：[クラスターの作成](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000378283)、[新規テナントの作成](https://www.oceanbase.com/docs/enterprise-oceanbase-ocp-cn-10000000000377507)。

## 機能の強化

* パフォーマンス監視機能を最適化し、クラスタおよびテナントの関連指標をさらに細分化して、より詳細なパフォーマンス情報を提供します。これらの指標は以下のとおりです：

  * クラスタ：**QPS**、**クエリ応答時間**、**TPS**、**トランザクション応答時間**。

  * テナント：**リクエスト待機キュー**、**TPS**、**トランザクション応答時間**。

* OBServerノードのアップグレードおよび再起動ロジックを最適化し、停止状態でのOBServerノードのアップグレードおよび再起動をサポートします。この最適化により、ビジネス継続性要件がない場合でも、OBServerノードを迅速にアップグレードおよび再起動できるようになります。

* クラスタの**<UI-TERM key="ocp-v2.Detail.Report.PerformanceReport">性能レポート</UI-TERM>**機能を改善し、パフォーマンスレポートに**<UI-TERM key="ocp-v2.src.component.DeleteUnitSpecModal.Memory">メモリ</UI-TERM>**、**RPC**、**<UI-TERM key="ocp-performance-report.pages.AWR.ParameterConfigurationChanges">パラメータ設定の変更</UI-TERM>**の統計情報の表示を追加しました。

## 修正された問題

OceanBaseクラウドプラットフォームV3.2.3バージョンでは、以下の問題が修正されました：

* SQL診断の収集が不完全であり、フロントエンドの読み込みが遅い問題。

* パフォーマンスレポートの一部データが欠落する問題。

* タスク失敗後の再試行および放棄クリック時の異常問題。

## バージョンの使用制限

### ハードウェア要件

OCP-Serverは物理マシンにインストールできるほか、Dockerコンテナ内での実行もサポートしています。OCP-Serverは、複数ノードの高可用性デプロイメントモードをサポートしています。

OCP-Serverノードの最低ハードウェア要件は以下の表のとおりです。

| ハードウェア  |                 要求                 |
|-----|------------------------------------|
| CPU | <li>X86_64、8コア</li><li>ARM AArch64アーキテクチャ、8コア</li> |
| メモリ  | 利用可能メモリ16GB                         |
| NIC  | 10ギガビットNIC                               |

OCP-Agent自体が消費するリソースは非常に少なく、インストールノードのハードウェアリソースに特別な要件はありません。

### オペレーティングシステム要件

OCPサーバー側（OCP-Agentを含む）のインストールに必要なオペレーティングシステム要件は以下の表のとおりです。

|    サーバーの種類    |    OS        |   対応バージョン    |
|-------------|------------|-----------|
| x86_64      | RHEL       | 7.2以降のバージョン |
| x86_64      | CentOS     | 7.2以降のバージョン |
| x86_64      | AliOS      | 7.2以降のバージョン |
| x86_64      | openSUSE   | 12 SP3以降 |
| ARM aarch64 | AliOS      | 7.2以降のバージョン |
| ARM aarch64 | NeoKylin    | 7.6       |
| ARM aarch64 | Huawei EulerOS | 2.0 SP8   |

### クライアント要件

一般的にユーザーはWebブラウザを通じてOCPサービスにアクセスします。そのため、クライアントに関する要件は以下のとおりです。

|   ブラウザ   | 最小バージョン |
|---------|------|
| Chrome  | 81   |
| Firefox | 64   |
| Safari  | 10   |
| Edge    | 13   |

iOSオペレーティングシステムを搭載したデバイスからOCPにアクセスする場合、バージョン要件は以下の表のとおりです。
