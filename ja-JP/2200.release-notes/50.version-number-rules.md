# バージョン番号ルール

本記事では、OCPのバージョン番号ルールとその意味について説明します。

OCPは継続的にイテレーションと最適化が行われており、不定期に新しいバージョンがリリースされます。異なるバージョンのOCPでは機能や特徴に大きな差異が生じる場合があるため、正確なドキュメント情報を入手するためには、OCPのバージョン番号を識別する必要があります。

OCPのバージョンはV.x.y.z-t形式で表されます。各部分の意味は次のとおりです。

* x はメジャーバージョンを表します。このバージョンでは通常、アーキテクチャのアップグレードや大規模な新機能がリリースされます。

* y は計画されたイテレーションバージョンを表します。このバージョンは通常のイテレーション計画に基づき、重要な機能や特徴の更新・向上が含まれます。

* z は更新バージョンを表します。このバージョンには少数の機能や特徴の更新、および既知の問題の修正が含まれます。

* t は通常、リリース日時の文字列で表示されます（例：4.3.2-20241011163611、4.3.5-20250610150154など）。機能や問題の修正により高いバージョン番号のリリースが必要な場合に使用されます。

## バージョン番号の確認

OCPをデプロイした後、以下の手順で現在のOCPのバージョン番号を確認できます。

1. OCPにログインします。

2. カーソルを右上の **ヘルプ** に合わせ、**OCPについて** をクリックします。

3. ポップアップウィンドウで、現在のOCPのバージョン番号を確認します。バージョン番号の例：4.3.2-20241011163611。
