# OCP V4.5.1

OCP V4.5.1は、複雑な本番環境における日常的な管理・運用能力を強化し、高リスクな操作が人の経験に依存している、バックアップストレージの階層計画が難しい、テナント容量問題の発見が遅れがちであるといった実際の課題に重点的に対処します。

## バージョンの特徴

### 標準的な運用保守プロセス

標準的な運用保守プロセスが追加され、複雑でリスクの高い操作を保存可能で実行可能かつ追跡可能な運用保守タスクに整理し、手動確認のステップと操作の見落としを減らします。

今回、以下のプロセスが組み込まれています：

+ スタンバイテナントの再構築
+ レプリカ異常時のアービトレーションサービスの開始
+ OBServer異常後のデータ再構築

運用保守担当者は各ステップの実行進捗状況を確認でき、失敗した場合はリトライできます。スタンバイテナントの再構築は、管理対象のプライマリ/スタンバイテナントが異なるOCPに属するシナリオをサポートします。その他の2つのプロセスは、現在OCPが管理するクラスタのみをサポートします。

### バックアップデータとアーカイブログの分離ストレージ

OceanBase 4.xクラスタは、バックアップデータとアーカイブログに異なるストレージ場所を設定でき、信頼性、容量、コストに応じてファイルストレージまたはオブジェクトストレージを選択できます。この機能は、バックアップポリシー、即時バックアップ、バックアップスキャン、テナント復元に適用されます。

既存の共有ストレージ方式は変更されません。分離ストレージを使用する必要がある場合は、まずOCP全体のアップグレードを完了してから、新しい設定を有効にすることを推奨します。

### Unitデータディスクのクォータ

Shared-NothingクラスタのUnit仕様では、データディスクのクォータ設定をサポートし、テナントおよびリソースビューで使用状況を表示します。使用率が80%および90%に達すると、システムはそれぞれ警告と重大な警告を生成し、容量不足になる前に拡張またはデータガバナンスを計画するのに役立ちます。

このクォータはソフトリミットであり、クォータを超えても業務の書き込みは中断されません。OceanBase 4.0以降のバージョンに適用されます。

## その他の新規機能と最適化

+ スタンバイテナントはログ復元の遅延を設定でき、遅延状態の監視と警告が提供されます。
+ アラート、モニタリング、巡回検査、パラメータ設定などの主要な製品テキストをカバーする日本語インターフェースが追加されました。
+ 透過的データ暗号化のシナリオにおけるKMSの対応を拡張し、Alibaba Cloud Apsara Stack、信安世纪、江南科友（金融）などのソリューションを新たに追加し、格尔KMSのHTTPS接続能力を改善しました。
+ ソフトウェアパッケージはSHA256による整合性検証をサポートし、アップロード数と総容量の制限が追加されました。
+ アラートイベントにリソースタグが追加され、長時間トランザクションアラートにログストリーム情報が補足され、特定のテナントやログストリームの特定が容易になりました。
+ SQLクエリインターフェースはデータベースユーザーの指定をサポートし、既存のアカウント権限に基づいてクエリを実行しやすくなりました。
+ グローバルバックアップ情報の解析とオフライン復元インターフェースが新たに追加され、自動化された復元プロセスの連携が容易になりました。
+ OCPとAgentのリソース監視、リアルタイム監視クエリ、多言語検索体験が最適化されました。

## 動作の変更と適用範囲

### 動作の変更

+ プライマリテナントのクローンはサポートされなくなりました。スタンバイテナントのクローン機能は影響を受けません。
+ ソフトウェアパッケージのアップロードに数と総容量の制限が追加され、制限を超えた場合、システムがアップロードを阻止します。

### 適用範囲

+ データとログの分離ストレージはOceanBase 4.xクラスタに適用されます。OceanBase 3.xクラスタは引き続き同一のストレージ場所を使用します。
+ UnitデータディスククォータはShared-Nothingクラスタに適用され、Shared-StorageおよびOceanBase AIクラスタには適用されません。
+ スタンバイテナントのログ復元遅延機能を有効にするには、OceanBase 4.4.2.2以降のバージョンが必要です。

## 主な修正内容

+ プライマリ/スタンバイテナントの切り替え、復元元の変更、遅延復元のシナリオにおける一部の異常を修正し、クラスタ間の災害復旧操作の安定性を向上させました。
+ バックアップストレージの認識、ログバックアップのチェック、および一部の復元シナリオにおける問題を修正しました。
+ AIクラスタとLogServiceで、Zoneの停止、キーローテーション、タスクのロールバック時に発生する一部のエラーを修正しました。
+ リアルタイム監視クエリの遅延、一部ホストの監視データ欠落、Agentリソースメトリクス表示異常などの問題を修正しました。
+ Oracleテナントのクエリ結果の日付時刻型異常、およびデータベース名の大文字小文字によるインデックス情報が空になる問題を修正しました。
+ SOPの権限検証、操作対象認識、タスク再試行、ページ表示などの問題を修正しました。

## 残存問題

| 問題の説明 | 発生確率 | 解決策 |
|---------|------|---------|
| OCP V4.5.1で分離ストレージからの復元を開始した際に、解析異常が発生する | 特定条件下 | バックグラウンドタスクを待機する |
| OCP V4.5.1でクラスタレベルのテナント復元が失敗する | 特定条件下 | 技術サポートにお問い合わせください |

## セキュリティ脆弱性の修正

複数の権限検証、入力検証、機密情報保護の問題を修正しました。このバージョンへのアップグレードを推奨します。
