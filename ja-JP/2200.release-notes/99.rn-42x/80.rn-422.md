# OCP V4.2.2

<!--#RNDate#2024-2-21-->

## V4.2.2

OCP V4.2.2は、OceanBase V4.2.2バージョンを正式にサポートし、OceanBaseのフルリンクトレースモジュールのクローズドループ管理機能を全面的に実装しています。例えば、OceanBase/OBProxyクラスタの移出機能やアービトレーションサービスによる引き継ぎ・移出などの機能をサポートしており、基本的な運用保守機能の完備度は95%に達しています。同時に、このバージョンでは重要な機能として「監視ダッシュボード」が提供されており、ユーザーは大規模なキャンペーンシナリオでのリアルタイム監視やカスタマイズ可能なパフォーマンス監視を実現できます。バックアップ・リカバリにおいては、Huawei Cloud OBSをサポートし、中国国内の主要なクラウドベンダーのストレージメディアへの対応をさらに強化しています。また、このバージョンでは監視・アラート、タスク管理、バックアップ・リカバリ、パスワード管理、ラベル管理などの分野で30項目以上の最適化と強化を行い、900項目以上の製品エラーコードを提供しています。これにより、製品の使いやすさと安定性を重点的に向上させ、よりシンプルで使いやすいライフサイクル全体のデータベース管理プラットフォームを構築し、ユーザーがOceanBaseデータベースをより効果的に管理できるよう支援します。

### 新機能

#### OceanBase V4.x対応

* モニタリング指標の追加：テナントレベルのログ同期最大遅延。詳細については、[clog 同期遅延
](https://www.oceanbase.com/docs/common-ocp-1000000000585563)。

#### モニタリングダッシュボード

モニタリングダッシュボードは、主にダブル11のような「盤を見る」シナリオや、ユーザー定義のモニタリングビューに対するニーズを満たすものです。ユーザーの複数インスタンス・複数指標のモニタリングビューにおける監視データの比較機能、チャートの連動、そしてパイチャート、テーブル、柱状図など7種類のチャート表示タイプをサポートしています。これにより、データベースシステム全体のパフォーマンスと運用状態を監視することができます。詳細については、[モニタリングダッシュボード](https://www.oceanbase.com/docs/common-ocp-1000000000584639)を参照してください。

#### タグの管理

OCPのタグには、整理・分類、クイック検索とフィルタリング、タスクおよびプロジェクト管理、チーム連携と共有の機能が備わっています。これにより、ユーザーはさまざまなデータベースオブジェクトを柔軟かつ効率的に整理・検索・管理でき、チーム連携のレベルを向上させることができます。詳細については、[タグの管理](https://www.oceanbase.com/docs/common-ocp-1000000000585054)を参照してください。

### 主な機能の解説

#### モニタリングダッシュボード

モニタリングダッシュボードは、例えばダブル11のような「盤を見る」シナリオや、ユーザー定義のモニタリングビューに対するニーズを満たします。モニタリングダッシュボードタブでは、複数のモニタリングダッシュボードページを作成でき、各ページには複数のチャートを追加して、ユーザーのマルチインスタンス、マルチメトリクスモニタリングビューの関連表示、単一または複数のクラスタの異なるモニタリング指標など、さまざまな指標とデータを表示できます。同時に、モニタリングダッシュボードは前年同期比、日比、週比、月比の4種類のモニタリング比較方式を提供し、データの異常を簡単に発見するのに役立ちます。また、データの特性とニーズに応じて、折れ線グラフ、円グラフ、テーブルなど7種類の異なるチャートタイプを選択できるため、データの理解と分析を深めることができます。さらに、モニタリングダッシュボードはグループ化機能も提供しており、関連する指標を同一グループに入れて統一的に管理することで、データベースの状況をより効果的に監視・分析できます。モニタリングダッシュボードは、チャートのドラッグ＆ドロップ、拡大、ドリルダウン（単一指標シナリオ）、チャート連動など、多様な機能をサポートしており、データベースシステム全体のパフォーマンスと運用状態を監視する目標の達成を支援します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>単一のモニタリングダッシュボードは最大32枚のチャートをサポートします。</p>
  </main>

#### タグ管理

OCPは、OceanBaseクラスタ、アービトレーションサービス、テナント、OBProxyクラスタ、ホストの5種類のオブジェクトタイプに対するタグ付け操作をサポートしており、新規作成、編集、削除、関連オブジェクトの変更などの管理機能もサポートしています。2種類の異なるスタイルから、ビジネス状況に合わせて適切なタグ表示形式を選択できます。OceanBaseクラスタなど、さまざまなオブジェクトタイプの画面では、クラスタにタグを付けて業務的な意味を付与できます。例えば、システムタイプ、管理者などです。同時に、タグフィルタリング機能により、クラスタオブジェクトの整理、検索、管理が容易になり、作業効率が向上します。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>タグ管理はAdminロールのユーザーのみがサポートします。</p>
  </main>

### 修正された問題

OCP V4.2.2バージョンでは、主に以下の問題が修正されました：

* OceanBaseデータベースV4.2バージョンで、パラメータ`EnableRebalance`の設定によりバージョンアップグレードが失敗する問題を修正しました。
* マシン再起動後に`obproxyd.sh`を起動できない問題を修正しました。
* Kylin V10システムでの起動時自動起動項目が有効にならない問題を修正しました。
* ログディスクリソースの表示比率が異常である問題を修正しました。
* モニタリングクエリロジックを最適化し、GC発生確率を低減しました。
* 前端ページのアクセスパフォーマンスを複数箇所最適化し、同等の管理規模でより高速なアクセス速度を実現しました。

### バージョンの使用制限

#### ハードウェア要件

OCP-Serverは物理マシンへのインストールが可能であり、Dockerコンテナでの稼働もサポートしています。OCP-Serverはマルチノード高可用性デプロイメントモードをサポートしています。

OCP-Serverノードの最低ハードウェア要件は以下の表のとおりです。

| ハードウェア | 要件 |
|-------|------------------------------------|
| CPU | <li>X86_64、8コア</li><li>ARM AArch64アーキテクチャ、8コア</li> |
| メモリ | 利用可能メモリ 16 GB             |
| NIC | 10ギガビットNIC                |

OCP-Agent自体が消費するリソースは非常に少なく、インストールノードのハードウェアリソースに特別な要件はありません。

#### オペレーティングシステム要件

OCPサーバー側（OCP-Agentを含む）のインストールに必要なオペレーティングシステム要件は以下のとおりです。

| サーバータイプ    | オペレーティングシステム    | 対応バージョン   |
|-------------|------------|-----------|
| x86_64   | RHEL    | 7.2以降のバージョン |
| x86_64   | CentOS   | 7.2以降のバージョン |
| x86_64   | AliOS   | 7.2以降のバージョン |
| x86_64   | openSUSE  | 12 SP3以降 |
| ARM aarch64 | AliOS   | 7.2以降のバージョン |
| ARM aarch64 | 中标麒麟    | 7.6    |
| ARM aarch64 | 华为 EulerOS | 2.0 SP8  |
| x86_64 | Debian    |  Debian GNU/Linux 11 (bullseye)  |
| x86_64 | Ubuntu | Ubuntu 18.04.6 LTS |
