# OCP V3.3.3

<!--#RNDate#2022-07-18-->

OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、OCP）の新バージョンは、主にパスワードボックスおよび巡回検査機能のアップグレードを行い、OceanBaseのバージョンに対応させるとともに、その他の機能も向上・最適化しています。

## バージョン情報

* **バージョン番号：** V3.3.3

* **前回バージョン：** V3.3.1

* **リリース日：** 2022年7月18日

* **サポートされているアップグレードパス：** OCP V2.3.x以降のバージョンからは直接このバージョンへアップグレードできます。OCP V2.3.0以前のバージョンからは、まずV2.3.xバージョンにアップグレードし、その後このバージョンにアップグレードする必要があります。

## サポートされているOceanBaseデータベースのバージョン

OCP V3.3.2バージョンは、下表に記載されているバージョンのOceanBaseデータベースをサポートしています。

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

## 新機能

### パスワードボックス

* 接管したクラスタに対して、クラスタまたはテナントのパスワードのインポート、エクスポート、共有操作をサポートします。

* パスワードボックス内の接続情報を他のOCPユーザーと共有できます。

### 監視

テナントのパフォーマンス監視ページに**メモリ使用率**指標が追加され、OceanBase側のテナントの使用済みメモリの割合を表示できるようになりました。

### セキュリティ

* **パスワード設定によるアカウント有効化**機能が追加されました。初回OCPへのログイン時に、組み込みアカウントのパスワードを変更する必要があります。

* ブラウザコンソールから平文パスワードに関するヒント情報が削除され、システムのセキュリティが向上しました。

## 機能強化

### OBProxy

OBProxyクラスタで、再起動後に有効になるパラメータの変更をサポートします。

### 巡視

**クラスタヘルス巡視**機能を**<UI-TERM key="ocp-v2.Inspection.Item.ConfigItem.Inspection">巡回点検</UI-TERM>**モジュールに統合し、巡視機能を改善・最適化します。

### バージョン対応

* OceanBase V3.2.4に対応し、MySQLテナント作成時のSRSデータインポートをサポートします。

* OceanBase V3.2.3.1に対応し、カーネルバージョン番号の取得方法を新規則則に適応させます。

## 修正された問題

OCP V3.3.2では、以下の問題が修正されました：

* いくつかのAgentのパフォーマンス問題を最適化し、Agentの安定性を向上させます。

* Server側のスレッドプールロジックを最適化し、監視クエリのパフォーマンスを向上させます。

* バックアップ・リストアの収集プロセスを最適化し、大容量バックアップ下でのOCPの安定性を向上させます。

* SQL診断データのリアルタイム性を最適化し、OASの診断データ取得速度を向上させます。

* アドミンアカウントの組織権限検証ロジックを最適化し、専用クラウドシナリオに適応させます。

* クラスタ作成時のデフォルトディレクトリの事前チェックプロセスを最適化し、問題がある場合に早期にエラーを表示してタスク全体のロールバックを回避できるようにします。

* monagentファイルハンドルの残留問題を修正します。

* 特殊なシナリオでクラスタ接続失敗エラーが発生する問題を修正します。

* バックアップ・リストアスケジューリングのタイムアウト問題を修正します。

* バックアップ・リストアを低バージョン(V2.x)から高バージョン(3.x)にアップグレードした後、サービスリストが表示されない問題を修正します。

* バックアップ・リストアの状態別フィルタリング失敗問題を修正します。

* データなし時のマージ管理ページでNPEが発生する問題を修正します。

* OATを使用したOCP V3.3.0のデプロイに失敗する問題を修正します。

* いくつかの巡視の国際化問題を修正します。

* 特定の状況下でデータディスク使用率が100%を超えて表示される問題を修正します。

* 例外状態においてCPU sys利用率に対するアラートが発報されない問題を修正しました。

## バージョンの使用制限

### ハードウェア要件

OCP-Serverは物理サーバーにインストールできるほか、Dockerコンテナ上での稼働もサポートしています。OCP-Serverは複数ノードの高可用性デプロイメントモードをサポートしています。

OCP-Serverノードの最低ハードウェア要件は以下の表のとおりです。

| ハードウェア  |                 要件                 |
|-----|------------------------------------|
| CPU | <li>X86_64、8コア</li><li>ARM AArch64アーキテクチャ、8コア</li> |
| メモリ  | 利用可能メモリ16GB                         |
| NIC  | 10ギガビットNIC                               |

OCP-Agent自体が消費するリソースは非常に少なく、インストールノードのハードウェアリソースに特別な要件はありません。

### オペレーティングシステム要件

OCPサーバー側（OCP-Agentを含む）のインストールに適したオペレーティングシステムの要件は以下の表のとおりです。

|    サーバータイプ    |    オペレーティングシステム    |   対応バージョン    |
|-------------|------------|-----------|
| x86_64      | RHEL       | 7.2以降のバージョン |
| x86_64      | CentOS     | 7.2以降のバージョン |
| x86_64      | AliOS      | 7.2以降のバージョン |
| x86_64      | openSUSE   | 12 SP3以降 |
| ARM AArch64 | AliOS      | 7.2以降のバージョン |
| ARM AArch64 | NeoKylin    | 7.6       |
| ARM AArch64 | Huawei EulerOS | 2.0 SP8   |

### クライアント要件

一般的にユーザーはWebブラウザを通じてOCPサービスにアクセスします。そのため、クライアントに関する要件は以下のとおりです。

|   ブラウザ   | 最低バージョン |
|---------|------|
| Chrome  | 81   |
| Firefox | 64   |
| Safari  | 10   |
| Edge    | 13   |

iOSオペレーティングシステムを搭載したデバイスからOCPにアクセスする場合、必要なバージョン要件は次の表のとおりです。

| OS | 最小バージョン |
|------|------|
| iOS  | 10   |

最適なユーザーエクスペリエンスを得るために、解像度が1440 × 810より高いディスプレイの使用を推奨します。
