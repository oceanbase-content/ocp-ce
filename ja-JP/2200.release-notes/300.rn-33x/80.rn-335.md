## V3.3.5 BP2

### バージョン情報

* **バージョン番号：** V3.3.5 BP2

* **前回のバージョン：** V3.3.5 BP1

* **リリース日：** 2023年11月29日

### バグ修正

* スイッチオーバーの切り替え時間を短縮しました。

* 大量のテナントを管理する際に予期しない数のスレッドが生成される問題を修正しました。

* モニタリングデータで直近1時間分のデータしか確認できない問題を修正しました。

* SQL収集時にメモリ上限を超えた場合の縮退処理が有効にならない問題を修正しました。

## V3.3.5

OceanBase Cloud Platform（OCP）の新バージョンでは、一部の監査イベントが追加されたほか、その他の機能も向上・最適化されています。

### バージョン情報

* **バージョン番号：** V3.3.5

* **前バージョン：** V3.3.4

* **リリース日：** 2023年07月25日

* **サポートされているアップグレードパス：** OCP V2.3.x以降のバージョンからは、このバージョンへ直接アップグレードできます。OCP V2.3.0より前のバージョンからは、まずV2.3.xバージョンにアップグレードし、その後このバージョンにアップグレードする必要があります。

### サポートされているOceanBaseデータベースのバージョン

OCP V3.3.5バージョンは、下表に記載されているバージョンのOceanBaseデータベースをサポートしています。

* OceanBase V1.4.x

* OceanBase V2.1.x

* OceanBase V2.2.x

* OceanBase V3.1.x

* OceanBase V3.2.x

### 新機能

* テナントレベルのモニタリング指標として、**<UI-TERM key="ocp-v2.page.Overview.Content.ThreadUsage">スレッド使用率</UI-TERM>**を新規追加しました。これにより、ユーザーは問題の診断を容易に行えます。

* テナントレベルのモニタリング指標 **CPU消費量** の計算ロジックを最適化し、より正確なリソース消費比率を提供します。

### 修正された問題

OCP V3.3.5バージョンでは、以下の問題が修正されました：

1. V3.3.4-BP1からV3.x系列のより新しいバージョンにアップグレードする際に、診断ページでエラーが発生する問題を修正しました。

2. V3.3.x-BPシリーズからアップグレードする際のその他の問題を修正しました。

3. ソフトウェアパッケージのダウンロードロジックを最適化し、複数ホストによる同時アップグレードをより適切にサポートできるようにしました。

4. データ管理ロジックを最適化し、30日より前の履歴タスクデータを自動的にクリーンアップすることをサポートし、ストレージ容量の使用量を削減しました。

### 既知の問題

なし。

### バージョンの制限

#### ハードウェア要件

OCP-Serverは物理マシンにインストールできるほか、Dockerコンテナ内での実行もサポートしています。OCP-Serverは、マルチノードの高可用性デプロイメントモードをサポートしています。

OCP-Serverノードの最低ハードウェア要件は、下表のとおりです。

| ハードウェア | 要件                                 |
|-------|------------------------------------|
| CPU   | <li>X86 X64 アーキテクチャ、8コア</li><li> ARM AArch64 アーキテクチャ、8コア</li> |
| メモリ | 利用可能メモリ 16 GB                         |
| NIC | 10ギガビットNIC                               |

OCP-Agent自体が消費するリソースは非常に少なく、インストールノードのハードウェアリソースに特別な要件はありません。

#### オペレーティングシステム要件

OCPサーバー側（OCP-Agentを含む）のインストールに必要なオペレーティングシステム要件は以下のとおりです。

|    サーバータイプ    |    オペレーティングシステム    |   対応バージョン    |
|-------------|------------|-----------|
| x86_64      | RHEL       | 7.2以降のバージョン |
| x86_64      | CentOS     | 7.2以降のバージョン |
| x86_64      | AliOS      | 7.2以降のバージョン |
| x86_64      | openSUSE   | 12 SP3以降 |
| ARM AArch64 | AliOS      | 7.2以降のバージョン |
| ARM AArch64 | NeoKylin    | 7.6       |
| ARM AArch64 | Huawei EulerOS | 2.0 SP8   |

#### クライアント要件

一般的にユーザーはWebブラウザを通じてOCPサービスにアクセスします。そのため、クライアントに関する要件は以下のとおりです。

| ブラウザ     | 最小バージョン |
|---------|------|
| Chrome  | 81   |
| Firefox | 64   |
| Safari  | 10   |
| Edge    | 13   |

iOSオペレーティングシステムを搭載したデバイスからOCPにアクセスする場合、バージョン要件は以下のとおりです。

| オペレーティングシステム | 最小バージョン |
|------|------|
| iOS  | 10   |
