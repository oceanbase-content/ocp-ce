# OCP V4.3.6

## V4.3.6 BP1

### バージョン情報

* **バージョン番号：** V4.3.6 BP1

* **前回のバージョン：** V4.3.6

* **リリース日：** 2025年8月11日

### 新機能

* OceanBase Centralized Enterprise Editionでは、ライセンスの表示、インポート、およびライセンスの期限切れ・期限到来に関するプロンプトやアラートなどの機能をサポートします。
* OceanBase Centralized Enterprise Editionのサービスを停止して分散型クラスタに拡張することをサポートします。
* OceanBase Centralized Enterprise Editionをより高いデータベースバージョンにアップグレードすることをサポートします。

### 製品最適化

* ホストOSカーネルバージョンが5.1.0未満の場合、クラスタのCgroup設定をデフォルトで無効にします。
* OBProxyバージョンがV4.3.1未満の場合、V4.3.4へのホットアップグレードはサポートされません。
* アラートに具体的な対象がない場合、自動消去を無効にすることができ、該当するアラートが自動的に復旧するのを防ぎます。
* 単一ノード構成における運用操作を制限します。例えば、OBServerの再起動やZoneの停止などはサポートされません。

## V4.3.6

OCP V4.3.6がリリースされました！今回のアップグレードは、**インテリジェンス**、**セキュリティ強化**、および **基盤機能の飛躍的向上** に焦点を当て、企業のデータベース運用管理を全面的に支援します。

* **インテリジェントな運用アシスタント**：OceanBase AIアシスタントを新たに導入し、大規模言語モデルとデータベースのネイティブ機能を深く統合することで、OceanBaseのエコシステム全体をカバーするインテリジェントなQ&Aサービスを構築し、運用上の質問に対して効率的かつ正確な回答を実現します。
* **セキュリティ機能のアップグレード**：OceanBase TDE（透過的データ暗号化）およびエンドツーエンドSSL暗号化機能を新たに追加し、データの保存から伝送までの全プロセスを保護し、データベースのセキュリティ防御ラインを強化します。
* **ネットワークアーキテクチャの適応**：IPv6のフルシナリオデプロイをサポートし、IPv6アドレスを持つOceanBaseクラスタのライフサイクル全体を管理することで、コンプライアンス要件とネットワーク進化のニーズを満たします。
* **30以上の機能最適化**：パフォーマンス監視、プライマリ/スタンバイデータベース管理、バックアップ・リストア、アラートセンター、巡回点検サービスなどのコアモジュールを徹底的に最適化し、操作の利便性と管理効率を大幅に向上させ、ユーザーがデータベース運用作業フローを容易に管理できるよう支援します。

### 新機能

#### 基盤運用

* **クラスタ管理**：インターネットプロトコルバージョン6（IPv6）を全面的にサポートし、クラスタ内のIPv6アドレスを管理できます。IPv6ネットワーク環境へのシームレスな対応により、政府や金融業界などの厳格なネットワークセキュリティ監督要件を満たします。
  * サポートされているOceanBaseのバージョン範囲は[V4.2.5 BP3 Hotfix3, V4.3.0)、[4.3.5 BP2 Hotfix1, +∞)です。
  * サポートされているOBClientのバージョン範囲は[V2.2.9, +∞)です。
  * サポートされているOBProxyのバージョン範囲は[V4.3.4, +∞)です。
* **クラスタ管理**：セキュリティ設定では、TDE（透過的データ暗号化）を設定できます。これにより、攻撃者がデータベースを迂回してストレージ層から機密情報を直接読み取ることを防ぎ、ユーザーデータのセキュリティを確保します。サポートされているOceanBaseのバージョン範囲は[V4.0.0, +∞)です。
* **クラスタ管理**：セキュリティ設定では、SSL通信暗号化（TCPおよびRPC）を設定できます。通信データが伝送途中で改ざんされることによるセキュリティリスクを防ぎ、システムのセキュリティを向上させます。サポートされているOceanBaseのバージョン範囲は[V4.0.0, +∞)です。
* **OBProxy**：セキュリティ設定では、SSL通信暗号化（TCPおよびRPC）を設定できます。通信データが伝送途中で改ざんされることによるセキュリティリスクを防ぎ、システムのセキュリティを向上させます。サポートされているOBProxyのバージョン範囲は[V2.0.0, +∞)です。
* **テナント管理**：一般ユーザーの一括ロックおよびロック解除をサポートし、データ移行やデータのインポート・エクスポートなどのシナリオにおけるユーザーの運用効率を向上させます。
* **テナント管理**：プライマリテナントのバックアップセットをコピーする方法でスタンバイテナントを構築できるようになり、災害復旧管理計画が強化されました。
* **ホスト管理**：リージョン、データセンター、ホストタイプの管理機能をサポートしていますが、関連するホストが存在するオブジェクトの削除は現在サポートされていません。

#### 監視・アラート

* モニタリング期間内のモニタリング指標の最大値（max）、平均値（avg）、および現在値（current）の表示をサポートします。
* QPSと応答時間に加えて、CommitやRollbackなどのモニタリング項目を追加できます。対応するOceanBaseバージョンは[V4.2.5 BP3, V4.3.0)、[V4.3.5 BP2, +∞)です。
* `/var/log/messages`をクエリすることでハードウェア監視が可能となり、ユーザーはハードウェア関連の障害を迅速に検出できます。

#### 巡回点検サービス

同一クラスタ内のOBServerのクロックソースの設定を巡回点検し、クロックソースの設定の不整合によるメジャーコンパクションの異常を回避します。

#### Binlog管理

* Binlogサービスを有効化する際にインスタンスレプリカ数を設定できます。Binlogサービスは、クラスタのBinlog Server数に基づいてインスタンスレプリカを自動的に分散配置します。
* Binlogインスタンスはインスタンスレプリカの追加機能をサポートしており、単一のビジネステナントで最大5つのインスタンスレプリカをサポートします。
* Binlogスタンバイインスタンスの管理をサポートし、起動、停止、レート制限、再起動、削除、リーダー切り替えなどの操作が可能です。
* Binlogプライマリインスタンスの削除をサポートします。
* BinlogサービスのMetaDBに対する運用保守操作を禁止するヒントを実装し、誤操作によるBinlogサービスの異常を防ぎます。

#### バックアップ・リストア

* Zone、Region、IDCのバックアップ属性を設定でき、複数地域または複数データセンター展開シナリオにおけるリージョン間ネットワークトラフィックを削減し、バックアップ速度を向上させます。
* テナント復元時にZone優先順位をRandomに設定できます。

#### プラットフォーム機能

* **AIアシスタント**：LLM + PowerRAG + 組み込みOceanBaseナレッジベースに基づき、OceanBaseおよび関連製品に関するインテリジェントなQ&Aサービスを提供します。
* **運用管理**：レポートセンターでは、OceanBaseクラスタ/テナント/OBProxyクラスタ/ホスト/Binlogサービス/アービトレーションサービスなどのリソース情報レポートの作成とダウンロードをサポートし、`ocp.report.center.report.retention.days`パラメータでレポートの保持期間を変更できます。
* **パラメータテンプレート**：yaml形式のOceanBaseクラスタ/テナント/OBProxyクラスタ/Binlogサービスのパラメータテンプレートのインポートとエクスポートをサポートします。
* **クラスタ管理** > **運用設定**：Waitevent、Cacheヒット率、パーティション数などの情報収集を有効にするための5つの収集指標スイッチが新規追加されました。

### 製品の最適化

#### クラスタ管理

* 直接削除できるのは、停止済み/利用不可/廃棄済み/移出済みなどの状態にあるクラスタのみです。

### 主要な機能の解説

#### AI アシスタント（実験的機能）

OceanBase AI アシスタントは、大規模言語モデル（LLM）と検索拡張生成技術（PowerRAG）を深く統合し、組み込みの OceanBase ナレッジベースおよびデータベース固有のベクトル・全文インデックス機能と融合することで、インテリジェントな Q&A のコアエンジンを構築します。PowerRAG を基盤とした多段階検索メカニズムにより、LLM はナレッジベースに蓄積された技術ドキュメント、ベストプラクティス、障害事例を正確に呼び出し、システム構成の最適化、障害診断と修復、パフォーマンスボトルネックの分析など、データベース運用のコアシナリオに対して、体系的かつ専門的なソリューションを提供します。

大規模言語モデルの設定に関して、OCP は **システム管理** > **外部連携** > **AI モデル** 機能モジュールを通じて、Alibaba Cloud Tongyi Qianwen、ByteDance DouBao、DeepSeek などのサードパーティ大規模言語モデルサービスへの柔軟な接続、または独自の大規模言語モデルのデプロイをサポートします。ユーザーは LLM + 埋め込みモデル + 再ランキングモデル（Rerank）（オプション）を自由に構成し、AI アシスタント機能を迅速に有効化できます。同時に、OCP は企業専用のベストプラクティスや標準操作手順（SOP）などの専門知識のインポートをサポートし、ナレッジベースの業界適応性を継続的に拡張します。

#### SSL（Secure Sockets Layer）通信暗号化

デジタルトランスフォーメーションが加速する中、データ転送の安全性は重要な要件となっています。OBProxy と OceanBase は SSL 通信暗号化機能を備えており、伝送層に暗号化通信チャネルを確立することで、ネットワーク接続にエンドツーエンドの保護を提供し、データの盗難や改ざんのリスクを効果的に防止します。これにより、通信プロセスの機密性と完全性が確保され、データ転送の安全防衛線が基盤から強化されます。

全リンク運用管理の中枢として、OCP（OceanBase Cloud Platform）は証明書のライフサイクル全体をカバーする管理能力を提供します：

* **便利な証明書操作**：ワンクリックで証明書のアップロード・削除が可能で、証明書管理プロセスが簡素化されます。
* **高度なセキュリティ設定**：OBProxy と OceanBase の SSL 暗号化設定機能を統合し、証明書更新ポリシーのカスタマイズをサポートすることで、暗号化リンクの持続的な有効性を保証します。
* **多形式証明書サポート**：ビジネスアプリケーションアクセスに必要な p7b/PEM/JKS などの標準形式証明書のダウンロードを提供し、異なる技術スタックのセキュアアクセス要件を満たします。

OCP の統一管理により、ユーザーはビジネスアプリケーション > OBProxy > OBServer の全リンクセキュア通信および OBServer 間の RPC セキュア通信のデプロイと監視を容易に実現できます。これにより、ビジネスアクセス、プロキシ転送、ノード間相互作用などの重要なプロセスにおけるデータの安全な転送が確保され、データベースの安定稼働のための包括的なセキュリティバリアが構築されます。
