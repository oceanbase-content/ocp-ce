# NICレートの確認

このセクションでは、クラスタのNICレートを確認する方法について説明します。

## 適用シナリオ

この点検項目は、OceanBaseクラスタがNICレートを正しく取得し、それに基づいてクラスタ内ノード間のデータ転送を適切に処理できるかどうかをチェックします。

## 前提条件

なし。

## 技術原理

OceanBaseは、優先的に`{WORK_DIR}/etc/nic.rate.config`設定ファイルからNICレートの設定を取得します。この設定ファイルが存在しない場合、OceanBaseはOSからNICレートを照会する試みをします。
上記のいずれからもNICレートを取得できない場合、デフォルト設定が採用されます。この設定は実際と異なることが多く、移行レプリケーション時のネットワーク速度が非常に遅くなったり、プライマリ/スタンバイデータベースのレイテンシが高すぎたりして、重大な問題を引き起こす原因となります。

## 手順

この点検項目が不合格の場合、OceanBaseの`{WORK_DIR}/etc/`ディレクトリに`nic.rate.config`ファイルを追加することを推奨します。具体的な形式は`$(IF_NAME)=$(SPEED)`です。SPEEDは数字+単位、または純粋な数字でも構いません。純粋な数字の場合、デフォルトの単位Mbpsが使用されます。設定ファイルの例：

```shell
bond0=10000
bond0=10000b
bond0=10000bit
bond0=10000k
bond0=10000kb
bond0=10000kbit
bond0=10000m
bond0=10000mb
bond0=10000mbit
bond0=100g
bond0=100gb
bond0=100gbit
```

設定ファイルのレートを変更した後、ログを確認して設定が正しく反映されているか確認できます：
