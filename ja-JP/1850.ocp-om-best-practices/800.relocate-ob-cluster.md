# OceanBaseクラスタのデータセンター間移行

この記事では、OceanBaseクラスタをデータセンター間で移行する方法について説明します。

## 適用シナリオ

* シナリオ1：OceanBaseクラスタをデータセンター間で移行し、クラスタ全体をデータセンターAからデータセンターBへ完全に移動します。

* シナリオ2：単一データセンター構成から2つのデータセンターを使用する構成への変更。例えば、単一データセンターのA-A-A構成から2つのデータセンターのA-A-B構成への変更です。

* シナリオ3：2つのデータセンターを使用する構成から3つのデータセンターを使用する構成への変更。例えば、2つのデータセンターのA-A-B構成から3つのデータセンターのA-B-C構成への変更です。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス** リソース権限。
  * クラスタ **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。
  * テナント **<UI-TERM key="ocp-v2.page.Overview.Overview">概要</UI-TERM>** メニュー権限。

* 移行対象のOceanBaseクラスタの状態が **<UI-TERM key="ocp-v2.src.constant.compute.Running">実行中</UI-TERM>** であること。

* 新しいデータセンターのホスト仕様が、元のデータセンターの移行対象ゾーンにあるすべてのユニットを収容できること。

## 手順

**シナリオ1** を例に説明します。あるOceanBaseクラスタがデータセンターAにデプロイされており、デプロイメントアーキテクチャはA-A-Aモードで、クラスタ内の各テナントは3レプリカアーキテクチャであると仮定します。現在、それをデータセンターBに移行する準備をしています。具体的な移行手順は以下のとおりです：

1. データセンターBのホストを使用して、クラスタゾーンをA-A-A-B-Bに拡張します。

2. データセンターBのゾーンに、データセンターAのすべてのテナントのレプリカを追加し、テナントのレプリカ数を3から5に増やします。

3. データセンターAの任意の2つのレプリカを削除し、クラスタをA-B-Bに変更します。テナントのレプリカ数は3で、引き続き過半数を維持します。

4. データセンターBのホストを使用して、クラスタゾーンをA-B-B-Bに拡張します。

5. データセンターBのゾーンに、データセンターAのすべてのテナントのレプリカを追加し、テナントのレプリカ数を3から4に増やします。

6. データセンターAのレプリカを削除し、クラスタをB-B-Bに変更します。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>この操作のいずれの手順においても、すべてのテナントのレプリカ数は過半数を維持する必要があります。そうでない場合、操作は失敗します。</a></p>
</main>
