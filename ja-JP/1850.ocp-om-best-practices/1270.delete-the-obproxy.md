# OBProxyの削除

この記事では、OBProxy Serverの削除方法について説明します。

## 適用シナリオ

OBProxyクラスタ内の一部のOBProxy Serverを削除する場合や、OBProxyクラスタ全体を削除する場合に適用されます。OBProxy Serverホスト上のOCP Agentがオフラインの場合、OCPでOBProxy Serverを削除した後も、対応するホストで手動でのクリーンアップ作業が必要です。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **OBProxyメンテナンス** リソース権限。
* OBProxy **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** メニュー権限。

## 手順

### ステップ１：OBProxy Serverの削除

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックします。

3. クラスタリストから操作対象のOBProxyクラスタを選択し、OBProxyクラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

4. OBProxyリストから削除するOBProxyを選択し、**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.page.Host.Delete">削除</UI-TERM>** をクリックします。

   ![1634](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%A0%E9%99%A4obproxy.png)

   複数のOBProxyを選択し、**<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** > **<UI-TERM key="ocp-v2.page.Package.BatchDelete">一括削除</UI-TERM>** をクリックすることもできます。

   ![1636](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4obproxy.png)

   OBProxyクラスタ内のすべてのOBProxyを削除する必要がある場合は、[OBProxyクラスタの削除](../800.obproxy-functions/300.manage-a-obproxy-cluster/500.delete-an-obproxy-cluster.md)を参照してください。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>OBProxyクラスタにオフライン状態のホストがある場合、OBProxyクラスタを削除すると、そのホストの自動クリーンアップ手順がスキップされます。<b>ステップ2</b>を参照して、手動でホスト環境をクリーンアップしてください。</p>
   </main>

5. ポップアップダイアログに **delete** と入力し、**<UI-TERM key="ocp-v2.component.ZoneFormCardList.Delete">削除</UI-TERM>** をクリックします。

6. タスクが送信された後、ポップアップダイアログの **<UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">タスクを確認する</UI-TERM>** ボタンをクリックすると、削除の進捗状況を確認できます。

### ステップ2：ホスト環境のクリーンアップ

削除対象のOBProxy Serverホスト上のOCP Agentがオフライン状態の場合、システムはホストのクリーンアップ操作を実行できません。この場合、オフラインホストのIPアドレス、OBProxyのインストールディレクトリ、およびOBProxyの実行ディレクトリを記録し、ホスト上で手動でクリーンアップ操作を実行する必要があります。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OBProxyのインストールディレクトリおよび実行ディレクトリは、OCP metaDBの<code>obproxy_server</code>テーブルに記録されており、デフォルトは<code>/home/admin/obproxy</code>です。</p>
</main>

1. ホストにログインします。ログインユーザーが`obproxy`プロセスを起動する権限を持っていることを確認してください。

2. 以下のコマンドを実行して`obproxyd.sh`プロセスを停止します。

   ```shell
   ps -ef | grep obproxyd.sh; kill -9 ${obproxyd_pid}
   ```

3. `obproxyd.sh`プロセスが停止したら、以下のコマンドを実行して`obproxy`プロセスを停止します。

   ```shell
   ps -ef | grep obproxy; kill -9 ${obproxy_pid}
   ```

4. 以下のコマンドを実行して、OBProxyのインストールディレクトリと実行ディレクトリを削除します。

   ```shell
   rm -rf /xxx
   ```
