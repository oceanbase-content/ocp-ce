# メールでのアラート通知

メールを通じてアラートを送信し、メールクライアントでアラートを確認できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.All">すべて</UI-TERM>** メニュー権限。

* SMTPサービスとポートを取得済みであること（デフォルトは25番と465番ですが、環境に応じて変更可能です）。デフォルトで25番ポートを使用する場合はTLSを有効化せず、465番ポートを使用する場合はTLSを有効化します。

* 一部のシステムでは、メールを送信するユーザーのメールアドレスとパスワードを提供する必要があります。

## 手順

1. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">アラートセンター</UI-TERM>** をクリックします。

2. アラートセンターページで、**<UI-TERM key="ocp-v2.Alarm.Channel.New.AlarmChannel">アラートチャネル</UI-TERM>** をクリックします。

3. アラートチャネルタブで、**<UI-TERM key="ocp-v2.Alarm.Channel.NewChannel">新規チャネル作成</UI-TERM>** をクリックします。

4. メールアラートチャネルを設定します。

    1. 基本設定。

        <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E9%85%8D%E7%BD%AE%E9%82%AE%E7%AE%B1%E5%91%8A%E8%AD%A6-1.png) -->

        | 選択項目 | 必須 | 説明 |
        |-------|----------|------|
        | チャネルタイプ | はい | ドロップダウンでメールを選択します。 |
        | チャネル名 | はい | 後の識別を容易にするためのカスタムチャネル名。 |
        | 受信者メールアドレス | はい | ユーザーがアラートを受信するメールアドレス。 |

    2. チャネル設定。

        <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E9%85%8D%E7%BD%AE%E9%82%AE%E7%AE%B1%E5%91%8A%E8%AD%A6-2.png) -->

        | 選択項目 | 必須 | 説明 |
        |-------|----------|------|
        | SMTPサーバー | はい | STMPサービスのアドレス。例：`stmp.163.com`。 |
        | ポート | はい | STMPサービスのポート。25番ポートを使用する場合はTLSを有効化せず、465番ポートを使用する場合はTLSを有効化します（25番と465番がデフォルト値で、環境に応じて変更可能です）。 |
        | TLSを有効化 | はい | スイッチをオンにするとTLSプロトコルが有効になります。 |
        | ユーザー名 | はい | 送信メールアドレスの場合もあれば、他のアカウントの場合もあります。 |
        | パスワード | はい | ユーザー名に対応するパスワード。送信メールのパスワードの場合もあります。 |
        | 送信者メールアドレス | はい | 通常はメールアドレスですが、状況によって変更可能です。 |

    3. メッセージの設定。

        <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E9%85%8D%E7%BD%AE%E9%82%AE%E7%AE%B1%E5%91%8A%E8%AD%A6-3.png) -->

        メッセージ構造は変更可能です。**メッセージ形式**を`markdown`に設定すると、`${}`を入力して変数を挿入できます。

       　```shell
       　### OCP アラート通知 ${alarm_name}
       　- レベル：${alarm_level}
       　- アラート対象：${alarm_target}
       　- 概要：${alarm_summary}
       　- 生成時間：${alarm_active_at}
       　- 詳細：${alarm_description}
       　- OCP リンク：${alarm_url}
       　```

5. その他の機能。

   アラートメッセージの集約：チャネル集約機能を有効にすると、一定期間に同一のアラートが複数回送信されるのを防ぐことができます。OCP アラートはデフォルトで3分ごと（4.1.0以降のバージョンから）に1回生成されます。アラートチャネル集約を有効にすると、同一のアラートはデフォルトで600秒間に1回のみ送信されます。

6. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.Submit">送信</UI-TERM>**をクリックして設定を完了します。

## よくある質問

* OCP 4.2.0より前では、複数のメールアドレスへの送信はサポートされていません。
* OCP 4.2.0より前で465ポートを使用しTLSを有効にしてアラートを送信すると失敗します。25ポートを使用してTLSを無効にするか、OCPバージョンを4.2.0以降にアップグレードしてください。
