# OceanBaseテナントのUnit移行

このセクションでは、OceanBaseテナントのUnit移行の方法について説明します。

## 適用シナリオ

Unit移行とは、単一ゾーン内の異なるOBServerノード間でUnitの位置を移動することです。これにより、OBServerノード上のリソース割り当てとレプリカの分散を制御できます。

Unit移行には、Root Serviceによる自動移行と手動移行の2種類のモードがあります。自動移行が有効な場合、Root Serviceはリソースの分布状況に応じてUnitを自動的に移行し、OBServerノード間のリソース均等化を保証します。使い方が簡単で追加の操作は不要です。関連する移行原理の詳細については、後述の**技術原理**セクションを参照してください。

以下のシナリオでは、自動移行を無効にし、手動でUnit移行を開始することを検討できます：

* OBServerノードのリソース割り当てを正確に制御したい場合。
* OBServerノードに障害が発生した場合、レプリカ補完のタイミングを制御したい場合。
* Unit移行がアプリケーションのトラフィックに影響を与えることを避けたい場合。

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>常に手動でUnit移行を開始したい場合は、以下の方法でRoot Serviceの自動移行を無効にすることができます：<li>OCPがV4.2.0以降のバージョンの場合、<b>クラスタ</b> > <b>リソース管理</b> > <b>Unit分布</b>ページに移動し、<b>自動移行</b>スイッチをオフにします。</li><li>OCPがV4.2.0未満のバージョンの場合、<b>クラスタ</b> > <b>パラメータ管理</b>ページに移動し、<code>enable_rebalance</code>パラメータの値を<code>false</code>に変更します。</li></p>
    </main>

## 技術原理

Root Serviceは、リソースの不均衡を検出すると、自動的にUnit移行を開始し、リソースの均衡を維持します。ここでいうリソースは主にCPUとメモリリソースを指します。Root Serviceは事前に定義されたリソース利用率アルゴリズムを使用して、各OBServerノードのリソース利用率を計算し、Unitの移行を繰り返し試みます。Unit移行完了後、各ノード間のリソース利用率が移行前よりも小さくなれば、リソースユニットの均衡が達成されたことになります。

`server_balance_cpu_mem_tolerance_percent`構成パラメータは、Unit均衡戦略を制御します。この構成パラメータはリソースユニット均衡をトリガーするしきい値であり、特定のノードのリソースユニット負荷が平均負荷との差が`server_balance_cpu_mem_tolerance_percent`の設定値を超えた場合、均衡のスケジューリングを開始し、すべてのノードのリソースユニット負荷が平均負荷との差が構成パラメータ`server_balance_cpu_mem_tolerance_percent`の設定値より小さくなるまで続けます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**リソース権限。
* クラスタ**<UI-TERM key="ocp-v2.Detail.Resource.ResourceManagement">リソース管理</UI-TERM>**メニュー権限。

## 手順

このセクションでは、主に手動でUnit移行を開始する方法について説明します。

1. Unit移行を開始します。

    **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Cluster">クラスタ</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Resource.ResourceManagement">リソース管理</UI-TERM>** > **<UI-TERM key="ocp-v2.Detail.Resource.UnitDistribution">ユニット分布</UI-TERM>**ページに移動し、移行対象のUnitをクリックし、ポップアップウィンドウで移行先を選択します。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E6%9C%80%E4%BD%B3%E5%AE%9E%E8%B7%B5/unit%E8%BF%81%E7%A7%BB.png)

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>移行先のユニットは同一ゾーン内にあり、十分なリソースが確保されている必要があります。そうでない場合は選択できません。</p>
    </main>

2. ユニットの移行完了を待ちます。

    **<UI-TERM key="ocp-v2.Detail.Resource.UnitDistribution">ユニット分布</UI-TERM>** ページには、移行中のユニットが表示されます。

    また、以下のコマンドを実行してRoot Serviceタスクを照会し、ユニット移行の詳細な進捗状況を確認することもできます：

    ```SQL
    SELECT * FROM oceanbase.DBA_OB_UNIT_JOBS WHERE JOB_TYPE = 'MIGRATE_UNIT';
    ```
