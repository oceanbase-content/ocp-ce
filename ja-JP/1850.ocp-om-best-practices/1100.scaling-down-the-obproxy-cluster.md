# OBProxyクラスタのスケールイン

このセクションでは、OBProxyクラスタをスケールインする方法について説明します。

## 適用シナリオ

既存のOBProxyクラスタからOBProxy Serverを削減します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **OBProxyメンテナンス** リソース権限。
  * OBProxy **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** メニュー権限。

* このOBProxy Serverの削除が業務に影響しないことを確認する必要があります。

## 手順

以下の手順に厳密に従って操作してください：

**ステップ１：ネットワークの切り替え**

1. ロードバランシングインスタンスを変更し、削除予定のOBProxyノードの重みを0に変更して、新規接続の誘導を防ぎます。

2. そのOBProxy上の接続数と業務状況を継続的に観察します。既存の接続が徐々に解放されるまで、数時間から数日待つ必要がある場合があります。

3. 業務で長い接続が作成されて解放できない場合は、業務量が少ない時間帯に既存の接続を閉じることができます。ただし、業務がエラーを報告する可能性があるため、慎重に操作してください。

4. 削除対象のOBProxyに業務接続がないことを確認したら、次のステップでOBProxy Serverを削除します。

**ステップ２：OBProxy Serverの削除**

1. OCPにログインします。

2. 左側のナビゲーションバーで **OBProxy** をクリックし、クラスタリストから操作対象のOBProxyクラスタを選択して、クラスタの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。

3. OBProxyリストで削除対象のOBProxy Serverを選択し、操作列の **<UI-TERM key="ocp-v2.page.OBProxy.Delete">削除</UI-TERM>** ボタンをクリックします。複数のOBProxyを選択して、**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.BatchDelete">一括削除</UI-TERM>** をクリックすることもできます。

    ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E5%88%A0%E9%99%A4obproxy.png)
    ![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E6%89%B9%E9%87%8F%E5%88%A0%E9%99%A4.png)

4. 削除タスクの実行完了を待ちます。
