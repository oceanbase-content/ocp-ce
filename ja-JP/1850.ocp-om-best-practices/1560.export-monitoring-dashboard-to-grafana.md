# 監視ダッシュボードをGrafanaにインポートする

このセクションでは、OCPの監視ダッシュボードをGrafanaにインポートする方法について説明します。

## 適用シナリオ

ユーザーは独自のPrometheusとGrafanaシステムを使用する必要があります。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または**ホスト読み取り専用**のいずれかのリソース権限。
  * システム管理 **<UI-TERM key="ocp-v2.page.Property.SystemParameters">システムパラメータ</UI-TERM>** メニュー権限。

* V2.28以降のPrometheusサービスがデプロイ済みであること。
* V4.3.5以降のOCPバージョンがデプロイ済みであること。
* ホスト読み取り権限を持つアカウントを所有していること。HOST_VIEWERロール（OCPホスト読み取り専用ロール）を割り当てるため、専用のユーザーを作成することを推奨します。

## 手順

1. GrafanaでPrometheusデータソースを設定します。

2. `prometheus_sd`関連情報を設定します。

   1. OCPにログインし、左側のナビゲーションバーで**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">システムパラメータ</UI-TERM>** をクリックし、OCPシステムパラメータ `ocp.monitor.server.exporter.auth.enabled` と `ocp.agent.auth.metric-auth-enabled` の値を `false` に設定してOCPを再起動します。

   2. Prometheusの設定ファイルで `ocp_sd` 関連情報を設定します。以下の例を参照してください：

        ```sql
        scrape_configs:
        - job_name: ocp_sd
            http_sd_configs:
            - url: 'http://xxx.xxx.xxx.xxx:8080/api/v2/monitor/prometheus_sd'
              basic_auth:
                username: admin
                password: '......'
        ```

        | パラメータ     | 説明 |
        |----------|-----------|
        | url      | OCPサービスのIPアドレス + ポート + API名。 |
        | username | アカウント名。HOST_VIEWERロール（OCPホスト読み取り専用ロール）を割り当てるため、専用のユーザーを作成することを推奨します。 |
        | password | アカウントのパスワード。 |

   3. Prometheusコンソールにアクセスし、`ocp_sd` の状態がすべて `up` であることを確認します。

3. OCPにログインし、**<UI-TERM key="ocp-v2.Monitor.Dashboard.MonitoringDashboard">監視ダッシュボード</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Monitor.Dashboard.Export">エクスポート</UI-TERM>** > **Grafanaダッシュボードをエクスポート** をクリックし、エクスポートする監視ダッシュボードを選択します。

4. エクスポートが成功したら、Grafanaでそのファイルをインポートします。
