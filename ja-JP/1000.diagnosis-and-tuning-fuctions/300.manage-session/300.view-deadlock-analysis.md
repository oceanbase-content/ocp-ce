# デッドロック履歴の表示

この記事では、デッドロック履歴を表示する方法について説明します。

デッドロックの分析と管理は、以下の2つの方法で行えます。

* **方法1**：OCPにログインし、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">診断サービス</UI-TERM>** をクリックします。表示したいクラスタを選択し、クラスタの **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** ページに移動して、**<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">セッション管理</UI-TERM>** タブをクリックします。

* **方法2**：OCPにログインし、テナントの **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>** ページに移動します。左側で **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">セッション管理</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.Realtime.Session.ViewDeadlockHistory">デッドロック履歴を表示</UI-TERM>** タブに移動します。

## 前提条件

* **方法1** でデッドロック履歴を表示する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * 診断サービス **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** メニュー権限。

* **方法2** でデッドロック履歴を表示する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナント **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">セッション管理</UI-TERM>** メニュー権限。

* テナントが存在するクラスタでデッドロックの自動検出が有効になっていること。詳細については、[デッドロックの自動検出の有効化](../../600.cluster-functions/300.manage-a-cluster/1000.enable-automatic-deadlock-detection.md)を参照してください。

## 手順

以下の手順は **方法1** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">診断サービス</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>** 領域で、表示したいクラスタ名をクリックします。

4. **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** の **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">セッション管理</UI-TERM>** タブに移動します。

5. 特定のテナントを選択し、**<UI-TERM key="ocp-v2.Realtime.Session.ViewDeadlockHistory">デッドロック履歴を表示</UI-TERM>** タブをクリックします。

6. デッドロックリストで、このクラスタの現在のテナントで過去7日間に発生したデッドロックの記録、およびデッドロックのEvent ID（デッドロックイベントの一意の識別子）と発生時間を確認できます。

7. 折りたたみページを展開すると、番号ID、トランザクションHash、中断の有無、要求リソース、SQL情報などのデッドロックの詳細を確認できます。
