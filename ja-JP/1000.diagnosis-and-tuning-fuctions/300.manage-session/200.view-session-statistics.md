# セッション統計の表示

このセクションでは、テナントのセッション統計を表示する方法について説明します。

テナントのセッション統計は、以下の2つのエントリポイントから確認できます：

* **エントリポイント1**：OCPにログインし、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">診断サービス</UI-TERM>** をクリックし、表示したいクラスタを選択してクラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** ページに移動します。そこで **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">セッション管理</UI-TERM>** タブをクリックします。

* **エントリポイント2**：OCPにログインし、テナントの **<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>** ページに移動します。左側で **<UI-TERM key="ocp-v2.Detail.Realtime.SessionManagement">セッション管理</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.Detail.Session.SessionStatistics">セッション統計</UI-TERM>** タブに移動します。

<main id="notice" type='notice'>
   <h4>機能の適用範囲</h4>
   <p>Community版は現在診断サービスをサポートしていません。この機能は <b>エントリポイント1</b> からアクセスしてご利用ください。</p>
</main>

## 前提条件

* * **エントリポイント1** でセッション統計を表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * 診断サービスの **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** メニュー権限。

* **エントリポイント2** でセッション統計を表示する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">セッション管理</UI-TERM>** メニュー権限。

## 手順

以下の手順は **エントリポイント1** を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.DiagnosticServices">診断サービス</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>** 領域で、表示したいクラスタ名をクリックします。

4. **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** の **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">セッション管理</UI-TERM>** タブに移動します。

5. **<UI-TERM key="ocp-v2.Realtime.Session.SessionStatistics">セッション統計</UI-TERM>** タブをクリックすると、ページにはテナントの現在のすべてのセッションの統計情報が表示されます。

   統計情報には、**セッション総数、アクティブセッション数、アクティブセッションの最長時間** など、セッション全体の統計が含まれます。**<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.User.1">ユーザー</UI-TERM>**、**アクセス元**、**<UI-TERM key="ocp-v2.TraceDetail.TraceContent.Database">データベース</UI-TERM>** で、ユーザーの **<UI-TERM key="ocp-v2.User.Component.DeleteUserModal.ActiveSessions">アクティブなセッション数</UI-TERM>** と **<UI-TERM key="ocp-v2.page.Diagnosis.TotalSessions">セッション総数</UI-TERM>** を集計できます。

    <h4>説明</h4>

   </main>
