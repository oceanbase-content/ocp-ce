# 行ロック分析の表示

本記事では、行ロック分析を表示する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**または**テナント読み取り専用**リソース権限。
* 診断サービス **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">診断サービス</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>** セクションで、表示したいクラスタ名をクリックします。

4. **<UI-TERM key="ocp-v2.Detail.Realtime.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** の **<UI-TERM key="ocp-v2.src.util.menu.SessionManagement">セッション管理</UI-TERM>** タブに移動します。

5. **<UI-TERM key="ocp-v2.Realtime.Session.RowLockAnalysis">行ロック分析</UI-TERM>** タブをクリックします。

6. **<UI-TERM key="ocp-v2.Realtime.Session.RowLockAnalysis">行ロック分析</UI-TERM>** タブでは、以下の操作を実行できます：

   * 対象テナントを選択すると、そのテナントの行ロックの詳細情報（ロックに関連する行情報やセッション数など）を表示できます。

   * ロックを保持しているセッションを解放する必要がある場合、そのセッションを閉じることができます。閉じる前に、そのセッションおよびその上で実行されている業務SQLが安全に終了できることを確認してください。

       <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><ul><li>行ロック分析はリアルタイムクエリ機能であり、ロック待機時間が20msを超える行ロックおよび関連するセッション情報のみを表示します。この機能はOceanBase 4.2以降のバージョンでのみサポートされています。</li><li>行ロック情報には遅延が生じる可能性があります。ロックを保持しているセッションIDが表示されない場合、そのトランザクションは既に完了している可能性があります。</li></ul></p>
    </main>
