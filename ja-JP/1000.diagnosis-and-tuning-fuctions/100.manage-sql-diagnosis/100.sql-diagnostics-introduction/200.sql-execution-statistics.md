# SQL実行統計情報

SQL診断は多角的な指標統計情報を提供し、カスタム列でフィルタリングして必要なSQL実行情報を取得できます。

カスタム列の指標は、時間モデル指標、一般的な指標、基本情報指標、実行計画指標の4種類に分けられます。

## 時間モデル

OBServerはユーザーからのSQLリクエストを受信すると、ポイントを打つことで、SQLがOceanBase内部の各段階で動作する際に消費される時間を記録します。ローカルで単一のSQL文を実行する際の時間モデル図は以下のとおりです：

![image.png](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/sql%E8%AF%8A%E6%96%AD%E6%B5%81%E7%A8%8B%E5%9B%BE.png)

上図のように：

* ネットワーク転送時間：SQLがクライアントから送信されてOBServerが受信するまでの時間消費で、主にネットワーク上の時間消費を指します。
* ネットワークキューイング時間：OBServerがリクエストを受信してからSQLがOBServerの処理キューに入るまでの時間消費で、主にOBServerのネットワークアーキテクチャ層での時間消費を指します。
* キュー時間：SQLが処理キューに入ってからキューから出るまでの時間消費で、SQL実行の待機時間消費です。OBServerの処理リソースが不足している場合、SQLは十分な処理リソースが利用可能になるまでキューで待機します。
* 解釈時間：SQLがキューから出て処理を開始してから、物理実行計画の実行が開始されるまでの時間消費で、主にOceanBase SQLエンジンが実行計画を生成または取得する時間消費を指します。
* 実行時間：SQL実行計画の実行開始から終了までの時間消費です。実行時間はCPU時間と待機時間に分けられ、待機時間は待機タイプに応じてアプリケーション待機、並行待機、I/O待機、スケジューリング待機の4種類に分類されます。
