# SQL実行計画

実行計画とは、データベースにおける単一のSQLクエリ文の実行プロセスを記述したものです。ユーザーはEXPLAINコマンドを使用して、オプティマイザーが指定されたSQLに対して生成した論理実行計画を確認できます。
特定のSQLのパフォーマンス問題を分析する場合、通常はまずそのSQLの実行計画を確認し、各実行ステップに問題がないか調査する必要があります。したがって、実行計画を理解することはSQL最適化の前提条件であり、実行計画を構成する演算子を把握することがEXPLAINコマンドを理解する鍵となります。

詳細については、[SQL実行計画の概要](https://www.oceanbase.com/docs/common-oceanbase-database-cn-10000000001700649)を参照してください。
