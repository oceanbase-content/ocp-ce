# SQL収集スイッチの履歴を表示する

このページでは、SQL収集スイッチの履歴を表示する方法について説明します。

収集スイッチの履歴は、以下の2つの方法で表示できます：

* **方法1**：OCPにログインし、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">診断サービス</UI-TERM>** をクリックし、表示したいクラスタを選択して、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** ページに移動します。

* **方法2**：OCPにログインし、テナントの **<UI-TERM key="ocp-v2.src.util.menu.SummaryInvestingComZa">概要</UI-TERM>** ページに移動し、左側のナビゲーションバーで **<UI-TERM key="ocp-v2.ParallelSQL.TraceDetail.SqlDiagnosis">SQL 診断</UI-TERM>** をクリックします。

<main id="notice" type='notice'>
   <h4>機能の適用範囲</h4>
   <p>コミュニティエディションは現在診断サービスをサポートしていません。この機能は <b>方法2</b> からアクセスしてご利用ください。</p>
</main>

## 前提条件

* **方法1** で収集スイッチの履歴を表示する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * 診断サービスの **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** メニュー権限。

* **方法2** で収集スイッチの履歴を表示する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用** または **テナント読み取り専用** のリソース権限。
  * テナントの **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SqlDiagnosis">SQL 診断</UI-TERM>** メニュー権限。

## 手順

以下の手順は **方法1** を例に説明します。

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">診断サービス</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>** でクラスタ名をクリックして、クラスタの **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** ページに移動します。

2. システムはデフォルトで **<UI-TERM key="ocp-v2.Detail.Monitor.SqlDiagnosis">SQL 診断</UI-TERM>** タブに移動します。

3. **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.ViewCollectionSwitchHistory">収集スイッチの履歴を確認する</UI-TERM>** ボタンをクリックします。

4. 右側の **<UI-TERM key="ocp-v2.component.TraceTimelineDrawer.SqlCollectionSwitchHistory">SQL収集スイッチの履歴</UI-TERM>** パネルで、操作時間と具体的な操作の詳細を確認します。

   * 操作時間に基づいてスイッチ操作を並べ替えることができます。

   * **開/閉** の異なる操作に基づいてスイッチ操作を並べ替えることができます。
