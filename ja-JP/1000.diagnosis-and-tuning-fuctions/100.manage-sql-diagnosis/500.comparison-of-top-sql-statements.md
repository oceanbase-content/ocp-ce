# TopSQLの比較

このセクションでは、TopSQLを比較する方法について説明します。

<main id="notice" type='notice'>
    <h4>機能の適用範囲</h4>
    <p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能を提供していません。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用** または **テナント読み取り専用** リソース権限。
* 診断サービス **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.DiagnosticServices">診断サービス</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>** セクションで、表示するクラスタ名をクリックします。

4. デフォルトで、**<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>** の **<UI-TERM key="ocp-v2.ParallelSQL.TraceDetail.SqlDiagnosis">SQL 診断</UI-TERM>** ページが表示されます。

5. TopSQLリストで、**<UI-TERM key="ocp-v2.Realtime.SQLDiagnosis.TopsqlComparison">TopSQLの比較</UI-TERM>** をクリックし、ポップアップパネルで **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonOfDifferentPeriods">異なる時間帯の比較</UI-TERM>** または **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonOfDifferentNodes">異なるノードの比較</UI-TERM>** のいずれかの方法でTopSQLを比較分析します。

    * **異なる期間の比較詳細を見る**

        **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonOfDifferentPeriods">異なる時間帯の比較</UI-TERM>** では、システムは **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.BasePeriod">基準時間帯</UI-TERM>** と比較した後、**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonPeriod">比較時間帯</UI-TERM>** 内で以下のルールを満たすSQLを出力します：

        * TopNに初めて入ったSQL。Nの値はOCPシステムパラメータ `perf.sql.top-sql-comparison.new-in-top-n-limit` で調整でき、パラメータのデフォルト値は100です。
        * 実行回数が閾値を超えて増加したSQL。この閾値はOCPシステムパラメータ `perf.sql.top-sql-comparison.executions-increase-limit` で調整でき、パラメータのデフォルト値は20%です。
        * 平均応答時間が閾値を超えて増加したSQL。この閾値はOCPシステムパラメータ `perf.sql.top-sql-comparison.elapsed-time-increase-limit` で調整でき、パラメータのデフォルト値は20%です。
        * 平均戻り行数が閾値を超えて増加したSQL。この閾値はOCPシステムパラメータ `perf.sql.top-sql-comparison.return-rows-increase-limit` で調整でき、パラメータのデフォルト値は20%です。
        * エラーレートが閾値を超えて増加したSQL。この閾値はOCPシステムパラメータ `perf.sql.top-sql-comparison.error-percentage-increase-limit` で調整でき、パラメータのデフォルト値は10%です。
        * リモート計画率が閾値を超えて増加したSQL。この閾値はOCPシステムパラメータ `perf.sql.top-sql-comparison.remote-plan-percentage-increase-limit` で調整でき、パラメータのデフォルト値は20%です。
        * 実行回数が閾値を超えて増加したSQL。この閾値はOCPシステムパラメータ `perf.sql.top-sql-comparison.executions-increase-limit` で調整でき、パラメータのデフォルト値は10%です。

        具体的な操作手順は以下のとおりです：

        1. **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.BasePeriod">基準時間帯</UI-TERM>** と **<UI-TERM key="ocp-v2.src.hook.sqlDiagnosis.ComparisonPeriod">比較時間帯</UI-TERM>** を選択します。

            * **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.BasePeriod">基準時間帯</UI-TERM>** はカスタム選択が可能です。
            * **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ComparisonPeriod">比較時間帯</UI-TERM>** では、ベース期間の **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.PreviousPeriod">前の時間帯</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.SamePeriodOfThePreviousDay">前日の同じ時間帯</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.TheSamePeriodLastWeek">先週の同じ時間帯</UI-TERM>** を選択でき、カスタム選択もサポートしています。

        2. **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.ComparativeAnalysis">比較分析</UI-TERM>** ボタンをクリックし、リストで **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.DetailedDataComparison">明細データの比較</UI-TERM>** の詳細と **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.PerformanceTrendComparison">パフォーマンストレンドの比較</UI-TERM>** の詳細を確認します。

            * 明細データ比較：**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.DetailedDataComparison">明細データの比較</UI-TERM>** タブでSQLの詳細データを確認できます。
            SQLテキストをクリックするとSQLの詳細を確認できます。右側のトレンドアイコンをクリックすると、詳細な指標の傾向比較図を確認できます。

            <!-- ![11](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%8D%E5%90%8C%E6%97%B6%E6%AE%B5%E5%AF%B9%E6%AF%94.png) -->

            * パフォーマンス傾向比較：**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.PerformanceTrendComparison">パフォーマンストレンドの比較</UI-TERM>** タブで、読み書き応答時間、読み書きリクエスト量、CPU使用率を含むSQLのパフォーマンス傾向比較図を確認できます。

            <!-- ![22](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%80%A7%E8%83%BD%E8%B6%8B%E5%8A%BF%E5%AF%B9%E6%AF%94.png) -->

    * **異なるノードの比較詳細を見る**

        ノード比較は、異なるノード上で同一のSQLを実行した場合のパフォーマンスを比較するために主に使用されます。

        1. **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerMonitor.BaselineNode">基準ノード</UI-TERM>** と **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerMonitor.ComparisonNode">比較ノード</UI-TERM>** を選択します。

        2. 分析期間を選択します。

            過去5分、過去30分、過去1時間、過去6時間、およびカスタム時間内の比較詳細を確認できます。

        3. **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.ComparativeAnalysis">比較分析</UI-TERM>** ボタンをクリックし、リストで明細データの比較詳細と応答時間の傾向比較詳細を確認します。

            * 明細データの比較：**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.DetailedDataComparison">明細データの比較</UI-TERM>** タブでSQLの詳細データを確認できます。
                SQLテキストをクリックするとSQLの詳細を確認できます。右側の **<UI-TERM key="ocp-v2.Component.filter.ColumnManagement">カラム管理</UI-TERM>** をクリックすると、ポップアップウィンドウでカスタム列のリスト式と列名を設定できます。

                <!-- ![11](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%B8%8D%E5%90%8C%E8%8A%82%E7%82%B9%E6%98%8E%E7%BB%86%E6%95%B0%E6%8D%AE%E5%AF%B9%E6%AF%94.png) -->

            * 応答時間の傾向比較：**<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerComparison.ComparisonOfResponseTimeTrends">応答時間のトレンド比較</UI-TERM>** タブで、ベースラインノードと比較ノードの実行時間割合のトレンドグラフを確認できます。
                右側の **<UI-TERM key="ocp-v2.Component.ComparisonSqlDrawer.ServerMonitor.AllSqlTypes">すべての SQL タイプ</UI-TERM>** をクリックすると、表示するSQLタイプをフィルタリングできます。
