# アクティブセッションレポートの管理

この記事では、アクティブセッションレポートの表示とダウンロード方法について説明します。このレポートを通じて、過去の診断期間内にデータベースリソースを多く消費したSQLや、OceanBaseクラスタの過去のセッション実行詳細などの情報を確認できます。これらの情報を基にSQLを最適化することで、SQLの実行効率を向上させることができます。

アクティブセッションレポートは、以下の2つのエントリから表示およびダウンロードできます：

* **エントリ1**：OCPにログインし、左側のナビゲーションバーで**<UI-TERM key="ocp-v2.page.Diagnosis.AutonomousService">診断サービス</UI-TERM>**をクリックし、表示したいクラスタを選択して、クラスタの**<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">レポートセンター</UI-TERM>**ページに移動します。

* **エントリ2**：OCPにログインし、テナントの**<UI-TERM key="ocp-v2.src.hook.useMenu.Overview">概要</UI-TERM>**ページに移動します。左側で**<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">セッション管理</UI-TERM>**をクリックし、**<UI-TERM key="ocp-v2.Detail.Report.ActiveSessionReport">アクティブセッションレポート</UI-TERM>**タブに移動します。

## 前提条件

* **エントリ1**でアクティブセッションレポートを管理する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**または**テナント読み取り専用**リソース権限。
  * 診断サービス**<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">レポートセンター</UI-TERM>**メニュー権限。

* **エントリ2**でアクティブセッションレポートを管理する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**または**テナント読み取り専用**リソース権限。
  * テナント**<UI-TERM key="ocp-v2.page.Iframe.SessionManagement">セッション管理</UI-TERM>**メニュー権限。

* [パラメータの管理](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md)で**<UI-TERM key="ocp-v2.src.constant.parameter.ActiveSessionHistoryCollection">アクティブセッション履歴の収集</UI-TERM>**モジュールパラメータが有効になっていること。

## 手順

以下の操作はすべて**エントリ1**を例に説明します。

### ASHレポートの表示

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.DiagnosticServices">診断サービス</UI-TERM>**をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>**エリアで、表示したいクラスタ名をクリックします。システムはデフォルトで**<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>**ページに移動します。

4. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">レポートセンター</UI-TERM>**をクリックし、**<UI-TERM key="ocp-v2.Detail.Report.ActiveSessionReport">アクティブセッションレポート</UI-TERM>**タブに移動します。

5. **<UI-TERM key="ocp-v2.Backup.Overview.Statistics.Tenant">テナント</UI-TERM>**、**<UI-TERM key="ocp-v2.License.util.licenseEntry.Node">ノード</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Analyze.TimeRange">時間範囲</UI-TERM>**、**SQL ID**、**TraceID**、**WaitClass**の情報をフィルタリングまたは入力し、**ASHレポートの表示**をクリックします。

6. システムは**ASH Report**ページに移動し、そこでフィルタ条件に合致するレポート内容を表示します。

### ASHレポートのダウンロード

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.AutonomousService">診断サービス</UI-TERM>**をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>**セクションで、表示するクラスタ名をクリックします。システムはデフォルトで**<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>**ページに移動します。

4. 左側のナビゲーションバーの**<UI-TERM key="ocp-v2.Detail.Report.ReportCenter">レポートセンター</UI-TERM>**をクリックし、**<UI-TERM key="ocp-v2.Detail.Report.ActiveSessionReport">アクティブセッションレポート</UI-TERM>**タブに移動します。

5. **<UI-TERM key="ocp-v2.page.AuditEvent.Tenant">テナント</UI-TERM>**、**<UI-TERM key="ocp-v2.component.AshPerformanceReport.Node">ノード</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Monitor.TimeRange">時間範囲</UI-TERM>**、**SQL ID**、**TraceID**、**WaitClass**の情報をフィルタリングまたは入力し、**ASHレポートをダウンロード**をクリックすると、HTML形式のASHレポートをローカルにダウンロードできます。
