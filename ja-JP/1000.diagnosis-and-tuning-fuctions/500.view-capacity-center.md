# 容量センターの表示

この記事では、容量センターの使い方について説明します。

<main id="notice" type='notice'>
  <h4>機能の適用範囲</h4>
  <p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionではこの機能は提供されません。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**または**テナント読み取り専用**リソース権限。
* 診断サービス **<UI-TERM key="ocp-v2.src.hook.useMenu.CapacityCenter">容量センター</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.pages.Diagnosis.DiagnosticServices">診断サービス</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>** セクションで、表示したいクラスタ名をクリックします。

4. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.Capacity.CapacityCenter">容量センター</UI-TERM>** をクリックすると、容量センターページで以下の情報を確認できます：

   1. クラスタ容量リスクを確認します。現在の容量検出には、テナントのCPU、メモリ、ディスク、接続数が含まれます。

      **<UI-TERM key="ocp-v2.Detail.Capacity.View">確認する</UI-TERM>** をクリックすると、下部の **<UI-TERM key="ocp-v2.Detail.Resource.Trend.ResourceUsageTrends">リソース使用傾向</UI-TERM>** モジュールに移動し、リソース使用傾向の詳細情報を見ることができます。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E5%AE%B9%E9%87%8F%E9%A3%8E%E9%99%A9.png)

   2. 容量使用の概要を確認します。CPU、メモリ、ログディスクの割り当て済み容量とその割合、およびデータディスクの使用済み容量とその割合が含まれます。

       ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/capacity-overview.png)

      **<UI-TERM key="ocp-v2.Component.OBServerList.Disk">データディスク</UI-TERM>** モジュールの **<UI-TERM key="ocp-v2.Detail.Capacity.ViewUsageTrends">使用傾向を確認する</UI-TERM>** をクリックし、ポップアップパネルで期間を選択すると、その期間内のデータディスク使用傾向を確認できます。

       ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/OAS/%E5%AE%B9%E9%87%8F%E4%B8%AD%E5%BF%83-2.png)

   3. テナントの過去7日間の使用明細を確認します。クラスタ内のすべてのテナントの仕様、および各テナントのCPU、メモリ、データディスクの使用状況と最大接続数が含まれます。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/OAS/%E5%AE%B9%E9%87%8F%E4%B8%AD%E5%BF%83-3.png)

   4. テナント容量情報を確認します。

      1. テナント、データベース、テーブルグループでフィルタリングできます。

      2. 横軸に時間を設定すると、CPU、メモリ、ログディスク、データディスクなどのリソース使用量のトレンドグラフを確認できます。

            最近1日、最近1週間、最近1か月、またはカスタム期間（最大60日）のトレンドグラフを選択して、現在のテナント、データベース、またはテーブルグループの状態を把握できます。CPU、メモリ、ログディスクのトレンドグラフは、テナント単位でのみ表示されます。

      3. **<UI-TERM key="ocp-v2.Detail.Resource.Trend.ResourceUsageTrends">リソース使用傾向</UI-TERM>** モジュールの右側にあるデータベース名をクリックすると、そのデータベース内のすべてのテーブルのデータ詳細を確認できます。これには、**<UI-TERM key="ocp-v2.TableInfoDrawer.TableList.NumberOfRows">行数</UI-TERM>**、**<UI-TERM key="ocp-v2.TableInfoDrawer.TableList.DiskUsage">ディスク使用量</UI-TERM>**、**<UI-TERM key="ocp-v2.TableInfoDrawer.TableList.DataSize">データサイズ</UI-TERM>** などが含まれます。
      ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/table-details.png)

         テーブル名をクリックすると、そのテーブルの容量使用トレンドを確認できます。

         ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/table-trend.png)

      4. データベース、テーブルグループ、テーブル、またはパーティションを **<UI-TERM key="ocp-v2.Detail.Resource.Trend.Data">データ量</UI-TERM>** または **<UI-TERM key="ocp-v2.Detail.Resource.Top.DiskUsage">ディスク使用量</UI-TERM>** の順で並べ替えることができます。

         ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/db-sort.png)

      5. **<UI-TERM key="ocp-v2.Detail.Resource.Trend.ResourceUsageTrends">リソース使用傾向</UI-TERM>** モジュールの上部では、**<UI-TERM key="ocp-v2.Detail.Resource.ConditionRange">条件範囲</UI-TERM>** の後ろで **<UI-TERM key="ocp-v2.Detail.Resource.Database">データベース</UI-TERM>** を選択してフィルタリングし、データベースを1つ選択します。その後、右側のテーブルランキングからテーブルを1つ選択すると、ポップアップウィンドウが表示され、そのデータベース内のすべてのテーブルが一覧表示され、選択したテーブルが強調表示されます。

         ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/table-highlight.png)

         詳細については、[テナントリソース管理](../700.tenant-functions/1300.manage-tenant-resource.md)を参照してください。
