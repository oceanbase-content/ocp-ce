# トランザクションの診断

OCPは、大規模トランザクションの基本情報と関連するSQLを提供しており、トランザクション診断機能を利用して大規模トランザクションを特定し分析することができます。

トランザクションの診断は、以下の2つの方法で行えます。

* **方法1**：OCPにログインし、左側のナビゲーションバーで**<UI-TERM key="ocp-v2.src.hook.useMenu.DiagnosticServices">診断サービス</UI-TERM>**をクリックし、確認したいクラスタを選択します。クラスタの**<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>**ページで、**<UI-TERM key="ocp-v2.SQLDiagnosis.TraceDetail.TransactionDiagnosis">トランザクション診断</UI-TERM>**タブをクリックします。

* **方法2**：OCPにログインし、テナントの**<UI-TERM key="ocp-v2.Backup.Overview.Statistics.SummaryInvestingComZa">概要</UI-TERM>**ページに移動します。左側のナビゲーションバーで**<UI-TERM key="ocp-v2.Detail.Transaction.TransactionDiagnosis">トランザクション診断</UI-TERM>**をクリックします。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>Community版では、現在診断サービスはサポートされていません。この機能は、<b>方法2</b>からアクセスしてご利用ください。</p>
</main>

## 前提条件

* * 方法1でトランザクションを診断する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**または**テナント読み取り専用**のリソース権限。
  * 診断サービスの**<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>**メニュー権限。

* 方法2でトランザクションを診断する場合、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**または**テナント読み取り専用**のリソース権限。
  * テナントの**<UI-TERM key="ocp-v2.page.Iframe.TransactionDiagnosis">トランザクション診断</UI-TERM>**メニュー権限。

* **単一参加者の生成済みログ量**フィールドの表示は、OceanBase V3.2.x以降のバージョンでのみサポートされています。
* [管理パラメータ](../../600.cluster-functions/300.manage-a-cluster/1200.manage-om-configuration/200.manage-om-configuration-parameters.md)で、**<UI-TERM key="ocp-v2.component.OperationConfig.List.TransactionDiagnosticCollection">トランザクション診断収集</UI-TERM>**モジュールパラメータが有効になっている必要があります。

## 手順

以下の手順は、**方法1**を例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.pages.Diagnosis.DiagnosticServices">診断サービス</UI-TERM>**をクリックします。

3. **<UI-TERM key="ocp-v2.page.Diagnosis.ClusterDetails">クラスタの詳細</UI-TERM>**セクションで、確認したいクラスタ名をクリックします。

4. **<UI-TERM key="ocp-v2.src.hook.useMenu.RealTimeDiagnosis">リアルタイム診断</UI-TERM>**の**<UI-TERM key="ocp-v2.page.Overview.TransactionDiagnosis">トランザクション診断</UI-TERM>**タブに移動し、トランザクションをフィルタリングします。

      * システムはデフォルトで、**実行時間が500msを超える**または**単一参加者の生成済みログ量が0.5MBを超える**トランザクションのリストを表示します。実行時間やログ生成量の他の範囲を選択してトランザクションを検索することもできます。

      * **<UI-TERM key="ocp-v2.Detail.Monitor.AutomaticRefresh">自動更新</UI-TERM>**スイッチをオンにすると、ページは設定された更新頻度でトランザクションリストを更新します。選択可能な更新頻度は5秒、10秒、30秒で、デフォルトは10秒ごとの更新です。

    <!-- ![Image 56](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E4%BA%8B%E5%8A%A1%E8%AF%8A%E6%96%AD.png) -->

* トランザクションリストの表示

  トランザクションの状態別に分類して、さまざまなトランザクションのリストを表示できます。トランザクションの状態には、長時間トランザクション、ハングトランザクション、その他のトランザクションが含まれます。トランザクションリストには、現在実行中の大規模トランザクションが表示され、表示列にはトランザクションHash、セッションID、トランザクションタイプ、影響を受けた行数、実行時間、単一参加者が生成したログ量の最大値が含まれます。表示列の説明は以下の表のとおりです。

  |    表示列    |                                   説明                                    |
  |-----------|-------------------------------------------------------------------------|
  | トランザクション Hash   | トランザクションの一意の識別子。                                                                |
  | セッション ID     | セッションの一意の識別子。[テナントセッションの管理](../300.manage-session/100.manage-tenant-sessions.md)でこのセッションを確認できます。 |
  | トランザクションタイプ      | トランザクションのタイプ。XAトランザクション、分散トランザクション、通常トランザクションが含まれます。<blockquote>**<UI-TERM key="ocp-v2.Cluster.Arbitration.Description">備考</UI-TERM>**</br>OceanBaseがV4.0以降のバージョンの場合、XAトランザクションタイプは現在サポートされていません。</blockquote>                                                |
  | 影響を受けた行数     | このトランザクション内のすべてのSQL実行プロセスでのaffected_row                                             |
  | 実行時間（ms） | トランザクションの実行開始からの経過時間。                                                              |

  <!-- ![Image 109](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E4%BA%8B%E5%8A%A1%E5%88%97%E8%A1%A8.png) -->

* トランザクションの詳細を見る

  特定のトランザクションHashをクリックすると、**<UI-TERM key="ocp-v2.SQLDiagnosis.TraceDetail.TransactionDetails">トランザクション診断の詳細</UI-TERM>**ページに移動します。このページでは、トランザクションの基本情報、実行情報、実行されたSQLの詳細を確認できます。
  * 右上の **<UI-TERM key="ocp-v2.Transaction.Detail.CloseATransaction">トランザクションを閉じる</UI-TERM>** をクリックすると、そのトランザクションセッションを閉じることができます。**<UI-TERM key="ocp-v2.page.Overview.LongTransaction">長時間トランザクション</UI-TERM>** リスト内の通常トランザクションと分散トランザクションのみサポートされています。

  * **<UI-TERM key="ocp-v2.Transaction.Detail.SqlStatementWithTheLongest">最も時間がかかる SQL</UI-TERM>** テキスト、**影響を受けた行数が最も多いSQL** テキスト、または **<UI-TERM key="ocp-v2.Transaction.Detail.SqlExecutionDetails">実行された SQL の詳細</UI-TERM>** 内のSQLテキストをクリックすると、そのSQLの詳細を確認できます。

  <!-- ![Image 108](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/%E4%BA%8B%E5%8A%A1%E8%AF%A6%E6%83%85.png) -->

* トランザクションを閉じる

  **<UI-TERM key="ocp-v2.Detail.Transaction.TransactionList">トランザクションリスト</UI-TERM>** ページで、閉じるトランザクションを選択し、操作列の **<UI-TERM key="ocp-v2.Detail.Transaction.CloseATransaction">トランザクションを閉じる</UI-TERM>** ボタンをクリックします。複数のトランザクションを選択し、**<UI-TERM key="ocp-v2.Detail.Transaction.CloseTransactionsInBatches">トランザクションを一括終了</UI-TERM>** をクリックすることもできます。ダイアログボックスで **<UI-TERM key="ocp-v2.Report.Component.GenerateReportModal.Determine">確定</UI-TERM>** をクリックすると、選択したトランザクションのセッションが終了します。セッションを終了すると、トランザクションはロールバックされ、セッション接続も終了します。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><strong>長時間トランザクション</strong> リスト内の通常トランザクションと分散トランザクションのみサポートされています。</p>
   </main>
