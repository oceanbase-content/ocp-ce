# アラート対象の設定

アラートテンプレートを設定した後、そのアラートテンプレートに対するアラート対象を設定する必要があります。**<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertRules">アラートルール</UI-TERM>** でそのオブジェクトにアラートルールを設定している場合、システムはここで選択したアラートテンプレート内のアラートルールを優先します。

アラート対象の設定には、以下の2つの方法があります：

* アラートテンプレートの作成が成功した後、送信結果ページで **<UI-TERM key="ocp-v2.Template.Component.Result.SetAlertObjects">アラート対象を設定する</UI-TERM>** をクリックします。
* アラートテンプレート一覧ページで、指定したアラートテンプレートを選択し、**...** > **<UI-TERM key="ocp-v2.Alarm.Template.Detail.SetAlertObjects">アラート対象を設定する</UI-TERM>** を選択します。

このセクションでは、アラートテンプレート一覧ページでアラート対象を設定する例を説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.All">すべて</UI-TERM>** メニュー権限。

* [新しいアラートテンプレートの作成](../400.manage-alert-templates/100.create-an-alert-template.md)を完了していること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.AlertTemplate">アラートテンプレート</UI-TERM>** タブをクリックします。

4. アラートテンプレートタブで、指定したアラートテンプレートの操作列を見つけ、**...** > **<UI-TERM key="ocp-v2.Template.Component.Result.SetAlertObjects">アラート対象を設定する</UI-TERM>** を選択します。

5. **<UI-TERM key="ocp-v2.Alarm.Template.Detail.SetAlertObjects">アラート対象を設定する</UI-TERM>** パネルで、実際のニーズに応じて具体的なアラート対象を選択します。

    対象として **<UI-TERM key="ocp-v2.Component.OCPObjscope.All">すべて</UI-TERM>** を選択すると、アラート対象には現在のアラート対象タイプの既存オブジェクトと今後追加されるオブジェクトが含まれます。右側の **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.ExcludeObjects">除外対象</UI-TERM>** をチェックすることで、このアラートテンプレートを使用しないオブジェクトを除外できます。

6. **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.Submit">送信</UI-TERM>** をクリックします。
