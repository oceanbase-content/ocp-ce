# アラートテンプレートの編集

ビジネスニーズに応じて、システム管理者およびOCPアラート管理者はアラートテンプレートを変更できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* アラートセンターの **<UI-TERM key="ocp-v2.component.common.ServerSelect.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Template.Detail.AlertTemplate">アラートテンプレート</UI-TERM>** タブをクリックします。

4. アラートテンプレートタブで、対象のアラートテンプレートの操作列を見つけ、**...** > **<UI-TERM key="ocp-v2.Alarm.Template.EditTemplate">テンプレートを編集する</UI-TERM>** を選択して、アラートテンプレートを再設定します。

   * アラートテンプレートの **<UI-TERM key="ocp-v2.component.StepsMoveOutCluster.Step2.BasicInformation">基本情報</UI-TERM>** を設定します。

     ![12060106](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E6%A8%A1%E6%9D%BF%E5%9F%BA%E6%9C%AC%E4%BF%A1%E6%81%AF1.png)

   * アラートテンプレートのルール情報を設定します。詳細については、[新しいアラートルールの作成](../300.manage-alert-rules/100.create-an-alert-rule.md)を参照してください。

     ![Image 142](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E6%A8%A1%E6%9D%BF%E8%A7%84%E5%88%991.png)

5. **<UI-TERM key="ocp-v2.Tenant.New.Submitted">送信</UI-TERM>** をクリックします。
