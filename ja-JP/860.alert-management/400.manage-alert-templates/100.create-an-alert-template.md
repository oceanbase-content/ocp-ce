# アラートテンプレートの作成

OCPシステムには、業務の日常的な監視ニーズを満たすための汎用的なアラートテンプレートが組み込まれています。それに加えて、このセクションを参照して、業務に必要なアラートテンプレートをカスタマイズし、業務オブジェクトに対して統一的なアラートルールを設定することもできます。

[新規アラートルールの作成](../300.manage-alert-rules/100.create-an-alert-rule.md)に比べて、アラートテンプレートを新規作成する方が、業務オブジェクトに対して一括でアラートルールを設定できるため、より迅速です。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* アラートセンターの **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.AlertTemplate">アラートテンプレート</UI-TERM>** タブをクリックします。

4. アラートテンプレートタブで、カーソルを右上の **<UI-TERM key="ocp-v2.Alarm.Template.CreateAnAlertTemplate">新しいアラートテンプレートを作成</UI-TERM>** に合わせ、メニューバーからテンプレートタイプを選択します。

5. アラートテンプレートの **<UI-TERM key="ocp-performance-report.pages.AWR.BasicInformation">基本情報</UI-TERM>** を設定します。

      **<UI-TERM key="ocp-v2.component.ParameterTemplate.DetailDrawer.TemplateName">テンプレート名</UI-TERM>** と **<UI-TERM key="ocp-v2.Alarm.Template.Detail.Description">説明</UI-TERM>** を入力し、**<UI-TERM key="ocp-v2.Alarm.Template.New.EnableTemplate">テンプレートを有効にする</UI-TERM>** かどうかを選択します。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%A8%A1%E6%9D%BF%E5%9F%BA%E7%A1%80%E4%BF%A1%E6%81%AF1.png)

      システムに組み込まれているアラートテンプレートや、作成後しばらく使用しないアラートテンプレートは、後からここで無効化できます。

6. アラートルール情報を設定します。

   1. アラートルールタイプを選択します。

      実際のニーズに応じて、アラートルールタイプタブを切り替えます。表示されるタブは、選択したテンプレートタイプによって異なります。

      |  テンプレートタイプ  |  アラートルールタイプ   |
      |--------|---------|
      | OceanBaseテンプレート    | <ul><li>クラスタアラート</li> <li>テナントアラート</li><li>OBServerアラート</li></ul> |
      | OBProxyテンプレート   | <ul><li>OceanBaseクラスタアラート</li> <li>OBProxyクラスタアラート</li></ul>   |
      | OCPテンプレート   |  <ul><li>バックアップ・リストアアラート</li> <li>サービスアラート</li><li>ホストアラート</li></ul> |
      | ログテンプレート   | <ul><li>OceanBaseアラート</li> <li>OBProxyアラート</li><li>ホストアラート</li> </ul> |

   2. **<UI-TERM key="ocp-v2.Alarm.Template.New.AddRule">ルールを追加する</UI-TERM>** ボタンをクリックし、ポップアップメニューから追加するルールを選択します。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%B7%BB%E5%8A%A0%E8%A7%84%E5%88%991.png)

   3. アラートルールの **<UI-TERM key="ocp-v2.Alarm.Rule.TriggerCondition">トリガー条件</UI-TERM>** や **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlarmCycle">アラート周期</UI-TERM>** などの情報を設定します。

   4. 左側の **<UI-TERM key="ocp-v2.Alarm.Template.Detail.Rules">ルール</UI-TERM>** リストの **<UI-TERM key="ocp-v2.Alarm.Template.New.AddRule">ルールを追加する</UI-TERM>** をクリックし、アラート対象に複数のアラートルールを設定します。

      アラートルールの設定については、[新規アラートルールの作成](../300.manage-alert-rules/100.create-an-alert-rule.md) の説明を参照してください。

7. **<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.Submitted">送信</UI-TERM>** をクリックします。

   結果ページでは、**<UI-TERM key="ocp-v2.Template.Component.Result.ReturnToTemplateList">テンプレートリストに戻る</UI-TERM>** を選択するか、テンプレート **<UI-TERM key="ocp-v2.Alarm.Template.Detail.SetAlertObjects">アラート対象を設定する</UI-TERM>** を操作できます。
