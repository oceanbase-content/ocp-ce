# アラートルールの削除

ビジネスニーズに応じて、システム管理者およびOCPアラート管理者はアラートルールを削除できます。システムで事前設定されたアラートルールは削除できません。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.Component.LogTypeSelect.All">すべて</UI-TERM>** メニュー権限。

* [新しいアラートルールの作成](../300.manage-alert-rules/100.create-an-alert-rule.md)を行っていること。削除するアラートルールは、システムで事前設定されたものではなく、カスタムアラートルールである必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertRules">アラートルール</UI-TERM>** タブで、対象のアラートルールを見つけます。

4. 対応する操作列の **...** ボタンから **<UI-TERM key="ocp-v2.Detail.LoadBalance.Delete">削除</UI-TERM>** を選択します。

   ![Image 122](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/alarm/%E5%88%A0%E9%99%A4%E5%91%8A%E8%AD%A6%E8%A7%84%E5%88%99-1.png)

5. システムが表示するこのアラートルールの削除を確認するダイアログボックスで、**<UI-TERM key="ocp-v2.src.constant.credential.Delete">削除</UI-TERM>** をクリックします。
