# アラートのグループ化

アラート配信の設定を容易にするため、OCPはアラートのグループ化をサポートしており、各アラートルールを簡単に分類できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* アラートセンターの **<UI-TERM key="ocp-v2.component.common.ClusterSelect.All">すべて</UI-TERM>** メニュー権限。

## 手順

### グループの管理

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Alarm.AlertRules">アラートルール</UI-TERM>** タブの左側で **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.RuleGrouping">ルールグループ</UI-TERM>** を管理します。

   * カスタムグループの作成：**<UI-TERM key="ocp-v2.Alarm.Rule.RuleGrouping">ルールのグループ化</UI-TERM>** の右側にある作成アイコンをクリックし、新しいグループ名を入力します。

     ![Image 82](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E8%A7%84%E5%88%99%E5%88%86%E7%BB%841.png)

   * グループ名の変更：指定したグループの右側にある **...** を展開し、**<UI-TERM key="ocp-v2.Detail.Component.RenameTenantModal.Rename">名前の変更</UI-TERM>** を選択します。

     ![Image 110](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/8912299461/p430091.png)

   * グループのコピー：指定したグループの右側にある **...** を展開し、**<UI-TERM key="ocp-v2.Auth.User.Detail.Copy">コピー</UI-TERM>** を選択します。

     システムはソースグループをベースに新しいグループを作成し、新しいグループにはソースグループのアラートルール情報が含まれます。新しいグループの名前はデフォルトで「ソースグループ名_COPY」となりますが、新しく作成したグループ名を変更できます。

   * グループの削除：指定したグループの右側にある **...** を展開し、**<UI-TERM key="ocp-v2.page.External.Delete">削除</UI-TERM>** を選択します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>システムの組み込みグループは、名前の変更や削除操作はできません。</p>
</main>

### グループ内のアラートルールの検索

1. 左側のナビゲーションバーで **システム管理 > アラート** をクリックします。

2. **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertRules">アラートルール</UI-TERM>** タブの左側にある **<UI-TERM key="ocp-v2.Alarm.Rule.RuleGrouping">ルールのグループ化</UI-TERM>** で、現在のすべてのアラートグループを確認できます。

   グループ名をクリックすると、画面の右側にそのグループ内のすべてのアラートルールが表示されます。

   ![Image 113](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E5%88%86%E7%BB%84%E8%AF%A6%E6%83%851.png)

3. ページ上部の検索ボックスで検索条件を選択すると、そのグループ内で検索条件に一致するアラートルールを検索できます。

### アラートルールの追加

* 単一のアラートルールをアラートグループに追加：

  1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.Alert">アラート</UI-TERM>** をクリックします。

  2. **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertRules">アラートルール</UI-TERM>** タブで、対象のアラートルールを見つけます。

  3. 対応する操作列の **...** から **<UI-TERM key="ocp-v2.Alarm.Rule.AddToRuleGroup">ルールグループに追加</UI-TERM>** を選択します。

  4. ポップアップウィンドウでルールグループを選択します。

  5. **<UI-TERM key="ocp-v2.component.FormEditTable.Determine">確定</UI-TERM>** をクリックします。

  ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%B7%BB%E5%8A%A0%E5%88%B0%E5%91%8A%E8%AD%A6%E5%88%86%E7%BB%841.png)

* 複数のアラートルールをアラートグループに追加：

  1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.constant.auth.Alert">アラート</UI-TERM>** をクリックします。

  2. **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">アラートルール</UI-TERM>** タブで、追加したいアラートルールにチェックを入れます。

  3. **一括してアラートグループに追加** をクリックします。

  4. ポップアップウィンドウでルールグループを選択します。

  5. **<UI-TERM key="ocp-v2.Component.ZoneList.EditZoneModal.Ok">確定</UI-TERM>** をクリックします。

  ![グループ管理](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%89%B9%E9%87%8F%E6%B7%BB%E5%8A%A0%E5%88%B0%E5%91%8A%E8%AD%A6%E5%88%86%E7%BB%841.png)

<main id="notice" type='explain'>
<h4>説明</h4>
<p>各アラートルールには必ずアラートグループが設定されている必要があります。アラートが発生した場合に関連する人員に通知するためです。</p>
</main>

### アラートルールの削除

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.constant.auth.Alert">アラート</UI-TERM>** をクリックします。

2. **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">アラートルール</UI-TERM>** タブで、左側の **グループ管理** から操作対象のグループを選択します。右側のページには、そのグループのすべてのアラートルールが表示されます。

   削除するアラートルールの **<UI-TERM key="ocp-v2.Component.ArbitrationServerList.Remove">削除する</UI-TERM>** ボタンを **<UI-TERM key="ocp-v2.Alarm.Channel.Operation">操作</UI-TERM>** 列でクリックし、そのアラートルールをグループから削除します。または、削除するアラートルールを選択し、**<UI-TERM key="ocp-v2.Alarm.Rule.BatchRemoval">一括削除</UI-TERM>** をクリックして、アラートルールを一括削除することもできます。

   ![Image 85](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%89%B9%E9%87%8F%E7%A7%BB%E9%99%A4%E5%91%8A%E8%AD%A6%E8%A7%84%E5%88%991.png)

<main id="notice" type='explain'>
<h4>説明</h4>
<p>この操作は、グループからアラートルールを削除するだけであり、アラートルール自体を削除するものではありません。</p>
</main>

## デフォルトのグループ

システムには8つの初期グループが組み込まれています。システムの組み込みグループは編集可能ですが、削除することはできません。

| **グループ名** |   **グループの説明**       |
|----------|-------|
| データベースカーネル      | OceanBaseクラスタアラート、OceanBaseテナントアラート、OceanBaseサーバーアラートなど、データベースリソース関連のアラート。 |
| dev      | 運用保守担当者が注目すべきアラート。   |
| バックアップ・リストア      | バックアップ・リストア管理者が注目すべきアラート。一般的にバックアップ・リストア関連のアラートが含まれます。   |
| データ移行      | OMS関連のアラート。   |
| プロンプト      | メンテナンス操作結果のリマインダーなどの通知情報。   |
| ocp      | OCP関連コンポーネントのアラート。関連コンポーネントにはOCP-Agent、MetaDB、MetaDBに依存するOBProxy、OCP内部コンポーネントなどが含まれます。  |
| oas     | インテリジェント診断に依存するアラートルール。 |
| ログ    | OceanBaseログアラート、OBProxyログアラート、サーバーメッセージログアラート、ocp_agentログアラートなどのログアラート。 |
| セルフヘルス     | ワンクリックで緊急対応計画を実行できるアラート。 |
| リソース     | メモリ、ハンドル、ディスクなどのサーバーリソース使用状況をリマインドするアラート。 |
| パフォーマンス     | サーバーパフォーマンス使用状況に関連するアラート。 |
| 可用性     | 高可用性状態に関連するアラート。 |
