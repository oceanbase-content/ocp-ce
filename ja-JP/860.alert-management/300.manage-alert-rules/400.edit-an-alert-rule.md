# アラートルールの編集

ビジネスニーズに応じて、システム管理者およびOCPアラート管理者はアラートルールを変更できます。

アラート対象がアラートルールとアラートテンプレートの両方に追加されている場合、システムはアラートテンプレート内のアラートルールを優先し、ここで変更したアラートルールは適用されません。その対象のアラートルールを変更するには、[アラートテンプレートの変更](../400.manage-alert-templates/600.edit-an-alert-template.md)を参照してください。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* アラートセンターの **<UI-TERM key="ocp-v2.Detail.Analyze.TimesChart.All">すべて</UI-TERM>** メニュー権限。

## 注意事項

* アラートの有効性を保証するため、一部のアラートルール設定における **演算子**、**しきい値**、および **継続時間** は変更できません。
* **arbitration_node_connection_with_observer_error Arbitrationノードがobserverに接続できない** アラートルールを変更する際は、**キーワード** に入力する文字列が正規表現として有効であることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Alarm.AlertRules">アラートルール</UI-TERM>** タブで、指定したアラートルールを見つけます。

4. 対応する操作列の **...** から **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Detail.Edit">編集</UI-TERM>** を選択し、アラートルールを再設定します。

   関連する設定の説明については、[新しいアラートルールの作成](../300.manage-alert-rules/100.create-an-alert-rule.md)を参照してください。

5. **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.Submitted">送信</UI-TERM>** をクリックします。
