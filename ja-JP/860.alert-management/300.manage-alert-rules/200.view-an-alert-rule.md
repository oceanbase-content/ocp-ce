# アラートルールの表示

このセクションでは、アラートルールを表示する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* アラートセンターの **<UI-TERM key="ocp-v2.Alarm.LogFilter.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertRules">アラートルール</UI-TERM>** タブの検索エリアに検索条件を入力します。アラートオブジェクトの正確な検索がサポートされ、検索結果がアラートルールリストとして返されます。

4. 表示したいアラート名をクリックすると、アラートルールの詳細設定を確認できます。
