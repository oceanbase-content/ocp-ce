# アラート項目設定のエクスポート

このセクションでは、指定したアラートオブジェクトのアラートルールをエクスポートする方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* アラートセンターの **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ClusterWithExclude.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlertRules">アラートルール</UI-TERM>** タブをクリックします。

4. そのタブ上部の検索エリアに検索条件を入力します。アラートオブジェクトの正確な検索が可能で、アラートルールのリストには検索結果が返されます。

5. **<UI-TERM key="ocp-v2.Alarm.Rule.ExportAlertItemConfiguration">アラート項目設定のエクスポート</UI-TERM>** ボタンをクリックし、検索結果を.xlsx形式でローカルにエクスポートします。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/alarm/%E5%AF%BC%E5%87%BA%E5%91%8A%E8%AD%A6%E8%A7%84%E5%88%99-1.png)

<main id="notice" type='explain'>
<h4>説明</h4>
<li>検索条件を入力しない場合、すべてのアラートルールがエクスポートされます。</li>
<li>データが2000件を超える場合、現在のリストの順序で上位2000件のデータのみがエクスポートされます。</li>
</main>
