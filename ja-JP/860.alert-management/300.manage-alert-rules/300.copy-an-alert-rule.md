# アラートルールのコピー

追加するアラートルールが既存のルールとほぼ同じ場合は、このセクションを参照して既存のルールをコピーし、一部の設定を変更できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.Component.LogTypeSelect.All">すべて</UI-TERM>** メニュー権限。

* 既に [新規アラートルールの作成](../300.manage-alert-rules/100.create-an-alert-rule.md) を行っていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Rule.AlertRules">アラートルール</UI-TERM>** タブの **<UI-TERM key="ocp-v2.Alarm.Rule.Detail.AlertRules">アラートルール</UI-TERM>** リストで、コピーしたいアラートルールを見つけます。

4. 対応する操作列で、**<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Copy">コピー</UI-TERM>** をクリックします。

   ![Image 93](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/alarm/%E5%A4%8D%E5%88%B6%E5%91%8A%E8%AD%A6%E8%A7%84%E5%88%99-1.png)

5. （オプション）**<UI-TERM key="ocp-v2.Alarm.Rule.New.CopyAlertRules">アラートルールをコピーする</UI-TERM>** ページで、アラートルールの基本情報、ルール設定、およびアラート詳細設定を変更します。

6. **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">送信</UI-TERM>** をクリックします。
