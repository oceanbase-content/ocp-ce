# アラートプッシュの新規作成

アラートプッシュを新規作成すると、システムが生成するアラートメッセージを指定したアラートチャネルを通じてユーザーに通知します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ管理**、**テナント管理**、**OBProxy管理**、**アービトレーションサービス管理**、**Binlogサービス管理**、または**ホスト管理**のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.Detail.Component.RestartModal.All">すべて</UI-TERM>** メニュー権限。

* [アラートルールの新規作成](../300.manage-alert-rules/100.create-an-alert-rule.md) を行っていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.AlertPush">アラート通知</UI-TERM>** タブをクリックします。

4. アラートプッシュタブで、**<UI-TERM key="ocp-v2.Alarm.Subscriptions.CreatePushConfiguration">新規プッシュ設定</UI-TERM>** ボタンをクリックします。

5. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.CreatePush">新規プッシュ</UI-TERM>** ページに移動し、**<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.PushConfiguration">プッシュ設定</UI-TERM>** モジュールでプッシュタイプを選択します。

   システムは **<UI-TERM key="ocp-v2.src.constant.alarm.AlarmClassification">アラートの分類</UI-TERM>** プッシュと **<UI-TERM key="ocp-v2.Alarm.Template.Detail.AlertTemplate">アラートテンプレート</UI-TERM>** の2種類のプッシュモードをサポートしています。

   * **<UI-TERM key="ocp-v2.src.constant.alarm.AlarmClassification">アラートの分類</UI-TERM>**

      **<UI-TERM key="ocp-v2.Alarm.Rule.New.AlarmClassification">アラートの分類</UI-TERM>** プッシュを選択した場合、アラートメッセージを指定されたオブジェクトにプッシュすることができます。指定オブジェクトを設定しない場合、システムはグループ設定ルールとアラートオブジェクトの設定に基づいてアラートメッセージをプッシュします。

      <main id="explain" type='alert'>
      <h4>説明</h4>
      <p><ul><li>アプリケーションに対して少なくとも1つのオブジェクト範囲を選択する必要があります。</li><li>OCPアプリケーションでは、オブジェクト範囲に <b>サービス</b> および <b>バックアップ・リカバリ</b> を選択した場合、指定オブジェクトの設定は不要です。</li><li>OMSアプリケーションでは、オブジェクト範囲に <b>サービス</b> を選択した場合、指定オブジェクトの設定は不要です。</li></ul></p>
      </main>

      <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/alarm/%E6%96%B0%E5%BB%BA%E6%8E%A8%E9%80%81%E9%85%8D%E7%BD%AE-1.png) -->

   * **<UI-TERM key="ocp-v2.page.Alarm.AlertTemplate">アラートテンプレート</UI-TERM>**

      **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.AlertTemplate">アラートテンプレート</UI-TERM>** プッシュを選択した場合、ページ下部にシステム内のすべてのアラートテンプレートが表示されます。メッセージをプッシュするテンプレートを選択すると、アラートメッセージはそのテンプレート内のすべてのオブジェクトにプッシュされます。

      <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>アラートテンプレートにアラートオブジェクトが設定されていない場合、そのテンプレートはグレーアウトされ、選択できません。<a href="../400.manage-alert-templates/200.set-alert-objects.md">アラートオブジェクトの設定</a> を参照して、アラートテンプレートにアラートオブジェクトを追加してください。</p>
      </main>

      <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/alarm/%E6%96%B0%E5%BB%BA%E6%8E%A8%E9%80%81%E9%85%8D%E7%BD%AE-2.png) -->

6. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.PushMessageConfiguration">プッシュメッセージの設定</UI-TERM>** セクションで、以下の内容を設定します：

   1. プッシュメッセージの言語を選択します。**<UI-TERM key="ocp-v2.Alarm.Channel.New.SimplifiedChinese">簡体字中国語</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Channel.Detail.TraditionalChinese">繁体字中国語</UI-TERM>**、および **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.English">英語</UI-TERM>** がサポートされています。

   2. アラート方式を設定します。**<UI-TERM key="ocp-v2.page.Overview.AlarmLevel">アラートレベル</UI-TERM>**、**<UI-TERM key="ocp-v2.Alarm.Event.Detail.AlertChannel">アラートチャネル</UI-TERM>**、および **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.NotificationPeriod">通知時間帯</UI-TERM>** を含みます。

      特定の時間帯にアラートプッシュメッセージを受信したくない場合は、指定時間でのプッシュを設定できます。設定しない場合は、終日アラートメッセージ通知を受信します。

      <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>少なくとも1つのアラートレベルに対してアラートチャネルを設定する必要があります。</p>
      </main>

      <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/430/%E5%91%8A%E8%AD%A6%E6%B6%88%E6%81%AF%E6%8E%A8%E9%80%81.png) -->

   3. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.AlarmMessageReceivingLimit">アラートメッセージ受信制限</UI-TERM>** を有効にするかどうかを選択します。

      有効にすると、アラートチャネルから送信されるメッセージの数を制限できます。アラート受信制限を超えた場合、アラートチャネルはアラートメッセージをプッシュしません。

      <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%91%8A%E8%AD%A6%E6%B6%88%E6%81%AF%E6%8E%A5%E6%94%B6%E9%99%90%E5%88%B61.png) -->

   4. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.RecoveryNotification">回復通知</UI-TERM>** を有効にするかどうかを選択します。

      有効にすると、アラートイベントが復旧状態に変更された場合、アラート復旧通知メッセージが送信されます。

   5. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.EnablePush">プッシュ通知を有効にする</UI-TERM>** を選択します。

      作成後、一時的に使用しないアラートプッシュについては、後からここで無効にできます。

7. **<UI-TERM key="ocp-v2.Template.Component.AddTargetDrawer.Submit">送信</UI-TERM>** をクリックします。
