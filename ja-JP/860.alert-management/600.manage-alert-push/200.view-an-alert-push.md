# アラートプッシュの表示

このセクションでは、作成したアラートプッシュを表示する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または**ホスト読み取り専用** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.src.component.MyDropdown.All">すべて</UI-TERM>** メニュー権限。

* [新規アラートプッシュの作成](../600.manage-alert-push/100.create-an-alert-push.md)を行っていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Alarm.AlertPush">アラート通知</UI-TERM>** タブをクリックします。

4. アラートプッシュタブの検索エリアに検索条件を入力し、アラートプッシュを正確に検索できます。**<UI-TERM key="ocp-v2.Alarm.Subscriptions.PushConfigurationList">プッシュ設定リスト</UI-TERM>** には、検索条件に一致するすべてのアラートプッシュ情報が返されます。

5. 表示するアラートプッシュを選択し、対応する **<UI-TERM key="ocp-v2.Cluster.Arbitration.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.page.Information.View">表示</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.Alarm.Subscriptions.View">プッシュ設定を確認する</UI-TERM>** パネルで、そのアラートプッシュの詳細設定を確認します。
