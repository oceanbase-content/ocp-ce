# アラートプッシュの編集

このセクションを参照して、作成済みのアラートプッシュを編集します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.component.common.OBProxySelect.All">すべて</UI-TERM>** メニュー権限。

* [新しいアラートプッシュの作成](../600.manage-alert-push/100.create-an-alert-push.md)を行っていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.AlertPush">アラート通知</UI-TERM>** タブをクリックします。

4. アラートプッシュタブの検索エリアに検索条件を入力すると、アラートプッシュの正確な検索が可能です。**<UI-TERM key="ocp-v2.Alarm.Subscriptions.PushConfigurationList">プッシュ設定リスト</UI-TERM>** には、検索条件に一致するすべてのアラートプッシュ情報が返されます。

5. 編集したいアラートプッシュを選択し、対応する **<UI-TERM key="ocp-v2.Component.ZoneList.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.page.Tags.TagList.Edit">編集</UI-TERM>** をクリックします。

    **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.EditPush">プッシュ通知を編集</UI-TERM>** パネルで、そのプッシュの詳細設定を変更します。具体的な設定については、[新しいアラートプッシュの作成](../600.manage-alert-push/100.create-an-alert-push.md)のパラメータ説明を参照してください。

6. **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.Submitted">送信</UI-TERM>** をクリックします。
