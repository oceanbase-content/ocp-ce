# アラートプッシュの削除

このセクションでは、作成したアラートプッシュを削除する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.Detail.Analyze.All">すべて</UI-TERM>** メニュー権限。

* [新しいアラートプッシュの作成](../600.manage-alert-push/100.create-an-alert-push.md)が完了していること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.page.Alarm.Alarm">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Detail.AlertPush">アラート通知</UI-TERM>** タブをクリックします。

4. アラートプッシュタブの検索エリアに検索条件を入力して、アラートプッシュを正確に検索できます。**<UI-TERM key="ocp-v2.Alarm.Subscriptions.PushConfigurationList">プッシュ設定リスト</UI-TERM>** には、検索条件に一致するすべてのアラートプッシュ情報が返されます。

5. 削除するアラートプッシュを選択し、対応する **<UI-TERM key="ocp-v2.Detail.Database.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.alarm.ExpressionFormList.MultipleExpressionFormList.Delete">削除</UI-TERM>** をクリックします。

6. ダイアログボックスで **<UI-TERM key="ocp-v2.Alarm.Template.New.Delete">削除</UI-TERM>** をクリックします。
