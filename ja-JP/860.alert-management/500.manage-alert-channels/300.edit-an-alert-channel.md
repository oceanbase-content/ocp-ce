# アラートチャネルの編集

業務上の要件に応じて、アラートチャネルを作成した後、管理者はその基本情報、通知内容、およびチャネル設定を変更できます。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.component.common.BinlogClusterSelect.All">すべて</UI-TERM>** メニュー権限。

* [新しいアラートチャネルの作成](../500.manage-alert-channels/100.create-an-alert-channel.md)を行っていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Alarm.AlarmChannel">アラートチャネル</UI-TERM>** タブをクリックします。

4. アラートチャネルタブで、編集するチャネルを選択し、対応する **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">編集</UI-TERM>** をクリックします。

5. インターフェースの指示に従ってチャネルの設定情報を変更します。関連する設定説明については、[新しいアラートチャネルの作成](100.create-an-alert-channel.md)を参照してください。

6. **<UI-TERM key="ocp-v2.Alarm.Channel.New.SendTestMessages">テストメッセージを送信</UI-TERM>** をクリックし、送信が成功した場合は、直接 **<UI-TERM key="ocp-v2.Auth.User.New.Submitted">送信</UI-TERM>** をクリックできます。
