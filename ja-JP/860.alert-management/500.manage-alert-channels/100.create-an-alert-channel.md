# アラートチャネルの作成

この章では、アラートチャネルを新規作成する方法について説明します。

## 背景

アラート自体は独立した機能であり、チャネルが設定されていない場合は、コンソールの **<UI-TERM key="ocp-v2.page.Alarm.AlarmEvent">アラートイベント</UI-TERM>** ページでのみアラートを確認できます。アラートチャネルを設定することで、ユーザーはアラート通知メッセージを受信できるようになります。

アラートチャネルは通知メッセージを送信する媒体であり、以下のチャネルタイプをサポートしています：

* 鋾钉

* 飞书

* 企业微信

* メール

* HTTP

* Slack

* カスタムスクリプト：PythonおよびBashスクリプトをサポートしています。[アラートチャネル設定例](../500.manage-alert-channels/600.examples-of-alert-channel-configuration.md)の **カスタムスクリプトチャネル** を参照してスクリプトをカスタマイズできます。

  <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>アラートの集計時間パラメータはチャネルで設定されます。アラートチャネルを更新すると、そのチャネルは集計計算をやり直します。現在アラートが発生しており、まだ収まっていない場合、集計期間内に再度アラート通知を受け取る可能性があります。</p>
  </main>

OCPにはデフォルトのチャネルが事前設定されていますが、使用するには設定が必要であり、削除することはできません。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * アラートセンターの **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.ObproxyClusterAndHostWithExclude.All">すべて</UI-TERM>** メニュー権限。

* 受信ユーザーの基本情報が事前に設定されていること。

## 手順

<main id="notice" type='explain'>
<h4>説明</h4>
<p>以下の手順は、<a href="700.alarm-channel-settings-example.md">アラートチャネル設定例</a>の説明と照らし合わせて理解することを推奨します。</p>
</main>

### ステップ１：チャネル作成ページにアクセスする

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.hook.useMenu.AlarmCenter">アラートセンター</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Alarm.Subscriptions.New.AlarmChannel">アラートチャネル</UI-TERM>** タブをクリックします。

4. アラートチャネルタブで、**<UI-TERM key="ocp-v2.Alarm.Channel.NewChannel">新規チャネル作成</UI-TERM>** をクリックします。

### ステップ2：チャネルの基本情報を設定する

画面の指示に従って、チャネルの基本情報を設定します。チャネルの種類によって、入力が必要な基本情報は異なります。

**<UI-TERM key="ocp-v2.Alarm.Channel.New.ChannelType">チャネルタイプ</UI-TERM>** が **HTTP**、**<UI-TERM key="ocp-v2.Auth.User.New.Mailbox">メールアドレス</UI-TERM>**、または **<UI-TERM key="ocp-v2.src.constant.alarm.CustomScript">カスタムスクリプト</UI-TERM>** のいずれかを選択した場合、画面の指示に従ってチャネルを設定する必要があります。**HTTP** チャネルタイプを例に、具体的な設定手順は以下のとおりです：

| パラメータ | 説明 |
|------|-------|
| プロキシ        | アラート情報を送信するプロキシを入力してください。形式は `http:ip:port` です。ここで、`ip` はプロキシサーバーのIPアドレス、`port` はアラート送信に使用するポートです。プロキシサーバーのIPアドレスが `xxx.xxx.xxx.xxx` で、アラートメッセージの送信にポート80を使用する場合、`http:xxx.xxx.xxx.xxx:80` と設定できます。<main id="notice" type='explain'><h4>説明</h4><p>プロキシの設定はHTTPチャネルのみが必要です。</p></main>   |
| リクエストメソッド      | 実際の状況に応じて選択します。 |
| URL テンプレート    | プッシュ対象のURLを入力します。  |
| Header テンプレート | 実際のニーズに応じて、HTTPプロトコルのHeaderテンプレートを入力します。パラメータ間は改行してください。例：</br><code>Content-Type:application/json</br>x-lt-openKey:diskJitterAlarm</br>charset:utf-8</code>  |
| Body テンプレート   | プッシュする内容のテンプレートを入力します。  |
| Response 検証情報      | オプションです。<ul><li>チャネルによってResponseが異なるため、OCPがメッセージ送信の成功を正確に判断できるように、送信成功時のResponse検証情報を設定する必要があります。</li><li>入力形式はJSON文字列です。OCPはJSON内のフィールドを解析し、チャネルのResponse Body内の対応する情報と照合します。照合が成功した場合、送信は成功したとみなされます。</li><li>チャネルのResponseが不確定な場合、まずは `{ }` と設定してください。OCPはメッセージが常に送信成功したものとみなします。</li><ul>  |

### ステップ3：アラートメッセージと回復メッセージを設定する

1. アラートメッセージの形式を選択します。**テキスト** と **Json** の2種類の形式をサポートしています。

2. 実際のニーズに応じて、アラートメッセージをカスタマイズ設定します。

   1. アラートの **メッセージテンプレート** を設定します。システムがプッシュするメッセージは、設定したテンプレートのスタイルに従って表示されます。

   2. **繰り返しアラート設定** では、同じアラートに対して送信回数と時間間隔を設定し、同一アラートのメッセージが繰り返し送信されるかどうか、およびアラートメッセージの送信頻度を制御します。アラートの時間間隔はデフォルトで600秒、最小値は300秒です。設定値はアラートルールの検出周期以上である必要があります。

   3. **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.AlertMessageAggregation">アラートメッセージの集約</UI-TERM>** 機能を有効にするかどうかを選択します。メッセージ集約を有効にすると、一定期間にアラートが過剰に送信され、重要なメッセージが埋もれるのを防ぐことができます。アラートメッセージ集約を有効にした後、システムは設定したテンプレートのスタイルと間隔でアラートメッセージを送信します。

3. 実際のニーズに応じて、回復メッセージをカスタマイズ設定します。

   1. アラートの **メッセージテンプレート** を設定します。システムがプッシュするメッセージは、設定したテンプレートのスタイルに従って表示されます。

   2. **<UI-TERM key="ocp-v2.Alarm.Channel.Detail.AlertMessageAggregation">アラートメッセージの集約</UI-TERM>** 機能を有効にするかどうかを選択します。メッセージ集約を有効にすると、一定期間に回復メッセージが過剰に送信され、重要なメッセージが埋もれるのを防ぐことができます。回復メッセージ集約を有効にした後、システムは設定したテンプレートのスタイルと間隔で回復メッセージを送信します。

### ステップ4：テストメッセージを送信する

**<UI-TERM key="ocp-v2.Alarm.Channel.New.SendTestMessages">テストメッセージを送信</UI-TERM>** をクリックし、現在設定されているアラートチャネルがアラートメッセージを正常に送信できるかどうかをテストします。

### ステップ5：アラートチャネル設定を送信する

テストメッセージの送信が成功した場合、**<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.Submit">送信</UI-TERM>** をクリックして、このアラートチャネル設定を保存します。
