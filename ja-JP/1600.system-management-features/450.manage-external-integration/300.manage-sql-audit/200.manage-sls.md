# SQL AuditとSLSの連携

本記事では、SQL AuditをSLSデータソースに連携させる方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーがadmin、組織管理者、またはクラスタ管理者ロールであることを確認してください。
* OCP AgentとSLSのネットワーク接続性を確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックします。

3. ページ上部の **SLS** タブで、右上の **<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.New">新規作成</UI-TERM>** をクリックします。

4. ポップアップダイアログで、以下のパラメータを設定します。

   | パラメータ  |   説明   |
   |-----|-------|
   | **<UI-TERM key="ocp-v2.External.Component.CreateSlsDataSource.DataSourceName">データソース名</UI-TERM>**          | 2～32文字。英字、数字、アンダースコアを含めることができます。  |
    | **<UI-TERM key="ocp-v2.SecurityCard.TDE.EnableTde.AccessDomainName">ドメイン名へのアクセス</UI-TERM>**          | SLSサービスのアクセスドメイン名。  |
    | **<UI-TERM>AccessKey ID</UI-TERM>**          | SLSサービスのアクセスID。ユーザー識別に使用されます。  |
    | **<UI-TERM>AccessKey Secret</UI-TERM>**          | 署名文字列の暗号化およびログ検索における署名文字列の検証に使用される秘密鍵です。機密保持が必要です。  |
    | **<UI-TERM key="ocp-v2.New.components.RestoreStandbyTenantSettingsCard.Region">リージョン</UI-TERM>**          | 現在の専用クラウドリージョン。  |
    | **<UI-TERM key="ocp-v2.External.Component.CreateSlsDataSource.Project">プロジェクト</UI-TERM>**          | SLSサービスのプロジェクト名。  |
    | **<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.Remarks">備考</UI-TERM>**          | オプションです。  |

5. ダイアログの右下にある **<UI-TERM key="ocp-v2.src.constant.external.Validation">検証</UI-TERM>** をクリックします。

6. 検証に合格したら、**<UI-TERM key="ocp-v2.Cluster.Component.ConfirmClusterDrawer.New">新規作成</UI-TERM>** をクリックします。

## 関連操作

* **SLSデータソースの検証**：データソース操作列で、**<UI-TERM key="ocp-v2.External.Component.CreateEsDataSource.Validation">検証</UI-TERM>** をクリックします。検証に合格すると、データソース名の後に **<UI-TERM key="ocp-v2.page.Credential.OBProxy.VerifiedSuccessfully">検証に成功しました</UI-TERM>** が表示されます。

* **<UI-TERM key="ocp-v2.External.Component.CreateSlsDataSource.EditSlsDataSource">SLS データソースを編集する</UI-TERM>**：データソース操作列で、**<UI-TERM>... > 編集</UI-TERM>** を選択し、ポップアップダイアログで関連情報を変更してから、**<UI-TERM key="ocp-v2.src.hook.useScaleDownLimitCheck.Save">保存する</UI-TERM>** をクリックします。

* **SLSデータソースの削除**：データソース操作列で、**<UI-TERM>... > 削除</UI-TERM>** を選択し、ポップアップダイアログで **<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.Ok">確定</UI-TERM>** をクリックします。
