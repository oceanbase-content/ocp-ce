# SQL AuditとSLS/ESの連携概要

この機能は、OceanBaseデータベースのSQL Auditデータを外部ストレージシステム（SLSおよびElasticSearch）に連携させることをサポートし、ユーザーの設定プロセスを最大限に簡素化するとともに、データ転送の即時性と信頼性を確保するための監視手段を提供し、データベース操作の可視性とセキュリティを向上させます。

## 背景

エンタープライズレベルのデータベース管理環境において、SQL Auditデータを保持することは、技術的および管理的なニーズに応えるだけでなく、ますます複雑化するセキュリティ上の課題や厳格なコンプライアンス要件に対応するためでもあります。SQL Auditは企業に包括的な操作の透明性を提供し、データセキュリティの確保、運用効率の最適化、コンプライアンス監査への対応、問題への迅速な対応を支える重要な基盤です。

SQL Auditデータを科学的に管理・分析することで、企業は競争においてより高いセキュリティと運用効率を維持しつつ、潜在的な法的およびビジネス上のリスクを低減することができます。

## 概念

### SQL Audit

SQL Auditとは、データベースで実行されるSQL文を監査記録する機能であり、実行時間、ユーザー情報、クライアントIPなどの関連メタデータ情報を含みます。

### アリババクラウドログサービス（SLS）

* アリババクラウドログサービス（SLS）は、クラウドネイティブの観測・分析プラットフォームであり、Log、Metric、Traceなどのデータに対して大規模で低コスト、リアルタイムのプラットフォームサービスを提供します。

* アリババクラウドログサービスは、データ収集、加工、クエリと分析、可視化、アラート、消費と配信などの機能をワンストップで提供し、開発、運用保守、運営、セキュリティなどのシナリオにおけるデジタル化能力を全面的に向上させます。

### ElasticSearch

* ElasticSearchはLuceneをベースとした分散型検索・分析エンジンであり、リアルタイムデータの保存、検索、高度な分析をサポートします。高い拡張性を備えており、大量のデータに対応するためのクラスタを容易に構築でき、RESTful APIを通じて柔軟なクエリを提供します。
* ElasticSearchは、ログ分析、全文検索、リアルタイムデータ監視などのシナリオで広く利用され、構造化データと非構造化データを高速に処理し、企業のデータインサイトと意思決定の最適化を支援します。

## 適用シナリオ

### セキュリティ・コンプライアンス監査

業界の監督要件を満たし、完全なSQL操作の監査記録を提供します。

### パフォーマンス分析と最適化

過去のSQL実行記録を分析し、パフォーマンスボトルネックを特定して最適化します。

### 故障の調査と特定

データベースの異常な操作を迅速に特定し、問題調査の効率を向上させます。
