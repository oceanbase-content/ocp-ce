# SQL AuditとElasticSearchの連携

本記事では、SQL AuditとElasticSearchデータソースを連携させる方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーがadmin、組織管理者、またはクラスタ管理者ロールであることを確認してください。
* OCP AgentとESのネットワーク接続性を確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーの **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックします。

3. ページ上部の **ElasticSearch** タブで、右上の **<UI-TERM key="ocp-v2.page.External.CreateDrawer.Create">新規作成</UI-TERM>** をクリックします。

4. ポップアップダイアログで、以下のパラメータを設定します。

   | パラメータ  |   説明   |
   |-----|-------|
   | **<UI-TERM key="ocp-v2.Detail.SqlAudit.DataSourceName">データソース名</UI-TERM>**          | 2～32文字。中国語、英字、数字、アンダースコアを含めることができます。  |
    | **<UI-TERM key="ocp-v2.Detail.Overview.AccessAddress">アクセスアドレス</UI-TERM>**          | opensearch接続文字列。<ul><li>単一ノードの場合は、ip:port の形式で入力します。例：127.0.0.1:9200</li><li>複数ノードの場合は、カンマで区切ります。例：ip1:port,ip2:port,ip3:port</li></ul>  |
    | **<UI-TERM key="ocp-v2.Auth.User.NewUserName">ユーザー名</UI-TERM>**          | opensearchクラスタのユーザー名。  |
    | **<UI-TERM key="ocp-v2.src.component.AddCredentialModal.Password">パスワード</UI-TERM>**          | opensearchクラスタのユーザーパスワード。  |
    | **<UI-TERM key="ocp-v2.component.alarm.ShieldDrawer.Remarks">備考</UI-TERM>**          | オプションです。  |

5. ダイアログの右下にある **<UI-TERM key="ocp-v2.External.Component.CreateEsDataSource.Validation">検証</UI-TERM>** をクリックします。

6. 検証に合格したら、**<UI-TERM key="ocp-v2.Component.AddSamplingInspectStrategy.New">新規作成</UI-TERM>** をクリックします。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/440/es.png)

## 関連操作

* **ElasticSearchデータソースの検証**：データソース操作列で、**<UI-TERM key="ocp-v2.src.constant.external.Validation">検証</UI-TERM>** をクリックします。検証に合格すると、データソース名の後に **<UI-TERM key="ocp-v2.page.Credential.Host.VerifiedSuccessfully">検証に成功しました</UI-TERM>** が表示されます。

* **ElasticSearchデータソースの編集**：データソース操作列で、**<UI-TERM>... > 編集</UI-TERM>** を選択し、ポップアップダイアログで関連情報を変更してから、**<UI-TERM key="ocp-v2.pages.Kubernetes.ConfigureZoneModal.Save">保存</UI-TERM>** をクリックします。

* **ElasticSearchデータソースの削除**：データソース操作列で、**<UI-TERM>... > 削除</UI-TERM>** を選択し、ポップアップダイアログで **<UI-TERM key="ocp-v2.User.Oracle.UserList.Determine">確定</UI-TERM>** をクリックします。
