# オブジェクトストレージ設定の作成

本記事では、OCPにおいてオブジェクトストレージ設定を作成し、AIクラスタにストレージサポートを提供する方法について説明します。

## 前提条件

* オブジェクトストレージサービス（S3プロトコルをサポートするオブジェクトストレージサービス、例：Alibaba Cloud OSS、AWS S3、Tencent Cloud COS、Huawei Cloud OBSなど）が準備されていること。
* オブジェクトストレージの以下の情報を取得していること：
  * エンドポイント（Endpoint）アドレス
  * リージョン
  * AccessKey ID
  * AccessKey Secret

## 手順

1. OCPにログインした後、左側のナビゲーションバーで一番下のアイコン **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** を選択し、外部連携ページに移動します。

2. 外部連携ページで、**<UI-TERM key="ocp-v2.Overview.components.BasicInformation.ObjectStorage">オブジェクトストレージ</UI-TERM>** タブをクリックします。

3. **<UI-TERM key="ocp-v2.New.Content.DataStorage.NewCreation">新規作成</UI-TERM>** ボタンをクリックすると、オブジェクトストレージ作成ダイアログが表示されます。

4. オブジェクトストレージの設定情報を入力します：

  <main id="notice" type='explain'>
  <h4>説明</h4>
  <ul>
  <li>オブジェクトストレージ設定を作成する際、システムはエンドポイントの到達可能性とAccessKey認証情報の有効性を検証します。</li>
  <li>異なる業務や環境のオブジェクトストレージ設定には、識別しやすい名前を付けることを推奨します。これにより、後の管理が容易になります。</li>
  <li>現在、オブジェクトストレージへのアクセスはAccessKey IDとAccessKey Secretによる方法のみをサポートしており、RAM URLによる認証はサポートされていません。</li>
  </ul>
  </main>

   | パラメータ | 説明 | 必須 |
   |------|------|---------|
   | **<UI-TERM key="ocp-v2.Host.Detail.OCPAgent.Name">名称</UI-TERM>** | オブジェクトストレージ設定の名前で、異なる設定を識別するために使用されます。名前は2～32文字で、英字、数字、アンダースコアを含むことができます。 | はい |
   | **<UI-TERM key="ocp-v2.ObjectStorage.Component.CreateDataSourceModal.TypeOfAgreement">契約の種類</UI-TERM>** | オブジェクトストレージサービスのプロトコルタイプ。**S3**、**OSS**、**OBS** プロトコルをサポートしています。 | はい |
   | **Endpoint** | オブジェクトストレージのアクセスドメイン名。例：`oss-cn-hangzhou.aliyuncs.com`。 | はい |
   | **AccessKey ID** | オブジェクトストレージのアクセスIDで、ユーザーを識別するために使用されます。 | はい |
   | **AccessKey Secret** | 署名文字列を暗号化するためのキーであり、署名サービスが署名文字列を検証するために使用する秘密鍵です。AccessKey Secretは大切に保管してください。 | はい |
   | **<UI-TERM key="ocp-v2.ObjectStorage.Component.getColumns.Region">リージョン</UI-TERM>** | 現在の専用クラウドリージョン。例：`cn-hangzhou`。 | はい |
   | **<UI-TERM key="ocp-v2.Alarm.Shield.Remarks">備考</UI-TERM>** | このオブジェクトストレージ設定に関する備考です。必須ではありません。 | いいえ |

5. 入力が完了したら、**<UI-TERM key="ocp-v2.page.Credential.Host.Verification">検証</UI-TERM>** ボタンをクリックし、設定情報が有効かどうか確認します。

6. 検証に合格したら、**<UI-TERM key="ocp-v2.Detail.Component.SwitchoverModal.Determine">確定</UI-TERM>** ボタンをクリックすると、オブジェクトストレージ設定の作成が成功します。

## オブジェクトストレージ設定の編集

作成済みのオブジェクトストレージ設定のメモ情報は編集できます。オブジェクトストレージリストで該当する設定の **編集** ボタンをクリックし、表示されるダイアログでメモを変更して保存します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>セキュリティ上の理由から、現在はメモ情報の変更のみがサポートされており、編集ページで直接AccessKeyを変更することはできません。AccessKeyの交換が必要な場合は、<a href="500.object-storage-best-practices.md">オブジェクトストレージのベストプラクティス - AccessKeyのローテーション</a>を参照してください。</p>
</main>
