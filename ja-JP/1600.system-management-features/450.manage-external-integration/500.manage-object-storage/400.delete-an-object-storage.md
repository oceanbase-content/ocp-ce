# オブジェクトストレージ設定の削除

本記事では、使用されていないオブジェクトストレージ設定を削除する方法について説明します。

## 前提条件

* オブジェクトストレージ設定が作成済みであること。
* 削除対象のオブジェクトストレージ設定が、AIクラスタやログサービスクラスタによって参照されていないこと。

## 手順

1. OCPにログインし、左側のナビゲーションバーで一番下のアイコン **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** を選択して、外部連携ページに移動します。

2. 外部連携ページで、**<UI-TERM key="ocp-v2.Cluster.Component.ConfirmClusterDrawerAiSection.ObjectStorage">オブジェクトストレージ</UI-TERM>** タブをクリックします。

3. 削除するオブジェクトストレージ設定を見つけ、その設定がどのクラスタにも参照されていないことを確認します。

   <main id="notice" type='notice'>
   <h4>注意</h4>
   <p>オブジェクトストレージ設定がAIクラスタで使用されている場合、削除操作は禁止されます。まず、クラスタの設定を変更し、参照関係を解除してから削除してください。</p>
   </main>

4. 操作列の **<UI-TERM key="ocp-v2.Detail.Component.BatchDeleteUnitModal.Delete">削除</UI-TERM>** ボタンをクリックすると、確認ダイアログが表示されます。

5. 確認ダイアログで、削除するオブジェクトストレージ設定名を確認し、間違いがなければ **<UI-TERM key="ocp-v2.src.hook.usePreCheckSteps.Determine">確定</UI-TERM>** ボタンをクリックします。

   オブジェクトストレージ設定の削除が成功しました。

## 削除できない場合

オブジェクトストレージ設定がAIクラスタによって参照されている場合、削除操作は阻止され、システムは関連するエラーメッセージを表示します。

### 対処手順

1. **参照しているクラスタの検索**：オブジェクトストレージ設定の詳細ページで、関連するクラスタのリストを確認します。

2. **クラスタ設定の変更**：参照されているAIクラスタの詳細ページに移動し、データストレージパスを他の設定に変更します。

3. **削除を再試行**：クラスタの参照がないことを確認したら、削除操作を再度実行します。

<main id="notice" type='notice'>
<h4>説明</h4>
<p>オブジェクトストレージ設定を削除しても、OCP内の設定レコードのみが削除され、オブジェクトストレージサービス上の実際のデータは削除されません。削除後もAK/SKはしばらくカーネル内で使用される可能性があるため、このページで削除した後も、オブジェクトストレージの管理プラットフォームでAK/SKを少なくとも1時間は保持することを推奨します。</p>
</main>
