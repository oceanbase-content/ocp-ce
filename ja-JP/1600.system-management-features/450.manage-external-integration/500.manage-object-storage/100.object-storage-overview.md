# オブジェクトストレージの概要

オブジェクトストレージ（Object Storage）は、OceanBase AIクラスタの核心的な依存コンポーネントです。AIクラスタを作成する際には、外部統合モジュールを通じて、バケットパス、エンドポイントアドレス、AccessKey資格証明など、オブジェクトストレージの接続情報を事前に設定する必要があります。

## 背景

AIクラスタはストレージと計算を分離したアーキテクチャを採用しており、データはローカルディスクではなくオブジェクトストレージサービス上に保存されます。オブジェクトストレージのアクセス資格証明を安全かつ便利に管理するため、OCPは外部統合モジュールを提供し、オブジェクトストレージの設定を一元管理します。

外部統合によるオブジェクトストレージの管理により、以下の利点があります：

* **一元管理**：複数のクラスタで使用されるオブジェクトストレージの設定を一元的に管理し、分散管理による設定の混乱を防ぎます。
* **ライフサイクル管理**：オブジェクトストレージの完全なライフサイクルを管理し、作成、更新、削除操作を含みます。削除操作はOCP内の設定レコードのみを削除し、クラウドベンダー側のAccessKey資格証明は削除しません。
* **資格証明のセキュリティ**：AccessKey資格証明を安全に保存し、クラスタ作成時に自動的に挿入されるため、手動で入力する必要はありません。

## 概念

* **オブジェクトストレージ（Object Storage）**：RESTful APIを介したデータの格納と取得をサポートする分散型ストレージサービスです。一般的なオブジェクトストレージサービスには、Alibaba Cloud OSS、AWS S3、Tencent Cloud COS、Huawei Cloud OBSなどがあります。

* **バケット（Bucket）**：オブジェクトストレージのコンテナで、オブジェクト（ファイル）を格納するために使用されます。各バケットには一意のドメイン名とアクセスアドレスが付与されます。

* **エンドポイント（Endpoint）**：オブジェクトストレージサービスへのアクセスエンドポイントアドレスで、リージョンによって異なります。

* **AccessKey**：オブジェクトストレージへのアクセス資格証明で、認証に使用されるAccessKey IDとAccessKey Secretで構成されます。

## 適用シナリオ

オブジェクトストレージは、OceanBase AIクラスタおよびその依存サービスであるLogserviceの主要なデータ格納領域です。AIクラスタはストレージと計算を分離したアーキテクチャを採用しており、すべてのデータファイルやログファイルなどは、ローカルディスクではなくオブジェクトストレージサービス上に保存されます。

### 注意事項

* **独立したバケット**：AIクラスタとLogserviceクラスタを作成する際には、それぞれ独立したバケットを使用する必要があり、混在はサポートされていません。異なるタイプのクラスタには独立したバケットを割り当てることを推奨し、データの分離とセキュリティを確保します。

* **権限の最小化**：オブジェクトストレージAccessKeyには最小限必要な権限のみを設定し、最小権限の原則に従います。

* **定期的なローテーション**：AccessKeyを定期的にローテーションし、資格証明の漏洩リスクを低減します。

## サポートされているストレージタイプ

OCPは以下のオブジェクトストレージタイプをサポートしています：

| ストレージタイプ | タイプ | 説明 |
|---------|------|------|
| Alibaba Cloud OSS | OSS/S3  | Alibaba Cloudのオブジェクトストレージサービス |
| AWS S3 | S3 | Amazon Web Servicesのオブジェクトストレージサービス |
| Tencent Cloud COS | S3  | Tencent Cloudのオブジェクトストレージサービス |
| Huawei Cloud OBS | S3  | Huawei Cloudのオブジェクトストレージサービス |
