# システムモデルの設定

モデルベンダーに接続した後、既に接続または追加されているモデルベンダーから、システムで使用するモデルを選択する必要があります。これがシステムモデルの設定です。設定完了後、システムは選択したモデルに基づいてOCPナレッジベースを更新し、その時点でチャットボットが有効になります。

以前にシステムモデルを設定していた場合、再設定すると、システムモデルは最新に設定されたモデルに置き換えられます。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。
* [モデルベンダーへの接続](100.link-a-model.md) を参照してターゲットモデルのベンダーに接続済み、または [モデルの追加](200.add-a-model.md) により必要なモデルを追加済みであること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックし、デフォルトで **<UI-TERM key="ocp-v2.pages.External.TheAiModel">大規模モデル</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.External.AIModel.CurrentUse">デフォルトシステムモデル</UI-TERM>** モジュールで、**<UI-TERM key="ocp-v2.AIAssistant.Content.Welcome.SetUpTheSystemModel">システムモデルの設定</UI-TERM>** をクリックします。

4. ポップアップダイアログで、具体的なモデルを選択します。

    |  パラメータ    |  説明    |
    |------------|---------|
    | 会話モデル   | 大規模なテキストデータ上で事前学習を行い、言語の規則性やパターンを学習することで、汎用的な言語理解能力と生成能力を備えたモデル。   |
    | 埋め込みモデル   | テキストを固定長のベクトルに変換して表現することに特化したモデル。ベクトルはデータの意味情報を保持し、後続の類似度計算や分類などのタスクを容易にします。   |
    | Rerankモデル（オプション）   | 初期検索結果を再ランキングし、検索システムの精度を向上させるために使用されます。これらのモデルは通常、コンテキスト情報とユーザーの意図を組み合わせて、初期検索で得られた結果を最適化し、より関連性の高い結果を提供します。<main id="notice" type='explain'><h4>説明</h4><p>QwenのRerankモデルのみサポートしています。</p></main>    |

5. **<UI-TERM key="ocp-v2.AIModel.Component.SetSystemModel.Setup">設定</UI-TERM>** をクリックします。
