# モデルの追加

システムに組み込まれているモデルではニーズを満たせない場合、必要なモデルを手動で追加できます。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 役割であることを確認してください。
* 対象モデルのベンダーのBase URLアドレスとAPI Keyを取得しておいてください。

## 注意事項

* 現在のところ、OCPはOpenAI API形式に互換性のあるモデルのみをサポートしており、モデルのmax_tokensは3.0万以上を推奨します。
* 既存のベンダーにモデルを追加する場合、そのベンダーのモデル状態は **接続済み** である必要があります。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックし、デフォルトで **<UI-TERM key="ocp-v2.pages.External.TheAiModel">大規模モデル</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.ModelManufacturer">モデルプロバイダー</UI-TERM>** モジュールで、**<UI-TERM key="ocp-v2.Alarm.Rule.New.Add">追加</UI-TERM>** をクリックします。

4. 右側のパネルで、モデル情報を入力します。

    |  パラメータ    |  説明   |
    |------------|---------|
    | 大規模言語モデルベンダー | 大規模言語モデルベンダーのタイプを選択します。**<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.ThereAreManufacturers">既存のプロバイダー</UI-TERM>** と **<UI-TERM key="ocp-v2.src.constant.tenant.Custom">カスタマイズ</UI-TERM>** の2種類がサポートされています。<ul><li>既存ベンダー：システムに既に存在する大規模言語モデルベンダーに、個別のモデルを追加します。</li><li>カスタム：その他の大規模言語モデルベンダー配下のモデルを追加します。</li></ul>   |
    | ベンダー名     | <ul><li>**<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">大規模モデルプロバイダー</UI-TERM>** で **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.ThereAreManufacturers">既存のプロバイダー</UI-TERM>** を選択した場合、具体的な大規模言語モデルベンダーを選択してください。</li><li>**<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">大規模モデルプロバイダー</UI-TERM>** で **<UI-TERM key="ocp-v2.Alarm.Rule.New.Custom">カスタマイズ</UI-TERM>** を選択した場合、大規模言語モデルベンダー名を入力してください。長さは2～32文字です。<main id="notice" type='explain'><h4>説明</h4><p>入力したベンダー名がOCP内に既に存在する場合、新規に追加されたモデルはそのベンダー配下のモデルと統合されます。</p></main></li></ul>   |
    | モデルタイプ   | 利用シナリオに応じて、具体的なモデルタイプを選択します。<ul><li>チャット：大規模なテキストデータ上で事前学習を行い、言語の規則性やパターンを学習し、汎用的な言語理解能力と生成能力を備えたモデル。</li><li>埋め込み：テキストを固定長のベクトル表現に変換することに特化したモデルです。このベクトルはデータの意味情報を保持し、後続の類似度計算や分類などのタスクを容易にします。</li><li>Rerank：初期検索結果を再ランキングし、検索システムの精度を向上させるために使用されます。これらのモデルは通常、コンテキスト情報とユーザーの意図を組み合わせて、初期検索で得られた結果を最適化し、より関連性の高い結果を提供します。<main id="notice" type='explain'><h4>説明</h4><p>通用千問の大規模言語モデルベンダーのRerankモデルのみ追加が可能です。</p></main></li></ul>    |
    | モデル名     | モデル名を入力してください。以下の要件があります：<ul><li>大規模言語モデルベンダーに実際に存在するモデル名を入力してください。</li><li>同一の大規模言語モデルベンダー配下で、モデル名は一意である必要があります。</li><li>長さは2～32文字です。</li></ul>    |
    | アクセスURL   | **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">大規模モデルプロバイダー</UI-TERM>** で **<UI-TERM key="ocp-v2.src.constant.tenant.Custom">カスタマイズ</UI-TERM>** を選択した場合に入力します。大規模言語モデル呼び出しのBase URLアドレスを入力してください。例：`https://api.deepseek.com/v1`。`   |
    | API Key    | **<UI-TERM key="ocp-v2.AIModel.Component.AddAiModelDrawer.LargeModelManufacturers">大規模モデルプロバイダー</UI-TERM>** で **<UI-TERM key="ocp-v2.src.constant.inspection.Custom">カスタマイズ</UI-TERM>** を選択した場合に入力します。大規模言語モデル呼び出しのSK（AccessKey Secret）情報を入力してください。デフォルトではマスク表示されますが、平文での確認が可能です。<br>**<UI-TERM key="ocp-v2.External.Component.CreateEsDataSource.AccessAddress">アクセスアドレス</UI-TERM>** と **API Key** の設定が完了したら、**<UI-TERM key="ocp-v2.src.component.ArchiveForm.Test">テスト</UI-TERM>** をクリックし、入力した情報で接続できるか確認してください。   |
    | 備考       | モデルに追加の説明を補足してください。   |

5. **<UI-TERM key="ocp-v2.Detail.Component.AddArbitrationGroupDrawer.Add">追加</UI-TERM>** をクリックします。

6. ダイアログボックスの **<UI-TERM key="ocp-v2.component.Compaction.DumpPolicyDrawer.Ok">確定</UI-TERM>** をクリックします。追加後、このモデルは元のベンダーカードに表示されます。
