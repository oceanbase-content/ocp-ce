# AIモデルベンダーへの接続

モデルベンダーは、AI検索機能を構築するための重要なインフラです。主要なAIサービスをOCPに統合すると、ユーザーが入力した内容はサービス呼び出し時に選択した第三者の大規模言語モデル開発主体に送信され、対応するサービス結果が生成された後、処理済みの形でOCPプラットフォームに返却されます。

AIインテリジェント対話を使用する前に、まずモデルベンダーを選択して接続する必要があります。OCPには、**Qwen**、**DouBao**、**DeepSeek** の3種類のモデルベンダーが組み込まれています。他のベンダーを使用する場合は、[モデルの追加](200.add-a-model.md)を参照して追加してください。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。
* 対象のモデルベンダーのAPI Keyを取得していること。
* 対象のモデルベンダーの接続状態が **未接続** であること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックし、デフォルトで **<UI-TERM key="ocp-v2.pages.External.TheAiModel">大規模モデル</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.ModelManufacturer">モデルプロバイダー</UI-TERM>** モジュールで、使用するAIモデルベンダーを選択し、カード内の **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Connection">接続</UI-TERM>** をクリックします。

4. ポップアップダイアログで、**API Key** と **<UI-TERM key="ocp-v2.Component.DomainNamePopover.Remarks">備考</UI-TERM>** の情報を入力します。

5. **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Connection">接続</UI-TERM>** をクリックします。

6. 接続に成功すると、そのモデルベンダーの接続状態は **<UI-TERM key="ocp-v2.pages.Kubernetes.adapter.Connected">接続済み</UI-TERM>** に切り替わります。

## 関連操作

* **AIモデルベンダーの表示**: モデルベンダーカードをクリックすると、右側のパネルでそのモデルベンダーの詳細なモデル情報を確認できます。

* **AIモデルベンダーの変更**: モデルベンダーへの接続に成功すると、モデルベンダーカード内の **<UI-TERM key="ocp-v2.AIModel.Component.LinkAiModel.Connection">接続</UI-TERM>** ボタンは **<UI-TERM key="ocp-v2.component.FormEditZoneReplicaTable.EditZoneReplicaTable.Modification">修正</UI-TERM>** に変わります。モデルベンダーのAPI Key情報や備考情報を変更する必要がある場合、**<UI-TERM key="ocp-v2.Tenant.Detail.Modify">変更</UI-TERM>** をクリックして内容を更新できます。

  * API Keyが空の場合、API Key情報は変更されません。
  * 変更後、そのベンダー配下のすべての利用可能なモデルがOCPに再読み込みされます。
