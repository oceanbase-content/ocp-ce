# モデルの削除

このセクションを参照して、大規模言語モデルベンダー配下のモデルを削除および管理できます。ユーザーが手動で追加した大規模言語モデルベンダーについては、そのベンダー配下のすべてのモデルが削除された後、該当するベンダーカードも同期されて削除されます。システムに組み込まれたベンダーカードは残ります。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 役割であることを確認してください。
* 使用中のモデルは削除できません。削除が必要な場合は、[システムモデルの設定](300.set-system-model.md)を参照して、現在使用中のモデルを変更してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックし、デフォルトで表示される **<UI-TERM key="ocp-v2.pages.External.TheAiModel">大規模モデル</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.ModelManufacturer">モデルプロバイダー</UI-TERM>** モジュールで、モデルベンダーカードをクリックすると、右側のパネルにそのベンダー配下のすべてのモデル情報が表示されます。

4. 削除するモデルを選択し、操作列の **<UI-TERM key="ocp-v2.Detail.LoadBalance.Delete">削除</UI-TERM>** をクリックします。

5. モデルを削除した後、再度OCPに追加する必要がある場合は、[モデルの追加](200.add-a-model.md)を参照して操作してください。
