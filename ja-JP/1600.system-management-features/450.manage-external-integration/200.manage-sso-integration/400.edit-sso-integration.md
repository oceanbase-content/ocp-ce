# SSO統合の編集

作成済みのSSO統合設定情報を更新する必要がある場合は、このセクションを参照して変更できます。

## 前提条件

現在OCPにログインしているユーザーがADMINロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">外部統合</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO統合リスト</UI-TERM>** ページに移動します。

3. 有効または無効にするSSO統合設定を選択し、**<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">編集</UI-TERM>** をクリックします。
4. ポップアップウィンドウで設定情報を更新し、**<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Ok">確定</UI-TERM>** をクリックします。
