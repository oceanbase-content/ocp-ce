# SSO統合の有効化/無効化の設定

OCPは一つのSSO統合のみをサポートしています。複数のSSO統合を作成した場合、有効化と無効化の操作により、サードパーティログイン方式を切り替えることができます。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** 役割であることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.hook.useMenu.ExternalIntegration">外部統合</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.page.External.SsoIntegrationList">SSO統合リスト</UI-TERM>** ページに移動します。

3. 有効化または無効化するSSO統合を選択し、**<UI-TERM key="ocp-v2.src.component.TraceConfigModal.WhetherToEnable">有効化</UI-TERM>** 列のスイッチをクリックします。

4. ポップアップウィンドウで **<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">確定</UI-TERM>** をクリックします。
