# Prometheusの概要

## 機能紹介

Prometheusは、オープンソースの監視、アラート、時系列データベースを統合したソリューションです。標準化されたデータモデルと、効率的なデータ収集・保存・クエリインターフェースを提供し、HTTPプロトコルを介して監視対象のコンポーネントの稼働状態を定期的に取得できます。システムは、監視クエリをPrometheusに接続することで、OCP-Serverのデータ収集および計算負荷を軽減し、クエリインターフェース全体のスループット性能を大幅に向上させることができます。

## 手順

1. Prometheusデータソースを新規作成します。
2. `prometheus.yaml` 設定ファイルを変更します。
3. Prometheusサービスを再起動します。
4. Prometheusデータソースを有効にします。
5. （オプション）Prometheusデータソースに対してその他の管理操作を実行します。

操作の詳細については、[Prometheusデータソースの新規作成](200.create-prometheus-data-source.md)および[Prometheusデータソースの管理](300.manage-prometheus-data-source.md)を参照してください。

## 注意事項

* OCPが旧バージョンからV4.4.2にアップグレードされた場合、アップグレード前に[OCP監視をPrometheusに統合する](../../../1850.ocp-om-best-practices/1550.prometheus-http-sd.md)手順でPrometheusに接続しており、認証を有効にしていない場合、新規にPrometheusデータソースを作成すると既存のPrometheus設定情報が上書きされます。また、データソースの作成後は、認証を手動で有効にする必要があります。
* 同一のOCP上では、SLSとPrometheusのうちどちらか一方のみを有効にできます。
* OCPとPrometheusサービスが正常に接続を確立するためには、OCPとPrometheusの接続方式を一致させる必要があります。HTTPS方式の接続を推奨します。セキュリティは高いものの設定がやや複雑です。詳細については[HTTPS認証の説明](../../../2100.appendix/1300.https-authentication-instructions.md)を参照してください。OCPがHTTP方式を採用している場合でも、HTTP方式でPrometheusに接続することは可能です。
