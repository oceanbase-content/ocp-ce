# Prometheusデータソースの新規作成

このセクションでは、OCP上でPrometheusデータソースを新規作成する方法と、その後の操作手順について説明します。

## 前提条件

* 現在のOCPでSLSデータソースが有効になっていないことを確認してください。
* V2.28以降のPrometheusサービスがデプロイ済みであること。
* 現在OCPにログインしているユーザーが**ADMIN**ロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーの**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>**をクリックします。

3. **Prometheus**タブをクリックします。

4. **Prometheusデータソース**ページで、**Prometheusデータソースの新規作成**をクリックします。

5. ポップアップダイアログで、**Prometheusデータソース**に関する情報を入力します。

   | パラメータ    | 説明     |
   | --------- | ---------- |
   | データソース名 | Prometheusデータソースの名前。2～32文字で、英字、数字、アンダースコア（_）を含むことができ、一意である必要があります。 |
   | アクセスアドレス   | PrometheusサービスのアクセスIPアドレス。`http/https`で始まり、1つのIPアドレスのみ入力可能です。 |
   | ポート       | Prometheusサービスのアクセスポート。デフォルトは9090で、カスタマイズ可能です。 |
   | ユーザー名     | Prometheusサービスの認証アカウントのユーザー名。なければ入力不要です。 |
   | パスワード       | Prometheusサービスの認証アカウントのパスワード。なければ入力不要です。 |
   | 備考       | Prometheusデータソースに関する特記事項を追加します。 |

6. **<UI-TERM key="ocp-v2.page.Credential.Cluster.Verification">検証</UI-TERM>**をクリックし、データソースの接続性を検証します。

7. 検証に成功したら、**<UI-TERM key="ocp-v2.component.ParameterTemplate.AddDrawer.New">新規作成</UI-TERM>**をクリックします。

## 次のステップ

データソースの作成後、以下の手順でPrometheusを設定・有効化する必要があります。

1. Prometheusの設定ファイル`prometheus.yaml`に以下の設定情報を追加します（パスワード情報は一度だけ表示されます）。

   ```yaml
   scrape_configs:
   - job_name: 'ocp_sd'
      scheme: 'http'
      fallback_scrape_protocol: "PrometheusText1.0.0"  # このパラメータはPrometheus 3.x系でのみ設定が必要です。Prometheus 2.x系では不要です
      http_sd_configs:
         - url: 'http://xx.xx.xx.xx:8080/api/v2/monitor/prometheus_sd'
         basic_auth:   # OCPにアクセスしてprometheus_sd内のすべてのTargetを取得する
               username: "******"
               password: "******"
      basic_auth:   # すべてのTargetへのアクセスを制御する
         username: "******"
         password: "******"
   ```

2. Prometheusサービスを再起動し、設定が有効になることを確認します。

3. 現在のOCPプラットフォームでPrometheus設定を有効にします。

   デフォルトでは、監視データはPrometheusにのみ書き込まれます。監視データをMonitorDBにも同時に書き込む必要がある場合は、システムパラメータ`ocp.monitor.metric.collect.service.type`の値を`LOCAL`に変更してください。
