# Prometheusデータソースの管理

本記事では、Prometheusデータソースの管理方法について説明します。

## Prometheusデータソースの有効化/無効化

Prometheusデータソースは作成後、手動で有効化する必要があります。このセクションを参照して、Prometheusデータソースの有効化/無効化作業を実行してください。Prometheusデータソースを無効化すると、監視データはMonitorDBにのみ書き込まれます。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 役割であることを確認してください。
* Prometheusデータソースを有効化する前に、必ず [新しいPrometheusデータソースの作成](200.create-prometheus-data-source.md) を参照して、`prometheus.yaml` 設定ファイルの変更とPrometheusサービスの再起動を完了してください。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックします。

3. **Prometheus** タブをクリックします。

4. **Prometheusデータソース** ページで、操作列の **有効化/無効化** をクリックすると、Prometheusデータソースの有効化/無効化作業が実行されます。

## Prometheusデータソースの検証

このセクションを参照して、Prometheusデータソースが使用可能かどうかを検証できます。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 役割であることを確認してください。
* [新しいPrometheusデータソースの作成](200.create-prometheus-data-source.md) を行っています。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックします。

3. **Prometheus** タブをクリックします。

4. **Prometheusデータソース** ページで、操作列の **<UI-TERM key="ocp-v2.External.Component.CreateSlsDataSource.Validation">検証</UI-TERM>** をクリックします。

5. ポップアップダイアログで **<UI-TERM key="ocp-v2.page.Credential.Host.Verification">検証</UI-TERM>** をクリックします。

6. バブル内で検証結果を確認します。

## Prometheusデータソースの編集

このセクションでは、Prometheusデータソースの設定情報を更新または変更する方法について説明します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。
* [Prometheusデータソースの作成](200.create-prometheus-data-source.md)を行っていること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックします。

3. **Prometheus** タブをクリックします。

4. **Prometheusデータソース** ページで、操作列の **...** > **<UI-TERM key="ocp-v2.Auth.Role.Detail.Editing">編集</UI-TERM>** をクリックします。

5. ポップアップダイアログで、Prometheusデータソースの設定情報を変更します。

   設定情報の説明については、[Prometheusデータソースの作成](200.create-prometheus-data-source.md)を参照してください。

6. 検証が成功したら、**<UI-TERM key="ocp-v2.Compaction.Settings.EditCard.Save">保存する</UI-TERM>** をクリックします。

## Prometheusデータソースの削除

このセクションでは、Prometheusデータソースを削除する方法について説明します。削除後は、すべてのクラスタの監視履歴データを参照できなくなり、監視システムにも接続できなくなります。データソースは削除後に復元できないため、慎重に操作してください。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。
* [Prometheusデータソースの作成](200.create-prometheus-data-source.md)を行っており、そのPrometheusデータソースが **待機中** または **無効** の状態であること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.page.External.ExternalIntegration">外部統合</UI-TERM>** をクリックします。

3. **Prometheus** タブをクリックします。

4. **Prometheusデータソース** ページで、操作列の **...** > **<UI-TERM key="ocp-v2.AIModel.Component.AiModelDetailDrawer.Delete">削除</UI-TERM>** をクリックします。

5. ポップアップダイアログで **<UI-TERM key="ocp-v2.Backup.Service.Delete">削除</UI-TERM>** をクリックします。
