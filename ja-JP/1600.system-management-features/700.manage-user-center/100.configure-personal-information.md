# 個人情報の設定

**<UI-TERM key="ocp-v2.page.Settings.Profile.PersonalSettings">個人設定</UI-TERM>** ページで、基本情報を設定し、AccessKeyを作成できます。

## 前提条件

AccessKeyを作成する際は、現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

## 手順

### 基本情報の設定

1. OCPにログインします。

2. OCPシステム画面の右上隅にある、現在ログインしているユーザー名をクリックし、**<UI-TERM key="ocp-v2.Layout.Header.PersonalSettings">個人設定</UI-TERM>** を選択します。

   <!-- ![07021628](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E4%B8%AA%E4%BA%BA%E8%AE%BE%E7%BD%AE.png) -->

3. **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.BasicInformation">基本情報</UI-TERM>** モジュールで、右上の **<UI-TERM key="ocp-v2.Auth.User.Editing">編集</UI-TERM>** をクリックし、メールアドレス、携帯電話番号、組織、部門、自己紹介を設定します。

   <!-- ![07021625](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E7%BC%96%E8%BE%91%E5%9F%BA%E7%A1%80%E4%BF%A1%E6%81%AF.png) -->

4. 完了後、**<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.Submitted">送信</UI-TERM>** をクリックします。

### AccessKeyの作成

AK/SK認証モードを選択してシステムAPIを呼び出す場合は、事前にAccessKeyを作成する必要があります。詳細については[AK/SK署名生成ルール](../../1900.reference-guide/200.api-reference/300.ak-sk-sign-roles.md)を参照してください。

1. OCPにログインします。

2. OCPシステム画面の右上隅にある、現在ログインしているユーザー名をクリックし、**<UI-TERM key="ocp-v2.Layout.Header.PersonalSettings">個人設定</UI-TERM>** を選択します。

3. **AccessKey** モジュールで、右上の **ワンクリックでAccessKeyを作成** をクリックします。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E5%88%9B%E5%BB%BAak.png) -->

4. 表示された **AccessKeyの作成が成功しました** ダイアログで、作成された **AccessKey ID** と **AccessKey Secret** を確認できます。

   * **<UI-TERM key="ocp-v2.Auth.User.Copy">コピー</UI-TERM>** ボタンをクリックすると、今回作成したAccessKey情報をコピーできます。
   * **<UI-TERM key="ocp-v2.User.Component.AccessKeyCardTable.DownloadCsvFile">CSVファイルをダウンロード</UI-TERM>** をクリックすると、今回作成したAccessKey情報を.csvファイルとしてローカルにエクスポートできます。

      <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/ak%E5%88%9B%E5%BB%BA%E6%88%90%E5%8A%9F.png) -->

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><ul><li>最大で5つのAccessKeyを作成できます。</li><li>AccessKeyの作成から経過時間が長いほど、漏洩リスクが高くなります。リスクのあるものに代わって、新しいAccessKeyを作成することを推奨します。</li></ul></p>
    </main>

5. 使用しなくなったAccessKeyがある場合、操作列の **<UI-TERM key="ocp-v2.Alarm.Rule.Disable">禁止</UI-TERM>** をクリックして、そのAccessKeyの使用を停止できます。

   無効状態のAccessKeyに対しては、**<UI-TERM key="ocp-v2.Settings.Credential.Cluster.Delete">削除</UI-TERM>** および **<UI-TERM key="ocp-v2.component.CPUBindCoreConfigDrawer.Enable">有効にする</UI-TERM>** の操作を実行できます。

   <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/402-cn/%E7%A6%81%E7%94%A8ak.png) -->

      <main id="notice" type='alert'>
      <h4>注意</h4>
      <p>現在のAccessKeyが業務で使用されている場合、無効化すると業務が中断する可能性があります。慎重に操作してください。</p>
      </main>
