# ログアウト

このページでは、OCPからログアウトする操作について説明します。

## 手順

1. OCPの任意のページで、右上のアイコンをクリックし、**<UI-TERM key="ocp-v2.Layout.Header.ExitLogin">ログアウト</UI-TERM>** を選択します。

2. 表示された確認ダイアログで、**<UI-TERM key="ocp-v2.Statistics.components.ManualCollectDrawer.Ok">確定</UI-TERM>** をクリックします。
