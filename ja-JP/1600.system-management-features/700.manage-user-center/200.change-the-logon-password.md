# ログインパスワードの変更

OCPに初めてログインした後、またはパスワードが期限切れになる直前には、ログインできなくならないよう速やかにパスワードを変更する必要があります。

## 背景

アカウントのセキュリティを確保するため、定期的にパスワードを変更することを推奨します。

## 手順

1. OCPシステム画面の右上隅にある現在のログインユーザー名をクリックし、**<UI-TERM key="ocp-v2.Layout.Header.ChangePassword">パスワードの変更</UI-TERM>** を選択します。

2. 表示された **<UI-TERM key="ocp-v2.User.Oracle.UserList.ChangePassword">パスワードの変更</UI-TERM>** ダイアログボックスに、古いパスワード、新しいパスワード、パスワードの確認を入力します。

   パスワードを変更する際、パスワードは以下の要件を満たす必要があります：長さが8～32文字で、数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字の4種類のうち、少なくとも3種類を含む必要があります。サポートされている特殊文字は <code>~!@#%^&*_-+=|(){}[]:;,.?/$`'"<>\\</code> です。

3. **<UI-TERM key="ocp-v2.Component.ZoneList.EditZoneModal.Ok">確定</UI-TERM>** をクリックします。

## その他の操作

OCPでは、パスワードの有効期限までのリマインド時間、パスワードの再利用回数の設定、パスワードの有効期間、失敗したログイン試行回数、パスワードの再利用回数などのパラメータを設定できます。

* ウェブページログインオプション：`ocp.iam.auth`、デフォルトは `composite` です。現在、`local`（ローカルMetaDB内のOCPアカウント）、`oauth2`（OAuth2プロトコル）、`cas`（CASプロトコル）、`composite`（組み合わせモード）、`buc`（Alibabaグループ従業員アカウント）、`ApsaraStack`（Alibaba Cloud専用クラウド）をサポートしています。
* パスワード有効期限までのリマインド時間：`ocp.iam.password.remind.before-expiration.days`、デフォルトは10日です。10日に設定すると、システムはパスワードが期限切れになる10日前にパスワードの変更を促します。
* パスワードの再利用回数の設定：`ocp.iam.password.reuse.times`、デフォルトは0回で、無制限を意味します。最大で6回に設定できます。5回に設定すると、パスワードを5回変更した後に既に使用したパスワードを使用できます。
* パスワードの有効期間：`ocp.iam.password.validity.period.days`、デフォルトは0で、0は永遠に期限が切れないことを意味します。90日に設定すると、90日を超えるとパスワードの再設定が必要になります。
* 失敗したログイン試行回数：`ocp.iam.login.max-attempts`、デフォルトは5回です。5回に設定すると、ログイン時にユーザー名またはパスワードを連続して5回間違えることが許容されます。5回を超えると、ユーザーのログインが一時的にブロックされます。
* ログイン失敗によるロックアウト時間：`ocp.iam.login.lockout-minutes`、デフォルトは15分です。20分に設定すると、ログイン失敗の制限回数を超えると、20分間ユーザーのログインが一時的にブロックされます。
* ログインセッションのタイムアウト時間：`server.servlet.session.timeout`、デフォルトは30m、最小は60sです。接尾辞単位を指定しない場合、デフォルトは秒です。30mに設定すると、ログイン後30分間操作がない場合、再ログインが必要になります。
* CSRF（Cross-Site Request Forgery）のクロスサイトリクエスト偽造セキュリティ保護を有効にするかどうか：`ocp.iam.csrf.enabled`、デフォルトは `true` です。通常、Webページによるログイン方式では、このパラメータを有効にすることを推奨します。
* 同一クライアントが連続してログインインターフェースにアクセスする回数：`ocp.iam.login.client.max-attempts`、デフォルトは10回です。15回に設定すると、同一クライアントによるログインインターフェースへの連続アクセスが15回を超えると、クライアントのログインリクエストが一時的にブロックされます。
* クライアントのログインブロック時間：`ocp.iam.login.client.lockout-minutes`、デフォルトは10分です。15分に設定すると、同一クライアントのログインリクエストが制限を超えると、15分間クライアントのログインリクエストが一時的にブロックされます。

詳細な操作手順については、[システムパラメータの変更](../500.manage-system-parameter/200.modify-system-parameters.md)を参照してください。
