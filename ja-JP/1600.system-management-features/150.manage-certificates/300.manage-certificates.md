# 証明書の削除

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版ではこの機能は提供されません。</p>
</main>

このページでは、アップロード済みの証明書を削除する方法について説明します。証明書を削除すると、対応するファイルがその証明書から削除されます。有効期限が切れていないファイルは、新しい証明書に再アップロードできます。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

* 証明書に利用対象が存在する場合、削除は現在サポートされていません。削除が必要な場合は、該当するクラスタのSSL暗号化を無効にしてください。詳細については、[OceanBaseクラスタのSSL暗号化管理](../../600.cluster-functions/1200.manage-security-configuration/100.manage-ssl-link-encryption-of-an-ob-cluster.md)および[OBProxyクラスタのSSL暗号化管理](../../800.obproxy-functions/550.manage-ssl-link-encryption-of-an-obproxy-cluster.md)を参照してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.hook.useMenu.SafetyManagement">安全管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.hook.useMenu.CertificateManagement">証明書管理</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.src.hook.useMenu.CertificateManagement">証明書管理</UI-TERM>** ページに移動します。

3. 削除する証明書を選択し、操作バーの **<UI-TERM key="ocp-v2.component.UploadPackageDrawer.Delete">削除</UI-TERM>** をクリックします。

4. ダイアログボックスで **<UI-TERM key="ocp-v2.component.DatabasePrivilegeTransfer.PrivilegesCheckbox.Delete">削除</UI-TERM>** をクリックします。
