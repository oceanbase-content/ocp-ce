# 証明書のアップロード

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise Editionにのみ適用されます。OCP Community Editionではこの機能は提供されません。</p>
</main>

ユーザーが証明書を管理しやすくするため、OCPは証明書ファイルの保存と管理を行うための証明書管理機能を提供します。ユーザーはOCPにCA証明書、サーバー証明書、およびサーバー証明書の秘密鍵という3つのファイルからなる証明書ファイルをアップロードします。これら3つのファイルは一つの証明書ファイルグループであり、すべてのファイルには`pem`が拡張子として付けられている必要があります。

## 前提条件

* 現在OCPにログインしているユーザーが**ADMIN**ロールまたは**ORG_ADMIN**ロールであることを確認してください。

* 同一クラスタ内のSSLリンク暗号化を有効にしている場合は、クラスタ内のOceanBaseとOBProxyのルート証明書`ca.pem`が一致していることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで**<UI-TERM key="ocp-v2.src.hook.useMenu.SafetyManagement">安全管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.hook.useMenu.CertificateManagement">証明書管理</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.src.hook.useMenu.CertificateManagement">証明書管理</UI-TERM>** ページに移動します。

3. 右上の**<UI-TERM key="ocp-v2.pages.Certificate.UploadCertificate">証明書をアップロード</UI-TERM>** をクリックします。

4. ダイアログボックスに以下の情報を入力または選択します。

    | 情報     | 説明   |
    |----------|--------|
    | 証明書名 | 証明書名は一意である必要があります。<ul><li>英字で始まり、英字または数字で終わる必要があります。</li><li>2文字以上32文字以下をサポートします。</li><li>特殊文字はアンダースコアのみサポートします。</li></ul>  |
    | 証明書のアップロード | 一度に最大3つのpemファイルのアップロードをサポートします。アップロードする証明書ファイルが有効であり、OBProxyおよびOceanBaseデータベースの使用規範に準拠していることを確認してください。また、CA証明書、サーバー証明書、およびサーバー証明書の秘密鍵を含む必要があります。そうでない場合、SSLリンク暗号化が失敗する可能性があります。  |
    | 備考     | アップロードする証明書に追加の説明を追加します。 |

5. **<UI-TERM key="ocp-v2.component.PreCheck.CheckResult.Upload">アップロード</UI-TERM>** をクリックします。
