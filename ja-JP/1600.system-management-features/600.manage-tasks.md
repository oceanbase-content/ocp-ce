# タスクの管理

OCPインターフェースを通じて開始されたOceanBaseクラスタ、テナント、およびホストの運用保守・管理タスクやOCPシステムの管理タスクについて、OCPはその管理と表示を提供します。

このセクションでは、タスクの詳細を表示する方法と、失敗したタスクを処理する方法について説明します。

## 前提条件

* タスクの詳細を確認し、現在の進捗状況を特定し、ログをダウンロードするには、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
  * タスクセンターの **<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.All">すべて</UI-TERM>** メニュー権限。

* タスクをスキップし、失敗したタスクを再試行し、失敗したタスクをロールバックするには、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * タスクセンターの **<UI-TERM key="ocp-v2.component.common.BinlogClusterSelect.All">すべて</UI-TERM>** メニュー権限。

## タスクの詳細を確認する

OCPに **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.Running">実行中</UI-TERM>** または **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">実行に失敗しました</UI-TERM>** のタスクが存在する場合、OCPシステムページの右上にある **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** に、具体的なタスク数が表示されます。タスクの詳細を確認するには、以下の2つの方法があります：

* 方法1：**<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** 上にカーソルを合わせ、バブル内のタスク番号をクリックします。**<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** ページは、選択したタスクの状態を条件にフィルタリングされ、同じ状態のタスクのみが表示されます。

* 方法2：**<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** をクリックします。**<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** ページは、デフォルトですべての状態のタスクを表示します。

以下の手順では、**方法2** を例に説明します：

1. OCPにログインします。

2. ページ上部の **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** ページに移動します。

3. **<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** ページでは、タスクの実行状態や発行者でタスクをフィルタリングしたり、操作対象やタスク名でタスクを検索したりできます。

   **<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** には、すべての条件に合致するタスクが返されます。その中で、**<UI-TERM key="ocp-v2.Detail.Component.BatchModifyUnitModal.OperationObject">操作対象</UI-TERM>** 内のリンクをクリックすると、**<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Object">対象</UI-TERM>** の概要ページに移動できます。

   ![07021600](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%BB%BB%E5%8A%A1%E5%88%97%E8%A1%A8.png)

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p>タスクの操作対象が削除されている場合は、オブジェクト名とオブジェクトタイプのみを確認でき、<b>オブジェクト</b> の概要ページには移動できません。</p>
   </main>

4. 詳細を確認するタスク名をクリックし、そのタスクの詳細ページに移動します。タスク詳細ページは、デフォルトでログビューで表示されます。ビューボタンをクリックすると、流れビューに切り替えられます。

   * ログビューでは、複数のタスクログを表示できます。図の左側のエリアでサブタスクを切り替えると、右側のエリアにサブタスクの実行情報とすべてのログが表示されます。以下の図の①または②の対応するボタンをクリックすると、サブタスクに対して対応する操作を実行できます。

      ![07021544](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%A4%B1%E8%B4%A5%E4%BB%BB%E5%8A%A1%E6%97%A5%E5%BF%97%E8%A7%86%E5%9B%BE.png)

   * 流れビューでは、ページはトポロジーマップを使用して各サブタスクの上流および下流関係を示します。折りたたみメニューを展開すると、画面の下部にログ情報を表示する折りたたみウィンドウが表示されます。ウィンドウはドラッグして拡大できます。指定したサブタスクの右側にある **...** 内の操作項目をクリックすると、現在のサブタスクを操作できます。

      <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>マウスを空白部分にドラッグするとトポロジーマップを移動できます。マウスホイールをスクロールするとトポロジーマップを拡大および縮小できます。右上のズームコントロールを使用してキャンバスのサイズを調整することもできます。トポロジーマップのズームはマウスポインタを中心に行われます。タスクのプロセスが長い場合は、まず縮小して関心のあるステップに素早く移動し、その後拡大して迅速に位置づけることができます。</p>
      </main>

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E4%BB%BB%E5%8A%A1%E6%B5%81%E8%BD%AC%E8%A7%86%E5%9B%BE.png)

   サブタスクの状態によってサポートされる操作は異なります。詳細は **...** に表示されている内容をご確認ください。

    * **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.SuccessfulExecution">実行に成功しました</UI-TERM>** のサブタスクは、詳細ログを確認できます。

    * **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">実行に失敗しました</UI-TERM>** のサブタスクでは、以下の操作を実行できます：

       * ログ情報をダウンロードします。

       * 再試行：現在のサブタスクを再実行します。まずロールバックしてから実行し、成功した場合は下流のサブタスクを続行します。

       * スキップ：現在のサブタスクの状態を直接成功状態に設定し、下流のサブタスクを続行します。サブタスクをスキップすると、後続の処理に異常が発生する可能性があるため、慎重に操作してください。

       * AI解析を見る：解析アイコンをクリックすると、AIアシスタントを通じてこのエラーに関するインテリジェントな解釈を取得できます。AIアシスタントについては、[AIアシスタント](../1075.ai-management/100.ai-overview.md)を参照してください。

    * **<UI-TERM key="ocp-v2.Layout.BasicLayout.Running">実行中</UI-TERM>** のサブタスクでは、ログをダウンロードするか、実行を終了できます。実行を終了すると、サブタスクの状態は **<UI-TERM key="ocp-v2.src.constant.task.Terminated">終了済み</UI-TERM>** に変わり、メインタスクの状態も **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">実行に失敗しました</UI-TERM>** に変わります。実行を終了したサブタスクに対しては、ログのダウンロード、スキップ、再試行、AI解析の表示操作を実行できます。

    * **<UI-TERM key="ocp-v2.src.constant.alarm.Warning">警告</UI-TERM>** 状態のサブタスクでは、以下の操作を実行できます：

      * ログ情報をダウンロードします。

      * 再試行：現在のノードタスクを再実行します。つまり、まずロールバックしてから現在のサブタスクを実行します。

    * **<UI-TERM key="ocp-v2.src.constant.backup.Paused">一時停止中</UI-TERM>** 状態のサブタスクでは、以下の操作を実行できます：

      * ログ情報をダウンロードします。

      * 続行：現在のサブタスクを続行します。

## 再試行失敗タスク

タスクが **ロールバック失敗** または **<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">実行に失敗しました</UI-TERM>** の場合、タスクの再試行操作をサポートしています。再試行失敗タスクでは、現在のステップで失敗したすべてのノードをロールバックして再度実行し、実行に成功した場合は次のステップを続行します。

タスクの再試行には、以下の2つの方法があります：

* 方法1：**<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** ページで、失敗したタスクを選択して再試行します。
* 方法2：タスクの詳細ページで、右上の **<UI-TERM key="ocp-v2.Detail.Log.TaskGraph.ReRun">再試行</UI-TERM>** ボタンをクリックして、タスクを再試行します。

以下の操作手順は **方法1** を例に説明します：

1. OCPにログインします。

2. ページ上部の **<UI-TERM key="ocp-v2.src.hook.useMenuOptions.TaskCenter">タスクセンター</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** ページに移動します。

3. 再試行が必要な失敗したタスクを選択し、操作列の①にある **<UI-TERM key="ocp-v2.page.Task.Retry">再試行</UI-TERM>** ボタンをクリックします。

   複数の失敗したタスクを選択し、②をクリックすると、一括で再試行できます。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%89%B9%E9%87%8F%E9%87%8D%E8%AF%95%E4%BB%BB%E5%8A%A1.png)

## タスクのロールバック失敗

ロールバック操作は、失敗したサブタスクから開始し、実行済みのすべてのサブタスクを段階的にロールバックします。主にタスクのリソース回収や状態変更などの目的で使用されます。

1. OCPにログインします。

2. ページ上部の **<UI-TERM key="ocp-v2.Layout.BasicLayout.TaskCenter">タスクセンター</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.page.Task.TaskList">タスクリスト</UI-TERM>** ページに移動します。

3. 詳細を確認するタスク名をクリックし、そのタスクの詳細ページに移動します。

4. タスク詳細ページの右上隅にある **<UI-TERM key="ocp-v2.src.constant.task.Rollback">ロールバック</UI-TERM>** をクリックします。

   ![05101010](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/421/%E5%9B%9E%E6%BB%9A%E4%BB%BB%E5%8A%A1.png)

## 現在の進捗状況を確認する

タスクの実行中に、**<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">現在の進捗状況を確認する</UI-TERM>** をクリックすると、実行中のサブタスクにすばやく移動し、タスクの実行状態や関連ログ情報を容易に確認できます。また、**<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ExecutionFailed">実行に失敗しました</UI-TERM>** と表示されているタスクについては、**<UI-TERM key="ocp-v2.Task.Detail.LocateTheCurrentProgress">現在の進捗状況を確認する</UI-TERM>** をクリックすると、実行失敗したサブタスクおよびタスクの実行異常情報をすばやく特定できます。

## ログをダウンロードする

タスクの詳細ページに移動し、右上の **<UI-TERM key="ocp-v2.src.constant.obproxy.DownloadLogs">ログをダウンロードする</UI-TERM>** ボタンをクリックすると、そのタスクのすべてのサブタスクの実行ログをローカルにダウンロードできます。
