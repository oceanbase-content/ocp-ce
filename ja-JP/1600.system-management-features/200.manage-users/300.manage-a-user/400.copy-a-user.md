# ユーザーのコピー

既存のユーザーAとほぼ同じ設定を持つユーザーBを作成する場合、ユーザーのコピー機能を使用して新しいユーザーを迅速に作成できます。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 機構または **ORG_ADMIN** 機構であることを確認してください。
* adminユーザーのコピーは **ADMIN** 機構のみがサポートしています。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Auth.User.New.User">ユーザー</UI-TERM>** タブで、ユーザーリストの **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Operation">操作</UI-TERM>** 列の **その他 > コピー** をクリックします。

   [ユーザーの作成](100.create-a-user.md) のパラメータ説明を参考に、一部のユーザー情報を再定義します。

   特に、**<UI-TERM key="ocp-v2.Backup.Component.BackupNowTenantDrawer.BasicInformation">基本情報</UI-TERM>** の **<UI-TERM key="ocp-v2.Auth.User.loginHistory.getUserName">ユーザー名</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.Password">パスワード</UI-TERM>**、および **<UI-TERM key="ocp-v2.Auth.User.New.Mailbox">メールアドレス</UI-TERM>** は必ず再定義する必要があります。

4. **<UI-TERM key="ocp-v2.Detail.Component.AddUserDrawer.Submitted">送信</UI-TERM>** をクリックします。

   システムは、Aユーザーと同じロールやアクセス制御を持つBユーザーを新規作成します。
