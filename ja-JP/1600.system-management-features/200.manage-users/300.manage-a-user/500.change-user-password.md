# ユーザーパスワードの変更

この記事では、ユーザーパスワードの変更方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 役割または **ORG_ADMIN** 役割であることを確認してください。
* adminユーザーのパスワード変更は、**ADMIN** 役割のみがサポートしています。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Detail.Session.Statistics.User">ユーザー</UI-TERM>** タブで、ユーザーリストの **<UI-TERM key="ocp-v2.component.FormEditTable.Operation">操作</UI-TERM>** 列の **その他 > パスワードの変更** をクリックします。

   システムはユーザーパスワード変更ダイアログを表示します。

4. ダイアログに新しいパスワードを入力します。

   パスワードの複雑さ要件は以下の通りです：長さが8～32文字で、数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字の4種類のうち、少なくとも3種類を含む必要があります。サポートされている特殊文字は <code>~!@#%^&*_-+=|(){}[]:;,.?/$`'"<>\\</code> です。

5. **<UI-TERM key="ocp-v2.Detail.Component.Event.Determine">確定</UI-TERM>** をクリックします。
