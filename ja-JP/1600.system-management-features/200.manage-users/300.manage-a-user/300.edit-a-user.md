# ユーザーの編集

このセクションでは、ユーザー情報を変更する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 機構または **ORG_ADMIN** 機構であることを確認してください。
* adminユーザー情報の変更は、**ADMIN** 機構のみがサポートしています。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Oracle.Component.AddOracleUserOrRoleDrawer.User">ユーザー</UI-TERM>** タブで、ユーザーリストの **<UI-TERM key="ocp-v2.Component.ServiceName.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.src.constant.credential.Edit">編集</UI-TERM>** をクリックします。

   [ユーザーの作成](100.create-a-user.md) のパラメータ説明を参照して、ユーザー情報を再編集します。

   <main id="notice" type='explain'>
   <h4>説明</h4>
   <p><b>ユーザー名</b> の変更はサポートされていません。</p>
   </main>

4. **<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.Submit">送信</UI-TERM>** をクリックします。
