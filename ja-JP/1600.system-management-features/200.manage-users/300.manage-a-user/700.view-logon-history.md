# ログイン履歴の表示

このセクションでは、指定した期間内のユーザーのログイン情報、クライアント情報、ログイン結果、および自動ロックがトリガーされたかどうかを確認する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロール、**ADMIN_VIEWER** ロール、または **ORG_ADMIN** ロールであることを確認してください。

## 手順

1. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックし、**<UI-TERM key="ocp-v2.Detail.Session.List.User">ユーザー</UI-TERM>** タブに移動します。**<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.User">ユーザー</UI-TERM>** タブの右上隅で **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonHistory">ログイン履歴</UI-TERM>** を選択します。

2. **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.Username">ユーザー名</UI-TERM>** のドロップダウンリストから、表示したいユーザーを選択します。

3. **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonTime">ログイン時間</UI-TERM>** で期間を選択します。

4. **<UI-TERM key="ocp-v2.page.QueryLog.Query">クエリ</UI-TERM>** をクリックすると、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">登録リスト</UI-TERM>** に検索条件に一致するすべてのユーザーが返されます。

   * **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">登録リスト</UI-TERM>** で、**<UI-TERM key="ocp-v2.Component.LBLoadBalanceConditon.Username">ユーザー名</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.IpSource">IPソース</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.Client">クライアント</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonTime">ログイン時間</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonResult">ログイン結果</UI-TERM>**、および **<UI-TERM key="ocp-v2.Auth.User.loginHistory.AutomaticallyLockAccounts">自動アカウントロック</UI-TERM>** の状況を確認できます。

      <!-- ![05101553](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/12091440.png) -->

   * **<UI-TERM key="ocp-v2.Auth.User.loginHistory.LogonList">登録リスト</UI-TERM>** のユーザー名をクリックすると、システムはユーザー詳細ページにジャンプします。ユーザー詳細ページについては、[ユーザーの表示](200.view-the-user-details-page.md)も参照してください。
