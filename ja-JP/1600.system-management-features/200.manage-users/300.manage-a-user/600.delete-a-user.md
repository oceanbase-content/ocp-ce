# ユーザーの削除

このセクションでは、ユーザーを削除する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

* adminユーザーの削除はサポートされていません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.User">ユーザー</UI-TERM>** タブで、ユーザーリストの **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.Operation">操作</UI-TERM>** 列の **その他 > 削除** をクリックします。

   システムは「ユーザーxxを削除しますか？」と表示します。

4. **<UI-TERM key="ocp-v2.src.constant.oceanbase.Delete">削除</UI-TERM>** をクリックします。

  <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>ユーザーは削除後に復元できません。慎重に操作してください。</p>
  </main>
