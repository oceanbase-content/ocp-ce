# ユーザーの表示

このセクションを参照することで、ユーザーの詳細情報を確認できます。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロール、**ADMIN_VIEWER** ロール、または **ORG_ADMIN** ロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.src.constant.auditEvent.User">ユーザー</UI-TERM>** タブで、ユーザーリストを確認します。

   * ログインユーザーがシステム管理者(ADMIN)ロールの場合、リストにはシステム全体のすべてのユーザーの全情報が表示されます。
   * ログインユーザーが組織管理者(ORG_ADMIN)ロールの場合、リストには所属組織内のすべてのユーザーの組織情報を除くすべての情報が表示されます。

4. ユーザーリストのユーザー名をクリックします。

   システムは **<UI-TERM key="ocp-v2.Auth.User.Detail.UserDetails">ユーザー詳細</UI-TERM>** ページをポップアップ表示し、このページではユーザーの基本情報と保有権限情報を確認できます。

   また、この画面の右上隅で [パスワードの変更](500.change-user-password.md)、[ユーザーのコピー](400.copy-a-user.md)、[ユーザーの編集](300.edit-a-user.md)、[ユーザーの削除](600.delete-a-user.md)、[AccessKeyの作成](../../700.manage-user-center/100.configure-personal-information.md) 操作を実行できます。
