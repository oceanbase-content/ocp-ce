# ロールの作成

この記事では、OCPで新しいロールを作成する方法について説明します。

## 背景

OCPのプリセットされたデフォルトロールが実際のニーズを満たせない場合、ADMINロールまたはORG_ADMINロールで新しいカスタムロールを作成し、より細かい管理権限を付与することができます。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Auth.Role.New.Role">ロール</UI-TERM>** タブの右上隅にある **<UI-TERM key="ocp-v2.User.Oracle.CreateARole">新しいロールを作成</UI-TERM>** をクリックします。

   システムは新規ロールページに移動します。

4. **<UI-TERM key="ocp-v2.Oracle.Component.RoleSelect.CreateARole">新しいロールを作成</UI-TERM>** ページで、ロールの以下の情報を設定します。

   1. **<UI-TERM key="ocp-v2.Auth.User.New.BasicInformation">基本情報</UI-TERM>** に、**<UI-TERM key="ocp-v2.Auth.User.Detail.RoleName">ロール名</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.Detail.Tissue">組織</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddArbitrationDrawer.Description">備考</UI-TERM>** を入力します。

      ロール名には、数字（0～9）、大文字（A～Z）、小文字（a～z）、アンダースコア（_）、ハイフン（-）を含めることができ、長さは2～48文字です。

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/12091547.png)

   2. **<UI-TERM key="ocp-v2.Auth.Role.AddRole.ResourcePermissions">リソース権限</UI-TERM>** で、そのロールのリソース操作権限を設定します。

      | パラメータ  |  説明  |
      |-------|--------|
      | 操作タイプ | クラスタ、テナント、OBProxyクラスタ、アービトレーションサービス、Binlogサービス、ホストの **管理**、**メンテナンス**、または **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.ReadOnly">読み取り専用</UI-TERM>** 権限を含みます。<ul><li>管理：削除を含むすべての運用保守権限を持ちます。</li><li>メンテナンス：削除を除くすべての運用保守権限を持ちます。</li><li>読み取り専用：読み取り専用権限のみを持ちます。</li></ul>      |
      | 対象  | 単一の対象またはすべての対象を選択できます。  |

      **+ リソース権限を追加** ボタンを使用して、ロールに複数のリソース権限を追加できます。

      <main id="notice" type='explain'>
      <h4>説明</h4>
      <p>クラスタの全権限を持っている場合、デフォルトでそのクラスタ内のテナントおよびホストの全権限を持ちます。</p>
      </main>

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/12091551.png)

   3. **<UI-TERM key="ocp-v2.Auth.Role.MenuPermissions">メニュー権限</UI-TERM>** で、そのロールの機能メニューの表示権限を設定します。

      | パラメータ  |  説明  |
      |-------|--------|
      | メニュータイプ | OCPのすべての一次ナビゲーションバーを含み、概要、クラスタ、テナント、OBProxy、Binlogサービス、ホスト、アラートセンター、監視ダッシュボード、パフォーマンス監視、診断サービス、運用管理、バックアップ・リカバリ、ログ検索、セキュリティ管理、システム管理、タスクセンターに分類されます。    |
      | メニュー  | 単一の二次ナビゲーションバーまたはすべての二次ナビゲーションバーを選択できます。  |

      **+ メニュー権限の追加** ボタンを使用すると、ロールに複数のメニュー権限を追加できます。

      <main id="notice" type='explain'>
      <h4>説明</h4>
      <p><ul><li>具体的なリソース権限を選択すると、そのリソース権限に必要なメニュー権限が自動的に表示されます。実際の状況に応じて、メニュー権限を追加、変更、削除できます。</li><li>いずれのメニュー権限も選択しない場合、デフォルトでそのロールは <b>概要</b> を除くすべてのメニューにアクセスできます。</li></ul></p>
      </main>

      ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/434/12091640.png)

5. ページの右下隅にある **<UI-TERM key="ocp-v2.Tenant.New.Submitted">送信</UI-TERM>** をクリックします。
