# OCPデフォルトロール

このセクションでは、OCPのデフォルトロールとその権限について説明します。OCPのデフォルトロールはOCPに組み込まれたロールであり、削除または編集することはできません。

組織によって、存在するデフォルトロールは異なります。

## デフォルト組織

OCPのデフォルト組織である**default**のすべてのデフォルトロールは、次の表のとおりです：

|     ロール             |    説明         |    リソース権限   |
|----------------------|-----------------|--------|
| ADMIN                | OCPシステム管理者ロールで、最大限の権限を持ちます。     | 全部    |
| ADMIN_VIEWER         | OCPシステム読み取り専用ロールで、OCPが管理するすべてのOceanBaseテナントの管理権限と、関連リソース（OceanBaseクラスタ、OBProxyクラスタ、ホスト、バックグラウンドタスク、アラート）の読み取り専用権限を持ちます。   | <li>クラスタ読み取り専用</li><li>テナント読み取り専用</li><li>OBProxy読み取り専用</li><li>アービトレーションサービス読み取り専用</li><li>Binlogサービス読み取り専用</li><li>ホスト読み取り専用 </li>   |
| ARBITRATION_MANAGER  | アービトレーションサービス管理者ロール。OCPが管理するすべてのアービトレーションサービスの管理権限と、関連リソース（クラスタ、テナント、ホスト）の読み取り専用権限、ソフトウェアパッケージの管理権限を持ちます。   | アービトレーションサービス管理   |
| ARBITRATION_VIEWER   | アービトレーションサービス読み取り専用ロール。OCPが管理するすべてのアービトレーションサービスおよび関連リソース（クラスタ、テナント、ホスト、ソフトウェアパッケージ）の読み取り専用権限を持ちます。   | アービトレーションサービス読み取り専用     |
| CLUSTER_MANAGER      | クラスタ管理者ロール。OCPが管理するすべてのOceanBaseクラスタ、OBProxyクラスタおよび関連リソース（ホスト、バックグラウンドタスク、アラート、ソフトウェアパッケージ、点検）の管理権限を持ち、間接的に関連するリソース（ユーザー、アービトレーションサービス）に対する読み取り専用権限を持ちます。         | クラスタ管理     |
| CLUSTER_VIEWER       | クラスタ読み取り専用ロール。OCPが管理するすべてのOceanBaseクラスタ、OBProxyクラスタおよび関連リソース（ホスト、バックグラウンドタスク、アラート、ソフトウェアパッケージ）の読み取り専用権限を持ちます。     | クラスタ読み取り専用      |
| HOST_MANAGER         | OCPホスト読み取り専用ロール。すべてのホストおよび関連リソース（ソフトウェアパッケージ）の読み取り専用権限を持ちます。デフォルトロールで、編集または削除できません。       | ホスト管理     |
| HOST_VIEWER          | OCPホスト読み取り専用ロール。すべてのホストおよび関連リソース（ソフトウェアパッケージ）の読み取り専用権限を持ちます。     | ホスト読み取り専用       |
| OBPROXY_MANAGER      | OBProxy管理者ロール。OCPが管理するすべてのOBProxyクラスタの管理権限と、関連リソース（クラスタ、ホスト）の読み取り専用権限、ソフトウェアパッケージの管理権限を持ちます。         | OBProxy管理     |
| OBPROXY_VIEWER       | OBProxy読み取り専用ロール。OCPが管理するすべてのOBProxyクラスタおよび関連リソース（クラスタ、ホスト、ソフトウェアパッケージ）の読み取り専用権限を持ちます。デフォルトロールで、編集または削除できません。          | OBProxy読み取り専用       |
| TENANT_MANAGER       | テナント管理者ロール。OCPが管理するすべてのOceanBaseテナントおよび点検の管理権限、および関連リソース（OceanBaseクラスタ、OBProxyクラスタ、ホスト、バックグラウンドタスク、アラート、アービトレーションサービス）の読み取り専用権限を持ちます。デフォルトロールで、編集または削除できません。           | テナント管理  |
| TENANT_VIEWER        | テナント読み取り専用ロール。OCPが管理するすべてのOceanBaseテナントおよび関連リソース（OceanBaseクラスタ、OBProxyクラスタ、ホスト、バックグラウンドタスク、アラート、アービトレーションサービス、点検）の読み取り専用権限を持ちます。デフォルトロールで、編集または削除できません。      | テナント読み取り専用    |

## カスタム組織

OCPカスタム組織のすべてのデフォルトロールは、次の表のとおりです：

|     ロール             |    説明         |    リソース権限   |
|----------------------|-----------------|--------|
| ORG_ADMIN  | 組織管理者ロール。同一組織内のリソースに対して全権限を持ちます。   |  全部  |
