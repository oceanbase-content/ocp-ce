# ロールの編集

このセクションでは、ロールを編集する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

* システムのデフォルトロールは編集できません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Scan.ReportTable.ZoneInfoTable.Role">ロール</UI-TERM>** タブの検索ボックスにロール名のキーワードを入力し、検索ボタンをクリックします。

   ロールリストに条件に合致するロールが表示されます。

4. 編集対象のロールの **<UI-TERM key="ocp-v2.page.Tags.TagList.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Backup.BackupStrategy.Detail.Edit">編集</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.Auth.Role.New.EditRoles">ロールを編集する</UI-TERM>** ページに移動し、[新規ロールの作成](100.create-a-role.md) の手順4を参照して、このロールの権限を再編集できます。

5. **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.Submitted">送信</UI-TERM>** をクリックします。
