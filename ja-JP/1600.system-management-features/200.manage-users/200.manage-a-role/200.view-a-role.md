# ロールの表示

この記事では、ロールの表示方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Auth.Role.New.Role">ロール</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.MultiCluster.RegisterOcp.Role">ロール</UI-TERM>** タブに移動します。

   このタブのロールリストには、デフォルトですべてのロールが表示されます。ロールが多すぎる場合は、ページネーションで表示されます。リスト下部のページネーション機能を使用してページを切り替えたり、1ページあたりのロール数を調整したりできます。

4. 検索バーにロール名のキーワードを入力し、検索ボタンをクリックします。

   ロールリストに、条件に一致するロールが表示されます。

5. ロールリスト内の特定のロール名をクリックします。

   そのロールの **<UI-TERM key="ocp-v2.Auth.Role.Detail.RoleDetails">ロールの詳細</UI-TERM>** ページに移動します。このページでは、ロールの詳細情報を確認できます。
