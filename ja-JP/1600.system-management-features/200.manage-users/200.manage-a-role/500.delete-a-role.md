# ロールの削除

この記事では、ロールを削除する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

* システムのデフォルトロールは削除できません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Scan.ReportTable.ZoneInfoTable.Role">ロール</UI-TERM>** タブの検索ボックスにロール名のキーワードを入力し、検索ボタンをクリックします。

   ロールリストに条件に合致するロールが表示されます。

4. 編集対象のロールの **<UI-TERM key="ocp-v2.Backup.Service.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.src.constant.backup.Delete">削除</UI-TERM>** ボタンをクリックします。

   システムは `xxx ロールを削除しますか？` というメッセージを表示します。

5. **<UI-TERM key="ocp-v2.src.constant.obproxy.Delete">削除</UI-TERM>** をクリックします。
