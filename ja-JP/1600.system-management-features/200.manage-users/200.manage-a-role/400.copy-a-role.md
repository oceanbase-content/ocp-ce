# ロールのコピー

作成するロールの権限が既存のロールとほぼ同じ場合は、このセクションを参照して既存のロールをコピーし、新しいロールを迅速に作成できます。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールであることを確認してください。

* システムのデフォルトロールはコピーできません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Oracle.UserOrRoleDetail.Role">ロール</UI-TERM>** タブの検索バーにロール名のキーワードを入力し、**<UI-TERM key="ocp-v2.src.util.component.Search">検索</UI-TERM>** をクリックします。

   ロールリストに条件に一致するロールが表示されます。

4. 編集するロールを選択し、**<UI-TERM key="ocp-v2.Service.Component.HostTable.Operation">操作</UI-TERM>** 列の **その他 > コピー** をクリックします。

   システムは **<UI-TERM key="ocp-v2.Auth.Role.New.CopyRoles">ロールのコピー</UI-TERM>** ページに移動します。

5. **<UI-TERM key="ocp-v2.Auth.Role.New.CopyRoles">ロールのコピー</UI-TERM>** ページで、**<UI-TERM key="ocp-v2.Auth.Role.New.RoleName">ロール名</UI-TERM>**、**ロール説明**、および **ロール権限** を変更します。

   ロール権限の変更については、[新規ロールの作成](100.create-a-role.md)の手順4の説明を参照してください。

6. **<UI-TERM key="ocp-v2.Detail.Component.AddDatabaseModal.Submitted">送信</UI-TERM>** をクリックします。
