# リソースの表示

このセクションでは、組織のリソースを表示する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Settings.Profile.Organization">組織</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.page.Settings.Profile.Tissue">組織</UI-TERM>** タブに移動します。

   このタブの組織リストは、デフォルトですべての組織を表示します。組織が多すぎる場合は、ページネーション表示されます。リスト下部のページネーション機能でページを切り替えたり、1ページあたりのロール数を調整したりできます。

4. 検索バーに組織名のキーワードを入力し、検索ボタンをクリックします。

   組織リストに条件に一致する組織が表示されます。

5. 表示する組織を選択し、操作リストの **<UI-TERM key="ocp-v2.Auth.Org.ViewResources">リソースを確認する</UI-TERM>** をクリックします。

   右側にポップアップ表示されたパネルで、その組織のすべてのリソース情報を確認できます。これには、**<UI-TERM key="ocp-v2.Auth.Org.SharedResourceDrawer.Resources">リソース</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.Role.Detail.ResourceType">リソースタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.Organization">所属組織</UI-TERM>**、**<UI-TERM key="ocp-v2.Detail.Database CREATED">作成日時</UI-TERM>**、および **<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.Creator">作成者</UI-TERM>** が含まれます。
