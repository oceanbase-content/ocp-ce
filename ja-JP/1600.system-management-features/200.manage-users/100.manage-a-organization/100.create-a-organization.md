# 組織の作成

この記事では、OCPで組織を新規作成する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Settings.Profile.Tissue">組織</UI-TERM>** タブの右上隅にある **<UI-TERM key="ocp-v2.Auth.Org.CreateAnOrganization">組織の新規作成</UI-TERM>** をクリックします。

4. ポップアップダイアログに組織名を入力します。

   組織名は英字で始まり、英字または数字で終わる必要があり、長さは2文字から128文字です。英字、数字、アンダースコア（_）を使用できます。

5. **<UI-TERM key="ocp-v2.Detail.Parameter.List.Submitted">送信</UI-TERM>** をクリックします。
