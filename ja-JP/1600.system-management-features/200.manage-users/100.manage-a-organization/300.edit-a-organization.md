# 組織の編集

このセクションでは、組織名の変更方法について説明します。組織名を変更すると、その組織に属するすべてのユーザーの組織名が新しい名前に変更されます。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。
* システムのデフォルト組織 **default** は編集できません。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Auth.User.New.Tissue">組織</UI-TERM>** タブの検索ボックスに組織名のキーワードを入力し、検索ボタンをクリックします。

   条件に合致する組織が組織リストに表示されます。

4. 編集対象の組織の **<UI-TERM key="ocp-v2.Component.OBServerList.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">編集</UI-TERM>** ボタンをクリックします。

   **<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.EditOrganization">組織を編集する</UI-TERM>** ダイアログで、組織名を変更します。

5. **<UI-TERM key="ocp-v2.Detail.Component.Event.Determine">確定</UI-TERM>** をクリックします。
