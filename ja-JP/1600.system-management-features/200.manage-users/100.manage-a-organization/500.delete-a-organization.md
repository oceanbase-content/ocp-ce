# 組織の削除

この記事では、組織を削除する方法について説明します。組織を削除すると、その組織配下のリソースはシステムのデフォルト組織である **default** に帰属します。

## 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。
* システムのデフォルト組織 **default** は削除できません。
* 組織内のすべてのユーザーが削除済みであること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Settings.Profile.Tissue">組織</UI-TERM>** タブの検索ボックスに組織名のキーワードを入力し、検索ボタンをクリックします。

   組織リストに条件に合致する組織が表示されます。

4. 削除する組織を選択し、**<UI-TERM key="ocp-v2.page.Host.Operation">操作</UI-TERM>** 列の **その他 > 削除** をクリックします。

5. 確認ダイアログで **<UI-TERM key="ocp-v2.Alarm.Template.Delete">削除</UI-TERM>** をクリックします。
