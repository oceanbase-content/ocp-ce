# リソース構成の共有

このセクションでは、組織間でリソース構成を共有する方法について説明します。リソース構成を共有すると、元の組織とターゲット組織は共有されたリソースに対する権限を同時に持つことになります。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>リソース構成の共有が完了した後、元の組織で新しいリソースを追加しても、そのリソースは元の組織内にのみ存在し、リソース構成が共有されているターゲット組織には同期されません。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロールであることを確認してください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Settings.Profile.Tissue">組織</UI-TERM>** をクリックし、**<UI-TERM key="ocp-v2.Auth.User.New.Tissue">組織</UI-TERM>** タブに移動します。

4. リソース構成を共有する元の組織を選択し、操作リストの **その他 > リソース構成の共有** をクリックします。

5. **<UI-TERM key="ocp-v2.Auth.Org.SharedResourceDrawer.SharedResourceConfiguration">共有リソースの設定</UI-TERM>** パネルに移動します。

6. 共有するリソース構成を選択します。少なくとも1種類のリソースを選択して共有してください。

7. 共有されたリソース構成を受信するターゲット組織を選択します。複数選択が可能です。

8. **<UI-TERM key="ocp-v2.TakeOver.Component.LoadBalancer.Ok">確定</UI-TERM>** をクリックします。
