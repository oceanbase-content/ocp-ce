# 認証情報の削除

この記事では、認証情報を削除する方法について説明します。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>認証情報を削除すると、OceanBaseクラスタ、テナント、OBProxyクラスタ、ホストの運用に影響します。運用手順で認証情報が見つからないために失敗する可能性があります。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**Binlogサービスメンテナンス**、または**ホストメンテナンス**のいずれかのリソース権限。
* セキュリティ管理 **<UI-TERM key="ocp-v2.src.constant.auditEvent.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">セキュリティ管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">認証情報管理</UI-TERM>** をクリックし、認証情報一覧ページに移動します。

3. 削除する認証情報オブジェクトを見つけ、そのオブジェクトの **<UI-TERM key="ocp-v2.Detail.Component.OBProxyList.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** にカーソルを合わせ、選択ボックスで **<UI-TERM key="ocp-v2.component.ZoneFormList.Delete">削除</UI-TERM>** をクリックします。

4. ダイアログで **<UI-TERM key="ocp-v2.component.FormEditTable.Delete">削除</UI-TERM>** をクリックします。
