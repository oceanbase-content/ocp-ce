# 凭据のエクスポート

このセクションでは、凭据をエクスポートする手順について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* セキュリティ管理 **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">安全管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">認証情報管理</UI-TERM>** をクリックし、凭据リストページに移動します。

3. **OceanBase**、**OBProxy**、または **<UI-TERM key="ocp-v2.src.constant.alarm.Host">ホスト</UI-TERM>** タブで、エクスポートする凭据オブジェクトを見つけます。

4. オブジェクトの **<UI-TERM key="ocp-v2.Component.SQLDetail.ParallelSQLTraceTable.Actions">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.src.util.component.More">もっと見る</UI-TERM>** にカーソルを合わせ、選択ボックスで **<UI-TERM key="ocp-v2.Monitor.Dashboard.Export">エクスポート</UI-TERM>** をクリックします。

5. ダイアログボックスに暗号化パスワードを入力します。パスワードの設定規則は以下のとおりです：

    * 長さは8文字から32文字です。
    * 数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字の4種類のうち、少なくとも3種類を含みます。
    * サポートされている特殊文字は <code>~!@#%^&*_-+=\|(){}[]:;,.?/</code> です。

6. **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ExportSqlButton.Export">エクスポート</UI-TERM>** をクリックします。

    <h4>説明</h4>
