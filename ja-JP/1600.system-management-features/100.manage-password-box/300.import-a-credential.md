# 認証情報のインポート

このセクションでは、OceanBaseクラスタの認証情報のインポートについて説明します。クラスタの引き継ぎ時（OceanBaseクラスタなどを含む）に、元のOCPのクラスタおよびテナントの認証情報をインポートできます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* セキュリティ管理 **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">セキュリティ管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">認証情報管理</UI-TERM>** をクリックし、認証情報リストページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.page.Credential.ImportCredentials">資格情報のインポート</UI-TERM>** ボタンをクリックします。

4. 表示された **<UI-TERM key="ocp-v2.page.Credential.ImportCredentials">資格情報のインポート</UI-TERM>** ダイアログで、[認証情報のエクスポート](200.export-a-credential.md)でエクスポートした認証情報ファイルを選択し、エクスポート時に設定した暗号化パスワードを入力して **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.ClickUpload">クリックしてアップロード</UI-TERM>** をクリックします。

5. **<UI-TERM key="ocp-v2.Credential.Component.ImportModal.NextStep">次のステップ</UI-TERM>** をクリックします。

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%AF%BC%E5%85%A5%E5%87%AD%E6%8D%AE%E7%AC%AC%E4%B8%80%E6%AD%A5.png)

6. 認証情報の事前チェックを確認します。

   事前チェックでは、認証情報が存在するか、接続に成功したかどうかなどの情報が表示されます。

7. 認証情報オブジェクトを選択し、**<UI-TERM key="ocp-v2.Monitor.Dashboard.Import">インポート</UI-TERM>** をクリックします。

    ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%AF%BC%E5%85%A5%E5%87%AD%E6%8D%AE%E7%AC%AC%E4%BA%8C%E6%AD%A5.png)
