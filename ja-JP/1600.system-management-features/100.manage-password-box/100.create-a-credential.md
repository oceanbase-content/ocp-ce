# 新規作成クレデンシャル

このセクションでは、OCPでクラスタまたはホストに接続するためのクレデンシャルを新規作成する方法について説明します。新しいOCPの管理タスクでクラスタへの接続やホストの追加が必要な場合、作成したクレデンシャルを直接選択できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* セキュリティ管理 **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">セキュリティ管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.constant.auditEvent.CredentialManagement">認証情報管理</UI-TERM>** をクリックし、クレデンシャル一覧ページに移動します。

3. 右上の **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CreateCredentials">認証情報を新規作成</UI-TERM>** ボタンをクリックし、クレデンシャルオブジェクトのタイプを選択します。

   **OceanBase**、**OBProxy**、**<UI-TERM key="ocp-v2.src.constant.monitor.Host">ホスト</UI-TERM>** の3種類が含まれます。

4. 表示された **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.CreateCredentials">認証情報を新規作成</UI-TERM>** ダイアログボックスに、クレデンシャル関連情報を入力します。

    | **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.ObjectType">オブジェクトタイプ</UI-TERM>** | **入力情報** |
    | --- | --- |
    | OceanBase | クレデンシャル接続オブジェクトが存在するOceanBaseクラスタ、OceanBaseテナント、具体的な接続ユーザー、および管理者ユーザーの接続可能なパスワードを入力します。|
    | OBProxy | クレデンシャル接続オブジェクトが存在するOBProxyクラスタおよび管理者ユーザーの接続可能なパスワードを入力します。 |
    | ホスト | ホスト関連のクレデンシャル情報を入力します。クレデンシャル名は英字で始まり、英字または数字で終わる必要があり、英字、数字、アンダースコアを含むことができ、長さは2～64文字である必要があります。 |

    <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>sysテナントのクレデンシャルは、そのテナント自身および所属クラスタへの接続に使用できます。他のテナントのクレデンシャルは、そのテナント自身の接続操作にのみ限定されます。</p>
    </main>

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E6%96%B0%E5%BB%BA%E5%87%AD%E6%8D%AE.png)

5. **<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Ok">確定</UI-TERM>** をクリックします。

   この時点で、パスワードボックスがクレデンシャルの接続テストを実行します。テストに失敗した場合、クレデンシャルの作成は失敗します。
