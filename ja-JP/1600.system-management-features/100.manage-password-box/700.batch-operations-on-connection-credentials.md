# 接続資格情報の一括操作

このセクションでは、接続資格情報の一括検証、一括エクスポート、および一括削除の方法について説明します。

## 前提条件

* **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchVerification">一括検証</UI-TERM>** および **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchExport">一括エクスポート</UI-TERM>** を実行する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
  * セキュリティ管理 **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

* **<UI-TERM key="ocp-v2.page.Host.BatchDelete">一括削除</UI-TERM>** を実行する場合は、現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
  * セキュリティ管理 **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">セキュリティ管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.hook.useMenu.CredentialManagement">認証情報管理</UI-TERM>** をクリックし、資格情報リストページに移動します。

3. **OceanBase**、**OBProxy**、または **<UI-TERM key="ocp-v2.src.component.AddArbitrationDrawer.Host">ホスト</UI-TERM>** タブで、一括操作を実行する資格情報オブジェクトを選択します。

4. 操作したいタイプをクリックします。

   **<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchVerification">一括検証</UI-TERM>**、**<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchExport">一括エクスポート</UI-TERM>**、および **<UI-TERM key="ocp-v2.Alarm.Rule.BatchDeletion">一括削除</UI-TERM>** が含まれます。

   * 一括検証：**一括テスト**をクリックすると、資格情報が接続に成功するかどうかを一括でテストできます。

   * 一括エクスポート：**<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchExport">一括エクスポート</UI-TERM>**をクリックし、表示されたダイアログボックスに暗号化パスワードを入力して、**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ExportSqlButton.Export">エクスポート</UI-TERM>**をクリックします。

   * 一括削除：**<UI-TERM key="ocp-v2.Credential.Component.FilterBar.BatchDeletion">一括削除</UI-TERM>**をクリックし、表示されたダイアログボックスで**<UI-TERM key="ocp-v2.Backup.BackupStrategy.Detail.Delete">削除</UI-TERM>**をクリックします。
