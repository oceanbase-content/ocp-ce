# 認証情報の編集

このセクションでは、認証情報を編集する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* セキュリティ管理 **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">セキュリティ管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.CredentialManagement">認証情報管理</UI-TERM>** をクリックし、認証情報リストページに移動します。

3. 変更したい認証情報を見つけ、その認証情報の **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Monitor.AddMonitor.VisualizationsTable.Edit">編集</UI-TERM>** をクリックします。

4. 表示された **<UI-TERM key="ocp-v2.src.component.AddBinlogCredentialModal.EditCredentials">認証情報を編集する</UI-TERM>** ダイアログで、認証情報を変更します。

    | **<UI-TERM key="ocp-v2.Statistics.components.TaskTable.ObjectType">オブジェクトタイプ</UI-TERM>** | **編集可能な内容** |
    | --- | --- |
    | OceanBaseクラスタ | 認証情報の **<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.Password">パスワード</UI-TERM>** と **<UI-TERM key="ocp-v2.MultiAzone.Parameter.Description">説明</UI-TERM>** を編集します。 |
    | OBProxyクラスタ | 認証情報の **<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.Password">パスワード</UI-TERM>** と **<UI-TERM key="ocp-v2.page.Host.Description">説明</UI-TERM>** を編集します。 |
    | ホスト | 認証情報を編集します。**<UI-TERM key="ocp-v2.Credential.Component.ImportModal.CredentialName">認証情報名</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.UserType">ユーザータイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.page.Settings.Profile.UserName">ユーザー名</UI-TERM>**、**<UI-TERM key="ocp-v2.Auth.User.New.Password">パスワード</UI-TERM>**、**<UI-TERM key="ocp-v2.src.component.AddHostCredentialDrawer.ApplicationHost">アプリケーションホスト</UI-TERM>**、および **<UI-TERM key="ocp-v2.Detail.LoadBalance.AddObproxyLoadBalanceAppDrawer.Description">説明</UI-TERM>** を含みます。 |

5. **<UI-TERM key="ocp-v2.Component.ZoneList.EditZoneModal.Ok">確定</UI-TERM>** をクリックします。
