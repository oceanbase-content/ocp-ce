# 認証情報の検証

このセクションでは、認証情報が使用可能かどうかを検証する方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**Binlogサービス読み取り専用**、または**ホスト読み取り専用** のいずれかのリソース権限。
* セキュリティ管理 **<UI-TERM key="ocp-v2.page.Credential.CredentialManagement">認証情報管理</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">セキュリティ管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.src.component.AddOBCredentialModal.CredentialManagement">認証情報管理</UI-TERM>** をクリックし、認証情報リストページに移動します。

3. **OceanBase**、**OBProxy**、または **<UI-TERM key="ocp-v2.Cluster.New.Host">ホスト</UI-TERM>** タブで、検証対象の認証情報オブジェクトを見つけます。

4. 当該認証情報の **<UI-TERM key="ocp-v2.Component.OBServerList.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.page.Credential.OBProxy.Verification">検証</UI-TERM>** をクリックします。

5. 認証情報の検証に成功した場合、その認証情報オブジェクトのクラスタ名または認証情報名の後に **<UI-TERM key="ocp-v2.page.Credential.Host.VerifiedSuccessfully">検証に成功しました</UI-TERM>** ラベルが表示されます。検証に失敗した場合は、認証情報を再入力する必要があります。
