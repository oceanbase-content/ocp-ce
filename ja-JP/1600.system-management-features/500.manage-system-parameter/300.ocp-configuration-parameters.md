# OCP構成パラメータ一覧
このセクションでは、現在のOCPに含まれるすべてのシステムパラメータを掲載しています。OCP管理者の参考としてください。パラメータを変更すると、デフォルトで約10分後に自動的に反映されます。「再起動が必要」と特別に記載されている項目は、OCP Serverを再起動しなければ変更が有効になりません。詳細は各パラメータの説明欄をご確認ください。

## グローバル設定

|              **<UI-TERM key="ocp-v2.Detail.Parameter.List.Parameter">パラメータ名</UI-TERM>**               |        **<UI-TERM key="ocp-v2.Detail.Parameter.List.DefaultValue">デフォルト値</UI-TERM>**        |                                               **パラメータ説明**                                                |
|---|---|---|
| ocp.site.url                       | `http://localhost:8080` | OCP Webサイトへの外部アクセスURLです。HTTPまたはHTTPSで始まる、VIPアドレス/ドメイン名/ポートを含むURLで、末尾にスラッシュ（/）が含まれていない必要があります。例：`http://localhost:8080`。         |
| ocp.config-url.site.url            |   -                    | OCP config urlサービスへの外部アクセスURLです。デフォルトは空文字列で、ocp.site.urlと同じ値を使用します。config urlサービスを単独でデプロイする場合は、ocp.site.urlとは異なる値を設定する必要があります。 |
| ocp.config-url.use-request-address | TRUE                  | Config urlサービスのレスポンスで、リクエスト元のアドレスを使用するかどうかを指定します。デフォルトはtrueです。falseに設定した場合、レスポンスにはocp.config-url.site.urlで設定されたアドレスが使用されます。    |
| ocp.system.default.timezone        |     -                  | システムのデフォルトタイムゾーンです。設定しない場合は、system default time zoneが使用されます。再起動後に反映されます。                                                         |
| ocp.system.default.language        | zh-CN                 | システムのデフォルト言語（フロントエンドの言語設定ではない）です。設定しない場合はzh-CNが使用されます。再起動後に反映されます。                                                                   |
| ocp.web.tracking.enabled   | false  | OCPのテレメトリ機能のスイッチです。Enterprise版はデフォルトでオフ、Community版はデフォルトでオンになっています。この機能は、特定のシナリオでユーザーの利用状況情報を収集し、その情報を匿名化した上でOceanBaseに共有し、製品体験の向上に役立てます。例えば、これらの情報を通じてユーザーがOceanBaseデータベースをどのように利用しているかを把握し、OceanBaseデータベースの使い勝手を改善することができます。<br>この機能を無効にするには、OCP MetaDBデータベースで```update config_properties set value = 'false' where `key` = 'ocp.web.tracking.enabled';```コマンドを実行します。  |
## セキュリティとログイン
| **<UI-TERM key="ocp-v2.Detail.Parameter.History.Parameter">パラメータ名</UI-TERM>**    |    **<UI-TERM key="ocp-v2.component.OperationConfig.List.DefaultValue">デフォルト値</UI-TERM>**      |        **パラメータ説明**         |

| server.servlet.session.timeout       | 30m      | ログインセッション/Sessionのタイムアウト時間です。デフォルトは30m、最小60sです。単位が付いていない場合、デフォルトは秒です。       |
| ocp.iam.auth                         | composite   | Webページからのログインオプションです。現在、local（ローカルMetaDB内のOCPアカウント）、oauth2（OAuth2プロトコル）、cas（CASプロトコル）、composite（組み合わせモード）、buc（Alibabaグループ従業員アカウント）、ApsaraStack（Alibaba Cloud専用クラウド）をサポートしています。デフォルトは`composite`です。再起動後に反映されます。     |
| ocp.iam.csrf.enabled                 | TRUE     | CSRFクロスサイトリクエストフォージェリングのセキュリティ保護を有効にするかどうかを指定します。通常、Webページからのログイン方式では有効にすることを推奨します。デフォルトは`true`です。再起動後に反映されます。        |
| ocp.iam.login.max-attempts           | 5        | ログイン時に連続してユーザー名またはパスワードを間違えることが許容される回数です。制限を超えた場合、クライアントIPのログインが一時的にブロックされます。デフォルトは5回です。        |
| ocp.iam.login.lockout-minutes        | 15       | ログイン失敗の制限を超えた場合、クライアントIPのログインを一時的にブロックする時間です。デフォルトは15分です。       |
| ocp.iam.login.client.max-attempts    | 10       | 同一クライアントが連続してログインインターフェースにアクセスする回数です。制限を超えた場合、クライアントのログインリクエストが一時的にブロックされます。デフォルトは10回です。       |
| ocp.iam.login.client.lockout-minutes | 10       | 同一クライアントのログインリクエストが制限を超えた場合、クライアントのログインリクエストが一時的にブロックされます。デフォルトは10分です。      |
| ocp.iam.password.remind.before-expiration.days | 10   | パスワードの有効期限までの事前リマインダー時間です。デフォルトは10日です。   |
| ocp.iam.password.reuse.times         | 0        | パスワードの再利用回数の設定です。デフォルトは0回で、制限なしを意味します。最大6回まで設定可能です。  |
| ocp.iam.password.validity.period.days | 0       | パスワードの有効期間日数です。デフォルトは0で、0は永遠に期限切れにならないことを意味します。  |
