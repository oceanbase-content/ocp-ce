# システムパラメータの確認

OCPでは、システムパラメータは一般的にアカウントログイン、バックアップ・リストアなどの機能に関連する設定に使用されます。このセクションでは、システムパラメータの確認方法について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または**ホスト読み取り専用** のいずれかのリソース権限。
* システム管理 **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">システムパラメータ</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** **\>** **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">システムパラメータ</UI-TERM>** をクリックします。

   **<UI-TERM key="ocp-v2.page.MultiCluster.Parameter.ParameterList">パラメータリスト</UI-TERM>** には、デフォルトで変更可能なすべてのパラメータが表示されます。

   パラメータリストの右下にあるページネーション機能でページを切り替えたり、各ページの表示数を調整したりできます。

   ![07021722](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E5%8F%82%E6%95%B0%E9%87%8D%E5%90%AF.png)

3. **<UI-TERM key="ocp-v2.page.Property.ParameterList">パラメータリスト</UI-TERM>** の右上にある検索ボックスにシステムパラメータ名のキーワードを入力し、検索記号をクリックします。

   **<UI-TERM key="ocp-v2.page.Property.ParameterList">パラメータリスト</UI-TERM>** に、条件に合致するシステムパラメータが返されます。
