# システムパラメータの変更

この記事では、システムパラメータの変更方法について説明します。

## 背景

システムパラメータは、OCPシステムのバックアップ・リストア機能のスイッチやリソース監視の頻度など、一般ユーザーが自ら変更することを推奨しない複雑な設定を制御します。

OCPシステムはデプロイ後、ユーザーが正常に利用できるようこれらのシステムパラメータにデフォルト値を設定しています。お客様に特別な要件がある場合は、管理者にこれらのパラメータの変更を依頼できます。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または**ホストメンテナンス** のいずれかのリソース権限。
* システム管理 **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">システムパラメータ</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > システムパラメータ** をクリックします。

   * *<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">パラメータリスト</UI-TERM>** には、変更可能なすべてのパラメータがデフォルトで表示されます。

3. **<UI-TERM key="ocp-v2.MultiAzone.Parameter.ParameterList">パラメータリスト</UI-TERM>** の右上にある検索ボックスにシステムパラメータ名のキーワードを入力し、検索アイコンをクリックします。

   * *<UI-TERM key="ocp-v2.page.Property.ParameterList">パラメータリスト</UI-TERM>** に、条件に一致するシステムパラメータが返されます。

4. そのパラメータの **<UI-TERM key="ocp-v2.page.Property.Value">パラメータ値</UI-TERM>** 列の編集ボタンをクリックします。

   システムは **<UI-TERM key="ocp-v2.Detail.Parameter.List.ModifyParameterValues">パラメータ値を変更する</UI-TERM>** ダイアログをポップアップ表示します。

5. [OCP構成パラメータリスト](300.ocp-configuration-parameters.md) のパラメータ説明を参照し、このダイアログにそのパラメータの値を入力します。

   JSONデータ型のパラメータを編集する際は、以下の運用保守機能を利用できます。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%BF%AE%E6%94%B9%E5%8F%82%E6%95%B0%E5%80%BC.png) -->

   * クリップボードにコピー。このボタンをクリックすると、パラメータの内容がクリップボードにコピーされます。
   * keyの追加。このボタンをクリックすると、ノードに新しいkeyを追加します。
   * keyの編集。このボタンをクリックすると、ノードのkeyを編集します。
   * keyの削除。このボタンをクリックすると、ノードまたはノードのkeyが削除されます。

6. **<UI-TERM key="ocp-v2.Cluster.Component.TakeOverArbitrationDrawer.Ok">確定</UI-TERM>** をクリックします。

   パラメータの変更が完了したら、パラメータの **<UI-TERM key="ocp-v2.Detail.Parameter.List.WhetherToRestartEntryInto">再起動して有効にする</UI-TERM>** の情報を確認し、パラメータが有効になる方法を判断します。
   * 再起動が不要なパラメータ：パラメータの変更が成功すると、約3分で反映されます。
   * 再起動が必要なパラメータ：OCPサーバーを再起動してから有効になります。
