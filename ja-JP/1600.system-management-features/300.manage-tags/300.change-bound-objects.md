# バインドオブジェクトの変更

このセクションでは、タグのバインドオブジェクトを変更する方法について説明します。タグがリソースオブジェクトに紐づけられると、そのタグ情報はそのオブジェクトに直接適用されます。

## 前提条件

* 現在OCPにログインしているユーザーがADMINロールであることを確認してください。

* 同一のリソースオブジェクトにおいて、同一のタグキーは一つのタグ値に対応します。同じタグキーを持つタグを再度そのオブジェクトに紐づけると、そのリソースオブジェクトの既存のタグは自動的に解除され、新たに紐づけたタグに更新されます。
* 各リソースオブジェクトは最大20個のタグを設定できます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**システム管理 > タグ管理** をクリックします。

3. **<UI-TERM key="ocp-v2.page.Tags.Label">タグ</UI-TERM>** の概要ページに移動し、バインドオブジェクトを変更したいタグを選択し、操作列の **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.ModifyBoundObjects">バインド対象を変更する</UI-TERM>** をクリックします。

4. パネルでオブジェクト範囲を選択します。

    * 最初の選択欄でタグが紐づくオブジェクトタイプを選択します。**<UI-TERM key="ocp-v2.src.constant.inspection.OceanbaseCluster">OceanBase クラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.component.AddChartDrawer.ChartConfigPanel.OceanbaseTenants">OceanBaseテナント</UI-TERM>**、**<UI-TERM key="ocp-v2.src.constant.auditEvent.ObproxyCluster">OBProxyクラスタ</UI-TERM>**、**<UI-TERM key="ocp-v2.component.OperationConfig_AGENTConfig.Host">ホスト</UI-TERM>**、**<UI-TERM key="ocp-v2.Component.ArbitrationServerList.ArbitrationService">アービトレーションサービス</UI-TERM>** の5種類のリソースオブジェクトがあります。オブジェクトタイプのみを選択した場合、そのタイプの下にあるすべてのリソースオブジェクトを一括で紐づけることができます。
    * 次の選択欄で具体的なリソースオブジェクトを選択します。複数選択が可能です。特定のリソースオブジェクトを選択した場合、タグは選択したオブジェクトにのみ紐づけられます。

    **<UI-TERM key="ocp-v2.src.constant.log.Host">ホスト</UI-TERM>** を例にすると、**<UI-TERM key="ocp-v2.Arbitration.ArbitrationGroup.Host">ホスト</UI-TERM>** タイプを選択した場合、タグはすべてのホストに適用されます。ホストの下の特定のIPアドレスのみを選択した場合、タグは選択したホストにのみ適用されます。

5. **<UI-TERM key="ocp-v2.component.TenantList.Ok">確定</UI-TERM>** をクリックします。
