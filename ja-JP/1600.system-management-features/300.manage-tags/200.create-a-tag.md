# タグの作成

このセクションでは、リソースオブジェクトにタグを作成する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーがADMINロールであることを確認してください。

* 単一のOCPシステムでは、デフォルトで最大5,000個のタグを作成できます。より高い要件がある場合は、OCPサポートチームにお問い合わせください。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで、**システム管理 > タグ管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.Label">タグ</UI-TERM>** の概要ページに移動し、**<UI-TERM key="ocp-v2.component.CreateTagDrawer.CreateTags">タグを作成する</UI-TERM>** をクリックします。

4. パネルにタグ情報を入力します。詳細は以下のとおりです。

    |  パラメータ  |  説明   |
    |--------|---------|
    |  タグキー  |  カスタムタグキー。リソースオブジェクトの一次グループ分けに使用されます。必須項目。<br>入力ルール：<ul><li>長さは1～128文字です。</li><li>大文字と小文字は区別されます。</li><li>UTF-8形式で表現されます。</li><li>一意であり、値は1つだけです。</li></ul>    |
    |  タグ値  | カスタムタグ値。リソースオブジェクトの二次グループ分けに使用されます。オプション。<br>入力ルール：<ul><li>長さは1～256文字です。</li><li>大文字と小文字は区別されます。</li><li>UTF-8形式で表現されます。</li><li>一意であり、値は1つだけです。</li></ul>     |

    ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/422/%E5%88%9B%E5%BB%BA%E6%A0%87%E7%AD%BE.png)

    * システムはデフォルトで1つのタグ情報を追加します。複数のタグを追加する必要がある場合は、下部の **<UI-TERM key="ocp-v2.Detail.TakeOver.Add">追加</UI-TERM>** ボタンをクリックして、複数のタグ情報を追加できます。
    * タグ行の末尾にある削除アイコンをクリックして、不要なタグを削除します。

5. **<UI-TERM key="ocp-v2.Detail.Component.DeleteModal.Ok">確定</UI-TERM>** をクリックすると、タグの作成が完了します。
