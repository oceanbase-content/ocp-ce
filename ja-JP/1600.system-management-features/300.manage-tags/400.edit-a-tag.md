# タグの編集

タグの情報を更新する必要がある場合は、このセクションを参照してタグ情報を変更してください。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>タグが参照されている場合、タグを変更すると、対応するオブジェクト上のタグも変更されます。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーがADMINロールであることを確認してください。

## 手順

以下では、**システム管理 > タグ管理** から操作する手順を説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > タグ管理** をクリックします。

3. **<UI-TERM key="ocp-v2.src.constant.auth.Label">タグ</UI-TERM>** リストから変更したいタグを選択するか、上部の検索バーにタグのキーワードを入力して検索します。リストには条件に一致するタグが表示されます。

4. 変更するタグの **<UI-TERM key="ocp-v2.Plan.Component.PlanTemplateTable.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Alarm.Channel.Editing">編集</UI-TERM>** ボタンをクリックします。

5. パネルでタグ情報を変更し、**<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">確定</UI-TERM>** をクリックします。

    タグ関連パラメータの説明については、[タグの作成](200.create-a-tag.md)を参照してください。
