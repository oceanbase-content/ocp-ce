# タグ管理の概要

このセクションでは、タグの役割とOCPがタグに対して提供する管理機能について説明します。

## タグの概要

タグは、整理、分類、迅速な検索、迅速なフィルタリング、タスクおよびプロジェクト管理、チーム連携、共有の機能を備えており、柔軟かつ効率的な方法を提供します。

OCPは、OceanBaseクラスタ、アービトレーションサービス、テナント、OBProxyクラスタ、ホストの5種類のオブジェクトタイプに対するタグ付け操作をサポートしており、新規作成、編集、削除、関連オブジェクトの変更などの管理機能もサポートしています。

OCPはキー値パターンを提供し、一次タグ(`Value=Key`、例：`本番環境`)または二次タグ(`Key:Value`、例：`環境：本番`、`環境：テスト`、`環境：プレビュー`)を実現しています。業務状況に応じて適切なタグ表示形式を選択できます。OceanBaseクラスタなど、さまざまなオブジェクトタイプのページでは、クラスタにタグを付けてフィルタリングすることで、クラスタオブジェクトの整理、検索、管理を容易にし、作業効率を向上させることができます。

## 手順

以下の手順を参考に、リソースオブジェクトにタグを作成して使用してください：

1. [タグの作成](200.create-a-tag.md)。

    リソースオブジェクトの内容や属性の特徴に基づいてキーワードを抽出し、タグを作成することで情報を整理します。

2. タグの[バインドオブジェクトの変更](300.change-bound-objects.md)。

    タグ作成後、タグの内容に基づいて対応するリソースオブジェクトに紐づけることができます。紐づけ後、タグがリソースオブジェクトにマークされ、タグによる分類、検索、管理が容易になります。

3. タグの運用管理。

    [タグの編集](400.edit-a-tag.md)、[タグの削除](500.delete-a-tags.md)などの運用管理操作をサポートしています。

## タグの管理

OCPは異なる観点からタグの運用管理をサポートしており、以下の10のエントリからタグを管理できます：

* エントリ1：

    OCPにログインし、クラスタ概要ページに移動して、**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>**でタグ管理を行います。

* エントリ2：

    OCPにログインし、クラスタ概要ページに移動して、クラスタの**<UI-TERM key="ocp-performance-report.pages.Report.Content.BasicInformation">基本情報</UI-TERM>**モジュールでタグ管理を行います。

* エントリ3：

    OCPにログインし、**クラスタ > テナント管理**に移動して、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails.TenantList">テナント一覧</UI-TERM>**でタグ管理を行います。

* エントリ4：

    OCPにログインし、テナント概要ページに移動して、**<UI-TERM key="ocp-v2.page.Tenant.TenantList">テナント一覧</UI-TERM>**でタグ管理を行います。

* エントリ5：

    OCPにログインし、テナント概要ページで、テナントの **<UI-TERM key="ocp-performance-report.pages.ASH.BasicInformation">基本情報</UI-TERM>** モジュールからタグを管理します。

* エントリ6：

    OCPにログインし、OBProxy概要ページで、**<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.ClusterList">クラスタ一覧</UI-TERM>** 内でタグを管理します。

* エントリ7：

    OCPにログインし、OBProxy概要ページで、OBProxyクラスタの **<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.BasicInformation">基本情報</UI-TERM>** モジュールからタグを管理します。

* エントリ8：

    OCPにログインし、ホスト概要ページで、**<UI-TERM key="ocp-v2.page.Host.HostList">ホスト一覧</UI-TERM>** 内でタグを管理します。

* エントリ9：

    OCPにログインし、ホスト概要ページで、**<UI-TERM key="ocp-v2.Report.Scan.ReportContent.BasicInformation">基本情報</UI-TERM>** タブの **<UI-TERM key="ocp-v2.Alarm.Event.Detail.Details">詳細</UI-TERM>** モジュールからタグを管理します。

* エントリ10：

    OCPにログインし、**システム管理 > タグ管理** に移動して、**<UI-TERM key="ocp-v2.src.constant.auth.Label">タグ</UI-TERM>** ページでタグを管理します。
