# タグの削除

特定のタグを使用しなくなった場合は、このセクションを参照してタグを削除できます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>タグが参照されている場合、タグを削除すると、対応するオブジェクト上のタグも削除されます。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーがADMINロールであることを確認してください。

## 手順

以下の手順は、**システム管理 > タグ管理** エントリを例に説明します。

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > タグ管理** をクリックします。

3. **<UI-TERM key="ocp-v2.page.OBProxy.Label">タグ</UI-TERM>** リストから削除するタグを選択するか、上部の検索バーにタグのキーワードを入力して検索します。条件に合致するタグがリストに表示されます。

4. 削除するタグの **<UI-TERM key="ocp-v2.Alarm.Subscriptions.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.MultiCluster.Detail.Delete">削除</UI-TERM>** ボタンをクリックします。

5. ポップアップウィンドウで **<UI-TERM key="ocp-v2.page.Information.Ok">確定</UI-TERM>** をクリックします。
