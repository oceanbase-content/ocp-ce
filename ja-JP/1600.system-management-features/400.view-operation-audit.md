# 操作監査の表示

操作監査では、最近のさまざまなイベントタイプの操作履歴を確認できます。これには、**<UI-TERM key="ocp-v2.Information.Detail.CollectDetails EventType">イベントタイプ</UI-TERM>**、**<UI-TERM key="ocp-v2.page.AuditEvent.EventAction">イベント操作</UI-TERM>**、**<UI-TERM key="ocp-v2.page.AuditEvent.Resource">リソース名</UI-TERM>**、**<UI-TERM key="ocp-v2.page.AuditEvent.EventInformation">イベント情報</UI-TERM>**、**クライアントIP**、**<UI-TERM key="ocp-v2.Detail.SQLDiagnosis.Outline.Operator">操作者</UI-TERM>**、**<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.ExecutionTime">実行時間</UI-TERM>**、および **<UI-TERM key="ocp-v2.page.AuditEvent.ExecutionResult">実行結果</UI-TERM>** の内容が含まれます。

<main id="notice" type='notice'>
<h4>機能の適用範囲</h4>
<p>この内容はOCP Enterprise版にのみ適用されます。OCP Community版はこの機能を提供していません。</p>
</main>

## 背景

OCPの操作監査機能は、プラットフォーム全体の重要な操作を完全に記録し、視覚的に追跡することを実現しています。ホスト、クラスタ、アービトレーションサービス、テナントなどのインフラ管理、バックアップ・リカバリ、ソフトウェアパッケージなどの運用操作、ユーザー・組織などの権限管理、および監視、パラメータ、ラベルなどのシステム設定行為を網羅しています。監査イベントの詳細を一元的に表示することで、この機能はユーザーに便利な問題特定手段を提供します。利用中に異常が発生した場合、操作履歴を迅速に遡り、問題の箇所を正確に特定することで、運用効率を大幅に向上させることができます。

## 前提条件

現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ADMIN_VIEWER** ロールであることを確認してください。

## 手順

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SecurityManagement">セキュリティ管理</UI-TERM>** \> **<UI-TERM key="ocp-v2.page.AuditEvent.HistoricalEvents">操作監査</UI-TERM>** をクリックし、イベントの検索ページに移動します。

2. 操作監査の検索と表示。

   1. 特定期間内の操作監査の検索：ドロップダウンボックスで期間を選択するか、カスタム設定も可能です。

   2. リソース名の検索：検索ボックスに表示するイベントのリソース名を入力し、検索アイコンをクリックするかEnterキーを押すと、対応するイベントの操作履歴を確認できます。

3. 操作監査のフィルタリングと表示。

   1. **<UI-TERM key="ocp-performance-report.ReportTable.TopWaitEvent.TopWaitEventTable.EventType">イベントの種類</UI-TERM>** のフィルタリング：イベントタイプの後ろのフィルタアイコンをクリックし、表示したいタイプを選択して、**<UI-TERM key="ocp-v2.component.Compaction.MergePolicyDrawer.Ok">確定</UI-TERM>** をクリックします。イベントタイプには、ホスト管理、OceanBaseクラスタ管理、アービトレーションサービス管理、OceanBaseテナント管理、OBProxyクラスタ管理、Binlogサービス管理、バックアップ・リカバリ管理、ソフトウェアパッケージ管理、OCPユーザー管理、OCPクラスタ管理、資格情報管理、アラート管理、巡回点検管理、個人情報管理、カスタムモニタリング管理、モニタリングダッシュボード管理、システムパラメータ管理、ラベル管理、SQLパフォーマンス管理、組織管理、計画管理、情報収集管理、証明書管理、AIアシスタントモデル管理、外部連携SLS管理、外部連携ES管理が含まれます。

   2. **<UI-TERM key="ocp-v2.page.AuditEvent.EventAction">イベント操作</UI-TERM>** のフィルタリング：イベント操作の後ろのフィルタアイコンをクリックし、表示したいタイプを選択して、**<UI-TERM key="ocp-v2.ResourceManager.ResourceGroupTab.CreateResourceGroup.Ok">確定</UI-TERM>** をクリックします。

4. **<UI-TERM key="ocp-v2.page.AuditEvent.EventInformation">イベント情報</UI-TERM>** で操作監査を表示します。検索ボックスにイベント情報の内容を入力し、**<UI-TERM key="ocp-v2.src.util.component.Search">検索</UI-TERM>** をクリックすると、リストには検索条件に一致するすべてのイベントが返されます。イベント情報をクリックすると、右側のポップアップウィンドウにイベントの詳細情報が表示されます。

   イベント情報は、イベント発生時のAPI呼び出しパラメータです（パスワードなどの情報はマスキング処理されています）。

5. 操作者別に操作監査を表示します。**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.SQLDetailTabs.Operator">オペレーター</UI-TERM>** の後ろのフィルタアイコンをクリックし、表示したい操作者を選択して、**<UI-TERM key="ocp-v2.Host.Component.ReinstallModal.Determine">確定</UI-TERM>** をクリックします。

6. 時間順に操作監査を表示します。

   1. 時間の古い順に操作監査を表示する：**<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.sqlTrendsAttributes.ExecutionTime">実行時間</UI-TERM>** の後ろの上向き三角形アイコンをクリックします。

   2. 時間の新しい順に操作監査を表示する：**<UI-TERM key="ocp-v2.page.AuditEvent.ExecutionTime">実行時間</UI-TERM>** の後ろの下向き三角形アイコンをクリックします。

7. 実行結果で操作監査を表示します。**<UI-TERM key="ocp-v2.page.AuditEvent.ExecutionResult">実行結果</UI-TERM>** の後ろのフィルタアイコンをクリックし、実行結果に基づいてイベントをフィルタリングします。
