# ソフトウェアパッケージのアップロード

このページでは、ソフトウェアパッケージをアップロードする手順について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタメンテナンス**、**テナントメンテナンス**、**OBProxyメンテナンス**、**アービトレーションサービスメンテナンス**、**Binlogサービスメンテナンス**、または **ホストメンテナンス** のいずれかのリソース権限。
* システム管理 **<UI-TERM key="ocp-v2.src.hook.useMenu.SoftwarePackageManagement">ソフトウェアパッケージ管理</UI-TERM>** メニュー権限。

## 手順

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.auditEvent.SoftwarePackageManagement">ソフトウェアパッケージ管理</UI-TERM>** をクリックし、ソフトウェアパッケージページに移動します。

2. **<UI-TERM key="ocp-v2.Component.UpgradeDrawer.Upload">アップロード</UI-TERM>** をクリックし、ポップアップウィンドウで **<UI-TERM key="ocp-v2.Dashboard.component.ImportDashboardModal.SelectFile">ファイルを選択してください</UI-TERM>** をクリックして、ローカルにアップロードするソフトウェアパッケージを選択し、**<UI-TERM key="ocp-v2.Auth.Org.CreateOrg.Ok">確定</UI-TERM>** をクリックします。

   サポートされているインストールパッケージのタイプは、OceanBase、Binlog、OCP Agent、OBProxy、バックアップ・リカバリ、その他です。

   <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li><code>.rpm</code> または <code>tar.gz</code> 形式のインストールパッケージを最大10個まで一括アップロードできます。</li><li>システムのOSが <code>debian</code> で、OCP Agentのインストールディレクトリをカスタマイズする必要がある場合は、<code>tar.gz</code> 付きのOCP Agentインストールパッケージを使用し、<code>ocp.agent.home.path.prefix</code> システムパラメータでインストールディレクトリをカスタマイズすることを推奨します。</li><li>アップロードするソフトウェアパッケージが非公式パッケージの場合は、一定のリスクが伴うため、本番クラスタ環境へのデプロイは推奨されません。</li><li>Enterprise Edition OCPは、アップロードされたソフトウェアパッケージに対して署名検証を行います。検証に失敗した場合は、ソフトウェアパッケージをアップロードできません。その場合は、別のソフトウェアパッケージを選択して再アップロードすることを推奨します。</li><li>OCPは、新しくアップロードされたソフトウェアパッケージに対してSHA256アルゴリズムを用いて検証値を計算し、ソフトウェアパッケージの整合性検証に利用します。</li></ul></p>
   </main>

3. アップロード完了後、ソフトウェアパッケージリストでパッケージ情報を確認できます。

## 関連操作

ソフトウェアパッケージリストでは、**ソフトウェアパッケージ名**、**タイプ**、**バージョン**、**システム**、**ハードウェアアーキテクチャ**、**サイズ(MiB)**、**アップロード時間**などの情報を確認できます。

* **タイプ**、**バージョン**、**システム**、**ハードウェアアーキテクチャ** でソフトウェアパッケージをフィルタリングできます。

* **ソフトウェアパッケージ名** と **<UI-TERM key="ocp-v2.page.Package.UploadTime">アップロード時間</UI-TERM>** でソフトウェアパッケージをソートできます。

## 関連設定

OCPは、管理するソフトウェアパッケージの総数と総容量に制限を設けています。
**<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.util.menu.SystemParameters">システムパラメータ</UI-TERM>** で、以下のパラメータを調整できます。

|  パラメータ  |  説明                                 |  リブートが必要か  |
|--------|------------------------------------|--------------|
| `ocp.software.package.max-count`  | ソフトウェアパッケージの総数の上限。上限に達すると、ソフトウェアパッケージのアップロードや作成ができなくなります。デフォルトは100です |  不要です |
| `ocp.software.package.max-total-size-gib`  | 登録済みのすべてのソフトウェアパッケージの総容量の上限。単位はGiBです。デフォルトは50GiBです |  不要です |
