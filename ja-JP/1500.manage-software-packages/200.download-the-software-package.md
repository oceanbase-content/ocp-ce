# ソフトウェアパッケージのダウンロード

このページでは、ソフトウェアパッケージをダウンロードする手順について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **クラスタ読み取り専用**、**テナント読み取り専用**、**OBProxy読み取り専用**、**アービトレーションサービス読み取り専用**、**Binlogサービス読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
* システム管理 **<UI-TERM key="ocp-v2.src.constant.auditEvent.SoftwarePackageManagement">ソフトウェアパッケージ管理</UI-TERM>** メニュー権限。

## 手順

1. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.menu.SystemManagement">システム管理</UI-TERM>** > **<UI-TERM key="ocp-v2.src.constant.auditEvent.SoftwarePackageManagement">ソフトウェアパッケージ管理</UI-TERM>** をクリックし、ソフトウェアパッケージページに移動します。

2. 対応するソフトウェアパッケージの後ろにある **<UI-TERM key="ocp-v2.page.Package.Download">ダウンロード</UI-TERM>** をクリックすると、対応するソフトウェアパッケージをダウンロードできます。
