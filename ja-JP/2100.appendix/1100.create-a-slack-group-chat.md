# Slackグループチャットの作成とWebhook URLの取得

Slackチャネルを通じてアラートメッセージを送信する前に、まずSlack上でカスタムボットのWebhook URLを取得する必要があります。本記事では、Slack内のWebhook URLを取得し、Slackグループに関連付ける方法について説明します。

## 手順

### ステップ1：Slackチャンネルを作成する

1. [Slack公式サイト](https://slack.com)またはSlackデスクトップ版にアクセスします。

2. 左側の**チャンネル**>**チャンネルを作成**をクリックし、アラート通知を受信するためのSlackチャンネル（グループチャットのようなもの）を作成します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01271050.png) -->

   チャンネル作成成功ページは以下のとおりです。

   <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261659.png) -->

### ステップ2：Incoming Webhookアプリケーションを追加する

1. Slack内で**<UI-TERM key="ocp-v2.Alarm.Rule.Detail.Application">アプリケーション</UI-TERM>**をクリックし、**Incoming Webhooks**を検索してアプリケーションに移動します。

   <!-- ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261700.png) -->

2. チャンネル設定ページで、**ステップ1**で作成したSlackチャンネルを選択し、**Add Incoming WebHook Integration**をクリックして関連付けます。

   <!-- ![3](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261701.png) -->

### ステップ3：WebHook URLを取得する

1. 関連付けが成功すると、Incoming Webhookは自動的に**WebHook URL**を生成します。例：`https://hooks.slack.com/services/xxx/xxx`。Sending Messagesの説明を参考に、任意のアラートメッセージ形式を選択して使用します。

   <!-- ![4](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261702.png) -->

2. 以下のスクリプトを実行してテストし、アラートメッセージがSlackグループチャットに正常に送信されるか確認します。

    ```bash
    # https://hooks.slack.com/services/XXXX はサブステップ3で生成されたWebHook URLです
    curl -X POST -H 'Content-type: application/json' \
    --data '{"text":"Hello, World!"}' \
    https://hooks.slack.com/services/XXXX
    ```

    テスト結果に`ok`が出力され、グループチャットに**Hello, World!**のメッセージが表示されれば、WebHook接続が正常であり、SlackグループチャットがWebHookに正常に関連付けられていることを意味します。

    <!-- ![5](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/441/01261415.png) -->
