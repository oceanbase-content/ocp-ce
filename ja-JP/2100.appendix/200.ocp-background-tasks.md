# バックグラウンドタスク一覧

OCP V4.4.xのバックグラウンドタスクは、2種類のスケジューリング形態に分類されます：

* **タスクエンジンによるスケジュールタスク**：OCPタスクエンジンを通じて`task_definition`/`task_template`テーブルに登録され、スケジュールごとに1件の`task_instance`レコードが生成され、複数の`subtask_instance`に分割されます。トラブルシューティング時には、`task_definition.id = task_instance.task_definition_id`および`task_instance.id = subtask_instance.task_instance_id`を使用してJOINクエリを実行できます。

* **設定ファイルに基づく定期タスク**：OCP Serverの設定ファイル`ocp.task.scheduled.*`の設定セクションから読み込まれ、Springスケジューラーによってトリガーされます。`task_definition`/`task_instance`テーブルにレコードは生成されないため、履歴はOCPログを通じてのみ調査可能です。個別タスクを無効にするには、`ocp.task.scheduled.<group>.<taskName>.enabled: false`を使用します。

旧バージョンの`dag_schedule`/`dag_instance`の2つのテーブルは、OCP V4.4.xで廃止されました。履歴のスケジューリング記録は自動的に`task_definition`/`task_instance`に移行されます。アップグレード後は、新しいテーブルを使用してクエリを実行してください。

バックグラウンドタスクの実行ログについては、`logging.file.name`設定パラメータで指定されたOCPログファイルにアクセスし、特定のキーワードで検索できます。OCPログファイルのデフォルトは`${user.home}/logs/ocp/ocp.log`、タスクサブプロセスのログディレクトリは`${user.home}/logs/task/`です。

以下は常駐バックグラウンドタスクの一覧で、タスク名、タスク説明、スケジューリング式、状態の調査方法などの情報が含まれています。OCPシステム管理者の参考および問題のトラブルシューティングに利用できます。

**スケジューリング式**

スケジューリングでは、以下の形式のCron式を使用します。これには6つのフィールドが含まれます。

```code
second, minute, hour, day of month, month, day(s) of week
```

設定ファイルに基づく定期タスクでは、Cronに加えて、`fixedDelay`（前回実行終了から次回開始までの間隔）、`fixedRate`（2回の開始時間間の間隔）、`initialDelay`（初回実行前の待機時間）という3つのフィールドもサポートしています。時間単位はデフォルトで秒ですが、`timeUnit: MINUTES|HOURS|DAYS`で指定できます。また、`enabled`を`false`に設定すると、個々のタスクを無効にできます。

**Cron式のフィールドと値**

|   **フィールド名**    |    **値の範囲**    | **サポートする特殊文字** |
|--------------|----------------|-------------|
| second       | 0-59           | ,-\*/       |
| minute       | 0-59           | ,-\*/       |
| hour         | 0-23           | ,-\*/       |
| day of month | 1-31           | ,-\*/?      |
| month        | 1-12 または JAN-DEC | ,-\*/       |
| day of week  | 1-7 または MON-SUN  | ,-\*/?      |

**式の例：**

|          **式**           |                              **説明**                               |
|----------------------------|-------------------------------------------------------------------|
| **0 0 \* \* \* \***        | “0秒 0分” - 毎時0分に1回実行されます。                                  |
| **\*/10 \* \* \* \* \***   | 10秒ごとに1回実行されます。                                                      |
| **0 0 8-10 \* \* \***      | 毎日の8時、9時、10時に1回ずつ実行されます。0秒0分に開始されます。                                 |
| **0 0/30 8-10 \* \* \***   | 毎日8:00、8:30、9:00、9:30、10:00、10:30に実行されます。                       |
| **0 0 9-17 \* \* MON-FRI** | 月曜日から金曜日の午前9時から午後5時まで実行されます。                                          |
| **0 0 9-17 \* \* 1-5**     | 月曜日から金曜日の午前9時から午後5時まで実行されます。曜日は数字で表し、1は月曜日、7は日曜日を表します。`crontab`の式とは若干異なります。 |
| **0 0 0 25 12 ?**          | 毎年12月25日の午前0時0分0秒。                                        |
