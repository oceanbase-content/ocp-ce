# プロセス一覧
このセクションでは、OCP関連のプロセスについて説明します。

## プロセスの説明

### OBServerノードサーバー
OBServerノード上で起動する業務関連プロセスについて紹介します。

<main id="notice" type='explain'>

<h4>説明</h4>

  <p>表内のプロセスはすべてOCP-Agent関連プロセスです。ocp_agent_ctl.pyスクリプトを使用してこれらのプロセスを操作できます。</p>
    </main>
    |      プロセス      | リスニングポート  |               起動・停止方法                |                                     用途及び説明                                      |
  |--------------|-------|-----------------------------------|--------------------------------------------------------------------------------|

| ocp_agentd   | -     | ocp-agentプロセス起動時に自動起動し、プロセスを守る必要がない場合は自動停止します。 | すべてのocp_agentプロセスを守ります。他のocp_agentプロセスを停止する必要がある場合は、このプロセスを停止してから行ってください。そうでないと、ocp_agentdが再度起動させます。            |
| ocp_mgragent | 62888 | ocp-agentプロセス起動時に自動起動します。             | OCPから指示された運用保守命令を実行し、ホスト上の各種運用保守操作を完了し、ホスト、OceanBase、OBProxyなどの運用保守操作を実現します。 プロセス異常により、ホストのOCP上の状態がオフラインになる可能性があります。 |
| ocp_monagent | 62889 | ocp-agentプロセス起動時に自動起動します。             | OCPが必要とする監視データを収集します。 このプロセスが異常になると、TopSQLやplan cacheの監視が利用できなくなったり、「OceanBaseログアラート」が利用できなくなる可能性があります。          |
### OCPサーバー
OCPサーバー上で起動する業務関連プロセスについて紹介します。

|     プロセス     | リスニングポート |                                  用途                                   |

|------------|------|-----------------------------------------------------------------------|

| ocp-server | -    | ホストのリモート管理およびメトリクスの取得。 OCP-Agent関連プロセスの起動は、正常に動作するocp-serverに依存します。 |
### OBProxyサーバー
OBProxyサーバー上で起動する業務関連プロセスについて紹介します。

|    プロセス    | リスニングポート |          用途           |

|----------|------|-----------------------|

| obproxyd | -    | OBProxyのデーモンプロセスです。        |
| obproxy  | -    | OceanBaseへのアクセスプロキシ業務を担当します。 |
| obproxyd | -    | OBProxy 的守护进程。        |
| obproxy  | -    | 负责 OceanBase 的访问代理业务。 |
