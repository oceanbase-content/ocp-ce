# コンポーネントのリスニングポート一覧

OCPのネットワークアクセス権限設定時の参考に使用します。

## デプロイメントユニットの説明

|     デプロイメントユニット     |                     説明                     |
|--------------|--------------------------------------------|
| OCP-Server   | OCP管理サービスプログラム Docker                          |
| OCP-Console  | OCP Web管理コンソール                              |
| OCP-Agent    | OCPが管理するホスト上にデプロイされるエージェントプログラム(OCP-Agent/OB-Agentを含む) |
| OBServer     | OCPがデプロイするOceanBaseプログラム                       |
| OBProxy      | OCPがデプロイするOBProxyプログラム                         |
| Backup-Agent | OCPがデプロイするバックアップ・リカバリagentプログラム                       |
| Application  | データベースにアクセスするアプリケーション                                 |
