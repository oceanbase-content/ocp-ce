# S3プロトコルの説明

OCPは、AWS S3プロトコルに互換性のあるストレージメディアをサポートしており、ネイティブAWS S3、Huawei Cloud OBS、Tianyi Cloud OBS、Google GCSなどが含まれます。

## 共有ストレージ形態でのオブジェクトストレージの使用

S3プロトコルに互換性のあるオブジェクトストレージは、バックアップメディアとしてだけでなく、AIクラスタ（共有ストレージ形態）の主データ永続化メディアとしても使用できます。共有ストレージ形態では、OceanBaseデータベースは`SHARED_STORAGE_INFO`起動パラメータを使用してオブジェクトストレージ情報を設定し、計算とストレージの分離を実現します。

`SHARED_STORAGE_INFO`パラメータには、以下の主要なフィールドが含まれます：

|     フィールド     |     説明   |
|-------------|---------|
| bucket_uri  | オブジェクトストレージのBucket URI。例：`s3://oceanbase-test-bucket/data`。 |
| host        | オブジェクトストレージサービスのドメイン名またはEndpoint。 |
| access_id   | オブジェクトストレージのアクセスキーID。 |
| access_key  | オブジェクトストレージのアクセスキー。 |
| max_iops    | オブジェクトストレージの最大IOPS制限。 |
| max_bandwidth | オブジェクトストレージの最大帯域幅制限。 |

AIクラスタの作成時にオブジェクトストレージを設定する方法の詳細については、[AIクラスタの作成](../600.cluster-functions/200.create-a-cluster/300.create-an-ai-cluster.md)を参照してください。

## AWS S3

OSSと同様に、AWS S3もdelete_modeパラメータを使用してバックアップファイルのクリーンアップモードを設定でき、設定方法はOSSと同じです。

S3をバックアップメディアとして使用する設定例は以下のとおりです：

* S3をバックアップメディアとして使用する場合、システムテナントは指定されたテナント`mysql_tenant`にバックアップ宛先を設定し、deleteクリーンアップモードを構成します。

    ```sql
    obclient> ALTER SYSTEM SET DATA_BACKUP_DEST='s3://oceanbase-test-bucket/backup/data?
    host=s3.<region>.amazonaws.com
    &access_id=****
    &access_key=****
    &s3_region=****
    &delete_mode=delete' TENANT = mysql_tenant;
    ```

* S3をバックアップメディアとして使用する場合、ユーザーテナントは自身のテナントにバックアップ宛先を設定し、deleteクリーンアップモードを構成します。

    ```sql
    obclient> ALTER SYSTEM SET DATA_BACKUP_DEST='s3://oceanbase-test-bucket/backup/data?
    host=s3.<region>.amazonaws.com
    &access_id=****
    &access_key=****
    &s3_region=****
    &delete_mode=delete';
    ```

例では、`s3://`はS3をバックアップ宛先メディアタイプとして使用することを示し、バケット名は`oceanbase-test-bucket`、バケット内のパスは`/backup/data`であり、`?`を使用してパスの他のパラメータを区切っています。`host`はAmazon S3サービスのドメイン名を設定するために使用され、`access_id`と`access_key`はAWSサービスのアクセスキーを設定するために使用されます。S3をバックアップメディアとして使用する場合、`s3_region`は必須パラメータであり、S3のバケットが存在するリージョンを表します。クリーンアップモードは`delete`に設定されます。

## S3プロトコルに互換性のあるオブジェクトストレージ

ほとんどのオブジェクトストレージはS3プロトコルに互換性があるため、S3プロトコルに互換性があり、OceanBaseデータベースの要件（オブジェクトストレージはOceanBaseシステムコールを実装したいくつかのS3 APIの動作に互換性が必要）を満たすオブジェクトストレージは、OceanBaseデータベースのバックアップメディアとして使用できます。S3を介してアクセスすることで、OBSやGCSなどの互換オブジェクトストレージにアクセスできます。

**OBSをバックアップメディアとして使用する設定例は以下のとおりです:**

* OBSをバックアップメディアとして使用する場合、システムテナントは指定されたテナント`mysql_tenant`にバックアップ宛先を設定します。

    ```sql
    obclient> ALTER SYSTEM SET DATA_BACKUP_DEST='s3://oceanbase-test-bucket/backup/data?
    host=obs.****.myhuaweicloud.com
    &access_id=****
    &access_key=****' TENANT = mysql_tenant;
    ```

* OBSをバックアップメディアとして使用する場合、ユーザーテナントが自身のテナントに対してバックアップ宛先を設定します。

    ```sql
    obclient> ALTER SYSTEM SET DATA_BACKUP_DEST='s3://oceanbase-test-bucket/backup/data?
    host=obs.****.myhuaweicloud.com
    &access_id=****
    &access_key=****';
    ```

上記の例では、`s3://` はS3プロトコル互換のオブジェクトストレージをバックアップ宛先メディアタイプとして使用することを示し、バケット名は `oceanbase-test-bucket`、バケット内のパスは `/backup/data` です。また、`?` を使用してパスの他のパラメータを区切ります。`host` はOBSサービスのドメイン名を設定するために使用され、`access_id` と `access_key` はOBSサービスのアクセスキーを設定するために使用されます。

**GCSをバックアップメディアとして使用する設定例は以下のとおりです：**

* GCSをバックアップメディアとして使用する場合、システムテナントが指定されたテナント `mysql_tenant` に対してバックアップ宛先を設定します。

    ```sql
    obclient> ALTER SYSTEM SET DATA_BACKUP_DEST='s3://oceanbase-test-bucket/backup/data?
    host=https://storage.googleapis.com
    &access_id=****
    &access_key=****' TENANT = mysql_tenant;
    ```

* GCSをバックアップメディアとして使用する場合、ユーザーテナントが自身のテナントに対してバックアップ宛先を設定します。

    ```sql
    obclient> ALTER SYSTEM SET DATA_BACKUP_DEST='s3://oceanbase-test-bucket/backup/data?
    host=https://storage.googleapis.com
    &access_id=****
    &access_key=****';
    ```

上記の例では、`s3://` はS3プロトコル互換のオブジェクトストレージをバックアップ宛先メディアタイプとして使用することを示し、バケット名は `oceanbase-test-bucket`、バケット内のパスは `/backup/data` です。また、`?` を使用してパスの他のパラメータを区切ります。`host` はGCSサービスのドメイン名を設定するために使用され、`access_id` と `access_key` はGCSサービスのアクセスキーを設定するために使用されます。
