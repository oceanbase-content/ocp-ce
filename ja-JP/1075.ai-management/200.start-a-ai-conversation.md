# 対話の開始

本記事では、OCP AIアシスタントのインテリジェントな対話機能とナレッジベース検索機能の使い方を紹介します。

## インテリジェントな対話の開始

このセクションを参照してAIインテリジェント対話を有効にすることができます。AIアシスタントは、大規模言語モデルを基に、ユーザーの質問に対して包括的な分析、インテリジェントな診断、解釈を行います。

### 前提条件

以下の操作を完了していること：

* [モデルメーカーへの接続](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/100.link-a-model.md) または [モデルの追加](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/200.add-a-model.md) でカスタムモデルを追加していること。
* [システムモデルの設定](../1600.system-management-features/450.manage-external-integration/100.manage-ai-models/300.set-system-model.md) を行っていること。

### 手順

1. OCPにログインします。

2. OCPの任意のページで、右側のAIアシスタントアイコンをクリックします。

3. AIアシスタントページで、**<UI-TERM key="ocp-v2.pages.AIAssistant.utils.IntelligentDialogue">スマートチャット</UI-TERM>** モードを選択します。

4. **<UI-TERM key="ocp-v2.AIAssistant.Content.Welcome.OpenDialogue">対話を開始する</UI-TERM>** をクリックします。

5. ダイアログボックスにOceanBaseに関する質問を入力すると、AIアシスタントは大規模言語モデルに基づいて関連する回答を出力します。

    * 対話では、AIアシスタントの思考プロセスがリアルタイムで表示されます。質問の内容に基づき、AIアシスタントは意識認識およびナレッジベースコンポーネントの認識を行い、より高品質な回答を出力します。
    * 回答の下にあるコピーアイコンをクリックすると、回答をクリップボードにコピーできます。
    * **関連リソース** には、お問い合わせいただいた質問に関する拡張情報が表示されます。必要に応じてご覧ください。
    * 各回答の終了後、AIアシスタントは関連する質問を自動的に3つ推薦します。新しい質問をクリックすると、AIアシスタントはその質問に基づいて即座にさらなる回答を提供します。これにより、AIアシスタントがユーザーの意図をより深く理解し、Q&Aの精度と効率を向上させることができます。

## ナレッジベース検索の使用

このセクションを参照して通常の対話を開始することができます。通常の対話は、OceanBaseのドキュメントナレッジベース検索機能のみを使用し、大規模言語モデルによるコンテンツ生成は有効になりません。

### 手順

1. OCPにログインします。

2. OCPの任意のページで、右側のAIアシスタントアイコンをクリックします。

3. AIアシスタントページで、**ナレッジベース検索** モードを選択します。

4. **対話の開始** をクリックします。

5. ダイアログボックスに検索したい内容を入力すると、OCPはナレッジベースに基づいて関連する回答を出力します。
