# マシンタイプの管理

マシンタイプは、同じ構成を持つホストに付与するラベルです。ホストの管理を容易にするため、意味のある名前を指定することをお勧めします。

## マシンタイプの追加

このセクションでは、マシンタイプの追加方法について説明します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持っていること。
* マシンタイプ名がグローバルに一意であること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Progress.ObServerError.AddObServer.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Host.Detail.Basic.Models">機種</UI-TERM>** タブに移動し、右上の **<UI-TERM key="ocp-v2.Host.Component.AddHostTypeModal.NewModel">機種を追加</UI-TERM>** をクリックします。

4. ダイアログボックスにマシンタイプ名と説明を入力し、**<UI-TERM key="ocp-v2.Credential.Component.ImportModal.Add">新規追加</UI-TERM>** をクリックします。

## マシンタイプ説明の変更

このセクションでは、マシンタイプの説明情報を変更する方法について説明します。

### 前提条件

現在OCPにログインしているユーザーが少なくとも以下の権限を持っていることを確認してください：

* **ホストメンテナンス** リソース権限。
* ホストの **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.auth.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Overview.components.LogServiceServerList.Model">機種</UI-TERM>** タブに移動し、変更するマシンタイプを選択し、説明列の編集ボタンをクリックします。

4. ダイアログボックスで説明情報を変更し、**<UI-TERM key="ocp-v2.Component.OBServerList.OBServerModal.Ok">確定</UI-TERM>** をクリックします。

## マシンタイプの削除

このセクションでは、マシンタイプの削除方法について説明します。

### 前提条件

* 現在OCPにログインしているユーザーが少なくとも以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * ホスト **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

* このマシンタイプに関連するホストが存在する場合、削除はサポートされません。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.component.TakeOverArbitrationDrawer.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Models">機種</UI-TERM>** タブに移動し、削除するマシンタイプを選択して、操作列の **<UI-TERM key="ocp-v2.src.constant.report.Delete">削除</UI-TERM>** をクリックします。

4. ダイアログボックスでホスト情報を確認し、間違いがない場合は **<UI-TERM key="ocp-v2.Alarm.Subscription.Delete">削除</UI-TERM>** をクリックします。
