# ホストタスクの詳細を表示する

このページでは、ホストの運用保守タスクの詳細を表示する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **クラスタ読み取り専用**、**テナント読み取り専用**、または **ホスト読み取り専用** のいずれかのリソース権限。
  * ホストの **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.OBServerWithExclude.All">すべて</UI-TERM>** メニュー権限。

* ホストが **<UI-TERM key="ocp-v2.src.constant.binlog.OM">運用中</UI-TERM>** 状態であること。これには、[OCP Agentの再起動](400.restart-the-ocp-agent.md)、[OCP Agentの再インストール](500.reinstall-ocp-agent.md)、ホストの削除が含まれます。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.util.cluster.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Host">ホスト</UI-TERM>** タブで、タスクを表示したいホストを選択し、操作列の **... > <UI-TERM key="ocp-v2.src.component.TaskLabel.ViewTasks">タスクを確認する</UI-TERM>** をクリックします。

4. ポップアップウィンドウで、そのホストで実行中のタスク情報を確認し、タスクIDをクリックするとタスクの詳細ページに移動します。タスクの詳細ページでは、タスクのログの表示、ロールバック、再試行などの操作を実行できます。詳細については、[タスクの管理](../../1600.system-management-features/600.manage-tasks.md)を参照してください。
