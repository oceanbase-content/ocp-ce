# OCP Agentの再起動

このページでは、OCP Agentを再起動する手順について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **ホストメンテナンス** リソース権限。
* ホスト **<UI-TERM key="ocp-v2.Auth.Role.Detail.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Component.ZoneList.AddOBServerDrawer.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Page.components.PdfMainColumn.Host">ホスト</UI-TERM>** タブで、OCP Agentを再起動するホストを選択し、操作列の **... > <UI-TERM key="ocp-v2.Host.Detail.OCPAgent.RestartOcpAgent">OCP Agent の再起動</UI-TERM>** をクリックします。

   システムは、再起動を確認するメッセージをポップアップ表示します。

4. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Detail.Component.UpgradeModal.Determine">確定</UI-TERM>** をクリックし、OCP Agentを再起動します。

5. OCP Agentの再起動タスクが送信された後、ホストリストで **<UI-TERM key="ocp-v2.Plan.Component.PlanExecuteTable.ViewTasks">タスクを確認</UI-TERM>** をクリックしてタスクの詳細を見ることができます。
