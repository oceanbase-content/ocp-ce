# ホストの削除

このページでは、ホストを削除する方法について説明します。

## 前提条件

* 現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

  * **ホスト管理**リソース権限。
  * ホスト **<UI-TERM key="ocp-v2.alarm.FormListWithExclude.TenantWithExclude.All">すべて</UI-TERM>** メニュー権限。

* ホストが **<UI-TERM key="ocp-v2.src.constant.compute.Idle">空き</UI-TERM>** または **<UI-TERM key="ocp-v2.Component.RecoverableTimeRange.Offline">オフライン</UI-TERM>** 状態であること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.constant.inspection.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.src.constant.monitor.Host">ホスト</UI-TERM>** タブで、削除するホストを選択し、操作列の **... > <UI-TERM key="ocp-v2.page.Package.Delete">削除</UI-TERM>** ボタンをクリックして単一のホストを削除します。または、削除するホストを選択して、**<UI-TERM key="ocp-v2.Alarm.Rule.BatchDeletion">一括削除</UI-TERM>** ボタンをクリックして複数のホストを削除することもできます。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p><ul><li>ホストを削除すると、そのホストのすべての情報と設定がOCPから永久に削除されます。</li><li><b>オフライン</b>状態のホストは、<b>強制削除</b>のみサポートされています。強制削除を実行すると、ホストのすべての情報と設定がOCPから永久に削除されますが、ホスト内のサービスや設定は対応するマシンにログインして手動で削除する必要があります。</li></ul></p>
    </main>

4. ポップアップウィンドウで **<UI-TERM key="ocp-v2.Detail.Component.DeleteUnitModal.Delete">削除</UI-TERM>** をクリックします。
