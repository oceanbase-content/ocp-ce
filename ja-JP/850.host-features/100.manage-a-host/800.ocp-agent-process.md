# OCP-Agentプロセス

このページでは、ocp-agentプロセスについて説明します。

## ocp-agentプロセス

|      プロセス名      |                機能                |               起動・停止方法                |
|---------------|----------------------------------|-----------------------------------|
| ocp_agentd    | ocp-agentプロセスをホストします。                 | OCP agentプロセス起動時に自動起動し、停止できません。 |
| ocp_mgragent  | OCPから指示された運用保守コマンドを実行し、ホスト上の各種運用保守操作を完了します。 | OCP agentプロセス起動時に自動起動し、停止できません。   |
| ocp_monagent  | OCPが必要とする監視データを収集します。 | OCP agentプロセス起動時に自動起動し、停止できません。      |

## ocp_agentプロセスの起動時自動起動

このバージョンでは、ocp_agentの起動時自動起動機能がサポートされています。マシンが再起動すると、ocp_agent関連のサービスプロセスが自動的に起動します。ocp_agentのインストール時に使用されるRPMパッケージのインストールスクリプトは、systemd設定を通じて起動時自動起動を実現し、`ocp_agent.service`をsystemd設定に書き込みます。

```Json
[Unit]
Description=start ocp_agent
[Service]
Type=forking
ExecStart=${ocp.agent.home.path}/bin/ocp_agentctl start
ExecStop=${ocp.agent.home.path}/bin/ocp_agentctl stop
ExecReload=${ocp.agent.home.path}/bin/ocp_agentctl restart
[Install]
WantedBy=multi-user.target
```

ここで、`ocp.agent.home.path`パラメータはインストール時に実際のパスに置き換えられます。

## ocp_agentプロセスの手動起動

黒画面状態でocp_agent関連のサービスプロセスを起動する必要がある場合は、ヘルプスクリプト内の`start`コマンドを使用できます。

## 関連サービスプロセス

ocp_agent関連のサービスプロセス以外にも、以下のサービスプロセスはマシンの再起動後、ocp-agentの起動と共に自動的に起動します。

|      プロセス名      |                機能                |               起動・停止方法                |
|---------------|----------------------------------|-----------------------------------|
| obproxy    | OceanBaseのアクセスプロキシ業務を担当します。       | ocp_agentプロセス起動時に自動起動し、停止できません。 |
| observer  | OceanBaseのカーネル機能を担当します。 | OCP agentプロセス起動時に自動起動し、停止できません。   |
