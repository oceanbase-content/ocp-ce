# ホストの変更

このページでは、ホストを変更する操作について説明します。

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **ホストメンテナンス** リソース権限。
* ホスト **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **ホスト** をクリックします。

3. **<UI-TERM key="ocp-v2.RealtimeMonitor.View3D.utils.Host">ホスト</UI-TERM>** タブで、変更するホストを選択し、操作列の **... > <UI-TERM key="ocp-v2.Alarm.Rule.Editing">編集</UI-TERM>** をクリックします。

4. ポップアップウィンドウで、ホストのIPアドレス、SSHポート、マシンタイプ、データセンター、タイプ、資格情報、ホストエイリアス、説明、OCP Agent設定などの情報を変更します。

5. **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.Ok">確定</UI-TERM>** をクリックして、変更を完了します。
