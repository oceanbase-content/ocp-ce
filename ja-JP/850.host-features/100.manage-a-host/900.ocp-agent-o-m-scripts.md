# OCP-Agent運用スクリプトの使用方法

ユーザーがOCP-Agentのインストール、起動、停止、アンインストールなどの操作を容易に行えるように、OCP-AgentのソフトウェアパッケージにはOCP-Agentの運用ツールであるocp_agentctlが組み込まれています。OCP-Agentのソフトウェアパッケージをインストールすれば、簡単なコマンドを使用してOCP-Agentを操作できます。

## 使用環境

OCP-Agentのソフトウェアパッケージをインストールすると、`ocp_agentctl`はOCP-Agentディレクトリ：`/home/admin/ocp_agent/bin`に配置されます。

  `ocp_agentctl`は実行ファイルであり、コマンドラインを通じてOCP-Agentの運用・管理を行います。`/home/admin/ocp_agent/bin`ディレクトリで直接`ocp_agentctl`を実行できます。

## コマンドライン形式

```javascript
ocp_agentctl [COMMAND] [OPTIONS]
```

* COMMANDは実行する操作コマンドです。例えば、起動(start)や停止(stop)などです。

* OPTIONSは操作の追加オプションです。例：

  * --help："-h"と略記して、使い方のヘルプを照会できます。

## 使用例

### 使い方のヘルプを照会する

* ヘルプを表示する

  ```python
  ./ocp_agentctl -h
  ```

  システムはこのツールの使い方とサポートされている操作コマンドを返します。

* 特定のコマンドの使い方のヘルプを表示する

  ```python
  ./ocp_agentctl config -h
  ```

  システムはconfigコマンドの使い方、および使用可能なオブジェクトとコマンドを返します。

### OCP-Agentを起動する

```python
./ocp_agentctl start
```

実行が成功すると、ocp_agentd、ocp_monagent、ocp_mgragentが一緒に起動します。

### OCP-Agentの停止

```python
./ocp_agentctl stop 
```

実行が成功すると、ocp_agentd、ocp_monagent、ocp_mgragentが停止し、ホストの状態はオフラインになります。これにより、OCPの監視メトリクスやSQL診断データが欠落し、OceanBaseのログアラートも利用できなくなります。

### OCP-Agentの再起動

```python
./ocp_agentctl restart
```

### OCP-Agentのインストール情報の確認

```python
./ocp_agentctl info
```

システムは、OCP-Agentの名前、バージョン、アーキテクチャ、説明などの情報を返します。
