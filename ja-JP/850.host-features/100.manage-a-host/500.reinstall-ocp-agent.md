# OCP Agentの再インストール

このページでは、OCP Agentを再インストールする手順について説明します。

<main id="notice" type='notice'>
<h4>注意</h4>
<p>再インストールにより、実行中のクラスタの運用保守操作が中断され、一時的にホストの監視データが欠落する可能性があります。慎重に操作してください。</p>
</main>

## 前提条件

現在OCPにログインしているユーザーが以下の権限を持っていることを確認してください：

* **ホストメンテナンス** リソース権限。
* ホスト **<UI-TERM key="ocp-v2.component.common.ClusterSelect.All">すべて</UI-TERM>** メニュー権限。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.RealtimeMonitor.View3D.ResourceDrawer.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.component.ZoneFormCardList.Host">ホスト</UI-TERM>** タブで、OCP Agentを再インストールするホストを選択し、操作列の **... > <UI-TERM key="ocp-v2.Host.Component.ReinstallModal.ReloadOcpAgent">OCP Agent を再インストール</UI-TERM>** をクリックします。

4. ポップアップウィンドウで、現在のホストのハードウェアアーキテクチャに対応するソフトウェアパッケージを選択し、**<UI-TERM key="ocp-v2.MultiCluster.Detail.FailoverModal.Determine">確定</UI-TERM>** をクリックします。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>エージェントのポート番号をカスタマイズする必要がある場合は、OCPサポートチームにお問い合わせください。</p>
</main>
