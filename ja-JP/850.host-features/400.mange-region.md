# リージョンの管理

リージョンはホストが配置される地理的エリアを表します。1つの物理リージョンには、1つ以上の物理データセンターが存在できます。リージョンとデータセンターは、OceanBaseのロードバランシングおよびSQL文のルーティングポリシーの参照項目となります。実際の状況に応じて入力してください。

## リージョンの追加

このセクションでは、リージョンの追加方法について説明します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** ロールまたは **ORG_ADMIN** ロールを持っていること。
* リージョン名がグローバルに一意であること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.NewVersion.Item.utils.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Resource.Component.Block.Area">リージョン</UI-TERM>** タブに移動し、右上の **<UI-TERM key="ocp-v2.Host.Component.AddHostRegionModal.NewArea">リージョンを追加</UI-TERM>** をクリックします。

4. ダイアログボックスにリージョン名と説明を入力し、**<UI-TERM key="ocp-v2.component.ZoneFormList.Add">新規追加</UI-TERM>** をクリックします。

## リージョン説明の変更

このセクションでは、リージョンの説明情報を変更する方法について説明します。

### 前提条件

現在OCPにログインしているユーザーが少なくとも以下の権限を持っていることを確認してください：

* **ホストメンテナンス** リソース権限。
* ホストの **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.src.component.ModifyTagResourceDrawer.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.pages.Host.RegionList.Area">地域</UI-TERM>** タブに移動し、変更するリージョンを選択し、説明列の編集ボタンをクリックします。

4. ダイアログボックスで説明情報を変更し、**<UI-TERM key="ocp-v2.component.ParameterTemplate.ParameterTemplateDropdown.Ok">確定</UI-TERM>** をクリックします。

## リージョンの削除

このセクションでは、リージョンの削除方法について説明します。

### 前提条件

* 現在OCPにログインしているユーザーが少なくとも以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * ホスト **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

* 当該リージョンに関連するデータセンターが存在する場合、削除はサポートされません。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Auth.Org.ResourceConfigDrawer.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Detail.Resource.Unit.Area">リージョン</UI-TERM>** タブに移動し、削除するリージョンを選択して、操作列の **<UI-TERM key="ocp-v2.Prometheus.Component.Main.Delete">削除</UI-TERM>** をクリックします。

4. ダイアログボックスで情報を確認し、間違いがない場合は **<UI-TERM key="ocp-v2.Cluster.Component.ClusterList.Delete">削除</UI-TERM>** をクリックします。
