# データセンターの管理

以下の内容を参照してデータセンターを管理できます。

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OCP V3.1.1バージョンからマルチアベイラビリティゾーンモードがサポートされています。新しいデータセンターを追加する場合、現在のOCPが配置されているアベイラビリティゾーン内に新しいデータセンターが作成されます。</p>
</main>

## データセンターの追加

このセクションでは、データセンターの追加方法について説明します。

### 前提条件

* 現在OCPにログインしているユーザーが **ADMIN** 機構または **ORG_ADMIN** 機構を持っていること。
* データセンター名がグローバルに一意であること。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.Detail.TakeOver.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.src.component.AddHostDrawer.ComputerRoom">データセンター</UI-TERM>** タブに移動し、右上の **<UI-TERM key="ocp-v2.Host.Component.AddHostIdcModal.NewMachineRoom">データセンターを追加</UI-TERM>** をクリックします。

4. ダイアログボックスにデータセンター名、リージョン、説明を入力し、**<UI-TERM key="ocp-v2.Host.Component.AddHostIdcModal.New">追加</UI-TERM>** をクリックします。

## データセンター説明の変更

このセクションでは、データセンターの説明情報を変更する方法について説明します。

### 前提条件

現在OCPにログインしているユーザーが少なくとも以下の権限を持っていることを確認してください：

* **ホストメンテナンス** リソース権限。
* ホストの **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.ViewTable.OBProxyItem.HostTable.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.pages.Host.IdcList.MachineRoom">データセンター</UI-TERM>** タブに移動し、変更するデータセンターを選択し、説明列の編集ボタンをクリックします。

4. ダイアログで説明情報を変更し、**<UI-TERM key="ocp-v2.Detail.Component.FailoverDrawer.Determine">確定</UI-TERM>** をクリックします。

## データセンターの削除

このセクションでは、データセンターの削除方法について説明します。

### 前提条件

* 現在OCPにログインしているユーザーが少なくとも以下の権限を持っていることを確認してください：

  * **ホストメンテナンス** リソース権限。
  * ホスト **<UI-TERM key="ocp-v2.component.common.ServerDropdown.All">すべて</UI-TERM>** メニュー権限。

* データセンターに関連するホストが存在する場合は、削除できません。

### 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **<UI-TERM key="ocp-v2.component.alarm.AlarmTargetLabel.Host">ホスト</UI-TERM>** をクリックします。

3. **<UI-TERM key="ocp-v2.Component.AddZoneDrawer.ComputerRoom">データセンター</UI-TERM>** タブに移動し、削除するデータセンターを選択して、操作列の **<UI-TERM key="ocp-v2.Component.BinlogInstanceList.Delete">削除</UI-TERM>** をクリックします。

4. ダイアログで情報を確認し、間違いがない場合は **<UI-TERM key="ocp-v2.Component.TenantConnectionString.Delete">削除</UI-TERM>** をクリックします。
