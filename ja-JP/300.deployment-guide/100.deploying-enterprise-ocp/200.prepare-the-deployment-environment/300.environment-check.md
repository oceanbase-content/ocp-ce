# 環境チェック

このページでは、ホスト、ポート、ソフトウェアのバージョン、時刻を確認する具体的な手順について説明します。

## ホストのチェック

ホストのリソースが [ホストリソース](../300.deployment/100.planning-resources/50.prepare-host.md) の章に記載されている **ハードウェア要件** の最低要件を満たしているかどうかを確認します。

* CPUコア数の確認

  ```shell
  cat /proc/cpuinfo  | grep processor | wc -l;
  ```

* メモリサイズの確認

  ```shell
  free -g;
  ```

* ホストのシステムが要件を満たしているかどうかの確認

  ```shell
  uname -a;
  ```

## ポートのチェック

`telnet`、`nc`、または `netstat` コマンドを使用して、リスニングポートが他のプロセスによって占有されていないかどうかを確認します。ポートの内容については、[コンポーネントのリスニングポートリスト](../../../2100.appendix/400.component-listening-port-list.md)を参照してください。

```shell
# telnetコマンドでチェックします。占有されている場合は>'>'のメッセージが表示され、占有されていない場合はtelnet: connect to address xxx.xxx.xxx.xxx: Connection refusedと返されます。
telnet xxx.xxx.xxx.xxx $PORT

# ncコマンドでポートをチェックします。占有されている場合は戻り値が0になり、占有されていない場合は戻り値が0以外になります。
echo hi | nc xxx.xxx.xxx.xxx $PORT -w 2 > /dev/null 2>&1
echo $?

# netstatコマンドでポートを確認します。
sudo netstat -anp | grep -w $PORT
```

## ソフトウェアバージョンのチェック

ホストシステム上のパッケージ管理コマンドを使用して、[システム要件](../../../200.product-introduction/400.restrictions/100.system-requirements.md) の章に記載されている **ソフトウェア要件** で挙げられているソフトウェアパッケージがすべて満たされているかどうかを確認します。

## 時刻のチェック

OceanBaseデータベースは分散型データベースであるため、クラスタの複数のノードおよびOCPノードの時計には、時刻同期サービスであるNTPまたはchronyを設定し、すべてのノードの時刻偏差を2秒以内に保つ必要があります。

OBServerを実行しているサーバーでは、システム時刻はNTPサービスによって同期されます。しかし、時刻のずれが大きすぎる場合、NTPサービスはシステム時刻を変更したり修正したりしません。クラスタの時刻が同期されていない場合、OceanBaseクラスタの選出モジュールに影響を及ぼし、プライマリレプリカが存在しない、またはスプリットブレインが発生する可能性があります。

OBServerのOS時刻の確認方法および調整方法の詳細については、[NTPオフセットの確認](../500.deploy-appendix-ee/200.check-the-ntp-offset.md)を参照してください。
