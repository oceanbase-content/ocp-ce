# サーバーの追加

OCPをデプロイする前に、OCP（MetaDBおよびMonitorDBを含む）をインストールするサーバーをOATに追加する必要があります。

## 前提条件

* サーバーを追加する前に、スーパーユーザーまたは運用保守担当者のアカウントでOATにログインしていることを確認してください。詳細については、[OATのインストール](100.install-oat.md)を参照してください。
* 複数ノードのOCPシナリオをデプロイする場合は、複数のサーバーを追加する必要があります。

## 手順

1. OATにログインします。

2. 左側のナビゲーションバーで、**サーバー > サーバー管理**をクリックします。

3. **サーバー管理**ページの右上隅で、**サーバーの追加**をクリックします。

   ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%9C%8D%E5%8A%A1%E5%99%A8%E7%AE%A1%E7%90%861.png)

4. 表示された**サーバーの追加**ダイアログで、サーバー情報を入力します。

   サーバー関連フィールドの説明は以下のとおりです：

   |  フィールド   |   説明    |
   |---------|-----------|
   |  サーバーIP       |   追加するサーバーの外部ネットワークカードのIPアドレス。        |
   |   SSHポート      |    追加するサーバーのSSHDポート。       |
   |   認証情報      |    追加するサーバーのアクセス認証情報。現在、ユーザー名とパスワード、キーの2種類の認証情報をサポートしています。       |
   |    初期化設定     |   この機能を有効にして、サーバーの初期化設定を行う必要があります。        |
   |   サーバー用途      |     追加するサーバーの用途。      |
   |   Dockerルートディレクトリ      |     Dockerデータディレクトリ。      |
   |    admin UID:GID     |   OSのadminユーザーに対応するUIDとGID。        |
   |    クロック同期     |     クロック同期を有効にするかどうか。      |

   ![2](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/401/%E6%B7%BB%E5%8A%A0%E6%9C%8D%E5%8A%A1%E5%99%A81.png)

5. **<UI-TERM key="ocp-v2.page.AuditEvent.Determine">確定</UI-TERM>**をクリックします。

   サーバーの追加に成功すると、サーバーリストに新しく追加されたサーバーが表示され、その時点でのマシン状態は**<UI-TERM key="ocp-v2.src.constant.backup.Initializing">初期化中</UI-TERM>**です。**サーバー管理**ページで、追加したサーバーを見つけ、対応する**<UI-TERM key="ocp-v2.Component.BinlogService.Operation">操作</UI-TERM>**列の**<UI-TERM key="ocp-v2.src.constant.ViewTasks">タスクを確認する</UI-TERM>**をクリックすると、タスクの進捗状況を確認できます。サーバーが多すぎる場合は、ページ上部の**IP**で検索できます。

   エラーが発生したサブタスクがあり、それが業務に影響しない場合は、ログ情報を確認した後、サブタスクを手動で成功に設定できます。
