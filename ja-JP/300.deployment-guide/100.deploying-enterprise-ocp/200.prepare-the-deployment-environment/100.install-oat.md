# OATのインストール

OCPは、OAT（OceanBaseエコシステム製品の自動デプロイツール）を使用したGUIベースのデプロイをサポートしています。OCPをデプロイする前に、まずOATをインストールしておく必要があります。

## 前提条件

OATをデプロイする前に、以下の情報を確認してください：

* お使いのオペレーティングシステムが以下の条件を満たしていること：

    | サーバータイプ | オペレーティングシステム | サポートバージョン |
    |---------|---------|------|
    | x86_64/ARM aarch64  | RHEL (および互換性のあるRockyLinux、CentOSなど) | 7.2以降 |
    | x86_64/ARM aarch64  | Anolis (および互換性のあるAlibaba Cloud Linux、Kylin V10、Unity Operating System UOS、China Mobile BC-Linux、Neusys OS、Zhongke Fangdeなど) | 8.4以降 |
    | x86_64/ARM aarch64  | Debian (および互換性のあるUbuntuなど) | 11以降 |
    | x86_64/ARM aarch64  | openSUSE | 12 SP3以降 |
    | x86_64/ARM aarch64 | Neusys | V6.0.99以降 |

* Dockerがインストールされ、起動していること。Docker Community Edition 18.09.9以降のバージョンを推奨します。

* OATのデフォルトポートである7000が使用されていないこと。

## 手順

1. OATのインストールパッケージをダウンロードします。

    詳細については、[インストールメディアの準備](../300.deployment/200.deploying-ocp/100.prepare-installation-media.md)を参照してください。

2. `scp` コマンドを使用して、OATのインストールパッケージをサーバーにアップロードします。

    ここで、`oat_server` はOATをデプロイするサーバーのIPアドレスです。

    ```shell
    scp <oat_directory> <oat_server_user>@:<oat_server_ip>
    ```

3. OATディレクトリをマウントします。

    サーバー上に `/data_dir` ディレクトリを作成し、OATの永続化データを保存します。

    `/data_dir` ディレクトリがOATコンテナにマウントされると、OATは自動的に `/data_dir/logs`、`/data_dir/images`、`/data_dir/db` ディレクトリを作成します。これらはそれぞれ、OATのシステムログ、コンポーネントと製品のDockerイメージ、およびOATのデータベースファイルを格納するために使用されます。

    ```shell
    mkdir -p /data_dir
    ```

4. OATのインストールパッケージをイメージとしてロードします。ここで、`oat_xxx_xxxxxxxx_xxx.tgz` はインストールパッケージの名前です。

    ```shell
    docker load -i oat_xxx_xxxxxxxx_xxx.tgz
    ```

5. `docker images` コマンドを使用して、OATイメージのタグを取得します。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OATのインストールパッケージが1つだけロードされている場合は、この例のコマンドを使用します。複数のインストールパッケージがロードされている場合は、docker imagesコマンドで表示内容を確認し、コロン(:)で最初の2列の内容を結合します。</p>
   </main>

    ```shell
    oat_image=`docker images | grep oat | awk '{printf $1":"$2"\n"}'`
    ```

6. `docker run` コマンドを実行してOATを起動します。ここで、`$oat_image` はOATイメージのタグです。

   ```shell
   docker run -d --net host --name oat  -v /data_dir:/data -e OAT_INITIAL_ADMIN_PASSWORD=xxx --restart on-failure:5 $oat_image
   ```

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p><ul><li>OATのHTTPサービスはデフォルトでポート7000をリッスンします。<code>-e HTTP_PORT=7001</code> パラメータを指定して他のポートに変更できます。</li><li><code>-e OAT_INITIAL_ADMIN_PASSWORD=xxx</code> パラメータを指定してOATのパスワードを変更できます。</li><li>OATはデータストレージとしてMariaDBを内蔵しており、デフォルトでポート3306をリッスンします。<code>-e DB_PORT=3307</code> パラメータを指定して他のポートに変更できます。</li><li><code>--net host</code> パラメータを使用して起動することを推奨します。bridgeネットワークモードで起動したコンテナは、docker0ブリッジの障害やOSパラメータ <code>ip_forward</code> の影響を受ける可能性があるためです。</li></ul></p>
   </main>

7. 起動が成功したら、ブラウザのアドレスバーに `http://<oat_server_ip>:7000` を入力します。ここで、`<oat_server_ip>` はOATをデプロイしたサーバーのIPアドレスに置き換えてください。

   ブラウザのウィンドウにログイン画面が表示されれば、OATのインストールと起動が成功したことを意味します。

   <main id="notice" type='explain'>
    <h4>説明</h4>
    <p>OATのデフォルトのユーザー名とパスワードは、テクニカルサポートにお問い合わせいただけます。初回ログイン後、必ずこのデフォルトのパスワードを変更してください。</p>
   </main>
