# MonitorDBパラメータの最適化
このページでは、OCPで50台以上のOceanBaseデータベースサーバーを管理する場合に、変更を推奨するMonitorDBパラメータについて説明します。

## パラメータ一覧

|                   パラメータ                   | デフォルト値  | 推奨値  |                        説明                        |
|----------------------------------------|------|------|--------------------------------------------------|

| clog_max_unconfirmed_log_count         | 500  | 5000 | トランザクションモジュール内の未確認ログの最大数を設定します。                             |
| _clog_aggregation_buffer_amount        | 0    | 4    | clog集約バッファの数を設定します。各バッファはデフォルトで2MBです。0の場合はログ集約が無効になります。 |
| _flush_clog_aggregation_buffer_timeout | 0 ms | 1 ms | トランザクション集約バッファのリフレッシュ時間間隔を設定します。                              |
| _clog_aggregation_buffer_amount        | 0    | 4    | 用于设置 clog 聚合缓冲区的数量。每个缓冲区默认是 2MB，为 0 的时候代表关闭日志聚合。 |
| _flush_clog_aggregation_buffer_timeout | 0 ms | 1 ms | 用于设置刷新事务聚合缓冲区的时间间隔。                              |
