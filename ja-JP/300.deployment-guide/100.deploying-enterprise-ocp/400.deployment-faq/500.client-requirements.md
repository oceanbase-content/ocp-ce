# クライアント要件
一般的に、ユーザーはWebブラウザを通じてOCPサービスにアクセスします。そのため、クライアントに関する要件は以下のとおりです。

## ブラウザ要件

| **ブラウザ** | **最小バージョン** |
|---------|----------|
| Chrome      | 88                            |
| Firefox     | 78                            |
| Safari      | 14                            |
| Edge        | 88                            |
## ディスプレイ要件
快適に利用するために、解像度が1440 × 810を超えるディスプレイの使用を推奨します。
