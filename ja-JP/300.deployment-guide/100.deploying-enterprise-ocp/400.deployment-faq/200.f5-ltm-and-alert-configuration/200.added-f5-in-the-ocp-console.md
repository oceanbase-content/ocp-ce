# OCP管理コンソールのF5への接続
F5 BIG-IPローカルトラフィックマネージャー（Local Traffic Manager、LTM）は、アプリケーショントラフィック管理システムであり、OBProxyとOCP ConsoleをそれぞれF5に接続することで、OCPのロードバランシングを実現します。

F5のローカルトラフィックマネージャー（Local Traffic Manager、LTM）のレイヤ7設定機能を使用して、OCP管理コンソールの外部サービスポートを設定します。レイヤ7モードのTypeはStandardを指定し、ソースアドレスセッション保持のためにSource Address Affinityを設定する必要があります。設定しない場合、同一IPからのページアクセスが途絶える現象が発生します。

## 前提条件

* F5 BIG-IPの設定が完了し、ライセンスが有効化されていること。
* F5のIPアドレスを確認すること。

* OCP管理コンソールサーバーのIPアドレスとポートを確認すること。

## 手順

1. OCPのユーザー名とパスワードを使用して、F5 BIG-IPにログインします。

![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5656190061/p167954.png "image.png")
2. **Pools**を作成します：

1. Local Traffic\>Poolsをクリックし、**+**をクリックして新しいPoolを作成します。

   ![11151353](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/6385987361/p352204.png)

2. ドロップダウンページで**New Node**を選択し、AddressとService PortにOCP ConsoleサーバーのIPとポートを入力します。

   3. 完了後、**Finished**をクリックします。

      4. **Local Traffic\>Pools\>Pool List**ページで、各Memberの状態Status列のアイコンが緑色になっていれば、追加は成功です。

   3. **Local Traffic\>Profiles\>Persistence\>add**をクリックして、新しいProfileを追加します。

   * **Parent Profile**はsource_addrを選択します。

   * **Timeout**は3600秒を入力することを推奨します。

4. **Local Traffic\>Profiles\>TCP\>add**をクリックして、新しいProfileを追加します。

   * **Parent Profile**はtcpを選択します。

   * **Idle Timeout**は1800秒を入力することを推奨します。

5. **Local Traffic\>Virtual Servers**をクリックして、新しいServerを追加します。

   1. ドロップダウンページに以下の情報を入力します。

   ![11151356](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7385987361/p352210.png)

|             パラメータ              |                 説明                  |

   |-----------------------------|-------------------------------------|

      | Source Address              | xxx.xxx.xxx.xxx/0                           |

      | Destination Address/Mask    | F5 VIPまたはSelf IP、例：xxx.xxx.xxx.xxx |
      | Type                        | Standard                |
      | Service Port                | ポート番号、顧客が自由に設定します                            |
      | Protocol Profile(Client)    | ステップ4で追加したProfileを選択                 |
      | Default Presistence Profile | ステップ3で追加したProfileを選択                 |
      2. ステップ4で追加した2つのProfileの**Source Address Translation**をauto mapに変更します。
      ![11151357](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/7385987361/p352212.png)
      |             パラメータ              |          説明          |

   |-----------------------------|----------------------|

      | Protocol Profile(Client)    | fastL4               |

      | HTTP Profile                | None                 |
      | HTTP Proxy Connect Profile  | None                 |
      | WebSocket Profile           | None                 |
      | Splitsession Client Profile | None                 |
      | Splitsession Server Profile | None                 |
      | Qoe Profile                 | None                 |
      | FiX Profile                 | None                 |
      | Statistics Profile          | None                 |
      | VLAN and Tunnel Traffic     | AII VANs and Tunnels |
      | Source Address Translation  | auto map             |
      | Band width Controller       | BandwidthController  |
      6. ブラウザにIPアドレスとポート番号を入力します。例：xxx.xxx.xxx.xxx:80。ページが正常に開く場合、OCP ConsoleはF5に正常に接続されています。
      | Source Address Translation  | auto map             |
      | Band width Controller       | BandwidthController  |

6. 在浏览器中，输入IP地址+端口，如：xxx.xxx.xxx.xxx:80，页面可正常打开，则 OCP Console 成功接入 F5 。
