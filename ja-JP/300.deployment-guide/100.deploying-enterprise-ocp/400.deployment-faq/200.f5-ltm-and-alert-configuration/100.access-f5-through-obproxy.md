# OBProxyのF5への接続
F5 BIG-IPローカルトラフィックマネージャー（Local Traffic Manager、LTM）は、アプリケーションのトラフィックを管理するシステムです。OBProxyとOCP管理コンソールをそれぞれF5に接続することで、OCPのロードバランシングを実現します。以下の手順に従い、LTMのレイヤ4機能を使用して、OBProxyの外部サービスポートを設定します。

## 前提条件

* F5 BIG-IPの設定が完了し、ライセンスが有効化されていること。
* F5のIPアドレスを確認してください。デフォルトのIPアドレスはxxx.xxx.xxx.xxxです。

* OBProxyサーバーのIPアドレスとポートを確認してください。

## 手順

1. ユーザー名とパスワードを入力してF5 BIG-IPにログインします。デフォルトのユーザー名とパスワードはadmin/adminです。

   ![image.png](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/0047190061/p167941.png "image.png")

2. **Pools**を作成します：

   1. **Local Traffic\>Monitors**をクリックし、新しいMonitorを追加します。タイプは**TCP Half Open**を選択します。

      ![11121742](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4385987361/p351926.png)

   2. **Local Traffic\>Pools**をクリックし、**+**をクリックして新しいPoolを作成します。

      ![11121749](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/4385987361/p351932.png)

   3. ステップ**a**で作成したMonitorを**Available**リストから選択し、**Active**リストに移動します。

      ![c](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1047190061/p169220.png)

   4. ページを下にスクロールし、**New Node**を選択します。AddressとService PortにOBProxyサーバーのIPとポートを入力します。

   5. **Add**をクリックすると複数のノードを追加できます。完了後、**Finished**をクリックします。

      ![e](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1047190061/p169221.png)

   6. **Local Traffic\>Pools\>Pool List**ページで、各Memberの状態を確認します。Status列のアイコンが緑色になっていれば、追加は成功です。

      ![f](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1047190061/p169223.png)

3. **Local Traffic\>Profiles\>FastL4**をクリックし、新しいProfileを追加します。レイヤ4モードのTypeはPerformance(Layer 4)を指定し、セッション保持は有効にしません。**Idle Timeout**は1800秒以上に設定することを推奨します。

   ![c](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/1047190061/p169226.png)

4. **Local Traffic\>Virtual Servers**をクリックし、新しいServerを追加します。

   ![11121752](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5385987361/p351940.png)

   1. 以下の情報を入力します。

      ![4.a](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2047190061/p169229.png)

      |            パラメータ            |                 説明                  |
      |--------------------------|-------------------------------------|
      | Source Address           | xxx.xxx.xxx.xxx/0                           |
      | Destination Address/Mask | F5 VIPまたはSelf IP（例：xxx.xxx.xxx.xxx） |
      | Type                     | Performance(Layer 4)                |
      | Service Port             | ポート番号、顧客が任意に設定します                            |
      | Protocol Profile(Client) | ステップ3で追加したProfileを選択します                 |

   2. ページを下にスクロールし、**Source address translation** で **Auto Map** を選択します。
      ![11121755](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/5385987361/p351945.png)

   3. Default pool には、ステップ2で作成したPoolを選択します。

      ![4.3](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2047190061/p169232.png)

   4. **Finished** をクリックします。

   5. **Local Traffic\>Virtual Servers** ページの **Virtual Server** タブで、Status列のアイコンが緑色になっていれば、新規作成は成功です。

      ![5.e](https://help-static-aliyun-doc.aliyuncs.com/assets/img/zh-CN/2047190061/p169233.png)

5. 作成後、F5およびOBProxyホストとネットワークで接続されているホストを1台選択し、`telnet xxx.xxx.xxx.xxx 2883`、`telnet xxx.xxx.xxx.xxx 3306` を実行します。以下の内容が返された場合、OBProxyがF5に正常に接続されたことを意味します。

   ```unknow
   Connected to xx.xx.x.xxx.Escape character is '^]'.
   ```
