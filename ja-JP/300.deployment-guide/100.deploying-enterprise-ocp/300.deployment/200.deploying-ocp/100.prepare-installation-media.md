# インストールメディアの準備

この章では、OCPのインストールメディアリストについて説明します。OCP-ServerはDockerイメージまたはRPMパッケージを使用してインストールできますが、Dockerイメージを使用したインストールを推奨します。

OCPをインストールする前に、OceanBaseの技術サポートチームに連絡し、以下のインストールパッケージを取得してください。

|    インストールメディア   |   説明   |
|-----------------------|---------|
| OAT RPMパッケージ             |  OceanBase管理ツールキット（OceanBase Admin Toolkit、OAT）は、OceanBaseエコシステム製品の自動化デプロイツールです。 <blockquote>**<UI-TERM key="ocp-v2.src.component.AddOBProxyCredentialModal.Description">説明</UI-TERM>**</br>OATのバージョンはV4.0.0以上である必要があります。</blockquote>  |
| OCP Dockerイメージ      |  インストール前にOCP Dockerイメージを取得する必要があります。   |
| OBServer Dockerイメージ |      OCP metaDBおよびmonitorDBのデプロイに使用します。     |
