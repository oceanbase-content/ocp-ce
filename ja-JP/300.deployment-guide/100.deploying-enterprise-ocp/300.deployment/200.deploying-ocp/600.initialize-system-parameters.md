# システムパラメータの初期化

OCPのインストールが完了した後、以下のシステムパラメータを確認し、必要に応じて変更する必要があります。

| パラメータ名 | 説明 | 初期値 | GUIでの変更可否 |
|----------------|-----------|-------------|-------------------|
| **server.port**     | アプリケーションサーバーの起動ポート番号。OCP-Serverの再起動で反映されます。  | 8080    | 不可 |
| **ocp.site.url**    | OCP Webサイトへの外部アクセスURL：`http/https`で始まり、VIPアドレス/ドメイン名/ポート番号を含むURLで、末尾にスラッシュ（/）がないこと。例：`http://localhost:8080`または`http://[::1]:8080`。 | `http://localhost:8080` | 可 |
| **ocp.config-url.site.url**   | OCP config urlサービスへの外部アクセスURL。デフォルトは空で、`ocp.site.url`と同じ値を使用します。config urlサービスを個別にデプロイする場合は、`ocp.site.url`とは異なる値を設定する必要があります。   | デフォルトは空   | 可 |

GUIでの変更が可能なパラメータについては、[システムパラメータの変更](../../../../1600.system-management-features/500.manage-system-parameter/200.modify-system-parameters.md)を参照して変更してください。

<main id="notice" type='explain'>
<h4>説明</h4>
<ul>
<li>Dockerイメージを使用してインストールする場合、システムにはOCPがOceanBaseクラスタを管理するためのOBProxyが組み込まれています。この場合、<code>ocp.system.obproxy.address</code>および<code>ocp.system.obproxy.port</code>の構成パラメータを変更する必要はありません。組み込みのOBProxyを使用したくない場合は、これら2つの構成パラメータを使用して、使用するobproxyクラスタを指定することもできます。</li>
<li>RPMを使用してインストールする場合、ユーザーはOCPがOceanBaseクラスタを管理するためのOBProxyを自らインストールし、<code>ocp.system.obproxy.address</code>および<code>ocp.system.obproxy.port</code>の構成パラメータを変更する必要があります。</li>
</ul>
</main>

MetaDBの初期化時に、負荷分散のアドレスを介してMetaDBが存在するOceanBaseクラスタに接続する操作を行わなかった場合、自動生成されるMonitorDB接続パラメータもOceanBaseに直接接続するものになります。後から負荷分散（DNSまたはVIPアドレス）のアドレスを介してMonitorDBに接続するように変更する必要がある場合は、下表の負荷分散関連パラメータを変更する必要があります。

| パラメータ名 | 説明 | GUIでの変更可否 |
|--------------------|----------------|----------------|
| ocp.monitordb.host | MonitorDB接続アドレス |   不可    |
| ocp.monitordb.port | MonitorDB接続ポート |   不可    |
