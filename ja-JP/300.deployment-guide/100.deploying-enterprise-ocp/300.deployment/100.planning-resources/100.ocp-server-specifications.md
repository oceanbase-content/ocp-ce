# OCPサービスリソース

OCPサービスは稼働中に大量の計算およびストレージリソースを消費するため、管理対象の規模に応じたリソース計画が必要です。なお、マルチノードOCPの構成では、[サーバーの追加](../../200.prepare-the-deployment-environment/200.standardized-host.md) の手順で複数のサーバーを追加する必要があり、各サービスノードマシンの構成は以下の要件を満たしている必要があります。

## CPUとメモリ

OCP-Serverサービスに必要なCPUおよびメモリリソースは以下の表のとおりです。以下の構成は、管理対象のクラスターごとに5つのテナントを含む場合を基準とした推奨値であり、実際の状況に応じて適切なCPUとメモリを選択してください。

| **管理ホスト台数** | **CPU（コア）** | **メモリ（GiB）** |
|---------------|------------|-------------|
| ≤ 10          | 2          | 4           |
| ≤ 50          | 4          | 8           |
| ≤ 200         | 8          | 16          |
| ≤ 500         | 16         | 32          |
| ≤ 1000        | 32         | 64          |

<main id="notice" type='explain'>
<h4>説明</h4>
<li>OCP-Serverサービスの最低構成要件は2コア4GiBです。</li>
<li>OCPは最大1000台以上のホスト管理をサポートしています。関連するニーズがある場合は、OceanBaseのサービス担当者にお問い合わせください。</li>
</main>

## ディスク容量

OCP-Serverは稼働中にファイルをディスクに書き込みます。これらのデータはディスク容量を消費するため、機能が影響を受けないように、少なくとも100GiBのディスク容量を確保することを推奨します。

OCP-Serverの稼働中のディスク使用状況は以下の表のとおりです。

|   **カテゴリ** |    **ストレージパス**       | **容量要件**                                                                                      |
|--------|------------------------|-----------------------------------------------------------------------------------------------|
| OCPプログラム | `/home/admin/ocp-server/`   | OCPのメインプロセスファイルなど、約800MiBの容量を占有します。              |
| OCPファイル | `/home/admin/data/files/`         | OCP付属のocp-agent rpmパッケージなど、約150MiBの容量を占有します。      |
| OCPログ | `/home/admin/ocp-server/log`     | OCPシステムパラメータでログファイルのサイズと保持するファイル数を設定できます。 デフォルト設定では、単一ファイル100MiB、1日に少なくとも5～10個のファイルが生成され、各ファイルは最大100日間保持されます。 100GiBの容量を確保することを推奨します。 |

<main id="notice" type='explain'>
<h4>説明</h4>
<p>OCP-Serverのログ保持サイズは、OCPシステムパラメータで設定できます。詳細については、<a href="../../../../1600.system-management-features/500.manage-system-parameter/200.modify-system-parameters.md">システムパラメータの変更</a>を参照してください。</p>
</main>
