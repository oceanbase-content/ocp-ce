# デプロイ後の確認

デプロイが完了したら、OCPへのログイン、OCPの機能、ログファイル、OCPのバージョン、時刻を確認することで、デプロイが正常に完了したかどうかを確認できます。

## OCPへのログインの確認

1. ブラウザにOCPのアクセスアドレスを入力し、Enterキーを押します。

   ```bash
   http://<hostip>:<port>/login
   ```

2. 表示されたログインページで、OCPのユーザー名とパスワードを入力します。

    <main id="notice" type='notice'>
    <h4>注意</h4>
    <p>デプロイが成功したページから、OCPのアカウントとパスワードをコピーできます。アカウントのセキュリティを確保するため、ログイン後にパスワードを変更することをお勧めします。パスワードの変更については、<a href="../../1600.system-management-features/700.manage-user-center/200.change-the-logon-password.md">ログインパスワードの変更</a>を参照してください。</p>
    </main>

## OCP機能の確認

OCPのデプロイが完了したら、以下の機能が正常に使用できるか確認してください：

* [アラートチャネルの設定](../../860.alert-management/500.manage-alert-channels/100.create-an-alert-channel.md)を行い、アラートチャネルが利用可能であることを確認します。

* [ホストの追加](../../500.quickstart/400.quickstart-add-a-host.md)、[クラスタの作成](../../500.quickstart/500.quickstart-create-a-cluster.md)、[テナントの作成](../../500.quickstart/600.quickstart-create-a-tenant.md)、[モニタリングの表示](../../880.manage-performance-monitoring/100.performance-monitoring-overview/100.ocp-monitoring-overview.md)などの基本機能を確認します。

## ログファイルの確認

* `/home/admin/logs/ocp` ディレクトリにocp.logファイルが存在するか確認します。

* `/home/admin/logs/ocp/ocp.log` ファイルの出力情報が正常であるか確認します。

## OCPバージョンの確認

以下のコマンドでOCP-Serverのバージョン情報を確認します。戻り値のbuildVersionが対応するバージョンと一致すれば、OCP-Serverのバージョンが正しいことを意味します。

```bash
curl --user <username>:<password> 'http://<OCP_HOST>:<OCP_PORT>/api/v2/info'
```

* username：OCPのログインアカウント。

* password：OCPのログインパスワード。

## 時刻の確認

以下のコマンドでOCP-Serverの時刻を取得します。返された時刻が期待通りであれば、OCP-Serverの現在時計が正常であることを意味します。

```bash
curl 'http://<OCP_HOST>:<OCP_PORT>/api/v2/time'
```
