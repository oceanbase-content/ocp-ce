# OCPのアンインストール

本記事では、コミュニティ版OCPのアンインストール方法について説明します。OCPのバージョンによってアンインストールの手順が異なる場合があります。実際のOCPバージョンに応じて、以下の内容を参照して操作を行ってください。

## 手順

OCPホストにログインし、任意のディレクトリで以下のコマンドを実行します：

```bash
# OCPをアンインストールする
obd cluster destroy <OCP name>
# MetaDBクラスタをアンインストールする
obd cluster destroy <MetaDB name>
```

パラメータ `OCP name` は、**OCPのデプロイ > OCPの設定** で設定したOCP名です。パラメータ `MetaDB name` は、**OCPのデプロイ > MetaDBの設定** で設定したMetaDBクラスタ名です。MetaDBクラスタをアンインストールする前に、そのMetaDBクラスタが他の業務で使用されていないことを確認する必要があります。

## アンインストール後の検証

OCPがアンインストールされたかどうかを確認するため、以下の情報を検証する必要があります：

1. `ps -ef | grep ocp-server` コマンドを実行し、MetaDBクラスタのホスト上にocp-serverプロセスが存在しないことを確認します。

    プロセスが存在しない場合のクエリ結果は以下のとおりです。

2. OCPのインストールディレクトリが空になっていることを確認します。
