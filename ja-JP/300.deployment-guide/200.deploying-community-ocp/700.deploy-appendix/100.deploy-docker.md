# Dockerのインストール

OCPをDocker形式でデプロイする場合、ホストには事前にDockerがインストールされていなければなりません。インストールされていない場合は、まずこのセクションを参照してDockerをインストールしてください。このセクションでは、AliOS上でネットワーク接続を利用したDockerのデプロイ方法のみを紹介します。他のサーバーを使用している場合は、インターネットで情報を検索し、ご自身でDockerをデプロイすることをお勧めします。

## 手順

1. 以下のコマンドを実行してdockerをインストールします。

    ```shell
    yum install docker
    ```

2. 以下のコマンドを実行してdockerを起動します。

    ```shell
    systemctl start docker
    ```
