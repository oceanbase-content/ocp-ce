# デプロイに関するよくある質問

**Q1：デプロイログを確認する方法は何ですか？**

A：OBDでOCPをデプロイした際のログは、デプロイプロセス中に画面上で表示されます。詳細については、[グラフィカルインターフェースを使用したOCPのデプロイ](../500.deploy-ocp.md) の **手順7** を参照してください。

また、画面上のアプリケーションのログファイルからも確認できます。ログファイルのパスは `~/.obd/app.log` です。

**Q2：デプロイログに出力されたエラーが明確ではない場合、より詳細なエラー情報を確認するにはどうすればよいですか？**

A：デフォルトでは、画面上に出力されるログ情報にはdebugやtraceレベルの情報が含まれていません。より詳細な内容を確認するには、OBDのログを確認してください。ログファイルのディレクトリは `~/.obd/log/obd` です。

**Q3：OCPのログを確認する方法は何ですか？**

A：デプロイ方法によって、ログの確認方法は異なります。

* コンテナを使用してOCPをデプロイした場合、ログ情報はコンテナ内部にログインして確認する必要があります。

    ```bash
    # log into ocp container
    docker exec -it ocp bash
    less /home/admin/ocp-server/log/ocp.log
    ```

* OBDを使用してOCPをデプロイした場合、ログ情報はデプロイパスの `log` サブディレクトリに保存されます。

    ```bash
    less ${ocp_home_path}/log/ocp-server.log
    ```
