# インストールプロセス

このセクションでは、コミュニティ版OCPのインストールプロセスについて簡潔に説明します。

インストールプロセスと詳細なインストールタスクの説明は、コミュニティ版OCPのインストール手順を理解するのに役立ち、十分な時間を確保してインストールを行うための指針となります。

以下の表は、具体的なインストールプロセスを示しています。

|   作業段階          |     サブタスク     |          タスクの説明     |
|--------------|------------|------------|
| インストール計画      | [ユーザー計画](300.installation-planning/100.user-planning.md)             | コミュニティ版OCPのデプロイに必要なユーザー計画。   |
| インストール計画   | [ホスト計画](300.installation-planning/200.host-planning.md)    | コミュニティ版OCPのデプロイに必要なホスト計画。     |
| インストール計画    | [ディスク及びディレクトリ計画](300.installation-planning/300.disk-and-directory-management.md)          | コミュニティ版OCPのデプロイにおけるディスク計画（ディスクサイズ）およびデプロイに使用するディレクトリの計画。     |
| インストール計画     | [ポート計画](300.installation-planning/400.port-planning.md)     | コミュニティ版OCPのデプロイで占有するポートの計画。     |
| インストール準備    | [インストール準備](400.installation-preparation.md)     | デプロイ前に、今回のデプロイに必要なソフトウェアパッケージと参照ドキュメントを準備する。     |
| OCPのインストール     | [OCPのデプロイ](500.deploy-ocp.md)           | OCPのデプロイ。       |
| デプロイ後のチェック        | [デプロイ後のチェック](600.check-after-installation.md)     | デプロイ完了後、OCPの機能、ログファイル、OCPバージョン、時刻、Dockerを検証することで、インストールが成功したかどうかを確認できます。     |
