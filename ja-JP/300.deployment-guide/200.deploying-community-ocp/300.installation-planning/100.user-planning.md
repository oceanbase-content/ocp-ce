# ユーザー計画

グラフィカルインターフェースを使用してコミュニティ版OCPをデプロイする場合、デプロイするユーザーにはパスワードレスのsudo権限が付与されていなければなりません。

以下の手順を参考に、ユーザーを手動で作成し（adminを例としますが、実際の状況に応じて変更可能）、sudo権限を付与することができます：

   1.  以下のコマンドを実行して、ユーザーを作成します。

      ```shell
      useradd -U admin -d /home/admin -s /bin/bash
      mkdir -p /home/admin
      sudo chown -R admin:admin /home/admin
      ```

   2.  以下のコマンドを実行して、ユーザーadminのパスワードを設定します。

      ```shell
      passwd admin
      ```

   3.  ユーザーadminにsudo権限を設定します。

      以下のコマンドを実行して、`/etc/sudoers`ファイルを開きます。`/etc/sudoers`ファイルの末尾に以下の内容を追加します：

      ```shell
      ## Same thing without a password
      # %wheel        ALL=(ALL)       NOPASSWD: ALL
      admin       ALL=(ALL)       NOPASSWD: ALL
      ```

   4.  以下のコマンドを実行して、ディレクトリの権限を確認します。

      ```shell
      ls -ld /data
      ls -ld /home/admin
      ```

      次のような結果が返されます：

      ```shell
      drwxr-xr-x 2 admin admin 4096 Feb 9 18:43
      drwxr-xr-x 2 admin admin 4096 Feb 9 18:43 /data
      drwxr-xr-x 2 admin admin 4096 Feb 9 18:43 /home/admin
      ```

      adminユーザーに権限がない場合は、rootユーザーとして以下のコマンドを実行します：

      ```shell
      chown -R admin:admin /data
      chown -R admin:admin /home/admin
       ```

      ここに実際のマウントディレクトリを入力します。ここでの`/data`、`/home/admin`はサンプルのマウントディレクトリです。
