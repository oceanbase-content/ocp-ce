# 概要

コミュニティ版OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、OCP）は、OceanBaseの管理ニーズを持つ中堅・中小規模ユーザー向けに、基本的なホスト管理、OceanBaseクラスタおよびテナントの運用保守などの機能を提供します。

OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、OCP）は、OceanBaseデータベースと共に生まれた、OceanBaseを核とするエンタープライズ向けデータベース管理プラットフォームです。最新バージョンのOCPは、OceanBase V2.2.76からV4.xまでの主要バージョンを全面的にサポートしているだけでなく、一般的なホスト管理、OceanBaseクラスタとテナントの運用保守、バックアップ・リカバリなどの機能を網羅し、精密な監視・アラート機能も提供します。

コミュニティ版OCPは、中堅・中小規模の業務量を対象としているため、限られたリソースで単独でデプロイして使用できるよう、OCPの機能が絞り込まれています。OceanBaseクラスタとテナントの運用保守に関する基本的なニーズを満たすために、必要な基本機能は維持されています。
