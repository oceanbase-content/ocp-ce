# 適切なインデックスが存在しない

## シナリオの概要

このシナリオでは、SQLフィルター条件に適切なインデックスが存在せず、全表スキャンしか行えないため、パフォーマンスが低下します。

## 事例分析

以下の例は、ある業務のSQLが本番環境に導入された後、適切なインデックスが存在せず、パフォーマンスが不安定になったケースです。

## 最適化の推奨事項

* SQLの最適化推奨事項：システムが出力する最適化の推奨事項に従い、適切なフィールドにインデックスを作成します。この例では、(ID,NAME)に通常インデックスを追加することで、全表スキャンを回避できます。

    <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E4%BC%98%E5%8C%96%E5%BB%BA%E8%AE%AE.png) -->

* ビジネスプロセスの推奨事項：コード統合段階でSQLレビューを実施し、インデックスのないSQLが本番環境に導入されるのを防ぐことを推奨します。
