# テナント内のハードパースに時間がかかるSQLを特定する方法

SQLの[実行プロセス](https://docs.oceanbase.com/oceanbase-database/V4.2.1-sql-request-execution-process-concepts)において、SQLがPlanCacheにヒットしない場合、ハードパースが実行され、新しい実行計画と制約条件が生成されます。ハードパースに時間がかかると、SQLの応答時間が長くなり、業務効率に影響します。

TopSQLの**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">カラム管理</UI-TERM>**をクリックし、**<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.ResolutionTime">解析時間</UI-TERM>**を選択してチェックし、**<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.ResolutionTime">解析時間</UI-TERM>**列でソートします。
