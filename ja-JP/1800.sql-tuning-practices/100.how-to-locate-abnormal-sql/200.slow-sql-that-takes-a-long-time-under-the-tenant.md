# テナント内で実行時間が長いスローSQLを特定する方法

スローSQLは、ビジネスのユーザーエクスペリエンスを低下させるだけでなく、データベースのリソースを大量に消費し、データベースの不安定化を引き起こします。そのため、可能な限り様々な観点からスローSQLの数を削減する必要があります。
実行時間が100ミリ秒を超えるSQLを特定する場合、まず **<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">カラム管理</UI-TERM>** で **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.MaximumResponseTime">最大応答時間</UI-TERM>** 列を選択し、次にTopSQLまたはSlowSQLの詳細条件に **最大応答時間 >=  100ms** と入力します。
