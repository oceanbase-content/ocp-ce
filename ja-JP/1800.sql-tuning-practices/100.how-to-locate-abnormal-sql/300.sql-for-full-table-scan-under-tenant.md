# テナント内の全表スキャンSQLを特定する方法

SQLの全表スキャンは大量のリソースを消費します。まず、業務において全表スキャンが必要なセマンティクスが存在するか確認する必要があります。クエリ時にフィルター条件を追加したり、パーティションキーを指定したりすることを推奨します。また、業務テーブルがパーティションテーブルの場合は、グローバルインデックスを追加することで全表スキャンを回避できる可能性があります。

TopSQLで、**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">カラム管理</UI-TERM>** セクションの **<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.TableScan">テーブルスキャン</UI-TERM>** を選択し、**<UI-TERM key="ocp-v2.SQLDiagnosis.attributes.slowSqlAttributes.TableScan">テーブルスキャン</UI-TERM>** 列に基づいてソートすることができます。
