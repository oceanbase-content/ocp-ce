# テナント内のCPU負荷が高いSQLを特定する方法

OceanBaseクラスタの最適化において、SQLのCPU使用率を低下させることは一般的な手法です。CPU負荷が高いSQLから調整を始めることができ、TopSQLのカスタム列機能を利用してCPU負荷が高いSQLを特定できます。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%AB%98CPU-%E8%87%AA%E5%AE%9A%E4%B9%89%E5%88%97.png)

入力式：**@executions * @avgCpuTime** 、列名を **TotalCpuTime** に設定します。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%B7%BB%E5%8A%A0%E5%88%97.png)

表示結果は自動的に **TotalCpuTime** の降順で並べ替えられるため、CPU負荷が高いSQLを容易に見つけることができます。
