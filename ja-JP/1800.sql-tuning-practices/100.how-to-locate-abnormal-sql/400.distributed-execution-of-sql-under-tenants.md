# テナント内の分散実行SQLを特定する方法

OceanBaseは分散データベースであり、クラスタ内の各マシンにデータの読み書きサービスを分散させることをサポートしています。分散実行の効率はローカル実行よりも低いため、OceanBaseはテーブルグループの構文を提供し、業務関連のテーブルを[テーブルグループ](https://docs.oceanbase.com/oceanbase-database/V4.2.1-table-groups-mysql-compatible-mode)にバインドすることで、分散実行をローカル実行に変換し、クエリの効率を向上させます。

単一マシンのTopSQLの**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.ColumnManager.ColumnManagement">カラム管理</UI-TERM>**で、**分散計画の割合(%)**オプションを選択し、**<UI-TERM key="ocp-v2.src.constant.sqlDiagnosis.ProportionOfDistributedPlans">分散プランの割合</UI-TERM>**列でソートするようにします。
