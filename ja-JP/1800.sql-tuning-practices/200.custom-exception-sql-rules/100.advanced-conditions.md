# 上級条件

SQL診断の上級条件では、列管理におけるすべてのメトリクスに対して、合計6種類の演算子を用いた計算フィルタリングをサポートしています。組み合わせることで異常なSQLを絞り込み、上級条件で複数のフィルタ条件を指定できます。

例えば、平均応答時間が100msを超え、かつマルチパーティションスキャンが存在するSQLを特定する場合、上級条件に以下の条件を追加できます：

* **平均応答時間 >= 100**
* **分散実行計画の割合 > 0**

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%AB%98%E7%BA%A7%E6%9D%A1%E4%BB%B6.png)

同時に、上級条件にさらにフィルタ条件を追加することも可能です。例えば、平均応答時間が100msを超え、マルチパーティションスキャンが存在し、かつ解析時間（列管理における**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.RecordTable.PlanGenerationTime">計画生成時間</UI-TERM>**に相当）が10msを超えるSQLを特定する場合、具体的なフィルタ条件の設定は以下の図のとおりです。

![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E9%AB%98%E7%BA%A7%E6%9D%A1%E4%BB%B6%E5%A2%9E%E5%8A%A0.png)

列管理の列に対して様々なフィルタ条件を設定することで、異なるシナリオにおけるニーズに合わせてSQLを検索できます。
