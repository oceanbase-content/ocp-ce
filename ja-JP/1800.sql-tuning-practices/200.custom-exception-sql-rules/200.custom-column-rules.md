# カスタム列ルール

SQL診断に組み込まれている列定義では業務上必要な検索条件を十分に表現できない場合、カスタム列を定義することで補うことができます。カスタム列の設定はTopSQLの指標に基づいており、**+**、**-**、**\***、**/** 演算子をサポートしています。カスタム列を追加すると、TopSQLはそのカスタム列に従ってソートされます。

例：OceanBaseデータベースノードでディスク帯域幅が飽和するケースが発生した場合、どのSQLが大量のディスクI/Oを引き起こしているかを特定する必要があります。そのため、各SQLの実行過程で発生した総ディスク読み取り回数を確認する必要があります。

1. カスタム列の設定：カスタム列の式を **@avgDiskReads * @executions**、列名を **TotalDiskReads** とします。

2. **TotalDiskReads** カスタム列に従ってソートします。
