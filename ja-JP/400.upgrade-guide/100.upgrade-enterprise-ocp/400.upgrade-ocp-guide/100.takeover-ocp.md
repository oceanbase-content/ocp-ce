# OCPの引き継ぎ

OCPをアップグレードする前に、まずOCPをOATに引き継ぐ必要があります。

## 前提条件

OCPを引き継ぐ前に、以下の情報を確認してください：

* OATがインストール済みであること。詳細については、[OATのインストール](https://docs.oceanbase.com/oat/V4.5.1-install-oat)を参照してください。

* OATに、OCPで使用されるイメージが追加されていること。

* OATで、OCPが依存するコンポーネントの引き継ぎが完了していること。

* OATに、引き継ぐOCPのサーバーが追加されていること。詳細については、[サーバーの追加](https://docs.oceanbase.com/oat/V4.4.1-add-servers)を参照してください。

* サーバーがOCPの引き継ぎ要件を満たしていること。詳細については、[OCPリソース計画](https://docs.oceanbase.com/ocp/V4.4.2-prepare-host)を参照してください。

## 手順

1. OATにログインします。

2. 左側のナビゲーションバーで、**プロダクトサービス \> プロダクト管理** をクリックします。

3. **プロダクト管理** ページで、右上の **プロダクトの引き継ぎ** をクリックし、**OCPの引き継ぎ** を選択します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%8E%A5%E7%AE%A1ocp-1.png) -->

4. **OCPの引き継ぎ** ページで、各パラメータを設定します。

   1. OCPの基本設定パラメータは以下のとおりです：

      | **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.ServerParamInfoTable.Parameter">パラメータ</UI-TERM>** | **<UI-TERM key="ocp-v2.TakeOver.Component.ParameterDiffDrawer.Description">説明</UI-TERM>**    |
      |--------|-----------|
      | OCPイメージ | OCPのDockerイメージ。     |
      | プロダクト名   | プロダクト名。他のプロダクトと重複してはなりません。   |
      | サーバー    | 引き継ぐOCPのサーバーIPアドレス。      |
      | CPU    | サーバー上でOCPが使用可能なCPU。デフォルトは8C。 |
      | メモリ     | サーバー上でOCPが使用可能なメモリ。デフォルトは20GB。 |

      <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%8E%A5%E7%AE%A1ocp-2.png) -->

   2. OCPメタデータベースMetaDBの設定パラメータは以下のとおりです：

      | **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.TenantParamInfoTable.Parameter">パラメータ</UI-TERM>**        | **<UI-TERM key="ocp-v2.Alarm.Rule.Description">説明</UI-TERM>**       |
      |---------------|-----------|
      | ストレージデータベースタイプ       | MetaDBのタイプを選択します。**MetaDB作成済み** と **その他のOB_MySQL** が含まれます。 |
      | 既存のMetaDBを選択 | OCPに対して既存のMetaDBを選択します。         |

      <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%8E%A5%E7%AE%A1ocp-3.png) -->

   3. （オプション）ロードバランシングの設定パラメータは以下のとおりです。

      | **<UI-TERM key="ocp-performance-report.ReportTables.ParameterStatInfo.TenantParamInfoTable.Parameter">パラメータ</UI-TERM>**           | **<UI-TERM key="ocp-v2.Auth.Role.Description">説明</UI-TERM>**    |
      |----------|------------|
      | ロードバランシングモード           | ロードバランシングモードを選択します。**既存のOBDNS**、**その他のロードバランシング**、**既存のNLB**、**使用しない**が含まれます。 |
      | MetaDB TCPプロキシIPアドレス | **その他のロードバランシング**モードを選択した場合に表示されます。MetaDBに接続するためのTCPプロトコルアドレスを入力します。                       |
      | MetaDB TCPプロキシポート番号 | **その他のロードバランシング**モードを選択した場合に表示されます。TCPプロトコルのポート番号を入力します。                                  |
      | HTTPプロキシドメイン名        | **既存のOBDNS**モードを選択した場合に表示されます。OCPのコンソールにアクセスするためのHTTPプロトコルアドレスを入力します。                 |
      | HTTPプロキシポート        | HTTPプロトコルのポート番号。                                                        |

      <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/410/%E6%8E%A5%E7%AE%A1ocp-4.png) -->

5. OCPの引き継ぎ設定が完了したら、**<UI-TERM key="ocp-v2.Inspection.Item.ConfigRule.Submit">送信</UI-TERM>**をクリックします。設定に誤りがある場合は、**<UI-TERM key="ocp-v2.SQLDiagnosis.Component.FieldListDrawer.Reset">リセット</UI-TERM>**をクリックすると、デフォルト設定にワンクリックで戻すことができます。
