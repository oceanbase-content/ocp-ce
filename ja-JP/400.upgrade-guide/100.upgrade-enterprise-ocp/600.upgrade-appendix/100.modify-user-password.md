# ユーザーパスワードの変更

この記事では、ユーザーのパスワードを変更する方法について説明します。

## 前提条件

現在ログインしているユーザーがシステム管理者（ADMIN）またはユーザー管理者（USER_MANAGER）ロールを持っていること。

## 手順

1. OCPにログインします。

2. 左側のナビゲーションバーで **システム管理 > ユーザー管理** をクリックします。

3. **<UI-TERM key="ocp-v2.Auth.User">ユーザー</UI-TERM>** タブで、ユーザーリストの **<UI-TERM key="ocp-v2.MultiAzone.Parameter.Operation">操作</UI-TERM>** 列の **<UI-TERM key="ocp-v2.Auth.User.Detail.ChangePassword">パスワードの変更</UI-TERM>** をクリックします。

   システムはユーザーパスワード変更ダイアログを表示します。

4. ダイアログに新しいパスワードを入力します。

   <!-- ![1](https://obbusiness-private.oss-cn-shanghai.aliyuncs.com/doc/img/ocp/403-cn/%E4%BF%AE%E6%94%B9%E7%94%A8%E6%88%B7%E5%AF%86%E7%A0%81.png) -->

   パスワードの複雑さ要件は以下の通りです：長さが8～32文字で、数字（0～9）、大文字（A～Z）、小文字（a～z）、特殊文字の4種類のうち、少なくとも3種類を含む必要があります。サポートされている特殊文字は <code>~!@#%^&*_-+=\|(){}[]:;,.?/</code> です。

5. **<UI-TERM key="ocp-v2.Detail.Component.FailoverStandbyTenantModal.Ok">確定</UI-TERM>** をクリックします。
