# アップグレードの概要

このドキュメントでは、OceanBaseクラウドプラットフォーム（OceanBase Cloud Platform、OCP）管理者の操作面から、OCPのアップグレードに関する注意事項、アップグレード前の準備、アップグレードの実施、アップグレード後のチェック、およびアップグレード失敗時のロールバックなどの操作について簡潔に説明します。

このドキュメントでは、OCP V3.2.4以降のバージョンから最新バージョンへのアップグレード手順を詳しく説明します。アップグレードの必要に応じて、このドキュメントを参照してOCPのバージョンをアップグレードできます。

<main id="notice" type='explain'>
<h4>説明</h4>
OCP V3.2.4以前のバージョンからのアップグレード手順については、テクニカルサポートにお問い合わせください。
</main>
